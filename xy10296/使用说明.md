# 社区AED点检提醒器 - 使用说明

## 一、项目概述

本工具用于管理社区AED设备的日常点检工作，解决以下痛点：
- **设备档案**：统一管理AED设备的基本信息、安装位置
- **点检计划**：定期安排志愿者点检，落实责任到人
- **耗材效期**：自动监控电极片、电池的有效期，提前预警
- **漏检追责**：记录志愿者签到，未按时点检自动标记漏检
- **异常复核**：点检报告存在问题时进入待复核流程

## 三、命令总览

```bash
python main.py --help                    # 查看帮助
python main.py import-devices <file>     # 导入设备档案
python main.py import-volunteers <file>  # 导入志愿者
python main.py import-supplies <file>    # 导入耗材信息
python main.py import-plans <file>       # 导入点检计划
python main.py checkin <plan_id>         # 志愿者签到
python main.py submit-report <file>      # 提交点检报告
python main.py check                     # 运行检查（效期+漏检+待复核）
python main.py query-exceptions          # 查询未解决异常
python main.py query-pending             # 查询待复核报告
python main.py review <id> --approved    # 复核通过
python main.py review <id> --rejected    # 复核驳回
python main.py export --format txt       # 导出报告
python main.py dashboard                 # 查看仪表板
python main.py list-devices              # 列出设备
python main.py list-volunteers           # 列出志愿者
python main.py clear-data                # 清空数据
```

## 六、核心业务规则说明

### 1. 耗材效期检查
- **预警阈值**：30天内到期
- **紧急级别**：已过期（days_left ≤ 0）
- **预警级别**：30天内到期但未过期
- **数据来源**：`supplies.json` 中的 `expiration_date`

### 2. 漏检判断
- **判断条件**：计划日期 < 当前日期，且状态为待处理
- **自动操作**：标记为漏检，创建异常记录
- **责任追踪**：异常记录包含志愿者姓名和联系电话

### 3. 报告复核机制
- **触发条件**：电极片异常 OR 电池异常 OR 位置标识不清晰
- **处理流程**：
  1. 志愿者提交报告
  2. 系统检测到问题 → 自动进入待复核
  3. 管理员通过 `review` 命令复核（通过/驳回）
- **正常报告**：所有检查项OK → 自动通过，无需复核

### 4. 签到验证
- 必须先签到才能提交报告
- 已完成的计划不能重复签到
- 已标记漏检的计划不能签到

## 七、数据格式说明

### 设备档案 (devices.json)
```json
{
  "device_id": "AED-001",           // 必填，设备唯一标识
  "location": "阳光社区1号楼",      // 必填，位置描述
  "floor": "1",                     // 必填，楼层
  "room": "大厅入口处",             // 必填，具体位置
  "model": "Philips HeartStart FRx", // 必填，设备型号
  "serial_number": "SNF12345678",   // 必填，序列号
  "installation_date": "2024-01-15" // 必填，安装日期
}
```

### 点检报告 (report.json)
```json
{
  "plan_id": "PLAN-001",            // 必填，关联的计划ID
  "electrode_pads_ok": true,        // 必填，电极片是否正常
  "battery_ok": true,               // 必填，电池是否正常
  "location_visible": true,         // 必填，位置标识是否清晰
  "device_clean": true,             // 必填，设备是否清洁
  "overall_status": "good"          // 必填，整体状态
}
```

## 八、常见问题

**Q: 如何重复导入数据？**
A: 系统支持重复导入，相同ID的记录会被更新覆盖。

**Q: 如何重跑检查？**
A: 随时执行 `python main.py check`，系统会重新扫描所有数据。

**Q: 导出的报告在哪里？**
A: 在 `exports/` 目录下，文件名包含时间戳。

**Q: 数据存储在哪里？**
A: 在 `data/` 目录下的JSON文件中，可以直接查看或备份。
