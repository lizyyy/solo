# 消防分区材料追踪 · BIM 协调工作台

面向 BIM 协调员小岑的消防分区材料送审追踪系统。
**统一数据源** 驱动：筛选条件、统计卡片、明细表、历史时间线 全部来自同一结果集。

---

## 🚀 快速上手（2 步）

### ① 启动
```bash
pnpm install   # 首次运行需要
pnpm dev       # 启动后浏览器访问 http://localhost:5173
```

### ② 日常处理
1. **选分区** → 顶部筛选面板选消防分区 / 状态，或直接点统计卡片联动筛选
2. **看详情** → 左侧明细表点任意一行 → 右侧抽屉打开
3. **改状态** → 明细表「确认/待补/退回」按钮 **强制填原因** → 原因写入历史时间线

---

## 🚨 坏材料来了该看哪里

按这个顺序，不会漏：

| 顺序 | 看什么 | 位置 | 说明 |
|------|--------|------|------|
| 1 | **图层异常说明卡** | 详情抽屉最顶部 | 🔴 红色边框 = 图层命名混乱；异常原因、建议修正方式、受影响图层 **全部写清楚**，不会在报表里冒充「已通过」 |
| 2 | **交底清单 vs 旧意见 比对** | 详情抽屉第二块 | 🟥 红底高亮 = 旧意见 **遗漏** 没出现在本次交底；🟢 绿底 = 本次新增意见；灰底 = 已覆盖的旧意见 |
| 3 | **后补备注处理过程** | 详情抽屉第三块 | 点「新增后补备注」→ 备注内容 + **处理过程（强制分步写清楚联系了谁 / 做了什么）** + 处理状态 + 处理结果描述；每条都留在记录旁边 |
| 4 | **历史变更时间线** | 详情抽屉底部 | 每次改判断都有「旧值 → 新值」和 **变更原因**；不是只给你看最终值，交接班全靠它 |

> 月底：切到「月底复核」标签 → 已确认 / 待补件 / 退回 三栏分列，**拖拽卡片换列就会弹原因框**，填完写入历史。

---

## 关键保障

- **改状态必填原因**：按钮 / 拖拽改状态都弹窗强制填写，空内容不能提交
- **原因全程可见**：时间线倒序展示 旧值→新值→原因，下一班同事不会停在「只看到最终值」
- **异常即红标**：图层异常记录表格左侧红竖条 + 异常标签，详情卡片红色条纹底，一眼能认出
- **数据持久化**：所有变更自动存 `localStorage`；右上角「重置数据」可回到示例数据
