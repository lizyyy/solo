# 中学实验器材预约台

## 安装运行

1. 安装依赖：
```bash
npm install
```

2. 启动服务：
```bash
npm start
```

3. 访问系统：
浏览器打开 http://localhost:3000

## 样例入口

首页点击 **"加载示例数据"** 按钮，会自动初始化：
- 8 个器材档案（含物理、化学、生物三类）
- 5 个班级（高一到高三）
- 5 条预约记录（覆盖普通器材自动确认、危险器材待审批、易耗品自动扣减）

## 核心操作

### 1. 器材管理
- **新增**：点击"新增器材"，填写名称、学科、类型（普通/危险）、是否易耗品、库存等信息
- **修改**：点击器材列表中的"修改"按钮
- **删除**：点击"删除"按钮

### 2. 预约管理
- **新增预约**：
  - 选择班级和器材，填写数量和预约日期
  - 普通器材：自动确认状态
  - 危险器材：进入待审批状态
  - 易耗品：确认后自动扣减库存

- **审批流程**（仅危险器材）：
  - **确认**：点击"确认"，填写审批人后通过
  - **拒绝**：点击"拒绝"，填写审批人后驳回
  - **修改**：仅待审批状态可修改

- **完成预约**：已确认状态可标记为完成

### 3. 数据导出
- **导出器材档案**：点击"导出器材档案"按钮（Excel格式）
- **导出预约记录**：点击"导出预约记录"按钮（Excel格式）

## 如何检查结果

### 1. 统计信息
首页顶部统计面板实时显示：
- 总预约数、待审批、已确认、已拒绝、已完成数量
- 危险器材数量、易耗品种类
- 各易耗品已扣减数量

### 2. 易耗品扣减验证
1. 加载示例数据后，查看"pH试纸"库存：初始 500 条
2. 高二(1)班预约了 20 条 pH试纸（普通易耗品，自动确认）
3. 统计面板会显示 "pH试纸 已扣减: 20"
4. 器材档案中 pH试纸 库存变为 480 条

### 3. 危险器材审批验证
1. 查看预约列表中"高二(2)班 - 浓硫酸"
2. 状态应为"待审批"（危险器材需要审批）
3. 点击"确认"填写审批人后，状态变为"已确认"
4. 统计面板中"待审批"减少，"已确认"增加

### 4. 数据幂等性验证
- 多次点击"加载示例数据"不会重复创建记录
- 统计数据、库存数量、导出文件不会膨胀
- 可删除 `data/lab.db` 文件后重新启动服务进行完整重置

### 5. 导出文件检查
- 导出的 Excel 文件保存在 `exports/` 目录
- 预约记录包含：班级、器材、数量、状态、审批信息等
- 器材档案包含：名称、学科、类型、是否易耗品、库存等
