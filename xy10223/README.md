# 面包房发酵批次看板

管理面包房多批面团发酵的温度、时间和阶段流转。

## 安装运行

```bash
npm install
npm run dev
```

## 样例入口

打开应用后，点击顶部工具栏的 **"加载样例数据"** 按钮，即可看到 4 个不同阶段的批次样例。

## 核心操作

1. **查看批次**：看板按发酵阶段分为 5 列（预发酵、基础发酵、中间醒发、最终醒发、已完成）
2. **查看详情**：点击任意批次卡片，右侧显示完整信息
3. **记录温度**：在批次详情中点击 **"记录温度"**，输入温度值和可选备注
4. **阶段流转**：在批次详情中点击 **"转至下一阶段"**，选择目标阶段并添加备注
5. **查看统计**：点击 **"显示统计"** 查看总体数据和阶段分布

## 检查结果

### 1. 数据一致性
- 重跑"加载样例数据"不会创建重复批次
- 重复导入已存在的批次会自动去重（按批次编号）

### 2. 导出文件
- **导出 JSON**：完整数据结构，包含所有温度记录和阶段流转历史
- **导出批次 CSV**：批次汇总信息
- **导出温度记录**：所有温度记录的详细 CSV

### 3. 统计验证
- 总批次数 = 各阶段数量之和
- 进行中 + 已完成 = 总批次数
- 平均温度基于所有温度记录计算

## 技术说明

- React 19 + TypeScript
- Vite 构建
- 本地存储持久化
- 无需后端即可完整运行
