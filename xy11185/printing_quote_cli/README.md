# 印刷报价组 - 印刷工艺报价 CLI 处理工具

专门用于处理印刷工艺报价CSV文件的命令行工具，针对起印量、覆膜加价、可复跑等核心业务字段进行验证。

## 项目结构

```
printing_quote_cli/
├── src/
│   └── printing_quote_cli.py    # 主CLI脚本
├── tests/
│   └── test_printing_quote_cli.py  # 测试用例
├── samples/
│   ├── normal/      # 正常文件样例
│   ├── bad/         # 坏文件样例（缺列、格式错误等）
│   └── empty/       # 空文件样例
└── README.md
```

## 样例文件说明

### 正常文件 (samples/normal/)
- `报价单_2024_001.csv` - 完整的5条报价记录
- `报价单_2024_002.csv` - 名片、传单等业务报价
- `报价单_2024_003.csv` - 精装书壳、贺卡等特殊工艺报价

### 坏文件 (samples/bad/)
- `报价单_缺起印量列.csv` - 缺少关键业务列"起印量"
- `报价单_缺覆膜加价列.csv` - 缺少关键业务列"覆膜加价"
- `报价单_缺可复跑列.csv` - 缺少关键业务列"可复跑"
- `报价单_重复行.csv` - 包含重复订单号记录
- `报价单_格式错误.csv` - 数值字段格式错误

### 空文件 (samples/empty/)
- `报价单_完全空.csv` - 0字节空文件
- `报价单_只有表头.csv` - 只有CSV表头，没有数据
- `报价单_只有空行.csv` - 只包含空行

## 核心功能

1. **必填列验证** - 检查订单号、起印量、覆膜加价、可复跑等必填列
2. **重复行检测** - 按订单号检测重复记录
3. **数值格式验证** - 验证起印量、覆膜加价等数值字段
4. **可复跑验证** - 检查可复跑字段是否为"是/否"
5. **错误后继续处理** - 遇到关键业务列问题时记录原因并继续处理其他文件
6. **友好错误提示** - 提供可读的错误信息，而非traceback

## 使用方法

### 处理单个文件
```bash
python3 src/printing_quote_cli.py samples/normal/报价单_2024_001.csv
```

### 处理目录下所有文件
```bash
python3 src/printing_quote_cli.py samples/
```

### 同时处理多个目录或文件
```bash
python3 src/printing_quote_cli.py samples/normal/ samples/bad/
```

### 查看帮助
```bash
python3 src/printing_quote_cli.py --help
```

## 运行测试

```bash
python3 tests/test_printing_quote_cli.py
```

测试覆盖范围：
- 正常文件读取和验证
- 缺列检测（起印量、覆膜加价、可复跑）
- 重复行检测
- 格式错误验证
- 空文件处理
- 部分文件失败后的继续处理

## 业务说明

### 关键业务列
- **起印量** - 印刷订单的最低起印数量，必须是数字
- **覆膜加价** - 覆膜工艺的额外费用，必须是数字
- **可复跑** - 该订单是否可以重复印刷，必须是"是"或"否"

### 继续处理规则
当遇到以下情况时，CLI会记录原因并继续处理剩余文件：
- 空文件或只有空行
- 缺少起印量列
- 缺少覆膜加价列
- 缺少可复跑列
