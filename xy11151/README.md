# 展会搭建队展会费用归集 CLI

专门为展会搭建队设计的费用归集工具，支持多文件输入、稳定识别临时加项和供应商返款，输出结果按稳定顺序排列，方便后续追责复盘和diff对比。

## 功能特性

- ✅ **多文件批量处理**: 支持同时处理多个CSV文件
- ✅ **稳定ID生成**: 基于关键信息生成MD5哈希，确保相同记录ID不变
- ✅ **临时加项识别**: 自动识别包含"临时加"、"增加"、"加急"等关键词的费用
- ✅ **供应商返款识别**: 自动识别负金额和包含"返款"、"退款"、"折扣"等关键词的记录
- ✅ **智能分类**: 自动识别费用类别（主场搭建、特装搭建、电气设备等）
- ✅ **去重处理**: 自动去除重复记录
- ✅ **稳定输出列顺序**: 输出列顺序固定，方便diff对比
- ✅ **详细摘要报告**: 显示成功、跳过、失败的详细统计

## 安装

```bash
npm install
npm link
```

## 使用方法

### 基本使用

```bash
# 处理单个文件
exhibition-cost examples/广交会主场搭建费用.csv -o output.csv

# 处理多个文件
exhibition-cost examples/*.csv -o output.csv

# 指定输出文件
exhibition-cost examples/*.csv -o 费用归集结果.csv
```

### 命令选项

```
-o, --output <file>    输出文件路径 (默认: cost-collection-output.csv)
-s, --summary          显示详细摘要报告 (默认: true)
-h, --help             显示帮助信息
```

## 输入文件格式

支持以下列名（中英文均可）：

| 中文列名 | 英文列名 | 说明 |
|---------|---------|------|
| 展会名称 | exhibitionName | 展会名称 |
| 费用项目 | itemName | 具体费用项目 |
| 供应商 | supplier | 供应商名称 |
| 金额 | amount | 费用金额（负数表示返款） |
| 日期 | recordDate | 记录日期 |
| 项目经理 | projectManager | 项目经理姓名 |
| 搭建队 | constructionTeam | 搭建队名称 |
| 付款状态 | paymentStatus | 付款状态 |
| 发票状态 | invoiceStatus | 发票状态 |
| 备注 | remarks | 备注信息 |

## 输出文件列顺序（固定）

1. `uniqueId` - 稳定唯一ID（MD5哈希）
2. `exhibitionName` - 展会名称
3. `itemType` - 收支类型（支出/收入）
4. `itemCategory` - 费用类别
5. `itemName` - 费用项目
6. `supplier` - 供应商
7. `amount` - 金额
8. `isTemporaryAdd` - 是否临时加项（是/否）
9. `isSupplierRefund` - 是否供应商返款（是/否）
10. `recordDate` - 记录日期
11. `projectManager` - 项目经理
12. `constructionTeam` - 搭建队
13. `paymentStatus` - 付款状态
14. `invoiceStatus` - 发票状态
15. `remarks` - 备注
16. `sourceFile` - 来源文件
17. `processedAt` - 处理时间

## 样例数据

项目包含3个真实业务场景的样例文件：

1. **广交会主场搭建费用.csv** - 广交会主场搭建费用，包含：
   - 铝合金桁架搭建
   - 舞台木板铺设
   - 临时加LED屏租赁（临时加项）
   - 供应商返款-桁架折扣（返款）

2. **上海进博会特装搭建费用.csv** - 上海进博会特装费用，包含：
   - 特装展台设计制作
   - 加急喷绘画面制作（临时加项）
   - 供应商折扣-特装优惠（返款）

3. **北京建材展费用.csv** - 北京建材展费用，包含：
   - 增加接待台制作（临时加项）
   - 返利-长期合作优惠（返款）

## 可复跑性验证

本工具设计为**可复跑**，即：
- 相同输入文件多次运行，生成的`uniqueId`完全一致
- `isTemporaryAdd`和`isSupplierRefund`标记稳定不变
- 输出列顺序固定，方便使用diff工具进行对比
- 去重逻辑稳定，不会出现"第一次报、第二次消失"的情况

## 业务价值

1. **追责复盘有据可依**: 每条记录有稳定ID，临时加项清晰标记
2. **供应商返款透明**: 自动识别所有返款/折扣记录，防止遗漏
3. **多文件统一管理**: 不同展会、不同供应商的费用统一归集
4. **便于审计对比**: 稳定输出格式，支持diff对比不同批次
