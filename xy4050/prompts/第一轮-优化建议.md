原始想法：
我想做一个给园区安全员用的本地桌面应用，叫“应急演练观察合并台”。我们做消防疏散或反恐演练时，楼层观察员、门岗和医务点会各自拿手机或纸表记录事件：报警响起、某楼层开始疏散、通道拥堵、人员折返、伤员处置、集合点清点等。复盘时最痛苦的是各组时间不一致、同一事件重复记录、照片编号和事件对不上，最后只能靠微信群一点点拼。请从 0 到 1 做一个可运行的桌面 GUI 项目：能创建一次演练档案，维护区域、观察员、事件类型、风险等级和标准时间轴；支持导入多个观察员 CSV/JSON 记录，字段包括来源、原始时间、区域、事件类型、描述、人数、照片编号和备注，导入时要校验缺字段、时间格式、未知区域、未知事件类型、同一来源重复编号，并把坏记录放进待处理列表而不是直接丢掉。应用要能把不同来源的记录按可配置的时钟偏移合并到统一时间线，识别可能重复事件、时间倒挂、关键节点缺失、同一区域连续高风险事件、照片编号未引用这些问题；用户可以在界面上确认合并、拆分误合并、手动修正时间偏移、给事件打复盘标签。所有演练档案、导入批次、人工修正和问题处理状态都要保存在本地，重启后还能继续。还要能导出 Markdown 复盘报告、CSV 事件明细和 JSON 完整档案。希望代码拆成 GUI 界面、档案模型、导入解析与校验、时间偏移/合并算法、问题检测、持久化、导出报告、示例数据和测试，不要写成一个大脚本。README 里写清楚安装、启动，以及如何用示例数据验证创建档案、导入多组记录、处理坏记录、自动合并、人工修正、刷新恢复和导出报告这些核心流程。
