# 应急演练观察合并台

一个给园区安全员使用的本地桌面应用，用于整合和分析消防疏散、反恐演练等应急事件记录。

## 功能特点

- **演练档案管理**: 创建和管理演练档案，维护区域、观察员、事件类型等基础数据
- **多源数据导入**: 支持导入多个观察员的CSV/JSON记录
- **智能数据校验**: 导入时校验缺字段、时间格式、未知区域/事件类型、重复编号
- **时间偏移校准**: 支持可配置的时钟偏移，将不同来源的记录合并到统一时间线
- **重复事件检测**: 自动识别可能重复的事件
- **问题自动检测**: 检测时间倒挂、关键节点缺失、连续高风险事件、照片未引用等问题
- **多格式导出**: 支持导出Markdown复盘报告、CSV事件明细、JSON完整档案
- **本地数据持久化**: 所有数据保存在本地SQLite数据库，重启后恢复

## 技术栈

- **语言**: Python 3.9+
- **GUI框架**: PyQt6
- **数据库**: SQLite (本地文件存储)
- **数据格式**: CSV/JSON 导入导出

## 核心功能使用指南

### 1. 创建演练档案

1. 点击左侧面板的 **"新建"** 按钮，或通过菜单 **文件 → 新建演练**
2. 填写演练信息：
   - **演练名称**: 例如 "2024年Q2消防疏散演练"
   - **演练编号**: 例如 "DRILL-2024-Q2-001"
   - **演练类型**: 选择类型（消防疏散、反恐等）
   - **时间设置**: 设置计划和实际的开始/结束时间
   - **描述**: 填写演练目的、场景等信息
3. 点击 **"OK"** 完成创建

演练会显示在左侧列表中，点击选择即可查看详情。

### 2. 导入记录

应用提供了示例数据文件，位于 `samples/` 目录下：
- `floor_observer.csv` - 楼层观察员记录
- `gate_guard.csv` - 门岗记录
- `medical_station.csv` - 医务点记录
- `test_with_errors.csv` - 包含错误数据的测试文件

**导入步骤：**

1. 在左侧列表选择一个演练
2. 点击 **"导入记录"** 按钮，或菜单 **文件 → 导入记录**
3. 在导入对话框中：
   - 点击 **"浏览"** 选择CSV或JSON文件
   - 选择 `samples/floor_observer.csv` 作为第一个测试文件
   - **来源名称** 会根据文件名自动填充（例如："楼层观察员"）
4. 点击 **"解析"** 按钮预览数据
5. 查看 **"问题记录"** 选项卡，确认是否有校验错误
6. 点击 **"导入"** 完成导入

**重复以上步骤**，分别导入 `gate_guard.csv` 和 `medical_station.csv`。

### 3. 处理坏记录

使用 `samples/test_with_errors.csv` 测试校验功能：

1. 选择一个演练后，点击 **"导入记录"**
2. 选择 `samples/test_with_errors.csv`
3. 点击 **"解析"**
4. 查看 **"问题记录"** 选项卡，你会看到：
   - 第2行: 缺少来源和时间（严重错误）
   - 第3行: 无效的时间格式（错误）
   - 第4行: 未知区域代码（错误）
   - 第5行: 未知事件类型（错误）
   - 第8行: 照片编号重复（警告）
5. 统计信息显示：
   - 总记录: 7
   - 有效: 2 (第6、7行)
   - 无效: 4
   - 警告: 1
6. 点击 **"导入"**，所有记录（包括无效的）都会被保存，状态会被标记

**注意**: 坏记录不会被丢弃，而是标记为 `is_valid=False`，供后续人工处理。

### 4. 自动合并时间线

1. 导入多个来源的数据后（楼层观察员、门岗、医务点）
2. 选择演练，点击 **"检测重复"** 按钮
3. 系统会分析事件相似度，找出潜在的重复事件
4. 点击 **"自动合并"** 进行事件合并
5. 查看合并结果提示

**时间偏移校准（可选）：**

如果不同来源的时钟不一致：

1. 切换到 **"时间偏移"** 选项卡
2. 点击 **"自动估算偏移"** - 基于共同锚点事件（如ALARM_START）自动计算偏移
3. 或手动编辑表格中的 **"偏移量(秒)"** 列
4. 点击 **"应用偏移到事件"** 保存偏移

### 5. 问题检测

1. 选择演练后，点击 **"检测问题"** 按钮
2. 系统会自动检测以下问题：
   - **时间倒挂**: 事件时间顺序异常
   - **时间间隙**: 时间段内无事件记录
   - **关键节点缺失**: 缺少ALARM_START、EVAC_START、DRILL_END等关键事件
   - **连续高风险**: 同一区域短时间内多个高风险事件
   - **照片未引用**: 照片编号未被任何事件引用
3. 查看 **"问题检测"** 选项卡中的问题列表
4. 选择问题后，可以：
   - **标记已解决**: 确认问题已处理
   - **忽略**: 标记为可忽略的问题

### 6. 人工修正

1. **修改时间偏移**:
   - 切换到 **"时间偏移"** 选项卡
   - 直接编辑表格中的 **"偏移量(秒)"** 单元格
   - 正偏移：该来源时间提前
   - 负偏移：该来源时间延后

2. **处理问题**:
   - 在 **"问题检测"** 选项卡中
   - 选择问题后点击 **"标记已解决"** 或 **"忽略"**

### 7. 刷新恢复

- **数据持久化**: 所有数据自动保存到本地SQLite数据库
- **重启恢复**: 关闭应用后重新打开，所有数据会自动恢复
- **刷新**: 左侧列表会显示所有演练档案，选择后自动加载相关数据

### 8. 导出报告

选择演练后，可以导出三种格式：

#### 导出CSV事件明细

1. 点击 **"导出CSV"** 按钮，或菜单 **文件 → 导出 → CSV事件明细**
2. 选择保存位置
3. 导出包含所有事件的详细CSV文件

#### 导出Markdown复盘报告

1. 点击 **"导出报告"** 按钮，或菜单 **文件 → 导出 → Markdown复盘报告**
2. 选择保存位置
3. 报告包含：
   - 演练基本信息
   - 导入批次统计
   - 时间偏移配置
   - 事件时间线（按时间排序）
   - 问题检测报告
   - 照片引用统计

#### 导出JSON完整档案

1. 菜单 **文件 → 导出 → JSON完整档案**
2. 选择保存位置
3. 导出包含所有数据的JSON文件，可用于备份或迁移

## 支持的数据格式

### CSV格式

CSV文件应包含以下列（支持字段别名）：

| 字段名 | 别名 | 必需 | 说明 |
|--------|------|------|------|
| 来源 | source, observer, 观察员 | 是 | 记录来源名称 |
| 时间 | time, timestamp, 原始时间 | 是 | 事件发生时间 |
| 区域 | area, location, zone | 是 | 区域代码 |
| 事件类型 | type, event_type, 类型 | 是 | 事件类型代码 |
| 描述 | description, 描述 | 否 | 事件描述 |
| 人数 | person_count, count | 否 | 涉及人数 |
| 照片编号 | photo, photo_number, photos | 否 | 照片编号（逗号分隔） |
| 备注 | notes, remark | 否 | 备注信息 |

**时间格式支持：**
- `2024-06-15 09:00:00`
- `2024-06-15 09:00`
- `2024/06/15 09:00:00`
- `20240615 090000`
- `09:00:00` (使用默认日期)
- `09:00` (使用默认日期)

**示例：**
```csv
来源,时间,区域,事件类型,描述,人数,照片编号,备注
楼层观察员,2024-06-15 09:00:00,OFFICE_A,ALARM_START,消防警报响起,0,PH001,首次警报
楼层观察员,2024-06-15 09:01:30,OFFICE_A_10F,EVAC_START,10层开始疏散,25,PH002,
```

### JSON格式

支持以下结构：

```json
[
  {
    "来源": "楼层观察员",
    "时间": "2024-06-15 09:00:00",
    "区域": "OFFICE_A",
    "事件类型": "ALARM_START",
    "描述": "消防警报响起",
    "人数": 0,
    "照片编号": "PH001",
    "备注": "首次警报"
  }
]
```

或使用英文字段：

```json
[
  {
    "source": "楼层观察员",
    "time": "2024-06-15 09:00:00",
    "area": "OFFICE_A",
    "event_type": "ALARM_START",
    "description": "消防警报响起"
  }
]
```

## 常见问题

### Q: 数据存储在哪里？

A: 所有数据存储在 `data/drill_db.sqlite` 数据库文件中。可以备份这个文件来备份所有数据。

### Q: 如何修改默认区域和事件类型？

A: 当前版本默认数据在 `models/area.py` 和 `models/event_type.py` 中定义。后续版本可能会添加GUI配置界面。

### Q: 支持同时打开多个演练吗？

A: 当前版本每次只能查看一个演练，但可以在左侧列表中快速切换。

### Q: 导入的记录可以删除吗？

A: 可以通过删除整个演练来清除所有相关记录。单条记录删除功能可以通过扩展实现。

### Q: 如何迁移数据到另一台电脑？

A: 复制整个项目目录（特别是 `data/` 文件夹）到目标电脑即可。
