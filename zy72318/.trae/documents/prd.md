## 1. 产品概述

风险价值 VaR 回放系统——面向竞赛教练与活动负责人的风险计算复核工具，核心使命是让问卷原始行、边界值说明备注、计算明细三者之间任何不一致都可见、可追溯、可裁决，而非被系统自动"归正常"。

- 目标用户：竞赛教练（唐老师等）、活动负责人
- 核心价值：杜绝数据被静默清洗，保障边界值备注比正式表更受重视，让每一次修改都有据可查

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 竞赛教练 | 系统分配 | 导入问卷、补看边界值说明、裁决冲突、查看计算明细 |
| 活动负责人 | 系统分配 | 复核百分数/小数混搭记录、审批教练裁决、导出最终结果 |

### 2.2 功能模块

1. **回放工作台**：问卷原始行导入 → 教练补看边界值说明 → 计算明细更新三步流程
2. **冲突与复核**：原始行与边界值说明矛盾时列出冲突证据，教练确认或驳回；百分数/小数混搭标记待复核
3. **自检与导出**：重复导入检测、百分数小数混搭告警、补录后重算验证、导出一致性校验

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 回放工作台 | 三步流程导航 | 步骤条展示当前阶段：①导入原始行 ②补看边界值说明 ③更新计算明细 |
| 回放工作台 | 问卷原始行导入 | 拖拽/选择文件导入，显示原始行表格，保留备注列，检测重复导入并告警 |
| 回放工作台 | 边界值说明面板 | 以备注原文展示，不可被清洗为整齐数据；标注与原始行冲突的字段 |
| 回放工作台 | 计算明细表 | 展示 VaR 计算结果，百分数/小数格式保持原始呈现，标记待复核项 |
| 回放工作台 | 修改审计条 | 谁改了什么、为什么改、改完影响哪些结果，时间线式展示 |
| 冲突与复核 | 冲突证据列表 | 原始行 vs 边界值说明的逐条对比，高亮矛盾字段，教练选择确认或驳回 |
| 冲突与复核 | 待复核队列 | 百分数/小数混搭记录集合，不自动归正常，留给活动负责人复核 |
| 冲突与复核 | 复核决策面板 | 教练/负责人填写裁决理由，记录决策过程 |
| 自检与导出 | 自检仪表盘 | 四项自检状态：重复导入、格式混搭、补录重算、导出一致，通过/失败/警告 |
| 自检与导出 | 导出管理 | 导出明细、页面展示、接口返回同源一致性验证；导出前强制自检 |

## 3. 核心流程

用户打开系统后进入回放工作台，按三步流程操作：
1. 导入问卷原始行数据（含备注），系统检测重复导入并告警
2. 教练补看边界值说明备注，系统自动比对原始行与边界值说明，发现矛盾时生成冲突证据
3. 如有冲突，系统暂停流程，列出冲突证据，教练逐条确认或驳回；如有百分数/小数混搭，标记待复核而不自动归正常
4. 冲突裁决完成后更新计算明细，记录审计轨迹
5. 导出前执行四项自检，确保导出明细、页面展示、接口返回数据一致

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深炭灰 (#1a1a2e) + 深靛蓝 (#16213e)，营造金融终端专业感
- 强调色：琥珀金 (#f0a500) 用于关键操作与状态高亮，警示红 (#e74c3c) 用于冲突告警，验证绿 (#2ecc71) 用于自检通过
- 按钮风格：微圆角矩形，金色边框主按钮，幽灵按钮次要操作
- 字体：DM Mono 用于数据/数字展示，Outfit 用于界面文本，保证专业感与辨识度
- 布局：左侧窄导航栏 + 右侧主内容区，数据表格为主，卡片为辅
- 图标：线性图标风格 (Lucide)，保持一致性

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 回放工作台 | 三步流程导航 | 步骤条组件，金色高亮当前步骤，深色未完成步骤 |
| 回放工作台 | 问卷原始行导入 | 拖拽上传区域，原始行表格（含备注列），重复导入告警横幅 |
| 回放工作台 | 边界值说明面板 | 右侧抽屉式面板，备注原文卡片，冲突字段红色边框高亮 |
| 回放工作台 | 计算明细表 | 深色数据表格，百分数/小数保留原始格式，待复核行琥珀色底纹 |
| 回放工作台 | 修改审计条 | 底部时间线，修改人头像+操作描述+影响范围标签 |
| 冲突与复核 | 冲突证据列表 | 双列对比布局（原始行 vs 边界值说明），矛盾字段红底高亮，确认/驳回按钮 |
| 冲突与复核 | 待复核队列 | 卡片列表，百分数/小数混搭标记，状态徽章 |
| 冲突与复核 | 复核决策面板 | 弹出式面板，裁决理由文本框，确认/驳回/搁置按钮 |
| 自检与导出 | 自检仪表盘 | 四个状态卡片（重复导入、格式混搭、补录重算、导出一致），绿/红/琥珀状态 |
| 自检与导出 | 导出管理 | 导出按钮（自检未全通过时禁用），导出预览表格，一致性校验结果 |

- 表格在窄屏下支持横向滚动
