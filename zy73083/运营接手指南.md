# 幕墙节点方案比选 · 运营接手指南

<callout emoji="📌" background-color="light-blue">
**文档目的**：结构工程师老叶不想再临时解释为什么图纸版本多没人敢确认、异常点要翻几张表、补录后结论怎么查。本手册把所有关键操作路径列清楚，接手即上手。
</callout>

## 一、整体架构：5张表分工明确

| 表名 | 核心职责 | 关键入口视图 | 谁常用 |
|------|---------|------------|--------|
| 幕墙节点方案比选（主表） | 所有节点汇总看板、异常判断、版本确认 | ①正常汇总 ②异常标记 ③历史追溯 ④运营看板 | 所有人 |
| 会议纪要 | 保留历史备注、旧版本截图、来源位置、碰撞点原始记录 | 默认Grid View | 结构工程师/复核人 |
| 异常碰撞点追踪 | 碰撞点独立管理，重复碰撞点排除正常汇总不污染数据 | 碰撞点总览 / 已排除正常汇总 | 结构工程师/复核人 |
| 历史变更记录 | 补录后结论变化：旧材料+新备注+改判原因全保留 | 变更追溯看板 | 运营主管/复核人 |
| 运营操作SOP | 每个场景操作步骤说明（本手册精简版） | 操作指引看板 | 运营主管 |

## 二、三大高频场景：一步到位

### 📎 场景1：放材料在哪里

**路径**：幕墙节点方案比选 → 找到对应节点行 → **「比选材料附件」**字段 → 点击上传

**注意事项**：
1. 图纸版本确认状态同步更新到「图纸版本确认」字段
2. 旧版本对比截图另存到「会议纪要」表的「旧版本截图」字段，保留历史

---

### 🚨 场景2：看异常在哪里

**路径**：幕墙节点方案比选 → 顶部视图切换到 **「② 异常标记视图」**

进入后直接看到所有异常行，每行的「关联会议纪要」和「关联异常碰撞点」字段都有跳转链接，点开即可回到：
- 这次的**计算口径**（在「计算口径」字段）
- 会议纪要正文和来源位置（点进纪要，看「来源位置标记」和「纪要正文」）

如果异常碰撞点标记了「排除正常汇总」= 是，说明是**重复碰撞点**，请到「异常碰撞点追踪」表的「已排除正常汇总（需单独看）」视图单独处理，不要揉进正常结论。

---

### 📤 场景3：在哪里重新导出

**路径**：打开需要的视图 → 右上角「...」菜单 → **「导出」**

导出视图选择建议：
- 给领导看汇总 → 「① 正常汇总看板」（只含已确认最新版）
- 给复核人看问题 → 「② 异常标记视图」
- 看变更痕迹 → 「③ 历史追溯视图」
- 运营进度看板 → 「④ 运营主管看板」（按状态分组）

---

## 三、补录后结论改判：怎么查历史痕迹

当补录材料后结论发生变化，历史不会被覆盖，所有变更自动保留：

1. **变更前后对照**：去「历史变更记录」表「变更追溯看板」视图，按「变更类型」筛选"结论改判"，看「变更前结论」→「变更后结论」对比
2. **旧材料找回**：同一条记录看「旧材料摘要」字段，主表「比选材料附件」历史版本在飞书版本记录里
3. **改判原因**：看「改判原因」字段 + 「新备注内容」字段
4. **一键回到主表**：通过「关联比选节点」字段直接跳转回主表看最新状态

<callout emoji="💡" background-color="pale-gray">
**小技巧**：主表「历史变更次数」公式字段，数字>0就代表改过，复核时优先看这些记录。
</callout>

---

## 四、碰撞点重复出现：处理规范

如果「会议纪要」里的「是否出现碰撞点」标记了「碰撞重复出现」，按以下流程处理：

1. 去「异常碰撞点追踪」表新建一条记录
2. 「碰撞来源纪要」关联到原始会议纪要
3. 影响范围写进「影响范围说明」（和来源写在一起，后续不用两边翻）
4. **勾选「是否重复碰撞」和「排除正常汇总」两个复选框** → 这样这条碰撞不会污染主表正常汇总
5. 处理完成后，在主表「当前结论」里更新为协调后的状态

<callout emoji="⚠️" background-color="light-orange">
**红线规则**：标记了「排除正常汇总」的碰撞点，绝对不能直接合并进正常方案比选结论，必须单独说明。
</callout>

## 五、版本确认流程：让老叶不用反复解释

| 步骤 | 操作位置 | 做什么 |
|------|---------|--------|
| 1 | 主表「图纸版本确认」字段 | 收到新图纸后第一时间更新：待确认 / 已确认最新版 / 版本存疑需复核 |
| 2 | 「会议纪要」表「旧版本截图」字段 | 旧版图纸截图上传到这里，和纪要一起留在历史里 |
| 3 | 主表「比选材料附件」字段 | 确认无误的最新版图纸/计算书放在这里 |
| 4 | 主表「① 正常汇总看板」视图 | 默认只显示「已确认最新版」的记录，任何人看到这张视图就代表是确认过的版本 |

---

## 六、来源位置怎么标：点异常就能跳回去

当会议纪要里提到具体问题时，「会议纪要」表的「来源位置标记」字段请按以下格式填写：

```
文档：幕墙专项评审会议纪要.docx
段落：第三章 3.2 节
原文："东立面转角处铝合金型材与埋件碰撞"
```

这样从主表异常点跳转到纪要记录时，一眼就能定位原文位置，不需要再通篇翻文档找。

## 七、交接Checklist

接手「幕墙节点方案比选」时，请按以下清单确认，不用口头问：

- [ ] 打开主表「④ 运营主管看板」，按状态看每个节点的进度分布
- [ ] 切到「② 异常标记视图」，确认每个异常都有对应的关联纪要和碰撞点记录
- [ ] 看主表「图纸版本确认」列，确认所有待确认和存疑的记录都有人跟进
- [ ] 「历史变更次数」>0 的记录抽查2-3条，确认变更记录完整可读
- [ ] 「异常碰撞点追踪」表的「已排除正常汇总（需单独看）」视图确认有无待协调项

<callout emoji="✅" background-color="light-green">
**以上全部确认完毕，即可独立接手运营，无需再向老叶确认版本、历史、异常等问题。**
</callout>
