## 快速开始

```bash

# 2. 安装依赖
```

## 看板功能一览

### 📊 三个视图 Tab

| Tab | 对应场景 | 你会看到 |
|-----|---------|---------|
| ① 正常汇总看板 | 给领导看/已确认版本 | 只显示「图纸版本 = 已确认最新版」的记录，看到这张视图就代表是确认过的 |
| ② 异常标记视图 | 复核人少翻表 | 所有 ⚠️ 异常的节点汇总，点击展开看详情 |
| ③ 历史追溯视图 | 审计/复盘 | 所有补录和结论改判记录，前后对比一目了然 |

### 🔍 节点详情能看到什么

点击任意节点卡片展开，可看到：

1. **📐 计算口径** — 这次比选的判断标准，不用跳表
2. **📎 比选材料附件** — 运营放材料的位置
3. **📝 关联会议纪要** — 纪要正文 + 后续补充备注 + 来源位置（文档+段落+原文）+ 旧版本截图占位
4. **💥 异常碰撞点** — 碰撞标题 + 影响范围 + 是否重复 + 是否排除汇总
5. **🔄 历史变更记录** — 变更前/后结论对比 + 改判原因 + 旧材料摘要 + 新备注内容

### 🚧 重复碰撞点隔离区

在「正常汇总看板」底部，有一个独立的**重复碰撞点隔离区**（橙色提示）。

- 标记了「排除正常汇总」的碰撞点，**绝对不能直接合并进方案比选结论**
- 必须单独复核，避免污染正常汇总数据

### 📤 一键导出 CSV

页面右上角有「导出当前比选结果 (CSV)」按钮，点击可下载当前全部节点的比选汇总表（含编号、名称、结论、版本状态、计算口径、异常状态、关联计数等）。

## 扩展说明

- **数据都在 `data.py`**：要增加/修改节点、纪要、碰撞点、变更记录，直接编辑这个文件的列表即可
- **逻辑都在 `analysis.py`**：异常判断规则、正常汇总筛选、碰撞隔离逻辑都在这里，可按需调整
- **样式都在 `generate_dashboard.py`** 的模板字符串里：想改配色/布局直接改 CSS 部分
- **纯静态 HTML**：生成后可离线打开、邮件转发、丢到任意静态服务器
