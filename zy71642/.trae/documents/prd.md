## 1. 产品概述

分子轨道云课堂是一款面向化学教师的分子轨道可视化与教学备注工具，核心解决三个问题：能级切换时电子云形状与节点变化的即时呈现、课堂观察记录（截图+筛选状态+异常说明）的可带走与可追溯、以及数据完整性保障（状态持久化、历史对比、异常标记而非虚假结论）。

- 目标用户：化学教师、教研团队，用于课堂演示与同事间方案讨论
- 核心价值：将分子轨道教学从静态图示升级为可交互、可记录、可导出、可回溯的专业工具

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 教师 | 直接使用 | 全部功能：可视化、备注、截图、报告、历史 |
| 教研同事 | 接收导出报告 | 查看、对比历史记录 |

### 2.2 功能模块

1. **轨道工作台**：3D电子云可视化、能级切换、节点面显示、截面控制、视角旋转
2. **备注面板**：课堂备注录入、异常标记（能级顺序错/节点面遮挡/颜色误导）、待处理队列
3. **截图与报告**：一键截图（含当前筛选状态与异常说明）、报告生成与导出
4. **历史记录**：操作版本链、状态快照、历史对比查看

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 轨道工作台 | 3D电子云场景 | Three.js渲染分子轨道电子云，支持旋转/缩放/平移，显示分子骨架 |
| 轨道工作台 | 能级选择器 | 列出分子所有轨道能级（σ2s, σ*2s, π2p, σ2p等），点击切换高亮对应电子云 |
| 轨道工作台 | 节点面控制 | 显示/隐藏节点面半透明平面，调整透明度，切换截面模式 |
| 轨道工作台 | 截面视图 | 在3D场景旁展示当前截面2D等值线图，截面位置可拖拽调整 |
| 轨道工作台 | 参数面板 | 显示当前轨道参数（能量值、对称性、成键/反键、节点数） |
| 备注面板 | 课堂备注 | 富文本备注输入，关联当前轨道状态，支持异常标记类型选择 |

| 历史记录 | 版本时间线 | 显示操作历史链，每条记录含完整状态快照（轨道选择、视角、备注、异常） |
| 历史记录 | 状态对比 | 选择两个版本并排对比，差异高亮显示 |

## 3. 核心流程

用户打开应用 → 选择分子（如O₂、N₂、CO） → 3D场景加载分子骨架与电子云 → 点击能级选择器切换轨道 → 观察电子云形状与节点面变化 → 拖拽截面查看2D等值线 → 发现异常时标记类型并加入待处理 → 添加课堂备注 → 截图捕获当前状态 → 生成报告导出 → 历史记录自动保存，可回溯任意版本

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝黑底（#0a0e1a），科学仪器面板风格，荧光青绿（#00ffd5）与琥珀橙（#ff9f1c）双色强调
- **按钮风格**：圆角矩形，微发光边框，hover时荧光增强
- **字体**：显示字体用 JetBrains Mono（数据/参数），正文字体用 Noto Sans SC（中文备注）
- **布局风格**：左大右小分栏——左侧3D场景占70%，右侧面板区30%（能级选择器+参数+备注+截面视图堆叠）
- **图标风格**：线性图标，lucide-react，与荧光色系一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 轨道工作台 | 3D电子云场景 | 深色背景+微网格，电子云体渲染（正相位青绿/负相位橙色），半透明节点面，分子骨架线框 |
| 轨道工作台 | 能级选择器 | 竖排能级图（类似能级图），当前选中轨道高亮荧光边框，成键蓝/反键红标识 |
| 轨道工作台 | 节点面控制 | 滑块控制透明度，开关切换显示，截面位置拖拽条 |
| 轨道工作台 | 截面视图 | 右侧面板内嵌2D等值线图，与3D场景同步 |
| 轨道工作台 | 参数面板 | 等宽字体显示能量值、对称性符号、节点数，荧光色数字 |
| 备注面板 | 课堂备注 | 深色输入区，支持文字输入，底部异常标记快捷按钮 |
| 备注面板 | 待处理队列 | 卡片列表，红/黄/绿状态标识，点击展开详情 |
| 截图与报告 | 截图捕获 | 浮动按钮触发，截图预览弹窗含状态信息摘要 |
| 截图与报告 | 报告生成 | 时间线视图，截图缩略图+备注摘要，导出按钮 |
| 历史记录 | 版本时间线 | 左侧竖线时间轴，节点标注操作类型，点击恢复快照 |
| 历史记录 | 状态对比 | 双栏对比视图，差异项荧光高亮 |

### 4.3 响应式设计

- 桌面优先设计，最低支持1280px宽度
- 3D场景区最小600px宽度
- 右侧面板可折叠为底部抽屉（窄屏适配）
- 触摸屏支持：双指旋转/缩放，单指平移

### 4.4 3D场景指导

- **环境**：深色实验室环境，微弱环境光+荧光自发光效果
- **灯光**：弱环境光（强度0.3）+ 两盏定向光（青绿与暖白），突出电子云荧光效果
- **相机**：透视相机，初始视角稍偏俯视（30°），轨道控制器支持旋转/缩放/平移
- **构图**：分子居中，电子云包裹分子骨架，节点面半透明叠加
- **交互**：鼠标拖拽旋转，滚轮缩放，右键平移；能级切换时电子云平滑过渡（0.5s）
- **后处理**：Bloom效果增强荧光感，微弱色调映射
- **性能预算**：电子云等值面控制在5万面以内，目标60fps

## 5. 数据完整性保障

- 所有操作自动保存至 localStorage，刷新/重启后完整恢复
- 历史记录每次操作生成快照（含轨道状态、视角参数、备注、异常标记）
- 截图与报告中的数值必须与当前3D场景参数一致，不支持不一致状态导出
- 异常标记类型：能级顺序错、节点面遮挡、颜色误导、自定义——标记后进入待处理，不作为结论
- 视角切换后，3D电子云、能级、截面、标注、报告的数值必须联动一致
