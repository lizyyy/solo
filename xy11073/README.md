# 运动康复门店康复器械预约 API

专为运动康复门店设计的康复器械预约数据导入接口，能够自动分离正常记录和异常记录，支持人工审核特殊情况。

## 功能特性

### 核心功能
- ✅ **数据导入**：支持 JSON 和 CSV 格式文件上传
- ✅ **智能校验**：自动验证数据完整性和格式正确性
- ✅ **异常分类**：自动识别并分类异常记录
- ✅ **人工审核**：支持对特定异常记录进行人工备注后继续推进
- ✅ **多格式导出**：支持 JSON、可读表格、CSV 格式导出

### 校验规则
1. **必填字段检查**：预约编号、门店名称、患者姓名、手机号等
2. **格式验证**：手机号、身份证号、日期、时间格式
3. **重复预约检测**：检测预约编号是否已存在
4. **状态流转验证**：防止状态越级跳转
5. **禁忌匹配检查**：检测禁忌患者是否被安排高强度器械
6. **预约一致性**：时间逻辑、时长合理性检查

## API 接口文档

### 1. JSON 数据导入
**POST** `/api/import/json`

请求体：
```json
{
  "data": [
    {
      "预约编号": "BK001",
      "门店名称": "北京朝阳康复中心",
      "患者姓名": "张三",
      "患者手机号": "13800138000",
      "器械编号": "EQ001",
      "器械名称": "上肢康复训练器",
      "器械强度等级": "中等强度",
      "预约日期": "2024-01-15",
      "预约开始时间": "09:00",
      "预约结束时间": "09:30",
      "治疗师姓名": "李医生",
      "预约状态": "待确认"
    }
  ],
  "existingBookings": []
}
```

### 2. 文件上传导入
**POST** `/api/import/upload`

支持上传 `.csv` 或 `.json` 文件，使用 `multipart/form-data` 格式，字段名为 `file`。

### 3. 人工审核异常记录
**POST** `/api/import/review`

请求体：
```json
{
  "批次号": "uuid-batch-id",
  "行号": 1,
  "人工备注": "主治医生已评估确认患者可以进行此项训练",
  "是否通过审核": true
}
```

### 4. 查询导入结果
**GET** `/api/import/result/:batchId`

### 5. 导出功能
- **JSON 导出**：`GET /api/import/export/:batchId/json`
- **可读报告导出**：`GET /api/import/export/:batchId/report`
- **CSV 导出**：`GET /api/import/export/:batchId/csv`

### 6. 查询所有导入结果
**GET** `/api/import/results`

## 数据字段说明

### 预约记录字段
| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| 预约编号 | 字符串 | 是 | 唯一标识 |
| 门店名称 | 字符串 | 是 | 康复门店名称 |
| 患者姓名 | 字符串 | 是 | 患者真实姓名 |
| 患者手机号 | 字符串 | 是 | 11位手机号 |
| 患者身份证号 | 字符串 | 否 | 18位身份证号 |
| 患者禁忌情况 | 枚举 | 否 | 无禁忌/心脏病/高血压/关节损伤/妊娠期/近期手术 |
| 器械编号 | 字符串 | 是 | 器械唯一编号 |
| 器械名称 | 字符串 | 是 | 器械名称 |
| 器械强度等级 | 枚举 | 是 | 低强度/中等强度/高强度 |
| 预约日期 | 字符串 | 是 | YYYY-MM-DD 格式 |
| 预约开始时间 | 字符串 | 是 | HH:MM 格式 |
| 预约结束时间 | 字符串 | 是 | HH:MM 格式 |
| 治疗师姓名 | 字符串 | 是 | 负责治疗师姓名 |
| 预约状态 | 枚举 | 是 | 待确认/已确认/进行中/已完成/已取消 |
| 预约备注 | 字符串 | 否 | 额外说明信息 |

### 异常记录类型
| 类型 | 是否允许人工审核 | 说明 |
|------|------------------|------|
| 必填字段缺失 | ❌ 否 | 必须补充后重新导入 |
| 格式错误 | ❌ 否 | 必须修正格式后重新导入 |
| 重复预约 | ❌ 否 | 预约编号已存在 |
| 状态越级 | ✅ 是 | 状态跳转不符合流程，可人工确认 |
| 禁忌与器械冲突 | ✅ 是 | 禁忌患者被安排高强度器械，需医生评估 |
| 一致性错误 | ✅ 是 | 预约时间逻辑有问题，可人工确认 |
