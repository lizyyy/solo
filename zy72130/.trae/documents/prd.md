## 1. 产品概述

为音乐老师林老师打造的"Livehouse票房分账"小工具，解决曲目Excel、音频文件、合同截图和群聊批注等多源材料对账混乱的问题。核心价值：保留原始乱备注、分账判断过程全程留痕、坏文件不拖垮整批、人工标注持久可追溯。

- 目标用户：音乐老师林老师及其后续接手分账的工作人员
- 核心场景：导入一批分账材料 → 系统自动判断分账归属 → 人工确认或修正 → 导出清单

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 操作者 | 直接访问 | 导入材料、查看/筛选记录、编辑备注、人工标注、导出清单 |
| 接手者 | 直接访问 | 查看历史判断记录和人工标注、继续处理分账 |

### 2.2 功能模块

1. **分账工作台**：批量导入、记录列表与筛选、备注编辑、一键导出
2. **判断详情**：单条记录的判断过程时间线、人工标注与差异说明、附件查看

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 分账工作台 | 批量导入区 | 拖拽上传Excel/音频/图片/文本文件，坏文件隔离报错不阻断正常文件处理，显示导入结果摘要（成功N条/失败M条及失败原因） |
| 分账工作台 | 筛选栏 | 按状态（顺利/待确认/旧口径）、来源（Excel/音频/合同/群聊批注）、日期范围筛选，筛选结果实时更新列表 |
| 分账工作台 | 记录列表 | 表格展示所有分账记录，列含：曲目名、演出者、票房收入、分账比例、分账金额、状态徽章、原始备注（原样保留Excel乱备注）、来源，支持排序 |
| 分账工作台 | 备注编辑 | 行内快速编辑备注，修改后自动持久化，刷新不丢失 |
| 分账工作台 | 导出按钮 | 导出当前筛选条件下的记录清单（CSV格式），导出内容与页面筛选一致 |
| 判断详情 | 判断时间线 | 展示该条记录从导入到当前的全部判断步骤，每步含：时间戳、判断内容、判断结果，系统自动判断与人工标注用不同颜色区分 |
| 判断详情 | 人工标注区 | 可将"待确认"记录标记为"确认"或"退回"，必须填写标注原因，标注后差异自动写入判断时间线 |
| 判断详情 | 差异说明 | 补录备注后自动对比原始数据与当前数据，高亮显示差异字段及差异原因 |
| 判断详情 | 附件区 | 展示该记录关联的原始文件（Excel片段/音频/图片缩略图），可点击预览 |

## 3. 核心流程

用户打开工具 → 拖入一批分账材料（Excel为主） → 系统逐条解析并自动判断分账归属 → 对有疑问的记录标记为"待确认" → 对来自旧Excel的记录标记为"旧口径" → 用户浏览列表，筛选查看不同状态 → 点击待确认记录进入详情 → 查看判断过程，填写人工标注及原因 → 补录备注 → 系统自动记录差异 → 返回列表继续处理 → 导出当前筛选下的清单 → 下次打开时所有标注和备注仍在

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰/近黑底色（#0F0F0F），搭配霓虹绿（#00FF88）作为强调色，营造Livehouse氛围
- **辅助色**：暗红（#FF3355）用于异常/待确认，暗金（#FFAA00）用于旧口径，中灰（#3A3A3A）用于卡片背景
- **按钮风格**：圆角微凸，霓虹绿主按钮带微弱发光效果，灰色次要按钮
- **字体**：标题用"Noto Sans SC Bold"，正文用"Noto Sans SC Regular"，数据/代码区用"JetBrains Mono"
- **布局风格**：顶部固定导航栏 + 左侧筛选面板 + 右侧主内容区，卡片式记录行
- **图标风格**：Lucide线性图标，与霓虹绿主题统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 分账工作台 | 批量导入区 | 虚线拖拽区域，霓虹绿边框，拖入后显示进度条和结果摘要 |
| 分账工作台 | 筛选栏 | 左侧固定面板，多选标签式筛选，霓虹绿选中态 |
| 分账工作台 | 记录列表 | 深色卡片行，状态用颜色徽章（绿/红/金），原始备注灰色小字原样展示 |
| 分账工作台 | 备注编辑 | 点击备注格进入编辑模式，边框变绿，失焦自动保存 |
| 分账工作台 | 导出按钮 | 顶部工具栏右侧，霓虹绿实心按钮 |
| 判断详情 | 判断时间线 | 垂直时间线，系统判断为灰色节点，人工标注为霓虹绿节点，连线渐变 |
| 判断详情 | 人工标注区 | 底部固定面板，下拉选择标注结果，必填原因文本框，确认按钮 |
| 判断详情 | 差异说明 | 差异字段高亮黄底，删除线标旧值，绿色标新值 |
| 判断详情 | 附件区 | 横向滚动缩略图列表，点击放大预览 |

### 4.3 响应式设计

- 桌面优先（1280px+），导航栏固定、筛选面板侧边
- 平板（768-1279px），筛选面板收为顶部折叠
- 手机（<768px），单列布局，筛选为底部抽屉

### 4.4 样例数据要求

必须预置以下三条样例记录：

1. **顺利记录**：曲目"夏夜晚风"，演出者"回声乐队"，票房12000元，分账比例50%，状态"顺利"，判断过程：系统自动匹配合同比例 → 确认分账6000元
2. **待确认记录**：曲目"深巷"，演出者"锈色吉他"，票房8000元，分账比例空缺，状态"待确认"，判断过程：系统未找到合同比例 → 标记待确认 → 等待人工标注
3. **旧口径记录**：曲目"旧日之光"，演出者"老王"，票房5000元，分账比例40%（旧标准60%），状态"旧口径"，原始备注"按老规矩分"，判断过程：来自旧Excel → 比例与当前标准不一致 → 标记旧口径 → 补录备注后差异为比例从60%→40%
