# PDF表单抽取复核系统

基于 FastAPI + SQLite + 原生 HTML/JS 的本地 API 服务，支持 PDF 表单的字段抽取、人工复核、版本训练和结果导出。

## 功能特性

- ✅ **模板管理**: 质量负责人可录入表单模板，配置字段坐标
- 📊 **数据看板**: 图表展示表单状态统计、处理进度
- 📋 **表单列表**: 支持按状态筛选，可跳转详情页
- ⏱️ **处理时间线**: 完整记录谁处理、何时处理、为什么处理
- 🔄 **人工修正**: 失败样例可标记字段正误，输入修正值
- 🎯 **版本训练**: 支持将表单纳入训练版本，记录处理理由
- 📤 **复核导出**: 导出包含字段值和处理记录的 PDF 报告
- 📍 **坐标重算**: 字段坐标变化后可重新计算相关记录

## 项目结构

```
├── main.py              # FastAPI 主服务
├── database.py          # 数据库模型
├── init_data.py         # 样例数据初始化脚本
├── requirements.txt     # 依赖列表
├── static/              # 静态资源
│   └── index.html       # 前端页面
├── uploads/             # 上传文件和导出文件
└── pdf_review.db        # SQLite 数据库（运行后自动生成）
```

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 初始化样例数据

```bash
python init_data.py
```

样例数据包含：
- 1 份报销单模板（含 4 个字段）
- 3 份表单（覆盖不同状态：需修正、训练中、已完成）
- 1 个训练版本（v1.1）
- 完整的时间线和复核记录

### 3. 启动服务

```bash
python main.py
```

或使用 uvicorn：

```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

### 4. 访问系统

打开浏览器访问：http://localhost:8000

## 使用流程

### 1. 查看失败样例

1. 点击「表单列表」菜单
2. 状态筛选选择「需修正」
3. 点击「详情」按钮进入表单详情页
4. 在「处理时间线」中可查看：
   - 谁做了处理（张主管、李工程师）
   - 何时进行的处理
   - 具体的处理理由

### 2. 人工修正流程

1. 在「抽取字段」区域点击「✓ 正确」或「✗ 错误」标记
2. 标记错误时可输入修正值
3. 点击「人工复核」按钮提交复核意见
4. 选择处理结果：处理失败/需要重新训练/复核通过
5. 填写处理理由后提交
6. 时间线会自动记录复核操作

### 3. 版本训练

1. 点击「版本训练」按钮
2. 选择处理结果（建议选择「需要重新训练」）
3. 填写训练理由
4. 提交后表单状态变更为「训练中」
5. 所有操作都会在时间线中记录，便于复盘

### 4. 导出报告

1. 点击「导出PDF」按钮
2. 自动下载包含以下内容的报告：
   - 表单基本信息
   - 所有字段的抽取值、正确性、修正值
   - 完整的处理时间线

### 5. 重新计算坐标

1. 如果模板字段坐标有变化
2. 点击「重新计算坐标」按钮
3. 系统会根据模板最新坐标重新计算该表单的所有字段位置
4. 坐标重算操作会记录到时间线

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/` | 首页 |
| GET | `/api/templates` | 获取所有模板 |
| POST | `/api/templates` | 创建模板 |
| GET | `/api/templates/{id}` | 获取模板详情 |
| GET | `/api/forms` | 获取表单列表（支持 status 参数） |
| POST | `/api/forms` | 创建表单 |
| GET | `/api/forms/{id}` | 获取表单详情 |
| PUT | `/api/extractions/{id}` | 更新抽取结果 |
| POST | `/api/reviews` | 创建复核记录 |
| POST | `/api/recalculate/{form_id}` | 重新计算坐标 |
| POST | `/api/training` | 创建训练版本 |
| GET | `/api/dashboard` | 获取看板数据 |
| GET | `/api/export/{form_id}` | 导出表单 PDF |
| POST | `/api/upload-pdf` | 上传 PDF 文件 |

## 数据库表说明

- **Template**: 表单模板
- **TemplateField**: 模板字段（含坐标信息）
- **Form**: 表单实例
- **Extraction**: 字段抽取结果
- **Review**: 复核记录
- **Timeline**: 处理时间线
- **TrainingVersion**: 训练版本

## 状态流转

```
已抽取 (extracted)
    ↓
已复核 (reviewed)
    ↓
    ├─→ 需修正 (correction_needed)  ← 人工复核失败
    ├─→ 训练中 (training)           ← 版本训练介入
    └─→ 已完成 (completed)          ← 复核通过
           ↓
        已训练 (trained)            ← 训练版本发布
```
