## 1. 产品概述

门店货架陈列体检系统是面向零售督导的3D可视化工具，解决手工圈照片效率低下的问题，支持在浏览器中进行交互式操作和陈列复盘。

- 核心价值：将静态照片转化为可交互3D场景，自动检测SKU重复占位、黄金层统计错误、端架遮挡等问题
- 目标用户：零售督导、门店运营管理人员、陈列优化专员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 零售督导 | 账号登录 | 导入门店数据、3D交互操作、生成陈列报告 |

### 2.2 功能模块

1. **主操作界面**：3D场景视图、左侧控制面板、右侧信息面板、底部时间轴
2. **数据导入模块**：样例数据加载、门店配置导入
3. **3D可视化模块**：货架3D渲染、SKU模型展示、动线热力图、黄金层高亮
4. **交互操作模块**：SKU拖拽调整、货架筛选、视角切换、时间轴回放
5. **校验检测模块**：SKU重复占位检测、黄金层合规校验、端架遮挡识别
6. **报告导出模块**：陈列问题汇总、导出PDF报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 主操作页 | 3D场景区 | Three.js渲染门店货架，支持旋转/缩放/平移，黄金层高亮显示 |
| 主操作页 | 左侧控制面板 | 数据导入、SKU筛选、图层开关、视角预设 |
| 主操作页 | 右侧信息面板 | 选中SKU详情、问题列表、校验结果、统计数据 |
| 主操作页 | 底部时间轴 | 陈列历史回放、状态切换、快照对比 |
| 主操作页 | 工具栏 | 状态重置、导出报告、帮助说明 |

## 3. 核心流程

用户导入门店数据 → 3D场景自动渲染 → 系统自动检测陈列问题 → 用户拖拽调整SKU → 切换视角和时间轴复盘 → 导出标准化报告

    E --> F["校验更新结果"]

## 4. 界面设计

### 4.1 设计风格

- 主色调：深蓝色系 (#0F172A, #1E40AF) 体现专业稳重
- 强调色：橙色 (#F97316) 用于高亮出问题区域
- 成功色：绿色 (#10B981) 用于合规状态指示
- 字体：Geist 显示字体 + 思源黑体 正文字体
- 布局：三栏布局 + 底部时间轴，暗黑模式减少视觉疲劳
- 风格：工业科技风，强调数据可视化的清晰度

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 主操作页 | 3D场景区 | 暗色背景、轮廓光效果、选中高亮、问题区域闪烁提示 |
| 主操作页 | 左侧面板 | 折叠面板、图标按钮、筛选标签、状态指示器 |
| 主操作页 | 右侧面板 | 卡片式信息组、进度条、问题标记、数据表格 |
| 主操作页 | 时间轴 | 渐变时间条、关键帧标记、播放控制按钮 |
| 主操作页 | 顶部栏 | Logo、门店名称、用户信息、快捷操作 |

### 4.3 响应式

- 桌面端优先设计，适配1920×1080及以上分辨率
- 支持窗口大小变化时3D画布自适应
- 侧边栏支持折叠，最大化3D视图空间

### 4.4 3D场景指导

- 环境：室内商超光照，柔和环境光 + 重点区域补光
- 相机：透视相机，初始俯视45度视角，支持轨道控制
- 构图：货架排列整齐，动线清晰，端架位置突出
- 交互：悬停高亮、点击选中、拖拽移动、双击聚焦
- 特效：黄金层发光边框、缺货洞半透明红色、动线热力图渐变着色
- 性能：使用实例化渲染优化大量SKU模型
