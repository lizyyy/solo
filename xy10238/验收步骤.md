# 热泵采暖能耗对比器 - 业务验收步骤

## 🎯 验收概述

本工具用于农村热泵采暖改造后的节能效果对比分析，支持：
- 不同户型的能耗归一化对比
- 天气校正消除年度气候差异影响
- 多种电价方案模拟
- 数据导入、校验、确认、导出全流程

### 异常3：人工改错检测
**测试数据位置：** `src/data/sampleData.ts` → `sampleManualErrorCSV`

**内容说明：**
```
传统土坯房,居民阶梯电价,1,2024,-100,20    ← 能耗为负数
砖瓦房中等保温,居民阶梯电价,2,2024,520,5   ← 室温过低(5℃)
新建节能房,低碳优惠电价,3,2024,8000,20    ← 能耗异常高(8000kWh)
农村别墅型,商业用电,4,2024,200,35        ← 室温过高(35℃)
```

**验证点：**
- 能耗 < 0 → 错误（manual_error类型）
- 室温 < 10 或 > 30 → 错误（manual_error类型）
- 能耗 > 5000 → 警告（outlier类型）
- 错误类型标记为 `manual_error`

## 📊 技术实现清单

### 核心算法

| 模块 | 实现文件 | 说明 |
|------|---------|------|
| 户型归一化 | `src/utils/houseNormalization.ts` | 面积×保温×年限×楼层系数 |
| 天气校正 | `src/utils/weatherCorrection.ts` | 温度+采暖度日数+太阳辐射+风速 |
| 电价模拟 | `src/utils/electricityPrice.ts` | 统一电价/峰谷电价两种模式 |
| 数据导入 | `src/utils/dataImport.ts` | CSV/JSON解析+校验+去重 |

### 数据流

```
导入数据 → 解析 → 户型归一校验 → 天气校正 → 电价计算 → 对比分析 → 导出
```

### 数据结构（在示例中）

**预设户型（4种）：**
1. 传统土坯房 - 基准对比
2. 砖瓦房中等保温 - 普通改造
3. 新建节能房 - 节能改造效果
4. 农村别墅型 - 大面积高能耗

**预设电价（4种）：**
1. 居民阶梯电价（0.56元/kWh）
2. 峰谷电价（峰0.85/谷0.35）
3. 商业用电（0.88元/kWh）
4. 低碳优惠电价（0.42元/kWh）

**预设天气数据（2年对比）：**
- 2023年（参考年）
- 2024年（实际年，1-3月更暖和2℃）

## 📝 常见问题

**Q: 如何添加新户型？**
A: 在 `src/data/sampleData.ts` 的 `sampleHouseTypes` 数组中添加新对象，系统会自动计算归一化系数。

**Q: 如何添加新电价方案？**
A: 在 `src/data/sampleData.ts` 的 `sampleElectricityPrices` 数组中添加新方案。

**Q: 天气数据来源？**
A: 当前为模拟数据，实际应用中需接入气象站API或导入CSV天气数据。

**Q: 如何批量导入真实数据？**
A: 准备CSV文件，格式参考「正常数据」示例，支持任意条数。
