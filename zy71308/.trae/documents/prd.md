## 1. 产品概述

激光雕刻能量密度工作台——为艺术工坊提供一站式激光工艺参数计算、校验与追溯工具。核心解决三个问题：① 快速算出能量密度并判断是否在材料安全阈值内；② 拦住明显不合理的参数并给出原因；③ 每条工艺数据从录入到变更全链路可查可追溯。

- 目标用户：艺术工坊激光操作员、工艺工程师
- 核心价值：减少试错浪费，避免因参数失误造成的材料报废和设备损伤

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 操作员 | 工坊内部分配账号 | 录入参数、查看记录、导出报告 |
| 工艺师 | 工坊内部分配账号 | 审核参数、补录记录、撤回记录、管理材料阈值 |

### 2.2 功能模块

1. **工作台页面**：能量密度计算器、参数实时校验、材料阈值匹配、参数扫描、风险提示
2. **工艺记录页面**：历史记录列表、状态流转（草稿→已校验→已审核→已撤回）、补录与撤回、审计轨迹查看
3. **材料库与报告页面**：材料阈值管理、工艺报告生成与导出

### 2.3 页面详情

| 页面 | 模块 | 功能说明 |
|------|------|----------|
| 工作台 | 能量密度计算器 | 输入激光功率(W)、移动速度(mm/s)、焦距(mm)、线宽(mm)，实时计算能量密度 J/mm²，公式 E = P / (v × d) |
| 工作台 | 参数校验面板 | 实时校验：功率越界（超出设备范围0-100W）、速度单位错误（如输入m/s未转换）、焦距偏移超出材料适用范围、线宽物理不可能值；拦截并给出中文原因 |
| 工作台 | 材料阈值匹配 | 根据所选材料自动加载阈值区间（如木材 0.5-3.0 J/mm²、亚克力 1.0-5.0 J/mm²），能量密度落入区间则显示安全，低于则「能量不足-可能无法刻透」，高于则「能量过高-有过烧风险」 |
| 工作台 | 参数扫描 | 选择一个变量（功率/速度/焦距），设定范围和步长，自动生成一组参数组合的能量密度对照表，快速找到最佳参数区间 |
| 工作台 | 风险提示条 | 汇总所有校验结果，按严重程度排列（错误→警告→建议），不可提交的错误用红色阻断，警告用橙色提醒 |
| 工艺记录 | 记录列表 | 按时间倒序展示所有工艺记录，支持按材料/状态/日期筛选，每条显示材料、功率、速度、能量密度、状态标签 |
| 工艺记录 | 状态流转 | 草稿→已校验（自动校验通过后）→已审核（工艺师确认）→已归档；支持撤回到草稿；补录记录直接进入已审核状态但标记为「补录」 |
| 工艺记录 | 审计轨迹面板 | 展开任一记录可查看完整变更历史：时间戳、操作人、字段级变更内容（从X改为Y）、操作原因 |
| 材料库与报告 | 材料阈值表 | 增删改查材料及其安全阈值区间、推荐参数，包含材料名称、最低能量密度、最高能量密度、推荐功率、推荐速度 |
| 材料库与报告 | 报告导出 | 选择时间范围和材料，生成工艺报告，包含参数汇总表、能量密度分布、风险统计，导出为可打印格式 |

## 3. 核心流程

### 3.1 参数录入与校验流程

操作员在工作台输入材料、功率、速度、焦距、线宽 → 系统实时校验参数合理性 → 校验通过显示能量密度并与材料阈值比对 → 显示风险等级 → 确认提交后自动创建草稿记录 → 自动校验触发状态流转至「已校验」→ 工艺师审核后流转至「已审核」

### 3.2 状态流转流程

```mermaid
stateDiagram-v2
    [*] --> "草稿": 录入参数并提交
    "草稿" --> "已校验": 自动校验全部通过
    "草稿" --> "草稿": 校验未通过（显示错误原因）
    "已校验" --> "已审核": 工艺师审核通过
    "已校验" --> "草稿": 工艺师退回修改
    "已审核" --> "已归档": 自动归档
    "已审核" --> "草稿": 撤回（标记撤回原因）
    "已归档" --> "已审核": 重新激活
    [*] --> "已审核": 补录记录（标记为补录）
```

### 3.3 参数扫描流程

选择扫描变量 → 设定范围和步长 → 系统批量计算能量密度 → 与材料阈值比对 → 生成对照表（安全/警告/危险标记）→ 选中参数可直接提交为记录

### 3.4 报告导出流程

选择时间范围 → 选择材料（可选全部）→ 系统汇总已审核记录 → 生成报告预览 → 导出

## 4. 用户界面设计

### 4.1 设计风格

- **色调**：深色工业风主调（炭灰 #1a1a2e 深底 + 琥珀橙 #f59e0b 强调色 + 翡翠绿 #10b981 安全色 + 玫红 #ef4444 危险色），营造工坊仪器感
- **按钮风格**：圆角矩形，主操作按钮带微弱发光效果，危险操作按钮红底白字
- **字体**：显示字体用 JetBrains Mono（数据/代码感），正文字体用 Noto Sans SC
- **布局**：左侧窄导航栏 + 右侧主内容区，工作台页面用三栏布局（参数输入 | 计算结果 | 风险提示）
- **图标**：使用 lucide-react 线性图标

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 工作台 | 参数输入区 | 材料下拉选择器、功率/速度/焦距/线宽数值输入框带单位标签、实时校验提示文字 |
| 工作台 | 计算结果区 | 能量密度大字显示、阈值区间条形图（当前值标记位置）、材料匹配状态徽章 |
| 工作台 | 参数扫描区 | 变量选择器、范围/步长输入、生成按钮、结果表格（行按安全等级着色）|
| 工作台 | 风险提示条 | 顶部固定横条，错误红/警告橙/建议蓝，带图标和文字说明 |
| 工艺记录 | 记录列表 | 表格布局，状态标签彩色徽章，筛选器在表头上方，行可展开查看审计轨迹 |
| 工艺记录 | 审计轨迹 | 时间线组件，每条显示时间+操作人+变更内容+原因 |
| 工艺记录 | 状态操作 | 行内操作按钮：审核/退回/撤回/补录，操作需填写原因 |
| 材料库与报告 | 材料表 | 可编辑表格，行内编辑+新增行 |
| 材料库与报告 | 报告生成 | 日期范围选择器、材料多选、预览区、导出按钮 |

### 4.3 响应式

桌面优先设计，最小支持 1280px 宽度。移动端仅保留工作台计算器核心功能。

### 4.4 动效

- 参数输入时计算结果数字渐变过渡
- 风险等级变化时颜色平滑过渡
- 状态流转时标签弹跳微动画
- 审计轨迹时间线逐条淡入
