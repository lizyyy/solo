导入数据说明

需要导入的数据文件

1. 藏品清单 CSV

必需列：item_id（藏品编号）、name（藏品名称）

可选列：category、description、dimensions、weight、condition、insurance_value、box_id

2. 箱号/封签记录 CSV

必需列：box_id（箱号）、seal_id（封签号）

可选列：box_description、box_type、box_dimension、applied_at、removed_at、applied_by、removed_by、previous_seal_id、next_seal_id、is_intact、item_id

3. 环境记录仪 JSON

必需字段：logger_id（记录仪编号）、temperature（温度）、humidity（湿度）

可选字段：timestamp、box_id、temp_min、temp_max、humidity_min、humidity_max

4. 交接照片清单 JSON

必需字段：filename（文件名）

可选字段：photo_id、description、category、box_id、item_id、seal_id、timestamp、photographer

5. 签收记录 CSV

必需列：person_name（签收人）、action（动作）

可选列：sign_id、role、box_id、item_id、seal_id、timestamp、location、notes、order
