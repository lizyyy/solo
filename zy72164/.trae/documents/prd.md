## 1. 产品概述

夜间经济人流预警系统是面向城市规划师的预警点管理与溯源工具。解决的核心痛点是：交接时巡检照片与预警数据对不上、旧版公示意见被新表覆盖、处理记录无法追溯来源。系统以地图交互为主界面，点击任意预警点可查看完整来源链、处理状态与历史意见，确保"夜间经济人流预警"每条记录都能从样例一路追到结果。

- 目标用户：城市规划师、社区管理方、巡检人员
- 核心价值：让预警数据可追溯、可交接、可导出，消除"靠猜"的判断

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 城市规划师 | 默认角色 | 查看/处理/导出预警点、管理历史意见 |
| 社区管理方 | 导出文件接收 | 查看分类导出的已处理/待核实/需复看点 |
| 巡检人员 | 照片上传 | 补充巡检照片、标记现场情况 |

### 2.2 功能模块

1. **地图总览页**：地图展示所有预警点，按状态着色，点击弹窗显示来源/状态/处理记录
2. **预警点详情页**：完整溯源链、历史意见时间线、处理操作（确认/标记/导出）
3. **导出页**：按已处理/待核实/需现场复看三类分开导出，可直接用于月底复盘

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 地图总览页 | 地图视图 | Leaflet地图展示预警点，按状态着色（绿=已处理、橙=待核实、红=需现场复看），支持缩放平移 |
| 地图总览页 | 预警点弹窗 | 点击地图标记弹出：预警名称、来源类型、当前状态、最近处理时间、快捷操作按钮 |
| 地图总览页 | 筛选面板 | 按状态/来源类型/时间段筛选，同名路口高亮提示 |
| 地图总览页 | 统计栏 | 顶部显示总数/已处理/待核实/需复看数量，含跨时段统计入口 |
| 预警点详情页 | 基本信息卡片 | 预警名称、坐标、来源类型、原始来源编号、首次记录时间 |
| 预警点详情页 | 溯源时间线 | 垂直时间线：每条记录含来源、处理人、处理时间、处理意见，旧方案被覆盖时保留历史意见并标注"已被新方案覆盖" |
| 预警点详情页 | 巡检照片区 | 展示关联巡检照片，标注"旧口径补录" |
| 预警点详情页 | 处理操作区 | 确认/标记待核实/标记需现场复看/添加处理意见 |
| 预警点详情页 | 坐标偏移提示 | 当检测到坐标与原始记录偏移时，显示偏移量与修正建议 |
| 预警点详情页 | 重复投诉提示 | 当存在重复投诉时，展示关联记录列表 |
| 导出页 | 分类导出 | 按已处理/待核实/需现场复看三类分开导出CSV，每条含原始来源和处理时间 |
| 导出页 | 导出预览 | 导出前可预览分类结果，确认数据完整 |

## 3. 核心流程

城市规划师进入系统 → 地图总览查看预警点分布 → 点击某个预警点 → 查看来源与处理历史 → 对待处理点进行确认/标记 → 历史意见保留完整 → 导出分类结果给社区

```mermaid
flowchart TD
    "A[进入地图总览]" --> "B[筛选预警点]"
    "B" --> "C[点击地图标记]"
    "C" --> "D[查看弹窗摘要]"
    "D" --> "E[进入详情页]"
    "E" --> "F[查看溯源时间线]"
    "F" --> "G{需要处理?}"
    "G" --> "是" --> "H[执行处理操作]"
    "G" --> "否" --> "I[返回地图]"
    "H" --> "J[处理记录写入时间线]"
    "J" --> "I"
    "I" --> "K[导出分类结果]"
    "K" --> "L[社区接收分类文件]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰/墨色背景（#1a1a2e），代表夜间经济氛围；状态色：翡翠绿（#10b981）=已处理、琥珀橙（#f59e0b）=待核实、珊瑚红（#ef4444）=需现场复看
- **辅助色**：钢蓝（#4a90d9）用于链接与交互元素，暖黄（#eab308）用于历史意见覆盖标记
- **按钮风格**：圆角矩形、微投影，状态按钮带色彩条
- **字体**：Noto Sans SC 做正文，JetBrains Mono 做数据/编号/坐标
- **布局风格**：左侧地图大面积，右侧可展开的详情面板；顶部固定统计栏
- **图标风格**：线性图标（lucide-react），简洁无填充

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 地图总览页 | 地图视图 | 深色底图Leaflet地图，预警点为彩色圆点标记，hover放大，点击弹出半透明弹窗 |
| 地图总览页 | 筛选面板 | 左侧折叠面板，复选框+日期选择器，同名路口用⚠️图标提示 |
| 地图总览页 | 统计栏 | 顶部横条，四格数字统计（总数/已处理/待核实/需复看），带渐变底色 |
| 预警点详情页 | 溯源时间线 | 右侧面板，垂直时间线，每节点为卡片，覆盖事件用暖黄边框标记 |
| 预警点详情页 | 巡检照片区 | 缩略图网格，旧口径照片角标标注"补录" |
| 预警点详情页 | 处理操作区 | 底部固定操作栏，三个状态按钮+意见输入框 |
| 导出页 | 分类导出 | 三列卡片布局，每列一个状态分类，含数量统计与导出按钮 |

### 4.3 响应式

- 桌面端优先，地图占满左侧70%宽度
- 平板端详情面板改为底部抽屉
- 移动端暂不作为主要适配目标

### 4.4 3D场景指引

不适用。本项目使用2D地图（Leaflet），不涉及3D场景。

## 5. 样例数据要求

样例数据必须包含以下三类预警点，每条都完整可追溯：

1. **顺利记录**：状态为"已处理"，从巡检报告来源，有完整处理时间线
2. **人工确认记录**：状态为"待核实"，存在坐标偏移和重复投诉，需要人工介入判断
3. **旧口径补录记录**：来源为巡检照片，状态为"需现场复看"，含旧方案被新方案覆盖的历史意见

特殊场景必须体现：
- 同名路口（两个不同位置但名称相同的预警点）
- 重复投诉（同一预警点多次投诉记录关联展示）
- 坐标偏移（原始坐标与实际位置有偏差，显示偏移量）
- 跨时段统计（某路口周末与工作日人流差异统计）
