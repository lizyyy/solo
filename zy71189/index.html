玩法说明

你是地铁站值班站务。目标：在每个回合内处理事件，保持秩序与乘客耐心，完成疏散与修复。

站厅布局：5 个区域连成一张图 —— A入口 / B入口 / C站台(闸机) / D换乘 / E服务台。乘客沿区域连线移动，封闭区域会阻断路径。

操作：点击 闸机切换开闭；点击 区域按钮切换封闭；右侧面板选择广播、派员工、修复、疏导。快捷键 1-8 广播、空格 暂停、R 重开。

事件：闸机故障、乘客迷路、临时封站、闸机拥堵、广播漏发、封站路线错误。

封站规则：接到封站指令后，须按 A入口 → B入口 → C站台 顺序封闭。顺序错误将触发"路线错误"扣分，超时未完成乘客滞留加剧。

失败：秩序值 ≤ 0 或 乘客耐心 ≤ 0。胜利：完成该回合所有处置目标。

结算：每回合结束自动生成报告，含区域封闭历史、封站结果、滞留乘客数，可导出为 JSON。
