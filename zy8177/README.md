# 青光眼视野检查复核工具

一款本地桌面工具，用于眼科技师复核青光眼随访中的 Humphrey 视野检查结果。

## 功能特性

- **数据导入**: 支持导入检查点位 CSV、患者随访 JSON、设备可靠性规则 YAML 和历史报告
- **热力图显示**: 左右眼视野热力图，支持阈值、总偏差、模式偏差三种显示模式
- **可靠性评分**: 圆形评分显示，包含固视丢失率、假阳性率、假阴性率指标
- **疑似进展检测**: 自动检测视野进展点位，支持聚类分析
- **待确认列表**: 人工确认界面，支持标记状态和添加备注
- **本地持久化**: 确认状态本地保存，支持加载和保存工作进度
- **导出功能**: 导出问题列表(issues.csv)和复核报告(review_report.md)

## 特殊处理

- **固视丢失过高检测**: 超过阈值自动标记为数据质量问题
- **左右眼混录检测**: 自动检测记录眼别与实际点位分布是否匹配
- **缺失点位检测**: 检查点位数量是否符合标准
- **跨日期随访排序**: 历史数据自动按日期排序

## 使用指南

### 1. 导入数据

通过菜单栏的 **文件** 菜单导入:
- **导入检查点位CSV**: 导入单个眼别的视野检查点位数据
- **导入患者随访JSON**: 导入包含历史随访记录的患者数据
- **导入可靠性规则YAML**: 导入设备可靠性评估规则（可选）

### 2. 查看结果

主界面分为四个主要区域:
- **左侧**: 热力图显示区（支持单眼/双眼视图切换）
- **右上角**: 可靠性评分组件（圆形评分 + 指标进度条）
- **右中**: 疑似进展组件（进展统计 + 点位表格）
- **底部**: 待确认列表（问题列表 + 人工确认操作）

### 3. 人工确认

在待确认列表中:
- 选中一行，点击 **确认** 标记为已确认
- 点击 **标记异常** 标记为需要关注
- 双击 **备注** 列可添加或编辑备注
- 选中状态通过工具栏 **保存状态** 按钮本地保存

### 4. 导出报告

通过 **导出** 菜单:
- **导出问题列表**: 导出 issues.csv，包含所有问题和确认状态
- **导出复核报告**: 导出 review_report.md，包含完整的复核报告

## 示例数据

`sample_data/` 目录包含示例数据:

- `left_eye_test.csv`: 左眼视野检查（正常质量）
- `right_eye_test.csv`: 右眼视野检查（正常质量）
- `patient_followup.json`: 患者随访历史（4次随访记录）
- `reliability_rules.yaml`: 设备可靠性规则配置
- `problematic_test.csv`: 有问题的检查（固视丢失率40%）
- `eye_mismatch_test.csv`: 左右眼混录测试数据

## 数据格式说明

### CSV 点位数据格式

文件头以 `# key=value` 格式包含元数据:

```
# patient_id=P001
# patient_name=张三
# test_date=2024-01-15
# eye=left
# md=-5.2
# psd=4.8
# vfi=92.5
# fixation_losses=4
# fixation_total=20
x,y,value,td,pd,td_p,pd_p,location
-27,-3,25,-8,-5,0.05,0.1,点位1
...
```

### JSON 随访数据格式

```json
{
  "patient_id": "P001",
  "patient_name": "张三",
  "birth_date": "1965-03-15",
  "gender": "男",
  "diagnosis": "原发性开角型青光眼",
  "history": [
    {
      "visit_date": "2024-01-15",
      "notes": "本次随访...",
      "left_eye": {...},
      "right_eye": {...}
    }
  ]
}
```

## 快捷键

- `Ctrl+O`: 打开文件
- `Ctrl+S`: 保存状态
- `Ctrl+E`: 导出报告
- `Ctrl+Q`: 退出应用
- `F5`: 刷新数据

## 注意事项

1. 本工具仅供辅助诊断使用，最终诊断需由专业医师确认
2. 数据保存在本地，请勿将敏感医疗数据上传至云端
3. 建议定期备份 `.review_state` 状态文件
