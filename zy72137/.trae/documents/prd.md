## 1. 产品概述

为演出统筹阿蓝定制的"采样授权到期提醒"桌面工具，用于整理音频文件夹中混杂的采样材料、追踪授权状态、标记问题记录并支持持续增量处理。核心目标是让每条采样都能追到来源，授权过期/时码错位/重复曲目单独列出，人工标注和备注跨会话持久化，月底复盘时可直接拿清单解释。

- 目标用户：演出统筹（非技术背景，需要清晰的视觉分层和操作引导）
- 核心价值：把混乱的音频材料变成可追溯、可筛选、可导出的授权清单，脏数据进来也有交代

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 演出统筹 | 打开即用，无需注册 | 导入材料、编辑备注、筛选导出 |

### 2.2 功能模块

1. **主控台页面**：材料总览、问题面板、筛选工具栏、备注编辑、导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主控台 | 材料导入区 | 拖拽/选择音频文件夹，自动解析文件名、采样信息，生成记录并标记处理时间 |
| 主控台 | 材料总览表 | 表格展示所有采样记录，含来源文件名、曲目名、授权状态、到期日、时码、重复标记、备注；支持多条件筛选 |
| 主控台 | 问题面板 | 三个独立分区：授权过期、时码错位、重复曲目，各分区计数徽标，点击展开列表 |
| 主控台 | 备注编辑 | 行内编辑备注，保存后自动记录编辑人和时间，刷新不丢失 |
| 主控台 | 筛选工具栏 | 按授权状态/到期区间/问题类型/关键字筛选，筛选状态与导出联动 |
| 主控台 | 导出功能 | 导出当前筛选结果的 CSV 清单，含原始来源和处理时间 |
| 主控台 | 增量导入 | 支持多次导入，新记录自动合并，已有人工标注保留不变 |
| 主控台 | 差异日志 | 每次导入/编辑自动生成差异记录，含操作类型、变更内容、时间戳 |

## 3. 核心流程

### 3.1 首次导入与处理流程

演出统筹阿蓝打开工具 → 拖入首批音频文件夹 → 系统自动解析并生成记录 → 自动检测三类问题（授权过期/时码错位/重复）→ 阿蓝在问题面板逐条处理，添加备注 → 关闭页面，数据持久化到 localStorage

### 3.2 增量补录流程

阿蓝再次打开 → 拖入新材料 → 系统增量合并，已有标注保留 → 新增记录自动检测问题 → 阿蓝补录备注 → 差异日志记录本次变更 → 导出当次筛选清单

### 3.3 月底复盘流程

阿蓝打开工具 → 查看差异日志全览 → 按问题类型筛选 → 导出对应清单 → 清单含原始来源和处理时间，可直接用于复盘说明

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底（#1a1a2e）+ 琥珀色强调（#e2a83e），传达专业音频工具的沉稳感
- **辅助色**：过期用珊瑚红（#e74c3c）、时码错位用天蓝（#3498db）、重复用紫罗兰（#9b59b6）
- **按钮风格**：圆角微凸（4px），主操作琥珀色实心，次操作描边
- **字体**：标题用 Noto Serif SC（衬线体，文化感），正文用 Noto Sans SC
- **布局风格**：左侧固定问题面板（可折叠），右侧主表格区，顶部工具栏
- **图标**：Lucide Icons 线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|----------|----------|---------|
| 主控台 | 材料导入区 | 拖拽虚线框，琥珀色虚线边框，拖入后显示解析进度 |
| 主控台 | 材料总览表 | 紧凑表格，行悬停高亮，状态列彩色徽标，备注列行内编辑图标 |
| 主控台 | 问题面板 | 左侧三块折叠卡片，各带彩色计数徽标，展开显示问题子列表 |
| 主控台 | 筛选工具栏 | 顶部横向排列：状态下拉、日期范围、问题类型多选、搜索框 |
| 主控台 | 导出按钮 | 工具栏右侧，琥珀色实心按钮，点击下载 CSV |
| 主控台 | 差异日志 | 底部可展开抽屉，时间线样式，每条含操作类型标签和变更内容 |

### 4.3 响应式

桌面优先设计（1280px+），工具面向办公场景使用，不优先适配移动端
