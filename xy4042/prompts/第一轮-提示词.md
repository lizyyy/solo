我想做一个给假肢矫形门诊和制作间一起用的本地桌面 GUI 应用，叫“矫形取模适配台”。门诊每天会给患者量尺寸、拍取模照片、登记石膏模或 3D 扫描文件，制作间再排版裁片、记录试穿调整；现在靠纸单和网盘文件夹，很容易把左右侧、版本和复诊时间弄混。请从 0 到 1 做一个能直接运行的桌面应用：用户可以创建患者档案，登记诊断部位、左右侧、尺寸表、取模日期、负责技师、复诊预约和附件文件；附件导入时要复制到项目数据目录，计算 SHA256，识别同名不同内容、缺失扫描文件、照片和尺寸记录不匹配这些问题。应用要有左侧患者/订单列表，中间是订单阶段看板（待取模、待设计、制作中、待试穿、需返修、已交付），右侧详情区能维护尺寸版本、附件清单、试穿反馈和返修原因。状态流转要有规则：没有尺寸版本不能进入设计，没有扫描或照片不能进入制作，返修必须关联一次试穿记录，交付前必须生成最终清单；每次状态变化和尺寸修改都要写入本地 SQLite 或文件数据库，重启后能继续。还要支持从门诊 CSV 导入预约和尺寸初稿，导入时逐行校验手机号、左右侧枚举、日期格式和重复订单；支持导出 Markdown 交付单、CSV 订单列表和一个包含附件哈希的 JSON 审计包。请把 GUI 入口、数据模型、附件归档、校验规则、状态机、持久化、导入导出、报告生成、示例数据和测试拆成多个文件，不要写成一个大脚本。README 里写清楚安装方式、启动命令，以及如何用临时目录验证创建患者、导入附件、推进状态、记录试穿返修、导入 CSV 和导出交付包这些核心流程。
