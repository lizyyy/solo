# 牙科器材库器械消毒台账 CLI 验收工具

## 功能概述

牙科器材库器械消毒台账自动化验收工具，支持先预览计划动作，再由正式模式写入结果文件。专门针对牙科消毒台账业务设计。

## 快速开始

### 1. 预览模式（默认）
先查看验收结果，不写入文件：
```bash
python3 disinfection_cli.py sample_input.json
```

### 2. 正式模式
确认无误后，写入结果文件：
```bash
python3 disinfection_cli.py sample_input.json --正式模式
```

### 3. 指定配置和输出
```bash
python3 disinfection_cli.py sample_input.json --配置 config.json --输出 我的验收结果.json
```

## 验收规则（默认口径）

### 🔴 消毒机离线检查
- **规则**: 使用在 `offline_sterilizers` 列表中的消毒机视为无效
- **原因**: 这些消毒机处于维护状态，不可用于消毒
- **严重级别**: ERROR
- **默认离线消毒机**: DIS-003, DIS-007

### 🟠 跨科室借用检查
- **规则1**: 必须在 `allowed_cross_departments` 允许列表中
- **规则2**: 必须有 `借用审批状态 = "已审批"`
- **严重级别**: 不在列表中=WARNING, 缺少审批=ERROR
- **默认允许借用路径**:
  - 牙体牙髓科 → 修复科
  - 正畸科 → 牙周科
  - 口腔外科 → 种植科

### 🔴 消毒记录完整性
- **规则**: `消毒前检查`、`消毒方式`、`消毒时长`、`消毒后检测` 必须填写
- **严重级别**: ERROR

### 🔴 时间逻辑一致性
- **规则**: 回收时间 < 消毒时间 < 发放时间
- **严重级别**: ERROR

## 可复跑特性

- 每次正式运行都会生成**带时间戳**的独立输出文件
- 不会覆盖之前的运行结果
- 相同输入多次运行，结果一致（幂等性）
- 便于追踪验收历史和问题修复过程

## 自定义规则

修改 [config.json](file:///Users/mac/pro/solo/workspaces/xy11132/config.json) 来自定义验收规则：

```json
{
  "offline_sterilizers": ["DIS-003", "DIS-007"],
  "sterilizer_maintenance": {
    "DIS-003": "2026-06-15"
  },
  "allowed_cross_departments": [
    "牙体牙髓科->修复科"
  ]
}
```

## 支持的输入格式

- **JSON**: 数组格式，每条记录为对象
- **CSV**: 表头字段需与JSON字段名一致

## 给新接手同事的建议

1. **先跑样例**: `python3 disinfection_cli.py sample_input.json`
2. **看输出**: 理解各种错误是如何被检测出来的
3. **改规则**: 修改 `config.json` 适配当前科室实际情况
4. **导数据**: 将真实台账导出为JSON或CSV格式
5. **先预览**: 不带 `--正式模式` 先看问题
6. **改数据**: 在原始台账中修复发现的问题
7. **正式跑**: 确认无误后加 `--正式模式` 存档
