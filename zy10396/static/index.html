功能说明

  • 调用方管理 - 管理使用 API 的业务系统或团队
  • 接口组管理 - 对 API 进行分组，便于统一计费
  • 资源单价 - 设置不同接口组的调用单价，支持版本管理
  • 调用记录 - 批量提交调用量，支持幂等性
  • 分摊规则 - 定义成本分摊计算规则，支持版本管理
  • 月度分摊 - 按月聚合调用量并计算分摊成本
  • 成本试算 - 预览计算结果，不生成正式数据
  • 调整记录 - 支持对分摊结果进行人工调整
  • 历史查询 - 分页查询历史分摊结果
  • 数据导出 - 导出为 Excel 格式，支持幂等性
