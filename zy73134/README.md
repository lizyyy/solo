# 潮汐能站报告汇总 Web3D

## 安装

```bash
npm install
```

## 启动

```bash
npm run dev
```

浏览器打开 <http://localhost:5173>

## 样例数据

内置 18 条东海沿岸潮汐能站样例记录：正常 / 时间冲突 / 结果超阈值 / 云遮挡 四类场景。

路径：`src/data/sampleStations.ts`

## 快速上手

1. 左侧 3D 场景查看站点空间分布，颜色：绿色正常 / 红色异常 / 灰色云遮 / 黄色待确认
2. 右侧面板切换「异常队列」Tab，默认筛出所有异常记录
3. 点击 3D 标记或列表行 → 弹窗查看详情，**原始脏数据字段保留不自动修正**
4. 填写「人工备注」→ 保存 → 记录变为「已核对」，并标记新批次号
5. 顶部工具栏「导出」→ 重新汇总 + 新旧记录对比 + 下载 JSON

## 找到异常队列

- 页面右侧面板 → 顶部 Tab → 点「异常队列」
- 可勾选筛选：☁️ 云遮挡严重 · ⏱ 采样时间冲突 · ⚠️ 结果超阈值

## 重新导出 & 对比

- 补完若干条备注后 → 顶部「导出」按钮
- 弹窗内可见「原始批次 vs 新导出」对比表，变更字段橙色高亮
- 点「下载 JSON」→ 文件名 `tidal-stations-report-时间戳.json`，含 `records` / `originalRecords` / `diff` 三层
