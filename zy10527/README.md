# 内部公告版本 API

## 项目概述

轻量级RESTful服务，用于管理内部公告的版本控制、员工确认、补充说明、撤回记录和确认报告导出。

## 核心功能

- **公告版本管理**: 创建公告、多版本迭代
- **员工确认回执**: 员工可对特定版本公告进行确认
- **补充说明**: 可对已有版本添加补充说明
- **撤回管理**: 支持撤回指定版本或全部公告
- **人工修正**: 管理员可修正历史版本内容
- **审计日志**: 所有操作均留痕，异常路径保留原始输入
- **报告导出**: 支持CSV格式导出确认报告

## 技术栈

- **框架**: FastAPI
- **数据库**: SQLite + SQLAlchemy ORM
- **数据验证**: Pydantic

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python main.py
```

服务启动后访问:
- API文档: http://localhost:8000/docs
- 备用文档: http://localhost:8000/redoc


## API 接口概览

### 公告管理

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/announcements` | 创建公告 |
| GET | `/announcements` | 查询公告列表 |
| GET | `/announcements/{no}` | 查询公告详情（含所有版本、确认、撤回记录） |
| POST | `/announcements/{no}/versions` | 创建新版本 |

### 确认管理

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/confirmations` | 员工确认公告 |

### 补充说明

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/supplements` | 给指定版本添加补充说明 |

### 撤回管理

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/withdrawals` | 撤回指定版本或全部公告 |

### 人工修正

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/manual-correction` | 人工修正历史版本内容 |

### 报告导出

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/reports/confirmations` | 查询确认报告 |
| GET | `/reports/confirmations/export` | 导出CSV报告 |

### 审计日志

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/audit-logs` | 查询操作审计日志 |

## 数据模型

- **Announcement**: 公告主表（编号、标题、创建人、状态）
- **AnnouncementVersion**: 版本表（内容、版本号、补充说明）
- **Confirmation**: 确认记录表（确认人、确认时间、备注）
- **Withdrawal**: 撤回记录表（撤回人、撤回时间、原因）
- **AuditLog**: 审计日志表（操作类型、原始输入、错误信息、操作者）
