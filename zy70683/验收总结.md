# 访客餐券会议取消核销状态排查CLI - 验收总结

## 项目文件清单

| 文件 | 说明 |
|------|------|
| [models.py](file:///Users/lzy/pro/solo/workspaces/zy70683/models.py) | 数据模型定义（餐券、会议、访客、核销记录等） |
| [service.py](file:///Users/lzy/pro/solo/workspaces/zy70683/service.py) | 核心业务逻辑（发放、会议联动、取消失效、核销幂等） |

## 核心功能实现

### 1. 餐券发放
- 访客与会议关联验证
- 有效期管理
- 状态追踪（已发放/已使用/已取消/已过期）

### 2. 会议联动
- 会议取消自动联动关联餐券
- 支持选择是否自动取消餐券

### 3. 取消失效
- 会议取消时餐券状态自动更新
- 取消原因记录

### 4. 核销幂等
- 重复核销返回最新检查结果
- 明确提示"幂等保护"

### 5. 报告导出
- **人读格式**：友好的控制台输出，含统计概览和详细记录
- **机器可读格式**：标准JSON格式，便于自动化处理

## 验收样例

### 正常样例 - VC20260518000005
- **场景**：会议正常进行，餐券状态正常
- **核销历史状态**：`NO_ACTION`（无需核销）
- **报告显示**：核销状态"无需核销"，备注"状态正常，无需核销"
- **一致性验证**：历史记录 ↔ 报告数据 完全一致

### 异常样例 - VC20260518000006
- **场景**：会议已取消，但餐券仍为已发放状态
- **核销历史状态**：`PENDING`（待核销）
- **报告显示**：核销状态"待核销"，备注"会议已取消：验收测试：会议临时取消"
- **一致性验证**：历史记录 ↔ 报告数据 ↔ 错误提示 三者完全对应

## 边界与异常场景

| 场景 | 验证结果 |
|------|----------|
| 餐券已使用后会议取消 | 标记为`CONFLICT`冲突状态，需人工处理 |
| 查询不存在的餐券 | 返回`success: false`，错误提示"餐券不存在" |
| 重复执行核销 | 返回已有记录，提示"幂等保护" |
| 脏数据输入 | 系统正常运行，不崩溃 |
| 空数据集 | 返回空报告，统计为0 |

## 使用方法

```bash
# 生成样例数据
python3 generate_samples.py

# 查看人读格式报告
python3 cli.py report --format human

# 查看机器可读格式报告
python3 cli.py report --format json

# 查看所有核销历史
python3 cli.py history

# 查看单个餐券核销历史
python3 cli.py history --voucher-code VC20260518000006

# 执行核销检查
python3 cli.py verify --voucher-code VC20260518000006 --operator "管理员"
```
