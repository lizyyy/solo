## 1. 产品概述

公园活动噪声调解追踪系统——面向市政设计师等一线审批人员，解决"同一地点写法五花八门、投诉重复、方案迭代后历史丢失"的痛点，让点位、居民反馈、调解方案版本和报告之间可互相追溯，且"公园活动噪声调解"每条记录都能追到原始来源。

- 目标用户：市政设计师（如老曹）及其同事、后续接手人员
- 核心价值：消除因地名写法不一致导致的点位混淆，保留方案迭代历史，确保跨人员交接时判据清晰

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 市政设计师 | 直接访问 | 录入/编辑点位、反馈、方案；查看报告；添加人工备注 |
| 接手同事 | 直接访问 | 只读全部记录与历史；可继续添加新方案与备注 |

### 2.2 功能模块

1. **总览看板**：地图标注 + 统计卡片 + 最近动态
2. **点位管理**：点位列表/地图标注、归一化合并、同名路口识别、坐标偏移标注
3. **反馈追踪**：居民反馈列表、重复投诉标记、来源追溯
4. **方案版本**：调解方案 CRUD、版本覆盖时历史意见保留、补材料续处理
5. **调解报告**：自动生成报告、同事风格文案、跨时段统计

## 3. 核心流程

1. 市政设计师录入居民反馈（含点位名称、坐标、投诉内容、来源）
2. 系统自动识别：同名路口、重复投诉、坐标偏移，并标注提醒
3. 设计师确认/合并点位归一化，将反馈关联到正确点位
4. 设计师编写调解方案（v1），方案与点位、反馈绑定
5. 后续方案迭代（v2、v3…），旧版本意见自动保留
6. 补材料时，在最新版本上继续追加，不丢失历史
7. 生成调解报告：自动汇总，文案像同事写给同事看的话
8. 刷新页面后，地图标注、人工备注、报告数字不丢失
9. 换人接手时，可追溯每条"公园活动噪声调解"记录的原始来源和判据

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：沉稳的灰绿色（#4A5568 基底），搭配暖橙（#DD6B20）作为强调色——市政公文的严肃感 + 同事间的温度感
- **辅助色**：浅灰蓝（#E2E8F0）用于卡片背景，琥珀色（#D69E2E）用于警告/边界标记
- **按钮风格**：圆角 8px，主按钮灰绿实色，次要按钮浅底描边
- **字体**：标题用 Noto Serif SC（公文质感），正文用 Noto Sans SC（清晰易读）
- **布局**：左侧导航 + 右侧主内容区，卡片式布局，固定高度内滚动
- **图标风格**：线性图标（lucide-react），尺寸 16-20px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 总览看板 | 地图标注区 | 占页面 60% 高度的地图，点位用自定义标记，点击弹出卡片 |
| 总览看板 | 统计卡片 | 4 列网格，数字大字 + 标签小字，hover 微抬升 |
| 总览看板 | 最近动态 | 左侧时间线，右侧简略内容，渐入动画 |
| 点位管理 | 点位列表 | 表格，同名行黄色底纹，偏移行橙色标记，空值灰色斜体 |
| 点位管理 | 归一化操作 | 拖拽或勾选合并，右侧预览合并后结果 |
| 反馈追踪 | 反馈列表 | 表格，重复行折叠显示关联项，边界行琥珀边框 |
| 方案版本 | 方案列表 | 卡片列表，当前版本实色徽章，历史版本折叠 |
| 方案版本 | 版本对比 | 左右分栏 diff 视图，删除线 + 新增高亮 |
| 调解报告 | 报告详情 | A4 纸张风格排版，专业但口语化，追源脚注 |

### 4.3 响应式

- 桌面优先（1440px 设计基准）
- 1280px 以下：侧边栏收起为图标导航
- 768px 以下：单列布局，地图全宽
