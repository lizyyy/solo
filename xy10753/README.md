# 库存预留释放服务

一个轻量级的库存预留释放管理系统，专为研发经理设计。

## 功能特性

### 核心功能
- **预留单校验**：检查预留单是否有效、是否超时
- **超时释放**：手动释放超时的预留库存
- **取消回滚**：取消预留单并记录失败原因
- **并发冲突记录**：使用版本号机制检测和记录并发操作冲突
- **库存流水**：完整记录所有库存操作历史
- **数据导出**：按负责人、时间和超时释放分组导出 CSV

### 前端功能
- 权限提示显示
- 搜索框（支持预留单ID、订单号、SKU、负责人）
- 统计面板展示
- 预留单管理标签页
- 库存流水标签页
- 并发冲突记录标签页

## 技术栈

- **后端**：Python Flask
- **前端**：原生 HTML + JavaScript
- **数据存储**：JSON 文件

## 快速开始

### 1. 启动后端服务
```bash
python3 app.py
```
服务将在 http://localhost:5000 启动

### 2. 打开前端页面
直接在浏览器中打开 `index.html` 文件即可使用

## 操作说明

### 1. 校验预留单
点击预留单列表中的「校验」按钮，系统会检查该预留单是否超时。

### 2. 释放预留单
点击「释放」按钮释放预留库存。系统会：
- 检查版本号是否匹配（防止并发冲突）
- 更新预留单状态为「已释放」
- 记录库存流水

### 3. 取消回滚
点击「取消」按钮，输入取消原因后确认：
- 预留单状态变为「已取消」
- 取消原因会记录在库存流水中

### 4. 并发冲突测试
尝试对 RES-004 使用错误的版本号（v1）进行释放操作，系统会检测到并发冲突并记录。

### 5. 导出库存流水
点击「导出库存流水」按钮，系统会生成按以下分组的 CSV 文件：
- 按负责人分组
- 按是否为超时释放分组
- 按操作时间倒序排列

## API 接口

### 预留单相关
- `GET /api/reservations` - 获取预留单列表（支持 search 参数）
- `POST /api/reservations/<id>/validate` - 校验预留单
- `POST /api/reservations/<id>/release` - 释放预留单
- `POST /api/reservations/<id>/cancel` - 取消回滚预留单

### 数据查询
- `GET /api/inventory-flow` - 获取库存流水
- `GET /api/conflicts` - 获取并发冲突记录
- `GET /api/stats` - 获取统计数据

### 导出
- `GET /api/export/inventory-flow` - 导出库存流水 CSV

## 数据文件

系统数据保存在 `data.json` 文件中，包含：
- `reservations` - 预留单列表
- `inventory_flow` - 库存流水记录
- `conflict_records` - 并发冲突记录
