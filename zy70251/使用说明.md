# 医院病理标本外送 API - 使用说明

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务

```bash
npm start
```

服务将在 `http://localhost:3000` 启动

### 3. 验证服务

```bash
curl http://localhost:3000/health
```

### 第二步：创建外送批次并打包标本

**场景**：将3个标本打包成一个批次准备外送。

**API 调用**：
```bash
# 创建批次
curl -X POST http://localhost:3000/api/batches \
  -H "Content-Type: application/json" \
  -d '{
    "destination_lab": "第三方基因检测实验室",
    "courier": "顺丰冷链物流",
    "scheduled_time": "2026-05-11T14:00:00.000Z",
    "operator": "王护士"
  }'
```

**注意**：从返回结果中获取批次 `id`，用于后续操作。假设批次ID为 `<batch_id>`。

```bash
# 将标本1加入批次
curl -X POST http://localhost:3000/api/specimens/<specimen1_id>/add-to-batch \
  -H "Content-Type: application/json" \
  -d '{"batch_id": "<batch_id>", "operator": "王护士"}'

# 将标本2加入批次
curl -X POST http://localhost:3000/api/specimens/<specimen2_id>/add-to-batch \
  -H "Content-Type: application/json" \
  -d '{"batch_id": "<batch_id>", "operator": "王护士"}'

# 将标本3加入批次
curl -X POST http://localhost:3000/api/specimens/<specimen3_id>/add-to-batch \
  -H "Content-Type: application/json" \
  -d '{"batch_id": "<batch_id>", "operator": "王护士"}'
```

**批次状态流转**：
```bash
# 批次准备就绪
curl -X POST http://localhost:3000/api/batches/<batch_id>/ready \
  -H "Content-Type: application/json" \
  -d '{"operator": "王护士"}'

# 批次发货
curl -X POST http://localhost:3000/api/batches/<batch_id>/ship \
  -H "Content-Type: application/json" \
  -d '{"operator": "张快递"}'

# 批次开始运输
curl -X POST http://localhost:3000/api/batches/<batch_id>/start-transit \
  -H "Content-Type: application/json" \
  -d '{"operator": "张快递"}'
```

**验证结果**：查看批次详情
```bash
curl http://localhost:3000/api/batches/<batch_id>
```

### 第三步：冷链片段追踪

**场景**：记录冷链运输过程，确保标本在运输过程中的温度控制。

**冷链片段类型**：
- `outbound` - 出库段（医院→中转站）
- `transfer` - 中转段（中转站→中转站）
- `last_mile` - 最后一公里（中转站→实验室）

**API 调用**：
```bash
# 创建出库冷链片段
curl -X POST http://localhost:3000/api/chain-segments \
  -H "Content-Type: application/json" \
  -d '{
    "batch_id": "<batch_id>",
    "segment_type": "outbound",
    "start_time": "2026-05-11T14:00:00.000Z",
    "start_location": "医院病理科冷库",
    "operator": "张快递",
    "notes": "标本从医院病理科出库"
  }'
```

**注意**：获取片段ID `<segment1_id>`

```bash
# 完成出库冷链片段 (模拟2小时后到达中转站)
curl -X POST http://localhost:3000/api/chain-segments/<segment1_id>/complete \
  -H "Content-Type: application/json" \
  -d '{
    "end_time": "2026-05-11T16:00:00.000Z",
    "end_location": "顺丰冷链中转站",
    "temperature_min": -20,
    "temperature_max": -15,
    "temperature_avg": -18,
    "operator": "中转站管理员",
    "notes": "温度正常，货物完好"
  }'

# 创建最后一公里冷链片段
curl -X POST http://localhost:3000/api/chain-segments \
  -H "Content-Type: application/json" \
  -d '{
    "batch_id": "<batch_id>",
    "segment_type": "last_mile",
    "start_time": "2026-05-11T16:00:00.000Z",
    "start_location": "顺丰冷链中转站",
    "operator": "赵快递",
    "notes": "从中转站发往实验室"
  }'
```

**获取片段ID `<segment2_id>`**

```bash
# 完成最后一公里冷链片段
curl -X POST http://localhost:3000/api/chain-segments/<segment2_id>/complete \
  -H "Content-Type: application/json" \
  -d '{
    "end_time": "2026-05-11T17:00:00.000Z",
    "end_location": "第三方基因检测实验室",
    "temperature_min": -19,
    "temperature_max": -16,
    "temperature_avg": -17.5,
    "operator": "实验室接收员",
    "notes": "收到货物，温度记录正常"
  }'
```

**验证冷链完整性**：
```bash
curl http://localhost:3000/api/chain-segments/batch/<batch_id>/verify
```

**返回示例**：
```json
{
  "data": {
    "verified": true,
    "reason": "冷链验证通过",
    "details": {
      "segmentCount": 2,
      "temperatureIssueCount": 0,
      "segments": [...]
    }
  }
}
```

### 第四步：批次送达确认

**场景**：第三方实验室确认收到标本。

**API 调用**：
```bash
curl -X POST http://localhost:3000/api/batches/<batch_id>/deliver \
  -H "Content-Type: application/json" \
  -d '{"operator": "实验室接收员"}'
```

---

### 第五步：检测报告回传

**场景**：第三方实验室完成检测，回传报告。

**报告状态流转**：
- `generated` - 报告已生成
- `reviewed` - 报告已审核
- `finalized` - 报告已终审（标本状态变为 completed）

**API 调用**：
```bash
# 创建标本1的报告
curl -X POST http://localhost:3000/api/reports \
  -H "Content-Type: application/json" \
  -d '{
    "specimen_id": "<specimen1_id>",
    "report_type": "基因检测报告",
    "result": "EGFR基因第19外显子缺失突变",
    "conclusion": "建议使用EGFR-TKI靶向药物治疗",
    "operator": "陈检验师"
  }'

# 创建标本2的报告
curl -X POST http://localhost:3000/api/reports \
  -H "Content-Type: application/json" \
  -d '{
    "specimen_id": "<specimen2_id>",
    "report_type": "细胞学诊断报告",
    "result": "找到异型细胞，考虑腺癌",
    "conclusion": "建议进一步组织学检查",
    "operator": "陈检验师"
  }'

# 创建标本3的报告
curl -X POST http://localhost:3000/api/reports \
  -H "Content-Type: application/json" \
  -d '{
    "specimen_id": "<specimen3_id>",
    "report_type": "免疫组化报告",
    "result": "PD-L1表达阳性 (TPS 60%)",
    "conclusion": "可考虑免疫治疗",
    "operator": "陈检验师"
  }'
```

**审核并终审报告**（对每个报告执行）：
```bash
# 审核报告
curl -X POST http://localhost:3000/api/reports/<report_id>/review \
  -H "Content-Type: application/json" \
  -d '{"operator": "主任检验师", "reason": "报告审核通过"}'

# 终审报告 (标本状态变为 completed)
curl -X POST http://localhost:3000/api/reports/<report_id>/finalize \
  -H "Content-Type: application/json" \
  -d '{"operator": "主任检验师"}'
```

---

### 第六步：批次闭环

**场景**：所有标本报告完成，标记批次为已报告。

**API 调用**：
```bash
curl -X POST http://localhost:3000/api/batches/<batch_id>/mark-reported \
  -H "Content-Type: application/json" \
  -d '{"operator": "系统管理员"}'
```

## 查看报表和看板

### 1. 系统概览看板

```bash
curl http://localhost:3000/api/dashboard/overview
```

**返回内容**：
- 总标本数、总批次、总报告数
- 各状态的标本/批次/报告数量统计
- 今日新增数据
- 进行中的冷链片段

---

### 2. 标本时间线追踪

```bash
curl http://localhost:3000/api/dashboard/specimen-timeline/SP-2026-001
```

**返回内容**：
- 标本条码、患者信息
- 当前状态
- 总体进度百分比
- 完整时间线：
  1. 标本登记
  2. 加入批次
  3. 冷链运输（含温度记录）
  4. 送达确认
  5. 报告回传

---

### 3. 批次完整报告

```bash
curl http://localhost:3000/api/dashboard/batch-report/<batch_number>
```

**返回内容**：
- 批次基本信息（批次号、目标实验室、物流、状态等）
- 标本统计（总数、各状态数量）
- 标本详情列表（条码、患者、状态、报告号）
- 冷链验证结果
- 冷链片段详情（类型、时间、温度范围）
- 报告统计
- 总体进度百分比

---

### 4. 冷链告警

```bash
curl http://localhost:3000/api/dashboard/cold-chain-alerts
```

**告警类型**：
- `incomplete_chain` - 未完成的冷链片段
- `temperature_violation` - 温度超出范围（<-25°C 或 >8°C）
- `pending_reports` - 已送达但未创建报告的标本

## 状态机说明

### 标本状态流转
```
created → in_batch → shipped → in_transit → delivered → reported → completed
```

### 批次状态流转
```
created → ready → shipped → in_transit → delivered → reported
```

### 冷链片段状态流转
```
in_progress → completed
```

### 报告状态流转
```
pending → generated → reviewed → finalized
```

## 核心 API 列表

### 标本 (Specimens)
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/specimens | 创建标本 |
| GET | /api/specimens | 获取标本列表 |
| GET | /api/specimens/:id | 获取标本详情 |
| GET | /api/specimens/barcode/:barcode | 通过条码获取标本 |
| POST | /api/specimens/:id/add-to-batch | 加入批次 |
| POST | /api/specimens/:id/remove-from-batch | 从批次移除 |
| GET | /api/specimens/:id/history | 状态历史 |

### 批次 (Batches)
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/batches | 创建批次 |
| GET | /api/batches | 获取批次列表 |
| GET | /api/batches/:id | 获取批次详情 |
| POST | /api/batches/:id/ready | 准备就绪 |
| POST | /api/batches/:id/ship | 发货 |
| POST | /api/batches/:id/start-transit | 开始运输 |
| POST | /api/batches/:id/deliver | 送达确认 |
| POST | /api/batches/:id/mark-reported | 标记为已报告 |
| DELETE | /api/batches/:id | 删除批次（仅空批次） |

### 冷链片段 (Chain Segments)
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/chain-segments | 创建冷链片段 |

| GET | /api/chain-segments/:id | 获取详情 |
| POST | /api/chain-segments/:id/complete | 完成片段 |
| GET | /api/chain-segments/batch/:batchId | 批次冷链片段 |
| GET | /api/chain-segments/batch/:batchId/verify | 验证冷链 |

### 报告 (Reports)

|------|------|------|

| PUT | /api/reports/:id/content | 修改报告内容 |
| POST | /api/reports/:id/review | 审核报告 |
| POST | /api/reports/:id/finalize | 终审报告 |

### 看板/报表 (Dashboard)
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/dashboard/overview | 系统概览 |
