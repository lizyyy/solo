## 1. 产品概述

珊瑚白化报告汇总系统，面向海洋生态调查团队与算法值班人，解决调查数据从船上记录本到最终报告链路中的数据溯源、参数追踪、异常对齐和沟通输出问题。核心价值：让采样时间与实验结果的错配可追溯、参数变更可归因、经纬度反写可持久化、异常队列可直接用于跨团队沟通。

- 目标用户：生态调查员（如阿宁，负责录入和校验船上记录本数据）、算法值班人（负责调参跑报告、定位异常来源）、报告审阅人（需要可直接沟通的异常队列）
- 解决的核心问题：数据溯源断层、参数变更不可归因、异常只看总数不看明细、历史备注丢失、经纬度反写不持久

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 生态调查员 | 登录系统 | 录入船上记录本数据、添加后补备注、校验采样时间与实验结果 |
| 算法值班人 | 登录系统 | 调参跑报告、查看参数变更链、异常明细下钻、导出报告 |
| 报告审阅人 | 登录系统 | 查看异常队列、确认异常口径、下载沟通版报告 |

### 2.2 功能模块

1. **报告汇总主页面**：异常队列总览、汇总统计口径、参数变更快照、最近一次跑批状态
2. **数据录入与校验页**：船上记录本录入、后补备注标注、采样时间/实验结果匹配校验
3. **参数追踪页**：历史参数快照列表、参数 diff 对比、每步变更标记
4. **异常明细页**：异常记录列表（含溯源链）、口径映射关系、经纬度反写状态、历史备注
5. **报告导出页**：沟通版异常队列导出、经纬度反写持久化到文件、历史备注保留

## 3. 核心流程

### 3.1 数据录入与校验流程

生态调查员从船上记录本录入数据，系统自动检测采样时间与实验结果错配，调查员可添加后补备注说明旧数据来源。后补备注永久关联原始记录，重跑不丢失。

```mermaid
flowchart TD
    "船上记录本录入" --> "时空匹配校验"
    "时空匹配校验" -->|"通过"| "数据入库"
    "时空匹配校验" -->|"错配"| "标红提示"
    "标红提示" --> "添加后补备注"
    "添加后补备注" --> "数据入库（标注来源）"
    "数据入库" --> "触发跑批"
```

### 3.2 参数变更与报告跑批流程

算法值班人调整参数重新跑报告时，系统自动保存参数快照，标记变更步骤，异常队列与当前状态对齐，历史备注保留。

```mermaid
flowchart TD
    "调整参数" --> "保存参数快照"
    "保存参数快照" --> "跑批执行"
    "跑批执行" --> "生成异常队列"
    "生成异常队列" --> "保留历史备注"
    "保留历史备注" --> "异常队列与当前状态对齐"
    "异常队列与当前状态对齐" --> "标记变更影响"
```

### 3.3 经纬度反写流程

经纬度反写不仅更新页面展示，同时持久化到记录详情和导出文件。

```mermaid
flowchart TD
    "检测经纬度反写" --> "修正经纬度值"
    "修正经纬度值" --> "持久化到记录详情"
    "修正经纬度值" --> "持久化到导出文件"
    "持久化到记录详情" --> "标注反写操作记录"
    "持久化到导出文件" --> "标注反写操作记录"
```

### 3.4 异常队列沟通输出流程

最终输出的异常队列不是功能清单，而是可直接用于跨团队沟通的结构化文档。

```mermaid
flowchart TD
    "异常队列生成" --> "映射汇总口径"
    "映射汇总口径" --> "附加历史备注"
    "附加历史备注" --> "附加经纬度反写记录"
    "附加经纬度反写记录" --> "生成沟通版文档"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 (#0A2540) 为主色，珊瑚橙 (#FF6B4A) 为强调色，海泡绿 (#4ECDC4) 为辅助色
- **按钮风格**：圆角 (rounded-lg)，主操作用珊瑚橙实心，次操作用深海蓝描边
- **字体**：标题使用 DM Serif Display，正文使用 DM Sans，数据/代码使用 JetBrains Mono
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式模块布局
- **图标风格**：Lucide 线性图标，搭配色彩区分模块
- **氛围元素**：背景使用极淡的海洋波纹纹理，卡片带微妙阴影和半透明效果

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
