# 窄水道避碰演练

一款专为港航学院引航课设计的本地 2D 训练小游戏，帮助学生学习国际海上避碰规则（COLREGs）和窄水道操船技巧。

## 功能特性

### 🎮 游戏核心
- **回合制操船系统**: 玩家可为所有可控船舶规划移动后统一执行
- **船舶类型**: 拖轮（蓝色）、货船（红色）、来船（紫色）
- **地形系统**: 深水航道、浅滩（禁入）、限速区、泊位

### 📋 规则判定
- **潮流系统**: 橙色箭头指示，自动推动船舶位移
- **惯性系统**: 船舶不能立即停下，有衰减惯性
- **会遇避让判定**:
  - 交叉相遇：让右方来船
  - 对遇：各自向右转向
  - 追越：追越船让路

### 📊 教学功能
- **事故和扣分记录**: 实时记录碰撞、违规等事件
- **撤销功能**: 支持最多50步操作撤销/重做
- **导出复盘**: 
  - Markdown 格式详细复盘报告
  - JSON 格式回放数据
- **本地存储**: 使用 localStorage 保存关卡和进度

### 🛠️ 关卡编辑
- **可视化编辑器**: 绘制地形、放置船舶、设置潮流
- **示例关卡**: 3个预设训练关卡
  - 基础进港练习（简单）
  - 潮流区避碰（中等）
  - 复杂港内操纵（困难）

## 快速开始

### 运行方式

本项目是纯前端应用，无需任何后端依赖，直接在浏览器中打开即可运行。

**方式一：直接打开**
```bash
# 在项目目录下直接用浏览器打开
open index.html
```

**方式二：使用本地服务器（推荐）**
```bash
# 使用 Python
python3 -m http.server 8080

# 或使用 Node.js
npx serve .

# 或使用 VS Code 的 Live Server 插件
```

然后在浏览器中访问 `http://localhost:8080`

## 操作指南

### 演练模式操作

**鼠标操作：**
- 点击船舶选中（黄色边框高亮）
- 选中后点击目标位置规划移动
- 右键点击取消移动规划

**键盘操作：**
- `W/A/S/D` 或 `方向键`：为选中船舶规划移动
- `Shift + 方向键`：加速移动（最多2格）
- `Enter` 或 `空格`：执行下一回合
- `Delete` 或 `Backspace`：取消移动规划
- `Ctrl + Z`：撤销上一步

### 关卡编辑操作

**编辑工具：**
- 选择工具：选择已放置的元素进行操作
- 深水航道：设置为蓝色可航行区域
- 浅滩：设置为黄色禁入区域
- 限速区：设置为灰色，每回合最多移动1格
- 泊位：设置为绿色停靠区域
- 设置潮流：设置橙色箭头推动区域
- 拖轮：放置蓝色可控拖轮
- 货船：放置红色可控货船
- 来船：放置紫色AI/预设路线船

## 扣分标准

| 违规类型 | 扣分数 | 说明 |
|----------|--------|------|
| 碰撞事故 | 10分 | 船舶间发生碰撞 |
| 浅滩驶入 | 5分 | 船舶驶入浅滩区域 |
| 越界违规 | 5分 | 船舶驶出棋盘边界 |
| 让路违规 | 3分 | 未按避碰规则让路 |
| 超速违规 | 2分 | 在限速区超速行驶 |

## 避碰规则速览

### 交叉相遇
- **规则**: 让右方来船
- **说明**: 当有他船在本船右舷时，本船是让路船，应给他船让路

### 对遇
- **规则**: 各自向右转向
- **说明**: 两船对遇或接近对遇时，应各自向右转向，从他船左舷驶过

### 追越
- **规则**: 追越船让路
- **说明**: 任何船舶在追越任何他船时，均应给被追越船让路，被追越船为直航船

### 自定义样式

修改 `css/style.css` 文件进行样式定制。
