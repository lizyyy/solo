## 1. 产品概述

芯片引脚信号塔——面向硬件评审工程师的 3D 交互式芯片封装评审工具。在 3D 封装空间内可视化引脚信号、电压域分布与冲突风险，支持点击查看数据、电压域筛选、冲突标记与评审报告批次导出，解决传统 2D 表格评审中引脚关系不直观、电压域混接与复用冲突易遗漏的问题。

- 目标用户：硬件评审工程师、芯片封装设计师
- 核心价值：将引脚-信号-电压域-冲突信息叠加到 3D 空间，冲突标记而非武断合并，评审结果可追溯、可区分批次

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 评审工程师 | 默认进入 | 浏览 3D 场景、筛选电压域、查看冲突、导出报告 |
| 封装设计师 | 默认进入 | 同上，可切换封装视角查看引脚布局 |

### 2.2 功能模块

1. **评审工作台页面**：3D 封装场景、引脚信号塔、电压域筛选面板、冲突提示面板、数据详情面板、报告导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 评审工作台 | 3D 封装场景 | 渲染芯片封装 3D 模型，引脚以信号塔形式从封装体向上延伸，按电压域着色；支持旋转、缩放、平移 |
| 评审工作台 | 引脚信号塔 | 每个引脚对应一根垂直信号塔柱体，高度映射信号频率/重要性，颜色映射电压域，悬停/点击显示引脚详情 |
| 评审工作台 | 电压域筛选面板 | 左侧面板列出所有电压域，点击域名高亮该域引脚、弱化其他引脚；支持多选 |
| 评审工作台 | 冲突提示面板 | 右侧面板列出所有检测到的冲突（电压域混接、引脚复用冲突、标签遮挡），点击冲突项聚焦到对应引脚 |
| 评审工作台 | 数据详情面板 | 点击 3D 场景中引脚/信号塔，底部/侧边弹出面板显示：引脚编号、信号名称、电压域、复用功能、冲突状态 |
| 评审工作台 | 报告导出 | 顶部工具栏提供导出按钮，生成 JSON 格式评审报告，文件名含批次号与时间戳；导出内容包含冲突清单、电压域分布、引脚信号映射 |

## 3. 核心流程

1. 工程师打开评审工作台，加载芯片封装数据
2. 3D 场景渲染封装体与引脚信号塔，按电压域着色
3. 工程师通过电压域筛选面板选择关注的电压域
4. 冲突检测引擎自动标记冲突引脚（红色脉冲闪烁）
5. 工程师点击冲突引脚或冲突列表项，查看详细冲突信息
6. 冲突仅标记，不自动合并或修复
7. 评审完成后导出报告，文件名区分批次

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色工业风底色（#0a0e17 深蓝黑），电压域使用高饱和度霓虹色（青 #00ffd5、橙 #ff6b35、紫 #c084fc、粉 #f472b6）
- **辅助色**：冲突标记用红色脉冲（#ff2d55），安全状态用绿色（#22c55e）
- **按钮风格**：扁平化微光边框按钮，hover 时霓虹描边发光
- **字体**：显示字体使用 JetBrains Mono（技术/等宽感），UI 文字使用 Noto Sans SC
- **布局风格**：左侧筛选面板 + 中间 3D 场景 + 右侧冲突面板 + 底部详情，沉浸式深色工作台
- **图标风格**：线性描边图标（lucide-react）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 评审工作台 | 3D 封装场景 | 深色空间背景、封装体半透明描边、引脚信号塔霓虹着色、冲突引脚红色脉冲动画、环境光+点光源 |
| 评审工作台 | 电压域筛选面板 | 左侧抽屉、电压域色块标签、复选框、选中态发光高亮 |
| 评审工作台 | 冲突提示面板 | 右侧抽屉、冲突类型分组、冲突项红色/橙色标记、点击聚焦动画 |
| 评审工作台 | 数据详情面板 | 底部滑出面板、引脚编号/信号/电压域/冲突状态表格、半透明磨砂背景 |
| 评审工作台 | 报告导出 | 顶部工具栏按钮、批次号输入框、导出按钮带进度提示 |

### 4.3 响应式

- 桌面优先设计，3D 场景占据核心视觉区域
- 面板可折叠收起，确保 3D 场景可见性
- 最小支持 1280px 宽度

### 4.4 3D 场景指引

- **环境**：深空背景，微弱网格地面，无 HDRI
- **光照**：环境光（低强度冷白）+ 多个点光源模拟芯片焊盘反射
- **摄像机**：透视相机，初始 45° 俯视角度，OrbitControls 交互
- **构图**：封装体居中，引脚信号塔向上延伸形成"城市天际线"视觉
- **交互**：点击引脚信号塔高亮并弹出数据；悬停时信号塔微放大+发光
- **动画**：冲突引脚红色脉冲呼吸灯效果；选中电压域时非选中引脚透明度渐变
- **后处理**：Bloom 效果增强霓虹发光感
- **性能预算**：支持 200+ 引脚实时交互，FPS ≥ 30
