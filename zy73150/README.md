# 海洋牧场数据清洗工具

面向生态调查员阿宁的海洋牧场实验室结果表清洗工具。重点解决**离群值不直接删、采样瓶重复先人工确认、材料不齐整退回补齐、月末复核口径统一、异常队列可直接用于沟通**这几个问题。

## 功能特性

- **实验室结果表总览**：内置 6 条示例数据（含 1 条正常、2 条离群值、2 条采样瓶重复、1 条材料不齐整），展示采样瓶、空间坐标、检测指标、来源表、材料齐全度、异常类型、清洗状态。
- **空间位置地图**：Leaflet + OpenStreetMap 展示各采样点坐标，颜色区分异常类型。
- **离群值检测**：指标超出正常范围即标为"离群值"，**不直接删除**，在异常队列中高亮并附判断口径和处理建议。
- **采样瓶重复检测**：同一 `bottleNo` 重复时，先标为**人工确认**，列出所有受影响记录，暂不给出最终统计数。
- **材料不齐整检测**：材料清单（采样瓶标签 / 现场记录表 / GPS / 原始数据 / 交接单 / 冷藏记录）缺失时标为"材料不齐整"，说明缺了哪些。
- **状态切换**：每条记录可在「已确认 / 待补件 / 退回」三态之间切换。
- **异常队列**：按优先级（重复→离群→材料）分组展示，每条异常都带**判断口径、异常说明、受影响记录、处理建议**，页面内容与导出文件口径一致。
- **导出沟通清单**：一键导出 TXT（含 CSV 明细），可直接复制到 Excel 用于跨团队沟通。

## 环境要求

- Node.js >= 18
- npm / pnpm / yarn 任一

## 启动步骤

```bash
# 1. 安装依赖
npm install

# 2. 本地启动（默认 http://localhost:5173）
npm run dev

# 3. 生产构建
npm run build

# 4. 本地预览构建产物
npm run preview
```

## 验收流程建议

1. 启动后进入「数据总览」：
   - 顶部 6 个统计卡片展示总数 / 状态 / 异常分类
   - 左半边地图看到 6 个采样点，颜色区分异常类型
   - 右半边筛选条件支持按状态和异常类型过滤
   - 表格展示所有字段，异常指标用红色高亮
2. 切到「异常队列」：
   - 顶部月末复核状态汇总：已确认 2 / 待补件 3 / 退回 1
   - 按「采样瓶重复 → 离群值 → 材料不齐整」分组展示
   - 点击「当前判断口径」展开查看异常的判定依据和处理建议
   - 采样瓶重复卡片中可见"受影响记录"列出了与之冲突的其他记录
3. 完成一次完整清洗流程：
   - 将 rec-003 从「待补件」改到「已确认」（假设实验室确认是录入重复，保留 B1 点）
   - 将 rec-002 从「待补件」改到「退回」（离群太严重需要重测）
   - 将 rec-005 从「待补件」改到「已确认」（轻度偏离人工核实后保留）
4. 点击右上角「导出沟通清单」，下载 TXT 文件：
   - 头部汇总统计（与页面状态一致）
   - CSV 明细列出每条异常的类型、说明、口径、受影响记录、建议
   - 可直接复制进 Excel 或发给实验室 / 采样组沟通

## 判断口径（页面与导出文件共用）

- **正常**：所有检测指标在正常范围内，采样瓶编号唯一，材料齐全
- **离群值**：任一检测指标超出正常参考范围；离群值不直接删除，需人工核实后再决定
- **采样瓶重复**：同一 `bottleNo` 在结果表中出现多次；先标人工确认，列出所有受影响记录
- **材料不齐整**：6 项材料清单任一项缺失；退回补齐后再复核
