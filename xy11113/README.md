# 养老日托站养老体征日报 CLI 工具

专门用于养老日托站养老体征日报数据清洗的命令行工具，自动分离正常记录和异常记录。

## 功能特性

- ✅ 自动分离正常记录和异常记录
- ✅ 检测空腹/餐后血糖混填
- ✅ 识别重复测量记录
- ✅ 验证数据格式正确性
- ✅ 异常摘要保留来源文件和行号
- ✅ 可复跑输出，处理失败继续处理剩余文件
- ✅ 运营友好的数据修复指南

## 安装方法

### 方式一：全局安装（推荐）

```bash
npm install -g .
```

安装后可直接使用 `elderly-sign-report` 命令。

### 方式二：直接运行

```bash
npm install
node src/cli.js -i 输入目录 -o 输出目录
```

## 使用说明

### 命令格式

```bash
elderly-sign-report -i <输入目录> -o <输出目录>
```

### 参数说明

| 参数 | 别名 | 说明 | 必填 |
|------|------|------|------|
| --input | -i | 包含养老体征日报CSV文件的目录 | 是 |
| --output | -o | 存放处理结果的目录 | 是 |
| --help | -h | 显示帮助信息 | 否 |

## 完整使用示例

### 1. 准备输入数据

将养老体征日报CSV文件放入 `examples/input` 目录，文件命名格式：
```
YYYY-MM-DD-日托站名称-体征日报.csv
```

### 2. 运行数据清洗

```bash
# 安装依赖
npm install

# 运行示例
npm test

# 或直接运行
node src/cli.js -i examples/input -o examples/output
```

### 3. 查看输出结果

输出目录会生成以下文件：

#### 正常记录.csv
- 所有验证通过的体征数据记录
- 包含来源文件和行号信息

#### 异常记录.csv
- 所有存在问题的数据记录
- 包含「异常原因」字段，说明具体问题
- 包含来源文件和行号，方便运营同事定位修复

#### 处理摘要.txt
- 人性化的处理统计报告
- 列出所有异常记录的详细信息
- 包含数据修复操作指南

#### 处理摘要.json
- 机器可读的处理摘要
- 便于集成到其他系统

## 异常检测规则

### 必填字段验证
- 老人姓名不能为空
- 测量日期不能为空
- 测量时间不能为空

### 数据格式验证
- 血压必须为「收缩压/舒张压」格式（如：120/80）
- 血糖必须为有效数字
- 心率必须为有效整数
- 体温必须为有效数字

### 业务规则验证
- 血糖类型必须是「空腹」或「餐后」
- 空腹血糖正常范围：3.9-7.0 mmol/L
- 餐后血糖正常范围：7.8-11.1 mmol/L
- 心率正常范围：60-100 次/分钟
- 体温正常范围：36.0-37.5 ℃

### 重复记录检测
- 同一老人、同一日期时间、同一血糖类型视为重复记录

## 数据修复流程

1. 打开 `处理摘要.txt` 查看异常记录列表
2. 根据「来源文件」和「行号」定位到具体数据
3. 按照「异常原因」修改对应字段
4. 重新运行本程序验证修复结果

## 注意事项

- 程序支持可复跑，多次运行不会影响结果
- 某个文件处理失败时，程序会继续处理其他文件
- 所有输出文件都会保留来源信息，便于追溯
- 建议每天的数据单独存放一个CSV文件
