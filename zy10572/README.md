# 文本编码修复CLI工具

客服导出的文本经常混着全角符号、不可见字符和乱码，在导入知识库之前需要进行清洗。这个CLI工具可以帮助你自动化完成这些工作。

## 功能特性

- ✅ **编码检测**：自动检测文件编码，支持GBK、UTF-8等常见编码
- ✅ **不可见字符定位**：检测并移除NULL、BOM、零宽空格等不可见字符
- ✅ **全角转半角**：自动将全角字符（数字、字母、标点）转换为半角
- ✅ **乱码修复**：识别并替换乱码字符（�）
- ✅ **坏行保留**：保留原始行号和异常原因，便于追溯问题
- ✅ **多种输出格式**：终端摘要、JSON机器可读结果、HTML友好报告
- ✅ **批量处理**：支持目录批量处理，自动生成汇总报告

## 安装

```bash
npm install
```

## 使用方法

### 1. 清洗单个文件

```bash
node src/cli.js clean test/sample.txt
```

指定输出目录：
```bash
node src/cli.js clean test/sample.txt -o ./my_output
```

仅预览不保存：
```bash
node src/cli.js clean test/sample.txt --preview
```

### 2. 批量处理目录

```bash
node src/cli.js batch ./test
```

指定文件扩展名：
```bash
node src/cli.js batch ./test -e txt,csv,md
```

### 3. 仅检测问题不修复

```bash
node src/cli.js detect test/sample.txt
```

## 命令选项

| 选项 | 说明 |
|------|------|
| `-o, --output <dir>` | 指定输出目录 |
| `--no-fullwidth` | 不转换全角字符 |
| `--no-invisible` | 不删除不可见字符 |
| `--no-mojibake` | 不替换乱码字符 |
| `--preview` | 仅预览修复效果，不保存文件 |

## 输出文件说明

每次运行会生成带时间戳的文件，避免覆盖旧结果：

- `*_cleaned.txt` - 清洗后的文本文件
- `*_result.json` - 机器可读的详细分析结果
- `*_report.html` - 适合发给同事的可视化报告
- `*_badlines.txt` - 坏行记录（仅当有坏行时生成）
- `batch_summary_*.json` - 批量处理汇总报告

## 处理的字符类型

### 不可见字符
- NULL、SOH、STX 等 ASCII 控制字符
- BOM（字节顺序标记）
- 零宽空格、零宽非连接符
- 各种特殊空格字符

### 全角字符
- 全角数字：０-９ → 0-9
- 全角字母：ａ-ｚ、Ａ-Ｚ → a-z、A-Z
- 全角标点：，．：；？！＂＇（）［］｛｝等

### 乱码字符
- Unicode 替换字符 �
- 编码错误导致的乱码
