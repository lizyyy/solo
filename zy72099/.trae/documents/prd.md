## 1. 产品概述

展馆参观路线优化系统——面向展馆运营团队，解决路线规划中"脏数据静默丢弃、计算过程不透明、汇总与明细脱节"三大痛点。系统从数据导入、校验、计算、补录到汇总报告全链路留痕，确保每一条异常记录可见、每一次优化建议有据可查、每一张图表可追溯明细，供月度复盘和老板汇报直接使用。

- 目标用户：展馆运营经理、产品同事（如小岑）、管理层（看汇总页的老板）
- 核心价值：让路线优化从"黑箱跑数"变成"可解释、可追溯、可补录"的透明流程

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 运营人员（小岑） | 导入数据、执行优化、补录备注 | 数据导入、优化计算、补录、查看明细 |
| 管理层（老板） | 查看汇总页、图表、追溯明细 | 只读汇总与明细，可从图表下钻 |

### 2.2 功能模块

1. **数据导入与校验页**：数据导入、实时校验、脏数据标记与原因说明
2. **路线优化与诊断页**：执行优化计算、展示推理过程、异常记录面面观
3. **汇总与追溯页**：图表汇总、点击图表下钻明细、补录备注与差异对比、冲突证据展示

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入与校验页 | 样例数据面板 | 内置含空值、重复点、单位混用、异常但正常样貌数据的真实小样例，一键加载 |
| 数据导入与校验页 | 数据导入区 | 支持 JSON 粘贴导入，逐行校验，校验结果实时标注 |
| 数据导入与校验页 | 校验结果面板 | 按类别展示：空值记录、重复展点、单位不一致、疑似异常数据，每条附原因说明 |
| 数据导入与校验页 | 校验统计条 | 合格/警告/无法计算三类计数，无法计算的记录不消失，单独列出 |
| 路线优化与诊断页 | 优化计算区 | 一键执行路线优化，展示每一步推导过程（为何选此路线、距离/时间权重说明） |
| 路线优化与诊断页 | 推理过程面板 | 分步展示：数据预处理→约束检查→路线候选→评分排序→最终推荐，每步有解释 |
| 路线优化与诊断页 | 异常记录表 | 所有无法参与计算的记录集中展示，标注原因（空坐标、重复合并逻辑、单位转换失败等） |
| 路线优化与诊断页 | 预测建议区 | 对优化结果给出预测性建议，附带"为什么这样建议"的推理链 |
| 汇总与追溯页 | 汇总图表区 | 核心指标图表（总距离、预计时间、各展点停留分布），点击任一图表元素下钻到对应明细行 |
| 汇总与追溯页 | 补录备注区 | 支持对任意展点或路线段追加备注，补录后自动计算差异并展示"补录前 vs 补录后"对比 |
| 汇总与追溯页 | 冲突证据面板 | 当汇总页中的说法与导入数据冲突时，左右分栏展示两边证据，给出建议动作，不替用户拍板 |
| 汇总与追溯页 | 明细追溯面板 | 从图表点击进入，高亮对应明细行，支持导出明细报告供月度复盘 |

## 3. 核心流程

用户打开系统 → 加载/导入样例数据 → 系统实时校验并分类展示问题 → 用户确认后执行优化 → 系统分步展示推理过程与异常记录 → 用户查看优化结果与预测建议 → 用户在汇总页查看图表 → 点击图表下钻明细 → 补录备注 → 查看补录差异 → 如遇冲突查看双方证据 → 导出报告用于复盘

```mermaid

    "A[加载数据]" --> "B[实时校验]"
    "B" --> "C{校验结果}"
    "C" --> "合格记录" --> "D[参与优化]"
    "C" --> "警告记录" --> "D"
    "C" --> "无法计算记录" --> "E[异常记录表(保留原因)]"
    "D" --> "F[分步推理展示]"
    "F" --> "G[优化结果+预测建议]"
    "G" --> "H[汇总图表]"
    "H" --> "I[点击图表下钻明细]"
    "I" --> "J[补录备注]"
    "J" --> "K[差异对比]"
    "H" --> "L[冲突证据展示]"
    "L" --> "M[双方证据+建议动作]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰 (#1e293b) 为主背景，搭配琥珀色 (#f59e0b) 作为强调色（代表"优化路线"的指引感）
- **辅助色**：石板灰 (#475569) 用于边框与次级文字，翠绿 (#10b981) 标记合格，珊瑚红 (#ef4444) 标记异常，琥珀 (#f59e0b) 标记警告
- **按钮风格**：圆角 (rounded-lg)，主操作按钮使用琥珀色填充，次要按钮灰色描边
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular，数据使用 JetBrains Mono
- **布局风格**：左侧导航 + 右侧内容区，卡片式布局，固定顶栏
- **图标风格**：Lucide 线性图标，与整体简洁风格一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 数据导入与校验页 | 样例数据面板 | 卡片容器，一键加载按钮，样例预览表格，空值/重复/单位异常用不同底色高亮 |
| 数据导入与校验页 | 数据导入区 | 代码编辑器风格文本框，行号+校验状态图标，右下角统计角标 |
| 数据导入与校验页 | 校验结果面板 | 三列统计卡（合格/警告/无法计算），下方可展开的问题列表，每条带原因标签 |
| 路线优化与诊断页 | 优化计算区 | 大号执行按钮，进度指示器，完成后展开结果面板 |
| 路线优化与诊断页 | 推理过程面板 | 垂直时间线布局，每步带图标与解释文字，可折叠 |
| 路线优化与诊断页 | 异常记录表 | 表格行带红色左侧边框，hover 展开原因详情 |
| 路线优化与诊断页 | 预测建议区 | 卡片列表，每张卡片包含建议+推理链+置信度标签 |
| 汇总与追溯页 | 汇总图表区 | 柱状图/饼图/折线图组合，图表元素可点击，点击后右侧面板展示对应明细 |
| 汇总与追溯页 | 补录备注区 | 行内编辑输入框，保存后出现差异对比表格（补录前→补录后，变更项高亮） |
| 汇总与追溯页 | 冲突证据面板 | 左右分栏，左栏"汇总页说法"、右栏"导入数据证据"，底部建议动作按钮组 |
| 汇总与追溯页 | 明细追溯面板 | 高亮行表格，可导出 CSV，顶部面包屑显示追溯路径 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1024px
- 平板端（768-1024px）侧边栏收起为图标模式
- 移动端（< 768px）内容区全宽，侧边栏变为底部标签栏

不适用
