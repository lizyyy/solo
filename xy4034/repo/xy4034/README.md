# 🥗 冷链留样复盘台

专为连锁轻食店中央厨房质控员设计的本地数据分析看板，帮助高效识别冷链物流和留样管理中的异常问题。

## 📋 功能特性

### 数据整合
- **多表自动归并**: 自动整合成品批次、冷柜温度、配送交接和留样抽检数据
- **智能字段识别**: 支持中英文混合字段名，自动识别数据类型
- **时间窗匹配**: 按批次号和时间窗口自动关联相关记录

### 异常识别
系统自动识别以下风险场景：

| 风险类型 | 规则说明 | 风险等级 |
|---------|---------|---------|
| 生产后未及时入冷 | 生产到出库时间超过60分钟 | 高风险 |
| 运输途中连续超温 | 连续超温超过20分钟（>4°C） | 高风险 |
| 温度记录断档 | 温度记录间隔超过30分钟 | 中风险 |
| 签收时间早于出库 | 逻辑时间矛盾 | 高风险 |
| 留样编号重复 | 同一留样编号多次出现 | 中风险 |
| 应留样但缺失 | 批次无任何留样记录 | 高风险 |
| 抽检不合格仍可售 | 抽检不合格但状态为已出库 | 高风险 |
| 温度超出范围 | 单次温度超过正常范围 | 中风险 |

### 可视化分析
- **批次风险列表**: 按风险等级展示所有异常批次
- **趋势分析**: 按门店/配送车/冷柜筛选的温度趋势图
- **异常时间轴**: 时间维度展示风险事件分布
- **批次详情页**: 查看单个批次的完整信息，包括温度曲线、交接记录、留样状态

### 报告导出
- **Markdown 复盘报告**: 包含数据概览、风险详情、改进建议的完整报告
- **CSV 异常清单**: 可导出用于进一步分析的异常数据表格

## 📁 数据格式说明

系统支持以下四种CSV文件：

### 1. 成品批次数据 (`batches`)
必需字段：
| 字段名 | 说明 | 示例 |
|-------|------|------|
| 批次号 | 唯一标识 | B202604300001 |
| 菜品 | 产品名称 | 凯撒沙拉 |
| 生产时间 | 格式：YYYY-MM-DD HH:MM:SS | 2026-04-30 08:00:00 |
| 出库时间 | 格式：YYYY-MM-DD HH:MM:SS | 2026-04-30 08:45:00 |
| 门店 | 配送门店 | 国贸店 |
| 配送车 | 配送车辆编号 | 京A12345 |
| 状态 | 批次状态 | 已出库 |

### 2. 冷柜温度记录 (`temperatures`)
必需字段：
| 字段名 | 说明 | 示例 |
|-------|------|------|
| 批次号 | 关联批次 | B202604300001 |
| 冷柜编号 | 冷柜标识 | F001 |
| 温度读数时间 | 格式：YYYY-MM-DD HH:MM:SS | 2026-04-30 08:50:00 |
| 温度值 | 数值（摄氏度） | 2.5 |

### 3. 配送交接记录 (`handover`)
必需字段：
| 字段名 | 说明 | 示例 |
|-------|------|------|
| 批次号 | 关联批次 | B202604300001 |
| 交接签收时间 | 格式：YYYY-MM-DD HH:MM:SS | 2026-04-30 09:15:00 |
| 签收人 | 配送员 | 配送员1 |
| 门店签收人 | 门店接收人 | 门店员工1 |

### 4. 留样抽检结果 (`samples`)
必需字段：
| 字段名 | 说明 | 示例 |
|-------|------|------|
| 批次号 | 关联批次 | B202604300001 |
| 留样编号 | 留样唯一标识 | S202604300001 |
| 留样时间 | 格式：YYYY-MM-DD HH:MM:SS | 2026-04-30 08:15:00 |
| 抽检时间 | 格式：YYYY-MM-DD HH:MM:SS | 2026-04-30 10:00:00 |
| 抽检结论 | 合格/不合格/待检 | 合格 |

### 文件命名建议
系统会根据文件名自动识别数据类型，建议使用以下命名模式：
- 包含"批次"或"batch" → 成品批次数据
- 包含"温度"或"temperature" → 冷柜温度记录
- 包含"交接"或"handover" → 配送交接记录
- 包含"留样"、"sample"或"抽检" → 留样抽检结果

## 📖 核心操作流程

### 1. 数据导入

**方式一：使用示例数据**
1. 在左侧侧边栏选择"使用示例数据"
2. 点击"📥 加载示例数据"按钮
3. 系统将自动生成包含多种异常场景的测试数据

**方式二：上传CSV文件**
1. 在左侧侧边栏选择"上传CSV文件"
2. 点击文件上传区域，选择一个或多个CSV文件
3. 点击"📥 处理上传的数据"按钮
4. 系统会自动验证数据并显示验证结果

### 2. 查看数据概览
数据加载成功后，"📊 概览"标签页会显示：
- **关键指标**: 总批次数量、高/中风险批次数量、异常总数
- **数据统计**: 菜品分布柱状图、门店分布柱状图
- **字段验证问题**: 如果存在数据格式问题，会在此处列出

### 3. 筛选异常批次
在"⚠️ 批次风险列表"标签页：
1. 使用多选框筛选风险等级（默认显示高/中风险）
2. 查看每个风险的详细信息：
   - 风险等级标识（🔴高风险/🟡中风险/🟢低风险）
   - 规则名称
   - 批次号
   - 问题描述
   - 具体证据

### 4. 趋势分析
在"📈 趋势分析"标签页：
1. **筛选条件**:
   - 选择特定门店或"全部"
   - 选择特定配送车或"全部"
   - 选择特定冷柜或"全部"
   
2. **温度趋势图**:
   - 查看不同冷柜的温度变化曲线
   - 红色虚线表示超温阈值（4°C）
   - 鼠标悬停可查看具体数值

### 5. 异常时间轴
在"⏰ 异常时间轴"标签页：
1. **散点图视图**:
   - X轴：时间
   - Y轴：风险等级
   - 不同颜色代表不同风险等级
   - 鼠标悬停显示详细信息

2. **事件列表**:
   - 按时间排序的所有异常事件
   - 包含时间、批次号、风险等级、规则名称、描述

### 6. 查看批次详情
在"📄 报告导出"标签页的底部：
1. 从下拉框选择要查看的批次号
2. 系统将显示该批次的完整信息：
   - **基本信息**: 菜品、生产时间、出库时间等
   - **配送信息**: 门店、配送车、签收时间
   - **风险状态**: 该批次命中的所有风险规则
   - **温度记录表格**: 详细的温度数据
   - **温度曲线图**: 可视化温度变化
   - **留样抽检记录**: 留样编号、抽检结论等

### 7. 导出报告

#### 导出 Markdown 复盘报告
1. 在"📄 报告导出"标签页
2. 点击"生成复盘报告"按钮
3. 等待报告生成（通常几秒钟）
4. 在预览区域查看报告内容
5. 点击"⬇️ 下载 Markdown 报告"保存文件

报告包含：
- 数据概览（统计表格）
- 风险规则分布
- 高风险异常详情（每个异常的完整信息）
- 中风险异常详情
- 批次风险统计
- 建议措施（紧急处理建议 + 长期改进建议）

#### 导出 CSV 异常清单
1. 在"📄 报告导出"标签页
2. 点击"生成异常清单"按钮
3. 点击"⬇️ 下载 CSV 异常清单"保存文件

CSV 包含以下列：
- 批次号
- 规则名称
- 规则ID
- 风险等级
- 描述
- 证据
- 时间戳

## ❓ 常见问题

### Q1: 上传的CSV文件无法识别？
**A:** 请检查：
1. 文件名是否包含关键字（批次、温度、交接、留样等）
2. 是否为UTF-8编码（可使用Excel另存为CSV UTF-8）
3. 必需字段是否完整

### Q2: 时间字段格式有要求吗？
**A:** 支持以下格式：
- `YYYY-MM-DD HH:MM:SS`（推荐）
- `YYYY-MM-DD HH:MM`
- `YYYY/MM/DD HH:MM:SS`
- `YYYY/MM/DD HH:MM`
- `YYYY-MM-DD`
- `YYYY/MM/DD`

### Q3: 如何确认风险规则是否正确触发？
**A:** 可以使用示例数据验证：
1. 加载示例数据
2. 查看风险列表，应能看到预设的异常
3. 具体可参考 `tests/test_self_check.py` 中的单个规则测试

### Q4: 报告导出后如何查看？
**A:** 
- Markdown报告：可用任意文本编辑器或Markdown查看器打开
- CSV异常清单：可用Excel或任意表格软件打开

### Q5: 系统支持批量处理多天数据吗？
**A:** 支持。只要批次号唯一，系统可以处理任意时间范围的数据。建议：
1. 每天的数据使用独立的批次号前缀
2. 时间字段要包含完整的日期信息
3. 可以一次性上传多天的CSV文件
