## 原始点子

我想做一个给连锁轻食店中央厨房质控员用的本地数据分析看板，叫“冷链留样复盘台”。每天门店会发来成品批次 CSV、冷柜温度记录 CSV、配送交接记录和留样抽检结果，现在靠 Excel 对时间窗和批次号很容易漏掉超温、断档和该留样没留样的问题。请从 0 到 1 做一个可本地运行的 Python Dash 或 Streamlit 项目：页面能导入示例数据或用户上传的 CSV，字段包括批次号、菜品、生产时间、出库时间、门店、配送车、冷柜编号、温度读数时间、温度值、交接签收时间、留样编号和抽检结论；系统要把多张表按批次和时间窗口归并，识别生产后未及时入冷、运输途中连续超温超过阈值、温度记录断档、签收时间早于出库、同一留样编号重复、应留样但缺失、抽检不合格仍被标成可售这些异常。看板上要有批次风险列表、按门店/配送车/冷柜筛选的趋势图、异常时间轴和一个批次详情页，点开能看到相关温度曲线、交接记录、留样状态和命中的规则证据；还要能导出 Markdown 复盘报告和 CSV 异常清单。数据处理逻辑不要全写在页面文件里，请拆成 CSV 解析、字段校验、时间窗归并、风险规则、图表数据、报告导出、示例数据和测试/自检脚本等多个文件。README 里写清楚安装、启动、示例数据格式，以及如何验证导入、筛选、识别异常、查看批次详情和导出报告这些核心流程。
