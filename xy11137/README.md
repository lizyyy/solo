# 母婴护理站夜班交接补全 CLI

母婴护理站夜班交接记录补全工具，专门处理跨夜时间、护理员换班等母婴护理业务场景。

## 业务背景

母婴护理站夜班交接通常在22:00至次日06:00之间进行，涉及：
- 跨夜时间的日期切换
- 护理员轮班交接
- 产妇和新生儿的护理记录
- 特殊事项的跟踪

本工具自动补全缺失的交接记录字段，确保数据完整性。

## 命令行用法


### 参数说明

| 参数 | 简写 | 说明 | 必需 |
|------|------|------|------|
| `--input` | `-i` | 输入CSV文件路径 | 是 |
| `--output` | `-o` | 输出CSV文件路径 | 是 |
| `--format` | `-f` | 输出格式: `human`\|`json`\|`both` (默认: `both`) | 否 |
| `--help` | `-h` | 显示帮助信息 | 否 |

### 示例

1. 基本用法（人类可读 + JSON输出）：


2. 仅输出人类可读汇总：

3. 仅输出机器可读JSON：

```bash

```

## 退出码说明

| 退出码 | 含义 | 场景 |
|--------|------|------|
| 0 | 完全成功 | 无补全操作，所有数据完整 |
| 2 | 部分成功 | 包含跨夜时间处理、护理员补全、班次补全等操作 |
| 1 | 错误 | 参数错误、文件不存在、处理异常等 |

## 业务列说明

输出文件按以下稳定顺序排列关键业务列：

1. **记录编号** - 唯一记录标识
2. **交接日期** - 交接发生日期（跨夜时自动调整）
3. **班次** - 夜班/白班（根据换班时间自动判断）
4. **护理员姓名** - 负责护理的护士（缺失时按轮班顺序补全）
5. **换班时间** - 实际换班的时间点
6. **产妇姓名** - 产妇的姓名
7. **房间号** - 所在房间编号
8. **宝宝情况** - 新生儿状况记录
9. **产妇情况** - 产妇身体状况记录
10. **特殊事项** - 需要特别注意的事项
11. **交接状态** - 已完成/待补充（自动判断）
12. **补全标记** - 标记哪些字段被补全
13. **补全时间** - 补全操作的时间戳

## 补全功能说明

### 1. 跨夜时间处理
- 检测换班时间在22:00-06:00的记录
- 当检测到从夜间(22:00+)到凌晨(06:00-)的跨夜换班时，自动将交接日期+1天
- 标记：`跨夜日期;`

### 2. 班次补全
- 根据换班时间自动判断班次：
  - 22:00-06:00 → 夜班
  - 其他时间 → 白班
- 标记：`班次;`

### 3. 护理员补全
- 缺失护理员姓名时，按固定轮班顺序补全
- 参考前一条记录的护理员，选择下一位护士
- 标记：`护理员;`

### 4. 交接状态补全
- 宝宝情况和产妇情况都有内容 → 已完成
- 缺少任一信息 → 待补充
- 标记：`交接状态;`

## 可复跑保证

本工具支持可复跑输出（幂等性）：
- 已补全的字段不会被重复覆盖
- 补全标记会累积
- 输出列顺序始终保持一致
- 同一份输入多次运行，输出结果可diff对比

## 常见问题

### Q: 为什么退出码是2？
A: 这是正常的"部分成功"状态，表示工具进行了有效的补全操作（跨夜处理、护理员补全等），不是错误。

### Q: 可以多次处理同一份文件吗？
A: 可以，工具支持可复跑，已补全的字段不会被覆盖，补全标记会累积。

### Q: 如何验证处理结果？
A: 可以对比输入输出文件，或者使用diff工具：
```bash
diff sample/input.csv sample/output.csv
```

## 错误处理

工具会清晰报告以下错误：
- 输入文件不存在
- 缺少必需参数
- CSV解析错误
- 处理过程中的异常

所有错误都会输出到stderr，并以退出码1结束。
