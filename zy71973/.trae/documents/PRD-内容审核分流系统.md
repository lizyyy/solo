## 1. 产品概述

内容审核分流系统是一个面向运营分析师的轻量级审核管理工具，解决内容审核过程中的来源追踪、状态流转、批量处理和质检周报导出问题。核心目标是通过留痕审计避免业务扯皮，确保数据处理的幂等性和一致性。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 运营分析师 | 系统登录 | 审核记录、批量处理、导出周报、查看历史 |
| 业务负责人 | 系统登录 | 查看质检周报、查看统计数据 |

### 2.2 功能模块

1. **审核记录列表页**：记录列表、筛选条件、批量操作、状态流转
2. **记录详情页**：来源信息、变更历史、状态原因、操作按钮
3. **质检周报页**：统计概览、周报预览、导出下载

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 审核记录列表页 | 顶部筛选栏 | 按状态、来源、时间、处理人筛选 |
| 审核记录列表页 | 记录表格 | 展示记录ID、来源、状态、处理人、更新时间 |
| 审核记录列表页 | 批量操作栏 | 批量审核、批量标记重复、批量导出 |
| 审核记录列表页 | 分页控件 | 支持页码跳转、每页数量调整 |
| 记录详情页 | 基本信息卡 | 展示记录完整信息和来源链路 |
| 记录详情页 | 变更历史时间线 | 展示所有状态变更、操作人、原因、时间 |
| 记录详情页 | 操作按钮区 | 通过、驳回、标记重复、添加备注 |
| 质检周报页 | 统计概览卡 | 本周处理量、各状态分布、同比环比数据 |
| 质检周报页 | 周报表格 | 筛选范围内的记录汇总 |
| 质检周报页 | 导出区 | Excel/PDF格式导出周报 |

## 3. 核心流程

数据导入后，系统自动识别记录类型（正常、晚到附件、重复项、人工更正），运营分析师可批量或单条处理，每条操作都留痕审计，最后生成与当前筛选范围一致的质检周报。

```mermaid
flowchart LR
    A["数据导入"] --> B["自动识别类型"]
    B --> C["待处理队列"]
    C --> D["批量/单条审核"]
    D --> E["状态变更留痕"]
    E --> F["生成质检周报"]
    F --> G["导出/查看"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝色 #165DFF（专业可靠）
- **辅助色**：绿色 #00B42A（通过）、橙色 #FF7D00（待处理）、红色 #F53F3F（驳回）
- **按钮风格**：圆角4px，扁平化设计，hover有轻微阴影
- **字体**：PingFang SC / -apple-system，标题16px半粗，正文14px常规
- **布局风格**：顶部导航 + 左侧筛选 + 右侧内容卡片式布局
- **图标风格**：线性图标，简洁专业

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 审核记录列表页 | 记录表格 | 斑马纹、状态标签色、hover高亮、分页动画 |
| 记录详情页 | 变更历史 | 时间线样式、状态图标、渐入动画 |
| 质检周报页 | 统计卡片 | 渐变背景、数字动效、悬浮效果 |

### 4.3 响应式

- 桌面端优先（1200px+）：三栏布局完整展示
- 平板端（768px-1199px）：筛选栏收起为可展开面板
- 移动端（<768px）：单列布局，表格支持横向滚动
