# 印刷排产拼版游戏 - 产品需求文档

## 1. 产品概述
印刷排产拼版游戏（Impose Master）是一款面向印刷厂新人的 2D 策略模拟器，通过真实的印刷行业规则，让玩家在限定回合内完成订单拼版、上料、调墨、排产，平衡纸张浪费、颜色切换成本、交期超时三大核心难题，培养排产直觉。

- 核心问题：新人对"开数/色号/交期"缺乏直觉，出错即浪费纸张与工时。
- 目标用户：印刷厂学徒、技校学生、工厂培训师。
- 核心价值：用回合制规则把真实拼版决策压缩到 10–30 分钟可重复练习的互动体验。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 | 核心权限 |
|------|------|---------|
| 排产员（玩家） | 单人游玩 | 接收订单、拼版、上料、调墨、提交工单、查看报表 |

### 2.2 功能模块
1. **主菜单**：关卡选择、游戏设置、历史回放入口。
2. **回合主界面**：左侧订单队列 / 中间 2D 拼版画布 / 右侧资源与状态面板 / 底部操作按钮。
3. **关卡配置**：三种难度（新手 / 熟练 / 主管），规则差异不在速度，而在约束维度。
4. **结算与报告**：订单完成评分、浪费明细、色组切换成本、超时罚款、排产报表导出。
5. **历史回放**：以帧为单位按步骤复现玩家决策，供复盘。

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主菜单 | 关卡选择 | 3 档难度卡片，显示解锁条件与推荐分数 |
| 主菜单 | 历史记录 | 列出最近 20 局回放，可加载查看 |
| 游戏界面 | 订单队列 | 显示未排、在产、逾期订单，带颜色与张数 |
| 游戏界面 | 拼版画布 | 大对开 / 四开 / 八开纸张可视化，拖拽或点击摆放订单矩形 |
| 游戏界面 | 资源面板 | 当前纸张库存、油墨色组、工时、利润、扣分 |
| 游戏界面 | 操作按钮 | 上料、切纸、调墨、印刷、暂停、放弃订单、结束回合 |
| 游戏界面 | 工具条 | 网格显示、吸附、测量、撤销 |
| 结算界面 | 报表 | 最终分数、分项扣分、订单评分、可导出 JSON/CSV |
| 结算界面 | 失败原因 | 若失败高亮主因（超时、超料、质量不达标） |

## 3. 核心流程
1. 玩家选择关卡 → 生成初始订单与资源。
2. 每个回合（1 天）：
   - 新订单进入队列。
   - 玩家选择订单放入某张纸的拼版图，考虑开数与颜色。
   - 玩家决定是否上料（切出该开数纸张）、调墨（切换色组有成本）、印刷（消耗工时）。
   - 回合结束时结算：完成订单获收益；超时订单扣分；浪费纸张扣钱。
3. 到达目标回合数后 → 结算界面 → 可选择导出报告或进入回放。

## 4. 用户界面设计
### 4.1 设计风格
- **主色**：油墨深蓝 `#0A1F44`，纸张米白 `#F7F3E9`，强调色 CMYK `#00A0E3 / #FFD100 / #E60012 / #000000`。
- **按钮**：直角、细边、微阴影，印刷品"墨色方块"风格。
- **字体**：标题用 `Space Mono`/等宽，正文 `Noto Sans SC`，突出"车间工装"感。
- **布局**：顶部状态栏 + 左订单栏 20% / 中画布 55% / 右资源栏 25% / 底部操作条。
- **图标**：Lucide 风格线性图标 + 印刷专用 emoji（📄🎨🖨️⏰）。

### 4.2 页面设计概览
| 页面 | 模块 | 关键元素 |
|------|------|---------|
| 主菜单 | 关卡卡片 | 悬停微抬、显示目标分数、徽章式难度标签 |
| 游戏界面 | 拼版画布 | 网格、标尺、吸附预览、订单矩形带颜色标签 |
| 结算界面 | 报表 | 分项条形图、分数徽章、可滚动日志 |

### 4.3 响应式
桌面优先（≥1200px），画布区在中等屏幕折叠为上下堆叠；触屏暂不强制。

## 5. 关卡设计（三档）
1. **新手档（学徒）**：只有大对开纸、单色黑、回合 8 天、订单 ≤4。目标：理解拼版占用与基本交期。
2. **熟练档（领机）**：大对开 + 四开、单黑 + 双色、回合 12 天、订单 ≤6，加入色组切换成本。
3. **主管档（车间主任）**：三种开数、CMYK 四色 + 专色、回合 16 天、订单 ≤8，加入质量门槛与专色加价。
