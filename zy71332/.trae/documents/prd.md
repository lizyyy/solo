## 1. 产品概述
琴房预约降噪排班系统——解决琴房、鼓房、声乐课互相串音投诉问题，通过时段冲突检测、噪声邻接分析和换房留痕，帮助管理员科学排班并快速定位排班异常。
- 目标用户：琴房管理员、教务人员
- 核心价值：将原本靠人工表格排查的高噪声相邻、重复预约、老师换房等问题自动化检测，并给出醒目处理结论，支持通知导出和报告持久化保存

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 管理员 | 系统预设账号 | 增删改预约记录、执行检测、导出报告、换房操作 |

### 2.2 功能模块
1. **排班总览页**：预约记录表格、多维度筛选、冲突/噪声/换房醒目标记、内联修正
2. **排班检测页**：时段冲突检测、噪声邻接分析、检测结论面板、一键通知导出

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 排班总览页 | 筛选栏 | 按琴房、乐器类型、预约人、时间段、噪声等级组合筛选 |
| 排班总览页 | 预约表格 | 展示所有预约记录，冲突行红色标记、高噪声行橙色标记、换房行蓝色标记，支持内联编辑修正 |
| 排班总览页 | 换房操作 | 选中记录后可执行换房，自动留痕（原房间→新房间、操作人、时间） |
| 排班总览页 | 导出按钮 | 导出当前筛选结果为 CSV，换房记录单独导出 |
| 排班检测页 | 时段冲突检测 | 扫描同一琴房同一时段的重复预约，列出冲突对，标记处理状态 |
| 排班检测页 | 噪声邻接分析 | 检测同一时段相邻琴房的高噪声组合（如鼓房旁排声乐），给出降噪建议 |
| 排班检测页 | 检测结论面板 | 汇总冲突数、邻接风险数、未处理项，醒目展示处理结论 |
| 排班检测页 | 通知导出 | 将检测结论生成文本通知，一键复制或导出文件 |
| 排班检测页 | 报告保存 | 将检测报告持久化保存，可查看历史报告列表 |

## 3. 核心流程

管理员登录后进入排班总览页，可浏览全部预约记录并按条件筛选。发现异常时，点击"执行检测"进入检测页，系统自动扫描时段冲突和噪声邻接风险，在结论面板给出醒目处理建议。管理员可在总览页修正预约或执行换房（自动留痕），处理完毕后导出通知或保存检测报告。

## 4. 用户界面设计

### 4.1 设计风格
- 主色：深蓝灰 (#1a2332)，辅色：琥珀橙 (#f59e0b) 用于警告，翠绿 (#10b981) 用于正常，红色 (#ef4444) 用于冲突
- 按钮：圆角矩形，带微妙阴影，状态切换有过渡动画
- 字体：Noto Sans SC 作为主字体，表格数据用等宽风格对齐
- 布局：左侧导航 + 右侧内容区，卡片式模块分区
- 图标：Lucide Icons 线条风格

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 排班总览页 | 筛选栏 | 下拉选择器 + 日期范围选择器，紧凑水平排列 |
| 排班总览页 | 预约表格 | 宽表格，行根据状态着色，操作列含编辑/换房按钮 |
| 排班总览页 | 换房弹窗 | 模态对话框，显示原房间信息，选择新房间，确认后留痕 |
| 排班检测页 | 冲突列表 | 卡片式列表，每张卡片含冲突详情和处理按钮 |
| 排班检测页 | 邻接风险图 | 相邻琴房可视化图，高噪声连线标红 |
| 排班检测页 | 结论面板 | 顶部固定横幅，数字大字醒目展示，颜色区分严重程度 |
| 排班检测页 | 历史报告 | 侧边抽屉，列表展示已保存报告，点击可查看详情 |

### 4.3 响应式
- 桌面优先设计，表格在大屏横向展开
- 平板端筛选栏折叠为下拉抽屉
- 移动端表格改为卡片列表视图
