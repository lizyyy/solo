## 1. 产品概述

物流无人机换电巡检作业系统——面向外场队长的实战工具，将巡检照片、航线KML、人工确认与飞行复盘串成完整证据链，确保每一次换电结论可追溯、可撤回、可导出。核心原则：宁可标"待确认"，绝不把电池循环错算、禁飞区擦边、返航点丢失混入正常结果。

- 目标用户：外场巡检队长（非评审人员），现场操作为主，设备为笔记本或平板
- 核心价值：消除证据断层，让接手人从结论一键定位到原始巡检照片或航线KML，降低交接认知负担

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 外场队长 | 管理员分配账号 | 导入数据、标记确认/待确认、撤回修正、筛选导出 |
| 复核员 | 管理员分配账号 | 查看完整证据链、追加备注、只读导出 |

### 2.2 功能模块

1. **换电总览页**：按架次聚合换电结论，异常状态高亮，支持从结论跳转至证据源
2. **证据链详情页**：单架次的巡检照片、航线KML轨迹、人工确认记录、飞行复盘数据四联面板
3. **数据导入页**：批量导入巡检照片/航线KML/备注，重复导入检测与冲突处理
4. **筛选导出页**：按状态/日期/异常类型筛选，一键导出含证据链的完整报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 换电总览页 | 架次列表 | 每行一架次，显示换电结论（正常/待确认/异常）、电池编号、时间、异常标签（电池循环错算/禁飞区擦边/返航点丢失） |
| 换电总览页 | 结论跳转 | 点击结论标签，直接定位到该架次的证据链详情页对应锚点（巡检照片/航线KML/确认记录/复盘数据） |
| 换电总览页 | 异常筛选栏 | 按异常类型快速过滤：电池循环错算、禁飞区擦边、返航点丢失、其他 |
| 证据链详情页 | 巡检照片面板 | 缩略图网格+大图预览，照片自动关联架次与电池编号，支持手动标注 |
| 证据链详情页 | 航线KML面板 | 内嵌地图渲染KML轨迹，标注换电点/禁飞区边界/返航点，点击航段查看参数 |
| 证据链详情页 | 人工确认面板 | 确认/待确认/驳回三态流转记录，每条确认必须绑定证据来源（照片ID或KML航段ID） |
| 证据链详情页 | 飞行复盘面板 | 关键参数时间线（电压/高度/速度），异常区间高亮，异常区间链接至照片或KML对应位置 |
| 证据链详情页 | 证据穿透 | 所有面板之间互相链接：点击复盘异常→跳转照片/KML；点击确认记录→跳转对应证据 |
| 数据导入页 | 批量导入 | 拖拽上传巡检照片（jpg/png）、航线文件（kml/kmz）、备注（csv/txt），自动解析关联 |
| 数据导入页 | 重复检测 | 导入时自动比对已有数据的SHA256/时间戳/电池编号，弹出重复冲突对话框（跳过/覆盖/合并） |
| 数据导入页 | 撤回修正 | 导入历史时间线，每笔导入可一键撤回，撤回操作生成审计日志，不可二次撤回 |
| 筛选导出页 | 多维筛选 | 状态（正常/待确认/异常）、日期范围、异常类型、电池编号、架次编号组合筛选 |
| 筛选导出页 | 导出报告 | 导出JSON（完整结构化数据）或HTML（含嵌入照片缩略图和KML截图的可打印报告） |
| 筛选导出页 | 证据完整性校验 | 导出前自动检查每条结论是否关联了证据，缺失证据的条目标红提示 |

## 3. 核心流程

### 3.1 数据导入与证据关联流程

外场队长将巡检照片、航线KML和备注批量导入系统。系统自动解析文件元数据（EXIF时间、KML坐标），按架次/电池编号关联。若检测到重复数据，弹出冲突处理对话框。导入完成后，队长在换电总览页查看各架次结论，对异常项跳转至证据链详情进行人工确认。

```mermaid
flowchart TD
    "导入巡检照片/KML/备注" --> "解析元数据(EXIF/KML坐标/时间戳)"
    "解析元数据" --> "按架次与电池编号自动关联"
    "按架次与电池编号自动关联" --> "重复检测(SHA256+时间戳+电池编号)"
    "重复检测" --> "有冲突?"
    "有冲突?" --> "是: 冲突处理(跳过/覆盖/合并)"
    "有冲突?" --> "否: 写入数据库"
    "冲突处理" --> "写入数据库"
    "写入数据库" --> "异常规则引擎检测"
    "异常规则引擎检测" --> "电池循环错算?"
    "异常规则引擎检测" --> "禁飞区擦边?"
    "异常规则引擎检测" --> "返航点丢失?"
    "电池循环错算?" --> "标记为待确认"
    "禁飞区擦边?" --> "标记为待确认"
    "返航点丢失?" --> "标记为待确认"
    "异常规则引擎检测" --> "无异常: 标记为正常"
```

### 3.2 人工确认与证据追溯流程

队长从总览页点击异常结论，进入证据链详情页。页面展示四联面板：巡检照片、航线KML、人工确认记录、飞行复盘。队长可从任意面板的证据元素跳转至其他面板的关联证据（如：从复盘电压异常跳转至对应时间的巡检照片）。确认操作必须绑定证据来源，确认后结论状态变更，全程留痕。

```mermaid
flowchart TD
    "总览页点击异常结论" --> "进入证据链详情页"
    "进入证据链详情页" --> "四联面板: 照片+KML+确认+复盘"
    "四联面板" --> "跨面板证据跳转"
    "跨面板证据跳转" --> "复盘异常→跳转照片/KML"
    "跨面板证据跳转" --> "确认记录→跳转对应证据"
    "确认记录→跳转对应证据" --> "选择确认/驳回/待确认"
    "选择确认/驳回/待确认" --> "绑定证据来源(照片ID/KML航段ID)"
    "绑定证据来源" --> "写入确认记录+审计日志"
    "写入确认记录+审计日志" --> "结论状态更新"
```

### 3.3 筛选导出流程

```mermaid
flowchart TD

    "证据完整性校验" --> "有缺失证据?"

    "有缺失证据?" --> "否: 选择导出格式"

    "补充证据或确认后导出" --> "选择导出格式"
    "选择导出格式" --> "JSON(结构化数据)"

```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰底（#1a1a2e）+ 琥珀警告色（#f59e0b）+ 翠绿确认色（#10b981）
- 辅助色：红色异常（#ef4444）、蓝色信息（#3b82f6）、灰色待确认（#6b7280）
- 按钮风格：圆角4px，扁平化，hover微抬升阴影
- 字体：标题用等宽字体 JetBrains Mono（技术感），正文用 Noto Sans SC（中文友好）
- 布局风格：左侧导航栏 + 右侧内容区，数据表格为主，面板可折叠
- 图标风格：lucide-react 线性图标，24px

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 换电总览页 | 架次列表 | 表格，每行状态徽标（绿/黄/红），异常标签胶囊，行点击跳转 |
| 换电总览页 | 异常筛选栏 | 顶部固定，多选标签组，活跃标签高亮 |
| 证据链详情页 | 巡检照片面板 | 缩略图网格(3列)，点击放大模态框，支持左右翻页 |
| 证据链详情页 | 航线KML面板 | 全宽地图画布，轨迹线条着色（正常绿/异常红），标记点可点击 |
| 证据链详情页 | 人工确认面板 | 时间线样式，每条记录显示确认人/时间/绑定证据链接 |
| 证据链详情页 | 飞行复盘面板 | 折线图(电压/高度/速度)，异常区间半透明红色遮罩 |
| 数据导入页 | 拖拽上传区 | 虚线边框大区域，拖入后显示文件列表+解析进度条 |
| 数据导入页 | 冲突对话框 | 模态框，逐条显示冲突，三选一按钮(跳过/覆盖/合并) |
| 数据导入页 | 导入历史 | 时间线，每笔显示文件数+导入时间，撤回按钮 |
| 筛选导出页 | 筛选面板 | 左侧固定，折叠式分组(状态/日期/异常类型/编号) |
| 筛选导出页 | 结果预览 | 右侧表格，缺失证据行标红底色 |
| 筛选导出页 | 导出按钮 | 底部固定，格式选择下拉+导出按钮 |

### 4.3 响应式设计

桌面优先，最小支持1280px宽度。平板横屏(1024px)时四联面板改为两列布局，竖屏时改为单列标签页切换。不适配手机端——外场操作以笔记本/平板为主。

### 4.4 3D场景指引

不涉及3D场景。
