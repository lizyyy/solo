# 轮胎翻新批次追溯 CLI - 验收指南

## 📋 工具说明

本工具用于轮胎翻新厂的批次追溯管理，主要功能：
- **胎体档案**：记录轮胎来源信息（物流公司、型号、规格等）
- **工序流转**：追踪翻新工序（初检→打磨→补洞→硫化→终检）
- **质检记录**：每个工序的质检结果
- **返修定位**：出现问题时快速定位责任工序和操作员

---

## 🚀 快速开始

### 前置准备

确保电脑已安装 Python 3.6 或更高版本。

### 第一步：安装依赖

打开终端（Mac用户按 `Command + 空格`，搜索 `Terminal`），执行以下命令：
