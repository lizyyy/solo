# 扫描交付质检台

一个用于档案数字化外包项目的本地桌面GUI质量检查工具。帮助工作人员快速检查扫描文件的完整性、准确性和质量。

## 功能特性

### 📁 文件扫描与元数据分析
- 自动扫描目录中的图片文件（JPG、PNG、TIFF）和PDF文件
- 提取图片分辨率、尺寸、方向等元数据
- 智能检测空白页（基于像素分析）
- 从文件名自动提取盒号、案卷号、页码

### 📋 索引CSV解析
- 支持多种分隔符（逗号、制表符、分号）
- 自动识别常见列名（盒号、案卷号、页码、文件名）
- 可自定义字段映射

### 🔍 智能规则校验
系统自动检测以下问题：

| 问题类型 | 说明 |
|---------|------|
| 缺页 | 索引中存在但文件夹中缺失的页码 |
| 重复页码 | 同一案卷号下存在多个相同页码的文件 |
| 文件名不匹配 | 实际文件名与索引中预期文件名不一致 |
| 分辨率过低 | 图片DPI低于设定阈值（默认300 DPI） |
| 疑似空白页 | 页面空白比例超过阈值（默认95%） |
| 方向不一致 | 同一案卷号下存在横版和竖版混合 |
| 索引有但文件缺失 | 索引记录对应的文件不存在 |
| 文件夹多出文件 | 扫描目录中有但索引未登记的文件 |
| 盒号不匹配 | 文件盒号与索引盒号不一致 |

### ✅ 人工复核
- 三栏布局：左侧批次列表、中间文件预览/问题列表、右侧复核面板
- 支持五种复核状态：
  - 确认无误
  - 需要重扫
  - 已替换
  - 忽略并备注
- 状态保存到本地SQLite数据库，重启后可继续
- 批量操作支持

### 📦 打包导出
- Dry-run模式预览导出计划
- 导出时自动创建案卷号子目录
- 生成`manifest.json`包含详细导出清单
- 保留原始文件不被覆盖
- 导出前检查目标目录是否存在冲突文件

## 安装指南

### 环境要求
- Python 3.8+
- pip 包管理器

### 安装步骤

1. **克隆或下载项目**
```bash
cd /path/to/xy4030
```

2. **安装依赖**
```bash
pip install -r requirements.txt
```

依赖包括：
- `PyQt5` - GUI框架
- `Pillow` - 图像处理
- `PyMuPDF (fitz)` - PDF处理
- `opencv-python` - 图像分析（空白页检测）
- `numpy` - 数值计算
- `python-dateutil` - 日期处理

## 启动应用

```bash
python main.py
```

## 使用指南

### 快速开始（使用示例数据）

1. **生成示例数据**
```bash
cd examples
python generate_sample_data.py
```

这会在 `examples/sample_scan` 目录下生成：
- 多个测试图片（模拟各种问题）
- 索引CSV文件（index.csv）

2. **启动应用**
```bash
cd ..
python main.py
```

3. **创建新项目**
   - 点击"新建项目"按钮
   - 项目名称：`示例测试项目`
   - 扫描目录：选择 `examples/sample_scan`
   - 索引CSV：选择 `examples/sample_scan/index.csv`
   - 点击"确定"

4. **查看扫描结果**
   - 系统会自动扫描文件、解析索引、执行规则校验
   - 在"文件列表"标签页查看所有扫描到的文件
   - 在"问题列表"标签页查看检测到的问题

5. **人工复核**
   - 点击"问题列表"中的任意问题
   - 在右侧复核面板查看问题详情
   - 选择合适的复核状态（确认无误、需要重扫等）
   - 可添加备注说明
   - 点击"应用审核"保存状态
   - 点击"下一个问题"快速处理

6. **预览文件**
   - 在"文件列表"中选择文件
   - 切换到"预览"标签页查看图片内容
   - 查看文件信息（分辨率、尺寸、是否空白等）

7. **导出交付包**
   - 点击菜单栏"文件" -> "导出交付包"
   - 选择导出目标目录
   - 点击"运行模拟导出 (Dry Run)"查看导出计划
   - 检查是否有警告或文件冲突
   - 确认无误后点击"开始导出"

8. **查看导出结果**
   - 导出目录会按案卷号创建子目录
   - 每个文件会复制到对应案卷号目录
   - 根目录生成 `manifest.json` 包含导出清单

### 重新打开项目

1. 启动应用后，左侧会显示所有已创建的项目列表
2. 双击项目名称或选中后点击"打开"
3. 系统会从SQLite数据库恢复之前的所有状态：
   - 文件列表
   - 问题列表
   - 复核状态和备注
4. 可以继续之前的复核工作

## 数据存储

应用数据存储在以下位置：

- **Windows**: `%APPDATA%\ScanQualityChecker\`
- **macOS**: `~/Library/Application Support/ScanQualityChecker/`
- **Linux**: `~/.scan_quality_checker/`

包含：
- `projects.db` - 项目主数据库
- `project_{id}.db` - 每个项目的独立数据库

## 配置选项

在创建项目时可以配置：

- **最低分辨率**: 默认300 DPI，低于此值会标记为"分辨率过低"
- **空白页阈值**: 默认95%，空白像素比例超过此值会标记为"疑似空白页"

## 索引CSV格式

索引CSV文件应包含以下列（列名可自动识别）：

| 列名 | 别名 | 说明 |
|------|------|------|
| 盒号 | box, box_number, H, h | 档案盒编号 |
| 案卷号 | case, case_number, A, a, 案卷 | 案卷编号 |
| 页码 | page, page_number, P, p | 页码 |
| 文件名 | filename, file_name, 文件, 名称 | 期望的文件名 |

示例CSV内容：
```csv
盒号,案卷号,页码,文件名
1,2024001,1,盒1_案2024001_1.jpg
1,2024001,2,盒1_案2024001_2.jpg
1,2024001,3,盒1_案2024001_3.jpg
```

## 文件名命名规则

系统支持从文件名自动提取信息，推荐命名格式：

```
盒{盒号}_案{案卷号}_{页码}.{扩展名}
```

示例：
- `盒1_案2024001_1.jpg` → 盒号1, 案卷号2024001, 页码1
- `H1_A2024002_005.png` → 盒号1, 案卷号2024002, 页码5
- `1-2024003-10.tiff` → 盒号1, 案卷号2024003, 页码10

## 常见问题

### Q: 应用无法启动？
A: 请检查Python版本是否为3.8+，并确保所有依赖已正确安装。

### Q: 为什么有些文件没有被识别？
A: 检查文件名格式是否符合预期命名规则。系统会尝试从文件名中提取盒号、案卷号和页码。

### Q: 数据保存在哪里？
A: 所有项目数据和复核状态都保存在本地SQLite数据库中，不会上传到任何服务器。

### Q: 如何备份项目数据？
A: 可以备份应用数据目录（见"数据存储"章节），或者导出交付包时会包含所有合格文件。

### Q: 支持哪些图片格式？
A: 支持 JPG/JPEG、PNG、TIFF/TIF 和 PDF 格式。
