## 原始点子

我想做一个给档案数字化外包小组用的本地桌面 GUI 应用，叫“扫描交付质检台”。每天扫描完一批纸质合同和病历，文件夹里会混着 jpg、png、tiff、pdf，还有一份客户给的索引 CSV，人工逐个核对页码、盒号、案卷号、空白页和重复扫描很费时间。请从 0 到 1 做一个能直接运行的桌面应用：用户可以创建项目，导入扫描目录和索引 CSV，系统按案卷号/页码/文件名规则生成交付清单，检查缺页、重复页码、文件名不匹配、分辨率低于阈值、疑似空白页、横竖方向不一致、索引里有但文件夹缺失、文件夹里多出未登记文件这些问题。界面上要有左侧批次列表、中间文件预览和问题列表、右侧人工复核面板，用户能把每条问题标记为“确认无误、需要重扫、已替换、忽略并备注”，状态要保存到本地 SQLite 或文件数据库，重启后仍能继续复核。还要支持生成 dry-run 重命名/打包计划，确认后把合格文件复制到 dist 目录并写 manifest.json，保留原始文件不被覆盖；如果导出目标已存在或清单变更，要给出清楚提示。请把 GUI、文件扫描、图片/文档元数据读取、规则校验、复核状态存储、打包导出、示例数据和 README 拆成多个文件，不要做成单文件演示。README 里写清楚安装、启动，以及如何用示例目录验证导入、扫描、复核、导出和重新打开项目这几个核心流程。
