# 示例答题卡文件夹

此文件夹包含模拟的答题卡文件命名示例，用于测试系统的各种检测功能。

## 命名规范说明

系统支持从文件名提取条码和页码信息：

- **条码格式**: 10位以上数字（如学号）
- **页码格式**:
  - `_1of2_` 或 `_1/2_` (第1页/共2页)
  - `_p1_` 或 `_page1_` (第1页)
  - `_01_` (第1页)

## 测试场景

### 1. 正常扫描的文件
- `2021001001_1of2.jpg` - 张三第1页
- `2021001001_2of2.jpg` - 张三第2页
- `2021001002_p1.jpg` - 李四
- `2021001004_1.jpg` - 赵六

### 2. 漏扫的学生（座位表中存在，但没有对应文件）
- 学生 `2021001006` (孙八) - 故意不创建文件，测试漏扫检测

### 3. 重复条码
- `2021001005_dup1.jpg` - 钱七重复1
- `2021001005_dup2.jpg` - 钱七重复2

### 4. 缺考却有答题卡
- 学生 `2021001003` (王五) 在缺考名单中，但有扫描文件
- `2021001003_absent.jpg` - 测试"缺考却有答题卡"

### 5. 额外答题卡（不在座位表中）
- `9999999999_extra.jpg` - 无效条码，测试额外答题卡检测

### 6. 无法识别的文件
- `unknown_sheet.jpg` - 没有条码格式的文件名

## 使用说明

1. 将实际扫描的答题卡图片放入此文件夹
2. 确保文件名包含学生条码（学号）
3. 支持的格式: `.jpg`, `.jpeg`, `.png`, `.pdf`
4. 系统会自动从文件名提取条码，或使用 pyzbar 检测图片中的条形码
