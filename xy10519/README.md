# 🎓 课程优惠叠加 API

一个完整的在线教育课程购买优惠叠加系统，处理优惠券、团购价、老学员折扣和退款的规则叠加。

## ✨ 功能特性

### 💰 价格计算
- **优惠叠加规则**：团购价 → 老学员折扣 → 优惠券（按优先级）
- **优惠互斥处理**：非可叠加优惠券与团购互斥时自动择优
- **老学员折扣**：按用户身份自动应用折扣率
- **计算步骤展示**：每一步都有清晰的计算过程

### 🔒 订单生命周期
- **价格锁定**：支持锁价，防止临时涨价
- **锁价过期**：团购锁价有时间限制，过期失效
- **状态追踪**：完整的状态历史记录

### 💳 支付与退款
- **幂等支付**：相同回调ID多次调用只处理一次
- **重复回调处理**：防止重复扣款
- **全额/部分退款**：支持两种退款方式
- **退款返券**：全额退款可退还优惠券
- **退款明细**：按优惠类型拆解退款金额

### 📝 人工修正
- **前后差异记录**：记录修改前后的数据
- **操作者追踪**：必须填写操作者和原因
- **变更原因**：必须说明修改理由

### 📊 报告导出
- **订单列表导出**：含客服解释口径
- **统计数据**：订单数、收入、退款统计

## 🎯 主要演示路径

### 路径1：普通购买（新学员 + 优惠券）
1. 选择用户：张三（新学员）
2. 选择课程：Python 全栈开发实战（¥999）
3. 选择优惠券：NEW100（减¥100）
4. 点击「试算价格」
5. **预期结果**：原价¥999 → 用券后¥899

### 路径2：团购购买（老学员 + 团购叠加）
1. 选择用户：李四（老学员，95折）
2. 选择课程：Python 全栈开发实战（¥999）
3. 选择团购：Python 课程限时团购（¥799）
4. 点击「试算价格」
5. **预期结果**：
   - 原价¥999
   - 团购价¥799（优惠¥200）
   - 老学员95折再减¥39.95
   - **最终¥759.05**

### 路径3：优惠冲突（自动择优）
1. 选择用户：张三（新学员）
2. 选择课程：Python 全栈开发实战（¥999）
3. **同时选择**：
   - 团购：Python 课程限时团购（¥799）
   - 优惠券：NEW100（减¥100）
4. 点击「试算价格」
5. **预期结果**：
   - 系统检测到冲突
   - 团购¥799 vs 用券¥899
   - **自动选择更优惠的团购**
   - 显示冲突警告

### 路径4：重复回调（幂等性测试）
1. 使用「快捷演示」→「🔄 重复回调」
2. **预期结果**：
   - 第一次支付：正常处理，isIdempotent=false
   - 第二次相同回调：直接返回历史结果，isIdempotent=true
   - 订单状态不变，只支付一次

### 路径5：部分退款
1. 创建订单并支付
2. 在订单详情页点击「↩️ 申请退款」
3. 选择「部分退款」，输入退款金额
4. **预期结果**：
   - 显示退款明细
   - 订单状态变为「部分退款」
   - 记录退款历史

## 🔌 API 接口

### 订单相关

#### 价格试算
```
POST /api/orders/calculate
Content-Type: application/json

{
  "userId": "用户ID",
  "courseId": "课程ID",
  "couponId": "优惠券ID（可选）",
  "groupBuyId": "团购ID（可选）"
}
```

#### 创建订单
```
POST /api/orders/create
Content-Type: application/json

{
  "userId": "用户ID",
  "courseId": "课程ID",
  "couponId": "优惠券ID（可选）",
  "groupBuyId": "团购ID（可选）"
}
```

#### 锁定价格
```
POST /api/orders/:orderId/lock-price
Content-Type: application/json

{
  "lockDurationMinutes": 30
}
```

#### 支付
```
POST /api/orders/:orderId/payment
Content-Type: application/json

{
  "amount": 999,
  "paymentMethod": "online",
  "callbackId": "回调ID（用于幂等）",
  "callbackData": {}
}
```

#### 支付回调
```
POST /api/orders/:orderId/payment/callback
Content-Type: application/json

{
  "callbackId": "唯一回调ID",
  "amount": 999,
  "paymentMethod": "alipay"
}
```

#### 退款
```
POST /api/orders/:orderId/refund
Content-Type: application/json

{
  "refundType": "full",
  "refundAmount": 500,
  "refundReason": "用户申请退款",
  "returnCoupon": true,
  "operatorId": "客服ID",
  "operatorName": "客服姓名"
}
```

#### 人工调整
```
POST /api/orders/:orderId/adjust
Content-Type: application/json

{
  "newFinalPrice": 800,
  "changeReason": "用户投诉补偿",
  "operatorId": "管理员ID",
  "operatorName": "管理员姓名"
}
```

#### 查询订单
```
GET /api/orders/:orderId
GET /api/orders?status=paid&userId=xxx
```

### 数据查询

```
GET /api/data/users        # 用户列表
GET /api/data/courses      # 课程列表
GET /api/data/coupons      # 优惠券列表
GET /api/data/group-buys   # 团购活动列表
```

## 📋 业务规则说明

### 优惠叠加顺序
1. **团购价**（优先级最高）
2. **老学员折扣**（基于团购价或原价）
3. **优惠券**（最后应用）

### 互斥规则
- 非可叠加优惠券（`is_stackable=0`）与团购互斥
- 互斥时系统自动选择更优惠的方案
- 可叠加优惠券（`is_stackable=1`）可以与其他优惠叠加

### 幂等性
- 支付回调通过 `callbackId` 实现幂等
- 相同 `callbackId` 多次调用，只处理第一次
- 后续调用直接返回历史结果

### 人工修正限制
- 已支付订单不允许直接修改价格
- 必须通过退款流程处理
- 所有人工操作必须记录操作者和原因
