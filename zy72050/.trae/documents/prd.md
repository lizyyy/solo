## 1. 产品概述

期权希腊值云台是一款面向数据分析同事的期权风险可视化工具，核心目标是将分散在 GIS、巡检平板和临时 Excel 中的期权希腊值数据统一呈现到 3D 空间中，支持异常高亮定位、备注补录追溯、查看方案保存和带原因截图导出，让周会交接不再依赖截图人工比对。
- 解决痛点：周会截图与筛选条件对不上、异常原因只在页面上闪一下就消失、备注被"洗掉"后无法追溯
- 目标用户：数据分析同事（如阿乔），需要在交接前快速定位异常、补录原因、导出带说明的报告

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 数据分析同事 | 无需注册，单用户本地使用 | 导入数据、3D 查看旋转、异常标注、备注补录、方案保存、截图与报告导出 |

### 2.2 功能模块

1. **数据导入页**：支持 Excel/CSV 文件上传，自动识别希腊值列（Delta/Gamma/Theta/Vega/Rho），保留原始字段名和来源备注
2. **3D 云台页**：期权希腊值 3D 散点/柱状可视化，支持旋转缩放、异常高亮、点击溯源到原始数据行与备注
3. **方案管理页**：保存/加载 3D 视角、筛选条件、标注状态等查看方案，支持方案命名和列表管理
4. **报告导出页**：截图导出（含异常原因标注）和文字报告生成，保留"期权希腊值云台"原因说明、原始来源和处理时间

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入页 | 文件上传区 | 拖拽上传 Excel/CSV，自动解析列头，保留原始命名，不强制统一格式 |
| 数据导入页 | 数据预览表 | 上传后展示前 N 行预览，标注字段识别结果，用户可手动修正映射 |

| 3D 云台页 | 3D 可视化画布 | 以 X/Y/Z 轴映射希腊值维度，渲染散点/柱体，支持旋转/缩放/平移 |
| 3D 云台页 | 异常高亮层 | 超阈值数据点自动高亮（红色脉冲），点击弹出溯源面板 |
| 3D 云台页 | 溯源面板 | 点击异常点后显示原始数据行、来源信息、已有备注、处理时间 |
| 3D 云台页 | 筛选控件 | 按希腊值范围、来源、异常状态筛选，筛选条件与截图同步显示 |
| 3D 云台页 | 备注补录 | 对选中的数据点追加备注，补录后高亮差异（新增/修改），记录补录时间 |

## 3. 核心流程

用户典型使用流程：导入数据 → 3D 云台查看旋转 → 发现异常高亮 → 点击溯源 → 补录备注 → 保存方案 → 导出截图/报告

```mermaid
flowchart TD
    "A[导入 Excel/CSV 数据]" --> "B[3D 云台自动渲染]"
    "B" --> "C[旋转/缩放查看空间分布]"
    "C" --> "D[发现异常高亮点]"
    "D" --> "E[点击异常点溯源到原始行]"
    "E" --> "F[补录备注/原因]"
    "F" --> "G[查看补录后差异]"
    "G" --> "H{是否需要保存视角?}"
    "H" --> "是" --> "I[保存为命名方案]"
    "H" --> "否" --> "J[导出截图/报告]"
    "I" --> "J"
    "J" --> "K[报告包含原因、来源、时间]"
```

补录备注差异流程：

```mermaid
flowchart TD
    "A[运行一小包材料]" --> "B[3D 云台展示初始状态]"
    "B" --> "C[临时补一条备注]"
    "C" --> "D[系统记录补录时间和内容]"
    "D" --> "E[差异视图：高亮新增/修改的备注]"
    "E" --> "F[差异说明写入报告]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰（#1a1f36）为背景底色，搭配琥珀色（#f59e0b）作为异常高亮色，冰蓝（#38bdf8）作为交互强调色
- **辅助色**：暗灰面板（#252b3b），白色文字（#e2e8f0），绿色表示正常（#22c55e），红色脉冲表示异常（#ef4444）
- **按钮风格**：圆角矩形（8px），轻微投影，hover 时亮度提升
- **字体**：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular，数据表格使用 JetBrains Mono
- **布局风格**：左侧 3D 画布占 70%，右侧面板占 30%（溯源/备注/筛选），顶部导航栏
- **图标风格**：线性图标（lucide-react），与整体科技感一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 数据导入页 | 文件上传区 | 虚线拖拽区域，中央上传图标，底部文件列表，暗色卡片式布局 |
| 数据导入页 | 数据预览表 | 紧凑型表格，JetBrains Mono 字体，列头标注识别状态（✓/✗），水平滚动 |
| 数据导入页 | 来源信息记录 | 底部信息栏，显示来源标签和时间戳 |
| 3D 云台页 | 3D 可视化画布 | WebGL 画布占主区域，网格地面，散点/柱体带渐变色，悬停 tooltip |
| 3D 云台页 | 异常高亮层 | 红色脉冲动画（CSS keyframe + shader），点击弹出右侧溯源面板 |

### 4.3 响应式设计

- 桌面优先（1440px 及以上最佳体验）
- 1280px 以下右侧面板可折叠为浮层
- 不强制适配移动端，但保证平板横屏可用

### 4.4 3D 场景指引

- **环境**：深色背景，微弱环境光，无 HDRI，简洁科技风
- **灯光**：一个方向光（偏冷白）+ 微弱环境光，异常点处加红色点光源
- **相机**：透视相机，初始 45° 俯视角，OrbitControls 自由旋转缩放
- **构图**：希腊值维度为坐标轴，数据点沿轴分布，异常点悬浮于主体之外形成视觉焦点
- **交互**：鼠标悬停高亮 + tooltip，点击选中弹出溯源面板，滚轮缩放，拖拽旋转
- **动画**：异常点脉冲动画（缩放 + 透明度循环），新增备注点闪烁两次后稳定
- **后期处理**：轻微 bloom 效果增强异常点发光感，性能预算 60fps @ 1000 数据点
