# 亲子摄影选片修图排程台

## 功能概述

这是一个专为亲子摄影工作室设计的全流程管理系统，涵盖：
- 📋 拍摄订单管理
- 📸 客户选片（含加修）
- 🎨 修图师排程
- 📦 交付管理
- 📊 数据统计与导出

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务

```bash
npm start
```

服务启动后访问：http://localhost:3000

## 订单完整流转指南

### 第一步：创建订单

1. 点击 **"新建订单"** 按钮
2. 填写客户信息、拍摄信息、套餐信息
3. **关键参数说明**：
   - **套餐精修数**：套餐包含的免费精修数量
   - **加修单价**：超过套餐数量后每张的加修费用
   - **照片总数**：这次拍摄的总照片数量
   - **加急订单**：勾选后优先排程
   - **优先级**：0-5 级，数字越大优先级越高
4. 点击 **"创建订单"**

> 💡 系统自动生成订单号（格式：年日月+4位序号，如 202605100001）

### 第二步：客户选片

1. 在订单列表中找到 **"待选片"** 状态的订单
2. 点击 **"选片"** 按钮进入选片界面
3. **选片操作**：
   - 点击照片 → 标记为精修（蓝色边框）
   - 再次点击精修照片 → 标记为加修（红色边框）
   - 第三次点击 → 取消选择
4. 系统自动计算：
   - 精修数量
   - 加修数量（超过套餐精修数的部分自动计算）
   - 加修费用
5. 点击 **"确认选片"**

> ⚠️ **异常拦截**：系统会自动检查
> - 照片编号是否存在
> - 加修照片是否已被选为精修
> - 是否存在重复加修
> - 加修费用与数量是否一致

### 第三步：修图排程

1. 选片完成后，订单状态变为 **"选片完成"**
2. 点击 **"排程"** 按钮
3. 填写：
   - **修图师**：从下拉列表选择
   - **排期日期**：计划完成修图的日期
   - **优先级**：可调整
4. 点击 **"安排"**

> 💡 排程后可在 **"排程看板"** 查看所有排程订单，也可随时点击 **"改排期"** 重新安排（历史记录会记录）

### 第四步：修图中

1. 排程后状态变为 **"已排程"**
2. 修图师开始工作时点击 **"开始"**，状态变为 **"修图中"**
3. 修图完成点击 **"完成"**，状态变为 **"待交付"**

### 第五步：交付客户

1. 在 **"交付中心"** 或订单列表中找到待交付订单
2. 点击 **"确认交付"**
3. 选择：
   - **交付方式**：网盘/U 盘/微信/邮箱
   - **备注**：如网盘链接等
4. 点击 **"确认交付"** 完成

> ⚠️ 已交付订单将被锁定，无法再修改选片或排程

## 异常拦截机制

系统内置多项安全检查，防止错误操作：

### 1. 防止重复加修
- 同一照片不能被多次标记为加修
- 已加修的照片再次选片时会被拦截

### 2. 已交付订单锁定
- 已交付订单不能：
  - 修改选片
  - 重新排程
  - 修改费用

### 3. 费用一致性校验
- 选片提交时自动计算：`加修费用 = 加修数量 × 加修单价`
- 如不一致（前端被篡改），后端拦截并返回错误

### 4. 加修照片必须先选精修
- 加修照片必须包含在精修范围内
- 单独标记加修会被拦截

### 5. 排程前必须完成选片
- 未选片的订单无法排程
- 防止"空订单"进入修图环节

## 高级功能

### 📊 排程看板
- 按状态分类展示（已排程/修图中/待交付）
- 加急订单红色高亮
- 显示修图师、排期、精修/加修数量
- 可直接改排期

### 📦 交付中心
- 汇总所有待交付订单
- 一键确认交付
- 记录交付方式和备注

### 📈 本周交付表
- 统计本周（周日-周六）交付情况
- 显示交付数量和营收
- 点击 **"导出为CSV"** 下载表格

### 📝 催单记录
- 点击 **"催单"** 添加催单记录
- 支持选片催单/修图催单/交付催单
- 历史记录可查

### 🔍 操作历史
- 点击 **"详情"** 查看订单完整历史
- 记录每次状态变更、排程修改、催单
- 显示操作人和时间

## 数据持久化

- 所有数据存储在 SQLite 数据库（`data/studio.db`）
- 页面刷新后状态完全保留
- 无需单独启动数据库服务

## 技术栈

- **后端**：Node.js + Express
- **数据库**：SQLite (better-sqlite3)
- **前端**：原生 HTML/CSS/JavaScript
- **API 规范**：RESTful

## 订单状态流转

```
待选片 → 选片完成 → 已排程 → 修图中 → 待交付 → 已交付
   ↓           ↓         ↓        ↓        ↓
 可添加催单  可改排程   可改排期   可催单    锁定
```

## 常见问题

**Q：照片上传后发现数量不对怎么办？**
A：目前系统通过照片总数模拟，实际项目中可接入真实照片管理。

**Q：如何区分手工加修和超套自动加修？**
A：系统将两者合并计算费用，前端点击照片标记的加修会被记录。

**Q：已交付订单发现错误怎么办？**
A：已交付订单锁定保护，如需修改需联系管理员手动处理数据库。
