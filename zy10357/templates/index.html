API 使用示例

            
# 登记吊销
curl -X POST http://localhost:8080/api/v1/revocations \
  -H "Content-Type: application/json" \
  -d '{"serial_number": "12345", "reason": "KEY_COMPROMISE"}'

# 检查吊销状态
curl http://localhost:8080/api/v1/revocations/12345/check

# 创建分发版本
curl -X POST http://localhost:8080/api/v1/versions

# 确认缓存
curl -X POST http://localhost:8080/api/v1/revocations/12345/confirm-cache

# 激活吊销
curl -X POST http://localhost:8080/api/v1/revocations/12345/activate

# 获取历史
curl http://localhost:8080/api/v1/revocations/12345/history

# 获取报表
curl http://localhost:8080/api/v1/report
