# 养老金领取试算系统

## 系统概述

这是一个全栈养老金领取试算系统，帮助社保窗口工作人员为退休人员进行养老金试算。系统包含数据录入、试算计算、边界校验、方案对比和PDF导出功能。

## 核心功能

### 1. 数据结构

- **参保人信息**: 姓名、身份证号、联系电话
- **参保记录**: 参保地、起止年月、缴费类型、缴费基数、个人账户储存额
- **补缴单**: 补缴起止年月、补缴基数、补缴金额、滞纳金、状态
- **领取地信息**: 城市、省份、户籍性质、社会平均工资、计发基数、缴费基数上下限
- **年龄信息**: 出生日期、退休年月、性别、工种、视同缴费年限
- **试算报告**: 缴费明细、账户信息、养老金构成、边界提示、方案对比

### 2. 核心业务逻辑

#### 年限归集
- 自动归集所有参保记录和补缴单的缴费月份
- 检测重复缴费和补缴重叠
- 计算实际缴费月数和年限

#### 养老金计算
- **基础养老金**: `(计发基数 + 计发基数 × 平均缴费指数) / 2 × 累计缴费年限 × 1%`
- **个人账户养老金**: `个人账户储存额 / 计发月数`
- **过渡性养老金**: `计发基数 × 平均缴费指数 × 视同缴费年限 × 过渡系数(1.3%)`
- **过渡性调节金**: 视同缴费年限>0时发放120元

#### 边界校验

| 边界类型 | 校验规则 | 严重程度 |
|---------|---------|---------|
| 重复缴费 | 同一月份存在多条缴费记录 | warning |
| 补缴重复 | 补缴月份与已缴月份重叠 | error |
| 提前退休 | 退休时间早于法定年龄 | warning |
| 延迟退休超限 | 退休时间超过法定年龄5年 | error |
| 多地满10年 | 多个参保地缴费满10年 | info |
| 多地均不满10年 | 所有参保地缴费均不满10年 | warning |
| 缴费年限不足 | 累计缴费不足15年 | error |

#### 领取地确定规则
1. 户籍地参保满10年以上：在最后参保地领取
2. 多地参保均不满10年：回户籍地领取
3. 累计缴费满15年且最后参保地满10年：在最后参保地领取

### 3. 边界案例样例

系统内置4个典型边界案例：

1. **补缴重复案例** - 测试补缴月份与正常缴费重叠的边界校验
2. **多地参保案例** - 测试多个参保地满10年的领取地确定规则
3. **提前退休案例** - 测试特殊工种提前退休的年龄边界校验
4. **缴费年限不足案例** - 测试累计缴费不足15年的边界提示

### 4. 数据持久化

- 所有数据自动保存到浏览器localStorage
- 刷新页面数据不会丢失
- 显示最后保存时间

### 5. 方案对比

- 支持保存多个试算方案
- 对比不同方案的养老金结果
- 按每月领取总额排序

### 6. PDF导出

- 导出完整的养老金试算报告
- 包含所有缴费明细和计算结果
- 包含边界提示信息

## 技术栈

### 后端
- Node.js + Express
- PDFKit (PDF生成)
- Moment.js (日期处理)

### 前端
- React 18 + TypeScript
- Vite (构建工具)
- Ant Design (UI组件库)
- Axios (HTTP客户端)
- jsPDF + autotable (前端PDF导出)

## 快速开始

### 安装依赖

```bash
# 安装后端依赖
npm install

# 安装前端依赖
cd client && npm install
```

### 启动应用

```bash
# 方式1：分别启动后端和前端
# 启动后端 (端口3001)
npm run server

# 启动前端 (端口3002)
cd client && npm start

# 方式2：使用concurrently同时启动
npm run dev
```

### 访问应用

打开浏览器访问: http://localhost:3002

## API接口

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/health` | GET | 健康检查 |
| `/api/sample-cases` | GET | 获取边界案例样例数据 |
| `/api/calculate` | POST | 执行养老金试算 |
| `/api/compare` | POST | 方案对比 |
| `/api/validate/payment-months` | POST | 缴费月份校验 |
| `/api/validate/age` | POST | 年龄边界校验 |
| `/api/determine-location` | POST | 确定领取地 |
| `/api/export-pdf` | POST | 后端PDF导出 |

## 注意事项

1. 所有金额单位为人民币元
2. 缴费基数上下限按当地社平工资的60%-300%确定
3. 本系统仅供试算参考，最终养老金以社保部门核定为准
4. 数据仅保存在本地浏览器，请注意数据备份
