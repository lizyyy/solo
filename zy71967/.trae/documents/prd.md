## 1. 产品概述

推荐实验看板是一款面向算法工程师和算法负责人的轻量级实验数据整合工具，将评估表、线上反馈和配置文件汇聚到同一条流水线中查看，解决多源数据口径不一致、指标变更溯源困难、评估结论不透明等痛点。

- 目标用户：算法工程师（日常导入、比对、导出）、算法负责人（审批、确认、查看评估说明）
- 核心价值：统一数据口径、可追溯的处理链路、自动判断附理由、评估说明附带处理口径

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 算法工程师 | 工号登录 | 导入数据、查看看板、撤回修正、筛选导出 |
| 算法负责人 | 工号登录 | 查看看板、确认/驳回记录、查看评估说明 |

### 2.2 功能模块

1. **实验看板页**：多源数据流水线视图、指标比对、自动判断及理由展示、筛选与导出
2. **数据管理页**：评估表/线上反馈/配置文件的导入、重复检测、撤回修正操作
3. **评估说明页**：已确认/待补/人工改过的记录分区展示、处理口径标注、指标变更溯源

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 实验看板页 | 数据流水线 | 将评估表、线上反馈、配置文件按实验维度串联展示，每条数据标注来源 |
| 实验看板页 | 指标比对区 | 同一指标跨来源对比，口径不一致时高亮提示 |

| 数据管理页 | 数据导入 | 支持评估表、线上反馈、配置文件三类导入，重复导入时检测并提示 |

## 3. 核心流程

### 3.1 数据导入与对齐流程

算法工程师将评估表、线上反馈、配置文件导入看板，系统自动按实验 ID 关联三类数据，检测重复并提示，指标口径变化时标明来源和下一步动作，最终在流水线上统一呈现。

```mermaid
flowchart TD
    "A:导入评估表" --> "D:系统按实验ID关联"
    "B:导入线上反馈" --> "D"
    "C:导入配置文件" --> "D"
    "D" --> "E:检测重复数据"
    "E" --> "F:存在重复？"
    "F" -->|"是"| "G:提示重复，选择覆盖/跳过/撤回修正"
    "F" -->|"否"| "H:口径一致性检查"
    "G" --> "H"
    "H" --> "I:口径有变化？"
    "I" -->|"是"| "J:标明来源与下一步，写入待补记录"
    "I" -->|"否"| "K:生成流水线视图"
    "J" --> "K"
```

### 3.2 评估确认流程

算法负责人在评估说明页查看分区记录，对已确认/待补/人工改动记录分别处理，确认后记录状态流转，处理口径始终可见。

```mermaid
flowchart TD
    "A:负责人打开评估说明页" --> "B:查看已确认记录"
    "A" --> "C:查看待补记录"
    "A" --> "D:查看人工改动记录"
    "C" --> "E:补充数据或指派负责人"
    "E" --> "F:状态转为已确认"
    "D" --> "G:审核改动原因"
    "G" -->|"认可"| "F"
    "G" -->|"不认可"| "H:驳回，标记待修正"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰 (#1E293B) + 琥珀色强调 (#F59E0B)，传达专业、可信赖的工具感
- 辅助色：翡翠绿 (#10B981) 表示已确认，珊瑚红 (#EF4444) 表示待补/异常，石板蓝 (#64748B) 表示人工改动
- 按钮：圆角矩形（6px），扁平风格，主操作用琥珀色实心，次要操作用边框样式
- 字体：JetBrains Mono（数据/指标）+ Noto Sans SC（正文/标题），数据区域用等宽字体确保对齐
- 布局：左侧导航 + 右侧内容区，内容区采用卡片式分区，流水线视图横向排列
- 图标：线性图标风格（Phosphor Icons），不使用 emoji

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 实验看板页 | 数据流水线 | 横向三列卡片（评估表/线上反馈/配置文件），每列顶部标注来源，卡片间用连线箭头表示数据流 |
| 实验看板页 | 指标比对区 | 表格形式，行=指标名，列=各来源值，不一致单元格高亮琥珀色边框 |
| 实验看板页 | 自动判断区 | 判断结果标签（达标/未达标）+ 展开式理由文本，标签颜色对应状态 |
| 实验看板页 | 口径变更提示 | 黄色条纹横幅，文字说明"口径变更来源：评估表 / 线上反馈"，附带"下一步：联系XXX补全" |
| 实验看板页 | 筛选与导出 | 顶部筛选条（来源/状态/时间下拉），右上角导出按钮 |
| 数据管理页 | 数据导入 | 三块拖拽上传区（评估表/线上反馈/配置文件），上传后显示导入结果和重复检测报告 |
| 数据管理页 | 撤回修正 | 操作列表，每行显示数据名+状态+操作按钮（撤回/修正），修正弹出模态框 |
| 数据管理页 | 操作日志 | 时间线样式，每条记录包含时间戳、操作人、操作类型、变更详情 |
| 评估说明页 | 已确认记录 | 绿色左边框卡片列表，每条带处理口径标签 |
| 评估说明页 | 待补记录 | 红色左边框卡片列表，标明缺失项和负责人 |
| 评估说明页 | 人工改动记录 | 蓝色左边框卡片列表，显示原始值→修改值对比，附修改原因 |
| 评估说明页 | 处理口径标注 | 每条记录底部灰色标签条，显示"口径：取评估表均值 / 对齐至线上反馈口径"等文字 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px
- 平板端（768px-1024px）：侧边导航折叠为图标模式，流水线视图改为纵向堆叠
- 移动端暂不支持，工具定位为桌面端效率工具

## 5. 数据状态定义

| 状态 | 含义 | 颜色标识 | 可执行操作 |
|------|------|----------|------------|
| 已确认 | 数据完整且已通过负责人审批 | 翡翠绿 | 查看、导出 |
| 待补 | 数据存在缺失或口径不一致，需补充 | 珊瑚红 | 补充数据、指派负责人 |
| 人工改动 | 数据经人工修改，需审核改动原因 | 石板蓝 | 审核通过、驳回 |
| 导入中 | 数据正在导入和处理中 | 琥珀色 | 等待、取消 |
