## 1. 产品概述

芯片封装热斑立方是一套面向芯片封装方案经理的热斑数据管理与追溯系统，核心解决热斑证据链断裂、参数改完不同步、坐标系冲突硬合并、交接时需反复翻周会截图找依据等痛点。目标用户为方案经理许姐及其团队，核心价值在于让每条热斑判断可追到来源、可带着原因导出、可零成本交接。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 方案经理 | 管理员分配 | 创建/编辑方案、导入数据、审核冲突、导出报告、交接 |
| 工程师 | 管理员分配 | 查看方案、提交点位/照片、标注坐标系、备注 |
| 接手人 | 管理员分配 | 查看方案与完整追溯链、导出报告 |

### 2.2 功能模块

1. **总览面板**：方案状态总览、异常统计、近期冲突摘要、快捷操作入口
2. **热斑工作台**：热斑记录表格、参数面板、场景视图/明细视图联动、来源追踪面板
3. **追溯与报告**：完整证据链可视化、冲突对比与决策记录、带原因导出报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 总览面板 | 方案状态卡片 | 显示当前方案数量、异常数、待处理冲突数、最近更新时间 |
| 总览面板 | 异常热力图 | 按芯片区域聚合异常密度，点击可跳转到工作台对应区域 |
| 总览面板 | 冲突摘要列表 | 列出未解决的来源冲突，每条显示双方来源和严重程度 |
| 总览面板 | 快捷操作 | 新建方案、导入数据、一键导出上次报告 |
| 热斑工作台 | 热斑记录表格 | 所有热斑条目列表，支持按来源类型/坐标系/异常等级筛选 |
| 热斑工作台 | 参数调整面板 | 侧边参数编辑区，修改后场景视图、明细和报告数字实时联动 |
| 热斑工作台 | 场景视图 | 热斑在封装结构上的空间分布，坐标系不一致时标注边界 |
| 热斑工作台 | 明细面板 | 选中热斑的详细参数、来源列表、处理时间线 |
| 热斑工作台 | 来源追踪浮层 | 点击任意数字可追溯其来源（点位表/照片/备注/周会截图） |
| 追溯与报告 | 证据链时间线 | 从原始数据导入→参数调整→判断结论的完整时间线 |
| 追溯与报告 | 冲突对比面板 | 左右并排展示冲突双方证据，附建议动作，不自动拍板 |
| 追溯与报告 | 错误定位提示 | 数据损坏时精确到点位类型或照片编号的错误提示 |
| 追溯与报告 | 导出报告 | 生成含来源原因、处理时间、坐标系标注的完整报告（PDF/JSON） |

## 3. 核心流程

### 3.1 热斑数据导入与追溯流程

方案经理导入点位表和现场照片，系统解析并生成热斑记录，每条记录绑定来源（点位表行号/照片编号/备注来源/周会截图引用）。若检测到坐标系不一致，标注但不强制合并。若周会截图说法与导入数据冲突，进入冲突队列等待人工决策。

```mermaid
flowchart TD
    "导入点位表" --> "解析点位数据"
    "导入现场照片" --> "识别热斑区域"
    "导入方案备注" --> "提取备注信息"
    "导入周会截图" --> "OCR提取文字"
    "导入同事手改坐标" --> "坐标格式识别"
    "解析点位数据" --> "坐标系检测与标注"
    "识别热斑区域" --> "坐标系检测与标注"
    "坐标格式识别" --> "坐标系检测与标注"
    "坐标系检测与标注" --> "生成热斑记录（含来源标签）"
    "OCR提取文字" --> "冲突检测"
    "提取备注信息" --> "冲突检测"
    "生成热斑记录（含来源标签）" --> "冲突检测"
    "冲突检测" --> "无冲突：自动入库"
    "冲突检测" --> "有冲突：进入冲突队列"
    "有冲突：进入冲突队列" --> "人工对比双方证据"
    "人工对比双方证据" --> "选择处理方式"
    "选择处理方式" --> "记录决策原因与时间"
    "记录决策原因与时间" --> "入库并标记已处理"
```

### 3.2 参数联动流程

方案经理在参数面板修改阈值或权重，修改事件广播到场景视图、明细面板和报告预览，所有数字同步更新。每次修改记录操作人、时间和变更前后的值，作为追溯链的一部分。

```mermaid
flowchart TD
    "参数面板修改值" --> "记录变更日志（操作人/时间/旧值/新值）"
    "参数面板修改值" --> "广播变更事件"
    "广播变更事件" --> "场景视图重新计算热斑等级"
    "广播变更事件" --> "明细面板更新数值"
    "广播变更事件" --> "报告预览刷新数字"
    "场景视图重新计算热斑等级" --> "热斑记录更新判断结果"
    "明细面板更新数值" --> "热斑记录更新判断结果"
    "热斑记录更新判断结果" --> "判断结果关联参数变更原因"
```

### 3.3 交接导出流程

方案经理点击导出，系统汇总所有热斑记录及其来源链、参数变更历史、冲突处理决策、坐标系标注，生成带时间戳的交接报告。

```mermaid
flowchart TD
    "点击导出报告" --> "收集热斑记录及来源链"
    "收集热斑记录及来源链" --> "附加参数变更历史"
    "附加参数变更历史" --> "附加冲突处理决策记录"
    "附加冲突处理决策记录" --> "附加坐标系标注说明"
    "附加坐标系标注说明" --> "生成交接报告（PDF/JSON）"
    "生成交接报告（PDF/JSON）" --> "报告包含每条判断的原因和处理时间"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底色（#1a1a2e）搭配琥珀色（#f59e0b）和红色（#ef4444）热力渐变，模拟热成像仪视觉
- **辅助色**：钢蓝色（#3b82f6）用于坐标系标注、绿色（#22c55e）用于正常状态
- **按钮风格**：微圆角矩形，带微光边框反馈，主操作按钮用琥珀色填充
- **字体**：标题用 JetBrains Mono（工程感），正文用 Noto Sans SC（中文可读性）
- **布局风格**：左侧导航 + 右侧主内容区，工作台采用三栏布局（记录列表/场景视图/参数面板）
- **图标风格**：线性图标，lucide-react 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 总览面板 | 方案状态卡片 | 深色卡片、琥珀色数字高亮、微型趋势图 |
| 总览面板 | 异常热力图 | 网格热力图、悬停显示区域详情、点击跳转 |
| 总览面板 | 冲突摘要列表 | 带红/黄/绿状态圆点的列表项、来源缩略图 |
| 总览面板 | 快捷操作 | 琥珀色填充主按钮、灰色描边次按钮 |
| 热斑工作台 | 热斑记录表格 | 可排序表格、行内坐标系标签、来源数量徽章 |
| 热斑工作台 | 参数调整面板 | 侧边滑出面板、滑块+数值输入、变更历史折叠区 |
| 热斑工作台 | 场景视图 | 封装结构俯视图、热斑热力叠加、坐标系边界虚线 |
| 热斑工作台 | 明细面板 | 底部抽屉、参数详情+来源时间线+变更记录 |
| 热斑工作台 | 来源追踪浮层 | 点击数字弹出浮层、显示来源类型/编号/截图缩略图 |
| 追溯与报告 | 证据链时间线 | 垂直时间线、节点图标区分来源类型、连接线动画 |

| 追溯与报告 | 导出报告 | 格式选择（PDF/JSON）、导出按钮、预览区 |

### 4.3 响应式设计

- 桌面优先设计，最小支持 1280px 宽度
- 工作台三栏在 1280-1440px 时参数面板收为抽屉
- 1024-1280px 时场景视图切换为简化模式
- 移动端仅支持总览面板和报告查看

### 4.4 3D场景指引（不适用）

本项目使用2D俯视图展示封装结构和热斑分布，不涉及3D场景渲染。
