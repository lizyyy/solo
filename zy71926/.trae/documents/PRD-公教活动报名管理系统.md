## 1. 产品概述

公教活动报名管理系统，解决作品调换无留痕导致的争议问题。面向策展人、布展工人、保险联系人三类核心用户，提供报名数据录入、异常检测、状态回溯、布展清单导出等核心功能。

- 核心痛点：作品调换无留痕，布展清单导出不一致，争议无法复核
- 设计原则：少装饰，重状态回看、异常解释、导出一致性

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心操作 | 关注点 |
|------|----------|--------|
| 策展人 | 录入报名、人工更正、作品调换、确认状态 | 数据准确性、变更留痕、争议复核 |
| 布展工人 | 查看布展清单、标记到场/缺失 | 可追溯性、下一班能继续查 |
| 保险联系人 | 导出清单、查看异常记录 | 数据一致性、争议点有明确原因 |

### 2.2 功能模块

1. **报名列表页**：数据录入、批量导入、重复检测、状态筛选
2. **报名详情页**：完整信息、状态历史、异常标记、作品调换操作
3. **异常面板**：集中展示所有异常（重复、晚到附件、缺失、冲突）
4. **布展清单导出**：CSV格式，侧重可追溯性，包含复核原因

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|

## 3. 核心流程

报名录入 → 自动校验（重复/缺失/冲突） → 异常标记 → 人工更正（留痕） → 状态确认 → 作品调换（必填原因） → 导出布展清单

    G --> H["状态：已确认"]

## 4. 用户界面设计

### 4.1 设计风格
- **美学方向**：工业实用主义/控制台风格。拒绝装饰，信息密度优先
- **主色**：深灰 `#1e293b` 背景，白色文字，强调可读性
- **强调色**：状态色严格区分——正常`#10b981`、警告`#f59e0b`、异常`#ef4444`、变更`#3b82f6`
- **按钮**：方角、无阴影、实心色块，点击即操作
- **字体**：`JetBrains Mono` 等宽字体，数字和时间戳对齐，适合表格密集显示
- **布局**：顶部固定工具栏 + 左侧异常快捷入口 + 主内容区表格，无多余留白
- **图标**：纯文字+符号标记（●▲■），不用SVG图标，减少视觉噪音

### 4.2 页面设计要点

| 页面名称 | 模块名称 | UI 关键设计 |
|-----------|-------------|-------------|
| 报名列表页 | 数据表格 | 斑马纹区分行，异常行整行浅红背景，最新变更列显示相对时间+绝对时间 |
| 报名列表页 | 异常标记 | 单元格内用 `[重]` `[缺]` `[调]` 文字标签，hover显示完整异常描述 |
| 报名详情页 | 状态时间线 | 左侧竖线+时间戳，右侧操作人+原因+附件，调换记录用红框高亮 |
| 报名详情页 | 作品调换 | 弹窗强制填写三个字段：调换原因、原作品、新作品，缺一不可提交 |
| 异常面板 | 异常卡片 | 标题带异常类型标签，内容区用固定宽度显示，便于快速扫描 |
| 导出文件 | 布展清单CSV | 列包含：当前信息 + 最后变更人 + 最后变更时间 + 变更原因 + 历史状态链 |

### 4.3 交互细节
- **状态回看**：每条记录点击可展开时间线，无需跳转新页面
- **异常解释**：点击异常标签弹出解释框，说明检测规则和处理建议
- **导出一致性**：每次导出生成唯一导出编号，记录导出人、导出时间、筛选条件
- **争议记录高亮**：有过作品调换的记录，在所有视图中用 `[调]` 永久标记

### 4.4 响应式
- 桌面端优先，表格支持横向滚动
- 移动端折叠表格为卡片列表，保留核心状态和操作按钮
