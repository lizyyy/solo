## 1. 产品概述

"保险定损快拍赛"是一款面向保险新人培训的互动小游戏，玩家根据事故照片判断车损部位、维修等级和赔付风险。所有原始线索不可覆盖，玩家犯错后必须知道错在哪里、影响了哪些对象、原因是什么，形成可复盘的完整审计链路。

- 目标用户：保险行业新入职定损员、理赔岗培训学员
- 核心价值：通过游戏化练习降低实际定损中的误判率，建立"线索→判定→结算→纠错"的闭环思维

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 学员 | 选择培训场次进入 | 查看事故照片、选择线索卡片、提交定损判定、查看错因回放、导出报告 |
| 讲师 | 管理后台进入 | 编辑案例数据、查看学员错因统计、人工修正判定结果、月底复盘导出 |

### 2.2 功能模块

1. **案例开场页**：事故照片展示、基本信息、倒计时开始
2. **线索选择台**：部位卡、维修价目、保单规则、客户情绪四类线索，每轮有限选择次数
3. **规则判定台**：根据已选线索判断车损部位、维修等级（轻微/中度/重度/报废）、赔付风险（低/中/高）
4. **赔付结算页**：计算赔付金额，触发规则校验（旧伤误判/价格超限/免责条款漏看）
5. **错因回放页**：列出所有误判项，标注影响对象+原因，支持逐条展开
6. **定损报告页**：汇总判定结果，支持导出；人工修正处保留旧值和修改理由
7. **月底复盘页**：讲师视角，按案例/学员/错因类型汇总，可翻查任意修正记录

## 3. 核心流程

1. 学员进入案例，查看事故照片和基本信息
2. 在限时内从四类线索中选择关键信息（线索选择有次数限制，需权衡）
3. 根据已选线索在判定台做出部位/等级/风险判定
4. 系统自动计算赔付金额并校验三种规则误判
5. 如有误判，在错因回放页展示影响对象和原因
6. 生成定损报告，讲师可人工修正，修正处保留审计追踪
7. 月底复盘时讲师可翻查所有修正历史

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深钢蓝（#1B2A4A）+ 琥珀警示橙（#E8913A）+ 翡翠正确绿（#2D9B6E）
- **辅助色**：冷灰（#6B7B8D）、米白背景（#F5F3EF）、浅蓝卡片（#E8EDF4）
- **按钮风格**：圆角6px，主按钮深钢蓝底白字，警示按钮琥珀橙，确认按钮翡翠绿
- **字体**：标题使用 Noto Serif SC（衬线体增加专业感），正文使用 Noto Sans SC
- **布局风格**：左侧线索面板 + 中央判定区 + 右侧结果面板的三栏布局
- **图标风格**：线性图标（lucide-react），配合卡片式信息展示

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 案例开场页 | 事故照片区 | 全宽照片，底部半透明信息条，圆角8px |
| 案例开场页 | 案例信息卡 | 左对齐文字，钢蓝色标题栏，米白内容区 |
| 线索选择台 | 部位卡组 | 网格3列卡片，选中态琥珀橙边框，禁用态灰色 |
| 线索选择台 | 保单条款卡 | 折叠面板，条款文字区，漏看标红星 |
| 规则判定台 | 判定表单 | 分区表单，下拉选择器，实时校验提示 |
| 赔付结算页 | 金额面板 | 大号数字展示，超限红色闪烁警示 |
| 赔付结算页 | 影响清单 | 列表式，每项可展开，图标标注误判类型 |
| 错因回放页 | 时间线 | 竖向时间线，节点标注误判类型，展开详情 |
| 定损报告页 | 报告区 | A4纸样式，修正处删除线旧值+绿色新值+灰色理由注释 |
| 月底复盘页 | 统计图表 | 柱状图+饼图，可按月筛选，修正记录可展开 |

### 4.3 响应式设计

- 桌面优先，三栏布局在 1280px 以上完整展示
- 1024-1280px 时线索面板折叠为侧边抽屉
- 768px 以下切换为单栏竖向布局，线索和判定分步展示

### 4.4 数据不可变与审计追踪设计

- 所有原始线索（照片、部位卡、维修价、保单规则、客户情绪、定损报告初版）创建后不可修改
- 每次修正生成一条修正记录：`{ 字段名, 旧值, 新值, 修改理由, 修改时间, 修改人 }`
- 修正记录追加式存储，不覆盖原始数据
- 错因回放时同时展示原始线索和修正链
- 月底复盘可按字段、时间、修改人筛选修正记录
