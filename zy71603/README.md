# 保理应收账款转让分析工具

## 启动

```bash
pnpm install
pnpm dev
```

浏览器打开 `http://localhost:5173/`，页面会自动加载样例数据并执行分析。

## 先看什么

1. 打开首页即自动分析，仪表盘展示 4 张总览卡片 + 4 个图表
2. **点击图表中的数据点**（饼图扇区、柱状图柱体、横向条形），右侧滑入抽屉显示对应明细
3. 点左侧边栏第二个图标进入「异常留痕」页，按步骤展开查看每条异常的描述和影响
4. 抽屉和留痕页都有「导出」按钮，点击生成 CSV 文件

## 样例数据说明

样例内含 10 张发票、4 笔转让申请、4 条买方确认、8 笔回款流水，刻意包含：

| 异常 | 在哪能看到 |
|------|-----------|
| 发票 INV-2024-0009 重复转让（出现在 TRF-0003 和 TRF-0004） | 债权校验饼图 - 重复 |
| TRF-0003 买方未确认 | 确认状态柱图 - 未确认 |
| TRF-0004 买方仅部分确认 ¥318,000 | 确认状态柱图 - 部分确认 |
| 回款 RPY-0002 比回款金额少 ¥2,000 | 回款匹配柱图 - 错配 |
| 回款 RPY-0007 指向错误发票 | 回款匹配柱图 - 错配 |
| 回款 RPY-0008 超额回款 | 回款匹配柱图 - 错配 |
| TRF-0003 缺合同附件 | 异常留痕 - 债权校验步骤 |
| TRF-0004 缺核验报告 | 异常留痕 - 债权校验步骤 |
| INV-2024-0005 手工更正（¥175,000→¥185,000） | 异常留痕 - 债权校验步骤 |
| TRF-0003 发票合计 ¥550,000 与声明总额 ¥570,000 不符 | 异常留痕 - 债权校验步骤 |

## 失败/异常记录在哪看

- **仪表盘**：异常条目卡片（红色左边框）、异常类型分布图
- **异常留痕页**：按分析步骤分组，点击步骤名展开，每条异常可再展开查看「影响说明」
- **CSV 导出**：点击导出按钮，浏览器下载 CSV 文件，可用 Excel 打开

## 关键文件

- 样例数据：`src/data/sampleData.ts`
- 分析引擎：`src/engine/analyzer.ts`
- 类型定义：`src/engine/types.ts`
