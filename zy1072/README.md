# 婚礼座位表和宾客关系冲突检查器

一个本地运行的婚礼/年会座位表检查工具，帮助筹备人员在现场前发现潜在的座位安排问题。

## 功能特性

- **数据导入**: 支持 guests.csv（宾客名单）和 tables.json（桌位配置）
- **冲突检测**: 自动检查超容量、同行人拆分、关系冲突、位置不合理等问题
- **调桌建议**: 生成可解释的调整建议，按优先级排序
- **多格式导出**: 导出座位表、厨房注意事项、打印卡片

## 快速开始

### 环境要求

- Node.js >= 18.0.0

### 安装

```bash
cd wedding-seating-checker
```

### 基本使用

```bash
# 检查座位表冲突
node src/cli/index.js validate

# 生成调桌建议
node src/cli/index.js suggest

# 导出最终方案
node src/cli/index.js export -o ./output/

# 查看帮助
node src/cli/index.js --help
```

### 使用示例数据测试

项目包含示例数据，可以直接运行测试：

```bash
# 检查示例数据
node src/cli/index.js validate

# 使用错误数据测试（包含多种冲突场景）
node src/cli/index.js validate --guests data/bad-guests.csv
```

## 命令说明

### validate - 检查冲突

```bash
node src/cli/index.js validate [options]
```

检查以下问题：
- **严重冲突**: 重复姓名、桌位超员、需要避免同桌的人被安排在一起
- **高优先级**: 桌号不存在、未分配座位、同行人被拆分、行动不便者离出口太远、儿童桌无成人、VIP视线差
- **信息提示**: 饮食限制汇总、同一分组被分散、空桌位等

### suggest - 生成调桌建议

```bash
node src/cli/index.js suggest [options]
```

生成：
- 按优先级排序的调整建议
- 每种问题的可执行方案
- 当前座位概览

### export - 导出方案

```bash
node src/cli/index.js export -o <output-dir>
```

导出三个文件：

| 文件名 | 格式 | 用途 |
|--------|------|------|
| seating-plan.csv | CSV | 完整座位表汇总，包含所有宾客信息和备注 |
| kitchen-notes.md | Markdown | 厨房用餐注意事项，包含所有饮食/过敏限制的汇总 |
| print-cards.html | HTML | 可打印的桌号卡和座位卡，直接在浏览器中打印 |

## 数据格式

### guests.csv（宾客名单）

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 姓名 | 字符串 | 是 | 宾客姓名（唯一标识） |
| 分组 | 字符串 | 是 | 所属分组（如：新郎家人、新娘家人、同事、同学） |
| 关系标签 | 字符串列表 | 是 | 关系描述（如：父亲、母亲、同事） |
| 同行人 | 字符串列表 | 否 | 需要坐在一起的人（逗号分隔） |
| 忌口/过敏 | 字符串列表 | 否 | 饮食限制（如：素食、海鲜过敏、坚果过敏） |
| 行动不便 | 布尔值 | 否 | 是否需要靠近出口 |
| 儿童 | 布尔值 | 否 | 是否需要成人陪同 |
| 是否需要安静区 | 布尔值 | 否 | 是否需要远离音箱 |
| 优先同桌 | 字符串列表 | 否 | 希望坐在一起的人 |
| 避免同桌 | 字符串列表 | 否 | 不能坐在一起的人 |
| VIP | 布尔值 | 否 | 是否需要前排座位 |
| 桌号 | 字符串 | 否 | 已分配的桌号（为空表示未分配） |

**布尔值支持的格式**: `是/否`, `yes/no`, `true/false`, `1/0`（不区分大小写）

**列表支持的分隔符**: 逗号 `,`、顿号 `、`、空格

### tables.json（桌位配置）

```json
[
  {
    "桌号": "1",
    "容量": 10,
    "区域": "主舞台前",
    "离舞台距离": 10,
    "离音箱距离": 15,
    "离出口距离": 80,
    "是否儿童友好": false,
    "是否安静区": false
  }
]
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| 桌号 | 字符串 | 是 | 桌号标识 |
| 容量 | 数字 | 是 | 该桌最大容纳人数 |
| 区域 | 字符串 | 否 | 区域名称（如：主舞台前、贵宾区） |
| 离舞台距离 | 数字 | 否 | 相对距离（0-100，越小越近） |
| 离音箱距离 | 数字 | 否 | 相对距离（0-100，越小越近） |
| 离出口距离 | 数字 | 否 | 相对距离（0-100，越小越近） |
| 是否儿童友好 | 布尔值 | 否 | 是否适合有儿童的家庭 |
| 是否安静区 | 布尔值 | 否 | 是否适合需要安静的宾客 |

## 检测规则

### 严重冲突 (必须修复)

| 规则 | 说明 |
|------|------|
| 重复姓名 | 存在同名宾客，无法唯一标识 |
| 桌位超员 | 某桌人数超过容量限制 |
| 避免同桌冲突 | 需要避免同桌的人被安排在一起 |

### 高优先级冲突 (建议修复)

| 规则 | 说明 |
|------|------|
| 桌号不存在 | 宾客分配的桌号未在配置中 |
| 未分配座位 | 宾客未安排桌位 |
| 同行人拆分 | 需要坐在一起的人被分开 |
| 行动不便位置 | 行动不便者离出口太远 |
| 儿童无成人 | 儿童桌没有成年人陪同 |
| VIP视线差 | VIP被安排在离舞台较远的位置 |

### 信息提示 (仅供参考)

| 规则 | 说明 |
|------|------|
| 安静区需求 | 需要安静区的宾客可能在嘈杂区域 |
| 饮食限制 | 有饮食/过敏限制的宾客汇总 |
| 空桌位 | 配置了但未使用的桌位 |
| 优先同桌分离 | 希望坐在一起的人被分开 |
| 分组分散 | 同一分组的宾客被分散在多桌 |

## 常见问题

### Q: 如何处理同名宾客？
A: 建议使用全名或添加标识区分，如"张三（父）"、"张三（子）"，或在姓名中包含中间名。

### Q: 距离值的单位是什么？
A: 距离值是相对值（0-100），越小表示越近。不需要精确测量，只需按相对位置填写即可。例如：
- 离舞台距离：第一排填10，最后一排填100
- 离出口距离：靠近出口的桌填20，远离的填80

### Q: 如何批量处理 Excel 文件？
A: 将 Excel 另存为 CSV 格式（UTF-8 编码）即可使用。对于复杂的 Excel 表格，建议先整理成标准格式。

### Q: 工具是否支持中文？
A: 完全支持。所有字段、输出、界面都是中文的。导出的 CSV 使用 UTF-8 BOM 编码，确保 Excel 打开时中文正常显示。
