# 合唱排练座位编排器

为社区合唱团领队设计的本地桌面 GUI 工具，用于管理排练座位编排。

## 功能特性

### 核心功能
- **成员管理**：维护成员信息（声部、身高、资深度、带教关系、搭档限制）
- **CSV 导入**：批量导入成员数据，支持中英文表头
- **可视化座位图**：可拖拽调整的座位网格，支持缩放
- **自动排座算法**：按声部、身高、带教关系智能排座
- **约束校验引擎**：自动检查 6 种常见问题：
  - 同声部断层（同一声部被其他声部隔开）
  - 视线遮挡（前排高个子遮挡后排）
  - 带教新人未相邻（新人与带教老师不相邻）
  - 请假成员仍占位（缺席/请假成员被分配座位）
  - 限制搭档相邻（关系不和的成员坐在一起）
  - 首选搭档未相邻（希望坐在一起的成员不相邻）
- **数据持久化**：自动保存到本地 JSON 文件
- **版本历史**：支持版本快照、回滚和标记
- **座位单导出**：支持 TEXT/CSV/JSON 三种格式

### 技术特性
- **跨平台**：支持 macOS、Windows、Linux
- **模块化架构**：按功能分层设计（GUI、数据模型、约束校验、排座算法、持久化、导入导出、测试）
- **PyQt6 界面**：现代化桌面 GUI
- **自动保存**：每分钟自动保存当前状态

## 使用指南

### 1. 导入成员

1. 点击菜单 `文件 -> 导入成员 CSV`
2. 选择包含成员信息的 CSV 文件
3. 成员将自动添加到成员列表

#### CSV 格式示例

```csv
姓名,声部,身高,资深度,状态,备注
张三,S1,165,资深,到场,女高音声部长
李四,S1,160,新人,到场,张三带教
王五,S2,168,中级,到场,
赵六,A1,158,初级,到场,
钱七,T1,175,资深,缺席,
```

#### 支持的表头映射

| 字段 | 支持的表头名称 |
|------|---------------|
| 姓名 | name, 姓名 |
| 声部 | voice_part, voice, part, 声部 |
| 身高 | height, height_cm, 身高 |
| 资深度 | seniority, level, 资深度 |
| 状态 | status, 状态 |
| 备注 | notes, note, 备注 |

#### 声部编码

| 编码 | 全称 |
|------|------|
| S1 | 女高音1 |
| S2 | 女高音2 |
| A1 | 女低音1 |
| A2 | 女低音2 |
| T1 | 男高音1 |
| T2 | 男高音2 |
| B1 | 男低音1 |
| B2 | 男低音2 |

### 2. 配置座位布局

1. 点击菜单 `编辑 -> 布局配置`
2. 设置排数（rows）和列数（cols）
3. 点击确定更新布局

### 3. 自动排座

1. 点击工具栏的 **自动排座** 按钮，或按 `F5`
2. 算法会自动：
   - 按声部分区（女高→女低→男高→男低，从左到右）
   - 后排排更高的成员（避免视线遮挡）
   - 新人与带教老师绑定相邻

### 4. 手动调整

- **拖拽移动**：在座位图上拖拽成员可以调整位置
- **锁定座位**：右键点击座位可以锁定/解锁，锁定的座位不会被自动排座改变
- **清空分配**：点击 `编辑 -> 清空分配` 可以清空所有座位分配（保留锁定座位）

### 5. 约束校验

1. 点击工具栏的 **执行校验** 按钮，或按 `F6`
2. 下方校验面板会显示发现的问题
3. 问题类型：
   - 🔴 **严重**：请假占位、限制搭档
   - 🟡 **警告**：声部断层、视线遮挡、带教未相邻
   - 🔵 **信息**：首选搭档未相邻

### 6. 版本管理

1. **保存版本**：点击 `版本 -> 保存版本` 或版本面板中的保存按钮
2. **标记版本**：在版本列表中选择一个版本，可以添加标签
3. **回滚**：选择一个历史版本，点击「恢复到此版本」
4. **自动保存**：默认开启，每分钟自动保存当前状态

### 7. 导出座位单

1. 点击 `文件 -> 导出座位单`
2. 选择导出格式：
   - **TEXT**：纯文本格式，便于打印
   - **CSV**：表格格式，便于后续编辑
   - **JSON**：完整数据格式

## 核心算法说明

### 自动排座算法

排座算法分为以下步骤：

1. **预处理**
   - 确定可用座位（启用且未锁定）
   - 过滤可排座成员（排除请假/缺席）
   - 保留锁定分配

2. **区域划分**
   - 默认从左到右：女高(SOPRANO) → 女低(ALTO) → 男高(TENOR) → 男低(BASS)
   - 按各声部人数比例分配座位

3. **身高排序**
   - 默认策略：后排更高（back_taller）
   - 座位按「从后往前、从左到右」分配
   - 成员按「从高到低」排序后依次分配

4. **带教绑定**
   - 新人与带教老师绑定
   - 带教在前，新人紧跟其后

### 约束校验规则

| 规则 | 严重程度 | 说明 |
|------|---------|------|
| 请假占位 | 🔴严重 | 缺席/请假成员被分配了座位 |
| 限制搭档 | 🔴严重 | 设置了限制的成员相邻而坐 |
| 声部断层 | 🟡警告 | 同声部成员被其他声部隔开 |
| 视线遮挡 | 🟡警告 | 前排成员比后排高 > 5cm |
| 带教未相邻 | 🟡警告 | 新人与带教老师不相邻 |
| 首选未相邻 | 🔵信息 | 首选搭档不相邻 |

## 开发说明

### 架构设计

项目采用分层架构：

1. **数据模型层 (models/)**：定义核心数据结构
2. **核心逻辑层 (core/)**：约束校验和排座算法
3. **持久化层 (persistence/)**：数据读写和版本管理
4. **导入导出层 (io/)**：CSV 导入和座位单导出
5. **GUI 层 (gui/)**：用户界面组件

### 扩展新约束

在 `constraint_validator.py` 中添加新的检查方法，遵循现有模式：

1. 在 `IssueType` 枚举中添加新类型
2. 在 `ConstraintValidator` 类中添加 `_check_xxx` 方法
3. 在 `validate` 方法中调用新的检查方法
