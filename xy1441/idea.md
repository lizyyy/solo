## 原始点子

我最近在帮小区做“共享冷藏柜取餐”登记，想要一个能本地跑起来的全栈小工具：前端可以给值班员创建当天批次、录入每个格口的餐品和取餐人手机号后四位，生成一次性取餐码；居民来取餐时输入手机号后四位和取餐码，系统要把对应格口标记为已取并记录时间，不能重复取。后台要提供接口和持久化存储，刷新页面后批次、格口状态和取餐记录都还在；还要有一个异常处理页，可以把超时未取的格口批量标为待联系，并支持把当天记录导出成 CSV。请把前后端、数据模型、校验规则、错误提示和 README 运行说明都做好，不要只做静态页面。
