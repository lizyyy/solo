# 样例数据说明

本目录包含管道水锤压力试算系统的三步工作流演示所使用的样例数据文件。

## 文件说明

| 文件名 | 对应工作流步骤 | 说明 |
|--------|----------------|------|
| `nameplate_001.json` | 第一步 | 设备铭牌参数样例，包含管道长度、管径、壁厚等基础参数 |
| `screenshot_001.json` | 第二步 | 维修群截图样例，记录训练教练老唐提供的现场实测数据 |
| `calc_input_001.json` | 第一步/第二步 | 计算输入样例，包含完整的计算参数及人工改系数标记 |

## 工作流步骤

1. **第一步**：使用 `nameplate_001.json` 导入设备铭牌参数，使用 `calc_input_001.json` 执行计算
2. **第二步**：使用 `screenshot_001.json` 导入维修群截图证据，链接到计算参数
3. **第三步**：设备工程师复核并为人工改系数补充原因

详见项目根目录 `README.md`。
