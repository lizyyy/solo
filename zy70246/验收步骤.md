---

### 【验收 4】导入异常公厕点位数据（检验异常检测）

**执行命令：**
```bash
node src/index.js import:toilets samples/toilets-anomalies.json -s "异常测试数据"
```

**预期结果：**
- 导入统计显示：总数 9，新增约 0-1，更新 0，重复约 1 条，无效约 8 条
- **重复数据**：T000001 会被检测为重复
- **无效数据类型**：
  - 公厕编号格式错误（INVALID_ID）
  - 缺失必填字段（district 为空、缺失多个字段）
  - 人流权重超范围（15 > 10）
  - 人流权重非数字（"高"）
  - 时间格式错误（"昨天上午"）
  - 库存为负数（-5）
  - 投诉为负数（-3）

## 🔍 异常类型说明

| 异常类型 | 示例 | 检测方式 |
|---------|------|---------|
| 重复数据 | 同一公厕多次导入 | 对比 ID 和内容 |
| 缺字段 | district 为空、缺失必填字段 | 必填字段校验 |
| 格式错误 | 公厕编号 INVALID_ID、人流权重 "高" | 正则表达式 + 类型检查 |
| 数值越界 | 人流权重 15（应 0-10）、库存 -5 | 范围校验 |
| 时间错误 | lastCleanTime = "昨天上午" | Date 解析校验 |
| 业务预警 | 库存 < 10、超 24 小时未清洁 | 业务规则判断 |

---

## 📊 优先级计算规则

```
优先级分数 = 人流权重 × 10 + 投诉数 × 8 + 库存预警分 + 超时清洁分
```

**优先级等级：**
- 🔴 **紧急 (Critical)**：人流权重 ≥ 7 或 投诉数 ≥ 3
- 🟡 **高 (High)**：人流权重 ≥ 4 或 超 12 小时未清洁 或 库存 < 10
- 🟢 **正常 (Normal)**：以上都不满足
