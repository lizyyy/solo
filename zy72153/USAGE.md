# 海绵城市雨水花园 - 使用说明

## 启动

```bash
npm install
npm run dev
```

浏览器打开终端输出的地址（通常 http://localhost:5173/）。

## 一、导入点位数据

1. 打开「导入台」页面
2. 在「点位数据导入」区域，拖拽 CSV 文件到虚线框内，或点击虚线框选择文件
3. 系统自动解析并显示前 5 条预览，同时提示空值数量
4. 确认无误后点击「确认导入」
5. 导入后系统自动执行归并检测和冲突检测

**CSV 列名对照表：**

| CSV列名 | 字段 | 是否必填 |
|---------|------|---------|
| 路口名称 | name | 是 |
| 行政区划 | district | 是 |
| 经度 | longitude | 否（缺失会标记为空值冲突） |
| 纬度 | latitude | 否（缺失会标记为空值冲突） |
| 投诉编号 | complaintId | 否 |
| 投诉时间 | complaintTime | 否 |
| 审批编号 | approvalRef | 否 |
| 设计容量 | designCapacity | 否（单位 m³） |
| 实际需求 | actualDemand | 否（单位 m³） |
| 施工期 | constructionPeriod | 否（格式：2024-04-01~2024-06-30） |
| 养护期 | maintenancePeriod | 否（格式同上） |

## 二、导入审批台账

1. 在「审批台账导入」区域，拖拽或选择审批台账 CSV 文件
2. 预览确认后点击「确认导入」
3. 导入后系统自动与已有点位数据比对，生成冲突项

**审批台账 CSV 列名对照表：**

| CSV列名 | 字段 |
|---------|------|
| 审批编号 | approvalRef |
| 路口名称 | locationName |
| 行政区划 | district |
| 审批内容 | content |
| 审批状态 | approvalStatus |
| 审批时间 | approvedAt |
| 设计容量 | designCapacity |
| 施工期 | constructionPeriod |
| 养护期 | maintenancePeriod |

## 三、补充照片附件

1. 在「照片附件补充」区域，从下拉列表选择一个点位
2. 选择要上传的照片文件（支持多选）
3. 已关联的照片以缩略图形式展示
4. 点击「上传照片」完成关联

## 四、归并池操作

1. 打开「归并池」页面，查看自动检测到的归并候选组
2. 三种归并类型：
   - **同名路口**：路口名称 + 行政区划相同的记录
   - **重复投诉**：投诉编号相同，或同路口7天内多次投诉
   - **坐标偏移**：同路口坐标差距小于 50 米的记录
3. 点击「展开详情」查看候选组内各条记录
4. 确认归并：点击「确认归并」，第一条记录保留为主记录，其余标记为已归并
5. 取消归并：点击「取消归并」，候选组标记为已取消
6. 可随时点击「重新检测」重新扫描

**溯源保证**：归并后的记录保留来源追溯链，可在归并原因中查看归并依据。

## 五、复核台操作

1. 打开「复核台」页面，查看所有冲突项
2. 每个冲突展示**双方证据**：
   - 左侧：导入数据证据
   - 右侧：审批台账证据
   - 若无审批台账对照，会明确标注
3. **建议动作**以琥珀色醒目提示，不自动替用户决策
4. 可填写处理说明，然后选择：
   - **确认**：接受建议或自行判断后确认
   - **驳回**：不采纳该冲突
   - **暂缓**：留待后续处理
5. 空值和边界记录在页面下方单独展示

**冲突类型说明：**
- 容量超限：实际需求超出设计容量，报告会说明超出多少立方米及调整建议
- 时段冲突：施工期或养护期与审批台账重叠，报告会说明重叠情况及错开建议
- 数据不一致：导入数据与审批台账字段值不匹配
- 空值缺失：必填字段为空
- 边界记录：跨区域或特殊情况

## 六、导出公示清单

1. 打开「公示清单」页面
2. 使用筛选条件缩小范围：
   - 按状态筛选（待处理/已归并/已确认/已驳回）
   - 按行政区划筛选
   - 勾选「存在冲突」只看有冲突的记录
   - 勾选「存在空值」只看有空值的记录
3. 点击「应用筛选」生效，「重置」清除所有筛选
4. 查看跨时段统计和冲突说明
5. 点击表格行展开详细信息（坐标、容量、时段等）
6. 点击「导出公示清单CSV」下载文件

**导出内容包含：**
- 基础字段：路口名称、行政区划、投诉编号、投诉时间、审批编号、经纬度、设计容量、实际需求、施工期、养护期
- **归并原因**：如无归并则显示"无"
- **冲突说明**：所有冲突的自然语言描述，如"容量超限：实际需求130m³，设计容量120m³。超出设计容量10.0m³，建议调整汇水面积或增设调蓄设施"
- **来源追溯**：记录的原始来源

## 数据存储

所有数据存储在浏览器 IndexedDB 中，清除浏览器数据会丢失记录。建议定期导出备份。

## 样例数据

首次打开时自动加载 7 条样例点位和 3 条审批台账记录，包含：
- 同名路口（中山路与解放路交叉口，2条）
- 重复投诉（长安街与复兴路交叉口，同一投诉编号2条）
- 坐标偏移（建设大道与光华路交叉口，偏移约1.5米）
- 空值记录（人民路与民主街交叉口，缺失经纬度和投诉编号）
- 容量超限（中山路口实际需求130m³超设计容量120m³）
- 数据不一致（中山路口导入120m³ vs 审批台账150m³）
- 时段冲突（长安街施工期与审批台账养护期重叠）
