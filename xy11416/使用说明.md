# 物业维修派单多源导入巡检 CLI 使用说明

## 项目概述

这是一个用于物业维修派单多源数据导入和巡检的 CLI 工具，支持：

- 多源数据导入（住户报修、维修师傅回执、材料领用、主管批注）
- 数据去重和事实更新（重复提交只更新同一条事实）
- 数据质量检查和错误追踪
- 人工改判和撤回功能
- 导出前冻结机制
- 完整的审计日志

## 快速开始

### 1. 安装依赖

```bash
npm install
npm run build
```

### 2. 初始化工作目录

```bash
node dist/index.js init my-workspace
```

### 3. 导入数据

```bash
# 导入单个文件
node dist/index.js import 住户报修表.csv

# 批量导入多个文件
node dist/index.js import 住户报修表.csv 维修师傅回执.csv 材料领用表.csv
```

### 4. 检查数据质量

```bash
node dist/index.js check
```

### 5. 生成报告

```bash
node dist/index.js report
```

### 6. 冻结并导出

```bash
# 冻结工单（防止修改）
node dist/index.js fix --freeze WO2024001 --reason "导出前冻结"

# 导出已冻结的工单
node dist/index.js export --frozen-only --include-raw
```

## 完整命令列表

### init - 初始化工作目录

```bash
pmi init [options]

选项:
  -f, --force  强制重新初始化
```

### import - 导入数据文件

```bash
pmi import [options] <files...>

选项:
  -m, --mode <mode>      导入模式: create/update/skip (default: "update")
  -b, --batch <id>       指定批次号
  -o, --operator <name>  操作人 (default: "cli")
  -t, --type <type>      数据源类型: resident_report/technician_receipt/material_usage/supervisor_note
```

### check - 检查数据质量

```bash
pmi check [options]

选项:
  -b, --batch <id>  检查指定批次
  -a, --all         显示所有记录
```

### fix - 修复数据问题

```bash
pmi fix [options]

选项:
  -r, --record <id>       记录ID
  -e, --error <id>        错误ID
  -f, --field <name>      字段名
  -v, --value <value>     新值
  -o, --operator <name>   操作人 (default: "cli")
  --reason <text>         修改原因
  --withdraw <id>         撤回指定记录
  --freeze <order>        冻结指定工单
  --unfreeze <order>      解冻指定工单
```

### report - 生成巡检报告

```bash
pmi report [options]

选项:
  -b, --batch <id>  指定批次
  -d, --detail      显示详细信息
```

### history - 查看导入历史

```bash
pmi history [options]

选项:
  -l, --limit <number>  显示条数 (default: "50")
  -b, --batch <id>      查看指定批次详情
```

### export - 导出数据

```bash
pmi export [options]

选项:
  -f, --format <format>  导出格式: csv/xlsx/json (default: "xlsx")
  -o, --output <path>    输出文件路径
  --frozen-only          仅导出已冻结工单
  --include-raw          包含原始来源信息
```

### show - 查看记录详情

```bash
pmi show <id>
```

## 边界情况处理

### 1. 重复提交

相同工单号的记录会自动关联到同一条事实记录，不会重复创建。导入模式：
- `update`（默认）：更新现有事实
- `skip`：跳过已存在的记录
- `create`：强制创建新记录

### 2. 撤回后再提交

```bash
# 撤回记录
pmi fix --withdraw <记录ID> --reason "数据有误"

# 修正后重新导入
pmi import 修正后的文件.csv
```

### 3. 部分失败

导入时如果部分记录失败，成功的记录会正常导入，失败的记录会被单独列出。可以：
- 修正源文件后重新导入
- 或使用 `pmi fix` 进行人工改判

### 4. 人工改判

```bash
# 修改单条记录的字段
pmi fix --record <记录ID> --field residentName --value "张三" --reason "姓名更正"

# 标记错误为已解决
pmi fix --error <错误ID> --reason "已核实数据正确"
```

### 5. 导出前冻结

```bash
# 冻结工单（冻结后无法修改）
pmi fix --freeze WO2024001 --reason "导出前冻结"

# 仅导出已冻结的工单
pmi export --frozen-only
```

## 数据模型

- **raw_records**: 原始记录，保留来源文件、行号、原始内容
- **standardized_records**: 标准化后的业务数据
- **fact_records**: 事实记录（按工单号去重）
- **validation_errors**: 验证错误详情
- **import_sessions**: 导入会话记录
- **change_logs**: 变更审计日志
