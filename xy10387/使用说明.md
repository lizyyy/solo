## 二、角色分工与操作流程

### 👨‍💼 业务员/门店督导

**负责：** 提交陈列记录、检查返利资格

**操作时间：** 活动期内，陈列完成后3天内

**操作步骤：**

1. **提交陈列申报**
   - 进入「📝 提交陈列」页面
   - 选择门店、选择活动
   - 填写照片数量（上传了几张就填几张）
   - 点击「🔍 先检查资格」看看能不能通过
   - 没问题就点「🚀 提交申报」

2. **遇到拦截怎么办？**
   - 红色提示会告诉你原因
   - 常见拦截及处理：

| 拦截提示 | 看哪里 | 怎么处理 |
|---------|--------|---------|
| 不在活动期内 | 活动时间 | 看活动起止日期，过期了就等下次活动 |
| 进货量不足 | 「📦 进货核对」页 | 先去录入进货记录，或确认门店实际进货量 |
| 照片数量不足 | 返利规则 | 补拍照片，达到最低要求（一般3-5张） |
| 该门店已申报过此活动 | 「📋 记录查询」页 | 同一门店同一活动只能申报一次，别重复 |

---

### 👩‍💻 审核员

**负责：** 照片审核、进货核对、整体审核

**操作时间：** 收到申报后2个工作日内

**操作步骤：**

1. **进入「✅ 审核管理」页**
2. **看清楚每一项：**
   - 照片数：对比要求数量，✓是达标，✗是不够
   - 进货量：对比要求数量，✓是达标，✗是不够

3. **审核照片：**
   - 照片没问题 → 点「照片通过」
   - 照片模糊/不符合要求 → 点「照片不通过」，输入原因

4. **整体审核：**
   - 照片达标 + 进货达标 → 点「审核通过」
   - 任何一项不达标 → 点「审核不通过」，输入原因

5. **确认无误后结算：**
   - 点「结算」按钮
   - ⚠️ 结算后就不能改了，想清楚再点

---

### 💼 财务/数据录入员

**负责：** 录入进货记录、导出结算表

**操作时间：** 门店进货后及时录入；活动结束后导出

**录入进货：**
1. 进入「📦 进货核对」页
2. 选门店、选活动、填进货数量
3. 点「➕ 添加进货记录」

**导出结算表：**
1. 进入「📥 导出结算」页
2. 确认所有记录都审核完了
3. 点「📥 导出结算表」
4. 下载Excel文件，发给品牌方核对

**导出表包含什么？**
- 门店信息（编号、名称、联系人、电话）
- 品牌和活动信息
- 进货量、照片数（及要求的最低值）
- 审核状态、返利金额
- 通过原因 / 不通过原因
- 是否已结算

## 三、样例演示（快速上手）

进入「🎯 样例演示」页，点击「🎬 运行样例」看看系统怎么拦截：

### ✅ 样例1：正常返利
- 门店：ST001 旺旺烟酒超市
- 进货量：35条（达标）
- 照片数：5张（达标）
- **结果：** 通过，返利1200元

### ❌ 样例2：照片缺失
- 进货量达标，但只传了1张照片
- **拦截原因：** 照片数量不足（至少3张）
- **处理：** 让门店补拍到3张以上

### ❌ 样例3：进货不足
- 照片数达标，但只进货8条
- **拦截原因：** 进货量不足（至少10条）
- **处理：** 确认进货记录，或等门店补进货

### ❌ 样例4：重复申报
- 同一门店同一活动已申报过
- **拦截原因：** 该门店已申报过此活动
- **处理：** 去「记录查询」看看已有记录

## 四、系统自动拦截规则（不用记，系统会提示）

| 拦截类型 | 什么情况触发 | 看提示怎么说 |
|---------|-------------|-------------|
| 活动期外 | 申报日期不在活动起止时间内 | "不在活动期内" |
| 进货不足 | 进货量 < 规则要求的最低进货量 | "进货量不足（当前X，最低要求Y）" |
| 照片不够 | 照片数 < 规则要求的最低照片数 | "照片数量不足（当前X，最低要求Y）" |
| 重复申报 | 同一门店同一活动已经申报过 | "该门店已申报过此活动" |
| 已结算修改 | 想改已经结算的记录 | "已结算记录无法修改" |

## 五、数据存在哪里？

所有数据都存在 `data/` 目录下的JSON文件里：

| 文件名 | 存什么 |
|-------|-------|
| stores.json | 门店信息 |
| brands.json | 品牌信息 |
| activities.json | 活动信息 |
| rebateRules.json | 返利规则 |
| displayTasks.json | 陈列任务 |
| stocks.json | 进货记录 |
| displayRecords.json | 申报记录 |

**⚠️ 重要：** 不要手动修改这些JSON文件，改坏了数据就丢了。

## 六、常见问题

**Q1：申报时显示"进货量不足"怎么办？**
A：先去「进货核对」页看看进货记录录了没有。没录就先录，录了但不够就让门店补进货。

**Q2：照片要求几张？**
A：看「返利试算」页的规则，一般活动要求3-5张。多拍几张没坏处，多的可以选更清楚的。

**Q3：结算了还能改吗？**
A：不能。结算前一定要确认清楚，结算后系统会锁死，改不了。

**Q4：同一个门店能参加多个活动吗？**
A：可以。每个活动单独申报，互不影响。

**Q5：返利金额怎么算的？**
A：系统自动匹配最高档的规则。比如同时满足基础档和进阶档，按进阶档的更高返利算。
