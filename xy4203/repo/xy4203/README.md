# 修复前后影像比对台 - 古籍修复质量管控系统

## 项目简介

**修复前后影像比对台**是一款专为图书馆古籍修复员设计的本地桌面GUI应用程序，用于对古籍修复质量进行智能检测和人工复核。

该系统针对古籍修复过程中常见的三大问题：
- **页码串错**：修复前后图像页码不对应
- **局部补纸面积漏算**：缺损标注面积与实际修复面积不匹配
- **色差变化太大未记录**：修复材料与原纸张颜色差异明显

通过计算机视觉技术自动检测这些问题，并提供人工圈选复核功能，最终生成可导出的复核单、问题清单和审计包。

## 功能特性

### 1. 图像查看功能
- **并排显示**：修复前后图像左右并列显示，方便对比
- **叠加显示**：两张图像半透明叠加，直观观察变化
- **差异图**：使用伪彩色显示像素差异，突出变化区域
- **缩放平移**：支持鼠标滚轮缩放、中键平移
- **适应窗口**：一键适应窗口大小

### 2. 自动分析功能
- **页码一致性检查**：
  - 检测页码缺失、重复、逆序
  - 检查图像、标注、材料记录之间的页码对应关系
  - 从文件名自动提取页码

- **缺损区域分析**：
  - 自动检测修复前后的缺损区域
  - 计算缺损面积变化
  - 比对标注面积与实际检测面积

- **色差分析**：
  - 使用CIEDE2000色差值进行专业评估
  - 分析亮度(L*)、饱和度(Chroma)变化
  - 检测局部颜色异常区域

- **材料记录匹配**：
  - 检查材料使用面积与缺损标注面积是否匹配
  - 验证修复材料记录的完整性

### 3. 人工圈选复核功能
- **多种标注工具**：
  - 矩形标注：用于规则形状的缺损
  - 椭圆标注：用于圆形/椭圆形缺损
  - 多边形标注：用于不规则形状的缺损
  - 自由绘制：用于复杂边界的缺损
  - 选择工具：用于编辑已有标注

- **标注属性管理**：
  - 标签分类：缺损、补纸、色差、污渍、褶皱、其他
  - 面积自动计算
  - 位置坐标显示
  - 描述备注

- **复核记录**：
  - 复核状态：未开始、复核中、已通过、需注意、需重新检查
  - 复核人信息
  - 复核日期时间
  - 复核备注

### 4. 数据导出功能
- **Markdown复核单**：
  - 项目概述
  - 问题统计和详情
  - 复核记录汇总
  - 数据来源说明
  - 智能复查建议

- **CSV问题清单**：
  - 问题类型、严重程度
  - 涉及页码
  - 问题描述
  - 检测时间
  - 是否已复核

- **JSON审计包**：
  - 完整项目数据
  - 详细统计信息
  - 所有问题列表
  - 复核记录详情
  - 人工标注数据
  - 数据来源信息

## 快速开始

### 1. 启动程序

```bash
python main.py
```

### 2. 使用示例数据进行验证

#### 步骤1：生成示例数据

打开Python交互模式或创建测试脚本：

```python
from sample_data import create_sample_data

# 生成示例数据到指定目录
result = create_sample_data("/path/to/sample_output")
print(result)
```

这将生成：
- 3对修复前后图像（page_001_before/after.jpg 等）
- 病害标注CSV（defect_annotations.csv）
- 材料记录CSV（material_records.csv）

#### 步骤2：创建新项目

1. 点击工具栏 **"新建"** 按钮
2. 输入项目名称，如"测试项目"
3. 点击 **"确定"**

#### 步骤3：导入数据

1. 点击工具栏 **"导入图像"**
2. 依次选择3张修复前图像（page_001_before.jpg 等）
3. 再依次选择对应的3张修复后图像（page_001_after.jpg 等）
4. 点击工具栏 **"导入CSV"**
5. 选择病害标注CSV文件
6. 选择材料记录CSV文件

#### 步骤4：运行自动分析

点击工具栏 **"运行分析"** 按钮，系统将自动执行：
- 页码一致性检查
- 缺损区域分析
- 色差变化分析
- 材料记录匹配检查

#### 步骤5：查看分析结果

分析完成后，可以在界面上查看：
- **左侧问题列表**：显示所有检测到的问题，按类型和严重程度分类
- **右侧分析结果**：详细的统计信息和问题描述
- **中间图像查看区**：并排/叠加/差异图查看

#### 步骤6：人工圈选复核

1. 使用标注工具在图像上圈选需要复核的区域
2. 选择预设标签或输入自定义标签
3. 在右侧属性面板填写描述
4. 设置复核状态（已通过/需注意/需重新检查）
5. 输入复核人姓名
6. 点击 **"保存复核记录"**

#### 步骤7：导出结果

点击工具栏 **"导出"** 按钮，选择导出格式：

**1. 复核单 (Markdown)**
- 生成完整的复核报告
- 可直接查看或转换为PDF
- 包含所有问题和复核记录

**2. 问题清单 (CSV)**
- 表格形式的问题列表
- 方便导入Excel或其他系统
- 便于汇总分析

**3. 审计包 (JSON)**
- 完整的结构化数据
- 包含所有项目信息、标注、问题
- 适用于数据存档和后续分析

## 详细验证流程

### 验证场景1：页码串错检测

**测试目的**：验证系统是否能检测页码缺失、重复、不匹配等问题

**测试步骤**：
1. 创建新项目
2. 导入图像时故意跳过第2页（只导入1、3页）
3. 或导入有重复页码的图像
4. 导入包含完整页码序列的CSV
5. 运行分析
6. 查看问题列表

**预期结果**：
- 检测到页码缺失（如"页码1和3之间缺失页码: [2]"）
- 或检测到重复页码（如"页码2出现重复"）
- 或检测到图像与标注页码不匹配

### 验证场景2：面积漏算检测

**测试目的**：验证系统是否能检测标注面积与实际不匹配的问题

**测试步骤**：
1. 创建项目并导入示例数据
2. 查看自动分析结果
3. 或在CSV中故意修改缺损面积（如将2500改为500）
4. 重新导入CSV并运行分析

**预期结果**：
- 检测到"标注面积与实际检测面积差异过大"的问题
- 显示标注面积、检测面积、差异百分比
- 根据差异大小标记严重程度（20%以上为中等，50%以上为高）

### 验证场景3：色差异常检测

**测试目的**：验证系统是否能检测修复材料与原纸张的颜色差异

**测试步骤**：
1. 使用示例数据（第2页设计了明显色差）
2. 运行颜色分析
3. 查看分析结果

**预期结果**：
- 检测到"全局颜色偏移"或"局部颜色异常"
- 显示CIEDE2000色差值（ΔE）
- ΔE > 5 为可感知差异
- ΔE > 8 为警告级别
- ΔE > 12 为严重级别

### 验证场景4：人工圈选功能

**测试目的**：验证人工圈选标注的完整性

**测试步骤**：
1. 打开某一页的图像
2. 使用矩形工具圈选一个区域
3. 选择标签为"缺损"
4. 使用椭圆工具圈选另一个区域
5. 在属性面板填写描述
6. 检查自动计算的面积
7. 切换到下一页再切换回来，验证标注是否保存

**预期结果**：
- 标注正常显示在图像上
- 标签和描述正确保存
- 面积自动计算（矩形：宽×高，椭圆：π×r1×r2）
- 切换页面后标注仍然存在
- 导出时包含所有标注信息

### 验证场景5：导出功能

**测试目的**：验证三种导出格式的正确性

**测试步骤**：
1. 创建包含问题和复核记录的项目

3. 检查导出文件

**预期结果**：

**Markdown文件**：

- 每个问题有序号、类型、严重程度、页码、描述

## 配置说明

### 阈值配置

各模块的检测阈值可在源码中调整：

**页码检查** (`rule_engine/page_checker.py`)：
- `max_gap_size = 2`：允许的最大连续缺失页数

**面积计算** (`rule_engine/area_calculator.py`)：
- `area_tolerance_percent = 20.0`：面积差异容忍百分比
- `min_repair_area = 100`：最小修复面积（像素）
- `overlap_threshold = 0.5`：重叠判定阈值（IOU）

**色差检测** (`rule_engine/color_checker.py`)：
- `delta_e_threshold = 5.0`：可感知色差阈值
- `delta_e_warning = 8.0`：警告级阈值
- `delta_e_critical = 12.0`：严重级阈值
- `luminance_threshold = 15.0`：亮度变化阈值
- `chroma_threshold = 12.0`：饱和度变化阈值
- `min_anomaly_area = 500`：最小异常区域面积

### 图像格式支持

支持的图像格式：
- JPEG (.jpg, .jpeg)
- PNG (.png)
- BMP (.bmp)
- TIFF (.tif, .tiff)

支持的CSV格式：
- UTF-8编码（推荐）
- GBK编码（自动检测）
- 逗号分隔（默认）
- 制表符分隔（自动检测）
- 分号分隔（自动检测）

## 故障排除

### 问题1：程序启动失败

**症状**：运行main.py时出现错误

**可能原因**：
1. 依赖包未安装
2. Python版本过低
3. Tkinter不可用

**解决方法**：
```bash
# 检查Python版本
python --version

# 重新安装依赖
pip install -r requirements.txt

# 检查Tkinter（通常随Python一起安装）
python -c "import tkinter; print(tkinter.TkVersion)"
```

### 问题2：图像无法加载

**症状**：导入图像后显示空白

**可能原因**：
1. 图像路径包含非ASCII字符
2. 图像格式不支持
3. 图像文件损坏

**解决方法**：
1. 确保图像路径只包含英文字符
2. 转换图像为JPEG或PNG格式
3. 用其他图像查看器验证图像是否正常

### 问题3：CSV解析失败

**症状**：导入CSV后没有数据

**可能原因**：
1. 编码问题
2. 分隔符不匹配
3. 字段名不匹配

**解决方法**：
1. 用文本编辑器打开CSV，检查编码（建议UTF-8）
2. 检查分隔符是逗号、制表符还是分号
3. 确保CSV包含必要字段（详见下文"CSV格式说明"）

### 问题4：分析结果为空

**症状**：运行分析后没有检测到任何问题

**可能原因**：
1. 数据不完整（缺少图像或CSV）
2. 图像过于相似
3. 阈值设置过高

**解决方法**：
1. 确认已导入修复前后图像和CSV
2. 检查图像是否真的存在差异
3. 可在源码中降低阈值进行测试

## CSV格式说明

### 病害标注CSV格式

**必填字段**：
- `id`：标注唯一标识
- `page_number`：页码
- `defect_type`：病害类型（孔洞、污渍、褶皱、残缺、褪色等）
- `position_x`：中心X坐标
- `position_y`：中心Y坐标
- `width`：宽度
- `height`：高度
- `area`：面积
- `severity`：严重程度（高、中、低）
- `description`：描述
- `repair_status`：修复状态（完全修复、部分修复、未修复）
- `material_used`：使用材料

**示例**：
```csv
id,page_number,defect_type,position_x,position_y,width,height,area,severity,description,repair_status,material_used
defect_001_1,1,孔洞,200,300,50,50,2500,高,边缘破损,部分修复,宣纸
defect_001_2,1,污渍,400,500,60,40,2400,中,墨水渍,完全修复,
```

### 材料记录CSV格式

**必填字段**：
- `id`：记录唯一标识
- `page_number`：页码
- `material_type`：材料类型（补纸、浆糊、染料等）
- `material_name`：材料名称
- `quantity`：数量
- `unit`：单位（张、克、毫升等）
- `usage_area`：使用面积
- `application_date`：使用日期
- `technician`：修复师
- `notes`：备注

**示例**：
```csv
id,page_number,material_type,material_name,quantity,unit,usage_area,application_date,technician,notes
mat_001_1,1,补纸,宣纸,1,张,3000,2024-01-15,张修复师,第1页补纸
mat_001_2,2,补纸,皮纸,2,张,5000,2024-01-15,李修复师,大面积修复
```

## 技术架构

### 核心技术栈

- **GUI框架**：Tkinter（Python标准库，跨平台）

```

CSV文件    数据校验     图像处理    状态记录    文件生成
```
