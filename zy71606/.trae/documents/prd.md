## 1. 产品概述

融资保证金追加通知系统——面向期货客服与业务同事，将行情波动、客户风险率、已发通知合在一起看，支持批量导入多源数据、幂等催缴通知、入金自动抵扣、状态回看与报告导出。核心目标：让催保证金这件事从"靠人盯"变成"系统跑"，异常可读、操作可靠、结果可追溯。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 客服专员 | 账号密码登录 | 查看风险总览、发送/撤回通知、录入入金、导出报告 |
| 业务主管 | 账号密码登录 | 全部客服权限 + 审核通知、查看催缴报告、管理导入规则 |

### 2.2 功能模块

1. **风险总览页**: 风险率看板、客户列表、行情快照、待催缴队列
2. **通知管理页**: 通知起草/发送/撤回、通知历史、幂等检查
3. **数据导入页**: 多文件批量导入（持仓/行情/入金/通知记录）、校验结果展示
4. **入金流水页**: 入金记录、自动抵扣匹配、未匹配异常
5. **催缴报告页**: 报告生成/导出、筛选导出、历史回看

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 风险总览 | 风险率看板 | 展示全量客户风险率分布（安全/预警/追保/强平），点击区域筛选对应客户 |
| 风险总览 | 行情快照面板 | 右侧嵌入实时行情，标注数据时点，与风险率同屏 |
| 风险总览 | 待催缴队列 | 按风险率排序，显示客户名/合约/风险率/已发通知数，一键勾选发起通知 |
| 风险总览 | 客户列表 | 可搜索/筛选的客户表，展示持仓、保证金、风险率、最近通知状态 |
| 通知管理 | 通知起草 | 预填客户信息和保证金缺口，支持编辑，保存草稿/发送 |
| 通知管理 | 通知历史 | 时间线展示，筛选（按客户/状态/日期），可撤回未确认通知 |

| 催缴报告 | 历史回看 | 保留每次报告快照，可回看任意历史版本 |

## 3. 核心流程

### 3.1 日常催缴主流程

客服登录 → 查看风险总览（行情+风险率+待催队列同屏）→ 勾选待催客户 → 系统检查幂等（同日同客户是否已发）→ 起草通知（预填缺口）→ 保存草稿/发送 → 客户入金 → 系统自动匹配抵扣 → 更新风险率 → 生成催缴报告

```mermaid
flowchart TD
    "登录系统" --> "查看风险总览"
    "查看风险总览" --> "行情+风险率+通知同屏"
    "行情+风险率+通知同屏" --> "勾选待催客户"
    "勾选待催客户" --> "幂等检查"
    "幂等检查" -->|"重复"| "提示已发通知"
    "幂等检查" -->|"通过"| "起草通知"
    "起草通知" --> "保存草稿"
    "起草通知" --> "发送通知"
    "发送通知" --> "客户入金"
    "客户入金" --> "自动匹配抵扣"
    "自动匹配抵扣" --> "更新风险率"
    "更新风险率" --> "生成催缴报告"
```

### 3.2 数据导入流程

上传多文件 → 逐文件解析 → 逐行校验（类型/格式/业务规则）→ 错误汇总（来源文件+行号+可读原因）→ 增量合并（保留旧数据，标记新版本）→ 更新风险率

```mermaid
flowchart TD
    "上传多个文件" --> "逐文件解析"
    "逐文件解析" --> "逐行校验"
    "逐行校验" -->|"校验通过"| "增量合并"
    "逐行校验" -->|"校验失败"| "错误汇总"
    "错误汇总" --> "展示来源文件+行号+原因"
    "增量合并" --> "标记数据来源和版本"
    "标记数据来源和版本" --> "更新风险率"
```

### 3.3 入金匹配流程

入金记录导入 → 查找该客户未结清催缴通知 → 按金额/时间自动匹配 → 匹配成功：更新通知状态为"部分抵扣/已结清" → 匹配失败：标记"未匹配"，提示可能原因

```mermaid
flowchart TD
    "入金记录导入" --> "查找客户未结清通知"
    "查找客户未结清通知" --> "按金额和时间匹配"
    "按金额和时间匹配" -->|"匹配成功"| "更新通知状态"
    "按金额和时间匹配" -->|"匹配失败"| "标记未匹配异常"
    "标记未匹配异常" --> "提示可能原因"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色**: 深蓝灰 (#1a2332) 搭配金融橙 (#e8883a) 作为警示/操作色
- **辅色**: 安全绿 (#22c55e)、预警黄 (#eab308)、追保红 (#ef4444)
- **按钮风格**: 圆角 6px，主操作实心填充，次操作描边，危险操作红色
- **字体**: 标题用 DM Sans（现代、可读），正文用 Noto Sans SC（中文友好）
- **布局**: 左侧固定导航栏 + 右侧内容区，内容区顶部固定筛选条
- **图标**: Lucide 线性图标
- **风格**: 金融仪表盘风格，深色主题为主，数据密度适中，关键数字突出

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|

### 4.3 响应式

- 桌面优先设计，最小支持 1280px 宽度
- 平板（768-1279px）隐藏右侧面板，改为抽屉展开
- 移动端仅支持基础查看，不提供导入和报告导出

### 4.4 设计原则

- **按钮最少化**: 每个页面核心操作不超过 3 个按钮，次要操作收入"更多"下拉
- **三大可靠操作**: 保存（草稿自动保存+手动保存）、撤回（可回退+可查看撤回原因）、历史（全量时间线+快照回看）
- **异常可读**: 所有错误信息使用业务语言（如"客户张三 5月28日已发送追保通知"而非"duplicate key error"）
