## 1. 产品概述

仓储机器人路径云——面向物流技术团队的 3D 仓库路径复盘平台。在三维仓库场景中回放机器人轨迹、叠加拥堵热力与低电量区域，自动检出路径穿架、电量突降、任务时间错位等异常，确保坏数据可追溯、处理决策可审计。

- 核心用户：物流技术团队工程师、仓库运营分析师
- 核心价值：将分散的轨迹/货架/任务数据统一到 3D 可视空间，快速定位拥堵根因、绕路浪费和电量风险，避免异常数据被静默吞掉

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 工程师 | 免登录 | 查看 3D 场景、筛选任务、导出异常清单 |
| 管理员 | 免登录 | 除上述外，可确认/驳回待确认项、修改审计标注 |

### 2.2 功能模块

1. **3D 路径云主视图**：三维仓库场景 + 轨迹云渲染 + 拥堵热力叠加 + 低电量区域标记 + 货架布局
2. **侧边数据面板**：任务明细表、异常清单、待确认队列、数据溯源卡片、审计日志

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 3D 路径云主视图 | 三维仓库场景 | 渲染货架网格、地面标记、区域编号；支持旋转/缩放/平移 |
| 3D 路径云主视图 | 轨迹云渲染 | 按机器人 ID 着色渲染轨迹线，支持回放动画与进度拖拽 |
| 3D 路径云主视图 | 拥堵热力图 | 在地面网格叠加热力颜色，红=高拥堵、蓝=畅通，支持阈值滑杆 |
| 3D 路径云主视图 | 低电量区域标记 | 电量低于阈值的轨迹段高亮，机器人位置显示电量气泡 |
| 3D 路径云主视图 | 路径穿架检测 | 轨迹穿越货架时自动标红并在 3D 中弹出警示 |
| 侧边数据面板 | 任务筛选器 | 按状态（正常/补录/撤回/重复提交）筛选，支持时间范围、机器人 ID |
| 侧边数据面板 | 任务明细表 | 展示筛选后的任务记录，缺字段行高亮，点击可跳转 3D 定位 |
| 侧边数据面板 | 异常清单 | 路径穿架、电量突降、时间错位分标签列出，不混入正常明细 |
| 侧边数据面板 | 待确认队列 | 系统自动检出的异常项进入待确认，管理员可确认/驳回 |
| 侧边数据面板 | 数据溯源卡片 | 每条异常显示来源文件、原始行号、触发材料，坏数据不吞掉 |
| 侧边数据面板 | 审计日志 | 记录所有人工确认/驳回/备注操作，含时间戳与操作人 |
| 3D 路径云主视图 | 参数同步 | 侧边栏参数变更（热力阈值、电量阈值、时间窗口）实时反映到 3D 场景 |

## 3. 核心流程

用户打开页面 → 加载样例数据（轨迹 + 货架 + 任务）→ 数据清洗引擎检出异常 → 正常数据进入 3D 渲染 + 明细表 → 异常数据进入待确认队列 + 异常清单 → 管理员审核待确认项（确认/驳回/备注）→ 审计日志记录 → 参数调整实时同步 3D 与侧边栏

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝黑底（#0a0e1a）+ 霓虹青（#00f0ff）作为科技感强调色 + 琥珀橙（#ff8c00）作为警告色
- **按钮风格**：微圆角（4px）、描边按钮为主、悬停时发光效果
- **字体**：显示字体 JetBrains Mono（等宽数据风）、正文 Noto Sans SC
- **布局风格**：左侧大画布 3D 视口 + 右侧可折叠数据面板
- **图标风格**：Lucide 图标，2px 描边，与等宽字体呼应

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 3D 路径云主视图 | 三维场景画布 | 全屏 Canvas、轨道控制器、暗色天空盒、网格地面 |
| 3D 路径云主视图 | 轨迹云 | 渐变色管线、回放进度条、机器人 ID 图例 |
| 3D 路径云主视图 | 热力叠加层 | 地面半透明色块、阈值滑杆控件、色标图例 |
| 3D 路径云主视图 | 低电量标记 | 黄色→红色渐变气泡、电量百分比浮标 |
| 3D 路径云主视图 | 穿架警示 | 红色闪烁线段、弹出警示卡片 |
| 侧边数据面板 | 筛选器 | 下拉菜单、时间范围选择器、状态标签组 |
| 侧边数据面板 | 明细表 | 紧凑行高表格、缺字段行黄色底纹、行点击高亮对应 3D 段 |

### 4.3 响应式策略

- 桌面优先：3D 视口占 70% 宽度，侧边栏 30%
- 平板：侧边栏可折叠为抽屉，3D 视口全宽
- 手机：不支持 3D 交互，仅展示数据面板精简版

### 4.4 3D 场景指引

- **环境**：暗色工业风仓库，微弱环境光 + 顶部日光灯阵列
- **灯光**：AmbientLight 微弱 + 顶部多个 RectAreaLight 模拟日光灯 + 轨迹自带发光
- **相机**：透视相机，45° 俯角默认，可自由轨道旋转，远裁面 2000
- **构图焦点**：仓库中心偏上，轨迹汇聚区域为视觉焦点
- **交互**：OrbitControls 旋转缩放、Raycaster 点击选中轨迹段/货架
- **动画**：轨迹回放动画（沿路径移动的发光点）、热力图渐变呼吸效果
- **后处理**：Bloom 发光效果让轨迹和标记更突出
- **性能预算**：目标 60fps，轨迹点 ≤ 10000，热力网格 ≤ 50×50

## 5. 数据分叉场景覆盖

| 场景 | 处理方式 |
|------|----------|
| 正常记录 | 直接进入 3D 渲染与明细表 |
| 缺字段记录 | 标黄进入明细表，缺字段列显示「缺失」，同步进异常清单 |
| 晚补记录 | 状态标记为「补录」，补录时间与原始时间均显示 |
| 备注改过 | 审计日志记录修改前后值，备注列显示最新值+修改标记 |
| 撤回记录 | 状态标记为「撤回」，3D 中灰色虚线渲染 |
| 重复提交 | 自动去重，保留最新版本，旧版本进入审计日志 |
| 路径穿架 | 进入异常清单「穿架」标签，3D 中红色闪烁 |
| 电量突降 | 进入异常清单「电量」标签，3D 中橙色气泡 |
| 任务时间错位 | 进入异常清单「时序」标签，时间线标注偏差 |
