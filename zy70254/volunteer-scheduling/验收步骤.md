# 公益课堂助教排班台 - 验收步骤

## 一、启动项目

### 方式 A：命令行启动（推荐开发者）

```bash
# 1. 进入项目目录
cd volunteer-scheduling

# 2. 安装依赖（首次运行需要）
npm install

# 3. 启动开发服务器
npm run dev
```

看到类似输出后，在浏览器中访问显示的地址（通常是 `http://localhost:5173/`）：

```
  VITE v8.0.12  ready in xxx ms

  ➜  Local:   http://localhost:5173/
  ➜  Network: use --host to expose
```

### 方式 B：构建后访问（可选）

```bash
# 1. 构建生产版本
npm run build

# 2. 预览构建结果
npm run preview
```

## 二、验收步骤

### 步骤 1：总览页面检查

**目标：** 确认首页数据展示正常

**操作：**
1. 打开浏览器访问应用
2. 观察「总览」页面
3. 确认显示：
   - ✅ 顶部有「总览」「助教档案」「校区约束」「课程管理」「排班管理」5个标签页
   - ✅ 显示统计卡片：助教总数、校区数量、课程数量、总排班时长
   - ✅ 显示各学科时长分布图表
   - ✅ 显示各校区时长分布图表
   - ✅ 显示排班状态统计（待确认、已确认等）
   - ✅ 顶部有「刷新」和「重置数据」按钮

**验证：** 确认页面无空白区域，所有卡片有数据显示

---

### 步骤 2：助教档案功能检查

**目标：** 验证助教档案的列表、详情、新增、筛选、导出功能

**操作：**

**2.1 查看列表**
- 点击顶部「助教档案」标签
- 确认显示：
  - ✅ 搜索框（支持按姓名或手机号搜索）
  - ✅ 筛选下拉框（状态、学科、校区）
  - ✅ 表格列：姓名、手机号、擅长学科、服务校区、志愿时长、状态、操作
  - ✅ 操作列有：详情、编辑、删除按钮

**2.2 查看详情**
- 点击某位助教（如「张小明」）的「详情」按钮（眼睛图标）
- 确认显示：
  - ✅ 助教基本信息（姓名、手机号、邮箱）
  - ✅ 擅长学科列表
  - ✅ 可服务校区
  - ✅ 历史排班记录
- 点击弹窗右上角「×」关闭

**2.3 新增助教**
- 点击「新建助教」按钮
- 填写以下测试数据：
  - 姓名：测试助教
  - 手机号：13800001111
  - 邮箱：test@example.com
  - 擅长学科：勾选「数学」和「英语」
  - 志愿时长：20
  - 可服务校区：勾选「阳光小学」
- 点击「保存」
- **验证：** 列表中新增了「测试助教」一条记录

**2.4 筛选和搜索**
- 在搜索框输入「张」，确认只显示含「张」的助教
- 清空搜索框
- 在学科筛选中选择「编程」，确认只显示擅长编程的助教
- 清空所有筛选

**2.5 导出**
- 点击「导出」按钮
- **验证：** 自动下载一个 CSV 文件（文件名类似 `助教档案_2024-xx-xx.csv`）

---

### 步骤 3：校区约束检查

**目标：** 验证校区数据，理解校区是排班的重要约束条件

**操作：**
1. 点击顶部「校区约束」标签
2. 观察列表，确认显示 3 个校区：
   - ✅ 阳光小学（主校区，活跃）
   - ✅ 春华中学校区（活跃）
   - ✅ 社区活动中心（停用）
3. 点击某校区的「详情」按钮
4. **验证：** 详情中显示：
   - 校区名称和地址
   - 联系人和电话
   - 该校区的课程列表
5. 关闭弹窗

---

### 步骤 4：排班校验核心功能检查 🔥

**目标：** 验证排班的三大校验规则：学科匹配、校区匹配、时间冲突

**前置条件：** 先点击「课程管理」标签，确认存在 5 门课程

**操作：**

**4.1 新建排班 - 正常情况**
1. 点击「排班管理」标签
2. 点击「新建排班」按钮
3. 填写数据：
   - 课程：小学数学启蒙（阳光小学）
   - 助教：张小明（擅长数学，服务阳光小学）
   - 日期：明天的日期（如 2024-06-16）
   - 开始时间：14:00
   - 结束时间：15:30
4. 点击「保存」
5. **验证：** 保存成功，列表新增一条排班，状态为「待确认」

**4.2 学科不匹配校验**
1. 点击「新建排班」
2. 选择：
   - 课程：少儿编程入门（需要编程学科）
   - 助教：李华（擅长语文、英语，**不擅长编程**）
3. 点击「保存」
4. **验证：** 显示错误提示「该助教不擅长此课程的学科，无法排班」

**4.3 校区不匹配校验**
1. 点击「新建排班」
2. 选择：
   - 课程：中学数学培优（春华中学校区）
   - 助教：张小明（服务校区是阳光小学，**不服务春华中学**）
3. 点击「保存」
4. **验证：** 显示错误提示「该助教不服务此课程所在的校区，无法排班」

**4.4 时间冲突校验**
1. 先创建一条排班：
   - 课程：小学数学启蒙
   - 助教：张小明
   - 日期：2024-06-20
   - 时间：10:00 - 11:30
   - 保存成功
2. 再新建另一条排班：
   - 课程：小学数学进阶
   - 助教：张小明
   - 日期：2024-06-20（同一天）
   - 时间：11:00 - 12:00（与上一条时间重叠）
3. 点击「保存」
4. **验证：** 显示错误提示「该助教此时间段已有排班，存在时间冲突」

---

### 步骤 5：状态推进功能检查

**目标：** 验证排班状态流转

**操作：**
1. 在「排班管理」列表中找到刚才创建的「待确认」状态排班
2. 点击「确认排班」按钮（绿色对勾图标）
3. **验证：** 状态变为「已确认」
4. 点击「开始上课」按钮（播放图标）
5. **验证：** 状态变为「进行中」
6. 点击「完成课程」按钮（对勾图标）
7. **验证：** 状态变为「已完成」

---

### 步骤 6：缺席改派流程检查 🔥

**目标：** 验证临时缺席和改派功能

**操作：**

**6.1 标记缺席**
1. 找到一条状态为「待确认」或「已确认」的排班
2. 点击操作列的「标记缺席」按钮（红色叉号图标）
3. 在弹窗中填写缺席原因："有事请假"
4. 点击「确认缺席」
5. **验证：**
   - 排班状态变为「需改派」（橙色背景）
   - 表格中显示缺席原因提示

**6.2 改派助教**
1. 点击「需改派」排班的「改派助教」按钮（刷新图标）
2. 观察弹窗中的「可选助教」列表
3. **验证：** 列表只显示：
   - 擅长该课程学科的助教
   - 服务该课程所在校区的助教
   - 该时间段没有冲突的助教
4. 选择另一位可用的助教
5. 点击「确认改派」
6. **验证：**
   - 原排班状态变为「已取消」
   - 新增一条排班，状态为「待确认」，助教是新选择的人
   - 原排班显示关联的新排班 ID

---

### 步骤 7：数据导入和异常检测 🔥

**目标：** 验证异常数据处理：重复数据、缺字段、人工改错

**操作：**

**7.1 加载异常示例数据**
1. 在「排班管理」页面，点击「导入」按钮
2. 选择导入类型：「排班记录」
3. 点击「加载示例数据（含异常）」
4. **验证：** 文本框中自动填入 JSON 数据

**7.2 校验预览 - 异常分类**
1. 点击「校验并预览」按钮
2. 观察统计条：
   - ✅ 总计：应该显示多条记录
   - ✅ 有效：部分有效记录
   - ✅ 警告：可能有警告记录
   - ✅ 无效：包含异常记录（红色）
3. 滚动查看详细记录，确认系统识别出以下异常类型：

**异常类型 1：不存在的关联 ID**
- 记录显示「无效」（红色）
- 错误信息类似：「课程不存在」或「助教不存在」

**异常类型 2：时间冲突**
- 记录显示「无效」
- 错误信息类似：「该助教此时间段已有排班」

**7.3 切换到助教档案导入**
1. 点击「返回修改」
2. 选择导入类型：「助教档案」
3. 点击「加载示例数据（含异常）」
4. 点击「校验并预览」
5. **验证：** 系统识别出以下异常：

**异常类型 3：重复数据**
- 记录显示「无效」
- 错误信息类似：「手机号已存在」或「ID 已存在」

**异常类型 4：缺字段**
- 记录显示「无效」
- 错误信息类似：「姓名不能为空」或「手机号不能为空」

**异常类型 5：字段类型错误（人工改错样例）**
- 记录显示「无效」
- 错误信息类似：「志愿时长必须是数字」
- （示例数据中 `volunteerHours: "五十"` 是字符串而非数字）

**7.4 确认导入**
- 点击「确认导入」（只导入有效记录）
- **验证：** 提示成功导入 N 条记录，无效记录被跳过

---

### 步骤 8：数据持久化验证

**目标：** 确认刷新页面后数据不丢失

**操作：**
1. 记住当前某列表的记录数量（如助教数量）
2. 点击浏览器的「刷新」按钮（或按 F5）
3. 页面重新加载后
4. **验证：**
   - 总览页的统计数字与刷新前一致
   - 助教档案列表的记录数量不变
   - 排班列表的状态不变
   - 之前新增的「测试助教」仍在列表中

---

### 步骤 9：数据重置

**目标：** 验证可以恢复到初始状态

**操作：**
1. 在「总览」页面，点击右上角「重置数据」按钮
2. 在确认弹窗中点击「确定」
3. **验证：** 所有数据恢复到初始示例状态，之前新增的「测试助教」被清除

## 五、异常数据说明

系统内置的异常测试数据位于 `src/data/seedData.ts`：

### 助教异常数据
1. **字段类型错误**：`volunteerHours: "五十"`（字符串而非数字）
2. **重复 ID**：`id: "v-001"`（已存在于示例数据中）
3. **缺字段**：`name` 和 `phone` 为空

### 排班异常数据
1. **不存在的课程**：`courseId: "cs-999"`
2. **不存在的助教**：`volunteerId: "v-999"`
3. **时间冲突**：与已有排班时间重叠

这些异常数据可通过「导入」功能中的「加载示例数据」按钮直接加载测试。
