# 配置文件说明

## 默认配置值

即使不提供配置文件，程序也会使用以下内置默认值运行：

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `required_columns` | 14列完整课表字段 | CSV必须包含的列名 |
| `transaction_types` | ["正常消课", "赠课消耗", "转让消课", "课包冻结", "课包解冻"] | 合法的交易类型 |
| `gift_course_keywords` | ["赠课", "活动", "奖励", "节日"] | 识别赠课记录的关键词 |
| `transfer_keywords` | ["转让", "转赠"] | 识别转让记录的关键词 |
| `freeze_keywords` | ["冻结", "解冻", "请假", "假期"] | 识别冻结记录的关键词 |
| `output_dir` | "reports" | 报告输出目录 |
| `continue_on_failure` | `true` | 单个文件失败时继续处理其他文件 |
| `deduplicate` | `true` | 自动去重 |
| `encoding` | "utf-8" | 文件编码 |

## 字段缺失默认值

当可选字段缺失时使用的默认值：

| 字段 | 默认值 |
|------|--------|
| 消耗课时 | "0" |
| 剩余课时 | "0" |
| 备注 | "" |
| 操作人 | "系统" |
