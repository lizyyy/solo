接口清单 v2.0.0
================

对外接口列表：

1. 用户登录接口
   - 方法：POST
   - 路径：/api/v1/auth/login
   - 说明：用户身份认证
   - 认证：JWT Token

2. 发送消息接口
   - 方法：POST
   - 路径：/api/v1/chat/send
   - 说明：发送对话消息
   - 支持：文本和富文本

3. 获取历史记录接口
   - 方法：GET
   - 路径：/api/v1/chat/history
   - 说明：获取历史对话记录（30天内）

4. 知识库查询接口
   - 方法：GET
   - 路径：/api/v1/knowledge/search
   - 说明：搜索知识库内容
   - 算法：语义匹配

5. 转人工客服接口
   - 方法：POST
   - 路径：/api/v1/chat/transfer
   - 说明：转接人工客服

6. 语音转文字接口（新增）
   - 方法：POST
   - 路径：/api/v1/voice/transcribe
   - 说明：语音文件转文字

7. 满意度评价接口（新增）
   - 方法：POST
   - 路径：/api/v1/chat/evaluate
   - 说明：会话结束后评价

接口总数：7个
认证方式：JWT Token
数据格式：JSON
限流策略：100次/分钟/用户
