# 示例照片目录说明

此目录用于模拟现场照片证据目录。

## 照片命名规范

照片文件名应包含以下信息以便系统自动识别：
- 展品编号：格式如 `EX-001`、`exhibit_001`、`展品_001`
- 箱号：格式如 `BOX-A01`、`box_01`、`箱_A01`
- 时间戳：格式如 `20240515_093000` 或 `2024-05-15_09-30-00`

## 示例文件名

以下是推荐的照片命名方式：

```
EX-001_BOX-A01_20240515_093000.jpg
展品_EX-002_箱_BOX-A01_装箱前.jpg
photo_ex003_boxb01_condition.jpg
BOX-C01_20240515_110000_ex005_ex006.jpg
```

## 系统识别规则

系统会自动从文件名中提取：
1. **展品编号**：匹配 `EX-XXX`、`exhibit_XXX`、`展品_XXX` 等模式
2. **箱号**：匹配 `BOX-XXX`、`box_XXX`、`箱_XXX` 等模式
3. **拍摄时间**：从文件名中的时间戳或文件修改时间获取

## 使用示例

在实际使用时，将现场拍摄的照片放入此目录，系统会：
- 自动扫描所有支持的图片格式（.jpg, .jpeg, .png, .gif, .bmp, .tiff, .webp）
- 从文件名提取关联信息
- 与扫描记录中的照片引用进行匹配校验
