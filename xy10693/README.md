# 采购比价预算审批系统

## 功能特性

- **异常看板**: 日常处理异常采购需求
- **批量导入**: 支持Excel批量导入采购需求
- **历史展示**: 查看历史采购记录
- **列表筛选**: 多条件筛选和导出
- **状态计算**: 自动计算审批状态
- **报表生成**: 按责任人和处理时间筛选导出

## 技术栈

- 后端: Python Flask
- 数据库: SQLite
- 前端: HTML + CSS + JavaScript

## 快速开始

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python app.py
```

### 访问系统

打开浏览器访问: http://localhost:5000

## 数据库

系统会自动创建，包含演示数据
