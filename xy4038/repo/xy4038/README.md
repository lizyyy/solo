# 吊点载荷排练台 - 3D舞台预演工具

## 项目简介

**吊点载荷排练台** 是一款专为小剧场技术总监设计的本地3D交互预演工具。在搭建演出前，技术人员可以在3D舞台工作区中预演灯具、音箱、幕布和临时道具的吊挂位置，实时检查吊点是否超载、设备是否碰撞、灯光照射锥是否被遮挡等问题，避免到现场才发现问题。

## 核心功能

### 🎭 3D舞台工作区
- 直接进入3D工作区，无营销首页
- 支持鼠标拖拽旋转视角、滚轮缩放
- 实时渲染舞台、吊点网格、横杆和设备

### 📦 设备库管理
- 预设多种设备类型：灯具、音箱、幕布、桁架、脚手架
- 每个设备包含：重量、尺寸、重心偏移、安全间距、默认挂载方式
- 支持从设备库拖拽设备到舞台

### 🔧 交互操作
- **拖拽放置**：从左侧设备库拖拽设备到舞台任意位置
- **吊点吸附**：拖拽到吊点附近时自动吸附
- **键盘操作**：
  - 方向键：移动选中设备
  - Shift + 方向键：旋转设备 / 调整高度
  - Delete：删除选中设备
- **撤销/重做**：支持最多50步操作历史

### ⚖️ 载荷计算
- 实时计算每个吊点的载荷
- 横杆载荷按支点位置计算杠杆分布
- 载荷状态显示：安全（<85%）、警告（85%-100%）、危险（>100%）
- 载荷平衡检查

### 🚨 问题检测
系统实时检测以下问题并高亮显示：
1. **吊点超载**：单个吊点载荷超过安全上限
2. **载荷分布不均**：相邻吊点受力差异过大
3. **设备碰撞**：两个设备的包围盒发生实际碰撞
4. **安全间距不足**：设备间距小于安全间距要求
5. **灯光遮挡**：灯具照射锥被幕布或其他设备遮挡
6. **边界违规**：设备超出舞台边界
7. **通道净高不足**：人员通道区域设备高度低于安全要求
8. **未挂载设备**：设备悬在空中未挂载到任何吊点或横杆

### 💾 数据存储
- **本地存储**：数据保存到浏览器localStorage，刷新不丢失
- **JSON导入/导出**：
  - 导出完整方案为JSON文件
  - 导入时校验版本号、设备编号、吊点坐标、重量单位
  - 坏数据拒绝导入，不覆盖当前方案

### 📋 报告导出
- **Markdown安全复核报告**：包含问题清单、载荷分析、设备清单、处理建议
- **CSV设备清单**：可导入Excel的设备明细表

## 安装与启动

### 环境要求
- Node.js >= 16.0.0
- npm 或 yarn

### 安装依赖

```bash
cd xy4038
npm install
```

### 启动开发服务器

```bash
npm run dev
```

启动后，在浏览器中打开显示的地址（通常是 `http://localhost:3001` 或 `http://localhost:3000`）。

### 构建生产版本

```bash
npm run build
```

构建产物位于 `dist/` 目录。

## 快速验证指南

### 1. 添加设备

**步骤：**
1. 启动应用后，左侧面板默认显示"设备库"标签
2. 选择任意设备（如 "PAR64 聚光灯" 或 "双15寸音箱"）
3. 按住鼠标左键，将设备拖拽到中间3D舞台区域
4. 松开鼠标完成放置

**验证要点：**
- 拖拽过程中设备应跟随鼠标移动
- 放置后设备应出现在3D场景中
- 设备数量计数器（左下角）应增加
- 载荷面板应显示该设备对相关吊点的载荷

### 2. 发现超载

**步骤：**
1. 在左侧"设置"标签中，将"吊点安全载荷"设置为较小值（如 50kg）
2. 从设备库拖拽一个较重的设备（如"双15寸音箱"，重量45kg）到某个吊点
3. 再拖拽一个相同设备到同一个吊点

**验证要点：**
- 两个设备总重量超过吊点载荷（90kg > 50kg）
- 该吊点应变为红色高亮
- 右侧"问题列表"中应出现"吊点超载"问题
- 点击问题项应自动选中该吊点并聚焦
- 载荷面板中该吊点的载荷条应显示为红色

### 3. 碰撞高亮

**步骤：**
1. 拖拽两个大型设备到舞台（如"电动幕布"和"桁架段"）
2. 选中其中一个设备
3. 使用方向键将其移动到另一个设备内部，使其发生碰撞

**验证要点：**
- 两个设备重叠时应同时被高亮
- 右侧"问题列表"中应出现"设备碰撞"问题
- 问题描述中应包含两个设备的名称
- 点击问题项应同时选中两个设备

### 4. 保存与恢复

**步骤：**
1. 在舞台上放置几个设备
2. 点击顶部工具栏的"保存"按钮
3. 刷新浏览器页面（按 F5 或 Ctrl+R）

**验证要点：**
- 刷新后设备应该仍然存在
- 左下角"上次保存"时间应更新
- 如果设备有载荷或问题，状态应保持不变

**备用方法：**
- 也可以点击"导出"按钮保存为JSON文件
- 点击"导入"按钮可从文件恢复

### 5. 导入导出

**导出步骤：**
1. 点击顶部工具栏的"导出"按钮
2. 浏览器会下载一个JSON文件（命名如 `stage-layout-2025-01-01.json`）

**导入步骤：**
1. 点击顶部工具栏的"导入"按钮
2. 选择之前导出的JSON文件
3. 确认导入对话框

**验证要点：**
- 导入后的设备位置、旋转角度应与导出时一致
- 载荷和问题状态应正确恢复

**版本校验：**
- 尝试编辑JSON文件，将 `version` 字段改为错误值
- 尝试导入坏数据，系统应拒绝并提示错误
- 当前方案不应被破坏

### 6. 生成报告

**生成Markdown报告：**
1. 在舞台上放置一些设备，故意制造一些问题（超载、碰撞等）
2. 点击顶部工具栏的"导出报告"按钮
3. 浏览器会下载一个.md文件

**验证要点：**
- 报告应包含：
  - 方案概览（设备数量、问题数量）
  - 问题清单（按严重程度排序）
  - 载荷分析（每个吊点的载荷百分比）
  - 设备清单（所有设备的详细信息）
  - 处理建议

**导出CSV设备清单：**
1. 点击顶部工具栏的"导出清单"按钮
2. 浏览器会下载一个.csv文件

**验证要点：**
- 可用Excel或Numbers打开
- 包含设备ID、名称、类型、重量、尺寸、位置等字段

### 导入校验规则

导入时系统会检查：
1. **版本校验**：`version` 字段必须匹配当前版本
2. **设置校验**：舞台尺寸、间距等必须为正数
3. **设备校验**：
   - `id` 字段存在且非空
   - `position`、`rotation`、`dimensions` 字段格式正确
   - `weight` 为非负数
4. **吊点坐标**：如有挂载，吊点ID必须存在

## 已知限制

1. **物理模拟**：当前版本不支持真实的物理碰撞模拟，仅检测包围盒重叠
2. **复杂结构**：多层横杆、复杂桁架系统的载荷计算可能需要简化
3. **浏览器兼容性**：需要支持 WebGL 2.0 的现代浏览器
4. **移动端**：UI设计针对桌面端，移动端体验可能不佳

## 故障排除

### 常见问题

**Q: 3D场景不显示？**
- 检查浏览器是否支持 WebGL
- 打开浏览器控制台查看是否有错误
- 尝试使用 Chrome 或 Firefox 浏览器

**Q: 拖拽设备没反应？**
- 确认从左侧设备库拖拽，不是从3D场景
- 检查是否有浏览器扩展拦截了拖拽事件

**Q: 保存后刷新数据丢失？**
- 确认使用了"保存"按钮，而不是仅导出
- 检查浏览器是否禁用了 localStorage
- 尝试在无痕模式下测试

**Q: 导入失败？**
- 检查JSON文件格式是否正确
- 确认版本号匹配（当前版本 1.0.0）
- 查看浏览器控制台的具体错误信息

### 获取帮助

如遇问题，请检查浏览器开发者工具的控制台（按 F12），查看是否有错误信息。
