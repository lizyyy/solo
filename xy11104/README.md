# 口腔诊所耗材领用汇总 CLI 工具

一个专门用于口腔诊所耗材领用数据质量校验和异常检测的命令行工具，核心目标是**保留状态和证据**。

## 功能特性

### 🔍 异常检测规则
- **负数退回检测** - 识别数量为负的退回操作（中优先级）
- **审批人缺失检测** - 标记缺少审批签字的记录（高优先级）
- **零金额检测** - 发现数量非零但金额为0的记录（低优先级）
- **科室缺失检测** - 检查领用科室是否填写（中优先级）
- **异常数量检测** - 预警单次领用超过阈值的记录（默认阈值100件）

### 📋 证据留存
- ✅ 保留原始行号和文件名
- ✅ 生成可复跑的时间戳输出文件
- ✅ 异常报告按类型分组，每条记录标注行号
- ✅ 证据日志包含完整处理流程说明

### 💡 日志模式
- **简洁模式**（默认）- 仅显示统计摘要和异常汇总
- **详细模式**（`-v`）- 展开每条记录的处理详情

## 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 运行样例数据（推荐新手先跑样例）
```bash
node src/cli.js process --sample
```

### 3. 处理实际业务数据
```bash
node src/cli.js process path/to/your/data.csv
```

### 4. 使用详细模式
```bash
node src/cli.js process --sample -v
```

## 命令选项

```
Usage: dental-consumables process [options] [file]

处理耗材领用汇总文件

Options:
  -c, --config <path>  规则配置文件路径 (default: "./config/rules.json")
  -o, --output <dir>   输出目录 (default: "./output")
  -v, --verbose        详细日志模式
  --sample             使用样例数据运行
  -h, --help           display help for command
```

## 输出文件说明

每次运行会在 `output/` 目录生成以下文件（文件名带时间戳，保证可复跑）：

| 文件名 | 说明 |
|--------|------|
| `summary-*.json` | 统计摘要JSON，包含总记录数、正常/异常数、类型分布 |
| `issues-*.csv` | 异常明细CSV，包含行号、类型、严重程度、字段、值、消息等 |
| `cleaned-*.csv` | 清洗后的数据（保留原始行号信息） |
| `evidence-*.txt` | **证据留存日志** - 完整的处理记录，适合审计存档 |
| `latest-run.txt` | 最近一次运行的时间戳标记 |

样例数据 `samples/dental-consumables-sample.csv` 包含真实口腔诊所耗材场景：

- 🦴 正畸科：托槽、弓丝、结扎丝

- 🏥 院感科：口罩、手套、隔离衣、洗手液

## 配置规则

编辑 `config/rules.json` 自定义校验规则：

```json
{
  "rules": {
    "missingApprover": {
      "enabled": true,
      "severity": "high",
      "description": "检测审批人缺失的记录"
    },
    "abnormalQuantity": {
      "enabled": true,
      "threshold": 100,
      "description": "检测数量异常大的记录"
    }
  }
}
```

## 标准工作流程

1. **运行工具** - 处理耗材领用CSV文件
2. **查看异常** - 按优先级处理（高→中→低）
3. **高优先级** - 补全审批人签字信息
4. **中优先级** - 确认退回操作原因和异常数量
5. **低优先级** - 确认零金额领用原因
6. **保存证据** - 留存证据日志作为审计记录

## 注意事项

⚠️ **证据留存重要提示**：
- 证据日志文件请妥善保存，不要修改
- 文件名包含时间戳，支持多次运行的审计追溯
- 每条异常都标注了原始行号，便于回溯原始数据

🔄 **可复跑性**：
- 每次运行生成独立的输出文件
- 不会覆盖历史处理结果
- `latest-run.txt` 标记最近一次处理
