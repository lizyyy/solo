## 1. 产品概述

代码生成提示词仓库——面向工程团队的提示词资产管理平台，解决提示词散落、版本混乱、失败原因不可追溯的问题。通过结构化归档、相似检索、版本对比和问题追踪，将"发现问题→修正→确认"全流程闭环，让每一条提示词的评分、失败原因、修改记录、检索报告都能追溯到源头。

- 目标用户：工程团队中负责代码生成提示词编写、评审和复用的开发者与技术负责人
- 核心价值：消除同题重复、评分口径不一、旧提示词误用等常见痛点，提升提示词复用率和质量

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 编辑者 | 团队内部邀请 | 录入/编辑提示词、提交修正、标记标签 |
| 审核者 | 团队内部邀请 | 确认修正、关闭问题、导出报告 |
| 访客 | 只读链接 | 浏览和检索提示词、查看报告 |

### 2.2 功能模块

1. **提示词归档页**：结构化录入提示词（文本、技术栈、产物评分、失败原因）、标签筛选、批量导入
2. **相似检索页**：基于技术栈+关键词的相似提示词检索，展示相似度排序和对比入口
3. **版本对比页**：同一提示词多版本差异对比，关联修改原因和确认状态
4. **问题追踪页**：发现问题（重复/口径不一/旧版误用）→ 修正 → 确认三段式流程，每步输入输出可追溯
5. **数据看板页**：提示词数量趋势、技术栈分布、评分分布、失败原因统计图表，图表下钻到明细
6. **报告导出页**：按筛选条件生成检索报告，支持 CSV/JSON 导出，导出数据与图表同源

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 3. 核心流程

### 3.1 提示词归档与重复检测

用户在归档页录入提示词文本和技术栈，系统自动检测同题重复，若发现冲突则展示具体冲突项（相似度、已有版本号、评分），用户选择继续录入或跳转已有条目修改。

```mermaid
flowchart TD
    "录入提示词" --> "自动重复检测"
    "自动重复检测" --> "有冲突?" 
    "有冲突?" -->|"是"| "展示冲突详情（相似度/版本/评分）"
    "展示冲突详情（相似度/版本/评分）" --> "继续录入?"
    "继续录入?" -->|"是，标记为变体"| "保存为新版本"
    "继续录入?" -->|"否"| "跳转已有条目"
    "有冲突?" -->|"否"| "保存为新条目"
    "保存为新条目" --> "生成检索报告"
    "保存为新版本" --> "生成检索报告"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底色（#0f1117）+ 琥珀色强调（#f59e0b），工业感仪表盘风格
- **辅助色**：翠绿（#10b981，表示通过/正常）、玫红（#f43f5e，表示问题/告警）、钢蓝（#3b82f6，表示信息/链接）
- **字体**：标题用 JetBrains Mono（技术感），正文用 DM Sans（清晰可读）
- **布局风格**：左侧导航栏 + 右侧内容区，顶部全局搜索和筛选栏
- **按钮风格**：圆角6px，轻微阴影，hover 时提升亮度
- **图标**：lucide-react 图标库，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 提示词归档页 | 录入表单 | 卡片式表单，多选标签输入，滑块评分，失败原因标签组，底部操作栏 |
| 提示词归档页 | 列表与筛选 | 顶部筛选条（技术栈/评分/失败原因chips），数据表格，行内操作按钮 |
| 提示词归档页 | 重复检测弹窗 | 模态框，冲突列表卡片，相似度进度条，操作按钮 |
| 相似检索页 | 检索输入 | 搜索框+技术栈多选下拉，搜索按钮 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px 完整体验
- 平板端（768-1280px）导航栏折叠为图标模式，图表变为两列
- 移动端（<768px）单列布局，图表纵向堆叠

### 4.4 动效设计

- 页面切换：淡入淡出 200ms
- 列表项进入：交错动画（stagger），每项延迟 50ms
- 图表加载：数据从零生长动画 600ms
- 弹窗/面板：从右侧滑入 300ms
- 筛选条件变化：列表内容平滑过渡
