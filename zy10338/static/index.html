系统概览

客户端管理

注册和管理客户端标识，支持客户端类型分类，记录创建人和创建时间。

能力声明

声明客户端支持的 API 版本和能力集，支持配置降级选项以备协商失败时使用。

版本协商

自动进行版本兼容性检查，匹配最佳能力集，防止重复提交产生脏数据。

状态追踪

完整记录协商状态流转历史，包括操作人、时间和原因，支持审计追溯。

命中日志

记录每次协商结果的查询命中情况，包括缓存命中情况和响应时间统计。

持久化存储

使用 SQLite 进行数据持久化，服务重启后所有状态数据保持完整不丢失。
