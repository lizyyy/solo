# 证据包导出系统

一个全栈应用，用于客服处理争议时导出证据包。

## 功能特性

- 📋 **证据目录管理** - 按争议单展示所有相关证据（订单截图、聊天记录、操作日志、合同附件）
- ⚠️ **材料缺失检测** - 自动检测缺失材料，不完整时无法导出
- 📦 **异步打包** - 后台异步生成ZIP压缩包，内含证据清单报告
- 🔄 **批次复用** - 相同证据组合重复导出时直接复用已有批次
- ⏰ **过期管理** - 下载链接24小时过期，支持一键重新授权续期
- 📝 **领取记录** - 完整审计追踪，记录操作人、操作类型、时间
- 📄 **清单报告** - 下载或查看格式化的证据清单报告

## 快速开始

### 1. 安装依赖

```bash
# 安装后端依赖
npm install

# 安装前端依赖
cd client && npm install && cd ..
```

### 2. 启动开发环境

```bash
# 同时启动前后端（推荐）
npm run dev

# 或分别启动：
# 后端端口 3001
npm run dev:server

# 前端端口 3000
npm run dev:client
```

### 3. 访问应用

打开浏览器访问: **http://localhost:3000**

## 核心API接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/disputes` | 获取争议单列表 |
| GET | `/api/disputes/:id` | 获取争议单详情（含证据、批次、校验结果） |
| POST | `/api/disputes/:id/evidences` | 添加证据 |
| POST | `/api/disputes/:id/export` | 创建/复用导出批次 |
| GET | `/api/disputes/:id/report` | 下载完整报告 |
| GET | `/api/batches/:id/access-records` | 获取领取记录 |
| POST | `/api/batches/:id/reauthorize` | 重新授权批次（重新生成ZIP） |
| GET | `/api/downloads/:filename` | 下载证据包ZIP文件 |

## 技术栈

- **后端**: Node.js + Express + TypeScript + SQLite
- **前端**: React + TypeScript + Vite
- **打包**: archiver (ZIP压缩)
- **校验**: SHA256 哈希校验

## 业务规则

1. **材料完整性**: 必须包含4类核心证据（订单截图、聊天记录、操作日志、合同附件）才能导出
2. **批次复用**: 相同证据组合复用已有批次，避免重复打包
3. **有效期**: 下载链接24小时后自动过期
4. **重新授权**: 过期批次点击"重新授权"会重新生成ZIP文件并续期24小时
5. **审计追踪**: 所有下载、查看、授权操作都记录在案
6. **哈希校验**: 每个证据都有SHA256哈希，确保数据完整性
