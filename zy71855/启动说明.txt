========================================
       工业机械臂示教系统 - 使用说明
========================================

【启动步骤】
1. 打开终端，进入项目目录
2. 执行命令: npm install
3. 执行命令: node server.js
4. 打开浏览器访问: http://localhost:3000

【系统功能】

1. 开始示教
   - 输入材料批次编号（如 BATCH-2024-001）
   - 填写材料名称、授课老师、班级名称
   - 点击"开始上课"进入课堂
   - 按顺序完成步骤，系统自动检测跳步
   - 记录课堂笔记
   - 导出课堂记录或简单清单

2. 视频版本
   - 上传步骤视频的版本信息
   - 自动检测视频内容变更（步骤、零件、时长等）
   - 查看版本历史和变更记录

3. 历史记录
   - 按材料批次查询历史课程
   - 同一批材料多次使用不会覆盖历史
   - 导出批次完整历史记录

4. 步骤设置
   - 自定义示教步骤
   - 支持添加、修改、删除步骤

【核心特点】

✓ 错误提示"说人话"，不显示技术字段
✓ 同一批材料反复使用，历史记录保留
✓ 导出记录方便下一班查阅
✓ 视频版本变更主动提醒
✓ 跳步自动检测和提醒

【文件结构】
server.js              - 后端服务
package.json           - 项目配置
data/                  - 数据处理模块
  models.js            - 数据存储基础
  errorMessages.js     - 友好错误提示
  teachingSession.js   - 课堂会话管理
  videoVersion.js      - 视频版本管理
  exportRecords.js     - 记录导出功能
public/                - 前端页面
  index.html           - 主页面
  style.css            - 样式文件
  app.js               - 前端逻辑
data/storage/          - 数据存储目录（自动创建）
