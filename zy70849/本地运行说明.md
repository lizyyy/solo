# 理赔材料审核系统 - 本地运行说明

## 项目概述
这是一个基于 FastAPI 的理赔材料智能审核系统，支持材料清单 CSV 上传、保单 JSON 导入，并根据预设规则自动将审核结果分为正常项、待确认项、失败项。

## 核心功能
- ✅ 材料清单 CSV 上传解析
- ✅ 保单信息 JSON 上传
- ✅ 规则引擎（缺失发票、金额超限、重复报案等7条默认规则）
- ✅ 审核结果分类（正常/待确认/失败）
- ✅ 失败记录保留原始字段和处理建议
- ✅ 防重复提交机制
- ✅ 历史审核记录追溯
- ✅ 复核意见来源追踪

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动服务
```bash
python main.py
```
或
```bash
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

服务启动后访问: http://localhost:8000/docs

### 3. 初始化默认规则
在 Swagger UI 中调用:
```
POST /api/rules/init-default
```
将初始化7条默认审核规则。

## API 调用流程示例

### 步骤1: 上传保单信息
```bash
curl -X POST "http://localhost:8000/api/claim/upload-policy" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@test_data/policy.json"
```

### 步骤2: 上传材料清单并审核
```bash
curl -X POST "http://localhost:8000/api/claim/upload-csv?batch_no=BATCH001&policy_no=POL20240001&claimant_name=张三&total_amount=60000" \
  -H "Content-Type: multipart/form-data" \
  -F "file=@test_data/materials.csv"
```

### 步骤3: 查询批次审核历史
```bash
curl "http://localhost:8000/api/history/batch/BATCH001"
```

### 步骤4: 追踪复核意见来源
```bash
curl "http://localhost:8000/api/history/trace/1"
```

### 步骤5: 添加复核意见
```bash
curl -X PUT "http://localhost:8000/api/history/review/1?reviewer=李四&comment=已确认情况属实"
```

## 默认规则说明

| 规则编码 | 规则名称 | 类型 | 严重程度 | 触发条件 |
|---------|---------|------|---------|---------|
| INVOICE_001 | 缺失发票 | material | high | 未找到发票类型材料 |
| INVOICE_002 | 发票金额不匹配 | material | medium | 发票金额<=0 |
| AMOUNT_001 | 金额超限 | batch | high | 理赔金额>保单保额 |
| AMOUNT_002 | 单张发票金额过高 | material | medium | 单张发票>10000元 |
| DUPLICATE_001 | 重复报案 | batch | high | 同一保单已有报案记录 |
| MATERIAL_001 | 缺失诊断证明 | material | medium | 未找到诊断证明 |
| MATERIAL_002 | 缺失费用清单 | material | medium | 未找到费用清单 |

## 测试场景

### 场景1: 金额超限测试
- 保单保额: 50000元
- 理赔申请: 60000元
- 预期结果: 触发 AMOUNT_001 规则，失败项

### 场景2: 重复报案测试
- 同一保单第二次提交
- 预期结果: 触发 DUPLICATE_001 规则，失败项

### 场景3: 大额发票复核
- 单张发票金额 15000元
- 预期结果: 触发 AMOUNT_002 规则，待确认项

### 场景4: 材料齐全
- 包含发票、诊断证明、费用清单
- 预期结果: 正常项

## 数据库说明
使用 SQLite 数据库 `claim_audit.db`，包含以下表:
- claim_submissions: 理赔提交记录
- claim_materials: 材料清单
- audit_rules: 审核规则
- audit_results: 审核结果（含 source_rule 字段可追溯规则来源）
- policy_info: 保单信息
