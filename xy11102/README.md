# 二手书店寄卖库存盘点 CLI

一个专门处理二手书店寄卖库存盘点数据的命令行工具，重点解决条码前导零丢失、重复扫码问题，并提供稳定排序的可复跑输出。

## 功能特性

### 1. 条码前导零丢失检测与修复
- 自动检测条码长度不足13位的问题
- 自动补齐前导零至标准13位ISBN格式
- 单独列出所有存在条码前导零问题的记录

### 2. 重复扫码检测
- 自动检测同一条码出现多次的情况
- 显示重复出现次数和所在行号
- 方便人工核对处理

### 3. 稳定排序与可复跑输出
- 按条码、寄卖日期、书名稳定排序
- 输出文件包含文件哈希，便于比较两次运行差异
- 相同输入始终产生相同哈希的输出文件

## 安装依赖

```bash
pip3 install -r requirements.txt
```

## 使用方法

### 1. 生成样例数据

```bash
python3 inventory_cli.py generate-samples [输出目录]
```

示例：
```bash
python3 inventory_cli.py generate-samples ./samples
```

### 2. 检查库存数据

```bash
python3 inventory_cli.py check <输入文件> [--output-dir 输出目录]
```

示例：
```bash
# 检查Excel文件
python3 inventory_cli.py check samples/二手书店寄卖库存盘点_原始数据.xlsx

# 检查CSV文件，指定输出目录
python3 inventory_cli.py check samples/二手书店寄卖库存盘点_原始数据.csv -o ./output
```

## 输出文件说明

运行后会在输出目录生成两个Excel文件：

### 1. inventory_result_时间戳_哈希.xlsx
包含两个Sheet：
- **盘点结果**：修复后的完整盘点数据，条码已修复并标记
- **统计摘要**：总记录数、异常数量、文件哈希等统计信息

关键业务列按固定顺序输出：条码、书名、作者、出版社、定价、寄卖人、寄卖日期、库存状态、货架位置、盘点数量、条码修复标记

### 2. inventory_issues_时间戳_哈希.xlsx
包含异常问题明细：
- **条码前导零问题**：所有条码长度不足的记录，含原始条码、建议修复值、缺失零个数
- **重复扫码问题**：所有重复扫码记录，含出现次数、重复行号

## 可复跑验证

相同输入文件多次运行会产生相同的文件哈希，证明输出结果稳定一致，便于diff比较。

## 业务数据说明

样例数据包含真实的二手书店寄卖业务场景：
- 10本经典畅销书籍信息
- 8位寄卖人信息
- 4种库存状态：在架、待售、预定、出库待结
- 9个货架位置编码
