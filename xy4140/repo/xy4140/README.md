# 🌡️ 高温避暑站调度沙盘

专为城市社区网格员设计的本地 Streamlit 数据分析工具，用于热浪期间的避暑站调度和老人探访安排。

## 📋 功能特性

### 核心功能
- **风险评估**: 根据老人年龄、健康状况、体感温度等计算个人风险分（低/中/高/极高风险四级）
- **覆盖分析**: 识别站点覆盖缺口和高风险热点区域，防止片区风险被平均值掩盖
- **拥挤预测**: 基于体感温度预报预测各时段站点拥挤程度
- **路线优化**: 智能生成探访排班甘特图，支持手动锁定站点和调整探访优先级
- **方案管理**: 保存和加载调度方案，支持多方案对比
- **导出报告**: 生成 Markdown 格式行动清单，便于打印和分享

### 可视化视图
- 🗺️ **地理分布地图**: 基于 Folium 的交互式地图，显示老人和站点位置
- 🔥 **风险热力图**: 各社区风险等级热力分布
- 📊 **统计图表**: 饼图、柱状图、直方图等多维度数据分析
- ⏰ **时间线分析**: 体感温度变化和站点拥挤度时间线

## ⚠️ 风险算法说明

### 风险分计算模型

风险分由五个维度加权计算得出：

| 维度 | 权重 | 说明 |
|------|------|------|
| 年龄 | 25% | ≥85岁极高风险，≥75岁高风险 |
| 健康状况 | 25% | 高血压/糖尿病/心脏病等为高风险 |
| 独居情况 | 15% | 独居且需特殊照顾为极高风险 |
| 行动能力 | 15% | 卧床为极高风险，轮椅为高风险 |
| 高温暴露 | 20% | 体感温度、有无空调、到站点距离 |

### 风险等级划分

| 等级 | 分数范围 | 颜色标识 | 处理建议 |
|------|----------|----------|----------|
| 低风险 | < 0.25 | 🟢 绿色 | 常规探访 |
| 中风险 | 0.25 - 0.50 | 🟡 黄色 | 增加探访频次 |
| 高风险 | 0.50 - 0.75 | 🟠 橙色 | 优先探访，确认避暑安排 |
| 极高风险 | ≥ 0.75 | 🔴 红色 | 紧急探访，24小时内确认 |

### 可配置参数

在 `config.py` 中可修改：

```python
RISK_CONFIG = {
    "HEAT_THRESHOLD": 35.0,        # 高温阈值（℃）
    "CRITICAL_HEAT_THRESHOLD": 38.0, # 危险阈值（℃）
    "WALKING_TIME_THRESHOLD": 15,   # 步行可达阈值（分钟）
    "BUS_TIME_THRESHOLD": 30,       # 公交可达阈值（分钟）
    "AGE_HIGH_RISK": 75,             # 高风险年龄
    "AGE_CRITICAL": 85,              # 极高风险年龄
}

WEIGHTS_CONFIG = {
    "age": 0.25,           # 年龄权重
    "health": 0.25,        # 健康权重
    "living_alone": 0.15,  # 独居权重
    "mobility": 0.15,      # 行动能力权重
    "heat_exposure": 0.20, # 高温暴露权重
}
```

| 字段名 | 类型 | 必填 | 说明 |

## 🔧 常见问题

### Q1: 地图无法显示？
A: 需要安装 `folium` 和 `streamlit-folium`：
```bash
pip install folium streamlit-folium
```

### Q2: 如何添加自定义数据？
A: 参考示例数据格式，准备：
1. 老人清单 CSV
2. 避暑站 CSV
3. 温度预报 JSON（可选）

在「数据导入」页面分别上传即可。

### Q3: 风险分计算不合理？
A: 可在「风险分析」页面临时调整权重，或修改 `config.py` 中的 `WEIGHTS_CONFIG` 永久调整。

### Q4: 站点分配可以手动调整吗？
A: 目前支持：
- 锁定站点（排除分配）
- 查看分配结果
- 手动修改需直接编辑方案数据
