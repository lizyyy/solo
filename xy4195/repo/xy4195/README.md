# 展柜光照眩光排练板

一个为博物馆展陈团队设计的本地 Web 前端工具，用于在布展前模拟和评估展柜光照效果，预防照度超标、玻璃反光和说明牌可见性问题。

## 功能特性

### 核心功能
- **数据导入**：支持展柜尺寸 JSON、灯具角度 CSV、文物材质表和观众动线数据导入
- **双视图模式**：平面图（俯视）和侧视图（剖面）切换展示
- **风险评估**：
  - 照度超标检测
  - 直接眩光评估
  - 玻璃反射眩光分析
  - 说明牌可见性检查
- **交互式编辑**：支持拖动调整灯具位置，实时更新风险评估
- **方案管理**：保存多个方案，支持方案对比
- **多格式导出**：Markdown 调整建议、CSV 风险清单、JSON 审计包

### 技术特点
- 纯前端实现，无需后端服务器
- 使用 HTML5 Canvas 进行可视化渲染
- 本地存储保存方案数据
- 响应式设计，支持多种屏幕尺寸

## 快速开始

### 1. 启动应用

由于是纯前端应用，您可以使用以下任意一种方式启动：

**方式一：使用 Python HTTP 服务器**
```bash
cd /path/to/xy4195
python3 -m http.server 8000
```

**方式二：使用 Node.js 的 http-server**
```bash
npm install -g http-server
cd /path/to/xy4195
http-server -p 8000
```

**方式三：直接在浏览器中打开**
- 某些浏览器（如 Firefox）支持直接打开本地 HTML 文件
- Chrome 可能需要使用上述服务器方式

启动后在浏览器中访问：`http://localhost:8000`

### 2. 验证流程

#### 第一步：加载示例数据

1. 打开应用后，点击左侧边栏的 **"加载示例数据"** 按钮
2. 观察页面右侧画布是否显示：
   - 3 个展柜（蓝色矩形）
   - 多个灯具（橙色圆点，带有灯束）
   - 观众动线（紫色虚线）
   - 风险提示区域（如有风险会显示不同颜色）

#### 第二步：检查风险评估

1. 观察左侧边栏下方的 **"风险清单"** 区域
2. 应该显示根据示例数据计算出的风险项：
   - **高风险（红色背景）**：照度超标、严重眩光等
   - **中风险（黄色背景）**：中等程度的问题
   - **低风险（蓝色背景）**：轻微问题

#### 第三步：切换视图模式

1. 点击左侧边栏的 **"平面图"** 或 **"侧视图"** 按钮
2. 观察画布内容的变化：
   - **平面图**：俯视视角，显示 X-Y 平面布局
   - **侧视图**：剖面视角，显示 X-Z 平面（高度信息）

#### 第四步：调整显示设置

1. 在左侧边栏的 **"显示设置"** 区域，勾选/取消勾选各个选项：
   - 显示灯束
   - 显示眩光风险
   - 显示说明牌可见区
   - 显示观众动线
2. 观察画布内容的实时变化

#### 第五步：交互式编辑灯具

1. **拖动灯具**：在画布上点击并拖动任意灯具（橙色圆点）
2. **观察变化**：
   - 灯束位置和形状实时更新
   - 风险清单实时重新计算
   - 画布信息栏显示当前状态
3. **双击编辑**：双击某个灯具，弹出属性编辑对话框：
   - 位置坐标（X, Y, Z）
   - 角度（水平角、倾斜角）
   - 光强
   - 光束角

#### 第六步：保存方案

1. 调整灯具后，点击顶部的 **"保存方案"** 按钮
2. 在弹出的对话框中输入方案名称
3. 点击 **"保存"** 按钮
4. 观察提示信息："方案保存成功"

#### 第七步：对比方案

1. 先保存两个不同的方案（例如：调整灯具前后各保存一个）
2. 点击顶部的 **"对比方案"** 按钮
3. 在方案列表中：
   - 选择一个方案作为 **"方案 A"**
   - 选择另一个方案作为 **"方案 B"**
4. 点击 **"开始对比"** 按钮
5. 观察下方出现的对比区域：
   - 两个方案的可视化对比
   - 风险数量统计
   - 差异分析（改进/退步）
6. 可点击 **"导出对比报告"** 生成 Markdown 格式报告

#### 第八步：导出数据

1. 点击顶部的 **"导出"** 按钮
2. 在弹出的对话框中有三种导出选项：

   **选项 1：Markdown 调整建议**
   - 点击导出，下载 `.md` 文件
   - 包含：风险概览、详细风险分析、调整建议、附录

   **选项 2：CSV 风险清单**
   - 点击导出，下载 `.csv` 文件
   - 包含：风险类型、严重程度、描述、相关灯具/展柜/文物等

   **选项 3：JSON 审计包**
   - 点击导出，下载 `.json` 文件
   - 包含：完整方案数据、风险分析、建议列表

## 核心算法说明

### 照度计算
使用简化的照度公式：
```
E = I * cos(theta) / r²
```
- E: 照度 (lux)
- I: 光强 (cd)
- theta: 入射角
- r: 距离

### 眩光评估
基于以下因素综合评估：
1. **直接眩光**：灯具是否在观众视野范围内
2. **反射眩光**：计算灯在玻璃上的反射点，评估反射光强度
3. **UGR 简化模型**：统一眩光评级的简化实现

### 可见性分析
考虑因素：
1. 观众到说明牌的距离
2. 视角范围（人眼舒适视角 ±30°）
3. 视线阻挡（简化模型）

## 注意事项

1. **数据单位**：所有长度单位为米，角度单位为度，照度单位为 lux
2. **坐标系统**：
   - 平面图：X-Y 平面，Y 轴向前
   - 侧视图：X-Z 平面，Z 轴向上
3. **本地存储**：方案数据保存在浏览器 localStorage 中，清除浏览器数据会丢失
4. **计算精度**：所有计算为简化模型，仅供排练参考，实际布展需专业测量

## 故障排除

### 问题 1：画布不显示内容
- 解决方案：检查是否已加载数据，点击"加载示例数据"按钮

### 问题 2：文件导入失败
- 解决方案：检查文件格式是否符合要求，参考 data/ 目录下的示例文件

### 问题 3：保存的方案丢失
- 解决方案：检查是否清除了浏览器数据，建议定期导出 JSON 审计包备份

### 问题 4：视图显示异常
- 解决方案：尝试刷新页面，或检查浏览器控制台是否有错误信息
