# 污水厂数据分析看板

给小型污水厂值班员使用的本地数据分析看板，用于分析SCADA数据、鼓风机电表、回流泵运行记录和化验复测数据，自动识别运行异常。

## 功能特性

- **多数据源整合**：支持导入SCADA导出的溶解氧/氨氮CSV、鼓风机电表数据、回流污泥泵运行记录、化验复测备注
- **智能风险分析**：自动判断曝气过量、缺氧、回流异常、化验结果偏差等风险事件
- **可视化展示**：按池组展示溶解氧、氨氮、鼓风机功率、回流泵流量等曲线图表
- **人工改判**：支持对系统自动判断的风险事件进行人工改判，并保存备注
- **数据持久化**：使用SQLite本地数据库，刷新页面数据不丢失
- **导出功能**：支持导出Markdown交班单和JSON格式的数据明细

## 使用说明

### 1. 导入数据

#### 方式一：导入示例数据

点击页面上的 **"导入示例数据"** 按钮，系统会自动生成包含多种风险事件的演示数据，方便快速体验功能。

#### 方式二：导入自定义CSV文件

1. 选择数据日期
2. 点击 **"导入数据"** 按钮
3. 可以选择以下类型的文件：
   - **SCADA数据**：包含时间、池组、溶解氧(DO)、氨氮(NH3)等字段
   - **鼓风机电表**：包含时间、鼓风机编号、功率、频率、状态等字段
   - **回流泵运行记录**：包含时间、泵编号、流量、状态等字段
   - **化验复测备注**：包含时间、项目、仪表值、化验值、单位、备注等字段

#### 方式三：导入JSON文件

点击 **"JSON文件"** 标签页，上传之前导出的JSON格式数据文件。

### 2. 查看数据

- **选择日期**：从下拉框中选择已导入数据的日期
- **查看曲线**：
  - 溶解氧曲线
  - 氨氮曲线
  - 鼓风机功率曲线
  - 回流泵流量曲线
- **筛选池组**：可以在溶解氧曲线图表上方选择特定池组查看

### 3. 风险分析

页面顶部显示四类风险事件的统计数量：
- **曝气过量**：溶解氧过高或鼓风机功率过大
- **缺氧风险**：溶解氧过低或氨氮超标
- **回流异常**：回流泵停机或流量过低
- **化验偏差**：仪表值与化验值偏差过大

点击 **"风险事件列表"** 可以查看详细的风险事件信息。

### 4. 人工改判

对于系统自动判断的风险事件，值班员可以进行人工改判：

1. 在风险事件列表中，点击事件卡片上的 **"人工改判"** 按钮
2. 填写改判原因和操作人员姓名
3. 点击 **"保存改判"**

改判记录会保存在数据库中，刷新页面后仍然可见。

### 5. 导出数据

#### 导出Markdown交班单

点击 **"导出交班单"** 按钮，会生成一个格式化的Markdown格式交班单，包含：
- 日期和生成时间
- 风险事件汇总（包括人工改判记录）
- 值班员和接班员签字栏

#### 导出JSON明细

点击 **"导出JSON明细"** 按钮，会导出完整的数据明细，包括：
- SCADA数据
- 鼓风机数据
- 回流泵数据
- 化验数据
- 分析结果
- 人工改判备注

## 数据格式说明

### CSV文件格式

#### SCADA数据格式

```csv
time,tank,dissolvedOxygen,ammoniaNitrogen
2026-05-05T00:00:00,1#池,2.0,1.2
2026-05-05T00:00:00,2#池,1.9,1.0
```

或使用中文字段名：

```csv
时间,池组,溶解氧,氨氮
2026-05-05 00:00:00,1#池,2.0,1.2
```

#### 鼓风机电表格式

```csv
time,blower,power,frequency,status
2026-05-05T00:00:00,1#鼓风机,80.5,40.2,运行
```

#### 回流泵运行记录格式

```csv
time,pump,flowRate,status
2026-05-05T00:00:00,1#回流泵,105.5,运行
```

#### 化验复测备注格式

```csv
time,item,instrumentValue,labValue,unit,remark
2026-05-05T08:00:00,氨氮,1.2,3.5,mg/L,偏差较大，需复核
```

### 分析规则说明

#### 曝气过量判断

1. 溶解氧 > 2.5 mg/L
2. 鼓风机功率 > 120 kW 且频率 > 45 Hz，同时溶解氧 > 2.5 mg/L

#### 缺氧风险判断

1. 溶解氧 < 0.5 mg/L
2. 氨氮 > 2.0 mg/L（硝化效果差，可能供氧不足）

#### 回流异常判断

1. 回流泵状态为"停机"
2. 回流泵流量 < 50 m³/h

#### 化验偏差判断

1. 仪表值与化验值偏差 > 30%
2. 化验备注包含"偏差"关键词

## 配置说明

可以在 `analyzer.js` 中修改分析规则的阈值：

```javascript
this.config = {
  dissolvedOxygen: {
    min: 0.5,      // 溶解氧下限（mg/L）
    max: 2.5,      // 溶解氧上限（mg/L）
    unit: 'mg/L'
  },
  ammoniaNitrogen: {
    max: 2.0,      // 氨氮上限（mg/L）
    unit: 'mg/L'
  },
  blower: {
    powerThreshold: 120,       // 鼓风机功率阈值（kW）
    frequencyThreshold: 45     // 鼓风机频率阈值（Hz）
  },
  pump: {
    minFlowRate: 50,  // 回流泵最小流量阈值（m³/h）
    unit: 'm³/h'
  },
  lab: {
    allowedDeviation: 0.3  // 化验允许偏差（30%）
  }
};
```

## 注意事项

1. **数据安全性**：本系统为本地部署，数据存储在本地 `data/wwtp.db` 文件中，请定期备份
2. **浏览器兼容性**：建议使用最新版本的 Chrome、Firefox 或 Safari 浏览器
3. **端口占用**：服务默认使用 3000 端口，如需修改请编辑 `server.js` 中的 `PORT` 变量

## 故障排查

### 无法启动服务

1. 检查 Node.js 版本是否 >= 14.0
2. 检查是否已执行 `npm install`
3. 检查端口 3000 是否被占用

### 数据导入失败

1. 检查CSV文件格式是否正确
2. 检查时间格式是否可解析（支持ISO格式和常见日期时间格式）
3. 查看浏览器控制台是否有错误信息

### 图表不显示

1. 检查浏览器是否支持Canvas
2. 检查Chart.js CDN是否可访问
3. 查看浏览器控制台是否有JavaScript错误
