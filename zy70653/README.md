# 工单录音匹配缺失归因抽样清单排查CLI

客服质检专用工具，用于排查工单、录音文件、坐席表三者之间的匹配问题，支持缺失原因自动归因、稳定抽样、Excel报告导出。

## 功能特性

### 核心功能
- **录音文件扫描**: 自动扫描录音目录，解析文件名中的工单号、坐席号、通话时长
- **工单表解析**: 支持CSV/Excel格式，自动识别工单号、坐席号、通话时长等字段
- **坐席表匹配**: 验证坐席号是否在坐席表中
- **智能匹配引擎**: 支持模糊匹配和严格匹配两种模式
- **缺失原因归因**: 自动分析匹配失败原因，给出置信度
- **稳定抽样算法**: 按缺失原因分层抽样，相同输入产生相同结果
- **Excel报告导出**: 6个工作表的完整报告，包含数据校验哈希

### 缺失原因分类
- 未找到录音文件
- 工单无工单号
- 坐席不在坐席表
- 工单号模糊匹配
- 坐席号不匹配
- 通话时长为0
- 综合匹配度不足

## 快速开始

### 1. 准备数据

**目录结构示例:**
```
./
├── recordings/              # 录音文件目录
│   ├── GD202401010001_agent001_30s.wav
│   ├── GD202401010002_agent002_45s.wav
│   └── ...
├── tickets.csv              # 工单表 (CSV/Excel)
├── agents.xlsx              # 坐席表 (CSV/Excel)
└── output/                  # 输出目录 (自动创建)
```

**工单表必需字段:**
- 工单号 / ticket_id
- 坐席号 / agent_id (可选)
- 通话时长 (可选)

**坐席表必需字段:**
- 坐席号 / agent_id
- 坐席姓名 (可选)

### 2. 执行完整流程

```bash
# 基本用法
python -m quality_check.cli run \
  --recording-dir ./recordings \
  --ticket-file ./tickets.csv \
  --agent-file ./agents.xlsx

# 指定抽样数量和方法
python -m quality_check.cli run \
  -r ./recordings \
  -t ./tickets.csv \
  -a ./agents.xlsx \
  -s 100 \
  -m weighted \
  -e 42

# 如果已安装包
qc-cli run -r ./recordings -t ./tickets.csv
```

### 3. 单独扫描录音

```bash
# 仅扫描录音目录，查看解析情况
python -m quality_check.cli scan -r ./recordings
```

## 命令参数说明

### run 命令

| 参数 | 简写 | 默认值 | 说明 |
|------|------|--------|------|
| --recording-dir | -r | 必填 | 录音文件目录路径 |
| --ticket-file | -t | 必填 | 工单表文件路径 (CSV/Excel) |
| --agent-file | -a | 可选 | 坐席表文件路径 (CSV/Excel) |
| --sample-size | -s | 50 | 抽样数量 |
| --sample-method | -m | stratified | 抽样方法: stratified/weighted/simple |
| --seed | -e | 42 | 随机种子，保证结果可复现 |
| --min-duration | -d | 10 | 最短通话时长(秒) |
| --output-dir | -o | ./output | 输出目录 |
| --filename | -f | 自动生成 | 输出文件名 |
| --strict | | | 严格匹配模式，关闭模糊匹配 |

### 抽样方法说明

1. **stratified (分层抽样)**: 按缺失原因类型分层，每层抽取相同数量样本，保证各类问题都有代表
2. **weighted (加权抽样)**: 对无录音、高置信度、低匹配分的工单增加权重，优先抽取这些问题工单
3. **simple (简单抽样)**: 按工单号排序后取前N条

## 报告说明

生成的Excel报告包含6个工作表：

### 1. 概览
- 生成时间
- 总工单数量
- 有录音/无录音工单数
- 完全匹配/部分匹配数量
- 录音匹配率
- 抽样数量

### 2. 缺失原因统计
- 各缺失原因的工单数量分布

### 3. 匹配结果详情
- 工单号、坐席号
- 匹配状态、匹配分数
- 是否有录音、匹配录音数量
- 录音文件名和路径
- 匹配问题描述
- 来源文件和行号

### 4. 缺失归因详情
- 工单号
- 缺失原因代码和描述
- 置信度百分比
- 匹配分数
- 详细信息（匹配问题、时长问题等）
- 来源文件和行号

### 5. 抽样清单
- 抽样编号
- 工单号、缺失原因
- 置信度、匹配分数
- 是否有录音、录音路径
- 来源文件和行号
- 随机种子（用于复现）

### 6. 数据校验追踪
各环节的MD5哈希值，用于：
- 验证两次运行结果是否一致
- 排查数据是否被修改
- 审计追踪

## 结果稳定性保证

本工具通过以下机制保证重复运行同一批材料时结果稳定：

1. **固定随机种子**: 默认seed=42，可手动指定
2. **确定性抽样算法**: 基于工单内容生成种子，相同工单始终被选中
3. **统一排序**: 所有输出按工单号排序
4. **哈希校验**: 各环节生成MD5哈希，可验证数据一致性

## 文件名解析规则

录音文件名自动解析支持以下格式：

**工单号:**
- `GD`/`KD`/`HD`/`OD`/`RD` + 数字 (如 GD202401010001)
- 纯数字串 (如 20240101000001)
- `ticket_`/`order_`/`work_` 前缀

**坐席号:**
- `agent_`/`坐席`/`cs_`/`op_` 前缀
- 4-8位数字串

**时长:**
- `XmYs` 格式 (如 3m45s)
- `X_Y_duration` 格式
- `dur_X` 格式

## 常见问题

### Q: 为什么录音匹配率很低？
A: 检查录音文件名格式是否符合解析规则，可以先用 `scan` 命令查看单个录音的解析结果。

### Q: 如何自定义工单号匹配规则？
A: 修改 `file_scanner.py` 中的 `TICKET_ID_PATTERNS` 正则表达式列表。

### Q: 相同数据两次运行抽样结果不一样？
A: 确保使用相同的 `--seed` 参数，并且输入文件内容完全一致。可通过报告中"数据校验追踪"工作表对比哈希值。

### Q: 支持哪些录音文件格式？
A: .wav, .mp3, .m4a, .aac, .flac, .ogg, .amr 及对应的大写格式。
