# 超时预算分配器 - 后端服务

过期审批催办列表的预算分配系统，支持版本冻结、人工修正备注、统一查询入口等功能。

## 功能特性

1. **预算分配核心算法**
   - 基于逾期天数、优先级、金额计算优先级评分
   - 自动识别预算编码（研发、运营、市场、人力等）
   - 部门预算限额检查与拦截

2. **人工修正不覆盖系统判断**
   - 人工修正时自动保存系统原始判断快照
   - 记录修正原因、修正人、修正时间
   - 不覆盖系统原始分配结果，保留完整审计轨迹

3. **版本冻结与复盘定位**
   - 支持对分配结果进行版本冻结
   - 冻结时记录冻结说明、操作人、算法哈希
   - 复盘时可通过执行时间线定位到具体版本冻结

4. **统一查询入口**
   - 支持按状态筛选（成功/失败）
   - 支持按部门筛选
   - 支持按是否有错误、是否有人工修正筛选
   - 异常路径和成功路径都能从同一入口查询

5. **数据持久化**
   - 本地重启后所有处理结论和材料摘要仍可查询
   - 所有历史操作记录完整保留

## API 接口

### 审批单管理
- `POST /api/v1/orders/` - 创建审批单
- `GET /api/v1/orders/` - 获取审批单列表

### 预算分配
- `POST /api/v1/allocate/` - 执行预算分配
  ```json
  {
    "order_ids": [1, 2, 3],
    "algorithm_version": "v1.0.0",
    "operator": "admin"
  }
  ```

### 人工修正
- `POST /api/v1/correct/` - 人工修正分配结果
  ```json
  {
    "order_id": 1,
    "corrected_amount": 9000,
    "corrected_budget_code": "OP-001",
    "correction_reason": "实际采购价格下调",
    "corrected_by": "预算专员"
  }
  ```

### 版本冻结
- `POST /api/v1/freeze/` - 冻结分配版本
  ```json
  {
    "allocation_id": 1,
    "freeze_note": "终审确认，锁定版本",
    "frozen_by": "财务总监"
  }
  ```

### 统一查询
- `POST /api/v1/query/` - 查询分配结果
  ```json
  {
    "status": "success",
    "department": "技术研发部",
    "has_error": false,
    "has_correction": true
  }
  ```

### 复盘追溯
- `GET /api/v1/review/{order_id}` - 获取审批单完整时间线

## 数据库模型

- **ApprovalOrder**: 审批单主表
- **BudgetAllocation**: 预算分配记录（支持多版本）
- **ManualCorrection**: 人工修正记录（含系统判断快照）
- **VersionFreeze**: 版本冻结记录
- **ProcessLog**: 操作日志

## 核心算法说明

### 逾期优先级评分计算

```
基础评分 = 逾期天数 × 10
优先级权重: critical=3.0, high=2.0, normal=1.0, low=0.5
金额权重: >10万=1.5, >5万=1.2
最终评分 = 基础评分 × 优先级权重 × 金额权重
```

### 预算编码自动识别

根据审批单主题关键词自动识别：
- 研发/开发/测试/技术/算法 → RD-002
- 推广/广告/营销/活动 → MK-003
- 工资/薪酬/招聘/社保 → HR-004
- 采购/设备/办公用品 → AD-005
- 差旅/招待/交通/住宿 → TR-006
- 其他 → OP-001

## 边界情况处理

1. **订单不存在**：优雅降级，记录错误日志
2. **预算超限**：分配失败，保留详细原因
3. **重复冻结**：拦截并提示已冻结
4. **修正未分配订单**：拦截并提示先执行分配
5. **系统异常**：捕获异常，记录完整错误信息
