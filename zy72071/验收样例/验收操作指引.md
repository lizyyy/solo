## 导出文件关键验收点

导出的 JSON 文件必须包含以下信息，接手人无需再问：

| 类别 | 关键字段 | 说明 |
|------|---------|------|
| 原始来源 | `source` | 数据来源说明 |
| 处理时间 | `createdAt`, `updatedAt` | 创建和更新时间 |
| 操作人 | `operator` | 方案经理许姐 |
| 关键判定 | `reviewNotes[].content` | 所有评审结论和补录备注 |
| 失败原因 | `importRecords[].errorMessage` | 导入失败的具体原因（如有） |
| 判断轨迹 | `judgmentTraces[]` | 每个异常的判断过程 |
| 交接信息 | `handoverRecords[]` | 交接复核记录 |
| 异常统计 | 从 points 统计 | 无隐藏，真实反映异常数量 |
