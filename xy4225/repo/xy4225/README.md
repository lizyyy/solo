# 字幕交付质检台

一个为短视频后期小组设计的本地桌面工具，用于自动化质检字幕交付内容。

## 功能特性

- **自动匹配**：选择项目目录后自动匹配视频(.mp4)和字幕(.srt)文件
- **多维度质检**：
  - 字幕时间轴重叠检测
  - 空字幕检测
  - 超长行检测（默认20字）
  - 时间轴越界/无效检测
  - 视频缺字幕/字幕缺视频检测
  - 客户术语表违禁词检测
  - 文件命名不一致检测
- **复核管理**：
  - 问题逐条标记状态：已修、忽略、需返工、待复核
  - 添加备注说明
  - 本地持久化存储，重启后继续复核
- **导出功能**：
  - 导出 Markdown 格式质检报告
  - 导出 CSV 格式问题清单
- **筛选查询**：按状态、严重程度、规则类型筛选问题

## 模块说明

### 1. 文件扫描模块 (`file_scanner.py`)
- 递归扫描项目目录下的所有文件
- 按文件名匹配视频和字幕对
- 识别术语表文件（含"术语表"、"违禁词"等关键词的txt/csv文件）
- 检测命名不一致问题

### 2. SRT解析模块 (`srt_parser.py`)
- 解析SRT字幕文件
- 支持UTF-8和GBK编码
- 解析时间码、序号、文本内容
- 检测序号不连续等解析错误

### 3. 规则校验模块 (`rules_checker.py`)
- 实现多种质检规则：
  - 字幕重叠检测
  - 空字幕检测
  - 超长行检测（可配置长度）
  - 时间轴越界检测
  - 结束时间早于开始时间检测
  - 字幕时长过短检测
  - 违禁词检测（加载术语表）
  - 字幕间隔过短检测

### 4. 复核存储模块 (`review_store.py`)
- 本地JSON文件持久化
- 支持四种状态：pending(待复核)、fixed(已修)、ignored(忽略)、rework(需返工)
- 项目文件变更检测
- 重启后自动加载历史复核状态

### 5. 导出模块 (`exporter.py`)
- Markdown报告：包含统计概览、问题详情、分类汇总
- CSV清单：完整的问题数据，便于导入Excel

### 6. GUI界面模块 (`gui/main_gui.py`)
- Tkinter实现的跨平台桌面界面
- 多线程质检，不阻塞UI
- 实时进度显示
- 快捷键支持

## 运行要求

- Python 3.7+
- 无需额外依赖（仅使用Python标准库：tkinter, pathlib, json, csv, threading等）

## 快速开始

### 1. 运行程序

```bash
cd /path/to/xy4225
python3 main.py
```

### 2. 使用示例目录测试

程序自带 `sample_project/` 目录，包含多种测试用例：

1. 启动程序后，点击 **"浏览..."** 按钮
2. 选择 `sample_project/` 目录
3. 点击 **"开始质检"** 按钮
4. 观察质检结果

示例中的问题分布：

| 文件 | 包含的问题类型 |
|------|---------------|
| episode_001.srt | 字幕重叠、违禁词、空字幕、超长行、时间轴无效、时长过短 |
| episode_002.srt | 超长行、违禁词 |
| episode_003.mp4 | 缺字幕 |
| episode_004.srt | 缺视频 |
| extra_video_001.mp4 | 命名不匹配 |

### 3. 完整操作流程示例

#### 步骤1：打开项目目录
- 点击菜单栏 **文件** → **打开项目目录** (或按 `Ctrl+O`)
- 选择包含视频、字幕和术语表的目录
- 程序会自动识别文件匹配关系

#### 步骤2：执行质检
- 点击 **"开始质检"** 按钮
- 程序会依次执行：
  1. 扫描并匹配文件
  2. 加载术语表（如果有）
  3. 解析每个SRT文件
  4. 应用所有质检规则
  5. 加载历史复核状态

#### 步骤3：复核问题
1. 在 **问题列表** 中点击任意问题
2. 查看下方 **问题详情** 和 **上下文**
3. 根据情况选择复核状态：
   - **✅ 已修**：问题已修复
   - **⏭️ 忽略**：无需处理（如误报、客户特批）
   - **🔄 需返工**：需要返工修改
   - **⏳ 待复核**：恢复为待处理状态
4. 可在 **备注** 框中填写说明，点击 **"保存备注"**
5. 状态会自动保存到项目目录下的 `.review_store.json`

#### 步骤4：筛选问题
使用 **筛选条件** 区域快速定位问题：
- **复核状态**：按待复核/已修/忽略/需返工筛选
- **严重程度**：按 error/warning 筛选
- **规则类型**：按具体质检规则筛选（如"字幕重叠"、"违禁词"等）

#### 步骤5：导出报告
1. 点击菜单栏 **文件** → **导出Markdown报告** (或按 `Ctrl+M`)
2. 选择保存位置，默认文件名格式为 `质检报告_{项目名}.md`
3. 如需导出CSV，选择 **文件** → **导出CSV问题清单** (或按 `Ctrl+S`)

#### 步骤6：重启后继续
- 下次打开同一项目目录时
- 程序会自动加载 `.review_store.json` 中的历史复核状态
- 可以继续上次的复核工作

### 4. 创建自己的项目目录结构

#### 术语表格式

支持纯文本或CSV格式，每行一个词：

```txt
# 注释行以#开头
大概
应该
可能
搞一下
搞定
```

或用逗号/竖线分隔：

```csv
大概,应该,可能|搞一下,搞定
```

## 规则配置

如需修改默认规则参数，可编辑 `modules/rules_checker.py` 中的常量：

```python
DEFAULT_MAX_LINE_LENGTH = 20    # 最大行长度
DEFAULT_MIN_SUBTITLE_GAP = 0.040 # 最小字幕间隔（秒）
```

## 注意事项

1. 视频文件目前仅用于匹配检测，不读取实际时长
2. 术语表文件名需包含"术语表"、"违禁词"、"glossary"或"forbidden"关键词
3. 复核记录保存在项目目录下的 `.review_store.json`，建议随项目一起备份
4. 如果项目文件内容有变化，建议重新运行质检

## 常见问题

**Q: 为什么有些视频没有匹配到字幕？**
A: 程序按文件名匹配（不含扩展名），请确保视频和字幕文件名完全一致。

**Q: 如何修改超长行的字数限制？**
A: 目前需要修改源码 `rules_checker.py` 中的 `DEFAULT_MAX_LINE_LENGTH` 常量。

**Q: 重启程序后复核记录不见了？**
A: 请确保选择的是同一个项目目录，且 `.review_store.json` 文件存在且未被删除。
