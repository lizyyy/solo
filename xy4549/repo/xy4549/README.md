# 行李转运班管理系统

小机场行李转运班全栈工具，用于管理到港航班、行李条码扫描、转盘分配、人工开箱/破损备注，以及防止中转行李被推到错转盘、超大件漏交接或同一条码重复装车。

## 功能特性

### 核心功能
- ✅ **航班管理**: 添加、查看到港航班清单
- ✅ **行李管理**: 条码扫描、中转标识、超大件标记、装车状态
- ✅ **转盘分配**: 按航班分配转盘号，自动更新关联行李
- ✅ **风险预警**: 自动检测以下风险并实时提醒：
  - 中转行李分配到错误转盘
  - 中转行李未分配转盘
  - 超大件行李未装车
  - 同一条码重复装车

### 辅助功能
- ✅ **导入示例数据**: 一键导入测试数据体验系统
- ✅ **导出功能**: 
  - 导出 Markdown 交接单
  - 导出 JSON 明细数据
- ✅ **备注管理**: 支持添加破损、开箱等备注
- ✅ **数据持久化**: SQLite 文件存储，刷新不丢失数据
- ✅ **统计概览**: 实时展示航班数、行李数、风险预警等关键指标

### 按维度展示
- **按航班展示**: 查看每个航班的行李明细
- **按转盘展示**: 查看每个转盘的分配情况
- **按风险展示**: 集中展示所有待处理的风险预警

## 技术栈

- **后端**: Node.js + Express
- **数据库**: SQLite (better-sqlite3)
- **前端**: 原生 HTML/CSS/JavaScript
- **其他**: CORS, Body-Parser, UUID

### 第四步：验证风险检测机制

#### 1. 错误转盘检测
1. 创建或编辑一个中转行李
2. 设置中转航班为已存在的航班号（如 MU5678）
3. 故意设置错误的转盘号（与中转航班分配的转盘不同）

1. 标记一个行李为"超大件"
2. 不进行装车操作
3. 检查 **风险预警** 页面是否出现"超大件行李未装车"的预警

1. 创建两条使用相同条码的行李（注意：系统会阻止直接添加重复条码，需要通过编辑或示例数据触发）
2. 将两条都标记为已装车
3. 检查是否出现"同一条码重复装车"的严重预警

## 数据库表结构

### flights (航班表)
- `id`: UUID 主键
- `flight_no`: 航班号
- `arrival_time`: 到达时间
- `origin`: 出发地
- `destination`: 目的地
- `status`: 状态

### baggage (行李表)
- `id`: UUID 主键
- `barcode`: 条码号（唯一）
- `flight_id`: 所属航班
- `transfer_flight`: 中转航班
- `carousel`: 转盘号
- `is_oversize`: 是否超大件
- `is_transfer`: 是否中转
- `is_loaded`: 是否已装车
- `loaded_time`: 装车时间

### carousel_assignments (转盘分配表)
- `id`: UUID 主键
- `flight_id`: 航班
- `carousel_number`: 转盘号
- `assigned_by`: 分配人

### notes (备注表)
- `id`: UUID 主键
- `baggage_id`: 关联行李
- `note_type`: 备注类型 (damage/opening/other)
- `content`: 内容
- `is_resolved`: 是否已解决

### risk_alerts (风险预警表)
- `id`: UUID 主键
- `baggage_id`: 关联行李
- `alert_type`: 预警类型
- `description`: 描述
- `risk_level`: 风险等级 (critical/high/medium)
- `is_acknowledged`: 是否已确认

## 风险检测算法

系统会在以下操作后自动重算风险：
1. 新增/修改行李
2. 分配转盘
3. 标记装车

**检测规则**：

| 风险类型 | 触发条件 | 风险等级 |
|----------|----------|----------|
| 中转行李未分配转盘 | is_transfer = true 且 carousel 为空 | HIGH |
| 超大件未装车 | is_oversize = true 且 is_loaded = false | HIGH |
| 同一条码重复装车 | 同一条码有多条记录且都已装车 | CRITICAL |
| 中转行李错误转盘 | 中转航班有指定转盘但行李转盘不符 | HIGH |

## 常见问题

### Q: 数据库文件在哪里？
A: SQLite 数据库文件 `baggage.db` 会在首次运行时自动创建在项目根目录。

### Q: 如何重置数据？
A: 删除 `baggage.db` 文件，重启服务即可。

### Q: 如何添加更多示例数据？
A: 可以修改 `server.js` 中的 `/api/import/sample` 接口，然后点击"导入示例数据"按钮。

### Q: 支持条码枪扫描吗？
A: 支持！条码扫描枪本质是键盘输入，在"扫描条码"输入框聚焦时扫描即可。
