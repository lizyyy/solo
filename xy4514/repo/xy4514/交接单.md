### 二、系统功能清单

#### 1. 数据导入功能

| 序号 | 功能模块 | 支持格式 | 说明 |
|------|----------|----------|------|
| 1 | 调阅申请导入 | CSV / JSON | 导入调阅申请单数据 |
| 2 | 库房温湿度导入 | CSV / JSON | 导入库房温湿度记录 |
| 3 | 密级授权导入 | CSV / JSON | 导入密级授权数据 |
| 4 | 虫霉处理导入 | CSV / JSON | 导入虫霉处理记录 |
| 5 | 出库封签导入 | CSV / JSON | 导入出库封签记录 |

#### 2. 调阅申请状态查询

| 序号 | 查询功能 | 说明 |
|------|----------|------|
| 1 | 单条查询 | 根据申请单号查询详细信息 |
| 2 | 列表查询 | 分页列出所有调阅申请 |
| 3 | 状态筛选 | 按状态筛选调阅申请 |

#### 3. 状态自动判断逻辑

| 判断条件 | 触发场景 | 状态结果 |
|----------|----------|----------|
| 调阅人无有效密级授权 | 申请密级高于授权密级 | 需补充授权 |
| 档案存在虫霉问题未处理 | 处理中/隔离中/待处理 | 需先隔离处理 |
| 档案有有效出库封签 | 封签状态为 active | 要主管复核 |
| 存在多个问题 | 以上任意两个及以上 | 要主管复核 |
| 全部条件满足 | 无上述问题 | 可以调阅 |

#### 4. 人工复核功能

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 提交复核意见 | 支持多种复核结果选择 |
| 2 | 保存复核备注 | 支持文字备注输入 |
| 3 | 主管复核标记 | 可标记是否需要主管复核 |
| 4 | 主管复核记录 | 记录主管复核信息 |

#### 5. 审计日志功能

| 序号 | 功能 | 说明 |
|------|------|------|
| 1 | 操作记录 | 记录所有导入、查询、复核、导出操作 |
| 2 | 操作人追踪 | 记录操作人信息 |
| 3 | IP地址 | 记录操作IP |
| 4 | JSON导出 | 支持按条件导出审计日志 |
| 5 | 条件筛选 | 支持日期、模块、操作类型筛选 |

### 五、业务规则说明

#### 1. 密级等级规则

| 密级 | 等级值 | 授权要求 |
|------|--------|----------|
| 公开 | 0 | 无需授权 |
| 内部 | 1 | 需内部级及以上授权 |
| 秘密 | 2 | 需秘密级及以上授权 |
| 机密 | 3 | 需机密级及以上授权 |
| 绝密 | 4 | 需绝密级授权 |

**规则：只有用户授权密级 >= 档案密级时，才允许调阅

#### 2. 温湿度标准

| 指标 | 正常范围 | 注意范围 | 异常范围 |
|------|----------|----------|----------|
| 温度 | 14-24℃ | <14 或 >24℃ | <10 或 >28℃ |
| 湿度 | 45-60% | <45 或 >60% | <40 或 >65% |

#### 3. 状态码说明

| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 400 | 请求参数错误 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |


```
http://localhost:5000
```

### 八、测试用例示例

#### 测试用例1：正常调阅申请

**场景**：张三申请调阅公开档案

**步骤**：
1. 导入密级授权数据
2. 导入调阅申请（密级为"公开"）
3. 调用查询接口

**预期结果**：
- status: "approved"
- status_description: "可以调阅"
- can_access: true

#### 测试用例2：需补充授权

**场景**：李四申请调阅机密档案，但只有秘密级授权

**步骤**：
1. 导入密级授权（李四授权为"秘密"）
2. 导入调阅申请（密级为"机密"）
3. 调用查询接口

**预期结果**：
- status: "needs_authorization"
- status_description: "需补充授权"
- needs_authorization: true

#### 测试用例3：需隔离处理

**场景**：申请调阅的档案处于隔离期

**步骤**：
1. 导入虫霉处理记录（处理状态为"已隔离"，隔离结束日期在未来）
2. 导入调阅申请（对应档案号匹配
3. 调用查询接口

**预期结果**：
- status: "needs_quarantine"
- status_description: "需先隔离处理"
- needs_quarantine: true

#### 测试用例4：需主管复核

**场景**：档案有有效出库封签

**步骤**：
1. 导入出库封签记录（封签状态为"active"）
2. 导入调阅申请（对应档案号匹配）
3. 调用查询接口

**预期结果**：
- status: "needs_supervisor"
- status_description: "要主管复核"
- needs_supervisor: true
