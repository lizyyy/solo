# 冰箱样本温控交接台

医院检验科夜班专用离线桌面工具，用于管理冰箱样本、温度记录和交接流程。

## 功能特性

### 1. 数据导入
- **扫码枪CSV**: 导入扫码枪导出的样本数据
- **温度记录JSON**: 导入冰箱温度监测数据
- **交接表CSV**: 导入样本交接记录表

### 2. 自动检测
- **超时离柜检测**: 检测样本离柜时间是否超过阈值（默认30分钟）
- **温度越界检测**: 检测冰箱温度是否超出正常范围（默认2-8℃）
- **架位冲突检测**: 检测同一架位是否被多个样本占用
- **缺签检测**: 检测交接记录超过24小时未确认签字

### 3. 数据管理
- 样本状态追踪（在柜/离柜）
- 冰箱/架位管理
- 交接记录管理
- 值班备注持久化存储

### 4. 导出功能
- **Markdown交接单**: 生成格式化的交接报告
- **CSV风险清单**: 导出风险统计摘要
- **CSV告警记录**: 导出完整告警历史

## 本地验证流程

### 步骤1: 启动程序

运行 `python main.py` 启动GUI界面。

### 步骤2: 导入示例数据

程序提供了三类示例数据在 `sample_data/` 目录下：

1. **导入样本数据**
   - 菜单: `文件` → `导入扫码枪CSV`
   - 选择文件: `sample_data/samples_scan.csv`
   - 点击确认，应提示导入成功

2. **导入温度记录**
   - 菜单: `文件` → `导入温度记录JSON`
   - 选择文件: `sample_data/temperature_logs.json`
   - 点击确认，应提示导入成功

3. **导入交接记录**
   - 菜单: `文件` → `导入交接表CSV`
   - 选择文件: `sample_data/handover_records.csv`
   - 点击确认，应提示导入成功

### 步骤3: 添加冰箱和架位

1. **添加冰箱**
   - 切换到 `冰箱/架位` 标签页
   - 点击 `添加冰箱` 按钮
   - 填写信息:
     - 冰箱ID: `FRIDGE01`
     - 名称: `冷藏冰箱1号`
     - 最低温度: `2`
     - 最高温度: `8`
   - 点击 `保存`

   - 再添加一个冰箱:
     - 冰箱ID: `FRIDGE02`
     - 名称: `冷藏冰箱2号`
     - 最低温度: `2`
     - 最高温度: `8`

2. **添加架位**
   - 在左侧冰箱列表中选择 `FRIDGE01`
   - 点击 `添加架位` 按钮
   - 填写信息:
     - 架位ID: `RACK01`
     - 容量: `20`
   - 点击 `保存`

   - 再添加两个架位:
     - RACK02 (FRIDGE01)
     - RACK03 (FRIDGE02)

### 步骤4: 运行规则检测

1. 点击工具栏上的 `运行规则检测` 按钮
2. 应该检测到以下告警（基于示例数据）:
   - **架位冲突**: BL001和BL004都在RACK01-A01位置
   - **超时离柜**: BL005离柜时间超过阈值
   - **温度越界**: FRIDGE01曾记录9.5℃，FRIDGE02曾记录1.0℃
   - **缺签检测**: 部分交接记录超过24小时未确认

3. 检查 `告警管理` 标签页，应该显示所有检测到的告警

### 步骤5: 添加值班备注

1. 切换到 `值班备注` 标签页
2. 点击 `添加备注` 按钮
3. 填写信息:
   - 值班人员: `张医生`
   - 值班日期: `2026-05-03`
   - 勾选 `标记为重要`
   - 内容: `夜班值班注意事项: FRIDGE01温度异常，已通知维修人员。`
4. 点击 `保存`

### 步骤6: 导出文件

1. **导出Markdown交接单**
   - 菜单: `导出` → `导出Markdown交接单`
   - 选择保存路径
   - 确认后，应在指定位置生成 `.md` 文件

2. **导出CSV风险清单**
   - 菜单: `导出` → `导出CSV风险清单`
   - 选择保存路径
   - 确认后，应在指定位置生成 `.csv` 文件

3. **导出告警记录CSV**
   - 菜单: `导出` → `导出告警记录CSV`
   - 选择保存路径
   - 确认后，应在指定位置生成 `.csv` 文件

### 步骤7: 验证数据持久化

1. 点击工具栏上的 `保存数据` 按钮
2. 关闭程序
3. 重新运行 `python main.py`
4. 检查数据是否保留:
   - 样本数据应该仍然存在
   - 冰箱和架位配置应该保留
   - 告警记录应该存在
   - 值班备注应该存在

### 步骤8: 运行单元测试

```bash
cd /path/to/xy4267
pytest tests/ -v
```

所有测试用例应该通过。

## 数据文件格式说明

### 扫码枪CSV格式

| 列名 | 说明 | 示例 |
|------|------|------|
| 样本ID | 样本唯一标识 | BL001 |
| 样本类型 | 血样/试剂/其他 | 血样 |
| 架位ID | 所属架位 | RACK01 |
| 位置 | 架位内位置 | A01 |
| 扫描时间 | 扫码时间 | 2026-05-03 08:30:00 |
| 状态 | 在柜/离柜 | 在柜 |

### 温度记录JSON格式

```json
[
    {
        "fridge_id": "FRIDGE01",
        "temperature": 4.5,
        "timestamp": "2026-05-03 08:00:00"
    }
]
```

### 交接表CSV格式

| 列名 | 说明 | 示例 |
|------|------|------|
| 样本ID | 交接的样本ID | BL001 |
| 移交人 | 移交人员姓名 | 张医生 |
| 接收人 | 接收人员姓名 | 李医生 |
| 交接时间 | 交接发生时间 | 2026-05-02 20:00:00 |
| 状态 | 待交接/交接中/已交接 | 已交接 |
| 备注 | 交接备注 | 白班转夜班 |

## 配置说明

### 默认规则参数

- **超时离柜阈值**: 30分钟
- **冰箱正常温度范围**: 2-8℃
- **缺签检测阈值**: 24小时

这些参数可以在 `src/rules/rule_engine.py` 中修改。

### 数据存储位置

默认情况下，数据存储在用户目录下的 `.fridge_handover` 文件夹中：
- Windows: `C:\Users\<用户名>\.fridge_handover\`
- macOS/Linux: `~/.fridge_handover/`

## 常见问题

### Q1: 程序无法启动？

请检查：
- Python版本是否为3.8+
- 依赖包是否已安装
- Tkinter是否可用（Python内置库，通常默认安装）

### Q2: 导入数据失败？

请检查：
- 文件编码是否为UTF-8
- CSV文件是否使用逗号分隔
- 日期格式是否正确（支持多种格式）

### Q3: 数据没有保存？

请确保：
- 点击了 `保存数据` 按钮
- 或者在退出时选择保存数据
- 检查数据存储目录是否有写入权限
