# 家庭药箱 - 用药核对工具

一个本地运行的家庭药箱管理和用药核对工具，帮助您管理家庭成员的药品信息、用药计划，并提供智能的用药风险检查。

## 功能特性

### 1. 家庭成员管理
- 维护家庭成员档案
- 记录年龄段、过敏信息、慢病标签、备注
- 支持增删改查操作

### 2. 药品管理
- 录入药品信息：药名、通用成分、规格、库存数量、有效期
- 记录适用人群、禁忌标签、建议间隔时间
- 支持 CSV 导入药品数据
- 药品状态标识：正常、即将过期、已过期、库存不足

### 3. 用药计划
- 为家庭成员安排用药计划
- 支持每天多次、饭前饭后、开始/结束日期
- 在今日卡片中标记已服用或漏服
- 按成员和状态筛选计划

### 4. 智能规则检查
- **成分重复检查**：检测同时使用的药品是否含有相同成分
- **过敏/禁忌检查**：检查药品是否与家庭成员的过敏信息或禁忌标签冲突
- **年龄适宜性检查**：验证药品适用人群是否匹配家庭成员年龄段
- **服药间隔检查**：确认同成分药品的服药间隔是否足够
- **过期药品检查**：提醒已过期或即将过期的药品
- **库存不足检查**：提示库存数量低于警戒线的药品

### 5. 数据导入导出
- JSON 备份导入导出
- CSV 药品导入
- Markdown 格式用药清单导出
- HTML 格式用药清单导出

### 6. 本地数据持久化
- 所有数据保存在浏览器 localStorage 中
- 刷新页面数据不丢失
- 首次运行自动加载示例数据

## 技术栈

- **前端框架**：Vue 3 (Composition API)
- **构建工具**：Vite
- **样式框架**：Tailwind CSS
- **路由管理**：Vue Router
- **数据存储**：浏览器 LocalStorage

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

应用将在 `http://localhost:5173` 运行。

### 构建生产版本

```bash
npm run build
```

## 模块说明

### 存储模块 (`storage.js`)

封装了 localStorage 操作，提供：
- 应用初始化（首次运行加载示例数据）
- 家庭成员 CRUD 操作
- 药品 CRUD 操作
- 用药计划 CRUD 操作
- 服药记录管理
- 数据导出导入

### 规则引擎 (`rulesEngine.js`)

实现6种检查规则：
1. `checkDuplicateIngredients` - 成分重复检查
2. `checkAllergyContraindications` - 过敏/禁忌检查
3. `checkAgeAppropriateness` - 年龄适宜性检查
4. `checkDoseIntervals` - 服药间隔检查
5. `checkExpiredMedicines` - 过期药品检查
6. `checkLowStock` - 库存不足检查

每个规则返回风险结果对象，包含：
- 风险级别（高/中/低）
- 风险类型
- 标题
- 详细描述
- 受影响的成员、药品、计划

### 导入导出模块 (`importExport.js`)

- `exportToJSON` / `importFromJSON` - JSON 备份
- `importMedicinesFromCSV` - CSV 药品导入（支持多种列名格式）
- `exportMarkdownChecklist` - Markdown 格式清单
- `exportHTMLChecklist` - HTML 格式清单

### 数据模型 (`models.js`)

工厂函数创建标准数据对象：
- `createFamilyMember` - 家庭成员
- `createMedicine` - 药品
- `createMedicationPlan` - 用药计划
- `createDose` - 服药记录
- `createRiskResult` - 风险结果

## 自定义配置

### 常量定义 (`constants.js`)

可以根据需要修改：
- `AGE_GROUP` - 年龄段分类
- `AGE_GROUP_RANGES` - 年龄段范围
- `APPLICABLE_POPULATION` - 药品适用人群
- `RISK_LEVEL` - 风险级别
- `DOSE_STATUS` - 服药状态

### Tailwind 主题 (`tailwind.config.js`)

自定义颜色：
- `primary` - 主色调（蓝色系）
- `danger` - 危险色（红色系）
- `warning` - 警告色（黄色系）
- `success` - 成功色（绿色系）

## 注意事项

1. **数据存储**：所有数据保存在浏览器 localStorage 中，清除浏览器数据会导致数据丢失，建议定期导出备份。

2. **示例数据**：首次运行时会自动加载示例数据，用于演示和测试。实际使用前建议：
   - 导出备份
   - 清除所有数据
   - 重新录入真实数据

3. **规则检查**：规则检查结果仅供参考，不能替代专业医疗建议。如有疑问，请咨询医生或药师。

4. **浏览器兼容性**：建议使用现代浏览器（Chrome、Firefox、Safari、Edge）以获得最佳体验。
