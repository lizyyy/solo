# 应急广播覆盖游戏 PRD

## 1. 产品概述
一款基于 Canvas 的 2D 放置策略小游戏，模拟社区应急广播部署与噪声投诉平衡。
- 面向：社区演练参与者、城市管理教学、策略游戏爱好者
- 核心价值：在「覆盖盲区、噪声超标、设备数量受限」三重约束下训练放置决策能力

## 2. 核心功能

### 2.1 核心模块
1. **关卡地图**：手绘小区地图，含楼栋、噪声敏感区、可放置点（灯柱/屋顶/绿地）
2. **放置交互**：点击可放置点部署广播，拖动调节功率（半径），右键回收
3. **覆盖计算**：按圆形覆盖楼栋数量与人口，实时计算覆盖率
4. **噪声投诉**：楼栋人口叠加噪声强度，超过阈值触发投诉
5. **回合/评分**：每关固定回合或限时，结束后给出报告与星级
6. **失败原因**：失败时给出「盲区/投诉/预算」三类原因提示
7. **历史回放**：记录玩家每步操作，可倒放查看
8. **报告导出**：导出 JSON 或文本报告

### 2.2 页面与模块
| 页面 | 模块 | 说明 |
|------|------|------|
| 主菜单 | 关卡选择、继续游戏、教程 | 入口 |
| 对局页 | Canvas 地图、HUD、回合控制、工具条 | 核心游戏界面 |
| 结算页 | 得分、星级、失败原因、重玩、下一关 | 回合结束 |
| 报告页 | 导出文本、JSON 下载 | 报告 |
| 历史页 | 列表回放、时间轴 | 历史记录 |

## 3. 核心流程

```mermaid
flowchart TD
    "主菜单" --> "选择关卡"
    "选择关卡" --> "进入对局"
    "进入对局" --> "放置广播/调节功率"
    "放置广播/调节功率" --> "实时计算覆盖与投诉"
    "实时计算覆盖与投诉" --> "回合结束"
    "回合结束" --> "评分结算"
    "评分结算" --> "成功?"
    "成功?" -- "是" --> "下一关/报告"
    "成功?" -- "否" --> "失败原因/回放"
```

## 4. 界面设计
- 风格：深色工业监控台 + 荧光绿信息高亮，营造"应急指挥中心"氛围
- 主色：#0d1117 背景、#22c55e 成功、#ef4444 报警、#fbbf24 警告
- 字体：`JetBrains Mono` + `Noto Sans SC`
- 布局：左侧 Canvas，右侧 HUD（计分/回合/投诉面板），顶部工具条
- 交互：Canvas 内 2D 放置，鼠标悬停显示覆盖圈预览
