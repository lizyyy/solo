# 应急广播覆盖游戏

一个基于 HTML5 Canvas + React 的 2D 放置策略小游戏。模拟社区应急演练中的广播部署，在「覆盖盲区、噪声投诉、预算限制」三重约束下寻找最优解。

## 启动

```bash
# 安装依赖（已预装，如遇问题重新执行）
npm install

# 开发模式（默认 http://localhost:5173）
npm run dev

# 构建生产包
npm run build

# 本地预览生产包
npm run preview
```

## 玩法

- **主菜单** → 选择三个难度递增的关卡之一。
- **对局页**：
  - 左侧 Canvas 地图：楼栋（方块）、可放置点（小圆点）、敏感区（黄/红色虚线圈）。
  - 右侧 HUD：实时覆盖率、投诉数、预算、得分；半径滑块；回合控制。
- **操作**
  - 鼠标**左键**单击空放置点 → 放置新设备（使用当前半径）。
  - 鼠标**左键**单击已放置设备 → 选中后可调半径或撤回。
  - 鼠标**右键**或 **Shift + 左键** → 撤回设备。
  - 鼠标**滚轮**在设备上 → 快速调节半径。
  - 顶部「暂停/继续/重开/结算」按钮控制流程。
- **结算**
  - 达到「最低覆盖率 + 不超过投诉上限 + 不超预算」即通过，按表现得 1~3 星。
  - 失败时明确展示「覆盖不足 / 噪声超标 / 超预算」中的具体原因。
  - 可导出 **TXT** 或 **JSON** 报告。

## 关卡说明

| ID | 名称 | 楼栋 | 敏感区 | 预算 | 最低覆盖 | 说明 |
|----|------|------|--------|------|---------|------|
| l1 | 晨光小区 | 7 | 2 | 420 | 70% | 新手关，低密度 |
| l2 | 锦绣雅苑 | 14 | 3 | 520 | 80% | 中等密度 |
| l3 | 云海豪庭 | 20 | 4 | 480 | 90% | 高难度，投诉上限为 0 |

## 规则

- **覆盖判定**：楼栋矩形中心落在任一广播圆形覆盖半径内即视为已覆盖。
- **噪声**：对每个敏感区累加所有广播的贡献，噪声值 = Σ(1 - d/r)（d≤r）。超过 `threshold` 即产生投诉。
- **花费**：`60 + radius * costPerPx`，半径越大越贵。
- **评分**：
  - 覆盖分 = 覆盖率 × 60
  - 投诉扣 = 投诉数 × 15
  - 预算扣 = 超预算部分按单价换算扣分
  - 最终分 = max(0, 覆盖分 - 投诉扣 - 预算扣)
  - 三星：覆盖率 ≥ min+25%、0 投诉、花费 ≤ 预算 80%

## 历史回放

- 完成对局后自动保存到浏览器 `localStorage`（最多保留最近 30 条）。
- 在主菜单右上角「历史」进入回放列表，拖动时间轴滑块可逐步回看每一次放置/撤回/调半径操作，并跳转到对局查看对应布局。

## 边界案例

1. **一个设备都不放**：覆盖率 0 → 失败原因「覆盖不足」。
2. **只追求覆盖率**：把半径拉到最大 → 花费超预算 → 失败原因「超预算」。
3. **半径太小放得近**：虽然便宜但覆盖不到远处楼栋 → 失败原因「覆盖不足」。
4. **广播放在敏感区附近**：噪声阈值低，投诉数超标 → 失败原因「噪声超标」。
5. **预算花光仍有盲区**：失败原因「覆盖不足」，提示具体未覆盖的楼栋名称。
6. **全部覆盖 + 0 投诉 + 节省预算**：三星通关。
7. **边界覆盖**：楼栋中心恰好落在半径边缘（距离 = 半径）仍算覆盖。
