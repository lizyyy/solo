# 美术培训室画材包分发 API

## 项目概述

这是一个为美术培训室设计的画材包分发管理系统，提供完整的REST API接口，支持画材包分发、库存管理、异常处理、数据导入导出等功能。

## 核心特性

### 1. 异常处理重点
- **学生跨班补领检测**: 防止使用其他学生的分发记录进行补领
- **库存扣重保护**: 分发时原子操作，防止超发
- **分发清单一致性**: 禁止静默覆盖原有分发记录
- **重复分发冲突检测**: 同一学生领取同类型画材包时自动检测

### 2. 业务字段
所有字段均使用业务语言命名，包含：
- 班级信息（班级编号、班级名称、授课教师）
- 学生信息（学号、姓名、年级、所属班级）
- 画材包类型（包类型编号、包类型名称、适用课程、包含物品清单、标准单价）
- 库存信息（仓库位置、当前库存量、安全库存线）
- 分发记录（分发记录编号、分发时间、分发人、领取状态、补领标记、原分发记录编号、备注）

### 3. 导出格式
- JSON格式：包含完整业务字段
- 表格格式（Markdown）：便于阅读和打印

## API 接口列表

### 基础接口
- `GET /health` - 服务健康检查

### 基础数据查询
- `GET /api/classes` - 查询班级列表
- `GET /api/students` - 查询学生列表
- `GET /api/packages` - 查询画材包类型及库存

### 分发管理
- `POST /api/distribute` - 分发画材包
  - 请求参数：学号、包类型编号、分发人、是否补领、原分发记录编号
  - 异常处理：学生不存在、画材包不存在、库存不足、重复分发冲突、跨班补领冲突、补领包类型不一致
- `GET /api/distributions` - 查询分发记录
  - 支持筛选：学号、班级编号、包类型编号、领取状态

### 导入导出
- `GET /api/export` - 导出发分发记录
  - 支持格式：json（默认）、table
  - 支持筛选：开始日期、结束日期
- `POST /api/import` - 导入分发记录
  - 文件格式：JSON数组
  - 自动验证：必填字段、学生存在、画材包存在、库存充足、重复记录检测

### 异常管理
- `GET /api/errors` - 查询分发异常日志

## 验收测试用例

测试脚本 `test_api.py` 包含以下验证场景：

1. **正常分发记录**: 小丽领取油画包（成功场景）
2. **冲突记录**: 小明已领取素描包，再次尝试领取（触发DUPLICATE_DISTRIBUTION错误）
3. **跨班补领冲突**: 尝试用小明的分发记录给小红补领（触发CROSS_STUDENT_REISSUE错误）
4. **导入坏行**:
   - 缺少学号字段（触发MISSING_REQUIRED_FIELDS错误）
   - 学号不存在（触发STUDENT_NOT_FOUND错误）
   - 重复分发记录（触发DUPLICATE_RECORD错误）

## 错误响应格式

所有错误响应均包含：
```json
{
    "错误码": "错误类型代码",
    "错误信息": "人性化错误描述",
    "建议操作": "操作指引",
    "异常编号": "关联的异常日志编号（如适用）"
}
```

## 数据库表结构

1. **班级** - 班级基本信息
2. **学生** - 学生基本信息，关联班级
3. **画材包类型** - 画材包定义
4. **画材库存** - 库存管理
5. **画材包分发记录** - 分发历史记录
6. **分发异常日志** - 所有异常操作记录
