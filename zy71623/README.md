# 🌉 多边形修桥挑战

一款几何学习类浏览器小游戏，通过拖拽多边形拼接桥梁的方式，让学生直观理解几何形状、面积计算和结构力学的关系。

## 🚀 快速开始

### 启动项目

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

开发服务器启动后，访问 `http://localhost:3000` 即可开始游戏。

### 构建项目

```bash
npm run build
```

## 📖 游戏指南

### 操作说明

| 操作 | 说明 |
|------|------|
| 拖拽 | 从左侧工具箱拖拽多边形到画布上 |
| 移动 | 点击并拖拽已放置的多边形 |
| R键 | 旋转选中的多边形（每次15°） |
| Delete键 | 删除选中的多边形 |
| 方向键 | 微调选中多边形的位置 |

### 游戏流程

1. **选择关卡**：从关卡选择页面选择适合的难度
2. **搭建桥梁**：使用左侧工具箱中的多边形块搭建桥梁
3. **校验桥梁**：点击「校验桥梁」按钮检查几何规则
4. **承重测试**：校验通过后点击「开始承重测试」
5. **查看报告**：测试结束后查看详细的分析报告

### 样例数据加载

在信息面板的「📚 加载样例」区域，可以快速加载预设的示例：

- **✅ 正确示例**：展示一座通过测试的桥梁
- **❌ 面积超限**：演示面积预算超标的情况
- **❌ 桥梁断开**：演示桥梁存在缺口的情况
- **❌ 多边形重叠**：演示多边形重叠的情况

## 🎯 游戏规则

### 几何校验规则

1. **面积预算**：所有使用的多边形总面积不能超过关卡预算
2. **连通性**：桥梁必须连接左右两个桥墩
3. **无重叠**：多边形之间不能发生重叠
4. **无孤立块**：所有多边形必须连接到主桥梁结构

### 承重评分

- **应力计算**：基于支撑点和载荷分布计算每个多边形的应力
- **断裂判定**：应力超过 100% 时多边形断裂，桥梁失效
- **效率评分**：综合面积使用效率和最大应力给出评分

## 📊 失败记录与报告

### 失败原因分析

游戏会自动检测并解释以下常见失败原因：

1. **📐 面积超限** - 多边形总面积超过预算
   - 建议：使用更小的多边形或减少块数
   - 几何原理：三角形结构比矩形更节省材料

2. **🔗 桥梁未连通** - 多边形没有连接起点和终点
   - 建议：确保每个多边形都与相邻块或桥墩相连
   - 几何原理：顶点对齐有助于建立连接

3. **⚠️ 多边形重叠** - 两个或多个多边形发生重叠
   - 建议：调整位置或旋转角度
   - 几何原理：重叠区域造成材料浪费

4. **💥 结构断裂** - 某个多边形应力过载
   - 建议：增加支撑结构或使用更强的多边形
   - 物理原理：三角形桁架能有效分散应力

5. **🕳️ 桥面缺口** - 载重车行驶时失去支撑
   - 建议：检查桥面是否存在空隙
   - 几何原理：确保连续的通行路径

### 报告导出

测试结束后，点击「📥 导出报告」可获得详细的 JSON 格式报告，包含：

- 关卡信息和难度
- 测试结果和效率评分
- 每个多边形的应力数据
- 完整的回放帧数据
- 校验错误详情

## 🧠 核心算法

### 几何计算

- **多边形面积**：鞋带公式（Shoelace Formula）
- **点在多边形内**：射线法（Ray Casting）
- **多边形相交**：分离轴定理（Separating Axis Theorem）
- **坐标变换**：2D 旋转矩阵和平移变换

### 物理模拟

- 简化桁架模型
- 基于支撑点的应力分布计算
- 实时断裂检测
- 60fps 回放数据生成
