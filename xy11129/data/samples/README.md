# 骑行俱乐部骑行轨迹整理 - 样例数据说明

## 概述
本目录包含用于测试骑行轨迹整理CLI工具的各类样例数据，覆盖骑行俱乐部实际场景中可能遇到的各种数据异常情况。

## 数据文件说明

### 1. normal_ride.csv - 正常骑行轨迹
**场景说明**：标准的周末骑行活动记录，数据完整无异常。

**包含字段**：
- timestamp: 时间戳
- latitude: 纬度
- longitude: 经度
- altitude: 海拔（米）
- speed: 速度（km/h）
- rider_id: 骑手编号
- ride_id: 骑行活动编号

**预期结果**：
- 全部记录有效
- 无错误报告
- 输出完整清洗后文件

---

### 2. power_loss_ride.csv - 设备断电场景
**场景说明**：骑手在骑行过程中GPS设备两次断电重启，造成时间断层。

**异常特征**：
- 07:00:20 → 07:45:00：45分钟断层（第一次断电）
- 07:45:30 → 08:30:00：45分钟断层（第二次断电）

**预期结果**：
- 检测到2次设备断电事件
- 错误日志中记录 POWER_LOSS_DETECTED
- 有效记录仍被保留（断电是设备问题，非数据问题）

---

### 3. reverse_route.csv - 路线反向场景
**场景说明**：GPS设备方向传感器异常，导致路线记录出现反向折返。

**异常特征**：
- 08:04 到达最远点后连续向起点方向返回
- 连续3个时间点距离起点距离持续减少

**预期结果**：
- 检测到至少1次路线反向异常
- 错误日志中记录 REVERSE_ROUTE_DETECTED
- 可用于后续路线修正算法测试

---

### 4. missing_columns.csv - 缺列场景
**场景说明**：旧版设备导出数据缺少 ride_id 字段。

**缺失字段**：
- ride_id: 骑行活动编号（业务核心主键）

**预期结果**：
- 检测到 MISSING_COLUMNS 错误
- 列出具体缺失字段名称
- 文件处理标记为失败

---

### 5. duplicate_rows.csv - 重复行场景
**场景说明**：数据导出时网络重传造成记录重复。

**重复特征**：
- 第1行与第3行完全重复
- 第2行与第5行完全重复
- 使用 (rider_id + ride_id + timestamp) 作为去重键

**预期结果**：
- 检测到2条重复记录
- 错误日志中记录 DUPLICATE_RECORD
- 输出文件中仅保留唯一记录

---

### 6. empty_file.csv - 空文件场景
**场景说明**：设备故障导致导出空文件。

**预期结果**：
- 检测到 EMPTY_FILE 错误
- 文件处理标记为失败
- 不影响后续文件处理（遇错继续模式）

---

### 7. invalid_records.csv - 无效记录场景
**场景说明**：包含各种字段异常的混合数据文件。

**异常类型**：
| 行号 | 异常类型 | 异常字段 | 说明 |
|------|----------|----------|------|
| 2 | 空值 | latitude | 纬度为空 |
| 3 | 空值 | longitude | 经度为空 |
| 4 | 越界 | speed | 速度为负值 (-5.0) |
| 5 | 越界 | speed | 速度超出合理范围 (200.0) |
| 6 | 越界 | latitude | 纬度超出 -90~90 范围 (95.0) |
| 7 | 越界 | longitude | 经度超出 -180~180 范围 (200.0) |
| 8 | 空值 | rider_id | 骑手编号为空 |
| 9 | 空值 | ride_id | 骑行活动编号为空 |

**预期结果**：
- 第1行和第10行为有效记录
- 检测到8条无效记录
- 每条无效记录附带具体错误原因
- 有效记录仍正常输出

---

## 业务场景说明

### 骑行俱乐部数据来源
1. **Garmin设备**：标准GPX/CSV导出，字段完整
2. **行者APP**：国内骑行APP，偶尔缺字段
3. **黑鸟单车**：批量导出时偶有重复
4. **俱乐部旧数据**：2018年以前数据，格式不统一

### 典型异常场景
1. **设备断电**：休息时设备自动休眠，唤醒后时间断层
2. **路线反向**：山地骑行折返路段被误判
3. **数据丢失**：隧道、山区GPS信号丢失
4. **漂移点**：高楼密集区GPS定位漂移
5. **重复导出**：管理员多次导出同一活动数据

## 测试命令示例

```bash
# 处理单个正常文件
node src/cli.js -i data/samples/normal_ride.csv

# 批量处理所有样例文件
node src/cli.js -i data/samples/*.csv

# 遇错即停模式
node src/cli.js -i data/samples/*.csv --no-continue-on-error

# 指定输出目录
node src/cli.js -i data/samples/normal_ride.csv -o ./my_output
```
