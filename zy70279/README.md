# 舞蹈教室地胶保养台

## 安装运行

直接用浏览器打开 `index.html` 即可运行。

```bash
# 或者使用本地服务器
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 样例入口

点击界面上的「加载样例数据」按钮，系统会加载4个舞蹈教室的样例档案数据。

样例数据包含：

- 一楼芭蕾教室（高强度）
- 二楼街舞教室（高强度）
- 三楼瑜伽教室（低强度）
- 四楼中国舞教室（中等强度）

## 核心操作

### 基本流程（按顺序执行）

1. **处理课程强度**
   - 根据课程类型和时长计算使用强度
   - 为每个教室分配高/中/低强度等级

2. **生成清洁计划**
   - 基于强度等级和上次清洁日期生成清洁计划
   - 计算下次清洁日期和优先级

3. **追踪损伤区域**
   - 分析入口区域、中心区域、边缘接缝等关键区域
   - 评估损伤风险等级
   - 生成维护建议

4. **一键执行全部流程**
   - 按顺序执行上述所有步骤
   - 自动计算统计数据

### 其他操作

- **重置状态**：清除处理结果，保留输入数据
- **导出结果**：导出为JSON文件

## 如何检查结果

界面右侧面板包含4个标签页：

1. **清洁计划**
   - 查看每个教室的清洁计划
   - 检查清洁优先级和任务详情

2. **损伤追踪**
   - 查看各区域损伤风险
   - 风险等级：紧急、高风险、中等风险、低风险

3. **统计数据**
   - 教室强度分布
   - 清洁计划统计
   - 损伤风险统计
   - 系统建议

4. **变更历史**
   - 追踪每次操作记录
   - 显示操作时间和详情

## 数据格式说明

输入的教室档案应为JSON数组，格式如下：

```json
[
  {
    "id": "CR001",
    "name": "教室名称",
    "area": 80,
    "lastCleaningDate": "2026-05-08",
    "courses": [
      { "type": "芭蕾", "hours": 6 },
      { "type": "考级集训", "hours": 3 }
    ]
  }
]
```

课程类型权重：考级集训(2.0)、街舞(1.8)、爵士(1.5)、拉丁(1.3)、芭蕾(1.2)、中国舞(1.1)、现代舞(1.0)、儿童舞蹈(0.8)、普拉提(0.6)、瑜伽(0.5)
