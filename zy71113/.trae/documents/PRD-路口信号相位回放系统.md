## 1. 产品概述

路口信号相位回放系统是交警用于事故复盘的WebGL交互工具，通过可视化方式回放事故路口的信号灯状态、车流轨迹和行人冲突，支持秒级精准回放与交互操作。

- 解决问题：替代传统表格数据，提供直观的3D可视化场景，便于交警分析相位偏移、行人冲突、轨迹同步等事故诱因
- 目标用户：交通警察、事故调查人员
- 核心价值：提升事故分析效率，确保可视化数据与导出报告完全一致

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 事故调查人员 | 本地访问 | 导入数据、回放分析、导出报告 |

### 2.2 功能模块
1. **主场景页面**：2D/3D路口可视化、时间轴控制、相位显示、冲突标记
2. **数据导入模块**：样例数据加载、自定义数据导入
3. **交互控制模块**：拖拽筛选、视角切换、状态重置
4. **报告导出模块**：HTML/PDF报告生成

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主场景页面 | 3D场景渲染 | WebGL渲染路口几何、车辆、行人、信号灯、事故点 |
| 主场景页面 | 时间轴控制 | 播放/暂停/快进/快退、秒级进度拖动、时间显示 |
| 主场景页面 | 相位指示器 | 实时显示各方向信号灯相位状态 |
| 主场景页面 | 冲突检测面板 | 高亮显示相位偏移、行人冲突、轨迹不同步问题 |
| 主场景页面 | 视角切换 | 2D俯视图/3D透视视角切换、预设视角快捷切换 |
| 主场景页面 | 筛选控件 | 按类型筛选显示（车辆/行人/信号灯/事故点） |
| 主场景页面 | 工具栏 | 导入样例、重置状态、导出报告 |

## 3. 核心流程

用户导入事故数据 → 切换视角查看路口全貌 → 拖动时间轴定位事故时刻 → 播放回放观察轨迹 → 发现冲突点标记 → 筛选关键元素聚焦分析 → 导出包含可视化截图的分析报告

```mermaid
    D --> E["冲突检测与标记"]
    E --> F["筛选聚焦"]
    F --> G["导出报告"]
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深蓝(#1a365d) + 警示红(#e53e3e) + 安全绿(#38a169)
- 辅助色：信号黄(#d69e2e)、相位蓝(#3182ce)
- 背景：深色科技感渐变背景，配合细微网格纹理
- 按钮风格：圆角矩形，微悬浮效果，功能按钮使用图标+文字
- 字体：主字体使用 Roboto Mono（数字显示更清晰），辅助字体使用 Inter
- 布局：左侧工具栏 + 中央3D场景 + 底部时间轴 + 右侧信息面板
- 图标风格：线性简约图标，配合状态色区分

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主场景页面 | 3D场景 | 深色地面、白色车道线、信号灯柱、车辆模型、行人模型 |
| 主场景页面 | 时间轴 | 进度条带刻度标记、播放控制按钮组、时间数字显示 |
| 主场景页面 | 相位面板 | 四方向信号灯状态卡片，相位时序图 |
| 主场景页面 | 冲突面板 | 冲突列表，点击定位到对应时间点 |
| 主场景页面 | 工具栏 | 垂直排列工具按钮，悬停显示提示 |

### 4.3 响应式
- 桌面端优先设计，确保宽屏显示效果
- 支持窗口缩放自适应布局
- 时间轴区域最小宽度800px

### 4.4 3D场景指导
- 环境：深色夜空背景，地面使用沥青材质纹理
- 光照：顶部主光源 + 各方向补光，确保车辆和行人有清晰阴影
- 相机：默认透视视角，支持正交俯视图切换，相机可拖拽旋转和缩放
- 交互元素：悬停高亮车辆/行人，点击显示详细信息
- 动画：车辆移动平滑插值，信号灯切换有过渡效果，冲突点闪烁提示
- 性能：控制同屏模型数量，使用实例化渲染优化车流显示
