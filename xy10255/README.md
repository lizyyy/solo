# 早教中心课包消课台

一个实用的早教中心课包管理系统，围绕课包消耗、请假冻结和家长对账三大核心场景。

## 安装运行

### 1. 安装依赖
```bash
npm install
```

### 2. 初始化样例数据（可选）
```bash
npm run seed
```

### 3. 启动服务
```bash
npm start
```

服务启动后访问：http://localhost:3001

## 样例入口

启动后访问首页即可看到完整界面。

如果已执行 `npm run seed`，系统已预置：
- 3位孩子：小明、小红、小华
- 4门课程：创意美术课、音乐启蒙课、感统训练课、英语启蒙课
- 5个课包（含历史消费和请假记录）

## 核心操作

### 1. 课包购买
1. 先通过API添加孩子和课程（或修改 seed.js 后重新 seed）
2. 点击「课包管理」→「购买新课包」
3. 选择孩子、课程，填写课时数、购买日期、到期日期
4. 确认购买

### 2. 签到消课
1. 点击「签到消课」
2. 选择要消课的课包（自动显示剩余课时）
3. 确认上课日期、时间
4. 点击「确认签到消课」
5. 系统自动扣除1课时

### 3. 请假处理
1. 点击「请假冻结」
2. 在「请假管理」区域选择课包
3. 填写请假日期、课时数、原因
4. 提交后，对应课时会被冻结（暂不扣除，但也不能使用）

### 4. 课包冻结/解冻
1. 点击「请假冻结」
2. 在「冻结管理」区域选择课包
3. 填写冻结起止日期和原因
4. 冻结后，所有剩余课时被锁定，无法签到
5. 在「当前冻结」列表点击「解冻」可恢复

### 5. 家长对账
1. 点击「家长对账」
2. 选择要对账的课包
3. 点击「加载对账信息」查看：
   - 课包摘要（总课时、已消课、冻结中、剩余）
   - 签到记录
   - 请假记录
   - 操作历史
4. 点击「导出对账Excel」下载完整对账文件

## 如何检查结果

### 1. 数据一致性检查
1. 课包管理页面验证：
   - 总课时 = 已消课 + 冻结中 + 剩余
   - 剩余课时计算正确

2. 仪表盘统计：
   - 总课包数、激活中、冻结中数量正确
   - 总消课数与所有课包已消课之和一致

3. 重跑验证：
   - 执行 `npm run seed` 会重置数据库并重新创建样例数据
   - 多次执行不会产生数据膨胀或矛盾
   - 每次 seed 后统计结果应该一致

### 2. 流程验证
1. 正常消课流程：
   - 购买课包（剩余=N）
   - 签到消课（剩余=N-1）
   - 查看历史，有消费记录

2. 请假冻结流程：
   - 剩余=N
   - 请假1课时
   - 剩余=N-1，冻结=+1
   - 消课时不能使用冻结的课时

3. 课包冻结流程：
   - 冻结课包
   - 尝试签到，提示已冻结
   - 解冻后可正常消课

### 3. 导出验证
1. 课包列表导出：
   - 所有课包数据完整
   - 剩余课时、状态计算正确

2. 对账导出：
   - 包含5个工作表：摘要、签到、请假、冻结、操作历史
   - 数据与页面展示一致

## 重置数据
```bash
npm run reset
```

重置后再次 seed 可恢复到初始样例状态。

## 技术说明
- 后端：Node.js + Express
- 数据库：SQLite（文件型，便于重跑验证）
- 前端：原生 HTML/CSS/JavaScript
- 导出：ExcelJS

所有操作通过数据库事务保证一致性，重跑同一批数据不会产生膨胀或矛盾。
