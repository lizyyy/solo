## 1. 产品概述

素材标签冷启动系统是面向模型评测与运营复核协作场景的轻量级工作台，解决"模型版本换了但样本编号没变"的异常追溯问题，让灰度批次导入、标注留言补录、产品复盘三步流转清晰可解释。

- 核心用户：模型评测同事小孟、运营复核人、产品经理
- 核心价值：异常留痕、责任交接可追溯、复盘结论可落地

## 2. 核心功能

### 2.1 用户角色

| 角色 | 接入方式 | 核心权限 |
|------|----------|----------|
| 模型评测小孟 | 小看板/命令行 | 导入灰度批次、补录标注留言、标记异常状态 |
| 运营复核人 | 小看板 | 查看异常、追溯来源、确认复核结论 |
| 产品经理 | 小看板 | 查看复盘页、跟踪下一步动作 |

### 2.2 功能模块

1. **小看板首页**：批次统计、异常概览、快速入口
2. **灰度批次导入**：CSV/JSON 导入、样本列表、异常自动检测
3. **样本详情与留言**：模型版本对比、标注员留言补录、异常标记
4. **产品复盘页**：单条样本解释、缺失材料说明、下一步责任人

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 小看板首页 | 批次统计卡片 | 显示导入批次总数、异常数、待复核数 |
| 小看板首页 | 异常快速列表 | Top 异常样本，点击跳转详情 |
| 灰度批次导入 | 文件上传区 | 支持拖拽上传 CSV/JSON，解析样本数据 |
| 灰度批次导入 | 样本列表 | 表格展示样本，高亮"模型版本换了但样本编号没变"的行 |
| 样本详情页 | 版本对比区 | 展示同一样本编号的不同模型版本差异 |
| 样本详情页 | 留言补录区 | 小孟补充标注员原始留言，时间戳留痕 |
| 样本详情页 | 状态标记区 | 标记为"待运营复核"/"已确认正常" |
| 产品复盘页 | 样本解释卡 | 说明这条为什么被留下，用交接式语言 |
| 产品复盘页 | 材料清单 | 列出已有的材料和还缺什么 |
| 产品复盘页 | 下一步指引 | 明确该找运营复核人还是找小孟 |

## 3. 核心流程

**主流程：灰度批次导入 → 异常检测 → 小孟补录留言 → 运营复核 → 产品复盘**

```mermaid
flowchart LR
    A["导入灰度批次"] --> B["自动检测异常\n（模型版本换了\n但样本编号没变）"]
    B --> C["异常列表高亮\n不急着归正常"]
    C --> D["小孟补看\n标注员留言"]
    D --> E["补录留言后\n复盘页同步更新"]
    E --> F["运营复核人\n点击追溯来源"]
    F --> G["产品复盘页\n说明下一步找谁"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖棕 #8B5E3C（编辑室质感）+ 墨绿 #2D4A3E（专业稳重）
- **辅助色**：异常警示橙 #E07B39，复核通过绿 #5A8F69
- **排版风格**：杂志编辑室风，衬线标题 + 无衬线正文，段落间距宽松
- **卡片风格**：轻微纸张纹理，柔和阴影，圆角 8px
- **图标风格**：细线手绘感，避免过于科技化

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 小看板首页 | 统计卡片 | 大号数字 + 小字说明，悬停微上浮 |
| 小看板首页 | 异常列表 | 每条带状态标签，异常条左侧橙色竖线 |
| 灰度批次导入 | 上传区 | 虚线边框，拖拽时高亮，纸张质感背景 |
| 样本详情页 | 版本对比 | 左右分栏，差异处用底色高亮 |
| 产品复盘页 | 解释卡 | 引用框样式，开头"小孟说："/"运营复核：" |

### 4.3 响应式

- 桌面端优先，最小支持 1280px
- 侧边栏导航在平板端折叠为顶部标签
- 表格在窄屏可横向滚动

### 4.4 数据可视化

- 批次趋势用折线图（面积填充，柔和渐变）
- 异常分布用环形图，中心显示总数
- 不做 3D 场景，用细腻的 2D 图表服务复核需求
