工厂换模停机统计 CLI 样例数据

文件说明：
1. production_plans.csv - 生产计划
   - P001: M001 生产 PROD-A (08:00-14:00)
   - P002: M001 生产 PROD-B (15:30-22:00)
   - P003: M002 生产 PROD-C (08:00-20:00)
   - P004: M002 生产 PROD-A (21:00-次日05:00)
   - P005: M003 生产 PROD-D (06:00-18:00)

2. changeover_records.csv - 换模记录
   - M001: PROD-A -> PROD-B (14:00-15:30, 90分钟) - 正常
   - M002: PROD-C -> PROD-A (20:00-21:00, 60分钟) - 正常
   - M001: 与第一条重复 - 会被标记为重复
   - M003: 结束时间早于开始时间 - 会被标记为时间无效

3. abnormal_downtimes.csv - 异常停机记录
   - M002: 设备故障 (12:30-13:45, 75分钟) - 正常
   - M003: 物料短缺 (09:00-09:30) - 正常
   - M003: 物料短缺 (09:15-09:45) - 与上一条重叠 - 会被标记为重叠
   - M001: 结束时间早于开始时间 - 会被标记为时间无效

4. production_records.csv - 产量记录
   - M001: PROD-A 950件, PROD-B 700件 - 正常
   - M002: PROD-C 1400件, PROD-A 200件 - 正常
   - M003: PROD-D 1900件 - 正常
   - M003: PROD-Z 100件 - 无对应计划 - 会被标记为无对应计划

使用方法：
1. 先导入所有数据
2. 然后核算 2025-05-10 的数据
3. 查看 M001 或 M002 的明细
4. 导出日报查看完整报告
