# 🚂 铁路道口视距检查工具

基于 Three.js 的 3D 可视化工具，用于演示铁路道口两侧遮挡物对司机视距的影响，帮助村委理解整改范围。

## ✨ 功能特性

- 🎯 **3D 场景可视化**: 完整的道口模型、轨道、列车和遮挡物
- 👁️ **实时视距检测**: 基于视线射线的实时视距计算
- 🎚️ **速度滑块**: 20-160 km/h 速度调节，自动计算制动距离
- 🌲 **遮挡物管理**: 拖拽移动、类型筛选、临时隐藏
- 🎥 **多视角切换**: 俯视图、司机视角、自由视角
- ⏱️ **时间轴播放**: 列车接近过程动画演示
- 💾 **状态持久化**: 刷新页面后筛选和关键状态不丢失
- 📋 **报告导出**: 生成 HTML 格式的视距检查报告
- 🔴 **整改区域高亮**: 视觉化显示需要整改的区域

## 📖 操作指南

### 一组可复现操作（演示流程）

#### 场景 1：村庄道口遮挡演示

1. **导入样例**
   - 在「场景控制」面板的「导入样例」下拉框中选择「样例1：村庄道口（有树木遮挡）」
   - 观察 3D 场景中出现的树木和农舍建筑
   - 查看右侧信息面板：当前视距约 45-51m，要求视距约 125.9m（不合格）

2. **调整列车速度**
   - 拖动「运行速度」滑块从 60 km/h 到 80 km/h
   - 观察「制动距离」从 125.9m 增加到 211.1m
   - 视距要求更严格，整改区域扩大

3. **切换视角**
   - 点击「俯视图」按钮，从上往下观察整体布局
   - 点击「司机视角」，模拟列车司机的第一人称视角
   - 点击「自由视角」，使用鼠标拖拽旋转场景

4. **遮挡物筛选**
   - 在「遮挡物筛选」面板取消勾选「树木」
   - 观察所有树木消失，视距显著改善
   - 重新勾选「树木」，视距恢复原状

5. **拖拽移动遮挡物**
   - 在 3D 场景中点击「大树1」（绿色树冠）
   - 按住鼠标左键拖动树木向远离道口的方向移动（X轴正方向）
   - 松开鼠标，观察视距报告实时更新
   - 继续拖动直到视距达到安全要求（绿色显示合格）

6. **时间轴播放**
   - 点击「▶️ 播放」按钮，列车开始向道口移动
   - 观察视距线颜色变化，整改区域动态调整
   - 点击「⏹️ 停止」暂停动画，或拖动时间轴滑块手动定位

7. **导出报告**
   - 调整好遮挡物位置后，点击「📥 导出报告」按钮
   - 浏览器自动下载 HTML 格式的检查报告
   - 打开报告文件查看详细的检查结果和整改建议

8. **重置状态**
   - 点击「🔄 重置状态」按钮恢复初始状态
   - 刷新浏览器页面，确认之前的筛选状态和遮挡物位置被保留

#### 场景 2：工厂道口对比演示

1. 导入「样例2：工厂道口（有建筑遮挡）」
2. 观察大型厂房对视线的严重遮挡
3. 取消勾选「围墙」，观察视距改善程度
4. 导出报告用于向村委展示整改必要性

## 📐 技术原理

### 视距计算公式

**制动距离 = 反应距离 + 制动距离**

- 反应时间：2 秒（行业标准）
- 减速度：1.5 m/s²（舒适制动）

```
速度(m/s) = 速度(km/h) × 1000 ÷ 3600
反应距离 = 速度(m/s) × 反应时间
制动距离 = 速度² ÷ (2 × 减速度)
总制动距离 = 反应距离 + 制动距离
```

### 视线检测算法

使用 Three.js Raycaster 进行射线检测：
1. 从司机观察点（可调高度）向左右 45° 方向发射射线
2. 检测射线与遮挡物的交点距离
3. 比较实际视距与要求制动距离
4. 绿色 = 合格，红色 = 不合格

### 本地存储

所有关键状态保存在 `localStorage` 的 `railway-crossing-sight-check-state` 键中：
- 列车速度、观察点高度
- 遮挡物位置和可见性
- 筛选类型、列车位置、当前视角

## 🔧 自定义扩展

### 添加新的遮挡物类型

在 `src/main.js` 的 `addObstacle` 方法中添加新的 case：

```javascript
case 'newType':
  geometry = new THREE.YourGeometry(...)
  material = new THREE.MeshStandardMaterial({ color: 0xrrggbb })
  mesh = new THREE.Mesh(geometry, material)
  break
```

### 添加新样例

在 `sampleData` 对象中添加新的配置：

```javascript
sample4: {
  name: '自定义样例名称',
  speed: 70,
  observerHeight: 3.5,
  obstacles: [
    { id: 'obj1', type: 'tree', name: '名称', position: { x: 10, z: -5 }, height: 10, width: 3, visible: true }
  ]
}
```

## 📝 常见问题

**Q: 遮挡物拖动不灵敏？**
A: 确保点击在物体的可见网格上，树木需要点击树冠部分。

**Q: 视距计算不准确？**
A: 检查观察点高度设置，不同型号列车的司机室高度不同。

**Q: 导出的报告打不开？**
A: 报告是标准 HTML 文件，用任何浏览器都可以打开。
