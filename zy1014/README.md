# ☕ 咖啡烘焙曲线复盘看板

家用咖啡烘焙数据分析与可视化工具，帮助你从每次烘焙中学习和进步。

## ✨ 功能特性

### 📊 数据导入与解析
- 支持上传烘豆机导出的 CSV 文件
- 内置 3 份示例数据可直接体验
- **智能列名映射**：自动识别中英文列名（时间/豆温/环境温/火力/风门/事件）
- 支持多种时间格式：`MM:SS`、秒数、`HH:MM:SS`

### 🎯 数据校验
- **时间校验**：检测时间倒退、间隔异常、烘焙过短
- **温度校验**：检测温度缺失、突降、异常高低温
- **事件校验**：检测事件顺序错误、温度异常

### 📈 曲线可视化
- 双轴图表：温度曲线 + RoR（升温率）曲线
- 平滑 RoR 计算（滚动平均）
- **事件点标记**：入豆、回温点、黄点、一爆、二爆、下豆
- 交互图表：悬停查看详细数据

### 🧮 指标计算
- **基础指标**：总时长、入豆温、下豆温
- **发展指标**：发展时间、发展比例（发展时间/总时长）
- **RoR 指标**：平均/最小/最大 RoR
- **阶段分析**：
  - 入豆 → 回温点
  - 回温点 → 黄点
  - 黄点 → 一爆
  - 一爆 → 下豆
- **RoR 异常检测**：RoR 过高、为负、抖动剧烈

### 🔄 多锅对比分析
- **曲线对比**：多锅温度/RoR 曲线叠加
- **阶段对比**：关键阶段耗时与温升柱状图
- **RoR 稳定性分析**：标准差、变异系数、波动幅度
- **时间归一化**：以入豆时间为起点对齐

### 📝 复盘笔记（本地存储）
- 记录咖啡豆信息：产地、品种、处理法、烘焙度
- 重量跟踪：生豆重/熟豆重/自动计算失重
- **缺陷标签**（15 种预置）：
  - 夹生、烤焦、烟味重、发展不足、发展过度
  - 烘焙不均、豆表过黑、银皮残留、涩味
  - 苦味过重、酸味尖锐、风味平淡、青草味、谷物味、木质味
- **优点标签**（10 种预置）：
  - 酸甜平衡、花香、果香、焦糖甜、巧克力
  - 坚果、醇厚度好、干净、层次丰富、回甘好
- 支持自定义标签
- 数据本地保存为 JSON（`.roast_data/roast_notes.json`）

### 📤 报告导出
- **HTML 报告**：带完整样式、交互图表
- **Markdown 报告**：纯文本、便于分享和版本控制
- 可选择包含：曲线图、复盘笔记、数据校验结果

## 🚀 快速开始

### 环境要求
- Python 3.8+
- pip

### 安装步骤

1. **克隆或下载项目**

2. **创建虚拟环境（推荐）**
```bash
cd zy1014
python -m venv venv

# macOS/Linux
source venv/bin/activate

# Windows (PowerShell)
.\venv\Scripts\Activate.ps1
```

3. **安装依赖**
```bash
pip install -r requirements.txt
```

4. **启动应用**
```bash
streamlit run app.py
```

浏览器会自动打开 `http://localhost:8501`

### 首次使用

1. 打开应用后，左侧边栏有「示例数据」区域
2. 选择任一示例文件，点击「📥 加载示例数据」
3. 即可体验所有功能

## 📋 CSV 格式说明

### 必需列
- **时间**：`time`、`时间`、`时刻`、`timestamp`、`elapsed`
  - 支持格式：`MM:SS`（如 `2:30`）、秒数（如 `150`）、`HH:MM:SS`
- **豆温**：`bean_temp`、`豆温`、`BT`、`豆温_实际`

### 可选列
- **环境温/排气温**：`env_temp`、`环境温`、`ET`、`排气温`、`exhaust`
- **火力**：`power`、`火力`、`heat`、`功率`
- **风门**：`damper`、`风门`、`风`、`air`
- **事件**：`event`、`事件`、`备注`、`note`、`mark`

### 事件标记关键词
在事件列中包含以下关键词会被自动识别：

| 事件 | 可识别关键词 |
|------|-------------|
| 入豆 | 入豆, charge, 入锅, 开始, start |
| 回温点 | 回温点, 回温, TP, turning point, 最低温 |
| 黄点 | 黄点, 转黄, 变黄, yellow, 脱水 |
| 一爆开始 | 一爆开始, 一爆, 1C, first crack, FC |
| 一爆结束 | 一爆结束, 一爆停, FC end |
| 二爆开始 | 二爆开始, 二爆, 2C, second crack, SC |
| 二爆结束 | 二爆结束, SC end |
| 下豆 | 下豆, 出锅, drop, 结束, end, 出炉 |

### 示例 CSV 格式
```csv

0:10,145,190,100,100,
```

## 🎯 使用指南

### 单锅数据分析流程

1. **导入数据**
   - 上传 CSV 或选择示例
   - 系统自动解析和校验

2. **查看曲线与指标**（Tab 1）
   - 温度 + RoR 双轴图表
   - 关键指标卡片
   - 阶段耗时分析
   - 事件时间线

3. **检查数据质量**（Tab 2）
   - 查看校验错误和警告
   - 预览原始数据

4. **记录复盘笔记**（Tab 3）
   - 填写咖啡豆信息
   - 选择缺陷/优点标签
   - 编写备注
   - 点击「💾 保存笔记」

5. **导出报告**（Tab 4）
   - 选择 HTML 或 Markdown 格式
   - 点击生成预览
   - 下载保存

### 多锅对比流程

1. 导入多个烘焙数据
2. 在左侧边栏「对比分析」区域
3. 选择至少 2 个烘焙
4. 切换到「📈 对比分析」标签页
5. 查看：
   - 叠加曲线对比
   - 阶段耗时对比图
   - RoR 稳定性分析
   - 导出对比报告

## 📊 烘焙术语说明

| 术语 | 说明 |
|------|------|
| **RoR (Rate of Rise)** | 升温率，每分钟温度上升的度数 |
| **回温点 (Turning Point)** | 入豆后温度降到最低后开始回升的点 |
| **黄点 (Yellow Point)** | 咖啡豆从绿色转为黄色的阶段 |
| **一爆 (First Crack)** | 咖啡豆第一次爆裂，水分蒸发释放压力 |
| **二爆 (Second Crack)** | 更深的烘焙程度，油脂开始释放 |
| **发展时间 (Development Time)** | 从一爆开始到下豆的时间 |
| **发展比例** | 发展时间占总烘焙时间的百分比 |

## 🔧 常见问题

### Q: 我的烘豆机导出的列名不一样怎么办？
A: 系统会自动识别常见的中英文列名变体。如果识别不正确，建议在导入前手动修改列名，或在 GitHub 提 Issue 请求支持更多列名。

### Q: 笔记保存在哪里？
A: 所有笔记保存在项目目录下的 `.roast_data/roast_notes.json` 文件中，可以直接备份或编辑。

### Q: 支持哪些烘豆机？
A: 只要能导出 CSV 格式，包含时间、豆温列，就可以使用。常见支持的品牌/机型：
- 拓璞（Topo）
- 狙击手（Bullet）
- 富士皇家
- 以及其他支持数据导出的烘焙机

### Q: 如何分享我的烘焙数据？
A: 可以通过「导出报告」功能生成 HTML 或 Markdown 文件分享，也可以直接分享原始 CSV 文件。
