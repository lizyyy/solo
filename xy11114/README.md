# 露营装备店租赁装备清点 CLI

模块化的露营装备租赁清点工具，支持解析、校验、分类生成报告，避免人工筛选的重复处理和漏处理。

## 功能特性

- **模块化设计**：解析、校验、报告生成独立模块
- **智能分类**：
  - 正常清点结果
  - 同配件跨套装（待复核）
  - 备注手写标记（待复核）
  - 重复记录（待复核）
  - 状态异常、数量异常
  - 解析失败（待修复）
- **可复跑输出**：自动添加时间戳，重复执行不覆盖历史数据
- **预览模式**：先预览再正式执行

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 预览清点结果

先预览不生成文件，确认数据情况：

```bash
npm run preview -- --input data/sample.csv
```

### 3. 正式执行清点

确认无误后，正式执行生成报告：

```bash
npm run run -- --input data/sample.csv --output output
```

输出示例：

查看已生成的报告文件：

```bash
npm run report -- --output output
```

## 命令说明

| 命令 | 说明 | 示例 |
|------|------|------|
| `npm run preview` | 预览清点结果，不生成文件 | `npm run preview -- --input data/sample.csv` |
| `npm run run` | 正式执行清点，生成报告 | `npm run run -- --input data/sample.csv --output output` |
| `npm run report` | 查看已生成的报告列表 | `npm run report -- --output output` |
| `npm test` | 运行所有测试用例 | `npm test` |

### 选项

- `--input <path>`: 输入CSV文件或目录路径（必需）
- `--output <path>`: 输出目录（默认: output）
- `--overwrite`: 覆盖已有文件，不添加时间戳（谨慎使用）

## 输出文件说明

| 文件名 | 说明 | 处理方式 |
|--------|------|----------|
| `*_正常清点结果.csv` | 无异常的正常记录 | 直接使用 |
| `*_同配件跨套装_待复核.csv` | 同一装备编号出现在多个套装中 | 人工复核确认归属 |
| `*_备注手写_待复核.csv` | 备注包含手写/手工/标注等关键词 | 人工确认备注有效性 |
| `*_重复记录_待复核.csv` | 完全重复的记录 | 清理重复数据 |
| `*_解析失败_待修复.csv` | CSV格式错误的行 | 修正格式后重新导入 |
| `*_清点汇总报告.md` | 汇总统计和问题明细 | 总体概览 |

## 数据格式要求

CSV文件需包含以下字段：

| 字段 | 说明 | 示例 |
|------|------|------|
| 装备编号 | 装备唯一标识 | TENT-001 |
| 装备名称 | 装备名称 | 双人帐篷 |
| 所属套装 | 所属套装名称 | 帐篷套装A |
| 数量 | 装备数量 | 2 |
| 状态 | 在库/借出/维修/报废/盘点中 | 在库 |
| 备注 | 备注信息 | 手写补登 |
