# 商场夜间施工申请管理系统

一个本地全栈应用，用于商场物业处理店铺夜间施工申请的审批流程。

## 功能特性

### 业务流程
1. **店长提交申请**：填写施工信息（店铺、类型、时间、图纸等）
2. **工程主管审核**：审核图纸和时间安排
3. **安保放行审核**：决定是否放行施工人员
4. **施工管理**：登记进场、暂停整改、复工、完成施工
5. **闭环归档**：施工完成后归档

### 状态机安全规则
- **角色权限限制**：每个角色只能执行指定的操作
- **时间检查**：过期的通行证无法继续进场
- **整改确认**：暂停后必须由工程主管确认复工
- **越级审批阻止**：必须按流程顺序审批

### 数据导出
- 支持导出 CSV 格式审批流水
- 支持导出 Markdown 格式审批流水

## 技术栈

- **后端**：Node.js + Express + SQLite (better-sqlite3)
- **前端**：React + Vite + React Router
- **数据格式**：JSON、CSV、Markdown

## 本地启动步骤

### 前置要求
- Node.js 18+
- npm 9+

### 步骤 1：安装依赖

```bash
# 安装所有依赖（包含前后端）
npm run install:all
```

或者分别安装：

```bash
# 安装根目录依赖
npm install

# 安装后端依赖
cd server && npm install && cd ..

# 安装前端依赖
cd client && npm install && cd ..
```

### 步骤 2：启动服务

方式一：同时启动前后端（推荐）

```bash
npm run dev
```

方式二：分别启动

```bash
# 终端 1：启动后端（端口 3001）
npm run dev:server

# 终端 2：启动前端（端口 3000）
npm run dev:client
```

### 步骤 3：访问应用

- **前端界面**：http://localhost:3000
- **后端 API**：http://localhost:3001

```

    ↓

               │
               └── 审核拒绝 → [工程审核拒绝] ✕ 终止
    ↓

    ↓
安保审核 ──────┬── 同意放行 → [安保已放行]
               │
               └── 拒绝放行 → [安保拒绝] ✕ 终止
    ↓

    ↓

    ↓
[施工中] ──────┬── 暂停整改 → [暂停整改]
               │                     ↓
               │                工程主管确认复工
               │                     ↓
               │               返回 [施工中]
               │
               └── 完成施工 → [已完成]
    ↓
[已完成]
    ↓

    ↓
[已归档] ✕ 终止
```

- `GET /api/applications` - 获取申请列表

- `GET /api/shops` - 获取店铺列表

- `GET /api/dashboard/stats` - 获取看板统计数据
- `GET /api/audit-logs` - 获取审计日志

## 状态机验证规则

系统内置以下安全验证：

1. **角色权限验证**
   - 店长只能提交申请和查看自己的申请
   - 工程主管只能进行图纸审核
   - 安保只能进行放行和现场管理操作
   - 管理员拥有全部权限

2. **时间验证**
   - 登记进场时检查当前时间是否在施工时间窗内
   - 过期的通行证无法继续进场

3. **流程验证**
   - 不允许越级审批（如安保不能先于工程主管审核）
   - 暂停整改后必须由工程主管确认复工
   - 整改未确认不能直接归档

## 注意事项

1. **数据库**：SQLite 数据库文件存储在 `server/data/construction.db`，首次运行自动创建
2. **样例数据**：首次运行自动插入样例数据，后续运行不会重复插入
3. **角色切换**：前端界面顶部可以切换不同角色身份，用于测试不同角色的权限
4. **时间测试**：测试进场功能时，确保当前时间在施工时间窗内

## 常见问题

**Q: 如何重置数据库？**
A: 删除 `server/data/construction.db` 文件，重启服务会自动重建数据库并重新插入样例数据。

**Q: 前后端端口可以修改吗？**
A: 可以。在 `server/src/index.js` 修改后端端口，在 `client/vite.config.js` 修改前端端口和代理配置。

**Q: 如何添加新用户？**
A: 可以直接修改 `server/src/seed.js` 中的用户数据，然后删除数据库重启服务。
