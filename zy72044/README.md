# 🚦 城市绿波信号赛 | 课程练习模拟器

面向课程教学的浏览器应用，帮助助教追踪学生练习进度，实时展示比赛过程并生成可追溯的练习报告。

---

## 快速开始

### 环境要求
- Node.js >= 18
- npm 或 pnpm

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

启动后访问：**http://localhost:5173**（Vite 默认端口）

### 类型检查
```bash

```

### 构建生产版本
```bash
npm run build
```

### 预览构建结果
```bash
npm run preview
```

## 功能一览

### 🎮 比赛控制
- **开始**：加载配置后开始比赛
- **暂停**：随时暂停比赛状态
- **继续**：从暂停位置恢复
- **重开**：重置到初始状态重新开始
- **结算**：立即中止并生成结算报告
- **推进一步**：手动触发下一个事件（空格键快捷键）

### 📊 实时监控
- **资源仪表盘**：时间、能量、预算三项核心资源
  - 正常区间：绿色显示
  - 接近下限：黄色预警
  - 负数/越界：红色高亮，立即报警
- **进度条**：显示当前关卡和整体进度
- **计时器**：记录已运行时长
- **事件日志**：每条事件可展开查看详情和来源

### 🔍 配置校验
- 空关卡检测（运行时自动跳过）
- 重复事件 ID / 名称警告
- 资源边界值检测
- 坏配置不会白屏，顶部给出可读提示

### 📋 结算报告
- 总记录数、顺利通过、需人工确认、旧口径四项统计
- 异常汇总：按来源分组，不被数字掩盖
- 记录明细：每条记录可追溯来源
- 异常记录红色高亮，需确认记录黄色标记

### 🎬 回放系统
- 进度条拖动定位
- 倍速播放：0.5x / 1x / 2x / 4x
- 上一步 / 下一步 单步控制
- 资源状态随回放实时更新

## 异常处理规则

| 场景 | 处理方式 | 可见性 |
|------|----------|--------|
| 资源变为负数 | 红色高亮，记录异常，标记需人工确认 | 仪表盘 + 日志 + 报告汇总 |
| 空关卡 | 配置警告，运行时自动跳过 | 配置校验区 + 日志 |
| 重复事件 | 配置警告，记录重复次数 | 配置校验区 |
| 资源超出边界 | 按边界截断，记录警告 | 日志 + 报告 |
| 坏配置加载 | 顶部红色提示，可关闭 | 页面顶部 |

## 核心操作流程

### 标准运行流程
1. 下拉选择"城市绿波信号赛"配置
2. 查看配置校验提示（空关卡、重复事件会列出来）
3. 点击**开始**按钮
4. 比赛运行中：
   - 点击**推进一步**或按空格键触发下一个事件
   - 可随时**暂停**后**继续**
   - 观察资源仪表盘，负数会立即变红
5. 跑完所有事件或点击**结算**进入报告页
6. 报告页可查看明细，点击**回放**重温过程

### 回放流程
1. 报告页找到目标记录
2. 点击右侧**回放**按钮
3. 使用底部控制条播放 / 拖动 / 变速
4. 点击右上角 ✕ 退出回放

## 测试说明

7. **三条样例**：报告页分别有绿色（顺利）、黄色（需确认）、灰色（旧口径）

## 给助教小何的说明

这个工具就是按你日常改作业的流程做的。学生跑一遍，记录会留着，卡在哪一步、资源爆没爆，一眼就能看到。配置如果有问题（空关卡、重复事件），不会白屏报错，上面会给人话提示。异常情况不会藏在总数里，每条都能追到是哪个关卡哪个事件触发的。
