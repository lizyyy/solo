## 1. 产品概述

桥梁支座备件排程系统——解决传感器日志异常被均值掩盖、追溯链路断裂、补录改判无历史痕迹的问题。

- 核心用户：现场调度小宋（录入与维护）、运营主管（审看与决策）、交接接手人（确认放行/缺料）
- 核心价值：异常数据不被抹平、从图表可一步追到材料、补录改判留痕可追溯、交接状态清晰、收尾文档打包交付

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 现场调度 | 默认登录 | 查看全部、录入传感器日志、补录备注、改判结论、打包收尾文档 |
| 运营主管 | 默认登录 | 审看图表、追明细、查历史变更、确认交接状态 |
| 交接接手人 | 默认登录 | 查看交接状态看板、核对放行/缺料、查看收尾材料包 |

### 2.2 功能模块

1. **排程看板页**：散点时序图（异常点单独标红不被均值掩盖）、状态汇总卡片、交接状态一览、快捷下钻入口
2. **排程详情页**：放大时序图（点散点→跳传感器日志原始行）、材料追溯卡片、处理记录时间线、历史版本对比
3. **传感器日志抽屉**：原始数据行级展示（异常/断档标记+原始说明）、关联材料信息
4. **补录/改判弹窗**：展示旧值快照、录入新备注/新结论、强制填写改判原因
5. **历史版本面板**：按时间排列所有版本快照（旧材料|新备注|改判原因三列对比）
6. **交接状态看板**：放行/缺材料状态分栏、缺料清单、一键切换状态
7. **收尾文档中心**：传感器日志+处理记录+Markdown报告一体化预览、复制Markdown、下载小包

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|

## 3. 核心流程

运营主管打开排程看板→看到红色异常散点→点击散点→弹出传感器日志抽屉→看到原始异常说明→追溯到材料小包→发现问题需要补录→点击补录/改判→系统自动保留旧快照→填写新备注+改判原因→保存生成新版本→到交接看板确认放行或标记缺料→最后到收尾文档中心复制Markdown或下载材料包交付。

```mermaid

    A["打开排程看板"] --> B["审看散点时序图"]
    B --> C["红色异常点/断档标记"]
    C --> D["点击散点→日志抽屉"]
    D --> E["查看原始传感器说明"]
    E --> F["追溯材料小包信息"]
    F --> G["判断是否需要补录/改判"]
    G -->|需要| H["打开补录弹窗<br/>自动加载旧快照"]
    H --> I["填新备注+强制写改判原因"]
    I --> J["保存→生成历史版本"]
    J --> K["交接看板：放行/缺料"]
    K --> L["收尾文档中心<br/>日志+记录+Markdown报告"]
    L --> M["复制MD or 下载材料包"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色**：工程蓝 `#2563eb`（信任与秩序），警示红 `#dc2626`（异常点），补录琥珀 `#d97706`（改判痕迹），放行绿 `#059669`
- **中性色**：slate 系列，背景 `#f8fafc`，卡片纯白
- **按钮**：方角轻微圆角（4px），2px边框强调工业感；危险按钮红边框红底白字
- **字体**：标题用"思源黑体 Heavy"（工业厚重感），正文"JetBrains Mono"混入数字（日志、编号对齐），强调数据表格的等宽对齐
- **布局**：顶部窄导航+左侧状态边栏+主内容区，卡片式分区，线条分隔简洁硬朗
- **图标**：lucide-react，线性图标为主，异常/警示处用填充变体
- **动效**：异常散点呼吸式轻微缩放，历史版本切换高亮闪烁1s，抽屉侧滑入

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要点 |
|----------|----------|--------|
| 排程看板 | 散点时序图 | 蓝色均值线为底，红色圆点叠绘异常（半径+2、呼吸动效），黄色三角标断档 |
| 排程看板 | 状态卡 | 三张并排：放行（绿）/缺料（琥珀）/待审（灰），下方数字+变化箭头 |
| 排程详情 | 时序图区 | 占页面60%高度，下方时间轴可缩放拖动 |
| 排程详情 | 版本对比 | 三列灰-白-琥珀底并排，中间箭头指向新值，改判原因用红框强调 |
| 传感器日志抽屉 | 表格 | 斑马纹，异常行整行浅红背景，断档行浅黄，"原始说明"列字体略小斜体 |
| 交接状态看板 | 双栏 | 左绿底白卡（放行），右琥珀底白卡（缺料），顶部大数字统计 |
| 收尾文档中心 | 三合一 | 三列等高滚动，顶部操作栏固定，预览区Markdown实时渲染 |

### 4.3 响应式

- Desktop-first，主断点 1280px / 1024px / 768px
- 小于 1024px：状态边栏收起为顶部标签页
- 小于 768px：图表自适应宽度，抽屉变为全屏弹窗，双栏交接改为上下堆叠
- 所有数据表格在移动端支持横向滑动
