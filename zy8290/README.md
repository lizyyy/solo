# 供应商商品/库存导入工具

一个本地桌面 GUI 小工具，用于门店运营导入供应商商品/库存表。

## 功能特性

- **多格式支持**: 支持 CSV 和 XLSX 格式文件导入
- **智能字段映射**: 自动识别多种中文/英文字段名（如"商品编码"、"product_code"、"SKU"等）
- **字段预检**: 导入前自动验证所有字段
- **持久化存储**: 使用 SQLite 本地数据库
- **失败处理**: 非法行标记行号、字段、原值和修复建议
- **断点续传**: 重启应用仍能看到批次进度、成功数量、失败明细
- **重试机制**: 修正失败行后可只重试这些行
- **报告导出**: 支持导出错误报告和导入摘要

## 支持的错误类型

| 错误类型 | 说明 | 修复建议 |
|---------|------|---------|
| 商品编码重复（文件内） | 同一文件内商品编码重复 | 修改重复的商品编码 |
| 商品编码重复（数据库） | 商品编码已存在数据库中 | 检查是否已导入，或更新商品 |
| 价格格式错误 | 成本价/售价格式不正确 | 检查价格格式，支持 19.99、¥19.99 等 |
| 必填字段缺失 | 商品编码或商品名称为空 | 补充必需字段值 |
| 数字格式错误 | 库存数量不是有效整数 | 检查库存数量格式 |

## 使用说明

### 1. 选择文件

点击"浏览..."按钮，选择 CSV 或 XLSX 格式的商品/库存表文件。

### 2. 字段预检

点击"预检"按钮，系统会:
- 解析文件内容
- 验证所有字段
- 显示有效行数和无效行数
- 在"错误预览"标签页中显示所有错误详情

### 3. 开始导入

预检通过后，点击"开始导入"按钮:
- 合法行会写入 SQLite 数据库
- 非法行会被记录到失败行表中
- 实时显示导入进度

### 4. 查看批次历史

切换到"批次历史"标签页，可以查看:
- 所有导入批次
- 每个批次的状态、成功数、失败数
- 点击"查看详情"查看完整信息

### 5. 重试失败行

1. 在"批次历史"中选择一个有失败行的批次
2. 点击"重试失败行"按钮
3. 系统会重新验证并尝试导入之前失败的行
4. 注意: 你需要先修改原始文件中的错误数据

### 6. 导出报告

支持两种导出方式:

**错误报告**:
- 包含所有失败行的详细信息
- 包含原始数据，可直接编辑后重试
- 支持 CSV 和 JSON 格式

**导入摘要**:
- 批次基本信息
- 导入统计数据
- 错误类型统计
- 操作日志

### 7. 查看已导入商品

切换到"已导入商品"标签页，查看所有已成功导入的商品记录。

## 样例文件

项目 `samples/` 目录下提供了两个样例文件:

- **good_sample.csv**: 好样例，所有行都符合要求，可以直接导入
- **bad_sample.csv**: 坏样例，包含各种典型错误，用于测试预检和错误处理功能

### 坏样例包含的错误类型

1. 商品编码为空 (第4行)
2. 商品名称为空 (第5行)
3. 成本价格式错误 ("abc" - 第6行)
4. 售价格式错误 ("xyz" - 第7行)
5. 库存数量格式错误 ("abc" - 第8行)
6. 文件内商品编码重复 (第9行 SKU001 与第2行重复)
7. 多个字段同时错误 (后续行)

## 数据库说明

数据存储在 `store.db` SQLite 数据库中，包含以下表:

| 表名 | 说明 |
|-----|------|
| products | 商品主表 |
| import_batches | 导入批次表 |
| import_logs | 操作日志表 |
| failed_rows | 失败行表 |

### products 表结构

| 字段 | 类型 | 说明 |
|-----|------|------|
| id | INTEGER | 主键 |
| product_code | TEXT | 商品编码（唯一） |
| product_name | TEXT | 商品名称 |
| category | TEXT | 分类 |
| cost_price | REAL | 成本价 |
| sale_price | REAL | 售价 |
| stock_quantity | INTEGER | 库存数量 |
| unit | TEXT | 单位 |
| supplier | TEXT | 供应商 |
| created_at | TIMESTAMP | 创建时间 |
| updated_at | TIMESTAMP | 更新时间 |

## 常见问题

### Q: 支持哪些价格格式？
A: 支持以下格式:
- 纯数字: 19.99, 19, 19,99
- 带货币符号: ¥19.99, $19.99
- 中文格式: 19元9角

### Q: 导入中断后如何继续？
A: 重启应用后，在"批次历史"标签页中可以看到之前的批次。如果是部分成功，你可以:
1. 查看失败明细
2. 修改原始文件中的错误数据
3. 点击"重试失败行"按钮

### Q: 如何防止商品编码重复？
A: 系统会在两个层面检查:
1. 文件内: 同一文件内是否有重复编码
2. 数据库: 数据库中是否已存在该编码

### Q: 导出的错误报告可以重新导入吗？
A: 可以。错误报告的 CSV 格式包含原始数据，你可以:
1. 导出错误报告
2. 用 Excel 或文本编辑器修改错误字段
3. 将修改后的文件重新导入
