# 咖啡豆烘焙厂烘焙曲线比对 CLI

专业的咖啡豆烘焙曲线数据比对与异常检测工具，专为烘焙厂数据质量控制设计。

## 功能特性

- **传感器断点检测**：自动识别温度传感器断连、数据中断问题
- **拼批检测**：发现重复录入或拼批处理的相似曲线
- **可复跑输出**：每次运行生成独立的结果文件，支持重复处理
- **精确定位**：异常报告包含来源文件和行号，运营同事可直接定位问题
- **批量处理**：支持整个目录的CSV文件批量比对

## 使用示例

### 基础用法

```bash
# 使用默认样例数据
roast-compare

# 指定输入输出目录
roast-compare --input ./my-data --output ./my-results

# 自定义检测阈值
roast-compare --sensor-gap 60 --batch-threshold 3
```

### 完整命令参数

```
选项：
  -V, --version                  输出版本号
  -i, --input <dir>              输入目录路径，包含烘焙曲线CSV文件
  -o, --output <dir>             输出目录路径，存放比对结果和异常报告
  -t, --template <file>          标准模板曲线文件路径（可选）
  -s, --sensor-gap <seconds>     传感器断点检测阈值（秒），默认30
  -b, --batch-threshold <percent>  拼批检测温度偏差阈值（%），默认5
  -h, --help                     显示帮助信息
```

## 输入文件格式

CSV文件需包含以下列（支持中英文列名）：

| 列名 | 说明 | 示例 |
|------|------|------|
| 时间 / time | 烘焙时间（分:秒格式） | 0:30, 1:00 |
| 豆温 / beanTemp | 咖啡豆温度（°C） | 168.5 |
| 环境温 / envTemp | 环境温度（°C） | 175.8 |
| 风门 | 风门开度（可选） | 40% |
| 火力 | 火力设置（可选） | 60% |
| 备注 | 备注信息（可选） | 一爆开始 |

## 异常类型说明

| 异常类型 | 严重程度 | 说明 | 修复建议 |
|----------|----------|------|----------|
| 传感器断点 | 警告 | 时间间隔超过阈值 | 检查传感器连接，补全缺失数据 |
| 数据缺失 | 错误 | 温度数据为空或格式错误 | 重新导出数据，修正空值 |
| 温度异常 | 警告 | 温度超出正常范围（0-300°C） | 校准温度传感器 |
| 拼批检测 | 警告 | 两条曲线高度相似 | 确认是否重复录入，去重处理 |

## 可复跑特性

- 每次运行会覆盖输出目录的结果文件
- 输入数据保持不变，支持多次重复运行
- 异常报告始终包含精确的文件和行号
- 适合CI/CD自动化质量检查流程
