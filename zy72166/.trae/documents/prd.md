## 1. 产品概述

口袋公园日照复核系统——为城市规划师提供从日照数据导入、归并去重、人工复核到导出公示清单的完整工具链，确保审批台账与实测数据之间的冲突可追溯、可裁决，历史意见不丢失，最终输出可供社区公示和跨岗位交接的分级结果。

- 面向城市规划审批人员，解决"口袋公园日照复核"流程中数据口径混乱、审批台账与实测冲突无据可依、历史意见被覆盖后无法追溯等核心痛点
- 目标：让日照复核从样例数据一路走到可公示的结果清单，脏数据进来时有明确交代，补录后差异可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 城市规划师 | 管理员分配账号 | 导入数据、归并去重、复核裁定、导出公示清单 |
| 审核主管 | 管理员分配账号 | 除规划师权限外，可复核争议项、查看操作日志 |

### 2.2 功能模块

1. **工作台页面**：项目概览、待处理任务统计、快速入口
2. **数据导入页面**：批量导入日照测量数据与审批台账、数据预检与口径标注
3. **归并去重页面**：同名路口识别、重复投诉合并、坐标偏移标注、跨时段统计提醒
4. **人工复核页面**：逐项复核、冲突裁决（展示双方证据与建议动作）、历史意见保留、补录与差异对比
5. **公示清单页面**：分级导出（已处理/待核实/需现场复看）、交接备注、历史版本

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台 | 项目概览 | 显示当前项目状态、待处理/已处理/需复看数量统计 |
| 工作台 | 快速入口 | 一键跳转到导入、归并、复核、导出各环节 |
| 工作台 | 最近操作日志 | 显示最近的操作记录，支持按时间筛选 |
| 数据导入 | 文件上传 | 支持CSV/Excel格式导入日照测量数据与审批台账 |
| 数据导入 | 数据预检 | 导入后自动检测：同名路口、重复条目、坐标偏移、跨时段数据、字段缺失，以警告列表展示，不自动清洗 |
| 数据导入 | 口径标注 | 对不同时间段的数据标记口径版本，冲突项高亮 |
| 数据导入 | 乱备注保留 | 审批台账中的原始备注（含错别字、非标格式）原样保留，不做整理 |
| 归并去重 | 同名路口识别 | 自动识别同名路口，展示各条记录详情供人工判断是否为同一地点 |
| 归并去重 | 重复投诉合并 | 识别同一地址/同一投诉人的重复投诉，合并时保留全部原始记录 |
| 归并去重 | 坐标偏移标注 | 检测同名地点坐标偏移超过阈值（默认50米），标注提醒 |
| 归并去重 | 跨时段统计 | 检测同一项目跨统计时段的数据，标注时段差异，不自动修正 |

| 人工复核 | 冲突裁决 | 审批台账说法与导入数据冲突时，展示双方证据与建议动作，由用户裁定 |
| 人工复核 | 历史意见保留 | 新方案覆盖旧方案时，旧方案的意见与判定结果完整保留，可展开查看 |
| 人工复核 | 补录与差异对比 | 补录一条备注后，自动对比补录前后差异，高亮变更内容 |
| 公示清单 | 分级导出 | 按已处理/待核实/需现场复看三级分类导出，每条标注判定依据和操作人 |
| 公示清单 | 交接备注 | 每条记录附带前次判定理由，换人处理时可看懂前因后果 |

## 3. 核心流程

用户从导入日照测量数据和审批台账开始，系统自动进行数据预检（识别同名路口、重复投诉、坐标偏移、跨时段数据等异常但不自动清洗），然后进入归并去重环节由人工确认合并策略，随后逐项进行人工复核（遇到冲突时展示双方证据供裁决），复核完成后导出分级公示清单（已处理/待核实/需现场复看），整个过程历史意见完整保留，补录差异可追溯。

```mermaid
flowchart TD
    "A[导入日照数据与审批台账]" --> "B[数据预检：异常检测与口径标注]"
    "B" --> "C[归并去重：同名路口/重复投诉/坐标偏移/跨时段]"
    "C" --> "D[人工复核：逐项判定]"
    "D" --> "E{是否存在冲突？}"
    "E" --> "是" --> "F[冲突裁决：展示双方证据与建议动作]"
    "F" --> "D"
    "E" --> "否" --> "G[导出公示清单]"
    "G" --> "H[分级输出：已处理/待核实/需现场复看]"
    "D" --> "I[补录备注]"
    "I" --> "J[差异对比：高亮变更]"
    "J" --> "D"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青色（#0F766E）配琥珀色（#D97706）强调色，传达专业与审慎感
- 辅助色：石板灰（#475569）用于中性元素，翡翠绿（#059669）用于通过状态，玫红（#E11D48）用于警告
- 按钮风格：圆角矩形（8px），带微妙阴影，主按钮深青色底白字，次按钮描边
- 字体：思源宋体（Noto Serif SC）用于标题传达权威感，思源黑体（Noto Sans SC）用于正文保证可读性
- 布局：左侧固定导航栏 + 右侧内容区，卡片式模块布局
- 图标：lucide-react 图标库，线条风格统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台 | 项目概览 | 顶部三张统计卡片（待处理/已处理/需复看），配对应颜色标识 |
| 工作台 | 快速入口 | 四个图标按钮横排，hover 时轻微上浮 |
| 工作台 | 最近操作 | 时间线列表，每条含操作类型图标、描述、时间戳 |
| 数据导入 | 文件上传 | 拖拽上传区域，虚线边框，拖入时高亮 |
| 数据导入 | 预检结果 | 预检警告表格，每行含严重程度标签、异常类型、详情、原始值 |
| 归并去重 | 同名路口 | 左右对比卡片，各展示一条记录详情，中间裁决按钮 |
| 归并去重 | 重复投诉 | 合并组卡片，组内各条原始记录堆叠展示 |
| 人工复核 | 复核列表 | 表格布局，每行可展开详情面板，含历史意见时间线 |
| 人工复核 | 冲突裁决 | 双栏对比：左侧审批台账证据，右侧导入数据证据，底部裁决按钮组 |
| 人工复核 | 补录差异 | 并排对比视图，变更处高亮黄色背景 |
| 公示清单 | 分级列表 | 三个可折叠分组，每组标题含数量徽章 |
| 公示清单 | 导出按钮 | 右上角悬浮，支持导出当前视图或全部 |

### 4.3 响应式

桌面优先设计，最小支持1280px宽度。平板端（768-1279px）导航栏折叠为图标模式。移动端暂不作为主要适配目标。
