# 地下管廊巡视系统

基于 Three.js 的 3D 模型巡检工具，用于展厅项目中模型摆放的复核、修正和历史追溯。

## 功能特性

### 🎯 核心功能
- **智能自动检测**
  - 坐标轴翻转检测
  - 模型重复摆放检测
  - 巡检路线遮挡检测
  - 所有问题默认标记为"待确认"，避免误判

- **问题留痕管理**
  - 自动记录检测原因
  - 提供下一步操作建议
  - 支持人工复核和状态变更
  - 完整操作历史记录

- **版本管理**
  - 支持多版本模型导入
  - 版本间差异对比
  - 关键变更醒目提醒
  - 避免静默覆盖历史判断

- **报告导出**
  - PDF 格式巡检报告
  - Excel 格式问题清单
  - JSON 完整数据备份

### 🛠 技术栈
- **前端框架**: React 18 + TypeScript
- **3D渲染**: Three.js + @react-three/fiber
- **状态管理**: Zustand
- **样式方案**: TailwindCSS 3
- **构建工具**: Vite 5

## 使用流程

### 1. 创建/选择项目
- 在首页点击"新建项目"创建新项目
- 或点击"加载示例数据"体验完整功能

### 2. 导入模型
- 上传 JSON 格式的模型清单文件
- 系统自动检测版本差异
- 关键变更会醒目提醒用户确认

### 3. 3D巡检
- 进入巡检页面后自动执行智能检测
- 点击 3D 模型查看详情
- 点击问题标记查看检测原因和下一步建议
- 人工复核后标记问题状态
- 可直接在属性面板微调模型位置

### 4. 查看历史
- 查看所有版本记录
- 对比不同版本间的差异
- 查看完整操作日志

### 5. 导出报告
- 支持导出 PDF、Excel、JSON 三种格式
- 报告包含问题统计和详细清单

## 模型文件格式

```json
{
  "models": [
    {
      "id": "model-1",
      "name": "阀门组A",
      "type": "exhibit",
      "position": { "x": 0, "y": 0.5, "z": 0 },
      "rotation": { "x": 0, "y": 0, "z": 0 },
      "scale": { "x": 1, "y": 1, "z": 1 },
      "geometry": {
        "type": "box",
        "dimensions": { "width": 1.5, "height": 1, "depth": 1 }
      },
      "color": "#3498db"
    }
  ]
}
```

## 问题类型说明

| 问题类型 | 检测条件 | 默认状态 |
|---------|---------|---------|
| 坐标轴翻转 | Y轴旋转接近180度或存在负缩放 | 待确认 |
| 模型重复摆放 | 两个模型距离<0.5m且名称相似度>70% | 待确认 |
| 路线被挡住 | 展品与预设巡检路线相交 | 待确认 |

## 设计原则

1. **宁可标成待确认，也不混进正常结果** - 所有自动检测结果默认标记为待确认
2. **关键变更必须提醒** - 补传旧版本时，关键变更醒目提示
3. **所有操作留痕** - 每次状态变更、模型调整都有记录
4. **原因清晰明确** - 每个问题都要有检测原因和下一步建议
