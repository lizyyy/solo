我想做一个给短剧译制和字幕交付小组用的本地自动化工具脚本，叫“多语字幕交付校对员”。我们每天要把剪辑师给的母版视频时间码、中文字幕、英文字幕、配音台本和平台要求的命名清单一起交付，现在靠人工打开一堆 srt、vtt、csv 文件核对，很容易漏掉时间轴重叠、字幕读速太快、同一句翻译丢了占位符、文件名和集数不匹配，返工时还说不清改了什么。请从 0 到 1 做一个可运行的 Python CLI 项目：init 命令能创建项目配置，维护语言列表、帧率、允许的最大读速、最短字幕间隔、保留占位符规则、平台文件命名模板和输出目录；import 命令能导入一批 srt/vtt 字幕、台本 CSV 和交付清单 CSV，保留原始文件并计算 SHA256；check 命令要校验时间码格式、字幕重叠、空字幕、序号断档、同集多语言缺段、读速超限、占位符或金额数字在翻译里丢失、说话人标签不一致、文件名与清单不匹配这些问题，坏项进入 quarantine.json 并说明原因。align 命令要按原文台本把多语言字幕段落对齐，生成每句的跨语言映射和置信度；plan-fix 命令只生成 dry-run 修复计划，比如重排序号、修正轻微间隔、补齐文件名、标出需要人工翻译的缺段，不能直接覆盖原始字幕；apply-fix 命令确认后把修复后的字幕写到 dist 目录并保留变更日志。review 命令允许人工确认或驳回某条问题，反馈要保存并影响下次 check；export 命令能导出 Markdown 交付复盘、CSV 问题清单和 JSON 审计包，history 命令能按剧集、语言和问题类型查询历史检查结果。请把 CLI 入口、配置模型、字幕解析、清单解析、规则校验、跨语言对齐、修复计划、人工复核存储、报告导出、示例数据和测试拆成多个文件，不要写成一个大脚本。README 里写清楚安装方式、示例命令，以及如何用临时目录验证 init、导入多语言字幕、检查问题、生成修复计划、确认输出、人工复核、导出报告和查询历史这些核心流程。
