# 桥梁支座异常归因

## 快速操作（2-3 步）

1. **看图表找异常**：默认已加载「小包试流程」试样包（含 1 条边界脏数据）。在中部趋势图上找**橙色/红色气泡**的时间窗口，点击该窗口下钻到明细。
2. **抓边界样本**：明细弹窗**顶部红色条纹卡片**是反掩盖算法单独拎出的边界/脏数据，不会淹没在均值里。下面异常样本表格每行都标注了「拉动因素：偏离均值 X mm · 贡献 Y%」。
3. **查坏材料批次**：在边界卡或异常行右侧点击「查看材料」，右侧抽屉会显示**供应商、入库日期、入库备注、同批次其他异常**——老何找坏料直接看这里。

> 阈值想临时调高？直接拖左侧滑块或点下面的快捷刻度。**阈值数值会同步到图表水印、明细表头、CSV 首行注释三处**，不会只在页面上闪一下。

## 坏材料来了，重点看哪里

| 现象 | 去哪里看 |
|------|---------|
| 边界/脏数据被单独拎出了 | 明细弹窗 **顶部红色卡**（呼吸灯动画，不会错过） |
| 某条记录把整个窗口均值拉高/拉低 | 表格里带「强拉动异常」标签的行 + 拉动因素进度条 |
| 同一批材料反复出问题 | 右侧材料抽屉底部的「**同批次其他异常**」列表 + 入库备注 |
| 给别人的明细 CSV 要和页面判断一致 | 明细弹窗右上角 **[导出 CSV]**，首行含阈值、试样包、生成时间，判定字段与页面逐行对齐 |
