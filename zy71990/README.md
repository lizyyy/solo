# 日志目录体检工具

给运维同事用的小工具，别太花，能办事就行。

## 功能特性

1. **目录快照** - 拍摄目录快照，自动识别带空格的路径
2. **配置解析** - 解析常见配置文件格式，检查配置中的路径
3. **日志分析** - 分析失败日志，识别：
   - 正常记录
   - 晚到附件
   - 重复项
   - 人工更正
4. **统一时间线** - 把目录快照、配置文件、失败日志放到同一条时间线
5. **修改历史** - 追踪文件人工修改记录，前后变化留在历史里
6. **人性化提示** - 错误提示说人话，不给你看堆栈

## 快速开始

```bash
# 完整体检（最常用）
python3 log_doctor.py check ./test_logs

# 只拍目录快照
python3 log_doctor.py snapshot ./test_logs

# 看统一时间线
python3 log_doctor.py timeline ./test_logs

# 看文件修改历史
python3 log_doctor.py history ./test_logs/fail_20240520.log
```

## 命令说明

### 1. check - 完整体检

会做以下检查：
- ✅ 目标目录是否存在
- ⚠️ 路径有没有空格（会说清是来自目录快照还是配置文件里的）
- 📋 日志文件情况（晚到附件、重复记录数
- ⚙️ 配置文件检查
- 👤 人工修改记录

输出内容包含：
- 问题来源（目录快照 / 配置文件 / 失败日志）
- 具体问题描述
- 下一步找谁处理

### 2. snapshot - 目录快照

拍下当前目录状态，包含：
- 文件总数、目录总数
- 总大小
- 带空格路径警告
- 文件列表（带修改时间和大小

### 3. timeline - 统一时间线

把所有事件按时间排序展示：
- 📁 目录和文件（目录快照
- ⚙️ 配置文件
- 📋 日志文件
- ✅ 正常日志
- ⏰ 晚到附件
- ✏️ 人工更正
- 👤 文件变更历史

### 4. history - 修改历史

查看文件的修改版本，包括：
- 版本号和修改时间
- 人工修改标记 👤
- 修改前后diff
- 变更摘要

## 测试数据

`test_logs/ 目录里有真实材料测试包：

```
test_logs/
├── app_config.ini          # 配置文件（含空格路径配置）
├── fail_20240520.log   # 失败日志（含晚到、重复、人工更正）
├── error_report.csv     # CSV格式日志
├── normal.log         # 正常日志
└── 日志目录 有空格/   # 带空格的目录（用于测试空格路径识别
```

## 输出文件

所有结果都会存到 `output/` 目录：
- `check_report_*.json / .txt  - 体检报告
- `snapshot_*.json          - 目录快照
- `timeline_*.json          - 时间线数据

## 注意事项

1. **路径带空格时，工具会标记来源：
   - 来源：目录快照 → 找目录创建者 / 文件上传者
   - 来源：配置文件 → 找应用负责人改配置

2. **人工修改日志文件后，记得用 history 命令看历史，别让运行账本和明细各说各话

3. 所有修改历史存在 `.log_doctor_history/` 目录下，别删
