# 🐾 宠物寄养交接风险台账系统

一个专为小型宠物寄养店设计的本地管理系统，帮助店主解决节假日前后宠物管理混乱的问题。

## ✨ 核心功能

### 1. 宠物和主人档案管理
- 维护宠物信息：名字、种类、品种、体重、性别、生日、性格特点、健康备注
- 维护主人信息：姓名、联系方式、紧急联系人
- 支持一对多关系（一个主人可以有多个宠物）

### 2. 寄养订单管理
- 创建寄养订单，选择入住/离店时间
- 智能笼位分配，**自动检查时间冲突**，防止同一笼位重复预订
- 记录喂食说明、用药计划、接送方式、特殊要求
- 订单状态流转：待入住 → 已入住 → 已离店

### 3. 今日待办面板
- 今天到店宠物提醒
- 今天离店宠物提醒
- 喂食提醒
- 用药提醒
- 异常事件跟进
- 完成后自动记录操作时间和备注

### 4. 异常事件记录
- 支持记录：不吃饭、呕吐、腹泻、受伤、情绪异常、打架、逃跑等
- 支持严重程度分级（低/中/高/紧急）
- 支持图片/文件名占位记录
- 自动创建跟进待办
- 解决后记录解决方案

### 5. 交接单导出
- 导出为 **Markdown** 格式
- 导出为 **CSV** 格式（兼容 Excel）
- 包含内容：
  - 宠物和主人完整信息
  - 寄养时间和笼位
  - 喂食说明和用药计划
  - 异常事件记录
  - 待办/操作记录
  - 签收确认区域

### 6. 本地数据持久化
- 使用 SQLite 本地数据库
- 数据保存在 `data/fostering.db` 文件
- 刷新页面、重启服务数据不会丢失
- 支持操作日志记录

## 🛠️ 技术栈

- **后端**: Node.js + Express
- **数据库**: SQLite (better-sqlite3)
- **前端**: 原生 HTML/CSS/JavaScript
- **数据格式**: JSON API

## 📖 使用指南

### 首次使用流程

1. **添加主人档案** → 左侧菜单「主人档案」→ 新增主人
2. **添加宠物档案** → 左侧菜单「宠物档案」→ 新增宠物（关联到主人）
3. **创建寄养订单** → 左侧菜单「订单管理」→ 新建订单
   - 选择宠物和主人
   - 选择入住/离店日期
   - 选择笼位（系统会自动检查冲突）
   - 填写喂食说明、用药计划等
4. **日常操作** → 查看「首页」今日待办
   - 点击「完成」标记待办完成
   - 点击「查看订单」查看详情
5. **记录异常** → 左侧菜单「异常事件」→ 记录异常
6. **离店交接** → 订单详情页 → 导出 Markdown/CSV

### 笼位冲突检查

系统会在以下情况自动检查笼位冲突：

1. **创建订单时**：检查该笼位在指定时间段内是否已有订单
2. **编辑订单时**：检查修改后的日期和笼位是否有冲突
3. **加载可用笼位时**：在订单表单中会自动标记已占用的笼位

如果发现冲突，系统会：
- 禁用已占用的笼位（灰色显示）
- 点击已占用笼位时会显示警告提示

### 订单状态说明

| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| 待入住 | 订单已创建，宠物还未到店 | 编辑、确认入住、取消 |
| 已入住 | 宠物已到店入住 | 确认离店 |
| 已离店 | 宠物已离店 | 查看详情、导出 |
| 已取消 | 订单已取消 | 查看详情 |

### 异常事件严重程度

| 级别 | 说明 | 示例 |
|------|------|------|
| 低 | 轻微异常，密切观察即可 | 食欲略有下降、轻微打哈欠 |
| 中 | 中等异常，需要处理 | 呕吐一次、轻微腹泻 |
| 高 | 较严重，需要及时处理 | 频繁呕吐、精神萎靡 |
| 紧急 | 紧急情况，需要立即处理 | 受伤出血、呼吸困难 |

## 🔧 API 接口

| 方法 | 路径 | 说明 |

| POST | /api/owners | 创建主人 |

## 🚀 常见问题

### Q1: 数据存储在哪里？安全吗？

数据存储在项目目录下的 `data/fostering.db` 文件中，这是一个 SQLite 数据库文件。这是本地文件，不会上传到任何服务器，数据完全在你本地。

### Q2: 如何备份数据？

直接复制 `data/fostering.db` 文件即可。恢复时将备份文件放回原位置即可。

### Q3: 支持多台电脑使用吗？

目前是单用户本地系统。如果需要多台电脑使用，可以：
1. 将整个项目目录放在 U 盘或移动硬盘上
2. 或者使用云盘同步 `data` 目录

### Q4: 系统可以定制吗？

可以。代码完全开源，你可以：
- 修改 `public/index.html` 定制前端界面
- 修改 `server.js` 定制 API 逻辑
- 修改 `database.js` 定制数据库结构

### Q5: 如何添加更多笼位？

系统默认创建了 10 个笼位。如需添加更多：

1. 启动系统后，左侧菜单「笼位管理」→「新增笼位」
2. 或者直接修改 `database.js` 中的默认笼位配置
