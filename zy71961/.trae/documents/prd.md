## 1. 产品概述

**模型漂移日报平台** —— 帮助算法工程师一键接收混合材料包，自动去重/归类/追踪人工更正，生成可从结论溯源到标注样本与评估表的漂移日报，同时保留所有手动变更的审计历史，消除"靠记忆问一圈"的协作痛点。

- 解决问题：算法工程师接手漂移日报时无法快速获知谁改过标注样本、评估依据在哪、手动修改是否留痕
- 目标用户：机器学习团队的算法工程师、标注审核员、模型评估负责人

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 算法工程师 | 邀请制 | 导入材料包、查看/导出日报、手动修改线上反馈、查看变更历史 |
| 标注审核员 | 邀请制 | 上传标注样本、查看关联的漂移日报 |
| 团队负责人 | 邀请制 | 查看所有日报、审核评估说明、导出报告 |

### 2.2 功能模块

1. **日报总览页**：日报列表、漂移趋势图、快速筛选与搜索
2. **材料包导入页**：上传材料包、自动识别记录类型（正常/晚到/重复/更正）、清洗预览
3. **日报详情页**：结论总表 + 可溯源链接 + 标注样本关联 + 评估表关联
4. **变更历史页**：所有手动修改的前后差异对比、操作人、时间戳
5. **收尾指南页**：标注样本放置指引、训练集泄漏检查入口、评估说明导出前复核清单

## 3. 核心流程

**材料包导入 → 智能解析清洗 → 生成漂移日报 → 查看溯源 → 手动修正（留痕） → 收尾复核 → 导出**

```mermaid
flowchart TD
    "A: 上传材料包" --> "B: 智能解析（识别四类记录）"
    "B" --> "C: 清洗预览（去重/合并/高亮更正）"
    "C" --> "D: 确认入库"
    "D" --> "E: 生成漂移日报"
    "E" --> "F: 查看结论总表"
    "F" --> "G: 点击溯源链接"
    "G" --> "H: 查看标注样本/评估表"
    "F" --> "I: 手动修正线上反馈"
    "I" --> "J: 自动记录变更历史"
    "J" --> "K: 一致性校验"
    "K" --> "L: 收尾复核清单"
    "L" --> "M: 导出评估说明"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰蓝（#1E293B）为底，搭配琥珀色（#F59E0B）作为警示/高亮色，青绿（#10B981）表示正常/已确认状态
- **按钮风格**：圆角8px，轻微投影，hover时提升投影层次
- **字体**：标题用 JetBrains Mono（数据工具感），正文用 Noto Sans SC
- **布局风格**：左侧固定导航 + 右侧内容区，表格为主但穿插卡片摘要
- **图标风格**：线性图标（Lucide），统一1.5px线宽

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 日报总览页 | 日报列表 | 表格行卡片化，左侧色条标严重度，右侧快速操作按钮 |
| 日报总览页 | 漂移趋势图 | 区域折线图，琥珀色标注漂移阈值线 |
| 材料包导入页 | 上传区 | 虚线边框拖拽区，上传后变为进度条+解析状态 |
| 材料包导入页 | 清洗预览 | 四列卡片（正常/晚到/重复/更正），每列显示数量与占比 |
| 日报详情页 | 结论总表 | 可展开行表格，展开后显示溯源依据链 |
| 日报详情页 | 溯源面板 | 右侧滑出抽屉，显示关联数据及跳转链接 |
| 变更历史页 | 差异对比 | 并排双栏diff视图，删除红底/新增绿底 |
| 变更历史页 | 一致性校验 | 警告横幅 + 不一致项列表 |
| 收尾指南页 | 复核清单 | 步骤卡片+复选框，完成时划线效果 |

### 4.3 响应式

- 桌面优先设计，最小宽度1280px
- 表格在小屏下隐藏次要列，提供横向滚动
- 抽屉面板在移动端改为全屏覆盖
