# 地下管线碰撞巡检系统

## 快速开始

### 1. 启动项目

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

启动后访问 `http://localhost:5173`

### 2. 样例数据位置

样例数据已内置在项目中，启动后自动加载：

- **管线数据**: `src/data/pipelines.ts`
  - 包含正常数据、标高单位错误、管线重叠、数据缺项、手工更正等样例
- **桩号数据**: `src/data/pileMarkers.ts`
  - K0+000 至 K0+300 桩号标记
- **检测配置**: `src/data/config.ts`
  - 净距阈值、颜色映射、标签配置

### 3. 操作流程

1. **查看3D管线** - 启动后自动加载样例管线
   - 鼠标左键：旋转视角
   - 滚轮：缩放
   - 右键：平移

2. **执行碰撞检测**
   - 点击右上角「开始碰撞检测」按钮
   - 检测完成后右侧面板显示结果

3. **桩号定位**
   - 左侧面板「桩号定位」区域
   - 输入桩号（如 K0+100）或点击快捷按钮

4. **问题流转**
   - 在「碰撞结果」中点击碰撞点
   - 点击「流转处理」进入问题流转
   - 选择状态、填写处理意见后提交

5. **导出报告**
   - 检测完成后点击「导出报告」
   - 填写项目名称和检测人员
   - 生成包含数据质量说明的PDF报告

### 4. 查看失败记录

**操作日志查看方式：**
- 点击顶部「日志」按钮
- 支持按级别（信息/警告/错误）和模块筛选
- 可导出为.log文件或清空

**日志存储位置：**
- 运行时日志：浏览器 localStorage (`pipeline_inspection_logs`)
- 导出日志：下载目录 `管线巡检日志_YYYY-MM-DD.log`

**数据异常记录：**
- 检测完成后在「碰撞结果」中点击碰撞点
- 展开查看关联的数据异常及影响说明
- 报告第四章「数据质量问题说明」汇总所有异常

### 5. 样例数据说明

| 问题类型 | 样例管段 | 说明 |
|---------|---------|------|
| 标高单位错误 | w-003 | y坐标-1500mm（应为-1.5m），自动修正 |
| 管线重叠 | w-004、w-005 | 坐标完全相同，标记为重复 |
| 数据缺项 | g-003、e-005 | 管径为0、桩号为空，跳过检测 |
| 手工更正 | e-004 | 标记为corrected数据源 |
| 净距不足 | e-003与w-002 | 交叉处净距不足 |
| 标高异常 | w-006与w-007 | 同桩号标高差异2.5m |

## 项目结构

```
src/
├── components/
│   ├── layout/       # Header、StatusBar
│   ├── panels/       # LeftPanel、RightPanel
│   ├── three/        # 3D渲染组件
│   └── modals/       # 弹窗组件
├── engine/           # 碰撞检测、数据校验
├── stores/           # Zustand状态管理
├── data/             # 样例数据和配置
├── types/            # TypeScript类型定义
└── utils/            # 工具函数
```

## 技术栈

- React 18 + TypeScript
- Three.js + @react-three/fiber
- Zustand 状态管理
- TailwindCSS 3
- jsPDF + html2canvas 报告导出
