## 1. 产品概述

租赁保证金退回管理工具，面向资金组人员，解决复盘时翻找银企回单截图、证据链断裂、改判无痕迹等痛点。目标是让每笔"租赁保证金退回"记录从发现、判定、补录到导出全程可追溯，缺凭证的记录挂起在明面上，不做数字粉饰。

- 核心用户：资金组小周及其同事，日常需要核查和判定租赁保证金退回业务
- 核心价值：减少翻旧记录的时间成本，每条记录的判定依据和处理时间一目了然，接手人无需重新翻银企回单截图

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 资金组人员 | 直接访问 | 查看、改判、回退、补录备注、导出 |
| 审计/接手人 | 直接访问 | 只读查看、导出 |

### 2.2 功能模块

1. **记录列表页**：全部退回记录的总览，支持筛选状态/金额/日期，挂起记录醒目展示，汇总区已确认与挂起金额分开展示
2. **记录详情页**：单条记录完整信息，含附件（银企回单截图、业务台账、群截图、补来说明）、原始备注、处理时间线、改判/回退/补录操作入口
3. **改判与回退**：改判需填写原因，回退至上一判定状态，所有变更记录在时间线上
4. **补录备注**：临时补一条备注，系统自动对比补录前后差异并展示
5. **导出**：按当前筛选条件导出 CSV，含所有字段及附件摘要

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 记录列表页 | 汇总区 | 已确认总金额、挂起总金额、记录总数分开展示，挂起金额用警示色标注 |
| 记录列表页 | 筛选栏 | 按状态（已确认/挂起/已退回）、金额范围、日期范围筛选，关键词搜索 |
| 记录列表页 | 记录表格 | 每行显示：编号、退回单位、金额、当前状态、原始来源、最近处理时间、操作按钮 |
| 记录详情页 | 基本信息卡 | 退回单位、金额、保证金类型、原始来源、首次录入时间 |
| 记录详情页 | 附件区 | 银企回单截图、业务台账、群截图、补来说明，保留原始文件名和备注（不清洗乱备注） |
| 记录详情页 | 判定时间线 | 按时间倒序展示所有判定/改判/回退/补录操作，含操作人、时间、原因、差异说明 |
| 记录详情页 | 操作区 | 改判按钮（需填原因）、回退按钮（回退到上一状态）、补录备注按钮 |
| 导出功能 | 导出面板 | 选择导出范围（全部/当前筛选），字段包含编号、金额、状态、原始来源、所有备注、处理时间 |

## 3. 核心流程

资金组小周打开系统，在列表页浏览全部退回记录。发现一笔挂起记录，点击进入详情页查看银企回单截图和原始备注。确认证据充分后点击"改判"，填写改判原因将状态改为"已确认"。如发现误判，点击"回退"恢复上一状态。临时补来新说明时，点击"补录备注"，系统自动对比并展示差异。完成一批后导出 CSV 归档。

## 4. 用户界面设计

### 4.1 设计风格

- **色调**：以深灰/炭色为底，搭配琥珀色（#D97706）作为强调色，挂起状态用铁锈红（#DC2626）警示，已确认用墨绿（#059669）。整体传达"财务严谨、工业实用"的氛围
- **字体**：数字和金额使用等宽字体 JetBrains Mono，正文使用 Noto Sans SC，标题使用 Source Han Sans / Noto Sans SC 加粗
- **布局**：桌面优先，左侧固定导航栏，主内容区宽屏卡片式布局，表格紧凑但不拥挤
- **按钮风格**：圆角矩形，改判用琥珀色实心，回退用灰色描边，补录备注用浅色描边+图标
- **图标风格**：线性图标（Lucide 风格），不使用 emoji

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 记录列表页 | 汇总区 | 3个统计卡片横排：已确认金额(墨绿)、挂起金额(铁锈红)、记录总数(深灰)，金额用 JetBrains Mono 大号显示 |
| 记录列表页 | 筛选栏 | 水平排列的状态标签按钮、日期选择器、金额输入框、搜索框，紧凑一行 |
| 记录列表页 | 记录表格 | 紧凑表格，状态用彩色标签，挂起行左侧有铁锈红竖条，操作列图标按钮 |
| 记录详情页 | 基本信息卡 | 左上信息网格，右上状态标签，底部原始来源和时间戳 |
| 记录详情页 | 附件区 | 缩略图网格，保留原始文件名，hover 显示备注气泡（含乱备注原文） |
| 记录详情页 | 时间线 | 左侧竖线+圆点，每条操作含时间戳、操作类型图标、描述、差异高亮 |
| 记录详情页 | 操作区 | 底部固定操作栏，3个主操作按钮 |

### 4.3 响应式策略

- 桌面优先设计（1280px+ 最佳体验）
- 1024px 以下：侧边栏收起为顶部汉堡菜单
- 768px 以下：表格改为卡片列表，详情页单列堆叠

### 4.4 数据持久化保证

- 使用 SQLite 本地数据库，所有记录、备注、改判历史、附件元数据均持久化存储
- 服务重启后数据完整保留，历史备注和导出数字对得上
- 附件文件存储在本地 uploads 目录
