# 建筑日照推演系统 - 使用说明

## 培训老师操作指南

### 1. 放置评分表样例

1. 进入「记录管理」页面
2. 点击「导入数据」按钮
3. 可先点击「下载导入模板」获取标准格式
4. 将评分表数据按照模板格式整理后，拖拽或选择文件导入
5. 导入后系统会自动为每条记录创建唯一ID并标记为「待处理」状态

**模板字段说明：**
- 建筑名称：对应建筑模型名称
- 楼层：数字格式
- 房间号：文本格式
- 来源：如"2024春季班-第3组"

### 2. 拖拽后状态丢失排查

系统所有数据自动保存到浏览器 localStorage，状态不会因为页面刷新或拖拽操作丢失。如遇问题：

**常见情况及解决：**

1. **3D场景中建筑选中状态消失**
   - 点击空白区域会取消选中状态
   - 重新点击建筑即可恢复选中
   - 记录数据本身不受影响

2. **记录列表筛选重置**
   - 切换页面或刷新后筛选条件会重置为"全部"
   - 可重新选择状态筛选
   - 记录状态本身不会改变

3. **浏览器清缓存后数据丢失**
   - ⚠️ 重要：定期导出数据备份
   - 可使用「重置示例」恢复演示数据
   - 建议每次课程结束后导出完整报告

### 3. 导出课堂记录前复核流程

**复核 checklist：**

1. **检查"待处理"记录**
   - 进入「记录管理」页面
   - 筛选"待处理"状态
   - 逐条确认：点击详情查看 → 3D场景核对日照 → 标记状态

2. **检查"待补充"记录**
   - 确保所有待补充记录都已填写原因
   - 如需补充：联系相关学生补充数据 → 更新状态

3. **检查"已修改"记录**
   - 确认人工修改的记录都有详细的修改原因
   - 状态历史中可查看完整变更记录

4. **最终确认**
   - 进入「导出报告」页面
   - 查看三个分类卡片的统计数字
   - 确认「已确认」记录数量符合预期
   - 确认「待补充」记录都已处理或有明确说明

**导出操作：**
- 点击「导出 Excel 报告」按钮
- 文件自动下载，命名格式：`建筑日照推演课堂记录_YYYY-MM-DD.xlsx`

## 教研负责人报告说明

### 报告结构

导出的 Excel 文件包含 3 个工作表：

| 工作表 | 说明 | 处理口径 |
|-------|------|---------|
| 已确认 | 数据复核无误，可直接用于教学评估 | 日照推演结果符合预期标准，数据经过至少1次复核 |
| 待补充 | 信息缺失或参数不全，需要补充 | 3个工作日内补充实测数据或修正参数后重新复核 |
| 人工改过 | 原始数据有误，已进行人工修正 | 重点跟踪验证修正效果，课堂上可作为错误案例讲解 |

### 每个工作表包含

1. **首行处理口径说明** - 便于快速了解分类标准
2. **数据列表** - 包含完整记录信息：
   - 建筑名称、楼层、房间号
   - 来源、导入时间、导入人
   - 当前状态、当前处理人
   - 待处理原因、是否人工修改
   - 最后修改时间、最后修改人、备注

### 数据统计参考

- **已确认比例**：建议 ≥ 80% 为合格
- **待补充比例**：建议 ≤ 15%
- **人工改过比例**：建议 ≤ 10%（过高可能说明学生普遍存在某类问题）

## 系统启动方式

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

系统启动后默认打开 `http://localhost:3000`
