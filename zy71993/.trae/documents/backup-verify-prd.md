## 1. 产品概述

本地备份核验系统——值班运维每周抽查机器本地备份时，自动比对目录快照、校验值清单、失败日志和回滚记录，将每个备份包的完整状态透明呈现，解决"控制台显示成功但实际缺文件"的信任危机。

- 目标用户：值班运维人员
- 核心价值：将备份状态从"表面成功"推进到"证据级可信"，一次核验即可发现缺文件、压缩包损坏、重复备份、回滚残留等隐患

## 2. 核心功能

### 2.1 用户角色

| 角色 | 权限 |
|------|------|
| 值班运维 | 导入数据、执行核验、查看问题清单、导出报告、查看历史遗留 |
| 研发人员 | 通过报告中的"必须研发介入"条目接收工单 |

### 2.2 功能模块

1. **核验工作台**：导入/加载数据源，一键启动核验，总览备份包状态分布
2. **问题清单页**：按严重程度分类的所有异常条目，支持从异常追溯到原始路径和日志片段
3. **历史对比页**：同一机器跨周核验时，展示上次遗留未关闭的问题
4. **报告导出**：生成值班群可读的核验报告，分"可忽略 / 需补备份 / 必须研发介入"三档

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 核验工作台 | 数据源面板 | 加载目录快照JSON、校验值清单CSV、失败日志文件、回滚记录JSON |
| 核验工作台 | 状态总览 | 饼图/数字卡片展示：正常/缺文件/损坏/重复/回滚残留数量 |
| 核验工作台 | 备份包列表 | 表格列出每个备份包的名称、路径、大小、校验结果、时间戳，异常行高亮可展开 |
| 问题清单 | 严重度筛选 | 三档筛选：可忽略 / 需补备份 / 必须研发介入 |
| 问题清单 | 异常条目卡片 | 每条异常显示：类型标签、涉及路径、简述、点击展开查看原始路径+日志片段 |
| 问题清单 | 追溯面板 | 展开异常条目时，显示完整的原始文件路径（含空格）、相关日志片段、校验值差异 |
| 历史对比 | 机器选择 | 选择目标机器，加载其历史核验记录 |
| 历史对比 | 遗留问题列表 | 上次核验未关闭的问题以醒目标记展示，支持标注"已处理"或"继续遗留" |
| 报告导出 | 报告预览 | 按三档严重度分组预览报告内容 |
| 报告导出 | 导出按钮 | 导出为 Markdown 文本，可直接粘贴到值班群 |

## 3. 核心流程

1. 运维打开核验工作台，选择目标机器并加载数据源（目录快照 + 校验值清单 + 失败日志 + 回滚记录）
2. 系统自动逐项核验：比对快照与校验值、检测压缩包完整性、识别同日重复备份、检测回滚后校验值是否更新
3. 核验完成后，问题清单页按严重度展示所有异常条目
4. 运维点击任意异常，追溯面板展示原始路径和日志片段
5. 运维导出核验报告至值班群，报告分三档严重度
6. 下周核验同一机器时，历史对比页展示上次遗留问题

## 4. 用户界面设计

### 4.1 设计风格

- **色调**：深色工业风，主色 `#1a1a2e`，辅色 `#16213e`，警告色 `#e94560`，成功色 `#0f3460` → `#00d2ff` 渐变，强调数据密度和可读性
- **按钮**：圆角 6px，扁平风格，操作按钮带微妙 hover 发光
- **字体**：数据区 `JetBrains Mono`，正文 `Noto Sans SC`，标题加粗大字号
- **布局**：左侧固定导航栏 + 右侧内容区，卡片式内容模块
- **图标**：线性图标（Lucide 风格），状态用颜色圆点标识

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 核验工作台 | 数据源面板 | 文件拖拽上传区域，已加载文件列表带状态标签（绿/红） |
| 核验工作台 | 状态总览 | 4张数字卡片（正常/缺文件/损坏/异常），数字大号+颜色编码 |
| 核验工作台 | 备份包列表 | 条纹表格，异常行红底，展开行显示详情面板 |
| 问题清单 | 严重度筛选 | 三个 Tab 切换，带数量角标 |
| 问题清单 | 异常条目卡片 | 左侧色条标识严重度，右侧展开箭头 |
| 问题清单 | 追溯面板 | 嵌入式面板，代码块展示路径和日志，支持复制 |
| 历史对比 | 遗留问题列表 | 时间线布局，新问题在上，遗留问题带⚠️图标 |
| 报告导出 | 报告预览 | Markdown 渲染预览，三档分色标题 |
| 报告导出 | 导出按钮 | 主按钮"复制到剪贴板" + "下载 .md 文件" |

### 4.3 响应式

- 桌面优先，最小宽度 1024px
- 导航栏在窄屏折叠为图标模式
- 表格在窄屏支持水平滚动
