# 古典唱片母带归档管理系统

为音乐老师林老师打造的合同扫描件与归档材料管理工具。

## 快速开始

直接用浏览器打开 `index.html` 文件即可使用，无需安装任何依赖。

## 功能特性

### 1. 曲目管理
- 录入曲目信息：名称、作曲家、表演者、时长、ISRC、音频文件
- 状态标记：待处理 / 已确认 / 需复核 / 已驳回
- 关联合同、记录原始来源
- 人工批注字段（保留林老师的原始备注）

### 2. 合同备注管理
- 记录合同信息：名称、编号、授权期限
- **原样保留**合同扫描件中的原始备注内容
- 记录内部批注（微信群补充、林老师批注等）
- 列出授权曲目清单

### 3. 自动问题检测
- ✅ **授权过期检测** - 自动识别已过期和即将到期（30天内）的授权
- ✅ **重复曲目检测** - 发现同名曲目（标注是不同版本还是数据重复）
- ✅ **时码差异检测** - 批注中提到时长不一致时自动检测
- ✅ **合同授权冲突** - 曲目关联了合同但不在授权列表中时提示

### 4. 冲突处理
- 合同扫描件说法 vs 导入数据说法 **并列展示**
- 不替用户做决定，只摆证据和建议动作
- 保留双方的原始来源信息

### 5. 数据导出
- **CSV格式** - 适合演出/发行同事查看（Excel可直接打开）
- **JSON格式** - 完整数据备份
- 导出范围可选：全部 / 仅已确认 / 仅问题项 / 当前筛选结果
- **导出时附带问题原因和处理建议**，不让同事靠猜

### 6. 数据导入导出
- 支持 JSON 格式完整备份和恢复
- 数据保存在浏览器 LocalStorage 中（定期导出备份）

## 界面说明

### 左侧边栏
- **统计概览** - 总曲目、合同数、过期数、问题数
- **快速筛选** - 按问题类型过滤曲目
- **问题列表** - 所有问题的集中展示

### 主内容区（三个标签页）
1. **曲目表** - 所有曲目卡片，带问题标签和状态
2. **合同备注** - 合同信息，保留原始备注
3. **冲突检测** - 数据冲突的证据对比和处理建议

## 使用流程

### 日常归档流程
1. 点击「添加曲目」录入曲目信息
2. 点击「添加合同」录入合同扫描件内容（备注原样输入）
3. 在曲目编辑中关联对应合同
4. 系统自动检测问题（左侧问题列表会更新）
5. 查看「冲突检测」标签页处理数据不一致
6. 确认无误后，点击「导出清单」给同事

### 交接时核对流程
1. 导出完整清单（CSV格式）
2. 对照合同扫描件检查「来源」字段是否对应
3. 问题项已在导出文件中单独列出原因
4. 「人工批注」字段保留了所有历史记录，接手人能看懂

## 字段说明

### 曲目字段
| 字段 | 说明 |
|------|------|
| 原始来源 | 必填，记录从哪来（如：合同扫描件第3页、微信群2024-01-15） |
| 人工批注 | 林老师的原始判断，不要修改 |
| 状态 | 待处理/已确认/需复核/已驳回 |

### 合同字段
| 字段 | 说明 |
|------|------|
| 合同备注 | **原样录入合同中的内容**，不要修改 |
| 内部批注 | 林老师补充、微信群内容等 |
| 合同扫描件来源 | 记录页码、文件名等 |

## 重要原则

1. **合同备注不修改** - 合同扫描件里怎么写就怎么录，系统会自动比对
2. **来源必填写** - 每一条数据都要能追溯到原始材料
3. **问题不隐藏** - 导出时问题原因会一起出现在清单里
4. **冲突不自动解决** - 只摆证据，人来拍板
