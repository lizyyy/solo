## 1. 产品概述

粮仓通风阻力复盘工具，面向粮仓设备工程师（如何工）和安全员，解决维修群截图一晚到后原始判断可能变化、返工无痕迹、传感器重启后编号变更难以追踪等痛点。目标：让每一次数据变更都留痕、每一步判断都有据可查、安全员无需追问即可分清卡点。

- 核心用户：设备工程师（导入与补录）、安全员（复核与审批）
- 价值：将"返工留在明面上"，避免一个地方显示异常、另一个地方消失的数据不一致问题

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 设备工程师 | 工号登录 | 导入设备铭牌参数、补看维修群截图、补录数据、触发重算 |
| 安全员 | 工号登录 | 查看复盘结果、复核传感器重启编号变更、审批安全提醒更新、导出报告 |

### 2.2 功能模块

1. **数据导入页**：CSV/Excel 导入设备铭牌参数，重复导入检测，原始行号保留
2. **复盘工作台**：三步工作流（铭牌导入 → 维修群截图补看 → 安全提醒更新），传感器重启编号变更卡点展示
3. **自检面板**：覆盖重复导入、传感器重启编号变更、补录后重算、导出一致四项自检
4. **审计追踪面板**：每条记录的原始行号、人工改动、当前处理状态完整留痕
5. **导出与报告**：明细导出、汇总报告，确保导出内容与页面展示和接口返回一致

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入页 | 文件上传区 | 拖拽/选择 CSV/Excel，解析后展示预览，标记重复行与异常行 |
| 数据导入页 | 导入历史 | 展示历次导入记录，含时间、操作人、行数、自检结果 |
| 复盘工作台 | 三步流程指示器 | 步骤1：铭牌参数确认→步骤2：维修群截图补看→步骤3：安全提醒更新 |
| 复盘工作台 | 传感器编号变更卡片 | 传感器重启后编号变更记录，标记状态（待复核/已确认/异常），卡点位置清晰 |
| 复盘工作台 | 数据明细表 | 当前批次所有记录，含原始行号、改动标记、处理状态 |
| 自检面板 | 自检结果列表 | 四项自检结果：重复导入、传感器编号变更、补录重算、导出一致，红/黄/绿状态 |
| 自检面板 | 自检详情 | 点击某项自检展开异常明细，支持一键跳转到对应记录 |
| 审计追踪面板 | 变更时间线 | 每条记录的所有变更事件，含操作人、时间、变更前后值 |
| 审计追踪面板 | 原始行号对照 | 显示原始行号、人工改动字段、当前处理状态，安全员追问时可回溯 |
| 导出页 | 导出配置 | 选择导出范围（全部/异常/待复核），格式（CSV/PDF） |
| 导出页 | 一致性校验 | 导出前自动校验导出数据与接口返回一致性 |

## 3. 核心流程

### 3.1 三步工作流

设备工程师何工第一次导入设备铭牌参数 → 维修群截图一晚到，何工补看截图发现传感器重启后编号变了 → 系统不自动归正常，标记为"待安全员复核" → 安全员打开结果，分清编号变更卡在哪一步 → 安全员确认后，安全提醒更新

```mermaid
flowchart TD
    "步骤1: 铭牌参数导入" --> "自检: 重复导入检测"
    "自检: 重复导入检测" --> "步骤2: 维修群截图补看"
    "步骤2: 维修群截图补看" --> "发现传感器重启编号变更?"
    "发现传感器重启编号变更?" -->|"是"| "标记: 待安全员复核"
    "发现传感器重启编号变更?" -->|"否"| "步骤3: 安全提醒更新"
    "标记: 待安全员复核" --> "安全员复核"
    "安全员复核" -->|"确认"| "步骤3: 安全提醒更新"
    "安全员复核" -->|"退回"| "步骤2: 维修群截图补看"
    "步骤3: 安全提醒更新" --> "自检: 补录后重算"
    "自检: 补录后重算" --> "导出报告"
    "导出报告" --> "自检: 导出一致性校验"
```

```mermaid

    "新编号与旧编号不匹配" --> "系统自动标记: 编号变更待复核"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1B2A4A）+ 琥珀警示色（#D97706）+ 翠绿正常色（#059669）
- 按钮风格：圆角矩形，带微妙阴影，状态色清晰
- 字体：思源黑体/Noto Sans SC，表头 14px 加粗，正文 13px 常规
- 布局风格：左侧导航栏 + 右侧内容区，卡片式模块
- 图标风格：线性图标（Lucide），配合状态色

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 数据导入页 | 文件上传区 | 虚线拖拽区域，上传图标，文件名与行数预览，重复行标黄 |
| 数据导入页 | 导入历史 | 时间线列表，每项含操作人头像、时间戳、行数徽章、自检结果色标 |
| 复盘工作台 | 三步流程指示器 | 水平步骤条，当前步高亮，完成步打勾，待做步灰色 |
| 复盘工作台 | 传感器编号变更卡片 | 独立卡片，琥珀色边框，旧编号→新编号对比，状态徽章，卡点步骤标签 |
| 复盘工作台 | 数据明细表 | 斑马纹表格，改动字段琥珀底色，处理状态列含色标圆点 |
| 自检面板 | 自检结果列表 | 四项大卡片，含图标+标题+状态色+异常计数，可点击展开 |
| 审计追踪面板 | 变更时间线 | 垂直时间线，每个事件含时间戳、操作人、变更字段、前后值 |
| 导出页 | 导出配置 | 选项卡切换导出范围，格式选择按钮组，一致性校验进度条 |

### 4.3 响应式设计

- 桌面优先（1440px+），适配 1280px 和 1024px
- 表格在小屏幕下支持横向滚动
- 移动端简化为关键操作视图

## 4.4 交接体验设计

安全员打开结果时：
1. 顶部横幅显示"待复核事项 N 项"，可直接跳转
2. 传感器编号变更卡片明确标注"卡在步骤2：维修群截图补看"
3. 无需询问设备工程师即可理解完整上下文
4. 审计时间线完整展示从导入到当前状态的所有变更
