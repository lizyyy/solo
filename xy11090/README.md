# 农贸市场摊位费减免管理系统

一个基于FastAPI的摊位费减免管理API，支持减免申请的导入、处理、复核全流程。

## 项目特点

- ✅ **完整业务流程**: 导入 → 处理 → 复核，三阶段审核
- ✅ **智能审核规则**: 重复减免检测、收费表一致性校验、休市请假重叠检测
- ✅ **详细错误消息**: 错误码、错误原因、处理建议三要素，调用方可据此补材料或转人工
- ✅ **真实业务数据**: 包含摊位、摊主、休市通知、请假申请、收费记录等完整业务字段
- ✅ **异常样例测试**: 预置正常和异常场景的样例数据，一键运行演示
- ✅ **目录结构简单**: 便于后续添加前端或定时任务

## 核心业务字段

| 业务实体 | 关键字段 |
|---------|---------|
| 摊位 | 摊位编号、摊位面积、摊位类型、所属区域、月费标准 |
| 摊主 | 摊主姓名、身份证号、联系电话、经营范围、合同起止日期 |
| 休市通知 | 通知编号、休市标题、休市原因、起止日期、影响区域、发布部门 |
| 请假申请 | 请假编号、请假原因、起止日期、请假天数、审批人、审批日期 |
| 收费记录 | 收费月份、应缴金额、实缴金额、缴费截止日、票据状态、票据编号 |
| 减免申请 | 减免编号、减免类型、关联休市/请假、减免金额、申请人、申请日期、复核截止日、处理人、复核人、票据状态 |

## 审核规则说明

### 1. 重复减免检测
- 同一摊位、同一月份、同一减免类型，不能重复申请
- 拦截后状态：**直接驳回**，提示具体重复的申请编号

### 2. 收费表一致性校验
- 减免金额不能超过当月应缴金额
- 如超过则进入 **待人工处理** 状态，提示补缴截止日

### 3. 休市与请假重叠检测
- 同一时间段内，不能同时申请临时休市减免和个人请假减免
- 如检测到重叠则进入 **待人工处理** 状态，说明重叠的具体日期范围

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 初始化种子数据

```bash
python seed_data.py
```

将导入以下数据：
- 5个摊位（A001-A002蔬菜摊、B001-B002水产摊、C001鲜肉摊）
- 5个摊主（张大明、李淑芬、王海洋、赵翠花、陈一刀）
- 3条休市通知（春节、五一、消防改造）
- 4条请假申请
- 20条收费记录（含补缴截止日和票据状态）

### 3. 启动服务

```bash
python main.py
```

或使用uvicorn：
```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

### 4. 访问API文档

- Swagger UI: http://localhost:8000/docs
- ReDoc: http://localhost:8000/redoc

### 5. 一键运行完整演示

在Swagger UI中找到 `/demo/run-full-flow/` 接口，点击"Try it out" → "Execute"

将自动执行：
1. 导入5个样例减免申请（含正常和异常场景）
2. 批量处理所有已导入的申请
3. 进行复核（一半通过、一半驳回）
4. 展示最终状态统计

## API接口说明

### 基础数据接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/stalls/` | 获取所有摊位 |
| GET | `/vendors/` | 获取所有摊主 |
| GET | `/closures/` | 获取所有休市通知 |
| GET | `/leaves/` | 获取所有请假申请 |
| GET | `/fee-records/` | 获取所有收费记录 |

### 减免申请接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/reductions/import/` | 导入减免申请 |
| GET | `/reductions/` | 获取所有减免申请（可按状态筛选） |
| GET | `/reductions/{id}` | 获取单个减免申请详情 |
| POST | `/reductions/{id}/process/` | 处理减免申请 |
| POST | `/reductions/{id}/review/` | 复核减免申请 |

### 辅助接口

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/sample-reductions/` | 获取样例减免申请数据 |
| POST | `/demo/run-full-flow/` | 运行完整演示流程 |

## 减免申请状态流转

```
已导入/待人工处理
      ↓
    [处理]
      ↓
   待复核
      ↓
    [复核]
   ↙   ↘
已通过  已驳回
```

## 错误响应格式

所有业务校验错误均返回统一格式：

```json
{
  "error_code": "DUPLICATE_REDUCTION",
  "error_message": "该摊位2024-02月份已存在临时休市减免申请（编号：JM-2024-02-001）",
  "suggestion": "请撤回原有申请后重新提交，或联系管理员进行合并处理"
}
```

## 样例数据说明

系统预置5个样例减免申请：

1. **正常申请-春节休市减免** - 正常导入，状态为"已导入"
2. **异常申请-重复减免** - 导入失败，提示重复减免
3. **异常申请-减免金额超标** - 进入"待人工处理"，提示金额超标
4. **异常申请-休市与请假同时减免** - 进入"待人工处理"，提示与休市重叠
5. **正常申请-个人请假减免** - 正常导入，状态为"已导入"
