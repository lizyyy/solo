# 配餐偏差复盘台

社区食堂营养师专用的本地数据分析可视化工具，用于分析配餐偏差、菜品浪费和慢病人群营养摄入情况。

## 功能特性

### 📥 数据导入与校验
- 支持导入五类CSV数据：老人信息、菜品信息、订餐数据、打餐数据、剩余数据
- 自动校验数据格式：老人编号(E+5位数字)、菜品编码(D+4位数字)、克重范围(0-5000g)、日期格式(YYYY-MM-DD)
- 坏行单独列出，可选择仅导入有效记录
- 提供"加载示例数据"快速开始功能

### ✅ 数据校验
- 多层次校验机制：格式校验 → 引用校验 → 交叉校验
- 校验统计展示：总行数、有效行数、无效行数、错误数
- 错误详情表格，包含行号、列名、错误类型、描述、建议
- 交叉校验订餐-打餐数据一致性

### 📊 数据分析仪表盘
- **总体概况**：总订单数、用餐老人数、总供给量、总浪费量
- **菜品浪费分析**：浪费率排行柱状图、长期少打菜品检测（连续3天少打率≥60%）
- **慢病人群分析**：各慢病标签钠/蛋白质摄入对比图、营养偏差分析
- **每日趋势**：重量趋势线图、浪费率趋势图、餐次分布图
- **营养告警**：按老人分析营养超标/不足，分三级告警（严重超标/超标/摄入不足）

### ✏️ 数据修正
- 支持按老人编号、菜品名称、餐次筛选记录
- 可编辑实际克重，选择修正原因
- 保存修正历史，标记手动修正记录

### 📤 数据导出
- 导出明细CSV：老人信息、菜品信息、订餐数据、打餐数据、剩余数据、修正记录
- 生成Markdown复盘报告：包含总体概况、浪费分析、慢病分析、改进建议

### 数据分析功能

#### 浪费分析
- **浪费率** = 剩余重量 / 实际打餐重量 × 100%
- **少打率** = 少打次数 / 总打餐次数 × 100%
- **长期少打**：连续3天以上少打率≥60%的菜品

#### 营养计算
- 实际摄入 = 打餐重量 - 剩余重量
- 营养摄入量 = (实际摄入重量 / 100) × 每100g营养成分
- 营养偏差 = (实际摄入 - 参考值) / 参考值 × 100%

#### 慢病分析
按慢病标签分组统计营养摄入：
- **糖尿病**：关注碳水化合物和能量摄入
- **高血压**：关注钠摄入
- **高血脂**：关注脂肪摄入
- **痛风**：关注嘌呤相关菜品
- **肾病**：关注蛋白质摄入

### 数据修正流程

1. 进入"数据修正"页面
2. 使用筛选条件找到需要修正的记录
3. 点击表格中的记录行进行选择
4. 在下方编辑区域输入新的实际克重
5. 选择修正原因，填写操作员信息
6. 点击"保存修正"按钮
7. 修正记录会保存到修正历史中

### 导出报告

1. 进入"数据导出"页面
2. 选择报告日期范围和餐次
3. **导出CSV**：勾选需要导出的数据类型，点击"生成并下载CSV"
4. **生成复盘报告**：点击"生成复盘报告"按钮，查看预览后可复制为Markdown格式

## 配置说明

主要配置在 `config/settings.py` 中：

- **MEAL_TYPES**: 餐次类型定义
- **CHRONIC_DISEASES**: 慢病标签及饮食限制
- **NUTRITION_ITEMS**: 营养项定义及每日参考值
- **VALIDATION_RULES**: 数据校验规则
- **STORAGE_CONFIG**: 存储配置（数据目录、版本数量等）
- **SAMPLE_DATA_CONFIG**: 示例数据生成配置

## 常见问题

**Q: 数据导入后校验失败怎么办？**
A: 查看"数据校验"页面的错误详情，根据建议修改CSV文件后重新导入。

**Q: 如何判断菜品是否长期少打？**
A: 系统定义连续3天以上少打率≥60%为长期少打，会在仪表盘高亮显示。

**Q: 营养参考值是如何设置的？**
A: 参考中国居民膳食指南（老年人版），可在 `config/settings.py` 中修改。

**Q: 数据会保存在哪里？**
A: 上传数据保存在 `data/uploads/` 目录，历史版本保存在 `data/archive/` 目录。
