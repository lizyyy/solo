# 养老院药事组养老药品效期管理 CLI

专为养老院药事组设计的药品效期管理工具，解决后续追责和复盘无依据的问题。

## 核心特性

- ✅ 正常结果和异常结果分开存储，便于人工复核
- ✅ 拆零药品、家属自带药、可复跑记录单独分类，不混入正常结果
- ✅ 完整的业务场景样例数据，无需外网依赖
- ✅ 清晰的复核指引和报告

## 目录结构

```
.
├── data/              # 待处理药品数据
├── output/
│   ├── normal/        # 正常有效期药品
│   ├── abnormal/      # 异常药品（过期、临期、信息不完整）
│   ├── split-medicine/ # 拆零药品
│   ├── family-brought/ # 家属自带药
│   └── re-runnable/   # 需人工复核后可复跑记录
├── src/               # CLI 源码
└── package.json
```

## 使用流程

### 第一步：安装依赖

```bash
npm install
```

### 第二步：预览数据分类结果

在正式执行前，先预览分类统计，确认数据无误：

```bash
npm run preview
# 或
node src/index.js preview
```

**输出示例：**
```
处理文件: 养老院药品库存_202605.csv
共读取 63 条记录

=== 分类统计 ===
正常药品: XX 条
异常药品: XX 条
拆零药品: XX 条
家属自带药: XX 条
可复跑记录: XX 条

预览模式，未写入文件
```

### 第三步：正式执行药品效期分类

确认预览结果无误后，正式执行分类并写入输出文件：

```bash
npm run run
# 或
node src/index.js run
```

执行完成后，所有分类结果将保存到 `output/` 目录下的对应子目录中。

### 第四步：查看分类报告和复核指引

```bash
npm run report
# 或
node src/index.js report
```

## 复核工作流程

### 1. 优先处理异常药品 (output/abnormal/)

| 状态 | 说明 | 处理优先级 |
|------|------|------------|
| expired | 药品已过期 | ⭐⭐⭐⭐⭐ 立即下架销毁 |
| warning | 30天内即将过期 | ⭐⭐⭐⭐ 优先使用 |
| attention | 90天内即将过期 | ⭐⭐⭐ 列入重点关注 |
| incomplete | 药品信息不完整 | ⭐⭐⭐ 补充批号/厂家信息 |
| invalid | 库存数量异常 | ⭐⭐ 核对库存 |

### 2. 单独复核特殊品类

- **拆零药品** (output/split-medicine/)：单独管理，注意拆零有效期
- **家属自带药** (output/family-brought/)：家属登记确认，单独存放

### 3. 处理可复跑记录

- **可复跑记录** (output/re-runnable/)：人工确认修正后，重新跑批

### 4. 正常药品存档

- **正常药品** (output/normal/)：作为存档备查

## 业务字段说明

| 字段 | 说明 |
|------|------|
| 药品名称 | 药品通用名 |
| 规格 | 药品规格 |
| 批号 | 生产批号 |
| 生产厂家 | 生产企业 |
| 有效期 | 有效期截止日期 |
| 库存数量 | 当前库存 |
| 药品类型 | 常规药品/拆零药品/家属自带药 |
| 存放位置 | 药品存放柜位 |
| 需复核 | 是否需要人工复核 |

## 追责和复盘依据

所有输出文件均包含：
- 原始药品信息
- 分类状态
- 分类原因说明
- 距过期天数（异常药品）

可作为：
- 药事组工作记录存档
- 药品效期问题追责依据
- 月度/季度复盘分析数据
- 管理评审佐证材料
