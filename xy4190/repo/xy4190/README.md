# 🌡️ 温控偏航复盘板

疫苗冷链质控数据分析可视化应用 - 专为疫苗冷链质控员设计的本地数据分析工具。

## 项目简介

每天会拿到多台冰箱温度记录 CSV、开门事件 JSON、校准证书和运输批次表，最怕探头漂移、短时超温被平均值盖掉、同批疫苗暴露时长算错。

温控偏航复盘板能够：
- 📊 **智能检测异常** - 自动识别超温、低温、连续超温、数据缺失、温度骤变、长时间开门等异常
- 🎯 **精准计算指标** - 防止平均值掩盖短时超温，精确定位异常片段
- ⏱️ **批次暴露追踪** - 精确计算同批疫苗在开门和异常期间的暴露时长
- 📝 **人工复核机制** - 支持对异常进行人工复核，标注原因和备注
- 📤 **多格式导出** - 导出 Markdown 报告、CSV 异常清单、JSON 审计包

## 功能特性

### 数据解析模块
- 支持多格式数据导入：
  - 温度记录 CSV（自动识别时间列和温度列）
  - 开门事件 JSON
  - 校准证书 JSON
  - 运输批次表 CSV
- 智能列名识别（支持中英文列名）
- 自动设备ID推断

### 规则引擎
- **温度阈值检测**：超温/低温瞬时异常
- **连续异常检测**：连续超温/低温（可配置窗口大小）
- **数据缺失检测**：时间间隔过大或 NaN 数据
- **温度骤变检测**：短时间内温度快速变化
- **长时间开门检测**：开门时长超过阈值
- **校准偏移应用**：支持校准证书偏移值自动应用

### 指标计算
- 温度统计：均值、最大值、最小值、中位数、标准差、波动系数
- 百分位数分析：25%、50%、75%、90%、95%、99%
- 开门统计：次数、时长、频次分布
- 批次暴露：开门暴露时长、异常暴露时长、风险等级评估
- 设备综合排行：基于多维度评分

### 可视化页面
- **数据导入**：文件上传 + 示例数据快速测试
- **规则配置**：灵活配置各类规则参数
- **分析总览**：设备排行、异常统计、批次风险
- **温度时间轴**：交互式 Plotly 图表，异常和开门事件高亮标注
- **异常复核**：人工复核界面，支持筛选和批量处理
- **数据导出**：Markdown 报告、CSV 清单、JSON 审计包

### 状态存储
- 本地文件存储（默认路径：`~/.temperature_monitor/state/`）
- 复核记录持久化
- 配置保存与加载
- 审计日志追踪
- 会话数据管理

### 导入自定义数据

1. 准备以下格式的数据文件：

#### 温度记录 CSV 格式

```csv

2024-01-01 00:00:00,5.2,REFRIG-001
2024-01-01 00:05:00,5.0,REFRIG-001
2024-01-01 00:10:00,4.9,REFRIG-001
```

支持的列名别名：
- 时间列：`timestamp`, `time`, `datetime`, `时间`, `日期时间`, `时间戳`
- 温度列：`temperature`, `temp`, `value`, `温度`, `数值`

#### 开门事件 JSON 格式

```json
{
  "events": [
    {
      "event_id": "door_001",
      "device_id": "REFRIG-001",
      "open_time": "2024-01-01 10:00:00",
      "close_time": "2024-01-01 10:02:30",
      "duration_seconds": 150,
      "event_type": "door",
      "notes": "取放货"
    }
  ]
}
```

#### 校准证书 JSON 格式

```json
[
  {
    "device_id": "REFRIG-001",
    "certificate_id": "CAL-2024-001",
    "calibration_date": "2024-01-01",
    "offset_value": 0.15,
    "offset_unit": "°C",
    "calibration_method": "标准温度计比对",
    "next_calibration_date": "2024-07-01",
    "is_valid": true

```


2. 在 **"📁 数据导入"** 页面上传相应文件

## 规则配置说明

在 **"⚙️ 规则配置"** 页面可调整以下参数：

### 温度阈值
- **温度上限 (°C)**：默认 8.0°C，超过此值判定为超温
- **温度下限 (°C)**：默认 2.0°C，低于此值判定为低温

### 连续异常窗口
- **连续超温判定窗口 (分钟)**：默认 15 分钟，持续超温超过此时间判定为严重异常
- **连续低温判定窗口 (分钟)**：默认 15 分钟

### 数据质量规则
- **数据缺失判定阈值 (分钟)**：默认 30 分钟，时间间隔超过此值判定为数据缺失
- **温度骤变阈值 (°C)**：默认 2.0°C，10分钟内温度变化超过此值判定为骤变

### 开门规则
- **长时间开门判定阈值 (秒)**：默认 180 秒（3分钟）

### 探头漂移
- **探头漂移阈值 (°C)**：默认 0.5°C

## 异常类型说明

| 异常类型 | 严重程度 | 说明 |
|----------|----------|------|
| 超温 (over_temperature) | 低/中/高 | 瞬时温度超过上限阈值 |
| 低温 (under_temperature) | 低/中/高 | 瞬时温度低于下限阈值 |
| 连续超温 (continuous_overtemp) | 严重 | 持续超温超过窗口时间 |
| 连续低温 (continuous_undertemp) | 严重 | 持续低温超过窗口时间 |
| 数据缺失 (missing_data) | 中等 | 时间间隔过大或 NaN |
| 温度骤变 (rapid_change) | 中等 | 短时间内温度快速变化 |
| 长时间开门 (door_open_too_long) | 中等 | 开门时长超过阈值 |

## 常见问题

**Q: 应用数据存储在哪里？**
A: 所有数据都存储在本地 `~/.temperature_monitor/state/` 目录，不涉及任何云端服务。

**Q: 支持哪些温度记录设备的数据格式？**
A: 应用支持灵活的列名识别，只要CSV包含时间列和温度列即可。支持中英文列名别名。

**Q: 如何处理校准偏移？**
A: 导入校准证书JSON后，系统会自动应用最新的有效校准偏移值到温度计算中。

**Q: 批次暴露时长是如何计算的？**
A: 系统会精确计算批次时间窗口内与开门事件和温度异常的重叠时间，避免平均值掩盖问题。

**Q: 如何验证数据是否正确导入？**
A: 导入后可在"温度时间轴"页面查看原始数据曲线，确认数据完整性和准确性。
