## 1. 产品概述

真空泵抽速曲线管理系统，面向质检与设备工程团队，解决温度校准记录与传感器编号临时拼接带来的数据口径混乱、人工改系数无留痕、补录返工后不一致等问题。目标是让每一次抽速曲线的导入、校验、补录、复核、导出都有据可查，冲突不自动拍板，异常不静默消失。

- 目标用户：质检员小白、设备工程师复核岗
- 核心价值：消除现场最常见的错口径和补录返工，确保明细/页面/接口三端一致

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 质检员 | 工号登录 | 导入记录、补看传感器编号、发起自检、确认/驳回冲突、导出明细 |
| 设备工程师 | 工号登录 | 复核人工改系数无原因记录、审批冲突确认、查看参数回放 |

### 2.2 功能模块

1. **导入与校验页**：温度校准记录首次导入、传感器编号提取、冲突检测与确认/驳回
2. **参数回放页**：曲线参数回放、人工改系数标记、设备工程师复核流程
3. **导出与一致页**：明细导出、自检结果展示、三端一致性校验

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 导入与校验页 | 温度校准记录导入 | 支持首次导入温度校准记录，解析主材料与传感器编号，重复导入拦截 |
| 导入与校验页 | 传感器编号补看 | 质检员补看/补充传感器编号备注，与温度校准记录交叉比对 |
| 导入与校验页 | 冲突检测面板 | 温度校准记录与传感器编号矛盾时列出冲突证据，质检员选择确认或驳回 |
| 参数回放页 | 曲线参数回放 | 展示抽速曲线参数回放，支持历史版本对比 |
| 参数回放页 | 人工改系数标记 | 检测人工修改系数但未写原因的记录，标记为待复核，不自动归正常 |
| 参数回放页 | 设备工程师复核 | 设备工程师对人工改系数无原因记录进行复核审批 |
| 导出与一致页 | 自检报告 | 展示自检结果：重复导入、人工改系数无原因、补录后重算、导出一致性 |
| 导出与一致页 | 明细导出 | 导出抽速曲线明细，确保明细/页面/接口三端读取同一份数据 |
| 导出与一致页 | 一致性校验 | 校验导出明细、页面展示、接口返回三者一致性，尤其关注人工改系数记录 |

## 3. 核心流程

质检员首次导入温度校准记录 → 系统解析主材料与传感器编号 → 如有矛盾列出冲突证据 → 质检员确认或驳回 → 质检员补看传感器编号 → 参数回放页更新 → 如检测到人工改系数无原因 → 标记待复核不归正常 → 设备工程师复核 → 自检与导出

    "C" -->|"否"| "H[质检员补看传感器编号]"

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深钢蓝（#1B3A5C）+ 琥珀警告色（#D97706）+ 翠绿正常色（#059669）
- 辅助色：冷灰背景（#F1F5F9）、白色卡片、红色错误色（#DC2626）
- 按钮风格：圆角矩形，主操作填充色，次要操作描边
- 字体：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular，数据用 JetBrains Mono
- 布局：左侧固定导航 + 右侧内容区，卡片式模块排列
- 图标：线性图标，2px 描边，工业仪表风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 导入与校验页 | 温度校准记录导入 | 拖拽上传区、解析进度条、解析结果卡片、重复导入警告横幅 |
| 导入与校验页 | 传感器编号补看 | 传感器编号表格、备注编辑弹窗、与温度校准记录对照列 |
| 导入与校验页 | 冲突检测面板 | 冲突证据卡片（左侧温度校准 vs 右侧传感器编号）、确认/驳回按钮组、冲突等级标签 |
| 参数回放页 | 曲线参数回放 | 抽速曲线图表（双轴折线）、参数表格、版本切换下拉 |
| 参数回放页 | 人工改系数标记 | 待复核标记徽章、系数变更差异高亮行、原因填写文本框 |
| 参数回放页 | 设备工程师复核 | 复核审批卡片、通过/退回按钮、复核意见文本框 |
| 导出与一致页 | 自检报告 | 自检项清单（✓/✗图标）、检测时间戳、异常项展开详情 |
| 导出与一致页 | 明细导出 | 导出按钮、格式选择、数据范围筛选、导出预览表格 |
| 导出与一致页 | 一致性校验 | 三端对比表格（导出/页面/接口）、不一致行高亮、差异说明 |

### 4.3 响应式

- 桌面优先设计，最小宽度 1280px
- 冲突检测面板和参数回放图表在窄屏下可横向滚动
- 触控优化：按钮最小 44px 点击区域
