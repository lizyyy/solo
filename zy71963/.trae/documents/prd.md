## 1. 产品概述

训练任务排队管理系统 - 解决算法团队训练任务管理混乱问题。系统记录训练任务的来源、状态、修改历史，区分补材料与实际修改，保留训练日志变更痕迹。

- 核心目标：规范化训练任务排队流程，透明化修改历史，减少沟通成本
- 目标用户：算法工程师、算法负责人

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 算法工程师 | 本地账号 | 创建任务、编辑状态、修改日志、导出评估 |
| 算法负责人 | 本地账号 | 查看所有任务、审核变更、查看历史记录 |

### 2.2 功能模块

1. **任务列表页**：任务筛选、状态统计、快速操作
2. **任务详情页**：任务信息、修改历史、日志对比、评估说明
3. **任务创建/编辑页**：表单填写、来源标注、原因说明
4. **使用指南页**：操作说明、样例放置、指标口径、复核流程

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 任务列表页 | 统计卡片 | 显示各状态任务数量、待处理原因分类 |
| 任务列表页 | 筛选工具栏 | 按状态、来源、负责人、时间范围筛选 |
| 任务列表页 | 任务表格 | 展示任务ID、标题、来源、状态、最后修改人、时间 |
| 任务详情页 | 基本信息 | 任务标题、来源、负责人、创建时间、当前状态 |
| 任务详情页 | 修改历史 | 时间线展示所有修改记录，包含修改人、修改内容、原因 |
| 任务详情页 | 日志对比 | 高亮显示训练日志前后变更差异 |
| 任务详情页 | 评估说明 | 关联任务的评估结论与明细数据 |
| 任务创建页 | 表单填写 | 任务标题、来源类型、描述、待处理原因、负责人 |
| 使用指南页 | 操作说明 | 如何放置线上反馈样例、去哪看指标口径、导出前复核 |

## 3. 核心流程

### 3.1 任务创建与流转
算法工程师创建训练任务 → 标注来源（线上反馈/配置文件/其他）→ 填写待处理原因 → 任务进入待处理队列 → 负责人查看并审批 → 任务状态更新 → 完成后归档

### 3.2 训练日志修改流程
工程师修改训练日志 → 系统自动记录前后版本 → 工程师填写修改原因 → 变更历史保存在时间线中 → 负责人可随时查看差异对比

### 3.3 评估导出流程
工程师确认任务完成 → 复核评估说明与明细一致性 → 导出评估报告 → 归档任务

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深海蓝 #1e3a5f，体现专业性和科技感
- **辅助色**：琥珀橙 #f59e0b 用于强调操作，翠绿 #10b981 表示完成
- **按钮风格**：圆角矩形，悬浮时有轻微上浮效果
- **字体**：标题使用思源黑体 Bold，正文使用思源黑体 Regular
- **布局风格**：卡片式布局，左侧导航 + 主内容区
- **图标风格**：线性简约图标，统一使用 Lucide Icons

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 任务列表页 | 统计卡片 | 渐变背景、数字放大展示、状态图标 |
| 任务列表页 | 任务表格 | 斑马纹行、状态标签颜色区分、悬停高亮 |
| 任务详情页 | 修改时间线 | 竖线连接、时间戳左对齐、变更内容右对齐 |
| 任务详情页 | 日志对比 | 分栏对比、新增绿色背景、删除红色删除线 |
| 使用指南页 | 步骤说明 | 编号列表、代码块展示样例、提示框 |

### 4.3 响应式
- 桌面端优先（1280px+）：三栏布局（导航 + 侧边栏 + 主内容）
- 平板端（768px-1279px）：两栏布局（导航折叠 + 主内容）
- 移动端（<768px）：单栏布局，底部导航

### 4.4 动效设计
- 页面加载：元素淡入，依次延迟出现
- 状态变更：数字跳动动画
- 卡片悬浮：轻微上浮 + 阴影加深
- 时间线展开：平滑滑入效果
