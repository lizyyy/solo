
# 跳绳比赛计分台

一个专为学校跳绳比赛设计的本地网页计分台系统，支持单摇、双摇、接力等项目，提供完整的计时、计分、成绩复核和排名计算功能。

## 功能特性

### 🎯 核心功能
- **多项目支持**: 单摇、双摇、接力三种比赛项目
- **分组检录**: 支持创建分组、手动添加选手或批量导入CSV
- **实时计时**: 精确到毫秒的倒计时，支持开始/暂停/重置/重赛
- **键盘/按钮计分**: 支持键盘快捷键和按钮操作，记录次数、失误、犯规
- **规则引擎**: 按项目规则自动计算有效成绩，支持处罚和取消资格
- **成绩复核**: 支持查看、修改、确认成绩，异常记录管理
- **排名计算**: 自动计算个人排名（含并列）和团队总分排名
- **本地存储**: 所有数据自动保存到浏览器本地存储，刷新不丢失

### 📦 导入导出
- **CSV导入**: 从CSV文件批量导入选手数据
- **CSV/JSON导出**: 导出选手数据和成绩
- **Markdown成绩单**: 生成美观的Markdown格式成绩单

## 使用指南

### 1. 项目选择
在页面顶部选择比赛项目（单摇、双摇、接力），不同项目有不同的计分规则。

### 2. 分组检录
1. **创建分组**: 输入组名，点击"创建分组"
2. **选择分组**: 点击左侧分组列表中的分组
3. **添加选手**:
   - 手动添加: 输入号码、姓名、队伍，点击"添加选手"
   - 批量导入: 点击"导入选手CSV"选择CSV文件

#### CSV格式要求
```csv
号码,姓名,班级
001,张三,一班
002,李四,一班
003,王五,二班
```

支持的列名（不区分大小写）：
- 号码列: `number`, `号码`, `运动员号`, `id`
- 姓名列: `name`, `姓名`, `名字`
- 队伍列: `team`, `队伍`, `班级`, `学校`, `单位`（可选）

### 3. 比赛计时
1. 选择项目、分组和选手
2. 点击"开始"按钮或按Enter键开始计时
3. 使用以下方式计分：
   - **按钮**: 点击"+1 次数"、"+1 失误"、"+1 犯规"
   - **快捷键**:
     - 空格: +1 次数
     - E: +1 失误
     - F: +1 犯规
     - Ctrl+Z: 撤销上一步
     - Enter: 开始/暂停
4. 时间结束后成绩自动保存

### 4. 成绩复核
1. 选择分组和选手
2. 点击"加载成绩"查看详情
3. 操作选项：
   - **确认成绩**: 确认后成绩可用于排名计算
   - **修改成绩**: 手动修改次数、失误、犯规数
   - **删除成绩**: 删除该选手的成绩记录

### 5. 成绩排名
1. 选择项目和分组筛选条件
2. 点击"计算排名"
3. 查看：
   - **个人排名**: 按有效成绩排名，支持并列
   - **团队排名**: 按各队伍总分排名

### 6. 数据导入导出
- **导出JSON/CSV**: 从检录页面导出所有数据
- **导出Markdown**: 点击顶部"导出成绩单"生成Markdown格式报告

## 比赛规则

### 单摇 (Single Rocker)
- 时长: 60秒
- 计分: 每跳1次记1分
- 处罚: 犯规1次扣5分
- 取消资格: 犯规3次

### 双摇 (Double Rocker)
- 时长: 60秒
- 计分: 每跳1次记2分
- 处罚: 失误1次扣2分，犯规1次扣5分
- 取消资格: 犯规2次

### 接力 (Relay)
- 时长: 180秒
- 计分: 每跳1次记1分
- 处罚: 犯规1次扣10分
- 取消资格: 犯规1次

## 技术说明

### 数据存储
- 使用浏览器 `localStorage` 存储所有数据
- 数据自动保存，刷新页面不丢失
- 可通过顶部"清空数据"按钮重置所有数据

### 模块说明

#### rulesEngine.js (规则引擎)
- `calculateEffectiveScore()`: 根据项目规则计算有效成绩
- `calculateRankings()`: 计算个人排名（支持并列）
- `calculateTeamRankings()`: 计算团队排名
- `validateResult()`: 验证成绩合法性

#### timerState.js (计时状态)
- 使用 `requestAnimationFrame` 实现高精度计时
- 支持 idle/running/paused/completed 四种状态
- 回调机制：onTick, onStateChange, onComplete

#### storage.js (存储管理)
- 封装 localStorage 操作
- 支持分组、选手、成绩、异常记录的增删改查
- 支持全量导入导出

#### importExport.js (导入导出)
- CSV解析：支持带引号、带逗号的字段
- 自动识别CSV列名（支持中英文）
- 支持导出为CSV和JSON格式

#### markdownExporter.js (Markdown导出)
- 生成标准化的Markdown表格
- 支持个人排名、团队排名、分组成绩
- 包含完整的报告标题和元信息

## 注意事项

1. **浏览器要求**: 需要使用支持ES6模块的现代浏览器
2. **本地服务器**: 由于使用了ES6模块，不能直接双击打开HTML文件，必须通过Web服务器访问
3. **数据备份**: 建议定期导出JSON备份数据，清除浏览器数据会导致数据丢失
4. **快捷键**: 快捷键只在非输入框状态下生效

## 常见问题

**Q: 为什么直接双击index.html打不开？**
A: 因为应用使用了ES6模块（`import/export`），浏览器出于安全考虑不允许直接从文件系统加载模块文件，必须通过HTTP服务器访问。

**Q: 数据存在哪里？换浏览器还有吗？**
A: 数据存储在浏览器的localStorage中，只在当前浏览器有效。换浏览器或清除浏览器数据会丢失数据，建议定期导出备份。

**Q: 如何修改比赛规则？**
A: 可以在 `js/rulesEngine.js` 的 `EVENT_CONFIGS` 对象中修改各项目的配置。

**Q: 支持多人同时使用吗？**
A: 当前版本是单用户本地应用，不支持多用户实时协作。如需多用户使用，每个裁判需要独立的浏览器窗口。
