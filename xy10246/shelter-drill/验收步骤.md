# 应急避难点容量演练器 - 验收步骤

## 一、启动应用

### 命令行方式（技术人员）

```bash
cd shelter-drill
npm run dev
```

启动成功后，浏览器会自动打开 `http://localhost:5173/`

### 浏览器访问方式（业务人员）

等待技术人员告知访问地址，通常是：
- 本地访问：`http://localhost:5173/`
- 网络访问：技术人员会提供具体地址

## 三、正常演练流程验收

### 3.1 选择预设场地布局

**操作步骤：**
1. 在「选择场地布局」区域，点击「社区公园避难点」卡片
2. 观察卡片边框变成蓝色，表示已选中

**预期结果：**
✅ 显示「数据校验通过」绿色提示
✅ 显示校验结果：无错误、无警告（或少量警告）

### 3.2 选择人员流入场景

**操作步骤：**
1. 在「设置人员流入场景」区域，选择任意场景：
   - 渐进式流入（正常演练）
   - 突发式流入（压力测试）
   - 均衡流入（理想状态）
2. 观察卡片边框变成绿色，表示已选中

**预期结果：**
✅ 显示「流入时间线」图表
✅ 时间线包含多个时间步骤，显示每个时间段的流入人数和入口

### 3.3 开始演练模拟

**操作步骤：**
1. 点击「开始演练模拟」按钮
2. 等待模拟完成（约 0.5-1 秒）

**预期结果：**
✅ 「等待演练开始」区域消失
✅ 显示「演练结果分析」区域
✅ 显示总体状态卡片（绿色=通过，黄色=有风险，红色=失败）
✅ 显示三个统计数据：
  - 总流入人数
  - 总容量
  - 整体利用率
✅ 显示三个分析面板：
  - 入口拥堵分析
  - 帐篷区容量分析
  - 物资可达性分析
✅ 如存在风险，显示「风险事件时间线」

## 四、异常样例测试验收

### 4.1 测试重复数据

**操作步骤：**
1. 在「异常样例测试」区域，点击「测试重复数据」按钮
2. 观察 JSON 文本框自动填充数据

**预期结果：**
✅ 自动填充 JSON 数据到文本框
✅ 显示「数据校验失败」红色提示
✅ 错误列表包含：
  - `入口 ID 重复: e1`
  - `帐篷区 ID 重复: t1`

### 4.2 测试缺字段

**操作步骤：**
1. 点击「测试缺字段」按钮
2. 观察校验结果

**预期结果：**
✅ 显示「数据校验失败」红色提示
✅ 错误列表包含：
  - `入口 #1 缺少最大容量`
  - `帐篷区 #1 缺少容量配置`
✅ 警告列表包含：
  - `物资点 #1 缺少名称`
  - `物资点 #1 缺少物资类型配置`

### 4.3 测试人工改错

**操作步骤：**
1. 点击「测试人工改错」按钮
2. 观察校验结果

**预期结果：**
✅ 显示「数据校验失败」红色提示
✅ 错误列表包含：
  - `入口 e1 最大容量必须大于 0`（容量为负数）
  - `入口 e2 最大容量必须大于 0`（容量为 0）
  - `入口 e2 当前流量超过最大容量`（流量 > 容量）
  - `帐篷区 t1 容量必须大于 0`（容量为负数）
  - `帐篷区 t2 当前入住人数超过容量`（入住 > 容量）
✅ 警告列表包含：
  - `物资点 1 缺少物资类型配置`

## 五、不同场景演练验收

### 5.1 渐进式流入（正常演练）

**操作步骤：**
1. 选择「社区公园避难点」布局
2. 选择「渐进式流入」场景
3. 点击「开始演练模拟」

**预期结果：**
✅ 总体状态：演练通过（绿色）或有风险（黄色）
✅ 入口拥堵分析：显示各入口的流量和利用率
✅ 帐篷区容量分析：显示各帐篷区的入住率
✅ 物资可达性分析：显示物资可达性评估

1. 选择「社区公园避难点」布局

**操作步骤：**
1. 选择「大型体育馆避难点」布局
2. 选择「均衡流入」场景
3. 点击「开始演练模拟」

**预期结果：**
✅ 总体状态：演练通过（绿色）
✅ 入口拥堵分析：各入口利用率均衡
✅ 帐篷区容量分析：各帐篷区入住率适中
✅ 物资可达性分析：显示多个物资点的可达性

## 八、常见问题排查

### Q1: 页面空白？
**排查：**
- 检查浏览器控制台是否有错误（按 F12）
- 确认开发服务器是否正在运行
- 刷新页面重试

### Q2: 「开始演练模拟」按钮灰色不可点？
**原因：** 当前选择的布局数据校验未通过
**解决：**
- 选择一个预设布局（社区公园或大型体育馆）
- 或修复自定义 JSON 中的错误

### Q3: 演练结果全是红色？
**原因：** 选择了压力测试场景（突发式流入）
**解释：** 这是正常的，该场景用于测试系统在极端情况下的表现

### Q4: 物资可达性显示缺少物资类型？
**解释：** 这是正常的提示，说明该场地布局缺少某些物资类型配置，实际演练时需要补充
