## 1. 产品概述

教学电场线空间台是一款面向设计院工程人员的3D空间数据管理工具，解决电场线点位在GIS底图、现场照片、方案备注等多源数据间对不上的问题。核心价值：将分散的点位数据统一到3D空间视图中，异常高亮、来源可溯、方案可存、截图可导出，确保"报告和明细不说两套话"。

- 目标用户：设计院工程人员（如小赵），需要频繁对照GIS底图、现场照片和方案备注来确认电场线点位状态
- 核心痛点：截图和筛选条件老是对不上、异常判断无来源追溯、刷新丢失标注、报告与明细不一致

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 工程人员 | 直接使用 | 查看/标注点位、管理方案、导出截图和报告 |

### 2.2 功能模块

1. **空间台主页**：3D场景 + 点位表格 + 方案面板，三栏联动
2. **方案管理面板**：保存/切换/对比两版方案，保留所有备注
3. **报告导出页**：基于当前方案生成一致报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 空间台主页 | 3D场景区 | 电场线3D空间可视化，异常点位高亮（红色脉冲），点击跳转来源行，相机视角保存/恢复 |
| 空间台主页 | 点位表格区 | 点位列表，含来源列、处理状态列、GIS备注列（保留原始乱备注），支持筛选，点击行高亮对应3D对象 |
| 空间台主页 | 方案面板 | 方案列表、方案备注（两版共存）、方案切换，保留同事手改坐标 |
| 空间台主页 | 截图工具栏 | 一键截图当前3D视图，含筛选条件水印，导出PNG |
| 报告导出页 | 报告生成 | 基于当前方案数据生成报告，明细与报告一致，可导出 |

## 3. 核心流程

用户打开空间台 → 查看样例/导入点位数据 → 在3D场景中浏览空间位置 → 点击异常对象→表格自动定位到来源行并显示处理备注 → 标注处理状态（顺利/人工确认/旧口径）→ 保存方案（含视角）→ 刷新页面后标注和视角不丢失 → 导出截图（含筛选条件）→ 生成报告（与明细一致）

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深灰（#1a1a2e）+ 电场蓝（#0f3460）+ 异常红（#e94560）
- 辅助色：通过绿（#16c79a）、待确认黄（#f5a623）
- 按钮风格：扁平圆角，hover微浮起
- 字体：JetBrains Mono（数据）+ Noto Sans SC（中文）
- 布局：左侧3D场景（60%宽），右侧面板（40%宽，上下分区：表格+方案）
- 风格定位：工业工具感，朴素实用，数据密度优先

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 空间台主页 | 3D场景区 | 深色背景、电场线粒子、点位球体（正常蓝/异常红脉冲）、坐标轴辅助线、右上角视角选择器 |
| 空间台主页 | 点位表格区 | 紧凑表格、状态标签色块、GIS备注原样显示（含乱码）、来源超链接、筛选下拉 |
| 空间台主页 | 方案面板 | 方案卡片列表、备注文本区、坐标编辑器、保存/切换按钮 |
| 空间台主页 | 截图工具栏 | 顶部工具栏、截图按钮、筛选条件标签、导出格式选择 |
| 报告导出页 | 报告区 | 结构化报告、数据表格、异常汇总、处理时间线 |

### 4.3 响应式设计

桌面优先设计，3D场景和表格需要充足空间。最小支持1280px宽度，低于此宽度时表格折叠为可展开面板。

### 4.4 3D场景指导

- 环境：深色工业风，微弱环境光 + 点光源
- 灯光：3盏方向灯（前、左、后），环境光0.3
- 相机：透视相机，FOV 60°，支持轨道控制（旋转/缩放/平移）
- 构图：电场线粒子流沿曲线分布，点位以球体标注
- 交互：点击球体→高亮+信息弹窗；双击→聚焦；右键拖拽旋转
- 后处理：异常点位Bloom发光效果
- 资源：纯程序生成，无外部3D模型依赖
