# 学校实验室耗材多源导入巡检CLI工具

## 安装

```bash
pip install -e .
```

## 命令列表

### 1. init - 初始化数据库
```bash
lab-inspect init
```
首次使用前必须执行，创建SQLite数据库。

### 2. import - 导入数据文件
```bash
lab-inspect import sample_data/领用单示例.csv --type 领用单
lab-inspect import sample_data/采购到货表示例.csv --type 采购到货表
lab-inspect import sample_data/老师补签记录示例.csv --type 老师补签记录
```

支持的数据源类型：
- 领用单
- 采购到货表
- 老师补签记录
- 门店交接纸
- 客服备注

### 3. check - 数据质量检查
```bash
lab-inspect check
lab-inspect check --detail
lab-inspect check --record-id 1
```

### 4. fix - 修正记录
```bash
lab-inspect fix 1 department "化学学院" --reason "部门补录"
lab-inspect fix 1 quantity 15 --reason "数量统计错误"
```

### 5. resolve - 解决失败记录
```bash
lab-inspect failed
lab-inspect resolve 1 --material-name "已知耗材" --quantity 10
```

### 6. invalidate - 作废记录
```bash
lab-inspect invalidate 1 --reason "重复录入"
```

### 7. report - 生成报表
```bash
lab-inspect report
lab-inspect report --detail
lab-inspect report --start-date 2024-01-01 --end-date 2024-12-31
lab-inspect report --department 化学学院
```

### 8. detail - 查看记录详情
```bash
lab-inspect detail 1
```

### 9. history - 查看导入历史
```bash
lab-inspect history
lab-inspect batch 1
```

### 10. audit - 查看审计日志
```bash
lab-inspect audit
lab-inspect audit --record-id 1
```

### 11. corrections - 查看修正历史
```bash
lab-inspect corrections
lab-inspect corrections --record-id 1
```

### 12. export - 导出数据
```bash
lab-inspect export output/report
lab-inspect export output/data --format csv
lab-inspect export output/failed --failed
lab-inspect export output/full_report --full
```

### 13. stats - 系统统计
```bash
lab-inspect stats
```

## 核心设计特点

1. **数据持久化**: 所有数据存在SQLite数据库，重启不丢失
2. **数据一致性**: 列表、详情、导出、历史都从同一数据源查询
3. **追踪能力**: 每条记录保留原始行号、来源文件
4. **坏数据隔离**: 导入失败的数据存入失败记录表，不影响汇总
5. **完整审计**: 所有修改都有日志，可追溯修改人和原因
6. **修正历史**: 每次改判都有记录，原值新值清晰对比

## 典型工作流程

1. `lab-inspect init` - 初始化
2. `lab-inspect import 领用单.csv --type 领用单` - 导入
3. `lab-inspect check` - 检查质量
4. `lab-inspect failed` - 查看失败记录
5. `lab-inspect resolve 1 --material-name "xxx"` - 解决失败
6. `lab-inspect fix 5 department "化学学院"` - 修正数据
7. `lab-inspect report` - 查看报表
8. `lab-inspect export 审计报告 --full` - 导出完整报告
