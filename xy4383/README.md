# 🎭 舞台安全复核工具

一个专为小剧场舞台监督设计的本地桌面复核工具，用于演出前的安全风险检测与复核。

## ✨ 功能特性

### 📥 数据导入
- **场景 Cue 表**: 支持 JSON/CSV 格式，包含时间、设备、负载等信息
- **吊杆/升降台设备清单**: 支持 JSON/CSV 格式，包含设备类型、负载限制、状态等
- **演员走位 JSON**: 记录演员走位时间、起点终点、路径等信息
- **烟火许可记录**: 支持 JSON/CSV 格式，包含许可编号、有效期、使用时间等

### 🔍 风险检测引擎
自动检测以下安全风险：

| 风险类型 | 检测内容 | 风险等级 |
|---------|---------|---------|
| 吊杆超载 | 当前负载超过额定负载 | 高风险 |
| 走位冲突 | 升降台运行时演员经过该区域 | 高风险 |
| 许可过期 | 烟火许可已过期或即将过期 | 高/中风险 |
| 时间冲突 | Cue 之间换景时间不足 | 高/中风险 |
| 设备异常 | 故障/维护中设备被使用 | 高/中风险 |
| 走位冲突 | 演员之间走位路径重叠 | 中风险 |

### 📊 复核界面
- **时间轴视图**: 按时间顺序展示所有 Cue 和走位，直观查看风险
- **风险清单**: 表格形式展示所有风险，支持按等级和状态筛选
- **风险处理**: 标记解决/驳回，添加备注
- **数据持久化**: 本地存储，刷新不丢失

### 📤 报告导出
- **Markdown 演前安全单**: 完整的安全检查报告，包含风险概览和详细分析
- **CSV 风险清单**: 表格形式的风险数据，便于存档和打印
- **JSON 审计包**: 包含所有原始数据和风险评估结果的完整数据包

## 🚀 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式运行

```bash
# 仅运行 Web 开发服务器
npm run dev

# 运行 Electron 开发模式（同时启动 Vite 和 Electron）
npm run electron:dev
```

### 构建应用

```bash
# 构建 Web 版本
npm run build

# 构建 Electron 应用
npm run electron:build
```

## 📋 数据格式说明

### 场景 Cue 表 (JSON)

```json

  {
    "id": "cue-1",
    "number": "1",
    "name": "开场幕布升起",
    "time": "19:30:00",
    "description": "演出开始，主幕布升起",
    "transitionTime": 8,
    "equipmentIds": ["eq-1"],
    "load": 80,
    "action": "升起"
  }
]
```

    "id": "eq-1",

    "number": "1",
    "name": "主幕布吊杆",
    "maxLoad": 100,

## 🎯 使用流程

1. **导入数据**: 在「数据导入」标签页，点击或拖拽文件上传，或直接点击「加载示例数据」
2. **分析风险**: 数据导入后自动进行风险分析，也可点击「重新分析风险」
3. **复核风险**: 
   - 切换到「时间轴复核」标签，按时间顺序查看每条风险
   - 或切换到「风险清单」标签，以表格形式查看
   - 对风险进行处理：标记解决/驳回，添加备注
4. **导出报告**: 点击「导出报告」按钮，选择导出格式（Markdown/CSV/JSON）

## 🔧 技术栈

- **前端框架**: Vue 3
- **构建工具**: Vite
- **桌面框架**: Electron
- **数据存储**: electron-store (Electron 环境) / localStorage (Web 环境)

## ⚠️ 注意事项

1. 本工具仅用于辅助安全复核，不能替代专业的安全检查
2. 请确保所有数据准确无误后再进行演出
3. 烟火效果必须持有合法许可并由专业人员操作
4. 建议在正式演出前进行多次彩排和安全检查
