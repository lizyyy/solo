## 1. 产品概述

音源预设版本仓库是为键盘手巡演前整理音源预设而设计的桌面工具，解决旧工程、不同键盘型号和踏板映射混用导致的混乱问题。核心价值：让团队成员自主导入样例、查看图表、点击明细、下载结果，同时完整保留来源与版本信息，确保预设覆盖、型号不兼容、踏板极性反转等问题在处理结论中被真实反映。

- 目标用户：巡演键盘手、音源工程师、乐队技术总监
- 核心痛点：预设版本无追踪、型号兼容靠记忆、踏板映射来源不清、问题通过后才被发现

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 键盘手 | 直接使用 | 导入预设、查看兼容性报告、导出结果 |
| 音源工程师 | 管理维护 | 归档预设、管理型号兼容表、审核踏板映射 |
| 技术总监 | 审核决策 | 查看全局状态、审批归档、确认兼容性结论 |

### 2.2 功能模块

1. **仓库总览页**：全局仪表盘、预设/型号/映射统计图表、兼容性警告摘要
2. **预设管理页**：预设列表、导入、版本追踪、归档操作、覆盖检测
3. **型号兼容页**：键盘型号管理、兼容性矩阵、不兼容影响说明
4. **踏板映射页**：映射列表、极性检测、版本对比、反转影响说明
5. **导入导出页**：批量导入、筛选导出（屏幕范围=导出范围）

## 3. 核心流程

### 3.1 预设导入与兼容检查流程

用户导入预设文件 → 系统提取来源/版本元数据 → 检测是否存在覆盖 → 检测型号兼容性 → 检测踏板极性 → 综合得出兼容结论 → 展示检查结果（含影响说明）→ 用户确认或归档

```mermaid
flowchart TD
    "A[用户导入预设文件]" --> "B[提取来源与版本元数据]"
    "B" --> "C[覆盖检测：同名/同参数预设]"
    "C" --> "D{是否存在覆盖？}"
    "D" --> "是" --> "E[标记覆盖关系，标注影响条目]"
    "D" --> "否" --> "F[型号兼容性检查]"
    "E" --> "F"
    "F" --> "G{存在不兼容型号？}"
    "G" --> "是" --> "H[标记不兼容，说明影响预设]"
    "G" --> "否" --> "I[踏板极性检测]"
    "H" --> "I"
    "I" --> "J{极性反转？}"
    "J" --> "是" --> "K[标记极性反转，列出受影响映射]"
    "J" --> "否" --> "L[综合结论：通过]"
    "K" --> "M[综合结论：警告/阻断]"
    "L" --> "N[展示检查结果]"
    "M" --> "N"
    "N" --> "O{用户操作}"
    "O" --> "归档" --> "P[归档旧版本，更新活跃结论]"
    "O" --> "修正" --> "Q[修正后重新检查]"
    "O" --> "接受风险" --> "R[记录风险接受，结论标记为已确认]"
```

### 3.2 筛选导出一致性流程

用户设置筛选条件 → 页面列表按条件过滤 → 图表同步更新为筛选范围 → 用户点击导出 → 系统以当前筛选范围生成导出文件

```mermaid
flowchart TD
    "A[用户设置筛选条件]" --> "B[列表按条件过滤]"
    "B" --> "C[图表同步更新为筛选范围]"
    "C" --> "D[用户点击导出]"
    "D" --> "E[以当前筛选条件提取数据]"
    "E" --> "F[生成JSON/CSV文件]"
    "F" --> "G[下载完成]"
```

## 5. 关键业务规则

### 5.1 预设覆盖检测
- 当导入的预设与已有预设同名且参数不同时，标记为"覆盖"
- 覆盖必须列出受影响的所有型号和映射条目
- 覆盖的预设在结论中标记为"待确认"

### 5.2 型号不兼容检测
- 维护型号×预设兼容表，不兼容时该预设在对应型号下结论为"不可用"
- 不兼容必须说明影响了哪几条预设结果
- 不兼容的预设-型号组合在导出时仍然保留，但标记状态

### 5.3 踏板极性反转检测
- 映射版本变更时自动比较极性方向
- 极性反转必须列出受影响的预设和型号组合
- 极性反转的映射在结论中标记为"极性警告"

### 5.4 归档影响
- 预设归档后从活跃兼容性检查中排除
- 归档预设导致的兼容性结论变化必须更新
- 归档版本仍可查看但不参与新导入的检查

### 5.5 筛选导出一致性
- 导出范围 = 当前筛选条件过滤后的数据集
- 图表和列表共享同一筛选状态
- 导出文件中包含筛选条件描述
