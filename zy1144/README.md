# 🎯 定位捉迷藏

一个基于位置的互动小游戏，玩家在虚拟地图中寻找隐藏的目标点，体验类似"捉迷藏"的乐趣。

## ✨ 功能特点

- 📍 **双定位模式**: 支持真实GPS定位和模拟定位（点击地图设置位置）
- 🎮 **雷达系统**: 实时显示距离、方向指示，配合扫描动画效果
- 🌪️ **GPS漂移模拟**: 真实模拟定位漂移，增加游戏难度和趣味性
- ⚠️ **干扰区**: 特定区域信号不稳定，漂移增强
- 🔍 **道具系统**: 可使用"扩大扫描圈"道具增加命中范围
- 📊 **完整统计**: 游戏结束后可查看轨迹回放、采样详情
- 📄 **报告导出**: 支持导出Markdown格式游戏报告

## 🎮 游戏玩法

### 1. 开始新局

1. 输入玩家名称
2. 选择定位模式：
   - **模拟定位**: 在地图上点击设置位置（适合桌面浏览器测试）
   - **真实GPS**: 使用设备的真实定位（需要HTTPS或localhost）
3. 选择关卡
4. 点击"开始新游戏"

### 2. 游戏操作

- **采样定位**: 点击"📍 采样定位"按钮提交当前位置
- **扩大扫描**: 使用"🔍 扩大扫描"道具（每局1次），扫描范围翻倍
- **校准定位**: 在真实GPS模式下，可校准定位偏移

### 3. 胜利条件

在倒计时结束前，找到关卡中所有的藏身点。

### 4. 命中规则

- 不能单点命中，需要**连续靠近**（通常需要3-4次采样持续靠近目标）
- 在**干扰区**内，定位漂移会增强，增加判定难度
- **异常跳点**（短时间内移动过远）会被标记为可疑，不参与命中判定

## 🗺️ 关卡介绍

### 1. 校园操场 (playground)
- 时间限制: 5分钟
- 藏身点: 3个
- 干扰区: 1个（高压电线区）
- 特点: 开阔区域，适合新手

### 2. 图书馆 (library)
- 时间限制: 4分钟
- 藏身点: 3个
- 干扰区: 2个（电梯井旁、地下室入口）
- 特点: 空间较小，但干扰较多

### 3. 湖边小路 (lake_path)
- 时间限制: 6分钟
- 藏身点: 4个
- 干扰区: 2个（茂密树林区、水面反射区）
- 特点: 面积最大，藏身点最多

## 🔧 API 接口

### 关卡管理

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/levels | 获取所有关卡 |
| GET | /api/levels/:levelId | 获取单个关卡详情 |

### 游戏管理

| 方法 | 路径 | 描述 |
|------|------|------|
| POST | /api/games | 创建新游戏 |
| GET | /api/games/:gameId | 获取游戏状态 |
| POST | /api/games/:gameId/start | 开始游戏 |
| POST | /api/games/:gameId/end | 结束游戏 |

### 游戏操作

| 方法 | 路径 | 描述 |
|------|------|------|
| POST | /api/games/:gameId/sample | 提交定位采样 |
| POST | /api/games/:gameId/items | 使用道具 |

### 回放和报告

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/games/:gameId/replay | 获取回放数据 |
| GET | /api/games/:gameId/report?format=json | 获取JSON格式报告 |
| GET | /api/games/:gameId/report?format=markdown | 下载Markdown格式报告 |

## 🧪 测试覆盖

测试文件 `tests/run-tests.js` 包含以下测试：

- **距离计算**: Haversine公式准确性测试
- **方位角计算**: 方向和角度测试
- **GPS漂移**: 噪声生成和随机性测试
- **可疑跳点检测**: 异常移动检测
- **命中判定**: 范围检测和连续靠近逻辑
- **干扰区**: 区域检测逻辑
- **异常输入**: 边界条件处理

## 📱 设备适配

- **手机端**: 竖屏优化，触摸友好
- **桌面端**: 支持模拟定位模式，可在浏览器中测试
- **响应式设计**: 自适应不同屏幕尺寸

## 🔒 隐私说明

- 所有位置数据**仅在本地处理**，不会上传到任何外部服务器
- 数据库文件 `game.db` 存储在本地
- 真实GPS定位仅在用户同意后才会获取

## 📝 开发说明

### 添加新关卡

在 `data/seedData.js` 中添加新的关卡配置：

```javascript
{
  id: 'new_level',
  name: '新关卡名称',
  description: '关卡描述',
  center_lat: 39.9087,    // 中心点纬度
  center_lng: 116.3975,   // 中心点经度
  radius: 200,             // 关卡半径（米）
  config: {
    timeLimit: 300,        // 时间限制（秒）
    scanRadius: 5,          // 基础扫描半径
    requiredContinuousSamples: 3,  // 需要连续采样次数
    baseAccuracy: 10        // 基础定位精度
  },
  hidingSpots: [/* 藏身点数组 */],
  interferenceZones: [/* 干扰区数组 */]
}
```

### 技术栈

- **后端**: Node.js + Express + SQLite (better-sqlite3)
- **前端**: 原生 HTML/CSS/JavaScript (无框架)
- **地图渲染**: Canvas 2D
