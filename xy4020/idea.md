## 原始点子

我想做一个给野外水质采样小组用的本地命令行工具。我们每次做碱度滴定都会拿到一份样品清单和一堆滴定读数，人工用表格复算端点、空白扣除和质控标记很容易漏。请从 0 到 1 做一个可运行的 Python CLI 项目：用户可以先 init 一个项目配置，维护采样点、瓶号、空白样、平行样和标准液浓度；再用 import-samples 导入样品 CSV，用 import-titration 导入每个样品的体积-pH 读数。calculate 命令要按 Gran 法或等价的线性拟合方法估计端点体积，计算总碱度 mg/L as CaCO3，并把温度、稀释倍数、空白扣除纳入公式；如果读数太少、pH 不单调、平行样相对偏差超阈值、标准液浓度缺失、样品编号对不上，要给出清楚的质控标记而不是静默跳过。每次计算结果要保存到本地 SQLite 或 JSON 数据目录，history 可以按日期、采样点和质控状态查询，report 可以导出 Markdown 报告和 CSV 结果表。请把 CLI 入口、CSV 解析、数值拟合、质控规则、存储层、报告导出和示例数据拆成多个文件，README 写清楚安装、示例命令和一组可以验证主流程的自检步骤。
