我想做一个给土木实验室研究生用的本地科学计算命令行工具，叫“梁板应变漂移校准器”。我们做桥梁模型加载试验时，会从多台采集仪导出应变片、位移计和温度传感器 CSV，字段格式不统一，最怕零点漂移、单位混用、采样时钟对不齐，最后手工算弯矩和中性轴位置很容易错。请从 0 到 1 做一个可运行的 Python CLI 项目：init 命令能创建项目配置，维护传感器清单、量纲单位、截面几何参数、温度补偿系数、允许的时间偏移和输出目录；import 命令能导入多份 CSV 并保留原始文件不覆盖；check 命令要校验字段缺失、时间倒序、重复时间戳、单位非法、采样频率不一致、传感器编号不在配置里这些问题，坏行进入 quarantine.json 并说明原因。calibrate 命令根据空载区间做零点漂移校正和温度补偿，align 命令把不同采集仪的时间轴对齐并插值到统一步长；analyze 命令要计算每个加载级的峰值应变、残余变形、曲率、中性轴位置和弯矩估算，并识别超限、滞回异常、卸载不回零、相邻测点变化突跳这些风险。export 命令能导出 Markdown 试验报告、清洗后的 CSV 和 JSON 计算结果，history 命令能查询过去的导入、校准和分析记录。希望代码拆成 CLI 入口、配置模型、CSV 解析/单位换算、数据校验、校准对齐、结构计算、隔离区、存储层、报告导出、示例数据和测试，不要写成一个大脚本。README 里写清楚安装方式、示例命令，以及如何用临时目录验证 init、导入两台采集仪数据、校验、校准、对齐、分析和导出报告这些核心流程。
