# 模具寿命预警服务 - 启动说明

## 🚀 快速启动（三步搞定）

### 第一步：检查环境

```bash
python3 setup.py --check
```

### 第二步：下载 Maven Wrapper

```bash
python3 setup.py --download-wrapper
```

### 第三步：启动服务

```bash
./mvnw spring-boot:run
```

## 🔧 环境配置详细步骤

### 方式一：全自动（推荐）

项目已包含 `setup.py`，可以自动检测环境并下载所需组件：

```bash
# 1. 检测当前环境
python3 setup.py --check

# 2. 如果 Java 未安装，按照提示安装
#    macOS:   brew install openjdk@17
#    Linux:   sudo apt-get install openjdk-17-jdk
#    Windows: 下载 https://adoptium.net/ (Temurin 17)

# 3. 下载 Maven Wrapper 组件
python3 setup.py --download-wrapper

# 4. 启动服务
./mvnw spring-boot:run
```

### 方式二：使用 Maven Wrapper（手动）

项目已包含 `mvnw` 和 `mvnw.cmd` 脚本：

```bash
# Unix/Linux/macOS
./mvnw spring-boot:run

# Windows
mvnw.cmd spring-boot:run
```

**注意：** 如果 wrapper jar 不存在，`mvnw` 会自动尝试调用 `setup.py` 下载。

### 方式三：已安装 Maven

如果你本机已安装 Maven，可以直接使用：

```bash
# 直接启动
mvn spring-boot:run

# 或先编译打包，再运行
mvn clean package
java -jar target/mold-life-alert-1.0.0.jar
```

## 🧪 测试核心 API 流程

### 场景 1：查看当前状态

```bash
# 查看模具寿命总览（包含预警/到期模具）
curl http://localhost:8080/api/reports/mold-life-summary

# 查看排程影响
curl http://localhost:8080/api/reports/schedule-impact
```

### 场景 2：录入冲压记录（触发完整链路）

```bash
# 给 MOLD-001 增加 5000 次冲压
# 当前 85,000 + 5,000 = 90,000（达到预警阈值）
curl -X POST http://localhost:8080/api/stroke-records \
  -H "Content-Type: application/json" \
  -H "X-Operator: test-user" \
  -d '{
    "batchId": "BATCH-TEST-001",
    "moldCode": "MOLD-001",
    "strokeCount": 5000,
    "recordTime": "'$(date -u +"%Y-%m-%dT%H:%M:%S")'"
  }'
```

**预期结果：**
- MOLD-001 状态变为 `WARNING`
- 自动创建类型为 `WARNING_PREVENTIVE` 的换模任务

### 场景 3：查看生成的换模任务

```bash
# 查看待处理任务
curl http://localhost:8080/api/mold-change-tasks/pending

# 查看所有任务
curl http://localhost:8080/api/mold-change-tasks
```

### 场景 4：异常续用审批

```bash
# 给预警的 MOLD-003 提交续用申请（续用 20,000 次）
curl -X POST http://localhost:8080/api/mold-extensions/request \
  -H "Content-Type: application/json" \
  -H "X-Operator: test-user" \
  -d '{
    "moldCode": "MOLD-003",
    "extensionStrokes": 20000,
    "reason": "生产紧急，临时续用",
    "productionLine": "LINE-01",
    "productCode": "PROD-C003"
  }'

# 查看待审批申请
curl http://localhost:8080/api/mold-extensions/pending

# 批准申请（替换为实际的审批号）
curl -X POST http://localhost:8080/api/mold-extensions/MEA-XXXXXXXXXXXXXX/approve \
  -H "Content-Type: application/json" \
  -H "X-Operator: manager" \
  -d '{"remark": "同意续用，限期更换"}'
```

### 场景 5：记录补录和撤回

```bash
# 查看原始记录
curl http://localhost:8080/api/stroke-records/batch/BATCH-TEST-001

# 补录（修正为 6000 次）
curl -X POST "http://localhost:8080/api/stroke-records/BATCH-TEST-001/compensate?newStrokeCount=6000&newBatchId=BATCH-TEST-001-C&reason=实际生产数量统计错误" \
  -H "X-Operator: test-user"

# 撤回记录
curl -X POST "http://localhost:8080/api/stroke-records/BATCH-TEST-001/revoke?reason=测试数据，需要撤回" \
  -H "X-Operator: test-user"
```

### 场景 6：历史追溯

```bash
# 查看单个模具的完整历史
curl http://localhost:8080/api/reports/history-trace/MOLD-001
```

## 🔍 常见问题

### Q1: `./mvnw` 提示 "Maven Wrapper JAR not found"

**解决：** 运行 `python3 setup.py --download-wrapper` 自动下载

### Q2: 提示 "Java Runtime Environment not found"

**解决：** 需要安装 JDK 17+
- macOS: `brew install openjdk@17`
- Linux: `sudo apt-get install openjdk-17-jdk`
- Windows: 下载 https://adoptium.net/

### Q3: 安装 JDK 后还是提示找不到

**解决：** 设置 JAVA_HOME 环境变量
```bash
# macOS (zsh)
echo 'export JAVA_HOME="$(/usr/libexec/java_home -v 17)"' >> ~/.zshrc
source ~/.zshrc

# Linux (bash)
echo 'export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64' >> ~/.bashrc
source ~/.bashrc
```

### Q4: 启动后端口被占用

**解决：** 修改 `src/main/resources/application.yml` 中的端口：
```yaml
server:
  port: 8081  # 改为其他端口
```

### Q5: 首次启动下载依赖很慢

**解决：** 这是正常现象，Maven 正在下载所有依赖。可以配置国内镜像加速，
在 `~/.m2/settings.xml` 中添加阿里云镜像。
