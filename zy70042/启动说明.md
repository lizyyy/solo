# 模具寿命预警服务 - 启动说明

## 前置要求

- JDK 17 或更高版本
- 网络连接（首次运行时下载依赖）

## 启动方式

### 方式一：已安装 Maven（推荐）

```bash
# 编译并启动
mvn spring-boot:run

# 或先编译打包，再运行
mvn clean package
java -jar target/mold-life-alert-1.0.0.jar
```

### 方式二：使用 Maven Wrapper（如已配置）

```bash
# Unix/Mac
./mvnw spring-boot:run

# Windows
mvnw.cmd spring-boot:run
```

### 方式三：初始化 Maven Wrapper

如果没有安装 Maven，且当前目录没有 mvnw，可以通过以下方式之一获取：

**方案 A：使用已安装的 Maven 生成 Wrapper**
```bash
mvn -N wrapper:wrapper
```

**方案 B：手动下载 Maven Wrapper**
```bash
# 创建目录
mkdir -p .mvn/wrapper

# 下载 maven-wrapper.jar（需要网络）
curl -o .mvn/wrapper/maven-wrapper.jar \
  https://repo.maven.apache.org/maven2/org/apache/maven/wrapper/maven-wrapper/3.2.0/maven-wrapper-3.2.0.jar

# 下载 mvnw 脚本
curl -o mvnw \
  https://raw.githubusercontent.com/apache/maven-wrapper/master/mvnw
chmod +x mvnw
```

## 验证服务启动

启动成功后，访问以下地址验证：

```bash
# 健康检查
curl http://localhost:8080/actuator/health

# 查看所有模具
curl http://localhost:8080/api/molds

# H2 数据库控制台（浏览器访问）
# http://localhost:8080/h2-console
# JDBC URL: jdbc:h2:mem:molddb
# 用户名: sa
# 密码: （空）
```

## 测试核心 API

### 1. 查看模具寿命总览

```bash
curl http://localhost:8080/api/reports/mold-life-summary
```

### 2. 录入冲压记录（触发链路）

```bash
curl -X POST http://localhost:8080/api/stroke-records \
  -H "Content-Type: application/json" \
  -H "X-Operator: test-user" \
  -d '{
    "batchId": "BATCH-TEST-001",
    "moldCode": "MOLD-001",
    "strokeCount": 5000,
    "recordTime": "'$(date -u +"%Y-%m-%dT%H:%M:%S")'"
  }'
```

### 3. 查看生成的换模任务

```bash
curl http://localhost:8080/api/mold-change-tasks/pending
```

### 4. 提交续用申请

```bash
curl -X POST http://localhost:8080/api/mold-extensions/request \
  -H "Content-Type: application/json" \
  -H "X-Operator: test-user" \
  -d '{
    "moldCode": "MOLD-003",
    "extensionStrokes": 20000,
    "reason": "生产紧急，临时续用",
    "productionLine": "LINE-01",
    "productCode": "PROD-C003"
  }'
```

### 5. 查看排程影响报告

```bash
curl http://localhost:8080/api/reports/schedule-impact
```
