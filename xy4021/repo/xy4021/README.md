# 器械包追踪台 - 口腔诊所消毒管理系统

## 项目简介

"器械包追踪台"是一个专为口腔诊所消毒间设计的本地桌面应用，用于追踪器械包从清洗、打包、灭菌、放行到领用的完整生命周期。解决了传统纸质记录难以追溯的问题，特别是在灭菌失败时能够快速定位需要隔离的器械包。

## 功能特性

### 📦 器械包管理
- 维护器械包模板（拔牙包、种植包、洁牙包等）
- 单个器械包编号管理
- 状态实时追踪
- 状态历史查询

### 🔥 锅次管理
- 登记灭菌锅次（锅号、开始/结束时间、操作人）
- 记录温度压力摘要
- 生物/化学指示结果管理
- 锅次内器械包添加/移除

### 🔄 状态流转
器械包状态流转规则：
```
待灭菌 → 灭菌中 → 待放行 → 已放行 → 已领用
   │         │         │          │
   │         │         ├──────────→ 已隔离
   │         └─────────→ 已隔离
   └───────────────────→ 已报废
   
已隔离 → 已报废 / 待灭菌
已领用 → （终止状态，不可逆转）
已报废 → （终止状态，不可逆转）
```

### ✅ 业务规则校验
- 指示结果未通过或缺失时不能放行
- 同一个包不能同时在两个未结束锅次里
- 已领用的包不能再回到待放行
- 锅次标记失败后，所有未领用包自动隔离

### 📊 数据导入导出
- 从CSV批量导入器械包
- 导出当前库存报告
- 导出锅次追溯报告
- 导出单个器械包历史

### 📈 报告生成
- 库存状态报告
- 失败锅次报告
- 每日汇总报告
- 单个器械包追溯报告

## 使用指南

### 核心流程操作

#### 1. 新增器械包
1. 打开应用 → 点击"器械包管理"标签
2. 点击"新增器械包"按钮
3. 选择模板类型、输入器械包编号
4. 点击"确定"

#### 2. 创建锅次
1. 点击"锅次管理"标签
2. 点击"新建锅次"按钮
3. 填写锅次编号、灭菌锅号、操作人等信息
4. 点击"确定"

#### 3. 添加器械包到锅次
1. 在锅次列表中选择一个"进行中"的锅次
2. 点击"添加器械包"按钮
3. 在弹出窗口中选择要添加的器械包（可多选）
4. 点击"添加选中"

#### 4. 完成锅次
1. 选择进行中的锅次
2. 点击"完成锅次"按钮
3. 填写生物/化学指示结果、温度、压力
4. 点击"确定"
   - 器械包状态自动变为"待放行"

#### 5. 放行器械包
1. 选择已完成的锅次
2. 点击"放行"按钮
   - 系统会检查指示结果是否通过
   - 若通过，器械包状态变为"已放行"
   - 若未通过或缺失，会提示错误

#### 6. 领用器械包
1. 回到"器械包管理"标签
2. 选择状态为"已放行"的器械包
3. 点击"领用"按钮
   - 器械包状态变为"已领用"

#### 7. 锅次失败处理
1. 在锅次列表选择要标记失败的锅次
2. 点击"标记失败"按钮
3. 输入失败原因
4. 点击"确定"
   - 系统自动将锅内所有未领用的器械包隔离
   - 记录隔离原因

### CSV导入指南

#### 导入格式要求
CSV文件必须包含以下列：
- `package_number`: 器械包编号（唯一）
- `template_name`: 模板名称（必须与系统中已存在的模板匹配）

可选列：
- `notes`: 备注

#### 示例CSV内容
```csv
package_number,template_name,notes
PKG-2026-001,拔牙包,新入库
PKG-2026-002,种植包,
PKG-2026-003,洁牙包,待灭菌
```

#### 导入步骤
1. 菜单栏 → 文件 → 导入器械包 (CSV)
2. 选择准备好的CSV文件
3. 系统会显示导入结果（成功数、跳过数、错误详情）

### 追溯查询

1. 点击"追溯查询"标签
2. 输入器械包编号
3. 点击"查询"
4. 查看：
   - 基本信息标签：器械包当前状态、模板类型、创建时间等
   - 状态历史标签：完整的状态变更历史记录

## 业务规则详解

### 状态转换规则

| 当前状态 | 允许转换到 | 说明 |
|---------|-----------|------|
| 待灭菌 | 灭菌中、已报废 | 可加入锅次或直接报废 |
| 灭菌中 | 待放行、已隔离、已报废 | 锅次完成后转待放行，或中途隔离/报废 |
| 待放行 | 已放行、已隔离、已报废 | 指示结果通过后放行，或隔离/报废 |
| 已放行 | 已领用、已隔离、已报废 | 可领用或隔离/报废 |
| 已领用 | 无 | 终止状态，不可逆转 |
| 已隔离 | 已报废、待灭菌 | 可报废或重新进入待灭菌 |
| 已报废 | 无 | 终止状态，不可逆转 |

### 放行规则
必须同时满足以下条件才能放行：
1. 生物指示结果 = "通过"
2. 化学指示结果 = "通过"
3. 两个结果都不能是"待确认"或空

### 隔离规则
锅次标记失败时，以下器械包会被自动隔离：
- 状态不是"已领用"
- 状态不是"已报废"

## 数据存储

- 数据库文件位置: `data/sterilization.db`
- 使用SQLite 3，本地文件存储
- 重启应用后数据不会丢失

### 数据库表结构

#### package_templates (器械包模板)
- id, name, description, created_at, updated_at

#### packages (器械包)
- id, template_id, package_number, status, current_cycle_id, notes, created_at, updated_at

#### cycles (锅次)
- id, cycle_number, autoclave_id, start_time, end_time, operator, temperature, pressure, biological_indicator, chemical_indicator, status, failure_reason, notes, created_at, updated_at

#### cycle_packages (锅次-包关联)
- id, cycle_id, package_id, added_at, removed_at, status_at_removal, removal_reason

#### status_history (状态历史)
- id, package_id, cycle_id, from_status, to_status, changed_at, operator, reason, notes

## 常见问题

### Q: 为什么无法放行器械包？
A: 请检查：
1. 锅次的生物/化学指示结果是否都为"通过"
2. 结果不能是"待确认"状态

### Q: 为什么无法将器械包加入锅次？
A: 请检查：
1. 器械包当前状态是否为"待灭菌"或"已隔离"
2. 器械包是否已在另一个进行中的锅次中

### Q: 数据存储在哪里？
A: 数据存储在应用目录下的 `data/sterilization.db` 文件中。建议定期备份此文件。

### Q: 如何备份数据？
A: 直接复制 `data/sterilization.db` 文件即可。恢复时将备份文件放回原位置。
