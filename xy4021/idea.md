## 原始点子

我想做一个给口腔诊所消毒间用的本地桌面小工具，叫“器械包追踪台”。现在护士每天要把拔牙包、种植包、洁牙包这些器械包从清洗、打包、灭菌、放行到领用都记在纸上，一旦某锅灭菌失败，靠人工很难知道哪些包要隔离。请从 0 到 1 做一个可运行的桌面 GUI 应用，不要做成网页演示：能维护器械包模板和单个包编号，登记每次灭菌锅次（锅号、开始/结束时间、操作人、温度压力摘要、生物/化学指示结果），把包加入锅次后自动流转到“待灭菌、灭菌中、待放行、已放行、已领用、已隔离、已报废”等状态。规则要认真做：指示结果未通过或缺失时不能放行；同一个包不能同时在两个未结束锅次里；已领用的包不能再回到待放行；某个锅次标记失败后，里面所有未领用包要批量隔离并留下原因。希望能从 CSV 导入一批器械包，也能导出当前库存和锅次追溯报告；数据要保存在本地 SQLite 或文件数据库，重启应用后不能丢。请把 GUI 界面、状态机/校验、存储层、导入导出、追溯报告和 README 拆成清晰的多文件结构，并带几条可运行的自检或测试，保证我能按说明验证新增器械包、创建锅次、放行、失败隔离、导入导出这些核心流程。
