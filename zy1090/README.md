# 手作工作室管理系统

一个专为手作工作室（香薰蜡烛、手工皂等）设计的本地全栈 Web 管理系统。

## 核心功能

- **材料批次管理**：支持不同批次的价格、有效期、过敏原备注
- **配方管理**：支持用量、损耗率、单位校验
- **生产批次管理**：生产时扣减对应批次库存，库存不足/材料过期/过敏原冲突/负毛利报价给出明确提示
- **订单管理**：支持报价、利润计算
- **风险看板**：筛选临期材料、低库存材料、亏损订单
- **批次追溯**：反查某个材料批次影响的成品和订单
- **数据导入**：支持 CSV/JSON 导入材料/材料批次
- **报告导出**：支持 Markdown/HTML 格式报告导出

## 技术栈

- **后端**：Node.js + Express + Prisma ORM + SQLite
- **前端**：Vue 3 + Vite + Element Plus + Pinia
- **数据持久化**：SQLite（文件型数据库，无需安装）

## 快速开始

### 1. 安装依赖

```bash
npm run install
```

### 2. 初始化数据库

```bash
npm run db:migrate
```

### 3. 填充种子数据

```bash
npm run db:seed
```

### 4. 启动开发服务

```bash
npm run dev
```

访问地址：
- 前端：http://localhost:5173
- 后端 API：http://localhost:3001

## 风险提示体系

系统会自动检测以下风险并给出明确提示：

| 风险类型 | 严重程度 | 说明 |
|---------|---------|------|
| 材料过期 | danger | 材料批次已过期 |
| 临期材料 | warning | 30 天内即将过期 |
| 低库存 | warning | 剩余库存不足 10% |
| 库存为空 | warning | 该批次已用完 |
| 负毛利订单 | danger | 报价低于成本 |
| 低毛利订单 | warning | 利润率低于 10% |
| 库存不足 | danger | 生产所需材料库存不足 |
| 单位不匹配 | warning | 配方单位与材料批次单位无法转换 |
| 过敏原提示 | info | 材料包含过敏原 |

## 数据导入

支持从 CSV 或 JSON 导入材料和材料批次：

1. 进入「数据导入」页面
2. 下载对应模板
3. 按模板填写数据
4. 上传文件并导入

## 报告导出

支持导出以下报告：

1. **批次追溯报告**：包含材料批次信息、影响的生产批次、影响的订单、召回影响范围
2. **订单利润报告**：包含订单列表、利润统计、风险订单
3. **看板汇总报告**：包含整体统计、风险提示、近期活动

支持两种格式：
- **Markdown**：可直接复制到笔记软件
- **HTML**：可直接在浏览器查看或打印

## 单位换算

支持三类单位的自动换算：

**重量单位**：g, kg, mg, 斤, 磅
**体积单位**：ml, l, tsp, tbsp, 杯
**数量单位**：个, 件, 套, 盒, 箱

> 注意：不同类型的单位之间无法转换（如 g 和 ml）

## 批次追溯链路

材料批次 → 生产耗用 → 生产批次 → 订单项 → 订单 → 客户

可在以下位置进行追溯：
- 材料批次列表 → 点击「追溯」按钮
- 看板 → 材料批次追溯

## 注意事项

1. **本地运行**：本系统设计为本地使用，不包含用户认证
2. **数据备份**：定期备份 `backend/prisma/dev.db` 文件
3. **端口占用**：后端默认端口 3001，前端默认端口 5173
4. **单位一致性**：建议配方和材料批次使用相同单位，避免换算误差
