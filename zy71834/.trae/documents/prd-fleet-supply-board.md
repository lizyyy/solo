## 1. 产品概述
舰队补给棋盘是为玩法策划设计的证据链追溯工具，解决测试数据碎片化、结论可追溯性差的问题。
- 核心用途：将测试记录、单位表、地形规则在同一时间线中联动展示
- 目标用户：玩法策划、测试人员、接手项目的后续开发人员

## 2. 核心特性

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 策划用户 | 本地工具，无需注册 | 导入材料包、查看时间线、标记待确认、导出证据链 |

### 2.2 功能模块
1. **材料导入页**：材料包上传、自动去重、异常检测、人工更正识别
2. **时间线主视图**：测试记录、单位表、地形规则三线联动
3. **棋盘详情面板**：证据链追溯、异常项标记、人工确认、复盘关联
4. **数据导出**：证据链导出、异常报告生成

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|----------|----------|
| 材料导入页 | 材料包解析 | 支持拖拽上传含正常记录、晚到附件、重复项、人工更正的混合材料包，自动解析并标记来源 |
| 材料导入页 | 数据预处理 | 自动去重、识别晚到附件、检测重复项、高亮人工更正 |
| 时间线主视图 | 三线联动视图 | 测试记录（上）、单位表（中）、地形规则（下）三线垂直对齐，按时间/回合顺序排列 |
| 时间线主视图 | 异常标记层 | 边界格穿越、战报结算不一致、回合顺序错误三类异常独立标记为待确认状态 |
| 棋盘详情面板 | 证据链追溯 | 点击结论节点可回溯到关联的测试记录、单位表项、地形规则 |
| 棋盘详情面板 | 人工确认 | 支持对异常项标记为已确认/待确认，记录确认人和时间 |
| 复盘关联 | 复盘报告 | 复盘报告与测试记录、异常项双向关联 |
| 数据导出 | 证据链导出 | 导出含完整证据链JSON/Markdown，包含所有关联数据和标记状态 |

## 3. 核心流程
用户导入材料包后，系统自动解析去重并检测异常，在时间线中展示三线联动视图，用户点击任意节点可查看证据链，对异常项进行人工确认，最终导出完整报告。
```mermaid
flowchart LR
    A["导入材料包" --> B["自动解析"]
    B --> C["去重与异常检测"]
    C --> D["三线时间线展示"]
    D --> E["点击节点查看证据链"]
    E --> F["异常项人工确认"]
    F --> G["关联复盘报告"]
    G --> H["导出证据链报告"]
```

## 4. 界面设计

### 4.1 设计风格
- 主色调：深灰(#1a1a1a) 配合 军绿(#4a5d23) 辅助色
- 强调色：琥珀橙(#d97706) 用于异常标记，浅灰(#d1d5db) 用于正常状态
- 按钮风格：直角矩形、细边框、无圆角
- 字体：等宽字体 JetBrains Mono 用于数据展示，思源黑体用于正文
- 布局风格：工业仪表板风格、网格对齐、信息密度高
- 图标风格：纯线条图标，无装饰

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|-----------|----------|----------|
| 材料导入页 | 上传区域 | 虚线边框上传区、文件列表、解析进度条、异常统计卡片 |
| 时间线主视图 | 三线联动 | 垂直时间轴、三列布局、悬浮高亮联动、滚动同步 |
| 时间线主视图 | 异常标记 | 橙色边框、待确认徽章、点击展开详情 |
| 棋盘详情面板 | 证据链 | 树形结构、连接线、来源标签、跳转链接 |
| 棋盘详情面板 | 人工确认 | 状态切换按钮、备注输入框、确认记录列表 |
| 复盘关联 | 复盘关联 | 双向链接指示器、关联时间戳 |

### 4.3 响应式
桌面端优先，支持1200px以上屏幕。移动端自适应为单列滚动视图，触屏点击优化。

### 4.4 交互细节
- 时间线滚动时三线同步滚动
- 鼠标悬浮某一节点时三线对应位置高亮
- 点击节点展开证据链面板从右侧滑入
- 异常项始终保持视觉焦点，不与正常项混合
- 所有操作有明确的状态变化动画
