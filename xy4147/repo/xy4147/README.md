# 烟雾逃生路线演练场

一个用于消防安全培训的2D小游戏，帮助学生学习如何规划安全的疏散路线。

## 功能特性

- **3个内置关卡**：从初级到高级，覆盖教学楼、办公楼和医院三种场景
- **拖放式交互**：拖拽疏散箭头、封堵危险门、放置灭火器和集合点
- **实时模拟**：模拟人群移动和烟雾扩散
- **多维度判定**：检查拥堵、逆行、超时和未救援等问题
- **评分系统**：从S到F的评级，帮助识别改进方向
- **方案存档**：保存和加载最佳方案
- **Markdown导出**：导出复盘报告用于课堂讨论

## 使用指南

### 1. 选择关卡

从顶部下拉菜单选择一个关卡：
- **初级关卡 - 教学楼一层**：简单布局，适合学习基本操作
- **中级关卡 - 办公楼三层**：中等难度，需要规划更复杂的路线
- **高级关卡 - 医院病房楼**：最高难度，包含多名行动不便人员

### 2. 放置工具

从左侧工具面板拖拽工具到楼层图：

| 工具 | 说明 |
|------|------|
| → 疏散箭头 | 指示疏散方向，点击可旋转方向 |
| 🚫 封堵危险门 | 只能放在门上，阻止人员进入危险区域 |
| 🧯 灭火器 | 延缓附近烟雾扩散速度 |
| 🏁 集合点 | 疏散后的人员集合点 |

### 3. 操作提示

- **放置**：拖拽工具到目标位置释放
- **删除**：点击已放置的物品
- **旋转箭头**：点击已放置的箭头

### 4. 开始模拟

点击"开始模拟"按钮观察：
- 人群根据箭头指示移动
- 烟雾从火源向四周扩散
- 行动不便人员需要附近正常人员协助
- 楼梯口有容量限制，过多会导致拥堵

### 5. 查看结果

模拟结束后会显示：
- **总分**：0-100分
- **评级**：S（完美）、A（优秀）、B（良好）、C（及格）、D（需改进）、F（不及格）
- **问题列表**：按严重程度列出需要改进的问题

### 6. 保存和导出

- **保存方案**：保存当前的工具布局
- **加载方案**：恢复之前保存的方案
- **保存为最佳方案**：记录最高分的方案
- **导出复盘**：生成详细的 Markdown 报告

## 判定规则

### 严重问题 (Critical)

- **楼梯口拥堵**：楼梯位置人数超过容量
- **行动不便人员未救援**：行动不便人员未能疏散
- **人员在烟雾中死亡**：进入高浓度烟雾区域
- **存在被困人员**：未疏散也未死亡

### 错误 (Error)

- **疏散超时**：超过时间限制
- **封堵数量过多**：超过关卡允许的最大数量

### 警告 (Warning)

- **区域拥堵**：3人以上聚集在同一区域
- **路线经过烟雾区**：虽然逃生但路线不安全
- **集合点不足**：未达到要求数量
- **无效封堵**：封堵位置不是门
- **发现逆行箭头**：相邻箭头方向相反

## 开发说明

### 模块职责

1. **levels.js** - 关卡数据定义
   - 3个完整关卡
   - 网格布局
   - 人员配置
   - 烟雾源和出口位置

2. **renderer.js** - 渲染和交互
   - Canvas绘制
   - 拖放处理
   - 事件监听

3. **simulation.js** - 模拟逻辑
   - A*路径寻路
   - 人群移动模拟
   - 烟雾扩散模拟
   - 协助关系处理

4. **rules.js** - 规则判定
   - 多维度检查
   - 评分计算
   - 评级系统

5. **storage.js** - 数据存储
   - localStorage操作
   - 方案保存/加载
   - 最佳方案记录

6. **exporter.js** - 报告导出
   - Markdown生成
   - 文件下载
