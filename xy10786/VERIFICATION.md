## 安装验证步骤

### 1. 安装依赖

```bash
# 方式一：一键安装（推荐）
npm install

# 方式二：分步安装
cd server && npm install && cd ..
cd client && npm install && cd ..
```

### 2. 类型检查验证

```bash
# 后端类型检查
cd server
npx tsc --noEmit

# 前端类型检查
cd ../client
npx tsc --noEmit
```

### 3. 运行项目

```bash
# 终端1：启动后端 (端口 3001)
cd server
npm run dev

# 终端2：启动前端 (端口 3000)
cd client
npm start
```

## 状态流转说明

### 完整审核闭环
```
草稿 → 提交审核 → 待审核
                              ↓ 通过          ↓ 驳回
                            已批准          需重新审核
                              ↓                   ↓
                          已发布              重新提交审核
```

### 发布状态流转
```
已批准 → 发布中 → 发布成功 → 渠道同步中 → 渠道同步成功
               ↓
          发布失败（可重试）
               ↓
          发布失败（不可重试）
```

### 渠道同步流转
```
同步中 → 同步成功
     ↓
  同步失败（可重试）→ 重试 → 同步中
     ↓
  同步失败（不可重试）→ 修正 → 可重试
```

## 常见问题

### Q: 为什么找不到 tsc 命令？
A: 需要先安装依赖：`cd server && npm install`

### Q: 前端启动后显示空白？
A: 检查浏览器控制台，通常是后端 API 未启动或跨域配置问题

### Q: 定时发布不生效？
A: 检查后端日志，cron 任务每分钟执行一次，需要内容处于 SCHEDULED 状态且 scheduledAt <= 当前时间
