原始想法：
我想做一个给小型发酵实验室用的本地科学计算 CLI 工具，叫“发酵曲线校准器”。我们做酵母和乳酸菌小试时，摇瓶和小罐会不断导出 CSV，里面有时间、温度、pH、溶氧、搅拌转速、取样 OD600、补料量和批次备注；现在大家用表格手工拼，很容易把传感器漂移、取样时间错位、补料事件和异常读数混在一起。请从 0 到 1 做一个可运行的 Python CLI 项目：init 命令能创建项目配置，维护传感器校准系数、允许的实验阶段、异常阈值、补料配方和输出目录；import-run 能导入一批实验 CSV，逐行校验时间格式、数值范围、重复时间点、阶段枚举和缺失字段，坏行要进入 quarantine.json 并说明原因；calibrate 命令要按配置修正 pH/温度/溶氧漂移，把取样 OD600 和在线传感器时间线对齐，支持按补料事件切分生长期、稳定期、衰退期；analyze 命令要计算最大生长速率、滞后期估计、补料前后 pH 变化、溶氧跌落区间和批次间相似度，并标出可能的污染、传感器失准、补料记录缺失这些风险；review 命令允许人工确认或驳回风险点，反馈要保存并影响后续报告；export 命令能导出 Markdown 实验复盘、CSV 指标表和包含配置、风险、人工复核记录的 JSON 审计包；history 命令能按菌株、批次、风险类型查询历史结果。请把 CLI 入口、配置模型、CSV 解析、校准算法、阶段切分、指标计算、风险规则、人工复核存储、报告导出、示例数据和测试拆成清晰的多文件结构，不要写成一个大脚本。README 里写清楚安装方式、示例命令，以及如何用临时目录验证 init、导入实验数据、校准、分析、人工复核、导出报告和查询历史的完整流程。
