# 闭馆前 7 分钟 - 博物馆志愿者培训游戏

一款用于博物馆夜场志愿者培训的 2D 小游戏，玩家需要在有限时间内巡查展厅，处理各种异常情况。

## 游戏简介

你是一名博物馆志愿者，现在距离闭馆还有7分钟。在这段时间里，你需要巡查展厅，处理各种异常情况，确保博物馆能够顺利闭馆。

### 游戏目标

在有限时间内完成以下任务：
- 关闭高温灯 - 节约能源，保护展品
- 扶正倾斜的展牌 - 保持展厅整洁
- 疏导拥堵的游客 - 避免安全隐患
- 发现未登记的展品移动 - 防止展品丢失

**注意：不要触发误报，否则会扣分！**

## 快速开始

### 1. 安装依赖

游戏使用纯 HTML5 Canvas 和 JavaScript 开发，无需额外安装依赖。

### 2. 启动游戏

**方式一：使用 Python 启动本地服务器**
```bash
# 在项目根目录下运行
python3 -m http.server 8080
```
然后在浏览器中打开：http://localhost:8080/index.html

**方式二：使用 Node.js 的 http-server**
```bash
# 安装 http-server（如果没有）
npm install -g http-server

# 在项目根目录下运行
http-server -p 8080
```
然后在浏览器中打开：http://localhost:8080/index.html

**方式三：直接打开 HTML 文件**
- 双击 `index.html` 文件在浏览器中打开
- *注意：部分浏览器可能会限制本地文件的 JavaScript 执行，推荐使用本地服务器方式*

## 游戏机制

### 事件类型

| 事件类型 | 图标 | 分数 | 误报扣分 | 持续时间 | 说明 |
|----------|------|------|----------|----------|------|
| 高温灯 | 💡 | +10 | -20 | 30秒 | 需要关闭的高温灯，保护展品 |
| 倾斜展牌 | 📋 | +5 | -10 | 45秒 | 需要扶正的倾斜展牌 |
| 拥堵游客 | 👥 | +15 | -30 | 25秒 | 需要疏导的拥堵游客 |
| 展品移动 | 🔍 | +25 | -50 | 20秒 | 发现未登记的展品移动 |

### 评分规则

- **基础得分**：根据事件类型获得相应分数
- **完美处理**：在事件持续时间的前一半时间内处理，额外 +5 分
- **时间奖励**：游戏结束时，每秒剩余时间 +2 分
- **误报惩罚**：在有互动物体但无事件时按空格键，-20 分
- **超时惩罚**：事件超时未处理，-10 分

### 关卡配置

| 关卡 | 名称 | 难度 | 时间乘数 | 事件生成率 | 最大同时事件数 | 通关要求 |
|------|------|------|----------|------------|----------------|----------|
| 1 | 初级培训 | easy | 1.0x | 0.8x | 5个 | ≥50分，≥3个事件 |
| 2 | 中级巡查 | medium | 0.9x | 1.0x | 7个 | ≥100分，≥5个事件 |
| 3 | 高级应对 | hard | 0.8x | 1.2x | 10个 | ≥200分，≥8个事件 |

### 风险规则

1. **误报检测**：当玩家在有展品或灯具附近但没有事件时按空格键，会触发误报
2. **事件超时**：每个事件有持续时间，超时未处理会扣分
3. **关卡解锁**：通过当前关卡后才能解锁下一关

## 模块说明

### 1. 游戏循环 (game.js)
游戏的主入口，负责：
- 初始化所有模块
- 运行游戏主循环 (requestAnimationFrame)
- 协调各模块之间的交互
- 绑定UI事件

### 2. 状态管理 (state.js)
管理游戏状态切换：
- `MENU` - 菜单状态
- `PLAYING` - 游戏中状态
- `PAUSED` - 暂停状态
- `LEVEL_SELECT` - 关卡选择状态
- `RESULT` - 结算状态

### 3. 关卡数据 (level.js)
管理关卡配置：
- 3个预定义关卡
- 地图布局数据
- 关卡难度参数
- 事件生成点配置

### 4. 地图系统 (map.js)
处理游戏地图：
- 瓦片地图渲染
- 碰撞检测
- 实体管理（墙、门、展品、灯）
- 事件生成点管理

### 5. 玩家模块 (player.js)
玩家角色控制：
- 移动控制
- 方向追踪
- 碰撞检测
- 互动范围检测

### 6. 输入系统 (input.js)
处理用户输入：
- 键盘事件监听
- 按键状态管理
- 瞬时按键检测（用于空格键互动）

### 7. 事件系统 (events.js)
游戏事件管理：
- 事件生成
- 事件计时
- 事件处理
- 超时检测

### 8. 评分系统 (scoring.js)
游戏评分管理：
- 得分计算
- 误报记录
- 表现评估
- 通关判定

### 9. 渲染系统 (render.js)
游戏渲染和UI：
- Canvas渲染
- HUD更新
- 事件日志
- 界面状态切换

### 10. 存储系统 (storage.js)
本地数据存储：
- 高分记录保存
- 关卡解锁状态
- 使用 localStorage API

### 11. 配置模块 (config.js)
游戏全局配置：
- 事件类型定义
- 关卡配置
- 评分参数
- UI配置

### 12. 工具函数 (utils.js)
通用工具函数：
- 随机数生成
- 数学计算
- 时间格式化
- 深拷贝

## 验证主要流程

### 流程1：开始游戏
1. 打开游戏页面 → 显示开始界面
2. 点击"开始游戏" → 显示关卡选择界面
3. 选择关卡 → 进入游戏

### 流程2：移动和互动
1. 按 WASD 或方向键 → 角色移动
2. 靠近事件（彩色圆环）→ 显示"按空格键处理"提示
3. 按空格键 → 事件被处理，获得分数

### 流程3：误报检测
1. 靠近展品或灯具（地图上的紫色/黄色方块）
2. 确保附近没有事件（没有彩色圆环）
3. 按空格键 → 触发误报，扣分 -20

### 流程4：游戏结算
1. 时间耗尽或主动结束 → 显示结算界面
2. 查看统计数据（得分、处理事件数、误报次数等）
3. 点击"重新开始"或"返回主菜单"

### 流程5：高分记录
1. 通过关卡并获得正分 → 自动保存到本地存储
2. 点击"查看最高分" → 显示历史高分记录
3. 高分按分数从高到低排序，最多保存10条

### 扩展开发

#### 添加新事件类型
在 `config.js` 的 `EVENT_TYPES` 中添加新类型：
```javascript
NEW_EVENT: {
    id: 'new_event',
    name: '新事件名称',
    description: '事件描述',
    score: 20,
    false_alarm_penalty: -40,
    color: '#ff0000',
    duration: 30,
    icon: '⭐'
}
```

#### 添加新关卡
在 `level.js` 的 `MAP_LAYOUTS` 中添加新地图布局，并在 `config.js` 的 `LEVELS` 中添加关卡配置。

#### 修改游戏参数
所有游戏参数都在 `config.js` 中，可以调整：
- 时间限制
- 事件生成间隔
- 评分参数
- 玩家速度
- 互动范围
