## 1. 产品概述

"基金组合咖啡馆"是一款面向金融教育课堂的交互式模拟游戏，玩家通过拖拽/点击操作在咖啡馆场景中组合基金资产，每次操作直接影响资源池、组合分数和风险指标。产品解决的核心问题是：教师错题本只能事后记录谁做错了，无法实时捕捉学生在哪一步卡住、为什么卡住，更无法区分"规则没理解"和"操作节奏慢了"。

- 目标用户：金融教育课堂的学生（操作者）、教师（观察者）、活动策划阿蓝（运营者）
- 核心价值：让基金组合教学从"静态示例"升级为"可操作、可回溯、可诊断"的闭环流程

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 学生（玩家） | 选择关卡直接进入 | 拖拽/点击操作、查看实时反馈、查看本局历史 |
| 教师 | 切换教师视角 | 查看全班汇总、查看例外记录、查看冲突数据 |
| 活动策划阿蓝 | 运营模式 | 运行小包材料、补录备注、查看补录差异、操作说明查阅 |

### 2.2 功能模块

1. **咖啡馆主界面**：操作台面、资源架、分数仪表盘、风险条、暂停/继续按钮
2. **关卡系统**：样例关卡（顺利流 + 返工流）、自由关卡、边界关卡
3. **实时反馈面板**：操作结果、失败诊断（规则 vs 节奏）、例外提示
4. **汇总面板**：全局数字 + 例外明细（例外不在汇总中消失）
5. **补录工作台**：小包材料运行、备注补录、差异对比视图
6. **冲突仲裁面板**：教师错题本 vs 导入数据冲突展示、双方证据与建议动作
7. **操作说明与历史**：启动指南、换关卡方法、历史记录回放

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 咖啡馆主界面 | 操作台面 | 拖拽基金资产卡片到组合区，点击调整配比，每次操作即时更新资源/分数/风险 |
| 咖啡馆主界面 | 资源架 | 显示可用基金资产（股票型、债券型、货币型、混合型），支持拖拽取出和放回 |
| 咖啡馆主界面 | 分数仪表盘 | 实时显示组合分数、目标差距、当前评级 |
| 咖啡馆主界面 | 风险条 | 实时显示组合风险值，红/黄/绿三色动态反馈 |
| 咖啡馆主界面 | 暂停/继续 | 支持暂停操作，记录暂停时间点和原因标签 |
| 关卡选择页 | 样例关卡 | 包含顺利处理流和返工流两套预设场景 |
| 关卡选择页 | 边界关卡 | 专门设计的边界分数场景（刚好达标/刚好不达标） |
| 实时反馈面板 | 操作结果 | 每步操作后弹出：资源变化、分数增减、风险变动 |
| 实时反馈面板 | 失败诊断 | 操作失败时明确标注：①规则未理解（哪条规则）②操作超时（剩余时间） |
| 实时反馈面板 | 例外提示 | 新手误操作、边界分数触发时弹出特殊标记 |
| 汇总面板 | 数字总览 | 显示总操作次数、成功/失败数、平均分数、风险分布 |
| 汇总面板 | 例外明细 | 每条例外独立列出，含时间戳、操作内容、例外类型，不被汇总数字吞没 |
| 补录工作台 | 小包运行 | 加载一小组材料快速运行，生成基准结果 |
| 补录工作台 | 备注补录 | 对已有结果添加备注条目，标记特殊说明 |
| 补录工作台 | 差异对比 | 补录前后并排对比，差异高亮显示 |
| 冲突仲裁面板 | 证据展示 | 教师错题本记录 vs 系统导入数据，左右对照展示 |
| 冲突仲裁面板 | 建议动作 | 列出可能的处理方案，由用户选择，不自动拍板 |

| 操作说明页 | 换关卡 | 如何切换一组关卡、如何重置进度 |
| 操作说明页 | 历史查看 | 如何查看一局的历史记录、如何回放操作序列 |

## 3. 核心流程

玩家进入咖啡馆 → 选择关卡 → 从资源架拖拽基金卡片到操作台 → 调整配比（点击增减）→ 系统实时计算资源消耗/分数/风险 → 达成目标或触发失败 → 反馈面板给出诊断 → 记录到历史

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深棕咖啡色 (#3E2723) + 暖奶白 (#FFF8F0)，营造咖啡馆氛围
- **辅助色**：风险红 (#D32F2F)、安全绿 (#388E3C)、注意黄 (#FBC02D)、数据蓝 (#1565C0)
- **按钮风格**：圆角胶囊按钮，hover 时微微浮起（shadow + translateY），active 时下沉
- **字体**：标题用 Noto Serif SC（衬线体，书卷气），正文用 Noto Sans SC（无衬线，清晰可读）
- **布局风格**：卡片式布局，左侧资源架 + 中间操作台 + 右侧仪表盘三栏结构
- **图标**：使用 lucide-react 图标库，金融相关用自定义 SVG 补充
- **动画**：拖拽时卡片放大 + 半透明，放入时弹跳效果，分数变化时数字翻滚，风险条渐变色过渡

### 4.2 页面设计总览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 咖啡馆主界面 | 操作台面 | 深木纹背景卡片，可放置区域用虚线框标识，卡片拖入时阴影加深 |
| 咖啡馆主界面 | 资源架 | 左侧竖向列表，基金卡片带类型色条（红=股票/蓝=债券/绿=货币/橙=混合） |
| 咖啡馆主界面 | 分数仪表盘 | 右上圆形仪表盘，指针式动画，数字翻滚效果 |
| 咖啡馆主界面 | 风险条 | 横向渐变条（绿→黄→红），当前值白色三角标记 |
| 关卡选择页 | 关卡卡片 | 网格排列，每张卡片带难度标签、预估时长、样例标记 |
| 实时反馈面板 | 操作结果弹出 | 右下角 toast，资源变化用 ↑↓ 箭头 + 绿红色标注 |
| 实时反馈面板 | 失败诊断 | 模态弹窗，顶部标签分类（规则/节奏/风险），下方详情 + 建议 |
| 汇总面板 | 数字总览 | 顶部 4 个统计卡片，底部例外明细表格 |
| 汇总面板 | 例外明细 | 表格行带例外类型色标，不可折叠，保证可见 |
| 补录工作台 | 差异对比 | 左右分栏，差异行高亮黄色背景，新增行绿色标记 |
| 冲突仲裁面板 | 证据展示 | 左右对照卡片，冲突字段红色下划线标注 |
| 操作说明页 | 步骤说明 | 竖向步骤卡片，每步配操作截图占位和文字说明 |

### 4.3 响应式设计

- 桌面优先设计，三栏布局在 ≥1024px 下完整展示
- 平板（768-1023px）：资源架折叠为顶部横向滚动条，仪表盘缩至右上角
- 手机（<768px）：单栏布局，底部 tab 切换资源架/操作台/仪表盘

### 4.4 无障碍

- 拖拽操作同时支持键盘 Tab + Enter 操作
- 颜色信息不作为唯一标识，辅以图标和文字标签
- 模态弹窗支持 Esc 关闭，焦点陷阱
