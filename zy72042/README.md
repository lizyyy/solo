# 基金组合咖啡馆 ☕

一款交互式金融教育模拟游戏。通过咖啡馆经营的隐喻，让学生在课堂环境中理解基金组合配置的核心概念。

## ✨ 核心特性

- **真实拖拽交互**：从资源架拖拽基金卡片到操作台，每次操作实时影响分数、风险和资源
- **四种失败诊断**：区分「规则没理解」「操作慢了」「风险超限」「资源耗尽」
- **例外不消失**：新手误操作、边界分数、暂停打断、脏数据全部留痕
- **活动策划补录**：阿蓝专用工作台，补录后差异自动同步至所有页面
- **冲突仲裁**：错题本与导入数据冲突时，展示双方证据，不替用户拍板

## 🎮 核心操作流程

### 步骤 1：选择关卡

首页展示 4 个预设关卡：

| 关卡 | 特点 | 适用场景 |
|------|------|----------|
| **晨间拿铁** | 资源充裕，入门友好 | 顺利流程演示 |
| **午后美式** | 资源受限，容易触发风险超限 | 返工练习 |
| **黄昏摩卡** | 分数卡在达标边缘 | 边界分数例外测试 |
| **深夜特调** | 自由组合，无固定答案 | 开放探索 |

点击「开始挑战」进入游戏。

### 步骤 2：拖拽基金构建组合 ⭐（真实拖拽）

游戏页面采用三栏布局：

```
┌─────────────┬───────────────────────┬─────────────────┐
│  资源架      │      操作台            │  分数仪表盘      │
│  (可拖拽)    │   (放置区域 + 配比调整) │  风险条         │
│             │                       │  暂停控制       │
└─────────────┴───────────────────────┴─────────────────┘
```

**拖拽操作**：
1. 从左侧「资源架」点击基金卡片左侧的拖拽手柄（⋮⋮）
2. 按住拖拽到中间「操作台」区域
3. 松开鼠标，基金以 20% 初始配比加入组合

**备选点击方式**：
点击操作台底部的「添加基金」按钮，从下拉菜单选择基金。

### 步骤 3：调整配比

操作台内的基金卡片可以：
- 点击 `-` / `+` 调整配比（每次 ±5%）
- 点击 `×` 从组合中移除基金

**实时反馈**：
- 右侧仪表盘实时更新分数和风险
- 每次操作触发 Toast 通知
- 剩余资源随操作消耗

### 步骤 4：提交组合

当分数 ≥ 目标分数 且 风险 ≤ 风险红线时：
1. 点击顶部「提交组合」按钮
2. 自动跳转至「游戏汇总」页面
3. 查看操作统计、例外明细、完整时间线

## 👩‍💼 活动策划阿蓝工作流

### 补录操作步骤

1. 游戏结束后，从汇总页点击「查看补录工作台」
2. 在补录表单中填写：
   - **补录备注**：说明补录原因（如「课堂测试奖励额外2分」「导入数据修正持仓」）
   - **修改字段**：
     - `得分`：修改前值 / 修改后值为数字（如 `75.9` → `77.9`）
     - `风险`：修改前值 / 修改后值为 0-1 小数（如 `0.323` → `0.28`）
     - **持仓**：见下方「持仓补录说明」
     - `失败原因`：`rule` / `timeout` / `risk` / `resource` / 空
   - **修改前值**：基线数据（系统会自动预填当前持仓的 JSON）
   - **修改后值**：修正后数据
3. 点击「添加补录」

### 持仓补录说明 ⭐

持仓值为 JSON 数组，每项含 `fundId`（基金ID）和 `ratio`（0-1 配比小数）。

**可用基金 ID 对照**：

| fundId | 基金名称 |
|--------|----------|
| `equity-growth` | 成长股票基金 |
| `equity-value` | 价值股票基金 |
| `bond-gov` | 国债债券基金 |
| `bond-corp` | 企业债基金 |
| `money-market` | 货币市场基金 |
| `mixed-balanced` | 平衡混合基金 |
| `mixed-aggressive` | 进取混合基金 |

**真实样例**：

原始持仓（国债 60% + 平衡混合 35%）：
```json
[{"fundId":"bond-gov","ratio":0.6},{"fundId":"mixed-balanced","ratio":0.35}]
```

补录修正为（国债 50% + 平衡混合 35% + 货币市场 10%）：
```json
[{"fundId":"bond-gov","ratio":0.5},{"fundId":"mixed-balanced","ratio":0.35},{"fundId":"money-market","ratio":0.1}]
```

选择「持仓」字段时，系统会：
- 自动预填当前持仓的 JSON 到「修改前值」和「修改后值」
- 实时解析 JSON，显示人类可读的基金名称和占比
- JSON 格式错误时标红提示，禁止提交
- **补录保存后自动重算分数和风险**，不需要手动改分数字段

### 补录效果

补录添加后**自动同步至所有页面**：
- ✅ 补录工作台：实时更新右侧差异视图，持仓按基金名称+占比对比
- ✅ 游戏汇总：显示「最终持仓组合」明细条（含进度条、分类颜色、合计配比）+「已补录」标记
- ✅ 历史记录：每条记录显示持仓摘要（如「国债债券基金 60% + 平衡混合基金 35%」）
- ✅ 冲突仲裁：基于补录后最新持仓和重算后的分数/风险检测

### 差异视图说明

补录工作台右侧展示完整差异：
- **基线快照**：补录前的原始状态（分数、风险、持仓按基金拆分）
- **当前状态**：已应用所有补录的最新状态（持仓补录后自动重算分数风险）
- **持仓补录对比**：按基金逐行展示修正前/后占比，新增基金显示「已移除」或新占比
- **补录轨迹**：按时间顺序展示每条补录的修正前、修正后（持仓自动格式化为名称+占比）、原因说明

## 🛠 技术栈

- **框架**：React 18 + TypeScript
- **构建**：Vite
- **样式**：Tailwind CSS 3
- **状态**：Zustand
- **拖拽**：@dnd-kit/core + @dnd-kit/utilities
- **路由**：react-router-dom
- **存储**：localStorage（游戏记录、补录、基线快照）
