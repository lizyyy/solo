# 民宿管家保洁照片抽检 - 业务样例说明

## 业务背景
民宿管家每日完成客房保洁后，需拍摄以下区域照片上传系统：
1. 卧室整体照（含床铺整理）
2. 卫生间（马桶、洗手台、淋浴区）
3. 厨房（灶台、台面）
4. 客厅（沙发、茶几）
5. 阳台/公共区域

## 抽检规则
- **时间要求**：照片拍摄时间需在保洁完成后7天内
- **照片命名规范**：民宿编号_管家姓名_日期_区域.jpg
  - 例如：MS001_张三_20240518_卧室.jpg

## 异常情况说明

### 1. 时间错位
- 照片拍摄时间超过7天（使用历史照片冒充）
- 照片拍摄时间晚于当前时间（系统时间错误）
- EXIF时间信息缺失（可能经过PS处理）

### 2. 压缩包嵌套
- 一线同事打包时嵌套多层zip
- 系统自动解压提取，不中断流程
- 记录嵌套原因，便于后续培训

### 3. 其他异常
- 文件损坏无法读取
- 非图片格式文件
