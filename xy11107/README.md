# 民宿管家保洁照片抽检 CLI

让一线同事照着流程跑，不再靠负责人临时解释。

## 业务背景
民宿管家每日完成客房保洁后，需拍摄各区域照片上传系统。本工具用于自动抽检照片合规性。

## 核心功能
- ✅ **时间错位检测**：检查照片拍摄时间是否在7天有效期内
- ✅ **压缩包嵌套处理**：自动解压多层嵌套zip，继续处理剩余文件并记录原因
- ✅ **可复跑输出**：支持断点续跑，跳过已处理文件
- ✅ **结果分离存放**：正常/异常照片分开存放，方便人工复核
- ✅ **简洁日志 + 详细模式**：默认简洁输出，`-v`参数展开每条记录

## 真实处理流程

### 第一步：预览待处理文件
正式执行前先预览，确认文件数量和范围：
```bash
node src/index.js preview samples/民宿管家5月保洁照片.zip
```

### 第二步：正式执行抽检
```bash
# 基本执行
node src/index.js run samples/民宿管家5月保洁照片.zip

# 指定输出目录
node src/index.js run samples/民宿管家5月保洁照片.zip -o ./output

# 详细模式（显示每条记录）
node src/index.js run samples/民宿管家5月保洁照片.zip -v

# 断点续跑（跳过已处理文件）
node src/index.js run samples/民宿管家5月保洁照片.zip --resume
```

### 第三步：查看抽检报告
执行完成后生成JSON报告，可通过命令查看：
```bash
node src/index.js report
```

## 输出目录结构
```
output/
├── normal/          # 正常通过的照片
├── abnormal/        # 异常照片（每项附带原因说明txt）
├── report.json      # 抽检报告
└── .processed.json  # 已处理文件记录（用于续跑）
```

## 异常判定标准

### 1. 时间错位
- 照片拍摄时间超过7天（使用历史照片冒充）
- 照片拍摄时间晚于当前时间（系统时间异常）
- EXIF时间信息缺失（可能经过PS处理）

### 2. 文件异常
- 文件损坏无法读取
- 非图片格式文件

### 3. 压缩包嵌套
- 检测到多层zip嵌套时自动提取内部文件
- 不中断流程，继续处理剩余文件
- 记录嵌套原因，便于后续培训一线同事
