## 2. 技术描述

- **前端框架**: React@18 + TypeScript + Vite@5
- **状态管理**: Zustand (轻量级，适合游戏状态管理)
- **样式方案**: TailwindCSS@3
- **2D渲染**: 原生 Canvas API (性能更好的性能，无需额外绘图库)
- **报告导出**: jsPDF (PDF导出) + 原生JSON导出
- **数据持久化**: LocalStorage (游戏设置) + IndexedDB (历史记录存储)
- **初始化工具**: vite-init
- **后端**: 无 (纯前端应用)

## 4. 核心数据模型

### 4.1 游戏状态 (GameState)

```typescript
// 物资类型
type SupplyType = 'water' | 'medicine' | 'tent';

// 物资
interface Supply {
  type: SupplyType;
  name: string;
  weight: number;  // 单位重量
  emoji: string;
}

// 物资库存
interface SupplyInventory {
  water: number;
  medicine: number;
  tent: number;
}

// 节点类型
type NodeType = 'warehouse' | 'shelter' | 'junction';

// 地图节点
interface MapNode {
  id: string;
  type: NodeType;
  name: string;
  x: number;
  y: number;
  demand?: SupplyInventory;  // 安置点需求
  received?: SupplyInventory;  // 已接收物资
}

// 道路状态
type RoadStatus = 'clear' | 'congested' | 'blocked';

// 道路
interface Road {
  id: string;
  from: string;
  to: string;
  distance: number;  // 距离(单位)
  status: RoadStatus;
  baseTime: number;  // 基础通行时间
}

// 车辆状态
type VehicleStatus = 'idle' | 'loading' | 'moving' | 'delivering' | 'returning';

// 车辆
interface Vehicle {
  id: string;
  name: string;
  maxCapacity: number;  // 最大载重
  currentLoad: SupplyInventory;
  currentWeight: number;
  status: VehicleStatus;
  currentNode: string;
  targetNodes: string[];  // 目的地队列
  progress: number;  // 0-1 当前路段进度
  speed: number;
}

// 事件类型
type EventType = 'weather' | 'road_block' | 'demand_surge' | 'supply_loss';

// 随机事件
interface GameEvent {
  id: string;
  type: EventType;
  title: string;
  description: string;
  timestamp: number;
  affectedRoad?: string;
  affectedNode?: string;
  resolved: boolean;
}

// 天气类型
type WeatherType = 'sunny' | 'rainy' | 'stormy';

// 游戏阶段
type GamePhase = 'planning' | 'executing' | 'paused' | 'finished';

// 关卡配置
interface LevelConfig {
  id: string;
  name: string;
  difficulty: 'easy' | 'medium' | 'hard';
  description: string;
  initialSupplies: SupplyInventory;
  nodes: MapNode[];
  roads: Road[];
  vehicles: Vehicle[];
  maxTurns: number;
  timeLimit: number;  // 秒
  eventProbability: number;  // 事件发生概率
}

// 操作记录 (用于回放)
interface ActionRecord {
  turn: number;
  timestamp: number;
  type: 'load' | 'unload' | 'route' | 'start' | 'event';
  payload: any;
  stateSnapshot: GameState;
}

// 评分详情
interface ScoreDetail {
  category: string;
  score: number;
  maxScore: number;
  description: string;
}

// 游戏状态
interface GameState {
  levelId: string;
  phase: GamePhase;
  turn: number;
  maxTurns: number;
  weather: WeatherType;
  warehouseSupplies: SupplyInventory;
  nodes: MapNode[];
  roads: Road[];
  vehicles: Vehicle[];
  events: GameEvent[];
  selectedVehicle: string | null;
  selectedRoute: string[];
  eventLog: string[];
  startTime: number;
  elapsedTime: number;
  isPaused: boolean;
  actionHistory: ActionRecord[];
  score: number;
  scoreDetails: ScoreDetail[];
  failReason?: string;
}
```

### 4.2 计分规则

```typescript
// 计分规则配置
interface ScoringRule {
  // 基础分 (1000分)
  baseScore: number;
  
  // 加分项:
  // - 按时完成: +200分
  // - 每回合剩余时间奖励: +10分/剩余回合
  // - 物资准确配送: +50分/安置点(需求完全匹配)
  // - 无浪费配送: +30分/物资类型(返回时无剩余)
  
  // 扣分项:
  // - 错误操作(超重发车): -50分/次
  // - 超时: -10分/回合
  // - 物资浪费(返回有剩余): -20分/单位
  // - 需求未满足: -100分/安置点
  // - 道路绕行: -30分/次
}
```

## 6. 核心模块说明

- 车辆移动逻辑
- 回合管理

- 扣分规则应用
- 结算报告生成

### 6.4 回放系统 (game/replay.ts)
- 操作记录
- 状态快照
- 回放控制

- 交互处理
