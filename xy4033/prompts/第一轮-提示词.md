我想做一个给外业测绘小组用的本地端侧同步工具，叫“外业资料双向同步预演器”。我们白天在山里用笔记本整理照片、航线、点位 CSV 和手写记录，晚上再把资料同步到加密移动硬盘；现在靠人工拖文件，经常出现同名文件被覆盖、大小写路径在不同系统里冲突、移动硬盘上删过的旧版本又被拷回来。请从 0 到 1 做一个可直接运行的 Python CLI 项目：init 命令能创建同步配置，维护左侧工作目录、右侧备份目录、忽略规则、允许的文件类型、冲突策略和日志目录；scan 命令要分别扫描两端文件树，生成包含相对路径、大小、mtime、sha256、文件类型和来源端的 manifest；plan 命令根据两端 manifest 生成 dry-run 同步计划，能识别新增、修改、删除、重命名候选、同路径不同内容、大小写仅差异、mtime 漂移、符号链接跳出根目录、忽略规则命中这些情况，冲突项必须进入 quarantine.json，不能直接覆盖；apply 命令只能执行无冲突计划，执行前写 journal，执行后逐项校验 sha256；undo 命令能根据最近一次 journal 回滚已复制、已删除和已改名的文件，遇到目标被用户改过时要停下来提示；report 命令能导出 Markdown 和 JSON 报告，history 命令能查询过去每次扫描和同步结果。请把 CLI 入口、配置模型、文件扫描/哈希、计划生成、冲突隔离、执行器、回滚 journal、报告导出、示例数据和测试拆成清晰的多文件结构，不要写成单文件脚本。README 里写清楚安装方式、示例命令，以及如何用两个临时目录验证 init、scan、plan、apply、undo、report 的完整流程。
