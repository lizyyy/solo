# 离线字幕对齐复核器

一个专为字幕制作人员设计的离线Web工具，用于检查和修正字幕时间与音频标记的对齐问题。

## 功能特性

- 📝 **多格式解析** - 支持 SRT 字幕、CSV 音频标记、JSON 节目段落
- 🔍 **智能校验** - 自动检测字幕与静音/说话区间的错位
- 📊 **可视化时间轴** - 可拖拽时间轴，直观展示各元素关系
- ✏️ **逐条修正** - 方便的编辑界面，支持自动修正
- 📋 **冲突提示** - 错误/警告分级，问题一目了然
- 💾 **状态持久化** - 自动保存，不用担心数据丢失
- 📤 **导出功能** - 导出修正后的 SRT 和详细的复核报告

## 处理的"坑"

1. **跨段落字幕** - 检测字幕是否跨越多个节目段落
2. **重叠字幕** - 检测字幕之间是否存在时间重叠
3. **毫秒/帧率混用** - 支持多种时间格式解析：
   - SRT 标准格式: `00:00:00,000`
   - 点分隔格式: `00:00:00.000`
   - 时间码格式: `00:00:00;00` (配合帧率转换)
   - 纯秒数: `123.456`

## 校验规则

| 规则类型 | 说明 | 严重程度 |
|---------|------|---------|
| `overlap_with_silence` | 字幕与静音区间重叠 | error |
| `overlap_between_subtitles` | 字幕之间时间重叠 | error |
| `start_in_silence` | 字幕开始时间落在静音区间 | warning |
| `end_in_silence` | 字幕结束时间落在静音区间 | warning |
| `cross_segment` | 字幕跨越多个节目段落 | warning/info |
| `time_gap` | 字幕之间间隔过大 | info |

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

### 3. 打开浏览器

访问 http://localhost:5173 即可看到应用。

### 4. 体验示例项目

点击 **"加载示例数据"** 按钮，即可预览一个预设的示例项目，包含：
- 5 条有对齐问题的字幕
- 10 个音频标记（说话/静音区间）
- 3 个节目段落

示例数据中特意设计了以下问题供测试：
- 字幕 #1 开始时间过早（落在静音区间）
- 字幕 #1 和 #2 存在时间重叠
- 字幕 #2 结束时间过晚（超出说话区间）
- 字幕 #3 跨越"开场介绍"和"主题讨论"两个段落
- 字幕 #4 开始时间落在静音区间
- 字幕 #5 结束时间超出说话区间

## 使用说明

### 1. 导入文件

应用支持导入以下三种文件：

#### 字幕文件 (.srt)
标准的 SRT 字幕格式：
```
1
00:00:02,000 --> 00:00:05,000
字幕内容

2
00:00:05,000 --> 00:00:08,000
第二条字幕
```

#### 音频标记文件 (.csv)
包含静音/说话区间的标记，格式：
```csv
id,start_time,end_time,type,confidence
1,00:00:00.000,00:00:02.500,silence,0.95
2,00:00:02.500,00:00:05.200,speech,0.98
```
- `type` 字段支持: `speech`（说话）、`silence`（静音）
- 时间格式支持: `00:00:00.000` 或纯秒数

#### 节目段落文件 (.json) - 可选
节目结构段落划分，用于检测跨段落字幕：
```json
[
  {
    "id": "segment-1",
    "name": "开场介绍",
    "startTime": 0,
    "endTime": 10,
    "segmentType": "intro"
  }
]
```

### 2. 查看时间轴

导入文件后，时间轴会显示：
- **音频轨道** - 蓝色表示说话区间，斜线表示静音区间
- **段落轨道** - 不同颜色表示不同节目段落（如果导入了段落文件）
- **字幕轨道** - 绿色表示字幕，红色表示有问题的字幕

### 3. 调整字幕时间

时间轴上的字幕块支持拖拽操作：
- **拖拽中间** - 整体移动字幕时间
- **拖拽左边缘** - 调整开始时间
- **拖拽右边缘** - 调整结束时间

每次调整后会自动重新校验。

### 4. 逐条修正

在字幕列表中点击某条字幕，可以在编辑器中：
- 精确调整开始/结束时间
- 修改字幕内容
- 查看该字幕的所有问题
- 点击"自动修正"尝试自动修复

### 5. 导出成果

完成修正后，可以导出：
- **导出 SRT** - 下载修正后的字幕文件
- **导出报告** - 下载详细的复核报告（Markdown 格式）

复核报告包含：
- 项目概览统计
- 问题统计和详细列表
- 时间轴统计（说话/静音时长）
- 节目段落信息
- 字幕详情表

## 技术栈

- **框架**: React 18
- **语言**: TypeScript
- **构建工具**: Vite 5
- **CSV 解析**: Papa Parse
- **状态管理**: React Context + useReducer
- **持久化**: LocalStorage

## 注意事项

1. 本工具是纯前端应用，所有数据仅存储在浏览器本地，不会上传到任何服务器。
2. 建议使用 Chrome 或 Firefox 浏览器以获得最佳体验。
3. 时间解析支持多种格式，但建议使用标准的 `00:00:00.000` 或 `00:00:00,000` 格式。
