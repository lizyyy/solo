## 1. 产品概述

影棚器材归还模拟器——一个基于真实影棚运营流程的轻 3D 浏览器小游戏。玩家扮演兼职实习生，对归还的摄影器材进行清点、检查和结算。核心目标是培养归还检查的肌肉记忆：配件不漏查、损伤不遗漏、押金不出错。

- 目标用户：影棚兼职、器材管理培训场景
- 核心价值：通过游戏化训练降低实际运营中的疏漏率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 玩家（实习生） | 浏览器直接进入 | 进入关卡、操作归还流程、查看报告 |

### 2.2 功能模块

1. **主菜单页**：关卡选择、游戏说明、历史记录
2. **游戏场景**：3D 影棚归还区 + 2D 清点面板叠加
3. **结算页**：得分、失败原因、历史回放、报告导出

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主菜单 | 关卡卡片 | 三个难度档位的卡片式选择，显示关卡名称、规则摘要、最高分 |
| 主菜单 | 游戏说明 | 弹出式说明：操作方式、评分规则、扣分机制 |
| 主菜单 | 历史记录 | 展示最近完成的关卡成绩、失败原因 |
| 游戏场景 | 3D 归还区 | Three.js 渲染的归还台、器材架，可旋转查看 |
| 游戏场景 | 2D 清点面板 | 左侧器材清单、右侧检查表格，拖拽交互 |
| 游戏场景 | 顶部状态栏 | 时间、得分、暂停按钮 |
| 结算页 | 得分详情 | 项目逐项得分展示 |
| 结算页 | 失败原因 | 红色高亮显示未通过的检查项 |
| 结算页 | 历史回放 | 时间轴回放玩家操作与正确答案对比 |
| 结算页 | 报告导出 | 导出 CSV 格式的检查报告 |

## 3. 核心流程

### 3.1 关卡流程

玩家从主菜单选择关卡 → 进入游戏场景 → 限时清点归还器材 → 逐项检查（拖拽配件、标记损伤、计算押金） → 时间到或主动提交 → 系统判定正误 → 结算页展示结果 → 可导出报告或重玩

## 4. 关卡设计

### 4.1 关卡一：入门档（1 小时归还）

- **器材**：单反相机 × 1、镜头 × 1、三脚架 × 1
- **规则**：检查清单明确，配件显眼，损伤明显（划痕、污渍），押金规则简单（按件数扣）
- **难度**：时间充裕（90 秒），干扰项少
- **教学元素**：逐步高亮提示

### 4.2 关卡二：进阶档（半天归还）

- **器材**：相机 × 1、镜头 × 2、灯架 × 2、电池 × 4、存储卡 × 2、滤镜 × 1
- **规则**：配件隐藏在器材旁需仔细寻找，损伤需旋转查看，押金按损耗程度分级（轻微/严重），存在"归还了不需要归还"的干扰物品
- **难度**：时间 120 秒，有 1-2 个陷阱项
- **差异化**：押金计算变复杂，存在冗余物品

### 4.3 关卡三：挑战档（全天归还）

- **器材**：相机 × 2、镜头 × 3、灯架 × 3、电池 × 6、存储卡 × 3、滤镜 × 2、反光板 × 1、脚架 × 2
- **规则**：多个镜头共用一个滤镜需要正确分配，电池容量状态影响押金（电量低扣更多），损伤描述有歧义需判断严重程度，存在"看起来损伤但实际是正常使用痕迹"的迷惑项
- **难度**：时间 150 秒，多个陷阱，押金公式分级细化
- **差异化**：电量检测、滤镜分配、正常使用痕迹 vs 真实损伤区分

## 5. 用户界面设计

### 5.1 设计风格

- **主色调**：深灰蓝 (#1a2332) 背景 + 琥珀黄 (#f59e0b) 强调 + 薄荷绿 (#10b981) 成功 + 红色 (#ef4444) 失败
- **按钮风格**：圆角 8px，微阴影，hover 上浮 + 背景加深
- **字体**：标题用 "Space Mono" 等宽字体，正文用系统等宽字体，营造"器材清单"的工业感
- **布局**：3D 画布全屏背景 + 右侧/底部 2D 操作面板浮层
- **图标**：Lucide 图标库，线性风格

### 5.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主菜单 | 关卡卡片 | 深色卡片、琥珀色边框高亮、底部显示最高分徽章 |
| 游戏场景 | 3D 画布 | 低多边形风格归还台、木质地板、暖黄射灯 |
| 游戏场景 | 清点面板 | 半透明白色面板、深色边框、等宽字体表格 |
| 游戏场景 | 拖拽物品 | 2D 卡片、拖拽时半透明跟随、放下时动画 |
| 结算页 | 回放时间轴 | 水平时间轴、绿色正确、红色错误节点 |

### 5.3 响应式

桌面优先设计，最小宽度 1024px，适配到 768px 平板。

### 5.4 3D 场景指引

- **环境**：低多边形影棚内部，木地板纹理，射灯光晕
- **灯光**：主光一盏聚光灯 + 环境光，暖色调
- **相机**：固定俯视 45°，可鼠标拖拽旋转
- **构图**：归还台居中，器材架在后方
- **交互**：点击器材在 2D 面板中高亮对应行
- **后处理**：轻微泛光、色彩校正
- **性能**：低面数模型，总面数 < 5000

## 6. 评分与判定

### 6.1 得分机制

- **配件匹配**：每件正确匹配 +10 分，漏匹配 -15 分
- **损伤标记**：正确标记损伤 +15 分，漏标记 -20 分，错误标记 -10 分
- **押金计算**：正确计算 +20 分，错误 -25 分
- **时间奖励**：剩余时间每秒 +0.5 分
- **快速检查**：30 秒内完成并全对额外 +50 分

### 6.2 胜负判定

- 总分 >= 80：通过
- 总分 60-79：需培训
- 总分 < 60：未通过
- 存在致命错误（漏记严重损伤、押金扣错 >= 3 项）：直接失败
