# 理赔对账服务

后端服务，用于理赔材料自动核对、人工复核和报告生成。

## 功能特性

- **数据导入**: 支持材料清单CSV、保单JSON导入
- **自动比对**: 智能检测缺发票、金额超限、重复报案等问题
- **差异解释**: 提供可读的差异来源说明
- **人工复核**: 支持复核人员修改判断，数据同步更新
- **重新计算**: 复核后自动重新计算汇总数据
- **报告导出**: 生成详细对账报告

## 快速开始

```bash
pip install -r requirements.txt
python main.py
```
