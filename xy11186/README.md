# 酒类经销商酒水返利台账 CLI

专业的酒类经销商返利台账数据处理工具，支持跨月退货识别、搭赠品标记、稳定排序输出。

## 功能特性

- ✅ **跨月退货自动识别** - 自动检测跨月退货并标记
- ✅ **搭赠品记录跟踪** - 自动识别搭赠品并生成日志
- ✅ **稳定排序输出** - 按交易日期、经销商、流水号稳定排序，便于 diff 比较
- ✅ **容错处理** - 单个文件出错不影响其他文件处理
- ✅ **处理日志** - 自动记录所有异常情况
- ✅ **可复跑** - 支持重复运行，结果一致

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 处理样例数据

```bash
# 处理所有样例文件
npm start -- process ./data/*.csv

# 或指定输出目录
npm start -- process ./data -o ./output
```

### 3. 查看结果

处理后的文件位于 `./output` 目录：

- `处理后_返利台账_202403_华北华东.csv`
- `处理后_返利台账_202403_华中华南.csv`
- `处理日志.csv` - 所有异常记录汇总

## 常见问题

### Q: 为什么两次运行结果完全一样？

A: 本工具采用稳定排序算法，确保相同输入总是产生相同输出，便于 `diff` 比较差异。

### Q: 某个文件处理失败了怎么办？

A: 工具会自动记录错误到`处理日志.csv`，并继续处理其他文件。可单独修复问题文件后重新运行。

### Q: 如何添加新的返利计算规则？

A: 修改 `src/index.js` 中的 `processRebateRecord` 函数。
