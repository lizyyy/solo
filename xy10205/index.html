使用说明 & 验收标准

一、系统概述

木材烘干窑曲线校准台用于验证烘干曲线导入是否生效、含水率模型是否可靠、批次对比是否与原始数据对得上，帮助在出窑前发现并修正问题，避免木材开裂。

二、校准流程

  1. 曲线导入验证：验证导入的温湿度曲线格式是否正确，数据是否完整
  2. 含水率模型验证：验证模型估算的含水率与实测值的偏差
  3. 批次对比校准：对比目标曲线与实测数据，生成校准建议

三、验收标准 - 正常通过

判定输出："正常通过"

满足以下所有条件：

  • 曲线格式验证：数据点数 ≥ 10，时间间隔一致，温湿度在合理范围
  • 含水率模型：平均偏差 ≤ 1.5%，最大偏差 ≤ 3.0%，相关系数 ≥ 0.95
  • 批次对比：温度偏差均值 ≤ ±2℃，湿度偏差均值 ≤ ±3%RH
  • 无关键警告信息

→ 系统自动标记为通过，无需人工处理

四、验收标准 - 需人工处理

判定输出："需人工处理"

满足以下任一条件：

  • 含水率模型：1.5% < 平均偏差 ≤ 3.0%，或3.0% < 最大偏差 ≤ 5.0%
  • 批次对比：2℃ < 温度偏差均值 ≤ 4℃，或3% < 湿度偏差均值 ≤ 6%
  • 存在中等警告信息（如部分时段偏差较大）
  • 数据存在异常但不影响整体趋势

→ 需人工复核偏差点，可选择"修正后重跑"或"标记通过"

五、验收标准 - 校准失败

判定输出："校准失败"

满足以下任一条件：

  • 曲线格式错误：数据点数 < 5，或时间间隔不一致超过20%
  • 含水率模型：平均偏差 > 3.0%，或最大偏差 > 5.0%，或相关系数 < 0.80
  • 批次对比：温度偏差均值 > 4℃，或湿度偏差均值 > 6%
  • 关键数据缺失或严重异常

→ 需检查数据质量，修正问题后点击"重新校准"

六、修正后重跑

当状态为"需人工处理"或"校准失败"时，可以：

  • 修改曲线数据（调整温度/湿度参数）
  • 补充实测数据
  • 调整验证阈值（如需）
  • 点击"重新校准"重新执行验证流程

七、数据持久化

所有数据存储在浏览器本地存储（LocalStorage）中，刷新页面后数据不会丢失。可以通过"导出数据"功能备份数据。
