# 夜航调度练习台

一个用于港口安全培训的本地浏览器小游戏，帮助新调度员练习在复杂情况下安排船只进出港。

## 功能特性

- 🚢 **实时地图渲染** - 港池/航道网格地图，实时显示船舶移动
- ⏱️ **时间推进模拟** - 支持暂停、倍速（1x/2x/5x/10x）
- 🔄 **撤销/重做** - 最多支持50步操作历史
- 💾 **本地存档** - 自动保存到localStorage，支持导入导出
- ⚠️ **冲突校验** - 12种安全约束实时检测
- 📊 **评分系统** - 多维度评分，等级从S到F
- 🎯 **多关卡** - 内置入门级和困难级两个训练场景

## 技术栈

- React 18
- Vite 5
- Canvas API (地图渲染)
- 原生JavaScript (模型/引擎)

## 核心功能验证指南

### 1. 派船流程验证

**操作步骤：**
1. 打开游戏后，默认加载第一关「基础港内调度」
2. 右侧「船舶队列」面板显示待调度船舶
3. 点击某艘进港船舶（如"长江客轮"）
4. 在船舶详情中：
   - 点击「分配泊位」按钮，选择一个可用泊位
   - 点击「分配拖轮」，选择所需拖轮数量（客船需要1艘）
   - 点击「开始作业」按钮

**预期结果：**
- 地图上的船舶开始移动
- 事件日志显示"已为X分配泊位"、"已为X分配拖轮"
- 拖轮状态从「空闲」变为「已分配」

### 2. 冲突提示验证

**触发条件：**
- **拖轮不足**：同时为多艘船分配超过可用数量的拖轮
- **航道会船**：让两艘对向行驶的船同时进入同一航道段
- **吃水超限**：吃水深的船进入浅水航道（第二关有此场景）
- **超时等待**：让船在等待区长时间等待

**预期结果：**
- 地图上冲突位置显示红色闪烁标记
- 事件日志显示对应等级的冲突信息：
  - 🚨 严重冲突（CRITICAL）- 红色
  - ⚠️ 警告（WARNING）- 橙色
  - ℹ️ 提示（INFO）- 蓝色

### 3. 暂停与倍速验证

**操作步骤：**
1. 点击顶部「暂停/播放」按钮
2. 观察船舶状态变化
3. 点击不同速度按钮（1x/2x/5x/10x）
4. 观察时间推进速度变化

**预期结果：**
- 暂停后船舶停止移动，时间不再推进
- 播放后船舶恢复移动
- 不同速度对应不同的时间推进速率

### 4. 撤销与重做验证

**操作步骤：**
1. 进行几次调度操作（分配泊位、分配拖轮等）
2. 点击「撤销」按钮（←）
3. 观察状态是否回到操作前
4. 点击「重做」按钮（→）
5. 观察操作是否被恢复

**预期结果：**
- 撤销后最近的操作被取消
- 重做后已撤销的操作被恢复
- 事件日志显示"已撤销上一步操作"或"已重做操作"

### 5. 存档与恢复验证

**操作步骤：**
1. 进行一些调度操作
2. 点击「保存」按钮
3. 事件日志显示"游戏已保存"
4. 刷新页面或重新打开
5. 点击「加载」按钮

**预期结果：**
- 保存成功后localStorage中有存档数据
- 加载后恢复到保存时的游戏状态

### 6. 结算评分验证

**触发结算条件：**
1. 所有船舶完成作业
2. 或到达关卡时长限制（第一关120分钟，第二关180分钟）

**查看评分：**
1. 游戏结束后自动弹出评分面板
2. 或点击「评分」按钮随时查看

**评分包含：**
- **等级**：S/A/B/C/D/F
- **总分**：0-1000分
- **统计数据**：准点率、冲突次数、拖轮利用率、平均等待时间
- **评分明细**：各项奖励和扣分
- **关键失误**：训练中发生的严重问题

**导出成绩：**
- 点击「导出JSON」按钮，下载评分数据文件

## 调度规则说明

### 船舶类型

| 类型 | 吃水 | 转弯半径 | 拖轮需求 | 优先级 |
|------|------|----------|----------|--------|
| 客船 | 中 | 大 | 1艘 | 高 |
| 集装箱 | 中 | 中 | 2艘 | 中 |
| 危险品 | 深 | 大 | 2艘 | 紧急 |
| 散货 | 深 | 中 | 2艘 | 低 |
| 油轮 | 深 | 大 | 3艘 | 高 |

### 航道约束

- **宽度限制**：窄航道禁止大型船舶通行
- **限速**：不同航道段有不同速度限制
- **单向/双向**：部分航道为单向行驶
- **封航时间窗**：特定时间禁止通行（第二关有施工封航）

### 安全规则

1. **安全距离**：船舶间需保持最小安全距离
2. **危险品与客船**：危险品船与客船需保持额外安全间隔
3. **吃水限制**：船舶吃水不能超过航道水深
4. **对向会船**：单向航道禁止对向行驶
5. **超时等待**：船舶不能无限期等待

## 关卡说明

### 第一关：基础港内调度（入门级）

**特点：**
- 简单的双向航道布局
- 3艘进港船 + 2艘离港船
- 4艘可用拖轮
- 天气变化（晴朗→多雾→大雨）
- 训练目标：掌握基础派船流程

**船舶列表：**
1. 长江客轮（客船，进港，06:00需靠泊）
2. 远洋集装箱（集装箱，进港，08:00需靠泊）
3. 危险品运输（危险品，进港，10:00需靠泊）
4. 货轮启航（散货，离港）
5. 油轮离港（油轮，离港）

### 第二关：复杂航道施工（困难级）

**特点：**
- 包含单向航道段
- 航道施工封航限制
- 更多船舶同时调度
- 更复杂天气变化
- 训练目标：应对复杂约束条件

**特殊条件：**
- 航道A段（0-500米）为单向航道，08:00-08:30封航施工
- 主航道部分区域有吃水限制
- 能见度下降影响安全距离

## 常见问题

### Q: 为什么点击"开始作业"没有反应？

A: 请检查：
1. 进港船是否已分配泊位
2. 是否分配了足够数量的拖轮
3. 船舶状态是否为"等待"

### Q: 如何查看当前冲突？

A: 两种方式：
1. 查看底部「事件日志」面板
2. 地图上红色闪烁区域即为冲突位置

### Q: 存档保存在哪里？

A: 保存在浏览器的localStorage中，刷新页面不会丢失。但清除浏览器缓存会删除存档。

### Q: 如何添加自定义关卡？

A: 编辑 `src/data/levels.js` 文件，参照现有关卡格式添加新关卡。每个关卡需要定义：
- 基本信息（名称、描述、时长）
- 船舶列表
- 航道段列表
- 泊位列表
- 拖轮列表
- 天气时间表
