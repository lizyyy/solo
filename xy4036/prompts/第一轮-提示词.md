我想做一个给港口安全培训用的本地浏览器小游戏，叫“夜航调度练习台”。新来的调度员培训时需要练习在能见度下降、航道施工、拖轮占用和船舶优先级变化时安排船只进出港，但现在只靠纸面案例很难看出一步错会怎样连锁影响。请从 0 到 1 做一个可运行的前端游戏项目：打开后直接进入训练台，左侧是港池/航道网格地图，右侧是待调度船舶队列、天气和资源面板。玩家要给每艘船安排靠泊、离泊、等待区、航道路线和拖轮资源，系统按时间推进模拟船舶移动；不同船型有吃水、转弯半径、危险品优先级、最晚到港时间和需要拖轮数量，航道边有宽度、限速、单向/双向、封航时间窗这些约束。游戏要能加载至少两关 JSON 场景，支持暂停、倍速、撤销最近一步、重新开始和保存当前进度到本地；每一步调度都要校验资源冲突、航道对向会船风险、靠泊窗口冲突、危险品船与客船安全间隔不足、船舶超时等待等问题，并在地图和事件日志里给出清楚反馈。训练结束后要生成评分，包括准点率、冲突次数、拖轮利用率、平均等待时间和关键失误列表，并能导出 JSON 成绩。请把地图渲染、关卡数据、船舶/航道模型、调度规则引擎、时间推进模拟、存档、评分和 UI 组件拆成多个文件，不要写成一个大组件或静态演示。README 里写清楚安装、启动，以及如何用内置关卡验证派船、冲突提示、暂停倍速、撤销、存档恢复和结算评分这些核心流程。
