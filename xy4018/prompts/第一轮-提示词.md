我想做一个给小法务团队用的本地命令行工具，叫“合同改稿巡检器”。我们经常收到客户发来的合同 Word 转文本或 Markdown 改稿，人工对比很容易漏掉付款周期、违约金、自动续约、管辖地这些关键条款变化。请从 0 到 1 做一个可运行的 CLI 项目：可以用命令导入两版合同文本，按章节/条款编号做结构化解析，生成差异摘要；再支持维护一份本地规则包，用 YAML 或 JSON 写风险规则，比如金额上浮超过 20%、付款周期从 30 天改成 60 天、出现自动续约但没有提前通知天数、管辖地变成外地法院等，扫描后输出风险等级、命中的原文片段和建议复核项。工具需要把每次巡检任务保存到本地数据目录，后续能按客户名、合同名、日期查询历史结果；还要支持导出 Markdown 报告和 CSV 风险清单。请把代码拆成清晰模块，比如 CLI 入口、文本解析、diff 计算、规则引擎、存储、报告导出和测试数据，不要全塞一个文件。README 里写清楚安装、运行示例、自带样例合同和一组能验证主流程的测试或自检命令。
