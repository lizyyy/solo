# 冰壶碰撞路径复盘 - 快速入门

## 5分钟内跑通

### 1. 启动项目
```bash
npm install
npm run dev
```

### 2. 界面说明
- **左侧面板**：播放控制、数据源管理、冰壶参数调整
- **中央3D视图**：冰壶场地和轨迹可视化
- **右侧面板**：错误分析、碰撞事件、操作记录

### 3. 基本操作
1. **播放模拟**：点击左侧「播放」按钮观看冰壶运动
2. **调整参数**：点击数据源中的冰壶图标，然后调整滑块
3. **添加冰壶**：点击数据源区域的「+」按钮，选择颜色后添加
4. **导入数据**：点击数据源区域的上传图标，选择JSON文件

### 4. 数据导入格式
```json
{
  "stones": [
    {
      "color": "yellow",
      "initialVelocity": { "x": 0.05, "y": 1.8 },
      "rotation": { "direction": "clockwise", "speed": 30 },
      "friction": 0.015,
      "initialPosition": { "x": 0, "y": -21 }
    }
  ]
}
```

### 5. 错误排查
- 摩擦系数过低：在右侧面板查看警告，调整到 0.008-0.05 范围
- 旋转方向异常：检查出手方向与旋转方向是否匹配
- 速度超出范围：冰壶出手速度应在 0-3 m/s 之间

### 6. 复查证据
- 点击右侧错误卡片展开详细信息
- 查看「操作记录」时间线了解处理历史
- 点击「定位到冰壶」快速跳转到问题对象
