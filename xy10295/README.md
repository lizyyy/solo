# 宠物美容毛结收费计算器

## 安装运行

本项目无需安装任何依赖，直接在浏览器中打开 `index.html` 即可使用。

```bash
# 在 Finder 中双击 index.html，或在终端中运行：
open index.html
```

## 样例入口

1. 打开页面后，点击右上角「添加宠物」按钮
2. 填写以下样例数据测试：
   - 宠物名称：小白
   - 体型：中型犬
   - 服务项目：洗澡护理 + 美容修剪
   - 毛结等级：中度
   - 附加服务：护毛素护理
3. 观察费用预览区域的实时计算

## 核心操作

### 1. 添加宠物记录
- 点击「添加宠物」按钮
- 填写必填项（名称、体型、至少一项服务、毛结等级）
- 实时预览费用明细
- 点击「保存」确认

### 2. 编辑/删除记录
- 在工作区列表中找到目标宠物
- 点击「编辑」修改，或「删除」移除
- 修改后自动更新统计数据

### 3. 导出记录
- 点击「导出记录」按钮
- 系统自动检测数据是否已导出过
- 生成 CSV 文件，可直接用 Excel 打开

### 4. 清空工作区
- 点击「清空全部」按钮
- 确认后清除所有本地数据

## 如何检查结果

### 费用计算验证
1. **基础费用** = 体型基础价 + 选中服务费用之和
   - 小型犬：¥80，中型犬：¥120，大型犬：¥180，猫咪：¥100
   - 洗澡¥50，修剪¥80，指甲¥30，耳道¥25

2. **毛结处理费** = (基础费用 × (等级系数 - 1)) + 等级附加费
   - 无：系数 1.0 + ¥0
   - 轻度：系数 1.2 + ¥50
   - 中度：系数 1.5 + ¥120
   - 重度：系数 2.0 + ¥250

3. **附加服务费** = 选中附加服务费用之和
   - 深层清洁¥60，护毛素¥40，牙齿清洁¥50，除蚤¥80

4. **总计** = 基础费用 + 毛结处理费 + 附加服务费

### 数据一致性验证
1. 刷新页面后，工作区数据应自动恢复
2. 同一批数据重复导出会提示确认
3. 编辑记录后，统计面板和导出内容应同步更新

### 统计面板
- 宠物数量：当前工作区记录数
- 总金额：所有记录总计金额之和
- 重度毛结：毛结等级为「重度」的宠物数量
- 附加服务：所有记录中附加服务项数量之和
