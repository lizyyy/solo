# 体检中心加项收费核对 CLI

一个帮助前台快速识别加项收费异常的命令行工具。

## 功能特点

- ✅ 分步骤运行：先检查 → 再确认 → 可查询 → 可导出
- ✅ 自动检测多种异常情况
- ✅ 数据持久化，支持多次导入和核对
- ✅ 幂等性设计：重复导入不会重复计算
- ✅ 友好的中文输出，适合窗口复核

## 检测的异常类型

| 异常类型 | 说明 |
|---------|------|
| 漏收 | 有加项记录但无收费流水 |
| 重复加项 | 同一员工同一项目同一天录入多次 |
| 企业套餐不允许 | 加项不在企业允许范围内 |
| 金额不符 | 收费金额不等于折后价 |
| 重复收费 | 同一加项有多笔收费记录 |
| 部分退费 | 退费后仍显示欠费 |
| 超额退费 | 退费金额超过收费金额 |

## 快速开始

### 1. 查看帮助

```bash
python3 cli.py --help
```

### 2. 导入数据

```bash
# 导入基础数据（只需导入一次）
python3 cli.py import-data \
  --group data/group_checkups.json \
  --employees data/employees.csv \
  --packages data/packages.json \
  --discounts data/discount_policies.json

# 导入业务数据（每天或定期导入）
python3 cli.py import-data \
  --addons data/add_ons.csv \
  --payments data/payments.csv \
  --refunds data/refunds.csv
```

### 3. 执行核对检查

```bash
python3 cli.py check
```

### 4. 确认核对结果

```bash
python3 cli.py confirm <session_id>
```

### 5. 导出结果

```bash
# 导出为CSV（Excel可直接打开）
python3 cli.py export <session_id> --format csv

# 导出为JSON
python3 cli.py export <session_id> --format json
```

### 6. 查看历史记录

```bash
# 查看历史会话列表
python3 cli.py history

# 查看某个会话详情
python3 cli.py show <session_id>

# 只看正常记录
python3 cli.py show <session_id> --no-pending --no-issues --show-normal
```

### 7. 查看数据状态

```bash
python3 cli.py status
```

### 8. 清空数据（谨慎操作）

```bash
python3 cli.py clear
```

## 工作流程

```
1. 导入数据 (import-data)
      ↓
2. 执行核对 (check) → 生成会话ID
      ↓
3. 人工核查异常
      ↓
4. 确认结果 (confirm)
      ↓
5. 导出存档 (export)
```

## 注意事项

1. **幂等性**：同一文件重复导入不会重复计算，但如果修改了文件内容会重新导入
2. **数据持久化**：所有导入的数据会自动保存到 `data_store/` 目录
3. **会话记录**：每次 `check` 都会生成一个新的会话，保存在 `history/` 目录
4. **确认操作**：`confirm` 只是标记状态，不会修改原始数据
5. **清空数据**：`clear` 命令会清空所有数据，请谨慎使用
