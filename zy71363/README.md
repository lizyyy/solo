# 插画委托进度看板 CLI (illust-board)

一个为自由插画师设计的委托管理工具，帮助你追踪草图、修改轮次、付款节点和客户确认。

## 功能特性

- 📋 **委托单管理** - 创建、查看、筛选所有委托
- 🎨 **版本留痕** - 每个草图版本独立记录，修改意见对应到具体版本
- 💳 **付款追踪** - 定金、尾款节点清晰可见，支持催款提醒
- ✅ **客户确认** - 分阶段确认记录，支持截图存档
- 🚨 **告警系统** - 修改超限、尾款未到、截图缺失单独提醒
- 📊 **报告导出** - 支持 JSON、Markdown、HTML 三种格式导出
- 💾 **自动备份** - 写入前自动备份，避免数据污染

## 快速开始

```bash
# 初始化工作目录
illust-board init

# 创建样例数据（包含边界案例）
illust-board sample

# 查看委托列表
illust-board list

# 查看告警
illust-board alerts

# 导出报告
illust-board export -f html
```

## 命令说明

| 命令 | 说明 |
|------|------|
| `init` | 初始化工作目录 |
| `create` | 创建新委托单 |
| `list` | 列出所有委托单 |
| `show <ID>` | 查看委托详情 |
| `sketch <ID> <文件>` | 添加草图版本 |
| `revise <ID> <意见>` | 添加修改意见 |
| `payment` | 添加付款节点 |
| `confirm` | 添加客户确认 |
| `status <ID> <状态>` | 更新委托状态 |
| `alerts` | 查看所有告警 |
| `export` | 导出进度报告 |
| `sample` | 创建样例数据 |

## 数据结构

每个委托单包含：
- 基本信息（标题、客户、状态、描述）
- 草图版本列表（每个版本含修改意见）
- 付款节点列表（定金、尾款等）
- 客户确认记录（含截图路径）

## 边界案例

样例数据包含以下场景：
1. **正常进行中** - 有草图、有修改、等待确认
2. **修改轮次超限** - 5次修改 vs 3次上限（需额外收费）
3. **尾款未付** - 已完成但尾款未到账
4. **截图缺失** - 有确认记录但缺少聊天截图
5. **全额完成** - 完美完成的委托
