## 1. 产品概述

广告投放贝叶斯更新小工具——帮调度主管周姐把复盘图表里的参数表、历史记录、人工备注和越界样本对上号，用贝叶斯公式跑出后验分布，单位换算、权重闭合和边界阈值全摆在明面，补录一条备注后差异讲清楚，原始来源和处理时间留痕，换人也能看懂前一次怎么判的。

- 面向不写代码的运营/调度人员，报告像同事写给同事看的话
- 不求大而全，先让"参数→计算→结果→报告"这条链路跑通
- 乱备注不洗、越界不藏、单位提醒不省

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 调度主管（周姐） | 浏览器直接使用 | 录入参数、跑贝叶斯更新、补录备注、导出报告 |
| 接手同事 | 浏览器直接使用 | 查看历史记录、追溯判断依据、继续补录 |

### 2.2 功能模块

1. **数据录入页**：参数表输入、历史记录导入、人工备注录入、越界样本标注
2. **贝叶斯计算页**：公式展示、先验→后验计算、单位换算提醒、边界阈值检测、权重闭合校验
3. **复盘报告页**：图表与明细联动、补录差异对比、原始来源和处理时间追溯、导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据录入页 | 参数表录入 | 输入先验分布参数（α, β 或 μ, σ²）、观测数据（曝光/点击/转化）、单位选择（CPM/CPC/CPA）、权重分配 |
| 数据录入页 | 历史记录导入 | 粘贴或逐条录入历史投放数据，自动识别单位并提示换算 |
| 数据录入页 | 人工备注录入 | 自由文本备注，保留原始写法（含乱码、非标格式），标注来源和处理时间 |
| 数据录入页 | 越界样本标注 | 自动检测超阈值数据并标红提醒，显示具体越界字段和阈值 |
| 贝叶斯计算页 | 公式展示区 | 用人话解释贝叶斯公式每一步，先验→似然→后验，参数含义和单位附在旁边 |
| 贝叶斯计算页 | 计算引擎 | Beta-Binomial 共轭更新（转化率场景）或 Normal-Normal 共轭更新（均值场景） |
| 贝叶斯计算页 | 单位换算提醒 | 检测输入单位不一致时弹出换算提示，显示换算系数和换算后数值 |
| 贝叶斯计算页 | 边界阈值检测 | 后验参数超出合理范围时告警，显示边界值和越界量 |
| 贝叶斯计算页 | 权重闭合校验 | 各渠道权重之和≠1 时提醒，显示差额和修正建议 |
| 复盘报告页 | 可视化图表 | 先验/后验分布对比图、各渠道效果柱状图、越界样本散点图 |
| 复盘报告页 | 明细联动 | 点击图表元素跳转到对应明细行，显示完整参数和备注 |
| 复盘报告页 | 补录差异对比 | 补录一条备注后，并排展示更新前/后结果，差异用颜色和文字说明 |
| 复盘报告页 | 来源追溯 | 每条结果显示原始来源、处理时间、操作人，可追溯到具体录入批次 |
| 复盘报告页 | 报告导出 | 导出为 HTML 或打印友好的格式，含图表截图和明细表 |

## 3. 核心流程

**主流程**：调度主管周姐打开工具 → 录入一批参数表和历史数据 → 系统自动检测单位/权重/边界问题并提示 → 运行贝叶斯更新 → 查看先验→后验对比图表 → 发现需要补录一条备注 → 补录后系统展示差异 → 导出报告给同事

**补录流程**：在已有计算结果上 → 新增一条人工备注 → 系统重新计算后验 → 展示"补录前 vs 补录后"差异（哪些参数变了、变了多少、为什么变）→ 更新报告

```mermaid
flowchart TD
    "A[录入参数表+历史数据]" --> "B[单位换算检测]"
    "B" --> "C[权重闭合校验]"
    "C" --> "D[边界阈值检测]"
    "D" --> "E[运行贝叶斯更新]"
    "E" --> "F[展示先验→后验对比]"
    "F" --> "G{需要补录备注?}"
    "G" --> "是" --> "H[补录人工备注]"
    "H" --> "I[重新计算后验]"
    "I" --> "J[展示补录差异]"
    "J" --> "K[导出报告]"
    "G" --> "否" --> "K"
    "K" --> "L[同事查看+追溯]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰（#1e293b）为底，琥珀色（#f59e0b）为强调色——像Excel的沉稳感加一点调度台的警告灯味
- **辅助色**：越界用红橙（#ef4444），正常用翠绿（#10b981），补录变更用天蓝（#3b82f6）
- **按钮风格**：圆角药片形，主操作琥珀色实心，辅助操作描边
- **字体**：数字用等宽字体（JetBrains Mono），正文用思源黑体风格，标题粗一点
- **布局**：左侧固定导航 + 右侧内容区，表格为主，卡片辅助
- **图标**：lucide-react 图标库，线条风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 数据录入页 | 参数表录入 | 表单表格，行内编辑，单位下拉选择，换算提示浮层 |
| 数据录入页 | 历史记录 | 可滚动表格，行点击展开备注，越界行红色背景 |
| 数据录入页 | 人工备注 | 文本域 + 来源标签 + 时间戳，保留原始格式显示 |
| 贝叶斯计算页 | 公式展示 | 数学公式卡片，参数说明用浅色背景框，单位标注在右侧 |
| 贝叶斯计算页 | 计算结果 | 后验参数高亮显示，边界告警条，权重闭合条 |
| 复盘报告页 | 图表区 | 先验/后验曲线叠加图，柱状图，散点图（Chart.js） |
| 复盘报告页 | 明细表 | 可折叠行，点击图表元素高亮对应行 |
| 复盘报告页 | 差异对比 | 左右分栏（补录前|补录后），差异字段用颜色标记 |

### 4.3 响应式

- 桌面优先，最小宽度 1024px
- 表格在小屏下横向滚动
- 图表自适应容器宽度
