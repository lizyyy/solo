## 新人引导：快速上手路径

### 🟢 材料入口（数据从哪来）
1. **寄养登记** → 录入宠物信息、主人微信、房间号（系统：寄养记录模块）
2. **日常巡检** → 兽医助理阿宁记录体温、食欲、精神等数据（自动触发异常规则）
3. **主人微信沟通** → 阿宁在「微信备注」中粘贴/录入主人反馈（关键！关联回访结论用）
4. **兽医处方** → 用药及剂量录入「用药记录」（每次调整自动留痕）

### 🔴 异常出口（异常怎么消）
1. **看到异常** → 列表中点击异常行，进入详情页
2. **确认信息** → 查看是否有主人微信备注，必要时手动补充（月底补录需标注并写清影响）
3. **处理异常** → 调整等级/解决异常，并填写回访结论（必须关联对应微信备注）
4. **用药调整** → 如改剂量必须在「用药记录」中新增一条并写明原因，系统自动记录前后变化
5. **导出报告** → 月底点击「导出Markdown」，所有筛选口径和明细自动写入报告
