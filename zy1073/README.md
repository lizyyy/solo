# 🎪 周末市集摊位摆位

一个策略性网页小游戏，玩家通过拖拽摊位到网格场地，在预算内合理布置，避开冲突，追求高收入和高满意度。

## 🎮 游戏特性

- **🎯 核心玩法**：拖拽摊位到网格场地，合理规划布局
- **⚡ 实时评分**：实时显示预算、满意度、风险和收入预估
- **⚠️ 冲突检测**：自动检测噪音、气味、用电、消防通道等冲突
- **✨ 相邻加成**：特定摊位组合相邻放置获得加成
- **📊 关卡系统**：3个内置关卡，支持自定义关卡导入
- **💾 数据持久化**：撤销/重做、保存布局、本地最高分
- **📄 报告导出**：支持导出 JSON 和 Markdown 格式的结算报告

## 📦 安装

### 前置要求

- Node.js 16+ 或更高版本
- npm 或 yarn 包管理器

### 安装步骤

1. 进入项目目录：
```bash
cd 周末市集摊位摆位
```

2. 安装依赖：
```bash
npm install
```

## 🚀 启动游戏

### 开发模式

```bash
npm run dev
```

游戏将在 `http://localhost:3000` 启动，浏览器会自动打开。

### 构建生产版本

```bash
npm run build
```

构建产物会生成在 `dist` 目录。

### 预览生产版本

```bash
npm run preview
```

## 🎯 如何玩一局

### 1. 选择关卡

- 打开游戏后，默认加载第一关「新手市集」
- 可以通过顶部的关卡选择器切换其他关卡

### 2. 拖拽摊位

1. **查看左侧「可用摊位」面板中的摊位卡片
2. **鼠标按住**想要放置的摊位
3. **拖动**到中间的网格场地
4. **释放鼠标**放置摊位（会自动检测是否可以放置）

### 3. 移动已放置的摊位

- 鼠标按住已放置的摊位可以拖动到新位置

### 4. 删除摊位

- 鼠标悬停在已放置的摊位上，点击右上角的 × 按钮

### 5. 查看实时评分

右侧面板会实时显示：
- **总分**：综合评分
- **满意度**：玩家和摊主的满意度 (0-100%)
- **风险度**：布局的风险程度 (0-100%)
- **预估收入**：根据人流和摊位吸引力计算的预估收入

### 6. 查看冲突和加成

- **冲突警告**：红色提示哪些摊位存在冲突（噪音、气味、消防通道等）
- **加成奖励**：绿色提示哪些摊位组合获得了相邻加成

## 📋 游戏规则

### 摊位属性

每个摊位有以下属性：

| 属性 | 说明 |
|------|------|
| 💰 成本 | 放置该摊位需要的预算 |
| ⚡ 电力 | 该摊位消耗的电力 |
| 🔊 噪音 | 噪音等级（影响儿童区和手作区敏感）|
| 👃 气味 | 气味等级（咖啡区和手作区敏感）|
| 吸引力 | 吸引客流的能力 |
| 人均消费 | 每位顾客的平均消费 |

### 场地元素

网格场地包含以下特殊区域：

| 元素 | 颜色/标识 | 说明 |
|------|-----------|------|
| 🚪 入口 | 蓝色虚线 | 游客进入的位置，靠近入口有加成 |
| 主路 | 橙色 | 人流通道，不能占用 |
| 🔥 消防通道 | 红色虚线 | 必须保持畅通，占用会严重扣分 |
| 🌳 障碍物 | 灰色 | 固定障碍物，不能放置摊位 |

### 冲突规则

| 冲突类型 | 触发条件 | 惩罚 |
|-----------|---------|------|
| 预算超支 | 总花费 > 预算 | -20 分 |
| 用电过载 | 总耗电 > 电力容量 | -15 分 |
| 消防通道占用 | 摊位占用消防通道 | -50 分 |
| 噪音冲突 | 高噪音摊位紧邻儿童区/手作区 | -10 分 |
| 气味冲突 | 强气味摊位紧邻咖啡区/手作区 | -8 分 |

### 相邻加成

| 组合 | 加成 | 说明 |
|------|------|------|
| 咖啡 + 手作 | +15 分 | 咖啡香气吸引手作爱好者 |
| 热食 + 儿童区 | +10 分 | 家长带孩子吃饭后停留 |
| 乐队 + 咖啡 | +12 分 | 音乐氛围提升咖啡消费 |
| 手作 + 儿童区 | +8 分 | 亲子家庭喜欢一起做手工 |

### 额外加成

- **入口邻近加成**：摊位靠近入口（2格内）可获得额外加成
- **预算效率加成**：高效使用预算和电力可获得效率加成

## 📁 导入自定义关卡

游戏支持导入自定义 JSON 格式的关卡文件。

### 导入方法

1. 点击顶部「导入关卡」按钮
2. 选择你的 JSON 关卡文件
3. 关卡会自动加载并添加到关卡选择器

### 关卡 JSON 格式

参考 `src/levels/level1.json` 作为模板。

```json
{
  "id": "my_custom_level",
  "name": "我的自定义关卡",
  "description": "关卡描述",
  "gridSize": {
    "width": 8,
    "height": 8
  },
  "budget": 5000,
  "maxElectricity": 50,
  "entrances": [
    {
      "id": "entrance1",
      "position": { "x": 0, "y": 3 },
      "flowRate": 120
    }
  ],
  "mainRoads": [
    {
      "id": "road1",
      "cells": [
        { "x": 3, "y": 0 }, { "x": 3, "y": 1 },
        { "x": 3, "y": 2 }, { "x": 3, "y": 3 }
      ],
      "priority": 1
    }
  ],
  "fireExits": [
    {
      "id": "fire1",
      "cells": [{ "x": 0, "y": 0 }, { "x": 1, "y": 0 }],
      "required": true
    }
  ],
  "obstacles": [
    {
      "id": "tree1",
      "position": { "x": 2, "y": 2 },
      "size": { "width": 1, "height": 1 },
      "type": "tree"
    }
  ],
  "stalls": [
    {
      "id": "coffee1",
      "name": "晨光咖啡",
      "category": "coffee",
      "size": { "width": 1, "height": 1 },
      "cost": 300,
      "electricity": 3,
      "noise": 20,
      "odor": 30,
      "attraction": 60,
      "incomePerPerson": 15,
      "adjacentRules": []
    }
  ],
  "objectives": [
    {
      "id": "obj1",
      "type": "minIncome",
      "description": "预估收入达到 5000 元",
      "target": 5000,
      "weight": 2
    }
  ],
  "rules": {
    "noiseConflict": {
      "threshold": 80,
      "penalty": -10,
      "affectedCategories": ["children", "handicraft"]
    },
    "odorConflict": {
      "threshold": 70,
      "penalty": -8,
      "affectedCategories": ["coffee", "handicraft"]
    },
    "adjacentBonus": {
      "coffee+handicraft": 15,
      "food+children": 10,
      "band+coffee": 12,
      "handicraft+children": 8
    }
  }
}
```

### 摊位分类

| 分类 | category 值 | 说明 |
|------|---------|------|
| 咖啡饮品 | coffee | 对气味敏感 |
| 热食餐饮 | food | 高噪音、高气味 |
| 手作文创 | handicraft | 对噪音和气味都敏感 |
| 乐队表演 | band | 高噪音 |
| 儿童游乐 | children | 对噪音敏感 |

### 目标类型

| 类型 | type 值 | 说明 |
|------|---------|------|
| 最低收入 | minIncome | 收入 >= target |
| 最高满意度 | maxSatisfaction | 满意度 >= target |
| 最低风险 | minRisk | 风险 <= target |
| 最多摊位 | maxStalls | 已放置摊位 >= target |

## 📄 导出结算报告

游戏支持导出两种格式的结算报告。

### 导出 JSON 报告

1. 点击右侧「导出 JSON」按钮
2. 下载包含完整数据的 JSON 文件

### 导出 Markdown 报告

1. 点击右侧「导出 Markdown」按钮
2. 下载格式化的 Markdown 报告

### 报告内容

报告包含以下信息：
- 基本信息（关卡、时间、已放置摊位数）
- 综合评分（总分、满意度、风险度、预估收入）
- 资源使用情况（预算、电力）
- 目标完成情况
- 摊位详情（位置、客流、收入）
- 冲突警告列表
- 加成奖励列表
- 人流分析

## 📝 开发说明

### 数据存储

- `marketGame_highScores`：各关卡的最高分
- `marketGame_savedLayouts`：保存的布局

### 模块说明

| 模块 | 职责 |
|------|------|
| levelParser.js | 解析和验证关卡 JSON 数据 |
| ruleEngine.js | 计算评分、检测冲突、计算加成 |
| gameState.js | 状态管理、撤销/重做、本地存储 |
| dragDrop.js | 网格渲染、拖拽交互、视觉反馈 |
| exporter.js | 导出 JSON 和 Markdown 报告 |
