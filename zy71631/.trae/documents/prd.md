## 1. 产品概述

声场剧院座位沙盘是一款面向演出团队与扩声工程师的3D可视化工具，用于在剧院排场阶段快速定位不同频段下声压过高或过低的座位区域。系统整合座位坐标、音箱位置、频段采样、观众区划分、调音备注与声场报告等多源数据，以3D热力沙盘为核心交互界面，让扩声问题"看得见、查得清、说得明"。

- 核心用户：扩声工程师、音响总监、演出制作人
- 核心价值：将频段声压分布从纸面数字变为空间直觉，异常频段/遮挡/延时不一致在页面内即可定位与解释

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 扩声工程师 | 直接使用 | 编辑音箱位置、调参数、生成报告 |
| 审核方 | 直接使用 | 查看沙盘、对比方案、导出截图 |

### 2.2 功能模块

1. **沙盘主页**：3D座位沙盘 + 声压热力 + 频段切换 + 对象点选 + 筛选面板 + 异常标注
2. **方案管理页**：扩声方案保存/加载/对比 + 调音备注 + 数据溯源

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 沙盘主页 | 3D座位沙盘 | 可旋转/缩放/平移的3D剧院模型，座位按坐标排列，音箱用图标标示，支持点击选中对象弹出详情卡片 |
| 沙盘主页 | 声压热力层 | 座位颜色映射声压级(dB SPL)，支持连续色阶图例，低→高从深蓝到亮红 |
| 沙盘主页 | 频段切换器 | 顶部频段标签栏（31.5Hz/63Hz/125Hz/250Hz/500Hz/1kHz/2kHz/4kHz/8kHz/16kHz），切换即刻更新热力与异常标注 |
| 沙盘主页 | 对象详情卡片 | 点击座位显示：坐标、所属观众区、各频段声压值、遮挡标记、数据来源；点击音箱显示：位置、型号、延时参数、覆盖范围、关联异常 |
| 沙盘主页 | 筛选面板 | 左侧折叠面板：按观众区筛选、按异常类型筛选（频段错配/座位遮挡/音箱延时反向）、按声压区间筛选 |
| 沙盘主页 | 异常标注层 | 在3D场景中以醒目图标叠加异常座位/音箱，点击图标弹出可读解释（如"座位C12被左前阵列音箱遮挡，2kHz衰减6dB"） |
| 沙盘主页 | 截图导出 | 一键将当前3D视角截图导出为PNG，截图包含图例、频段标识、时间戳 |
| 沙盘主页 | 报告快照 | 生成当前频段声场摘要面板（平均声压、最大/最小值、异常计数），所有数字可点击溯源 |
| 方案管理页 | 方案列表 | 显示已保存方案卡片（名称、时间、频段快照缩略图），支持加载与删除 |
| 方案管理页 | 方案对比 | 双方案并列对比（热力差异图、频段偏差统计），差异值标注数据来源 |
| 方案管理页 | 调音备注 | 每个方案内可添加备注，备注关联到具体座位或音箱对象 |
| 方案管理页 | 报告导出 | 导出完整声场报告（含异常说明、频段表、截图），格式为可打印HTML |

## 3. 核心流程

### 3.1 沙盘分析流程

用户打开沙盘 → 加载剧院模型与座位/音箱数据 → 选择频段 → 观察3D热力分布 → 点击异常标注查看可读解释 → 调整筛选条件缩小范围 → 点击具体座位/音箱查看详情与数据溯源 → 保存当前方案

### 3.2 方案管理流程

用户切换到方案管理 → 查看已保存方案 → 选择两个方案对比差异 → 在差异中点击数字溯源 → 添加调音备注 → 导出报告

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底(#0D1117) + 声压热力色阶（深蓝→青→绿→黄→红），辅以冰蓝高亮(#58A6FF)
- **强调色**：异常标注用亮橙色(#FF8C00)，频段激活用冰蓝(#58A6FF)
- **按钮风格**：微圆角(4px)、扁平面板风格，hover时微微浮起
- **字体**：标题用 Space Grotesk 700，正文用 IBM Plex Sans 400/600，数据用 JetBrains Mono
- **布局**：左侧筛选面板(可折叠) + 中间3D视口(占主空间) + 右侧详情卡片(弹出式) + 顶部频段栏 + 底部报告摘要条
- **图标**：线性图标风格(Lucide)，音箱用扬声器图标，异常用三角警示

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 沙盘主页 | 3D视口 | 深色背景、座位以3D方块排列、音箱以锥形指示器表示、轨道控制器旋转缩放 |
| 沙盘主页 | 频段栏 | 顶部水平标签组，当前频段高亮冰蓝，hover显示频段范围 |
| 沙盘主页 | 热力图例 | 视口左下角垂直色阶条(45-105 dB SPL)，标注关键阈值 |
| 沙盘主页 | 筛选面板 | 左侧深色半透明面板，三组折叠筛选器(观众区/异常类型/声压区间) |
| 沙盘主页 | 详情卡片 | 右侧弹出卡片，深色毛玻璃效果，显示对象属性与数据溯源链接 |
| 沙盘主页 | 异常标注 | 3D空间中浮动三角警示图标，颜色区分类型(橙=遮挡/红=延时反向/紫=频段错配) |
| 沙盘主页 | 报告摘要条 | 底部半透明条，显示关键指标，点击数字弹出溯源 |
| 沙盘主页 | 截图/保存按钮 | 右上角工具栏，图标按钮组 |
| 方案管理页 | 方案卡片网格 | 响应式网格，每卡片含缩略图+名称+时间+备注计数 |
| 方案管理页 | 对比面板 | 双栏并列，差异高亮 |
| 方案管理页 | 报告导出 | 全屏模态，预览可打印报告 |

### 4.3 响应式

- 桌面优先设计，3D视口最小宽度1024px
- 平板：筛选面板默认折叠，详情卡片改为底部抽屉
- 移动端：仅方案列表可用，3D视口提示切换桌面端

### 4.4 3D场景指引

- **环境**：深色剧场空间，微弱环境光模拟暗场
- **灯光**：顶部冷白方向光 + 低强度环境光，让座位热力色清晰可辨
- **相机**：透视相机，默认俯视45°角，可自由旋转，近裁面0.1远裁面500
- **交互**：OrbitControls旋转/缩放/平移，Raycaster点击拾取对象
- **后处理**：可选Bloom效果让高声压区域发光，SSAO增加空间深度感
- **性能**：座位数≤2000时保持60fps，使用InstancedMesh渲染座位
