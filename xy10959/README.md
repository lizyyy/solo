# 渠道线索去重 CLI 工具

一个功能完整的线索去重命令行工具，支持按手机号、邮箱、公司名进行精确和模糊匹配，并提供详细的去重报告。

## 功能特性

- **多维度去重**: 手机号、邮箱精确匹配，公司名模糊匹配
- **来源优先级**: 可配置渠道优先级（展会 > 表单 > 电话）
- **冲突检测**: 自动识别并报告字段冲突
- **合并建议**: 提供字段合并的人工确认建议
- **完整输出**: 
  - 终端摘要显示
  - 机器可读的 JSON 结果
  - 详细的 Markdown 报告
  - 清洗后的 CSV 数据
  - 重复组详情 CSV
  - 错误行保留 CSV

## 安装

```bash
npm install
```

## 使用方法

### 基本用法

```bash
node cli.js -i <输入CSV文件> -o <输出目录>
```

### 参数说明

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `-i, --input` | 输入CSV文件路径（必需） | - |
| `-o, --output` | 输出目录 | `./output` |
| `-p, --priority` | 来源优先级，逗号分隔 | `展会,表单,电话` |
| `-t, --threshold` | 模糊匹配阈值 (0-1) | `0.85` |
| `-k, --keep-all` | 保留所有重复记录，只标记组号 | `false` |

### 示例

```bash
# 基本用法
node cli.js -i test-leads.csv -o ./results

# 自定义优先级和阈值
node cli.js -i leads.csv -o output -p "电话,展会,表单" -t 0.9

# 保留所有记录，只标记重复组
node cli.js -i leads.csv -o output -k
```

## 输入CSV格式要求

必需字段：
- `手机号`: 联系人电话
- `邮箱`: 邮箱地址
- `公司名`: 公司名称
- `来源渠道`: 数据来源（如：展会、表单、电话）

其他字段会被保留并一同输出。

## 输出文件说明

| 文件名 | 说明 |
|--------|------|
| `cleaned-leads.csv` | 去重后的线索数据，可直接使用 |
| `duplicate-groups.csv` | 所有重复组的详细信息 |
| `deduplication-results.json` | 机器可读的完整处理结果 |
| `deduplication-report.md` | 给同事查看的详细报告 |
| `error-rows.csv` | 无法处理的坏行，保留原始位置 |

## 去重规则说明

1. **精确匹配**: 手机号或邮箱完全相同
2. **链式匹配**: A与B手机号相同，B与C邮箱相同，则A、B、C为一组
3. **模糊匹配**: 公司名相似度超过阈值（默认0.85），且无邮箱冲突
4. **优先级选择**: 同一组内按来源优先级保留记录
5. **冲突报告**: 字段值不一致时生成冲突报告和合并建议

## 常见问题

**Q: 如何处理手机号格式不一致？**
A: 系统会自动清洗手机号，去除非数字字符后进行匹配。

**Q: 公司名如何处理？**
A: 去除"有限公司"、"集团"等后缀，去除括号内容后进行模糊匹配。

**Q: 坏行会被丢弃吗？**
A: 不会，所有错误行都会保留在 `error-rows.csv` 中，包含原始行号和问题描述。
