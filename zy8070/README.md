# 直播导播单整理工具

本地桌面应用，用于直播运营在开播前整理导播单。

## 功能特性

- **数据导入**: 支持 CSV 直播场次、JSON 商品素材、txt 禁用词
- **时间轴预览**: 按时间顺序显示环节、提词卡、商品卡
- **问题检测**:
  - 时间重叠或格式错误
  - 商品缺少图片
  - 商品缺少优惠价
  - 口播踩禁用词
- **彩排备注**: 每个环节可写备注，数据持久化存储
- **导出功能**: 支持 Markdown 导播单和问题 CSV 导出

## 环境要求

- Python 3.8+
- PyQt5
- pandas

## 安装步骤

```bash
pip install PyQt5 pandas
```

## 运行方式

```bash
python main.py
```

## 使用流程

1. 点击「导入直播场次 CSV」导入场次数据
2. 点击「导入商品素材 JSON」导入商品信息
3. 点击「导入禁用词 txt」导入禁用词库 (可选)
4. 点击「检测问题」分析数据问题
5. 点击表格行查看详情
6. 在备注区填写彩排备注 (自动保存)
7. 点击「导出 Markdown」或「导出问题 CSV」导出结果

## 样本数据

sample_data 目录包含测试数据:

- `sessions.csv` - 6 个环节的直播场次
- `products.json` - 5 个商品 (其中有缺图、缺价格问题)
- `banned_words.txt` - 16 个禁用词

## 数据格式说明

### CSV 场次格式

| 列名 | 说明 | 示例 |
|------|------|------|
| 环节名称 | 环节标题 | 开场预热 |
| 开始时间 | HH:MM:SS 格式 | 19:00:00 |
| 结束时间 | HH:MM:SS 格式 | 19:05:00 |
| 提词卡 | 环节话术 | 欢迎来到直播间 |

### JSON 商品格式

```json
[
    {
        "环节ID": 0,
        "商品名称": "商品A",
        "优惠价": "99.00",
        "图片路径": "images/a.png",
        "口播脚本": "口播内容"
    }
]
```

## 边界情况处理

- 空文件: 抛出明确错误提示
- 时间格式错误: 支持多种格式，自动检测
- 缺少必要列: 提示具体缺少哪些列
- 备注持久化: 保存在 data/notes.json
