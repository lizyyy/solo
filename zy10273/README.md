# 二手家电上门检测台

一个完整的二手家电上门检测与结算管理系统。

## 功能特性

### 1. 预约管理
- 创建新预约（客户信息、家电信息、预约时间、预估价格）
- 预约列表查看与搜索
- 防重复预约校验（同一客户同一型号家电不能重复预约）

### 2. 检测流程
- 开始检测（标记师傅到达）
- 检测项填写（外观、遥控器、电源线、功能测试等）
- 照片占位（预留上传功能）
- 完成检测并填写实际价格

### 3. 改价审批
- 申请改价（填写改价原因）
- 审批流程（通过/驳回，填写审批意见）
- 改价历史记录查看

### 4. 拒收处理
- 填写拒收原因
- 拒收记录留痕

### 5. 结算管理
- 检测完成后才能结算
- 存在待审批改价时不能结算
- 已拒收订单不能结算
- 多种支付方式支持
- 导出结算报表（CSV格式）

### 6. 工作台与异常处理
- 统计面板（总预约、待审批、已结算、总收入）
- 异常提醒（检测超过3天未结算、待审批改价、重复预约等）
- 最近预约快速查看
- 状态分布图

### 7. 操作日志
- 完整记录所有操作
- 可追溯的操作历史

## 业务规则保障

1. **检测未完成不能结算** - 必须完成所有检测项才能进入结算流程
2. **改价必须审批** - 改价申请审批通过后才能结算
3. **拒收后不生成付款** - 已拒收订单无法结算
4. **同一机器不能重复预约** - 防重复预约校验
5. **导入/提交去重** - 数据持久化时自动去重

## 技术栈

- React 18
- TypeScript
- Vite
- Zustand（状态管理）
- Tailwind CSS
- React Router
- lucide-react（图标）

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```
