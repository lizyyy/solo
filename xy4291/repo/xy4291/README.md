# 夜班分诊风暴 - 急诊科新护士训练游戏

## 项目简介

"夜班分诊风暴"是一款专为急诊科新护士设计的本地训练小游戏，旨在帮助护士在模拟环境中练习分诊技能，提高应对紧急情况的能力。

## 功能特性

### 核心功能
- **数据导入**：支持导入CSV（病人信息）、JSON（生命体征）、YAML（床位/医生排班）格式的数据
- **实时计时**：10分钟倒计时，模拟真实夜班交班前的紧张场景
- **拖拽分诊**：将病人拖到抢救、留观、转诊或等待区
- **智能评分**：按分诊规则实时扣分/预警
- **动态模拟**：模拟病情恶化、床位占用和医生疲劳
- **决策回放**：游戏结束后可回放关键决策
- **数据导出**：支持导出Markdown复盘报告和CSV错分清单

### 游戏特色
- 四级分诊系统：抢救区(1级)、留观区(2级)、转诊区(3级)、等待区(4级)
- 基于真实医疗标准的分诊规则引擎
- 优先级加分机制：紧急病人正确分诊获得更多分数
- 病情恶化模拟：等待区病人可能随时间病情加重
- 床位管理：各区域床位有限，需合理分配

## 安装说明

### 环境要求
- Node.js 14.0 或更高版本
- npm 6.0 或更高版本

### 安装步骤
1. 克隆项目到本地
2. 进入项目目录
3. 安装依赖：
```bash
npm install
```

4. 启动服务器：
```bash
npm start
```

5. 在浏览器中打开 http://localhost:3000

## 游戏玩法

### 开始游戏
1. 在开始界面点击"开始游戏"按钮
2. 系统会自动加载示例数据（或您自定义的数据）
3. 游戏开始，10分钟倒计时启动

### 分诊操作
1. 在左侧"待分诊病人"区域选择一个病人卡片
2. 拖拽病人卡片到右侧的分诊区域：
   - **抢救区(红)**：紧急生命危险情况
   - **留观区(橙)**：需要进一步观察治疗
   - **转诊区(绿)**：需要转往其他科室
   - **等待区(蓝)**：病情稳定，可以等待

3. 系统会自动评估您的分诊决策：
   - 正确分诊：获得分数（基础分100分 + 优先级加分）
   - 错误分诊：扣除分数（基础分50分 + 优先级扣分），并增加预警次数

### 游戏结束
游戏结束条件：
- 所有病人都已分诊
- 倒计时结束

游戏结束后，您可以：
- 查看成绩总结（分数、准确率、预警次数、用时）
- 回放决策过程
- 导出Markdown复盘报告
- 导出CSV错分清单
- 保存游戏记录

### 查看存档
1. 在开始界面点击"查看存档"按钮
2. 查看所有已保存的游戏记录
3. 可以加载或删除存档

## 数据格式说明

### 病人数据 (CSV)
文件路径：`data/patients.csv`

字段说明：
- `id`：病人唯一标识符
- `name`：病人姓名
- `age`：年龄
- `gender`：性别
- `complaint`：主诉
- `department`：科室
- `arrivalTime`：到达时间

示例：
```csv
id,name,age,gender,complaint,department,arrivalTime
P001,张三,65,男,胸痛伴呼吸困难,急诊科,00:15
P002,李四,45,女,严重腹痛伴呕吐,急诊科,00:20
```

### 生命体征数据 (JSON)
文件路径：`data/vitals.json`

字段说明（每个病人ID对应一个对象）：
- `heartRate`：心率（次/分）
- `respiratoryRate`：呼吸频率（次/分）
- `systolicBP`：收缩压（mmHg）
- `diastolicBP`：舒张压（mmHg）
- `temperature`：体温（°C）
- `oxygenSaturation`：血氧饱和度（%）
- `glasgowComaScale`：格拉斯哥昏迷评分

示例：
```json
{
  "P001": {
    "heartRate": 110,
    "respiratoryRate": 32,
    "systolicBP": 100,
    "diastolicBP": 60,
    "temperature": 37.2,
    "oxygenSaturation": 88,
    "glasgowComaScale": 14
  }
}
```

### 床位/医生排班 (YAML)
文件路径：`data/schedule.yaml`

字段说明：
- `zones`：各区域配置
  - `beds`：床位数
  - `doctors`：医生数
  - `nurses`：护士数
  - `description`：区域描述
- `onCallDoctors`：值班医生信息
- `availableDepartments`：可用科室列表

示例：
```yaml
zones:
  emergency:
    beds: 5
    doctors: 2
    nurses: 4
    description: "抢救区 - 用于处理紧急生命危险情况"

onCallDoctors:
  - id: D001
    name: 张医生
    specialty: 急诊科
    zone: emergency
```

## 分诊规则引擎

### 1级 - 抢救区（紧急生命危险）
触发条件：
- 呼吸骤停或心跳骤停（心率=0 或 呼吸=0）
- 严重呼吸急促（>30次/分）或过缓（<8次/分）
- 严重心动过速（>180次/分）或过缓（<40次/分）
- 严重低血压（收缩压<70mmHg）
- 意识不清（格拉斯哥评分<9）
- 严重缺氧（血氧<90%）
- 严重主诉：胸痛、呼吸困难、意识不清、严重出血、过敏性休克、抽搐

### 2级 - 留观区（需要进一步观察）
触发条件：
- 中度呼吸急促（21-30次/分）
- 中度心动过速（101-180次/分）
- 中度低血压（70-89mmHg）
- 中度高血压（>180mmHg）
- 中度缺氧（90-94%）
- 发热（>38.5°C）
- 中度主诉：腹痛、呕吐、头痛、外伤、发热、咳嗽

### 3级 - 转诊区（需要转往其他科室）
触发条件：
- 专科主诉：骨折、烧伤、眼科急诊、耳鼻喉急诊、妇产科急诊、精神科急诊
- 非急诊科科室转诊
- 生命体征稳定但需要专科处理

### 4级 - 等待区（病情稳定）
触发条件：
- 生命体征稳定
- 无紧急或严重主诉
- 不需要立即处理

## 评分系统

### 正确分诊得分
- 基础分：100分
- 优先级加分：
  - 1级（抢救区）：+80分
  - 2级（留观区）：+60分
  - 3级（转诊区）：+40分
  - 4级（等待区）：+20分

### 错误分诊扣分
- 基础分：50分
- 优先级扣分：
  - 1级病人错误分诊：+40分
  - 2级病人错误分诊：+30分
  - 3级病人错误分诊：+20分
  - 4级病人错误分诊：+10分
