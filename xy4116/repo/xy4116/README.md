# 无线麦频率彩排台

专为小剧场音响师设计的本地桌面GUI工具，用于无线麦克风频率规划和风险检测。

## 功能特点

- 🎤 **麦克风清单管理** - 管理演员、设备ID、频率、电量、备用频率等信息
- 📅 **时间走位表** - 按场景时间线安排麦克风使用
- 🚫 **禁用频段** - 设置禁止使用的频率范围（如对讲机、广播电台）
- 📻 **频道配置** - 管理可用频道资源
- 🔍 **风险检测** - 自动检测以下问题：
  - 频率间隔不足
  - 三阶互调干扰
  - 频率落在禁用频段
  - 设备电量不足
  - 缺少备用频率
  - 重叠场景/换场冲突
- 💾 **本地保存** - 方案保存到本地，数据不联网
- 📄 **报告导出** - 导出Markdown彩排报告和CSV风险清单

## 验证流程

### 1. 基础功能验证

1. **启动程序**：运行 `python main.py`，应看到主窗口
2. **加载示例方案**：
   - 点击菜单 `文件` → `加载示例方案`
   - 确认麦克风清单、时间表、禁用频段都有数据
3. **执行风险检查**：
   - 点击顶部的 `🔍 执行风险检查` 按钮
   - 应自动跳转到「风险检测」标签页
   - 应看到多个风险项（示例数据故意设置了问题）
4. **查看风险详情**：
   - 检查风险等级显示（🔴严重、🟠高、🟡中、🟢低）
   - 确认风险类型正确识别

### 2. 数据编辑验证

1. **编辑麦克风**：
   - 切换到「麦克风清单」标签
   - 双击任意单元格修改数据
   - 点击 `➕ 添加` 按钮添加新行
   - 选中一行点击 `➖ 删除选中` 删除
2. **编辑时间表**：
   - 切换到「时间走位表」标签
   - 编辑场景名称、时间格式（HH:MM）
   - 演员名单用逗号分隔
3. **重新检查**：
   - 再次点击「执行风险检查」
   - 确认风险列表随数据变化

### 3. 导入导出验证

1. **导出Markdown报告**：
   - 菜单 `文件` → `导出` → `导出Markdown报告...`
   - 选择保存位置，保存为 `.md` 文件
   - 用文本编辑器打开，确认包含：
     - 项目概览
     - 风险摘要表格
     - 麦克风配置表
     - 时间走位表
     - 风险详情

2. **导出风险清单CSV**：
   - 菜单 `文件` → `导出` → `导出风险清单CSV...`
   - 保存后用Excel或表格软件打开
   - 确认列：序号、风险等级、风险类型、状态、影响演员等

### 4. 持久化验证

1. **保存方案**：
   - 菜单 `文件` → `保存方案` 或 `Ctrl+S`
   - 选择保存位置，生成 `.micplan` 文件
2. **新建方案**：
   - 菜单 `文件` → `新建方案` 或 `Ctrl+N`
   - 确认所有表格被清空
3. **打开方案**：
   - 菜单 `文件` → `打开方案` 或 `Ctrl+O`
   - 选择之前保存的 `.micplan` 文件
   - 确认数据完整恢复

## CSV导入格式

程序支持从CSV文件导入数据，支持中英文列名。

### 麦克风清单CSV

支持的列名：
- `device_id` 或 `设备ID`
- `actor_name` 或 `演员姓名` 或 `演员`
- `frequency` 或 `频率` (MHz)
- `channel` 或 `频道`
- `battery_level` 或 `电量` (%)
- `backup_frequency` 或 `备用频率`
- `backup_channel` 或 `备用频道`
- `notes` 或 `备注`

示例：
```csv
device_id,actor_name,frequency,channel,battery_level,backup_frequency,backup_channel
MIC-001,王利发,640.1,CH-01,85,650.5,CH-10
MIC-002,秦仲义,640.3,CH-02,92,650.8,CH-11
```

### 时间走位表CSV

支持的列名：
- `scene_name` 或 `场景名称` 或 `场景`
- `start_time` 或 `开始时间` (格式: HH:MM 或 HH:MM:SS)
- `end_time` 或 `结束时间`
- `actor_names` 或 `演员名单` 或 `演员` (逗号分隔)
- `notes` 或 `备注`

示例：
```csv
scene_name,start_time,end_time,actor_names,notes
第一幕：开场,19:00:00,19:20:00,王利发,秦仲义,常四爷,茶馆开业
第一幕：冲突,19:15:00,19:35:00,常四爷,松二爷,唐铁嘴,注意时间重叠
```

### 禁用频段CSV

支持的列名：
- `name` 或 `频段名称` 或 `名称`
- `start_freq` 或 `起始频率` (MHz)
- `end_freq` 或 `结束频率` (MHz)
- `reason` 或 `原因`

示例：
```csv
name,start_freq,end_freq,reason
对讲机频段,640.0,640.5,剧组对讲机使用
广播电台,655.0,656.0,本地FM电台
```

### 频道配置CSV

支持的列名：
- `channel_name` 或 `频道名称` 或 `频道`
- `center_freq` 或 `中心频率` 或 `频率` (MHz)
- `bandwidth` 或 `带宽` (MHz, 默认0.2)
- `is_available` 或 `可用` (True/False 或 是/否)

示例：
```csv
channel_name,center_freq,bandwidth,is_available
CH-01,640.1,0.2,False
CH-02,640.3,0.2,False
CH-07,645.0,0.2,True
```

## 风险检测规则说明

### 1. 频率间隔检查
- **安全间隔**：默认 0.3 MHz
- **严重风险**：间隔 < 0.1 MHz
- **高风险**：0.1 MHz ≤ 间隔 < 0.3 MHz

### 2. 三阶互调干扰检测
- 检测公式：`2f1 - f2` 和 `2f2 - f1`
- 当计算结果与第三个麦克风频率接近（±0.05 MHz）时触发风险

### 3. 禁用频段检查
- 检测麦克风频率是否完全落在任何禁用频段内
- 触发严重风险，必须调整

### 4. 电量检查
- **严重风险**：电量 < 15%
- **高风险**：15% ≤ 电量 < 30%

### 5. 备用通道检查
- 麦克风未设置备用频率 → 中等风险
- 可用通道数 < 主麦克风数 + 2 → 高风险

### 6. 时间线冲突检查
- 重叠场景中的频率间隔检查
- 换场期间的频道占用冲突
- 同一麦克风同时出现在重叠场景

## 常见问题

**Q: 程序保存的方案文件在哪里？**
A: 默认保存到用户目录下的 `无线麦频率彩排台/rehearsal_plans` 文件夹，也可以自己选择保存位置。

**Q: 为什么有些风险显示为红色背景？**
A: 红色背景表示「严重」或「高」风险等级，建议优先处理。

**Q: 如何标记风险为已解决？**
A: 在「风险检测」标签页选中一行或多行，点击 `✅ 标记已解决` 按钮。

**Q: 支持哪些无线麦克风系统？**
A: 本工具是通用的频率规划工具，不绑定特定品牌。只要输入频率值（MHz），就能进行检测。
