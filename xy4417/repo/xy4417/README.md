# 沙盘铁路系统分析工具

一个用于沙盘火车模型社的本地工具，用于在布展前分析铁路系统的电压衰减、电源过载和调度冲突问题。

## 功能特性

- **电压衰减分析**：计算各钢轨分段在不同列车编组下的电压衰减，识别超出阈值的区段
- **电源过载分析**：根据电源额定功率和列车编组总功耗，判断电源是否会过载
- **调度冲突检测**：检测同时运行的列车是否在同一时间段内使用相同的区段
- **可视化线路图**：SVG 绘制线路图，直观展示各区段状态
- **复核记录**：手动标记已调整的区段，保存复核记录
- **数据导出**：支持导出 Markdown 排查单和 JSON 审计包
- **数据导入**：支持导入 JSON 数据创建新项目

## 安装与运行

### 环境要求

- Python 3.7+
- pip

### 安装步骤

1. 安装 Python 依赖：

```bash
cd backend
pip install -r requirements.txt
```

2. 启动后端服务：

```bash
cd backend
python app.py
```

3. 打开浏览器访问：

```
http://localhost:5000
```

## 使用指南

### 1. 创建新项目

1. 点击"新建项目"按钮
2. 输入项目名称
3. 选择是否使用示例数据（推荐选择"是"以快速体验）
4. 点击"创建"

### 2. 编辑数据

1. 点击左侧"编辑数据"按钮
2. 在弹出的对话框中添加或编辑以下数据：
   - **钢轨分段**：区段 ID、名称、长度、关联的馈电点 ID
   - **馈电点**：馈电点 ID、名称、关联的电源 ID、位置
   - **列车编组**：编组 ID、名称、功率(W)
   - **电源**：电源 ID、名称、额定功率(W)、电压(V)

### 3. 执行计算

1. 点击左侧"执行计算"按钮
2. 系统将自动计算：
   - 各区段的电压衰减
   - 各电源的负载情况
   - 调度冲突（如已配置路线）

### 4. 查看结果

- **线路图**：可视化展示各区段状态（蓝色=正常，橙色=电压衰减，绿色=已调整）
- **风险列表**：详细列出所有问题区段、过载电源和调度冲突
- **复核记录**：查看历史复核记录
- **详细数据**：查看所有配置数据的表格

### 5. 标记已调整

1. 在"风险列表"标签页
2. 找到问题区段
3. 点击"标记已调整"按钮
4. 区段状态变为绿色

### 6. 添加复核记录

1. 点击左侧"添加复核记录"按钮
2. 输入备注信息
3. 勾选已调整的区段
4. 点击"保存"

### 7. 导出数据

- **导出排查单**：点击顶部"导出排查单"按钮，下载 Markdown 格式的排查报告
- **导出审计包**：点击顶部"导出审计包"按钮，下载完整的 JSON 数据（含计算结果和复核记录）

### 8. 导入数据

1. 点击顶部"导入数据"按钮
2. 粘贴 JSON 格式的数据
3. 点击"导入"创建新项目

| 字段 | 类型 | 描述 |
|------|------|------|

| name | string | 编组名称 |
| power | number | 功率（瓦特） |

| 字段 | 类型 | 描述 |
|------|------|------|
| id | string | 唯一标识符 |
| name | string | 电源名称 |
| max_power | number | 额定功率（瓦特） |
| voltage | number | 输出电压（伏特） |
| description | string | 描述（可选） |

### 运行路线 (Route) - 可选

| 字段 | 类型 | 描述 |
|------|------|------|
| id | string | 唯一标识符 |
| name | string | 路线名称 |
| sections | array | 经过的区段 ID 列表 |
| start_time | number | 开始时间（分钟） |
| end_time | number | 结束时间（分钟） |
| description | string | 描述（可选） |

| 字段 | 类型 | 默认值 | 描述 |
|------|------|--------|------|
| voltage_threshold | number | 0.9 | 电压衰减阈值（电压比低于此值视为问题） |
| wire_resistance_per_meter | number | 0.01 | 每米导线电阻（欧姆） |

## 计算逻辑

### 电压衰减计算

```
导线电阻 = 区段长度 × 每米电阻
电流 = 列车功率 / 电源电压
电压降 = 电流 × 导线电阻
电压比 = (电源电压 - 电压降) / 电源电压
```

如果电压比 < 电压阈值（默认 90%），则标记为电压衰减问题。

### 电源过载计算

```
总需求功率 = 所有列车编组功率之和
功率比 = 总需求功率 / 电源额定功率
```

如果总需求功率 > 电源额定功率，则标记为电源过载。

### 调度冲突检测

检查任意两条路线是否满足以下条件：
1. 经过相同的区段
2. 运行时间段有重叠

如果同时满足，则标记为调度冲突。

## API 接口

### 项目管理

- `GET /api/projects` - 获取所有项目列表
- `POST /api/projects` - 创建新项目
- `GET /api/projects/<id>` - 获取单个项目详情
- `PUT /api/projects/<id>` - 更新项目数据

- `POST /api/projects/<id>/calculate` - 执行计算分析

### 复核记录

- `POST /api/projects/<id>/review` - 添加复核记录
- `GET /api/projects/<id>/reviews` - 获取复核记录列表

### 数据导出

- `GET /api/projects/<id>/export/markdown` - 导出 Markdown 排查单
- `GET /api/projects/<id>/export/json` - 导出 JSON 审计包

## 示例数据

项目包含示例数据，创建项目时选择"使用示例数据"即可体验：

- **5 个钢轨分段**：形成环形铁路
- **3 个馈电点**：连接到 2 台电源
- **3 个列车编组**：不同功率的列车
- **2 台电源**：主电源和备用电源

示例数据设计用于演示电压衰减和电源过载问题：
- 长区段（如"北环线-东站"80米）在大功率列车运行时会产生电压衰减
- 总需求功率（95W）可能超过备用电源（50W）

## 注意事项

1. **数据关联**：区段的 `feed_point_id` 必须对应已存在的馈电点 ID；馈电点的 `power_supply_id` 必须对应已存在的电源 ID。

2. **调度冲突**：如需使用调度冲突检测功能，需要手动在数据中添加 `routes` 字段。

3. **数据持久化**：所有数据保存在 `backend/data/railway.db` SQLite 数据库中，刷新页面数据不会丢失。

4. **本地使用**：本工具设计为本地使用，不建议在公开网络环境部署。

## 故障排除

### 后端无法启动

- 检查 Python 版本是否 >= 3.7
- 检查是否已安装依赖：`pip install -r requirements.txt`
- 检查端口 5000 是否被占用

### 前端无法连接后端

- 确认后端服务已启动
- 检查浏览器控制台是否有 CORS 错误
- 确认访问地址为 `http://localhost:5000` 而非其他端口

### 计算结果不正确

- 检查数据关联是否正确
- 检查功率单位是否为瓦特(W)
- 检查长度单位是否为米(m)
