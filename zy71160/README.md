# ♻️ 回收分拣产线游戏

一款面向环保课堂教育的垃圾分类分拣模拟器游戏，通过游戏化方式学习真实的垃圾分类规则。

## 🚀 快速开始

### 环境要求
- Node.js >= 16.0.0
- npm 或 pnpm

### 安装依赖
```bash
npm install
```

### 启动开发服务器
```bash
npm run dev
```

### 构建生产版本
```bash
npm run build
```

### 预览生产版本
```bash
npm run preview
```

## 🎮 玩法说明

### 基本操作
1. **选择关卡**：在开始界面选择难度关卡
2. **拖拽分拣**：用鼠标（或触摸）按住传送带上的物品，拖动到下方对应的分类桶中
3. **正确分类**：物品放入正确的桶中获得分数
4. **错误分类**：放入错误的桶会扣分并重置连击

### 游戏元素

| 标记 | 说明 | 注意事项 |
|------|------|----------|
| 🔴 红色感叹号 | 危险品 | 漏拦会有严重扣分惩罚 |
| 💧 黄色水滴 | 污染物 | 需要特别注意辨别分类 |
| 🔥 连击数 | 连续正确 | 连击越高，每道题额外加分越多 |

### 分类说明

| 分类桶 | 颜色 | 包含物品示例 |
|--------|------|--------------|
| ♻️ 可回收物 | 蓝色 | 塑料瓶、纸张、易拉罐、玻璃瓶 |
| ☠️ 有害垃圾 | 红色 | 电池、药品、灯泡、油漆桶 |
| 🍂 厨余垃圾 | 绿色 | 苹果核、鱼骨、菜叶、蛋壳 |
| 🗑️ 其他垃圾 | 灰色 | 烟蒂、卫生纸、碎陶瓷、口罩 |

## 📊 关卡说明

### 关卡1：新手培训 🎓
- **难度**：简单
- **物品数量**：15个
- **传送带速度**：x1.0
- **物品种类**：可回收物、厨余垃圾、其他垃圾
- **通关要求**：正确率 >= 70%
- **适合人群**：初学者，熟悉基本操作

### 关卡2：正式上岗 👷
- **难度**：中等
- **物品数量**：25个
- **传送带速度**：x1.5
- **物品种类**：全部4类（含有害垃圾）
- **通关要求**：正确率 >= 80%
- **特点**：开始出现危险品，需要更加谨慎

### 关卡3：分拣大师 🏆
- **难度**：困难
- **物品数量**：40个
- **传送带速度**：x2.2
- **物品种类**：全部4类
- **通关要求**：正确率 >= 85%
- **特点**：高速分拣，考验反应力和判断力，危险品频繁出现

## 📈 计分规则

### 加分规则
- **基础分**：每个物品本身的分数（10-28分不等）
- **连击加成**：`连击数 × 0.1 × 基础分`
  - 例：5连击时，基础分10分的物品额外获得5分

### 扣分规则
- **错误分类**：`基础分 × 1.5`
- **危险品错误分类**：额外扣除 `基础分 × 3`
- **漏分拣**：不计分但计入错误统计

## 📋 结算报告

游戏结束后会生成详细的结算报告，包含：
- 最终得分和星级评价
- 正确率统计
- 最高连击记录
- 正确/错误/漏分拣数量
- 所有错误记录的详细信息
- 支持导出 PDF 格式报告

## 🔍 错误回放

在结算界面可以：
1. 查看所有错误记录的列表
2. 点击任意错误进行回放
3. 支持上一条/下一条切换
4. 了解每种错误的原因：
   - 分类错误：放入了错误的桶
   - 漏分拣：物品从传送带末端滑走
   - 危险品漏拦：危险品未被正确分拣

## ⚠️ 边界案例

### 案例1：拖拽时松手位置不准确
- **问题**：拖拽物品时，松手位置不在分类桶区域内
- **处理**：物品会自动回到传送带继续移动，可以再次拖拽

### 案例2：物品重叠时的拖拽
- **问题**：多个物品在传送带上重叠
- **处理**：点击最上层的物品进行拖拽，不会影响其他物品

### 案例3：暂停时的状态保留
- **问题**：游戏暂停后继续
- **处理**：所有物品位置、分数、连击数完全保留

### 案例4：危险品漏拦的惩罚
- **问题**：危险品（如电池）从传送带滑走
- **处理**：记录为"危险品漏拦"，在结算报告中特殊标记

### 案例5：快速连续操作
- **问题**：在一个物品还没完成分拣时，快速拖拽另一个物品
- **处理**：支持同时拖拽，每个物品独立计算分类结果

### 案例6：浏览器窗口大小变化
- **问题**：游戏过程中调整浏览器窗口
- **处理**：传送带宽度自动调整，物品位置重新计算

### 案例7：刷新页面或重新进入
- **问题**：游戏中途刷新页面
- **处理**：游戏状态重置，需要重新开始，但最高分记录会保留
