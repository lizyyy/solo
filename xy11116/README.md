# 烘焙工坊烘焙配方换算工具

专业的烘焙配方批量换算CLI工具，支持克/公斤单位自动转换、半份订单分离输出、机器可读JSON输出等核心业务功能。

## 功能特性

- ✅ **真实业务字段**: 完整保留烘焙工坊关键业务列（配方名称、产品编码、原料编码等）
- ✅ **稳定输出顺序**: 按固定列序输出，方便后续diff比对
- ✅ **单位自动转换**: 智能处理克/公斤混用情况，自动归一化计算
- ✅ **半份订单分离**: 半份订单结果独立输出到带时间戳的文件，不混入正常结果
- ✅ **双格式输出**: 同时支持人类友好汇总 + 机器可读JSON输出
- ✅ **可复跑安全**: 异常记录带时间戳命名，重复运行不会覆盖正常结果

## 快速开始

### 安装依赖

```bash
npm install
npm link
```

### 基本用法

```bash
烘焙工坊烘焙配方换算 samples/烘焙配方_输入.csv
```

### 常用选项

| 选项 | 说明 | 默认值 |
|------|------|--------|
| `--scale <比例>` | 配方换算比例 | 1.0 |
| `--portions <份数>` | 订单份数 | 1 |
| `--output <目录>` | 输出目录 | ./output |
| `--json` | 输出机器可读JSON | - |
| `--summary` | 仅显示汇总信息 | - |
| `--help, -h` | 显示帮助 | - |

## 完整示例

### 1. 正常换算（2倍比例）

```bash
烘焙工坊烘焙配方换算 samples/烘焙配方_输入.csv --scale 2
```

**输出文件:**
- `output/烘焙配方_输入_normal.csv` - 正常换算结果
- `output/烘焙配方_输入_单位混用_YYYY-MM-DD-HH-MM-SS-SSS.csv` - 原始单位为公斤的记录
- `output/烘焙配方_输入_汇总.json` - 汇总数据

### 2. 半份订单换算（自动分离）

```bash
烘焙工坊烘焙配方换算 samples/烘焙配方_输入.csv --portions 0.5
```

**输出文件:**
- `output/烘焙配方_输入_半份订单_YYYY-MM-DD-HH-MM-SS-SSS.csv` - 半份订单独立文件
- `output/烘焙配方_输入_单位混用_*.csv` - 单位混用记录
- `output/烘焙配方_输入_汇总.json`

### 3. 机器可读JSON输出

```bash
烘焙工坊烘焙配方换算 samples/烘焙配方_输入.csv --scale 3 --json
```

### 4. 仅查看汇总

```bash
烘焙工坊烘焙配方换算 samples/烘焙配方_输入.csv --summary
```

## 输入文件格式

CSV文件需包含以下列（顺序可任意）：

| 列名 | 必填 | 说明 |
|------|------|------|
| 配方名称 | ✅ | 如"法式牛角面包" |
| 产品编码 | ✅ | 如"BP-CRO-001" |
| 原料名称 | ✅ | 如"高筋面粉" |
| 原料编码 | ✅ | 如"FLR-001" |
| 基准用量 | ✅ | 数值 |
| 基准单位 | ✅ | 克/公斤/g/kg |
| 备注 | ⬜ | 备注信息 |

参见: [samples/烘焙配方_输入.csv](samples/烘焙配方_输入.csv)

## 输出列顺序（固定）

```
1. 配方名称
2. 产品编码
3. 原料名称
4. 原料编码
5. 基准用量
6. 基准单位
7. 换算比例
8. 换算后用量
9. 换算后单位
10. 订单份数
11. 备注
```

## 业务规则

### 单位处理
- 输入支持：克、g、公斤、kg、千克
- 内部统一转为克计算
- 输出 >= 1000克时自动转为公斤显示

### 半份订单判定
- 份数 = 0.5
- 份数 < 1 且非整数

### 文件命名规则
- 正常结果: `{文件名}_normal.csv`
- 半份订单: `{文件名}_半份订单_{时间戳}.csv`
- 单位混用: `{文件名}_单位混用_{时间戳}.csv`
