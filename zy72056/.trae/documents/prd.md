## 1. 产品概述

为运维工程师何工打造的"地铁站厅拥堵热力"轻量工具，核心解决 GIS 底图中设备点位、照片、备注等材料对不上的问题。通过 Three.js 渲染站厅热力图，实现点选-筛选-时间轴-侧边面板四维同步，保留原始"乱备注"不清洗，让数据质量判断过程全程可追溯。

- 目标用户：地铁站厅运维工程师（单人操作为主，偶尔交接）
- 核心价值：消除 GIS 底图材料手工二次核对，判断过程留痕可审计，增量补录有据可查

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 运维工程师 | 打开页面直接使用 | 全部操作权限（查看、筛选、标注、导出） |
| 交接人员 | 接收审计日志 | 只读查看判断记录和导出截图 |

### 2.2 功能模块

1. **站厅热力图主页面**：GIS 底图 + 热力渲染 + 点位叠加 + 交互面板
2. **数据质量看板（侧边面板内）**：异常分类提示、补录差异展示

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 站厅热力图主页面 | GIS 底图层 | 加载站厅平面 SVG/GeoJSON 底图，保留原始备注文字 |
| 站厅热力图主页面 | 热力渲染层 | Three.js 渲染拥堵热力，颜色从蓝→绿→黄→红映射拥挤度 |
| 站厅热力图主页面 | 设备点位层 | 叠加设备标记点，可点选查看详情 |
| 站厅热力图主页面 | 时间轴组件 | 底部时间轴，拖动切换时段热力数据 |
| 站厅热力图主页面 | 筛选器面板 | 顶部/左侧筛选：楼层、设备类型、数据质量状态 |
| 站厅热力图主页面 | 侧边说明面板 | 右侧面板：选中点位详情、原始备注、照片、数据质量标记 |
| 站厅热力图主页面 | 截图导出 | 导出带筛选条件水印的截图（PNG） |
| 站厅热力图主页面 | 审计日志 | 底部可展开面板，记录每次筛选/标注/补录操作 |
| 站厅热力图主页面 | 增量补录 | 侧边面板内补录备注，展示与上次数据的差异 |

## 3. 核心流程

运维工程师打开页面 → 加载站厅数据（含原始乱备注） → 浏览热力图，筛选楼层/设备类型 → 点选异常点位 → 侧边面板展示详情（含数据质量标记：坐标偏移/重名/缺照片/跨楼层） → 标注判断 → 补录备注 → 导出带条件截图 → 审计日志记录全过程

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深灰 #1A1A2E + 工业蓝 #16213E + 热力橙红 #E94560
- 辅色：数据质量标记用 暖黄 #F0A500（警告）、灰紫 #6C63FF（信息）、红 #FF4444（异常）
- 按钮风格：圆角 6px，半透明底 + 边框，hover 时填充
- 字体：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular
- 布局：左侧筛选区（可折叠）+ 中间热力图（占主体）+ 右侧详情面板 + 底部时间轴
- 图标风格：线性图标（lucide-react），与工业风一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|----------|----------|---------|
| 站厅热力图主页面 | GIS 底图层 | SVG 底图，半透明叠加，保留原始备注文字（灰色小字） |
| 站厅热力图主页面 | 热力渲染层 | Three.js heatmap，蓝→绿→黄→红渐变，半透明叠加底图 |
| 站厅热力图主页面 | 设备点位层 | 圆形标记点，数据质量状态用边框颜色区分 |
| 站厅热力图主页面 | 时间轴 | 底部 48px 高度条，刻度 + 拖动手柄，当前时段高亮 |
| 站厅热力图主页面 | 筛选器面板 | 左侧 240px 可折叠面板，复选框 + 下拉 |
| 站厅热力图主页面 | 侧边说明面板 | 右侧 320px 面板，分区：基本信息 / 原始备注 / 照片 / 数据质量 / 补录 |
| 站厅热力图主页面 | 截图导出按钮 | 顶部工具栏相机图标，点击后 Canvas 截图 + 水印合成 |
| 站厅热力图主页面 | 审计日志 | 底部可展开 200px 面板，时间线列表 |
| 站厅热力图主页面 | 增量补录区 | 侧边面板底部输入框 + 差异高亮 |

### 4.3 响应式

- 桌面优先（1440px+ 为最佳体验）
- 1280px 以下筛选面板自动折叠为图标触发
- 1024px 以下侧边面板变为底部抽屉
- 不支持移动端（运维工具场景为桌面工位）

### 4.4 3D 场景指引

- 环境：正交俯视相机，60° 倾斜可切换正视
- 光照：环境光 + 方向光，保持底图可读性
- 热力渲染：自定义 ShaderMaterial，基于点位密度 + 拥堵值插值
- 交互：鼠标悬浮显示 tooltip，点击选中高亮边框
- 后处理：轻微辉光（Bloom）增强热力效果

## 5. 数据质量处理规则

| 异常类型 | 识别方式 | 展示方式 | 可操作 |
|----------|----------|----------|--------|
| 坐标偏移 | 点位超出站厅边界或距最近走廊>10m | 橙色边框 + 标记"偏移" | 可手动拖拽修正（记录修正日志） |
| 重名设备 | 名称相似度>80%且同楼层 | 黄色边框 + 标记"疑似重名" + 列出疑似对 | 可标记为同一设备或确认为不同 |
| 缺照片 | photo 字段为空 | 灰色边框 + 照片区显示"缺失"占位 | 可补传照片路径 |
| 跨楼层异常 | 同设备 ID 出现在不同楼层 | 红色边框 + 标记"跨楼层" | 可标注楼层归属或标记为数据错误 |

## 6. 审计日志规则

- 每次筛选条件变更 → 记录筛选快照
- 每次点选/标注 → 记录对象 ID + 操作类型
- 每次补录 → 记录补录内容 + 差异对比
- 每次导出 → 记录导出时的筛选条件 + 时间戳
- 日志不可删除，只能追加
- 换人处理时可查看上一轮所有判断记录
