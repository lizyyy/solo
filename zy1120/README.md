# 陶艺小窑烧成曲线预演工具

一个专为陶艺工作室老师设计的烧成方案管理与风险检查系统。

## 功能特性

- **窑炉参数管理**: 维护多个窑炉的功率、容量、最高温度等参数
- **坯体/釉料资料库**: 管理不同坯体的升/降温速率限制、釉料的成熟温区和保温要求
- **作品库管理**: 记录作品的坯体类型、釉料、厚度、重量等信息
- **烧成曲线设计**: 支持多阶段升温、保温、降温曲线配置
- **智能计算**: 根据窑炉功率、作品重量、升温速率自动计算总时长和电费
- **风险检查**: 自动检测厚坯升温过快、釉料成熟温区不匹配、装窑超载、降温过急等风险
- **方案对比**: 支持两个方案的详细对比分析
- **烧成记录复盘**: 记录实际烧成结果，支持历史查询
- **报告导出**: 支持导出 Markdown 和 HTML 格式的烧成计划/复盘报告
- **本地数据持久化**: 使用 SQLite 本地存储，无需数据库服务

## 安装与运行

- Node.js 14 或更高版本
- npm 或 yarn

1. 安装依赖：

```bash
npm install
```

2. 启动服务器：

```bash

```

3. 打开浏览器访问：


- 插入种子数据（示例窑炉、坯体、釉料、作品）

## 使用指南

### 1. 数据准备

在创建烧成方案之前，建议先完善基础数据：

- **窑炉参数**: 记录工作室窑炉的功率、容量、最高温度
- **坯体资料**: 设置不同坯体的安全升/降温速率
- **釉料资料**: 定义釉料的成熟温区、保温要求、降温敏感度
- **作品库**: 录入待烧作品的详细信息

### 2. 创建烧成方案

1. 点击「烧成方案」→「新建方案」
2. 填写方案基本信息：
   - 方案名称
   - 选择窑炉
   - 设置电价（元/度）
   - 可选：设置预期最长时间和最高电费
3. 选择待烧作品
4. 配置烧成曲线阶段：
   - **升温阶段**: 设置起始温度、目标温度、升温速率
   - **保温阶段**: 设置起始温度、保温时长
   - **降温阶段**: 设置起始温度、目标温度、降温速率
5. 点击「创建」保存方案

### 3. 风险检查

创建方案后，系统会自动计算并进行风险检查：

- **高风险**:
  - 厚坯（≥1cm）升温速率超过安全值
  - 最高温度低于釉料最低成熟温度
  - 装窑容量利用率超过100%

- **中风险**:
  - 普通坯体升温速率超过最大值
  - 保温时间不足釉料/坯体要求
  - 装窑容量超过80%
  - 降温速率超过安全值（根据釉料敏感度）
  - 预计时长/电费超过预期

### 4. 方案对比

1. 创建至少两个烧成方案
2. 点击「烧成方案」→「方案对比」
3. 选择两个要对比的方案
4. 查看对比结果：
   - 预计时长差异
   - 预计电费差异
   - 风险数量对比
   - 高风险数量对比

### 5. 烧成复盘

烧成完成后，记录实际结果：

1. 点击「烧成记录」→「添加记录」
2. 选择关联的烧成方案
3. 填写实际数据：
   - 实际开始/结束时间
   - 实际时长和电费
   - 是否开裂
   - 釉面是否成熟
   - 遇到的问题和备注

### 6. 报告导出

在方案详情页可导出报告：

- **Markdown 格式**: 适合复制到笔记软件或文档
- **HTML 格式**: 适合打印或网页浏览

报告包含：
- 基本信息（窑炉、功率、容量、电价）
- 烧成曲线阶段详情
- 待烧作品列表
- 风险检查结果
- 烧成复盘记录（如有）

- 铜红釉：1250-1280°C，保温1小时，高敏感度
- 哑光釉：1200-1240°C，保温0.5小时

### 示例作品

## API 接口

### 窑炉管理
- `GET /api/kilns` - 获取窑炉列表
- `GET /api/kilns/:id` - 获取单个窑炉
- `POST /api/kilns` - 创建窑炉
- `PUT /api/kilns/:id` - 更新窑炉
- `DELETE /api/kilns/:id` - 删除窑炉

### 坯体/釉料
- `GET /api/bodies` - 获取坯体列表
- `POST /api/bodies` - 创建坯体
- `GET /api/glazes` - 获取釉料列表
- `POST /api/glazes` - 创建釉料

### 作品管理
- `GET /api/pieces` - 获取作品列表
- `POST /api/pieces` - 创建作品
- `PUT /api/pieces/:id` - 更新作品
- `DELETE /api/pieces/:id` - 删除作品

### 烧成方案
- `GET /api/plans` - 获取方案列表
- `GET /api/plans/:id` - 获取方案详情（含阶段、作品、风险）
- `POST /api/plans` - 创建方案
- `PUT /api/plans/:id` - 更新方案
- `DELETE /api/plans/:id` - 删除方案
- `POST /api/plans/:id/calculate` - 执行计算和风险检查
- `GET /api/plans/compare/:planId1/:planId2` - 对比两个方案
- `GET /api/plans/:id/export/markdown` - 导出 Markdown 报告
- `GET /api/plans/:id/export/html` - 导出 HTML 报告

### 烧成记录
- `GET /api/records` - 获取记录列表
- `POST /api/records` - 创建记录
- `PUT /api/records/:id` - 更新记录
- `DELETE /api/records/:id` - 删除记录

## 计算模型说明

### 时长计算

```
升温阶段时长 = (目标温度 - 起始温度) / 升温速率 × 重量因素 × 容量因素

重量因素 = 1 + (总重量 × 0.1)
容量因素 = 1 + (容量利用率 × 0.2)

保温阶段时长 = 设定的保温时长

降温阶段时长 = (起始温度 - 目标温度) / 降温速率

总时长 = 各阶段时长之和
```

### 电费计算

```
电费 = 总时长(小时) × 窑炉功率(kW) × 电价(元/度)
```

### 容量利用率估算

```
估算体积 = 总重量(kg) × 0.002 (m³/kg)
容量利用率 = 估算体积 / 窑炉容量
```

### 风险检查规则

| 风险类型 | 风险等级 | 触发条件 |
|---------|---------|---------|
| 厚坯升温过快 | 高 | 厚度≥1cm 且 升温速率 > 安全速率×0.8 |
| 普通坯升温过快 | 中 | 厚度<1cm 且 升温速率 > 最大速率×0.8 |
| 釉料温度过低 | 高 | 最高温度 < 釉料最低成熟温度 |
| 釉料温度过高 | 中 | 最高温度 > 釉料最高温度+50°C |
| 保温时间不足 | 中 | 总保温时间 < 釉料/坯体要求 |
| 降温过快 | 低/中/高 | 降温速率 > 安全速率×0.7（根据釉料敏感度） |
| 容量超载 | 高 | 容量利用率 > 100% |
| 容量预警 | 中 | 容量利用率 > 80% |
| 时长超预期 | 中 | 预计时长 > 预期上限 |
| 电费超预期 | 中 | 预计电费 > 预期上限 |

## 常见问题

**Q: 为什么我的方案有高风险？**
A: 最常见的高风险原因：
1. 厚坯作品（≥1cm）使用了过高的升温速率
2. 釉料成熟温区高于方案最高温度
3. 装窑作品过多导致容量超载

**Q: 如何设置合理的升温速率？**
A: 建议：
- 普通坯体：200-300°C/小时
- 厚坯（≥1cm）：100-150°C/小时
- 高铝瓷泥：150-200°C/小时
- 500-600°C 区间建议放慢（石英晶型转变期）

**Q: 系统会自动保存数据吗？**
A: 所有创建、更新、删除操作都会立即保存到本地数据库文件。
