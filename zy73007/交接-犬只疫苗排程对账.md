## 二、月底怎么重跑

### 方式 A：命令行（推荐给老周）

```bash
# 当月对账 → CSV 落到 data/ 目录
python scripts/rerun_reconcile.py --print

# 指定月份（比如补 5 月的）
python scripts/rerun_reconcile.py 2026-05 --print
```

`--print` 会在终端直接打出异常队列摘要，不用打开 CSV 就能先扫一眼。

### 方式 B：接口（给负责人或其他系统调）

```bash
# 触发重跑 + 自动导CSV + 校验状态一致性
curl -X POST "http://127.0.0.1:8000/api/reconcile/rerun?month=2026-06"
```

返回 JSON 里带 `状态一致性校验` 字段，**接口查到的 status 字段和导出 CSV 的「状态」列完全一致**，不一致会列详情。

月底复核直接拿 data/ 下三份分类 CSV：`疫苗对账明细-已确认-*`、`疫苗对账明细-待补件-*`、`疫苗对账明细-退回-*`。

## 三、异常队列从哪进

| 入口 | 地址 | 作用 |
|---|---|---|
| 接口（JSON） | `GET /api/abnormal-queue` | 可按 `?status=待补件` 过滤，状态与明细一致 |
| CSV 下载 | `GET /api/download/abnormal-queue` | 月底复核带走整份异常队列 |
| 明细反查 | `GET /api/reconcile/{reconcile_id}` | 点进单条看：原话引用 → 异常类型 → 处理结论 → 改判理由 |
| 统计总览 | `GET /api/stats` | 一眼看各状态/各异常类型数量 |

**对接顺序**（老周交接给下一位时）：
1. 先打开 `/api/registers` 找到登记表里主人的原话；
2. 再打开 `/api/abnormal-queue` 按异常摘要定位是哪条；
3. 最后用 `reconcile_id` 去 `/api/reconcile/{id}` 看完整处理结论（改判理由、处理人、处理时间都在这）。
