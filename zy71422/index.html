月面滑翔补给局 - 操作说明

🚀 快速上手（5分钟）

  1. 点击 "加载默认配置" 或导入自定义材料
  2. 按 ↑ 启动推进器开始飞行
  3. 用 ← → 调整水平轨迹
  4. 接近地面时控制速度 ≤ 5 m/s
  5. 在绿色着陆区平稳着陆

⚠️ 失败条件

  • 速度过高: 着陆时速度超过5 m/s → 补给舱损毁
  • 燃料耗尽: 燃料归零后无法控制 → 自由坠毁
  • 落点越界: 落在着陆区外或月坑中
  • 撞击月坑: 飞行中直接撞击月坑边缘

📥 材料导入格式（JSON）

// 补给舱参数 capsule.json
{
  "mass": 100,
  "maxThrust": 1500,
  "dragCoeff": 0.02
}

// 月坑分布 crater.json
{
  "craters": [
    {"x": 200, "y": 550, "radius": 40, "depth": 20},
    {"x": 500, "y": 550, "radius": 60, "depth": 30}
  ]
}

// 燃料配置 fuel.json
{
  "initialFuel": 100,
  "consumptionRate": 0.5,
  "landingZone": {"x": 700, "width": 120}
}

🔍 失败分析

每次失败后系统会显示：

  • 触发材料: 哪份配置导致失败
  • 卡点位置: 失败发生的坐标和时间
  • 下一步建议: 如何调整材料和操作
