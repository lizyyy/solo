# 月面滑翔补给局

> 一局就能玩的月面补给游戏 - 低重力 + 燃料管理 + 精准着陆

## 🚀 5分钟快速上手

### 1. 启动游戏
直接用浏览器打开 `index.html` 即可，无需安装。

### 2. 开始飞行
- 按 **↑** 键发射补给舱，启动推进器
- 用 **← →** 调整水平轨迹
- 按 **空格** 进行悬停制动，快速减速
- 目标：在绿色着陆区以 ≤ 5 m/s 的速度着陆

### 3. 快捷键
| 按键 | 功能 |
|------|------|
| ↑ | 主推进器（上升/减速下降） |
| ← | 向左平移 |
| → | 向右平移 |
| 空格 | 悬停制动 |
| R | 重新开始 |
| P | 查看回放（任务结束后） |

## 📥 材料导入系统

补给舱、月坑、燃料配置可以分别从不同的JSON文件导入。

### 导入步骤
1. 点击左侧面板对应的导入按钮
2. 选择JSON文件
3. 系统自动验证并应用参数
4. 右侧"材料追溯"面板会显示原始材料和处理结果

### 配置文件格式

**补给舱参数 (capsule.json)**
```json
{
  "mass": 100,
  "maxThrust": 1500,
  "dragCoeff": 0.02
}
```

**月坑分布 (crater.json)**
```json
{
  "craters": [
    {"x": 200, "y": 550, "radius": 40, "depth": 20},
    {"x": 500, "y": 550, "radius": 60, "depth": 30}
  ]
}
```

**燃料配置 (fuel.json)**
```json
{
  "initialFuel": 100,
  "consumptionRate": 0.5,
  "landingZone": {"x": 700, "width": 120}
}
```

示例配置文件位于 `sample-configs/` 目录。

## ⚠️ 失败条件

1. **速度过高** - 着陆时速度 > 5 m/s
2. **燃料耗尽** - 燃料归零后无法控制
3. **落点越界** - 落在着陆区外或月坑中
4. **撞击月坑** - 飞行中直接撞击月坑边缘

## 🔍 失败分析

每次失败后系统会显示：
- **触发材料**：哪份配置导致失败（补给舱/月坑/燃料/操作）
- **卡点位置**：失败发生的坐标、速度、剩余燃料
- **下一步建议**：如何调整材料参数和操作技巧

## 📼 回放功能

任务结束后按 **P** 键或点击"查看回放"按钮：
- 播放/暂停整个飞行过程
- 逐帧前进/后退分析
- 查看每帧的飞行参数

## 🎯 核心机制

- **月球重力**：1.62 m/s²（约地球的1/6）
- **轨迹预测**：橙色虚线显示无动力轨迹
- **飞行轨迹**：蓝色实线显示已飞行路径
- **燃料管理**：每次推进都消耗燃料，耗尽后只能自由落体
