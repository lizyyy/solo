# 铁路调车信号联锁解谜

一个本地浏览器游戏，模拟铁路调车作业。

## 项目结构

```
.
├── index.html          # 主页面
├── styles.css          # 样式文件
├── js/
│   ├── levels.js     # 关卡数据
│   ├── state.js      # 状态管理
│   ├── rules.js      # 规则引擎
│   ├── renderer.js   # 渲染交互
│   ├── storage.js    # 存储模块
│   └── game.js       # 游戏主逻辑
└── README.md
```

## 模块说明

### 1. **levels.js
- 关卡数据结构定义
- 3个示例关卡
- 包含地图、列车、目标、禁行规则

### 2. **state.js**
- 游戏状态管理
- 状态机实现
- 历史记录（撤销功能

### 3. **rules.js**
- 规则引擎
- 碰撞判定
- 边界条件处理
- "列车占用道岔无法切换
- 两列车预订同一区段判定

### 4. **renderer.js**
- Canvas渲染
- 用户交互处理

### 5. **storage.js**
- localStorage存储
- 本地最佳步数记录

### 6. **game.js**
- 整合所有模块
- 游戏主循环

## 本地启动方式

### 方法1：直接打开
直接用浏览器打开 `index.html`

### 方法2：使用HTTP服务器（推荐）

使用 Python 3：
```bash
python3 -m http.server 8080
```

使用 Node.js (http-server)：
```bash
npx http-server -p 8080
```

然后在浏览器访问 http://localhost:8080

## 游戏操作说明

- **点击道岔**：切换道岔方向（直/弯）
- **点击信号机**：切换信号（红/绿）
- **点击列车**：推进列车前进
- **自动推进**：自动移动第一辆可移动的列车
- **撤销**：撤销上一步操作
- **重新开始**：重置当前关卡

## 关卡列表

1. **入门：单线调车** - 学习基础操作
2. **双车交会** - 两列车会车调度
3. **复杂站场调度** - 三列车复杂调度

## 核心规则

1. 列车占用道岔时，道岔无法切换
2. 前方区段被占用时，列车无法移动
3. 信号机关闭时，列车无法发车
4. 两列车不能同时预订同一区段
5. 所有列车到达目标位置获胜
