## 1. 产品概述

字体授权追踪工具——面向品牌设计师的授权状态管理应用。解决品牌设计流程中字体授权到期无感知、色卡版本混用、导出规格不一致三大核心问题。所有确认状态和异常标注持久化存储，核心证据不依赖内存或临时页面提示，确保交付物可追溯、可审计。

- 目标用户：品牌设计师（非评审人员），日常工作依赖色卡、审稿意见和不完整备注
- 核心价值：将"色卡→人工确认→交付说明"串成完整链路，异常项宁可标待确认也不混入正常结果

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 品牌设计师 | 主要使用者 | 导入/编辑字体记录、关联色卡、标记确认状态、筛选导出 |
| 审核人（可选） | 复核交付物 | 查看记录、标注审稿意见、确认/驳回 |

### 2.2 功能模块

1. **授权总览页**：状态看板、异常告警、近期变更时间线
2. **字体授权列表页**：核心工作区，支持筛选/排序/批量操作/撤回修正
3. **导入与复核页**：重复导入检测、字段补全、冲突处理
4. **导出与交付页**：导出一致性校验、交付说明生成、异常项隔离

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 授权总览页 | 状态看板 | 统计正常/即将到期/已过期/待确认数量，点击可跳转筛选 |
| 授权总览页 | 异常告警 | 列出授权过期、色卡版本混用、导出规格漏改等异常项，标红+待确认标签 |
| 授权总览页 | 变更时间线 | 最近操作记录（导入/修正/撤回/确认），支持回溯查看 |
| 字体授权列表页 | 记录表格 | 展示字体名称、授权类型、到期日、色卡关联、确认状态，支持多条件筛选 |
| 字体授权列表页 | 批量操作 | 批量标记确认/待确认、批量关联色卡、批量修改授权类型 |
| 字体授权列表页 | 撤回修正 | 操作撤回（保留操作日志），修正后自动更新状态和时间线 |
| 字体授权列表页 | 详情侧栏 | 展开单条记录详情：授权文件、色卡快照、审稿意见、备注、操作历史 |
| 导入与复核页 | 文件导入 | 支持 CSV/JSON 导入，自动解析字段映射 |

| 导入与复核页 | 字段补全 | 标注缺失字段（如到期日空、色卡未关联），导入前强制补全或标待确认 |

| 导出与交付页 | 导出历史 | 记录每次导出的快照，支持对比和回看 |

## 3. 核心流程

### 3.1 导入→确认→导出 主流程

设计师收到色卡和审稿意见后，将字体信息导入系统。系统检测重复和异常，设计师逐项确认或标待确认。确认完成后，筛选所需条目导出，系统自动校验一致性并生成交付说明。

```mermaid
flowchart TD
    "A[导入字体数据]" --> "B[重复检测]"
    "B" --> "C{有重复？}"
    "C" --> "是" --> "D[选择合并/覆盖/跳过]"
    "C" --> "否" --> "E[字段补全检查]"
    "D" --> "E"
    "E" --> "F{有缺失字段？}"
    "F" --> "是" --> "G[补全或标待确认]"
    "F" --> "否" --> "H[写入记录]"
    "G" --> "H"
    "H" --> "I[关联色卡与审稿意见]"
    "I" --> "J[人工逐项确认]"
    "J" --> "K{有异常？}"
    "K" --> "是" --> "L[标待确认+异常说明]"
    "K" --> "否" --> "M[标已确认]"
    "L" --> "N[修正后重新确认]"
    "N" --> "M"
    "M" --> "O[筛选导出]"
    "O" --> "P[一致性校验]"
    "P" --> "Q{校验通过？}"
    "Q" --> "是" --> "R[生成交付说明+导出]"
    "Q" --> "否" --> "S[异常项隔离标待确认]"
    "S" --> "L"
```

### 3.2 撤回修正流程

```mermaid
flowchart TD
    "A[发起撤回]" --> "B[记录撤回操作到日志]"
    "B" --> "C[恢复上一状态]"
    "C" --> "D[修正数据]"
    "D" --> "E[重新确认]"
```

### 3.3 异常处理规则

| 异常类型 | 检测时机 | 处理方式 |
|----------|----------|----------|
| 授权过期 | 导入时/列表展示时/导出前 | 自动标红+待确认，不允许标已确认 |
| 导出规格漏改 | 导出前校验 | 自动标待确认，隔离到异常清单 |
| 色卡版本混用 | 关联色卡时/导出前校验 | 提示版本不一致，标待确认 |
| 到期日缺失 | 导入时字段检查 | 强制补全或标待确认后才能写入 |
| 重复导入 | 导入时 | 提供合并/覆盖/跳过选项，记录操作日志 |

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底（#1a1a1a）+ 白色文字，强调色用琥珀色（#F59E0B）表示待确认/警告，翠绿色（#10B981）表示已确认
- **按钮风格**：扁平矩形，小圆角（4px），hover 时微升亮度
- **字体**：JetBrains Mono 用于数据字段，Noto Sans SC 用于中文界面文本
- **布局风格**：左侧固定导航栏 + 右侧内容区，表格为主，侧栏展开详情
- **图标风格**：Lucide 线性图标，16px，与文字同色

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 授权总览页 | 状态看板 | 三栏卡片（已确认/待确认/已过期），数字大字+趋势箭头 |
| 授权总览页 | 异常告警 | 红色左边框列表项，异常类型图标+字体名+异常描述+操作按钮 |
| 授权总览页 | 变更时间线 | 竖向时间线，每项显示操作类型图标+描述+时间戳，可点击展开详情 |
| 字体授权列表页 | 记录表格 | 可排序表头，行状态用色条左边框区分，checkbox 批量选择 |
| 字体授权列表页 | 筛选栏 | 顶部固定，下拉筛选（状态/色卡/授权类型/到期范围），搜索框 |
| 字体授权列表页 | 详情侧栏 | 右侧滑出面板，分区展示：基本信息/色卡快照/审稿意见/操作日志 |
| 导入与复核页 | 导入区 | 拖拽上传区+文件选择按钮，下方显示解析进度和字段映射预览 |
| 导入与复核页 | 冲突列表 | 卡片式，每张标注冲突类型和解决选项，底部操作栏 |
| 导出与交付页 | 筛选条件 | 标签式筛选器，已选条件显示为可删除标签 |
| 导出与交付页 | 校验结果 | 分两区：通过项（绿色勾）和异常项（琥珀色感叹号+待确认标签） |
| 导出与交付页 | 交付说明 | 可预览的 Markdown 区域，导出按钮在右上角 |

### 4.3 响应式设计

桌面优先，最小宽度 1280px。列表页在窄屏下隐藏侧栏改为模态框。不支持移动端操作（品牌设计师工作环境为桌面）。
