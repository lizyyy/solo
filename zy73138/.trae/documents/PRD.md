## 1. 产品概述

近岸水质空间标注系统——面向生态调查员的实地采样数据空间化管理工具。解决船上记录本转电子化后仅剩平均值、异常风险被掩盖的问题，让空间位置、异常高亮和船上记录本来源严格对齐，并完整保留数据处理的版本痕迹与复核线索。

- 目标用户：生态调查员（如阿宁）、接手复核的数据分析人员、项目交接人
- 核心价值：将船上记录本中的"脏数据"原样呈现于空间地图上，使异常不被平均值吞没，让接手人能追溯每条记录的来源、复核原因和变更历史

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 生态调查员 | 直接访问 | 录入/编辑采样记录、标注异常、查看空间地图、导出交接包 |
| 复核人员 | 直接访问 | 查看空间地图、查阅复核标记、浏览变更历史、确认复核结论 |
| 项目交接人 | 直接访问 | 查看空间地图、导出CSV明细、浏览船上记录本溯源、确认交接完成 |

### 2.2 功能模块

1. **空间地图主页**：近岸采样点空间分布、异常高亮、船上记录本来源联动
2. **采样记录详情页**：单条记录的完整生命周期——原始录入、晚到附件、后补说明、复核标记
3. **变更历史页**：结论修改的时间线，可翻查任意历史版本
4. **交接工作台**：按船上记录本+CSV明细完成交接，非开发者可独立操作

## 3. 核心流程

### 3.1 采样数据录入与异常标注流程

生态调查员阿宁在船上完成采样后，将记录本数据录入系统。录入时系统自动在地图上标注采样点位置。若检测值超出阈值范围，系统自动高亮为异常。对于晚到附件（如延迟提交的现场照片），阿宁将其关联到对应采样记录，系统在数据来源时间线中标注"晚到附件"。后补说明同样追加到时间线，标注为"后补备注"。

```mermaid
flowchart TD
    "船上记录本录入" --> "系统自动标注空间位置"
    "系统自动标注空间位置" --> "检测值与阈值比对"
    "检测值与阈值比对" --> "正常: 常规显示"
    "检测值与阈值比对" --> "异常: 高亮标记"
    "异常: 高亮标记" --> "关联船上记录本来源"
    "正常: 常规显示" --> "关联船上记录本来源"
    "关联船上记录本来源" --> "晚到附件追加"
    "晚到附件追加" --> "后补说明追加"
    "后补说明追加" --> "数据来源时间线完整"
```

### 3.2 重复采样瓶复核流程

当同一采样瓶编号被重复录入时，系统自动标记为"需复核"，并在复核标记区显示复核原因（重复录入）。接手人点击该记录后，可看到两条录入的详细信息、时间差异和来源差异，判断应保留哪条或需合并。

```mermaid
flowchart TD
    "录入采样瓶编号" --> "系统检测编号唯一性"
    "系统检测编号唯一性" --> "编号重复"
    "编号重复" --> "自动标记为需复核"
    "自动标记为需复核" --> "显示复核原因: 重复录入"
    "显示复核原因: 重复录入" --> "接手人查看两条记录详情"
    "接手人查看两条记录详情" --> "判断保留/合并/删除"
    "判断保留/合并/删除" --> "更新复核结论"
```

### 3.3 交接流程

阿宁完成所有记录整理后，进入交接工作台。系统自动生成交接清单，列出所有记录及其状态。阿宁逐条核对船上记录本与系统记录是否对齐，确认后导出CSV明细包。接手人收到交接包后，可沿船上记录本来源和CSV明细回溯每条记录的完整链路。

```mermaid
flowchart TD
    "进入交接工作台" --> "生成交接清单"
    "生成交接清单" --> "逐条核对船上记录本"
    "逐条核对船上记录本" --> "标记对齐/偏差"
    "标记对齐/偏差" --> "导出CSV明细包"
    "导出CSV明细包" --> "接手人确认"
    "接手人确认" --> "交接完成"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 (#0A2540) 为底，搭配潮汐青 (#00BFA5) 作为异常高亮色，浪花白 (#F0F4F8) 作为内容背景
- **辅助色**：锈橙 (#E8653A) 用于需复核/警告标记，沙金 (#D4A843) 用于后补备注标记
- **按钮风格**：圆角矩形，微凸起阴影，主操作按钮用潮汐青填充
- **字体**：标题使用 Noto Serif SC（衬线体，呼应记录本质感），正文使用 Noto Sans SC，数据使用 JetBrains Mono
- **布局风格**：左侧地图主画布，右侧信息面板，顶部工具栏，底部状态栏
- **图标风格**：线性图标，2px 描边，航海/测量仪器风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|

| 空间地图主页 | 异常高亮图例 | 左下角悬浮图例面板，颜色+形状双重编码说明 |
| 空间地图主页 | 船上记录本来源面板 | 右侧抽屉式面板，展示记录本页码、照片缩略图、录入时间 |

### 4.3 响应式设计

- 桌面优先设计，地图画布占据主要空间
- 平板端：信息面板改为底部抽屉，地图全屏
- 移动端：地图简化为列表视图，保留关键异常高亮

### 4.4 示例数据设计

示例数据故意包含以下"不完美"场景以暴露真实问题：
- **晚到附件**：WQ-015号采样记录，现场照片在录入后2天才上传，系统标记为"晚到附件"
- **后补说明**：WQ-023号采样记录，阿宁在录入次日补充了"采样时风速较大，可能影响表层水样"的备注
- **重复采样瓶**：WQ-008号采样瓶被录入了两次（一次来自记录本第3页，一次来自记录本第7页附件），系统自动标记需复核，复核原因显示"同编号重复录入，来源页码不同"
- **结论变更**：WQ-031号记录的异常结论从"疑似污染"修改为"确认污染"，历史可追溯
