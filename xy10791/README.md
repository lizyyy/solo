# 考试防作弊巡检台

一个基于Python Flask的考试防作弊巡检系统，提供API接口和Web管理界面。

## 功能特性

### 核心功能
- **考生会话管理**：录入和管理考生考试会话
- **切屏事件监控**：记录和统计考生切屏行为
- **摄像头状态监控**：跟踪摄像头开启/关闭状态
- **异常分级算法**：根据切屏次数和摄像头状态自动计算异常等级

### 异常分级
- **正常 (normal)**：无切屏或摄像头问题
- **注意 (notice)**：1次切屏
- **警告 (warning)**：3次以上切屏或摄像头关闭60秒以上
- **严重 (critical)**：5次以上切屏或摄像头关闭120秒以上

### 申诉处理
- 考生提交申诉
- 监考老师处理申诉
- 处理理由记录，支持复盘
- 处理结果：认可/部分认可/驳回

### 巡检报告
- 一键生成巡检报告
- 包含完整事件时间线
- 包含申诉处理记录
- 包含处理人信息和处理理由

## API接口

### 会话管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/sessions | 获取所有会话列表 |
| POST | /api/sessions | 创建新会话 |
| GET | /api/sessions/{id} | 获取单个会话详情 |
| POST | /api/sessions/{id}/handle | 处理会话 |
| POST | /api/sessions/{id}/recalculate | 重新计算状态 |

### 事件管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/sessions/{id}/events | 获取会话事件 |
| POST | /api/events | 添加新事件 |

### 申诉管理

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/appeals | 获取所有申诉 |
| POST | /api/appeals | 创建新申诉 |
| POST | /api/appeals/{id}/handle | 处理申诉 |

### 报告管理

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/reports | 生成巡检报告 |
| GET | /api/reports/{id} | 获取报告详情 |

## 使用说明

### 1. 查看会话列表
- 首页显示所有考生会话的统计卡片和列表
- 统计卡片显示：异常分级失败数、警告状态数、正常状态数、总会话数
- 点击"查看详情"跳转到会话详情页

### 2. 会话详情页
- 显示考生基本信息和异常等级
- **事件时间线**：按时间倒序显示所有事件（切屏、摄像头状态变化、处理记录、申诉）
- **申诉记录**：显示该会话的所有申诉及其处理状态
- **处理信息**：显示处理人、处理时间、处理理由（如果已处理）

### 3. 处理会话
- 点击"处理会话"按钮
- 填写处理人姓名和处理理由
- 提交后会话状态变为"已处理"

### 4. 申诉处理
- 在详情页或申诉管理页点击"处理申诉"
- 选择处理结果（认可/部分认可/驳回）
- 填写处理理由（将用于后续复盘）

### 5. 重新计算
- 添加切屏事件后会自动重新计算异常等级
- 也可手动点击"重新计算"按钮刷新状态

### 6. 生成巡检报告
- 点击"生成巡检报告"按钮
- 报告包含完整的事件记录、申诉记录和处理记录

## 技术栈

- **后端**：Python Flask
- **前端**：原生 HTML + JavaScript + CSS
- **数据存储**：JSON文件
- **跨域支持**：Flask-CORS

## 注意事项

- 数据存储在本地 `data.json` 文件中
- 添加切屏事件会自动触发状态重新计算
- 申诉处理理由会被持久化保存，用于审计和复盘
- 所有时间戳使用ISO 8601格式存储
