## 1. 产品概述

"多面体矿山探险"课堂活动管理与复盘工具——解决活动复盘群临时凑数、例外情况无法追溯、原始备注被清洗、失败原因不清晰等痛点，让老师能直接拿导出结果和回放在月底或复盘会上解释每条记录的来龙去脉。

- 目标用户：课程助教、课堂教师
- 核心价值：将零散的活动复盘群记录变成可追溯、可回放、可导出的人话报告，例外不消失、来源有交代

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 课程助教/教师 | 打开即用，无需注册 | 管理活动、录入记录、查看复盘报告、导出数据 |

### 2.2 功能模块

1. **活动控制台**：开始、暂停、重开、结算四大操作按钮，活动状态一目了然
2. **探险记录面板**：实时展示当前活动的所有探险记录，保留原始备注和来源标记
3. **失败反馈区**：每次失败时明确区分"规则没理解"还是"操作慢了"，而非笼统的"游戏结束"
4. **复盘报告页**：汇总统计 + 逐条明细，像同事写给同事看的话，保留原始来源和处理时间
5. **回放功能**：完整回放活动过程，包括中途暂停的记录也不丢失
6. **数据导出**：导出成绩与回放文件，月底复盘直接能用

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 活动控制台 | 状态栏 | 显示当前活动状态（未开始/进行中/已暂停/已结算），活动ID和开始时间 |
| 活动控制台 | 操作按钮组 | 开始、暂停、继续、重开、结算按钮，按状态智能启用/禁用 |
| 活动控制台 | 计时器 | 显示活动进行时间，暂停时冻结 |
| 探险记录面板 | 记录列表 | 每条记录显示：编号、结果、得分、耗时、失败原因（如有）、来源标记、处理时间、原始备注 |
| 探险记录面板 | 来源标签 | 区分"实时录入"、"活动复盘群补录"、"旧口径"三种来源 |
| 探险记录面板 | 备注编辑 | 可添加/编辑备注，保留原始乱备注不自动清洗 |
| 失败反馈 | 原因分类 | 明确标注：规则误解、操作超时、边界分数待确认、其他例外 |
| 失败反馈 | 具体提示 | 如"第3题选择了正六面体，但题目要求选择面数大于8的多面体——规则没理解" |
| 复盘报告 | 汇总统计 | 总记录数、成功数、失败数、各类失败占比，例外单独列出不合并 |
| 复盘报告 | 逐条明细 | 每条记录的完整信息，含来源和处理时间，像同事间的工作备忘 |
| 复盘报告 | 导出按钮 | 导出为JSON/CSV，文件名含活动ID和日期 |
| 回放 | 时间轴 | 按时间顺序回放每条记录的产生过程，暂停记录也完整保留 |
| 回放 | 播放控制 | 播放/暂停/跳转，可跳到任意记录 |

## 3. 核心流程

用户打开页面 → 点击"开始新活动" → 系统生成活动ID和计时 → 逐步录入探险记录（含多面体类型、得分、耗时等）→ 遇到失败时弹出具体原因反馈 → 可随时暂停/继续 → 点击"结算"结束活动 → 生成复盘报告 → 可回放整个过程 → 可导出数据

暂停流程：点击暂停 → 计时冻结 → 记录面板标记暂停时间点 → 点击继续 → 计时恢复 → 回放时暂停记录完整保留

补录流程：活动复盘群发现遗漏 → 在记录面板手动添加 → 系统标记来源为"活动复盘群补录" → 备注中保留原始群聊备注

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深矿石灰(#1a1a2e) + 琥珀金(#f0a500) 强调色，搭配岩灰(#16213e)和钢蓝(#0f3460)
- **按钮风格**：圆角矩形，主操作用琥珀金填充，次操作用描边，暂停用醒目橙色
- **字体**：标题用 Noto Serif SC（衬线体，有书卷气），正文用 Noto Sans SC
- **布局风格**：左侧活动控制台 + 右侧记录面板，底部复盘报告区，顶部状态栏
- **图标**：使用 Lucide 图标库，矿车、宝石、计时器等意象

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 活动控制台 | 状态栏 | 深色背景，琥珀金文字显示状态，活动ID灰色小字，计时器等宽字体 |
| 活动控制台 | 操作按钮 | 琥珀金填充按钮（开始/结算），描边按钮（暂停/继续），红色描边（重开） |
| 探险记录面板 | 记录卡片 | 左侧色条标识结果（绿=成功，橙=待确认，红=失败），右侧来源标签 |
| 探险记录面板 | 备注区 | 浅灰底色文本框，保留原始格式，不自动清洗 |
| 失败反馈 | 弹出面板 | 右侧滑入面板，标题明确原因分类，正文用同事语气解释 |
| 复盘报告 | 汇总区 | 大字号关键数字，失败原因饼图，例外单独卡片 |
| 复盘报告 | 明细表 | 表格式逐条展示，来源和处理时间列不省略 |
| 回放 | 时间轴 | 左侧竖线时间轴，每个节点一条记录，暂停节点用虚线标记 |

### 4.3 响应式设计

- 桌面优先设计，左右分栏布局
- 平板：单栏布局，控制台和记录面板上下排列
- 手机：底部固定操作栏，上方滚动记录列表
