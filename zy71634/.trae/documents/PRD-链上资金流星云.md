
## 1. 产品概述
链上资金流星云是一款面向Web3分析师的3D可视化工具，用于追踪和分析加密货币钱包之间的资金流动。通过星云状的3D网络展示钱包地址节点和交易连线，帮助分析师发现异常资金路径，支持交互式参数调整、实时数据同步和报告导出功能。

- **核心目标**：解决链上数据分析中材料不一致、异常路径难以发现、分析流程断裂的痛点
- **目标用户**：Web3分析师、区块链调查员、合规审计人员
- **市场价值**：提升链上资金追踪的效率和准确性，降低人工分析成本

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| Web3分析师 | 无需注册（本地应用） | 数据导入、3D可视化、参数调整、报告导出 |

### 2.2 功能模块
1. **主工作区**：3D星云网络图、参数控制面板、时间轴播放器
2. **侧边数据面板**：节点详情、交易记录、标签备注、工作流状态
3. **异常检测模块**：自动识别并隔离问题数据
4. **报告导出模块**：生成分析报告

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 主工作区 | 3D星云视图 | 钱包节点3D展示、拖拽交互、缩放旋转、异常路径高亮钻取 |
| 主工作区 | 参数控制面板 | 力导向参数调节、筛选条件设置、显示选项 |
| 主工作区 | 时间轴播放器 | 时间范围筛选、播放/暂停、速度调节 |
| 侧边面板 | 节点详情 | 地址信息、代币余额、交易历史 |
| 侧边面板 | 标签编辑 | 地址标签、备注添加、批量编辑 |
| 侧边面板 | 工作流状态 | 记录状态追踪、退回补材料、继续处理 |
| 导出面板 | 报告生成 | PDF/CSV导出、数据同步更新 |

## 3. 核心流程

用户导入钱包地址和交易数据 → 系统自动检测数据质量（地址合并、时间顺序、循环转账）→ 3D星云网络可视化 → 分析师交互式探索（拖拽/筛选/时间轴）→ 发现异常路径并标注 → 编辑标签和备注 → 同步更新侧边数据 → 导出分析报告。

```mermaid
    E --> D
    D --> F["交互式探索"]
    F --> G["异常路径发现"]
    G --> H["标签备注编辑"]
    H --> I["数据同步更新"]
    I --> J["报告导出"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深空蓝(#0a1628) 配合 星云紫(#6366f1) 高光
- **辅助色**：异常红(#ef4444)、正常绿(#10b981)、警示橙(#f59e0b)
- **按钮风格**：玻璃拟态玻璃拟态、圆角8px、发光边框
- **字体**：JetBrains Mono（等宽字体，适合数据展示）
- **布局**：暗黑科技风、分层设计、深度感层次

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 主工作区 | 3D星云视图 | 深色背景、发光节点、动态连线、粒子效果、深度雾效 |
| 主工作区 | 参数控制面板 | 滑动条、复选框、下拉选择器、实时预览 |
| 侧边面板 | 数据卡片 | 玻璃拟态卡片、滚动区域、状态徽章 |
| 时间轴 | 播放器控件 | 进度条、播放按钮、速度调节、时间刻度 |

### 4.3 响应式
- 桌面端优先设计，支持三栏布局（主工作区自适应
- 侧边面板可折叠收起
- 触控设备支持手势缩放旋转

### 4.4 3D场景指导
- **环境**：深空黑色背景，星点粒子背景
- **光照**：环境光+点光源，节点自发光效果
- **相机**：轨道控制器，支持自由旋转、缩放、平移
- **交互**：节点悬停高亮、点击钻取、路径动画
- **后处理**： bloom发光效果、景深、抗锯齿
