# 影像科胶片自助取片台 - 使用说明

## 一、项目简介

这是一个医院影像科胶片自助取片管理系统，用于处理患者检查、取片码验证、胶片打印、补打审核、异常记录和取片统计等功能。

### 主要功能模块：
- **首页**：快速入口、统计概览、测试样例数据
- **取片服务**：通过取片码或身份证验证患者身份，打印胶片
- **补打申请**：胶片丢失或损坏时申请补打
- **管理中心**：审核补打申请、处理异常记录、数据导出
- **历史记录**：查看所有操作历史和变更追踪
- **统计分析**：取片、打印、补打和异常数据统计

## 四、完整操作流程演示

### 流程 1：正常取片流程

#### 步骤 1：验证身份
1. 点击顶部导航栏「取片服务」
2. 选择「使用取片码」
3. 输入取片码：`20260510-8876`
4. 点击「验证并查询胶片」

#### 步骤 2：确认信息
- 系统显示患者信息：张三，男，45岁
- 显示检查详情：胸部CT，2张胶片，检查科室：呼吸内科
- 检查状态：✓ 可打印

#### 步骤 3：打印胶片
1. 点击「确认打印胶片」
2. 系统显示「打印成功！」提示
3. 顶部通知栏显示绿色成功通知

#### 步骤 4：查看记录
1. 点击「历史记录」查看操作日志
2. 点击「统计分析」查看打印统计

---

### 流程 2：补打申请与审核流程

#### 步骤 1：提交补打申请
1. 点击「补打申请」
2. 输入身份证号：`110101197901011234` 或检查号：`EX20260510001`
3. 点击「查询检查记录」
4. 选择补打原因：如「胶片损坏」
5. 输入申请人：张三
6. 点击「提交补打申请」

#### 步骤 2：审核补打申请
1. 点击「管理中心」
2. 进入「补打审核」标签页
3. 看到待审核的补打申请（黄色背景高亮）
4. 点击「审核」按钮
5. 可选择：
   - **批准**：点击「批准」按钮，系统自动打印补打胶片
   - **拒绝**：点击「拒绝」按钮，填写拒绝原因
6. 审核后状态更新

---

### 流程 3：异常处理流程

#### 步骤 1：触发异常
1. 尝试输入错误的取片码（如 `12345-678`）
2. 系统显示错误提示
3. 异常自动记录到系统

#### 步骤 2：查看异常记录
1. 点击「管理中心」
2. 切换到「异常记录」标签页
3. 看到待处理的异常（红色背景高亮）
4. 异常类型包括：取片码无效、信息不匹配、打印机错误等

#### 步骤 3：处理异常
1. 点击「处理」按钮
2. 输入处理方案
3. 点击「标记已处理」
4. 异常状态更新为「已处理」

---

### 流程 4：数据导出流程

#### 步骤 1：导出数据
1. 点击「管理中心」
2. 切换到「数据导出」标签页
3. 选择要导出的数据类型：
   - **打印记录**：导出所有打印历史
   - **补打申请**：导出所有补打申请
   - **异常记录**：导出所有异常记录
4. 点击对应卡片，JSON文件自动下载

#### 步骤 2：查看导出历史
1. 点击「历史记录」
2. 可以看到「导出数据」操作记录

## 五、关键特性说明

### 1. 取片码验证规则
- 格式要求：`8位数字-4位数字`（如 `20260510-8876`）
- 验证内容：格式、是否存在、是否过期、是否已使用、是否与患者匹配

### 2. 异常拦截机制
- 格式错误 → 立即拦截并记录
- 不存在 → 拦截并记录
- 已使用 → 拦截并提示申请补打
- 身份不匹配 → 拦截并记录
- 胶片未准备好 → 拦截并提示稍后再来

### 3. 状态追踪
- 取片码状态：active（可用）→ used（已使用）→ expired（已过期）
- 检查状态：pending（处理中）→ ready（可打印）→ printed（已打印）→ reprinted（已补打）
- 补打申请：pending（待审核）→ approved（已批准）→ rejected（已拒绝）
- 异常记录：pending（待处理）→ resolved（已处理）

### 4. 操作反馈
- 所有关键操作都有通知提示（成功/失败/警告）
- 异常记录不会静默处理，全部显示在管理中心
- 历史记录完整追踪每次操作

## 六、数据结构说明

```
- id: 患者ID
- name: 姓名
- gender: 性别
- age: 年龄
- idCard: 身份证号
- phone: 手机号
```

### 检查信息
```
- examNo: 检查号
- examType: 检查类型
- examDate: 检查日期
- filmCount: 胶片数量
- status: 状态
```

### 取片码
```
- pickupCode: 取片码
- examNo: 关联检查号
- createdAt: 创建时间
- expiresAt: 过期时间
- status: 状态
```
