# 急诊科分诊训练系统

为急诊科新护士设计的交互式分诊训练小游戏，帮助护士快速掌握急诊分诊流程和规则。

## 功能特点

- **实时分诊练习**：在限定时间内处理不断到来的患者
- **标准分诊系统**：红/黄/绿/黑四色分诊区域，符合急诊分诊规范
- **智能规则判定**：根据患者信息自动判断分诊正确性，提供实时反馈
- **可编辑关卡**：通过JSON文件自定义关卡，灵活调整难度
- **数据记录**：保存历史成绩，支持Markdown格式训练报告导出
- **暂停复盘**：随时暂停游戏查看当前状态和评分情况

## 快速开始

### 方式一：直接打开HTML文件

1. 克隆或下载本项目到本地
2. 直接在浏览器中打开 `index.html` 文件

### 方式二：使用本地服务器（推荐）

1. 确保已安装 [Node.js](https://nodejs.org/)（版本 >= 14.0.0）
2. 安装依赖：
```bash
npm install
```
3. 启动开发服务器：
```bash
npm start
```
4. 浏览器会自动打开 `http://localhost:8080/index.html`

## 游戏玩法

### 基本规则

1. **开始游戏**：点击"开始游戏"按钮，选择关卡后进入游戏
2. **患者卡片**：每个患者卡片包含以下信息：
   - 基本信息：姓名、年龄、性别
   - 主诉：主要症状
   - 生命体征：体温、脉搏、呼吸、血压、血氧饱和度
   - 过敏史：药物或食物过敏情况
   - 等待时长：已等待时间（随游戏进行增加）

3. **分诊区域**：
   - **红区（紧急）**：立即救治，生命体征不稳定或有严重症状
   - **黄区（较重）**：优先处理，病情较重但暂时稳定
   - **绿区（普通）**：常规处理，病情较轻
   - **黑区（死亡/濒死）**：死亡或抢救无望

4. **计分规则**：
   - 正确分诊：获得基础分，连续正确会有连击加成
   - 错误分诊：扣除分数，并显示错误原因
   - 风险提示：特定情况会触发提示（如胸痛伴低血压、儿童高热等）

### 游戏流程

1. **选择关卡**：点击"选择关卡"按钮，从可用关卡中选择一个
2. **开始游戏**：点击"开始游戏"按钮
3. **分诊患者**：将患者卡片拖放到相应的分诊区域
4. **查看反馈**：系统会实时显示分诊是否正确及原因
5. **暂停/继续**：游戏中可点击"暂停"按钮暂停，查看当前状态后继续
6. **游戏结束**：时间结束或所有患者处理完毕后，显示游戏结果
7. **导出报告**：游戏结束后可导出Markdown格式的训练报告
8. **查看历史**：点击"历史记录"查看过去的游戏成绩

## 关卡配置

关卡采用JSON格式定义，位于 `levels/` 目录下。每个关卡文件包含以下结构：

```json
{
  "name": "关卡名称",
  "description": "关卡描述",
  "timeLimit": 300,
  "patients": [
    {
      "id": "p001",
      "name": "张三",
      "age": 65,
      "gender": "男",
      "chiefComplaint": "胸痛2小时",
      "vitalSigns": {
        "temperature": 36.8,
        "pulse": 110,
        "respiration": 22,
        "bloodPressure": {
          "systolic": 90,
          "diastolic": 60
        },
        "oxygenSaturation": 92
      },
      "allergies": ["青霉素"],
      "correctTriage": "red",
      "riskFactors": ["胸痛伴低血压"],
      "notes": "急性冠脉综合征可能"
    }
  ]
}
```

### 字段说明

- **name**: 关卡名称
- **description**: 关卡描述
- **timeLimit**: 游戏时间限制（秒）
- **patients**: 患者列表
  - **id**: 患者唯一标识
  - **name**: 患者姓名
  - **age**: 年龄
  - **gender**: 性别
  - **chiefComplaint**: 主诉
  - **vitalSigns**: 生命体征
    - **temperature**: 体温（摄氏度）
    - **pulse**: 脉搏（次/分）
    - **respiration**: 呼吸（次/分）
    - **bloodPressure**: 血压
      - **systolic**: 收缩压
      - **diastolic**: 舒张压
    - **oxygenSaturation**: 血氧饱和度（%）
  - **allergies**: 过敏史列表
  - **correctTriage**: 正确分诊区域（red/yellow/green/black）
  - **riskFactors**: 风险因素列表（用于提示）
  - **notes**: 备注信息

## 分诊规则说明

### 红区（紧急）指征

- 呼吸心跳骤停
- 严重呼吸困难
- 休克（收缩压<90mmHg）
- 昏迷
- 抽搐发作
- 严重创伤
- 急性胸痛伴生命体征不稳定
- 急性脑卒中
- 药物过量伴意识障碍
- 严重过敏反应

### 黄区（较重）指征

- 急性胸痛但生命体征稳定
- 腹痛较剧烈
- 高热（>39℃）
- 中度创伤
- 眩晕、呕吐
- 呼吸困难但生命体征稳定
- 急性尿潴留
- 精神状态改变

### 绿区（普通）指征

- 轻微创伤
- 轻度发热
- 感冒症状
- 慢性疾病常规复诊
- 轻微疼痛
- 皮肤问题

### 黑区（死亡/濒死）指征

- 明确死亡
- 不可逆性昏迷
- 严重创伤无生命体征
- 终末期疾病病情恶化

## 特殊风险提示规则

- **胸痛伴低血压**：提示可能为急性心肌梗死或主动脉夹层
- **儿童高热**：提示需警惕热性惊厥，触发复测提示
- **意识改变伴发热**：提示可能为中枢神经系统感染
- **外伤伴低血压**：提示可能为失血性休克
- **过敏史用药**：提示需注意药物过敏风险

## 训练报告导出

游戏结束后，点击"导出报告"按钮，将生成一份Markdown格式的训练报告，包含以下内容：

- 基本信息：玩家、日期、关卡
- 游戏结果：总分数、准确率、平均反应时间
- 详细统计：各分诊区域正确/错误数量
- 错误案例分析：错误分诊的患者及正确答案
- 学习建议：根据表现提供的改进建议

## 验证主流程

1. 启动应用后，点击"选择关卡"
2. 选择 "基础关卡"
3. 点击"开始游戏"
4. 尝试将第一个患者拖放到不同区域，观察系统反馈
5. 完成所有患者处理或时间结束后，查看游戏结果
6. 点击"导出报告"验证报告生成功能
7. 点击"历史记录"验证成绩存储功能
