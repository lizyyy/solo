# 客服聊天意图聚类和质检台

一个本地运行的轻量级客服聊天分析工具，专为小团队设计。无需外部大模型、无需 API Key，完全本地运行。

## ✨ 功能特性

### 🎯 意图聚类分析
- **TF-IDF + KMeans 算法**: 使用经典的文本聚类算法，完全本地计算
- **中文分词支持**: 集成 jieba 分词，自动识别客服场景关键词
- **簇管理**: 支持手动合并簇、重命名簇
- **满意度分析**: 每个簇展示平均满意度、满意度分布

### ✅ 质检规则引擎
- **预设规则**: 包含8类常用质检规则
  - 退款时效承诺检查
  - 投诉安抚检查
  - 改地址确认检查
  - 催发货回复检查
  - 优惠券问题处理
  - 负面词汇规避
  - 回复完整性检查
  - 首次问候检查
- **可自定义规则**: 支持启用/禁用规则
- **风险标记**: 高/中/低优先级问题标记

### 📊 完整工作流
1. **项目管理**: 创建、打开、删除分析项目
2. **数据导入**: 支持 CSV/Excel 文件，支持 UTF-8/GBK 编码
3. **示例数据**: 内置示例数据，一键体验
4. **导出报告**: 支持 Markdown 和 HTML 格式周报导出
5. **本地持久化**: 项目数据自动保存到本地 JSON 文件

## 📖 使用指南

### 完整工作流程

#### 第一步：创建项目
1. 点击「新建项目」按钮
2. 输入项目名称（如：2024年第5周客服数据分析）
3. 点击「创建」

#### 第二步：导入数据
**方式一：使用示例数据（推荐新手）**
1. 点击「使用示例数据体验」按钮
2. 系统自动加载预设的示例聊天数据

**方式二：上传自己的数据**
1. 点击或拖拽 CSV 文件到上传区域
2. 等待解析完成

**CSV 文件格式要求**:

| 字段名 | 必需 | 说明 | 示例 |
|--------|------|------|------|
| session_id | 是 | 会话ID/订单号 | S001, 订单123 |
| user_message | 是 | 用户消息 | 我想申请退款 |
| agent_message | 是 | 客服回复 | 您好，请问有什么可以帮您 |
| time | 否 | 时间 | 2024-04-29 09:15:00 |
| tags | 否 | 标签 | 售后, 退款 |
| satisfaction | 否 | 满意度 | 5, 4, 满意, 好评 |

#### 第三步：聚类分析
1. 调整「聚类数量」（默认8个，建议2-20）
2. 点击「运行聚类」按钮
3. 查看聚类结果：
   - 每个簇显示会话数、关键词、平均满意度
   - 点击簇卡片查看详情和样例会话
   - 双击簇名称可以重命名
   - 点击「合并簇」按钮可以多选合并

#### 第四步：质检分析
1. 点击「运行质检」按钮
2. 查看质检问题：
   - 全部问题标签页：显示所有问题
   - 待处理标签页：显示未解决的问题
   - 按簇查看标签页：按簇分组显示问题
3. 管理规则：
   - 点击「管理质检规则」
   - 可以启用/禁用特定规则
4. 处理问题：
   - 点击「标记已解决」
   - 填写处理说明

#### 第五步：导出报告
1. 选择导出格式：
   - **Markdown**: 适合编辑、分享到知识库
   - **HTML**: 适合浏览器查看、打印
2. 点击格式卡片自动下载报告

## 🔧 核心算法说明

### 文本聚类流程
```
用户消息 → 中文分词(jieba) → 停用词过滤 → TF-IDF向量化 → KMeans聚类
```

### TF-IDF 参数
- `max_features`: 1000（最大特征词数）
- `min_df`: 2（最小文档频率）
- `max_df`: 0.8（最大文档频率比例）
- `ngram_range`: (1, 2)（支持一元和二元词）

### KMeans 参数
- `n_init`: 10（多次初始化取最优）
- `random_state`: 42（固定随机种子确保可复现）

## ❓ 常见问题

### Q1: 聚类数量设多少合适？
- 建议根据数据量调整：
  - 50条以下：2-5个簇
  - 50-200条：5-10个簇
  - 200条以上：8-15个簇
- 可以先运行聚类，根据结果手动合并相似的簇

### Q2: 支持哪些 CSV 编码？
- UTF-8（推荐）
- GBK/GB2312（国内常用）
- 系统会自动尝试识别

### Q3: 数据保存在哪里？
- 项目数据保存在 `data/projects/` 目录下
- 每个项目是一个独立的 JSON 文件
- 可以直接备份这个目录

### Q4: 如何添加自定义质检规则？
- 目前版本需要修改代码：
  - 编辑 `modules/quality_checker.py` 中的 `get_default_rules()` 方法
  - 后续版本会支持界面化规则编辑

### Q5: 运行报错缺少依赖？
```bash
pip install -r requirements.txt
```
确保所有依赖都安装成功。
