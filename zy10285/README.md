# 🧊 桶装冰块配送管理系统

一个完整的桶装冰块配送管理平台，包含客户管理、订单管理、产能监控、保温箱管理、账单管理等功能。

## 功能特性

### 📋 配送看板
- 订单统计概览（总订单数、待确认、配送中、已签收）
- 订单列表筛选（状态、客户、配送日期）
- 新建订单（自动检查产能）
- 订单操作：确认、配送、签收、退款
- 订单详情查看（含操作历史时间线）

### ⚠️ 产能预警
- 按日期展示各时段产能利用率
- 三级预警：正常（≤90%）、紧张（90%-100%）、超载（>100%）
- 可视化进度条展示当前负载

### 💰 客户账单
- 按客户和日期范围查询账单
- 账单汇总统计（订单数、总金额、已退款、应收金额）
- 订单明细列表
- 支持导出CSV

### 👥 客户管理
- 客户列表展示
- 新增/编辑客户信息
- 客户基础信息管理

### 🧊 保温箱管理
- 保温箱状态统计（总数、可用、使用中）
- 保温箱列表及状态筛选
- 保温箱归还操作

## 核心业务逻辑

### 产能不足拦截
- 创建订单时自动检查对应时段产能
- 产能超过90%显示警告提示
- 产能超过100%阻止下单

### 重复加单拦截
- 使用MD5哈希（客户+规格+时段+数量+日期）检测重复订单
- 重复订单直接拦截，防止重复导入或提交

### 签收超时退款
- 配送后超过4小时未签收自动触发退款
- 自动回补时段产能

### 保温箱追踪
- 分配保温箱给客户时记录状态
- 支持归还操作，记录归还时间

## 技术栈

### 后端
- Node.js + Express
- SQLite (sqlite3)
- Day.js (日期处理)
- UUID (主键生成)

### 前端
- React 18
- React Router (路由)
- Axios (HTTP客户端)
- Day.js (日期处理)
- Vite (构建工具)

## 快速开始

### 1. 安装依赖

```bash
# 安装项目根目录依赖
npm install

# 安装前后端所有依赖
npm run install:all
```

### 2. 初始化数据库

```bash
npm run init:db
```

### 3. 启动项目

```bash
# 同时启动前后端
npm start

# 或者分别启动
# 启动后端 (端口 3001)
npm run dev:backend

# 启动前端 (端口 3000)
npm run dev:frontend
```

### 4. 访问应用

打开浏览器访问: http://localhost:3000

## API 接口

### 订单相关
- `GET /api/orders` - 获取订单列表
- `GET /api/orders/:id` - 获取订单详情
- `POST /api/orders` - 创建订单
- `POST /api/orders/:id/confirm` - 确认订单
- `POST /api/orders/:id/dispatch` - 安排配送
- `POST /api/orders/:id/sign` - 签收订单
- `POST /api/orders/:id/refund` - 退款订单
- `POST /api/orders/check-capacity` - 检查产能

### 客户相关
- `GET /api/customers` - 获取客户列表
- `GET /api/customers/:id` - 获取客户详情
- `POST /api/customers` - 创建客户
- `PUT /api/customers/:id` - 更新客户
- `GET /api/customers/:id/billing` - 获取客户账单

### 公共接口
- `GET /api/ice-specs` - 获取冰块规格
- `GET /api/delivery-slots` - 获取配送时段
- `GET /api/coolers` - 获取保温箱列表
- `POST /api/coolers/:id/return` - 归还保温箱
- `GET /api/capacity-alerts` - 获取产能预警
- `GET /api/health` - 健康检查

## 开发说明

### 添加新的冰块规格
直接在数据库 `ice_specs` 表中插入记录，或修改 `seedData.js` 脚本。

### 调整配送时段产能
修改 `delivery_slots` 表中的 `max_capacity` 字段（单位：kg）。

### 调整签收超时时长
修改 `orderService.js` 中 `checkSignTimeout` 函数的超时时间配置。
