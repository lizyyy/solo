# 🏪 摊位布置预演工具 (Booth Planner 3D)

一款用于市集/展会摊位规划的 3D 工具，帮助你在现场布置前预演摊位布置，避免实际摆放时才发现问题。

## ✨ 核心功能

### 📐 场地与物件
- **可调整尺寸的场地网格**：支持自定义场地宽度、深度
- **丰富的物件库**：
  - 🪑 家具类：长条桌、方桌、圆形展台
  - 🖼️ 展示类：层架展架、立式展架、主视觉墙
  - 🔌 基础设施：收银台、电源插座、电源线
  - 🚪 标记类：入口、出口
  - 📐 区域类：安全通道

### 🎮 交互编辑
- **拖动**：鼠标左键拖动物件
- **旋转**：键盘 Q/E 键 (-45°/+45°) 或属性面板精确调整
- **缩放**：属性面板调整物件尺寸
- **网格吸附**：自动对齐网格，也可切换为自由模式
- **3D视角控制**：
  - 鼠标滚轮：缩放
  - 鼠标中键拖动：旋转视角
  - 快捷键 1/2/3/4：切换预设视角（顶/前/侧/透视）

### ✅ 智能检查引擎
用户最关心的实用检查功能：

| 检查项 | 说明 | 严重级别 |
|--------|------|----------|
| **边界检查** | 物件不能超出场地边界 | 🔴 错误 |
| **碰撞检查** | 桌子/展架之间不能互相穿模 | 🔴 错误 |
| **通道检查** | 安全通道不可被占用，宽度符合要求 | 🔴 错误 |
| **通路检查** | 入口到收银台、入口到出口要有通路 | 🔴 错误 |
| **视线检查** | 展架是否遮挡入口看向主视觉墙的视线 | 🟡 警告 |
| **基础检查** | 方案完整性提示 | 🔵 信息 |

### 💾 数据管理
- **自动保存**：方案实时保存到浏览器 LocalStorage
- **JSON 导入导出**：方案文件可分享、可备份
- **示例方案**：内置 3 个预设方案供参考

### 📄 报告生成
- **Markdown 报告**：适合技术文档
- **HTML 报告**：美观的可视化报告，包含：
  - 检查摘要统计
  - 物件清单列表
  - 详细问题及建议方案
  - 场地信息统计

## 🚀 快速开始

### 环境要求
- Node.js >= 16.0.0
- npm >= 7.0.0 或 yarn

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

### 预览生产构建

```bash
npm run preview
```

### 类型检查

```bash

```

## 🎯 使用指南

### 1. 加载示例方案
1. 点击顶部工具栏的 **「示例」** 按钮
2. 选择一个预设方案：
   - `基础标准摊位 (3m x 6m)` - 适合小型展会的标准布置
   - `转角展位 (6m x 6m)` - L型转角位置的布置示例
   - `问题布置示例` - 包含多个违规布置，用于测试检查功能

### 2. 添加物件
1. 在左侧 **「物件库」** 面板
2. 按分类浏览（全部/家具/展示/基础设施/标记/区域）
3. 点击任意物件即可添加到场景中心

### 3. 编辑物件
- **选择**：鼠标左键点击场景中的物件
- **移动**：选中后按住左键拖动
- **旋转**：选中后按 `Q` (逆时针45°) 或 `E` (顺时针45°)，或在属性面板精确输入角度
- **调整尺寸**：在右侧属性面板修改尺寸数值
- **删除**：选中后按 `Delete` 或 `Backspace` 键，或点击属性面板的「删除物件」按钮

### 4. 检查问题
1. 查看右侧 **「检查结果」** 面板
2. 点击 **「刷新」** 按钮运行最新检查
3. 根据严重级别（错误/警告/信息）查看问题
4. 每个问题都附带 **💡 建议调整方案**

### 5. 生成报告
1. 点击顶部工具栏的 **「检查报告」** 按钮
2. 选择报告格式：
   - **确定**：导出美观的 HTML 报告
   - **取消**：导出 Markdown 格式报告
3. 报告将自动下载

### 6. 导入导出方案
- **导出**：点击 **「导出」** 按钮，方案将保存为 JSON 文件
- **导入**：点击 **「导入」** 按钮，选择之前导出的 JSON 文件

## 🔍 检查规则详解

### 1. 边界检查 (BoundaryCheckRule)
检查所有实体物件（桌子、展架、收银台）是否超出场地边界。
- 计算物件旋转后的边界盒 (Bounding Box)
- 与场地边界进行比较
- 报告超出的方向和距离

### 2. 碰撞检查 (CollisionCheckRule)
检查实体物件之间是否发生重叠/穿模。
- 使用轴对齐边界盒 (AABB) 碰撞检测
- 避免重复报告同一对碰撞
- 支持旋转后物件的碰撞检测

### 3. 安全通道检查 (SafetyAisleCheckRule)
检查安全通道是否被占用，以及宽度是否符合要求。
- 物件不能与安全通道区域重叠
- 通道宽度需 >= `最小通道宽度` 设置

### 4. 通路检查 (PathfindingCheckRule)
使用 BFS 寻路算法检查：
- **入口 → 收银台**：顾客能否顺畅到达收银台
- **入口 → 出口**：顾客能否顺畅进出

算法原理：
- 将场地离散化为网格 (0.5m 精度)
- 障碍物占据的网格标记为不可通行
- 使用 BFS 寻找最短路径

### 5. 视线检查 (LineOfSightCheckRule)
检查从入口看向主视觉墙的视线是否被遮挡。
- 在入口中心与主视觉墙中心之间采样多个点
- 检查采样点是否被桌子或展架遮挡

### 6. 基础检查 (BasicRequirementsCheckRule)
检查方案的完整性：
- 是否设置了入口
- 是否设置了出口（可选，入口可兼作出口）
- 是否有收银台
- 是否有主视觉墙（视线检查需要）
- 方案是否为空
