# 潮汐能站异常预警 · 值班员使用手册（小宋专用）

> 适用场景：每天巡检数据回来以后，花 5~10 分钟跑一遍，
> 把经纬度写法不统一、站点名字写得五花八门、采样瓶重复录入
> 这些坑先筛出来，再交给下一步。

---

## 先跑哪条命令？（新手按顺序）

```bash
cd tidal-warning

# 第 1 步：跑完整流程（必读的一步，跑完看输出）
python tidal_warning.py run

# 跑完如果有补录，加一条备注（可选但推荐）
python tidal_warning.py run --append-note "6月16日补小门岛方向修正、江厦经度转正"

# 第 2 步：看交接状态（接班/交班都要跑）
python tidal_warning.py status

# （辅助）忘了标准站点名怎么写？
python tidal_warning.py stations
```

---

## 先看哪份异常队列？

跑完 `run` 以后，系统会在 `queue/` 目录生成 5 份 CSV，
**按优先级从高到低**顺序看：

| 序号 | 队列文件 | 看什么 | 什么时候能放行 |
|---|---|---|---|
| ① | `queue/异常队列-采样瓶重复.csv` | 瓶号重复是否串站点、数值是否打架 | 对照签领本+仪器日志确认后删错条 |
| ② | `queue/异常队列-经纬度格式.csv` | 写法不统一和解析失败的条目 | 对照 `logs/coord_format_report_YYYYMMDD.md` 那张表+遥感截图 |
| ③ | `queue/异常队列-站点名称.csv` | 别名替换过、模糊匹配到的 | `放行标记=是`的别名可直接放，`放行标记=否`需看交接备注 |
| ④ | `queue/异常队列-数据质量.csv` | 坏行、空行、截断 | 原始CSV重导出即可 |
| ⑤ | `queue/异常队列-待补充材料.csv` | 还缺什么材料 | 材料到了补录再重跑 |

## 输出数字怎么读？

`run` 命令输出不再只给一个"总数"，会拆开讲：

```
原始行数(不含表头): 25
├─ 已处理: 22 行   ← 格式完整、进入清洗的
├─ 跳过行:  2 行   ← 空行、只有逗号的，直接略过不处理
└─ 坏  行:  1 行   ← 列数不足、结构坏的，必须找原始数据重导
```

这三类要**分开算、分开说**，汇报给站长的时候不能只说"处理了22条"，
要把跳过和坏行的原因也带上。

## 采样瓶重复了怎么办？

系统会把每组重复的：
- **影响范围**讲清楚（同站点重复录？还是跨站点串瓶？数值还不一致？）
- **收尾建议**直接给（删哪条、对照哪本原始记录本）

常见三种情况：
1. **同站点数值完全一样** → 重复点了保存，保留行号最小的那条
2. **同站点数值不一样** → 仪器日志为准，保留仪器时间戳那条
3. **跨站点用了同个瓶号** → 一定是串瓶了，找"采样瓶签领登记本"核对归属

## 补录以后导出变了哪里？

只要 `run` 的时候加了 `--append-note "说明文字"`，
系统会自动在 `logs/` 下生成一份 `diff_时间戳.md`，
列出本次补录让导出文件 `data/exports/cleaned_export.csv` 发生了：

- 新增了几行
- 删除了几行
- 哪些单元格从什么值改成了什么值（行号、字段、原值、新值）

这份 diff 交班时一起打印出来，接手同事一眼能看到这次改了什么。

## 交接状态看什么？

`python tidal_warning.py status` 会给一张看板：

```
▌可放行的 → 已由系统自动核对，可直接归档，不用再花时间
▌缺材料的 → 先打 ☎ 给现场催材料，补齐后再补录重跑
▌其余待处理 → 对照下面的遥感截图和交接板人工确认
```

每条异常都带有：
- `放行标记=是`：接班时不用再看
- `缺材料说明=xxx`：先把 xxx 材料要到再说
- `交接备注`：上一班（比如老李、老赵）写的处理线索

## 常见问题（Q&A）

**Q: 经纬度写法太多了，我怎么知道哪种是对的？**
A: 不用死记，系统会统一成 `度°分′秒″方向符` 格式，
   详细对照看 `logs/coord_format_report_YYYYMMDD.md` 那张 Markdown 表，
   拿着它和贴在交接板上的遥感截图一一对应就好。

**Q: 站点名称我写了"双合站"会不会被算错？**
A: 不会，系统有别名表（`python tidal_warning.py stations` 能看），
   "双合站""双合潮汐站""岱山双合潮汐站"都会自动替换成标准名
   `舟山岱山双合潮汐能站`，而且这条会标记"可放行"。

**Q: 接手同事问"今天这些数据能不能交出去？"**
A: 先跑 `status`，`缺材料=0`且`待处理-缺材料`的条目都补完以后，
   就可以交；否则把缺材料清单打出来一起交，注明什么时候补。
