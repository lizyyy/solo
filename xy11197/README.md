# 小学校服订购点校服批次分拣CLI工具

专门为小学校服订购点设计的订单分拣工具，支持换码、缺货、同名学生等特殊情况的分离处理。

## 功能特点

- ✅ **分类清晰**: 正常订单与特殊情况（换码、缺货、同名学生）完全分开
- ✅ **异常追踪**: 每条数据记录来源文件和行号，便于定位问题
- ✅ **可复跑**: 重复执行不混乱，支持 `--force` 参数覆盖
- ✅ **新人友好**: 命令简单、输出清晰、样例齐全

## 安装方式

### 方式一：可编辑安装（推荐）

```bash
cd 项目目录
pip install -e .
```

安装完成后，全局可用 `校服分拣` 命令。

## 快速开始

### 第一步：查看命令帮助

```bash
校服分拣 --help
```

### 第二步：生成示例数据

```bash
校服分拣 example
```

会在当前目录生成 `示例数据` 文件夹，包含完整的样例订单。

### 第三步：运行分拣

```bash
校服分拣 样例数据/正常 分拣结果
```

## 输入文件格式

### 必填列

| 列名 | 说明 | 示例 |
|------|------|------|
| 学校名称 | 学校全称 | 第一小学 |

| 数量 | 订购数量 | 1、2 |

| 列名 | 说明 | 特殊标记 |
|------|------|----------|
| 备注 | 备注信息 | 含"换码"→换码订单<br>含"缺货"→缺货订单 |

## 异常摘要说明

`异常摘要.csv` 是给运营同事修数据用的，包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| 来源文件 | 哪个文件出的问题 | 第三小学_问题数据.csv |
| 行号 | 文件的第几行（从1开始） | 3 |
| 错误类型 | 什么类型的错误 | 数据格式错误 |
| 错误信息 | 具体错误内容 | 学生姓名不能为空 |
| 原始数据 | 这一行的原始数据 | {'学生姓名': '', ...} |

运营同事可以直接打开 `异常摘要.csv`，根据来源文件和行号找到对应的数据，修改完成后重新运行分拣即可。

## 常见问题

### Q: 什么情况会被识别为"同名学生"？
A: **同一学校、同一年级、同一班级、同一姓名**的多条订单会被标记为同名学生。同名的订单都不会出现在正常订单中，需要人工核对学号后再处理。

### Q: 换码和缺货是怎么识别的？
A: 根据"备注"列的关键词：
- 备注含"换码"或"换尺码" → 换码订单
- 备注含"缺货"或"无货" → 缺货订单

### Q: 输出文件里的"来源文件"和"行号"有什么用？
A: 方便追溯，特别是发现数据有问题时，可以快速定位到原始文件的具体位置。

### Q: 可以处理Excel文件吗？
A: 目前只支持CSV格式。如果是Excel文件，请另存为UTF-8编码的CSV。
