# 采血窗口排队复盘工具

为医院采血窗口护士长设计的本地排队分析工具，帮助分析等待时长、窗口利用率、超时风险和异常样本，支持图表可视化和数据导出。

## 功能特性

- **数据导入**: 支持导入叫号记录 CSV、窗口开闭时间 CSV
- **核心指标计算**: 等待时长、窗口利用率、超时风险、异常样本占比
- **图表可视化**: 多维度图表展示不同窗口/时段/项目的瓶颈
- **人工备注**: 支持保存人工备注到 SQLite，刷新后可回看
- **导出功能**: 导出 Markdown 复盘报告和 CSV 改班建议

## 使用指南

### 一、导入数据

#### 1. 准备数据文件

**必填：叫号记录 CSV** (`queue_records.csv`)

字段说明：

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| ticket_number | 字符串 | 叫号单号 | A001 |
| patient_type | 字符串 | 患者类型 | 老年患者/普通患者 |
| specimen_type | 字符串 | 标本类型 | 血常规/生化全套/血糖/凝血功能 |
| is_fasting | 布尔 | 是否空腹项目 | True/False |
| is_elderly | 布尔 | 是否老年患者 | True/False |
| arrival_time | 时间 | 到达时间 | 07:30:00 或 2024-01-01 07:30:00 |
| start_time | 时间 | 开始服务时间 | 07:55:00 |
| end_time | 时间 | 服务结束时间 | 08:02:00 |
| window_number | 整数 | 窗口号 | 1/2/3 |
| status | 字符串 | 状态 | 已完成/其他 |
| is_abnormal | 布尔 | 是否异常样本 | True/False |
| abnormal_reason | 字符串 | 异常原因 | 溶血/血量不足/凝块 |

**可选：窗口开闭时间 CSV** (`window_schedule.csv`)

| 字段名 | 类型 | 说明 |
|--------|------|------|
| window_number | 整数 | 窗口号 |
| open_time | 时间 | 开门时间 |
| close_time | 时间 | 关门时间 |
| is_open | 布尔 | 是否开放 |

#### 2. 导入操作

1. 打开 Web 界面 http://localhost:5000
2. 在"数据导入"区域：
   - 选择"分析日期"（默认为当天）
   - 点击"叫号记录 CSV"选择你的数据文件
   - （可选）点击"窗口开闭时间 CSV"选择窗口时间文件
3. 点击"📤 导入数据"按钮
4. 导入成功后，页面会显示"成功导入 X 条叫号记录"的提示

#### 3. 验证导入

- 页面显示绿色成功提示
- 点击"🔍 分析当前数据"按钮
- 应该看到"分析结果"区域显示出来
- 核心指标卡片显示数据（总患者数、老年患者等）

#### 4. 使用示例数据测试

项目提供了示例数据，可用于测试：

1. 点击页面上的"📥 下载示例数据"按钮
2. 或直接使用 `sample_data/` 目录下的文件：
   - `sample_data/queue_records.csv`
   - `sample_data/window_schedule.csv`

### 二、数据分析

导入数据后，系统自动计算以下指标：

#### 1. 核心指标

- **总患者数**：当天所有患者数量
- **老年患者**：65岁以上老年患者数量
- **空腹项目**：需要空腹的检查项目数量
- **异常样本**：采血失败或异常的样本数量
- **平均等待时间**：所有患者的平均等待时长
- **最长等待时间**：单个患者的最长等待时长

#### 2. 图表分析

切换到"📈 图表分析"标签页，可查看：

1. **各时段患者数量分布** - 柱状图，展示哪些时段患者最多
2. **各时段平均等待时间** - 折线图，展示等待时间的变化趋势
3. **老年/空腹患者对比** - 分组柱状图，对比特殊人群分布
4. **异常样本占比** - 饼图，展示正常与异常样本比例

#### 3. 超时风险分析

切换到"⚠️ 超时风险"标签页：

- **风险等级分布**：
  - 高风险：等待 > 30分钟
  - 中风险：等待 20-30分钟
  - 低风险：等待 < 20分钟

- **重点关注人群**：
  - 老年患者超时率
  - 空腹项目超时率

#### 4. 窗口利用率

切换到"🪟 窗口利用率"标签页：

- 表格展示各窗口的：
  - 服务患者数
  - 总服务时长
  - 累计服务时长
  - 利用率百分比
  - 状态（正常/繁忙/过载）

- 柱状图对比各窗口利用率

#### 5. 标本类型分析

切换到"🧪 标本类型"标签页：

- 表格展示各标本类型的：
  - 样本数
  - 平均等待时间
  - 最长等待时间
  - 异常率
  - 风险等级

- 柱状图对比等待时间分布

### 三、保存和查看人工备注

#### 1. 添加备注

1. 切换到"📝 备注管理"标签页
2. 在左侧"添加备注"区域：
   - **时段**：选择备注针对哪个时段（或选择"全天"）
   - **窗口号**：选择针对哪个窗口（或选择"全部窗口"）
   - **备注类型**：问题记录/改进建议/特殊情况/其他
   - **备注内容**：输入详细的备注文字
3. 点击"💾 保存备注"按钮
4. 弹出"备注保存成功！"提示

#### 2. 查看备注

- 备注保存后，立即显示在右侧"已有备注"区域
- 每条备注显示：
  - 备注类型和时段
  - 关联的窗口号
  - 备注内容

#### 3. 验证备注持久化

备注保存到 SQLite 数据库，可通过以下方式验证：

1. 添加一条备注
2. **刷新浏览器页面**（或重新打开浏览器）
3. 点击"🔍 分析当前数据"
4. 切换到"📝 备注管理"标签页
5. **之前添加的备注应该仍然存在**

### 四、导出功能

#### 1. 导出 Markdown 复盘报告

1. 确保已导入并分析数据
2. 点击页面底部"📝 导出 Markdown 复盘报告"按钮
3. 浏览器自动下载 `.md` 文件

**报告内容包括**：
- 整体概况（指标表格）
- 超时风险分析（风险等级分布、重点人群）
- 窗口利用率分析
- 标本类型分析
- 人工备注
- 改进建议

#### 2. 验证 Markdown 导出

- 检查下载的文件：`queue_analysis_YYYY-MM-DD.md`
- 用 Markdown 编辑器打开（如 VS Code、Typora）
- 确认包含所有分析数据

#### 3. 导出 CSV 改班建议

1. 点击页面底部"📊 导出 CSV 改班建议"按钮
2. 浏览器自动下载 `.csv` 文件

**改班建议内容**：
- 日期
- 时段
- 当前窗口数
- 建议窗口数
- 患者数
- 老年患者数
- 空腹项目数
- 平均等待时间
- 建议类型（增开窗口/老年高峰/空腹高峰/可减少）
- 建议原因

**建议逻辑**：
- **增开窗口**：患者数 > 15 或 平均等待 > 20分钟
- **老年高峰**：老年患者 > 5人
- **空腹高峰**：空腹项目 > 8人
- **可减少**：患者数 < 5人

#### 4. 验证 CSV 导出

- 检查下载的文件：`shift_recommendation_YYYY-MM-DD.csv`
- 用 Excel 或 Numbers 打开
- 确认包含所有列和数据

## 数据库说明

项目使用 SQLite 数据库 `queue_analysis.db`，包含以下表：

### 1. QueueRecord (叫号记录表)

存储所有导入的叫号记录

### 2. WindowSchedule (窗口时间表)

存储窗口开闭时间安排

### 3. ManualNote (人工备注表)

存储用户添加的备注，支持持久化

### 4. ShiftRecommendation (改班建议表)

预留表，可用于存储历史建议

## 常见问题

### Q1: 导入数据时提示编码错误？

**解决**：确保 CSV 文件使用 UTF-8 编码保存。
- Windows：另存为时选择"UTF-8"编码
- macOS：默认就是 UTF-8

### Q2: 时间格式不识别？

**支持的时间格式**：
- `07:30:00` (HH:MM:SS)
- `07:30` (HH:MM)
- `2024-01-01 07:30:00` (完整日期时间)
- `2024/01/01 07:30:00` (斜杠分隔)

### Q3: 备注刷新后消失？

**检查**：
1. 确认数据库文件 `queue_analysis.db` 存在
2. 确认保存备注时弹出成功提示
3. 确认分析日期选择正确（备注与日期关联）

### Q4: 图表不显示？

**检查**：
1. 确认网络连接正常（Chart.js 从 CDN 加载）
2. 打开浏览器开发者工具查看是否有报错
3. 确认已成功导入数据
