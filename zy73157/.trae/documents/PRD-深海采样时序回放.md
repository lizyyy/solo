## 1. 产品概述
深海采样时序回放交班工具 — 让港口工程师老何不用翻船上记录本就能说清楚风险，项目经理从汇总一路追到异常记录。
- 解决问题：历史报告只剩平均值掩盖风险、船上记录本散乱、撤回记录埋在备注、传感器漂移靠人眼、变动原因断链
- 目标用户：港口值班工程师（老何）、深海采样项目经理
- 产品价值：交班时能直接调出带空间位置、异常高亮、记录本来源的时序回放视图，状态分明可追溯

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 港口工程师 | 本地工具 | 查看时序回放、标记异常、整理记录本来源、交班导出 |
| 项目经理 | 本地工具 | 查看汇总面板、追溯异常记录、导出进展交代视图 |

### 2.2 功能模块
1. **汇总面板**：已处理 / 待补证据 / 卡着的记录分类统计，总览风险分布
2. **时序回放主界面**：采样点空间位置、时间轴播放、异常高亮、传感器漂移影响范围标记
3. **追溯链路面板**：从汇总卡片 → 异常记录 → 船上记录本来源行（含撤回记录专门展示）
4. **进展交代视图**：项目经理专用，可直接拿去沟通

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-----------|----------------|
| 汇总面板 | 状态分类卡片 | 已处理/待补证据/卡着的 三类统计 + 异常总数、撤回记录、传感器漂移影响范围概览 |
| 时序回放 | 空间位置地图 | 采样站位平面示意，可点击切换站点 |
| 时序回放 | 时间轴播放 | 拖动/播放/暂停，按时间推进展示各传感器数据 |
| 时序回放 | 异常高亮 | 超阈值点红色标记，悬浮显示异常详情 |
| 时序回放 | 传感器漂移区 | 浅橙色半透明覆盖受漂移影响的时间范围，标注来源行号 |
| 追溯链路 | 记录本来源面板 | 左侧异常点 → 右侧船上记录本页（含行号、原文、修改人、时间） |
| 追溯链路 | 撤回记录专区 | 单独列出已撤回采样记录，标注撤回原因、替代数据、是否已补证据 |
| 进展交代视图 | 项目经理沟通卡片 | 按状态分组的异常清单 + 每条含：描述、处理状态、证据链、下一步动作 |

## 3. 核心流程
工程师打开工具 → 汇总面板一眼看到风险分布 → 点击"卡着的记录"或异常点进入时序回放 → 时间轴上看到异常高亮和漂移影响范围 → 点击异常点 → 右侧联动显示船上记录本对应行原文（含撤回原因） → 切换到"进展交代"视图 → 导出/截图直接给项目经理交代

## 4. 用户界面设计
### 4.1 设计风格
- 主色：深海蓝 (#0A2540) 搭配 警示红 (#E63946) + 琥珀橙 (#F4A261) 作为状态色：已处理(#2A9D8F) / 待补证据(#F4A261) / 卡着(#E63946)
- 字体：等宽字体呈现数据，衬线字体呈现记录本原文（打字机感）
- 布局：左侧汇总卡片列 + 中间时序回放区 + 右侧来源追溯面板
- 风格：工业航海风，深色主题，带轻微网格背景纹理

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|----------|
| 汇总面板 | 状态卡片 | 三列大数字 + 趋势小图 + 列表预览
| 时序回放 | 空间位置 | 圆形站位点，异常点红色脉冲
| 时序回放 | 时序图 | SVG 折线，异常点红色圆点，漂移区橙色半透明带
| 追溯面板 | 记录本原文 | 打字机字体，行号，高亮当前行
| 进展视图 | 沟通卡片 | 清晰分组，状态标签，可复制文本

### 4.3 响应式
桌面端优先（工程师/项目经理在办公室大屏查看），右侧面板可折叠

### 4.4 动效
- 异常点脉冲呼吸动画
- 时间轴播放时数据点依次淡入
- 点击异常点时记录本行高亮滚动
