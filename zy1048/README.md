# 🎨 贴纸小样拼版工具

一个用于手账贴纸、钥匙扣小卡等周边小样排版的 Web 前端工具。支持素材导入、画布排版、实时问题检查、导出预览等功能。

## ✨ 功能特性

### 📦 素材管理
- 支持导入 PNG 和 SVG 格式的透明素材
- 素材库管理，支持拖拽到画布
- 添加自定义文字标签，支持字体大小和颜色调整

### 🎨 画布排版
- 支持 A4、A5 标准尺寸和自定义尺寸
- 可设置出血线和安全区
- 吸附对齐功能（网格对齐、对象对齐）
- 素材可拖拽、缩放、旋转
- 支持层级调整（上移/下移一层）
- 透明度调节

### ⚠️ 实时问题检查
- 素材越过安全区警告
- 素材越界错误提示
- 裁切边太近警告
- 素材重叠错误提示
- 素材未命名提示
- 工艺备注缺失提醒
- 点击问题可跳转到对应素材

### 💾 数据管理
- 本地存储保存草稿
- 导入/导出工程 JSON 文件
- 操作历史记录，支持撤销/重做

### 🖨️ 导出功能
- 导出 PNG 预览（高分辨率）
- 导出 SVG 矢量预览
- 导出 Markdown 格式印前清单
  - 包含画布基本信息
  - 详细的素材清单
  - 所有风险提醒
  - 打印建议

## 🚀 快速开始

### 方法一：直接打开
1. 克隆或下载本项目
2. 用浏览器直接打开 `index.html` 文件

### 方法二：本地服务器（推荐）
使用 Python 启动简单的 HTTP 服务器：

```bash
# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```

然后在浏览器中访问 `http://localhost:8080`

或者使用 Node.js 的 `http-server`：

```bash
# 安装（如果还没有）
npm install -g http-server

# 启动
http-server -p 8080
```

## 📖 使用指南

### 1. 导入素材
- 点击左侧面板的「导入素材」按钮
- 选择 PNG 或 SVG 文件（支持多选）
- 素材会显示在左侧素材库中

### 2. 添加素材到画布
- 方法一：双击素材库中的素材
- 方法二：将素材从素材库拖拽到画布

### 3. 添加文字标签
- 在左侧面板「添加文字标签」区域输入文字
- 调整字体大小和颜色
- 点击「添加到画布」按钮

### 4. 操作画布上的素材
- **移动**：直接拖拽素材
- **缩放**：拖拽素材边角的蓝色圆点
- **旋转**：拖拽素材顶部的紫色圆点
- **选择**：点击素材即可选中
- **删除**：选中后按 Delete 键或点击属性面板的「删除」按钮

### 5. 设置画布
- 在画布上方的控制面板中：
  - 选择画布尺寸（A4/A5/自定义）
  - 设置出血线大小（默认 3mm）
  - 设置安全区大小（默认 5mm）
  - 选择吸附对齐模式
  - 点击「应用」按钮生效

### 6. 设置素材属性
选中素材后，右侧会显示属性面板，可以设置：
- 素材名称（建议给每个素材命名）
- 颜色/工艺备注（如 UV 烫金、白墨等）
- 精确的坐标和尺寸
- 旋转角度
- 透明度
- 层级调整

### 7. 检查问题
- 右侧「问题检查」面板会实时显示排版问题
- 点击「重新检查」按钮可以手动刷新
- 点击问题条目可以跳转到对应的素材
- 问题类型：
  - ❌ 错误：必须修复（如素材越界、重叠）
  - ⚠️ 警告：建议修复（如越过安全区、距离太近）
  - 💡 提示：可选优化（如未命名、无备注）

### 8. 保存和导出
- **保存草稿**：点击顶部「保存草稿」按钮，数据会保存到浏览器本地存储
- **加载草稿**：点击顶部「加载草稿」按钮
- **导出工程**：点击「导出工程」按钮，保存为 JSON 文件
- **导入工程**：点击「导入工程」按钮，加载之前保存的 JSON 文件
- **导出预览**：点击「导出预览」按钮，选择 PNG 或 SVG 格式
- **导出印前清单**：点击「导出印前清单」按钮，生成 Markdown 格式的清单

## 💡 使用技巧

1. **命名素材**：给每个素材起一个有意义的名字，方便印厂识别
2. **填写备注**：如有特殊工艺要求（如烫金、UV、白墨等），务必在备注中说明
3. **保持在安全区**：重要内容请保持在安全区内，避免被裁切
4. **留出裁切边距**：素材之间建议保持至少 3mm 的距离，方便裁切
5. **定期保存**：使用「保存草稿」功能定期保存，避免数据丢失
6. **导出前检查**：导出前仔细查看「问题检查」面板，确保没有错误
7. **先打样**：建议先导出预览打样确认，再批量生产

## 🐛 常见问题

**Q: 为什么有些 PNG 图片导入后不显示？**
A: 请确保图片是有效的 PNG 格式。如果是从网络下载的图片，可能需要先保存到本地再导入。

**Q: SVG 文件导入后显示不正常？**
A: 目前支持标准的 SVG 格式。复杂的 SVG（如包含滤镜、动画等）可能无法正常显示，建议简化后再导入。

**Q: 导出的 PNG 为什么没有透明背景？**
A: 导出的 PNG 默认带白色背景。如果需要透明背景，可以导出 SVG 格式，然后在专业软件中处理。

**Q: 本地存储的草稿会丢失吗？**
A: 草稿保存在浏览器的 localStorage 中，如果清除浏览器缓存或更换浏览器，数据会丢失。建议重要的工程同时导出 JSON 文件备份。
