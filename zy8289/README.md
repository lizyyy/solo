# 社区活动室预约管理系统

一个基于 Python + tkinter + SQLite 的本地桌面 GUI 工具，用于社区活动室管理员管理场地预约。

## 功能特性

### 核心功能
- **新增预约**: 添加新的场地预约记录
- **编辑预约**: 修改已有的预约信息
- **删除/恢复预约**: 软删除到回收站，支持恢复
- **查询预约**: 关键词搜索、多条件筛选

### 数据字段
- 活动名称
- 负责人
- 手机号
- 场地
- 日期时段（开始/结束时间）
- 人数
- 备注
- 状态（待确认/已确认/已取消/已完成）

### 数据验证
- **手机号格式验证**: 必须是 11 位手机号（1开头）
- **时间重叠检查**: 同一场地不能有时间重叠的预约
- **人数验证**: 1-1000 之间
- **时间范围验证**: 结束时间必须晚于开始时间

### 首页功能
- **筛选条件**: 按日期、场地、状态筛选
- **今日预约提示**: 启动时提醒今天的预约
- **操作日志**: 记录所有新增、编辑、删除、恢复操作
- **搜索功能**: 支持关键词搜索活动名称、负责人、手机号、场地、备注

### 回收站
- 软删除，数据不会真正删除
- 可查看已删除的预约列表
- 支持恢复已删除的预约

### 导出功能
- **导出 CSV**: 导出预约列表为 CSV 格式
- **导出 Markdown**: 导出预约清单为 Markdown 格式，包含表格和详细信息

## 环境要求

- Python 3.6+
- tkinter（Python 内置，通常随 Python 一起安装）
- SQLite（Python 内置）

**注意**: macOS 系统自带的 Python 可能没有 tkinter，建议使用 Homebrew 安装完整的 Python:
```bash
brew install python
```

## 使用说明

### 新增预约
1. 点击顶部「新增预约」按钮
2. 填写表单信息（带 * 为必填项）
3. 可使用快捷按钮填充常用时间段
4. 点击「保存」完成添加

**注意**: 系统会自动检查时间冲突和手机号格式。

### 编辑预约
1. 在列表中选中要编辑的预约
2. 点击「编辑」按钮，或双击列表项
3. 修改信息后点击「保存」

### 删除预约
1. 选中要删除的预约
2. 点击「删除」按钮
3. 确认后预约将移至回收站

### 恢复删除的预约
1. 点击顶部「回收站」按钮
2. 选中要恢复的预约
3. 点击「恢复选中」

### 筛选与搜索
- **日期筛选**: 下拉选择日期（包含今天、明天等快捷标签）
- **场地筛选**: 下拉选择场地
- **状态筛选**: 下拉选择状态
- **关键词搜索**: 在搜索框输入关键词，点击「搜索」按钮

### 导出数据
1. 点击「导出CSV」或「导出Markdown」
2. 选择保存位置和文件名
3. 确认保存

## 常见问题

### Q1: 启动报错说没有 tkinter？
A: macOS 用户需要安装 tkinter。使用 Homebrew 安装：
```bash
brew install python-tk@3.12
```

### Q2: 数据保存在哪里？
A: 所有数据保存在项目目录下的 `reservations.db` 文件中，这是一个 SQLite 数据库文件。可以使用任何 SQLite 工具查看。

### Q3: 如何备份数据？
A: 直接复制 `reservations.db` 文件即可。恢复时将备份文件覆盖原文件。

### Q4: 为什么删除的预约还能恢复？
A: 系统使用软删除机制，删除操作只是设置 `is_deleted` 标记为 1，数据并没有真正删除。如需彻底删除，可以直接操作数据库文件。

### Q5: 支持哪些场地？
A: 系统预设了常用场地（多功能厅、会议室A/B、活动室A/B、棋牌室），也支持手动输入新的场地名称。
