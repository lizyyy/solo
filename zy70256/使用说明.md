# 自习室座位静音巡检系统 - 使用说明

## 项目概述

这是一个纯前端的自习室座位静音巡检系统，帮助管理员快速记录座位占用状态、噪音投诉和临时锁座，替代传统的纸面巡检方式。

### 文件结构
- `index.html` - 主页面
- `styles.css` - 样式文件
- `app.js` - 核心应用逻辑
- `使用说明.md` - 本文档

### 核心功能
1. **座位平面图** - 可视化展示自习室座位布局
2. **占用状态管理** - 标记/取消座位占用
3. **噪音投诉** - 记录噪音问题并支持待复核
4. **临时锁座** - 支持15/30/60/120分钟锁座，带倒计时
5. **本地记录** - 使用localStorage持久化，刷新后自动恢复
6. **巡检导出** - 导出CSV详细记录和TXT统计摘要
7. **冲突检测** - 实时反馈操作冲突和异常

## 操作模式说明

### 查看模式（默认）
点击座位可查看详细信息，不会执行任何状态变更。

### 标记占用
点击空闲座位可将其标记为**已占用**（红色）。

**冲突拦截：**
- 已被临时锁座的座位无法标记为占用
- 已占用座位重复标记会提示

### 标记空闲
点击已占用/有噪音的座位可将其恢复为**空闲**（绿色）。

**特殊情况：**
- 已锁座座位会弹出确认框，询问是否先解锁
- 标记空闲会同时清除噪音投诉和待复核状态

### 噪音投诉
选择此模式后，先在文本框输入投诉详情，再点击目标座位。

**智能检测：**
- 如果座位本身是空闲状态，系统会自动标记为**待复核**（橙色），并添加到待复核列表
- 这是为了防止误报（空位怎么会有噪音？）

### 临时锁座
选择此模式后，先选择锁座时长（15/30/60/120分钟），再点击目标座位。

**冲突拦截：**
- 已占用的座位无法锁座
- 已锁座的座位再次点击可选择延长锁座时间

**自动解锁：**
- 锁座时间到期后系统自动解锁，恢复空闲状态
- 也可手动提前解锁

## 完整巡检流程（实战演练）

### 步骤1：准备数据
1. 打开页面，确认所有座位都是绿色（空闲）
2. 如果有历史数据，点击「重置数据」清空

### 步骤2：模拟巡检
1. 选择「标记占用」模式，点击以下座位：1、3、5、7、9
2. 选择「噪音投诉」模式，输入"大声打电话"，点击座位3
3. 选择「噪音投诉」模式，输入"吃东西声音大"，点击座位10（空位）
   - 注意：座位10会变成橙色（待复核），因为它本身是空闲的
4. 选择「临时锁座」模式，选择30分钟，点击座位15

### 步骤3：查看统计
- 左侧统计面板应显示：
  - 已占用：5
  - 噪音投诉：2
  - 临时锁座：1
  - 待复核：1

### 步骤4：处理待复核
1. 右侧「待复核事项」面板显示座位10的投诉
2. 点击「驳回」（假设是误报）
   - 座位10恢复绿色
   - 待复核数量变为0
   - 噪音投诉数量变为1

### 步骤5：观察锁座倒计时
- 右侧「锁座倒计时」面板显示座位15的剩余时间
- 点击「提前解锁」可立即释放
- 或等待自动解锁

### 步骤6：导出报告
1. 点击「导出巡检记录」，下载CSV文件
2. 用Excel打开，查看所有座位的详细状态
3. 点击「导出统计摘要」，下载TXT文件
4. 查看统计数据和最近操作记录

### 步骤7：验证持久化
1. 记录当前座位状态
2. 刷新浏览器页面
3. 系统会自动恢复上次的工作区
4. 座位状态、锁座倒计时、历史记录都应保持不变

## 冲突和拦截场景汇总

| 场景 | 操作 | 系统行为 | 提示消息 |
|------|------|----------|----------|
| 锁座上尝试占用 | 标记占用已锁座座位 | 拦截操作 | "已被临时锁座，无法标记为占用" |
| 占用上尝试锁座 | 锁座已占用座位 | 拦截操作 | "已被占用，无法锁座" |
| 标记空闲（已锁座） | 标记空闲已锁座座位 | 弹出确认框 | "已被临时锁座，是否先解锁？" |
| 空位噪音投诉 | 噪音投诉空闲座位 | 标记待复核 | "空位但记录了噪音投诉，已标记为待复核" |
| 噪音无说明 | 投诉时未输入详情 | 拦截操作 | "请输入噪音投诉详情" |
| 重复相同状态 | 多次点击同一操作 | 提示警告 | "已处于XX状态" |
| 已锁座再次点击 | 锁座模式点击已锁座 | 弹出延长确认 | "是否延长30分钟？" |

## 注意事项

1. **数据存储**：所有数据存在浏览器localStorage中，清除浏览器数据会丢失
2. **多房间**：支持两个自习室，数据独立存储
3. **刷新恢复**：刷新页面自动恢复，但不包含倒计时的精确秒数（会有1秒误差）
4. **离线使用**：纯前端应用，无需服务器
5. **浏览器支持**：推荐Chrome、Firefox、Safari最新版本

## 常见问题

**Q: 刷新页面后锁座时间准吗？**
A: 基本准确，误差在1-2秒内。系统记录的是锁座结束的绝对时间点。

**Q: 如何备份数据？**
A: 使用「导出巡检记录」功能，CSV文件可作为备份。

**Q: 两个自习室的数据会混吗？**
A: 不会，每个自习室的数据独立存储，切换时自动切换数据。

**Q: 噪音投诉输入了中文，导出会乱码吗？**
A: 不会，CSV使用UTF-8 BOM格式，Excel打开正常显示中文。
