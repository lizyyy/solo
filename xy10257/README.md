# ⛰️ 山地步道救援定位板

一个用于山地步道救援场景的定位与调度系统原型。在高差路径上快速定位报警点、补给点和救援队位置，实现智能调度。

## 项目简介

本系统解决山地步道救援时的核心问题：在复杂高差路径上，如何快速判断报警点位置、选择最佳救援队伍、估算到达时间，并生成详细的路线报告。

**核心辨识度：**
- 🌄 **山地高差计算**：不仅考虑平面距离，更重要的是海拔高度变化对救援时间的影响
- 🚁 **救援队位置动态管理**：支持在地图上拖拽救援队到任意节点
- ⏱️ **智能到达估算**：综合距离、高差、风险多重因素计算ETA

## 核心算法

### 高差权重路径查找

```javascript
// Dijkstra 算法变体，考虑海拔因素
findShortestPath(startId, endId, useElevation = false) {
  // 距离 = 平面距离 + 海拔差 * 权重
  if (useElevation) {
    distance += Math.abs(elevationDiff) * 0.1;
  }
}
```

### ETA 计算公式

```
总时间 = 基础时间 + 高差惩罚 + 风险惩罚

基础时间 = 距离 / 队伍速度
高差惩罚 = 爬升高度 * 0.002 + 下降高度 * 0.001
风险惩罚 = Σ(节点风险等级 * 1.5)
```

**示例计算（TEAM_B → N6）：**
- 距离：260单位，速度：12km/h
- 基础时间：260/12 ≈ 21.7分钟
- 爬升420m：420×0.002 = 0.84分钟
- 下降0m：0分钟
- 风险节点N5(4) + N6(2)：6×1.5 = 9分钟
- **总时间：21.7+0.84+9 ≈ 31.5分钟（约27-30分钟）**

### 风险评估

```javascript
overallRisk = max(maxRisk, avgRisk + elevationGain * 0.001)
```

综合考虑：
1. 路径中的最高风险节点
2. 路径平均风险
3. 总爬升高度的额外风险
