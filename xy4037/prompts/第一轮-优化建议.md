原始想法：
我想做一个给客服质检小组用的本地 AI/ML 命令行工具，叫“投诉工单相似簇助手”。我们每周会从客服系统导出几千条工单 CSV，里面有用户描述、渠道、产品线、时间、处理人和最终处理结论，现在靠人工翻表找重复投诉和新冒出来的问题，既慢又容易被模板话术干扰。请从 0 到 1 做一个可运行的 Python CLI 项目：init 命令能创建项目配置，维护停用词、需要脱敏的字段、文本清洗规则、聚类参数、相似度阈值和输出目录；import 命令能导入多份 CSV，保留原始文件并把手机号、邮箱、订单号这类敏感信息脱敏；check 命令要校验必填字段缺失、时间格式错误、重复工单号、空文本、渠道或产品线不在配置里，坏行进入 quarantine.json 并说明原因。fit 命令用 TF-IDF 或轻量文本向量把工单聚成相似问题簇，自动给每个簇生成关键词、代表工单和置信度；detect 命令要识别新一批工单里可能属于旧簇、疑似全新问题、同一用户重复投诉和处理结论前后矛盾的记录。review 命令支持人工把工单合并到某个簇、拆出新簇、给簇打标签或标记误报，这些反馈要保存下来并影响下次 detect；export 命令能导出 Markdown 周报、簇明细 CSV、疑似新问题 JSON，history 命令能按日期、产品线、簇标签查询历次导入和训练结果。希望代码拆成 CLI 入口、配置模型、CSV 解析与脱敏、数据校验、文本特征、聚类/相似度、人工反馈存储、检测规则、报告导出、示例数据和测试，不要写成一个大脚本。README 里写清楚安装方式、示例命令，以及如何用临时目录验证 init、导入历史工单、校验、训练聚类、导入新工单、检测新问题、人工复核和导出周报这些核心流程。
