# 门店品控管理 CLI 工具

将门店品控负责人手里的老流程后端化，解决手工表格记录难以追溯的问题。

## 功能特性

- ✅ **菜品留样、冰箱温度、废弃时间** 三类记录统一管理
- ✅ 按**负责人、时间、状态、异常类型**多维度筛选
- ✅ 导出 **Excel/CSV** 格式报告，与查询结果一致
- ✅ **JSON 轻量存储**，命令间共享历史数据
- ✅ **批量操作**，失败时明确区分成功/失败记录
- ✅ **异常原因追溯**，支持解释为什么某条记录被拦下

## 快速开始

### 1. 安装

```bash
pip install -e .
```

### 2. 初始化

```bash
qc init
```

### 3. 导入样例数据

```bash
qc import_csv sample_data.csv
```

预计输出：
```
批量操作完成: 成功 14/14, 失败 0/14
```

### 4. 查询记录

查看所有记录：
```bash
qc list
```

按负责人筛选：
```bash
qc list -r 张经理
```

按日期范围筛选：
```bash
qc list -s 2024-05-01 -e 2024-05-02
```

按状态筛选：
```bash
qc list -t 待复核
```

按异常类型筛选：
```bash
qc list -a 温度过高
```

查看摘要统计：
```bash
qc list --summary
```

### 5. 复核记录

批量通过：
```bash
qc approve REC000001 REC000002 -v 张总监 -m "复核通过"
```

批量驳回（必须说明原因）：
```bash
qc reject REC000007 REC000009 -v 张总监 -m "温度异常，需重新检测"
```

### 6. 查看记录详情

```bash
qc show REC000007
```

预计输出（异常记录）：
```
=== 记录详情 ===
ID: REC000007
日期: 2024-05-02
门店: 朝阳店
负责人: 张经理
类型: 冰箱温度
品项: 冷藏库
温度: 8.5°C
状态: 待复核
异常类型: 温度过高
备注: 温度超过安全阈值

⚠️  异常说明:
  该记录温度 (8.5°C) 超出安全范围，已被标记为异常
```

### 7. 导出报告

导出所有记录为 Excel：
```bash
qc export report.xlsx
```

导出筛选后的记录为 CSV：
```bash
qc export report.csv -r 张经理 -s 2024-05-01 -f csv
```

导出所有异常记录：
```bash
qc export abnormal_report.xlsx -a 温度过高
```

## 命令大全

| 命令 | 说明 |
|------|------|
| `qc init` | 初始化数据存储 |
| `qc import_csv <文件>` | 从 CSV 导入记录 |
| `qc list` | 查询记录列表 |
| `qc show <ID>` | 查看单条记录详情 |
| `qc approve <IDs> -v <复核人>` | 批量通过记录 |
| `qc reject <IDs> -v <复核人> -m <原因>` | 批量驳回记录 |
| `qc export <文件>` | 导出报告 |
| `qc data_path` | 显示数据文件位置 |
| `qc clear --yes` | 清除所有数据（谨慎使用） |

## 筛选参数

所有支持筛选的命令（`list`、`export`）都可以使用以下参数：

| 参数 | 简写 | 说明 |
|------|------|------|
| `--responsible` | `-r` | 按负责人筛选 |
| `--start-date` | `-s` | 开始日期 (YYYY-MM-DD) |
| `--end-date` | `-e` | 结束日期 (YYYY-MM-DD) |
| `--status` | `-t` | 状态: 待复核/已通过/已驳回 |
| `--abnormal` | `-a` | 异常类型 |
| `--record-type` | `-y` | 记录类型: 留样/冰箱温度/废弃 |

## CSV 导入格式

```csv
日期,门店,负责人,类型,品项,温度,留样时间,废弃时间,异常类型,备注
2024-05-01,朝阳店,张经理,留样,宫保鸡丁,,10:30,,,
2024-05-01,朝阳店,张经理,冰箱温度,冷藏库,4.2,,,,
```

字段说明：
- **日期**: 必填，格式 YYYY-MM-DD
- **门店**: 必填
- **负责人**: 必填
- **类型**: 必填，可选值：留样/冰箱温度/废弃
- **品项**: 必填
- **温度**: 可选，仅冰箱温度记录填写
- **留样时间**: 可选，仅留样记录填写
- **废弃时间**: 可选，仅废弃记录填写
- **异常类型**: 可选，默认：无异常
- **备注**: 可选

## 状态说明

| 状态 | 说明 |
|------|------|
| 待复核 | 新导入的记录，等待审核 |
| 已通过 | 复核通过，无问题 |
| 已驳回 | 有问题被拦下，需处理 |

## 异常类型

| 异常类型 | 说明 |
|----------|------|
| 无异常 | 正常记录 |
| 温度过高 | 冷藏/冷冻温度超出上限 |
| 温度过低 | 冷藏/冷冻温度低于下限 |
| 超时未处理 | 记录超过48小时未复核 |
| 记录缺失 | 关键信息缺失 |
| 格式错误 | 数据格式不符合要求 |

## 批量操作错误处理

导入或复核时，系统会：
1. 逐个处理每条记录
2. 遇到错误时**不影响已成功的记录**
3. 最后汇总显示成功/失败数量
4. 列出具体失败原因

示例输出：
```
批量操作完成: 成功 12/14, 失败 2/14
失败记录:
  - REC000099: 记录不存在
  - REC000100: 数据库连接超时
```

重试时，只需对失败的记录重新操作即可。

## 数据存储位置

数据默认存储在用户目录下：
- macOS: `~/.qc_data/records.json`
- Windows: `C:\Users\<用户名>\.qc_data\records.json`

查看数据位置：
```bash
qc data_path
```

## 常见问题

### Q: 为什么某条记录被拦下了？
```bash
qc show REC000007
```
查看详情页的「异常说明」部分，系统会自动解释拦截原因。

### Q: 导入失败怎么办？
使用 `--skip-errors` 跳过错误行继续导入：
```bash
qc import_csv data.csv --skip-errors
```

### Q: 如何重新导入？
先清除数据再导入：
```bash
qc clear --yes
qc import_csv data.csv
```
