## 1. 产品概述

海草床调查时序回放是一套面向海洋生态调查团队的数据质检与回放工具。它解决现场遥感数据人工兜底效率低、换参数重跑时变化痕迹不可追溯、脏数据（异常值/单位混写/命名不一致）需要人工判断留存的问题。目标用户为水质分析师（阿乔）及接手同事，核心价值是将原来靠人眼扫、凭经验判的工作变为"异常可追溯、参数可对比、导入不重复、备注不丢失"的标准化流程。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心权限 |
|------|---------|---------|
| 水质分析师（阿乔） | 日常质检、异常判读、结果导出 | 所有功能、人工改判、导出结果 |
| 接手同事 | 换参数重跑、查看历史版本、了解异常位置 | 参数调整、版本对比、查看改判记录 |

### 2.2 功能模块

1. **时序回放主面板**：参数控制栏 + 时序折线图 + 数据点状态标注
2. **三段式记录区**：已处理记录 / 待补材料 / 人工改判，并排三栏布局
3. **参数版本对比器**：多轮参数快照并排展示，差异高亮标记影响步骤
4. **异常标记引擎**：离群值疑似噪声不删除、潮位单位混写留痕迹留来源行、命名对不上的旧记录完整保留
5. **导入去重模块**：指纹键（站点+时间+指标）去重，已有人工备注永不被新导入覆盖
6. **接班指引卡片**：样例在哪 / 异常在哪 / 怎么导出，三个按钮入口简明说明

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|-----------|
| 时序回放主页 | 顶部参数控制栏 | 平滑窗口、阈值系数、单位归一化开关、重跑按钮；每次重跑产生新版本快照 |
| 时序回放主页 | 时序折线图 | 按时间轴展示海草覆盖度、水质指标；异常点不同色标，悬浮显示原始值与单位 |
| 时序回放主页 | 三段式记录区 | 左：已处理记录（已标注状态）/ 中：待补材料（缺照片、缺潮位等）/ 右：人工改判（操作人+时间+理由） |
| 时序回放主页 | 参数版本对比器 | 可勾选2-3个版本并排，参数差异标红，对应数据点变化联动高亮 |
| 时序回放主页 | 导入模拟面板 | 一键模拟"重复导入现场数据"，展示去重结果和备注保留情况 |
| 时序回放主页 | 接班指引抽屉 | 点击右下角卡片展开：样例数据按钮（定位到带脏数据的演示站点）、异常列表按钮（跳到第一条异常）、导出按钮（CSV+截图） |

## 3. 核心流程

用户打开页面 → 默认加载含脏数据的演示站点（有一条叫法对不上的旧记录 + 潮位单位混写 + 疑似噪声离群点）→ 查看时序图上各异常点 → 切换参数版本或调整参数后点重跑 → 版本对比器高亮哪一步参数变化对应哪条数据状态变化 → 如需人工改判，在改判区填写理由 → 模拟重复导入验证不重复不覆盖 → 接班同事通过指引卡片快速找到样例、异常、导出入口。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海青蓝 `#0B3D4F` 作为主背景色，海藻绿 `#3BAF7B` 为正异常/正常色，琥珀橙 `#E8913A` 为待补/可疑色，珊瑚红 `#D9534F` 为异常/离群色，浅沙灰 `#F4EFE6` 为面板底色。
- **辅助色**：潮位米 `#C9B896`、水质蓝 `#4A90B8`，构成海床遥感色系。
- **按钮风格**：胶囊型圆角（`rounded-full`），实心带细边框，悬停上浮+阴影加深。
- **字体**：标题用 `DM Serif Display` 衬线体（海洋调查报告出版物风格），正文用 `JetBrains Mono` 等宽字体（数据表格对齐易读）。
- **布局风格**：左右不对称，左侧时序图占 2/3 宽度，右侧三段式记录区占 1/3；版本对比器在底部抽屉式展开。
- **装饰元素**：背景使用径向渐变模拟海水深度分层 + 细微颗粒噪点纹理；异常点旁带"气泡"式注释胶囊。

### 4.2 页面设计总览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 时序回放主页 | 顶部标题栏 | 衬线大标题 + 副标题（站点名 + 调查批次）+ 右上角导出/指引卡按钮 |
| 时序回放主页 | 参数控制栏 | 玻璃拟态横条，参数滑块带数值实时显示，重跑按钮带脉动提示 |
| 时序回放主页 | 时序折线图 | 双 Y 轴（覆盖度 % + 潮位），点按异常点后弹出来源行浮层 |
| 时序回放主页 | 三段式记录区 | 三张卡片带角标（已处理/待补/改判），卡片内部纵向滚动，条目可点击 |
| 时序回放主页 | 版本对比器 | 底部从下向上滑出的抽屉，三列参数表，差异单元格红框闪烁 |
| 时序回放主页 | 接班指引卡 | 右下角悬浮三角卡片，点击展开三按钮：样例定位 / 异常定位 / 一键导出 |

### 4.3 响应式

桌面端为主要使用场景（≥1280px），三栏记录区并排。平板尺寸（768-1279px）将记录区改为上下堆叠。移动端（<768px）保证时序图和参数栏可读，记录区折叠为标签页切换。

### 4.4 动画细节

- 页面加载：标题栏先淡入 → 参数栏滑入 → 时序图折线从左到右逐段绘制 → 记录区卡片依次浮现（stagger 延迟）
- 重跑后：新版本在版本对比器中从右向左滑入，差异点闪烁 3 次
- 异常点悬浮：数据点放大 1.5 倍，弹出气泡注释从下方淡入上移
- 抽屉开合：版本对比器/指引卡抽屉使用弹性 ease-out 缓动
