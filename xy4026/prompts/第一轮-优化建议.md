我想做一个给线下展会检票组用的本地命令行工具，叫“离线闸口对账器”。展会现场网络经常不稳，几个入口的扫码枪只能各自导出 CSV，散场后我们要把入场、退场和二次入场记录合在一起，最怕同一张票被重复放行、设备时间漂移、VIP/普通票走错入口、黑名单票漏拦。请从 0 到 1 做一个可运行的 Python CLI 项目：init 命令能创建项目配置，维护允许二次入场的票种、各设备时间偏移、入口和票种的通行规则；import-roster 能导入票务名单 CSV，字段包括票号、姓名、手机号后四位、票种、允许入口、是否黑名单；import-log 能导入多台扫码枪日志 CSV，字段包括设备号、入口、时间戳、票号、动作（entry/exit/reentry）、操作员。reconcile 命令要生成一条可信时间线，按配置修正设备时间，合并 90 秒内的重复扫码，识别未知票、黑名单、错入口、先退场后入场、普通票重复入场、同一票多人同时扫码、日志坏行这些异常，并把无法自动处理的记录放进 quarantine.json 而不是静默丢掉。report 命令能导出 Markdown 复盘报告和 CSV 异常清单，export-ledger 能导出清洗后的 JSON 台账，history 能按日期、入口、异常类型查询过去的对账结果。请把 CLI 入口、CSV 解析、配置/规则、对账状态机、隔离区、存储层、报告导出、示例数据和测试拆成清晰的多文件结构，不要做成单文件脚本。README 里写清楚安装、示例命令，以及如何用临时目录验证 init、导入名单、导入多份日志、对账、导出报告和查询历史的完整流程。
