💡 使用说明

完整工作流程

1
初始化项目
subtitle-checker init
→
2
配置规则
添加说话人、术语、禁用词
→
3
检查字幕
subtitle-checker check
→
4
生成报告
subtitle-checker report
→
5
应用修复
subtitle-checker apply

常用命令

# 初始化项目
subtitle-checker init "我的纪录片项目"

# 添加说话人
subtitle-checker speaker add "张教授" --alias "张老师" "张先生"

# 添加术语
subtitle-checker term add "人工智能" --alt "AI" "机器智能"

# 检查字幕
subtitle-checker check ./subtitles/

# 生成报告
subtitle-checker report ./subtitles/ --output-dir ./reports

# 应用安全修复
subtitle-checker apply ./subtitles/ --output-dir ./fixed

⚠️ 重要提示

  • 时间轴问题（重叠、阅读速度过快、时间码错误）需要手动调整，因为涉及到视频同步
  • 禁用词需要手动审查替换，确保语义正确
  • 单行过长需要手动拆分，保持阅读体验
  • 所有自动修复都会生成新文件，不会覆盖原文件
