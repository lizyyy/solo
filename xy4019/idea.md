## 原始点子

我想做一个给纪录片字幕统筹用的本地命令行工具。我们每周会收到好几集采访素材的 SRT/VTT 字幕，送审前要靠人工检查时间轴、说话人名字、术语表和敏感词，来回翻文件特别容易漏。请从 0 到 1 做一个可以直接在终端运行的 CLI：能创建项目配置，维护说话人别名、统一术语和禁用词；能导入多个字幕文件并解析 SRT/VTT；check 命令要输出重叠时间轴、序号断裂、单行过长、阅读速度过快、说话人/术语不一致、禁用词命中等问题；report 命令能生成 Markdown 和 JSON 两种质检报告；apply 命令只能对安全项生成修复后的副本，比如重排序号、统一说话人和术语，不能覆盖原文件。再做一个本地缓存，重复检查时能跳过没变化的字幕文件，但配置变更后必须重新检查。请把解析器、规则引擎、配置/缓存、报告生成、修复器和 CLI 入口拆成合理的多文件结构，带几份示例字幕、README 和最基本的运行/验证说明，不要做成单文件演示。
