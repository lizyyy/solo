## 1. 产品概述

券商融券台券源预约协调系统，面向融券柜台操作员，解决客户优先级排序、券源库存锁定、到期归还回写、临时撤单补偿等日常高频操作中"表格间来回复制、状态对不上"的问题。所有操作（筛选、修正、导出）基于同一份持久化记录，筛选后导出内容与屏幕所见一致。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 柜台操作员 | 日常唯一使用者 | 券源管理、预约单操作、归还处理、撤单补偿、报告导出 |

### 2.2 功能模块

1. **券源预约总览页**：券源库存看板、预约单列表、归还到期预警、撤单记录、分配报告 — 五大板块在同一页面以 Tab 切换呈现
2. **预约操作面板**：新建预约、修正预约数量/日期、客户优先级调整、库存锁定校验
3. **归还与撤单面板**：归还回写（逾期标记）、撤单补偿（库存即时回补）、逾期自动告警
4. **分配报告导出**：按当前筛选条件导出 CSV，导出内容 = 屏幕显示内容

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 券源预约总览 | 库存看板 | 展示各证券可用库存、已锁定数量、可分配数量，超分时红色标记 |
| 券源预约总览 | 预约单列表 | 展示所有预约单，支持按证券代码/客户/状态/日期筛选，状态机驱动（待确认→已锁定→已归还/已撤单） |
| 券源预约总览 | 归还到期预警 | 展示即将到期和已逾期未归还的预约单，逾期行标红 |
| 券源预约总览 | 撤单记录 | 展示撤单历史，含撤单时间、库存回补状态、补偿操作人 |
| 券源预约总览 | 分配报告 | 汇总各证券分配情况，支持按当前筛选条件导出 CSV |
| 预约操作 | 新建预约 | 输入客户账户、证券代码、数量、预约日期，校验库存并锁定 |
| 预约操作 | 修正预约 | 修改数量/日期，校验库存差额重新锁定 |
| 归还与撤单 | 归还确认 | 确认归还后释放库存锁定，记录归还时间，逾期自动标记 |
| 归还与撤单 | 撤单操作 | 撤单后即时回补库存，记录撤单原因和补偿明细 |

## 3. 核心流程

### 3.1 预约主流程

操作员选择客户 → 输入证券代码和数量 → 系统校验可分配库存（可用 = 总库存 - 已锁定）→ 库存充足则锁定并创建预约单（状态：已锁定）→ 库存不足则拒绝并返回具体差额 → 到期前操作员确认归还 → 释放锁定库存（状态：已归还）→ 逾期未还则自动标记逾期

### 3.2 撤单补偿流程

操作员发起撤单 → 预约单状态置为已撤单 → 锁定库存即时回补至可用库存 → 记录撤单时间、原因、补偿明细 → 若回补失败则标记异常需人工介入

```mermaid

    "创建预约" --> "库存校验"
    "库存校验" -->|"可用 >= 需求"| "锁定库存"
    "库存校验" -->|"可用 < 需求"| "返回差额不足错误"
    "锁定库存" --> "状态: 已锁定"
    "状态: 已锁定" --> "到期归还"
    "状态: 已锁定" --> "主动撤单"
    "到期归还" -->|"按时"| "状态: 已归还"
    "到期归还" -->|"逾期"| "状态: 逾期未还"
    "主动撤单" --> "库存回补"
    "库存回补" -->|"成功"| "状态: 已撤单"
    "库存回补" -->|"失败"| "状态: 回补异常"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1E293B）+ 金色强调（#F59E0B），体现金融专业感
- 辅助色：绿色表示正常/可分配、红色表示逾期/超分/异常、灰色表示已撤单
- 按钮风格：圆角 6px，主要操作用金色填充，危险操作用红色描边
- 字体：DM Sans（正文）+ JetBrains Mono（数据/数字），数据密集场景下保证数字对齐
- 布局：左侧固定导航栏 + 右侧内容区，Tab 切换五大板块
- 表格：斑马纹 + 固定表头，操作列右对齐

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 券源预约总览 | 库存看板 | 顶部统计卡片（总库存/已锁定/可分配/逾期数），下方表格 |
| 券源预约总览 | 预约单列表 | 筛选栏（证券代码、客户、状态、日期范围）+ 数据表格 + 分页 |
| 券源预约总览 | 归还到期预警 | 日期倒计时列 + 逾期标红 + 快捷归还按钮 |
| 券源预约总览 | 撤单记录 | 撤单原因列 + 库存回补状态标签 |
| 券源预约总览 | 分配报告 | 汇总表格 + 导出按钮（导出当前筛选结果） |
| 预约操作 | 新建/修正 | 右侧抽屉式表单，含实时库存校验提示 |
| 归还与撤单 | 操作确认 | 模态对话框，显示操作影响范围（库存变动预览） |

### 4.3 响应式

桌面优先设计，最小宽度 1280px，表格横向滚动，筛选栏可折叠。

### 4.4 错误展示

- 券源超分：显示"可用库存仅 {X} 股，当前预约 {Y} 股，差额 {Z} 股"
- 归还逾期：行标红 + 倒计时/逾期天数列
- 撤单后库存未回补：显示"撤单成功但库存回补异常，请联系管理员"并标记该记录
- 操作冲突：显示"该预约单状态已变更，请刷新后重试"
