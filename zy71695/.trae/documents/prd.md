## 1. 产品概述

太阳能小车赛道估算工具，面向科创教师和学生，帮助减少手工对表，将光照、赛道坡度、齿轮比、小车质量、电机参数综合计算为完赛时间预测。每条导出数据可一路追溯到原始明细；参数异常时聚焦其对预算、时间和参赛名单的影响，而非仅展示错误代码。

- 解决问题：手工对表耗时易错，异常参数缺乏业务影响提示，数据不可追溯
- 目标用户：科创教师、参赛学生

## 2. 核心功能

### 2.1 用户角色
| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 教师 | 直接使用 | 录入/编辑所有参数、运行估算、导出报告、管理学生数据 |
| 学生 | 直接使用 | 查看参数、运行估算、查看报告 |

### 2.2 功能模块
1. **仪表盘页面**：项目概览、待确认记录提醒、业务影响预警卡
2. **光照记录页面**：光照强度录入、编辑、删除、缺口检测
3. **赛道参数页面**：坡度录入与方向校验、齿轮比边界检查
4. **小车参数页面**：质量、电机参数管理
5. **估算报告页面**：功率估算、阻力修正、时间预测、参数对比、报告导出、全链路追溯

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 仪表盘 | 项目概览卡 | 显示当前项目数、待确认记录数、最近估算结果 |
| 仪表盘 | 预警卡 | 光照缺口、坡度方向反、齿轮比越界 → 对预算/时间/名单的影响提示 |
| 光照记录 | 光照表格 | 按时间段录入光照强度(W/m²)，支持批量录入 |
| 光照记录 | 缺口检测 | 自动标记光照低于阈值的时间段，标注影响等级 |
| 赛道参数 | 坡度管理 | 录入坡度(%)与方向(上坡/下坡)，方向反自动预警 |
| 赛道参数 | 齿轮比管理 | 录入齿轮比，越界(>10或<0.5)标红并提示影响 |
| 小车参数 | 质量/电机 | 录入小车质量(kg)、电机额定电压(V)、额定转速(rpm)、额定功率(W)、效率(%) |
| 估算报告 | 功率估算 | 根据光照×太阳能板面积×效率计算可用功率 |
| 估算报告 | 阻力修正 | 坡度阻力、滚动阻力、空气阻力叠加修正 |
| 估算报告 | 时间预测 | 综合功率和阻力估算完赛时间(s) |
| 估算报告 | 参数对比 | 两个方案并排对比，差异高亮 |
| 估算报告 | 报告导出 | 导出CSV，每个数字可追溯到源记录ID |
| 估算报告 | 追溯链路 | 点击任何估算结果 → 展开完整输入链：光照ID→坡度ID→齿轮比ID→电机ID |

## 3. 核心流程

用户录入光照记录 → 配置赛道坡度和齿轮比 → 填写小车质量和电机参数 → 系统自动估算功率 → 阻力修正 → 预测完赛时间 → 异常参数标红并提示业务影响 → 导出报告(含追溯信息)

```mermaid
flowchart TD
    "录入光照记录" --> "配置赛道参数(坡度+齿轮比)"
    "配置赛道参数(坡度+齿轮比)" --> "填写小车参数(质量+电机)"
    "填写小车参数(质量+电机)" --> "运行功率估算"
    "运行功率估算" --> "阻力修正"
    "阻力修正" --> "时间预测"
    "时间预测" --> "异常检测与业务影响提示"
    "异常检测与业务影响提示" --> "生成估算报告"
    "生成估算报告" --> "参数对比(可选)"
    "生成估算报告" --> "导出CSV(含追溯链)"
    "异常检测与业务影响提示" --> "标记待确认记录"
    "标记待确认记录" --> "仪表盘预警"
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深靛蓝(#1a2744) + 太阳能橙(#f59e0b) 强调色
- 辅助色：钢灰(#64748b)用于次要信息，红(#ef4444)用于警告
- 按钮风格：圆角6px，主要按钮填充色，次要按钮描边
- 字体：正文用系统字体栈，标题用 "DM Sans" (Google Fonts)
- 布局风格：左侧导航栏 + 右侧内容区，卡片式模块布局
- 图标风格：Lucide 图标库，线型风格

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 仪表盘 | 项目概览卡 | 3个统计卡片(项目数/待确认/最近估算)，白色底+微阴影 |
| 仪表盘 | 预警卡 | 红色/橙色/黄色边框卡片，左侧图标+标题+影响描述+跳转链接 |
| 光照记录 | 光照表格 | 表格+内联编辑，缺口行红色背景标记，底部汇总行 |
| 赛道参数 | 坡度表单 | 分段表单，方向下拉框，异常时表单下方红色提示条 |
| 赛道参数 | 齿轮比表单 | 数字输入+滑块双模式，越界值红色+警告文字 |
| 小车参数 | 质量/电机表单 | 分组表单，实时计算预览区 |
| 估算报告 | 估算结果区 | 卡片式布局：功率/阻力/时间三张结果卡，点击展开追溯链 |
| 估算报告 | 参数对比 | 双列并排表格，差异行橙色背景 |
| 估算报告 | 导出按钮 | 右上角"导出CSV"按钮，下载后Toast提示 |

### 4.3 响应式
- 桌面优先设计，最小宽度1024px
- 导航栏在768px以下折叠为汉堡菜单
- 表格在窄屏下允许横向滚动

### 4.4 追溯链路交互
- 估算结果卡片中每个数字旁有"追溯"图标按钮
- 点击后展开内联面板，显示完整输入链：光照记录ID → 坡度记录ID → 齿轮比ID → 电机ID → 小车ID
- 每个ID可点击跳转到对应管理页面并高亮该记录
