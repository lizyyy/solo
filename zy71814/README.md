# 预付卡沉淀核对系统 使用说明

## 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 生成样例数据（可选）
```bash
python generate_samples.py
```
样例数据将生成在 `data/samples/` 目录下。

### 3. 启动系统
```bash
streamlit run app.py
```

## 财务结算操作指南

### 📥 一、结算附件存放规范

1. **文件命名规则**
   - 交易明细：`交易明细_YYYYMMDD.xlsx`
   - 结算记录：`结算记录_YYYYMMDD.xlsx`

2. **必填字段说明**
   
   **交易明细表必须包含以下列：**
   | 列名 | 说明 | 示例 |
   |------|------|------|
   | 交易流水号 | 唯一标识 | TXN202401000001 |
   | 交易日期 | YYYY-MM-DD | 2024-01-15 |
   | 卡号 | 预付卡号 | 622202****1234 |
   | 卡类型 | 储值卡/礼品卡等 | 储值卡 |
   | 交易金额 | 消费金额 | 1500.00 |
   | 手续费 | 扣取手续费 | 4.50 |
   | 结算金额 | 实际结算 | 1495.50 |
   | 商户号 | 商户编号 | MCH12345 |
   | 商户名称 | 商户全称 | XX超市 |
   | 终端号 | 终端编号 | TRM1234 |
   | 订单号 | 业务订单号 | ORD2024011512345 |

   **结算记录表建议包含以下列：**
   | 列名 | 说明 |
   |------|------|
   | 结算流水号 | 结算记录编号 |
   | 结算日期 | 银行结算日期 |
   | 批次号 | 结算批次号 |
   | 交易总金额 | 该批次总金额 |
   | 手续费总额 | 该批次总手续费 |
   | 实际结算金额 | 银行到账金额 |
   | 交易笔数 | 该批次交易数 |
   | 结算账户 | 收款银行账户 |

3. **存放位置**
   - 导入时系统自动保存到 `data/attachments/` 目录
   - 可通过文件ID追溯原始文件

### 🔍 二、重复入账查看方法

**在哪里查看？**
1. 进入【数据核对】页面
2. 查看"重复入账风险"卡片
3. 下方表格列出所有疑似重复的记录

**判断规则：**
- 同一交易日期
- 同一商户号
- 同一订单号
- 金额差异小于0.01元

**处理方式：**
1. 点击交易流水号查看详情
2. 查看"来源文件"列追溯原始附件
3. 确认重复后，在【人工修正】页面标记状态
4. 在备注中说明重复原因

### ✅ 三、导出前复核流程

**导出对账说明前必须完成以下复核：**

1. **数据完整性检查**
   - ✅ 所有交易流水均已导入
   - ✅ 所有结算记录均已导入
   - ✅ 期初余额录入正确

2. **异常记录处理**
   - ✅ 重复入账风险已核实
   - ✅ 手续费跨期记录已标注
   - ✅ 待补充记录已跟进

3. **人工修正复核**
   - ✅ 所有修改记录均有备注说明
   - ✅ 修改原因已核实无误

4. **余额核对**
   - ✅ 期末沉淀 = 期初 + 存款 - 结算 - 手续费
   - ✅ 与银行对账单余额一致

5. **填写复核信息**
   - 在【对账说明】页面填写复核人
   - 填写复核意见（如"核对无误"）
   - 点击"确认复核"按钮

### 📊 四、对账说明处理口径

#### 1. 已确认记录
- **定义**：交易流水与结算记录匹配一致
- **判断标准**：金额差异在0.01元以内
- **展示位置**：对账说明"已确认交易"sheet

#### 2. 待补充记录
- **定义**：缺少关键信息或无法匹配的交易
- **常见情况**：
  - 缺失商户信息
  - 结算银行未到账
  - 交易金额与结算金额差异较大
- **处理要求**：标注待跟进，补充完整后再确认

#### 3. 人工修改记录
- **定义**：经人工核实并修改状态的记录
- **必填信息**：修改原因、修改人、修改日期
- **追溯方式**：保留原始值，记录修改日志

## 常见问题

**Q: 手续费跨期是什么意思？**
A: 系统默认每月25日之后的手续费视为跨期，需在备注中说明归属期间。

**Q: 如何查看某笔交易的原始附件？**
A: 在交易明细表格的"来源文件"列可查看原始文件名，文件保存在 data/attachments/ 目录。

**Q: 历史记录可以删除吗？**
A: 目前版本不支持删除，如需清理请手动删除 data/history/ 目录下的文件。

**Q: 导出的Excel文件在哪里？**
A: 所有导出文件保存在 data/exports/ 目录，文件名为时间戳开头。
