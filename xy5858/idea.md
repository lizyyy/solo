## 原始点子

我家里老人常年吃好几种药，药盒拆封后有效期、剩余量、下次补货时间经常靠微信群消息记，容易漏。请做一个本地可运行的全栈 Web 应用，叫“家庭药箱轮换台”：前端要能登记药品、批次、开封日期、每日用量、库存数量和存放位置，自动算出预计耗尽日和开封后风险状态；后端要提供 REST API 并把数据持久化到本地文件或轻量数据库，不允许只存在前端内存里；列表页支持按“快过期 / 快用完 / 正常”分组筛选，详情页能记录一次服用或补货并立刻更新库存；还要支持 CSV 导入导出，导入时要做字段校验、错误行提示和重复批次合并。请把运行说明、示例数据、基本测试或自检脚本一起补上。
