# 3D 叉车通道演练台

一个基于 Three.js 的仓库新员工培训用 3D 叉车通道演练台系统。

## 项目简介

本项目是一个交互式的 3D 叉车模拟训练系统，专为仓库新员工培训设计。学员可以在虚拟仓库环境中练习叉车操作，包括取货、搬运、避让行人和放货等操作。系统会实时监控并提示各类违规行为，并在训练结束后提供详细的评分和成绩导出功能。

## 主要功能

- **3D 虚拟仓库场景**：包含货架、行人盲区、限速区、装卸月台和待搬运托盘
- **实时违规检测**：碰撞风险、超速、转弯半径不足、盲区有人、托盘顺序错误
- **模拟控制**：暂停/继续、倍速播放（0.5x/1x/2x/4x）、撤销上一步
- **存档系统**：保存和加载训练进度
- **评分系统**：实时计分、任务完成奖励、违规扣分
- **成绩导出**：训练完成后导出 JSON 格式成绩报告

## 模块说明

### 1. SceneManager (场景管理)
**文件**: `src/scene/SceneManager.js`

负责管理 Three.js 3D 场景，包括：
- 场景、相机、渲染器的初始化和配置
- 灯光、地面、网格的创建
- 关卡元素的构建（货架、行人区、限速区、装卸月台、托盘、障碍物）
- 相机跟随和动画循环

### 2. LevelLoader (关卡解析)
**文件**: `src/level/LevelLoader.js`

负责加载和解析 JSON 关卡文件，包括：
- 从网络加载 JSON 关卡文件
- 数据验证和转换
- 关卡数据缓存
- 默认值填充

### 3. Vehicle (车辆模型)
**文件**: `src/vehicle/Vehicle.js`

实现叉车模型和物理运动，包括：
- 3D 叉车模型创建（车身、驾驶室、轮子、门架、货叉）
- 路径跟随运动
- 货叉升降控制
- 状态保存和恢复
- 碰撞边界计算

### 4. RulesEngine (规则引擎)
**文件**: `src/rules/RulesEngine.js`

核心规则检测引擎，包括：
- **碰撞检测**: 检测与货架、障碍物、装卸月台的距离
- **限速检测**: 在限速区域检测超速行为
- **转弯半径检测**: 检测高速急转弯
- **盲区检测**: 检测是否进入行人盲区
- **任务检查**: 检查取货、放货、避让等任务完成状态
- **顺序检查**: 验证托盘搬运顺序

### 5. SimulationClock (模拟时钟)
**文件**: `src/simulation/SimulationClock.js`

控制模拟时间流逝，包括：
- 模拟时间的开始、暂停、恢复
- 时间倍率控制（倍速播放）
- 格式化时间显示
- 时间状态保存

### 6. SaveManager (存档管理)
**文件**: `src/save/SaveManager.js`

管理训练进度的保存和加载，包括：
- LocalStorage 存储
- JSON 文件导入导出
- 存档列表管理
- 存储空间使用统计

### 7. ScoringSystem (评分系统)
**文件**: `src/scoring/ScoringSystem.js`

负责计分和评级，包括：
- 基础分数设置
- 违规扣分（2秒内重复违规不重复扣分）
- 任务完成加分
- 时间奖励计算
- 等级评定（A-F 级）
- 成绩报告生成

### 8. UIController (UI 控件)
**文件**: `src/ui/UIController.js`

管理用户界面，包括：
- 顶部信息栏（关卡名、时间、速度、分数）
- 底部控制栏（暂停、倍速、撤销、保存、加载）
- 通知和违规警告显示
- 训练完成结果弹窗
- 路线规划面板

## 安装和启动

### 前置要求
- Node.js 16+
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

服务器将在 `http://localhost:3000` 启动，浏览器会自动打开。

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist` 目录。

```bash
npm run preview
```

## 核心流程验证

### 1. 场景加载验证
启动项目后，你应该能看到：
- 一个 3D 仓库场景
- 4 个货架（左右各两个）
- 中央的黄色行人区域
- 红色的限速区域
- 顶部的装卸月台
- 两个带货物的托盘
- 橙色的叉车模型

### 2. UI 控件验证
界面应包含：
- **顶部栏**：显示关卡名、时间、速度倍率、当前分数
- **底部控制栏**：
  - 暂停/继续按钮
  - 倍速按钮（0.5x、1x、2x、4x）
  - 撤销按钮
  - 保存/加载按钮
- **右侧通知区**：显示成功消息
- **左侧警告区**：显示违规警告
- **右下角路线规划面板**

### 3. 规则引擎验证

#### 碰撞检测
将叉车移动到货架附近（距离 < 3m），系统应该：
- 显示红色警告：「与货架发生碰撞风险！距离: X.XXm」
- 分数减少 20 分

#### 超速检测
在红色限速区域内（中心区域），如果叉车速度超过 2m/s：
- 显示红色警告：「超速！当前速度: X.X m/s, 限速: 2 m/s」
- 分数减少 10 分

#### 盲区检测
当叉车从后方或侧方接近黄色行人区域时：
- 显示红色警告：「盲区警告！行人区域距离: X.Xm」
- 分数减少 25 分

### 4. 存档功能验证

#### 保存进度
1. 点击「保存」按钮
2. 应该看到绿色通知：「进度已保存」

#### 加载进度
1. 先进行一些操作
2. 刷新页面
3. 点击「加载」按钮
4. 应该恢复到之前保存的状态

### 5. 评分系统验证

#### 基础分
- 初始分数：100 分

#### 任务加分
- 取货完成：+20 分
- 放货完成：+30 分
- 避让行人：+15 分

#### 时间奖励
- 每提前 1 秒完成：+0.5 分
- 最多奖励：50 分

#### 等级评定
- 90+ 分：A 级（优秀）
- 80-89 分：B 级（良好）
- 70-79 分：C 级（中等）
- 60-69 分：D 级（及格）
- 60 分以下：F 级（不及格）

### 6. 成绩导出验证
当所有任务完成后：
1. 应该弹出结果窗口
2. 显示最终分数和等级
3. 显示用时、完成任务数、违规次数
4. 点击「导出成绩」按钮
5. 应该下载一个 JSON 文件

## 关卡配置说明

关卡使用 JSON 格式配置，位于 `levels/` 目录。

### 配置结构

```json
{
  "id": "关卡ID",
  "name": "关卡名称",
  "description": "关卡描述",
  "difficulty": 1,
  "timeLimit": 180,
  
  "vehicle": {
    "startPosition": { "x": 0, "y": 0, "z": -20 },
    "startRotation": 0,
    "maxSpeed": 5,
    "turningRadius": 3
  },
  
  "racks": [...],           // 货架配置
  "pedestrianZones": [...], // 行人区域
  "speedLimitZones": [...], // 限速区域
  "loadingDocks": [...],    // 装卸月台
  "pallets": [...],         // 托盘
  "obstacles": [...],       // 障碍物
  "tasks": [...],           // 任务列表
  "scoringRules": {...}     // 评分规则
}
```

### 违规类型和扣分

| 违规类型 | 扣分 | 说明 |
|---------|------|------|
| collision | -20 | 碰撞风险 |
| speeding | -10 | 超速 |
| turningRadius | -15 | 转弯半径不足 |
| blindSpot | -25 | 盲区有人 |
| wrongSequence | -30 | 托盘顺序错误 |

### 任务类型和加分

| 任务类型 | 加分 | 说明 |
|---------|------|------|
| pickup | +20 | 取货完成 |
| delivery | +30 | 放货完成 |
| avoid | +15 | 安全避让 |

## 扩展开发

### 添加新关卡

1. 在 `levels/` 目录创建新的 JSON 文件
2. 参考 `level1.json` 的结构
3. 在 `src/main.js` 中修改加载路径

### 自定义评分规则

在关卡 JSON 的 `scoringRules` 字段中调整：

```json
{
  "scoringRules": {
    "baseScore": 100,
    "timeBonus": {
      "perSecond": 0.5,
      "maxBonus": 50
    },
    "violations": {
      "collision": -20,
      "speeding": -10
    }
  }
}
```

### 添加新的违规检测

在 `src/rules/RulesEngine.js` 中：
1. 添加新的检测方法
2. 在 `checkAll()` 方法中调用
3. 在 `scoringRules` 中配置扣分

## 常见问题

### 场景不显示
- 检查浏览器控制台是否有错误
- 确认依赖已正确安装
- 尝试清除浏览器缓存

### 3D 性能不佳
- 降低浏览器标签页数量
- 检查 GPU 使用率
- 在低配置设备上可能需要简化模型

### 存档不工作
- 检查浏览器是否启用了 LocalStorage
- 清除浏览器数据后再试
- 检查隐私设置
