💡 参数提示

常见错误:
  • ETag 应该用双引号包裹: "abc123" 而非 abc123
  • Range 头格式: bytes=0-99 而非 0-99
  • Cache-Control 指令用逗号分隔: public, max-age=3600

Cache-Control 速查

public: 任何缓存都可以存储 private: 仅浏览器缓存 no-cache: 使用前必须重新验证 no-store: 不存储任何内容 max-age=N: 缓存有效期 N 秒 must-revalidate: 过期后必须重新验证 immutable: 有效期内不会改变

状态码速查

200 OK - 请求成功 206 Partial Content - 部分内容 301 Moved Permanently - 永久重定向 302 Found - 临时重定向 304 Not Modified - 未修改 412 Precondition Failed - 前提条件失败 504 Gateway Timeout - 网关超时

条件请求头

If-Match: ETag 匹配才执行 If-None-Match: ETag 不匹配才执行 If-Modified-Since: 指定时间后修改才返回 If-Unmodified-Since: 指定时间后未修改才执行 If-Range: 范围请求的条件验证
