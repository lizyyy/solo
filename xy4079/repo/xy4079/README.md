# 维保照片归档质检台

电梯维保班组用本地桌面工具，用于照片导入、规则校验、人工复核、批量重命名归档和报告导出。

## 功能特性

- **照片导入**: 从目录导入照片，自动解析EXIF拍摄时间、计算哈希值
- **工单导入**: 解析CSV格式工单，支持多种日期格式和编码
- **规则校验**:
  - ✅ **必拍点位检查**: 机房、轿厢、底坑、安全回路等点位是否漏拍
  - ✅ **时间窗口校验**: 照片拍摄时间是否与工单日期一致
  - ✅ **重复哈希检测**: 同一张图是否重复上传
  - ✅ **命名规范检查**: 文件名是否符合规范
  - ✅ **整改配对检查**: 整改前后对比照片是否配对
- **人工复核**: 问题进入待复核列表，支持确认、忽略、标记已解决
- **批量归档**: 支持多种重命名规则，自动创建子目录
- **报告导出**: 导出Markdown格式质检报告和CSV问题清单

## 使用流程

### 1. 准备数据

**工单CSV格式**:

```csv
工单号,电梯编号,位置,维保日期,维保人员,必拍点位,有整改,整改项
WB20260501001,DT-001,1号楼1单元,2026-05-01,张师傅,机房、轿厢、底坑、安全回路,否,
WB20260501002,DT-002,1号楼2单元,2026-05-01,李师傅,机房、轿厢、底坑、安全回路,是,轿门开关故障、厅门门锁调整
```

**CSV字段说明**:

| 字段 | 必需 | 说明 |
|------|------|------|
| 工单号 | 是 | 唯一标识 |
| 电梯编号 | 是 | 电梯编号 |
| 位置 | 是 | 电梯位置 |
| 维保日期 | 是 | 支持多种格式：2026-05-01、2026/05/01、2026年05月01日 |
| 维保人员 | 是 | 维保人员姓名 |
| 必拍点位 | 否 | 默认为：机房、轿厢、底坑、安全回路 |
| 有整改 | 否 | 是/否 |
| 整改项 | 否 | 多项用顿号分隔 |

**照片命名规范建议**:

- 点位类型: `机房_20260501_143000.jpg` 或 `轿厢_001.jpg`
- 整改前后: `整改前_轿门.jpg` 或 `整改后_轿门.jpg`
- 点位关键词: 机房、轿厢、底坑、安全回路、ROOM、CAR、PIT、SAFETY

### 2. 操作步骤

1. **导入工单CSV**:
   - 点击「文件」→「导入工单CSV」或界面上的「选择文件」按钮
   - 选择准备好的CSV文件

2. **导入照片目录**:
   - 点击「文件」→「导入照片目录」或界面上的「选择目录」按钮
   - 选择包含照片的文件夹

3. **执行质检**:
   - 点击「📊 执行质检」按钮
   - 系统会自动执行所有校验规则
   - 查看统计信息和问题列表

4. **人工复核**:
   - 在右侧「问题列表」中选择问题
   - 点击:
     - ✅ 确认问题: 确认问题存在
     - ❌ 忽略问题: 标记为忽略（不影响质检结果）
     - 🔄 标记已解决: 确认问题已解决

5. **预览重命名**:
   - 点击「📋 预览重命名」按钮
   - 查看重命名前后的对比
   - 确认是否需要调整

6. **执行归档**:
   - 点击「📁 执行归档」按钮
   - 选择目标目录
   - 系统会:
     - 按点位自动创建子目录
     - 按规则重命名文件
     - 复制（不删除原文件）到目标目录

7. **导出报告**:
   - 点击「📄 导出报告」按钮
   - 选择导出目录
   - 系统会生成:
     - `质检报告_时间戳.md`: Markdown格式质检报告
     - `质检报告_时间戳_问题清单.csv`: CSV格式问题清单

## 校验规则说明

### 1. 点位校验 (PointValidator)

- 检查工单指定的必拍点位是否都有照片
- 每个点位有最少照片数量要求（默认: 机房2张、轿厢2张、底坑2张、安全回路1张）
- 检查是否有无法识别点位的照片

### 2. 时间校验 (TimeValidator)

- 默认时间窗口: 工单日期前后各1天
- 检查每张照片的拍摄时间是否在允许窗口内
- 拍摄时间来源优先级: EXIF > 文件名解析 > 文件修改时间

### 3. 重复校验 (DuplicateValidator)

- 基于SHA256哈希值检测完全相同的照片
- 同一哈希出现多次即为重复

### 4. 命名校验 (NamingValidator)

- 检查文件名是否包含非法字符: `< > : " / \ | ? *`
- 检查是否使用默认相机命名: `IMG_xxxx`, `DSC_xxxx`
- 检查文件名是否包含点位信息

### 5. 整改配对校验 (PairValidator)

- 检查整改前照片是否有对应的整改后照片
- 检查整改后照片是否有对应的整改前照片
- 基于文件名相似度自动配对

## 重命名规则

| 规则 | 示例 | 说明 |
|------|------|------|
| 保持原名 | 不改变 | 不重命名 |
| 按点位_时间 | 机房_20260501_143000.jpg | 点位类型 + 拍摄时间 |
| 按点位_序号 | 机房_001.jpg | 点位类型 + 序号 |
| 按工单号_点位_序号 | WB20260501001_机房_001.jpg | 工单号 + 点位 + 序号 |

## 常见问题

**Q: 程序启动失败，提示找不到tkinter?**

A: tkinter通常随Python一起安装。如果没有:
- Windows: 重新安装Python，勾选"tcl/tk and IDLE"
- macOS: 通常已预装，如缺失可使用Homebrew: `brew install python-tk`
- Linux: `sudo apt-get install python3-tk` (Debian/Ubuntu)

**Q: 照片拍摄时间识别不准确?**

A: 程序按以下优先级获取时间:
1. EXIF元数据中的 DateTimeOriginal
2. 文件名中的时间戳（如 20260501_143000）
3. 文件修改时间

如果EXIF数据丢失，确保文件名包含时间信息。

**Q: 如何自定义时间窗口?**

A: 当前默认是工单日期前后各1天。如需修改，可编辑 `validator/time_validator.py` 中的:

```python
DEFAULT_WINDOW_BEFORE_DAYS = 1
DEFAULT_WINDOW_AFTER_DAYS = 1
```
