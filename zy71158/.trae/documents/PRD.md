## 1. 产品概述

"夜市摊位经营游戏"是一款面向街区摊主的策略模拟教育游戏，通过回合制经营模拟让玩家理解用电容量限制、油烟排放标准、投诉处理等真实运营规则。游戏以 Canvas 2D 为渲染基础，强调规则真实性而非美术堆料。

- 目标用户：街区摊主、市场管理者
- 核心价值：用游戏化方式传授合规经营知识，降低通知阅读门槛
- 差异化：真实规则映射 + 可回放操作历史 + 可导出经营报告

## 2. 核心功能

### 2.1 功能模块

1. **游戏主界面（Canvas）**：夜市摊位地图、摊位状态可视化、油烟扩散效果
2. **控制面板**：摊位操作（开关/调节功率/调整排烟）、回合控制
3. **状态仪表盘**：用电容量、油烟指数、投诉值、资金、评分实时显示
4. **事件日志**：随机事件触发、操作历史记录
5. **结算报告**：回合结算、最终评分、失败原因分析
6. **历史回放**：操作历史回放、关键节点跳转

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|

| 游戏主界面 | 顶部状态栏 | 显示当前回合、剩余时间、暂停/重开按钮、重开按钮 |

## 3. 核心流程

### 3.1 游戏流程

```
开始游戏 → 选择关卡 → 回合开始 → 玩家操作摊位 → 时间流逝 → 结算本回合 → 
检查胜利/失败 → 下一回合/游戏结束 → 结算报告 → 历史回放
```

### 3.2 Mermaid 流程图

```mermaid
flowchart TD
    "A[开始游戏]" --> "B[选择关卡]"
    "B" --> "C[初始化关卡状态]"
    "C" --> "D[回合开始]"
    "D" --> "E[玩家操作摊位]"
    "E" --> "F[时间推进]"
    "F" --> "G[计算用电容量]"
    "G" --> "H[计算油烟扩散]"
    "H" --> "I[触发随机事件]"
    "I" --> "J[更新投诉值]"
    "J" --> "K[回合结算]"
    "K" --> "L{检查胜负}"
    "L" --> "|未结束|" "D"
    "L" --> "|游戏结束|" "M[生成结算报告]"
    "M" --> "N[导出报告/历史回放]"
```

### 3.3 核心规则映射

| 真实规则 | 游戏机制 |
|-----------|-------------|
| 用电容量限制 | 每个摊位有功率值，总和不能超过总容量，超限扣分+跳闸 |
| 油烟排放标准 | 高功率烹饪产生油烟，油烟扩散到邻摊触发投诉 |
| 投诉处理 | 邻摊投诉累积到阈值即失败，可通过降低功率/开排烟缓解 |
| 营业时间 | 回合制，每回合代表一个时间段，限时操作 |

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖橙色系（夜市灯牌感）+ 深色背景（夜空氛围）
- **配色方案**：主色 `#FF6B35`（暖橙），次色 `#FFD23F`（金黄），警告色 `#E63946`（红），成功色 `#2EC4B6`（青），背景 `#1A1A2E`（深靛蓝）
- **按钮风格**：圆角矩形、霓虹描边、悬停发光
- **字体**：标题用特色中文字体，正文用系统默认
- **布局风格**：Canvas 居中 + 左控制面板 + 右仪表盘 + 底事件日志
- **图标风格**：emoji + 简约 SVG，避免堆料

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 游戏主界面 | Canvas 区 | 深色背景，摊位以彩色方块表示，油烟以半透明橙色云团扩散动画 |
| 游戏主界面 | 顶部状态栏 | 霓虹风格边框，回合数/时间大字显示，按钮带发光效果 |
| 游戏主界面 | 左侧面板 | 卡片式摊位列表，滑块带颜色渐变，排烟档位用按钮组 |
| 游戏主界面 | 右侧仪表盘 | 进度条带阈值标记，数值实时跳动，评分明细可折叠 |
| 游戏主界面 | 底部日志 | 滚动列表，不同事件类型用不同颜色标记 |
| 结算弹窗 | 结算面板 | 半透明深色背景，评分环形图，失败原因高亮 |
| 结算弹窗 | 报告导出 | 按钮带下载图标，JSON 预览可复制 |
| 历史回放 | 回放面板 | 时间轴带刻度，关键事件节点可点击跳转 |

### 4.3 响应式设计

- 桌面端优先：Canvas 800x600，左右面板各 280px
- 平板适配：左右面板折叠为可展开抽屉
- 触摸优化：滑块增大触摸区域，按钮最小 44x44px

### 4.4 动画效果

- 油烟扩散：Canvas 粒子动画，从摊位向四周渐隐扩散
- 客流：小图标在摊位间移动动画
- 警告闪烁：容量/油烟超限时空格闪烁
- 回合切换：淡入淡出过渡
- 结算评分：数字滚动动画
