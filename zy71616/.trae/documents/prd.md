## 1. 产品概述

"量子骰子概率馆"是一款面向科普营学生的概率启蒙小游戏，通过掷骰子的交互让学生直观体验量子叠加态、测量坍缩和样本偏差三个核心概念的区别。游戏采用小关卡制，学生可以反复试错，老师课后可通过课堂报告区分学生的概念性错误与操作失误。

- 核心目标：让学生在玩耍中建立对概率、叠加与测量、样本偏差的正确直觉
- 目标用户：科普营中小学生（10-14岁），辅助教师用于课堂评估

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 学生 | 输入姓名进入 | 游戏闯关、查看个人记录、导出成绩 |
| 教师 | 输入教师码进入 | 查看全班报告、查看脏数据标记、导出课堂报告 |

### 2.2 功能模块

1. **游戏主界面**：量子骰子展示区、测量按钮、样本次数控制、概率板、关卡导航
2. **关卡选择页**：三个主题关卡入口（叠加关卡、测量关卡、偏差关卡）
3. **学生记录页**：个人操作历史、错因回放、成绩单
4. **课堂报告页**（教师）：全班统计、脏数据标记、概念错误 vs 操作失误分布

## 3. 核心流程

### 学生游戏流程
学生进入游戏 → 选择/进入关卡 → 看到任务卡目标 → 操作骰子（投掷/测量/调样本量） → 观察概率板变化 → 提交答案判断 → 成功则进入下一关，失败则触发失败反馈面板 → 查看错因回放 → 重试

### 教师评估流程
教师进入 → 查看全班报告 → 识别脏数据标记 → 区分概念错误与操作失误 → 导出课堂报告

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：科学馆互动展台风 — 深色背景+荧光色点缀，营造量子实验室氛围
- **主色调**：深靛蓝 (#0a0e27) 背景 + 荧光青 (#00f5d4) 主强调色 + 荧光紫 (#b388ff) 次强调色
- **骰子样式**：3D等距视角骰子，叠加态时六面同时半透明显示并缓慢旋转，测量坍缩时聚拢为确定一面
- **按钮风格**：圆角胶囊按钮，测量按钮为脉冲动画圆形按钮
- **字体**：标题用 Orbitron（科技感），正文用 Noto Sans SC
- **布局**：左侧骰子操作区，右侧概率板，底部任务卡，顶部关卡导航

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 游戏主界面 | 量子骰子区 | 3D等距骰子、叠加态概率云粒子、坍缩动画、脉冲测量按钮 |
| 游戏主界面 | 概率板 | 双柱状图（理论/实验）、荧光色柱条、实时更新动画 |
| 游戏主界面 | 样本数控 | 胶囊切换按钮组(1/10/100/1000)、当前数量高亮 |
| 游戏主界面 | 失败反馈 | 滑出面板、错因分类标签（概率/测量/样本）、回放按钮、重试按钮 |
| 游戏主界面 | 任务卡 | 底部浮层卡片、关卡目标文字、星级显示 |
| 关卡选择页 | 关卡卡片 | 三张大卡片、科技感边框、进度条、星级 |
| 学生记录页 | 操作时间线 | 垂直时间线、操作节点、颜色区分成败 |
| 学生记录页 | 错因回放 | 弹窗重放、步骤回放器、状态快照 |
| 课堂报告页 | 统计图表 | 柱状/饼图、脏数据红色标记、概念vs操作双维度分析 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px
- 平板适配：骰子区与概率板上下排列
- 触控优化：测量按钮≥48px点击区域，样本量切换大按钮

### 4.4 动画与反馈

- 叠加态骰子：六面半透明缓慢旋转，概率云粒子环绕
- 测量坍缩：六面急速旋转→聚拢→确定面放大闪光
- 概率板更新：柱条弹性动画过渡
- 失败反馈：面板从右侧滑入，错因标签脉冲闪烁
- 样本量增大时：骰子快速投掷雨动画
