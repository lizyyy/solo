# 校园食堂留样与过敏原追溯复盘看板

后勤食品安全负责人专用系统 - 数据导入、风险分析、问题追溯、报告导出

## 📋 功能特性

- **数据导入**: 支持导入 dishes.csv、sample_fridges.jsonl、allergen_rules.yaml、supplier_batches.csv
- **多维筛选**: 按日期、窗口、冰箱、问题类型筛选数据
- **留样时间线**: 可视化展示留样事件时间线，标记风险事件
- **过敏原风险分析**: 识别含过敏原的菜品及风险等级
- **供应商批次链路**: 追踪原料从供应商到食堂的完整链路
- **智能问题检测**:
  - 留样重量不足 (< 125g)
  - 冰箱温度断档 (> 2小时无记录)
  - 温度异常 (超出 0-4°C 范围)
  - 批次错配 (同一原料同一窗口不同批次)
  - 跨午夜夜宵归属错误
- **报告导出**: 生成 issues.csv 和 canteen_review.md

## 🚀 本地预览步骤

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务器

```bash
npm start
```

### 3. 访问系统

打开浏览器访问: **http://localhost:3000**

### 4. 核心演示流程

页面顶部有一键演示按钮，按顺序点击执行:

1. **点击 "1. 一键加载示例数据"** - 自动导入所有示例数据文件
2. **点击 "2. 执行风险分析"** - 开始检测各类问题
3. **点击 "3. 使用筛选器"** - 定位到筛选区域，可按条件过滤数据
4. **点击 "4. 查看问题详情"** - 定位到问题列表标签页
5. **点击 "5. 导出报告"** - 定位到导出区域，导出分析报告

### 5. 手动导入数据说明

如需使用自己的数据，点击各导入卡片选择对应文件:

| 文件名 | 格式 | 说明 |
|--------|------|------|
| dishes.csv | CSV | 菜品信息（包含配料列表） |
| sample_fridges.jsonl | JSON Lines | 留样冰箱记录（含温度日志） |
| allergen_rules.yaml | YAML | 过敏原规则配置 |
| supplier_batches.csv | CSV | 供应商批次信息 |

## 📊 示例数据说明

示例数据中故意设置了以下问题用于演示:

### 留样重量不足
- D001 红烧肉: 100g (标准 ≥125g)
- D006 水煮肉片: 80g (标准 ≥125g)
- D012 麻辣烫: 95g (标准 ≥125g)

### 温度异常
- D003 西红柿炒蛋: 5°C (标准 0-4°C)
- D004 宫保鸡丁: -1°C (标准 0-4°C)

### 温度断档
- D002 清蒸鱼: 3小时无记录 (> 2小时阈值)
- D005 麻辣香锅: 4小时无记录
- D012 麻辣烫: 3小时无记录

### 批次错配
- I001 猪肉 (窗口1, 2026-05-01): BATCH-P001 和 BATCH-P002 两个批次

### 过敏原风险
- 宫保鸡丁: 含花生 (花生/坚果类过敏原)
- 多道菜品: 含鸡蛋 (蛋类过敏原)
- 海鲜炒饭: 含虾、鱿鱼 (海鲜类过敏原)

## 🔧 技术栈

- **后端**: Node.js + Express
- **前端**: 原生 HTML/CSS/JavaScript
- **数据解析**: csv-parser, js-yaml

## 📝 输出文件说明

### issues.csv
包含所有检测到的问题，列包括:
- 严重程度 (高/中/低)
- 问题类型
- 日期
- 窗口
- 相关项目
- 详情描述

### canteen_review.md
完整的食品安全复盘报告，包含:
- 概览统计
- 问题分布分析
- 详细问题列表
- 改进建议

## 🎯 使用场景

1. **日常监管**: 后勤负责人每日/每周复盘食堂留样情况
2. **问题追溯**: 发现食品安全问题时快速定位来源
3. **合规检查**: 确保留样、温度、批次管理符合规范
4. **报告生成**: 自动生成食品安全报告供上级审查
