## 1. 产品概述

碳配额履约资金表是为能源公司财务部门打造的月底碳配额履约核算与资金规划工具。解决的核心问题：配额缺口、市场价格和锁价合约频繁变动，手工对表易出错且无法追溯数字来源。

- 目标用户：能源公司财务人员、碳资产管理人员
- 核心价值：将排放数据、配额账户、成交记录、锁价合同、预算表、资金报告六路数据自动归集，缺口与资金需求一键可查，所有数字可追溯至原始明细

## 2. 核心功能

### 2.1 用户角色

| 角色 | 权限说明 |
|------|----------|
| 财务人员 | 导入数据、查看资金表与报告、导出报告 |
| 碳资产管理人员 | 导入数据、管理锁价合约、查看缺口分析 |
| 管理层 | 查看预算预警与汇总报告 |

### 2.2 功能模块

1. **数据总览页**：配额缺口概览、资金缺口卡片、预算预警状态、异常提示
2. **配额归集页**：排放数据与配额账户的汇总、单位换算校验、缺口计算
3. **锁价匹配页**：锁价合约与缺口的匹配、重复锁价检测、锁价覆盖率
4. **预算预警页**：预算与实际资金需求对比、预警规则、超预算提示
5. **报告导出页**：可追溯报告生成、数字来源标注、多格式导出

## 3. 核心流程

1. 用户从排放数据、配额账户、成交记录、锁价合同、预算表、资金报告六处导入数据
2. 系统增量归集，后到数据不覆盖已有判断，而是标记冲突供用户确认
3. 系统自动计算配额缺口，进行单位换算校验
4. 系统匹配锁价合约与缺口，检测重复与异常
5. 系统对比预算与实际资金需求，生成预警
6. 用户在各页面查看一致的数据结论，点击任意数字可追溯来源
7. 用户导出报告，报告中数字同样可追溯

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深墨绿（#0D4B3C）象征碳/能源行业，辅以琥珀色（#D4A843）作为警示与强调
- 次要色：冷灰（#6B7280）用于中性信息，暖红（#DC2626）用于异常/预警
- 按钮风格：圆角微凸起，主按钮填充墨绿，次要按钮描边
- 字体：标题用 "Noto Serif SC" 庄重感，正文用 "DM Sans" 清晰易读
- 布局：左侧固定导航 + 右侧内容区，卡片式布局，表格带斑马纹
- 图标：线性图标风格，使用 lucide-react

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 数据总览页 | 缺口概览卡片 | 墨绿渐变卡片，大字数字，右下角溯源链接图标 |
| 数据总览页 | 预算预警状态 | 三色圆环图（绿/黄/红），悬浮显示阈值与明细 |
| 数据总览页 | 异常提示栏 | 琥珀色横幅，每条异常带解释文字与"查看详情"链接 |
| 配额归集页 | 数据溯源面板 | 右侧滑出面板，树状结构展示计算路径与来源 |
| 锁价匹配页 | 匹配结果区 | 桑基图展示锁价-缺口匹配流向 |
| 报告导出页 | 报告预览 | A4纸模拟排版，数字右上角带溯源标记徽章 |

### 4.3 响应式设计

- 桌面端优先，最小宽度 1280px
- 平板端（768-1279px）侧边栏收起为图标模式
- 手机端（<768px）堆叠布局，卡片全宽

### 4.4 数据溯源交互设计

- 页面上所有计算结果数字带有「溯源」小图标
- 点击溯源图标展开溯源面板，显示：数据来源文件、导入时间、计算公式、中间值
- 报告导出时，溯源信息以脚注形式附加
- 异常项溯源面板额外显示：异常类型、检测规则、修复建议
