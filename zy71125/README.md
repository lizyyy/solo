# 港口箱堆可达性分析系统

基于 WebGL/Three.js 的交互式港口集装箱堆场可视化分析工具，帮助堆场计划员分析集装箱被压层数、最优取箱路径和倒箱作业规划。

## ✨ 核心功能

- **3D 交互式箱堆场景**：支持拖拽旋转、滚轮缩放、右键平移
- **可达性分析**：自动计算目标箱被遮挡层数、最优取箱侧、倒箱数量
- **取箱路径可视化**：动态展示倒箱和取箱的完整路径
- **时间轴复盘**：支持播放、暂停、步进、速度调节的作业过程回放
- **多视角切换**：默认视角、俯视图、侧视图、吊机第一人称视角
- **筛选与搜索**：按箱区筛选、按箱号搜索集装箱
- **样例场景导入**：内置多种典型场景，支持自定义数据导入
- **报告导出**：支持 JSON 数据导出和 PDF 作业报告导出
- **状态持久化**：刷新页面后筛选条件和关键状态自动恢复

## 🎮 可复现操作指南

### 场景一：基础样例 - 分析单层遮挡

1. **启动应用**
   - 执行 `npm run dev`
   - 打开浏览器访问 `http://localhost:5173`

2. **加载样例场景**
   - 在左侧面板"样例场景"区域
   - 点击"基础样例 - 单层遮挡"
   - 系统自动加载场景并选中目标箱 CNT-02-01-00

3. **查看分析结果**
   - 右侧面板显示：目标箱信息、遮挡层数、最优取箱侧
   - 3D 场景中：目标箱高亮为绿色，遮挡箱高亮为橙色
   - 取箱路径以发光管线形式展示

4. **回放作业过程**
   - 点击底部时间轴的 ▶️ 播放按钮
   - 观察倒箱和取箱的动画过程
   - 可使用滑块拖动到任意步骤

5. **切换视角**
   - 点击底部左侧视角按钮
   - 依次尝试：默认、俯视、侧视、吊机视角

6. **导出报告**
   - 点击底部右侧"报告"按钮
   - 下载 PDF 格式的作业分析报告

### 场景二：自定义筛选和搜索

1. **箱区筛选**
   - 在左侧"筛选条件"区域
   - 箱区筛选选择"3区"
   - 3D 场景中只显示 3 区的集装箱

2. **搜索集装箱**
   - 在搜索框输入 `CNT-03`
   - 列表和场景自动过滤匹配的集装箱
   - 点击列表中的任意集装箱进行分析

3. **清除筛选**
   - 点击"清除筛选"按钮
   - 恢复显示所有集装箱

### 场景三：数据导入导出

1. **导出当前状态**
   - 点击底部"JSON"按钮
   - 下载包含当前堆场状态的 JSON 文件

2. **重置状态**
   - 点击左侧"重置状态"按钮
   - 场景恢复初始状态

3. **导入数据**
   - 点击左侧"导入数据"按钮
   - 选择刚才导出的 JSON 文件
   - 场景恢复到导出时的状态

## 🧩 核心数据模型

### Container (集装箱)

```typescript
{
  id: string;           // 箱号
  bay: number;          // 箱区号
  row: number;          // 行号
  tier: number;         // 层号
  size: '20ft' | '40ft';// 尺寸
  weight: number;       // 重量(吨)
  status: 'normal' | 'target' | 'blocking' | 'moved';
  color: string;        // 显示颜色
}
```

### Task (取箱任务)

```typescript
{
  id: string;
  targetContainerId: string;
  moves: Move[];        // 作业步骤列表
  totalRelocations: number;  // 倒箱总数
  optimalSide: 'left' | 'right';  // 最优取箱侧
}
```

## 🎯 可达性分析算法

1. **遮挡检测**：遍历同箱区同列中位于目标箱上方的集装箱
2. **侧方可达性**：分析从左右两侧接近目标箱的可行性
3. **成本计算**：比较两侧的倒箱成本，选择最优取箱侧
4. **路径规划**：为每个需要倒箱的集装箱寻找临时存放位置
5. **步骤生成**：生成完整的作业步骤序列

## 📝 注意事项

1. **浏览器兼容性**：建议使用 Chrome/Edge/Firefox 最新版本
2. **性能优化**：集装箱数量较多时，可降低浏览器缩放级别
3. **数据格式**：导入的 JSON 文件需包含 `yard` 和 `containers` 字段
4. **状态持久化**：筛选条件和视角设置会自动保存到 localStorage

## 🤝 常见问题

**Q: 3D 场景加载很慢？**
A: 首次加载 Three.js 资源需要时间，后续访问会有缓存加速。

**Q: 为什么有些集装箱无法选中？**
A: 可能被其他集装箱遮挡，切换视角或旋转场景后再尝试。

**Q: 导出的 PDF 中文显示乱码？**
A: 当前使用系统默认字体，中文显示可能有问题，建议配合 JSON 数据使用。

**Q: 刷新页面后分析结果丢失？**
A: 分析结果不会持久化，但筛选条件和视角设置会保留，重新选择目标箱即可。
