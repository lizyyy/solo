# 导出任务记录大文件排队分析 CLI

一个用于分析导出任务记录中排队情况、大文件任务和用户异常行为的命令行工具。

## 功能特性

- 📊 **概览统计**: 总任务数、大文件任务占比、各状态任务分布
- ⏱️ **排队时长分析**: 计算平均等待时间、中位数、P95、最长等待TOP列表
- 📁 **大文件任务详情**: 识别并展示超过阈值的大文件导出任务
- 🔄 **重复任务检测**: 检测短时间内同一用户重复导出相同文件的情况
- 👆 **用户连点识别**: 识别间隔小于3秒的快速点击行为
- 📈 **用户重试模式分析**: 分析用户取消后重试、失败后重试等行为模式
- 💥 **压缩失败分析**: 专门分析压缩导出任务的失败情况
- ❌ **取消任务分析**: 分析取消原因、取消方、排队时长等信息

## 快速开始

### 环境要求

- Node.js >= 18.0.0

### 安装依赖

```bash
npm install
```

### 运行分析

#### 分析正常数据

```bash
node bin/cli.js -i samples/normal.json
```

#### 分析异常数据（包含连点、取消、压缩失败）

```bash
node bin/cli.js -i samples/abnormal.json
```

#### 输出JSON格式

```bash
node bin/cli.js -i samples/normal.json -f json
```

#### 输出到文件

```bash
node bin/cli.js -i samples/abnormal.json -o report.txt
```

#### 自定义阈值参数

```bash
# 把大文件阈值设为50MB，重复任务时间窗口设为60秒
node bin/cli.js -i samples/abnormal.json -t 50 -w 60
```

### 命令行选项

```
-i, --input <文件>      输入JSON文件路径（必需）
-o, --output <文件>     输出文件路径（可选，默认输出到控制台）
-f, --format <格式>     输出格式: text|json（默认: text）
-t, --threshold <MB>    大文件阈值，单位MB（默认: 100）
-w, --window <秒>       重复任务时间窗口，单位秒（默认: 300）
-h, --help              显示帮助信息
```

## 输入数据格式

输入JSON文件应为任务记录数组，每条记录支持以下字段：

```json
[
  {
    "taskId": "EXPORT-2024-001",
    "userId": "U10001",
    "userName": "张三",
    "fileName": "销售数据汇总.xlsx",
    "fileSize": 157286400,
    "exportType": "Excel报表",
    "status": "success",
    "statusReason": "导出完成",
    "createdAt": "2024-05-16T09:00:00.000Z",
    "startedAt": "2024-05-16T09:00:45.000Z",
    "completedAt": "2024-05-16T09:05:20.000Z",
    "cancelledAt": null,
    "cancelledBy": null,
    "cancelReason": null,
    "isCompression": false,
    "errorMessage": null,
    "retryCount": 0
  }
]
```

### 字段说明

| 字段 | 类型 | 必需 | 说明 |
|------|------|------|------|
| taskId | string | 是 | 任务唯一标识 |
| userId | string | 是 | 用户唯一标识 |
| userName | string | 否 | 用户姓名 |
| fileName | string | 是 | 导出文件名 |
| fileSize | number | 是 | 文件大小（字节） |
| exportType | string | 否 | 导出类型 |
| status | string | 是 | 状态: queued/processing/success/failed/cancelled |
| statusReason | string | 否 | 状态说明 |
| createdAt | string | 是 | 创建时间（ISO格式） |
| startedAt | string | 否 | 开始处理时间（ISO格式） |
| completedAt | string | 否 | 完成时间（ISO格式） |
| cancelledAt | string | 否 | 取消时间（ISO格式） |
| cancelledBy | string | 否 | 取消方: user/system |
| cancelReason | string | 否 | 取消原因 |
| isCompression | boolean | 否 | 是否压缩任务 |
| errorMessage | string | 否 | 错误信息 |
| retryCount | number | 否 | 重试次数 |

## 验收说明

### 正常路径验证

```bash
node bin/cli.js -i samples/normal.json
```

验证输出包含：
- 具体的业务文件名（如"2024年度销售数据汇总.xlsx"）
- 真实的用户名（如"张三"、"李四"）
- 导出类型信息（如"Excel报表"）
- 清晰的排队时长统计

### 异常路径验证

```bash
node bin/cli.js -i samples/abnormal.json
```

验证输出包含：
- 用户连点行为标记（如"周经理"的快速点击）
- 重复任务的时间间隔和状态关系
- 压缩失败的具体错误信息
- 取消任务的原因和排队时长
- 所有异常分析部分完整展示

### Diff兼容性

连续运行两次分析，比较输出（除了分析时间戳外应该完全一致）：

```bash
node bin/cli.js -i samples/normal.json > run1.txt
node bin/cli.js -i samples/normal.json > run2.txt
diff run1.txt run2.txt
```
