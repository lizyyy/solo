# 非遗器物修复委托流转台

一个用于非遗器物修复工作室的本地修复委托流转管理系统，帮助师傅们高效管理客户委托、器物修复状态、照片、报价和提醒事项。

## 功能特性

### 核心功能
- **客户管理**：登记客户信息，包括姓名、电话、邮箱、地址等
- **委托登记**：创建修复委托，记录器物信息、损伤描述、预计完成日期
- **状态流转**：支持6种状态流转（待评估 → 评估中 → 报价确认 → 修复中 → 待客户确认 → 已交付）
- **照片管理**：上传和关联器物照片，记录修复前后的状态
- **报价管理**：记录修复报价，支持确认状态追踪
- **提醒功能**：设置提醒事项，防止错过重要时间节点

### 筛选与导出
- **超期筛选**：快速查看已超期的修复任务
- **待确认筛选**：查看等待客户确认的任务
- **状态筛选**：按当前状态筛选器物
- **导出Markdown修复单**：生成详细的修复单文档
- **导出CSV待办清单**：导出所有未完成任务的清单

## 技术栈

- **后端**：Node.js + Express + SQLite
- **前端**：原生 HTML + CSS + JavaScript
- **文件上传**：Multer
- **跨域**：CORS

## 安装与启动

### 环境要求
- Node.js 14.0 或更高版本
- npm 或 yarn 包管理器

### 安装步骤

1. **安装依赖**
```bash
npm install
```

2. **初始化数据库**
```bash
node database/init.js
```

3. **导入示例数据（可选）**
```bash
node database/seed.js
```

4. **启动服务器**
```bash
npm start
```

5. **访问应用**
打开浏览器访问：`http://localhost:3000`

## 状态流转说明

系统支持以下6种状态，按修复流程顺序流转：

| 状态 | 说明 | 下一步操作 |
|------|------|-----------|
| 待评估 | 客户提交委托，等待师傅评估 | 开始评估 |
| 评估中 | 师傅正在评估器物损伤情况 | 给出报价 |
| 报价确认 | 已向客户报价，等待确认 | 客户确认报价 |
| 修复中 | 客户确认报价，开始修复工作 | 完成修复 |
| 待客户确认 | 修复完成，等待客户确认满意 | 客户确认 |
| 已交付 | 客户确认满意，完成交付 | 流程结束 |

## 完整流程验证

### 1. 新建委托流程

1. 点击「+ 新增委托」按钮
2. 选择或新增客户
3. 填写器物信息：
   - 器物名称（必填）
   - 器物类型
   - 年代
   - 材质
   - 尺寸
   - 损伤描述
   - 预计完成日期
4. 点击「保存」

### 2. 状态流转流程

1. 在器物列表找到新建的委托
2. 点击「详情」按钮
3. 切换到「状态日志」标签
4. 选择新状态，填写说明和操作人
5. 点击「更新」

**建议按以下顺序测试状态流转：**
```
待评估 → 评估中 → 报价确认 → 修复中 → 待客户确认 → 已交付
```

### 3. 照片管理流程

1. 进入器物详情页
2. 切换到「照片」标签
3. 选择图片文件，填写描述（可选）
4. 点击「上传」
5. 可以在下方看到已上传的照片列表

### 4. 报价管理流程

1. 进入器物详情页
2. 切换到「报价」标签
3. 填写报价金额和说明
4. 点击「添加」
5. 报价状态为「待确认」时，可点击「确认」按钮

### 5. 筛选与导出

**筛选功能：**
- 在「器物列表」页面使用状态筛选
- 使用「特殊筛选」查看超期或待确认的任务

**导出功能：**
1. **导出CSV待办清单**：在工作台点击「导出待办清单」
2. **导出Markdown修复单**：进入器物详情页，点击「导出修复单」

### 6. 提醒管理

1. 切换到「提醒事项」页面
2. 点击「+ 新增提醒」
3. 填写提醒标题、描述、日期
4. 可选择关联特定器物
5. 点击「保存」

## API 接口说明

### 客户管理
- `GET /api/customers` - 获取客户列表
- `GET /api/customers/:id` - 获取单个客户
- `POST /api/customers` - 新建客户
- `PUT /api/customers/:id` - 更新客户
- `DELETE /api/customers/:id` - 删除客户

### 器物管理
- `GET /api/artifacts` - 获取器物列表（支持筛选参数：status, overdue, pending_confirmation）
- `GET /api/artifacts/:id` - 获取单个器物
- `POST /api/artifacts` - 新建器物
- `PUT /api/artifacts/:id` - 更新器物
- `PUT /api/artifacts/:id/status` - 更新器物状态
- `DELETE /api/artifacts/:id` - 删除器物

### 照片管理
- `GET /api/artifacts/:id/photos` - 获取器物照片
- `POST /api/artifacts/:id/photos` - 上传照片（multipart/form-data）
- `DELETE /api/photos/:id` - 删除照片

### 状态日志
- `GET /api/artifacts/:id/status-logs` - 获取状态日志

### 报价管理
- `GET /api/artifacts/:id/quotes` - 获取报价列表
- `POST /api/artifacts/:id/quotes` - 新建报价
- `PUT /api/quotes/:id` - 更新报价

### 提醒管理
- `GET /api/reminders` - 获取提醒列表
- `POST /api/reminders` - 新建提醒
- `PUT /api/reminders/:id` - 更新提醒
- `DELETE /api/reminders/:id` - 删除提醒

### 导出接口
- `GET /api/artifacts/:id/export/markdown` - 导出Markdown修复单
- `GET /api/export/todos/csv` - 导出CSV待办清单

## 注意事项

1. **数据库文件**：`database/repair.db` 会在首次运行初始化脚本后生成
2. **照片上传**：上传的照片会保存在 `uploads/` 目录下
3. **端口配置**：默认使用3000端口，如需修改请编辑 `server.js` 中的 `PORT` 变量
4. **数据备份**：定期备份 `database/repair.db` 文件以防止数据丢失

## 常见问题

**Q: 如何修改服务器端口？**
A: 编辑 `server.js` 文件，修改 `const PORT = 3000;` 这一行的端口号。

**Q: 数据库文件在哪里？**
A: 数据库文件位于 `database/repair.db`，这是一个SQLite数据库文件，可以使用SQLite客户端工具查看。

**Q: 上传的照片保存在哪里？**
A: 上传的照片保存在 `uploads/` 目录下，文件名会自动重命名以避免冲突。

**Q: 如何重置数据库？**
A: 删除 `database/repair.db` 文件，然后重新运行 `node database/init.js` 和 `node database/seed.js`。
