## 1. 产品概述

播客多语字幕对齐工具——为播客制作团队提供统一时间线，将原始音轨、多语字幕草稿、剪辑点和广告口播表整合到同一视图中，自动检测静音段误删、时间轴漂移和语种遗漏，并确保字幕与上线清单同步更新，支持人工校正历史保留与外包协作导出。

- 解决播客剪辑中中英字幕对齐难、改稿后多端数据不同步、人工校正易丢失的痛点
- 面向播客制作人、剪辑师和外包字幕团队，提升上线前审校效率与质量

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 剪辑师 | 项目邀请链接 | 上传音轨/字幕、编辑时间线、标记问题、调整对齐 |
| 制作人 | 项目邀请链接 | 审校对齐清单、标注需重听片段、导出外包文件、确认上线 |
| 外包字幕员 | 导出文件链接 | 查看指派片段、编辑字幕文本、提交修正 |

### 2.2 功能模块

1. **时间线工作台**：多轨道统一时间线、音轨波形可视化、字幕轨道叠加、剪辑点/广告口播标记、拖拽调整
2. **对齐检测面板**：静音段误删检测、时间轴漂移检测、语种遗漏检测、问题片段标记与人工修正
3. **同步更新引擎**：剪辑修改后自动级联更新字幕时间戳与上线清单、冲突提示
4. **制作人清单**：已对齐/待重听/有问题片段汇总、状态标记、批量操作
5. **导出与历史**：外包导出（SRT/VTT+标注）、字幕重上传后保留旧校正点、校正历史时间线

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 时间线工作台 | 多轨时间线 | 显示音轨波形、中文/英文字幕轨、剪辑点轨、广告口播轨，支持缩放/拖拽/选区 |
| 时间线工作台 | 片段编辑器 | 选中片段后弹出编辑面板，可调整起止时间、修改字幕文本、标记状态 |
| 时间线工作台 | 波形与播放控制 | 音频波形展示、播放/暂停/跳转、A-B循环播放、播放速度调节 |
| 对齐检测面板 | 自动检测 | 一键检测静音段误删、时间轴漂移、语种遗漏，结果以标记形式落在时间线上 |
| 对齐检测面板 | 问题列表 | 侧边栏列出所有检测到的问题，按严重程度排序，点击跳转对应位置 |
| 对齐检测面板 | 人工校正 | 对检测问题逐条修正，校正点自动记录操作人与时间 |
| 制作人清单 | 对齐状态总览 | 饼图/进度条显示已对齐、待重听、有问题片段比例 |
| 制作人清单 | 片段明细表 | 表格列出每个片段的序号、时间范围、语种对齐状态、问题类型、操作人、备注 |
| 制作人清单 | 批量操作 | 批量标记为已对齐/需重听、批量添加备注 |
| 导出与历史 | 外包导出 | 选择语种和片段范围，导出SRT/VTT及标注文件（含需修正说明） |

| 导出与历史 | 校正历史 | 时间线式展示所有校正操作，支持按时间/操作人/片段筛选 |

## 3. 核心流程

1. 剪辑师上传原始音轨和字幕草稿（SRT/VTT），系统自动解析并放置到多轨时间线上
2. 剪辑师在时间线上标记剪辑点和广告口播位置
3. 运行自动对齐检测，系统标出静音段误删、时间轴漂移、语种遗漏等问题
4. 剪辑师逐条修正问题，每次校正记录操作人与时间戳
5. 修改任一片段时间后，关联的字幕时间戳和上线清单自动级联更新
6. 制作人查看清单，标记需重听片段，添加审核备注
7. 制作人导出外包文件，外包字幕员离线处理后上传修正字幕
8. 系统对比新旧字幕，保留旧校正点以虚线显示，新内容以实线显示

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底 (#1A1A2E) + 暖橙强调 (#FF6B35) + 薄荷绿状态 (#2EC4B6)，营造专业音频工作站氛围
- **辅助色**：浅灰面板 (#16213E)、淡蓝信息 (#0F3460)、珊瑚红警告 (#E94560)
- **按钮风格**：圆角矩形（6px），主操作填充暖橙，次操作描边，危险操作珊瑚红
- **字体**：标题用 JetBrains Mono（等宽专业感），正文用 Noto Sans SC（中文清晰）
- **布局风格**：深色专业工作站风格，左侧窄导航栏，顶部工具条，中间大时间线区域，右侧可折叠面板
- **图标**：线性图标风格（类似 Lucide），4px 描边宽度
- **动效**：波形动画随播放实时滚动，问题标记脉冲闪烁，片段调整时吸附反馈

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |

### 4.3 响应式策略

- 桌面优先（1440px+）：完整多轨时间线+侧面板
- 平板（1024px-1439px）：时间线压缩，面板变为底部抽屉
- 手机（<1024px）：仅显示制作人清单视图，不支持时间线编辑
