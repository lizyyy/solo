# 少儿打击乐课堂评分工具

为录音师老许打造的小工具，用于整理和评分少儿打击乐课堂录音材料。

## 功能特点

- ✅ Excel曲目清单与音频文件自动匹配
- ✅ 异常检测（重复曲目、旧版母带、未授权、人工改名等）
- ✅ 批量处理错误隔离（坏文件不拖垮整批）
- ✅ 补录备注与差异对比
- ✅ 数据冲突证据展示
- ✅ 统一报告输出（Excel明细 + 文本汇总 + HTML报告）

## 目录结构

```
.
├── sample_data/
│   ├── excel/          # 曲目Excel文件存放处
│   │   └── 曲目清单.xlsx
│   └── audio/          # 音频文件存放处（支持wav/mp3/flac/m4a/aac）
├── output/             # 处理报告输出目录
├── logs/               # 日志目录
├── src/                # 源代码
└── main.py             # 主程序入口
```

## 快速开始

### 1. 安装依赖

```bash
pip3 install -r requirements.txt
```

### 2. 准备数据

- 将曲目清单Excel放入 `sample_data/excel/`
- 将音频文件放入 `sample_data/audio/`

**音频文件命名规范**（推荐）：
```
TRK001_小星星变奏曲_小明.wav
{曲目编号}_{曲目名称}_{学生姓名}.{扩展名}
```

### 3. 运行完整演示

一键运行完整流程，体验：首次处理 → 补录备注 → 返工对比

```bash
python3 main.py demo
```

### 4. 常规使用

运行完整处理流程：
```bash
python3 main.py run --excel sample_data/excel/曲目清单.xlsx --audio sample_data/audio --name 三月第一周
```

为曲目补录备注：
```bash
python3 main.py note TRK005 "家长已确认授权，下周补交签字文件"
```

## Excel列名说明

| 列名 | 说明 | 必填 |
|------|------|------|
| 曲目编号 | 唯一标识，如TRK001 | ✅ |
| 曲目名称 | 曲目名称 | ✅ |
| 学生姓名 | 学生姓名 | ✅ |
| 上课日期 | 上课日期 | - |
| 时长(秒) | 曲目时长 | - |
| 已授权 | 是否获得授权（是/否） | - |
| 版本 | 版本号，如v2.0 | - |
| 备注 | 其他备注信息 | - |

## 异常类型说明

工具会自动检测以下异常：

| 异常类型 | 说明 |
|----------|------|
| 重复曲目 | 同一曲目编号出现多次或匹配到多个音频 |
| 旧版母带 | 版本含v1/旧版/old标识 |
| 未授权 | 已授权列为"否" |
| 人工改名 | 备注含"改名"/"原曲目"等关键词 |
| 文件损坏 | 音频文件大小为0 |
| 时长不符 | Excel时长与实际音频时长不一致 |
| 缺失音频 | 未找到匹配的音频文件 |
| 名称不匹配 | Excel曲目名与文件名解析不一致 |

## 报告说明

每次处理会生成3个报告文件：

1. **{名称}_时间_明细.xlsx** - 完整Excel明细
   - Sheet1: 曲目明细（含状态、异常、处理日志）
   - Sheet2: 异常清单

2. **{名称}_时间_汇总.txt** - 快速查看的文本摘要
   - 处理统计
   - 异常分布
   - 需关注曲目列表

3. **{名称}_时间_报告.html** - 可视化HTML报告
   - 统计卡片
   - 数据冲突证据对比
   - 补录差异展示
   - 完整曲目表格

## 工作流程示例

### 场景一：顺利处理一批新录音

```bash
# 1. 放入新材料
# cp 新录音/*.wav sample_data/audio/
# cp 新曲目.xlsx sample_data/excel/

# 2. 运行处理
python3 main.py run --name 2024年3月第一周

# 3. 查看output目录下的报告
```

### 场景二：补录备注后返工

```bash
# 1. 首次处理
python3 main.py run --name 首次处理

# 2. 补录备注
python3 main.py note TRK005 "家长电话确认授权"
python3 main.py note TRK003 "旧版母带已审核通过"

# 3. 更新Excel后返工
python3 main.py run --excel sample_data/excel/曲目清单_返工.xlsx --name 返工处理
```

### 场景三：数据冲突人工判断

当Excel与导入数据不一致时，工具会：
- 保留两边证据
- 不自动合并或覆盖
- 在报告中列出冲突字段和建议操作
- 由录音师老许人工判断后手动更新

## 注意事项

1. **坏文件隔离**：单个音频文件损坏不会影响其他曲目处理
2. **异常可见**：所有异常都会在报告中明确列出，不会被汇总数字掩盖
3. **处理日志**：每条曲目都有完整处理日志，方便追溯问题
4. **备注持久化**：补录的备注保存在 `output/notes.json` 中，不会丢失
