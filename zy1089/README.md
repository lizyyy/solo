# ☕ 咖啡店早高峰出杯调度游戏

一款本地网页小游戏，模拟咖啡店早高峰的出杯调度。作为店长，你需要合理安排咖啡机、磨豆机、冰柜和店员动作，在8分钟内尽可能多地完成订单，同时注意设备温度和原料库存。

## 🎮 游戏特色

### 核心玩法
- **8分钟营业回合**：模拟真实的早高峰时间压力
- **订单系统**：支持普通单、加急单、冰饮单、外带单四种类型
- **饮品配方**：10种不同咖啡，每种都有详细制作步骤
- **设备管理**：咖啡机、磨豆机有温度限制，过热会扣分和故障
- **店员调度**：同一时间只能做一件事，需要合理分配
- **顾客耐心**：超时会扣分，提前完成有加分

### 玩家操作
- **暂停/继续**：随时暂停（暂停时也可以排程）
- **倍速**：1x/2x/3x 加速游戏
- **撤销**：撤销最近一次排程操作
- **查看详情**：当前队列、设备状态、库存、预计出杯时间

### 关卡系统（3个难度）
| 关卡 | 难度 | 特点 |
|------|------|------|
| 新手练习 | 简单 | 2咖啡机+2磨豆机+2店员，订单频率低 |
| 繁忙早班 | 中等 | 2咖啡机+2磨豆机+2店员，订单频率中等，有一定故障概率 |
| 极限挑战 | 困难 | 1咖啡机+1磨豆机+2店员，订单频率高，故障概率大，加急单多 |

### 评分系统
- 按时完成: +100分
- 提前完成: +额外50分
- 加急单小费: +50分
- 连单奖励: 连续完成订单额外加分
- 超时: -50分
- 漏单: -100分
- 设备过热: -20分

### 营业日报
每局结束生成详细的营业日报，包含：
- 最终评分和评级（S/A/B/C）
- 完成率、平均等待时间
- 浪费原料、过热次数、漏单统计
- 支持导出 **Markdown** 和 **JSON** 格式

### 本地保存
- 最高分记录（Top 10）
- 最近一次游戏草稿（24小时内有效）
- 刷新页面后可以继续游戏

## 🎯 玩法指南

### 基础操作
1. **选择订单**：点击左侧订单队列中的订单
2. **选择店员**：点击中间空闲的店员卡片
3. **自动分配**：当同时选中订单和空闲店员时，会自动开始制作
4. **暂停思考**：点击暂停按钮，暂停时也可以安排任务

### 操作技巧
- **加急单优先**：加急单有时间限制但有小费奖励
- **设备轮换**：不要一直使用同一台咖啡机/磨豆机，会过热
- **连单加分**：连续完成订单会有额外加分
- **库存预警**：注意右侧库存面板，红色表示不足
- **利用暂停**：订单多的时候可以暂停仔细安排

### 快捷键
| 按键 | 功能 |
|------|------|
| 空格 / P | 暂停/继续 |
| 1 | 1倍速 |
| 2 | 2倍速 |
| 3 | 3倍速 |
| Ctrl + Z | 撤销 |
| ESC | 退出到菜单 |

## 🔧 自定义配置

你可以通过修改 `config.js` 文件来自定义游戏参数：

### 修改关卡配置
```javascript
// 在 LEVELS 数组中修改
{
    id: 0,
    name: '自定义关卡',
    difficulty: 'easy',
    config: {
        coffeeMachines: 3,      // 咖啡机数量
        grinders: 3,            // 磨豆机数量
        staff: 3,               // 店员数量
        orderFrequency: 0.01,   // 订单频率
        urgentRatio: 0.05,      // 加急单比例
        // ... 更多配置
    }
}
```

### 添加新饮品
```javascript
// 在 DRINKS 对象中添加
MY_NEW_DRINK: {
    id: 'MY_NEW_DRINK',
    name: '我的新饮品',
    isIced: false,
    steps: [
        { type: 'GRIND', duration: 5, equipment: 'grinder' },
        { type: 'BREW', duration: 10, equipment: 'coffee_machine' },
        // ... 更多步骤
    ],
    ingredients: {
        coffee_beans: 1,
        water: 1,
        // ... 更多原料
    },
    baseTime: 150
}
```
