# 🏭 生产线安全距离检查系统

基于 Three.js 的 3D 可视化安全距离检查工具，用于工厂设备搬迁前的安全评估。

## ✨ 功能特性

- **3D 可视化车间**：完整的车间场景，包含机器人臂、操作台、安全门、人员通道
- **机器人扫掠模拟**：动态展示机器人运动轨迹和扫掠范围
- **实时距离校验**：自动检测安全距离违规情况
- **风险高亮显示**：风险设备自动高亮，风险列表实时更新
- **设备筛选**：可单独显示/隐藏各类设备
- **多视角切换**：俯视图、正视图、侧视图、透视图一键切换
- **时间轴控制**：可播放、暂停、拖拽控制机器人动画进度
- **状态持久化**：刷新页面后筛选条件和关键状态不丢失
- **报告导出**：一键导出 HTML 格式的安全检查报告

## 🚀 快速开始

### 环境要求

- 现代浏览器（Chrome 80+, Firefox 75+, Safari 13+, Edge 80+）
- 无需 Node.js 或其他后端环境

### 启动方式

**方式一：直接打开（推荐）**
```bash
# 直接在浏览器中打开 index.html
open index.html
```

**方式二：使用本地服务器**
```bash
# 使用 Python 3
python3 -m http.server 8080

# 或使用 Node.js
npx serve .

# 或使用 PHP
php -S localhost:8080
```

然后在浏览器中访问 `http://localhost:8080`

## 🎮 可复现操作指南

### 基础操作流程

1. **加载样例场景**
   - 点击顶部「📥 导入样例」按钮
   - 系统自动加载预设的车间布局并执行安全检测

2. **观察 3D 场景**
   - **旋转视角**：按住鼠标左键拖动
   - **平移场景**：按住鼠标右键拖动
   - **缩放**：滚动鼠标滚轮

3. **切换视角**
   - 点击左侧「👁 视角切换」面板中的按钮
   - 快速切换到：俯视图、正视图、侧视图、透视图

4. **设备筛选**
   - 在「📋 设备筛选」面板中勾选/取消勾选
   - 支持筛选：机器人臂、操作台、安全门、人员通道、扫掠区域
   - **状态持久化**：刷新页面后筛选条件自动恢复

### 扫掠模拟与风险检测

1. **播放扫掠动画**
   - 点击「🎬 扫掠模拟」面板的「▶ 播放」按钮
   - 观察机器人臂的完整运动周期
   - 系统自动检测并高亮风险设备

2. **手动控制时间轴**
   - 拖拽时间轴滑块到任意位置
   - 观察特定时刻的机器人姿态
   - 风险检测实时更新

3. **暂停与复位**
   - 点击「⏸ 暂停」停止动画
   - 点击顶部「🔄 状态重置」恢复初始状态

### 风险检查与调整

1. **查看风险列表**
   - 左侧「⚠️ 风险检测」面板显示所有风险
   - 红色 = 高风险，黄色 = 中风险，蓝色 = 低风险

2. **调整安全阈值**
   - 在「📐 安全阈值」面板修改参数：
     - 机器人与操作台安全距离（默认 1.5m）
     - 机器人与安全门安全距离（默认 2.0m）
     - 人员通道最小宽度（默认 1.2m）
   - 修改后风险检测自动重新计算

3. **验证场景风险**
   - 当前预设场景中：
     - 机器人与操作台 1 距离 = 5.00m ✅ 正常
     - 机器人与操作台 2 距离 = 10.00m ✅ 正常
     - 机器人与安全门 1 距离 = 10.00m ✅ 正常
     - 机器人与安全门 2 距离 = 5.83m ✅ 正常

### 导出检查报告

1. 点击顶部「📊 导出报告」按钮
2. 系统自动下载 HTML 格式报告
3. 报告包含：
   - 检查时间和状态概览
   - 风险分类统计
   - 安全阈值设置
   - 详细风险列表

## 🎯 核心检测逻辑

### 距离计算
- 基于 3D 空间两点间欧氏距离
- 机器人基准点：底座中心位置
- 设备基准点：Group 位置坐标

### 风险等级
- **高风险**：距离小于安全阈值 → 红色高亮
- **中风险**：距离小于安全阈值 + 0.5m → 黄色提示
- **正常**：距离满足安全要求

### 检测项目
1. ✅ 机器人扫掠越界（与操作台距离）
2. ✅ 安全门被挡风险（与机器人距离）
3. ✅ 人员通道宽度检查

## ⚠️ 注意事项

1. **浏览器兼容性**：建议使用 Chrome 或 Firefox 获得最佳性能
2. **WebGL 支持**：确保浏览器启用 WebGL
3. **性能优化**：低配电脑可关闭「扫掠区域」显示提升帧率
4. **状态保存**：仅保存筛选条件和阈值设置，不保存视角位置

## 🐛 故障排查

**Q: 3D 场景无法显示？**
- 检查浏览器是否支持 WebGL
- 尝试使用本地服务器方式打开

**Q: 动画卡顿？**
- 关闭不必要的设备筛选（如扫掠区域）
- 使用 Chrome 浏览器

**Q: 刷新后状态丢失？**
- 检查浏览器是否禁用 localStorage
- 检查是否使用隐私浏览模式
