# 危化品柜巡检签收台

校园实验室危化品柜巡检管理桌面应用，用于安全员日常巡检、盘点和领用管理。

## 功能特性

### 核心管理功能
- **试剂管理**: 维护试剂信息（瓶号、名称、类别、有效期、库存等）
- **柜位管理**: 管理试剂存放柜位信息
- **责任人管理**: 管理实验室安全员和操作人信息
- **领用/归还**: 记录试剂领用和归还流水，自动更新库存

### 巡检与校验
- **扫码盘点**: 支持扫码枪或手动输入瓶号完成盘点
- **自动校验**:
  - ✅ **过期预警**: 检查试剂是否已过期或即将过期（30天内）
  - ✅ **库存下限**: 检查当前数量是否低于最低预警值
  - ✅ **同柜禁配**: 检查酸碱混放、氧化剂与还原剂混放等禁配情况
  - ✅ **超期未归还**: 检查领用记录是否超过预计归还日期

### 报告生成
- **Markdown 巡检报告**: 包含巡检概览、按柜位统计、异常详情、禁配规则说明
- **CSV 异常清单**: 包含所有异常信息和处理建议

### 数据持久化
- 使用 SQLite 本地文件数据库
- 数据存储在 `data/chemicals.db`
- 刷新/重启不丢失数据

## 安装与运行

### 环境要求
- Python 3.7+
- PyQt5 >= 5.15.0

### 安装步骤

1. **安装依赖**
```bash
pip install PyQt5
```

2. **运行应用**
```bash
python main.py
```

### 首次运行
首次运行时会自动：
- 创建 SQLite 数据库文件 `data/chemicals.db`
- 初始化所有数据表
- 加载示例数据（3个责任人、4个柜位、6个试剂、3条领用记录）

示例数据中故意设置了各种异常场景用于测试：
- 1个已过期试剂
- 1个即将过期试剂
- 2个库存不足试剂
- 1个禁配存放的试剂（碱类放在酸类柜）
- 1条超期未归还领用记录

## 使用指南

### 1. 试剂管理
- **搜索**: 输入瓶号、试剂名称或生产厂家搜索
- **新增**: 点击"新增试剂"按钮，填写表单后保存
- **编辑**: 双击表格行或选中后点击"编辑"
- **删除**: 选中后点击"删除"（有确认提示）
- **导入导出**: 支持 CSV 格式的批量导入导出

### 2. 柜位管理
- 管理试剂存放柜位的名称、位置、责任人等信息
- 删除柜位时会检查是否有试剂关联，有关联则禁止删除

### 3. 责任人管理
- 管理实验室安全员信息
- 删除时检查是否有关联数据（试剂、柜位、领用记录）

### 4. 领用/归还
- **扫码输入**: 在瓶号输入框扫码或输入瓶号后按回车，自动查询试剂信息
- **领用操作**:
  - 选择操作类型为"领用"
  - 输入数量（不能超过当前库存）
  - 选择操作人
  - 设置预计归还日期
  - 保存后自动扣减库存
- **归还操作**:
  - 选择操作类型为"归还"
  - 输入数量
  - 保存后自动增加库存
- **状态显示**:
  - 领用中（蓝色）
  - 已归还（绿色）
  - 超期（红色）
- **筛选**: 可按操作类型和状态筛选记录

### 5. 盘点管理
- **扫码盘点**: 在瓶号输入框扫码或输入瓶号后按回车
- **核对数量**: 系统显示当前库存数量，输入实际盘点数量
- **记录差异**: 如有差异，说明差异原因
- **实时统计**: 显示总数、已盘点、待盘点、异常数量
- **按柜位筛选**: 可选择特定柜位进行盘点
- **导出报告**: 盘点完成后可导出盘点报告

### 6. 巡检报告
- **执行检查**: 点击"执行巡检检查"按钮，自动运行所有校验规则
- **统计面板**: 显示各类问题数量（过期、即将过期、库存不足、禁配警告、超期未归还）
- **问题列表**: 显示详细异常信息和处理建议
- **生成报告**:
  1. 选择巡检人
  2. 点击"生成巡检报告"
  3. 选择输出目录
  4. 生成 Markdown 报告和 CSV 异常清单
- **历史记录**: 查看过往巡检记录

### 7. 预警中心
- **预警列表**: 显示所有预警信息
- **类型筛选**: 按预警类型筛选（过期、即将过期、库存不足、禁配、超期未归还）
- **状态筛选**: 按处理状态筛选（未处理、已处理）
- **标记已处理**: 选中预警后点击"标记为已处理"
- **批量处理**: 可将所有未处理预警标记为已处理

### 8. 实时预警面板
- 主窗口左侧实时显示未处理预警
- 不同类型预警用不同颜色标识
- 点击"查看全部预警"跳转到预警中心

## 校验规则说明

### 1. 过期校验
- **已过期**: 有效期至 < 当前日期 → 红色预警
- **即将过期**: 有效期至 - 当前日期 ≤ 30天 → 橙色预警

### 2. 库存下限校验
- 当前数量 ≤ 最低预警值 → 棕色预警

### 3. 同柜禁配规则
以下类别的试剂不能存放在同一柜位：

| 类别1 | 禁配类别 |
|-------|---------|
| 酸类 | 碱类、还原剂、腐蚀性物质 |
| 碱类 | 酸类、还原剂、腐蚀性物质 |
| 氧化剂 | 还原剂、有机溶剂、易爆物 |
| 还原剂 | 氧化剂、酸类、碱类 |
| 有机溶剂 | 氧化剂、易爆物 |
| 易爆物 | 氧化剂、有机溶剂、酸类 |
| 有毒物质 | 酸类、碱类 |
| 腐蚀性物质 | 酸类、碱类、还原剂 |

### 4. 超期未归还校验
- 领用操作且未归还
- 预计归还日期 < 当前日期 → 深红色预警

## 开发说明

### 技术栈
- **语言**: Python 3

- **数据库**: SQLite
- **架构**: 多层架构（数据层、业务逻辑层、界面层）

### 数据模型
- `Reagent`: 试剂信息
- `Cabinet`: 柜位信息
- `ResponsiblePerson`: 责任人信息
- `UsageRecord`: 领用/归还记录
- `InventoryCheck`: 盘点记录
- `InspectionRecord`: 巡检记录
- `Alert`: 预警信息

### 关键文件说明

#### storage/db_manager.py
- 数据库连接管理
- 所有数据表的 CRUD 操作
- 使用 contextmanager 管理连接
- 自动创建数据表

#### logic/validation_rules.py
- `INCOMPATIBLE_RULES`: 禁配规则字典
- `check_expired()`: 过期校验
- `check_low_stock()`: 库存校验
- `check_incompatible()`: 禁配校验
- `check_overdue_return()`: 超期归还校验
- `validate_all_reagents()`: 全面校验

#### logic/report_generator.py
- `generate_inspection_report()`: 生成 Markdown 报告和 CSV 清单
- `generate_inventory_report()`: 生成盘点报告

#### gui/main_window.py
- 主窗口布局
- 左侧实时预警面板
- 7个功能标签页
- 顶部快捷操作按钮

## 常见问题

### Q: 数据存储在哪里？
A: 数据存储在应用目录下的 `data/chemicals.db` SQLite 文件中。

### Q: 如何备份数据？
A: 直接复制 `data/chemicals.db` 文件即可完成备份。

### Q: 如何重置数据？
A: 删除 `data/chemicals.db` 文件，重启应用会自动创建新数据库并加载示例数据。

### Q: 支持扫码枪吗？
A: 支持。扫码枪通常模拟键盘输入，扫描后会自动输入瓶号并发送回车，触发查询。

### Q: 报告可以用什么软件打开？
A: Markdown 报告可以用任意文本编辑器或 Markdown 阅读器打开；CSV 清单可以用 Excel 或 WPS 打开。
