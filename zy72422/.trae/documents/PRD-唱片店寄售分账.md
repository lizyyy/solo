## 1. 产品概述

唱片店寄售分账系统是为音乐唱片行业设计的分账管理工具，解决分账数据散落在合同截图、曲目别名表、排练变更记录中难以追溯的问题。目标用户包括录音师、版权运营人员和唱片店管理者。

核心价值：建立完整的分账证据链，从合同导入到最终分账，每一步变更都可追溯，避免"结论看着很满，追证据时断在半路"的问题。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 描述 | 核心权限 |
|------|------|----------|
| 录音师（小段） | 负责导入合同、补录曲目别名 | 导入合同截图、编辑曲目别名、查看分账记录 |
| 版权运营 | 负责复核有返工原因的记录 | 复核返工记录、确认最终分账 |
| 管理员 | 系统配置和数据管理 | 全部权限 |

### 2.2 功能模块

1. **分账看板页**：分账记录列表、状态筛选、快速操作
2. **分账详情页**：合同截图预览、轨道信息、曲目别名、排练变更记录、证据链时间线
3. **合同导入页**：上传合同截图、自动解析轨道信息、手动修正
4. **曲目别名表管理**：批量导入别名、别名映射、旧口径补录
5. **复核工作台**：待复核记录列表、返工原因标注、复核操作

## 3. 核心流程

### 3.1 三步核心流程

1. **合同页截图第一次导入**：录音师上传合同截图，系统解析出轨道列表和备注信息
2. **录音师小段补看曲目别名表**：录音师检查曲目别名，补录缺失的旧口径别名
3. **排练变更记录更新**：补录别名后，关联的排练变更记录自动同步更新

### 3.2 特殊处理规则

- 轨道备注中识别出返工原因时，记录自动标记为"待复核"状态，不自动归为正常
- 待复核记录需要版权运营人员手动确认后才能进入正常分账流程
- 所有操作都记录在证据链时间线中，包括操作人、时间、修改内容

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深褐色系（#5D4037），营造唱片店复古专业的氛围
- **辅助色**：金色（#FFD54F）用于强调重要信息，红色（#EF5350）标记返工原因
- **背景**：米白色（#FAFAFA）搭配轻微纸张纹理
- **按钮风格**：圆角矩形，轻微阴影，hover时有上浮效果
- **字体**：标题使用 Noto Serif SC（衬线体，复古感），正文使用 Noto Sans SC
- **布局风格**：卡片式布局，清晰的分区，充足的留白
- **图标风格**：线性图标，简洁专业

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 分账看板 | 顶部导航 | 深色背景，白色文字，金色品牌标识 |
| 分账看板 | 状态标签 | 不同颜色区分状态（绿色正常/黄色待复核/蓝色已完成） |
| 分账看板 | 记录卡片 | 白色卡片，轻微阴影，hover时上浮 |
| 分账详情 | 证据链时间线 | 垂直时间线，不同节点用不同颜色标记 |
| 分账详情 | 合同截图 | 带边框的图片展示，支持点击放大 |
| 分账详情 | 返工标记 | 红色背景标签，醒目但不刺眼 |
| 合同导入 | 上传区域 | 虚线边框，拖拽时有高亮效果 |
| 复核工作台 | 列表 | 表格形式，重要信息加粗突出 |

### 4.3 响应式

- 桌面端优先设计（1280px+）
- 平板端（768px-1279px）：卡片两列布局
- 移动端（<768px）：单列布局，简化操作按钮

### 4.4 动效设计

- 页面加载：卡片依次淡入，有轻微延迟
- 状态变更：平滑过渡动画
- 时间线展开：节点依次出现
- 悬停效果：卡片轻微上浮，阴影加深
