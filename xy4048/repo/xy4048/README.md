# 冷藏药品交接温控追溯台

一个用于医院药房和社区配送员管理冷藏药品配送的本地桌面 GUI 应用。

## 功能概述

### 核心功能
- **三栏式界面**: 左侧维护基础数据、中间任务看板、右侧任务详情
- **温度记录仪CSV导入**: 支持多种编码、分隔符、字段名自动映射
- **多规则数据校验**: 时间倒序、采样间隔缺口、设备号不在配置、箱号与任务不匹配、温度单位混乱、低电量、重复记录、超温
- **任务状态机**: 待装箱 → 运输中 → 待签收 → 需复核 → 已归档
- **超温自动检测**: 连续超温超过阈值自动转为需复核状态
- **附件管理**: SHA256哈希完整性校验、同名不同内容识别、缺失签收照片检查
- **审计包生成**: 包含温度风险评估、处理意见、附件哈希的完整审计记录
- **多种格式导出**: Markdown交接复盘、CSV超温风险清单、JSON审计包

### 界面布局
- **左侧面板**: 冷藏箱维护、药品批号管理、配送路线设置、收货点配置
- **中间面板**: 任务看板（按状态分组：待装箱、运输中、待签收、需复核、已归档）
- **右侧面板**: 温度曲线、装箱清单、签收附件、异常记录、审计日志

## 核心流程验证

### 1. 首次运行与示例数据初始化

1. 启动应用:
   ```bash
   python main.py
   ```

2. 首次运行时，系统会提示是否初始化示例数据，点击"是"即可创建演示数据。

3. 或手动初始化:
   - 点击菜单栏 **工具** → **初始化示例数据**
   - 将创建: 3个冷藏箱、5个药品批号、2条配送路线、4个收货点、3个演示任务

### 2. 创建新任务

1. 在中间任务看板点击 **新增任务** 按钮

2. 填写任务信息:
   - 任务编号（留空自动生成）
   - 选择冷藏箱
   - 选择配送路线（可选）
   - 选择收货点
   - 填写药师、配送员
   - 添加备注

3. 点击 **保存** 完成创建

### 3. 添加装箱清单

1. 在中间面板选中刚创建的任务

2. 点击 **装箱清单** 按钮

3. 在弹出的对话框中点击 **添加**

4. 选择药品批号、填写数量、单位

5. 重复添加多个药品，点击 **关闭** 完成

### 4. 开始运输（状态变更）

1. 在中间面板选择任务

2. 右侧面板顶部会显示可执行的状态按钮

3. 点击 **开始运输** 按钮
   - 系统会检查是否有装箱清单
   - 无装箱清单时会提示错误

4. 成功后任务状态变为 **运输中**

### 5. 导入温度CSV

#### 5.1 正常数据导入

1. 确保有一个处于 **运输中** 状态的任务

2. 点击右侧面板 **导入温度** 按钮

3. 选择 `samples/temperature_normal.csv` 文件

4. 点击 **导入** 完成

5. 右侧面板 **温度曲线** 标签页将显示温度数据

#### 5.2 超温数据导入（触发复核）

1. 确保有一个处于 **运输中** 状态的任务

2. 点击右侧面板 **导入温度** 按钮

3. 选择 `samples/temperature_overtemp.csv` 文件

4. 点击 **导入**

5. 系统会自动检测连续超温（默认3次以上）

6. 任务状态自动变为 **需复核**

7. 右侧面板 **异常记录** 标签页显示超温详情

### 6. 处理复核状态

1. 在中间面板 **需复核** 标签页查看任务

2. 在右侧面板查看异常记录详情

3. 点击 **生成审计包** 按钮进行风险评估

4. 根据评估结果决定下一步操作:
   - 如果是开箱操作等正常超温，可继续流转
   - 如果是设备故障，需要记录处理措施

### 7. 添加签收附件

1. 确保任务处于 **待签收** 或 **需复核** 状态

2. 在右侧面板点击 **添加附件** 按钮

3. 选择任意图片或文档文件

4. 在弹出的对话框中选择附件类型:
   - 签收单（必须有才能签收）
   - 异常照片
   - 其他

5. 系统会:
   - 自动复制文件到 `data/attachments/` 目录
   - 计算 SHA256 哈希值
   - 检查同名不同内容的冲突

6. 附件会显示在 **签收附件** 标签页

### 8. 完成配送与签收

1. 确保任务有:
   - 关联的收货点
   - 至少一个 **签收单** 类型的附件

2. 点击右侧面板 **完成配送** 按钮

3. 任务状态变为 **待签收**（或继续后续流程）

### 9. 生成审计包

1. 在右侧面板点击 **生成审计包** 按钮

2. 系统会:
   - 评估温度风险等级
   - 生成处理意见
   - 计算附件哈希
   - 保存审计包记录

3. 审计包信息显示在右侧底部

### 10. 归档任务

1. 确保任务已:
   - 生成审计包
   - 有签收附件
   - 所有异常已处理

2. 点击右侧面板 **归档** 按钮

3. 系统检查归档条件:
   - 必须有审计包
   - 审计包必须包含风险评估、处理意见、附件哈希

4. 成功后任务状态变为 **已归档**

### 11. 导出功能

#### 11.1 导出Markdown交接复盘报告

1. 选择任意任务

2. 点击右侧面板 **导出** 按钮

3. 选择 **导出Markdown复盘报告**

4. 文件保存到 `data/exports/` 目录

#### 11.2 导出JSON审计包

1. 选择已生成审计包的任务

2. 点击右侧面板 **导出** 按钮

3. 选择 **导出JSON审计包**

4. 文件包含完整任务信息、温度数据、附件哈希、审计日志

#### 11.3 导出CSV超温风险清单

1. 点击菜单栏 **文件** → **导出超温风险清单**

2. 或在右侧面板点击 **导出** → **导出超温风险CSV**

3. CSV文件包含所有超温记录，可用于统计分析

## 数据校验规则

导入温度CSV时，系统会执行以下校验:

| 校验规则 | 说明 | 处理方式 |
|---------|------|---------|
| 时间倒序 | 记录时间晚于下一条记录 | 放入隔离区 |
| 采样间隔缺口 | 间隔超过2小时 | 放入隔离区 |
| 设备号不在配置 | 设备号未在冷藏箱中配置 | 放入隔离区 |
| 箱号与任务不匹配 | 箱号/设备号无对应活跃任务 | 放入隔离区 |
| 温度单位混乱 | 同时存在℃和℉范围的值 | 放入隔离区 |
| 低电量 | 电量低于20% | 警告，不影响导入 |
| 重复记录 | 相同设备+时间+温度 | 放入隔离区 |
| 超温 | 温度超出2-8°C范围 | 警告，记录异常 |

## 状态流转规则

```
┌──────────┐     开始运输      ┌──────────┐
│  待装箱   │ ───────────────> │  运输中   │
└──────────┘                  └────┬─────┘
     ▲                             │
     │                             │ 连续超温
     │                             ▼
     │                       ┌──────────┐
     │                       │  需复核   │
     │                       └────┬─────┘
     │                            │
     │         复核完成           │
     └────────────────────────────┘
                                  │
                                  │ 完成配送
                                  ▼
                            ┌──────────┐
                            │  待签收   │
                            └────┬─────┘
                                 │
                                 │ 归档
                                 ▼
                           ┌──────────┐
                           │  已归档   │
                           └──────────┘
```

### 状态转换条件

| 当前状态 | 目标状态 | 前置条件 |
|---------|---------|---------|
| 待装箱 | 运输中 | 必须有装箱清单 |
| 运输中 | 待签收 | 无强制条件（建议有温度数据） |
| 运输中 | 需复核 | 连续超温超过阈值（自动触发） |
| 待签收 | 需复核 | 发现异常时手动触发 |
| 待签收 | 已归档 | 必须有收货点和签收附件 + 已生成审计包 |
| 需复核 | 运输中/待签收/已归档 | 异常已处理 + 已生成审计包 |
| 已归档 | - | 最终状态，不可逆转 |

## 常见问题

### Q1: 应用无法启动，提示缺少依赖

确保已安装所有依赖:
```bash
pip install -r requirements.txt
```

### Q2: 导入温度CSV时提示"设备号不在配置"

需要先在左侧面板 **冷藏箱** 中配置对应设备号的冷藏箱，且该冷藏箱需关联到某个活跃任务。

### Q3: 无法开始运输，提示"没有装箱清单"

需要先为任务添加装箱清单:
1. 选中任务
2. 点击 **装箱清单** 按钮
3. 添加药品项目

### Q4: 无法归档，提示"必须生成审计包"

归档前必须:
1. 点击右侧面板 **生成审计包** 按钮
2. 确保审计包包含温度风险、处理意见、附件哈希

### Q5: 附件导入失败，提示"同名不同内容"

同一任务中不能存在文件名相同但内容不同的附件。请重命名文件后再导入。
