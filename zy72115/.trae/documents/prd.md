## 1. 产品概述

压缩机振动频谱分析看板——面向实验老师和设备工程师的轻量级振动分析工具，解决交接前后频谱数据靠微信群人工核对、极端值被平均掉后风险不可见的问题。将物理近似计算、单位换算、阈值提醒和分析报告串联在同一流程中，确保每条记录的判据可追溯、可复盘。

- 目标用户：实验室林老师、设备维修工程师
- 核心价值：减少翻旧记录和微信群找证据，换人处理时也能看懂前一次怎么判的

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 实验老师 | 录入/查看数据 | 录入振动数据、查看分析报告、确认异常记录 |
| 设备工程师 | 复盘/审批 | 查看分析报告、确认/驳回异常判定、补充历史口径 |

### 2.2 功能模块

1. **数据录入页**：录入振动频谱数据（频率、幅值、方向、工况信息），支持空值/重复项/边界记录的异常提醒
2. **频谱分析看板页**：频谱图表展示、物理近似计算结果、阈值超限高亮、单位自动换算
3. **分析报告页**：可复盘的图表+明细报告，记录每条判定的来源和依据

### 2.3 页面明细

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据录入页 | 数据表单 | 录入压缩机编号、测点方向、频率(Hz)、幅值(mm/s或μm)、工况参数；数据来源标记(实验表/照片/微信补录) |
| 数据录入页 | 验证提醒 | 方向符号检查、单位自动换算与校验、时间间隔异常检测、空值/重复项提示；提醒信息用人话写，不抛技术术语 |
| 数据录入页 | 数据列表 | 展示已录入记录，标记各条状态(正常/需确认/微信补录) |
| 频谱分析看板 | 频谱图 | 频率-幅值折线图/柱状图，阈值线叠加显示，超限点高亮 |
| 频谱分析看板 | 物理近似面板 | 基频/倍频分量识别，振动速度→位移换算，RMS/峰值换算 |
| 频谱分析看板 | 阈值状态卡片 | 各测点阈值判定结果：正常(绿)/警告(黄)/危险(红)，极端值不被平均掉 |
| 分析报告页 | 报告头部 | 压缩机编号、分析时间、数据来源摘要 |
| 分析报告页 | 图表区 | 频谱图+阈值线缩略版 |
| 分析报告页 | 判定明细表 | 每条记录的判定结果、依据(物理近似/阈值比较)、数据来源、是否人工确认 |
| 分析报告页 | 异常备注区 | 需人工确认的记录和微信补录的旧口径，明确标注，不隐藏 |

## 3. 核心流程

用户打开看板 → 录入/导入振动数据 → 系统自动验证(方向/单位/时间)并提醒 → 物理近似计算+阈值比较 → 生成频谱图表(超限高亮) → 标记异常记录(需确认/微信补录) → 输出可复盘的分析报告

```mermaid
flowchart TD
    "A[录入振动数据]" --> "B[数据验证]"
    "B" --> "C{验证通过?}"
    "C" -->|"是"| "D[物理近似计算]"
    "C" -->|"否"| "E[显示友好提醒]"
    "E" --> "A"
    "D" --> "F[阈值比较]"
    "F" --> "G[生成频谱图表]"
    "G" --> "H[标记异常记录]"
    "H" --> "I[输出分析报告]"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主题**：工业深色主题——深灰底色(#1a1d23)，强调用琥珀色(#f59e0b)和翠绿(#10b981)
- **按钮风格**：圆角微凸，状态色明确(绿/黄/红)
- **字体**：数据区用等宽字体 JetBrains Mono，正文用 Noto Sans SC
- **布局**：左侧导航栏 + 右侧内容区，数据密集区用卡片式布局
- **图表风格**：深色背景下的亮色折线，阈值线用虚线标注

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 数据录入页 | 数据表单 | 深色卡片式表单，输入框带单位标注，验证提醒用行内黄色标签 |
| 数据录入页 | 数据列表 | 紧凑表格，行状态用左侧色条标识(绿/黄/灰) |
| 频谱分析看板 | 频谱图 | 深色背景折线图，阈值线虚线，超限点红色标记 |
| 频谱分析看板 | 阈值状态卡片 | 三色卡片组(绿/黄/红)，显示数值和状态文字 |
| 分析报告页 | 报告整体 | 类A4白底报告区，嵌入深色图表，判定明细用表格 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度1280px
- 图表区自适应宽度
- 移动端暂不优先适配
