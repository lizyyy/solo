## 1. 产品概述

数据库慢查询讲解器——面向DBA与业务团队的慢查询分析协作平台。将原始慢查询日志转化为业务可理解的分析报告，涵盖SQL聚类、索引建议、接口关联、影响排序与报告导出，并在数据不完整时主动标注缺口，而非静默吞掉。

- 核心目标：让业务方不看原始日志也能理解"哪个接口慢、为什么慢、怎么修"
- 差异价值：数据缺口识别 > 强行给出错误结论；报告区分已处理/待确认/需退回补材料

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| DBA | 默认进入 | 上传日志、执行分析、审核索引建议、导出报告 |
| 业务开发 | 通过报告链接 | 查看关联接口、确认/退回记录、补充材料 |

### 2.2 功能模块

1. **日志总览页**：时间窗口选择器、慢查询趋势图、聚类卡片列表、数据质量警告
2. **聚类详情页**：同SQL归并列表、索引分析、接口关联、原始记录展开
3. **报告管理页**：报告列表（已处理/待确认/需退回）、导出、补录与撤回操作

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 日志总览页 | 时间窗口选择器 | 选择分析时间范围，校验窗口是否与数据对齐，错位时高亮警告 |
| 日志总览页 | 慢查询趋势图 | 按分钟/小时/天聚合的扫描行数与执行时间趋势，点击异常点可下钻到原始记录 |

| 聚类详情页 | 同SQL归并列表 | 同一聚类下所有原始记录，标注归并置信度；归并错误时可手动拆分 |

## 3. 核心流程

1. DBA上传慢查询日志（含接口名、表结构、索引信息，允许部分缺失）
2. 系统执行聚类分析，同时检测数据缺口并生成质量警告
3. DBA在聚类详情页审核索引建议与接口关联，可手动修正归并
4. DBA生成报告，记录按数据完整度自动分类：已处理/待确认/需退回
5. 业务方查看报告，对"待确认"记录确认或退回
6. 退回记录由DBA补录后重新提交，系统检测重复提交

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：工业仪表盘——深色底色，高对比度数据呈现，类似数据库监控工具的专业感
- **主色调**：深灰底（#0F1419）+ 青绿强调色（#00D9A6）+ 琥珀警告色（#F5A623）+ 红色异常色（#E74C3C）
- **按钮风格**：小圆角（4px），实心主按钮用青绿色，次按钮用半透明描边
- **字体**：代码区用 JetBrains Mono，正文用 Noto Sans SC，标题用 DM Sans
- **布局**：左侧窄导航 + 主内容区卡片网格，图表优先
- **图标**：线性图标（Lucide风格），不使用emoji

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 日志总览页 | 时间窗口选择器 | 双端滑块+日期输入框，错位时滑块轨道变红色脉冲动画 |
| 日志总览页 | 慢查询趋势图 | 面积图，异常点高亮圆点+脉冲动画，hover显示详情tooltip |
| 日志总览页 | 聚类卡片列表 | 网格卡片，每张卡片顶部色条表示索引状态（绿/黄/红），hover展开摘要 |
| 日志总览页 | 数据质量警告 | 右上角固定警告栏，按严重度排序，可点击跳转到问题详情 |
| 聚类详情页 | 同SQL归并列表 | 表格行，归并置信度用色块标记，低置信度行左侧黄色竖线 |
| 聚类详情页 | 索引分析 | 左右分栏：左侧当前索引状态树，右侧建议索引卡片+执行计划diff |
| 聚类详情页 | 接口关联 | 标签云形式，已关联接口青绿色标签，缺失接口虚线框+红色"+"按钮 |
| 聚类详情页 | 原始记录展开 | 可展开行，展开后显示完整SQL（语法高亮）和所有原始字段 |
| 聚类详情页 | 影响排序 | 水平柱状图，柱宽=加权影响值，悬停显示计算公式 |
| 报告管理页 | 报告列表 | 三栏卡片：已处理/待确认/需退回，每栏顶部计数badge |
| 报告管理页 | 补录操作 | 侧边抽屉滑出补录表单，字段根据缺口类型动态显示 |

| 报告管理页 | 重复提交检测 | 提交时toast提示"检测到重复报告"，显示匹配详情，可合并或另存 |

### 4.3 响应式

- 桌面优先（1280px+），平板（768px-1279px）卡片单列，移动端暂不优化
- 图表在小屏下隐藏次要轴线，保留核心数据

### 4.4 动效

- 页面加载：卡片依次淡入（stagger 50ms）
- 数据质量警告：滑入+脉冲边框
- 聚类展开：高度动画+背景渐变
- 报告状态变更：卡片平滑滑入目标列
- 导出：按钮进度条→完成打勾
