## 1. 产品概述

公交发车间隔优化工具——面向调度主管的一站式决策辅助工具，将历史运行样本、参数配置、人工备注等多源杂乱数据统一清洗、校验、对齐后，基于可追溯的推理链给出发车间隔优化建议，每一条建议都附带"为什么这样建议"的判断过程，而非仅输出最终数字。

- 目标用户：公交调度主管（周姐）及调度室日常操作人员
- 核心价值：让历史样本中的乱材料"对得上"，让优化判断过程"留得住"，让报告和明细"说一不二"

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 调度主管 | 直接使用 | 全部功能：查看/筛选/导出/确认人工审核项 |
| 调度员 | 直接使用 | 查看数据与优化建议、标记备注 |

### 2.2 功能模块

1. **数据总览页**：原始样本表格 + 数据质量仪表盘 + 筛选条件栏
2. **优化判断页**：逐条推理链面板 + 人工确认区 + 历史口径补录

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据总览页 | 样本数据表格 | 展示全部历史样本，含空值/重复/越界标记，支持排序和筛选 |
| 数据总览页 | 数据质量仪表盘 | 汇总空值数、重复项数、越界记录数、单位不一致数、权重未闭合数，每项有可读提醒文案 |
| 数据总览页 | 筛选条件栏 | 按线路/时段/日期范围/数据来源/校验状态筛选，切换条件后表格与导出同源同口径 |
| 优化判断页 | 推理链面板 | 每条记录展开完整判断过程：参数引用→权重计算→阈值比对→结论与建议原因 |
| 优化判断页 | 人工确认区 | 对需确认记录标记"通过/驳回/待定"，备注栏可追加文字，保留操作时间戳 |
| 优化判断页 | 历史口径补录 | 展示从历史样本补来的旧口径记录，标注"旧口径"标签及来源说明 |
| 优化判断页 | 导出区 | 一键导出报告(PDF/CSV)，报告摘要与明细数据同源，口径一致 |

## 3. 核心流程

用户打开工具 → 加载历史样本数据 → 系统自动执行数据清洗校验（空值检测、重复检测、边界检测、单位换算提醒、权重闭合检查）→ 用户在数据总览页查看质量仪表盘和标记问题 → 用户切换筛选条件查看不同子集 → 用户进入优化判断页查看逐条推理链 → 对需确认记录执行人工审核 → 补录历史旧口径 → 导出报告（报告与明细同口径）

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青蓝(#0F4C5C) + 暖橙强调色(#E36414)，传达"严谨调度+高效行动"气质
- 辅助色：浅灰底(#F7F7F7)、中灰边框(#D1D5DB)
- 按钮风格：圆角6px，主按钮实色填充，次要按钮描边
- 字体：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular，数字/数据用 JetBrains Mono
- 布局：左侧固定筛选面板 + 右侧主内容区，卡片式模块布局
- 图标：lucide-react 线性图标风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 数据总览页 | 样本数据表格 | 条纹行、悬浮高亮、问题列彩色徽标(红=空值/黄=越界/灰=重复)、固定表头 |
| 数据总览页 | 质量仪表盘 | 5个指标卡片横排，每卡显示数值+可读提醒文案，超标时卡片边框变红/变黄 |
| 数据总览页 | 筛选条件栏 | 下拉框+日期选择器+复选框组，筛选标签显示当前口径名称 |
| 优化判断页 | 推理链面板 | 时间轴样式，每步一个节点，节点内显示参数名→计算→比对→结论，颜色区分通过(绿)/警告(黄)/驳回(红) |
| 优化判断页 | 人工确认区 | 卡片式布局，左侧行动按钮(通过/驳回/待定)，右侧备注输入框，底部时间戳 |
| 优化判断页 | 历史口径补录 | 带"旧口径"标签的卡片，灰色虚线边框区分，内含来源说明和补录时间 |
| 优化判断页 | 导出区 | 两个按钮并排"导出报告"/"导出明细"，导出前预览口径一致性校验状态 |

### 4.3 响应式

桌面优先设计，最小适配1280px宽度；平板端筛选面板折叠为抽屉；移动端暂不作为主要适配目标。
