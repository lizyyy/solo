# 表格导入前哨站

一个纯本地 Web 前端工具，用于在导入系统前预检 CSV/JSON 数据，统一字段名、日期格式、金额单位，检测各类数据问题。

## 功能特性

### 📥 数据输入
- 支持拖拽上传 CSV/JSON 文件
- 支持直接粘贴数据内容
- 提供多份示例数据供测试

### 📑 模板管理
- 预置「订单导入模板」和「员工信息模板」
- 支持新建、编辑、删除自定义模板
- 字段配置：
  - 字段名称和别名（用于自动映射不同来源的列名）
  - 数据类型：字符串、数字、日期、布尔值、金额
  - 必填/可选标记
  - 唯一键检测
  - 枚举值限制
  - 日期格式指定
  - 金额单位指定

### ⚖️ 跨列校验规则
- 日期顺序检查（如：结束时间不能早于开始时间）
- 金额校验（如：总金额 = 单价 × 数量）
- 自定义公式校验

### 🔍 数据校验
自动检测以下问题：
- ❌ 缺少必填字段
- 🔄 重复唯一键
- ⚠️ 类型错误
- 🚫 枚举越界
- 📅 日期格式歧义
- 💰 金额单位混乱
- ⚡ 跨列规则冲突

### 👁️ 多视图展示
- **原始表格**：查看导入的原始数据
- **标准化预览**：按模板规则标准化后的数据，问题行高亮显示
- **错误分组**：按错误类型分组展示所有问题
- **修复队列**：逐条处理问题，支持手动修改、选择枚举/单位/格式、批量应用/忽略

### 💾 本地持久化
- 模板保存在浏览器 LocalStorage
- 当前草稿自动保存，刷新页面不丢失
- 退出后再次打开可选择恢复草稿

### 📤 导出功能
- `cleaned.csv`：已清洗的有效数据
- `rejects.csv`：问题数据，附带错误信息
- `rules.json`：当前使用的模板和统计信息
- `import-report.md` / `import-report.html`：数据导入报告（Markdown 和 HTML 两种格式）

## 使用方法

### 方式一：直接用浏览器打开
直接双击 `index.html` 或在浏览器中打开该文件即可使用。

### 方式二：使用本地服务器（推荐）
使用 Python 启动本地服务器：
```bash
# Python 3
python3 -m http.server 8080

# 然后在浏览器访问 http://localhost:8080
```

或使用 Node.js：
```bash
npx serve .

# 或使用 http-server
npx http-server -p 8080
```

### 快速开始

1. **选择模板**：顶部下拉选择「订单导入模板」或「员工信息模板」，或创建新模板

2. **导入数据**：
   - 方式1：将 CSV/JSON 文件拖放到上传区域
   - 方式2：点击「选择文件」按钮选择文件
   - 方式3：切换到「粘贴数据」标签，粘贴数据内容后点击「解析数据」
   - 方式4：点击顶部「加载示例数据」按钮选择预设示例

3. **查看校验结果**：
   - 切换不同视图标签查看数据
   - 红色高亮表示有错误的单元格/行
   - 顶部进度条显示校验状态和统计数据

4. **处理问题**：
   - 在「修复队列」视图中逐条处理
   - 可以从下拉选择正确值、手动输入、或选择正确的单位/格式
   - 支持批量勾选后点击「应用选中修复」或「忽略选中」
   - 已修复/忽略的问题会有状态标记

5. **导出结果**：
   - 点击底部相应按钮导出所需文件
   - 建议导出 `cleaned.csv` 用于后续导入系统
   - 导出报告可作为审计或问题追踪用

## 示例数据说明

程序内置了多份示例数据，点击「加载示例数据」按钮即可选择：

### 正常数据
- ✅ 正常订单数据 (CSV/JSON)
- ✅ 正常员工数据

### 问题数据
- ❌ 问题订单数据：包含重复订单号、缺必填字段、日期歧义、金额单位混乱、枚举越界、类型错误等多种问题
- ❌ 问题员工数据：包含重复工号、缺姓名、无效部门、日期格式、金额单位等问题

- 💰 金额单位混乱示例：混合使用元、万元、千元等不同单位的金额数据
- ⚡ 跨列规则冲突示例：包含结束时间早于开始时间、金额与单价数量不符等跨列问题

## 注意事项

1. **数据隐私**：所有数据仅在浏览器本地处理，不会上传到任何服务器
2. **存储限制**：LocalStorage 通常有 5MB 限制，超大文件可能无法保存草稿
3. **日期歧义**：对于 `03/04/2024` 这样的格式，程序会标记为歧义，需要手动确认
4. **金额单位**：如果金额值没有单位后缀（如"万"），程序会标记为单位不明确，需要手动确认
