# 茶叶拼配批次试算器

一个用于茶厂拼配不同等级毛茶时，平衡香气评分、成本和库存约束的智能决策系统。

## 项目简介

本系统帮助茶叶生产企业在进行茶叶拼配时，科学地平衡以下三个关键因素：

1. **香气评分**：确保成品茶的香气品质达到预期标准
2. **成本控制**：在保证品质的前提下尽量降低成本
3. **库存约束**：根据实际库存量制定可行的生产方案

## 核心功能

### 1. 原料库存管理
- 查看所有原料的等级、香气评分、单价和库存量
- 支持动态添加新原料
- 实时库存状态展示

### 2. 手动拼配试算
- 自定义批次参数（名称、重量、目标评分、成本上限）
- 设置各原料的拼配比例
- 实时计算并显示可行性判断

### 3. 智能方案优化
- 根据目标参数自动生成多种可行方案
- 按成本从低到高排序推荐
- 展示不可行方案及问题原因

### 4. 方案比较
- 保存多个候选方案
- 对比不同方案的关键指标
- 系统给出推荐建议

### 5. 报告导出
- 导出完整的拼配方案报告
- 包含关键假设和免责声明

## 快速开始

### 环境要求
- Python 3.8+
- pip

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python run.py
```

服务启动后，访问：`http://localhost:5000`

**端口冲突处理（macOS 常见问题）：**
- macOS 上端口 5000 可能被 AirPlay Receiver 占用
- 如需使用其他端口，可通过环境变量指定：
```bash
PORT=5001 python run.py
```
- 默认关闭 debug 模式（避免临时目录权限问题），如需开启：
```bash
FLASK_DEBUG=True PORT=5001 python run.py
```

## 主流程演示

### 场景：生产一批 100kg 的成品茶，要求香气评分 ≥ 85分，平均单价 ≤ 400元/kg

#### 步骤 1：手动拼配试算
1. 打开「拼配试算」标签页
2. 设置批次参数：
   - 批次名称：`精品批次001`
   - 目标重量：`100` kg
   - 目标香气评分：`85`
   - 最高单价：`400` 元/kg
3. 添加原料组合：
   - 雨前龙井（M002）：70%
   - 二级龙井（M003）：30%
4. 点击「计算拼配方案」

**预期结果：**
- 平均香气评分：85.6 分（达标）
- 平均单价：378 元/kg（达标）
- 方案判定：✅ 可行

#### 步骤 2：使用智能优化
1. 打开「方案优化」标签页
2. 设置优化参数：
   - 目标重量：`100` kg
   - 目标香气评分：`85`
   - 最高单价：`400` 元/kg
3. 点击「生成优化方案」

**预期结果：**
- 系统自动生成多个可行方案和不可行方案
- 可行方案按成本从低到高排序显示
- 每个可行方案显示：达标原因、原料配比、具体指标
- 不可行方案显示具体违反的约束条件（如香气不足、成本超标、库存不足等）
- 用户可明确知道每个方案为什么可行或不可行

#### 步骤 3：方案比较与导出
1. 在优化结果中选择 2-3 个方案，点击「保存此方案」
2. 打开「已存方案」标签页
3. 勾选多个方案，点击「比较选中方案」
4. 查看对比结果和系统推荐
5. 点击「导出报告」下载详细报告

## 异常操作演示

### 异常 1：拼配比例不等于 100%
**操作：** 设置原料比例合计为 90%
**预期结果：** 
- 页面提示："拼配比例合计应为100%"
- 无法进行计算

### 异常 2：库存不足
**操作：** 选择明前龙井（库存50kg），设置100%比例，目标重量 100kg
**预期结果：**
- 系统判定：❌ 方案不可行
- 详细原因："原料 明前龙井 (特级) 库存不足：需要 100.00kg，实际库存 50.00kg"

### 异常 3：香气评分不达标
**操作：** 选择三级龙井（评分72分），设置100%比例，目标香气评分 85分
**预期结果：**
- 系统判定：❌ 方案不可行
- 详细原因："平均香气评分不足：目标 85 分，实际 72.00 分"

### 异常 4：成本超标
**操作：** 选择明前龙井（单价680元/kg），设置100%比例，最高单价 500元/kg
**预期结果：**
- 系统判定：❌ 方案不可行
- 详细原因："平均成本超标：目标 500.00 元/kg，实际 680.00 元/kg"

### 异常 5：参数缺失
**操作：** 调用 API 时缺少必填字段
**预期结果：**
- API 返回 400 状态码
- 错误信息："缺少必填字段: xxx"

## 关键假设说明

### 评分计算假设
- **加权平均法**：平均香气评分 = Σ(原料评分 × 拼配比例)
- 例如：特级茶(95分)占60% + 一级茶(88分)占40% = 92.2分
- 评分为0-100分，越高表示香气越好

### 成本计算假设
- **直接成本**：仅计算原料采购成本
- **不含加工费**：人工、能耗、包装等费用需另行计算
- 总成本 = Σ(原料单价 × 使用量)

### 库存约束
- **实时库存**：基于当前显示的库存量
- **使用量检查**：各原料使用量不能超过库存
- 使用量 = 目标重量 × 拼配比例

### 可行性判定标准
必须同时满足以下所有条件：
- ✅ 平均香气评分 ≥ 目标香气评分
- ✅ 平均单价 ≤ 最高单价限制
- ✅ 所有原料使用量 ≤ 库存量
- ✅ 拼配比例合计 = 100%

### 茶叶等级说明

| 等级 | 典型香气评分范围 | 说明 |
|------|------------------|------|
| 特级 | 90-100分 | 顶级原料，香气浓郁持久 |
| 一级 | 85-90分 | 优质原料，香气明显 |
| 二级 | 75-85分 | 中等原料，香气一般 |
| 三级 | 70-75分 | 基础原料，香气较淡 |

## API 接口

### 健康检查
```bash
GET /api/health
```

### 获取库存
```bash
GET /api/inventory
```

### 添加原料
```bash
POST /api/materials
Content-Type: application/json

{
    "id": "M007",
    "name": "高级铁观音",
    "grade": "特级",
    "aroma_score": 93.0,
    "cost_per_kg": 550.0,
    "stock_kg": 40.0,
    "description": "可选描述"
}
```

### 计算拼配方案
```bash
POST /api/calculate
Content-Type: application/json

{
    "batch_name": "测试批次",
    "target_weight_kg": 100.0,
    "target_aroma_score": 85.0,
    "max_cost_per_kg": 400.0,
    "components": [
        {"material_id": "M002", "proportion": 70},
        {"material_id": "M003", "proportion": 30}
    ]
}
```

### 生成优化方案
```bash
POST /api/optimize
Content-Type: application/json

{
    "target_weight_kg": 100.0,
    "target_aroma_score": 85.0,
    "max_cost_per_kg": 400.0
}
```

### 保存方案
```bash
POST /api/plans/save
Content-Type: application/json

{...方案详细数据...}
```

### 方案比较
```bash
POST /api/plans/compare
```

### 导出报告
```bash
POST /api/export
```

## 注意事项

1. **数据持久化**：当前版本使用内存存储，重启服务后数据会重置
2. **精度问题**：所有计算保留两位小数，可能存在微小精度差异
3. **假设限制**：请仔细阅读「关键假设说明」，了解计算的局限性
4. **生产建议**：建议在小批量试生产验证后再进行大规模生产
