# 投诉工单包投诉升级整理 CLI

用于整理投诉升级处理材料的命令行工具。

## 安装

```bash
pip install -e .
```

## 使用方法

```bash
投诉工单包投诉升级整理 --input <输入路径> --rules <规则文件> --output <输出目录> [--dry-run] [--overwrite]
```

### 参数说明

- `--input`, `-i`: 投诉工单文件路径（Excel）
- `--rules`, `-r`: 规则配置文件路径（JSON）
- `--output`, `-o`: 输出目录路径
- `--dry-run`, `-d`: 试运行模式，不生成实际文件
- `--overwrite`, `-w`: 覆盖已存在的输出文件

## 功能特点

- 自动识别并单独列出追加证据情况
- 自动识别并单独列出司机申诉情况
- 自动识别并单独列出客服改判情况
- 生成结构化的升级处理材料报告
