# 室内攀岩馆线路定线复盘器

一个本地桌面工具，帮助定线员管理攀岩线路、检测风险、生成复盘报告。

## 功能特性

### 📥 数据导入
- **墙面分区 JSON**: 导入攀岩墙的区域划分，包含位置、大小和难度范围
- **线路数据 CSV**: 导入每条线路的名称、颜色、难度、抓点位置等信息
- **抓点磨损记录 CSV**: 导入抓点使用次数、磨损等级等维护数据
- **会员反馈 CSV**: 导入会员对线路的难度评分、满意度和问题反馈

### 🧗 线路管理
- 查看、筛选所有线路（按区域、难度、儿童线路）
- 新增、编辑、删除线路
- 支持儿童线路特殊标记

### 🗺️ 墙面可视化
- Canvas 绘制墙面区域分布图
- 显示线路路径和抓点位置
- 风险区域高亮标记
- 可切换显示/隐藏线路、风险、抓点

### ⚠️ 风险检测
- **难度断层检测**: 检测同一区域内难度跨度是否超过阈值（默认3级）
- **抓点过期检测**: 根据使用次数检测抓点是否需要更换（80%预警、90%建议更换、95%立即更换）
- **儿童线路冲突检测**: 检测儿童线路之间的抓点是否过于接近

### 📝 复核意见
- 记录定线员的复核意见
- 支持从未解决风险直接创建复核
- 标记已处理/待处理状态
- 按优先级排序显示

### 📤 数据导出
- **Markdown 复盘报告**: 完整的复盘报告，包含风险分析、区域统计、抓点状态、会员反馈
- **CSV 维护清单**: 需要关注或更换的抓点清单，包含风险等级和建议行动
- **JSON 审计包**: 包含所有数据和统计信息的完整数据包，用于审计或备份

## 快速开始

### 环境要求
- Node.js 16+
- npm 或 yarn

### 安装步骤

1. **安装依赖**
```bash
npm install
```

2. **编译 TypeScript**
```bash
npm run build
```

3. **运行应用**
```bash
npm start
```

### 开发模式（自动编译+运行）
```bash
npm run dev
```

## 完整验证流程

### 第一步：准备数据

项目提供了示例数据文件，位于 `examples/` 目录：

| 文件 | 格式 | 说明 |
|------|------|------|
| `wall-zones.json` | JSON | 4个墙面区域（初学者区、进阶区、高级区、儿童区） |
| `routes.csv` | CSV | 9条线路（含3条儿童线路） |
| `wear-records.csv` | CSV | 10条抓点磨损记录 |
| `feedback.csv` | CSV | 8条会员反馈 |

### 第二步：导入数据

1. 启动应用后，点击顶部导航的 **📥 数据导入** 标签
2. 按以下顺序导入数据（建议顺序，非强制）：

   **a. 导入墙面分区 JSON**
   - 点击「墙面分区 JSON」卡片中的「选择 JSON 文件」
   - 选择 `examples/wall-zones.json`
   - 应显示："成功导入 4 个墙面区域"

   **b. 导入线路数据 CSV**
   - 点击「线路数据 CSV」卡片中的「选择 CSV 文件」
   - 选择 `examples/routes.csv`
   - 应显示："成功导入 9 条线路"

   **c. 导入抓点磨损记录 CSV**
   - 点击「抓点磨损记录 CSV」卡片中的「选择 CSV 文件」
   - 选择 `examples/wear-records.csv`
   - 应显示："成功导入 10 条磨损记录"

   **d. 导入会员反馈 CSV**
   - 点击「会员反馈 CSV」卡片中的「选择 CSV 文件」
   - 选择 `examples/feedback.csv`
   - 应显示："成功导入 8 条会员反馈"

### 第三步：查看数据概览

点击 **📊 概览** 标签，应看到：

- **统计卡片**：
  - 墙面区域：4
  - 线路总数：9
  - 抓点总数：10（从磨损记录自动创建）
  - 会员反馈：8
  - 待处理风险：若干（具体数量取决于数据）
  - 待复核：0

- **最近风险概览**：显示检测到的风险列表
- **线路难度分布**：柱状图显示各难度的线路数量

### 第四步：风险检测验证

点击 **⚠️ 风险检测** 标签，或点击顶部的「⚠️ 检测风险」按钮。

根据示例数据，应该检测到以下风险：

#### 1. 难度断层风险
- **初学者区 (ZONE_A)**：区域设计难度 1-6，但实际只有难度 2、3、5
  - 难度 3 和 5 之间存在 2 级断层
  - 缺少难度 4 的线路

#### 2. 抓点过期风险
- **H001**: 使用 950/1000 次 (95%) - 严重，立即更换
- **H005**: 使用 980/1000 次 (98%) - 严重，立即更换
- **H009**: 使用 920/1000 次 (92%) - 高，近期更换
- **H002**: 使用 880/1000 次 (88%) - 中，纳入计划
- **H006**: 使用 850/1000 次 (85%) - 中，纳入计划
- **H008**: 使用 750/1000 次 (75%) - 正常（低于80%阈值）

#### 3. 儿童线路冲突风险
- **儿童线1 (K001)** 和 **儿童线3 (K003)**：抓点位置接近
  - 可能导致儿童攀爬时互相干扰

点击任意风险项，可查看详情并创建复核意见。

### 第五步：墙面视图验证

点击 **🗺️ 墙面视图** 标签：

1. **区域显示**：
   - 初学者区 (ZONE_A)：左上角绿色区域
   - 进阶区 (ZONE_B)：中间区域
   - 高级区 (ZONE_C)：右上角区域
   - 儿童区 (ZONE_KIDS)：底部区域

2. **线路显示**：
   - 每条线路以其颜色显示路径
   - 儿童线路使用虚线显示
   - 起点标记为绿色 "S"，终点标记为红色 "E"

3. **风险显示**：
   - 有难度断层的区域会显示为红色/橙色背景
   - 过期抓点会显示红色虚线警告圈

4. **切换选项**：
   - 勾选/取消勾选「显示线路」、「显示风险」、「显示抓点」观察变化

### 第六步：线路管理验证

点击 **🧗 线路管理** 标签：

1. **筛选功能**：
   - 区域筛选：选择 "ZONE_A"，应只显示初学者区的线路
   - 难度筛选：选择 "2"，应只显示难度为 2 的线路
   - 仅显示儿童线路：勾选后应只显示 3 条儿童线路

2. **编辑线路**：
   - 点击任意线路的「编辑」按钮
   - 修改线路名称或颜色
   - 点击「保存」，应显示保存成功通知

3. **新增线路**：
   - 点击「➕ 新增线路」
   - 填写测试数据：
     - 名称：测试线
     - 代码：TEST001
     - 颜色：任意
     - 难度：4
     - 区域：选择 ZONE_A
     - 抓点位置：`[{"x": 180, "y": 450}, {"x": 200, "y": 380}]`
   - 点击「保存」
   - 返回概览，线路总数应变为 10

### 第七步：复核意见验证

1. **从风险创建复核**：
   - 回到 **⚠️ 风险检测** 标签
   - 点击任意风险项查看详情
   - 点击「创建复核意见」
   - 填写：
     - 复核人：你的名字
     - 发现的问题：（自动填充风险描述）
     - 建议措施：（自动填充建议）
   - 点击「保存」

2. **查看复核**：
   - 点击 **📝 复核意见** 标签
   - 「待处理」列表应显示刚才创建的复核
   - 点击「标记已处理」，复核会移到「已处理」列表

### 第八步：导出功能验证

点击 **📤 导出数据** 标签，测试三种导出：

#### 1. 导出 Markdown 复盘报告
- 点击「导出 Markdown」
- 选择保存位置
- 打开保存的 `.md` 文件，应包含：

#### 2. 导出 CSV 维护清单

  - 风险等级、建议行动
  - 只包含使用比例 >= 80% 的抓点

#### 3. 导出 JSON 审计包
- 点击「导出 JSON」

- 打开保存的 `.json` 文件，应包含：
  - 版本信息、生成时间
  - 数据摘要统计
  - 完整的区域、线路、抓点数据
  - 会员反馈、复核意见

  - 附加统计信息

## 配置参数

风险检测阈值可在代码中调整（位于 `src/services/risk-detection.ts`）：

```typescript
// 难度断层阈值（超过此值会触发警告）
private readonly DIFFICULTY_GAP_THRESHOLD = 3;

// 抓点使用预警比例
private readonly USE_COUNT_WARNING_RATIO = 0.8;  // 80%

// 抓点使用危险比例
private readonly USE_COUNT_DANGER_RATIO = 0.95;  // 95%

// 儿童线路点位冲突检测距离阈值
private readonly POSITION_OVERLAP_THRESHOLD = 20;
```

## 常见问题

### Q: 导入数据后没有显示？
A: 检查以下几点：
- 确保文件格式正确（参考示例数据）
- 检查 CSV 文件的编码（建议 UTF-8）
- 查看开发者工具控制台是否有错误信息

### Q: 风险检测没有找到问题？
A: 可能是数据中没有达到阈值的情况：
- 难度断层：需要区域内难度跨度 >= 3 级
- 抓点过期：需要使用次数 >= 80% 的最大次数
- 儿童冲突：需要至少 2 条儿童线路且点位接近

### Q: 如何重置所有数据？
A: 删除数据库文件：
1. 关闭应用
2. 找到数据库位置（见上文）
3. 删除 `climbing-reviewer.db` 文件
4. 重新启动应用
