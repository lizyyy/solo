# 📚 图书馆排架修复游戏

一个帮助图书馆志愿者学习索书号排序和错架处理的教育类浏览器游戏。

## 🚀 快速启动

### 方法一：直接打开
双击 `index.html` 文件在浏览器中打开即可。

### 方法二：本地服务器（推荐）
```bash
# 使用 Python
python3 -m http.server 8000

# 或使用 Node.js
npx serve .

# 或使用 PHP
php -S localhost:8000
```

然后在浏览器中访问 `http://localhost:8000`

## 🎮 游戏玩法

### 基本操作
1. **选择关卡**：在开始界面选择想要挑战的关卡
2. **拖拽图书**：从左侧「待上架图书」区域拖拽图书到中间排序区
3. **调整顺序**：在排序区内可以继续拖拽调整图书位置
4. **处理特殊图书**：
   - 预约图书：双击图书进行预约处理
   - 破损图书：双击图书进行破损登记
5. **确认上架**：排序完成后点击「确认上架」按钮

### 索书号排序规则
图书馆索书号按以下优先级排序：

1. **分类号字母**：按字母表顺序 A-Z
   - 例：A01 < B05 < C03

2. **分类号数字**：按数值大小排序
   - 例：A01 < A10 < A100
   - 例：A20 < A20.5 < A21

3. **著者号**：分类号相同时，按著者号排序
   - 例：D23.F45 < D23.G67

## ⚠️ 边界案例与常见错误

### 1. 数字排序误区
**错误**：认为 A100 < A20（按字符串比较）
**正确**：A20 < A100（按数值比较）

### 2. 小数排序
**注意**：A20.5 应该排在 A20 之后，A21 之前
- 正确顺序：A20 → A20.5 → A21

### 3. 预约图书处理
**错误**：将预约图书直接上架
**正确**：双击图书进行预约处理后，图书会被移出待上架列表

### 4. 破损图书处理
**错误**：将破损图书直接上架
**正确**：双击图书进行破损登记后，图书会被移出待上架列表

### 5. 混合图书处理
当同时存在预约和破损图书时：
1. 先筛选出所有需要特殊处理的图书
2. 对预约图书双击处理
3. 对破损图书双击登记
4. 剩余图书按索书号排序上架

### 6. 著者号排序
分类号完全相同时，按著者号字母顺序排序：
- D23.F45 (F开头) < D23.G67 (G开头)

## 💡 学习建议

1. **循序渐进**：从第1关开始，逐步熟悉排序规则
