🎯 基本玩法

从待上架区拖拽图书到排序区，按索书号从小到大排列后确认上架

📐 索书号排序规则

  • 分类号：按字母顺序(A-Z)，如 A < B < C
  • 数字部分：按数值大小，如 A10 < A20 < A100
  • 著者号：分类号相同时按著者号排序

📋 预约单处理

带有预约标记的图书需要先放到预约台，不能直接上架

🔧 破损图书

破损图书需要先登记，不能直接上架

  • 预约书误上架：-100分
