Python 编程课程讲义

第一章：Python 简介
Python 是一种高级编程语言，由 Guido van Rossum 在 1991 年创建。
它的设计哲学强调代码的可读性，使用了显著的空白缩进。

第二章：人工智能与 Python
Python 是人工智能（AI）领域最流行的编程语言之一。
许多人工智能框架如 TensorFlow、PyTorch 都使用 Python 作为主要接口。
机器学习（Machine Learning）和深度学习（Deep Learning）是人工智能的重要分支。

第三章：用户界面设计
用户登录系统时需要提供账号和密码。
系统设计必须考虑安全性和用户体验。
