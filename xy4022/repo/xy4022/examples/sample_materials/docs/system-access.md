# 系统访问指南

## 概述

本文档介绍新员工如何获取各个系统的访问权限。

## 企业邮箱

### 激活流程

1. 访问公司邮箱门户网站
2. 使用临时密码登录
3. 按提示修改密码

### 注意事项

- 密码需要包含大小写字母、数字和特殊字符
- 密码有效期为90天

## VPN访问

### 客户端安装

1. 从IT部门获取VPN客户端
2. 安装并重启电脑
3. 使用AD账号登录

### 连接步骤

1. 打开VPN客户端
2. 选择"公司网络"配置文件
3. 输入凭据并连接
