我想做一个给公司内训负责人用的本地命令行工具，叫“资料包交付巡检器”。每次把一堆 Markdown SOP、图片附件、PDF 模板打包给新员工前，靠人工一个个点链接很容易漏掉失效附件、路径大小写问题和多余大文件。请从 0 到 1 做一个可直接运行的 Python CLI 项目：init 命令能创建项目配置和忽略规则；scan 命令读取一个资料根目录，解析所有 Markdown 里的相对链接、图片引用和标题锚点，检查缺失文件、大小写不一致、引用跳出根目录、同名附件冲突、未被任何文档引用的大文件、标题层级跳跃这些问题；pack 命令把通过检查的资料复制到 dist 目录，生成 manifest.json，记录文件路径、sha256、大小和引用来源；report 命令能导出 Markdown 和 CSV 两种巡检报告；cache 机制要能跳过未变化文件，但配置或忽略规则变化后必须重新扫描。希望核心代码拆成 CLI 入口、Markdown 解析、规则校验、缓存/manifest、打包器、报告导出和示例数据/测试，不要做成单文件演示。README 写清楚安装方式、示例命令，以及如何用临时资料目录验证 init、scan、pack、report 的完整流程。
