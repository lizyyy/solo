## 1. 产品概述

艺术品修复记录API——为博物馆修复师提供从作品建档、修复步骤录入、材料批次追踪、照片版本管理、签名留痕到报告导出的全流程记录平台。核心解决三个问题：修复过程证据链不完整、异常发现后无修正追溯机制、最终确认环节缺乏签名留痕。目标用户为博物馆修复师及馆方管理层。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 修复师 | 管理员分配账号 | 创建/编辑修复记录、上传照片、录入材料批次、提交签名 |
| 馆方审核员 | 管理员分配账号 | 审核修复记录、确认修正、签批报告导出 |
| 管理员 | 系统内置 | 用户管理、规则配置、全局数据查看 |

### 2.2 功能模块

1. **作品档案页**：作品信息录入与查看、关联修复记录列表、状态筛选
2. **修复步骤页**：步骤录入（清洁/补色/加固等）、顺序校验、异常标记、修正记录
3. **材料批次页**：批号录入与校验、材料与步骤关联、异常追踪
4. **照片管理页**：上传/版本控制、缺失检测、与步骤/材料关联
5. **签名与确认页**：修复师签名、馆方审核确认、三段式追溯链（发现→修正→确认）
6. **报告导出页**：按作品/时间段生成报告、异常清单嵌入、签名页附入

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 作品档案 | 作品信息卡片 | 展示作品名称、年代、材质、尺寸、入馆编号、当前修复状态 |
| 作品档案 | 修复记录列表 | 关联该作品的所有修复记录，支持按状态/日期/修复师筛选 |
| 修复步骤 | 步骤时间线 | 按时间顺序展示修复步骤，异常步骤红色标记，支持拖拽排序 |
| 修复步骤 | 异常检测引擎 | 自动检测步骤顺序倒置、材料批号缺失、照片缺失并生成异常清单 |
| 修复步骤 | 修正面板 | 对异常进行修正，记录修正原因、修正人、修正时间，形成修正链 |
| 材料批次 | 批号登记 | 录入材料名称、批号、供应商、有效期，校验批号格式 |
| 材料批次 | 追踪关联 | 材料与使用步骤的关联映射，支持反查某批材料用在了哪些步骤 |
| 照片管理 | 上传与版本 | 支持上传多张照片，自动版本编号，标记修复前/中/后 |
| 照片管理 | 缺失检测 | 自动检查每个步骤是否已关联照片，缺失时在异常清单中标记 |
| 签名确认 | 修复师签名 | 修复完成后修复师手写/电子签名，锁定步骤不可再修改 |
| 签名确认 | 馆方审核 | 审核员查看修正记录，确认后签名，完成确认闭环 |
| 签名确认 | 三段追溯链 | 展示"异常发现→修正操作→确认签批"完整链路 |
| 报告导出 | 报告生成 | 选择作品/时间段，生成含异常清单、修正记录、签名页的完整PDF |
| 报告导出 | 异常嵌入 | 报告中单独章节列出所有异常：照片缺失、批号错误、步骤倒置 |
| 报告导出 | 规则说明附录 | 附录中包含修复状态、材料追踪、照片版本等规则的解释文本 |

## 3. 核心流程

修复师创建作品档案 → 录入修复步骤 → 关联材料批次与照片 → 系统自动检测异常 → 修复师修正异常 → 修复师签名提交 → 馆方审核确认签名 → 导出完整报告（含异常清单与签名页）

```mermaid
flowchart TD
    "创建作品档案" --> "录入修复步骤"
    "录入修复步骤" --> "关联材料批次"
    "关联材料批次" --> "上传修复照片"
    "上传修复照片" --> "系统异常检测"
    "系统异常检测" --> "存在异常?"
    "存在异常?" --> "是：标记异常并修正" --> "修正记录留痕"
    "存在异常?" --> "否：直接签名" 
    "修正记录留痕" --> "修复师签名"
    "否：直接签名" --> "修复师签名"
    "修复师签名" --> "馆方审核确认"
    "馆方审核确认" --> "导出报告（含异常与签名）"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：暖棕 (#8B6914) 搭配象牙白底 (#FAF8F0)，传达文物修复的沉稳与专业
- 辅助色：琥珀色 (#D4A843) 用于强调，暗红 (#8B2500) 用于异常标记
- 按钮风格：圆角矩形，微阴影，hover 时微微上浮
- 字体：衬线体用于标题（如 Noto Serif SC），无衬线体用于正文（Noto Sans SC）
- 布局风格：左侧导航 + 右侧内容区，卡片式布局，时间线组件贯穿修复步骤
- 图标风格：线性图标，线宽一致，古典工具意象（画笔、放大镜、印章）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 作品档案 | 作品信息卡片 | 卡片布局、衬线标题、状态徽章（颜色区分）、信息网格 |
| 作品档案 | 修复记录列表 | 表格布局、状态筛选栏、行内状态标签、操作按钮组 |
| 修复步骤 | 步骤时间线 | 垂直时间线、异常节点红点标记、展开/收起详情、拖拽手柄 |
| 修复步骤 | 异常检测引擎 | 右侧滑出面板、异常列表、严重程度标签、快捷修正入口 |
| 修复步骤 | 修正面板 | 模态弹窗、修正原因文本框、修正前后对比、提交按钮 |
| 材料批次 | 批号登记 | 表单布局、批号格式校验提示、有效期日历选择器 |
| 材料批次 | 追踪关联 | 关联图/表格、材料→步骤箭头、反查跳转链接 |
| 照片管理 | 上传与版本 | 网格缩略图、拖拽上传区、版本号标签、修复阶段标记 |
| 照片管理 | 缺失检测 | 缺失照片步骤高亮、警告横幅、快捷上传入口 |
| 签名确认 | 修复师签名 | 签名画布（Canvas）、清除/确认按钮、签名时间戳 |
| 签名确认 | 馆方审核 | 审核面板、修正记录摘要、确认/退回按钮 |
| 签名确认 | 三段追溯链 | 横向三段式卡片、发现→修正→确认箭头连接、每段附操作人与时间 |
| 报告导出 | 报告生成 | 选择器（作品/时间）、预览区域、导出按钮 |
| 报告导出 | 异常嵌入 | 报告内独立章节、异常类型分组、异常详情表格 |
| 报告导出 | 规则说明附录 | 可折叠的规则说明区块、规则编号、规则解释文本 |

### 4.3 响应式

桌面优先设计，平板与手机端采用抽屉式导航，表格转为卡片列表，签名画布自适应宽度。
