# 🏃 跑步训练复盘工具

一个本地 Web 应用，帮助你复盘跑步训练数据，识别训练风险（如突然加量、连续高强度、休息不足、带伤跑步等），规划未来训练，并生成结构化复盘报告。

---

## ✨ 主要功能

### 📊 核心看板
- **周度统计**：按周查看跑量、时长、训练负荷、单次最长距离
- **滚动负荷曲线**：7天/28天滚动训练负荷 + ACWR（急性慢性工作负荷比）
- **强度分布**：按训练负荷/次数统计轻松跑、节奏跑、阈值跑、间歇跑、比赛的占比
- **区间分析**：配速区间和心率区间统计

### ⚠️ 风险识别（真实计算驱动）
| 风险类型 | 检测规则 |
|---------|---------|
| **突然加量** | 周跑量较前一周增加 >30% |
| **连续高强度** | 连续3天及以上安排阈值/间歇/比赛强度 |
| **休息不足** | 一周训练>=5次且休息<2天 |
| **带伤跑步** | 记录中包含伤痛位置标记 |
| **负荷突增** | ACWR > 1.3（警告）/ > 1.5（危险）|
| **计划超量** | 未来计划执行后预计 ACWR 超标 |
| **计划休息冲突** | 连续高强度训练计划间隔不足2天 |

### 📥 数据导入
- 支持 **佳明 Garmin**、**Keep**、**手动格式** CSV 导入
- 自动检测来源和字段映射
- 可手动调整字段映射
- 详细的错误提示和数据预览

### ✏️ 训练记录编辑
- 补充/修改 **主观疲劳度 (RPE)**
- 标记 **伤痛位置** 和 **疼痛程度**
- 添加/编辑 **标签** 和 **备注**
- 删除记录

### 📅 训练计划
- 规划未来两周训练
- 指定距离、时长、强度、描述
- 与历史负荷对比，预测 **ACWR 变化**
- 警告可能的超量风险

### 💾 数据持久化
- **导出项目 JSON**：备份所有记录、计划、标签定义
- **导入项目 JSON**：从备份恢复
- 内置示例数据便于快速体验

### 📄 复盘报告生成
- 生成 **Markdown** 和 **HTML** 格式报告
- 包含关键指标总览、近期周度趋势
- 风险分析与解释
- 基于数据的个性化训练建议

## 🚀 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动应用

```bash
streamlit run app.py
```

浏览器会自动打开应用（默认 http://localhost:8501）。

### 3. 首次使用

应用启动后会自动加载 **示例数据**，包含：
- 约 8 周的训练记录
- 故意设计的风险场景（突然加量、连续高强度、左膝伤痛等）
- 未来两周的训练计划

你可以：
1. 直接在看板上查看风险提示和统计
2. 点击侧边栏 `📥 导入数据` 上传你自己的 CSV
3. 点击侧边栏 `📄 复盘报告` 生成报告

## 📐 核心算法说明

### ACWR (急性慢性工作负荷比)
- **急性负荷 (7天)**：最近7天的训练负荷总和
- **慢性负荷 (28天基线)**：过去4周的周均训练负荷
- **ACWR** = 急性负荷 / 慢性负荷

**解读**：
- 0.8 - 1.3：✅ 安全范围，稳步提升
- 1.3 - 1.5：⚠️ 偏高，注意恢复
- > 1.5：🔴 危险，受伤风险大幅增加

### 训练负荷计算
```
训练负荷 = 距离(km) × 时长(小时) × 强度系数 × RPE系数
```

强度系数：
- 轻松跑：1.0
- 节奏跑：1.4
- 阈值跑：2.0
- 间歇跑：2.8
- 比赛：3.2

### 强度推断
按优先级：
1. 平均心率（>175=比赛, 165-175=间歇, 155-165=阈值, 145-155=节奏, <145=轻松）
2. 配速（<3:30=比赛, 3:30-4:00=间歇, 4:00-4:30=阈值, 4:30-5:30=节奏, >5:30=轻松）
3. RPE（>=9=比赛, 8=间歇, 7=阈值, 5-6=节奏, <5=轻松）

## 💡 使用建议

1. **首次使用**：先用示例数据熟悉界面和风险规则
2. **导入数据**：导出 Garmin/Keep 的 CSV 后上传，检查字段映射是否正确
3. **补充信息**：在「训练记录」中为每次跑步补充 RPE 和伤痛信息，让风险检测更准确
4. **定期复盘**：每周生成一份复盘报告，跟踪 ACWR 趋势
5. **关注伤痛**：如果某部位多次标记疼痛，建议完全休息直到恢复
