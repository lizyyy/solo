# 农田喷灌覆盖模拟系统

一个基于 WebGL 的交互式农田喷灌覆盖可视化模拟工具，帮助农技员向农户直观演示喷灌系统的覆盖效果。

## 功能特性

- 🌾 **3D 可视化场景** - Three.js 渲染的真实农田场景，支持坡度模拟
- 💧 **喷头管理** - 支持添加、删除、拖拽调整喷头位置
- 🎯 **覆盖热力图** - 实时计算并显示喷灌覆盖范围
- ⚠️ **漏浇区域识别** - 自动标记边角漏浇、间隙漏浇区域
- 🌬️ **环境参数调节** - 坡度、风向、风速、水压实时调节
- 📊 **覆盖分析报告** - 覆盖率统计、漏浇分析、PDF/JSON 导出
- 💾 **状态持久化** - 刷新页面后配置自动保存
- 🎮 **多视角切换** - 透视、俯视、正视、侧视四种视角

## 操作指南

### 基础操作

1. **场景导航**
   - 鼠标左键拖拽：旋转视角
   - 鼠标滚轮：缩放场景
   - 鼠标右键拖拽：平移视角

2. **喷头操作**
   - 点击喷头：选中喷头（显示金色圆环）
   - 拖拽喷头：调整喷头位置
   - 控制面板：修改喷头半径、水压参数

3. **参数调节**
   - 左侧控制面板提供所有可调节参数
   - 拖动滑块实时查看效果变化

### 演示样例操作步骤

#### 样例 1：观察坡地漏浇现象

1. 在「场景样例」下拉菜单选择「坡地漏浇案例」
2. 切换视角到「侧视」，观察地块坡度
3. 注意上坡方向（坡顶一侧）覆盖范围明显缩短
4. 查看右侧报告面板，确认漏浇区域位置和面积

#### 样例 2：风向对覆盖的影响

1. 选择「强风偏斜案例」
2. 观察场景左侧的风向指示器
3. 注意覆盖范围向顺风方向偏移
4. 逆风侧出现明显的漏浇带
5. 调节「风速」滑块，观察覆盖变化

#### 样例 3：水压不足的影响

1. 选择「水压不足案例」
2. 观察所有喷头的有效射程都明显缩短
3. 地块中心和四个边角出现大面积漏浇
4. 逐步提高「水压系数」滑块，观察覆盖率提升

#### 样例 4：边角漏浇经典问题

1. 选择「边角漏浇经典案例」
2. 观察 3 个喷头的三角形布局
3. 注意四个边角的红色漏浇区域
4. 点击「+ 添加喷头」补充一个喷头到角落
5. 观察覆盖率变化

### 自定义场景操作

1. 从任意预设样例开始
2. 使用「+ 添加喷头」按钮增加新喷头
3. 拖拽喷头到理想位置
4. 调节环境参数（坡度、风向、水压）
5. 观察热力图和漏浇区域
6. 点击「导出 PDF 报告」保存分析结果

## 核心算法

### 覆盖计算模型

系统考虑以下因素计算有效覆盖范围：

1. **水压影响**：射程与水压平方根成正比
2. **风向影响**：顺风方向射程增加，逆风方向减少
3. **坡度影响**：上坡射程缩短，下坡射程延长
4. **叠加效应**：多喷头覆盖区域强度叠加

### 漏浇区域识别

使用洪水填充（Flood Fill）算法识别连通的漏浇区域：
- 面积 >= 1m² 的区域会被标记
- 边角区域和间隙区域分别分类

## 技术栈

- **前端框架**: React 18 + TypeScript
- **3D 引擎**: Three.js + React Three Fiber
- **状态管理**: Zustand (支持 localStorage 持久化)
- **样式方案**: Tailwind CSS
- **导出功能**: jsPDF + html2canvas
- **构建工具**: Vite

## 数据持久化

系统自动保存以下状态到浏览器 localStorage：
- 喷头配置（位置、半径、水压）
- 环境参数（坡度、风向、风速、水压）
- 显示选项（热力图、漏浇标记、范围显示）
- 当前视角模式

点击「重置」按钮可恢复到默认状态。
