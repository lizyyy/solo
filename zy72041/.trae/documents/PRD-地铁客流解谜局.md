## 1. 产品概述

"地铁客流解谜局"是一款面向活动策划的轻量化解谜工具，帮助活动策划阿蓝将课堂计分表中的地铁客流数据材料转化为可互动的解谜游戏，解决课堂计分表材料与导出结果脱节的问题。

- 核心价值：将课堂计分表中的地铁客流数据转化为互动解谜体验
- 目标用户：活动策划阿蓝及课堂教学场景
- 解决问题：材料与结果脱节、翻找记录效率低、结算原因不清晰

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 活动策划者 | 无需注册 | 配置关卡、导入数据、查看结算、导出报告 |
| 玩家 | 无需注册 | 参与解谜、查看结算 |

### 2.2 功能模块

1. **开始页面**：关卡选择、游戏说明、数据导入
2. **游戏页面**：回合进度、选择交互、暂停/继续/重开
3. **结算页面**：关键选择展示、扣分原因说明、评分备注展示
4. **导出报告**：包含解谜原因的完整报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|----------|----------|
| 开始页面 | 关卡选择 | 展示可用关卡列表，支持选择不同的地铁客流场景 |
| 开始页面 | 数据导入 | 支持导入课堂计分表数据，自动校验数据完整性 |
| 开始页面 | 数据冲突检测 | 检测导入数据与预设参数冲突，展示两边证据和建议 |
| 游戏页面 | 回合进度 | 显示当前回合数、总回合数、当前得分 |
| 游戏页面 | 选择交互 | 玩家根据客流数据做出决策选择 |
| 游戏页面 | 回合进度条 | 可视化展示游戏进度 |
| 游戏页面 | 暂停/继续 | 支持暂停游戏，状态持久化 |
| 游戏页面 | 重开 | 重置游戏，回合数和结算原因保持稳定 |
| 结算页面 | 关键选择回顾 | 展示每回合的关键选择和对应原因 |
| 结算页面 | 扣分原因详情 | 逐条展示扣分原因和对应证据 |
| 结算页面 | 评分备注 | 展示老师的评分备注和建议 |
| 导出报告 | PDF/文本导出 | 导出包含所有解谜原因的完整报告 |

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：地铁蓝（#1E40AF）搭配警示橙（#F59E0B）、错误红（#EF4444）、成功绿（#10B981）
- 按钮风格：圆角8px，悬停有微妙阴影，点击有按压效果
- 字体：标题使用"Noto Serif SC（宋体）增加正式感，正文使用"PingFang SC"
- 布局风格：卡片式布局，左侧为游戏区域，右侧为数据证据面板
- 图标：使用地铁线路图标、客流图表图标作为装饰

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|-----------|----------|---------|
| 开始页面 | 关卡卡片 | 地铁线路图背景、关卡标题、难度标签、开始按钮 |
| 游戏页面 | 回合面板 | 回合进度条、当前场景描述、选择按钮组 |
| 游戏页面 | 证据面板 | 课堂计分表数据展示、关键数据高亮 |
| 结算页面 | 时间线 | 每回合选择时间线、可展开查看详情 |
| 结算页面 | 扣分卡片 | 红色边框、扣分原因、证据引用 |
| 导出报告 | 报告预览 | 可滚动预览、导出按钮 |

### 4.3 响应式

- 桌面端优先设计
- 移动端自适应布局
- 触控按钮尺寸不小于44px
- 断点：<768px时改为上下布局

### 4.4 动画效果

- 页面切换使用渐入效果
- 选择按钮悬停时轻微上浮
- 扣分时红色边框闪烁提示
- 进度条平滑过渡动画
- 时间线节点依次出现动画
