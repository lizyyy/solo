# 公益书库捐书入库管理系统

这是一个为一线公益书库志愿者设计的书籍入库管理系统，解决 ISBN、品相、年级标签混乱的问题，确保上架清单准确可靠。

## 功能特性

### 核心功能
- **批量导入**: 从 JSON 文件批量导入书籍数据
- **智能去重**: 同 ISBN + 同标题 + 同品相 = 重复，避免重复计数
- **分级规则**: 智能识别和标准化年级标签
- **品相校验**: 标准化品相描述（全新、九成新、八成新、七成新、六成新及以下）
- **上架单生成**: 按年级排序生成上架清单，包含书架编号
- **历史查询**: 支持按操作人、ISBN、状态等条件查询历史记录

### 审计与安全
- **操作人记录**: 每条记录都包含操作人姓名
- **角色权限**: 支持志愿者(volunteer)、管理员(admin)、审计员(auditor)三种角色
- **时间戳**: 记录每次操作的时间
- **完整历史**: 所有处理结果都保存，可追溯

## 数据模型

### 书籍状态
- `已通过 (ACCEPTED)`: 校验通过，成功入库
- `已拒绝 (REJECTED)`: 校验失败，无法入库
- `重复导入 (DUPLICATE)`: 检测为重复书籍

### 品相关别
- 全新
- 九成新
- 八成新
- 七成新
- 六成新及以下

### 年级分类
- 一年级 ~ 六年级
- 初一 ~ 初三（七年级 ~ 九年级）
- 高一 ~ 高三
- 未分级

## 安装与使用

### 安装依赖
```bash
npm install
```

### 编译
```bash
npm run build
```

### 运行测试
```bash
npm test
```

### CLI 命令

#### 1. 导入书籍
```bash
npm run cli -- import sample-books.json --operator 张三 --role volunteer
```

#### 2. 查看所有批次
```bash
npm run cli -- batches
```

#### 3. 查看批次详情
```bash
npm run cli -- batch <批次ID>
```

#### 4. 查看批次处理结果
```bash
npm run cli -- results <批次ID>
```

#### 5. 生成上架单
```bash
npm run cli -- shelf <批次ID> --operator 张三 --role volunteer
```

#### 6. 查看所有上架单
```bash
npm run cli -- shelf-list
```

#### 7. 查询历史记录
```bash
# 查询所有历史
npm run cli -- history

# 按操作人查询
npm run cli -- history --operator 张三

# 按 ISBN 查询
npm run cli -- history --isbn 9787107186041

# 按状态查询
npm run cli -- history --status accepted
```

## 核心规则说明

### 1. ISBN 处理
- 有效 ISBN: 10位或13位数字格式
- 缺少 ISBN: 允许入库，按标题+品相去重
- 无效 ISBN: 拒绝入库，记录原因

### 2. 去重规则
重复检测条件（同时满足）:
- ISBN 相同（或都为空）
- 标题完全相同
- 品相完全相同

### 3. 品相标准化
支持的品相表述:
- 全新、新
- 九成新、9成新、9新
- 八成新、8成新、8新
- 七成新、7成新、7新
- 六成新、6成新、6新、六成新及以下

### 4. 年级标准化
支持的年级表述:
- 小学: 一年级~六年级、1年级~6年级
- 初中: 初一、初二、初三、七年级~九年级
- 高中: 高一、高二、高三

### 5. 上架单排序
上架单按以下优先级排序:
1. 年级从低到高（一年级 → 高三）
2. 标题拼音排序

## 持久化存储

系统使用 SQLite 数据库进行本地持久化，保存以下信息:
- 导入批次记录
- 书籍详情
- 所有处理结果（通过/拒绝/重复）
- 上架单记录

重启服务后，所有历史数据依然可查询。

## 审计特性

每条处理记录都包含:
- 操作人姓名
- 操作人角色
- 操作时间戳
- 处理状态
- 处理原因（详细说明）

确保所有操作可追溯，符合公益机构的审计要求。
