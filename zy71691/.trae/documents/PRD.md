# 港口集装箱堆场沙盘 - 产品需求文档

## 1. 产品概述
港口集装箱堆场沙盘是一个3D可视化运营管理系统，帮助港口运营人员实时监控箱位状态、吊机作业和卡车路线，提前发现压港风险。系统通过直观的空间展示、时间轴回放和冲突高亮功能，让运营决策更高效。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 港口运营人员 | 账号密码登录 | 查看3D堆场、回放任务、导出报告、保存方案 |
| 调度管理员 | 账号密码登录 | 管理箱位数据、配置吊机任务、导出调度报告 |

### 2.2 功能模块
1. **3D堆场沙盘主页面**：箱位可视化、吊机实时状态、卡车路线展示、冲突高亮
2. **任务回放页面**：时间轴控制、速度调节、历史作业追溯
3. **报告管理页面**：冲突清单、统计图表、方案保存、报告导出
4. **对象详情面板**：箱位信息、吊机任务、卡车路线、作业备注

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 3D堆场沙盘 | 3D场景渲染 | 展示堆场箱位、吊机、卡车的空间位置，支持缩放旋转平移 |
| 3D堆场沙盘 | 筛选面板 | 按箱型、状态、时间范围筛选对象，异常对象一键定位 |
| 3D堆场沙盘 | 冲突高亮 | 箱位重叠、吊机冲突、路线堵塞自动检测并高亮显示 |
| 任务回放 | 时间轴控制 | 拖动时间滑块查看任意时刻状态，支持播放/暂停/速度调节 |
| 任务回放 | 事件标记 | 关键作业节点在时间轴上标记，点击可跳转 |
| 报告管理 | 数据可视化 | 堆场利用率、作业效率、冲突统计的图表展示 |
| 报告管理 | 方案保存 | 保存当前视图配置和筛选条件，支持快速切换 |
| 报告管理 | 报告导出 | 导出PDF报告、截图、数据清单，包含数字来源说明 |
| 对象详情 | 信息展示 | 点击对象显示详细信息，包含关联数据和历史记录 |
| 对象详情 | 数据溯源 | 图表和清单中的数字可点击查看计算逻辑和来源 |

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深海蓝 (#0F4C81) - 代表专业和信任
- **辅助色**：警示橙 (#FF6B35) - 异常状态高亮；安全绿 (#2ECC71) - 正常状态
- **中性色**：深灰 (#1A1A2E) - 背景；浅灰 (#E8E8E8) - 边框和分隔线
- **按钮风格**：直角矩形，2px边框，hover时有轻微上浮效果
- **字体**：标题使用 Noto Sans SC Bold；正文使用 Noto Sans SC Regular
- **布局风格**：左右分栏布局，左侧3D场景主区域，右侧信息面板
- **图标风格**：线性图标，统一2px描边，配合工业风格

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 3D堆场沙盘 | 3D场景 | 等轴测视角，半透明箱位模型，动态吊机动画，流动卡车路线 |
| 3D堆场沙盘 | 顶部工具栏 | 时间显示、视图切换、筛选按钮、导出按钮 |
| 3D堆场沙盘 | 右侧面板 | 对象详情、冲突列表、筛选条件 |
| 3D堆场沙盘 | 底部时间轴 | 时间刻度、播放控制、事件标记点 |
| 任务回放 | 控制面板 | 播放/暂停、速度调节(0.5x/1x/2x)、进度条 |
| 报告管理 | 图表区域 | 柱状图、折线图、饼图，支持钻取 |
| 报告管理 | 方案列表 | 卡片式布局，显示方案名称、创建时间、缩略图 |

### 4.3 响应式
- 桌面端优先设计，支持1920x1080及以上分辨率
- 侧边栏可折叠，适应不同屏幕宽度
- 触摸设备支持手势缩放和旋转3D场景

### 4.4 3D场景设计
- **环境**：工业风格，深色背景配网格地面，模拟港口夜景
- **光照**：方向光主光源配合环境光，突出集装箱金属质感
- **相机**：默认45度俯视角，支持轨道控制，限制最大仰角避免穿模
- **动画**：吊机作业平滑动画，卡车路线使用流动光效，异常对象脉冲闪烁
- **后处理**：轻微泛光效果，高亮对象发光描边
