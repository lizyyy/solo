## 1. 产品概述

屋顶光伏航线管理系统——面向飞手、巡检员和安全员的航线巡检数据管理工具，核心解决电池循环错算、返航点丢失、禁飞区擦边等异常记录无法溯源与复核的问题。

- 让每一条巡检结论都能回溯到具体的巡检照片或航线 KML，接手人可快速找到依据
- 对异常记录宁可标为"待确认"，也不混入正常结果；提供可复核原因而非仅给总数

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心职责 |
|------|----------|
| 飞手 | 导入航线与飞行数据，标记飞行异常 |
| 巡检员 | 查看巡检结果，关联照片与航线，确认或标记待复核 |
| 安全员 | 审核异常记录（电池循环、禁飞区等），最终确认或驳回 |

### 2.2 功能模块

1. **航线总览页**：航线列表、状态筛选、异常统计、快速导入入口
2. **航线详情页**：飞行数据总览、巡检照片溯源、KML 可视化、异常记录与复核链路

### 2.3 页面详情

| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 航线总览页 | 状态统计栏 | 展示总航线数、正常/待确认/异常数量，点击可筛选 |
| 航线总览页 | 航线列表 | 展示航线名称、日期、状态标签、电池循环、异常标记，支持多条件筛选与排序 |
| 航线总览页 | 导入面板 | 支持重复导入（覆盖/追加）、撤回最近一次导入、导入后自动检测异常 |
| 航线总览页 | 筛选导出 | 按状态/日期/异常类型筛选后导出 CSV |
| 航线详情页 | 飞行数据卡片 | 电池循环数、飞行时长、返航点状态、禁飞区距离等关键指标 |
| 航线详情页 | 异常标记区 | 电池循环错算、返航点丢失、禁飞区擦边分别展示，附复核原因与溯源链接 |
| 航线详情页 | 照片溯源 | 点击结论可跳转到对应的巡检照片缩略图，照片支持放大查看 |
| 航线详情页 | KML 可视化 | 简易地图展示航线轨迹，标注异常点位 |
| 航线详情页 | 复核操作 | 对待确认记录进行确认/驳回，填写复核原因 |

## 3. 核心流程

### 3.1 导入与异常检测流程

飞手导入航线数据 → 系统自动检测异常（电池循环错算、返航点丢失、禁飞区擦边）→ 异常记录标记为"待确认" → 正常记录标记为"已通过" → 安全员复核待确认记录 → 确认后转正常或标记为异常

```mermaid
flowchart TD
    "导入航线数据" --> "自动异常检测"
    "自动异常检测" --> "异常?" 
    "异常?" -->|"是"| "标记为待确认"
    "异常?" -->|"否"| "标记为已通过"
    "标记为待确认" --> "安全员复核"
    "安全员复核" -->|"确认正常"| "标记为已通过"
    "安全员复核" -->|"确认异常"| "标记为异常+复核原因"
```

### 3.2 结论溯源流程

用户查看航线详情 → 点击结论/指标 → 跳转到对应巡检照片或 KML 轨迹上的点位 → 照片显示 EXIF 与关联航线信息

```mermaid
flowchart LR
    "结论/指标" --> "巡检照片"
    "结论/指标" --> "KML轨迹点位"
    "巡检照片" --> "EXIF与航线信息"
    "KML轨迹点位" --> "异常标注"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰（#1a1f2e）作为背景底色，搭配青绿（#10b981）为正常状态色，琥珀（#f59e0b）为待确认，玫红（#ef4444）为异常
- **按钮风格**：圆角微立体，主操作用实色填充，次操作用描边
- **字体**：标题用 JetBrains Mono（数据工具感），正文用 Noto Sans SC（中文可读性）
- **布局**：左侧固定导航栏 + 右侧内容区，卡片式布局
- **图标**：Lucide 图标库，线条风格

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
|------|------|---------|
| 航线总览页 | 状态统计栏 | 3个统计卡片（正常/待确认/异常），渐变背景，数字大字展示 |
| 航线总览页 | 航线列表 | 表格布局，行左侧状态色条，hover 展开详情预览 |
| 航线总览页 | 导入面板 | 拖拽上传区，导入模式切换（覆盖/追加），导入进度条 |
| 航线总览页 | 筛选导出 | 顶部筛选条（状态多选、日期范围、异常类型），右上导出按钮 |
| 航线详情页 | 飞行数据卡片 | 2x3 网格卡片，每张卡片有图标+数值+单位 |
| 航线详情页 | 异常标记区 | 独立区块，每条异常用醒目色块+图标+复核原因文本 |
| 航线详情页 | 照片溯源 | 缩略图网格，hover 放大，点击打开灯箱 |
| 航线详情页 | KML 可视化 | 右侧地图区，SVG 绘制简易轨迹 |
| 航线详情页 | 复核操作 | 底部操作栏，确认/驳回按钮+原因输入框 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px
- 平板端侧边栏折叠为汉堡菜单
- 移动端列表卡片化，详情页纵向堆叠

## 5. 异常检测规则

| 异常类型 | 检测条件 | 默认状态 | 复核要求 |
|----------|----------|----------|----------|
| 电池循环错算 | 电池循环数与累计充电次数偏差 > 2 | 待确认 | 必须填写复核原因 |
| 返航点丢失 | KML 中无返航坐标或返航高度 < 安全阈值 | 待确认 | 必须填写复核原因 |
| 禁飞区擦边 | 航线最近点距禁飞区边界 < 50m | 待确认 | 建议填写复核原因 |
