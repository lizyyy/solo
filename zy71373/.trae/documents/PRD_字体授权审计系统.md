## 1. 产品概述
字体授权使用审计系统，帮助设计公司法务和业务团队自助完成字体合规审计，识别授权过期、渠道超范围、字体更名等风险，减少手工分析成本，实现全流程可追溯。
- 主要目的：让业务同事自助拖拽样例文件完成字体审计，无需分析师手工跑批
- 解决问题：授权风险识别不透明、审计流程不可追溯、回归验证困难
- 目标用户：法务人员、业务同事、设计师
- 市场价值：降低合规风险，提升审计效率80%以上

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 法务管理员 | 系统账号 | 全功能权限、授权库管理、风险规则配置 |
| 业务同事 | 系统账号 | 审计任务创建、样例上传、报告查看 |
| 设计师 | 系统账号 | 查看项目字体授权状态 |

### 2.2 功能模块
1. **审计工作台**：拖拽上传、字体识别、实时进度、审计结果
2. **授权库管理**：字体文件管理、授权证书管理、授权信息录入
3. **项目与渠道管理**：项目信息、客户信息、发布渠道配置
4. **风险分析仪表盘**：风险概览、趋势分析、待办事项
5. **审计报告**：报告生成、历史追溯、导出下载
6. **回归验证**：回归样例库、修改验证、风险重检

## 3. 核心流程

用户拖拽样例文件到审计工作台 → 系统自动识别字体 → 匹配授权库 → 校验发布渠道 → 风险分层判定 → 生成审计报告 → 导出报告

```mermaid
    A["用户拖拽样例文件
    到审计工作台"] --> B["字体识别引擎
    提取字体名称/字重"]
    B --> C["授权库匹配
    查找对应授权"]
    C --> D{"匹配成功?"]
    D -->|是| E["渠道范围校验"]
    D -->|否| F["标记未匹配
    待补资料"]
    E --> G{"渠道合规?"}
    G -->|是| H["低风险
    标记合规"]
    G -->|否| I["高风险
    标记渠道超范围"]
    F --> J["待办事项
    通知相关人员"]
    H --> K["生成审计报告"]
    I --> K
    J --> K
    K --> L["导出报告
    支持PDF/Excel"]
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深海军蓝 (#0F2B4A) 代表专业、可信
- 辅助色：警示红 (#E53935) 用于高风险，警告橙 (#FB8C00) 用于中风险，成功绿 (#43A047) 用于低风险/合规
- 按钮风格：圆角4px，扁平化设计，hover时微阴影
- 字体：标题使用 Playfair Display，正文使用 Source Sans Pro
- 布局风格：左侧导航 + 右侧内容区，卡片式模块
- 状态标签设计：已确认（实心标签，绿色边框）、临时备注（虚线边框，灰色）

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|---------|----------|--------|
| 审计工作台 | 拖拽上传区 | 大尺寸虚线边框区域，拖拽时背景变蓝，图标动画效果 |
| 审计工作台 | 识别进度 | 进度条动画，分步显示识别步骤 |
| 审计工作台 | 风险卡片 | 三色风险标签，悬停显示风险详情 |
| 授权库管理 | 状态标签 | 已确认/临时备注 两种视觉区分 |
| 审计报告 | 追溯链路 | 时间轴样式，每步可展开查看输入输出 |
| 回归验证 | 样例卡片 | 三种回归场景卡片，点击展开详情 |

### 4.3 响应式
- 桌面端优先设计，支持1280px及以上
- 平板端自适应调整列数
- 移动端简化导航，保持核心功能可用

### 4.4 交互细节
- 拖拽上传时的微动效
- 识别过程分步动画
- 风险标签hover提示
- 状态切换平滑过渡
- 报告导出加载动画
