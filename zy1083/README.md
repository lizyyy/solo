# 租房看房复盘台

一款纯本地运行的 Web 前端工具，帮助您系统性地整理多套房的看房记录，生成可比较、可导出的签约前风险清单，避免凭印象拍板。

## 功能特点

- 📊 **多房源对比**：导入多套房源数据，自动计算综合评分并排序
- ⚖️ **可调节权重**：根据个人偏好调整各项因素的权重（租金、通勤、采光、噪音等）
- 🚨 **风险分析**：自动识别押金风险、维修风险、安全风险等，给出具体解释和建议
- ✅ **签约前核对**：创建短名单，记录待确认问题，逐条跟踪确认状态
- 📤 **多格式导出**：支持导出 JSON（可恢复）、Markdown、HTML 报告
- 🔒 **纯本地运行**：所有数据保存在浏览器本地，不上传任何服务器
- 🎯 **内置示例数据**：提供示例数据，快速体验所有功能

## 技术栈

- React 18 + TypeScript
- Vite 5
- Tailwind CSS
- Context API (状态管理)

## 快速开始

1. 启动应用后，点击顶部导航栏的「数据导入」

#### 2. 准备看房记录 (visit-notes.csv)

创建一个 CSV 文件，格式如下：

```csv
id,houseId,visitDate,lighting,noise,waterLeak,waterLeakDescription,odor,odorDescription,repairItems,applianceStatus,surroundingSafety,generalNotes,pendingQuestions,photos
visit_001,house_001,2026-04-29,5,4,否,,否,,[{"item":"厨房水龙头","severity":"轻微","needsLandlordRepair":true}],[{"name":"空调","status":"正常","notes":""}],5,整体感觉不错,[{"question":"物业费包含什么？","status":"待确认","answer":""}],
```

**CSV 字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 看房记录唯一ID |
| houseId | string | 关联的房源ID（必须与 houses.json 中的 id 对应） |
| visitDate | string | 看房日期 (YYYY-MM-DD) |
| lighting | number | 采光评分 (1-5) |
| noise | number | 噪音评分 (1-5) |
| waterLeak | string | 是否漏水 (是/否) |
| waterLeakDescription | string | 漏水描述 |
| odor | string | 是否有异味 (是/否) |
| odorDescription | string | 异味描述 |
| repairItems | string | JSON 数组格式的维修项列表 |
| applianceStatus | string | JSON 数组格式的家电状态 |
| surroundingSafety | number | 周边安全评分 (1-5) |
| generalNotes | string | 看房备注 |
| pendingQuestions | string | JSON 数组格式的待确认问题 |
| photos | string | 照片路径（分号分隔） |

**提示**：在「数据导入」页面可以点击「下载模板」获取完整的 CSV 模板。

#### 3. 导入数据

1. 进入「数据导入」页面
2. 在「导入房源数据」区域选择 houses.json 文件，点击「导入房源数据」
3. 在「导入看房记录」区域选择 visit-notes.csv 文件，点击「导入看房记录」
4. 系统会自动校验数据格式，如有错误会显示具体的行号和列号

## 功能详解

### 1. 数据导入

- **加载示例数据**：快速体验所有功能
- **导入房源数据**：支持 JSON 格式
- **导入看房记录**：支持 CSV 格式
- **导入完整项目**：导入之前导出的 JSON 项目文件，恢复所有数据
- **数据校验**：自动检查字段缺失、数值格式错误，定位具体行和列

### 2. 房源对比

- **综合评分排名**：根据权重配置自动计算每套房源的综合评分
- **多维度排序**：支持按评分、租金、通勤时间、面积排序
- **评分明细**：查看每项因素的具体得分和权重
- **风险卡片**：显示所有风险因素，包括风险等级、描述和建议
- **隐性成本计算**：自动计算中介费分摊、额外费用等月均隐性成本
- **通勤成本估算**：按时间成本估算通勤的经济价值
- **加入/移除短名单**：将感兴趣的房源加入短名单进行重点关注

### 3. 权重设置

- **自定义权重**：调整各项因素的重要性
- **快速预设**：提供 4 种预设配置
  - 🏃 通勤优先：更看重通勤时间
  - 💰 预算优先：更看重租金和各项费用
  - 🏠 品质优先：更看重房屋质量和环境
  - 🛡️ 安全优先：更看重押金保障和安全因素
- **实时生效**：调整权重后，所有房源的评分会实时重新计算
- **恢复默认**：一键恢复默认权重配置

### 4. 签约核对

- **短名单管理**：管理您重点关注的房源
- **优先级设置**：为每套房源设置高/中/低优先级
- **待确认问题**：
  - 添加自定义问题
  - 快速选择常用问题（物业费、押金退还、口头承诺等）
  - 标记状态：待确认/已确认/放弃
  - 记录确认结果
- **风险分析**：集中显示该房源的所有风险点
- **备注记录**：记录对比思路和最终决策参考

### 5. 数据导出

- **JSON 格式**：导出完整项目数据，可随时重新导入恢复
- **Markdown 格式**：导出结构化报告，适合用笔记软件整理
- **HTML 格式**：导出格式美观的网页报告，可直接在浏览器打开或打印
- **导出选项**：可选择导出所有房源或仅导出短名单

## 评分逻辑说明

### 评分项权重（默认）

| 评分项 | 默认权重 | 说明 |
|--------|----------|------|
| 月租金 | 15 | 租金价格，越低评分越高 |
| 押金风险 | 12 | 押金额度和退还安全性 |
| 通勤时间 | 12 | 单程通勤时间，越短越好 |
| 采光 | 10 | 房屋采光情况 (1-5) |
| 噪音 | 10 | 周边安静程度 (1-5) |
| 漏水 | 8 | 是否存在漏水问题 |
| 异味 | 8 | 是否存在异味问题 |
| 维修成本 | 10 | 需要维修的项目数量和严重程度 |
| 周边安全 | 10 | 小区和周边治安情况 (1-5) |
| 中介费 | 3 | 中介费用高低 |
| 额外费用 | 2 | 物业费、网费等额外费用 |

### 风险评估规则

**押金风险评估：**
- 押一付一：低风险（20分风险值）
- 押二付一：中等风险（50分风险值）
- 押三付一：高风险（80分风险值）
- 押金超过月租金3倍：额外增加风险

**维修风险评估：**
- 严重维修项：每项增加30分风险值
- 中等维修项：每项增加15分风险值
- 轻微维修项：每项增加5分风险值
- 故障家电：每台增加10分风险值
- 漏水问题：增加30分风险值
- 异味问题：增加20分风险值

### 评分等级

| 等级 | 分数范围 | 说明 |
|------|----------|------|
| 优秀 | 85-100 | 综合条件很好，推荐优先考虑 |
| 良好 | 70-84 | 综合条件不错，有小瑕疵 |
| 一般 | 50-69 | 存在一些问题，需要仔细权衡 |
| 较差 | 0-49 | 问题较多，建议谨慎考虑或放弃 |

## 数据持久化

- 所有数据自动保存在浏览器的 `localStorage` 中
- 刷新页面或关闭浏览器后重新打开，数据仍然存在
- 可以通过「数据导出」功能备份数据
- 可以通过「导入完整项目」功能恢复数据

## 常见问题

### Q: 数据会上传到服务器吗？

不会。这是一个纯前端应用，所有数据只保存在您的浏览器本地，不会上传到任何服务器。您可以放心使用。

### Q: 支持哪些浏览器？

推荐使用最新版本的 Chrome、Firefox、Safari 或 Edge 浏览器。

### Q: 如何备份我的数据？

进入「数据导出」页面，选择「JSON」格式导出，将文件保存到安全位置。以后可以通过「导入完整项目」功能恢复。

### Q: 我可以修改评分规则吗？

可以通过「权重设置」页面调整各项因素的权重。如果需要更深度的自定义（如修改评分算法），可以直接修改 `src/utils/scoring.ts` 文件。

### Q: 最多支持多少套房源？

理论上没有限制，但建议单次导入不超过 50 套，以保持良好的性能体验。
