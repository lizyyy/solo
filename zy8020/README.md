# 🚌 公交调度复盘工具

一个基于 Streamlit 的本地公交调度复盘工具，帮助调度员导入计划时刻表、GPS到站记录和车辆事件数据，自动匹配计划班次与真实到站记录，检测异常情况并生成复盘报告。

## ✨ 功能特性

- **数据校验**：自动校验计划时刻表、GPS到站记录、车辆事件数据格式
- **匹配计算**：智能匹配计划班次与实际到站记录，支持跨午夜数据处理
- **异常检测**：
  - 串车检测（发车间隔过小）
  - 大间隔检测（发车间隔过大）
  - 漏发检测（计划班次未匹配到实际记录）
  - 到站偏差异常
  - 跨午夜数据标识
- **归因分析**：根据车辆故障、临时绕行、堵车等事件线索给出异常原因
- **报告导出**：支持导出 Markdown 报告和 CSV 数据

## 📊 数据格式说明

### 计划时刻表 CSV

| 字段 | 说明 | 必填 |
|------|------|------|
| 线路名称 | 线路名称 | 是 |
| 线路编号 | 线路编号 | 是 |
| 方向 | 上行/下行 | 是 |
| 站点名称 | 站点名称 | 是 |
| 站点顺序 | 站点序号 | 是 |
| 计划到站时间 | HH:MM:SS 格式 | 是 |
| 计划发车时间 | HH:MM:SS 格式 | 否 |
| 班次号 | 唯一班次标识 | 是 |

### GPS到站记录 CSV

| 字段 | 说明 | 必填 |
|------|------|------|
| 线路编号 | 线路编号 | 是 |
| 方向 | 上行/下行 | 是 |
| 站点名称 | 站点名称 | 是 |
| 车辆编号 | 车辆牌照 | 是 |
| 到站时间 | YYYY-MM-DD HH:MM:SS 格式 | 是 |
| 离站时间 | YYYY-MM-DD HH:MM:SS 格式 | 否 |
| GPS经度 | 经度坐标 | 否 |
| GPS纬度 | 纬度坐标 | 否 |

### 车辆事件 JSON

```json
[
  {
    "车辆编号": "粤A12345",
    "事件类型": "故障",
    "事件描述": "发动机故障",

    "结束时间": "2024-01-15 06:55:00",
    "影响站点": "科技园",
    "线路编号": "101",
    "方向": "上行"
  }
]
```

## 🎯 使用说明

1. **选择数据来源**
   - 上传本地 CSV/JSON 文件，或勾选"使用样例数据"
   
2. **设置参数**
   - 在左侧边栏设置参考日期和异常检测阈值
   
3. **查看结果**
   - 概览统计：匹配率、异常数量等关键指标
   - 异常详情：各类型异常的详细列表和原因分析
   - 匹配数据：计划与实际数据的匹配结果
   - 发车间隔：各站点的发车间隔统计
   
4. **导出报告**
   - 下载 Markdown 格式的复盘报告
   - 下载异常数据或匹配数据的 CSV 文件

## 🔧 异常检测参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 串车阈值 | 3 分钟 | 发车间隔小于此值视为串车 |
| 大间隔阈值 | 20 分钟 | 发车间隔大于此值视为大间隔 |
| 到站偏差阈值 | 5 分钟 | 到站时间与计划偏差超过此值视为异常 |
| 正常间隔下限 | 8 分钟 | 正常发车间隔的最小值 |
| 正常间隔上限 | 12 分钟 | 正常发车间隔的最大值 |
