# ❄️ 雪道开放风险复盘看板

滑雪场运营主管早场开园前风险评估工具

## 📋 功能概述

本工具用于在滑雪场早场开园前，对各雪道进行全面的风险评估，帮助运营主管快速识别安全隐患并做出开放决策。

### 核心功能

- **风险检测**：自动检测 5 种类型的风险
  - 未压实：压雪作业完成度低于阈值
  - 风吹雪覆盖不足：大风导致雪面覆盖不均
  - 巡查过期：巡查时间超过有效期
  - 跨午夜作业归属异常：压雪作业跨越午夜
  - 结冰/裸露：巡查发现结冰或裸露点

- **数据分析**：
  - 重建每条雪道夜间作业和巡查时间线
  - 展示风险分布趋势图
  - 天气趋势分析（气温、风速、降雪量）

- **报告导出**：
  - 导出 `risk_items.csv`：风险项详细列表
  - 导出 `open_review.md`：雪道开放复盘报告

## 📊 数据说明

### 1. snowcats.csv（压雪车数据）

| 字段 | 类型 | 说明 |
|------|------|------|
| vehicle_id | string | 压雪车编号 |
| trail_name | string | 雪道名称 |
| start_time | datetime | 作业开始时间 |
| end_time | datetime | 作业结束时间 |
| completion_pct | float | 作业完成度 (%) |
| operator | string | 操作员姓名 |

### 2. weather.csv（天气数据）

| 字段 | 类型 | 说明 |
|------|------|------|
| timestamp | datetime | 记录时间 |
| temperature_c | float | 气温 (°C) |
| wind_speed_kmh | float | 风速 (km/h) |
| snowfall_cm | float | 降雪量 (cm) |
| wind_direction | string | 风向 |

### 3. patrol.jsonl（巡查数据）

每行是一个 JSON 对象，包含：

```json
{
  "patrol_id": "巡查编号",
  "trail_name": "雪道名称",
  "timestamp": "巡查时间",
  "inspector": "巡查员姓名",
  "issues": ["问题列表"],
  "status": "状态"
}
```

### 4. rules.yaml（规则配置）

定义不同级别雪道的开放阈值：

- **初级道**：压雪完成度 ≥90%，风速 ≤30km/h，降雪 ≤2cm/h
- **中级道**：压雪完成度 ≥85%，风速 ≤35km/h，降雪 ≤2.5cm/h
- **高级道**：压雪完成度 ≥80%，风速 ≤40km/h，降雪 ≤3cm/h

## 🖥️ 使用指南

### 侧边栏筛选

1. **选择日期**：从可用日期中选择要分析的日期
2. **选择雪道**：勾选要分析的雪道（默认全选）
3. **风险等级筛选**：只显示特定等级的风险

### 页面标签

#### 1. 📋 风险列表

- 按严重程度（高/中/低）分类展示所有风险项
- 点击展开查看详细描述和缓解措施
- 高风险项以红色突出显示

#### 2. 📊 趋势分析

- **风险类型分布**：饼图展示各类风险占比
- **雪道风险分布**：堆叠柱状图展示各雪道的风险情况
- **天气趋势**：多轴折线图展示气温、风速、降雪量变化

#### 3. 🕐 时间线

- 选择特定雪道查看详细时间线
- 包含：压雪作业记录、巡查记录、天气变化
- 可视化展示夜间作业全过程

#### 4. 📄 导出报告

- **导出风险列表 (CSV)**：下载包含所有风险项的 CSV 文件
- **生成开放复盘报告 (Markdown)**：
  - 风险概览
  - 雪道状态分类（需关注/可正常开放）
  - 风险详情
  - 运营建议

## 🔧 自定义配置

### 修改规则阈值

编辑 `sample/rules.yaml` 文件，调整各类雪道的开放标准：

```yaml
trail_categories:
  beginner:
    name: 初级道
    min_completion_pct: 90      # 最低压雪完成度
    max_wind_speed_kmh: 30      # 最大允许风速
    max_snowfall_cm_per_hour: 2 # 最大每小时降雪量
    patrol_expiry_hours: 2       # 巡查有效期
```

### 添加新雪道

在 `snowcats.csv` 中添加新雪道的压雪记录，系统会自动识别雪道级别（根据名称中的"初级"/"中级"/"高级"）。

## 📝 使用示例

### 典型工作流程

1. **早班到岗**（约 7:00 AM）
   - 启动应用，选择当天日期
   - 查看风险概览，确认高风险项数量

2. **详细分析**
   - 查看风险列表，重点关注高风险雪道
   - 检查天气趋势，确认是否有大风或暴雪影响
   - 查看特定雪道的时间线，了解夜间作业情况

3. **决策与行动**
   - 导出风险列表，分发给相关团队
   - 对高风险雪道安排紧急处理
   - 生成开放复盘报告，作为当日运营决策依据

4. **开园确认**
   - 处理完成后，确认所有高风险项已解决
   - 对无风险雪道做出开放决策

## 🛠️ 故障排除

### 常见问题

**Q: 应用启动后显示错误？**

A: 检查以下几点：
- Python 版本是否为 3.8+
- 是否已安装所有依赖：`pip install -r requirements.txt`
- 数据文件是否在 `sample/` 目录下

**Q: 没有显示任何数据？**

A: 确认：
- 选择了正确的日期
- `sample/` 目录下的数据文件格式正确
- 数据文件包含所选日期的记录

**Q: 如何添加自己的数据？**

A: 按照以下步骤：
1. 备份 `sample/` 目录下的示例文件
2. 用您的实际数据替换对应文件
3. 确保数据格式与示例文件一致
4. 重启应用

## 📄 输出文件说明

### risk_items.csv

导出的风险列表包含以下字段：
- `risk_id`: 风险唯一标识
- `trail_name`: 雪道名称

- `risk_type`: 风险类型
- `severity`: 严重程度
- `description`: 风险描述
- `mitigation`: 缓解措施
- `timestamp`: 生成时间
- `details`: 详细信息（JSON 格式）

### open_review.md

生成的复盘报告包含：
1. 风险概览（高/中/低风险数量）
2. 雪道状态分类（需重点关注/可正常开放）
3. 风险详情（按严重程度分类）
4. 运营建议
