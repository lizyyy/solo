## 1. 产品概述

浮标海况异常预警系统——面向海洋水质分析师与监测团队的异常数据管理工具，解决船上人工记录与传感器实时数据之间的时序错位问题，确保异常筛选口径可追溯、经纬度反写可挂起、重复导入不翻倍、人工备注不覆盖、服务重启后历史可接续。

- 核心用户：水质分析师、监测站值班员、接手同事
- 核心价值：将"传感器异常队列"与"船上人工记录"统一在同一视图中管理，杜绝假稳定结论，让换班交接零成本

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 水质分析师 | 默认进入 | 浏览异常队列、导入船上记录、添加人工备注、导出数据 |
| 值班员 | 默认进入 | 浏览异常队列、查看历史备注、确认挂起记录 |
| 接手同事 | 默认进入 | 沿历史备注追溯异常结论、重新导出、查看材料位置 |

### 2.2 功能模块

1. **异常队列总览页**：异常记录列表、筛选口径面板、实时传感器状态指标、导出功能
2. **记录详情与比对页**：传感器数据与船上记录并排比对、经纬度反写挂起操作、人工备注编辑
3. **船上记录导入页**：少量批量导入、边界样本标记、重复检测与合并策略

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 异常队列总览页 | 筛选口径面板 | 按时间范围、浮标编号、异常类型、确认状态筛选，筛选条件持久化保留在异常队列上下文中 |
| 异常队列总览页 | 异常记录列表 | 展示传感器异常记录卡片，含浮标编号、时间、异常指标、确认状态标签 |
| 异常队列总览页 | 导出按钮 | 导出时携带当前筛选口径参数，导出数据与屏幕显示一致，口径信息写入导出文件头部 |
| 异常队列总览页 | 实时指标栏 | 顶部固定显示当前异常数量、挂起数量、今日新增数量 |
| 记录详情与比对页 | 传感器数据区 | 展示该条异常的传感器原始数据（含时间戳、经纬度、各项水质指标） |
| 记录详情与比对页 | 船上记录区 | 展示对应船上人工记录，标注记录时间与传感器时间的偏差 |
| 记录详情与比对页 | 经纬度反写检测 | 自动检测经纬度是否反写（如纬度值超出正常范围），检测到则标记为"挂起待确认"，禁止给出稳定结论 |
| 记录详情与比对页 | 人工备注编辑 | 支持添加、查看人工备注，备注按时间线展示，新备注不覆盖旧备注 |
| 记录详情与比对页 | 状态流转 | 未确认→已确认/挂起待确认，挂起记录需接手同事确认后方可解除 |
| 船上记录导入页 | 批量导入区 | 支持少量（10条以内）船上记录批量导入，每次导入显示预览与校验结果 |
| 船上记录导入页 | 边界样本标记 | 导入时自动标记或手动标记边界样本（正常与异常临界值的记录），方便验证确认逻辑 |
| 船上记录导入页 | 重复检测 | 导入时自动检测重复记录（基于浮标编号+时间戳），正常记录不翻倍，人工备注不被覆盖 |
| 船上记录导入页 | 导入结果报告 | 导入完成后展示：新增N条、跳过重复N条、边界样本N条、挂起N条 |

## 3. 核心流程

**异常队列查看与导出流程**：用户进入异常队列总览页→设定筛选口径→浏览筛选后的异常记录→点击导出→系统将筛选口径参数写入导出文件头部+导出当前屏幕数据→导出完成

**船上记录导入流程**：用户进入导入页→粘贴或上传少量记录→系统预览校验（检测重复、检测经纬度反写、标记边界样本）→用户确认导入→系统执行导入（跳过重复、保留备注、挂起异常）→展示导入结果报告

**经纬度反写挂起流程**：系统检测到经纬度反写→自动标记为"挂起待确认"→记录出现在异常队列的挂起区域→接手同事查看→确认或修正→状态流转

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 `#0A2540` 搭配荧光海绿 `#00E5A0` 作为异常/激活态，警示橙 `#FF6B35` 标记挂起状态
- **辅助色**：冷灰 `#1E293B` 背景、浅灰 `#94A3B8` 次要文字、白 `#F8FAFC` 卡片
- **按钮风格**：圆角矩形 `rounded-lg`，主按钮实色填充，次要按钮描边，挂起操作按钮橙色警示
- **字体**：标题使用 DM Sans（粗体 700/600），正文使用 Source Sans 3（400/500），数据数字使用 JetBrains Mono
- **布局风格**：左侧固定导航栏 + 右侧内容区，卡片式布局，顶部固定指标栏
- **图标风格**：线性描边图标（Lucide），2px 描边宽度，与数据表格场景匹配

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 异常队列总览页 | 顶部指标栏 | 3个指标卡片横排：异常总数(荧光绿)、挂起数(警示橙)、今日新增(白色)，带数字动画 |
| 异常队列总览页 | 筛选口径面板 | 可折叠侧面板，含时间选择器、浮标编号下拉、异常类型多选、确认状态切换，面板底部"应用到导出"开关 |
| 异常队列总览页 | 异常记录列表 | 虚拟滚动表格，行高亮悬停，状态标签（未确认/已确认/挂起），点击行跳转详情 |
| 异常队列总览页 | 导出按钮 | 右上角固定按钮，点击展开下拉：导出当前筛选/导出全部，导出时自动附带口径参数 |
| 记录详情与比对页 | 比对双栏 | 左栏传感器数据（默认）、右栏船上记录（如有），时间偏差用橙色高亮标注 |
| 记录详情与比对页 | 经纬度警告条 | 检测到反写时顶部横幅警告，橙色底+图标，含"挂起待确认"按钮 |
| 记录详情与比对页 | 备注时间线 | 右侧纵向时间线，每条备注含作者、时间、内容，底部输入框添加新备注 |
| 记录详情与比对页 | 状态操作区 | 底部操作栏：确认/挂起/退回，状态流转需二次确认弹窗 |
| 船上记录导入页 | 导入输入区 | 文本域粘贴+文件上传双模式，支持 JSON/CSV 格式 |
| 船上记录导入页 | 预览校验表格 | 导入前预览，重复行灰色删除线、反写行橙色背景、边界样本蓝色标记 |
| 船上记录导入页 | 结果报告 | 导入完成后模态弹窗，4项统计数据+详情折叠面板 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1024px
- 大屏（≥1440px）筛选面板常驻展开，中小屏折叠为抽屉
- 记录详情比对页在窄屏时切换为上下堆叠而非左右双栏
- 导入页在移动端简化为单条逐条录入模式

### 4.4 设计调性

- **工业监测美学**：整体暗色系仪表盘风格，模拟海洋监测控制室的专业感
- 数据密度适中，关键指标用荧光色突出，次要信息收敛
- 微交互：状态标签切换时有缩放动画、数字变化时有滚动计数效果、挂起操作有脉冲警示
- 背景使用深海渐变 + 微弱网格纹理，营造深度感
