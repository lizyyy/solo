# 内河船闸调度员

一款本地浏览器小游戏，玩家扮演内河船闸调度员，需要合理安排货船、客船和应急船的过闸顺序，在潮汐水位窗口、闸室容量、等待成本和优先级的约束下获得最高分数。

## 游戏特色

- 🚢 **多种船只类型**：货船、客船、应急船，各有不同的大小、优先级和等待成本
- 🌊 **潮汐系统**：高水位只能上行，低水位只能下行，包含跨午夜的复杂潮汐窗口
- 🎯 **策略深度**：需要平衡容量、时间、优先级等多个因素
- 💾 **存档功能**：支持保存和读取游戏进度，包含损坏存档恢复机制
- 📊 **结算复盘**：游戏结束后显示详细得分明细、违规原因和改进建议

## 快速开始

### 本地预览

使用以下任意一种方式在本地预览游戏：

#### 方式一：使用 Python 内置服务器
```bash
# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

然后在浏览器中打开：`http://localhost:8000`

#### 方式二：使用 Node.js (serve)
```bash
# 安装 serve (如果没有安装)
npm install -g serve

# 启动服务器
serve -p 8000
```

然后在浏览器中打开：`http://localhost:8000`

#### 方式三：使用 VS Code Live Server 插件
1. 在 VS Code 中安装 "Live Server" 插件
2. 右键点击 `index.html` 文件
3. 选择 "Open with Live Server"

## 游戏玩法

### 基本操作

1. **拖拽船只**：将船只从"等待区域"拖拽到"闸室区域"
2. **开闸操作**：点击"↑ 开闸上行"或"↓ 开闸下行"按钮让船只过闸
3. **清空闸室**：点击"清空闸室"按钮将闸室中的船只移回等待区域
4. **保存进度**：点击"保存进度"按钮保存当前游戏状态
5. **读取进度**：点击"读取进度"按钮加载之前保存的游戏状态
6. **选择关卡**：点击"选择关卡"按钮切换不同的关卡

### 游戏规则

#### 船只类型

| 类型 | 优先级 | 占用空间 | 等待成本 | 基础分数 |
|------|--------|----------|----------|----------|
| 货船 | 1 (最低) | 2 | 1 分/分钟 | 30-45 |
| 客船 | 2 (中等) | 1 | 2 分/分钟 | 20-35 |
| 应急船 | 3 (最高) | 1 | 5 分/分钟 | 50-60 |

#### 潮汐窗口

- **高水位 (绿色)**：只能执行上行操作
- **低水位 (橙色)**：只能执行下行操作
- 每次开闸操作消耗 15 分钟游戏时间

#### 得分计算

- **基础分**：每艘船都有固定的基础分数
- **时间奖励**：提前完成过闸可获得额外奖励
- **违规扣分**：违反规则会被扣分
- **未完成惩罚**：关卡结束时未完成的船只会被扣 50% 基础分

#### 违规类型

| 违规类型 | 扣分数 | 说明 |
|----------|--------|------|
| 超出闸室容量 | 20 | 闸室已满仍尝试添加船只 |
| 潮汐水位不匹配 | 15 | 在错误的潮汐水位执行操作 |
| 错过截止时间 | 30 | 船只未在截止时间前完成过闸 |
| 优先级违规 | 25 | 低优先级船只优先于高优先级船只过闸 |
| 方向不匹配 | 10 | 船只方向与操作方向不一致 |
| 空闸室操作 | 5 | 闸室为空时执行开闸操作 |
| 超出时间限制 | 50 | 关卡时间耗尽 |

## 关卡介绍

### 关卡 1：新手教程
- **闸室容量**：3
- **时间限制**：120 分钟
- **船只数量**：2 艘
- **特点**：简单的潮汐窗口，适合学习基本操作

### 关卡 2：繁忙时段
- **闸室容量**：4
- **时间限制**：180 分钟
- **船只数量**：4 艘
- **特点**：更多船只，更复杂的潮汐窗口，包含应急船

### 关卡 3：午夜挑战
- **闸室容量**：5
- **时间限制**：240 分钟 (22:00 - 02:00)
- **船只数量**：6 艘
- **特点**：跨午夜的潮汐窗口，多艘应急船，挑战性最高

## 模块说明

### 1. 关卡数据模块 (levelData.js)
- 定义船只类型、优先级、等待成本、大小等常量
- 包含 3 个示例关卡的数据
- 提供时间格式化和关卡克隆等工具函数

### 2. 规则引擎模块 (rulesEngine.js)
- 潮汐水位检查（支持跨午夜窗口）
- 闸室容量计算和检查
- 等待成本计算
- 违规检测和记录
- 分数计算（单船只和最终得分）
- 时间推进和关卡结束判断

### 3. 拖拽状态管理模块 (dragState.js)
- 船只拖拽功能（支持鼠标和触摸操作）
- 拖拽开始/结束/放置的状态管理
- 放置目标验证（有效/无效放置高亮）
- 可拖拽船只元素创建和渲染

### 4. 存档和结算复盘模块 (saveLoad.js)
- 游戏状态保存到 localStorage
- 游戏状态读取和验证
- 损坏存档恢复机制
- 结算复盘数据生成
- 违规分析和改进建议生成

### 5. 主游戏逻辑 (game.js)
- 整合所有模块
- 游戏状态管理
- UI 事件绑定和处理
- 界面渲染和更新
- 关卡选择和切换
- 结算结果展示

## 游戏技巧

1. **优先处理应急船**：应急船优先级最高，等待成本也最高
2. **注意潮汐窗口**：提前规划，在正确的潮汐窗口执行操作
3. **合理组合船只**：货船占用 2 个空间，可以和客船/应急船组合
4. **关注截止时间**：截止时间临近的船只要优先安排
5. **批量处理同方向**：尽量让同一方向的船只一起过闸

## 开发说明

### 添加新关卡

在 `js/levelData.js` 的 `levels` 数组中添加新的关卡对象：

```javascript
{
    id: 4,
    name: '新关卡名称',
    description: '关卡描述',
    lockCapacity: 5,           // 闸室容量
    targetScore: 400,         // 目标分数
    initialTime: 0,           // 初始时间（分钟）
    timeLimit: 300,           // 时间限制（分钟）
    tidalWindows: [           // 潮汐窗口
        { start: 0, end: 60, level: 'high' },
        { start: 60, end: 120, level: 'low' },
        // ...
    ],
    ships: [                  // 船只列表
        {
            id: 'ship_1',
            type: ShipTypes.EMERGENCY,
            name: '应急船-001',
            // ...
        },
        // ...
    ]
}
```
