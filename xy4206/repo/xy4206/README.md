## ✨ 功能特性

### 🔍 精准分析
- **错音检测**: 识别按下错误音高的音符
- **节奏问题**: 标注提前/滞后超过容差的演奏
- **漏音检测**: 找出乐谱中应该演奏但没有按下的音符
- **连音断裂**: 检测连音线（slur）演奏中的中断
- **力度偏差**: 分析力度控制是否符合乐谱要求
- **时值问题**: 检查音符持续时间是否正确

### 🎵 回放功能
- 同步播放目标乐谱和实际演奏
- 可选择只听目标音、只听演奏音、或两者对比
- 支持变速播放（0.5x - 2x）
- 播放时自动高亮当前小节

### 💾 存档与导出
- 本地存储练习档案（最多20条）
- 导出 **Markdown讲评**：包含详细分析和建议
- 导出 **CSV错误明细**：便于导入Excel进一步分析
- 导出 **JSON审计包**：完整数据备份

### 验证流程

#### 第一步：加载数据
1. 打开页面后，你会看到"数据导入"面板
2. 有两种方式加载数据：
   - **点击"加载示例数据"**：快速体验预设数据
   - **导入自己的数据**：
     - 点击"目标乐谱 (JSON)"选择 `.json` 文件
     - 点击"演奏记录 (CSV)"选择 `.csv` 文件

#### 第二步：查看分析结果
数据加载后，页面会自动进行分析并显示：

1. **左侧分析摘要**：
   - 总分与等级（A-F）
   - 小节数
   - 各类错误统计（错音、节奏问题、漏音、连音断裂）

2. **中间谱架显示**：
   - 按小节组织的乐谱显示
   - 不同颜色标识：
     - ✅ **绿色**：正确演奏
     - ⚠️ **黄色**：轻微问题（如小幅度节奏偏差）
     - ❌ **红色**：严重错误（如漏音、大偏差）

3. **音符详情**：
   - 每个音符显示音名（如 C4, D5）
   - 显示时值（秒）
   - 节奏问题音符会显示"提前XXms"或"滞后XXms"

#### 第三步：小节详情
点击任意小节的头部（显示小节号和分数的区域）：

1. 下方会弹出"小节详情"面板
2. 显示内容包括：
   - 小节得分
   - 详细错误列表（如果有）
   - 每个错误的具体信息：
     - 错误类型
     - 严重程度（🔴严重 / 🟡中等 / 🟢轻微）
     - 期望值 vs 实际值
     - 扣分数值
   - 本小节所有音符状态概览

#### 第四步：回放体验
1. 使用顶部播放控制：
   - ▶ **播放**：从头或从上次暂停位置开始
   - ⏸ **暂停**：暂停当前播放
   - ⏹ **停止**：停止并重置到开头

2. 播放选项：
   - **播放目标音**：播放乐谱应该的声音（正弦波）
   - **播放演奏音**：播放学生实际演奏的声音（三角波）
   - **速度调节**：滑块可调整 0.5x - 2x 播放速度

3. 播放时特性：
   - 当前小节高亮显示
   - 自动滚动到当前播放位置
   - 时间码实时更新（分:秒）

#### 第五步：保存与加载档案
1. **保存当前分析**：
   - 点击左侧"保存当前分析"按钮
   - 数据保存到浏览器本地存储（localStorage）
   - 最多保存 20 条记录

2. **加载已有档案**：
   - 在"练习档案"列表中点击 📂 图标加载
   - 点击 🗑️ 图标删除（需确认）

#### 第六步：导出功能
三种导出格式：

1. **Markdown讲评**：
   - 完整的练习报告
   - 包含：基本信息、总体评分、错误统计、节奏统计、详细错误、练习建议
   - 格式：`.md`，可直接用 Markdown 编辑器打开

2. **错误明细 CSV**：
   - 所有错误的表格形式
   - 列：小节、错误类型、音高、音符名称、严重程度、消息、扣分、期望时间、实际时间、偏差(ms)、期望力度、实际力度、期望时值、实际时值
   - 可导入 Excel 或 Google Sheets 进一步分析

3. **JSON审计包**：
   - 完整数据备份
   - 包含：乐谱数据、演奏数据、对齐结果、分析结果
   - 可用于后续导入或程序处理

## 📊 数据格式

### 目标乐谱 JSON 格式

```json
{
  "title": "C大调音阶与和弦练习",
  "composer": "练习曲",
  "timeSignature": "4/4",
  "tempo": 120,
  "measures": [
    {
      "number": 1,
      "timeSignature": "4/4",
      "tempo": 120,
      "notes": [
        {
          "pitch": 60,
          "noteName": "C4",
          "velocity": 64,
          "startTime": 0.00,
          "duration": 0.5,
          "isSlurred": true,
          "slurGroup": 1
        }
      ],
      "pedalEvents": [
        {
          "type": "damper",
          "time": 0.0,
          "value": 64,
          "isPressed": true
        }
      ]
    }
  ]
}
```

#### 音符字段说明
| 字段 | 类型 | 说明 |
|------|------|------|
| pitch | number | MIDI音高编号（C4=60） |
| noteName | string | 音符名称（如 "C4", "F#5"） |
| velocity | number | 力度值（0-127） |
| startTime | number | 开始时间（秒，相对于小节开始） |
| duration | number | 持续时间（秒） |
| isSlurred | boolean | 是否有连音线 |
| slurGroup | number | 连音组编号（同一组表示同一条连音线） |

#### 踏板事件字段
| 字段 | 类型 | 说明 |
|------|------|------|
| type | string | 踏板类型："damper"（延音踏板） |
| time | number | 时间（秒） |
| value | number | 踏板值（0-127，0为抬起，>0为踩下） |
| isPressed | boolean | 是否踩下 |

### 演奏记录 CSV 格式

```csv
time,type,pitch,velocity,duration,noteName
0.02,note,60,62,0.48,C4
0.51,note,62,60,0.52,D4
1.02,note,64,65,0.48,E4
```

#### 字段说明
| 列名 | 说明 |
|------|------|
| time | 事件发生时间（秒，从开始计算） |
| type | 事件类型："note"（音符事件） |
| pitch | MIDI音高编号 |
| velocity | 力度值（0-127） |
| duration | 持续时间（秒） |
| noteName | 音符名称 |

## 🔧 核心模块说明

### 1. Parser (解析器)
**位置**: `js/parser.js`

**职责**:
- 解析目标乐谱 JSON 文件
- 解析演奏记录 CSV 文件
- MIDI音高与音符名相互转换
- 拍号解析（如 "4/4" → 4拍每小节）

**关键方法**:
- `parseScoreJSON(jsonString)`: 解析 JSON 乐谱
- `parsePerformanceCSV(csvString)`: 解析 CSV 演奏记录
- `midiToNoteName(midiNote)`: MIDI编号转音符名
- `noteNameToMidi(noteName)`: 音符名转MIDI编号

### 2. Aligner (对齐算法)
**位置**: `js/aligner.js`

**职责**:
- 将演奏音符与目标乐谱按时间对齐
- 识别匹配的音符、漏音、额外音
- 检测连音断裂

**核心算法**:
- **时序容差**: 默认 0.15 秒（150ms）
- **最佳匹配**: 对每个目标音，寻找音高相同且时间最接近的演奏音
- **连音分析**: 检测同一连音组内音符之间是否有间隔

**配置项**:
```javascript
timingTolerance: 0.15,  // 时间容差（秒）
```

### 3. Scorer (评分规则)
**位置**: `js/scorer.js`

**职责**:
- 根据对齐结果计算分数
- 识别各类错误类型
- 分配错误严重程度

**错误类型与权重**:

| 错误类型 | 权重(扣分) | 触发条件 |
|----------|-----------|----------|
| 漏音 | 30 | 目标音没有匹配的演奏音 |
| 错音 | 25 | 演奏音不在乐谱中 |
| 严重节奏 | 20 | 偏差 > 300ms |
| 轻微节奏 | 5 | 偏差 150-300ms |
| 力度问题 | 3 | 力度偏差 > 15 |
| 时值问题 | 5 | 时值偏差 > 30% |
| 连音断裂 | 15 | 连音间隔 > 50ms |

**评分等级**:
- A: 90-100 分（优秀）
- B: 80-89 分（良好）
- C: 70-79 分（中等）
- D: 60-69 分（及格）
- F: <60 分（需努力）

### 4. Player (播放器)
**位置**: `js/player.js`

**职责**:
- 使用 Web Audio API 生成音频
- 管理播放状态（播放/暂停/停止/跳转）
- 支持变速播放
- 同步高亮显示

**音频特性**:
- **目标音**: 正弦波 (Sine)，频率 2000Hz 低通
- **演奏音**: 三角波 (Triangle)，频率 1500Hz 低通
- **音量**: 目标音 0.2，演奏音 0.3（归一化后）
- **包络**: Attack 20ms, Decay 100ms, Sustain 70%, Release 200ms

### 5. Storage (存储)
**位置**: `js/storage.js`

**职责**:
- 使用 localStorage 持久化存储
- 最多保存 20 条记录（超出自动删除最早的）
- 提供增删改查接口

**存储内容**:
- 乐谱数据
- 演奏数据
- 对齐结果
- 分析结果
- 元数据（标题、作曲家、创建时间、总分）

### 6. Exporter (导出)
**位置**: `js/exporter.js`

**职责**:
- 生成 Markdown 格式的讲评报告
- 生成 CSV 格式的错误明细表
- 生成 JSON 格式的完整数据备份
- 触发浏览器下载

### 7. UI (界面)
**位置**: `js/ui.js`

**职责**:
- DOM元素缓存与事件绑定
- 谱架可视化渲染
- 错误高亮显示
- 小节详情面板
- 消息提示

## ❓ 常见问题

### Q: 为什么需要本地服务器？
A: 直接打开 `index.html` 可能会遇到浏览器安全限制（如 CORS 策略）。使用本地服务器可以确保所有功能正常工作。

### Q: 数据保存在哪里？
A: 数据保存在浏览器的 localStorage 中，不会上传到服务器。清除浏览器数据会同时删除存档。

### Q: 如何获取 MIDI 或 CSV 演奏数据？
A: 可以通过以下方式：
1. 使用 MIDI 键盘录制软件导出
2. 使用浏览器虚拟键盘（如 WebMIDI 项目）
3. 从音乐制作软件（如 Ableton, Logic）导出

### Q: 支持的浏览器？
A: 推荐使用：
- Chrome / Edge（最新版）
- Firefox（最新版）
- Safari（最新版）

### Q: 如何修改评分权重？
A: 编辑 `js/scorer.js` 中的 `config.weights` 对象：

```javascript
this.config = {
    weights: {
        missed: 30,      // 漏音
        wrongPitch: 25,   // 错音
        timingSevere: 20, // 严重节奏
        timingMild: 5,    // 轻微节奏
        velocity: 3,      // 力度
        duration: 5,      // 时值
        slurBreak: 15     // 连音断裂
    }
};
```
