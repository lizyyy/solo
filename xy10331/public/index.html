📖 使用说明

第一步：准备装备套装

在「装备套装」页面添加您的装备套装，每个套装包含多个装备物品，每个物品设置押金和租赁费用。

示例：基础露营套装

  • 帐篷 1顶 - 押金300元，租赁费50元/天
  • 睡袋 2个 - 押金100元/个，租赁费20元/个/天
  • 炉头 1个 - 押金80元，租赁费10元/天
  • 防潮垫 2个 - 押金50元/个，租赁费5元/个/天

第二步：创建租赁订单

在「创建订单」页面：

  1. 填写客户姓名和电话
  2. 选择装备套装
  3. 设置租赁天数或起止日期
  4. 输入实际支付的押金金额
  5. 系统会自动计算：租赁费、应交押金、押金状态
💡 押金不足处理：如果客户支付的押金低于应交押金，系统会标记为「押金不足」，您可以后续在订单详情中让客户补交押金。

第三步：归还验收

在「订单管理」页面找到需要归还的订单，点击「归还验收」按钮：

  1. 系统会显示该订单的所有装备明细
  2. 对每件装备勾选「已归还」
  3. 如有需要清洗的，勾选「需要清洗」并设置清洗费（默认20元）
  4. 如有损坏，勾选「已损坏」，填写损坏描述并设置赔偿金额
  5. 可以手动添加其他费用
  6. 系统会自动预览扣费明细和退还金额

第四步：结算完成

点击「确认归还」后：

  • 系统计算最终退还金额：实际押金 - 租赁费 - 各项扣费
  • 订单状态更新为「已完成」（全部归还）或「部分归还」
  • 装备库存自动恢复
  • 所有扣费记录保存在历史中

📋 样例场景

样例1：完整归还

场景：客户按时归还所有装备，无损坏无清洗需求

操作：在归还验收时，将所有装备标记为「已归还」，不勾选清洗或损坏

结果：只扣除租赁费，其余押金退还

样例2：少还一个炉头

场景：客户归还时发现炉头不见了

操作：在归还验收时，炉头不勾选「已归还」，其他装备正常归还

结果：系统自动标记为「部分归还」，炉头按押金全额扣除（遗失赔偿）

后续：如果客户后续找到炉头，可以在「部分归还」状态的订单中再次点击「归还验收」完成剩余归还

样例3：睡袋需清洗

场景：客户归还的睡袋有污渍需要清洗

操作：在归还验收时，勾选睡袋的「需要清洗」选项，设置清洗费20元

结果：扣除租赁费 + 20元清洗费

样例4：押金不足

场景：客户只带了部分押金，承诺后续补交

操作：创建订单时，在「实际支付押金」中输入客户实际支付的金额

结果：订单状态为「已借出」，但标记「押金不足」，后续可在订单详情中让客户补交

🔄 批量导入订单

如果需要批量创建订单，可以使用 Excel 导入功能：

  1. 准备 Excel 文件，包含以下列：客户姓名、联系电话、装备套装、租赁天数、实际押金、开始日期、结束日期
  2. 在「创建订单」页面点击「批量导入」
  3. 上传文件后，系统会逐行处理
  4. 结果会分开显示：全部成功、部分成功（如库存不足）、全部失败
✓ 容错机制：坏数据不会影响好数据，每行独立处理，失败的行会显示具体原因。

📊 对账导出

在「历史与对账」页面可以：

  • 查看所有历史订单及其扣费明细
  • 按日期范围筛选
  • 导出 Excel 对账单，包含所有订单和扣费记录
