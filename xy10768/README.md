# ETL任务回放台

用于ETL批次数据校验、脏数据拦截与任务重放管理的轻量级系统。

## 功能特性

### 核心功能
- ✅ **批次管理**：上传、查看、删除ETL批次数据
- ✅ **数据校验**：自动检测脏数据（空值、类型错误、负值异常等）
- ✅ **重放范围拦截**：脏数据区域自动拦截，避免错误扩散
- ✅ **任务重放**：指定范围和节点进行任务重放
- ✅ **失败节点追踪**：记录每个节点的失败信息和次数
- ✅ **校验摘要**：可视化展示数据质量统计

### 前端功能
- 🔍 搜索框支持按批次ID、负责人、状态筛选
- ⚠️ 权限提示横幅展示当前用户权限范围
- 📊 统计面板展示批次概览数据
- 📋 批次详情弹窗
- 🔄 任务重放表单

### 导出功能
- 📊 Excel格式报告导出
- 👥 按负责人分组统计
- 📅 按时间排序的批次记录
- ❌ 按失败节点分类汇总
- 📈 校验摘要和重放日志

## 技术栈

- **后端**：FastAPI + Python 3.8+
- **数据库**：SQLite（轻量级，无需额外安装）
- **前端**：原生HTML/CSS/JavaScript
- **导出**：Pandas + OpenPyXL

打开浏览器访问：http://localhost:8000

## API接口

### 批次管理
- `GET /api/batches` - 获取批次列表
- `GET /api/batches/{batch_id}` - 获取批次详情
- `POST /api/batches` - 创建新批次
- `DELETE /api/batches/{batch_id}` - 删除批次

### 数据校验
- `POST /api/validation` - 执行批次数据校验
- `GET /api/validation/{batch_id}` - 获取校验结果

### 任务重放
- `POST /api/replay` - 执行任务重放
- `GET /api/replay/check/{batch_id}` - 检查重放可行性

### 日志查询
- `GET /api/logs/replay` - 获取重放日志
- `GET /api/logs/failed-nodes` - 获取失败节点列表
- `GET /api/logs/statistics` - 获取统计数据

### 导出功能
- `GET /api/export/report` - 导出综合报告
- `GET /api/export/detailed/{batch_id}` - 导出批次详情

## 使用流程示例

### 1. 数据校验拦截演示
1. 点击批次 `BATCH-2024-001` 的【校验】按钮
2. 系统自动检测脏数据并标记为「失败」状态
3. 查看【详情】可以看到：
   - 校验摘要：总记录数、脏数据数、占比
   - 具体错误列表
   - 重放拦截区域（含起始/结束记录和拦截原因）

### 2. 重放范围拦截演示
1. 在批次详情页点击【重放】按钮
2. 系统自动检测拦截区域并显示警告横幅
3. 尝试设置重放范围包含拦截区域（如起始=2，结束=5）
4. 系统拒绝重放，提示：「重放范围包含被拦截的脏数据区域」
5. 调整重放范围避开拦截区域后可以正常重放

### 3. 导出报告演示
1. 在主页面点击【导出报告】按钮
2. 下载Excel文件，包含以下工作表：
   - **批次概览**：所有批次的基本信息
   - **按负责人统计**：按负责人分组的失败情况
   - **按失败节点统计**：按节点分类的失败次数
   - **重放日志**：所有重放操作记录
   - **统计摘要**：关键指标汇总

## 数据校验规则

| 规则类型 | 检查内容 |
|---------|---------|
| 空值检查 | 字段值为None或空字符串 |
| 类型检查 | 数值字段包含非数字字符串 |
| 负值检查 | 数值字段包含负数（业务不允许） |
