## 1. 产品概述

声学降噪材料筛选工具面向录音棚装修前的声学顾问，用于在低/中/高频段下对比不同材料的吸声效果，结合频段加权、材料组合模拟、预算约束与缺口识别，输出可追溯的筛选报告。
- 解决声学顾问在材料样本不完整、系数越界、预算超限等场景下手动对比困难、易遗漏风险的问题
- 目标用户：录音棚声学顾问、装修项目经理，价值在于将散乱的样本数据转化为可解释、可追溯的筛选决策

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 声学顾问 | 无需注册，直接使用 | 录入材料、配置加权、执行筛选、导出报告 |

### 2.2 功能模块

1. **材料数据库页**：材料录入与编辑、频段吸声系数表格、数据验证与缺口识别、材料卡片总览
2. **筛选分析页**：频段加权配置、预算与房间约束、材料组合模拟、综合评分排序、缺口与越界提示
3. **对比报告页**：雷达图/柱状图对比、评分明细回溯、报告预览与导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 材料数据库页 | 材料录入表单 | 录入材料名称、类型、单价、频段吸声系数（125Hz/250Hz/500Hz/1kHz/2kHz/4kHz），实时校验系数范围0~1，越界红色高亮并提示 |
| 材料数据库页 | 材料卡片列表 | 卡片展示各材料概要：名称、类型、低/中/高频平均系数、单价，缺失频段黄色警告标记 |
| 材料数据库页 | 缺口识别面板 | 汇总所有材料的数据缺口：哪些频段缺样、哪些系数越界、哪些必填项为空，支持一键定位到对应材料编辑 |
| 筛选分析页 | 频段加权配置 | 滑块设置低频(125/250Hz)、中频(500/1kHz)、高频(2/4kHz)权重，实时更新评分 |
| 筛选分析页 | 预算与房间约束 | 输入房间尺寸（长宽高）、总预算上限，自动计算墙面/天花板面积与材料用量 |
| 筛选分析页 | 材料组合模拟 | 选择多种材料组合使用，系统计算组合后的综合吸声系数（按面积加权），展示组合评分 |
| 筛选分析页 | 综合评分排序 | 按加权评分排序材料/组合，标注预算超限（红色）、低频缺样（黄色）、系数越界（红色）等异常 |
| 筛选分析页 | 异常提示条 | 顶部横幅展示当前筛选结果中的异常统计：X个系数越界、Y个低频缺样、Z个预算超限 |
| 对比报告页 | 雷达图对比 | 6频段吸声系数雷达图，支持勾选2~5种材料叠加对比，悬停显示具体数值 |
| 对比报告页 | 柱状图对比 | 低/中/高频加权得分柱状图，点击柱子跳转至评分明细面板 |
| 对比报告页 | 评分明细面板 | 点击图表元素后展示该材料/组合的评分推导：各频段原始系数→加权值→总评分，解释"为什么是这个结果" |
| 对比报告页 | 报告预览与导出 | 生成结构化筛选报告（含材料列表、频段系数、加权评分、异常标注、推荐方案），支持导出为PDF/JSON |

## 3. 核心流程

用户录入材料样本数据 → 系统实时校验并识别缺口（系数越界/频段缺样/必填缺失）→ 用户配置频段加权与预算约束 → 系统计算综合评分并排序 → 用户选择材料组合进行模拟 → 系统计算组合吸声效果与预算 → 用户在图表中对比材料 → 点击图表元素回溯评分明细 → 导出筛选报告

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深墨绿(#1a2f2a) + 暖琥珀(#e8a838)作为强调色，呼应录音棚深色控台氛围
- 辅助色：中灰绿(#3d5c52)用于卡片背景，浅沙色(#f5f0e8)用于文本区域
- 按钮风格：圆角微凸(3px)，深色按钮带琥珀色边框hover效果
- 字体：标题用 DM Serif Display（编辑感），正文用 Source Sans 3（清晰可读），数据用 JetBrains Mono（等宽数字对齐）
- 布局风格：左侧窄导航栏 + 右侧内容区，卡片式布局，顶部状态条
- 图标风格：线性图标，2px描边，琥珀色点缀

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 材料数据库页 | 材料录入表单 | 深色表单区域，6个频段输入框横排，系数越界时输入框红框+抖动动画，底部"添加材料"琥珀色按钮 |
| 材料数据库页 | 材料卡片列表 | 3列网格卡片，卡片顶部色条标识材料类型（吸声板-绿/吸声棉-蓝/扩散体-橙），缺失频段黄色角标 |
| 材料数据库页 | 缺口识别面板 | 右侧抽屉式面板，按异常类型分组列表，每条可点击跳转到对应材料编辑区 |
| 筛选分析页 | 频段加权配置 | 3个垂直滑块（低/中/高频），滑块轨道渐变色（低频暖色→高频冷色），右侧实时预览加权得分 |
| 筛选分析页 | 预算与房间约束 | 顶部横向输入组（长/宽/高/预算），预算超限时数字变红+图标警告 |
| 筛选分析页 | 材料组合模拟 | 拖拽式组合区，从左侧材料列表拖入右侧组合槽，下方实时显示组合效果预览 |
| 筛选分析页 | 综合评分排序 | 排序列表行，评分用渐变进度条表示，异常标签红色/黄色，行hover展开简要明细 |
| 筛选分析页 | 异常提示条 | 顶部固定横幅，琥珀色背景，分三段显示越界/缺样/超限数量，可折叠 |
| 对比报告页 | 雷达图对比 | 深色背景雷达图，多材料叠加用不同颜色线条，悬停显示系数值tooltip |
| 对比报告页 | 柱状图对比 | 分组柱状图（低/中/高频），点击柱子高亮并触发右侧明细面板 |
| 对比报告页 | 评分明细面板 | 右侧滑出面板，展示评分推导树：频段原始值→权重→加权值→汇总，琥珀色连线 |
| 对比报告页 | 报告预览与导出 | 底部工具栏，预览按钮打开模态框，导出按钮（PDF/JSON）带下载动画 |

### 4.3 响应式

- 桌面优先（1440px+），3列卡片网格
- 平板（768-1440px），2列卡片，图表自适应缩放
- 手机（<768px），单列堆叠，导航栏折叠为汉堡菜单

不适用
