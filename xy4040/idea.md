## 原始点子

我想做一个给纪录片外拍助理用的本地命令行工具，叫“素材回卡守门员”。拍摄回酒店后会把多张 SD 卡里的视频、音频和字幕边车文件拷到移动硬盘，最怕漏拷一段、卡号混淆、文件名重复覆盖、时间码错位，第二天才发现补不了。请从 0 到 1 做一个可运行的 Python CLI 项目：scan 命令能扫描一个或多个卡目录，识别相机素材、录音文件、代理文件和 .srt/.json 边车，读取文件大小、修改时间、可用的 timecode/拍摄日期元数据（读不到也要有降级策略），写入本地 manifest.json；plan 命令根据项目配置生成拷贝计划，按拍摄日/机位/卡号归档，发现重复文件名、同名不同内容、缺失边车、音视频时间窗没有对应、卡内序号断档、目标盘剩余空间不足时要给出阻断或警告；copy 命令按计划执行可续传拷贝，使用哈希校验，不允许覆盖未确认的不同内容，支持 dry-run 和 resume；verify 命令能重新扫描目标目录并比对 manifest，输出漏拷、校验失败和多余文件；report 命令导出 Markdown 交接报告和 CSV 问题清单。配置、文件扫描、元数据适配、规则校验、拷贝执行、manifest 存储、报告生成和 CLI 入口请拆成多个文件，提供示例素材目录生成脚本和测试/自检命令，README 里写清楚怎么用临时目录完整验证 scan、plan、copy、resume、verify、report 流程。
