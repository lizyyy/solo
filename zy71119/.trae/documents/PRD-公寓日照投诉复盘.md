# 公寓日照投诉复盘系统 PRD

## 1. 产品概述

公寓日照投诉复盘系统是一个基于WebGL的交互式3D可视化工具，用于物业管理人员分析和解释低楼层住户的日照遮挡问题。系统通过3D楼栋模型、太阳轨迹动画和实时遮挡计算，帮助工作人员直观展示特定日期和时段内的日照遮挡来源，为投诉处理提供可视化依据。

- **核心价值**：将抽象的日照问题转化为直观的3D交互场景，提高投诉处理效率和业主满意度
- **目标用户**：物业管理人员、客服人员、业主沟通专员

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 物业管理员 | 无需登录（本地应用） | 导入样例、操作3D场景、导出报告 |

### 2.2 功能模块

1. **主场景页面**：3D楼栋可视化、太阳轨迹动画、窗户高亮、遮挡展示
2. **控制面板**：日期选择、时段控制、窗户筛选、视角切换
3. **统计面板**：遮挡时长统计、遮挡来源分析、日照报告生成
4. **报告导出**：PDF格式报告，包含截图、数据统计、分析结论

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主场景页 | 3D视窗 | 展示楼栋模型、太阳位置、窗户状态、遮挡阴影 |
| 主场景页 | 顶部工具栏 | 导入样例、重置状态、切换视角、导出报告 |
| 主场景页 | 左侧控制面板 | 日期选择器、节气快速切换、时间轴滑块 |
| 主场景页 | 右侧统计面板 | 遮挡时长图表、遮挡来源列表、窗户筛选器 |

## 3. 核心流程

### 3.1 日照分析流程

用户进入系统 → 导入样例数据 → 选择投诉日期 → 调整时间轴查看太阳位置 → 筛选被投诉窗户 → 观察遮挡来源楼栋 → 查看遮挡时长统计 → 导出日照分析报告

```mermaid

    A["进入系统"] --> B["导入样例数据"]
    B --> C["选择投诉日期"]
    C --> D["调整时间轴"]
    D --> E["筛选目标窗户"]
    E --> F["观察遮挡楼栋"]
    F --> G["查看遮挡统计"]
    G --> H["导出分析报告"]
```

### 3.2 常见错误提示

系统针对以下常见操作错误提供即时反馈：
- 窗户朝向配置错误
- 节气切换时数据未更新
- 遮挡时长统计异常

## 4. 用户界面设计

### 4.1 设计风格

**专业数据可视化风格**
- **主色调**：深邃蓝色系 (#0F172A, #1E40AF) - 代表专业、科技感
- **辅助色**：琥珀色 (#F59E0B) - 用于高亮太阳和日照区域
- **警示色**：红色 (#EF4444) - 用于标记遮挡区域
- **按钮风格**：圆角矩形 (8px)，轻微悬浮效果，带图标
- **字体**：Geist Sans (现代无衬线) + JetBrains Mono (数据展示)
- **布局风格**：三栏布局，中心3D场景为主，两侧控制面板采用半透明毛玻璃效果
- **图标风格**：线性简洁图标，统一24px尺寸

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主场景页 | 3D视窗 | 全屏幕Canvas，楼栋采用白模+边线，窗户用颜色编码，太阳用发光球体 |
| 主场景页 | 顶部工具栏 | 深色半透明条，按钮横向排列，hover时高亮 |
| 主场景页 | 左侧控制面板 | 垂直布局，分组折叠面板，时间轴带刻度 |
| 主场景页 | 右侧统计面板 | 卡片式布局，迷你条形图，数据表格 |

### 4.3 响应式设计

- **桌面端 (≥1200px)**：三栏布局，左右面板固定宽度，中间场景自适应
- **平板端 (768-1199px)**：左右面板可折叠收起，通过侧边按钮展开
- **窄屏/移动端 (<768px)**：单栏流式布局，控制面板改为底部抽屉式，3D场景占满上部区域
- **触控优化**：按钮最小尺寸48px，支持双指缩放和旋转

### 4.4 3D场景设计

- **环境/氛围**：纯色渐变天空，日间/黄昏动态切换，柔和环境光
- **光照设置**：主光源模拟太阳位置随时间变化，环境光补充阴影细节
- **相机设置**：默认正交视角，支持环绕、平移、缩放，预设多个查看角度
- **构图与焦点**：被选中窗户采用发光边框高亮，遮挡楼栋使用半透明红色遮罩
- **交互与动画**：太阳移动平滑动画，窗户选中缩放效果，时间轴 scrub 实时响应
- **后处理效果**：轻微泛光（太阳），屏幕空间环境光遮蔽，FXAA抗锯齿
- **资产来源与性能**：程序化生成楼栋模型，单帧渲染目标60fps，面数控制在5万以内

### 4.5 布局约束保障

- 使用CSS Grid和Flexbox进行精确布局控制
- 3D Canvas采用fixed定位，z-index层级严格管理
- 控制面板使用`pointer-events: auto`，确保交互不被遮挡
- 响应式断点处重新计算布局容器尺寸
