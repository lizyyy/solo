# 🐄 奶牛场早班检测工具

一个给小奶牛场场长在早班挤奶后使用的本地 AI 小工具，帮助检测异常并生成交班单。

## 功能特点

### 数据导入
- 🥛 **挤奶机产奶量 CSV** - 包含牛号、日期、产奶量、奶罐号、真空泵压力等
- 🔬 **体细胞检测表** - 包含牛号、日期、体细胞计数、检测类型
- 📋 **牛群分栏表** - 包含牛号、分栏、备注
- 📝 **兽医备注** - 包含牛号、日期、备注

### 异常检测
- 🤒 **疑似乳房炎检测** - 基于体细胞计数过高和产奶量骤降
- 🔧 **真空泵异常** - 检测压力是否在正常范围 (40-50 kPa)
- ⚠️ **混奶风险** - 检测高体细胞牛只是否与其他牛混装在同一奶罐
- 📊 **需要复检** - 体细胞计数处于临界范围的牛只

### 数据展示
- 🐄 **按牛号查看** - 查看每头牛的检测结果和详细记录
- 🥛 **按奶罐查看** - 按奶罐分组展示，识别混奶风险
- 🔍 **筛选功能** - 按检测类型、严重程度、状态筛选
- 🔎 **搜索功能** - 按牛号快速搜索

### 人工改判与备注
- ✅ **确认异常** - 人工确认检测结果
- ❌ **驳回** - 认为是误报可驳回
- 📝 **备注** - 记录人工检查的详细情况
- 💾 **数据持久化** - 刷新页面或重启服务后数据不丢失

### 导出功能
- 📄 **导出 Markdown 交班单** - 打印或电子存档
- 📋 **导出 JSON 明细** - 用于数据分析

## 快速开始

### 1. 环境准备

确保你的电脑已安装 Python 3.8 或更高版本。

```bash
python3 --version
```

### 2. 安装依赖

```bash
cd 奶牛场检测工具
pip3 install -r requirements.txt
```

### 3. 启动服务

```bash
python3 app.py
```

服务启动后会显示：
```
 * Running on http://127.0.0.1:5000
 * Running on http://192.168.1.x:5000
```

### 4. 打开浏览器

访问 http://localhost:5000

## 使用示例

### 1. 使用示例数据测试

`sample_data/` 目录下提供了示例数据，包含：
- `milk_records.csv` - 产奶量记录（包含异常数据）
- `somatic_records.csv` - 体细胞检测记录
- `cow_groups.csv` - 牛群分栏表
- `vet_notes.csv` - 兽医备注

**示例数据中预设的异常：**
1. **A001** - 体细胞 120万（严重）+ 产奶量从27kg骤降到15kg
2. **A004** - 体细胞 55万（临界）+ 建议复检
3. **A006** - 体细胞 45万（临界）+ 建议复检
4. **A003** - 真空泵压力 35.5kPa（过低）
5. **A005** - 真空泵压力 55kPa（过高）
6. **奶罐 T01** - 包含 A001（高体细胞）与其他牛混装

### 2. 操作流程

1. **导入数据** - 依次导入四个 CSV 文件
2. **运行检测** - 点击"运行异常检测"按钮
3. **查看结果** - 查看按牛号或按奶罐展示的检测结果
4. **查看详情** - 点击"查看牛只详情"了解更多信息
5. **人工改判** - 对每条记录选择"确认异常"或"驳回"，添加备注
6. **导出** - 导出交班单和明细数据

## 检测规则说明

### 疑似乳房炎

检测条件（满足任一即触发）：
1. **体细胞计数过高**：
   - 严重：>= 1,000,000 个/mL
   - 警告：>= 400,000 个/mL

2. **产奶量骤降**：
   - 比前一次下降 >= 30%

### 真空泵异常

检测条件：
- 压力 < 40 kPa（过低）
- 压力 > 50 kPa（过高）

正常范围：40-50 kPa

### 混奶风险

检测条件：
- 同一奶罐中同时包含高体细胞牛（>= 400,000）和其他牛

### 需要复检

检测条件：
- 体细胞计数在 400,000 - 1,000,000 之间（临界范围）

## 注意事项

1. **数据安全**：所有数据存储在本地 `cow.db` 文件中，不会上传到任何服务器
2. **备份数据**：定期备份 `cow.db` 文件，防止数据丢失
3. **本地服务**：关闭终端或按 Ctrl+C 会停止服务，需要重新运行 `python app.py`
4. **浏览器兼容**：建议使用 Chrome、Firefox、Safari 等现代浏览器

## 常见问题

### Q: 页面打不开？
A: 确保服务已启动（运行 `python app.py`），并检查终端显示的端口号（默认 5000）

### Q: 导入数据失败？
A: 检查 CSV 文件格式是否正确，确保列名与说明一致，并且文件没有被其他程序占用

### Q: 数据丢失了？
A: 确保没有删除 `cow.db` 文件，这个文件存储了所有数据。建议定期备份。

### Q: 如何修改检测阈值？
A: 可以在 `app.py` 中找到 `AnomalyDetector` 类，修改以下参数：
- `somatic_threshold_high` = 400000（体细胞警告阈值）
- `somatic_threshold_critical` = 1000000（体细胞严重阈值）
- `yield_drop_threshold` = 0.3（产奶量骤降比例）
- `pump_normal_min/max`（真空泵正常范围）
