## 1. 产品概述

吉他弦张力计算 3D 工作台——为吉他维修师设计的弦张力估算与琴颈安全校验工具。通过弦长、目标音高、线密度等参数实时计算单弦张力与总张力，在3D可旋转琴颈模型上直观呈现受力状态，并在频率错八度、线密度单位错误、总张力超限时主动发出异常提示，支持调弦方式对比和报告导出。

- 目标用户：吉他维修师、制琴师、弦乐调音师
- 核心价值：避免琴颈受力过大导致永久变形，防止参数录入错误导致的危险结论

## 2. 核心功能

### 2.1 功能模块

1. **3D 工作台页面**：3D可旋转琴颈模型 + 弦参数录入面板 + 张力实时计算 + 异常提示 + 调弦对比 + 报告导出

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 3D 工作台 | 3D 琴颈可视化 | 可旋转、可缩放的3D吉他琴颈模型，6根弦用颜色和粗细区分，张力大小映射到弦的视觉粗细和发光强度，超限弦段标红闪烁 |
| 3D 工作台 | 弦参数录入面板 | 6行数据录入（弦序号、弦长mm、目标音高、频率Hz、线密度g/m、弦径mm），实时联动3D模型和计算结果，保留原始输入值用于排错 |
| 3D 工作台 | 张力计算结果 | 单弦张力(N)、总张力(N)、张力百分比（单弦/总张力），公式 T=4μL²f² 可展开查看推导过程 |
| 3D 工作台 | 异常检测提示 | 三类异常：①频率错八度（如E4录成E3/E5）②线密度单位疑似错误（g/m vs kg/m vs lb/in）③总张力超限（>800N警告，>1000N危险） |
| 3D 工作台 | 调弦方式对比 | 预设标准调弦(EADGBE)、Drop D、DADGAD、Open G、Open D等，一键切换对比总张力和单弦变化，显示差异百分比 |
| 3D 工作台 | 数据筛选 | 按弦序号、张力范围、异常状态筛选，筛选结果同步高亮3D模型对应弦 |
| 3D 工作台 | 报告导出 | 导出CSV格式报告，包含原始输入值、计算结果、异常标记、时间戳 |

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深胡桃木色(#3E2723)搭配暖琥珀色(#FFA000)强调色，呼应吉他木纹质感
- 辅助色：琴钢色(#90A4AE)、危险红(#EF5350)、安全绿(#66BB6A)
- 按钮风格：圆角微凸起，木质纹理底色
- 字体：标题使用衬线体表现古典乐器质感，数据区使用等宽字体保证数字对齐
- 布局：左侧3D场景占60%，右侧面板占40%（参数录入+结果+提示），底部调弦对比栏

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 3D 工作台 | 3D 琴颈可视化 | 深色背景，Three.js场景，OrbitControls旋转缩放，6弦颜色编码(低音弦暖色→高音弦冷色)，张力映射弦粗细，超限弦红色脉冲 |
| 3D 工作台 | 弦参数录入面板 | 6行x6列输入表格，等宽数字字体，异常单元格橙色/红色边框，hover显示单位说明 |
| 3D 工作台 | 张力计算结果 | 右侧卡片，大字显示总张力，下方6行单弦结果，展开可看公式推导 |
| 3D 工作台 | 异常提示 | 右上角Toast通知+3D模型叠加标记，三级：警告(橙)、危险(红)、信息(蓝) |
| 3D 工作台 | 调弦对比 | 底部水平滑动栏，调弦预设按钮组，切换后3D模型过渡动画 |
| 3D 工作台 | 报告导出 | 右下角导出按钮，点击生成CSV下载 |

### 4.3 响应式设计

- 桌面优先：1920x1080最佳体验
- 平板适配：3D场景和面板上下排列
- 手机端：隐藏3D场景，仅展示数据面板（降级方案）

### 4.4 3D 场景指引

- 环境：暗室HDRI，温暖侧光打在琴颈上，营造工坊氛围
- 灯光：主光暖色(0xFFF3E0)从左上方照射，补光冷色(0xE3F2FD)从右侧微弱补充
- 相机：默认45度俯视角，OrbitControls自由旋转，限制仰角避免穿模
- 焦点元素：6根弦的张力可视化是核心视觉焦点
- 交互：鼠标拖拽旋转、滚轮缩放、点击弦高亮对应数据行
- 后处理：轻微泛光(Bloom)效果让高张力弦发光，增加视觉冲击力
