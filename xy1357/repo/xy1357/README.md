# 🎂 烘焙工作室预订排产小助手

一个专为小型烘焙工作室设计的订单管理和排产系统，帮助店主解决手抄订单容易漏掉原料和取货时间的问题。

## ✨ 核心功能

### 📋 订单管理
- 新增、编辑、删除订单
- 5种订单状态：待确认、已确认、制作中、已完成、已取消
- 取消订单后自动释放原料占用
- 按状态筛选订单

### 📅 排产清单
- 按取货日期和时段自动分组订单
- 生成时间线视图，直观展示当天生产任务
- 实时计算并标出原料缺口
- 一键导出CSV

### 📦 原料库存管理
- 维护原料基础信息（名称、单位、当前库存、安全库存）
- 按日期自动计算该日所有有效订单的原料总需求量
- 计算剩余库存并标出：
  - ❌ 缺口（库存不足）
  - ⚠️ 低于安全线
  - ✅ 正常

### 🍰 商品配方管理
- 维护商品信息和配方
- 每个商品配置消耗的原料及用量
- 修改配方后，所有相关排产和缺口自动重新计算

### 📥 CSV导入导出
- **导入功能（带详细校验）**：
  - 支持拖拽或点击上传CSV文件
  - 先校验再导入，不会一报错就整批静默失败
  - 校验内容包括：
    - 缺字段提示（客户姓名、取货日期、取货时间、商品名称、数量）
    - 未知商品提示
    - 数量必须是正整数
    - 取货日期格式错误
    - 取货时间格式错误
  - 页面逐行显示错误信息，标红显示
  - 同一客户同一取货时间的多行商品自动合并为一个订单

- **导出功能**：
  - 导出指定日期的排产清单为CSV
  - 包含订单号、客户、商品、状态、备注等完整信息

### 3. 库存计算逻辑

**什么时候占用原料？**
- 订单状态为：待确认、已确认、制作中 时占用库存
- 订单状态为：已完成、已取消 时不占用库存

**什么时候重新计算？**
- 新增/修改/删除订单 → 重新计算
- 修改订单状态 → 重新计算
- 修改商品配方 → 重新计算
- 修改原料库存 → 重新计算

**计算内容：**
```
预计用量 = Σ(订单商品数量 × 该商品配方中对应原料用量)
剩余库存 = 当前库存 - 预计用量
缺口 = max(0, 预计用量 - 当前库存)
```

## 📝 CSV导入格式

| 字段名 | 说明 | 示例 |
|--------|------|------|
| 客户姓名 | 客户名称 | 张女士 |
| 取货日期 | YYYY-MM-DD 格式 | 2026-05-01 |
| 取货时间 | HH:MM 格式 | 10:30 |
| 商品名称 | 必须是系统中已有的商品 | 原味戚风蛋糕 |
| 数量 | 正整数 | 2 |

### 可选字段
| 字段名 | 说明 | 示例 |
|--------|------|------|
| 联系电话 | 客户电话 | 13800138000 |
| 单价 | 商品单价（默认为0） | 88 |
| 状态 | 订单状态 | 已确认 |
| 订单备注 | 订单级别的备注 | 需要蜡烛 |
| 商品备注 | 该行商品的备注 | 少糖 |

## 💡 常见问题

**Q: 数据存储在哪里？刷新页面会丢失吗？**
A: 数据存储在 SQLite 数据库文件 `data/bakery.db` 中，刷新页面不会丢失，重启服务也不会丢失。

**Q: 为什么取消订单后原料需求没有减少？**
A: 已取消和已完成的订单不参与原料计算。如果刚刚取消，请刷新页面或重新进入原料库存页面确认。

**Q: 如何修改订单中的商品？**
A: 在订单列表点击"编辑"按钮，可以修改订单的所有信息，包括增删商品、修改数量。保存后会自动重新计算原料需求。

**Q: CSV导入时，同一客户多个商品要怎么填？**
A: 分多行填写，每行一个商品，但客户姓名、取货日期、取货时间要相同。系统会自动将这些行合并为一个订单，包含多个商品。

**Q: 怎么知道导入的CSV格式对不对？**
A: 系统会先进行校验，逐行显示错误。只有校验通过的行才能导入。你可以故意填写一些错误数据来测试校验功能。
