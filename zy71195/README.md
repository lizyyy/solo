# 码头闸口验放游戏

一款面向港口闸口工作人员的训练模拟器，通过游戏化方式提升工作人员识别箱号、核对预约单、检查危品标记的能力。

## 🎮 游戏特性

- **真实规则**：模拟真实闸口验放流程，箱号、车牌、预约单、危品标记一一核对
- **关卡系统**：5个难度递进的关卡，从新手入门到综合考验
- **限时挑战**：每辆车有独立验放时限，锻炼高压下的判断能力
- **队列压力**：合理管理验放队列，避免拥挤扣分
- **历史回放**：完整记录每一次操作，支持回看失败原因
- **报告导出**：支持 JSON/CSV 格式导出验放报告

## 🎯 游戏玩法

### 基本操作

| 操作 | 鼠标 | 键盘快捷键 |
|------|------|------------|
| 放行 | 点击「放行」按钮 | 空格 / Enter |
| 拦截 | 点击「拦截」按钮 | Backspace / Delete |
| 暂停 | 点击「暂停」按钮 | P / Esc |
| 重开 | 点击「重开」按钮 | Ctrl + R |

### 验放规则

✅ **可以放行的条件**：
- 箱号与预约单完全一致
- 车牌与预约单完全一致
- 无危险品标记，或危险品已申报
- 预约单有效

❌ **需要拦截的情况**：
- 箱号不匹配
- 车牌不匹配
- 有危险品标记但未申报
- 预约单已失效

### 计分规则

| 操作 | 得分 |
|------|------|
| 正确放行 | +100 分 |
| 正确拦截 | +150 分 |
| 正确拦截危品 | +200 分 |
| 错误放行 | -200 分 |
| 错误拦截 | -100 分 |
| 处理超时 | -150 分 |
| 队列拥挤（每车/次） | -50 分 |

### 关卡说明

| 关卡 | 名称 | 车辆数 | 时限/车 | 危品率 | 及格分 | 说明 |
|------|------|--------|---------|--------|--------|------|
| 1 | 新手入门 | 10 | 15秒 | 10% | 500 | 熟悉基本操作，学习识别箱号和预约单匹配 |
| 2 | 节奏加快 | 15 | 12秒 | 15% | 800 | 提升反应速度，适应更快的验放节奏 |
| 3 | 危品专项 | 12 | 10秒 | 30% | 700 | 重点训练危品识别能力，提高安全意识 |
| 4 | 预约陷阱 | 15 | 10秒 | 20% | 800 | 识别各种预约信息不匹配的情况 |
| 5 | 综合考验 | 20 | 8秒 | 25% | 1000 | 高压环境下的综合能力测试 |

### 边界案例

游戏中会出现以下边界情况，考验你的识别能力：

1. **相似字符混淆**：0/O、1/I/L、2/Z、5/S、8/B 等易混淆字符
2. **预约信息差异**：箱号多一位或少一位、车牌字符差异
3. **危品标记位置**：危品标记可能出现在不同位置，需要仔细检查
4. **预约有效期**：部分预约单已过期失效
5. **队列压力**：车辆密集到达，需要快速处理避免扣分

## 🛠 技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **样式**：Tailwind CSS
- **状态管理**：Zustand
- **图标**：Lucide React
- **路由**：React Router

## 📊 数据存储

游戏数据使用浏览器 localStorage 存储：

- `gate_inspection_history`：游戏历史记录（最多保存50条）
- `gate_inspection_best_scores`：各关卡最高分
- `gate_inspection_unlocked_levels`：已解锁关卡

## 🎨 设计理念

- **工业风格**：采用港口工业风设计，深蓝色主色调，橙色警示色
- **信息优先**：信息密集型布局，模拟真实闸口操作终端
- **等宽字体**：箱号信息使用等宽字体，增强专业感和可读性
- **即时反馈**：每次操作都有明确的视觉反馈，帮助快速学习
