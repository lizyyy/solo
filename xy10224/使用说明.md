# 游泳馆泳道训练排布器 - 使用说明

## 📋 项目概述

这是一个功能完整的游泳馆泳道训练排布系统，专门解决以下核心问题：

- **泳道资源共享**：支持训练队、散客和私教课三种预约类型共用泳道资源
- **冲突检测**：自动检测同一泳道同一时段的预约冲突
- **灵活调整**：支持拖拽方式调整预约位置
- **操作追踪**：完整记录所有操作历史
- **数据导出**：支持 CSV 和 JSON 格式导出

**核心差异点**：
- 泳道长度差异（25米短道 vs 50米长道）
- 训练队与私教课混排支持

## 📖 完整使用流程

### 第一步：造数 - 加载样例数据

应用提供了两组预设样例数据，可快速体验系统功能。

#### 1.1 顺利样例（无冲突）
点击顶部 **「📋 加载顺利样例」** 按钮

**样例内容**：
- 5条泳道（3条50米长道，2条25米短道）
- 8个训练时段
- 5个预约，全部无冲突
- 包含训练队、散客、私教课三种类型

**预期结果**：
- 侧边栏显示 ✅ **当前无冲突**
- 操作历史记录"加载顺利样例数据"
- 所有预约卡片正常显示

#### 1.2 冲突样例（有冲突）
点击顶部 **「⚠️ 加载冲突样例」** 按钮

**样例内容**：
- 在顺利样例基础上增加2个预约
- 包含1个时间冲突（区业余队与市体校一队在同一泳道同时段）
- 包含1个待复核预约

**预期结果**：
- 侧边栏显示 ⚠️ **冲突检测 (1)**
- 红色高亮显示冲突预约
- 冲突面板显示详细冲突信息

### 第二步：处理 - 添加新预约

#### 2.1 快速添加
1. 点击任意空白单元格
2. 弹出预约表单
3. 选择预约类型（训练队/散客/私教课）
4. 填写必填信息
5. 点击 **「创建预约」**

**三种预约类型字段**：

| 类型 | 必填字段 | 颜色标识 |
|------|---------|---------|
| 🔵 训练队 | 队伍名称、教练、队员人数 | 蓝色 |
| 🟢 散客 | 客户姓名、电话 | 绿色 |
| 🟣 私教课 | 客户姓名、教练、电话 | 紫色 |

#### 2.2 编辑已有预约
1. 点击任意预约卡片
2. 修改表单信息
3. 点击 **「保存修改」**

#### 2.3 删除预约
1. 鼠标悬停在预约卡片上
2. 右上角出现 ✕ 删除按钮
3. 点击后确认删除

### 第三步：调整 - 拖拽功能

#### 3.1 拖拽操作
1. 点击并按住任意预约卡片
2. 拖拽到目标泳道和时段
3. 释放鼠标完成移动

**拖拽视觉反馈**：
- 拖拽中卡片半透明
- 目标位置高亮（蓝色边框）
- 操作历史记录移动详情

#### 3.2 拖拽后的自动处理
- 自动检测新位置是否有冲突
- 如有冲突自动标记为红色
- 冲突面板实时更新

### 第四步：复核 - 冲突处理

#### 4.1 查看冲突
侧边栏 **冲突检测** 面板显示：
- 冲突数量统计
- 冲突双方详细信息
- 泳道和时段位置
- 处理建议

#### 4.2 解决冲突方法

**方法1：移动预约**
- 拖拽其中一个冲突预约到其他位置

**方法2：删除预约**
- 点击预约卡片的删除按钮

**方法3：编辑预约**
- 修改预约的时段或泳道

#### 4.3 待复核预约
- 黄色边框标识
- 可编辑后可调整状态为"已确认"

### 第五步：导出 - 数据导出

#### 5.1 导出格式

**CSV 格式**：
- 点击 **「📊 导出 CSV」**
- 用 Excel 打开查看
- 包含：预约ID、泳道、时段、类型、状态、客户信息等

**JSON 格式**：
- 点击 **「📋 导出 JSON」**
- 包含完整结构化数据
- 适合备份或程序处理

#### 5.2 导出内容统计
导出面板显示实时统计：
- 泳道数量
- 时段数量
- 预约总数
- 冲突数量

## ⚠️ 注意事项

1. **泳道长度提示：系统目前不强制限制预约类型与泳道长度的匹配（如50米训练队只能安排在50米泳道），这需要根据实际业务规则配置。

2. **冲突处理策略**：当前实现检测到冲突后仅做标记，不强制阻止创建，方便人工复核调整。

3. **数据持久化**：当前为内存存储，刷新页面数据会重置。如需持久化需配合后端存储。
