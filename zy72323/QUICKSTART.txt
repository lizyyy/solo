【最快体验】

  1. 一键跑完整流程
     $ python3 run_demo.py

  2. 看课堂演示结果
     $ python3 -m dorm_allocator.cli --data-dir ./demo_data/runtime demo

  3. 打开小看板
     双击打开 demo_dashboard.html

【三条关键命令，吴老师给新人讲流程用】

  ┌─ 步骤回放 ───────────────────────────────────────┐
  │                                                   │
  │  $ bash replay_steps.sh                           │
  │                                                   │
  │  一步步展示：无批注导入 → 补批注 → 修正 → 重跑    │
  │                                                   │
  └───────────────────────────────────────────────────┘

  ┌─ 课堂演示 ───────────────────────────────────────┐
  │                                                   │
  │  $ python3 -m dorm_allocator.cli demo             │
  │                                                   │
  │  每条记录显示：                                    │
  │  • 为什么这条被留下                                │
  │  • 还缺什么材料                                    │
  │  • 下一步找谁（数据复核人 / 吴老师）               │
  │                                                   │
  └───────────────────────────────────────────────────┘

  ┌─ 复盘报告 ───────────────────────────────────────┐
  │                                                   │
  │  $ python3 -m dorm_allocator.cli report <RUN_ID>  │
  │                                                   │
  └───────────────────────────────────────────────────┘

【三个细节，你会看的】

  ✓ 分母为0保留空字符串，不自动归正常 → 留给数据复核人
  ✓ 老师批注补录后，课堂演示结果自动更新
  ✓ 完整流程可追溯，每一步操作都有记录

【三种入口】

  • 命令行: python3 -m dorm_allocator.cli --help
  • API:     python3 -m dorm_allocator.api (访问 /docs)
  • 看板:    python3 -m dorm_allocator.dashboard

【给教研负责人吴老师】

  讲流程时的话术参考：
  "你们看，第一次导入的时候，李华这条分母是0，截图里是空的。
   我们没有直接填1，为什么？因为原始数据要保留，给数据复核人看。
   后来老师批注补到群里了，吴老师我回看的时候补上，
   你看演示结果里的'为何保留'就变了，'下一步'也变了。
   最后数据复核人核实完修正，再重跑，
   这才是一份能用于课堂演示的完整记录。"
