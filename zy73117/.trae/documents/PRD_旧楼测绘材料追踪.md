## 1. 产品概述
旧楼测绘材料追踪系统是面向建筑设计院的专业工程材料管理工具，解决旧楼改造项目中测绘材料记录零散、变更追溯困难、交底清单遗漏等核心痛点。通过统一的数据模型和完整的追踪链条，确保每一条记录（包括撤回、变更）都能追溯到最终结论，让现场老师能够清晰理解结论变化原因。

- 核心目标：让旧楼测绘材料的每一次变更都可追溯、每一个异常都可解释、每一条待办都清晰明确
- 目标用户：设计院助理（材料录入）、现场老师（审核追溯）
- 核心价值：避免临时解释、减少交底遗漏、变更追溯透明化

## 2. 核心 Features

### 2.1 User Roles
| Role | Registration Method | Core Permissions |
|------|---------------------|------------------|
| 设计院助理 | 内部账号登录 | 导入材料、添加记录、撤回记录、添加备注和截图 |
| 现场老师 | 内部账号登录 | 查看汇总、追溯变更、审核异常、查看待处理 |

### 2.2 Feature Module
1. **材料追踪主页面**：筛选面板、材料列表、详情侧边栏、变更时间线
2. **材料导入模块**：批量导入旧材料、单条新增、数据校验
3. **记录操作模块**：撤回记录、变更单处理、异常标记
4. **备注截图模块**：人工备注、截图上传、变更说明关联
5. **汇总视图**：异常统计、待处理列表、变更趋势

| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|

| 材料追踪主页 | 材料列表 | 显示材料状态、最新结论、变更次数、异常标记 |
| 材料追踪主页 | 详情侧边栏 | 完整变更时间线、撤回记录追溯、变更单处理状态 |
| 材料追踪主页 | 操作工具栏 | 导入材料、新增记录、撤回、添加备注/截图 |

| 材料追踪主页 | 异常解释面板 | 异常记录自动生成变化原因说明 |

## 3. 核心 Process

### 3.1 主工作流程
设计院助理导入旧楼测绘材料 → 系统校验并建立初始记录 → 补录撤回/变更记录 → 关联备注和截图说明 → 自动生成变更时间线 → 现场老师查看汇总和异常解释 → 处理待办事项

### 3.2 变更追溯流程
```mermaid
flowchart LR
    A["导入旧材料"] --> B["建立初始记录"]
    B --> C["补录撤回记录"]
    C --> D["关联变更单"]
    D --> E["添加备注和截图"]
    E --> F["自动生成变更说明"]
    F --> G["现场老师追溯"]
    G --> H["查看完整时间线"]
    H --> I["理解结论变化原因"]
```

### 3.3 异常处理流程
```mermaid
flowchart LR
    A["检测变更单晚到"] --> B["标记异常状态"]
    B --> C["生成错误提示+下一步建议"]
    C --> D["待处理列表推送"]
    D --> E["助理处理并更新状态"]
    E --> F["自动更新结论说明"]
```

## 4. 界面设计

### 4.1 设计风格
- 主色调：工程蓝（#1E3A5F）+ 警示橙（#E67E22）+ 安全绿（#27AE60）
- 字体：专业工程字体 "JetBrains Mono" 用于编号和数据，"Noto Sans SC" 用于正文
- 布局：三栏布局（筛选区 + 列表区 + 详情区），严谨专业
- 风格：工业风 / 工程管理风格，深色主题为主，高对比度确保数据可读性
- 图标：使用线条型工程图标，强调专业性

### 4.2 页面设计 Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 材料追踪主页 | 筛选面板 | 下拉选择器、日期范围、状态标签、重置按钮，带持久化标记 |
| 材料追踪主页 | 材料列表 | 卡片式列表，状态色标、变更次数徽章、异常三角标 |
| 材料追踪主页 | 详情侧边栏 | 垂直时间线、状态节点、撤回记录高亮、变更单卡片 |
| 材料追踪主页 | 操作区 | 浮动操作按钮组、导入对话框、截图预览区 |
| 材料追踪主页 | 异常解释 | 时间线节点hover气泡，自动生成"结论变化说明"文本 |
| 材料追踪主页 | 待处理面板 | 右下角抽屉式面板，每条待办带箭头指示下一步 |

### 4.3 响应式
- Desktop-first 设计，1280px 以上完整三栏布局
- 1024-1280px：筛选区折叠为顶部栏
- 768-1024px：详情区改为底部抽屉
- 768px 以下：列表卡片单列布局，筛选和详情均为抽屉

### 4.4 微交互设计
- 时间线节点：hover 时放大并显示变更摘要，点击展开完整说明
- 撤回记录：红色虚线边框，附带"撤回原因 → 最终结论"的箭头连接
- 异常标记：脉冲动画的橙色三角，点击展开变化原因说明
- 页面刷新：筛选条件淡入恢复，给出"筛选条件已恢复"提示条
- 变更单晚到：错误提示非阻塞式弹出，下方直接显示"下一步操作"按钮组
