# 票据影像命名 CLI 工具

自动解析扫描票据文件名，与Excel报销单比对，智能重命名并归档，解决财务票据整理难题。

## 功能特性

- ✅ **智能文件名解析**：自动提取报销单号、发票代码、金额等信息
- ✅ **Excel数据比对**：与报销单Excel智能匹配，准确率高
- ✅ **重复文件检测**：MD5校验识别重复扫描件
- ✅ **异常文件隔离**：坏数据保留在 errors 目录，不影响整体流程
- ✅ **多格式输出**：终端摘要 + 机器可读JSON + 人性化Markdown报告
- ✅ **参数校验**：完善的输入验证和友好的错误提示
- ✅ **试运行模式**：--dry-run 预览结果不实际操作

cd /path/to/project

## 快速开始

### 1. 准备目录结构

```
your_workspace/
├── scans/                      # 影像文件目录（扫描件）
│   ├── BX20240001_1234.56.jpg
│   ├── IMG_001_发票0123456789.pdf
│   ├── 扫描件001_888.00.png
│   └── bad_file.jpg
└── 报销单.xlsx                  # Excel报销单（可选）
```

### 2. Excel文件格式

Excel需包含以下列（列名可灵活识别）：
- 报销单号 / 报销编号 / reimbursement_id
- 发票代码 / 发票号 / invoice_code
- 金额 / 报销金额 / amount

示例：

| 报销单号 | 发票代码 | 金额 |
|---------|---------|------|
| BX20240001 | 0123456789 | 1234.56 |
| BX20240002 | 9876543210 | 888.00 |

### 3. 运行命令

#### 基础用法（无Excel）
```bash
python invoice_renamer.py --image-dir ./scans
```

#### 完整功能（含Excel比对）
```bash
python invoice_renamer.py --image-dir ./scans --excel-file 报销单.xlsx
```

#### 指定输出目录
```bash
python invoice_renamer.py -i ./scans -e 报销单.xlsx -o ./output
```

#### 试运行（预览效果）
```bash
python invoice_renamer.py -i ./scans -e 报销单.xlsx --dry-run
```

#### 详细模式
```bash
python invoice_renamer.py -i ./scans -e 报销单.xlsx -v
```

## 参数说明

| 参数 | 简写 | 说明 | 必填 |
|------|------|------|------|
| `--image-dir` | `-i` | 影像文件所在目录 | ✅ |
| `--excel-file` | `-e` | 报销单Excel文件路径 | ❌ |
| `--output-dir` | `-o` | 输出目录（默认: 影像目录/output） | ❌ |
| `--dry-run` | `-n` | 试运行模式，不实际复制文件 | ❌ |
| `--verbose` | `-v` | 显示详细处理信息 | ❌ |
| `--help` | `-h` | 显示帮助信息 | ❌ |

## 匹配规则说明

### 文件名解析规则
- **报销单号**：识别 BX 开头的编号（如 BX20240001）
- **发票代码**：识别 10-20 位的纯数字串
- **金额**：识别数字格式（如 1234.56、1,234.56）

### Excel匹配得分
- 报销单号匹配：+3分
- 发票代码匹配：+2分
- 金额匹配（误差<0.01）：+2分
- 得分 ≥ 2 分视为匹配成功

## 常见问题

### Q: 文件名太乱解析不到信息怎么办？
A: 解析失败的文件会被复制到 `errors/` 目录，您可以手动处理后重新运行。

### Q: 有些文件没匹配到Excel记录怎么办？
A: 这些文件会列在报告的"未匹配到Excel记录"部分，您可以核对后手动处理。

### Q: 如何确认结果正确？
A: 建议先使用 `--dry-run` 试运行，查看报告确认无误后再正式运行。

### Q: 输出目录的文件会覆盖吗？
A: 不会，同名文件会自动添加序号后缀（如 file_1.jpg、file_2.jpg）。
