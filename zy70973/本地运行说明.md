# 街道活动报名管理系统 - 本地运行说明

## 一、环境准备

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

  -H "Content-Type: application/json" \

## 三、功能特性说明

### 1. 核心规则引擎
| 规则类型 | 说明 | 处理结果 |
|---------|------|---------|
| **候补递补** | 报名时检测候补列表，自动递补 | 成功 + 递补建议 |
| **重复报名** | 同手机号+同活动+同场次检测 | 失败 |
| **黑名单检测** | 手机号/身份证号黑名单匹配 | 失败 |
| **无报名签到** | 签到时未找到报名记录 | 待确认（需人工处理） |
| **重复签到** | 同活动同场次重复签到 | 失败 |

### 2. 结果分类说明
| 状态 | 说明 | 后续操作 |
|-----|------|---------|
| ✅ success | 正常处理 | 无需操作 |
| ⏳ pending | 待确认 | 需要人工审核修正 |
| ❌ failed | 失败 | 查看建议后决定是否重新提交 |

### 3. 批次幂等性
- 系统通过文件 MD5 哈希值判断重复提交
- 同一文件再次上传不会重复处理，直接返回原批次结果
- API 提交的 JSON 数据也会做内容哈希去重

## 四、API 接口清单

| 方法 | 路径 | 说明 |
|-----|------|------|
| POST | `/api/v1/upload/registration` | 上传报名文件（CSV/JSON） |

| POST | `/api/v1/blacklist` | 添加黑名单 |
| GET | `/api/v1/blacklist` | 获取黑名单列表 |

## 五、字段说明（CSV/JSON）

### 报名数据字段
| 字段名 | 必填 | 说明 |

| phone / 手机号 / 电话 | ✅ | 手机号码 |

| wait_time / 候补时间 | ⬜ | 候补时间 |

| 字段名 | 必填 | 说明 |
|-------|------|------|
| phone / 手机号 | ✅ | 手机号码 |
| activity_name / 活动名称 | ✅ | 活动名称 |
| activity_session / 场次 | ✅ | 活动场次 |
| name / 姓名 | ⬜ | 用户姓名 |
| checkin_time / 签到时间 | ⬜ | 签到时间 |

## 七、常见问题

### Q: 如何处理待确认（pending）记录？
A: 待确认记录是系统无法自动判断的情况（如签到时未找到报名记录），需要人工核实后：
1. 如果是数据录入错误，修正后重新提交
2. 如果确实需要特殊处理，联系管理员后台操作

### Q: 如何重新处理已提交的批次？
A: 修改文件内容后重新上传（任意修改一个字符即可，因为系统按内容哈希去重），或者使用新的批次号通过 JSON API 提交。

### Q: 数据库在哪里？
A: 默认使用 SQLite，数据文件在项目根目录 `activity.db`，可直接删除重置。
