🚌 校车调度服务 API

家长申诉、GPS轨迹匹配、迟到责任判定系统

📊 系统概览

健康检查: GET /api/health

数据持久化: SQLite 本地数据库

主要功能: 数据导入、异常检测、申诉处理、报告导出

基础URL: http://localhost:3000/api 所有接口支持 JSON 格式

📁 数据导入接口

POST /api/import/stops
导入站点时刻表 CSV 文件
参数: file (multipart/form-data) - CSV文件
CSV字段: stop_id, stop_name, route_id, scheduled_time, sequence
POST /api/import/gps
导入GPS轨迹 JSON 文件
参数: file (multipart/form-data) - JSON文件
JSON字段: device_id, driver_id, driver_name, latitude, longitude, timestamp, speed
POST /api/import/complaints
导入家长申诉单 JSON 文件
参数: file (multipart/form-data) - JSON文件
JSON字段: complaint_id, parent_name, student_name, complaint_type, complaint_time, description

🔍 异常检测接口

POST /api/anomalies/analyze
分析线路异常 - 匹配GPS轨迹和时刻表
请求体: { route_id, date }
检测内容: 迟到、站点偏离、未按规定停靠
curl -X POST http://localhost:3000/api/anomalies/analyze \ -H "Content-Type: application/json" \ -d '{"route_id": "R001", "date": "2024-01-15"}'
GET /api/anomalies
查询异常记录（支持筛选）
筛选参数: driver_id, driver_name, status, anomaly_type, severity, start_date, end_date, responsibility, limit
# 查询待处理的高优先级异常 GET /api/anomalies?status=pending&severity=high # 按司机查询 GET /api/anomalies?driver_id=D001&start_date=2024-01-01 # 按责任方筛选 GET /api/anomalies?responsibility=driver
PUT /api/anomalies/:id/handle
处理异常记录
请求体: { handler, status, responsibility, notes }
状态: pending, resolved, rejected
责任方: driver, traffic, school, investigate

📤 导出接口

GET /api/export/anomalies
导出异常记录为CSV（支持与查询相同的筛选条件）
GET /api/export/complaints
导出申诉记录为CSV

⚠️ 错误记录接口

GET /api/import-errors
查看导入错误记录（保留原始数据、错误原因、修改建议）
筛选参数: import_type, resolved, start_date, end_date
PUT /api/import-errors/:id/resolve
标记错误为已解决

📜 历史记录接口

GET /api/processing-history
查看所有数据处理历史
GET /api/dashboard/summary
获取仪表盘统计摘要

📋 枚举值说明

异常状态 (status)

pending 待处理 resolved 已处理 rejected 已驳回

严重级别 (severity)

high 高 medium 中 low 低

责任判定 (responsibility)

driver 司机责任 traffic 交通原因 school 学校安排 investigate 待调查

异常类型 (anomaly_type)

late_arrival (迟到), stop_deviation (站点偏离), no_show (未到站)

💡 使用示例

# 1. 导入站点数据 curl -X POST http://localhost:3000/api/import/stops \ -F "file=@stops.csv" # 2. 导入GPS数据 curl -X POST http://localhost:3000/api/import/gps \ -F "file=@gps_data.json" # 3. 导入申诉数据 curl -X POST http://localhost:3000/api/import/complaints \ -F "file=@complaints.json" # 4. 分析线路异常 curl -X POST http://localhost:3000/api/anomalies/analyze \ -H "Content-Type: application/json" \ -d '{"route_id": "R001", "date": "2024-01-15"}' # 5. 查询待处理异常 curl http://localhost:3000/api/anomalies?status=pending # 6. 处理异常 curl -X PUT http://localhost:3000/api/anomalies/1/handle \ -H "Content-Type: application/json" \ -d '{"handler": "调度员A", "status": "resolved", "responsibility": "traffic"}' # 7. 导出报告 curl -o anomalies_report.csv http://localhost:3000/api/export/anomalies?status=pending
