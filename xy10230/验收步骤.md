## 📝 API 接口清单（可选验证）

如果需要通过命令行验证 API，可以使用以下 `curl` 命令：

```bash
# 获取所有志愿者
curl http://localhost:3000/api/volunteers

# 获取所有岗位
curl http://localhost:3000/api/positions

# 获取所有排程
curl http://localhost:3000/api/schedules

# 获取仪表板数据
curl http://localhost:3000/api/dashboard

# 测试异常 - 重复数据
curl -X POST http://localhost:3000/api/exceptions/test \
  -H "Content-Type: application/json" \
  -d '{"type":"duplicate"}'

# 测试异常 - 缺字段
curl -X POST http://localhost:3000/api/exceptions/test \
  -H "Content-Type: application/json" \
  -d '{"type":"missing_fields"}'

# 测试异常 - 人工改错
curl -X POST http://localhost:3000/api/exceptions/test \
  -H "Content-Type: application/json" \
  -d '{"type":"manual_error"}'

# 导出排程数据
curl http://localhost:3000/api/schedules/export

# 重置数据
curl -X POST http://localhost:3000/api/reset
```
