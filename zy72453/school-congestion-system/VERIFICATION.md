验证图表点击 → 选中真实记录 → 详情各标签页数据一致 → CSV 导出字段匹配，确保图表溯源不断链、不丢详情。

## 六、常见问题排查

### Q1：点击柱子后详情为空
**排查**：
- 确认 store 中 `findFirstRecordByLevel` 是否返回正确记录
- 确认 `selectRecordAndJump` 方法同时设置了 selectedRecordId 和 activeDetailTab
- 确认 RecordDetail 使用了 store 的 activeDetailTab 而非本地 ref

### Q2：点击柱子后标签页不切换
**排查**：
- 确认 RecordDetail 中 `activeDetailTab` 是 computed 且来自 `state.activeDetailTab`
- 确认点击 tab 时调用的是 `setActiveDetailTab()` 而非直接赋值

### Q3：CSV 导出中记录 ID 与页面不一致
**排查**：
- 确认导出函数使用 `record.id` 而非序号
- 确认导出时遍历的 records 数组与列表展示的是同一数据源

### Q4：刷新后重复判断结果变化
**排查**：
- 确认导入去重算法稳定（先判断本次重复，再判断历史重复）
- 确认模拟数据中 `isDuplicate` 和 `duplicateOfId` 字段正确设置
