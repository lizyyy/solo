# 装配式墙板吊装预演系统

## 项目简介

本系统用于装配式墙板吊装前的预演工作，帮助航测内业人员处理障碍物备注和楼层剖面草图数据，提供完整的自检、审计追踪和数据导出功能。

## 核心功能

### 1. 三步工作流

**第一步：导入障碍物备注**
- 支持 CSV、Excel 文件批量导入
- 支持手动添加单条记录
- 自动检测重复导入
- 自动识别坐标格式（经纬度/米制）

**第二步：补看楼层剖面草图**
- 航测内业人员可补充/修改剖面备注
- 自动标记受影响的障碍物记录
- 查看每条记录的审计追踪

**第三步：更新现场班组说明**
- 生成给现场班组的吊装说明
- 自动包含受影响的记录清单
- 便于巡检组当天复核

### 2. 自检功能

系统自动进行以下检查：
- **重复导入检查**：检测重复的墙板记录
- **坐标格式检查**：检测经纬度和米制坐标混合的记录（标记待复核，不自动归正）
- **补录重算检查**：记录补录后重新计算的情况
- **导出一致性检查**：确保明细、页面、接口返回数据一致

### 3. 审计追踪

每条记录保留完整的可追溯信息：
- 原始行号
- 原始备注内容
- 人工修改记录（修改人、时间、前后值）
- 处理状态历史
- 坐标类型及是否混合

### 4. 数据一致性保证

所有数据来源于统一的 `unifiedResult` 对象：
- 页面展示读同一份结果
- 导出明细读同一份结果
- API 接口返回读同一份结果
- 确保不会出现"一个地方显示异常、另一个地方消失"的情况

### 5. 日常检查

当小魏只修改楼层剖面草图备注时：
- 系统自动标记受影响的障碍物记录
- 在现场班组说明中明确指出需复核的记录
- 方便巡检组当天完成复核工作

## 快速开始

### 环境要求

- Node.js >= 16.0.0
- npm >= 7.0.0

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:3000 即可使用系统。

### 样例数据演示

1. 启动系统后，点击右上角的"加载样例数据"按钮
2. 系统会自动导入预设的障碍物和楼层剖面条目
3. 可以观察到：
   - WP-001 被标记为重复导入
   - WP-002、WP-005 被标记为坐标混合待复核
   - 自检面板显示各项检查结果

### 完整流程演示

#### 第一步：导入障碍物备注

1. 点击"加载样例数据"或拖拽 CSV/Excel 文件上传
2. 查看已导入的记录列表
3. 注意坐标混合的记录会标红并显示"坐标混合待复核"
4. 可点击"编辑备注"修改障碍物说明

#### 第二步：补看楼层剖面草图

1. 点击"下一步"进入第二步
2. 在楼层剖面记录中点击"编辑备注"
3. 修改剖面备注内容后保存
4. 系统会显示"日常检查提示"，告知有受影响的记录
5. 点击某条障碍物记录的"查看审计追踪"，可看到完整的变更历史

#### 第三步：更新现场班组说明

1. 点击"下一步"进入第三步
2. 填写说明标题、内容等信息
3. 点击"生成说明"
4. 生成的说明会自动包含受影响的记录清单
5. 点击"查看详情"可看到完整的说明内容和受影响记录

### 数据导出

在"数据导出"面板中：
- 支持导出 Excel、CSV、JSON 三种格式
- 查看 API 接口返回数据预览
- 验证统一数据源信息

### 审计追踪

在"审计追踪"面板中：
- 查看所有操作日志
- 导出审计记录 CSV
- 查看审计汇总（原始行号、原始备注、修改次数等）

## 核心设计要点

### 坐标混合处理

检测到经纬度和米制坐标混合时：
- 标记为"待复核"状态
-- 不会自动归正
- 保留原始数据
- 标记为待巡检组复核
- 不会自动修改或删除
- 留给巡检组人工确认
