# 🏔️ 山地步道海拔导览系统

基于 Three.js + Canvas 的交互式3D山地步道可视化系统，为文旅局提供步道高程、补给点、危险路段的交互式导览体验。

## ✨ 核心功能

### 3D可视化
- **Three.js 3D地形**：真实感地形渲染，支持阴影和光照
- **步道轨迹**：彩色渐变路线，海拔高度可视化
- **高程剖面图**：底部2D Canvas实时同步显示海拔曲线

### 交互功能
- **导入样例**：青城山、黄山、峨眉山三条经典步道
- **拖拽旋转**：OrbitControls 支持360度视角操作
- **筛选控制**：补给站/风险路段/高程点独立筛选
- **风险等级**：低/中/高风险分类筛选
- **时间轴**：滑动进度条模拟徒步行程
- **视角切换**：总览/跟随/俯视/侧视四种预设视角

### 天气与安全
- **四种天气状态**：晴朗/多云/小雨/暴雨
- **雨天自动关闭**：高风险路段在雨天自动隐藏并提示
- **实时安全提示**：根据天气和风险路段给出徒步建议

### 数据与状态
- **状态持久化**：localStorage 保存筛选和关键状态，刷新不丢失
- **一键重置**：恢复到初始状态
- **导出报告**：生成导览报告卡片，支持图片下载和文本复制

## 📋 可复现操作指南

### 基础操作流程

#### 1. 导入样例数据
1. 点击顶部「导入样例数据」下拉框
2. 选择「青城山步道」
3. 观察3D场景加载地形和步道
4. 查看右侧信息面板显示步道数据

#### 2. 视角操作
1. **旋转视角**：按住鼠标左键拖拽
2. **缩放**：鼠标滚轮滚动
3. **平移**：按住鼠标右键拖拽
4. **预设视角**：点击侧栏「视角切换」按钮
   - 🌍 总览：默认全局视角
   - 🔝 俯视：90度俯视视角
   - 📐 侧视：侧面观察海拔变化

#### 3. 筛选功能演示
1. 取消勾选「补给站」- 绿色锥形标记消失
2. 取消勾选「风险路段」- 彩色管状风险区消失  
3. 取消勾选「高程点」- 白色旗杆标记消失
4. 风险等级筛选选择「高风险」- 只显示红色高风险区域
5. **注意**：底部高程剖面图同步更新筛选状态

#### 4. 天气变化演示
1. 点击「🌧️ 雨」按钮
2. 观察：
   - 场景雾气变浓
   - 光照变暗
   - 出现「⚠️ 雨天部分路段已关闭」红色警告
   - 标记为 `closedInRain` 的风险路段自动隐藏
3. 点击「⛈️ 暴雨」- 雾气更浓，光照更暗

#### 5. 行程进度模拟
1. 拖动「行程进度」滑块到50%
2. 观察：
   - 3D场景中的蓝色发光球体移动到对应位置
   - 底部高程图中的白色圆点同步移动
   - 信息面板显示当前位置和海拔
3. 切换到「🚶 跟随」视角 - 相机跟随进度标记移动

#### 6. 导出报告
1. 点击顶部「📤 导出报告」按钮
2. 查看弹出的报告卡片，包含：
   - 步道基本信息
   - 天气与安全建议
   - 行程进度条
3. 点击「📥 下载图片」保存报告为PNG
4. 点击「📋 复制文本」复制文本格式报告

#### 7. 状态持久化验证
1. 设置筛选状态（如只显示补给站）
2. 选择天气为「多云」
3. 拖动进度到30%
4. 刷新浏览器页面
5. 验证：所有筛选和状态设置自动恢复

#### 8. 重置功能
1. 点击「🔄 重置状态」按钮
2. 验证：
   - 所有数据清空
   - 筛选恢复默认
   - 天气恢复晴朗
   - 进度归零

## 🎯 数据一致性保证

系统确保可视化和导出报告的数据一致性：

1. **筛选状态同步**：3D场景 ↔ 2D海拔图 ↔ 导出报告
2. **天气状态同步**：场景光照/雾气 ↔ 安全提示 ↔ 风险路段可见性
3. **进度状态同步**：3D标记位置 ↔ 高程图指示器 ↔ 报告进度条
4. **风险路段逻辑**：雨天自动关闭逻辑在所有视图中一致应用

## 🔧 技术栈

- **Three.js 0.160**：3D图形渲染
- **Tween.js**：相机和动画过渡
- **Canvas 2D**：海拔剖面图绘制
- **Vite 5**：构建工具
- **localStorage**：状态持久化
- **html2canvas**：报告图片导出（CDN动态加载）

## ⚠️ 常见问题验证点

### 高程断点检测
- 样例数据生成采用平滑插值算法，确保高程连续
- 实际应用中可在数据导入时增加断点检测逻辑

### 补给点偏移检测
- 补给点位置基于距离从轨迹点精确计算
- 鼠标悬停显示详细信息，便于人工核对

### 雨天关闭提示
- 风险路段数据包含 `closedInRain` 标记
- 天气切换时自动更新可见性并显示警告
