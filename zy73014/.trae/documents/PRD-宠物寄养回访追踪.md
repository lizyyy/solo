## 1. 产品概述
宠物医院寄养回访追踪看板，解决寄养登记表中新旧记录信息不一致、复核翻表效率低、体重单位混写误判、补录改判无追溯等问题。
- 目标用户：复核人（主看板）、算法值班人（交接+挂起确认）、前台小温（接班三件事）
- 核心价值：减少翻表量、避免假稳定结论、交接不遗漏、历史可追溯

## 2. 核心功能

### 2.1 用户角色
| 角色 | 使用场景 | 核心能力 |
|------|----------|----------|
| 复核人 | 日常核对寄养登记表与回访记录 | 看板总览、异常标记点击、回到登记表/计算口径 |
| 算法值班人 | 下班前交接、体重单位挂起确认、补录改判 | 放行/待补材料分类、挂起记录人工确认、改判备注留痕 |
| 前台小温 | 接班快速上手 | 样例入口、异常入口、结果导出（不用读大段说明） |

### 2.2 功能模块
1. **主看板页（复核人视角）**：顶部统计卡、记录列表（含异常标签）、角色切换栏
2. **异常详情弹窗**：原寄养登记表快照、本次计算口径、体重单位处理逻辑、操作按钮
3. **历史追溯面板**：旧材料快照、新备注、改判原因时间线
4. **算法值班人交接页**：放行清单、待补材料清单、挂起待确认清单
5. **前台小温接班页**：样例卡片、异常卡片、导出按钮卡片（三卡布局）

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主看板 | 顶部统计卡 | 总数/异常数/挂起数/放行数，点击可筛选列表 |
| 主看板 | 记录列表 | 行内展示宠物名、主人、寄养日期、异常标签（彩色徽章）、操作列 |
| 异常详情弹窗 | 原登记表快照 | 还原当时录入的所有字段，有差异字段高亮对比 |
| 异常详情弹窗 | 计算口径说明 | 本次比对的规则（旧记录来源、字段匹配逻辑、容差阈值） |
| 异常详情弹窗 | 体重单位处理 | 单位混写时置灰结果，显示"需算法值班人确认"挂起状态 |
| 历史追溯面板 | 时间线 | 每次操作：旧材料快照→新备注输入→改判原因选择→操作人时间戳 |
| 交接页 | 三栏清单 | 放行（绿）、待补材料（黄）、挂起待确认（红），可拖动手动升级降级 |
| 小温接班页 | 三卡布局 | 样例卡→跳转样例、异常卡→跳转异常列表、导出卡→一键导出CSV |

## 3. 核心流程
复核人打开看板 → 看到异常标签列表 → 点击异常行弹出详情 → 查看原登记表+计算口径
→ 若为体重单位混写：自动挂起 → 算法值班人确认 → 记录进入放行/待补材料
→ 若补录后结论变化：在历史面板写入旧材料+新备注+改判原因 → 算法值班人下班前查交接三栏
→ 小温接班：打开接班页→点样例卡看边界样本→点异常卡看今日异常→点导出卡拿CSV

```mermaid
    E --> G[算法值班人确认]
    F --> G
    G --> H{补录后改判?}

    J --> K[交接页 三栏清单]
    K --> L[小温接班页 三卡]
```

## 4. 用户界面设计
### 4.1 设计风格
- **主色**：暖青 #2A9D8F（专业可靠）+ 奶橙 #E9C46A（宠物温暖感）+ 深墨 #264653（文字）
- **异常色**：挂起红 #E76F51、待补黄 #F4A261、放行绿 #2A9D8F
- **按钮风格**：圆角 10px，无阴影扁平，按下 0.92 缩放
- **字体**：标题 "Noto Serif SC"（衬线稳重大气）、正文 "LXGW WenKai"（开源手写楷体，亲和力）
- **布局风格**：卡片式，卡片边缘 1px 实线，圆角 16px，微浮起 hover
- **图标**：lucide-react，统一线性风格

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 主看板 | 统计卡 | 4 张横排，数字大 36px 衬线，图标在左，点击有下沉动画 |
| 主看板 | 记录列表 | 斑马纹浅灰交替，异常标签彩色圆角徽章，行 hover 奶橙淡背景 |
| 异常详情 | 双栏对比 | 左旧记录右登记表，差异字段橙红高亮边框，中间 ↔ 箭头 |
| 历史面板 | 垂直时间线 | 左侧圆点三色（绿/黄/红），右侧卡片含操作人+时间+旧快照缩略+备注 |
| 交接页 | 三栏看板 | 每栏头带数字标，卡片可拖拽，空栏有虚线占位+提示 |
| 小温接班页 | 三大卡 | 每卡 220px 高，图标+标题+一行说明+大按钮，留白充足 |

### 4.3 响应式
桌面优先（最小 1280px），交接页三栏在 <960px 时改为竖排堆叠。

### 4.4 动效细节
- 统计卡数字：进入时从 0 滚到目标值（600ms）
- 异常标签：首次出现时轻微脉冲（opacity 0.6→1 两次）
- 弹窗：顶部滑入 + 背景淡入（250ms ease）
- 拖拽交接卡片：半透明跟随 + 目标位置虚线高亮
