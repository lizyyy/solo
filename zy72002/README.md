# 门店日结现金差异分析工具

专门处理月底对账表中"门店日结现金差异"的对账工具，重点解决**同一笔钱被两个批次认走**的重复认领问题。

## 快速开始

### 1. 放样例数据（一键生成）
```bash
python -m store_cash_diff --sample
```
自动在 `samples/` 目录生成测试用的月底对账表、银行回单、业务台账和附件索引。

### 2. 用自己的数据跑
```bash
# 多文件一起分析
python -m store_cash_diff \
  --data samples/monthly_statement.csv:月底对账表 \
  --data samples/bank_receipts.csv:银行回单 \
  --data samples/business_ledger.csv:业务台账 \
  --attachment samples/attachment_index.csv \
  --output output/
```

### 3. 临时补录备注
```bash
python -m store_cash_diff --sample --remark "REC001:已确认是收银员误操作"
```

### 4. 处理晚到附件
```bash
python -m store_cash_diff --sample --late-attach "REC002:银行回单:scan_003.pdf:5月30日补送的回单"
```

## 差异报告去哪看

终端跑完会直接显示彩色摘要，同时导出到 `output/` 目录：

| 文件名 | 内容 |
|--------|------|
| `门店日结现金差异_明细_时间戳.csv` | 给财务看的完整明细，带原始备注、当前备注、所有历史变更 |
| `门店日结现金差异_摘要_时间戳.csv` | 快速浏览的摘要版 |
| `门店日结现金差异_重复认领_时间戳.csv` | 核心问题：同一笔钱被多个批次认走的明细 |
| `门店日结现金差异_处理日志_时间戳.txt` | 系统判断的完整过程日志 |
| `门店日结现金差异_终端输出_时间戳.txt` | 终端显示内容的存档 |

## 核心能力

- ✅ **重复认领检测**：同门店同金额被不同批次认领自动标记
- ✅ **原始备注不覆盖**：月底对账表的"门店日结现金差异"列完整保留在原始备注字段
- ✅ **历史变更追踪**：每次补录备注、晚到附件都记录原值→新值→操作人→原因
- ✅ **空值/边界处理**：金额为空、日期为空、0金额、负数、测试批次号自动识别
- ✅ **晚到附件不覆盖**：原判断保留，只追加新判断，导出时前后变化都在
- ✅ **多源数据**：支持银行回单、业务台账、月底对账表、群截图、补录说明
- ✅ **金额不匹配**：银行回单与台账金额不一致自动比对

## CSV字段要求

| 字段（别名都认） | 说明 |
|----------------|------|
| 记录ID / ID / 编号 | 唯一标识，不填会自动生成 |
| 门店编号 / 门店ID | 必填 |
| 门店名称 / 门店 | |
| 交易日期 / 日期 | |
| 金额 / 交易金额 | 必填，支持￥,逗号格式 |
| 批次号 / 批次 | 重复认领判断的关键 |
| 备注 / 说明 / 门店日结现金差异 | 原始备注，**不会被覆盖** |
| 数据来源 / 来源 | 银行回单/业务台账/月底对账表等 |
