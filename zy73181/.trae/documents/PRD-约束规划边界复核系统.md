## 1. 产品概述

约束规划边界复核系统是一款面向数学教学与算法运维的专业工具，旨在解决题目清单中约束规划类问题的边界条件校验混乱问题。系统通过可视化图表、明细回溯、单位校验和中间计算过程透明化，帮助数学教师和算法值班人员快速定位边界异常、验证复核结果、导出一致数据。

- 目标用户：数学教师（老叶）、算法值班人员、题目清单维护者
- 核心价值：让边界复核从"乱"到"清"，图表可追溯、数据可导出、异常可定位、计算过程透明

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 数学教师 | 查看题目清单、筛选复核结果、图表交互与明细回溯、导出报告 |
| 算法值班人 | 两组参数对照复核、查看中间计算过程与单位换算、定位异常行 |
| 系统维护者 | 管理题目清单备注、灰度发布标记、演示数据配置 |

### 2.2 功能模块

1. **题目清单总览页**：题目列表表格、筛选摘要区、边界复核状态统计
2. **约束规划边界复核详情**：复核算法参数配置、中间计算过程展示、单位校验结果
3. **图表交互面板**：边界分布散点图、异常高亮、点击回溯明细行
4. **导出与报告**：一键导出、筛选口径附随、问题行定位标记
5. **灰度发布备注**：临时备注机制、复核影响说明、版本对比

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 题目清单总览 | 筛选摘要区 | 显示当前筛选条件（难度、知识点、复核状态等），常驻页面顶部 |
| 题目清单总览 | 题目列表表格 | 展示题目编号、题干摘要、约束类型、边界复核状态、单位完整性、操作列 |
| 题目清单总览 | 统计概览卡片 | 总数、正常数、异常数、单位缺失数、待复核数 |
| 题目清单总览 | 边界分布图 | 散点图展示所有题目边界值分布，异常点高亮，点击跳转对应行 |
| 边界复核详情 | 复核参数配置 | 支持两组参数对照（A组/B组），可切换对比 |
| 边界复核详情 | 中间计算过程 | 逐步展示约束求解、边界判定、单位换算的每一步计算细节 |
| 边界复核详情 | 单位校验模块 | 检测单位缺失、单位不匹配、单位换算错误，独立标记不混入正常结果 |
| 边界复核详情 | 影响判断说明 | 明确列出本次复核改变了哪些判断结论（灰度发布备注用） |
| 导出报告 | 数据导出 | 导出CSV/Excel，与屏幕数字完全一致，附筛选口径说明 |
| 导出报告 | 问题行定位 | 报告中标注哪一行拖偏了整体结果，附带行号和偏差值 |
| 演示数据中心 | 混合样例集 | 包含正常样例、单位缺失、后补备注的"不太干净"的演示数据 |

## 3. 核心流程

```mermaid
flowchart LR
    A["进入题目清单"] --> B["设置筛选条件"]
    B --> C["筛选摘要实时更新"]
    C --> D["查看边界分布图表"]
    D --> E["点击异常点回溯明细行"]
    E --> F["进入边界复核详情"]
    F --> G["配置A组/B组参数"]
    G --> H["查看中间计算过程"]
    H --> I["单位校验结果分离展示"]
    I --> J["生成复核报告"]
    J --> K["导出（附筛选口径+问题行定位）"]
    L["灰度发布备注"] --> F
    M["演示数据（含单位缺失+后补备注）"] --> A
```

用户从题目清单出发，通过筛选定位目标题目，借助图表快速发现异常，点击回溯到具体行，然后进入复核详情页进行两组参数对照，查看透明的中间计算和单位校验，最后导出携带筛选口径和问题行定位的报告。灰度发布期间可临时补充备注，说明复核改变了哪些判断。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深邃的学术蓝（#1e3a5f）搭配琥珀金（#d4a853）强调色，营造专业严谨的数学工具氛围
- 辅助色：异常红（#e74c3c）、正常绿（#27ae60）、警告黄（#f39c12）、单位缺失紫（#8e44ad）
- 字体：标题用 Playfair Display（衬线体，学术感），正文用 JetBrains Mono（等宽字体，数学公式友好）
- 布局：左侧导航 + 右侧内容区，顶部筛选摘要常驻，表格与图表上下分栏
- 卡片风格：细边框 + 微妙阴影 + 8px圆角，学术期刊式排版
- 图标风格：线性图标，数学符号风格（∑、∫、⊂、∅等）

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 题目清单总览 | 筛选摘要区 | 胶囊式筛选标签、可移除、带"筛选口径"说明文字 |
| 题目清单总览 | 统计卡片行 | 4张数字卡片，带趋势小箭头，悬停微动效 |
| 题目清单总览 | 题目表格 | 斑马纹行、状态标签、异常行淡红色背景、单位缺失行紫色标记 |
| 题目清单总览 | 边界分布图 | 深色背景画布、散点分布、参考线、异常点脉冲动画 |
| 边界复核详情 | 参数对照区 | 左右分栏A/B组对比，当前组高亮边框 |
| 边界复核详情 | 计算过程面板 | 可折叠步骤、等宽字体、当前步骤高亮、单位换算专门区块 |
| 边界复核详情 | 单位校验结果 | 独立紫色卡片，与正常结果视觉分离，绝不混入 |
| 导出报告 | 导出预览弹窗 | 数据预览、筛选口径说明区、问题行定位清单、下载按钮 |
| 演示数据中心 | 样例卡片 | 标记"含单位缺失"、"含后补备注"标签，脏数据醒目标识 |

### 4.3 响应式

- 桌面优先设计，最小支持 1280px 宽度
- 平板端图表与表格左右并排改为上下堆叠
- 筛选摘要区在小屏幕可折叠收起，点击展开
- 表格支持横向滚动，固定首列

### 4.4 交互动效

- 页面加载：卡片错峰淡入（staggered fade-in），间隔 80ms
- 图表点悬停：数据点放大 + 光晕 + tooltip 滑入
- 行高亮：从图表点击跳转时，对应表格行有黄色闪烁高亮 2 秒
- 计算过程：步骤展开时数字从 0 滚动到目标值（counter animation）
- 状态切换：标签颜色过渡 300ms 缓动
