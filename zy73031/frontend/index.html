📖 系统文档 只写实在的，不铺概念

🚀 启动方式

  • 后端：cd backend && npm install && npm start
  • 首次启动自动建库 + 导入示例数据，之后复用数据库
  • 前端：直接用浏览器打开 frontend/index.html（或任意静态服务器）
  • 后端默认端口 3001，前端 API_BASE 变量可改

🔄 算法重跑入口

  • 命令行：cd backend && npm run rerun-algorithm（会清空旧同版本异常并重跑）
  • 页面按钮：异常列表页右上角「🔄 算法重跑」
  • API：POST /api/algorithm/rerun，无参数
  • 算法版本 v1.0，口径版本 2026-06-v1

📡 接口返回位置（全量清单）

所有接口返回 JSON 均携带 _context 字段，保证页面和文件口径一致：

📐 口径说明（和接口 _context 一致）

  • 体重单位混写判定：同一记录中 kg/g/lb 混用，或数值与单位量级明显不匹配
  • 回访结论异常：空值（无人能接查）或含歧义措辞（待查/？等）
  • 关联断裂：训练课未关联有效病历，无法回溯原始材料
  • 复核口径：已确认=异常属实处理；待补件=需补充材料；退回=误报

🔗 追溯链路说明

  • 异常图表 → 点击异常点 → 异常列表（自动筛选） → 点击编号 → 异常详情页
  • 详情页「材料追溯链」：异常提醒 ⇄ 病历手写单 ⇄ 训练课记录，每级可跳转
  • 详情页顶部 banner：说明该异常「改变了哪些判断」
