# 影院影厅清洁交接台

影院散场后清洁、遗失物和设备异常交接的桌面工作台。数据本地持久化，重启可继续使用。

## 安装运行

```bash
npm install
npm run dev
```

打开浏览器访问 `http://localhost:5173`

## 样例入口

进入「工作台」→ 点击 **「载入今日样例数据」**

该按钮会：
1. 导入 3 个影厅共 9 场排片（含散场间隙）
2. 自动生成对应清洁任务

## 核心操作

### 1. 排片导入 → 清洁任务生成
- 「排片管理」→ 粘贴排片文本 → 「导入排片」→「生成清洁任务」
- 支持格式：`日期,影厅,影片,开始-结束时间,观众数`

### 2. 清洁任务交接
- 「清洁任务」→ 点击「开始清洁」输入责任人
- 清洁过程中可登记 **遗失物** 和 **设备异常**
- 清洁完成点击「完成」，设置质量评分（1-10 分）和备注
- 超过下一场开映前截止时间会自动标记「超时」

### 3. 遗失物登记与认领
- 清洁中或已完成的任务均可登记遗失物
- 「遗失物」→ 点击「认领」记录认领人
- 无人认领可标记「已处理」

### 4. 设备异常上报与处理
- 清洁中发现的设备问题可上报（含优先级）
- 「设备异常」→「开始处理」→「标记已解决」
- 紧急问题可「升级」处理

### 5. 历史查询与导出
- 「历史查询」→ 查看所有数据统计、任务/遗失物/设备明细
- 支持搜索（影厅、影片、物品、人员）
- 点击「导出 Excel」生成 4 个 Sheet：排片信息、清洁任务、遗失物登记、设备异常

## 如何检查结果

1. **排片间隙验证**：同一影厅多个排片间的清洁任务会显示「距下场 X 分钟」，并据此设置截止时间
2. **状态流转验证**：排片 → 待清洁 → 清洁中（可登记遗失物/设备异常）→ 已完成/超时
3. **数据关联验证**：清洁任务详情会显示关联的遗失物数量和设备异常数量
4. **导出一致性验证**：
   - 导出后「导出 Excel」按钮变灰（数据未变化时不允许重复导出）
   - 数据状态变更后按钮重新可用
   - 重复导入相同排片会被自动跳过（基于日期+影厅+开始时间去重）
5. **持久化验证**：刷新浏览器页面，重新打开各标签页，所有数据应保持不变
