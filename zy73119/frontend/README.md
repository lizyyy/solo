# 旧楼测绘交底清单 · 现场测绘交底工作台

> BIM 协调员与算法值班人的协作工作台：从汇总一路追到现场异常、材料送审来源、历史截图和备注变化。

## 功能特性

### 🗺️ 空间视图
- SVG 简化楼层平面图，展示房间分布与测点位置
- 异常点按等级高亮（高/中/低），正常点绿色
- 测点带编号标签，点击可查看详情
- 支持 5 个楼层切换（B1 / 1F / 2F / 3F / RF）

### ⚠️ 异常追溯
- 异常类型、所在空间、偏移量、模型坐标
- 影响材料关联
- 追溯时间线：从汇总到现场测量的完整链路，不断链
- 负责人、状态、跑批 ID

### 📋 材料送审历史
- 每种材料保留所有版本历史，不只展示最终值
- 每个版本包含：规格、供应商、送审人、备注、截图占位
- 可展开/收起历史版本，对比新旧差异
- 备注以醒目样式呈现，补充说明全程留痕

### 🎯 可执行动作
- 坐标偏移超限时自动生成处置动作
- 动作类型：复测 / 锁定偏移 / 回写模型 / 补充材料依据
- 每个动作标注责任人和流转方向
- 支持标记完成、追加动作

### 📊 汇总统计
- 异常测点、高危异常、坐标超限、材料缺口、待处理动作、已闭环
- 所有卡片可点击下钻，自动定位到对应测点和详情 tab
- 楼层快速切换，显示每层异常数

### 📥 CSV 导出
- 导出文件头携带口径版本、口径说明、导出时间、楼层/类型筛选
- 字段完整：空间、测点、异常状态、材料来源版本、历史备注摘要、坐标偏移、处置动作
- 每行末尾附带口径版本号，文件与页面口径一致

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（默认端口 3000）
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

启动后访问 http://localhost:3000

## 完整演示链路

1. **打开页面** → 顶部显示口径版本号 + 导出 CSV 按钮
2. **查看汇总** → 左侧 6 张统计卡片，点击「高危异常」卡片
3. **自动下钻** → 跳转到对应楼层，选中高危异常测点，切换到异常详情 tab
4. **查看追溯** → 向下滚动看到追溯链路时间线（汇总 → 现场 → 材料）
5. **查看材料** → 切到「材料送审」tab，展开历史版本，看到 v1/v2/v3 全部保留
6. **查看处置** → 切到「处置动作」tab，看到复测 / 回写模型 / 补充材料依据三项动作
7. **标记完成** → 点击「标记完成」，动作置灰并加删除线
8. **楼层切换** → 左侧点「B1 设备层」/「屋面」等，平面图和测点同步切换
9. **导出 CSV** → 点右上角「导出 CSV」，文件带口径元数据，与当前页面筛选一致

## 技术栈

- **构建**：Vite 5
- **框架**：React 18
- **视图**：原生 SVG 绘制平面图（无需 Three.js，轻量快速）
- **样式**：原生 CSS（无 UI 框架依赖）
- **数据**：内置 mock 数据（可替换为后端 API）

## 口径说明

当前口径版本：**v2.4-202606**

- 空间位置精度 ±50mm
- 异常等级按偏移量分级
- 材料送审表保留所有版本历史
- 坐标超限自动生成可执行动作

## 后端对接

数据层当前使用 mock 数据。如需对接后端 API，可在 `src/utils/` 下添加 API 封装，并在各组件中替换数据源。

后端 API 约定参考（FastAPI）：
- `GET /api/checklist` - 清单项列表
- `GET /api/checklist/{id}` - 单项详情（含异常、材料、偏移、历史）
- `GET /api/export/csv` - CSV 导出（带口径元数据）
- `POST /api/batch-run` - 一键跑批
