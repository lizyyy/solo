# 无人机灯光秀航线排练台

一个专为低空文旅运营团队设计的本地3D交互可视化工具，用于无人机灯光秀演出前的航线排练与风险检测。

## 功能特性

### 🎯 核心功能
- **3D实时可视化**: 使用Three.js渲染无人机编队3D场景
- **时间轴控制**: 播放/暂停/拖动时间轴，精确控制演出进度
- **风险检测**: 实时检测碰撞风险、禁飞区穿越、低电量警告
- **人工标记**: 支持手动标记关键位置，便于复核

### 📊 数据支持
- **无人机编队数据**: JSON格式，包含无人机ID、航点、颜色等
- **禁飞区数据**: GeoJSON格式，支持圆形和多边形禁飞区
- **音乐节拍表**: CSV格式，用于同步灯光效果
- **电池批次表**: CSV格式，支持不同电池的损耗率计算

### 💾 数据管理
- **会话保存/加载**: 保存当前排练状态，随时恢复
- **报告导出**: 支持导出Markdown、CSV、JSON格式的风险报告

## 快速开始

### 环境要求
- Node.js >= 16.0.0
- npm 或 yarn

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

服务器将在 `http://localhost:3000` 启动。

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist/` 目录。

### 运行测试

```bash
npm run test
```

## 使用说明

### 1. 加载数据

#### 方法一：使用示例数据
点击界面左上角的 **"加载示例数据"** 按钮，系统将自动加载预设的示例数据，包含：
- 8架无人机的编队航线
- 3个禁飞区（中央圆形、机场多边形、临时活动区）
- 电池批次数据
- 音乐节拍表

#### 方法二：导入自定义数据
在左侧面板选择对应文件类型：

| 文件类型 | 格式 | 说明 |
|---------|------|------|
| 无人机编队数据 | .json | 无人机航点配置 |
| 禁飞区数据 | .geojson/.json | 禁飞区域定义 |
| 音乐节拍表 | .csv | 节奏点时间轴 |
| 电池批次表 | .csv | 电池损耗参数 |

### 2. 时间轴操作

- **播放**: 点击"播放"按钮开始模拟
- **暂停**: 点击"暂停"按钮暂停当前位置
- **重置**: 点击"重置"按钮回到初始状态
- **拖动时间轴**: 直接点击或拖动时间轴上的滑块跳转到任意时间点

### 3. 实时状态监控

右侧面板显示实时状态：

| 状态项 | 说明 |
|-------|------|
| 当前时间 | 模拟当前时间（分:秒.毫秒） |
| 总时长 | 整个演出的总时长 |
| 无人机数量 | 已加载的无人机总数 |
| 活动无人机 | 当前时间点活跃的无人机 |
| 禁飞区数量 | 已加载的禁飞区总数 |
| 碰撞风险 | 是否检测到无人机距离过近 |
| 禁飞区穿越 | 是否有无人机进入禁飞区 |
| 低电量警告 | 是否有无人机电量过低 |
| 最小距离 | 当前无人机间的最小距离 |

### 4. 事件标记

右下角面板显示所有事件标记，包括：
- 🔴 **碰撞风险**: 无人机距离小于3米
- 🟠 **禁飞区穿越**: 无人机进入禁飞区域
- 🟡 **低电量警告**: 电池电量低于20%
- 🔵 **人工标记**: 手动添加的标记

### 5. 保存与导出

#### 保存会话
点击 **"保存会话"** 按钮，将当前状态保存为JSON文件，包含：
- 所有已加载的数据
- 所有事件标记
- 当前时间位置

#### 加载会话
点击 **"加载会话"** 按钮，选择之前保存的会话文件恢复。

#### 导出报告

支持三种格式：

| 格式 | 特点 | 用途 |
|------|------|------|
| Markdown | 结构化文档，含建议 | 存档、汇报 |
| CSV | 表格格式，便于处理 | 数据分析 |
| JSON | 完整数据结构 | 程序处理 |

## 数据格式说明

### 无人机编队数据 (JSON)

```json
{
  "version": "1.0",
  "drones": [
    {
      "id": "drone_0",
      "name": "无人机 1",
      "batteryId": "battery_0",
      "color": "#ff6b6b",
      "startTime": 0,
      "waypoints": [
        { "time": 0, "x": 0, "y": 0, "z": 10, "speed": 2 },
        { "time": 10, "x": 10, "y": 10, "z": 20, "speed": 3 }
      ]
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 无人机唯一标识 |
| name | string | 显示名称 |
| batteryId | string | 关联电池ID |
| color | string | 显示颜色（HEX） |
| startTime | number | 开始活动时间（秒） |
| waypoints | array | 航点数组 |
| waypoints[].time | number | 到达该航点的时间 |
| waypoints[].x/y/z | number | 三维坐标 |
| waypoints[].speed | number | 飞行速度 |

### 禁飞区数据 (GeoJSON)

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "properties": {
        "id": "zone_0",
        "name": "中央禁飞区",
        "radius": 50,
        "minAltitude": 0,
        "maxAltitude": 100
      },
      "geometry": {
        "type": "Point",
        "coordinates": [0, 0]
      }
    },
    {
      "type": "Feature",
      "properties": {
        "id": "zone_1",
        "name": "多边形禁飞区",
        "minAltitude": 0,
        "maxAltitude": 200
      },
      "geometry": {
        "type": "Polygon",
        "coordinates": [
          [[60, 60], [120, 60], [120, -60], [60, -60], [60, 60]]
        ]
      }
    }
  ]
}
```

### 电池批次表 (CSV)

```csv
id,capacity,drain_rate,voltage,cycle_count,health
battery_0,95,0.6,3.7,15,good
battery_1,88,0.7,3.6,35,fair
```

| 列名 | 说明 |
|------|------|
| id | 电池唯一标识 |
| capacity | 初始容量（%） |
| drain_rate | 每秒损耗率（%/秒） |
| voltage | 电压 |
| cycle_count | 充放电循环次数 |
| health | 健康状态 |

### 音乐节拍表 (CSV)

```csv
time,type,measure,beat,intensity
0.0,strong,1,1,1.0
0.5,weak,1,2,0.6
1.0,weak,1,3,0.6
1.5,weak,1,4,0.6
```

## 风险检测规则

### 碰撞检测
- **危险距离**: < 3米（红色警告）
- **警告距离**: < 10米（黄色提示）
- 实时计算所有活跃无人机之间的3D距离

### 禁飞区检测
- 支持圆形和多边形禁飞区
- 考虑高度限制（minAltitude ~ maxAltitude）
- 支持时间限制（startTime ~ endTime）

### 电池检测
- **警告阈值**: < 20%
- **危险阈值**: < 10%
- 根据电池批次表计算损耗率
- 显示颜色变化：正常→黄色→红色

## 本地验证流程

### 1. 环境准备
```bash
# 检查Node.js版本
node --version  # 应 >= 16.0.0

# 安装依赖
npm install
```

### 2. 运行测试
```bash
npm run test
```
应看到所有测试通过。

### 3. 启动应用
```bash
npm run dev
```
浏览器自动打开 `http://localhost:3000`

### 4. 验证功能

#### 步骤1：加载数据
- 点击 **"加载示例数据"**
- 观察数据加载完成提示
- 确认左侧面板显示"示例数据已加载"

#### 步骤2：观察3D场景
- 应看到8个彩色球体（无人机）
- 应看到3个红色半透明区域（禁飞区）
- 应看到灰色的轨迹线

#### 步骤3：控制时间轴
- 点击 **"播放"** 按钮
- 观察无人机沿轨迹移动
- 时间轴进度条同步更新
- 右侧状态面板实时更新

#### 步骤4：检测风险
- 播放到约20秒时，应检测到碰撞风险
- 某些无人机会飞入禁飞区，显示红色警告
- 电量不足的无人机会变成黄色/红色

#### 步骤5：添加标记
- 点击 **"暂停"** 暂停模拟
- 点击 **"标记当前位置"**
- 右下角面板显示新的人工标记

#### 步骤6：导出报告
- 点击 **"导出 Markdown"**
- 检查下载的文件内容
- 同样测试CSV和JSON导出

#### 步骤7：保存/加载会话
- 点击 **"保存会话"**
- 下载session.json文件
- 刷新页面后，点击 **"加载会话"**
- 选择刚才保存的文件，确认状态恢复

### 5. 构建生产版本
```bash
npm run build
```
检查`dist/`目录是否生成完整。

## 注意事项

1. **性能**: 大量无人机（>100架）可能影响帧率，建议分批模拟
2. **浏览器**: 推荐使用Chrome/Edge最新版本，确保WebGL支持
3. **数据格式**: 导入数据时请严格遵循格式要求，否则可能解析失败
4. **坐标系统**: 采用右手坐标系，Y轴为高度
