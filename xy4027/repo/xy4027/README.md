# 口播脱敏剪刀 ✂️

一款专为播客剪辑师和企业内训视频剪辑师设计的本地桌面小工具，用于快速检测和处理音频中的敏感信息。

## 功能特性

- **项目管理**: 支持创建、打开、删除项目，所有数据本地存储
- **多格式支持**: 
  - 音频: MP3, WAV
  - 转写: SRT, JSON（支持多种AI转写工具输出格式）
- **智能检测**: 内置多种敏感信息检测规则
  - 手机号（中国大陆格式）
  - 邮箱地址
  - 身份证号
  - 银行卡号
  - 地址关键词（省市区街道等）
  - 支持自定义规则包
- **音频处理**:
  - 播放/暂停/跳转
  - 按敏感片段快速跳转
  - 支持导出脱敏音频（静音替换 / 哔声替换）
- **人工复核**:
  - 按风险等级筛选
  - 标记为「保留、静音、哔声、需要复核」
  - 支持手动新增时间段
  - 添加备注
- **导出功能**:
  - 脱敏后的音频副本（不覆盖原始音频）
  - CSV / JSON 剪辑清单
  - Markdown 交付报告
- **边界处理**:
  - 转写时间重叠检测与提示
  - 时间超出音频长度时自动截断
  - 同一片段重复命中去重
  - 导出文件已存在时提示
  - 规则包格式错误时给出清楚提示

## 安装与启动

### 环境要求

- Python 3.8+
- macOS / Windows / Linux
- 建议使用虚拟环境

### 安装步骤

1. **创建虚拟环境（推荐）**

```bash
cd /path/to/xy4027
python3 -m venv venv
```

2. **激活虚拟环境**

macOS/Linux:
```bash
source venv/bin/activate
```

Windows:
```powershell
.\venv\Scripts\activate
```

3. **安装依赖**

```bash
pip install -r requirements.txt
```

### 启动程序

```bash
python main.py
```

## 使用指南

### 快速验证流程

使用项目内置的示例数据可以快速验证所有核心功能。

#### 1. 生成测试音频

```bash
cd samples
python generate_test_audio.py
```

这会在 `samples/` 目录下生成 `test_audio.wav` 文件（约65秒）。

#### 2. 创建新项目

1. 启动程序: `python main.py`
2. 点击左上角「新建项目」按钮
3. 输入项目名称，如「测试项目」
4. 点击「确定」

#### 3. 导入文件

在「项目」标签页：

1. 点击「加载音频」，选择 `samples/test_audio.wav`
2. 点击「加载转写」，选择 `samples/test_sample.srt`（或 `test_sample.json`）

系统会自动解析时间轴，切换到「导入预览」标签页可以查看解析结果。

**注意**: 如果转写文件中有时间重叠或超出音频长度的片段，系统会给出警告提示。

#### 4. 扫描敏感内容

1. 切换到「扫描」标签页
2. 点击「开始扫描敏感内容」按钮
3. 等待扫描完成

扫描完成后会显示：
- 风险分布统计（高/中/低风险数量）
- 命中列表表格

#### 5. 复核与标记

1. 切换到「复核与播放」标签页
2. 在表格中选中一个命中项，查看左侧详情
3. 在「标记状态」下拉框选择处理方式：
   - **需要复核**: 暂时标记，后续处理
   - **保留**: 确认不包含敏感信息，无需处理
   - **静音**: 导出时替换为静音
   - **哔声**: 导出时替换为提示音
4. 可以在「备注」文本框添加说明
5. 点击「应用」按钮

**快捷操作**:
- 双击表格中的行 → 直接跳转到对应时间并播放
- 使用筛选下拉框 → 按风险等级或处理状态筛选
- 点击「手动添加片段」→ 手工添加敏感时间段

#### 6. 导出结果

1. 切换到「导出」标签页
2. 点击「浏览...」选择输出目录
3. 勾选需要导出的内容：
   - 导出脱敏音频
   - 导出CSV清单
   - 导出JSON清单
   - 导出Markdown报告
4. （可选）勾选「覆盖已存在的文件」
5. 点击「开始导出」

导出完成后，在输出目录可以看到：
- `{项目名}_脱敏后.wav` (或.mp3)
- `{项目名}_剪辑清单.csv`
- `{项目名}_剪辑清单.json` (如果勾选)
- `{项目名}_交付报告.md`

#### 7. 验证重新打开项目

1. 关闭程序
2. 重新启动: `python main.py`
3. 在左侧项目列表中双击之前创建的项目
4. 验证：
   - 项目信息完整
   - 之前的扫描结果和人工标记都已保存
   - 可以继续编辑和导出

### 敏感规则说明

#### 内置规则

系统内置以下检测规则：

| 规则类型 | 说明 | 风险等级 |
|---------|------|---------|
| 手机号 | 中国大陆手机号格式（11位、带86前缀等） | 高 |
| 邮箱 | 标准邮箱格式 | 高 |
| 身份证号 | 18位身份证号格式 | 高 |
| 银行卡号 | 16-19位银行卡号格式 | 高 |
| 地址关键词 | 省市区街道楼号等关键词 | 中 |

#### 自定义规则

可以通过JSON文件加载自定义规则。格式参考 `samples/custom_rules.json`：

```json
{
  "version": "1.0",
  "created_at": "2024-01-01",
  "rules": [
    {
      "name": "合同编号",
      "rule_type": "custom",
      "pattern": "HT\\d{4,}",
      "is_regex": true,
      "risk_level": "high",
      "is_active": true,
      "description": "合同编号格式：HT前缀+数字"
    }
  ]
}
```

字段说明：
- `name`: 规则名称
- `rule_type`: 规则类型（phone/email/id_card/bank_card/address/custom）
- `pattern`: 匹配模式（字符串或正则表达式）
- `is_regex`: 是否为正则表达式（true/false）
- `risk_level`: 风险等级（high/medium/low）
- `is_active`: 是否启用
- `description`: 规则描述

### 转写格式说明

#### SRT格式

标准SRT字幕格式：

```
1
00:00:00,000 --> 00:00:05,000
这是第一句话的文本内容

2
00:00:05,500 --> 00:00:10,000
这是第二句话的文本内容
```

#### JSON格式

支持多种常见的AI转写工具输出格式：

**格式1 - segments数组**:
```json
{
  "segments": [
    {
      "start": 0.0,
      "end": 5.0,
      "text": "文本内容"
    }
  ]
}
```

**格式2 - words数组（单词级时间戳）**:
```json
{
  "words": [
    {"word": "大家好", "start": 0.0, "end": 0.8},
    {"word": "欢迎", "start": 0.9, "end": 1.2}
  ]
}
```

**格式3 - 直接数组**:
```json
[
  {"start": 0.0, "end": 5.0, "text": "文本内容"},
  {"start": 5.5, "end": 10.0, "text": "文本内容"}
]
```

支持的时间字段名：
- `start`, `startTime`, `start_time`, `begin`
- `end`, `endTime`, `end_time`, `stop`

时间值可以是：
- 数字（秒，如 `5.5`）
- 字符串时间格式（如 `"00:05:30"`）

### 数据存储

所有项目数据存储在本地SQLite数据库中：

- macOS: `~/.desensitize_scissors/projects.db`
- Windows: `C:\Users\{用户名}\.desensitize_scissors\projects.db`
- Linux: `~/.desensitize_scissors/projects.db`

数据库包含以下表：
- `projects`: 项目信息
- `segments`: 转写片段
- `sensitive_hits`: 敏感命中记录
- `custom_rules`: 自定义规则

**注意**: 数据库仅存储元数据，原始音频和转写文件不会被复制或修改。

## 注意事项

1. **原始音频保护**: 导出脱敏音频时，原始音频文件**不会被修改**，只会生成新的副本。

2. **时间轴匹配**: 系统使用字符位置比例估算敏感词在音频中的时间位置。如果转写准确度不高，建议在复核时手工调整。

3. **音频播放**: 音频播放基于简单的定时器模拟，可能与实际播放略有偏差。建议在专业音频软件中进行精确剪辑。

4. **哔声频率**: 默认哔声为800Hz正弦波，音量适中。如需调整频率或音量，可以修改 `core/audio_handler.py` 中的 `BEEP_FREQUENCY` 和 `BEEP_AMPLITUDE` 常量。

5. **自定义规则性能**: 大量复杂正则表达式可能影响扫描速度。建议保持规则简洁。

## 常见问题

**Q: 为什么扫描没有检测到某些敏感信息？**

A: 检查以下几点：
- 敏感信息是否在转写文本中？
- 是否被多个规则同时匹配导致去重？
- 自定义规则的正则表达式是否正确？

**Q: 导出的音频为什么没有声音？**

A: 可能原因：
- 所有片段都被标记为「静音」
- 原始音频文件已被删除或移动
- 导出过程出错（查看导出日志）

**Q: 为什么重新打开项目后音频无法播放？**

A: 音频文件的绝对路径保存在数据库中。如果原始文件被移动或重命名，需要重新加载音频文件。

**Q: 如何批量处理多个项目？**

A: 目前版本只能打开一个项目进行处理。可以创建多个项目分别处理，每个项目独立保存。
