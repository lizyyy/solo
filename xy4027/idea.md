## 原始点子

我想做一个给播客剪辑师和企业内训视频剪辑师用的本地桌面小工具，叫“口播脱敏剪刀”。我们经常拿到一段 wav/mp3 音频和一份人工转写的 SRT 或 JSON 时间轴，里面会夹着客户姓名、手机号、地址、合同编号、银行卡尾号这些不该交付出去的信息，靠人工拖时间线找很容易漏。请从 0 到 1 做一个可运行的桌面 GUI 应用，不要做成网页：用户可以创建项目，导入音频和转写文件；系统解析时间轴后，用可配置的规则包扫描敏感词和模式（手机号、邮箱、身份证片段、银行卡尾号、地址关键词、自定义名单），把命中的片段按风险等级列出来。界面上要能播放/暂停音频，按命中片段跳转，允许剪辑师把每条命中标记为“保留、静音、哔声、需要复核”，并能手动新增一个时间段。导出时要生成一份脱敏后的音频副本、CSV/JSON 剪辑清单和 Markdown 交付报告，原始音频不能被覆盖；项目数据要保存在本地 SQLite 或文件数据库里，重启后仍能看到项目、命中结果和人工标记。请认真处理边界：转写时间重叠、时间超出音频长度、同一片段重复命中、导出文件已存在、规则包格式错误时都要给出清楚提示。希望代码拆成 GUI 界面、音频处理、转写解析、敏感规则引擎、项目存储、导出报告和示例数据/测试等多个文件，并写好 README，说明如何安装、启动，以及如何用一个很短的示例音频验证导入、扫描、复核、导出和重新打开项目这些核心流程。
