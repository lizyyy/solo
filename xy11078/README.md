# 乡镇客运站客运退票手续费 API

## 项目简介

本系统为乡镇客运站提供退票手续费管理服务，支持完整的审计追踪、多条件筛选、批量导入和数据导出功能。

## 技术栈

- Python 3.8+
- FastAPI
- SQLAlchemy (SQLite)
- Pandas + OpenPyXL (Excel导出)

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 初始化样例数据

```bash
python init_sample_data.py
```

样例数据包含：
- 6条退票手续费记录（覆盖2024年1月-3月）
- 6条历史变更记录
- 包含跨日期、跨门店、旧记录修正等真实业务场景

### 3. 启动服务

```bash
python main.py
```

服务启动后访问: http://localhost:8000/docs

## 二、修改退票记录

### 更新记录

**接口**: `PUT /api/refund-fees/{退票单号}`

**请求示例 (curl)**:
```bash
curl -X PUT "http://localhost:8000/api/refund-fees/TK202402100004" \
-H "Content-Type: application/json" \
-d '{
  "当前状态": "已完成",
  "审核人": "王审核",
  "审核时间": "2024-05-20T15:00:00",
  "操作人": "张主管",
  "IP地址": "192.168.1.200"
}'
```

### 查看变更历史

**接口**: `GET /api/refund-fees/{退票单号}/history`

**请求示例 (curl)**:
```bash
curl -X GET "http://localhost:8000/api/refund-fees/TK202401050005/history"
```

## 三、查询退票记录

### 列表查询（支持多条件筛选）

**接口**: `GET /api/refund-fees/`

**支持的筛选条件**:
- `start_date`: 开始日期 (YYYY-MM-DD)
- `end_date`: 结束日期 (YYYY-MM-DD)
- `状态`: 当前状态（待审核、已完成、已拒绝）
- `负责人`: 负责人姓名（模糊匹配）
- `门店`: 门店名称（模糊匹配）
- `班次号`: 班次号（模糊匹配）
- `退票类型`: 退票类型（个人原因、班车原因）
- `是否旧记录修正`: 是否为旧记录修正（true/false）
- `skip`: 跳过条数
- `limit`: 返回条数限制

**查询示例**:

1. **按日期范围查询**:
```bash
curl -X GET "http://localhost:8000/api/refund-fees/?start_date=2024-01-01&end_date=2024-01-31"
```

2. **按状态+负责人查询**:
```bash
curl -X GET "http://localhost:8000/api/refund-fees/?状态=已完成&负责人=李芳"
```

3. **按门店+退票类型查询**:
```bash
curl -X GET "http://localhost:8000/api/refund-fees/?门店=县城客运站&退票类型=个人原因"
```

4. **查询旧记录修正数据**:
```bash
curl -X GET "http://localhost:8000/api/refund-fees/?是否旧记录修正=true"
```

### 单条查询

**接口**: `GET /api/refund-fees/{退票单号}`

**请求示例**:
```bash
curl -X GET "http://localhost:8000/api/refund-fees/TK202401150001"
```

## 四、导出数据

### JSON格式导出

**接口**: `GET /api/refund-fees/export/json`

**支持筛选条件**: 同列表查询（日期、状态、负责人、门店）

**请求示例**:
```bash
curl -X GET "http://localhost:8000/api/refund-fees/export/json?start_date=2024-01-01&end_date=2024-03-31" \
-o refund_export.json
```

### Excel格式导出

**接口**: `GET /api/refund-fees/export/excel`

**支持筛选条件**: 同列表查询

**请求示例**:
```bash
curl -X GET "http://localhost:8000/api/refund-fees/export/excel?门店=县城客运站&状态=已完成" \
-o refund_export.xlsx
```

## 业务字段说明

| 字段名 | 说明 |
|--------|------|
| 退票单号 | 系统自动生成，格式 TK + 日期(YYYYMMDD) + 序号(4位) |
| 原购票单号 | 对应原购票记录编号 |
| 乘车日期 | 原定乘车日期时间 |
| 退票日期 | 实际退票日期时间 |
| 班次号 | 客运班次编号 |
| 起点站/终点站 | 出发和到达站点 |
| 乘客姓名/身份证号/联系电话 | 乘客信息 |
| 原票价 | 原始购票金额 |
| 退票手续费比例 | 手续费百分比 |
| 退票手续费金额 | 实际收取的手续费 |
| 实退金额 | 实际退还乘客金额 |
| 退票原因 | 退票具体原因说明 |
| 退票类型 | 个人原因 / 班车原因 |
| 班次状态 | 正常 / 停运 |
| 门店名称/门店编号 | 办理退票的门店 |
| 负责人姓名 | 办理退票的工作人员 |
| 审核人/审核时间 | 审核信息 |
| 当前状态 | 待审核 / 已完成 / 已拒绝 |
| 是否旧记录修正 | 标识是否为历史数据修正 |
| 修正原因 | 旧记录修正的原因说明 |

## 特殊业务处理

1. **班次停运规则**: 当班次状态为"停运"且退票类型为"个人原因"时，系统自动将手续费调整为0，全额退款。

2. **手续费一致性校验**: 导入时自动校验 `手续费金额 = 原票价 × 手续费比例 / 100`，不一致时自动修正。

3. **审计追踪**: 所有创建、修改、导入操作均记录完整历史，包括操作人、操作时间、变更字段、IP地址。
