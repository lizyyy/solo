# 工地通行资格访客时段安全拦截排查CLI

一个用于工地闸机通行记录检查的命令行工具，整合人员档案、访客申请、安全培训状态、黑名单记录进行综合校验。

## 核心功能

- **人员档案校验**: 验证通行人员是否有有效档案
- **访客时段校验**: 检查访客通行时间是否在申请的访问时段内
- **安全培训状态检查**: 验证人员安全培训是否有效
- **黑名单拦截**: 自动拦截黑名单人员
- **重复事件去重**: 自动识别并标记重复闸机记录
- **来源追踪**: 每条记录保留原始文件位置信息
- **坏记录处理**: 解析错误的记录单独保留，不影响整体流程
- **结果稳定**: 相同输入产生一致的检查结果

## 使用方法

### 1. 生成测试模板

```bash
python3 main.py template <输出文件.xlsx>
```

模板包含5个工作表：
- **人员档案**: 员工、承包商、访客的基本信息
- **闸机记录**: 闸机通行事件记录
- **访客申请**: 访客的访问申请和时段
- **培训状态**: 安全培训记录和状态
- **黑名单**: 黑名单人员记录

### 2. 执行检查并导出报告

```bash
python3 main.py check <输入文件.xlsx> [--output 输出文件.xlsx] [--verbose]
```

## 输出报告内容

检查结果Excel包含4个工作表：

1. **统计汇总**: 总体统计信息，包括：
   - 总事件数、通过数、警告数、拦截数
   - 通过率
   - 坏记录数
   - 各规则违规次数统计

2. **检查结果明细**: 每条闸机记录的详细检查结果，包含：
   - 事件基本信息（ID、人员、时间、闸机等）
   - 最终状态和消息
   - 各数据源位置追踪（人员档案、闸机记录、访客申请等来源）

3. **规则明细**: 每条规则的执行详情

4. **坏记录**: 解析过程中出错的记录，保留：
   - 来源文件、工作表、行号
   - 错误类型和消息
   - 原始内容

## 核心规则说明

| 规则名称 | 检查内容 | 结果类型 |
|---------|---------|---------|
| 黑名单拦截 | 检查人员是否在有效的黑名单中 | BLOCK |
| 访客时段校验 | 检查访客通行时间是否在申请时段内 | BLOCK |
| 安全培训状态 | 检查安全培训是否有效、未过期 | WARN/BLOCK |
| 人员档案校验 | 检查是否存在人员档案 | WARN |
