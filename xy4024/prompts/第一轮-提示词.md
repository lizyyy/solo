我想做一个给徒步领队用的本地命令行工具，叫“轨迹净化和行程报告器”。每次活动结束后，队员发来的 GPX/KML 轨迹经常混着 GPS 漂移、断点、重复时间戳和海拔毛刺，靠手工在地图软件里修很费时间。请从 0 到 1 做一个可运行的 Python CLI 项目：init 命令能创建项目配置，维护时区、速度阈值、断点阈值、海拔突变阈值和默认导出目录；import 命令能读取 GPX、KML 或 CSV 轨迹文件并保留原始文件不被覆盖；clean 命令先给出 dry-run 清洗计划，识别重复时间戳、时间倒序、瞬时速度不合理、长时间断点、海拔尖峰和坐标缺失，再按配置生成清洗后的轨迹段；summary 命令要计算总距离、移动时间、累计爬升/下降、平均速度、移动速度，并能结合一份检查点 CSV 标记哪些检查点实际经过；compare 命令能把计划路线和实际路线对比，提示偏离路线的区间、漏掉的检查点和异常停留；export 命令能导出清洗后的 GPX、GeoJSON、Markdown 报告和 CSV 摘要；history 命令能从本地 JSON 或 SQLite 数据目录查询过去的清洗任务。希望核心代码拆成 CLI 入口、轨迹解析、地理计算、异常规则、清洗计划、存储层、报告导出和示例数据/测试，不要做成单文件演示。README 请写清楚安装方式、示例命令，以及如何用临时目录验证 import、clean、summary、compare、export、history 的完整流程。
