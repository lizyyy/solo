# 摄像头盲区巡检沙盘

一个面向地下停车场运维员的本地3D交互工具，用于可视化分析摄像头盲区、视锥重叠和通道覆盖风险。

## 功能特性

- **3D场景渲染**: 使用Three.js构建沉浸式地下停车场3D场景
- **多元素编辑**: 支持导入/编辑墙体、立柱、摄像头、车位和重点通道
- **视锥体可视化**: 实时显示摄像头视锥体范围
- **遮挡检测**: 智能计算立柱和墙体造成的遮挡区域
- **覆盖热度图**: 彩色显示停车场各区域的监控覆盖程度
- **拖拽交互**: 支持拖拽调整摄像头位置和朝向
- **参数调整**: 可实时调整摄像头焦距、高度、视角等参数
- **风险分析**: 
  - 盲区检测 - 找出未被监控覆盖的区域
  - 重叠检测 - 发现摄像头资源浪费的情况
  - 通道覆盖 - 检测关键通道是否完全覆盖
- **本地存储**: 自动保存场景到浏览器localStorage
- **数据导出**: 支持导出JSON布局文件和Markdown巡检报告

## 使用说明

### 界面布局

- **顶部工具栏**: 新建、保存、导入/导出、添加元素按钮
- **左侧边栏**: 摄像头、车位、通道列表
- **中央区域**: 3D场景视图
- **右侧边栏**: 属性编辑面板和风险分析结果
- **左上角**: 场景统计信息

### 基本操作

#### 场景导航
- **鼠标左键**: 选择物体 / 拖拽物体
- **鼠标滚轮**: 缩放视图
- **鼠标右键拖动**: 旋转视角
- **中键拖动**: 平移视图

#### 添加元素
点击顶部工具栏的对应按钮：
- 🧱 **添加墙体** - 在场景中心创建新墙体
- 🏛️ **添加立柱** - 在场景中心创建新立柱
- 📹 **添加摄像头** - 在场景中心创建新摄像头
- 🅿️ **添加车位** - 在场景中心创建新车位
- 🚗 **添加通道** - 在场景中心创建新通道

#### 编辑属性
1. 点击选择场景中的物体
2. 右侧属性面板会显示该物体的可编辑属性
3. 修改数值后会自动更新

#### 摄像头参数
- **安装高度**: 摄像头离地高度（米）
- **视角 (FOV)**: 水平视角角度（30°-120°）
- **朝向角度**: 水平旋转角度
- **最远距离**: 有效监控距离

### 风险分析

1. 点击工具栏的 **⚠️ 计算风险** 按钮
2. 系统会自动分析：
   - **监控盲区**: 红色区域表示未被任何摄像头覆盖
   - **视锥体重叠**: 黄色/红色提示表示摄像头覆盖范围重叠过多
   - **通道覆盖**: 检查关键通道是否达到80%覆盖率
   - **车位覆盖**: 检查车位是否达到60%覆盖率
3. 右侧风险面板会显示详细风险列表
4. 场景中会显示**热度图**：
   - 🔴 红色: 盲区（0个摄像头覆盖）
   - 🟡 黄色: 低度覆盖（1-2个摄像头）
   - 🟢 绿色: 高度覆盖（3+个摄像头）

### 数据管理

#### 保存与恢复
- 系统每30秒自动保存到浏览器localStorage
- 刷新页面后会自动加载上次保存的场景
- 点击 **💾 保存** 按钮可立即保存

#### 导入/导出
- **📤 导出JSON**: 下载当前场景布局为JSON文件
- **📋 导出报告**: 生成Markdown格式的巡检报告
- **📥 导入**: 加载已保存的JSON布局文件

#### 加载示例
点击 **🎯 加载示例** 按钮可加载预设的示例停车场场景，包含：
- 5面墙体（四周墙壁+中央分隔墙）
- 6根立柱
- 5个摄像头（4个角+中央全景）
- 16个车位（A、B、C、D四个区域）
- 5条关键通道

## 技术栈

- **Three.js**: 3D渲染引擎
- **Vite**: 构建工具和开发服务器
- **OrbitControls**: 相机控制
- **localStorage**: 本地数据持久化

## 模块说明

### 几何计算 (src/geometry/index.js)
- `calculateViewFrustum`: 计算视锥体顶点和平面
- `calculateHeatMap`: 计算覆盖热度图
- `checkPointBlocked`: 检测点是否被障碍物遮挡
- `calculateViewFrustumOverlap`: 计算两个视锥体的重叠度

### 场景渲染 (src/scene/index.js)
- `SceneRenderer`: 管理Three.js场景、相机、灯光
- `createWall/Pillar/Camera/Parking/Passage`: 创建各类物体
- `createHeatMap`: 渲染热度图到场景
- `updateCameraFrustum`: 更新摄像头视锥体显示

### 风险分析 (src/rules/index.js)
- `analyze`: 执行完整风险分析
- `analyzeBlindSpots`: 检测盲区聚类
- `analyzeOverlaps`: 检测视锥体重叠
- `analyzePassages`: 检测通道覆盖率
- `calculateObjectCoverage`: 计算单个物体的覆盖率

## 注意事项

1. **本地应用**: 这是纯前端应用，数据只保存在浏览器本地
2. **浏览器兼容**: 建议使用Chrome/Edge最新版本
3. **性能提示**: 大量物体（>100个摄像头）可能影响性能
4. **数据备份**: 建议定期导出JSON文件作为备份
