# 股票新闻快反局

投资社团新闻事件快速反应训练系统。解决投影大屏复盘时暂停后局面混乱的问题，让每一次训练都有完整记录可追溯。

---

## 快速开始

### 怎么启动？

1. **安装依赖**
   ```bash
   npm install
   ```

2. **启动开发服务器**
   ```bash
   npm run dev
   ```

3. **访问应用**
   浏览器打开终端提示的地址（默认 `http://localhost:5173`，如端口被占用会自动递增）

4. **开始一局**
   - 默认加载"2024年春季学期 第3周训练"配置
   - 点击左侧控制面板的"开始对局"按钮
   - 点击新闻下方的"基于此新闻交易"按钮，选择买入/卖出/观望，设置仓位后确认
   - 点击"下一回合"继续，直到所有回合结束自动结算，或随时点击"手动结算"提前结束

## 核心功能

### 怎么换一组关卡？

1. 点击首页右上角的**齿轮图标**，或访问 `/config`
2. 选择预设关卡（共4组）：
   - **2024年春季学期 第3周训练**：正常配置，5回合，含3类来源样例
   - **测试配置-含空关卡**：第2回合无新闻，用于测试异常处理
   - **测试配置-含重复事件**：第1回合有重复ID的新闻
   - **测试配置-含边界异常**：影响指数超出[-100,100]范围
3. 或点击"上传自定义配置"上传JSON格式的关卡文件
4. 系统自动检测配置异常（空关卡/重复事件/边界值），可点击"自动修复边界和重复问题"一键修复
5. 确认无误后点击"加载此配置"，回到首页即可开始新局

> 💡 **配置格式说明**：详见 `/help` 页面或 `src/data/sample-levels/` 下的样例文件

---

### 怎么看一局的历史？

#### 查看历史记录列表
- 点击首页右上角的**时钟图标**，或访问 `/history`
- 列表展示所有已完成对局的关键指标：收益率、胜率、最大回撤、交易次数等

#### 查看完整报告
- 结算后页面上方出现"查看报告"按钮（吸顶显示），直接点击即可进入报告页
- 也可在历史记录列表点击任意记录或"报告"按钮
- 报告包含：
  - 关键绩效指标（总收益、年化收益、胜率、最大回撤、结算原因等）
  - 交易明细表（可展开查看决策理由和新闻来源追溯）
  - 最终持仓明细
  - 支持导出 **CSV** 和 **JSON** 格式

#### 回放对局过程
- 在历史记录列表点击"回放"按钮，或在报告页点击"回放对局"
- 支持：
  - 逐回合查看当时的新闻、交易决策和资产状态
  - 播放/暂停、上一回合、下一回合、回到开始、跳到结尾控制
  - 0.5x / 1x / 2x / 4x 倍速播放
  - 点击时间轴跳转到任意回合

## 核心操作说明

| 操作 | 说明 |
|------|------|
| **开始对局** | 从待开始状态进入进行中状态，开始计时 |
| **暂停** | 锁定当前局面，回合数和持仓保持不变，弹出暂停遮罩 |
| **继续** | 从暂停处恢复，局面保持一致 |
| **下一回合** | 保存当前回合数据，进入下一回合 |
| **手动结算** | 提前结束对局，生成最终报告 |
| **重新开始** | 重置所有数据，开始新的一局 |

## 样例数据说明

"2024年春季学期 第3周训练"关卡包含3类典型新闻记录：

1. **顺利记录**（news-001）：茅台业绩超预期
   - 来源类型：auto（自动采编，置信度高）
   - 来源：路透社
   - 可直接基于此新闻交易

2. **需要人工确认**（news-003）：宁德时代传闻
   - 来源类型：need_confirm（待确认，置信度中）
   - 来源：市场传闻
   - 带"待确认"标识，提醒交易前需要核实

3. **旧口径记录**（news-004）：2019年降准历史数据
   - 来源类型：manual（人工补录旧口径，置信度低）
   - 来源：旧口径-投影大屏
   - 带"旧口径"标识，提醒注意时效性

> 每条新闻都保留：原始来源、处理人（小林）、处理时间，别人接手时不用再问这条为什么这么判。

## 异常处理机制

系统会自动检测并处理以下配置异常：

| 异常类型 | 检测方式 | 修复方式 |
|----------|----------|----------|
| **空关卡** | 某回合没有新闻事件 | 标记提醒，可确认后继续 |
| **重复事件** | 同一回合内新闻ID重复 | 自动去重，保留第一条 |
| **边界异常** | 影响指数超出[-100,100] | 自动钳位到边界值 |

---

## 数据一致性保证

- **报告和明细同源**：结算时通过同一数据源生成报告汇总和交易明细，不会出现两套说法
- **状态持久化**：对局状态实时保存到 LocalStorage，刷新页面不丢失
- **暂停锁定**：暂停时锁定所有修改操作，确保暂停/继续/重开后回合数和结算原因稳定

## 技术栈

- **前端框架**：React 18 + TypeScript 5
- **构建工具**：Vite 5
- **状态管理**：Zustand 4（带 persist 中间件）
- **样式方案**：TailwindCSS 3 + CSS Variables
- **路由**：React Router 7
- **图表**：Recharts 2
- **图标**：Lucide React
- **数据存储**：LocalStorage（纯前端，无后端）
