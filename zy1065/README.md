# ⚡ 电费分析小工具

一个基于 Streamlit 的本地电费分析工具，帮助你分析智能电表数据，优化用电时间，节省电费支出。

## ✨ 功能特性

### 📊 数据导入与校验
- 支持导入 CSV 格式的智能电表数据
- 内置示例数据，可直接体验
- 完整的数据校验：
  - 检查必需列是否存在
  - 验证日期和时间格式
  - 检测负值和异常高值
  - 自动处理重复记录

### 💰 电价配置
- 支持峰/平/谷多时段电价配置
- 可自定义各时段的时间范围和价格
- 自动检查时段重叠和覆盖完整性
- 支持跨天时段（如 22:00 - 次日 08:00）

### 📈 用电分析
- **每日趋势图**：展示每日用电量变化
- **小时分布图**：24小时用电分布，标注峰平谷时段
- **峰谷对比图**：饼图展示各时段用电和电费占比
- **用电热力图**：直观展示日期x小时的用电热度
- **异常检测**：自动识别异常高用电时段

### 🔧 任务管理
- 维护可挪动的用电任务（如洗衣、烘干、充电等）
- 预设常用任务模板：
  - 洗衣机 (1.2 kWh)
  - 烘干机 (2.5 kWh)
  - 热水器 (3.0 kWh)
  - 电动车充电 (30.0 kWh)
  - 洗碗机 (0.8 kWh)
- 可自定义任务的用电量、持续时间、时间窗口和最大延迟

### 🎯 错峰优化
- 智能算法计算最优运行时间
- 考虑电价差异和时间约束
- 输出详细的优化方案：
  - 原始安排 vs 推荐安排
  - 预计节省金额和比例
  - 延迟时间检查
- 标记超出约束的任务

### 📄 报告导出
- 支持 Markdown 和 HTML 两种格式
- 报告包含：
  - 数据摘要
  - 电价配置
  - 峰谷用电分析
  - 异常高耗电时段
  - 错峰优化分析
  - 优化建议

## 🚀 快速开始

### 1. 环境准备

确保你的电脑已安装 Python 3.8 或更高版本。

```bash
# 检查 Python 版本
python --version
```

### 2. 安装依赖

```bash
# 进入项目目录
cd /path/to/electricity-analyzer

# 安装依赖包
pip install -r requirements.txt
```

依赖包包括：
- `streamlit` - Web 应用框架
- `pandas` - 数据处理
- `plotly` - 可视化图表
- `markdown2` - Markdown 转 HTML

### 3. 启动应用

```bash
streamlit run app.py
```

应用启动后，会自动在默认浏览器中打开。如果没有自动打开，可以手动访问终端显示的本地地址（通常是 `http://localhost:8501`）。

## 📖 使用指南

### 第一步：导入数据

1. 启动应用后，进入「📊 数据导入」页面
2. 可以选择：
   - **上传自己的数据**：点击文件上传框，选择 CSV 文件
   - **加载示例数据**：点击侧边栏的「📥 加载示例数据」按钮

#### 数据格式要求

CSV 文件应包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| 日期 | 日期，格式为 YYYY-MM-DD | 2024-04-01 |
| 小时 | 小时，0-23 的整数 | 18 |
| 用电量(kWh) | 该小时的用电量（度） | 2.45 |

支持的列名别名：
- 日期：`date`, `Date`, `时间`, `time`, `Time`
- 小时：`hour`, `Hour`, `时段`
- 用电量(kWh)：`用电量`, `kWh`, `consumption`, `Consumption`, `usage`, `Usage`

### 第二步：配置电价

1. 进入「💰 电价配置」页面
2. 查看当前时段配置
3. 可进行以下操作：
   - **添加新时段**：设置时段名称、时间范围和价格
   - **编辑现有时段**：修改已有的时段配置
   - **删除时段**：移除不需要的时段
   - **重置为默认配置**：恢复到预设的峰谷电价

#### 默认电价配置

| 时段 | 时间范围 | 电价 (元/kWh) |
|------|----------|---------------|
| 峰 | 08:00 - 21:00 | 0.977 |
| 谷 | 22:00 - 07:00 | 0.307 |

> 注：默认配置以上海居民阶梯电价为例，请根据当地实际电价调整。

### 第三步：用电分析

1. 进入「📈 用电分析」页面
2. 使用筛选器：
   - 日期范围：选择要分析的日期区间
   - 小时范围：筛选特定时段
3. 浏览各个图表标签页：
   - **📅 每日趋势**：查看每日用电量变化
   - **⏰ 小时分布**：分析24小时用电规律
   - **📊 峰谷对比**：比较各时段的用电和电费
   - **🔥 热力图**：直观发现用电高峰
   - **⚠️ 异常检测**：找出异常高用电时段

### 第四步：管理用电任务

1. 进入「🔧 任务管理」页面
2. 查看预设任务列表
3. 可进行以下操作：
   - **添加新任务**：设置任务名称、用电量、持续时间、可用时段等
   - **编辑任务**：修改现有任务的参数
   - **启用/禁用**：控制任务是否参与优化
   - **删除任务**：移除不需要的任务

#### 任务参数说明

| 参数 | 说明 | 示例 |
|------|------|------|
| 任务名称 | 任务的描述性名称 | 洗衣机 |
| 用电量 (kWh) | 预计用电量（度） | 1.2 |
| 持续时间 (小时) | 任务运行时长 | 1.5 |
| 可用时段 - 开始 | 最早可以开始的小时 | 22（表示22:00） |
| 可用时段 - 结束 | 最晚可以运行的小时 | 7（表示次日07:00） |
| 最大延迟 (小时) | 从偏好时间开始的最大允许延迟 | 10 |

### 第五步：错峰优化

1. 进入「🎯 错峰优化」页面
2. 查看当前电价分布图
3. 点击「🚀 开始优化」按钮
4. 查看优化结果：
   - 汇总统计：优化前后费用对比、预计节省
   - 任务详情：每个任务的原始安排和推荐安排
   - 问题警告：标记超出约束的任务

### 第六步：导出报告

1. 进入「📄 报告导出」页面
2. 选择报告格式：
   - Markdown：适合编辑和分享
   - HTML：适合浏览器查看
3. 选择是否包含错峰优化分析
4. 点击「📄 生成报告」
5. 预览报告并下载

## 🔧 数据校验说明

工具会对导入的数据进行以下校验：

### 错误（会导致导入失败）

| 错误类型 | 说明 |
|----------|------|
| 缺少必需列 | CSV 缺少日期、小时或用电量列 |
| 日期格式错误 | 日期无法解析为有效格式 |
| 小时值无效 | 小时不在 0-23 范围内 |
| 用电量为负 | 用电量包含负值 |

### 警告（不影响导入，但需要注意）

| 警告类型 | 说明 |
|----------|------|
| 缺失值 | 用电量列包含空值（自动填充为 0） |
| 重复记录 | 存在相同日期+小时的记录（保留第一条） |
| 异常高值 | 用电量超过平均值 3 倍标准差 |

## ⚙️ 电价配置校验

配置电价时段时，系统会检查：

1. **时段重叠**：两个时段不能包含相同的小时
2. **覆盖完整**：所有 24 小时都应被某个时段覆盖
3. **价格有效**：电价不能为负数

## 💡 使用技巧

### 1. 如何确定可用时段？

对于每个用电任务，考虑以下因素：
- **使用需求**：什么时候需要使用这个电器？
- **灵活性**：是否可以提前或延后？
- **生活习惯**：是否受作息时间限制？

例如：
- 洗衣机：可以在晚上洗完澡后运行，也可以延迟到睡觉后 → 可用时段 20:00 - 次日 08:00
- 电动车充电：通常晚上回家后开始，第二天早上需要充满 → 可用时段 22:00 - 次日 07:00

### 2. 如何设置最大延迟？

最大延迟是指从你"通常"使用的时间开始计算，最多可以延后多久。

例如：
- 你通常在晚上 20:00 开洗衣机
- 最多可以延迟到第二天早上 06:00
- 那么最大延迟就是 10 小时

### 3. 优化结果解读

- **节省金额为正**：表示优化后更省钱
- **节省金额为零**：表示已经在最优时段
- **状态为"⚠️ 延迟过长"**：表示推荐时间超出了你设定的最大延迟

### 4. 异常时段排查

如果发现异常高用电时段，可以：
1. 记录具体的日期和时间
2. 回忆当时使用了哪些电器
3. 检查是否有设备故障（如冰箱门没关、空调故障等）
4. 考虑是否需要调整用电习惯

## 📋 常见问题

### Q1: 支持哪些数据格式？

目前只支持 CSV 格式。如果你的数据是 Excel 格式，请先另存为 CSV。

### Q2: 日期格式有什么要求？

支持大多数常见的日期格式，包括：
- `2024-04-01`（推荐）
- `2024/04/01`
- `04-01-2024`
- `2024年4月1日`

### Q3: 为什么优化后没有节省？

可能的原因：
1. 任务已经在谷时段运行
2. 可用窗口内没有更便宜的时段
3. 电价差异太小

### Q4: 如何保存我的配置？

目前配置保存在浏览器会话中，刷新页面会重置。建议在导出报告前完成所有配置。
