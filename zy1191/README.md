# 虚拟内存和内存池实验台

一个用于教学目的的本地实验平台，帮助理解虚拟内存管理和内存池机制。

## 功能特性

### 虚拟内存模拟器
- **虚拟地址翻译**：演示虚拟地址如何通过页表和TLB翻译成物理地址
- **页表管理**：展示页表的结构和状态变化
- **TLB缓存**：模拟Translation Lookaside Buffer的命中/未命中机制
- **置换算法**：支持FIFO、LRU和Optimal三种置换策略
- **可视化展示**：
  - 访问时间线（TLB命中、缺页、置换）
  - 页表状态
  - TLB条目状态
  - 物理内存映射

### 内存池/对象池模拟器
- **对象池**：固定大小的内存块分配
- **内存池**：可变大小的内存分配
- **对齐规则**：支持1/2/4/8/16/32字节对齐
- **碎片统计**：
  - 内部碎片（因对齐产生的浪费）
  - 外部碎片（不连续的空闲空间）
- **可视化展示**：
  - 操作时间线
  - 池槽位状态
  - 内存映射图
  - 填充和碎片统计

### 实验管理功能
- **保存实验**：将当前配置和结果保存到本地存储
- **加载实验**：重新加载已保存的实验
- **对比实验**：同时对比多个同类型实验的配置和结果
- **导出报告**：
  - JSON格式（完整数据）
  - Markdown格式（结构化报告）

## 使用指南

### 虚拟内存实验

1. **配置参数**：
   - 页大小：选择1KB、2KB、4KB或8KB
   - 物理页数：设置物理内存的帧数量
   - TLB容量：设置TLB的条目数（设为0禁用TLB）
   - 置换策略：选择FIFO、LRU或Optimal
   - 访问序列：输入虚拟地址序列（空格分隔）
   - 随机种子：可选，用于生成随机访问序列

2. **运行模拟**：点击"运行模拟"按钮

3. **查看结果**：
   - 统计信息：TLB命中率、缺页率、总访问次数、置换次数
   - 访问时间线：详细记录每次访问的事件
   - 页表状态：显示页表的最终状态
   - TLB状态：显示TLB条目的使用情况
   - 物理内存：显示物理帧的占用情况

### 内存池实验

1. **配置参数**：
   - 池类型：选择"对象池"（固定大小）或"内存池"（可变大小）
   - 总池大小：设置池的总字节数
   - 对象/块大小：对象池的单个对象大小
   - 对齐规则：选择1/2/4/8/16/32字节对齐
   - 操作序列：格式为 `alloc:大小` 或 `free:分配ID`，空格分隔

2. **运行模拟**：点击"运行模拟"按钮

3. **查看结果**：
   - 统计信息：空间使用率、内部碎片率、外部碎片、分配失败次数
   - 池槽位状态：每个槽位的详细信息
   - 内存映射：可视化展示内存使用情况
   - 操作时间线：记录每次分配/释放的详情

### 实验管理

1. **保存实验**：
   - 在"实验管理"标签页输入实验名称
   - 点击"保存"按钮保存当前实验

2. **加载/删除实验**：
   - 在已保存实验列表中点击"加载"或"删除"

3. **对比实验**：
   - 按住Ctrl键多选要对比的实验
   - 点击"对比选中实验"按钮

4. **导出报告**：
   - 点击"导出JSON"下载完整数据
   - 点击"导出Markdown"下载结构化报告

## 核心概念

### 虚拟内存术语

| 术语 | 说明 |
|------|------|
| 虚拟地址 | 程序使用的逻辑地址 |
| 物理地址 | 实际内存中的地址 |
| 页 (Page) | 虚拟内存的管理单位 |
| 帧 (Frame) | 物理内存的管理单位 |
| 页表 (Page Table) | 存储虚拟页到物理帧的映射 |
| TLB | Translation Lookaside Buffer，页表缓存 |
| 缺页 (Page Fault) | 访问的页不在物理内存中 |
| 置换 (Replacement) | 腾出物理帧加载新页 |

### 置换算法

- **FIFO** (First-In, First-Out)：最早进入内存的页先被置换
- **LRU** (Least Recently Used)：最近最少使用的页先被置换
- **Optimal**：未来最久不使用的页先被置换（理论最优）

### 内存池术语

| 术语 | 说明 |
|------|------|
| 对象池 | 预分配固定大小的内存块 |
| 内存池 | 预分配可变大小的内存区域 |
| 对齐 | 内存地址按特定边界对齐 |
| 内部碎片 | 对齐导致的内存浪费 |
| 外部碎片 | 不连续的空闲空间 |
| 槽位 (Slot) | 池中的内存块 |

## 示例数据

### 虚拟内存示例序列

经典Belady异常示例（3个物理帧）：
```
0 4096 8192 0 12288 4096 16384 0 4096 12288 16384
```

这个序列展示了FIFO可能比LRU表现更差的情况。

### 内存池示例操作

```
alloc:256 alloc:512 alloc:128 free:1 alloc:384 free:0 alloc:256
```

这个序列演示了内存分配和释放的基本操作。
