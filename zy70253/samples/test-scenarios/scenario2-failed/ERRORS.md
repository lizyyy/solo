# 场景2 - 失败原因说明

此场景包含以下数据错误，用于测试 CLI 的错误检测功能：

## 门禁日志 (access_log.csv) 错误
- 行3: 缺少时间戳 (timestamp 为空)
- 行4: 缺少门禁ID (doorId 为空)
- 行6: 无效的时间戳格式 (INVALID_DATE)

## 温度数据 (temperature.csv) 错误
- 行3: 无效的温度值 (INVALID)
- 行5: 缺少时间戳

## 货品批次 (batches.csv) 错误
- 行2: 缺少批次ID (batchId 为空)
- 行3: 入库时间晚于出库时间 (2024-01-25 > 2024-01-18)

## 班次排班 (shifts.csv) 错误
- 行2: 缺少班次名称 (shiftName 为空)

## 修正方法 (参考 scenario3-fixed)
1. 补充缺少的时间戳和门禁ID
2. 修正无效的日期格式
3. 修正温度值为有效数字
4. 补充批次ID
5. 修正入库/出库时间顺序
6. 补充班次名称
