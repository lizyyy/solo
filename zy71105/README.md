# 舞台灯光束预演系统

一个基于 Three.js 的交互式 3D 舞台灯光预演工具，帮助灯光师在换场时预判灯束是否会打到观众区或遮住字幕屏。

## 功能特性

### 🎭 3D 灯光可视化
- **实时 3D 渲染**: 使用 Three.js 渲染舞台、灯具和光束
- **可拖拽操作**: 支持拖拽调整灯具位置和照射目标点
- **光束效果**: 自定义着色器实现半透明光束效果
- **禁区检测**: 观众区和字幕屏区域高亮显示

### ⏱️ 时间轴控制
- **节目段落**: 支持多个节目段落切换
- **播放控制**: 播放/暂停、上一段/下一段跳转
- **进度条**: 可点击进度条快速定位时间点

### 🔍 灯具管理
- **筛选功能**: 按分组筛选和搜索灯具
- **开关控制**: 单独控制每个灯具的开启/关闭
- **状态指示**: 碰撞警告高亮显示

### ⚠️ 碰撞检测
- **实时检测**: 自动检测光束是否进入禁区
- **警告分级**: 严重警告（字幕屏）和一般警告（观众区）
- **详细信息**: 显示碰撞灯具、区域和描述

### 💾 场景管理
- **导入样例**: 一键加载预置样例场景
- **导入/导出**: 支持 JSON 格式场景文件
- **状态持久化**: 刷新页面后筛选和状态不丢失
- **重置功能**: 快速恢复到初始状态

### 📊 报告导出
- **HTML 报告**: 导出包含碰撞警告的完整报告
- **打印功能**: 支持打印报告
- **统计信息**: 灯具数量、警告统计、节目段落信息

## 快速开始

### 环境要求
- Node.js >= 16.0.0
- npm >= 8.0.0

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

```bash
npm run build
```

```bash
npm run preview
```

## 可复现操作指南

### 场景 1：查看样例碰撞警告

1. 打开应用，点击顶部工具栏的 **「导入样例」** 按钮
2. 观察右侧 **「碰撞检测」** 面板：
   - 应该显示 **2 个严重警告**（字幕屏区域）
   - 应该显示 **1 个一般警告**（观众区区域）
3. 查看 3D 场景：
   - 红色方框 = 字幕屏禁区
   - 橙色方框 = 观众区禁区
   - 黄色测试灯光束进入字幕屏禁区
   - 红色测试灯光束进入观众区禁区

### 场景 2：调整灯位解决碰撞

1. 在左侧 **「灯具列表」** 中找到 **「字幕屏测试灯」**
2. 点击该灯具使其选中（蓝色高亮）
3. 在 3D 场景中拖拽目标点（蓝色球体）：
   - 将目标点向下拖拽到舞台地面
4. 观察右侧面板：
   - 严重警告数量从 2 减少到 1
   - 「字幕屏测试灯」的警告消失

### 场景 3：切换节目段落

1. 点击底部时间轴的 **「表演段落 A」** 按钮
2. 观察场景变化：
   - 侧光 1# 和 侧光 2# 自动开启
   - 面光强度降低
3. 点击 **「表演段落 B」**：
   - 追光 1# 自动开启
   - 部分面光关闭
4. 点击 **「谢幕」**：
   - 所有面光恢复全强度

### 场景 4：使用筛选功能

1. 在左侧面板顶部的 **搜索框** 输入「面光」
2. 列表只显示包含「面光」的灯具（共 3 个）
3. 清空搜索框，在 **分组下拉框** 选择「测试」
4. 列表只显示「测试」分组的灯具（共 2 个）
5. 观察 3D 场景：只有筛选出的灯具会显示光束

### 场景 5：切换视角

1. 点击顶部工具栏 **「视角」** 按钮
2. 选择 **「俯视视角」**：相机切换到正上方
3. 选择 **「侧视视角」**：相机切换到正侧方
4. 选择 **「正面视角」**：相机切换到正前方
5. 选择 **「自由视角」**：可以通过鼠标拖拽自由旋转

### 场景 6：导出报告

1. 点击顶部工具栏 **「导出」** 按钮
2. 选择 **「预演报告 (.html)」**
3. 浏览器会下载一个 HTML 文件
4. 打开下载的 HTML 文件查看：
   - 警告统计
   - 碰撞警告详情
   - 灯具清单
   - 节目段落列表

### 场景 7：刷新验证状态持久化

1. 在搜索框输入「测试」进行筛选
2. 记住当前的筛选状态
3. 刷新浏览器页面（F5 或 Cmd+R）
4. 确认：
   - 筛选条件保持不变
   - 灯具状态保持不变
   - 碰撞检测结果一致

## 核心概念

### 碰撞检测原理

系统使用光线投射（Raycasting）技术检测光束与禁区的相交：

1. 对每个启用的灯具，沿光束方向生成多个采样点
2. 检测每个采样点是否在禁区边界盒（Box3）内
3. 如果发现相交，则生成碰撞警告

### 状态持久化

使用 Zustand 的 persist 中间件：

- 自动保存到 localStorage
- 保存内容：灯具状态、筛选条件、面板开关状态
- 页面刷新时自动恢复

### 节目段落切换

每个节目段落包含一组灯具状态：

- 位置坐标
- 目标点坐标
- 强度值

切换段落时，系统自动应用对应状态到所有灯具。

## 常见问题

**Q: 为什么有些灯具没有光束？**
A: 检查灯具是否启用（左侧面板 Power 按钮），以及强度是否大于 0。

**Q: 如何精确调整灯位？**
A: 选中灯具后，在 3D 场景中拖拽灯具本体（位置）或蓝色球体（目标点）。

**Q: 导出的报告可以打印吗？**
A: 可以，选择「打印报告」选项，或在浏览器中打开 HTML 文件后按 Ctrl+P 打印。
