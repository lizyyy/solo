# 冷库货位温层可视化系统

基于 WebGL 的交互式 3D 冷库货位可视化管理系统，帮助冷库主管直观查看不同温层货位和临期货在空间中的分布。

## 功能特性

- **3D 冷库场景**：基于 Three.js + React Three Fiber 的交互式 WebGL 场景
- **温层筛选**：支持多层温层独立显示/隐藏，颜色区分不同温度区域
- **效期高亮**：临期商品红色脉冲闪烁，支持自定义临期天数阈值
- **货位搜索**：支持按货位编码、SKU 名称、批次号快速搜索
- **视角切换**：总览/正面/侧面/俯视/自由视角快速切换
- **报告导出**：支持 JSON 和 CSV 格式盘点报告导出
- **状态持久化**：筛选条件和关键状态自动保存，刷新不丢失
- **面板折叠**：左右面板可折叠，最大化 3D 可视区域

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 5
- **3D 引擎**: Three.js + @react-three/fiber + @react-three/drei
- **状态管理**: Zustand (persist middleware)
- **样式方案**: TailwindCSS 3
- **图标库**: Lucide React
- **报告导出**: PapaParse (CSV)

## 可复现操作指南

### 操作 1: 温层筛选与视角切换

1. **启动应用**：运行 `npm run dev` 并打开浏览器
2. **查看默认状态**：默认显示全部 4 个温层，视角为总览模式
3. **筛选温层**：
   - 点击左侧控制面板中的"冷冻层 (-18°C)"取消选中
   - 观察 3D 场景中第一层货位隐藏
   - 再次点击重新显示该层
4. **切换视角**：
   - 点击左侧"视角切换"中的"正面"
   - 观察相机自动切换到正面视角
   - 点击"俯视"查看顶部视角
   - 点击"自由"进入手动控制模式
5. **验证状态持久化**：
   - 刷新浏览器页面
   - 确认筛选的温层和视角设置保持不变

### 操作 2: 效期高亮与货位搜索

1. **调整效期阈值**：
   - 在左侧"效期高亮"区域拖动滑块到 60 天
   - 观察 3D 场景中闪烁的临期货位数量变化
   - 查看底部状态栏"60天内临期"数字更新
2. **搜索货位**：
   - 在顶部搜索框输入"牛肉"或"三文鱼"
   - 观察匹配的货位保持高亮，不匹配的货位变透明
   - 清空搜索框恢复全部显示
3. **查看货位详情**：
   - 点击任意闪烁的临期货位
   - 右侧面板显示货位信息和 SKU 列表
   - 查看效期进度条和剩余天数
   - 点击货位外区域取消选中

### 操作 3: 导入样例与报告导出

1. **重置状态**：
   - 点击顶部工具栏的"重置"按钮
   - 确认所有筛选条件恢复默认
   - 3D 场景恢复初始状态
2. **导入样例数据**：
   - 点击顶部"导入样例"按钮
   - 观察数据重新加载
   - 货位状态随机更新（温层错放、临期等）
3. **导出盘点报告**：
   - 点击顶部"导出报告"下拉菜单
   - 选择"导出 JSON 格式"
   - 下载文件并查看内容，确认与可视化数据一致
   - 再次点击选择"导出 CSV 格式"
   - 用 Excel 打开 CSV 文件，验证数据完整性

### 操作 4: 面板折叠与场景交互

1. **折叠左侧面板**：
   - 点击左侧控制面板左上角的"←"按钮
   - 面板收起，显示"→"展开按钮
   - 点击展开按钮恢复面板
2. **折叠右侧面板**：
   - 点击右侧信息面板右上角的"→"按钮
   - 面板收起，显示"←"展开按钮
   - 点击展开按钮恢复面板
3. **3D 场景交互**：
   - **旋转**：鼠标左键拖动场景
   - **缩放**：鼠标滚轮或右键拖动
   - **平移**：按住 Shift + 左键拖动
   - **选中货位**：左键点击任意货位
   - **取消选中**：点击场景空白区域

## 状态说明

系统自动保存以下状态到 localStorage：

- `selectedLayerIds`：选中的温层 ID 列表
- `selectedSlotId`：当前选中的货位 ID
- `searchQuery`：搜索关键词
- `expiryFilterDays`：临期天数阈值
- `cameraView`：当前视角模式
- `leftPanelOpen`：左侧面板展开状态
- `rightPanelOpen`：右侧面板展开状态
