# 潮汐能发电估算工具

面向海洋工程课程的潮汐能发电量可复算估算工具。

---

## 核心功能

- **能量估算**：基于潮差、流速、叶轮面积、效率计算潮汐势能和动能
- **周期积分**：梯形法积分潮汐周期分段，计算日/年发电量
- **设备约束**：额定功率、最大流速、允许潮差范围校验
- **情景对比**：最多4个记录并排对比，差异热力图可视化
- **报告导出**：PDF格式估算报告，包含参数、结果、校验说明
- **可复算ID**：相同输入产生相同ID，确保结果可追溯
- **续算功能**：基于历史记录继续计算，保留parentId关联
- **错误透明化**：效率>1、周期缺段、单位混用等问题明确标注拦截原因

## 样例入口

进入应用首页后，点击右上角 **"载入样例数据"** 按钮，自动填充以下标准样例：

| 参数 | 数值 | 单位 |
|------|------|------|
| 潮差 | 5.0 | 米 |
| 流速 | 2.5 | m/s |
| 叶轮面积 | 20 | m² |
| 效率 | 0.35 | - |
| 潮汐周期 | 4段（涨潮-平潮-落潮-平潮） | 小时 |
| 额定功率 | 500 | kW |
| 最大流速 | 5.0 | m/s |
| 允许潮差范围 | 1.0 ~ 8.0 | 米 |

点击 **"开始计算"** 按钮即可获得估算结果。

## 一条会失败的操作

### 操作步骤
1. 点击右上角 **"载入无效样例"** 按钮（或手动设置以下参数）
2. 参数设置：
   - 效率 = **1.2** （超过1，物理不可能）
   - 删除潮汐周期中的1~2段（造成周期缺段）
   - 潮差单位选择 **"英尺"**，流速单位选择 **"m/s"** （混用公制英制）
3. 观察校验面板的红色错误提示

### 预期拦截原因
```
❌ EFFICIENCY_EXCEEDS_ONE: 效率值 1.2 超过最大值 1.0
   建议：效率应为0~1之间的小数，如35%应输入0.35

❌ CYCLE_GAP_DETECTED: 潮汐周期缺少第2段
   建议：完整潮汐周期应包含涨潮、平潮、落潮、平潮4个阶段

⚠️  UNIT_MIX_DETECTED: 公制/英制单位混用
   提示：已自动转换为公制计算，请注意结果单位
```

**计算按钮将被禁用**，必须修正所有红色错误后才能继续。

## 数据存储

所有记录保存在浏览器本地 IndexedDB 中，清除浏览器数据将丢失记录。

### 目录结构
```
src/
├── engine/         # 计算引擎（calculator, validator, reproducibleId）
├── components/     # UI组件
├── pages/          # 页面路由
├── store/          # Zustand状态管理
├── types/          # TypeScript类型定义
└── utils/          # 工具函数（storage等）
```
