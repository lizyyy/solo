# 美术培训室画材缺料统计 CLI 工具

用于美术培训室画材缺料数据的批量处理和统计，自动处理班级改名、套装拆分和格式错误检测。

## 功能特点

- **班级改名**: 根据规则自动将旧班级名称转换为新班级名称
- **套装拆分**: 将画材套装自动拆分为单个画材明细
- **格式错误检测**: 自动检测缺料数量为 0、为空、非数字等格式错误
- **可复跑输出**: 支持多次运行，结果可追踪来源文件
- **详细日志**: 默认简洁输出，加 `-v` 参数可查看每条记录处理详情
- **分类统计**: 按班级改名、套装拆分、格式错误分别统计和输出

## 使用步骤

### 第一步：生成示例数据（可选）

```bash
python -m art_material_stats.cli sample
```

或使用入口命令：

```bash
art-stats sample
```

这会在 `sample_data` 目录下生成：
- `处理规则.xlsx` - 包含班级改名和套装拆分规则
- `输入数据/` - 包含两周的缺料统计样例数据

### 第二步：预览处理结果

正式执行前先预览，只显示统计概览，不生成文件：

```bash
art-stats run -i sample_data/输入数据 -r sample_data/处理规则.xlsx -o sample_output -p
```

参数说明：
- `-i, --input-dir`: 输入目录，包含待处理的 Excel 文件
- `-r, --rules`: 规则文件路径（Excel）
- `-o, --output-dir`: 输出结果目录
- `-p, --preview`: 预览模式，不生成输出文件

预览模式会显示：
- 总记录数
- 班级改名记录数
- 套装拆分记录数
- 格式错误记录数
- 正常记录数

### 第三步：正式执行处理

预览确认无误后，去掉 `-p` 参数正式执行：

```bash
art-stats run -i sample_data/输入数据 -r sample_data/处理规则.xlsx -o sample_output
```

如需查看每条记录的详细处理过程，添加 `-v` 参数：

```bash
art-stats run -i sample_data/输入数据 -r sample_data/处理规则.xlsx -o sample_output -v
```

### 第四步：查看统计报告

执行完成后，可随时查看已生成的统计报告：

```bash
art-stats report -o sample_output
```

## 输出文件说明

处理完成后，输出目录包含以下文件：

1. **处理结果.xlsx** - 完整处理结果
   - `全部记录` 工作表：所有处理后的记录（含错误记录）
   - `有效记录` 工作表：正常、班级改名、套装拆分的有效记录
   - `缺料汇总` 工作表：按班级和画材的汇总统计

2. **班级改名记录.xlsx** - 班级改名的记录明细

3. **套装拆分记录.xlsx** - 套装拆分的记录明细

4. **格式错误记录.xlsx** - 格式错误的记录明细

5. **统计报告.txt** - 文本格式的统计报告

## 规则文件说明

规则文件（Excel）包含两个工作表：

### 班级改名 工作表

| 原班级名称 | 新班级名称 |
|-----------|-----------|
| 素描初级班 | 素描基础班(2024春季) |
| 色彩基础班 | 色彩班(2024春季) |

### 套装拆分 工作表

| 套装名称 | 包含画材 | 拆分数量 |
|---------|---------|---------|
| 素描工具套装 | 素描铅笔;橡皮;素描纸;美工刀 | 1;1;1;1 |
| 水彩画套装 | 水彩颜料;水彩笔;调色盘;水彩纸 | 1;2;1;2 |

## 输入数据格式

输入的 Excel 文件需要包含以下列：

- **班级**: 学生所在班级
- **画材名称**: 缺料的画材名称（可能是套装名称）
- **缺料数量**: 缺料的数量（必须为正整数）
- **学生姓名**: 申请缺料的学生姓名
- **申请日期**: 缺料申请日期

## 常见问题

**Q: 如何添加新的班级改名规则？**
A: 编辑规则文件的「班级改名」工作表，添加原班级名称和新班级名称即可。

**Q: 如何添加新的套装拆分规则？**
A: 编辑规则文件的「套装拆分」工作表，添加套装名称、包含画材（用分号分隔）、拆分数量（用分号分隔，顺序与画材对应）。

**Q: 处理后的记录还能看到来源文件吗？**
A: 可以，处理结果中包含「来源文件」列，记录每条数据来自哪个输入文件。

**Q: 可以多次运行吗，会覆盖之前的结果吗？**
A: 可以多次运行，每次运行会覆盖输出目录的文件。如需保留历史结果，请使用不同的输出目录。
