# 社区维修基金办基金票据装订 CLI 工具

专门用于社区维修基金票据数据的解析、校验和报告生成，支持发票红冲校验、附件缺页检测和可复跑输出对比。

## 项目结构

```
.
├── src/
│   ├── cli.js              # 主入口
│   └── modules/
│       ├── parser.js       # 票据解析模块
│       ├── validator.js    # 票据校验模块
│       └── reporter.js     # 报告生成模块
├── samples/                # 业务样例数据
│   ├── maintenance_bills_2024_01.json
│   └── maintenance_bills_2024_02.json
├── output/                 # 报告输出目录
└── package.json
```

## 功能特性

1. **票据解析** - 支持 JSON 和 CSV 格式的票据数据解析
2. **发票红冲校验** - 检测红冲票据是否关联正确、金额是否为负
3. **附件缺页校验** - 检测附件数量与页数是否匹配
4. **基础信息校验** - 必填字段完整性校验
5. **金额校验** - 金额合理性校验
6. **可复跑报告** - 每次运行生成独立报告，支持报告对比

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 预览票据数据

预览数据，不生成正式报告，用于快速检查数据完整性：

```bash
npm run preview

# 或指定来源
node src/cli.js preview -s samples/maintenance_bills_2024_01.json
```

### 3. 正式执行校验

对票据进行完整校验并生成报告：

```bash
npm run run

# 或指定来源
node src/cli.js run -s samples
```

### 4. 查看报告

查看历史报告列表和对比报告：

```bash
npm run report

# 对比两次运行
node src/cli.js report -c 20240115_103000,20240115_103500
```

## 业务说明

### 票据字段说明

| 字段 | 说明 | 示例 |
|------|------|------|
| billNumber | 票据编号 | WXJJ-2024-001 |
| billDate | 开票日期 | 2024-01-15 |
| amount | 金额 | 25000.00 |
| payer | 付款方 | 阳光花园业主委员会 |
| payee | 收款方 | 市物业维修资金管理中心 |
| projectName | 项目名称 | 电梯维保项目 |
| communityName | 小区名称 | 阳光花园 |
| itemType | 费用类型 | 设备维修 |
| attachmentCount | 附件数量 | 3 |
| attachmentPages | 附件页数 | 6 |
| operator | 经办人 | 张三 |
| isRed冲 | 是否红冲 | false |
| relatedBillId | 关联原票号 | WXJJ-2023-128 |

### 校验规则

**红冲票据校验：**
- 红冲票据必须有关联原票号
- 关联票据不能是已红冲的票据
- 红冲票据金额必须为负数

**附件缺页校验：**
- 有附件数量时必须有附件页数
- 附件页数不能为0（有附件数量时）
- 有附件页数但附件数量为0时给出警告

**基础信息校验：**
- 票据编号不能为空
- 开票日期不能为空
- 付款方不能为空
- 收款方不能为空
- 项目名称不能为空
- 小区名称不能为空

**金额校验：**
- 非红冲票据金额不能为负数
- 金额为0时给出警告

## 命令行选项

### preview 命令

```
选项：
  -s, --source <path>  数据来源文件或目录 (默认: samples)
```

### run 命令

```
选项：
  -s, --source <path>  数据来源文件或目录 (默认: samples)
```

### report 命令

```
选项：
  -l, --list                 显示报告列表
  -c, --compare <runId1,runId2>  对比两个报告
```

## 报告说明

每次运行会生成3个文件到 output 目录：

1. `report_<runId>.json` - 完整报告数据，包含所有校验细节
2. `report_<runId>.txt` - 人类可读的文本格式报告
3. `comparison_<runId>.json` - 报告对比专用数据，提取关键指标

## 业务样例

项目内置真实社区维修基金业务样例：

- samples/maintenance_bills_2024_01.json - 正常数据样例
- samples/maintenance_bills_2024_02.json - 包含异常数据样例（用于测试校验功能）

样例覆盖场景：
- 正常票据
- 红冲票据
- 附件缺页票据
- 缺失必填字段票据
- 零金额票据

## 注意事项

1. 本工具不依赖外网服务，所有数据和报告均在本地处理
2. 所有样例数据均为真实业务场景，不是通用演示数据
3. 规则变更后，可通过对比功能查看前后差异
4. 建议每次规则变更后保存报告，用于后续追溯对比
