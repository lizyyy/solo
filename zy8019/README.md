# 小批量生产换线排程模拟器

一个本地可运行的生产排程工具，帮助计划员导入订单、产线日历、物料到齐时间和换线矩阵后，自动排出生产顺序。

## 功能特性

- **数据解析/校验**: 支持CSV订单文件、JSON产线日历、物料到齐时间和换线矩阵的解析与验证
- **智能排程引擎**: 基于优先级、物料可用性、换线时间的综合排程算法
- **甘特图展示**: 可视化展示生产进度
- **统计分析**: 延误订单数、加班时间、跨天生产等统计指标
- **结果导出**: 支持CSV格式导出排程结果
- **警告提示**: 物料晚到、订单跨天、换线矩阵缺项等异常提示

## 运行方式

### 方式一：Streamlit Run

```bash
cd scheduler/ui
streamlit run app.py
```

### 方式二：Python直接运行

```bash
cd scheduler/ui
python app.py
```

### 方式三：使用样例数据快速预览

```bash
cd scheduler/ui
streamlit run app.py
```

打开浏览器后点击"执行排程"按钮即可使用样例数据进行排程。

## 数据格式说明

### 订单文件 (CSV)

| 字段 | 说明 | 示例 |
|------|------|------|
| 订单号 | 唯一标识 | ORD001 |
| 产品型号 | 产品名称 | A型手机 |
| 数量 | 生产数量 | 100 |
| 优先级 | 紧急/高/中/低 | 高 |
| 交货日期 | YYYY-MM-DD | 2024-01-15 |
| 工艺时间(分钟) | 生产耗时 | 120 |

### 产线日历 (JSON)

```json
{
  "产线ID": "LINE001",
  "产线名称": "SMT-A线",
  "工作日期": [
    {"日期": "2024-01-13", "班次": "白班", "开始时间": "08:00", "结束时间": "18:00", "可用": true}
  ],
  "休息日": ["2024-01-20", "2024-01-21"]
}
```

### 物料到齐时间 (JSON)

```json
{
  "物料供应": [
    {"产品型号": "A型手机", "物料到齐时间": "2024-01-13 08:00:00"}
  ]
}
```

### 换线矩阵 (JSON)

```json
{
  "换线矩阵": [
    {"当前产品": "开始", "下一产品": "A型手机", "换线时间(分钟)": 20},
    {"当前产品": "A型手机", "下一产品": "B型手机", "换线时间(分钟)": 30}
  ]
}
```

## 排程规则

1. **优先级顺序**: 紧急 > 高 > 中 > 低
2. **物料约束**: 订单必须等待物料到齐后才能开始生产
3. **换线时间**: 根据换线矩阵计算产品切换时间
4. **工作时段**: 生产时间不能超出工作时段，超出部分计为加班
5. **延误判定**: 超过18:00完成且超出交货日期的订单计为延误
