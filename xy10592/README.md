# 门店设备折旧 CLI

一套偏实用的连锁门店设备资产管理和折旧计算工具，围绕门店设备资产的购置、调拨、维修、报废和折旧规则生成财务台账。

## 核心功能

### 业务场景覆盖
- **资产购置**: 记录设备购买信息、原值、使用年限、残值率
- **门店调拨**: 处理资产跨门店调拨，支持调拨当月折旧归属规则
- **设备维修**: 支持资本化维修（延长年限、增加原值）和费用化维修
- **资产报废**: 处理资产报废，报废后禁止调拨
- **折旧计算**: 直线法折旧，支持期间变更

### 关键规则
1. **调拨当月折旧归属**: 调拨当月折旧仍归属原门店
2. **维修资本化**: 资本化维修费用计入资产原值，延长使用年限
3. **报废后限制**: 已报废资产不能再进行调拨
4. **重复资产检测**: 自动检测重复资产编号
5. **幂等性**: 重复执行或重复回调保持幂等
6. **人工修正留痕**: 所有修正操作记录前后差异和操作者

## 快速开始

## CLI 命令

### init - 初始化数据目录

初始化系统数据存储目录。

```bash
# 默认使用 ./data 目录
npm run dev -- init

# 指定数据目录
npm run dev -- init --data-dir ./my-data
```

### import - 导入数据

导入业务数据，支持三种方式：

```bash
# 1. 使用内置正常样例数据（推荐用于演示）
npm run dev -- import --sample

# 2. 使用错误样例数据（演示失败路径）
npm run dev -- import --invalid

# 3. 从外部 JSON 文件导入
npm run dev -- import --file ./my-data.json
```

**数据文件格式** (JSON)：
```json
{
  "stores": [...],
  "assets": [...],
  "acquisitions": [...],
  "transfers": [...],
  "repairs": [...],
  "scraps": [...]
}
```

### check - 验证数据

处理所有业务交易并验证数据完整性。

```bash
npm run dev -- check
```

执行流程：
1. 按时间顺序处理所有交易记录
2. 更新资产状态（原值、净值、使用门店等）
3. 记录历史变更和操作者
4. 验证数据完整性
5. 输出错误和警告

### detail - 查看资产详情

查看单个资产的完整信息。

```bash
# 通过资产编号
npm run dev -- detail FRE-0001

# 通过资产ID
npm run dev -- detail asset_xxx
```

展示内容：
- 基本信息（编号、名称、类别、状态、当前门店）
- 财务信息（原值、累计折旧、净值）
- 购置记录
- 调拨历史
- 维修记录
- 报废记录
- 历史变更记录
- 人工修正记录
- 折旧明细

### report - 生成财务报表

生成门店资产财务报表。

```bash
# 全部汇总报表
npm run dev -- report

# 按年份
npm run dev -- report --year 2024

# 按年月
npm run dev -- report --year 2024 --month 3

# 按门店
npm run dev -- report --store WJ
npm run dev -- report --store store_001
```

报表内容：
- **汇总报告**: 门店总数、资产总数、原值总额、累计折旧、净值总额
- **门店明细**: 每个门店的资产汇总
- **分类明细**: 按设备类别（冰柜、收银机、咖啡机）分类统计
- **异常清单**: 所有检测到的业务异常
- **闭环检查**: 业务是否完全闭环的判断

## 折旧规则说明

### 直线法折旧

```
月折旧额 = (原值 × (1 - 残值率)) ÷ 使用月数
```

**默认参数**：
- 冰柜 (FREEZER): 使用年限 60个月，残值率 5%
- 收银机 (CASH_REGISTER): 使用年限 36个月，残值率 5%
- 咖啡机 (COFFEE_MACHINE): 使用年限 48个月，残值率 5%

### 折旧归属规则

1. **购置当月**: 不计提折旧
2. **报废当月**: 照提折旧
3. **调拨当月**: 折旧归属**原门店**
4. **净值保护**: 净值不能低于残值

### 示例计算

**资产**: 海尔立式冰柜 (FRE-0001)
- 原值: ¥8,500
- 使用年限: 60个月
- 残值率: 5%
- 残值: ¥8,500 × 5% = ¥425

**月折旧额**:
```
(8,500 - 425) ÷ 60 = 8,075 ÷ 60 = ¥134.58/月
```

**资本化维修后** (COF-0001):
- 原原值: ¥25,000
- 维修费用: ¥5,000 (资本化)
- 新年值: ¥30,000
- 原使用年限: 48个月
- 延长年限: 12个月
- 新使用年限: 60个月

## 异常检测清单

| 异常代码 | 类型 | 说明 |
|---------|------|------|
| DUPLICATE_ASSET_CODE | 错误 | 资产编号重复 |
| INVALID_STORE | 错误 | 资产所在门店不存在 |
| TRANSFER_AFTER_SCRAP | 错误 | 资产在报废后仍有调拨 |
| INVALID_TO_STORE | 错误 | 调拨目标门店不存在 |
| INVALID_FROM_STORE | 错误 | 调拨来源门店不存在 |
| RESIDUAL_RATE_VARIANCE | 信息 | 残值率与类别默认值不同 |
| NEGATIVE_NET_BOOK_VALUE | 错误 | 资产净值为负 |
| SCRAP_NO_ASSET | 错误 | 报废记录引用不存在的资产 |
| SAME_STORE_TRANSFER | 警告 | 调拨到同一门店 |
| CAPITALIZED_REPAIR_NO_EXTENSION | 警告 | 资本化维修未延长年限 |
| DEPRECIATION_MISMATCH | 警告 | 累计折旧与预期值不符 |

## 幂等性保证

- **导入幂等**: 每次导入都会增加版本号，可追溯
- **处理幂等**: 使用 transactionId 记录已处理交易，重复处理不会重复执行
- **状态留痕**: 所有状态变更记录 beforeState 和 afterState
- **操作者记录**: 所有操作记录 operator
