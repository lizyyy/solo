# 市集共享冷柜占用结算台

## 项目概述

这是一个完整的市集共享冷柜占用结算系统，解决摊主共用冷柜时的计费和争议问题。

### 核心主线
```
市集摊主共用冷柜 → 按格口分配 → 按温区定价 → 按占用时长计费 → 解决临时挪货争议
```

### 关键概念

1. **格口**：冷柜的最小使用单元，摊主按格口租用
2. **温区**：同一冷柜可分冷藏区、冷冻区，不同温区单价不同（温区规则）
3. **占用时长**：从登记开始到结束的小时数
4. **争议解决**：所有操作留痕、确认后不可修改、拒绝需注明原因、全程可追溯

## 完整操作流程（5步走）

### 第1步：初始化数据

**快速方式**：进入「总览看板」或「数据导出」页面，点击「📦 加载示例数据」一键完成初始化

**或手动添加**：
1. 「冷柜与温区」→ 新增冷柜
2. 点击冷柜的「管理温区」→ 添加温区（冷藏区 2.5元/小时、冷冻区 3.0元/小时）
3. 「格口管理」→ 为每个温区分配格口编号
4. 「摊主管理」→ 添加摊主信息

### 第2步：登记占用

1. 进入「占用登记」页面
2. 点击「+ 新增占用」
3. 选择：摊主 → 冷柜 → 温区 → 格口
4. 填写：开始时间、结束时间
5. 系统自动计算：占用时长 × 温区单价 = 预估金额
6. 提交后状态为「待确认」

### 第3步：审核确认

- **确认**：状态变为「已确认」，格口状态变为「已占用」，**不可修改**
- **拒绝**：状态变为「已拒绝」，格口释放，**需注明原因**
- **留痕**：所有操作记录创建时间和修改时间，全程可追溯

### 第4步：查看报表

进入「总览看板」查看：
- 冷柜格口实时状态图（绿色可用、红色已占用）
- 温区收入统计
- 摊主账单统计
- 占用记录状态分布

### 第5步：导出结算

进入「数据导出」页面：
- 按状态/摊主筛选记录
- 导出CSV明细报表（可用Excel打开）
- 导出统计数据（JSON格式）

## 边界情况覆盖

系统已处理以下边界情况：

1. **重复提交**
   - 同一温区类型的计费规则不能重复创建
   - 格口编号在同一冷柜中不能重复

2. **状态冲突**
   - 同一格口同一时间段不能重复登记
   - 已确认的记录不能修改或删除
   - 已拒绝的记录不能修改

3. **来源记录缺失**
   - 登记时摊主不存在会提示错误
   - 格口对应的温区不存在会提示错误

## 数据模型

```
冷柜(Freezer)
├── 温区(Zone) - 按温区定价
│   └── 格口(Slot) - 最小使用单元
│       └── 占用记录(Occupancy) - 摊主占用历史
└── 摊主(Vendor) - 使用方
```

## 技术栈

- **前端**：原生 JavaScript + CSS
- **数据存储**：内存存储（演示用）
