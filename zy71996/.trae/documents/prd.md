## 1. 产品概述

文档链接巡检平台——解决运维团队"配置文件先到、失败日志晚补、值班群看不懂代码"的痛点。系统自动判断每条巡检记录的处置分类（补材料 vs 改结论），将判断理由、下一步操作和运行账本以值班群可直接转发的格式呈现，消除反复解释的沟通成本。

- 目标用户：运维值班人员、文档质量负责人
- 核心价值：将"土法"巡检升级为自动判断 + 分类账本 + 可导出的标准化流程

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 运维值班 | 管理员分配 | 查看巡检结果、导出账本、标记人工改动 |
| 文档负责人 | 管理员分配 | 上传配置文件样例、确认/待补记录、复核导出 |

### 2.2 功能模块

1. **巡检仪表盘**：自动执行链接巡检，展示每条记录的判断结果、判断理由、下一步操作
2. **运行账本**：按"已确认 / 待补 / 人工改过"三栏分区展示，每条附带处理口径
3. **配置与说明**：配置文件样例放置指引、重复执行风险说明、导出复核流程

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 巡检仪表盘 | 判断结果列表 | 每条记录展示：链接地址、判断分类（补材料/改结论）、判断理由、下一步操作建议 |
| 巡检仪表盘 | 快速筛选栏 | 按分类筛选：全部 / 仅补材料 / 仅改结论 / 异常 |
| 巡检仪表盘 | 执行状态卡片 | 展示本轮巡检总数、自动判断数、待人工确认数 |
| 运行账本 | 已确认区 | 系统自动确认或人工确认的记录，附处理口径 |
| 运行账本 | 待补区 | 配置文件早到/失败日志晚补的记录，标注缺失材料类型与补交截止 |
| 运行账本 | 人工改过区 | 变更单手工改动的记录，标注改动前后对比与改结论理由 |
| 运行账本 | 导出功能 | 导出含处理口径的账本（JSON / CSV），导出前需复核确认 |
| 配置与说明 | 配置样例指引 | 说明配置文件放置位置、命名规范、样例模板下载 |
| 配置与说明 | 重复执行风险 | 说明重复执行可能改坏结果的场景与规避方法 |
| 配置与说明 | 导出复核流程 | 导出前的复核步骤说明 |

## 3. 核心流程

用户进入仪表盘 → 查看自动判断结果 → 区分"补材料"和"改结论" → 跳转运行账本 → 在三栏分区中查看详细记录与处理口径 → 导出前复核 → 导出账本发值班群

```mermaid
    "A[启动巡检]" --> "B[自动判断链接状态]"
    "B" --> "C{判断分类}"
    "C" --> "D[补材料：配置早到/日志晚补]"
    "C" --> "E[改结论：变更单手工改动]"
    "D" --> "F[标记为 待补]"
    "E" --> "G[标记为 人工改过]"
    "B" --> "H[自动确认的记录标记为 已确认]"
    "F" --> "I[运行账本]"
    "G" --> "I"
    "H" --> "I"
    "I" --> "J[复核]"
    "J" --> "K[导出账本]"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝（#1E3A5F）+ 琥珀橙强调色（#F59E0B）
- 次色调：浅灰底（#F8FAFC）、白卡片
- 按钮：圆角 8px，轻微投影，悬停加深
- 字体：Noto Sans SC（正文）+ JetBrains Mono（代码/链接）
- 布局：左侧固定导航 + 右侧内容区，卡片式布局
- 图标：lucide-react 线性图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 巡检仪表盘 | 执行状态卡片 | 3 张统计卡片，数字大字号 + 标签小字号，深靛蓝底白字 |
| 巡检仪表盘 | 筛选栏 | 水平按钮组，选中态琥珀橙底白字 |
| 巡检仪表盘 | 判断结果列表 | 白色卡片列表，左侧彩色竖条区分分类（绿=已确认/黄=待补/红=人工改过），展开显示判断理由和下一步 |
| 运行账本 | 三栏分区 | 三个并列面板，各自标题带颜色标识，内部为可滚动记录卡片 |
| 运行账本 | 导出按钮 | 页面右上角，琥珀橙实心按钮，点击弹出复核弹窗 |
| 配置与说明 | 说明卡片 | 步骤式卡片，带序号图标，简洁文字说明 |

### 4.3 响应式

桌面优先设计，平板端三栏账本折叠为标签切换，移动端单列布局。

### 4.4 3D 场景

不适用
