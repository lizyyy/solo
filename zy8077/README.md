# 离线巡检表同步演练台

一个模拟一线巡检员在弱网环境下填写设备巡检表的演示应用，实现断网时数据写入 IndexedDB 和待同步队列，恢复后与服务器合并的功能。

## 功能特性

- 📝 **巡检单管理** - 创建和编辑设备巡检表单，包括设备信息、备注、异常项和照片占位
- 📡 **在线/离线切换** - 模拟网络连接状态，测试离线模式下的数据处理
- 💾 **本地存储** - 使用 IndexedDB 持久化存储离线数据
- 📋 **同步队列** - 离线时保存操作队列，联网后按顺序同步
- ⚔️ **冲突解决** - 多种冲突解决策略：
  - 最后写入优先
  - 本地优先
  - 服务器优先
- 📊 **实时监控** - 显示同步队列、日志、冲突状态和服务器快照

## 使用指南

### 基本流程

1. **填写巡检单** - 在两个表单区域中填写设备巡检信息
2. **切换离线** - 点击"切换离线"按钮模拟断网
3. **离线保存** - 在离线状态下保存巡检单，数据会加入同步队列
4. **恢复在线** - 点击"切换在线"恢复网络
5. **同步数据** - 点击"同步数据"按钮将队列中的操作同步到服务器

### 冲突解决测试

1. 在在线状态下创建一个巡检单
2. 切换到离线状态，修改该巡检单
3. 在另一个浏览器窗口（或直接修改服务器数据）也修改该巡检单
4. 恢复在线并同步，观察冲突检测和解决过程

### 界面说明

- **顶部控制栏** - 网络状态、切换在线/离线、新建巡检单、同步数据、重置
- **巡检单表单** - 两个独立的巡检单编辑区域
- **同步队列** - 显示待同步的操作列表
- **同步日志** - 显示操作历史记录
- **冲突状态** - 显示检测到的冲突及其解决状态
- **服务器快照** - 显示当前服务器端的数据状态

## 核心模块说明

### 数据模型 (models.js)

定义巡检单、同步队列项、同步日志和冲突的数据结构。

### 同步队列 (sync-queue.js)

基于 IndexedDB 实现的持久化队列，支持：
- 添加操作到队列
- 按顺序处理队列
- 失败重试
- 队列失败时保护后续数据

### 冲突策略 (conflict-strategy.js)

实现多种冲突检测和解决策略：
- 检测字段级别的冲突
- 支持多种自动解决策略
- 支持手动解决预留接口

### Mock API 服务 (mock-api.js)

模拟服务器端 API：
- CRUD 操作
- 在线/离线状态切换
- 数据快照功能

### 本地存储 (local-storage.js)

封装 IndexedDB 操作，实现本地数据持久化。
