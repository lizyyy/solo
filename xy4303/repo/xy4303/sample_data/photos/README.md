# 示例照片目录

本目录用于演示照片导入功能。

## 文件名格式

照片文件名应遵循以下格式：
```
{模型编号}_{照片类型}.{扩展名}
```

例如：
- `MDL001_咬合关系.jpg`
- `MDL001_模型正面.jpg`
- `MDL001_模型侧面.jpg`
- `MDL001_模型咬合面.jpg`

## 支持的照片类型

- 咬合关系（必需）
- 模型正面（必需）
- 模型侧面（必需）
- 模型咬合面（必需）

## 示例数据说明

本目录中的 `.jpg` 文件实际上是文本占位文件，用于演示系统功能。

**实际使用时**：
1. 请将真实的患者照片放入此目录
2. 确保文件名包含模型编号和照片类型
3. 系统会自动从文件名中提取信息

## 测试场景

- `MDL002` 缺少 `咬合关系` 照片，用于测试缺失检查功能
