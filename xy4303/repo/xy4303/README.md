# 取模返工复核台

牙科义齿加工所前台管理系统，用于检查模型编号串单、咬合关系缺图、返工原因没闭环等问题。

## 功能特点

### 📥 数据导入
- 导入医生订单CSV
- 导入加工状态表CSV
- 扫描患者取模照片目录
- 扫描STL文件目录

### 🔍 智能检查
- **文件缺失检查**: 检查订单信息、必需照片、STL文件缺失
- **编号一致性检查**: 检查模型编号串单、订单编号重复
- **照片时间异常检查**: 检查照片拍摄时间跨度、未来时间、与订单日期差异
- **返工状态检查**: 检查返工次数超限、返工原因未闭环、状态跳转异常
- **超期风险检查**: 检查已超期、即将超期订单，加急订单特别提醒

### 📋 复核工作台
- 订单列表视图（支持筛选、搜索）
- 订单详情多标签页
- 问题列表管理
- 人工复核备注
- 问题标记已解决

### 💾 数据管理
- 本地JSON持久化存储
- 自动备份机制
- 撤销/重做操作（最多50步历史）
- 数据导入/导出

### 📤 导出功能
- **Markdown交付单**: 按问题/正常订单分组的详细交付报告
- **CSV问题表**: 问题清单（支持筛选未解决）
- **CSV订单表**: 订单汇总表
- **JSON审计包**: 完整审计数据，含元数据、汇总、详细数据

## 数据格式说明

### 订单CSV格式
```csv
订单编号,模型编号,医生姓名,患者姓名,患者性别,患者年龄,牙位,修复类型,订单日期,备注,加急
ORD2024001,MDL001,张医生,张三,男,45,#11-#12,烤瓷冠,2024-01-15,左上切牙,否
```

**必填字段**: 订单编号、模型编号、医生姓名、患者姓名

### 状态CSV格式
```csv
订单编号,模型编号,当前状态,接收日期,预期交付日期,实际交付日期,负责人,返工次数,返工原因1,返工日期1,返工解决方案1,...
ORD2024002,MDL002,待返工,2024-01-14,2024-01-19,,李工,1,咬合过高,2024-01-16,调磨咬合,
```

**支持最多3次返工记录**

### 照片文件名格式
```
{模型编号}_{照片类型}.{扩展名}
示例：MDL001_咬合关系.jpg
```

**照片类型关键词**：
- 咬合关系 (occlusion)
- 模型正面 (front)
- 模型侧面 (side)
- 模型咬合面 (occlusal_surface)

### STL文件名格式
```
{模型编号}_{上下颌}.stl
示例：MDL001_upper.stl
```

**上下颌关键词**：
- 上颌: upper, maxilla, U, 上, 上颌
- 下颌: lower, mandible, L, 下, 下颌

## 常见问题

### Q1: CSV文件导入乱码？
A: 系统支持UTF-8和GBK编码自动检测。建议使用UTF-8-BOM编码保存CSV文件（Excel保存时选择「CSV UTF-8」）。

### Q2: 照片无法识别？
A: 确保照片文件名包含模型编号和照片类型关键词。系统会自动从文件名提取信息。

### Q3: STL文件无法解析？
A: 系统支持ASCII和二进制STL格式。确保文件名包含模型编号。

### Q4: 如何恢复历史数据？
A: 备份文件位于 `backups/` 目录，可通过「文件」→「打开...」选择备份文件恢复。

### Q5: 如何添加新的检查规则？
A: 在 `rules/` 目录下创建新的规则类，继承 `BaseRule`，然后在 `rule_engine.py` 中注册即可。
