# API 文档

## 概述

本文档描述了产品的 API 接口。

## 端点

### GET /api/users

获取用户列表。

#### 请求参数

| 参数 | 类型 | 描述 |
|------|------|------|
| page | number | 页码 |
| limit | number | 每页数量 |

#### 响应示例

```json
{
  "data": [],
  "total": 0
}
```

### POST /api/users

创建新用户。

## 错误处理

查看 [错误码](#错误码) 了解更多。

## 错误码

| 代码 | 描述 |
|------|------|
| 400 | 请求错误 |
| 401 | 未授权 |
| 404 | 未找到 |
| 500 | 服务器错误 |
