# 🧗 抱石线路预排台

Bouldering Route Planner - 给攀岩馆定线员用的本地 3D 交互工具

## 功能概述

### 核心功能
- **3D 墙面可视化**：导入墙面尺寸和岩点 JSON，在 3D 场景中渲染
- **岩点交互**：选择、拖动岩点组成线路
- **实时校验**：
  - 身高分段可达性分析（儿童/青少年/成人）
  - 相邻动作跨度计算
  - 落地区冲突检测
  - 颜色重复警告
  - 儿童区安全距离校验
- **线路管理**：保存多个方案、撤销/重做
- **数据导入导出**：
  - Session JSON（完整数据）
  - Markdown 定线说明
  - CSV 岩点清单/线路统计

### 适用场景
- 新墙定线前预规划
- 多线路颜色冲突检查
- 儿童线路安全距离评估
- 线路跨度和可达性分析

## 验证流程

### 步骤 1：加载示例数据
1. 点击顶部工具栏的 **「加载示例」** 按钮
2. 观察：
   - 左侧线路列表应显示 4 条示例线路
   - 中间 3D 场景应显示墙面和岩点
   - 右侧校验结果应显示校验通过或警告信息

### 步骤 2：查看线路详情
1. 在左侧线路列表中点击任意线路
2. 观察：
   - 线路详情面板展开，显示线路名称、难度、颜色等
   - 3D 场景中该线路的岩点高亮显示，并绘制连接线
   - 右侧「可达性分析」显示儿童/青少年/成人三个身高段的可达性评估

### 步骤 3：操作岩点
1. **查看岩点详情**：点击 3D 场景中的任意岩点
   - 右侧「选中岩点」面板显示岩点的位置、类型、颜色、所属线路等信息

2. **添加岩点到线路**：
   - 先在左侧选择一条线路
   - 点击 3D 场景中不属于该线路的岩点
   - 观察：岩点被添加到线路，线路岩点列表更新

3. **从线路移除岩点**：
   - 保持线路选中状态
   - 点击 3D 场景中已属于该线路的岩点
   - 观察：岩点从线路中移除

### 步骤 4：撤销/重做测试
1. 对线路做一些修改（添加/移除岩点）
2. 使用以下方式之一撤销：
   - 点击顶部 **「撤销」** 按钮
   - 键盘快捷键 `Ctrl+Z` (Windows) 或 `Cmd+Z` (Mac)
3. 使用以下方式之一重做：
   - 点击顶部 **「重做」** 按钮
   - 键盘快捷键 `Ctrl+Y` 或 `Ctrl+Shift+Z`

### 步骤 5：创建新线路
1. 点击左侧线路列表下方的 **「+ 添加线路」** 按钮
2. 观察：新线路被创建并自动选中
3. 在 **线路详情** 面板中：
   - 修改线路名称
   - 选择难度级别
   - 点击颜色圆点选择线路颜色
   - 勾选「儿童线路」标记为儿童区线路

### 步骤 6：设置起步/结束点
1. 确保选中一条线路
2. 点击 3D 场景中的一个岩点（应已添加到该线路）
3. 点击 **「设为起步点」** 按钮
4. 点击另一个位置更高的岩点
5. 点击 **「设为结束点」** 按钮
6. 观察：
   - 线路岩点列表中，起步点显示绿色「起步」标签
   - 结束点显示红色「结束」标签
   - 3D 场景中对应的岩点有特殊标记

### 步骤 7：校验功能验证
1. **颜色冲突测试**：
   - 创建两条线路，选择相同颜色
   - 观察右侧「校验结果」是否显示「颜色重复」警告

2. **落地区冲突测试**：
   - 创建两条线路，让它们的起步点位置非常接近
   - 观察校验结果是否显示「落地区域重叠」警告

3. **儿童区安全距离**：
   - 创建一条线路，勾选「儿童线路」
   - 创建另一条普通线路，使其起步点与儿童线路非常接近
   - 观察是否有安全距离相关警告

### 步骤 8：数据导出测试
1. 点击顶部 **「导出」** 按钮
2. 依次测试以下导出选项：

   **导出 Session JSON**：
   - 选择「导出 Session JSON」
   - 下载的 JSON 文件应包含完整的墙面、岩点、线路数据

   **导出定线说明 (Markdown)**：
   - 选择「导出定线说明 (Markdown)」
   - 下载的 `.md` 文件应包含：
     - 方案概览
     - 每条线路的详细信息（岩点列表、跨度分析）
     - 可达性报告
     - 校验结果摘要

   **导出岩点清单 (CSV)**：
   - 选择「导出岩点清单 (CSV)」
   - 下载的 CSV 应包含所有岩点的位置、类型、颜色、所属线路等

   **导出线路统计 (CSV)**：
   - 选择「导出线路统计 (CSV)」
   - 下载的 CSV 应包含各线路的难度、岩点数、起步/结束点高度等

### 步骤 9：数据导入测试
1. 先导出一份 Session JSON 保存
2. 点击顶部 **「新建」** 按钮清空当前数据
3. 点击 **「导入」** 按钮
4. 选择刚才导出的 JSON 文件
5. 观察：数据应完全恢复

### 步骤 10：本地存储持久化
1. 对数据做一些修改
2. 刷新浏览器页面
3. 观察：修改后的数据应自动恢复（从 localStorage 读取）

## 核心模块说明

### 数据模型 (`src/core/dataModels.js`)
- **HoldType**：岩点类型枚举（大把手、小抠点、斜坡点、指洞点、捏点、脚点、造型岩点）
- **HoldColors**：岩点颜色预设（红、蓝、绿、黄、紫、橙、粉、白、黑）
- **HeightSegments**：身高分段定义（儿童 110-140cm、青少年 140-160cm、成人 160-190cm）
- **Wall**：墙面对象（尺寸、类型、角度、岩点列表）
- **Hold**：岩点对象（位置、类型、颜色、尺寸）
- **Route**：线路对象（名称、难度、岩点序列、起步/结束点）
- **Session**：会话对象（完整定线方案）

### 几何计算 (`src/core/geometry.js`)
- **Anthropometrics**：人体测量学常量（臂展系数、站立摸高系数等）
- `calculateReachBounds()`：计算给定身高的可达范围
- `calculateSpan()`：计算两岩点之间的跨度（水平、垂直、直线距离）
- `checkReachability()`：检查岩点可达性
- `analyzeRouteReachability()`：分析整条线路按身高分段的可达性
- `calculateLandingZone()`：计算落地区域
- `checkLandingZoneConflict()`：检查落地区域冲突
- `estimateDifficulty()`：根据跨度估算线路难度

### 状态管理 (`src/core/stateManager.js`)
- **StateManager** 类：支持撤销/重做的状态管理器
- 历史栈机制（_undoStack, _redoStack）
- 批量操作模式（startBatch/commitBatch）
- 多方案管理（saveCurrentSession/loadSession）
- 本地存储持久化（saveToLocalStorage/loadFromLocalStorage）
- 事件系统（on/off/_emit）

### 校验规则 (`src/core/validation.js`)
- `validateSession()`：校验会话中所有线路
- 校验类型：
  - **颜色冲突**：多条线路使用相同颜色
  - **落地区域冲突**：线路起步点落地区域重叠
  - **儿童区安全距离**：儿童线路与其他线路距离过近
  - **线路完整性**：线路缺少起步点或结束点
  - **岩点重叠**：岩点物理位置重叠
  - **可达性**：跨度超出正常范围

### 3D 场景 (`src/scene/Scene3D.js`)
- **Scene3D** 类：Three.js 场景管理器
- OrbitControls 轨道控制（鼠标拖拽旋转、滚轮缩放）
- 射线投射选择（Raycaster）
- 岩点拖拽交互
- 墙面渲染、岩点渲染（按类型不同形状）
- 线路连接线渲染、起步/结束点标记
- 落地区域可视化

## 扩展说明

### 添加新的岩点类型
在 `src/core/dataModels.js` 的 `HoldType` 对象中添加新类型，然后在 `src/scene/Scene3D.js` 的 `createHoldMesh` 方法中添加对应的几何体生成逻辑。

### 添加新的身高分段
在 `src/core/dataModels.js` 的 `HeightSegments` 对象中添加新的分段定义，可达性分析会自动应用新分段。

### 自定义校验规则
在 `src/core/validation.js` 中添加新的校验函数，并在 `validateSession` 或 `validateRoute` 中调用。

## 常见问题

### Q: 3D 场景显示空白？
A: 检查浏览器控制台是否有错误。常见原因：
- Three.js 未正确加载（确保执行了 `npm install`）
- WebGL 不支持（尝试使用现代浏览器）

### Q: 数据没有保存？
A: 数据默认保存到浏览器的 localStorage。如果使用隐身模式或清除了浏览器数据，数据会丢失。建议定期导出 Session JSON 备份。

### Q: 岩点拖拽不精确？
A: 拖拽是基于墙面平面的投影计算。对于非垂直墙面（仰角/俯角），拖拽精度可能略有下降。

### Q: 可达性分析不准确？
A: 可达性计算基于标准人体测量学数据，实际情况可能因个人身体条件、攀岩技术而异。建议将分析结果作为参考而非绝对标准。
