釉药禁忌表 (JSON)

定义哪些釉药不能放在同一层板，避免碰釉反应。

支持格式: .json

JSON格式示例

[
  {
    "glaze_a": "青瓷釉",
    "glaze_b": "铜红釉",
    "conflict_severity": "high",
    "conflict_description": "两者会发生化学反应，产生气泡和裂纹",
    "is_mutual": true
  },
  {
    "glaze_a": "透明釉",
    "glaze_b": "裂纹釉",
    "conflict_severity": "medium",
    "conflict_description": "可能会影响裂纹效果，建议分开摆放",
    "is_mutual": true
  },
  {
    "glaze_a": "釉下彩",
    "glaze_b": "釉上彩",
    "conflict_severity": "high",
    "conflict_description": "烧制温度不同，会导致颜色变化",
    "is_mutual": true
  }
]
风险等级说明：
  • high (高风险): 绝对不能放在同一层板，会导致作品报废
  • medium (中风险): 尽量避免，可能影响效果
  • low (低风险): 轻微影响，可根据情况调整
