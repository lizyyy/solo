# 🧪 试剂领用安全闸 - 中学化学实验室管理系统

一个专为中学化学实验室管理员设计的本地桌面应用，实现试剂库存管理、实验预约审批、智能安全检查等核心功能。

---

## ✨ 功能特性

### 🔒 智能安全检查（核心）

| 检查项 | 阻断(BLOCKED) | 警告(WARNING) |
|--------|--------------|---------------|
| **库存数量** | 可用量 < 申请量 | 可用量 < 安全库存 |
| **有效期** | 已过期 | 30天内即将过期 |
| **相容性** | - | 酸碱混放、氧化剂/还原剂混放等 |
| **重复领用** | - | 高危险试剂同一天被多个班级预约 |
| **危险等级** | - | 含有高/中危险试剂提醒 |

### 📦 库存管理
- 试剂信息全生命周期管理
- CSV批量导入导出
- 低库存、即将过期预警

### 📅 预约审批流
```
老师提交预约 → 管理员安全检查 → 审批通过/拒绝 → 领用登记 → 归还登记
  (pending)        (安全检查)         (approved)      (collected)    (returned)
```

### 📊 数据导出
- **Markdown安全交接单**: 含试剂清单、危险等级、安全注意事项、签名区域
- **CSV台账**: 库存台账、预约记录

### 💾 本地数据持久化
- SQLite单文件数据库（`data/lab_management.db`）
- 审计日志记录所有操作
- 重启/刷新数据不丢失

## 📖 使用示例

### 验证主流程（使用示例数据）

#### 1. 查看首页仪表盘
启动程序后，首页显示：
- 📊 数据概览卡片（试剂总数、待审批、已领用等）
- ⚠️ 库存预警列表（低库存、即将过期）
- 📋 最近预约列表

#### 2. 试剂库存管理
点击顶部导航栏 **「🧪 试剂库存」**：
- 查看17种预置试剂（浓硫酸、浓盐酸、氢氧化钠等）
- 支持按危险等级筛选（高危险🔴、中危险🟠、低危险🟡、一般🟢）
- 支持搜索试剂名称
- 点击「导出CSV」可导出完整库存

#### 3. 创建新预约（模拟老师提交）
点击顶部导航栏 **「📅 实验预约」** → 「新建预约」：
1. 选择班级：如「高一1班」
2. 实验名称：如「酸碱中和反应」
3. 任课老师：如「张老师」
4. 实验日期：选择最近的日期
5. 学生人数：45
6. 添加试剂：
   - 选择「浓盐酸」（酸类，高危险🔴），申请量：500毫升
   - 选择「氢氧化钠」（碱类，高危险🔴），申请量：200克
   - 选择「酚酞指示剂」，申请量：50毫升
7. 点击「保存」

#### 4. 安全检查与审批
点击顶部导航栏 **「✅ 审批管理」**：
1. 在「待审批列表」中选中刚创建的预约
2. 点击「执行安全检查」
3. **预期警告**：
   - ⚠️ **相容性警告**: 酸类(浓盐酸)与碱类(氢氧化钠)不相容，请勿混放
   - ⚠️ **危险等级提醒**: 含有高危险试剂(2种)，请严格管理
4. 点击「通过审批」（警告不阻断，确认后可继续）
5. 或点击「拒绝审批」并填写拒绝原因

#### 5. 领用登记
点击顶部导航栏 **「📤 领用登记」**：
1. 选择已通过审批的预约
2. 确认实际发放数量（可修改）
3. 填写领用人姓名
4. 点击「确认领用」
   - 系统自动扣减库存
   - 预约状态变为「已领用」
5. 点击「导出交接单」生成Markdown安全交接单

#### 6. 归还登记
点击顶部导航栏 **「📥 归还登记」**：
1. 选择已领用的预约
2. 填写本次归还数量（如：浓盐酸实际归还450毫升）
3. 选择试剂状态（完好/部分损耗/损坏）
4. 填写归还人姓名
5. 点击「确认归还」
   - 系统自动增加库存
   - 全部归还：状态变为「已归还」
   - 部分归还：状态变为「部分归还」

#### 7. 报表导出
点击顶部导航栏 **「📋 报表导出」**：
- 导出「库存台账CSV」
- 导出「预约记录CSV」（可选择日期范围）
- 查看数据统计（按危险等级、类别分布）

## 📋 试剂类别相容性矩阵

| 类别 | 不相容类别 | 说明 |
|------|-----------|------|
| 酸类(acid) | 碱类、氧化剂、有机物 | 酸碱反应、氧化反应 |
| 碱类(base) | 酸类、氧化剂、有机物 | 酸碱反应、氧化反应 |
| 氧化剂(oxidizer) | 酸类、碱类、还原剂、有机物 | 剧烈氧化反应 |
| 还原剂(reducer) | 氧化剂、酸类 | 氧化还原反应 |
| 有机物(organic) | 酸类、碱类、氧化剂 | 可能引发燃烧 |
| 金属(metal) | 酸类、氧化剂 | 置换反应、氧化反应 |
| 盐类(salt) | 无 | 一般稳定 |
| 指示剂(indicator) | 无 | 一般稳定 |
| 水溶液(water) | 无 | 一般稳定 |

## 🔧 高级操作

### 导入CSV试剂库存

**CSV格式要求**（中文表头，支持多种别名）：

| 必需字段 | 支持的表头别名 |
|----------|----------------|
| 试剂名称 | 名称、name、试剂名 |
| 类别 | 分类、category、类型 |
| 危险等级 | 等级、danger_level、危险级别 |
| 单位 | unit、计量单位 |
| 总量 | 总数量、total_quantity、数量 |
| 可用量 | 可用数量、available_quantity、库存 |

**可选字段**：英文名称、CAS号、分子式、浓度、纯度、安全库存、存放位置、货架、有效期、生产厂家、批号、备注

**危险等级值**：
- `高危险` 或 `1` → 🔴高危险
- `中危险` 或 `2` → 🟠中危险  
- `低危险` 或 `3` → 🟡低危险
- `一般` 或 `4` → 🟢一般

**类别值**：酸类、碱类、氧化剂、还原剂、有机物、金属、盐类、指示剂、水溶液

### 重置数据库

```bash
# 删除数据库文件
rm -rf data/lab_management.db

# 重新启动程序，自动重建

```

## ❓ 常见问题

**Q: 程序启动失败，提示找不到模块？**
- 确保在项目根目录运行 `python3 main.py`
- 检查Python版本是否为3.7+

**Q: 安全检查中的"阻断"和"警告"有什么区别？**
- **阻断(BLOCKED)**: 库存不足、试剂已过期 → 禁止领用
- **警告(WARNING)**: 相容性问题、重复预约、即将过期 → 确认后可继续

**Q: 数据存在哪里？可以备份吗？**
- 所有数据存储在 `data/lab_management.db`
- 直接复制该文件即可备份
- 将备份文件放回原位置即可恢复

**Q: 如何添加更多试剂？**
- 方式一：在「试剂库存」页面手动添加
- 方式二：准备CSV文件，点击「文件」→「导入试剂CSV」
