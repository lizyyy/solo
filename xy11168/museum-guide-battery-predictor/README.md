# 博物馆讲解组讲解器电量预测 CLI

统一口径的电量预测工具，将正常结果和异常结果分开写，方便人工复核。

## 功能特性

- ✅ 统一处理口径，确保结果一致性
- ✅ 正常结果与异常数据分离输出
- ✅ 不会因漏归还、快充设备、可复跑输出导致整批任务失败
- ✅ 损坏文件会在汇总报告中明确列出
- ✅ 支持单个文件或整个目录批量处理

## 目录结构

```
museum-guide-battery-predictor/
├── src/
│   └── battery_predictor.py    # 主程序
├── input_samples/
│   ├── normal/                 # 正常输入样例
│   │   └── batch_001.csv
│   ├── dirty/                  # 脏数据输入样例
│   │   ├── batch_002_dirty.csv
│   │   └── batch_003_corrupted.csv
│   └── rerun/                  # 重跑对照样例
│       └── batch_001_rerun.csv
└── output/                     # 输出目录
    ├── normal_results/         # 正常电量预测结果
    └── exception_results/      # 异常数据记录
```

## 使用方法

### 基本用法

```bash
python3 src/battery_predictor.py --input <输入路径> --output <输出目录>
```

### 命令行参数

- `--input, -i`: 输入文件或目录路径（必需）
- `--output, -o`: 输出目录路径（默认: ./output）

### 示例

#### 处理单个文件

```bash
python3 src/battery_predictor.py --input input_samples/normal/batch_001.csv --output output
```

#### 处理整个目录

```bash
python3 src/battery_predictor.py --input input_samples/dirty --output output
```

## 输入格式要求

CSV 文件必须包含以下列：

| 列名 | 说明 |
|------|------|
| 设备ID | 设备唯一标识 |
| 设备名称 | 设备名称 |
| 领用时间 | 格式: YYYY-MM-DD HH:MM:SS |
| 归还时间 | 格式: YYYY-MM-DD HH:MM:SS |
| 初始电量(%) | 0-100 之间的数值 |
| 当前电量(%) | 0-100 之间的数值 |
| 讲解员 | 讲解员姓名 |
| 展区 | 展区名称 |
| 快充标识 | 0 或 1 |

## 输出说明

### 正常结果 (`output/normal_results/正常电量预测结果.csv`)

包含电量预测成功的记录，附加字段：

- **耗电速率(%/小时)**: 计算得出的每小时耗电量
- **预测剩余电量(%)**: 预测2小时后的剩余电量
- **预测可使用时长(小时)**: 按当前速率可使用的时间
- **预测说明**: 快充设备按70%耗电计算

### 异常结果 (`output/exception_results/异常数据记录.csv`)

包含所有验证不通过的记录，附加字段：

- **异常原因**: 详细说明问题，多个问题用 | 分隔

### 汇总报告 (`output/处理汇总报告.json`)

JSON 格式的处理统计，包含：

- 总文件数、成功处理数、处理失败数
- 总记录数、正常记录数、异常记录数
- 未处理的损坏文件列表及错误原因
- 异常类型统计

## 异常检测规则

程序会检测以下异常情况：

1. **设备未归还**: 归还时间缺失
2. **时间异常**: 归还时间早于领用时间，或格式无效
3. **电量异常**:
   - 电量数值超出 0-100 范围
   - 当前电量高于初始电量
   - 电量数值缺失或格式无效
4. **快充标识异常**: 不是 0 或 1
5. **文件损坏**: 缺少必需列，或格式严重损坏

## 样例对比说明

三组样例数据可用于验证程序功能：

1. **normal**: 全部数据正常，验证程序对正常数据的处理能力
2. **dirty**: 包含各种异常数据和损坏文件，验证鲁棒性
3. **rerun**: 与 normal 大部分相同，便于对比重跑结果一致性
