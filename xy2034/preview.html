🚀如何运行

⚠️ 重要提示

这是一个微信小程序原生项目，无法直接在普通网页浏览器中运行。需要使用微信开发者工具进行预览和调试。

1

下载微信开发者工具

访问 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
下载并安装稳定版微信开发者工具

2

导入项目

打开微信开发者工具 → 选择"导入项目"
项目目录选择：/Users/mac/pro/solocoder/pro/xy2034/xy2034
AppID：选择"测试号"（或使用项目配置中的 wx1234567890abcdef）
项目名称：高考失利帮

3

编译运行

点击"导入"后项目会自动编译
在左侧模拟器中即可看到小程序界面
可以点击各功能模块进行测试

4

真机预览

点击工具栏的"预览"按钮
用微信扫描二维码，在手机上体验真实效果

💡 关于登录功能

项目中的 wx.getUserProfile API 在新版微信中可能有变化。如需真实登录体验，可能需要调整授权方式。但所有其他功能（浏览帖子、测试、游戏、涂鸦等）都可以正常使用。

💎核心特性

🔒

数据持久化

使用 wx.setStorageSync / wx.getStorageSync 本地存储，所有数据（帖子、评论、测试记录等）都会保存在本地，刷新页面不丢失。

📊

完整数据结构

用户、帖子、评论、测试记录等都有完整的数据模型，包含 ID、创建时间、关联关系等，可直接对接后端接口。

⚙️

真实业务逻辑

GAD-7焦虑量表标准算法、Canvas绘图逻辑、游戏连击系统、点赞评论流程等都是真实可运行的业务逻辑。

🔗

完整用户流程

首页 → 登录 → 使用功能 → 个人中心；列表页 → 详情页 → 评论/点赞；创建页 → 输入验证 → 提交 → 成功反馈。

🎨

统一设计风格

所有页面采用统一的蓝紫色渐变主题、卡片式布局、圆角设计，视觉风格统一，用户体验一致。

📱

响应式适配

所有页面都考虑了不同屏幕尺寸的适配问题，使用 rpx 单位和 flex 布局，确保在各种设备上都能正常显示。
