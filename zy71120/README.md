# 机房机柜热区图 3D 可视化系统

基于 Three.js 的数据中心机房 3D 交互式热区可视化系统，帮助值班员实时监控机柜功耗、温度分布和告警状态，快速识别高危机柜排。

## 功能特性

- 🎮 **3D 交互式场景**: 支持拖拽旋转、缩放、平移，全视角观察机房
- 🔥 **热力层渲染**: 基于功耗/温度数据的动态热区可视化
- ⚠️ **告警系统**: 三级告警筛选（严重/预警/提示），实时告警推送
- 📊 **时间轴回放**: 历史数据播放、快进、暂停，支持多倍速
- 🎯 **视角切换**: 预设 5 种常用视角一键切换
- 💾 **状态持久化**: 刷新页面后筛选和关键状态自动恢复
- 📤 **报告导出**: 一键导出 JSON 格式热区报告
- 📥 **数据导入**: 支持导入自定义机房数据

## 技术栈

- **框架**: React 18 + TypeScript
- **构建**: Vite 5
- **3D 渲染**: Three.js + @react-three/fiber + @react-three/drei
- **状态管理**: Zustand (含 localStorage 持久化)
- **样式**: Tailwind CSS 3
- **图标**: Lucide React
- **导出**: html2canvas + jsPDF

## 操作指南

### 基础操作

1. **导入样例数据**: 首次打开自动加载样例数据，也可点击顶部「导入样例」按钮
2. **3D 场景操作**:
   - 左键拖拽: 旋转视角
   - 右键拖拽: 平移视角
   - 滚轮: 缩放视角
3. **点击机柜**: 查看机柜详细信息（功耗、温度、传感器状态）

### 告警筛选

左侧控制面板「告警筛选」区域，点击不同告警级别可筛选显示对应告警机柜：

- 🔴 严重告警: 功耗 > 80kW
- 🟡 一般告警: 功耗 60-80kW
- 🔵 提示信息: 普通信息

### 图层控制

左侧控制面板「图层控制」区域，可开关以下图层：

- 热力层: 地面温度热力图
- 机柜: 3D 机柜模型
- 标签: 机柜名称和功耗标签
- 气流: 空调出风可视化

### 时间轴操作

底部时间轴控件：

- ⏮️ 跳转到开始
- ▶️/⏸️ 播放/暂停
- ⏭️ 跳转到结束
- 速度调节: 0.5x / 1x / 2x / 4x
- 拖动滑块: 快速跳转时间点

### 视角切换

顶部工具栏「视角」下拉菜单：

- 总览视角: 默认全局视角
- 正面视角: 从前方观察
- 侧面视角: 从右侧观察
- 俯视视角: 从上方俯视
- 热区特写: 聚焦高热区

### 数据导入/导出

1. **导入数据**: 点击「导入数据」按钮，选择 JSON 格式数据文件
2. **导出报告**: 点击「导出报告」按钮，下载当前状态的 JSON 报告
3. **重置**: 点击「重置」按钮清空所有数据

## 可复现操作示例

### 场景 1: 识别高危机柜排

1. 打开页面，等待样例数据加载
2. 确保左侧「热力层」开关已打开
3. 点击顶部「视角」→「俯视视角」
4. 观察地面热力图，红色最集中的区域即为高危险区
5. 第 3 排（索引为 2）的 5-7 号机柜区域会显示明显的红色热区

### 场景 2: 时间轴回放发现异常

1. 点击时间轴的「播放」按钮（▶️）
2. 观察机柜顶部 LED 灯颜色变化
3. 在时间轴约 20/48 位置（约 10 小时后），第 3 排会从正常变为严重告警
4. 点击闪烁红色的机柜查看详细功耗和温度数据

### 场景 3: 告警筛选和报告导出

1. 左侧控制面板只勾选「严重告警」
2. 观察场景中只有红色机柜可见
3. 点击「导出报告」按钮
4. 打开下载的 JSON 文件，确认只包含严重告警数据
5. 刷新页面，验证筛选状态自动恢复

### 场景 4: 传感器离线检测

1. 找到第 2 排第 4 号机柜（机柜 2-4）
2. 点击该机柜，右侧面板显示详情
3. 观察「传感器状态」区域，温度传感器显示为离线状态（红色 WifiOff 图标）
4. 其他机柜传感器均显示在线状态（绿色 Wifi 图标）

## 注意事项

1. **探针离线**: 系统会自动检测传感器在线状态，离线数据显示灰色
2. **机柜方向**: 机柜默认正面朝南，送风方向在数据中定义
3. **同排聚合**: 热区计算会考虑相邻机柜的温度叠加效应
4. **性能优化**: 大量机柜时建议关闭标签显示以提升帧率
