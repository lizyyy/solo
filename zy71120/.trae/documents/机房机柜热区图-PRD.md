## 1. 产品概述
数据中心机房 3D 热区可视化系统，用于值班员实时监控机柜功耗、温度分布和告警状态，快速识别高危机柜排。通过交互式 3D 场景支持拖拽操作、时间轴回放、视角切换和报告导出，实现机房热环境的可操作化和可复盘。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 值班员 | 系统登录 | 3D 场景浏览、告警筛选、报告导出、数据导入 |
| 管理员 | 系统登录 | 配置管理、数据管理、用户管理 |

### 2.2 功能模块
1. **3D 机房场景**: 机柜、空调、温度探针的 3D 可视化
2. **热力层显示**: 基于功耗/温度的热区渲染
3. **告警系统**: 告警筛选、状态标记、离线检测
4. **时间轴控制**: 历史数据回放、视角保存切换
5. **数据管理**: 样例导入、状态持久化
6. **报告导出**: 热区报告生成

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|---------|
| 主页面 | 3D 场景区 | 全视角 3D 机房展示，支持拖拽旋转、缩放、平移 |
| 主页面 | 左侧控制面板 | 告警筛选器、机柜分组、图层开关 |
| 主页面 | 底部时间轴 | 时间滑块、播放/暂停、视角切换按钮 |
| 主页面 | 顶部工具栏 | 导入样例、重置状态、导出报告、设置 |
| 主页面 | 右侧信息面板 | 机柜详情、告警列表、探针状态 |

## 3. 核心流程
用户打开系统 → 导入样例数据 → 3D 场景自动渲染机房布局 → 通过左侧面板筛选告警级别 → 在时间轴上拖动查看历史数据 → 切换视角观察热区分布 → 发现异常机柜 → 导出热区报告作为复盘依据

```mermaid
    E --> F["切换视角观察热区"]
    F --> G["识别高危机柜排"]

    H --> I["复盘分析"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**: 深蓝色 (#0a1628) 背景，营造科技感和数据中心氛围
- **强调色**: 热区红橙色渐变 (#ff4757 → #ff6b35)，安全区域青绿色 (#00d2d3)
- **辅助色**: 告警黄色 (#feca57)，离线灰色 (#576574)
- **字体**: JetBrains Mono 等宽字体用于数据展示，配合 Space Grotesk 标题
- **布局**: 深色系科技风格，半透明面板，玻璃拟态效果
- **图标**: Linear 风格线条图标，简约现代

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 主页面 | 3D 场景区 | 暗色背景、机柜金属质感、热力半透明层、平滑相机动画 |
| 主页面 | 左侧控制面板 | 玻璃拟态面板、折叠分组、开关切换、颜色图例 |
| 主页面 | 底部时间轴 | 渐变进度条、播放控制按钮、时间刻度、热区波动曲线 |
| 主页面 | 顶部工具栏 | 图标按钮组、下拉菜单、状态指示器 |
| 主页面 | 右侧信息面板 | 数据卡片、告警列表、滚动条样式、状态徽章 |

### 4.3 响应式
- Desktop-first 设计，最低支持 1920×1080 分辨率
- 3D 场景自适应窗口大小
- 面板可折叠以适应小屏幕

### 4.4 3D 场景指导
- **环境**: 深色机房环境，地板网格纹理，天花板轻微发光
- **光照**: 环境光 + 方向光模拟机房照明，机柜有环境光遮蔽
- **相机**: 透视相机，支持 OrbitControls 环绕、缩放、平移
- **元素**: 机柜用长方体表示，顶部有 LED 指示灯，热力层为平面几何体
- **交互**: 悬停高亮，点击显示详情，双击聚焦视角
- **动画**: 热力层呼吸效果，告警闪烁，数据更新时平滑过渡
- **性能**: LOD 优化，机柜批量渲染，热力贴图动态更新
