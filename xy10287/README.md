# 物业水泵房巡检声纹记录台

## 安装运行

```bash
pip install -r requirements.txt
python app.py
```

服务启动后访问: http://localhost:5001

## 样例入口

先生成样例数据:
```bash
python sample_data.py
```

生成 `sample_inspection.xlsx`，包含8条典型巡检记录（正常、轴承故障、叶轮失衡、气蚀等场景）。

## 核心操作

### 1. 导入数据
- 上传 Excel/CSV 文件
- 必需列: `pump_room`, `pump_name`, `inspection_date`, `inspector`, `noise_description`
- 系统自动完成：清洗去重 → 声纹特征占位提取 → 规则分类

### 2. 查看记录
- 列表按异常级别(正常/预警/告警/严重)和状态(待复核/已复核)筛选
- 点击眼睛图标查看详情，包含：
  - 巡检基本信息
  - 声纹特征(RMS值、峰值频率、频谱质心、谐波比、匹配关键词)
  - 异常分类结果和匹配规则

### 3. 人工复核
- 点击对勾图标进行人工复核
- 填写复核人、最终异常类型、级别和意见
- 系统更新记录状态为"已复核"

### 4. 导出结果
- 点击"导出全部"按钮下载 Excel
- 包含两个sheet: 巡检结果、统计汇总

### 5. 查看规则
- 点击"查看规则"按钮查看9条可解释规则
- 每条规则包含: ID、名称、触发条件、异常类型/级别、置信度、解释说明

## 如何检查结果

### 数据流转验证
1. 导入后查看统计卡片，确认记录数
2. 打开任意记录详情，检查：
   - `声纹特征` 部分: 4个数值特征是否生成
   - `匹配规则` 部分: 哪些规则被触发(红色高亮)
   - `异常分类结果`: 规则是否可解释

### 幂等性验证
1. 同一文件导入两次
2. 第二次导入时提示"该批次已存在"，新增记录数为0
3. 导出文件检查：统计数据不重复，无膨胀

### 复核验证
1. 对某条记录执行复核
2. 记录状态变为"已复核"
3. 重新导出，检查"最终异常类型/级别"列
