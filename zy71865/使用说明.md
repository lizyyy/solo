# 线性规划讲评 - 使用说明

## 快速开始

### 1. 安装依赖
```bash
npm install
npm link  # 可选，全局安装 lp-review 命令
```

### 2. 三步上手

#### 第一步：放题库表样例
把你的数据文件放到 `data/raw/` 目录下，或直接使用 `samples/` 目录下的样例：

**题库表格式** (`samples/questions.json`):
```json
{
  "questions": [
    {
      "questionNo": 1,
      "content": "题目内容",
      "standardAnswer": "标准答案",
      "equivalentAnswers": ["等价答案1", "等价答案2"],
      "knowledgePoint": "知识点名称",
      "score": 5
    }
  ]
}
```

**学生错题格式** (`samples/mistakes.json`):
```json
{
  "records": [
    {
      "studentId": "S001",
      "studentName": "张三",
      "questionNo": 1,
      "studentAnswer": "学生答案",
      "originalJudgment": "wrong"
    }
  ]
}
```

#### 第二步：导入数据
```bash
# 导入题库表
node bin/index.js import questions 项目名 data/raw/你的题库.json

# 导入学生错题
node bin/index.js import mistakes 项目名 data/raw/你的错题.json

# 导入备注（可选）
node bin/index.js import notes 项目名 data/raw/你的备注.json
```

#### 第三步：运行完整流程
```bash
# 查看项目状态
node bin/index.js review status 项目名

# 自动复核
node bin/index.js review auto 项目名

# 查看异常记录
node bin/index.js review anomalies 项目名
```

## 关键操作指南

### 去哪看等价答案误判？

运行 `lp-review review anomalies 项目名` 或 `node bin/index.js review anomalies 项目名 --detail`

- **异常代码 EQ001** 就是等价答案误判
- 系统会自动识别学生答案与标准答案表述不同但实质等价的情况
- 查看详情：`lp-review review explain EQ001`

处理方法：
```bash
# 查看所有异常
lp-review review anomalies 项目名 --detail

# 手动改判为正确
lp-review correct mistake 项目名 --question 题号 --student 学生ID --judgment correct --reason "等价答案"
```

### 导出讲评稿前怎么复核？

**导出前必做三步检查：**

1. **导出前预检**
   ```bash
   lp-review export check 项目名
   ```
   检查内容：
   - ✓ 复核进度 100%
   - ✓ 无异常记录
   - ✓ 数据一致性
   - ✓ 讲评分段完整性

2. **处理遗留问题**
   ```bash
   # 查看待复核
   lp-review review pending 项目名
   
   # 查看异常
   lp-review review anomalies 项目名
   
   # 版本对比，确认改判无误
   lp-review history compare 项目名
   ```

3. **确认截图变更历史**
   ```bash
   lp-review history screenshot 项目名
   ```
   确保讲义截图的前后变化都已留痕，讲评稿和明细数据一致。

**最后导出：**
```bash
# 正常导出（所有检查通过）
lp-review export script 项目名

# 强制导出（有未处理问题时）
lp-review export script 项目名 --force
```

导出文件在 `data/exports/` 目录下：
- `*-review-script-v*.md` - 讲评稿（Markdown格式）
- `*-export-detail-v*.json` - 明细数据
- `*-consistency-report-v*.json` - 一致性报告

## 常用命令速查

| 功能 | 命令 |
|------|------|
| 导入题库 | `lp-review import questions <项目> <文件>` |
| 导入错题 | `lp-review import mistakes <项目> <文件>` |
| 自动复核 | `lp-review review auto <项目>` |
| 看异常 | `lp-review review anomalies <项目>` |
| 看状态 | `lp-review review status <项目>` |
| 手动改判 | `lp-review correct mistake <项目> --question 1 --student S001 --judgment correct` |
| 更新讲评稿 | `lp-review correct section <项目> --knowledge-point "知识点" --screenshot-note "截图说明"` |
| 看截图历史 | `lp-review history screenshot <项目>` |
| 看改判历史 | `lp-review history correction <项目>` |
| 导出前检查 | `lp-review export check <项目>` |
| 导出讲评稿 | `lp-review export script <项目>` |

---

## 数据一致性保证

- 所有手动修改自动留痕，可随时回看历史
- 讲评稿导出时自动标记版本号，每次导出版本号+0.1
- 导出同时生成一致性报告，确保讲评稿和明细数据一致
- 讲义截图备注的每次变更都有diff对比，前后变化清晰可查
