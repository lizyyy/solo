# 物理实验误差传播分析工具

专为大学物理实验课设计的误差传播分析系统，支持：

- **误差传播计算**：基于符号计算自动推导误差传播公式
- **单位校验**：自动检测单位不一致问题
- **数据清洗**：处理空列、错别字、重复行等脏数据
- **步骤解释**：每一步计算都有清晰的公式和文字说明
- **图表导出**：误差贡献柱状图、误差传播网络图等
- **历史追踪**：记录所有人工修改，支持版本对比

## 安装

```bash
pip install -e .
```

## 快速开始

```bash
# 处理单个CSV文件
errorprop process data/experiment.csv --output report.html

# 交互式模式
errorprop interactive

# 查看历史记录
errorprop history list
```

## 处理流程

1. **数据导入与清洗** → 2. **单位校验** → 3. **误差传播计算** → 4. **步骤解释生成** → 5. **图表导出** → 6. **历史保存**
