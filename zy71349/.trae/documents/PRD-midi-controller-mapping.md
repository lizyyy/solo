## 1. 产品概述

MIDI控制器映射看板——帮助键盘手在更换MIDI控制器后，快速完成旋钮、踏板、音源参数的映射，自动识别通道冲突、踏板极性反转、预设覆盖等异常，并提供预设保存、导出、回滚历史与复盘能力。
- 解决键盘手换控制器后反复查说明书的痛点，让映射过程可追溯、异常可识别、历史可回滚
- 目标用户：使用MIDI控制器进行音乐制作/现场演出的键盘手

## 2. 核心功能

### 2.1 用户角色
无需角色区分，单用户本地工具。

### 2.2 功能模块
1. **映射工作台**：MIDI学习、控制器事件到音源参数的映射绑定、踏板与旋钮配置
2. **冲突检测面板**：通道冲突、踏板极性反转、预设覆盖的实时识别与告警
3. **预设管理**：预设保存/加载/覆盖、导出映射报告、回滚历史
4. **复盘入口**：查看历史映射结论、异常溯源、补传材料后的增量分析

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 映射工作台 | 控制器事件面板 | 展示当前控制器输入（CC号、通道、值范围），支持MIDI学习模式捕获事件 |
| 映射工作台 | 音源参数面板 | 展示音源可映射参数列表（参数名、类型、值域），支持搜索与筛选 |
| 映射工作台 | 映射绑定区 | 拖拽/点击将控制器事件绑定到音源参数，显示当前映射关系表 |
| 映射工作台 | 踏板配置 | 踏板极性设置（正/反）、CC号指定、值范围校准 |
| 冲突检测面板 | 冲突列表 | 实时展示所有检测到的冲突（通道冲突、极性反转、预设覆盖），按严重程度排序 |
| 冲突检测面板 | 异常追溯 | 点击冲突项可追溯来源（哪条映射记录、哪个预设、哪次操作引发） |
| 预设管理 | 预设列表 | 保存/加载/删除预设，显示预设名称、创建时间、映射条目数 |
| 预设管理 | 导出映射 | 导出当前映射为JSON/CSV报告 |
| 预设管理 | 回滚历史 | 操作历史时间线，支持回滚到任意历史节点 |
| 复盘入口 | 历史结论 | 展示过往映射会话的结论摘要，支持跳转到对应历史快照 |
| 复盘入口 | 补传分析 | 接收晚到/补传的材料（控制器事件、音源参数），增量更新冲突检测结果 |

## 3. 核心流程

**主流程**：用户选择控制器 → MIDI学习捕获事件 → 绑定音源参数 → 系统实时检测冲突 → 保存预设 → 导出映射报告
**异常流程**：冲突检测发现异常 → 用户点击追溯 → 定位来源材料/映射记录 → 修正映射 → 重新检测
**复盘流程**：用户进入复盘入口 → 查看历史结论 → 补传新材料 → 增量分析更新 → 不重新导入即可解释结论

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深色背景（#0D1117）配荧光绿（#00FF87）作为强调色，致敬硬件合成器面板风格
- 辅助色：琥珀色（#FFB800）用于警告/冲突，红色（#FF4444）用于严重冲突
- 按钮风格：圆角微凸起，带微妙渐变，模拟硬件旋钮质感
- 字体：JetBrains Mono（数据显示）+ Noto Sans SC（中文界面）
- 布局风格：三栏布局（左：控制器事件 / 中：映射绑定 / 右：音源参数），顶栏导航
- 图标风格：线性图标，1.5px描边，荧光绿高亮

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 映射工作台 | 控制器事件面板 | 深色卡片列表，每行显示CC号/通道/值范围，MIDI学习时脉冲动画 |
| 映射工作台 | 映射绑定区 | 连线可视化（左→右），表格展示映射关系，冲突项红色高亮 |
| 映射工作台 | 踏板配置 | 旋钮式交互控件，极性切换开关（正/反），值范围滑块 |
| 冲突检测面板 | 冲突列表 | 琥珀/红色边框卡片，按严重程度排序，点击展开详情 |
| 冲突检测面板 | 异常追溯 | 面包屑路径：冲突→映射记录→来源事件/预设 |
| 预设管理 | 预设列表 | 紧凑卡片网格，显示名称/时间/条目数，hover显示操作按钮 |
| 预设管理 | 回滚历史 | 垂直时间线，每个节点显示操作摘要，点击回滚 |
| 复盘入口 | 历史结论 | 折叠面板，每条结论含异常计数、映射完整性评分 |
| 复盘入口 | 补传分析 | 拖拽上传区，解析后自动触发增量分析 |

### 4.3 响应式
桌面端优先设计（键盘手主要在DAW环境中使用），最小支持1280px宽度，移动端暂不适配。

### 4.4 3D场景
不适用。
