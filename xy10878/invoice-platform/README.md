# 用量计费发票台

SaaS客户API调用量计费对账系统，支持按规则版本聚合、人工折扣调整、发票申请和差异清单导出。

## 功能特性

### 核心功能
- ✅ **调用明细导入** - 批量导入API调用记录
- ✅ **按规则版本聚合** - 自动匹配适用的定价规则
- ✅ **免费额度抵扣** - 支持每个规则版本的免费调用次数
- ✅ **人工折扣调整** - 支持人工输入折扣或附加费
- ✅ **锁定账期** - 锁定后金额不可重复生成
- ✅ **发票状态管理** - 草稿/提交/审批/驳回/开票
- ✅ **差异清单导出** - Excel导出，标注每笔差异来源规则

### 数据模型
- **客户(Customer)** - 客户基本信息
- **定价规则(PricingRule)** - 多版本定价规则，含免费额度和单价
- **调用明细(CallDetail)** - 每条API调用记录
- **账期(BillingPeriod)** - 计费周期管理
- **计费汇总(BillingSummary)** - 按规则版本聚合的计费结果
- **调整记录(Adjustment)** - 人工调整历史
- **发票(Invoice)** - 发票申请单
- **差异记录(VarianceRecord)** - 每笔差异的来源和说明

## 快速开始

### 1. 安装后端依赖

```bash
cd backend
pip install -r requirements.txt
```

### 2. 初始化测试数据

```bash
python init_test_data.py
```

测试数据包含：
- 1个客户：云端科技有限公司
- 2个定价规则版本：
  - v1.0: 1000次免费，超出0.10元/次 (1-3月适用)
  - v2.0: 500次免费，超出0.15元/次 (4月起适用)
- 2300条调用明细：
  - 3月：1500次 (超额500次，计费50元)
  - 4月：800次 (超额300次，计费45元)

### 3. 启动后端服务

```bash
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

API文档地址: http://localhost:8000/docs

### 4. 访问前端页面

直接用浏览器打开 `frontend/index.html` 即可

## API接口说明

### 客户管理
- `GET /customers/` - 获取客户列表
- `POST /customers/` - 创建客户

### 定价规则
- `GET /pricing-rules/` - 获取定价规则
- `POST /pricing-rules/` - 创建定价规则

### 调用明细
- `GET /call-details/` - 获取调用明细
- `POST /call-details/import/` - 批量导入调用明细

### 账期管理
- `GET /billing-periods/` - 获取账期列表
- `POST /billing-periods/` - 创建账期
- `GET /billing-periods/{id}` - 获取账期详情
- `POST /billing-periods/{id}/lock/` - 锁定账期

### 调整与发票
- `POST /adjustments/` - 创建人工调整
- `POST /invoices/submit/` - 提交发票申请
- `POST /invoices/{id}/approve/` - 审批发票
- `POST /invoices/{id}/reject/` - 驳回发票
- `POST /invoices/{id}/export/` - 导出Excel

## 核心业务逻辑

### 锁定账期流程
```
1. 检查账期是否已锁定 → 已锁定则直接返回，避免重复计费
2. 查询该账期内所有未计费的调用明细
3. 对每条调用明细，根据调用时间匹配适用的定价规则
4. 按规则版本分组聚合：
   - 计算总调用次数
   - 抵扣该版本的免费额度
   - 计算计费调用次数和基础金额
5. 标记所有调用明细为"已计费"
6. 标记账期为"已锁定"
```

### 差异记录生成
```
1. 查询 Adjustment 表获取所有人工调整记录（支持折扣和附加费）
2. 比较基础金额与预期金额 → 记录系统计算差异 (base_amount_mismatch)
3. 为每条折扣调整生成差异记录 (manual_discount)
4. 为每条附加费调整生成差异记录 (manual_surcharge)
5. 每条差异记录都包含：
   - 规则版本
   - 预期金额
   - 实际金额
   - 差异金额
   - 差异说明（含调整原因、操作人）
   - 来源规则（含调整记录ID、类型）
```

### 人工调整类型
| 类型 | 说明 | 差异类型 |
|------|------|----------|
| discount | 人工折扣，从基础金额中扣除 | manual_discount |
| surcharge | 额外收费，添加到最终金额 | manual_surcharge |

## 技术栈

- **后端**: Python 3.8+, FastAPI, SQLAlchemy, Pydantic
- **数据库**: SQLite (可切换为MySQL/PostgreSQL)
- **前端**: Vue 3, Element Plus
- **导出**: pandas, openpyxl (Excel)

## 注意事项

1. **重复锁账保护**：已锁定的账期不会重复生成计费汇总，确保幂等性
2. **调用去重**：每条调用明细只会被计费一次(通过is_billed标记)
3. **规则匹配**：按调用时间和规则生效/结束时间精确匹配
4. **差异追溯**：所有金额变更都有差异记录可追溯，标注来源
