## 1. 产品概述
为街道工作人员提供"15分钟生活圈缺口图"数据处理工具，解决同一点位多种写法导致的重复核对问题。支持GIS点位导入、智能归并、人工复核、历史留痕及分类导出，大幅提升工作效率。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 街道工作人员 | 无需注册（本地工具） | 数据导入、点位归并、人工复核、导出清单 |

### 2.2 功能模块
1. **数据导入页面**：GIS点位导入、居民反馈导入、巡检照片上传、街道备注录入
2. **点位归并页面**：智能匹配相同点位、人工确认归并关系、查看匹配证据
3. **人工复核页面**：点位详情查看、冲突对比展示、状态标记、补录备注、历史意见查看
4. **导出公示页面**：按状态筛选、分类导出、导出预览

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入页 | 导入面板 | 支持多源数据批量导入，显示导入进度和结果统计 |
| 数据导入页 | 样例数据 | 提供"顺利处理"和"需要返工"两套样例数据一键导入 |
| 点位归并页 | 智能匹配列表 | 按相似度分组展示疑似相同点位，支持人工确认/拒绝 |
| 点位归并页 | 匹配详情 | 展示点位匹配证据，包括名称相似度、地址匹配度、坐标距离 |
| 人工复核页 | 点位详情卡 | 展示点位完整信息：GIS数据、居民反馈、巡检照片、历史记录 |
| 人工复核页 | 冲突处理 | 当GIS与导入数据冲突时，并排展示两边证据，提供建议动作 |
| 人工复核页 | 状态流转 | 标记为"已处理"/"待核实"/"需要现场复看"，支持补录临时备注 |
| 人工复核页 | 历史记录 | 展示点位的所有修改历史，包括旧方案被覆盖时保留的历史意见 |
| 导出公示页 | 分类筛选 | 按处理状态筛选点位，查看各类别统计数量 |
| 导出公示页 | 导出预览 | 预览导出内容，支持Excel/CSV格式导出 |

## 3. 核心流程
用户导入多源数据 → 系统智能归并疑似相同点位 → 人工确认归并关系 → 逐点复核并标记状态 → 冲突时展示证据供用户决策 → 按状态分类导出公示清单

```mermaid
flowchart LR
    A["数据导入"] --> B["智能归并"]
    B --> C["人工确认归并"]
    C --> D["点位复核"]
    D --> E{"存在冲突?"}
    E -->|是| F["展示双方证据+建议"]
    E -->|否| G["标记状态"]
    F --> G
    G --> H{"补录备注?"}
    H -->|是| I["记录差异说明"]
    H -->|否| J["保留历史意见"]
    I --> J
    J --> K["分类导出"]
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：政务蓝 (#1E40AF)，体现专业可信
- 辅助色：绿色 (#059669) 已处理、橙色 (#D97706) 待核实、红色 (#DC2626) 需现场复看
- 按钮风格：圆角矩形，轻微阴影，hover时有微放大效果
- 字体：系统无衬线字体，标题18px粗体，正文14px常规
- 布局风格：卡片式布局，左侧导航+右侧内容区
- 图标风格：简洁线性图标，与政务系统风格统一

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|----------|
| 数据导入页 | 导入面板 | 拖放区域、文件列表、进度条、统计数字卡片 |
| 点位归并页 | 匹配列表 | 相似度标签、并排对比卡片、确认/拒绝按钮组 |
| 人工复核页 | 详情卡片 | 标签页切换（基本信息/反馈/照片/历史）、状态切换器、冲突对比面板 |
| 导出公示页 | 分类视图 | 状态筛选标签、数据表格、导出按钮组 |

### 4.3 响应性
桌面端优先（1280px+），支持平板适配，保证核心功能在1024px宽度下可用。

### 4.4 交互动效
- 页面加载：内容区域淡入（200ms）
- 卡片hover：轻微上浮（translateY -2px）+ 阴影加深
- 状态切换：平滑过渡颜色变化
- 导入进度：进度条动画流畅
