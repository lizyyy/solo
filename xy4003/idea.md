## 原始点子

我想做一个给小型物业前台用的全栈 Web 小工具，专门登记住户寄存钥匙和临时放行条。打开后就是可用的工作台：左侧录入房号、住户姓名、手机号、寄存物类型、领取人、有效期和备注，右侧能按房号、手机号、状态快速查找。数据要放到本地 SQLite 数据库里，刷新页面或重启服务后不能丢；同一房号同一手机号如果还有“待领取”的记录，录入时要拦住并提示原因。每条记录都要有状态流转：待领取、已领取、已过期，领取时记录领取时间和操作人，过期状态要能自动算出来但不能覆盖历史。再做一个 CSV 导入/导出，导入时要逐行校验并给出成功、跳过、失败的明细，失败行不要写进库里。请把前端页面、服务端、数据库初始化、校验规则和 README 都搭好，README 里写清楚怎么启动和验证主要流程。
