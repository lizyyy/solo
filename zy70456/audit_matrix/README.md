# 多源审计取证参数矩阵命令行工具

用于检查和验证门店设备台账审计材料的命令行工具。

## 功能特性

- **负责人验证**: 自动检测审计材料中的负责人缺失情况
- **部分成功处理**: 遇到部分成功时，保留每条明细状态，不整批标记
- **人工修正备注**: 支持人工修正判断，保留修改历史和理由
- **环境追溯**: 通过环境名称查找原始输入和处理依据
- **明确的返回码**: 不同场景返回不同的退出码，便于自动化集成

## 安装

```bash
cd audit_matrix
pip install -e .
```

## 使用方法

### 1. 检查审计材料

```bash
# 检查正常材料（文本输出）
audit-matrix check examples/朝阳门店_正常材料.yaml

# 检查负责人缺失材料（JSON输出）
audit-matrix check examples/海淀店_负责人缺失.yaml -f json

# 保存结果到文件
audit-matrix check examples/朝阳门店_正常材料.yaml -o result.json
```

### 2. 人工修正审计项

```bash
audit-matrix correct examples/海淀店_负责人缺失.yaml DEV-102 \
  -c "审核员-王芳" \
  -s "pass" \
  -r "该设备负责人为孙涛，已通过OA流程确认" \
  -e "https://oa.example.com/approval/20241201" \
  -o corrected_result.json
```

### 3. 查找环境原始数据和处理依据

```bash
audit-matrix lookup "朝阳门店"
```

## 返回码说明

| 返回码 | 含义 |
|--------|------|
| 0 | 全部通过 |
| 1 | 全部失败 |
| 4 | 部分成功（部分通过，部分失败） |
| 其他 | 处理错误 |

## 错误码说明

| 错误码 | 含义 |
|--------|------|
| E001 | 负责人缺失 |
| E002 | 数据格式无效 |
| E003 | 文件不存在 |
| E004 | 部分成功 |
| E999 | 未知错误 |
