# 电动车换电柜槽位分配台 - 使用说明

## 项目概述

本系统是一个完整的电动车换电柜槽位分配演示平台，覆盖了从槽位状态管理、预约锁定、电池流转、故障隔离到超时释放和运营报表的完整业务流程。

### 核心差异点

1. **换电槽位**：支持多种状态（满电、空槽、预约中、使用中、故障），带可视化状态标识
2. **电池状态**：实时追踪电池电量、健康状态，支持电量异常检测
3. **预约释放**：支持超时自动释放、手动取消、异常状态人工复核

## 功能模块详解

### 🎯 主流程覆盖

#### 1. 槽位状态机

系统支持以下槽位状态：
- **满电 (full)**：电池充满，可预约取电
- **空槽 (empty)**：无电池，可用于归还
- **已预约 (reserved)**：被预约锁定中
- **使用中 (occupied)**：电池充电中或刚归还
- **故障 (fault)**：槽位或电池故障

状态转换图：
```
空槽 ←→ 已预约 → 归还电池 → 使用中(充电)
       ↑                          ↓
       └── 取消/超时 ──────────────┘

满电 ←→ 已预约 → 取电完成 → 空槽
       ↑                     ↓
       └── 取消/超时 ────────┘
```

#### 2. 预约锁定流程

完整换电流程步骤：

1. **创建预约**：骑手发起预约，系统自动分配两个槽位
   - 取电槽位：有满电电池的槽位
   - 归还槽位：空槽位

2. **归还空电池**：骑手到柜，插入空电池
   - 系统验证电量（>80% 触发待复核）
   - 验证通过后开始充电流程

3. **取满电电池**：骑手取出满电电池
   - 系统验证电池状态（故障电池触发待复核）
   - 验证通过后完成换电

#### 3. 故障隔离

- **自动检测**：归还时电量过高、取电时电池故障自动触发
- **运营标记**：人工标记槽位故障
- **解除故障**：运营复核后解除
- **待复核状态**：异常预约需要人工确认

#### 4. 超时释放

- 预约有效期：5分钟（可配置）
- 自动释放：过期预约自动释放槽位
- 手动检查：点击"检查超时"按钮立即处理

## 📋 演示样例

### 样例一：顺利换电流程 ✅

**预期结果**：完整完成一次换电操作

**操作步骤**：

   - 确认柜面显示：5个满电、7个空槽

2. **创建预约**
   - 点击「+ 新建预约」按钮
   - 输入骑手信息：
     - 姓名：`张师傅`
     - 手机号：`13800138000`
   - 点击「确认预约」
   - 记录分配的槽位号（如：取电 #1，归还 #4）

3. **归还空电池**
   - 在右侧「预约管理」找到刚创建的预约
   - 点击「归还电池」按钮
   - 输入电池编号（正常电池）：
     ```
     BAT-TEST001
     ```
   - 点击「确认归还」
   - 观察：状态变为 `in_progress`（进行中）

4. **取出满电电池**
   - 点击「取出满电电池」按钮

   - 观察：状态变为 `completed`（已完成）

5. **查看历史**
   - 切换到「📜 历史记录」标签
   - 查看完整操作轨迹

### 样例二：触发拦截 - 电量过高 ⚠️

**预期结果**：归还时检测到电量过高，触发待复核

**操作步骤**：

1. **重置演示数据**
   - 点击「🔄 重置演示」按钮

2. **创建预约**
   - 点击「+ 新建预约」
   - 输入：姓名=`李师傅`，手机号=`13900139000`
   - 确认预约

3. **归还高电量电池（触发拦截）**
   - 点击「归还电池」按钮
   - 输入电池编号（以 **HIGH** 开头强制高电量，85-99%）：
     ```
     HIGH-TEST001
     ```
   - 点击「确认归还」
   - ⚠️ **关键：电池编号必须以 `HIGH` 开头**（不区分大小写），如 `HIGH001`、`high-test`、`HIGH-DEMO`

4. **观察异常状态**
   - 收到错误提示：「归还电池电量异常，需要运营复核」
   - 预约状态变为 `needs_review`（待复核）
   - 预约卡片显示黄色警告边框

5. **运营复核**
   - 点击「运营复核」按钮
   - 选择复核操作：
     - **批准**：允许继续换电流程
     - **拒绝**：终止流程，电池标记为待处理
   - 确认后观察状态变化

### 样例三：触发拦截 - 电池故障 🔧

**预期结果**：取电时发现故障电池，触发待复核

**操作步骤**：

1. **加载混合场景**
   - 点击「⚠️ 加载混合场景」
   - 观察：柜面有故障槽位（红色闪烁）

2. **手动模拟故障电池**
   - 先完成一次正常预约和归还（步骤同样例一）
   - 在归还后、取电前，系统内部检测到取电槽位的电池状态

3. **取出故障电池**
   - 当预约状态为 `in_progress` 时
   - 点击「取出满电电池」
   - （注：可在代码中设置特定槽位电池为故障状态来测试）

4. **触发待复核**
   - 收到错误提示：「该槽位电池故障，需要运营复核」
   - 预约进入 `needs_review` 状态

5. **复核处理**
   - 选择「批准」：假设运营确认电池可用，继续完成
   - 或选择「拒绝」：终止流程

---

### 样例四：故障隔离和解除 🔴

**操作步骤**：

1. **标记槽位故障**
   - 点击任意非预约中的槽位（如 #2）
   - 点击「标记故障」按钮
   - 输入故障原因：
     ```
     槽位门无法正常关闭
     ```
   - 点击「确认标记」

2. **观察故障状态**
   - 槽位变为红色，带闪烁动画
   - 右侧「运营报表」显示故障槽位列表

3. **解除故障**
   - 再次点击该槽位
   - 点击「解除故障」按钮
   - 槽位恢复正常状态

## 📊 运营报表

### 查看报表

1. 切换到「📊 运营报表」标签
2. 系统自动生成当月报表

### 报表包含内容

- **总预约数**：本月所有预约数量
- **成功率**：完成的预约占比
- **待复核**：需要人工处理的异常数
- **统计详情**：完成/取消/超时/失败分类统计
- **故障槽位**：当前故障列表

### 导出报表

- 点击「📥 导出报表」按钮
- 下载 JSON 格式文件
- 文件名格式：`换电柜报表_YYYY-MM-DD.json`

### 常见问题

**Q: 页面显示"加载中..."怎么办？**
- 确认后端服务已启动（端口 3001）
- 检查网络连接
- 刷新页面重试

**Q: 创建预约失败？**
- 检查是否有可用的满电槽位和空槽位
- 当前进行中的预约是否超过3个
- 查看错误提示中的建议

**Q: 如何查看详细状态？**
- 点击任意槽位查看详情
- 查看历史记录追踪完整操作轨迹

**Q: 如何批量测试？**
- 使用「加载正常场景」和「加载混合场景」快速切换
- 使用「重置演示」回到初始状态

## 📝 状态对照

### 槽位状态颜色
- 🟢 绿色渐变：满电
- 🔵 蓝色渐变：空槽
- 🔴 粉红渐变：已预约（带脉冲动画）
- 🟣 紫色渐变：使用中
- 🔴 红色渐变：故障（带摇晃动画）

### 预约状态
- `pending`：等待确认
- `confirmed`：已确认，待归还
- `in_progress`：进行中，待取电
- `completed`：已完成
- `expired`：已超时
- `cancelled`：已取消
- `failed`：失败
- `needs_review`：待复核
