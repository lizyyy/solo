# 租户水电分摊账单系统

## 功能特性

### 异常看板 (Dashboard)
- 待处理异常统计
- 本月账单总额统计
- 未收款总额统计
- 活跃租户统计
- 异常账单列表（提前退租、水量异常、电量异常）
- 未收款汇总

### 账单管理
- 生成账单（按合同+月份）
- 账单列表筛选（状态、异常、月份）
- 收款登记
- 人工调整（增加/减少费用）
- 调整记录查看
- 异常处理

### 基础数据管理
- 租户管理（增删改查）
- 合同管理（含分摊比例）
- 抄表记录管理
- 特殊设备管理（空调、网络设备等）

### 批量导入
- Excel导入抄表记录
- Excel导入租户数据

### 报表导出
- 月度汇总报表
- Excel导出账单明细
- 按处理人、状态筛选导出

### 审计日志
- 记录所有数据操作（增删改）
- 记录修改前后值
- 操作人追踪

## 业务规则

### 异常检测规则
1. **提前退租异常**：合同结束日期在账单月份内，按天计算费用
2. **水量异常**：单月用水量 > 200 吨
3. **电量异常**：单月用电量 > 5000 度

### 分摊计算
- 水费：用水量 × 水价 × 分摊比例
- 电费：用电量 × 电价 × 分摊比例
- 设备费：按功率×小时×天数计算或固定费用

## 技术栈

- **后端**：Node.js + Express
- **数据库**：SQLite3（持久化存储，重启不丢失）
- **前端**：Vue.js + Element UI
- **Excel处理**：xlsx

## 安装运行

```bash
# 安装依赖
npm install

# 初始化数据库
npm run init-db

# 插入演示数据
npm run sample-data

# 启动服务
npm start
```

访问 http://localhost:3000
