我想做一个给内网安全培训小组用的本地 Passkey/WebAuthn 演练沙盒，叫“无密码登录训练场”。我们给业务系统改造登录方式时，经常讲不清楚注册挑战值、凭据 ID、签名计数器、撤销设备和重放攻击之间的关系，培训时只能拿 PPT 说，大家很难真正试一遍。请从 0 到 1 做一个可以在 localhost 运行的全栈 Web 应用：前端打开后直接是训练工作台，不要做营销首页；左侧能维护演练用户和设备备注，中间提供 Passkey 注册、登录验证、撤销凭据、模拟丢失设备的操作流，右侧显示每一步的挑战值、credentialId、签名计数器、校验结果和审计日志。后端要提供真实 API，并用 SQLite 或本地文件数据库保存用户、凭据、公钥/算法信息、挑战值、撤销状态和审计记录，刷新页面和重启服务后数据不能丢。注册和登录流程要正确处理 challenge 的一次性使用和过期，校验 rpId/origin/userHandle，发现重复凭据、已撤销凭据继续登录、challenge 重放、签名计数器倒退、用户不存在、前端字段缺失时要返回清楚错误，不能只做前端假状态。考虑到有些环境没有可用 Passkey，项目还要提供一个“教学模拟器”模式，用可复现的本地密钥对模拟 authenticator 响应，但真实 WebAuthn 模式和模拟模式的 API、状态机、审计日志要共用同一套校验逻辑。还要支持导出 Markdown 培训复盘和 JSON 审计包，里面列出每次注册/登录/撤销的证据、命中的风险和操作时间。请把前端组件、WebAuthn/模拟器适配、挑战值服务、凭据存储、校验规则、审计日志、导入导出、API 路由、示例数据和测试拆成清晰的多文件结构，不要写成一个大文件。README 里写清楚安装、启动，以及如何用 localhost 验证注册、登录、重放挑战被拒、撤销后登录失败、模拟器模式和导出报告这些核心流程。
