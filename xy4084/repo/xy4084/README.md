# 训练随访趋势复盘台

一个给社区康复治疗师使用的本地数据分析与可视化应用，帮助治疗师分析老人居家训练数据，识别需要提前回访的患者。

## 功能特性

- **数据导入**：支持批量导入多份CSV文件，自动识别数据类型
- **数据清洗**：自动清洗异常值、去重、标准化处理
- **指标计算**：
  - 训练依从率
  - 疼痛评分变化趋势
  - 动作完成质量与稳定性
  - 缺训天数统计
- **风险评估**：
  - 依从性风险
  - 疼痛风险
  - 动作稳定性风险
  - 缺训风险
  - 风险等级自动分级（低/中/高/危急）
- **可视化展示**：
  - 依从率趋势图
  - 疼痛评分时间序列
  - 训练项目分布
  - 风险等级分布
- **报告导出**：
  - 单人周报（Markdown格式）
  - 风险汇总报告（Markdown格式）
  - 指标汇总CSV
  - 风险评估CSV
- **阈值配置**：可自定义各项风险阈值
- **示例数据**：一键生成模拟数据用于测试

## 数据格式说明

### 支持的CSV文件类型

#### 1. 患者信息 (patient.csv)

| 列名 | 类型 | 必填 | 说明 |
|------|------|------|------|
| patient_id | 字符串 | 是 | 患者唯一标识 |
| name | 字符串 | 是 | 患者姓名 |
| age | 整数 | 是 | 年龄 |
| gender | 字符串 | 是 | 性别（男/女） |
| primary_diagnosis | 字符串 | 否 | 主要诊断 |
| treatment_plan | 字符串 | 否 | 治疗计划 |
| admission_date | 日期 | 否 | 入院日期 |
| notes | 字符串 | 否 | 备注 |

示例：
```csv
patient_id,name,age,gender,primary_diagnosis,treatment_plan,admission_date,notes
P0001,张三,65,男,脑卒中后偏瘫,每周训练5天,2024-01-15,需要密切关注
P0002,李四,70,女,膝关节置换术后,每日训练30分钟,2024-02-01,
```

#### 2. 训练记录 (training.csv)

| 列名 | 类型 | 必填 | 说明 |
|------|------|------|------|
| patient_id | 字符串 | 是 | 患者ID |
| date | 日期 | 是 | 训练日期 |
| training_program | 字符串 | 是 | 训练项目名称 |
| is_completed | 布尔/字符串 | 是 | 是否完成（是/否, true/false, 1/0） |
| completion_percentage | 浮点数 | 否 | 完成百分比（0-100） |
| duration_minutes | 整数 | 否 | 训练时长（分钟） |
| difficulty_level | 字符串 | 否 | 难度等级 |
| notes | 字符串 | 否 | 备注 |

示例：
```csv
patient_id,date,training_program,is_completed,completion_percentage,duration_minutes,difficulty_level,notes
P0001,2024-01-15,上肢力量训练,是,85,30,中等,完成良好
P0001,2024-01-16,下肢力量训练,是,75,25,中等,
P0001,2024-01-17,平衡训练,否,30,10,简单,未完成
```

#### 3. 疼痛评分 (pain.csv)

| 列名 | 类型 | 必填 | 说明 |
|------|------|------|------|
| patient_id | 字符串 | 是 | 患者ID |
| date | 日期 | 是 | 评分日期 |
| pain_location | 字符串 | 是 | 疼痛部位 |
| pain_score | 整数 | 是 | 疼痛评分（0-10） |
| pain_type | 字符串 | 否 | 疼痛类型 |
| notes | 字符串 | 否 | 备注 |

示例：
```csv
patient_id,date,pain_location,pain_score,pain_type,notes
P0001,2024-01-15,左膝关节,5,酸痛,
P0001,2024-01-17,左膝关节,6,胀痛,疼痛加剧
P0001,2024-01-20,左膝关节,4,酸痛,有所缓解
```

#### 4. 动作完成度 (movement.csv)

| 列名 | 类型 | 必填 | 说明 |
|------|------|------|------|
| patient_id | 字符串 | 是 | 患者ID |
| date | 日期 | 是 | 记录日期 |
| movement_name | 字符串 | 是 | 动作名称 |
| completion_score | 浮点数 | 是 | 完成分数（0-100） |
| form_quality | 浮点数 | 否 | 动作质量分数 |
| range_of_motion | 浮点数 | 否 | 活动度分数 |
| symmetry_score | 浮点数 | 否 | 对称性分数 |
| notes | 字符串 | 否 | 备注 |

示例：
```csv
patient_id,date,movement_name,completion_score,form_quality,range_of_motion,symmetry_score,notes
P0001,2024-01-15,坐位站起,70,75,65,72,
P0001,2024-01-17,坐位站起,75,78,70,75,有所进步
P0001,2024-01-20,坐位站起,80,82,75,78,
```

#### 5. 随访记录 (followup.csv)

| 列名 | 类型 | 必填 | 说明 |
|------|------|------|------|
| patient_id | 字符串 | 是 | 患者ID |
| date | 日期 | 是 | 随访日期 |
| therapist_name | 字符串 | 是 | 治疗师姓名 |
| follow_up_type | 字符串 | 是 | 随访类型 |
| summary | 字符串 | 是 | 随访摘要 |
| recommendations | 字符串 | 否 | 建议 |
| next_follow_up_date | 日期 | 否 | 下次随访日期 |

示例：
```csv
patient_id,date,therapist_name,follow_up_type,summary,recommendations,next_follow_up_date
P0001,2024-01-20,王医生,电话随访,训练依从性良好,继续当前计划,2024-02-03
P0001,2024-02-03,李治疗师,上门随访,疼痛有所加剧,建议门诊复查,2024-02-17
```

## 使用指南

### 快速开始

1. **生成示例数据**（推荐首次使用）：
   - 进入 **"🧪 示例数据"** 页面
   - 点击 **"生成示例数据并加载"**
   - 应用会自动生成10名患者4周的模拟数据

2. **导入自己的数据**：
   - 准备符合上述格式的CSV文件
   - 进入 **"📥 数据导入"** 页面
   - 上传一个或多个CSV文件
   - 点击 **"开始导入"**

3. **查看数据概览**：
   - 进入 **"📊 数据概览"** 页面
   - 查看患者统计、依从率趋势、疼痛趋势等图表

4. **风险分析**：
   - 进入 **"⚠️ 风险分析"** 页面
   - 查看风险等级分布
   - 识别高风险患者
   - 查看详细风险因素和随访建议

5. **单人详情**：
   - 进入 **"👤 单人详情"** 页面
   - 选择特定患者
   - 查看完整的训练、疼痛、动作趋势图

6. **导出报告**：
   - 进入 **"📄 报告导出"** 页面
   - 选择要导出的报告类型
   - 下载Markdown或CSV格式的报告

### 阈值配置

可在 **"⚙️ 阈值配置"** 页面调整以下风险阈值：

- **依从性阈值**：
  - 依从率警戒线（默认70%）
  - 依从率危急线（默认50%）

- **疼痛阈值**：
  - 高疼痛评分阈值（默认7分）
  - 疼痛上升阈值（默认2分）

- **动作稳定性阈值**：
  - 动作变异系数阈值（默认25%）

- **缺训阈值**：
  - 连续缺训预警天数（默认2天）
  - 连续缺训危急天数（默认4天）

修改后点击 **"应用阈值"**，会自动重新评估所有患者的风险等级。

## 风险评估规则

### 风险等级

| 等级 | 说明 | 颜色 |
|------|------|------|
| 低风险 | 状态良好，按计划随访 | 绿色 |
| 中风险 | 需要关注，增加随访频率 | 橙色 |
| 高风险 | 需要提前回访 | 红色 |
| 危急风险 | 紧急，立即回访 | 紫色 |

### 风险权重

- 依从性风险：30%
- 疼痛风险：25%
- 缺训风险：25%
- 动作稳定性风险：20%

### 触发条件

**依从性风险**：
- 依从率 < 50% → 高风险（分数1.0）
- 依从率 < 70% → 中风险（分数0.6）

**疼痛风险**：
- 平均疼痛评分 >= 7 → 风险（分数+0.5）
- 周期内疼痛上升 >= 2 → 风险（分数+0.5）

**动作稳定性风险**：
- 变异系数 >= 25% → 风险（分数0.7）

**缺训风险**：
- 连续缺训 >= 4天 → 高风险（分数1.0）
- 连续缺训 >= 2天 → 中风险（分数0.6）
