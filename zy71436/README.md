# 艺术品拍卖心理战

艺术市场课程教学用拍卖模拟小游戏。玩家在有限预算内，根据估价信息、藏家画像和竞价节奏做出出价决策，体验真实拍卖中的心理博弈。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5174/` 即可开始游戏。

## 玩法说明

1. **开始拍卖** → 进入第一件拍品的信息审阅界面
2. **审阅信息** → 查看拍品描述（主信息）、估价区间、参与藏家画像，注意系统标记的"信息冲突"
3. **开始竞价** → 输入出价金额或使用快捷加价按钮，也可选择"过"放弃本轮
4. **冲动加价预警** → 加价超过20%时弹出确认，确认后行为记入异常事件
5. **回合结束** → 连续两次无人出价时当前拍品成交，显示结果
6. **复盘** → 在复盘页面查看每件拍品的出价历程、冲突留痕、异常事件
7. **导出报告** → 一键导出JSON格式完整报告，含所有拍品结果、冲突记录与异常事件

## 核心机制

### 三重信息体系
- **拍品描述**（主信息）：作品基本信息与风险提示
- **估价区间**：来源、置信度、保留价
- **藏家画像**：偏好类型、激进度、预算、偏好品类

### 信息冲突留痕
当主信息/估价/藏家画像三者出现矛盾时，系统自动记录冲突并标记类型（估价↔描述 / 藏家↔估价 / 藏家↔描述），由玩家判断是否接受。

### 异常事件追踪
- **冲动加价**：加价幅度超过当前价20%
- **保留价误判**：成交价超出估价上限
- **预算透支**：出价超出剩余预算

所有异常事件均纳入最终导出报告，不会在页面提示后丢失。
