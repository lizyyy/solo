## 1. 产品概述

"艺术品拍卖心理战"是一款面向艺术市场课程教学场景的浏览器端拍卖模拟小游戏。玩家需要在有限预算内，综合估价信息、藏家偏好画像和竞价节奏做出出价决策，体验真实拍卖中的心理博弈。

- 目标用户：艺术市场课程的学生与讲师
- 核心价值：让学生在模拟拍卖中理解估价-偏好-竞价三重信息的冲突与决策，培养拍卖心理博弈意识

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 玩家 | 进入游戏即默认 | 出价、暂停、重开、查看复盘、导出报告 |

### 2.2 功能模块

1. **拍卖主界面**：拍品展示、估价信息、藏家画像、竞价面板、出价历史
2. **游戏控制**：开始、暂停、重开、结算
3. **复盘面板**：回合回顾、冲突留痕、异常事件追踪
4. **报告导出**：含冲动加价、保留价误判、预算透支等异常事件的完整报告

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 拍卖主界面 | 拍品信息区 | 展示当前拍品图片、名称、描述（主信息），估价区间（估价信息），藏家偏好画像 |
| 拍卖主界面 | 竞价面板 | 显示当前价格、AI对手出价节奏、玩家出价输入与确认、剩余预算 |
| 拍卖主界面 | 出价历史 | 当前拍品的出价流水，标注每轮出价方与金额 |
| 拍卖主界面 | 游戏控制栏 | 开始/暂停/重开按钮，当前局状态指示 |
| 复盘面板 | 回合回顾 | 每件拍品的最终结果、成交价、买家 |
| 复盘面板 | 冲突留痕 | 主信息/估价/藏家画像三者不一致时的记录 |
| 复盘面板 | 异常事件 | 冲动加价、保留价误判、预算透支的事件列表 |
| 报告导出 | 导出按钮 | 一键导出JSON格式完整报告，含所有拍品结果、异常事件、冲突记录 |

## 3. 核心流程

玩家进入游戏后，依次对每件拍品进行竞价。每件拍品有三类信息：主信息（拍品描述）、估价（估价区间与来源）、藏家画像（偏好类型与出价倾向）。当三类信息冲突时，系统自动留痕。玩家在竞价回合中根据信息决策出价，AI对手模拟不同藏家行为。单局包含5件拍品，全部拍品结束后进入结算，玩家可查看复盘并导出报告。

```mermaid

    "开始游戏" --> "展示拍品信息"
    "展示拍品信息" --> "信息冲突检测"
    "信息冲突检测" --> "冲突留痕"
    "信息冲突检测" --> "进入竞价回合"
    "冲突留痕" --> "进入竞价回合"
    "进入竞价回合" --> "玩家出价?"
    "玩家出价?" --> "是: 检测异常事件"
    "玩家出价?" --> "否: AI对手出价"
    "AI对手出价" --> "竞价结束?"
    "检测异常事件" --> "记录异常"
    "记录异常" --> "竞价结束?"
    "竞价结束?" --> "否: 进入竞价回合"
    "竞价结束?" --> "是: 还有拍品?"
    "还有拍品?" --> "是: 展示拍品信息"
    "还有拍品?" --> "否: 结算"
    "结算" --> "复盘"
    "复盘" --> "导出报告"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深炭黑(#1a1a2e) + 暖金(#c9a84c) + 象牙白(#f5f0e8)
- 辅助色：酒红(#8b2252)用于警告/异常，墨绿(#2d5a3d)用于成功
- 按钮风格：圆角矩形，金色边框，悬停时发光效果
- 字体：Playfair Display（标题）+ Noto Sans SC（正文）
- 布局风格：居中卡片式布局，拍卖锤图标装饰，深色画廊氛围

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 拍卖主界面 | 拍品信息区 | 深色卡片，金边装饰，拍品图片居中，估价与藏家画像左右分栏 |
| 拍卖主界面 | 竞价面板 | 居中出价输入框，金边按钮，价格动态动画，预算进度条 |
| 拍卖主界面 | 出价历史 | 侧栏滚动列表，玩家/AI颜色区分，时间戳 |
| 拍卖主界面 | 游戏控制栏 | 底部固定栏，图标按钮，状态指示灯 |
| 复盘面板 | 回合回顾 | 时间线式布局，每件拍品一个节点 |
| 复盘面板 | 冲突留痕 | 黄色警示卡片，冲突类型标签 |
| 复盘面板 | 异常事件 | 红色警示卡片，事件类型图标 |
| 报告导出 | 导出按钮 | 金色主按钮，导出成功提示 |

### 4.3 响应式

- 桌面优先设计（1280px+）
- 768px-1280px 适度调整布局
- 768px以下移动端基础可用

### 4.4 3D场景

不适用
