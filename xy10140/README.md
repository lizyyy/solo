# 表格筛选状态回放前端

解决复杂表格筛选后刷新或分享链接丢失排序、分组和选中项的问题。

## 特性

- ✅ **URL 状态持久化** - 刷新或分享链接恢复完整状态
- ✅ **多输入筛选** - 支持 8 种筛选操作符
- ✅ **排序与分组** - 点击列头排序，按字段分组展示
- ✅ **行选择** - 支持单选/全选，选中状态也会持久化
- ✅ **历史记录** - 最多保存 50 条状态，支持标签和恢复
- ✅ **可复验命令** - 创建命名命令，重复执行幂等
- ✅ **失败重试** - 非永久错误自动重试（指数退避）
- ✅ **报告导出** - JSON/CSV/ZIP 三种格式
- ✅ **坏数据不静默跳过** - 验证错误明确显示
- ✅ **幂等执行** - 相同状态执行结果一致

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 打开浏览器访问 http://localhost:5173
```

## 可验收示例

运行 `npm run dev` 后，按以下步骤验收各项功能：

---

### 示例 1：URL 状态回放（刷新不丢失）

**操作步骤：**
1. 在「全局搜索」输入框输入 `张三`
2. 选择「排序字段」为 `salary`，「排序方向」为 `降序`
3. 选择「分组字段」为 `department`
4. 勾选表格中前 3 条记录
5. 点击「复制链接」按钮
6. 打开新标签页，粘贴链接访问
7. 或者直接刷新当前页面

**验收标准：**
- [ ] 搜索框显示 `张三`
- [ ] 排序字段为 `salary` 降序（点击列头可见排序箭头）
- [ ] 数据按 `department` 分组展示
- [ ] 勾选的 3 条记录保持选中状态

---

### 示例 2：多输入筛选条件

**操作步骤：**
1. 在筛选条件区域，依次添加以下条件：
   - 字段 `age`，操作符 `greaterThan`，值 `30`
   - 字段 `department`，操作符 `in`，值 `开发部,技术部`
   - 字段 `salary`，操作符 `between`，值 `10000,30000`
2. 观察表格实时过滤结果

**验收标准：**
- [ ] 已添加的 3 个条件以标签形式显示
- [ ] 表格只显示年龄 >30、部门为开发部/技术部、薪资在 10000-30000 之间的记录
- [ ] 点击条件标签右侧 `✕` 可删除该条件

**可用操作符：**
| 操作符 | 说明 | 示例值 |
|--------|------|--------|
| equals | 等于 | 张三 |
| contains | 包含 | 张 |
| startsWith | 开头是 | 张 |
| endsWith | 结尾是 | 部 |
| greaterThan | 大于 | 30 |
| lessThan | 小于 | 50 |
| in | 在列表中（逗号分隔） | 北京,上海 |
| between | 范围（两个值） | 10000,30000 |

**操作步骤：**
1. 设置筛选条件：

5. 点击该命令的「执行」按钮（第一次执行）

**验收标准：**
- [ ] 第一次执行后显示 `命令执行结果: 成功匹配 X 条记录`
- [ ] 第二次执行命中缓存，结果与第一次一致（幂等）
- [ ] 命令可点击「复制」得到 JSON，可在其他浏览器「导入命令」后重复执行

**导入命令示例 JSON（可直接粘贴到导入框测试）：**
```json

```

- [ ] 显示红色错误提示，不静默跳过
- [ ] 错误信息包含具体字段和问题描述

**测试 URL 坏数据：**

- `?t=invalid_base64` - 解码错误
- `?t=e30=` (空对象 `{}`) - 应为默认状态
- `?t=eyJzZWFyY2hUZXh0IjoxMjN9` (searchText 为数字) - 应显示验证错误

## 关键实现说明

### 幂等性保障
- 命令 ID 基于状态哈希生成
- 执行日志记录 `commandId + stateHash`
- 相同状态重复执行直接返回缓存结果
- 可通过 `forceReexecute` 参数强制重跑

### 错误处理
- URL 解码失败显示具体错误
- 筛选条件验证失败显示红色提示
- 无效操作符/值类型不静默跳过
- 执行错误区分「永久错误」（不重试）和「临时错误」（重试）

### 状态包含项
```typescript
{
  searchText: string,        // 全局搜索文本
  filters: FilterCondition[], // 多个筛选条件
  sort: SortConfig | null,   // 排序字段和方向
  groupBy: GroupConfig | null, // 分组字段
  selectedIds: string[],     // 选中的行 ID
  pagination: { page, pageSize } // 分页状态
}
```
