# 公交改线调度游戏 PRD

## 1. 产品概述
一款面向公交公司培训场景的 2D 浏览器调度模拟器，玩家作为调度员在道路施工、客流高峰等突发事件下临时改线、派车、调整发车间隔。目标是以真实规则让玩家体验调度难点（跳站投诉、间隔失衡、绕行超时、车辆资源紧张），并以关卡结算报告体现运营表现。
- 目标用户：公交公司培训调度员、交通模拟爱好者、策略游戏玩家。
- 核心价值：真实可玩的调度规则 + 可复盘的历史回放与调度报告。

## 2. 核心功能

### 2.1 功能模块
1. **主菜单**：选择关卡/难度档、历史回放、规则说明。
2. **调度地图**：2D 俯视路网、站点、线路、车辆实时位置、施工封路、客流可视化。
3. **调度面板**：派车、改线、跳站、加开、发车间隔调整、暂停/恢复/加速。
4. **实时反馈**：事件日志、乘客投诉、车辆延误警告、客流热力。
5. **关卡结算**：评分、失败原因、详细运营报告、导出（JSON/文本）。
6. **历史回放**：按时间轴回放已完成关卡，定位关键决策节点。

## 3. 核心流程

玩家从主菜单选择关卡进入调度界面。游戏以回合（时间片）推进：每 1 秒（1x）代表 1 分钟运营时间，关卡时长约 10–20 分钟。玩家根据事件日志与客流变化调整派车、改线、跳站；关卡结束后给出评分和报告；可进入历史回放在关键节点复盘。

```mermaid
flowchart TD
  "A[主菜单]" --> "B[选择关卡]"
  "B" --> "C[加载地图/线路/事件脚本]"
  "C" --> "D[进入调度界面]"
  "D" --> "E{运行中?}"
  "E" --> "是" --> "F[玩家派车/改线/跳站/调整间隔]"
  "F" --> "G[仿真推进: 车辆行驶、客流上下、事件触发]"
  "G" --> "H[日志/警告更新]"
  "H" --> "E"
  "E" --> "否" --> "I[结算: 评分/报告/失败原因]"
  "I" --> "J[导出或保存历史]"
  "I" --> "K[重开关卡]"
  "I" --> "L[返回主菜单]"
  "L" --> "M[历史回放]"
```

## 4. 关卡与难度档
规则变化不以速度单一维度衡量，而是同时改变约束与事件：

| 关卡 | 名称 | 规则差异 |
|-----|------|---------|
| 1 | 常规运营 | 单一主线、无施工、仅高峰客流、容错高 |
| 2 | 施工绕行 | 存在固定施工路段，必须绕行；投诉阈值更低 |
| 3 | 多线冲突 | 两条线路共享路段，车辆间隔失衡加剧；可用车辆减半 |
| 4（可选） | 突发事故 | 随机施工 + 高峰叠加，允许跳站但惩罚加倍 |

## 5. 评分与失败规则
- **分项评分**：准点率、间隔均衡（CV）、投诉次数、满载率、服务覆盖度。
- **失败条件**（任一触发即失败）：投诉次数超过阈值；单线路最大延误超过阈值；可用车辆耗尽；服务覆盖低于最低要求。
- **胜利条件**：到达结束时间且无失败条件触发。

## 6. 交互界面设计

### 6.1 设计风格
- 主色：深灰蓝 `#1B2A41`，强调色：琥珀金 `#E2A93B`，提示红 `#E05252`。
- 按钮：扁平圆角，悬停上浮；危险操作用描边红色强调。
- 字体：标题使用 `ZCOOL QingKe HuangYou` 或 `Noto Sans SC` 粗体；正文 `Noto Sans SC`/`PingFang SC`。
- 布局：左侧 2D Canvas 地图（占 65%），右侧事件日志+调度面板（占 35%）；顶部时间/速度控制；底部结算/回放浮层。

### 6.2 页面设计概览
| 页面 | 模块 | UI 要素 |
|-----|------|---------|
| 主菜单 | 关卡卡 | 深色卡片、编号、标题、规则摘要、难度星级、进入按钮 |
| 主菜单 | 历史回放列表 | 行式列表，显示关卡、评分、失败原因、开始按钮 |
| 调度界面 | 2D 地图 | 站点编号/名称、线路颜色标识、封路红色虚线、客流气泡、车辆小圆点 |
| 调度界面 | 调度面板 | 线路标签页、发车间隔滑块、派车按钮、跳站/改线快捷按钮 |
| 调度界面 | 事件日志 | 时间戳 + 级别（info/warn/error）条目，自动滚动 |
| 结算页 | 评分条 | 横向进度条展示各分项及总分 |
| 结算页 | 操作面板 | 导出、重开、回放、返回主菜单 |
| 回放页 | 时间轴 | 可拖动滑块 + 播放/暂停、显示关键事件标记 |

### 6.3 响应式
- Desktop-first，最小宽度 1200px。
- 移动端仅保留主菜单与报告查看，地图简化为摘要。
