## 1. 产品概述

透镜成像误差管理工具——面向物理实验室助教，将传感器日志导入、零点漂移复核、标定修正、变更追溯与实验批改表导出串联为一条完整工作流。所有数据本地存储（localStorage），无需后端服务，单机即可运行。

- 核心问题：传感器日志先到、实验记录晚半天，修正过程缺乏追溯，批改表与明细不一致
- 目标用户：物理实验室助教、任课教师
- 核心价值：每条记录可见来源、状态、修改人与原因，标定修正前后变化留痕，导出前自动校验一致性

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 实验室助教 | 本地配置姓名 | 导入日志、复核漂移、修正标定、导出批改表 |
| 任课教师 | 本地配置姓名 | 查看历史追溯、导出批改表 |

### 2.2 功能模块

1. **导入页**：传感器日志样例导入、实验记录补录、自动标记待处理
2. **复核页**：零点漂移可视化、待处理记录列表、逐条审核通过/驳回
3. **修正页**：标定表在线编辑、前后差异高亮、自动写入历史
4. **历史页**：全量变更时间线、按记录/操作人/时间筛选、查看前后对比
5. **导出页**：实验批改表生成、一致性校验提示、CSV/JSON导出
6. **3D可视化**：Three.js透镜成像光路示意，辅助理解误差来源

### 2.3 页面详情

| 页面 | 模块 | 功能说明 |
|------|------|----------|
| 导入页 | 日志导入区 | 拖拽或选择CSV/JSON文件，解析传感器日志样例，自动生成记录并标记来源为"传感器日志" |
| 导入页 | 手动补录区 | 表单录入实验记录，标记来源为"手动录入" |
| 导入页 | 导入预览 | 导入后预览数据，确认后写入本地状态 |
| 复核页 | 零点漂移图 | 折线图展示零点漂移趋势，标注超限点 |
| 复核页 | 待处理列表 | 来源、状态、进入待处理原因一目了然 |
| 复核页 | 审核操作 | 通过→标记已复核；驳回→填写原因，退回待处理 |
| 修正页 | 标定表编辑器 | 表格形式编辑标定值，修改后自动生成历史记录（含修改前值、修改后值、修改人、时间） |
| 修正页 | 差异高亮 | 修改单元格以颜色标记，悬浮显示修改前值 |
| 历史页 | 变更时间线 | 所有记录的变更历史按时间排列 |
| 历史页 | 筛选器 | 按记录ID、操作人、时间范围筛选 |
| 历史页 | 前后对比 | 弹窗展示修改前后的完整标定表差异 |
| 导出页 | 一致性校验 | 导出前检查批改表与明细是否一致，不一致项标红提示 |
| 导出页 | 导出操作 | 生成实验批改表CSV/JSON文件下载 |
| 3D可视化 | 透镜成像光路 | Three.js渲染凸透镜成像光路，可调焦距/物距，显示像距计算值与实测值差异 |

## 3. 核心流程

传感器日志导入 → 自动标记"待处理"并记录来源与原因 → 助教复核零点漂移 → 通过/驳回 → 修正标定表（变更留痕）→ 导出前一致性校验 → 生成批改表

```mermaid
flowchart TD
    "传感器日志导入" --> "自动标记待处理"
    "手动补录实验记录" --> "自动标记待处理"
    "自动标记待处理" --> "复核页：零点漂移检查"
    "复核页：零点漂移检查" --> "通过 → 已复核"
    "复核页：零点漂移检查" --> "驳回 → 退回待处理（记录原因）"
    "已复核" --> "修正标定表（可选）"
    "修正标定表（可选）" --> "变更写入历史"
    "已复核" --> "导出页"
    "变更写入历史" --> "导出页"
    "导出页" --> "一致性校验"
    "一致性校验" --> "通过 → 下载批改表"
    "一致性校验" --> "不一致 → 标红提示修正"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青灰（#1a2332）为底，琥珀色（#d4a843）为强调色——精密光学仪器质感
- 辅助色：冷白（#e8ecf1）前景文字，暗红（#c94040）用于警告/不一致标记，暗绿（#3a9a5c）用于通过/已复核
- 按钮：圆角4px，深色填充+琥珀色边框，hover时微发光
- 字体：JetBrains Mono 用于数据/表格，Noto Sans SC 用于中文界面
- 布局：左侧固定导航栏 + 右侧主内容区，顶栏显示当前操作人
- 图标：lucide-react线性图标

### 4.2 页面设计概览

| 页面 | 模块 | UI元素 |
|------|------|--------|
| 导入页 | 日志导入区 | 虚线拖拽框、文件类型提示、解析进度条 |
| 导入页 | 手动补录区 | 表单输入框组、来源自动标注 |
| 导入页 | 导入预览 | 表格预览、确认/取消按钮 |
| 复核页 | 零点漂移图 | Canvas折线图、超限点红色标注 |
| 复核页 | 待处理列表 | 卡片列表、来源标签、状态徽章、原因文本 |
| 复核页 | 审核操作 | 通过/驳回按钮、驳回原因输入弹窗 |
| 修正页 | 标定表编辑器 | 可编辑表格、差异单元格琥珀色背景 |
| 修正页 | 差异悬浮提示 | tooltip显示修改前值与修改人 |
| 历史页 | 变更时间线 | 垂直时间线、操作人头像/名称、变更摘要 |
| 历史页 | 前后对比弹窗 | 左右双栏对比、差异高亮 |
| 导出页 | 一致性校验 | 校验结果列表、不一致项红色标记 |
| 导出页 | 导出操作 | 格式选择（CSV/JSON）、下载按钮 |
| 3D可视化 | 透镜成像光路 | Three.js场景、焦距/物距滑块、误差标注 |

### 4.3 响应式

桌面优先设计，最低支持1280px宽度。导航栏在窄屏下收缩为图标模式。

### 4.4 3D场景指引

- 环境：暗色实验室环境，微弱环境光模拟光学实验室
- 灯光：点光源模拟激光束沿光轴传播，琥珀色辅助光
- 相机：正交相机俯视光路，支持旋转和缩放
- 构图：凸透镜居中，物在左像在右，焦点标注
- 交互：拖动滑块改变物距，实时更新像距与误差显示
- 后处理：轻微辉光效果模拟光束
- 资源：纯几何体（透镜用LatheGeometry生成），无需外部模型
