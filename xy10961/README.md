# 售楼处来访合并 CLI

一个用于合并售楼处渠道表和来访登记表的命令行工具，解决同一客户被多个渠道重复认领的问题。

## ✨ 功能特性

- **电话归一化**：自动处理不同格式的电话号码（带国家码、分隔符等）
- **渠道优先级**：根据渠道优先级确定最终归属渠道
- **重复认领检测**：自动识别被多个渠道或顾问认领的客户
- **顾问汇总统计**：按置业顾问统计认领客户数和重复认领数
- **渠道汇总统计**：按渠道统计认领客户数和重复认领数
- **坏数据保留**：保留原始行号，方便定位和排查异常数据
- **多格式输出**：终端摘要、机器可读 JSON、Excel 多表报告

## 🚀 快速开始

### 方式一：一键运行（推荐）

```bash
npm run merge -- -v examples/来访表示例.xlsx -c examples/渠道表示例.xlsx -o output
```

### 方式二：使用 bin 入口（零配置）

```bash
node bin/run.js -v examples/来访表示例.xlsx -c examples/渠道表示例.xlsx -o output
```

### 方式三：开发模式

```bash
npm run dev -- -v examples/来访表示例.xlsx -c examples/渠道表示例.xlsx -o output
```

### 生成示例数据（可选）

```bash
npx tsx examples/generate-sample.ts
```

将在 `examples/` 目录下生成：
- `来访表示例.xlsx` - 模拟来访登记表
- `渠道表示例.xlsx` - 模拟渠道记录表

## 📖 命令行参数

| 参数 | 缩写 | 说明 | 必填 |
|------|------|------|------|
| `--visit` | `-v` | 来访表文件路径（支持 .xlsx, .xls, .csv） | ✅ |
| `--channel` | `-c` | 渠道表文件路径（支持 .xlsx, .xls, .csv） | ✅ |
| `--output` | `-o` | 输出目录，默认为 `./output` | ❌ |
| `--phone-column` | - | 电话列名（自动检测） | ❌ |
| `--advisor-column` | - | 置业顾问列名（自动检测） | ❌ |
| `--channel-column` | - | 渠道列名（自动检测） | ❌ |
| `--help` | `-h` | 显示帮助信息 | ❌ |
| `--version` | - | 显示版本号 | ❌ |

### 输入表要求

**来访表**应包含以下列（自动检测别名）：
- 客户电话 / 电话 / 手机号码（必填）
- 客户姓名 / 姓名
- 来访日期 / 日期
- 置业顾问 / 顾问 / 销售
- 渠道名称 / 渠道 / 来源
- 认领状态 / 状态

**渠道表**应包含以下列（自动检测别名）：
- 客户电话 / 电话 / 手机号码（必填）
- 客户姓名 / 姓名
- 渠道名称 / 渠道 / 来源（必填）
- 置业顾问 / 顾问 / 销售
- 认领状态 / 状态

- 统计数据概览（原始记录数、有效记录数、合并后客户数等）

- 顾问业绩 Top 5（客户数、重复认领数）

## ⚙️ 配置说明

### 渠道优先级（从高到低）

```
1. 全民经纪人
2. 老业主推荐
3. 渠道分销
4. 中介带看
5. 线上广告
6. 线下活动
7. 自然到访
8. 电话咨询
9. 其他
```

### 认领状态优先级（从高到低）

```
1. 已认领
2. 已确认
3. 待确认
4. 未认领
5. 已放弃
6. 已失效
```

### 电话归一化规则

- 去除所有分隔符（空格、`-`、`(`、`)`、`.`、`+`）
- 去除中国国家码前缀（`+86`、`86`）
- 仅保留 11 位有效手机号码

## 🚨 坏数据处理

工具会自动识别并保留以下坏记录：

| 错误类型 | 说明 |
|---------|------|
| 电话为空 | 电话列没有值 |
| 电话格式无效 | 不是 11 位有效手机号 |
| 渠道名称为空 | 渠道表中渠道名称缺失 |

所有坏记录会：
1. 在终端输出中高亮显示
2. 在 JSON 结果中完整保留
3. 在 Excel 的「坏记录」工作表中列出
4. 标注原始行号，方便回溯源文件

## ❓ 常见问题

**Q: 运行时提示找不到 `dist/index.js` 怎么办？**

A: 这是因为项目还没有构建。可以：
- 运行 `npm run build` 手动构建
- 或者直接使用 `node bin/run.js`，它会自动检测并构建

**Q: 为什么有些列没有被正确识别？**

A: 工具会根据列名别名自动匹配，如果你的列名不在预设别名中，可以通过命令行参数指定列名。

**Q: 电话格式有特殊要求吗？**

A: 没有，工具会自动归一化处理各种格式（如 `+86 138-0013-8001`、`13800138001` 等）。

**Q: 坏数据会被丢弃吗？**

A: 不会，所有坏数据都会被完整保留在输出结果中，并标注原始行号和错误原因。

**Q: 可以处理 CSV 格式吗？**

A: 可以，支持 `.xlsx`、`.xls`、`.csv` 格式。

**Q: 如何验证项目是否正常工作？**

A: 运行 `npm run test` 会自动构建并使用示例数据进行完整测试。
