# 酒店后勤布草洗涤管理系统

一套完整的后端服务，用于管理酒店布草洗涤的送洗、回收、赔付和追踪流程。

## 功能特性

✅ **数据导入**
- 支持CSV格式导入房型配置标准
- 支持CSV格式导入送洗批次
- 支持JSON格式导入回收单

✅ **核心业务接口**
- 新增洗涤批次
- 标记处理状态（审核通过 / 退回修改 / 处理完成）
- 记录短少赔付、破损归因、重复计费
- 保留完整操作日志（原因、处理人、时间）

✅ **查询与导出**
- 按房型标准查询
- 按洗涤批次查询
- 按赔付记录查询
- 导出明细数据（支持JSON/CSV格式）
- 导出数量与查询结果数量一致

✅ **数据持久化**
- SQLite本地数据库存储
- 重启服务后所有历史记录可查
- 完整操作审计日志

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 初始化样例数据

```bash
node init_sample.js
```

这会创建包含以下内容的样例数据：
- 13条房型配置标准（标准间、大床房、豪华套房）
- 1个洗涤批次（共410件布草）
- 4条需要人工修正的赔付记录（短少待审核）

### 3. 启动服务

```bash
npm start
```

服务将在 `http://localhost:3000` 启动

### 4. 运行测试验证

新开终端窗口运行：
```bash
node test/test.js
```

## API 接口文档

### 房型管理

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/room-types/import | 导入房型配置CSV |
| GET | /api/room-types | 查询所有房型标准 |

### 洗涤批次

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/batches | 新增洗涤批次（送洗CSV） |
| GET | /api/batches | 查询批次列表（支持status/日期筛选） |
| GET | /api/batches/:id | 查询批次详情 |
| POST | /api/batches/:id/process | 标记处理（approve/reject/complete） |

### 回收与赔付

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/recovery | 导入回收单JSON |
| POST | /api/compensation | 登记赔付记录 |
| GET | /api/compensations | 查询赔付记录 |

### 导出与日志

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/export/details | 导出明细数据（format=json/csv） |
| GET | /api/logs | 查询操作审计日志 |

## 工作流程示例

1. **导入房型标准** - 配置每种房型的布草标配数量
2. **创建送洗批次** - 导入本次送洗明细CSV
3. **导入回收单** - 洗涤厂返回后导入回收JSON
4. **差异比对** - 系统自动计算短少/破损差异
5. **登记赔付** - 记录短少原因、处理人、赔偿金额
6. **审核流程** - 退回修改 → 审核通过 → 处理完成
7. **导出明细** - 导出完整记录用于对账

| 标准间 | 枕套 | 3件 | pending | 需与洗涤厂确认 |

### 状态流转

```
pending → rejected (退回修改) → pending
   ↓
approved (审核通过)
   ↓
completed (处理完成)
```
