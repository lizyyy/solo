# 🏛️ 博物馆夜间文物搬运

一个有趣的推箱子类浏览器小游戏，玩家指挥搬运员在博物馆展厅网格中推送文物箱到临时库房，同时需要避开各种危险区域和限制条件。

## 🎮 游戏特色

- **多关卡系统**：内置3个精心设计的样例关卡，难度递增
- **可配置关卡**：支持自定义关卡配置，轻松创建新关卡
- **游戏状态机**：完整的游戏状态管理（菜单、游戏中、暂停、胜利、失败、结算）
- **碰撞/违规判定**：
  - 湿度超标区域进入判定
  - 巡检路线进入判定
  - 箱子推到死角判定（游戏结束）
  - 电梯载重超限判定（游戏结束）
- **计分系统**：基础分 + 推箱奖励 - 违规惩罚
- **回放摘要**：记录每一步操作，结算时显示详细违规记录和统计数据
- **边界情况处理**：箱子被推到死角、电梯载重超限等特殊情况

## 🎯 游戏目标

将所有文物箱（📦）推到临时库房（绿色区域），同时：
- 不要进入蓝色的湿度超标区域
- 不要进入红色的巡检路线
- 不要将箱子推到无法再移动的死角
- 注意电梯的载重限制

## 🗺️ 地图元素

| 元素 | 颜色 | 说明 |
|------|------|------|
| 普通地板 | 深灰 | 可自由通行 |
| 墙壁 | 深黑 | 无法通过 |
| 湿度超标区 | 蓝色 | 进入会扣分，文物箱进入会严重扣分 |
| 巡检路线 | 红色 | 进入会扣分，箱子被推到此处会扣分 |

| 电梯 | 黄色 | 有载重限制，超限会导致游戏失败 |

## 🚀 安装和运行

### 环境要求

- 现代浏览器（支持 ES6 Modules）
- Python 3（用于启动本地服务器）

### 本地预览

**方式一：使用 Python 启动服务器**

```bash
# 进入项目目录
cd zy8265

# 启动本地服务器 (端口 8080)
npm run dev

# 或者直接使用 Python
python3 -m http.server 8080
```

然后在浏览器中打开：`http://localhost:8080`

**方式二：使用其他 HTTP 服务器**

如果你有其他偏好的 HTTP 服务器，只要能够正确提供静态文件服务即可：

```bash
# 使用 Node.js 的 http-server
npx http-server -p 8080

# 或者使用 VS Code 的 Live Server 插件
# 直接右键 index.html 选择 "Open with Live Server"
```

### 直接打开文件（不推荐）

⚠️ 注意：由于使用了 ES6 Modules，直接双击打开 `index.html` 可能会遇到跨域限制。建议使用上述的 HTTP 服务器方式运行。

## 🎯 内置关卡

### 第一关：入门展厅
- 简单关卡，帮助玩家熟悉操作
- 只有一个箱子，没有危险区域
- 目标：将箱子推到库房区域

### 第二关：湿度禁区
- 增加了湿度超标区域（蓝色）
- 玩家和箱子都不能进入这些区域
- 两个箱子需要被推到库房

### 第三关：电梯危机
- 包含电梯系统（黄色），有载重限制
- 箱子有不同的重量（右上角数字）
- 包含湿度区域和巡检路线
- 需要小心规划路线，避免箱子被推到死角

## ⚙️ 自定义关卡

你可以在 `src/js/levels/defaultLevels.js` 中添加自定义关卡。关卡配置格式如下：

```javascript
{
  name: "关卡名称",
  description: "关卡描述",
  width: 8,           // 网格宽度
  height: 8,          // 网格高度
  player: { x: 1, y: 1 },  // 玩家初始位置
  boxes: [            // 箱子配置
    { x: 3, y: 3, weight: 1 },  // weight 为箱子重量
    { x: 5, y: 5, weight: 2 }
  ],
  walls: [            // 墙壁位置
    { x: 0, y: 0 }, { x: 1, y: 0 },
    // ...
  ],
  storagePositions: [  // 库房位置（目标）
    { x: 6, y: 5 }, { x: 6, y: 6 }
  ],
  humidityAreas: [    // 湿度超标区域
    { x: 3, y: 4 }, { x: 4, y: 4 }
  ],
  patrolPaths: [      // 巡检路线
    { x: 2, y: 4 }, { x: 3, y: 4 }
  ],
  elevators: [        // 电梯配置
    { x: 9, y: 3, maxCapacity: 2, floors: [1, 2] }
  ]
}
```

## 📊 计分规则

| 项目 | 分数 |
|------|------|
| 基础分 | 1000 分 |
| 每次移动 | -5 分 |
| 每次推箱 | -10 分 |
| 箱子送达库房 | +200 分 |
| 完美通关奖励（无违规） | +500 分 |

### 违规惩罚

| 违规类型 | 惩罚分数 | 是否游戏结束 |
|----------|----------|--------------|
| 玩家进入湿度区域 | -50 | 否 |
| 玩家进入巡检路线 | -100 | 否 |
| 箱子被推到湿度区域 | -200 | 否 |
| 箱子被推到巡检路线 | -150 | 否 |
| 箱子被推到死角（无法移动） | -300 | **是** |
| 电梯载重超限 | -250 | **是** |

### 评级系统

| 分数百分比 | 评级 | 颜色 |
|------------|------|------|
| ≥ 120% | S | 金色 |
| ≥ 90% | A | 绿色 |
| ≥ 70% | B | 蓝色 |
| ≥ 50% | C | 橙色 |
| < 50% | D | 红色 |

## 📝 开发说明

本项目使用纯原生 JavaScript ES6 Modules 开发，无需任何构建工具。所有模块通过 `import`/`export` 直接在浏览器中运行。

### 核心模块说明

1. **GameEngine**：游戏主引擎，整合所有子系统
2. **GameStateManager**：管理游戏状态（菜单、游戏中、胜利、失败等）
3. **LevelManager**：关卡加载和管理
4. **Grid**：网格地图系统
5. **MovementSystem**：玩家移动和推箱子逻辑
6. **CollisionSystem**：碰撞检测
7. **ViolationSystem**：违规判定
8. **ScoringSystem**：计分和评级
9. **ReplaySystem**：记录操作历史
