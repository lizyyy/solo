# 月子餐配送组 - 月子餐配送核对 CLI

专为月子餐配送团队打造的数据核对工具，确保订单准确、特殊要求不遗漏。

## 功能特性

- ✅ **数据校验** - 自动校验必填字段、手机号格式、日期格式
- 👶 **双胞胎订单识别** - 智能识别备注中的"双胞胎"、"双胎"、"龙凤胎"等关键词
- 🥗 **临时忌口识别** - 识别姜、酒、海鲜、辣等饮食禁忌
- 📋 **可复跑输出** - 多次运行结果一致，不会第一次报问题第二次消失
- 📝 **来源追踪** - 异常信息包含文件名和行号，方便定位修复
- 🔇 **简洁日志** - 默认简洁输出，加 `-v` 参数显示详细记录
- 🎨 **彩色输出** - 不同级别信息用不同颜色展示
- 💾 **结果导出** - 支持将核对结果导出为文本文件

## 快速开始

### 安装依赖

```bash
npm install
```

### 全局安装（可选）

```bash
npm link
```

这样就可以在任何地方使用 `yuezi-check` 命令了。

## 使用方法

### 基本使用

```bash
# 如果已全局安装
yuezi-check ./data/2024-05-19-配送数据.csv

# 如果未全局安装
npm start -- ./data/2024-05-19-配送数据.csv
node bin/yuezi-check.js ./data/2024-05-19-配送数据.csv
```

### 显示详细日志

```bash
yuezi-check ./data/2024-05-19-配送数据.csv -v
```

### 导出结果到文件

```bash
yuezi-check ./data/2024-05-19-配送数据.csv -o 核对结果.txt
```

### 禁用彩色输出

```bash
yuezi-check ./data/2024-05-19-配送数据.csv --no-color
```

### 组合使用

```bash
yuezi-check ./data/2024-05-19-配送数据.csv -v -o result.txt
```

## 异常信息说明

所有异常信息都包含**文件名**和**行号**，运营同事可以直接打开CSV文件对应行号进行修改，无需查看源码。

### 数据校验错误示例

```
[配送数据.csv:5] 手机号格式不正确 | 字段: 联系电话 | 值: "1360013600"
```

- `[配送数据.csv:5]` - 文件名和行号
- `手机号格式不正确` - 错误类型
- `字段: 联系电话` - 问题字段
- `值: "1360013600"` - 具体值

## 可复跑保证

本工具采用确定性算法，对于同一份输入数据：
- 每次运行都会产生相同的输出结果
- 不会因为运行次数不同而产生不同的识别结果
- 所有识别逻辑都是基于关键词精确匹配，无随机性

如果第一次运行报告了某个问题，第二次运行那个问题依然会被报告，直到数据被修复。

## 常见问题

### Q: 如何添加新的忌口关键词？

A: 修改 `src/meal-checker.js` 中的 `restrictionKeywords` 数组，添加新的关键词即可。

### Q: 导出的结果文件在哪里？

A: 如果使用 `-o` 参数指定了文件名，会在当前目录下生成。如果指定了绝对路径，会在指定路径生成。

### Q: 为什么有些忌口没有被识别出来？

A: 请检查忌口说明是否在以下字段中：备注、特殊要求、忌口说明、饮食禁忌。如果在其他字段中，需要修改代码添加对应字段。

### Q: 如何卸载全局安装？

```bash
npm unlink -g yuezi-meal-delivery-check
```
