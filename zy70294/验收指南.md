# 便利店鲜食报废预测器 - 验收指南

## 🎯 项目简介

这是一个专门为便利店设计的鲜食报废预测系统，通过分析：
- **销量数据**（入口）：了解商品销售趋势
- **临期库存**（核心校验）：判断商品是否即将过期
- **天气节假日**（影响因素）：作为预测理由的证据

帮助店长科学预测鲜食报废，减少损失，优化订货策略。

### 验收步骤4：运行预测模式

**操作步骤：**
```bash

```

**应该看到的输出：**

**报告包含：**
1. **总体情况**：总库存、预测报废数量、整体报废率

3. **分类统计**：各鲜食品类的报废率
4. **详细预测**：每个高风险商品的预测理由（最重要！）

---

## 📊 如何理解预测报告

### 报告中每个商品包含5个预测理由：

**1. 临期状态（核心）**
- ✅ 正常：保质期充足
- ⚠️ 临期警告：仅剩1天保质期
- ❌ 已过期：必须立即报废

**2. 天气影响（证据）**
- 🌞 晴天：销售正常
- 🌧️ 雨天：销量下降20-50%
- ❄️ 寒冷：销量下降20%
- 🔥 高温：销量下降15%

**3. 节假日影响（证据）**
- 🎉 节假日：销量上升20-50%
- 📅 周末：销量上升20%
- 💼 工作日：正常销量

**4. 销量趋势**
- 📈 上升：近期销量高于历史平均
- 📉 下降：近期销量低于历史平均
- ➡️ 平稳：销量稳定

**5. 综合报废评分**
- 0-30分：低风险
- 40-60分：中风险
- 70-100分：高风险（需要重点关注）

## 🧪 异常样例说明

### 我们在样例数据中植入了以下异常（用于测试系统鲁棒性）：

#### 1. 重复数据
- **位置**：sales_data.csv 第72-75行
- **表现**：相同日期+商品编码出现多次
- **系统处理**：自动检测并删除重复，保留最后一条

#### 2. 过期库存
- **位置**：inventory_data.csv 第18行（红烧肉饭）
- **表现**：生产日期2024-01-05，保质期1天，检查日期2024-01-08
- **预期**：系统标记为"已过期"，报废率100%

#### 3. 临期库存
- **位置**：inventory_data.csv 第2行、第6行、第9行
- **表现**：仅剩1天保质期
- **预期**：系统标记为"临期警告"，高风险

#### 4. 即将临期
- **位置**：inventory_data.csv 第4行、第7行
- **表现**：剩余2天保质期
- **预期**：系统标记为"临近过期"，中风险

## 📞 常见问题

**Q1：运行命令时提示"python不是内部或外部命令"怎么办？**
A：说明Python没有安装好，请先安装Python 3.8或更高版本。

**Q2：安装依赖时速度很慢怎么办？**
A：可以使用国内镜像源：
```bash
pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

**Q3：报告中的理由看不懂怎么办？**
A：所有理由都用了通俗语言：
- "临期警告" = 今天再不卖就过期了
- "天气:大雨,寒冷天气" = 今天下雨又冷，没人出门买
- "节假日:周末" = 周末人多，可能卖得快

**Q4：如何判断预测是否准确？**
A：可以通过以下方式验证：
1. 对比预测报废数量和实际报废数量
2. 检查高风险商品是否真的报废了
3. 观察天气/节假日与销量的相关性
