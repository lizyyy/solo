# 展厅动线热区排布器

一个为展馆布展负责人设计的本地 3D 交互可视化工具，用于规划展柜、入口、出口、互动屏和消防通道的布局，实时检测人流热区、视线遮挡、消防通道宽度不足和入口出口冲突等问题。

## 功能特性

### 核心功能
- **3D 俯视场景**: 使用 Three.js 渲染交互式 3D 展厅场景
- **元素拖拽**: 鼠标左键拖动展柜、入口、出口、互动屏和消防通道
- **元素旋转**: 选中元素后使用按钮进行旋转调整
- **实时规则检测**: 自动检测以下问题：
  - 人流热区（元素聚集区域）
  - 视线遮挡（展柜/互动屏相互遮挡）
  - 消防通道问题（宽度不足或被阻挡）
  - 入口出口冲突（间距过近）

### 数据管理
- **本地保存**: 方案自动保存到浏览器 localStorage
- **刷新恢复**: 页面刷新后自动恢复上次编辑状态
- **JSON 导入/导出**: 支持导入和导出布局方案
- **Markdown 报告**: 导出完整的评审报告
- **完整方案包**: 导出包含检测结果的完整方案

### 布局模板
- **示例布局**: 预设的合理布局示例
- **问题演示**: 包含多种常见问题的演示布局
- **空布局**: 从零开始创建新布局

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 5
- **3D 渲染**: Three.js
- **样式**: 原生 CSS
- **数据持久化**: LocalStorage

### 模块说明

| 模块 | 职责 |
|------|------|
| `SceneRenderer` | Three.js 场景管理、元素渲染、拖拽交互、视角控制 |
| `RulesDetector` | 人流热区检测、视线遮挡检测、消防通道检测、入口出口冲突检测 |
| `LocalStoragePersistence` | 方案保存、方案加载、数据清除 |

| `App.tsx` | 状态管理、UI 组织、模块协调 |

## JSON 格式说明

### 布局方案格式

```json
{
  "hall": {
    "id": "hall-id",
    "name": "展厅名称",
    "width": 20,
    "depth": 15,
    "height": 3,
    "walls": [],
    "color": "#ffffff"
  },
  "elements": [
    {
      "id": "element-id",
      "type": "cabinet",
      "name": "展柜A-1",
      "position": { "x": -6, "y": 0, "z": -4 },
      "rotation": { "x": 0, "y": 0, "z": 0 },
      "scale": { "x": 1, "y": 1, "z": 1 },
      "description": "",
      "visibility": 1,
      "color": "#8B4513"
    }
  ]
}
```

### 元素类型

| 类型值 | 名称 | 说明 |
|--------|------|------|
| `cabinet` | 展柜 | 展示展品的展柜 |
| `entrance` | 入口 | 观众进入展厅的入口 |
| `exit` | 出口 | 观众离开展厅的出口 |
| `interactive_screen` | 互动屏 | 互动体验设备 |
| `fire_exit` | 消防通道 | 紧急疏散通道 |

### 完整方案包格式

```json
{
  "version": "1.0.0",
  "exportDate": "2026-05-03T10:00:00.000Z",
  "layout": { /* 布局方案，见上方格式 */ },
  "detectionResult": {
    "heatZones": [],
    "visionOcclusions": [],
    "fireExitIssues": [],
    "entranceExitConflicts": [],
    "totalIssues": 0
  }
}
```

## 检测规则说明

### 人流热区检测

检测条件：
- 入口附近 6 米内有展柜
- 出口附近 4 米内有展柜
- 互动屏附近 3 米内有超过 2 个元素
- 展柜之间距离小于 2.5 米且聚集数量超过 3 个

### 视线遮挡检测

检测条件：
- 两个展柜/互动屏之间的距离小于它们的最小安全距离
- 最小安全距离 = max(元素1尺寸, 元素2尺寸) + 0.5 米
- 遮挡程度超过阈值（默认 30%）

### 消防通道检测

检测条件：
- 消防通道宽度小于最小要求（默认 1.2 米）
- 其他元素距离消防通道过近（小于安全距离）

### 入口出口冲突检测

检测条件：
- 入口和出口之间的距离小于最小要求（默认 8 米）

## 常见问题

### Q: 为什么某些元素不能被选中？
A: 确保点击的是元素本身而不是标签或地面。标签是半透明的 Sprite，实际可点击的是 3D 模型部分。

### Q: 为什么热区显示不出来？
A: 热区显示需要先运行"规则检测"，检测完成后勾选"显示人流热区"复选框。

### Q: 保存的数据存在哪里？
A: 数据保存在浏览器的 localStorage 中，清除浏览器缓存或使用隐私模式会丢失数据。

### Q: 如何调整检测规则的阈值？
A: 目前阈值在 `RulesDetector.ts` 中硬编码，后续版本可能会添加配置界面。
