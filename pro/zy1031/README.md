# 🏸 羽毛球训练复盘工具

一个为业余羽毛球教练和学员设计的本地训练数据分析与可视化看板。

## 功能特性

### 📊 核心功能
- **数据导入**：支持 CSV 和 JSON 格式的数据导入，包含完整的字段和坐标范围校验
- **热力图可视化**：在羽毛球场地地图上绘制落点热力图，支持单打和双打场地
- **多维度筛选**：按球员、拍型、回合结果、训练日期进行数据筛选
- **训练对比**：支持两场训练数据对比分析，查看技术进步情况
- **复盘备注**：教练可以为每次训练写复盘备注，数据保存在本地，下次打开还在
- **报告导出**：
  - 导出 Markdown 格式的复盘报告（包含关键统计、热区分析、丢分球路、训练建议）
  - 导出筛选后的 CSV 数据

### 📈 统计分析
- 拍型分布统计（饼图）
- 回合结果统计（柱状图）
- 球员得分情况（堆叠柱状图）
- 时间段分布（折线图）

### 🔄 训练对比
- 总拍数对比
- 得分率对比
- 网前失误率对比
- 拍型使用变化分析
- 落点区域变化分析
- 自动生成对比建议

## 快速开始

### 方式一：直接打开（推荐）

1. 克隆或下载此项目到本地
2. 直接在浏览器中打开 `index.html` 文件
3. 点击"加载示例数据"按钮即可体验所有功能

### 方式二：本地服务器（推荐）

如果你想使用本地服务器运行（推荐，体验更好）：

```bash

python3 -m http.server 8080

# 或使用 Node.js (需要安装 serve)
npx serve .

# 或使用 VS Code 的 Live Server 插件
```

然后在浏览器中访问 `http://localhost:8080`

## 数据格式说明

### 必填字段

| 字段名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| 球员 | 字符串 | 球员姓名 | 张三, 李四 |
| 拍型 | 字符串 | 击球类型 | 高远球, 杀球, 搓球 |
| 落点X | 数字 | 横向坐标（米） | 0.5, -1.2 |
| 落点Y | 数字 | 纵向坐标（米） | 5.2, -3.8 |
| 回合结果 | 字符串 | 该回合结果 | 得分, 失分, 继续 |

### 可选字段

| 字段名 | 类型 | 说明 |
|--------|------|------|
| 时间段 | 字符串 | 热身、开场、相持、收尾、其他 |
| 备注 | 字符串 | 该拍的备注信息 |
| 训练日期 | 字符串 | 训练日期，格式：YYYY-MM-DD |

### 坐标系统说明

羽毛球场地坐标以**场地中心为原点**：

- **X轴（横向）**：范围约 -3.05 到 3.05 米（双打场地宽度）
- **Y轴（纵向）**：范围约 -6.7 到 6.7 米（场地长度）
- **网的位置**：Y = 0
- **前场区域**：Y < -3.0（靠近网的一侧）
- **后场区域**：Y > 3.0（远离网的一侧）

### 标准拍型列表

高远球、平高球、杀球、吊球、搓球、推球、勾球、扑球、挑球、接杀、抽球、挡网

### 标准回合结果

- **得分**：该拍直接得分
- **失分**：该拍直接失分
- **继续**：回合继续进行

### 示例数据

项目提供了示例数据文件：
- `data/sample_2026-05-01.json` - 示例JSON数据（30条记录）

你也可以直接点击页面上的"加载示例数据"按钮，系统会自动生成两份完整的训练数据用于体验对比功能。

## 使用流程

### 1. 导入数据
- 点击"导入训练数据"按钮，选择 CSV 或 JSON 文件
- 或直接拖拽文件到导入区域
- 或点击"加载示例数据"使用预设数据

### 2. 查看热力图
- 导入数据后自动显示落点热力图
- 支持单打和双打两种场地视图
- 鼠标悬停查看具体落点数量

### 3. 数据筛选
- 在筛选区域选择：球员、拍型、回合结果、训练日期
- 筛选条件实时生效，图表同步更新
- 点击"重置筛选"清除所有筛选条件

### 4. 统计分析
- 切换到"统计分析"标签页
- 查看拍型分布、回合结果统计、球员得分情况、时间段分布

### 5. 训练对比
- 切换到"训练对比"标签页
- 选择两份要对比的训练数据
- 点击"开始对比"查看详细分析
- 查看得分率、网前失误率、拍型变化、区域变化等

### 6. 写复盘备注
- 切换到"复盘备注"标签页
- 选择要备注的训练数据
- 填写训练主题、整体评价、主要问题、进步之处、下次训练建议等
- 点击"保存备注"，数据会保存在浏览器本地存储中

### 7. 导出报告
- 切换到"报告导出"标签页
- 选择要导出的训练数据
- 勾选要包含的内容（关键统计、热区分析、丢分球路、训练建议）
- 预览报告内容
- 点击"导出 Markdown 报告"下载完整复盘报告
- 或点击"导出筛选后 CSV"下载当前筛选的数据

## 技术栈

- **前端框架**：原生 HTML + CSS + JavaScript（无需构建工具）
- **CSS框架**：Tailwind CSS（通过CDN引入）
- **可视化库**：ECharts（热力图、统计图表）
- **数据处理**：Papa Parse（CSV解析）
- **本地存储**：localStorage（数据和备注持久化）

## 注意事项

### 数据存储
- 所有导入的数据和备注都保存在浏览器的 localStorage 中
- 清除浏览器数据会导致数据丢失
- 建议定期导出重要数据作为备份

### 浏览器兼容性
- 建议使用现代浏览器（Chrome、Firefox、Safari、Edge）
- 需要支持 ES6+ 语法和 localStorage

### 坐标精度
- 落点坐标以米为单位，建议精确到小数点后两位
- 场地边界：单打 5.18m × 13.4m，双打 6.1m × 13.4m

## 常见问题

**Q: 如何创建自己的数据文件？**

A: 你可以使用 Excel 或任何电子表格软件创建数据，然后保存为 CSV 格式。确保包含所有必填字段。

**Q: 为什么导入数据时提示"字段校验失败"？**

A: 请检查你的数据文件是否包含所有必填字段，字段名是否正确，坐标值是否在有效范围内。

**Q: 数据保存在哪里？**

A: 所有数据都保存在浏览器的 localStorage 中，不会上传到任何服务器。这是一个纯本地应用。

**Q: 如何在不同设备间同步数据？**

A: 目前数据只保存在本地。你可以通过导出 CSV/JSON 文件，然后在另一台设备上导入来实现数据同步。

**Q: 为什么对比功能找不到数据？**

A: 你需要至少导入两份训练数据才能使用对比功能。点击"加载示例数据"会自动生成两份数据。
