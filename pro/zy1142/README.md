# 物理题解题工具 (Physics Solver)

一个用于高中到大一基础物理教学的交互式解题和动画演示工具。

## ✨ 功能特性

### 📐 支持的物理题型

1. **斜面滑块** - 支持有摩擦和无摩擦两种情况
   - 力的分解（重力沿斜面和垂直斜面的分力）
   - 摩擦力计算（动摩擦）
   - 匀变速直线运动

2. **抛体运动** - 支持地面发射和高台发射
   - 速度分解（水平/竖直分量）
   - 竖直上抛运动
   - 平抛/斜抛合成
   - 射程、最大高度计算

3. **弹簧振子** - 支持有阻尼和无阻尼简谐运动
   - 胡克定律
   - 简谐运动微分方程
   - 周期、频率、角频率
   - 能量守恒（弹性势能/动能）

### 📝 核心功能

- **详细推导**：不仅仅是答案计算器，完整展示"为什么这么列式"
- **公式渲染**：使用 KaTeX 渲染标准数学/物理符号
- **参数校验**：智能检测不合理参数（质量为0、角度越界、劲度系数为负等）
- **动画演示**：交互式动画，支持播放/暂停、时间轴拖动、调速
- **图表展示**：位置-时间图、速度-时间图、加速度-时间图
- **数据持久化**：本地 JSON 文件存储题目记录、输入参数、推导步骤、轨迹采样
- **导出功能**：支持 Markdown/HTML/JSON 三种格式的讲解报告
- **种子题目**：预置 6 道经典示例题目，打开即试

## 🚀 快速开始

### 环境要求

- Node.js >= 18.0.0
- npm 或 yarn

### 安装

1. 克隆仓库（如适用）或进入项目目录

```bash
cd zy1142
```

2. 安装所有依赖

```bash
npm run install:all
```

或者分别安装：

```bash
# 安装根目录依赖
npm install

# 安装后端依赖
cd server && npm install

# 安装前端依赖
cd ../client && npm install
```

### 启动开发服务器

**方式一：同时启动前后端（推荐）**

```bash
npm run dev
```

这会同时启动：
- 后端服务：http://localhost:3001
- 前端开发服务器：http://localhost:3000

**方式二：分别启动**

```bash
# 启动后端
cd server && npm run dev

# 另开一个终端，启动前端
cd client && npm run dev
```

### 访问应用

打开浏览器访问：http://localhost:3000

## 📖 使用指南

### 基本操作流程

1. **选择题型**：点击顶部的「斜面滑块」、「抛体运动」或「弹簧振子」按钮
2. **填写参数**：在左侧面板输入各物理量的数值和单位
3. **开始求解**：点击「开始求解」按钮
4. **查看结果**：
   - 「解题结果」标签：查看公式推导、数值代入、关键物理量、运动图表
   - 「动画演示」标签：查看运动动画，可播放/暂停、拖动时间轴、调节播放速度
5. **导出报告**：点击右上角「导出报告」按钮，选择格式和内容

### 参数输入说明

每个题型的常见参数：

#### 斜面滑块
- **质量 (kg)**：滑块质量，必须 > 0
- **斜面角度 (deg)**：0 ~ 90 度
- **摩擦系数**：>= 0（无摩擦时设为 0）
- **有摩擦**：是/否选择
- **初速度 (m/s)**：滑块初始速度
- **斜面长度 (m)**：滑动距离，必须 > 0

#### 抛体运动
- **初速度 (m/s)**：发射初速度，必须 > 0
- **抛射角度 (deg)**：0 ~ 90 度
- **初始高度 (m)**：发射点相对于地面的高度

#### 弹簧振子
- **振子质量 (kg)**：必须 > 0
- **劲度系数 (N/m)**：必须 > 0
- **振幅 (m)**：最大位移
- **初始位移 (m)**：t=0 时的位移
- **初始速度 (m/s)**：t=0 时的速度
- **阻尼系数**：>= 0
- **有阻尼**：是/否选择

## 🧪 测试说明

### 正常样例测试

#### 样例 1：斜面滑块（有摩擦）

**参数：**
- 质量：2 kg
- 斜面角度：30°
- 摩擦系数：0.1
- 有摩擦：是
- 初速度：0 m/s
- 斜面长度：10 m

**预期结果：**
- 重力分力（平行）：9.8 N
- 支持力：约 16.97 N
- 摩擦力：约 1.70 N
- 加速度：约 4.05 m/s²
- 末速度：约 9.00 m/s
- 运动时间：约 2.22 s

#### 样例 2：抛体运动（45°角）

**参数：**
- 初速度：20 m/s
- 抛射角度：45°
- 初始高度：0 m

**预期结果：**
- 最大高度：约 10.20 m
- 总飞行时间：约 2.89 s
- 射程：约 40.82 m
- 落地速率：约 20.00 m/s（能量守恒）

#### 样例 3：弹簧振子

**参数：**
- 振子质量：1 kg
- 劲度系数：100 N/m
- 振幅：0.1 m
- 初始位移：0.1 m
- 初始速度：0 m/s
- 阻尼系数：0
- 有阻尼：否

**预期结果：**
- 角频率：10 rad/s
- 周期：约 0.628 s
- 频率：约 1.59 Hz
- 最大速度：1.00 m/s
- 总机械能：0.50 J

### 异常参数测试

#### 测试 1：质量为 0 或负数

**输入：** 质量 = 0 kg 或 -1 kg

**预期行为：**
- 参数验证失败
- 显示明确错误提示："参数 质量 的值必须大于 0"
- 不执行求解

#### 测试 2：角度越界

**输入：** 斜面角度 = 95° 或 -10°

**预期行为：**
- 参数验证失败
- 显示错误提示："参数 斜面角度 的值不能大于 90" 或 "不能小于 0"
- 不执行求解

#### 测试 3：劲度系数为负

**输入：** 劲度系数 = -50 N/m

**预期行为：**
- 参数验证失败
- 显示错误提示："参数 劲度系数 的值必须大于 0"
- 不执行求解

#### 测试 4：单位缺失

**输入：** 某个参数的单位为空

**预期行为：**
- 自动使用该参数的默认单位（如质量默认 kg，长度默认 m）
- 或显示错误提示（取决于参数类型）

## 🔌 API 文档

### 基础路径
后端服务运行在 `http://localhost:3001`

### 健康检查
```
GET /api/health
```

### 题型管理
```
GET  /api/problems/types           # 获取所有题型
GET  /api/problems/types/:type/defaults  # 获取某题型的默认参数
```

### 题目管理
```
GET    /api/problems              # 获取所有题目
GET    /api/problems/:id          # 获取单个题目
POST   /api/problems              # 创建新题目
PUT    /api/problems/:id          # 更新题目
DELETE /api/problems/:id          # 删除题目
```

### 解题接口
```
POST /api/problems/solve          # 快速解题（不保存）
POST /api/problems/:id/solve      # 求解指定题目并保存
```

### 导出接口
```
POST /api/problems/:id/export     # 导出解题报告
```

### 重置接口
```
POST /api/problems/reset          # 重置为种子题目
```

## 📊 数据格式

所有物理量自动转换为国际单位制（SI）：
- 长度：米 (m)
- 质量：千克 (kg)
- 时间：秒 (s)
- 角度：弧度 (rad) - 输入时支持度(°)
- 速度：米/秒 (m/s)
- 加速度：米/秒² (m/s²)
- 力：牛顿 (N)
- 劲度系数：牛顿/米 (N/m)
- 能量：焦耳 (J)

## 📝 开发说明

### 构建生产版本

```bash
npm run build
```

### 启动生产服务器

```bash
npm start
```

### 添加新题型

1. 在 `server/src/physics/solvers/` 创建新的求解器文件
2. 在 `server/src/physics/solverManager.ts` 中注册新题型
3. 在前端 `client/src/App.tsx` 中添加类型图标（可选）

### 自定义导出模板

修改 `server/src/export/exporter.ts` 中的导出函数。

## ⚠️ 注意事项

1. **精度问题**：所有计算使用浮点数，结果保留 3-4 位有效数字
2. **物理近似**：忽略空气阻力、弹簧质量、滑轮摩擦等次要因素
3. **阻尼振动**：当前实现支持欠阻尼、临界阻尼、过阻尼三种情况
4. **单位转换**：确保输入单位与参数描述一致，系统会自动转换
