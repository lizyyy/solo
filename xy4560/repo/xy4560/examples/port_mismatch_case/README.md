# 端口不一致示例项目

这个示例项目演示了 README 中描述的端口与实际使用的端口不一致的情况。

## 安装依赖

```bash
npm install
```

## 启动服务器

```bash
npm run start
```

**注意**: 服务器将在 **端口 8080** 上运行，请访问 http://localhost:8080

## 运行测试

```bash
npm run test
```

## 构建项目

```bash
npm run build
```

## 验证 API

```bash
curl http://localhost:8080/api/status
```

## 预期输出

构建后生成文件：
- `output/result.json`

## 开发模式

```bash
npm run dev
```

开发模式使用端口 3000。
