# 🎷 爵士即兴段落标注系统

## 这是啥？

巡演统筹阿梅和音乐老师交接用的小工具。专门解决「同一首歌现场叫一个名、版权登记又是另一个名」的头疼问题。

## 三个入口，随便用

### 1. 命令行（阿梅补材料最快）

```bash
# 走一遍完整示例流程
node src/cli.js seed

# 看所有标注
node src/cli.js list

# 只看标红的（曲名冲突的）
node src/cli.js list flagged

# 看某条详情，能回到授权期限页和调音师留言
node src/cli.js detail <标注ID>

# 生成店长周报
node src/cli.js report

# 音乐老师复核
node src/cli.js review <ID> confirm_same_song "确认是同一首，秋叶就是Autumn Leaves"
```

### 2. Web小看板（店长和音乐老师看图说话）

启动服务：
```bash
npm start
# 然后打开 http://localhost:3001
```

小看板有三页：
- **小看板**：图表看整体情况，标注状态分布、下一步分工
- **标注列表**：按状态筛选，点进去能看授权页和调音师留言
- **店长周报**：给店长看的，说明每条为啥留下、缺啥材料、该找谁

### 3. REST API（对接其他系统用）

```
GET  /api/annotations              列出标注
GET  /api/annotations/:id          标注详情（含授权页+调音师留言）
POST /api/import/licenses          导入授权期限页
POST /api/import/notes             导入调音师留言
POST /api/annotations/:id/review   音乐老师复核
GET  /api/report/weekly            店长周报
```

## 核心流程（三步走完）

### 第一步：导入授权期限页
从版权方拿到的正式名单，包含版权名、授权方、有效期。
导入后系统自动生成待复核标注，状态是「等阿梅补现场名」。

### 第二步：阿梅补看调音师留言
调音师现场记下的名字和备注。导入后系统自动匹配：
- 如果现场名和版权名对上了 → 自动确认可用
- **如果现场名和版权名不一样 → 标红！留给音乐老师，别急着归正常**

### 第三步：音乐老师复核，店长周报自动更新
音乐老师听完确认：
- 是同一首歌 → 确认可用
- 还需要更多信息 → 退回给阿梅补材料
- 是两首不同的歌 → 标红待拆分

复核完，店长周报里的数字和说明自动跟着变。

## 关键细节（你说我都记着了）

✅ **点到曲名冲突的标注，能回到授权期限页和调音师留言**，不是只剩漂亮画面
✅ **店长周报不说冷冰冰的系统术语**，写清楚：这条为啥留下、还缺啥材料、下一步找音乐老师还是找阿梅
✅ **同一首歌有现场名和版权名时，自动标红**，留给音乐老师复核，不会自动归正常
✅ **解释都是阿梅和音乐老师的对话风格**，不是评测说明书
✅ **补录调音师留言后，给店长看的周报自动跟着变**

## 文件结构

```
src/
  core.js        核心业务逻辑（导入、标注、复核、周报）
  storage.js     数据存储（JSON文件，简单够用）
  cli.js         命令行入口
  server.js      API服务 + Web看板
public/
  index.html     Web小看板界面
data/            数据存在这儿（JSON文件）
```
