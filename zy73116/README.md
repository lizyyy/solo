# 旧楼测绘碰撞预审

结构工程师老叶工作台。

## 三步操作

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173

## 坏材料来了该看哪里

| 症状 | 去哪里看 |
|------|----------|
| 碰撞点重复提交 | 预审面板 → 红色「重复×N」徽章，展开可见异常原因 |
| 截图视角说不清 | 预审面板 → 点行展开 → 「截图视角 / BIM坐标 / 现场说明 |
| 签证单哪一行拖偏了预审 | 签证单 → 左侧红色竖条行 / 底部「拖偏预审」红色标签，含具体行号+偏移mm |
| 月底分不清哪些需要处理 | 月底复核 → 已确认 / 待补件 / 退回 三Tab，退回Tab含异常原因 |
| 想定位签证单 | 预审面板每条碰撞点「签证单 · Lx → 直接跳转对应行 |

所有筛选条件、统计数字、明细表、截图说明都来自同一套数据，不会各说各话。
