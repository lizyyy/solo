# 旧楼测绘碰撞预审

结构工程师老叶工作台。

## 两步操作

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173

## 坏材料来了该去哪里看

| 症状 | 去哪里看 | 关键线索 |
|------|----------|----------|
| 先看整体分类 | 预审面板 → 筛选统计 | 5 张统计卡：总碰撞 / 已确认 / 待补件 / 退回 / 异常重复 |
| 找异常行（重复碰撞） | 预审面板 → 明细表 | 红色「重复×N」徽章；行底红底色；展开见红色异常原因框（**改状态后仍保留**） |
| 三类材料是否齐全 | 预审面板 → 材料区三张卡 | 现场签证单（琥珀）/ 边界样本（紫）/ 后补说明（青），各带数量徽标 |
| 单条碰撞的材料明细 | 明细表 → 点行展开 | 左侧截图+视角+坐标；右侧三栏：签证行 / 边界样本 / 后补说明 |
| 碰撞点重复但被标已确认 | 预审报告 → 异常重复碰撞区 | 红色警告块：异常原因 + 关联签证行号 + 截图视角 + 关联重复记录状态，**不视为顺利通过** |
| 签证单哪一行拖偏了预审 | 预审报告 → 拖偏预审来源区 | 碰撞点编码 + 签证单行号 + 偏移mm + 边界样本阈值对照 + 处理状态 |
| 月底复核分类 | 月底复核 → 三Tab | 已确认 / 待补件 / 退回，数量徽标实时同步 |
| 生成正式报告 | 预审面板右上角「生成预审报告」或导航「预审报告」 | 汇总：异常、拖偏来源、全量明细+三类材料关联 |

所有筛选条件、统计数字、明细表、截图说明、报告输出都来自同一套数据，不会各说各话。
重复碰撞的异常原因、重复次数、关联说明**无论标记为已确认/待补件/退回都会保留**，不会被洗掉。
