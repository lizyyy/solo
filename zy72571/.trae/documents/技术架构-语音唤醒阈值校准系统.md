## 2. 技术描述

- **前端框架**: React@18 + TypeScript
- **构建工具**: Vite@5
- **样式方案**: TailwindCSS@3 + CSS Modules
- **路由管理**: React Router@6
- **状态管理**: React Context + useReducer
- **图表可视化**: 纯CSS + SVG实现，无需额外图表库
- **图标方案**: Lucide React
- **数据方案**: 内置Mock数据，无需后端服务

## 4. 数据模型

### 4.1 数据类型定义

```typescript
// 样本状态类型
type SampleStatus = 'normal' | 'time_window_inflated' | 'old_caliber' | 'pending_review' | 'reviewed' | 'rejected';

// 调参笔记记录
interface ThresholdNote {
  id: string;
  batchId: string;
  threshold: number;
  wakeRate: number;
  falseAlarmRate: number;
  timeWindowStart: string;
  timeWindowEnd: string;
  crossesTimeWindow: boolean;
  status: SampleStatus;
  createdAt: string;
  operator: string;
}

// 线上实验桶记录
interface ExperimentRecord {
  id: string;
  experimentName: string;
  caliberVersion: string;
  threshold: number;
  wakeRate: number;
  falseAlarmRate: number;
  isOldCaliber: boolean;
  imported: boolean;
  createdAt: string;
}

// 异常样本
interface AnomalySample {
  id: string;
  noteId: string;
  type: 'time_window' | 'old_caliber' | 'other';
  description: string;
  status: 'pending_review' | 'reviewed' | 'rejected';
  reviewer?: string;
  reviewComment?: string;
  createdAt: string;
}

// 操作历史记录
interface HistoryRecord {
  id: string;
  action: string;
  operator: string;
  targetId: string;
  targetType: 'note' | 'experiment' | 'anomaly';
  detail: string;
  timestamp: string;
}

// 应用状态
interface AppState {
  thresholdNotes: ThresholdNote[];
  experiments: ExperimentRecord[];
  anomalies: AnomalySample[];
  history: HistoryRecord[];
  currentStep: number;
  selectedSampleId?: string;
}
```

## 7. 关键实现要点

### 7.1 时间窗穿越检测逻辑
- 检测记录的统计时段是否跨多个统计窗口边界
- 跨窗口的记录标记为时间窗穿越，效果可能虚高
- 不自动归为正常，而是标记为待复核状态

### 7.2 三步流程状态机
- 导入调参笔记 → 查看实验桶 → 更新异常页
- 每完成一步，流程进度更新
- 状态不可逆，确保按顺序执行

### 7.3 友好错误消息
- 所有错误提示使用自然语言
- 不暴露内部字段名
- 提供解决方案建议

### 7.4 动画效果
- 使用CSS transition实现微交互
- 状态变更时平滑过渡
- 页面加载时元素按序淡入
