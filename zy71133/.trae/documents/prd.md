## 1. 产品概述

料场堆体体积估算系统是一款基于Web的3D可视化工具，专为矿区月底盘点场景设计，解决无人机点云截图难以解释体积差异的问题。目标用户包括矿区盘点人员、物资管理人员和工程技术人员。

产品核心价值在于：通过交互式3D可视化让盘点过程可操作、可复盘，减少边界漏选、基准面变化、同堆重复统计等常见错误，提高盘点效率和准确性。

## 2. 核心 Features

### 2.2 Feature Module

1. **3D可视化主界面**：点云网格渲染、料堆边界显示、地面基准层
2. **边界编辑模块**：多边形绘制、顶点拖拽、边界筛选
3. **体积计算模块**：实时体积估算、基准面设置、物料密度配置
4. **批次管理模块**：盘点批次创建、时间轴回放、多批次对比
5. **报告导出模块**：体积报告生成、PDF/JSON导出、快照截图

## 3. Core Process

```mermaid
flowchart LR
    A["导入点云样例"] --> B["设置基准面"]
    B --> C["绘制/编辑料堆边界"]
    C --> D["选择物料类型"]
    D --> E["计算体积/重量"]
    E --> F["保存盘点批次"]
    F --> G["时间轴回放对比"]
    G --> H["导出盘点报告"]
```

用户流程说明：
1. 用户导入无人机点云数据或使用系统样例
2. 调整地面基准面高度，确保计算基准正确
3. 使用多边形工具绘制料堆边界，支持拖拽调整顶点
4. 选择物料类型（矿石、煤炭、砂石等）自动应用密度
5. 系统实时计算料堆体积和估算重量
6. 保存当前状态为一个盘点批次
7. 通过时间轴查看历史批次，对比体积变化
8. 导出包含3D截图和详细数据的盘点报告

## 4. User Interface Design

### 4.1 Design Style
- **主色调**：工业蓝 (#165DFF) - 体现专业和科技感
- **辅助色**：警示橙 (#FF7D00) - 用于边界和高亮
- **中性色**：深灰背景 (#1D2129)、浅灰文字 (#C9CDD4) - 3D场景深色背景更舒适
- **按钮风格**：扁平化设计，细微圆角(4px)，悬停有轻微上浮效果
- **字体**：系统无衬线字体，标题16px/正文14px/小字12px
- **布局风格**：左侧工具面板 + 中央3D视口 + 右侧属性面板的三栏布局
- **图标风格**：简洁线性图标，与工业主题一致

### 4.2 Page Design Overview

| 页面名称 | 模块名称 | UI Elements |
|---------|---------|-------------|
| 主工作台 | 顶部工具栏 | 渐变背景、图标按钮组、当前批次显示 |
| 主工作台 | 3D视口 | 深色背景、坐标轴指示器、视角切换按钮 |
| 主工作台 | 左侧面板 | 半透明卡片、工具列表、批次时间轴 |
| 主工作台 | 右侧面板 | 属性表单、实时数据、计算结果高亮 |

### 4.3 Responsiveness
- Desktop-first 设计，优先优化1920x1080分辨率
- 面板可折叠，适应较小屏幕
- 3D视口自适应窗口大小
- 触摸设备支持手势旋转和缩放

### 4.4 3D Scene Guidance
- **环境**：深色背景配合柔和环境光，突出点云数据
- **光照设置**：HemisphereLight + DirectionalLight，避免强烈阴影
- **相机设置**：PerspectiveCamera，OrbitControls轨道控制
- **交互**：鼠标旋转/缩放/平移，点击选择边界
- **动画**：视角切换平滑过渡，批次切换时的淡入淡出
- **性能优化**：点云LOD、缓冲区几何体、合理的点数量限制
