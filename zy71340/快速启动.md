# 音乐治疗情绪日志系统 - 快速启动

## 🚀 第一步：安装依赖

```bash
npm install
```

## ▶️ 第二步：启动服务

```bash
npm start
```

## 👀 第三步：打开浏览器

访问：**http://localhost:3000**

---

## 📋 功能模块

| 模块 | 位置 | 说明 |
|------|------|------|
| 日志录入 | 首页 | 记录患者情绪、曲目、反应 |
| 日志列表 | 第2个标签 | 查看所有记录，支持补录/撤回 |
| 趋势图 | 第3个标签 | 情绪变化可视化 |
| 月报导出 | 第4个标签 | 生成并导出月报 |
| 警告中心 | 第5个标签 | 漏填、重复等预警 |

---

## ⚠️ 核心特性

✅ **数据不丢**：SQLite本地存储，刷新不丢失

✅ **版本控制**：同ID重复提交自动升版本，不覆盖

✅ **三重校验**：
- 情绪量表漏填 → 红色警告
- 曲目重复添加 → 弹窗提醒
- 隐私字段 → 自动脱敏（手机号/邮箱/诊断）

✅ **四种场景**：
- 正常录入
- 补录（新版本
- 撤回记录
- 重复提交自动升版本

## 💡 操作流程

1. **新增患者** → 点击「+ 新增患者」按钮
2. **添加曲目** → 录入日志时点击「+ 添加曲目」
3. **填写情绪** → 拖动滑块评分（0-10分
4. **保存** → 点击「保存记录」
5. **查看趋势** → 选择患者+月份，点击「查看趋势」
6. **导出月报** → 选择患者+月份，生成后点击「导出」

---

## 🔧 技术栈

- 后端：Node.js + Express + SQLite
- 前端：原生 HTML/JS（无构建工具
- 数据持久化：本地 SQLite 自动建表
