# 装修材料核算工具

一个纯本地 Web 前端工具，帮助你管理装修材料采购、核算用量、检测风险。

## 功能特点

### 📊 双视角查询
- **房间视角**：按房间查看每种材料的需求量、已采购量、差额
- **材料视角**：按材料查看总需求、各房间用量明细、采购记录

### ⚠️ 智能风险检测
自动检测以下风险：
- **材料不足**：已采购量 < 需求量
- **采购过量**：已采购量 > 需求量 × 1.15
- **混批风险**：同一种材料存在不同批次/色号
- **临期风险**：胶水/辅料有效期不足90天
- **尺寸变更**：房间尺寸改动影响材料用量

### 💾 本地数据管理
- 本地草稿自动保存（localStorage）
- 支持导入/导出 JSON 格式数据
- 支持导入 CSV 格式数据文件

### 📄 报告导出
- **Markdown 格式**：适合编辑、分享、存档
- **HTML 格式**：适合浏览器查看、打印

## 快速开始

### 1. 启动服务

```bash
# 使用 Python 内置服务器
python3 -m http.server 8081

# 或使用 Node.js
npx serve -p 8081

# 或使用 PHP
php -S localhost:8081
```

### 2. 打开浏览器

访问 http://localhost:8081/

### 3. 加载示例数据

点击左侧「数据管理」区域的 **「加载示例数据」** 按钮，即可体验完整功能。

## 使用流程

### 第一步：导入数据

支持两种方式：

**方式一：加载示例数据**
- 点击「加载示例数据」按钮
- 系统内置一套完整的装修示例数据

**方式二：导入自己的数据**
- 点击顶部「导入数据」按钮
- 选择以下格式的文件：
  - `rooms.csv` - 房间信息
  - `materials.json` - 材料库
  - `purchases.csv` - 采购记录
  - `changes.csv` - 变更记录
  - 或完整的 `data.json` 文件

### 第二步：查看核算结果

切换不同标签页：

| 标签页 | 内容 |
|--------|------|
| 房间视角 | 每个房间的面积、材料用量、风险状态 |
| 材料视角 | 每种材料的总需求、已采购、差额、各房间明细 |
| 风险检测 | 自动检测到的风险列表，支持按等级筛选 |

### 第三步：查看风险详情

在「风险检测」标签页：
1. 点击任意风险卡片
2. 查看风险描述和计算依据
3. 了解风险是如何算出来的（房间面积、规格、损耗率、采购批次等）

### 第四步：模拟尺寸变更

示例数据中已包含变更记录：
- 客厅面积从 27.0㎡ 调整为 26.04㎡
- 主卧面积从 17.28㎡ 调整为 16.32㎡

你可以通过修改 `data/changes.csv` 文件或在应用中重新计算来模拟变更。

### 第五步：导出报告

1. 点击顶部「生成报告」按钮
2. 选择报告格式（Markdown 或 HTML）
3. 报告将自动下载，包含：
   - 风险摘要
   - 补货清单
   - 退料清单
   - 风险详情
   - 材料汇总

## 核心算法

### 材料需求量计算

```
基础用量 = 房间面积 / 每单位面积
损耗量 = 基础用量 × 损耗率
总需求 = 基础用量 + 损耗量
```

### 风险检测规则

| 风险类型 | 触发条件 | 等级 |
|----------|----------|------|
| 材料不足 | 已采购 < 需求 | 缺口>20%为高风险，否则中风险 |
| 采购过量 | 已采购 > 需求×1.15 | 超量>30%为高风险，否则低风险 |
| 混批风险 | 同一材料存在2个以上批次/色号 | 高风险 |
| 临期风险 | 距到期<90天且有剩余 | <30天高风险，否则中风险 |
| 尺寸变更 | 面积变化>0.5㎡ | 变化>10%高风险，否则中风险 |

## 示例数据场景

示例数据模拟了以下场景：

1. **混批风险**：客厅地砖分两次采购，批次号不同（B20260101 和 B20260115），存在色差风险
2. **临期风险**：瓷砖背胶 2026-05-30 到期，距当前（2026-05-04）不足30天
3. **采购过量**：填缝剂采购10袋，实际需求约4.5袋，超量122%
4. **材料不足**：部分材料采购量略低于需求量
5. **尺寸变更**：客厅和主卧均有尺寸调整记录

## 常见问题

**Q: 数据会丢失吗？**

A: 数据保存在浏览器 localStorage 中，只要不清除浏览器数据就不会丢失。建议定期使用「导出数据」功能备份。

**Q: 支持批量导入吗？**

A: 支持。点击「导入数据」按钮时，可以同时选择多个 CSV/JSON 文件。

**Q: 如何修改数据？**

A: 目前版本支持：
1. 导出 JSON 文件后编辑，再重新导入
2. 直接修改 CSV 文件后导入
3. 使用浏览器开发者工具修改 localStorage

**Q: 为什么需要本地服务器？**

A: 现代浏览器出于安全考虑，禁止从 file:// 协议读取本地文件。使用本地服务器可以正常加载示例数据和导入导出功能。
