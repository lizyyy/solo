# 📊 表格导入规则引擎

面向内部团队的智能数据导入解决方案，核心是 API 和完整的数据闭环。

## ✨ 核心特性

### 🔗 智能字段映射
- 自动识别常见字段名（姓名、手机号、邮箱、部门、入职日期、薪资、负责人）
- 支持中英文别名自动匹配（如 phone → 手机号，email → 邮箱）
- 可扩展自定义字段映射规则

### 🧹 脏数据校验与修复建议
- **手机号校验**: 11位有效号码检测
- **邮箱校验**: 标准邮箱格式验证
- **日期校验**: 多格式日期识别与合法性检查
- **薪资校验**: 数值范围和格式检查
- **姓名校验**: 必填项和长度约束

### 💡 智能修复建议
- 针对每种错误类型提供具体的修复建议
- 支持批量修复和单行修复
- 修复后自动重新校验

### 📦 批次管理
- 每次导入作为独立批次管理
- 支持搜索（按文件名、负责人、批次号）
- 状态跟踪（已上传 → 已校验 → 已导入）
- 批次级别的数据导出

### 📑 友好导出报告
导出的 Excel 报告包含 **4 个工作表**：

1. **批次概览** - 批次基本信息、数据统计、按负责人分组统计
2. **成功导入数据** - 所有通过校验的干净数据
3. **脏数据详情** - 每行错误的具体字段和原因（红色高亮）
4. **修复建议** - 针对脏数据的具体修复指导（黄色高亮）

## 🚀 快速开始

### 1. 安装依赖
```bash
pip install -r requirements.txt
```

### 2. 启动服务
```bash

```

服务将在 `http://localhost:5000` 启动

### 3. 运行测试
```bash
# 先启动服务，再开一个终端运行
python test_api.py
```

## 🔌 API 端点

### 上传文件
```
POST /api/upload
Content-Type: multipart/form-data

参数:
- file: CSV/Excel 文件
- owner: 负责人姓名（可选）
```

### 获取批次列表
```
GET /api/batches?search=xxx
```

### 获取批次详情
```
GET /api/batch/{batch_id}
```

### 重新校验
```
POST /api/batch/{batch_id}/validate
```

### 执行导入
```
POST /api/batch/{batch_id}/import
```

### 导出报告
```
GET /api/batch/{batch_id}/export
```

### 应用修复
```
POST /api/batch/{batch_id}/fix
Content-Type: application/json

{
  "row_index": 0,
  "fixes": {
    "手机号": "13800138000",
    "邮箱": "test@example.com"
  }
}
```

## 🎯 使用流程

### 标准导入流程
1. **上传文件** → 拖拽或选择 CSV/Excel 文件
2. **填写负责人** → 便于后续按负责人分组统计
3. **查看校验结果** → 系统自动检测脏数据并给出修复建议
4. **修复数据** → 根据建议修正错误
5. **执行导入** → 干净数据成功导入
6. **导出报告** → 生成完整的导入报告供非技术同事查看

### 失败路径演示
1. **格式不支持** → 上传非 CSV/Excel 文件会被拒绝
2. **未校验就导入** → 系统阻止，要求先完成校验
3. **部分数据失败** → 脏数据被拦截，只导入干净数据
4. **批次不存在** → 访问无效批次号返回 404

## 🔧 技术栈

- **后端**: Flask + Pandas + OpenPyXL
- **前端**: 原生 HTML/CSS/JavaScript (无框架依赖)
- **数据格式**: CSV, Excel (.xlsx, .xls)
- **部署**: 单文件服务，无需复杂配置
