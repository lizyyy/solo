## 1. 产品概述

泵站振动巡检工具——面向设备工程师和值班长的一线巡检辅助工具，将工况日志、阈值表和维修单统一到同一条时间线上查看，支持混杂数据导入（正常记录、晚到附件、重复项、人工更正），生成带处理口径的分类巡检报告。

- 解决设备工程师在巡检时需在多个系统间切换查看数据的问题
- 目标用户：设备工程师（一线巡检操作）、值班长（报告审阅与处置决策）

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用场景 | 核心权限 |
|------|----------|----------|
| 设备工程师 | 现场巡检、导入数据、复核导出 | 导入数据、查看时间线、标记记录状态、导出报告 |
| 值班长 | 审阅报告、确认处理口径 | 查看分类报告、确认/退回记录 |

### 2.2 功能模块

1. **巡检时间线页面**：工况日志、阈值触发、维修单同一线展示，按时间排序
2. **数据导入与校验页面**：上传数据包，自动识别正常记录、晚到附件、重复项、人工更正
3. **巡检报告页面**：已确认/待补/人工改过分类展示，带处理口径，支持导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 巡检时间线 | 时间线视图 | 按时间轴展示工况日志（蓝色）、阈值触发（橙色）、维修单（红色）三种事件 |
| 巡检时间线 | 事件详情面板 | 点击时间线节点展开详情，显示完整数据和关联记录 |
| 巡检时间线 | 状态标记 | 对记录标记为"已确认""待补""人工更正" |
| 数据导入 | 上传区 | 拖拽或点击上传 JSON/CSV 数据包 |
| 数据导入 | 校验结果 | 逐条展示校验结果：正常✓、晚到附件⚠、重复项⛔、人工更正✏ |
| 数据导入 | 人性化错误提示 | 用大白话描述问题，如"这条振动记录比日志晚了2天，请确认是否漏传" |
| 巡检报告 | 分类汇总 | 已确认/待补/人工改过三个分组，各自计数 |
| 巡检报告 | 处理口径 | 每条记录附带处理口径标签（如"继续观察""需补附件""已人工修正"） |
| 巡检报告 | 导出复核 | 导出前弹出复核清单，确认数据完整性后再导出 |
| 收尾说明 | 使用指引 | 简要说明：如何放置工况日志样例、去哪看故障复现顺序错、导出前怎么复核 |

## 3. 核心流程

设备工程师完成一次完整巡检的流程：

1. 导入数据包（含工况日志、阈值配置、维修单）
2. 系统自动校验，用大白话提示异常（晚到、重复、更正）
3. 在时间线上查看所有事件，标记记录状态
4. 修复或确认所有问题后，进入报告页面
5. 复核报告内容，导出给值班长

## 4. 用户界面设计

### 4.1 设计风格

- **整体风格**：工业实用风，不花哨，信息密度高，操作路径短
- **主色**：深灰（#1e293b）为底，配合功能色
- **功能色**：工况日志蓝（#3b82f6）、阈值触发橙（#f59e0b）、维修单红（#ef4444）
- **状态色**：已确认绿（#22c55e）、待补黄（#eab308）、人工改过蓝紫（#8b5cf6）
- **按钮风格**：圆角矩形，适度阴影，操作感明确
- **字体**：正文使用系统无衬线体，数据用等宽字体
- **布局风格**：左侧导航 + 右侧内容区，顶部工具栏

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 要素 |
|----------|----------|---------|
| 巡检时间线 | 时间线视图 | 垂直时间线，左侧时间刻度，右侧事件卡片，颜色区分事件类型 |
| 巡检时间线 | 事件详情面板 | 右侧抽屉式面板，字段对齐展示，关联记录高亮 |
| 巡检时间线 | 状态标记 | 卡片右上角下拉选择状态标签 |
| 数据导入 | 上传区 | 虚线拖拽区，支持文件类型提示 |
| 数据导入 | 校验结果 | 列表式逐条展示，图标+颜色+人话描述 |
| 巡检报告 | 分类汇总 | 三栏卡片布局，每栏顶部计数，下方记录列表 |
| 巡检报告 | 处理口径 | 每条记录右侧标签徽章 |
| 巡检报告 | 导出复核 | 模态对话框，清单式逐项确认 |

### 4.3 响应式设计

- 桌面优先设计，兼顾平板竖屏查看
- 时间线在小屏幕下切换为简化视图
