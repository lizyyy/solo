# 养老驿站配送路线 - 城更数据平台

专为城更项目经理阿宁设计的养老驿站配送路线数据管理系统。

## 🌟 核心特性

- **三步工作流**：网格员巡查表导入 → 项目经理审核施工告示 → 热力图更新与复核
- **施工告示备注保留**：不清洗备注信息，完整保留重要说明
- **冲突检测**：自动检测网格员巡查表与施工告示的矛盾，列出冲突证据供人工确认
- **晚间采样缺口处理**：识别晚间缺采样导致热力图偏低，标记为待复核状态
- **系统自检**：覆盖重复导入、缺采样检测、补录重算、导出一致性检查
- **多角色支持**：网格员、城更项目经理（阿宁）、街道规划员

## 📋 使用指南（新人照着做就能从样例跑到报告）

### 第一步：导入网格员巡查表

1. 打开首页默认在"第一步：导入网格员巡查表"
2. 点击 **📊 正常材料** 加载正常样例数据
3. 查看已导入数据列表，确认数据正确
4. （可选）点击 **⚠️ 错口径材料** 测试错口径数据导入
5. 点击 **下一步：审核施工告示 →**

### 第二步：城更项目经理审核施工告示

1. 切换右上角角色为 **"城更项目经理（阿宁）"
2. 点击 **🏗️ 正常施工告示** 加载施工告示样例
3. 点击 **🔍 检测网格员巡查表与施工告示冲突**
4. 查看冲突列表，每个冲突都显示：
   - 冲突类型和描述
   - 巡查记录证据
   - 施工告示证据（包含完整备注）
5. 对冲突进行处理：
   - **✓ 确认冲突**：输入说明后确认
   - **✗ 驳回**：认为不构成冲突
6. 点击 **下一步：生成热力图 →**

### 第三步：热力图更新与复核

1. 点击 **🔥 生成热力图**
2. 查看热力图：
   - 颜色越深表示通行难度越高
   - 红色闪烁边框表示晚间缺采样待复核
3. 切换角色为 **"街道规划员"**
4. 点击待复核的网格进行确认
5. 点击 **🔧 运行自检** 检查系统状态
6. 点击 **📤 生成完整报告** 导出所有数据

## 🔧 自检功能说明

系统内置5项自检：

| 检查项 | 说明 |
|--------|------|
| 重复导入检测 | 检查是否有重复导入的文件和记录 |
| 晚间采样缺口检测 | 检查晚间采样是否不足，热力图是否有缺口 |
| 补录后重算检测 | 检查补录数据后热力图是否重新生成 |
| 导出一致性检测 | 检查内存数据与存储数据是否一致 |
| 数据完整性检测 | 检查是否有缺失位置信息的记录，备注是否保留 |

## 🎯 关键业务规则

### 冲突检测规则

1. **通行状态冲突**：施工告示显示封路，但巡查表显示可通行
2. **路况描述冲突**：同一地点施工期内，巡查表未提及施工

### 热力图规则

1. 晚间（18:00 - 次日6:00）采样缺口超过3小时，标记为晚间缺口
2. 有晚间缺口的网格热力权重自动下调40%
3. 晚间缺口网格标记为待复核，需街道规划员确认

### 施工告示备注

- **永不清洗备注字段
- 冲突证据中完整展示备注内容
- 导出时保留全部备注信息

## 🐛 常见问题

**Q: 错口径的数据能导入吗？**
A: 可以，系统会自动识别常见的列名映射，导入记录会标注列口径类型。

**Q: 补录的数据会重新计算热力图吗？**
A: 补录导入后需要手动点击"生成热力图"重新计算，自检会提示是否已重算。

**Q: 施工告示的备注会被删掉吗？**
A: 绝对不会！备注会完整保留在所有环节，包括冲突证据展示和导出。

**Q: 冲突可以批量处理吗？**
A: 目前需要逐条确认，确保每条冲突都经过人工判断，不替业务同事自动拍板。
