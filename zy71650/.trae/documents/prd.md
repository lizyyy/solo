## 1. 产品概述

合成器包络参数拟合工具——帮助电子音乐教师从录音中反推 ADSR 包络参数，让学生直观理解音色的起落变化。核心解决三个问题：① 从音频采样中自动拟合 Attack/Decay/Sustain/Release 参数；② 原始值、修正值和最终结论分层管理、可追溯；③ 异常标记与审计明细让复核不再依赖口头解释。

- 目标用户：电子音乐课堂教师、音频分析爱好者
- 核心价值：将"听感→参数"的推导过程完整记录、透明可审，避免同批数据在屏幕和报告里出现两套数字

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 教师 | 本地创建账号 | 上传音频、拟合包络、编辑备注、导出报告、对比历史 |
| 学生 | 本地创建账号 | 查看拟合结果、导出图表、只读备注 |

### 2.2 功能模块

1. **工作台页面**：音频上传与波形显示、ADSR 包络拟合控制、实时包络曲线可视化、拟合参数面板
2. **数据明细页面**：原始值/修正值/结论值分层展示、异常记录筛选与标记、审计明细（判断理由）查看、备注编辑与版本保护
3. **历史对比页面**：多条拟合记录并排对比、参数变化趋势图、结论覆盖保护检测

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台 | 音频上传区 | 拖拽/点击上传 WAV/MP3，显示文件名、时长、采样率、BPM（自动检测） |
| 工作台 | 波形显示区 | 实时渲染音频波形，支持缩放、选区标记起音点 |
| 工作台 | 包络拟合面板 | 一键拟合 ADSR，显示 Attack/Decay/Sustain/Release 原始值、修正值、结论值三列 |
| 工作台 | 曲线可视化 | 叠加显示原始包络曲线与拟合 ADSR 曲线，起音点、峰值、稳态段、释放段标注 |
| 工作台 | 乐器标签与备注 | 乐器类型下拉选择、课堂备注文本框，保存后生成带时间戳的版本记录 |
| 数据明细 | 三层数据表 | 原始值列（算法直出）、修正值列（人工调整后）、结论值列（最终采纳），每列独立可编辑 |
| 数据明细 | 异常标记栏 | 起音点误判 / 噪声干扰 / 参数越界 三类标记，筛选与导出时保留标记 |
| 数据明细 | 审计明细 | 每条记录的操作类型（拟合/峰值检测/参数解释/图表导出/历史对比）、判断理由、时间戳 |
| 数据明细 | 备注编辑 | 编辑课堂备注，保存为新版本，旧版本不可覆盖，仅可追加 |
| 历史对比 | 对比列表 | 选择两条以上拟合记录并排展示 ADSR 参数与曲线 |
| 历史对比 | 变化趋势 | 参数随时间变化的折线图，标注异常点 |
| 历史对比 | 覆盖保护 | 检测并提醒"旧结论被新结果覆盖"风险，保留历史结论快照 |

## 3. 核心流程

**主流程**：教师上传音频 → 系统自动检测 BPM 与波形 → 教师选择起音区域 → 系统拟合 ADSR 包络 → 展示原始值/修正值/结论值 → 教师标记异常、填写判断理由、编辑备注 → 导出报告或图表 → 历史记录可对比、可追溯

```mermaid
flowchart TD
    "上传音频" --> "波形渲染与 BPM 检测"
    "波形渲染与 BPM 检测" --> "选择起音区域"
    "选择起音区域" --> "ADSR 包络拟合"
    "ADSR 包络拟合" --> "三层数据展示"
    "三层数据展示" --> "异常标记与判断理由"
    "异常标记与判断理由" --> "备注编辑（版本保护）"
    "备注编辑（版本保护）" --> "导出报告/图表"
    "导出报告/图表" --> "历史对比与追溯"
    "ADSR 包络拟合" --> "峰值检测"
    "峰值检测" --> "参数解释"
    "参数解释" --> "异常标记与判断理由"
```

**覆盖保护流程**：教师修改备注 → 重新拟合 → 系统比对旧结论 → 若参数变化超过阈值则保留旧结论快照并标记"已覆盖" → 新结论独立保存，旧结论不删除

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深灰底色（#0F1117）搭配荧光绿（#39FF14）与琥珀色（#FFB800）双强调色，模拟合成器面板质感
- **次色调**：深蓝灰（#1A1D2E）用于卡片背景，暗紫（#2D1B4E）用于选中态
- **按钮风格**：圆角矩形，带微妙内阴影，悬浮态发光效果
- **字体**：标题使用 JetBrains Mono（等宽科技感），正文使用 Noto Sans SC
- **布局风格**：左侧面板 + 中央波形区 + 右侧参数面板的三栏布局
- **图标风格**：线性图标（lucide-react），荧光绿色调
- **动效**：包络拟合完成时曲线从左到右绘制动画，参数卡片入场时交错淡入

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 工作台 | 音频上传区 | 虚线边框拖拽区、文件信息卡片（名称/时长/采样率/BPM） |
| 工作台 | 波形显示区 | Canvas 波形、可拖拽起音标记线、缩放滑块、时间轴刻度 |
| 工作台 | 包络拟合面板 | 三列表格（原始值/修正值/结论值）、滑块微调、拟合按钮 |
| 工作台 | 曲线可视化 | SVG 叠加曲线、A/D/S/R 段色块标注、起音点/峰值标记点 |
| 工作台 | 乐器标签与备注 | 下拉选择框、多行文本框、保存按钮（带版本号提示） |
| 数据明细 | 三层数据表 | 分组表格，每组展开显示三层值、差异高亮（红/黄/绿） |
| 数据明细 | 异常标记栏 | 标记徽章（起音点误判=红、噪声干扰=黄、参数越界=橙）、筛选下拉 |
| 数据明细 | 审计明细 | 时间线组件，每条显示操作类型图标+判断理由+时间戳 |
| 数据明细 | 备注编辑 | 版本化文本区、历史版本折叠列表、只读旧版本 |
| 历史对比 | 对比列表 | 双栏/多栏卡片，参数数值并排+差异百分比 |

### 4.3 响应式策略

- 桌面优先：三栏布局在 1440px+ 完整展示
- 平板（768-1439px）：左右面板折叠为抽屉式，中央波形区全宽
- 手机（<768px）：单栏堆叠，波形区置顶，参数面板下方滑动切换
