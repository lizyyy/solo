## 1. 产品概述

道路绿波速度带计算工具——面向交通信号协调场景，帮助产品人员从杂乱参数表中快速算出绿波速度带范围，并在数据存在空值、重复、单位混用或边界异常时给出明确提示与建议，而非静默跳过或覆盖。目标用户为产品同事小岑，需便于交接。

- 解决问题：绿波协调参数表经常有空值、重复路口、单位不统一，手工推算耗时且易漏异常
- 目标：让小岑能把一份原始参数表丢进来，一次顺利出结果，遇到问题也有据可查、可返工修正

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 产品人员（小岑） | 直接打开网页使用 | 导入参数、计算、人工调参、导出结果 |

### 2.2 功能模块

1. **参数导入页**：粘贴/上传参数表，预览解析结果，标记异常（空值、重复、单位混用、冲突）
2. **计算与结果页**：执行绿波速度带计算，展示速度带范围、带宽、时距图；优化建议附带理由；异常记录单独展示且不消失
3. **调参与重算页**：人工微调参数后重算，已有调参不被默认值覆盖；筛选条件变更后屏幕与导出口径一致

### 2.3 页面详情

| 页面 | 模块 | 功能描述 |
|------|------|----------|
| 参数导入页 | 数据输入区 | 支持粘贴 CSV/TSV 或上传文件；自动检测分隔符 |
| 参数导入页 | 预览与校验 | 解析后预览表格，用颜色/图标标记：空值(黄)、重复路口(橙)、单位混用(红)、参数表与导入冲突(紫) |
| 参数导入页 | 冲突处理 | 参数表说法与导入数据冲突时，列出两边证据和建议动作，由用户选择 |
| 计算与结果页 | 速度带计算 | 输入公共周期、方向后一键计算；展示每段速度范围[min,max]与带宽 |
| 计算与结果页 | 优化建议 | 给出偏移量优化方案，附带"为什么这样建议"的文字说明 |
| 计算与结果页 | 时距图 | 可视化展示绿波带在时间-距离图上的位置 |
| 计算与结果页 | 异常记录 | 空值/重复/边界异常数据单独列出，标注对结果的影响，确保不会在汇总中悄悄消失 |
| 调参与重算页 | 参数微调 | 人工修改单个路口偏移量/绿信比等，保存后重算；重复运行不覆盖已有调参 |
| 调参与重算页 | 筛选与导出 | 按方向/路段筛选，屏幕展示与导出文件口径一致；导出为 CSV |

## 3. 核心流程

用户导入参数表 → 系统解析并校验 → 展示预览与异常标记 → 用户处理冲突（选择保留哪边）→ 用户设置公共周期与方向 → 执行计算 → 展示速度带范围、带宽、时距图 → 查看优化建议与理由 → 如需微调：修改参数 → 重算（保留历史调参）→ 筛选/导出结果

```mermaid
flowchart TD
    "A[导入参数表]" --> "B[解析与校验]"
    "B" --> "C{存在异常?}"
    "C" --> "|否|" "D[预览正常数据]"
    "C" --> "|是|" "E[标记异常:空值/重复/单位/冲突]"
    "E" --> "F[用户处理冲突]"
    "F" --> "D"
    "D" --> "G[设置周期与方向]"
    "G" --> "H[执行绿波速度带计算]"
    "H" --> "I[展示结果:速度带/带宽/时距图]"
    "I" --> "J[查看优化建议与理由]"
    "J" --> "K{需微调?}"
    "K" --> "|否|" "L[筛选与导出]"
    "K" --> "|是|" "M[修改参数(保留历史)]"
    "M" --> "H"
    "L" --> "N[完成]"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青色(#0D7377) + 琥珀色(#D4A017)点缀，深色背景(#1A1A2E)，体现交通工程的工业感
- 按钮：圆角矩形，主操作用实心琥珀色，次操作用描边
- 字体：正文用 Noto Sans SC，数据/数字用 JetBrains Mono
- 布局：左侧参数面板，右侧结果区，顶部导航标签页
- 图标：lucide-react 图标集

### 4.2 页面设计概览

| 页面 | 模块 | UI 元素 |
|------|------|----------|
| 参数导入页 | 数据输入区 | 大文本框+文件上传按钮，自动检测分隔符提示 |
| 参数导入页 | 预览表格 | 斑马纹表格，异常行高亮标记+悬浮 tooltip 说明 |
| 参数导入页 | 冲突面板 | 左右对比卡片（参数表 vs 导入数据），底部单选按钮 |
| 计算与结果页 | 速度带结果 | 卡片展示每段速度范围，数字用等宽字体 |
| 计算与结果页 | 优化建议 | 折叠面板，展开显示理由文字 |
| 计算与结果页 | 时距图 | Canvas 绘制时间-距离图，绿波带着色 |
| 计算与结果页 | 异常记录 | 侧边抽屉，列出所有异常条目及影响说明 |
| 调参与重算页 | 参数表格 | 可编辑单元格，已调参数显示编辑标记 |
| 调参与重算页 | 导出按钮 | 导出 CSV，筛选条件标签同步显示 |

### 4.3 响应式

桌面优先设计，最小宽度 1024px 保证时距图可读；平板端参数面板收折为顶部面板。

不适用

## 5. 数据样例设计

样例覆盖两种场景：
- **顺利处理**：5 个路口，数据完整，单位统一，直接出结果
- **返工处理**：8 个路口，包含：1 个空值行、2 个重复路口（路口编号相同但数据不同）、1 处单位混用（km/h 与 m/s）、1 条边界记录（绿灯时间=0 导致带宽为 0）

样例字段：路口编号、路口名称、距起点距离(m)、周期(s)、绿信比、偏移量(s)、方向(上行/下行)
