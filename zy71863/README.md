# 概率树复核系统

一个轻量级的教研管理工具，帮助备课组清晰区分"补材料"与"改结论"，记录变更历史。

## 功能特性

- ✅ **记录管理**：查看所有复核记录，支持按状态筛选
- ✅ **状态追踪**：四种状态（待处理、已完成、补材料、改结论）
- ✅ **变更历史**：完整的时间线记录，显示每次修改的前后值
- ✅ **快捷操作**：补充讲评记录、修改难度标签、标记处理完成
- ✅ **导出功能**：一键导出包含完整历史的讲评稿
- ✅ **操作指南**：教研组长专属操作说明

## 技术栈

- React 18 + TypeScript
- Vite 5
- TailwindCSS 3
- Zustand（状态管理）
- React Router 6
- Lucide React（图标）

## 使用说明

### 教研组长操作三步法

1. **放置难度标签**：根据实际答题数据调整难度（基础/简单/中等/困难/挑战）
2. **检查空集边界**：在变更历史中查看题库修改记录，确认概率树的条件分支
3. **导出前复核**：确认所有变更有记录、状态标记正确、讲评记录补全后导出

### 数据持久化

系统使用 LocalStorage 自动保存数据，刷新页面后数据不会丢失。

## 状态说明

| 状态 | 说明 |
|------|------|
| 待处理 | 需要教研组长复核的记录 |
| 补材料 | 仅补充讲评记录，难度标签无变化 |
| 改结论 | 实际修改了难度标签或题目结论 |
| 已完成 | 复核完成的记录 |
