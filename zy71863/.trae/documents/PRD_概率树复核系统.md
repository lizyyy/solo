## 1. 产品概述
概率树复核系统是一个轻量级教研管理工具，解决"难度标签-讲评记录"流程混乱问题。帮助备课组清晰区分"补材料"与"改结论"，记录变更历史，提供操作指引。

目标用户：教研组长、备课组老师。

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|---------|---------|
| 教研组长 | 系统预置 | 查看全部记录、修改题库表、导出复核报告 |
| 备课组老师 | 系统预置 | 查看记录、提交复核、补录讲评记录 |

### 2.2 功能模块
1. **复核记录列表页**：记录列表、筛选、状态概览
2. **记录详情页**：变更历史、来源追踪、操作记录
3. **操作指引面板**：快速操作、状态流转
4. **教研组长指南**：操作说明、注意事项

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 复核记录列表页 | 状态筛选栏 | 待处理、已完成、补材料、改结论四类状态筛选 |
| 复核记录列表页 | 记录卡片 | 显示来源、当前状态、修改人、时间、待处理原因 |
| 记录详情页 | 变更时间线 | 可视化展示所有历史变更 |
| 记录详情页 | 差异对比 | 题库表改动前后对比 |
| 操作指引面板 | 快捷操作 | 补录讲评、修改难度、标记完成 |
| 教研组长指南 | 操作说明 | 难度标签样例、空集边界检查、导出前复核 |

## 3. 核心流程

```mermaid
graph TD
    A["难度标签到达"] --> B{"讲评记录到达"]
    B --> C{"是否有差异？"]
    C -->|是| D["标记：改结论"]
    C -->|否| E["标记：补材料"]
    D --> F["进入待处理"]
    E --> F["进入待处理"]
    F --> G["教研组长复核"]
    G --> H["确认变更/补录完成"]
    H --> I["记录历史"]
    I --> J["导出讲评稿"]
```

## 4. 核心流程说明
1. 难度标签先到系统，生成初始记录
2. 讲评记录晚到后，系统自动比对
3. 区分"补材料"（只是补录信息）与"改结论"（实际修改）
4. 有差异的记录进入待处理
5. 教研组长复核确认
6. 所有变更记入历史
7. 导出最终讲评稿

## 5. 用户界面设计

### 5.1 设计风格
- 主色调：深蓝 #1e3a5f，辅助色：琥珀 #d97706
- 按钮风格：圆角、微立体、悬停微动效
- 字体：思源宋体（标题）、思源黑体（正文）
- 布局：卡片式、左侧导航+主内容区
- 图标：线性图标，简洁专业

### 5.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|---------|---------|--------|
| 列表页 | 记录卡片 | 阴影卡片、状态标签色、时间线徽标 |
| 详情页 | 变更时间线 | 垂直时间线、差异高亮、悬停详情 |
| 指南页 | 步骤说明 | 编号步骤、重点框、提示框 |

### 5.3 响应式
桌面优先，平板适配，移动端单列布局
