# 雨后井盖异响排查台

城市排水巡检员本地数据分析可视化工具，专为暴雨后井盖异响排查设计。

## 功能特性

### 核心功能
- **多源数据导入**: 支持井盖传感器 CSV、人工巡检 CSV、积水点位 GeoJSON
- **数据校验**: 自动校验坐标范围、时间格式、井盖编号、重复记录和坏行
- **跨源匹配**: 智能匹配传感器数据和人工巡检数据，解决同一井盖多源编号对不上问题
- **规则引擎**: 识别暴雨后2小时内高频异响、积水半径命中、同井盖连续复发和超时未复核
- **风险分层**: 按街区展示风险等级分布，支持交互式地图查看
- **异响趋势**: 可视化展示异响次数、振动强度的分布和趋势
- **待复核清单**: 批量或单条复核高风险记录，支持任务分配
- **重复合并**: 智能识别重复记录，支持人工确认合并
- **多格式导出**: Markdown 复盘报告、CSV 派单表、JSON 审计包

### 解决的痛点
1. **同一井盖多源编号对不上**: 自动归一化井盖编号，支持跨源匹配
2. **异响持续时间算错**: 规则引擎精确计算时间窗口内的异响次数
3. **已派单点被重复派**: 工作流状态跟踪，避免重复派单

**井盖传感器 CSV 格式**:
```csv

MH-001,118.8,31.0,2024-05-01 08:30:00,5,3.5,正常,中心城区
```

**必需列**:
- `井盖编号`: 井盖唯一标识
- `经度`: 经度坐标 (WGS84)
- `纬度`: 纬度坐标 (WGS84)
- `记录时间`: 传感器记录时间
- `异响次数`: 检测到的异响次数
- `振动强度`: 振动强度值
- `传感器状态`: 传感器运行状态

**人工巡检 CSV 格式**:
```csv
井盖编号,经度,纬度,巡检时间,异响情况,积水深度,巡检员,状态,街区
井盖-001,118.8,31.0,2024-05-01 09:00:00,有异响,15,张三,待复核,中心城区
```

**必需列**:
- `井盖编号`: 井盖唯一标识
- `经度`: 经度坐标
- `纬度`: 纬度坐标
- `巡检时间`: 巡检时间
- `异响情况`: 是否发现异响 (有/无)
- `积水深度`: 积水深度 (厘米)
- `巡检员`: 巡检员姓名
- `状态`: 当前状态

**积水点位 GeoJSON 格式**:
```json
{
    "type": "FeatureCollection",
    "features": [
        {
            "type": "Feature",
            "properties": {
                "积水深度": 25,
                "积水半径": 60,
                "发生时间": "2024-05-01 07:00:00",
                "严重程度": "严重"
            },
            "geometry": {
                "type": "Point",
                "coordinates": [118.805, 31.005]
            }
        }
    ]
}
```

**必需属性**:
- `积水深度`: 积水深度 (厘米)
- `积水半径`: 影响半径 (米)
- `发生时间`: 积水发生时间

**Geometry**:
- `type`: 必须为 `"Point"`
- `coordinates`: `[经度, 纬度]`

## 规则引擎说明

### R001: 暴雨后2小时内高频异响
- **触发条件**: 暴雨后2小时内异响次数 ≥ 3次
- **基础评分**: 30分
- **额外加分**: 每超过阈值1次加5分
- **说明**: 暴雨后短期内频繁异响是井盖松动的重要信号

### R002: 积水半径命中
- **触发条件**: 井盖位于积水点影响半径内 (默认50米)
- **基础评分**: 25分
- **额外加分**: 积水深度每10厘米加1分
- **说明**: 井盖浸泡在积水中容易造成密封失效、异响加剧

### R003: 同井盖连续复发
- **触发条件**: 同一井盖7天内连续出现问题 ≥ 2次
- **基础评分**: 20分
- **额外加分**: 每超过阈值1次加10分
- **说明**: 反复出现问题的井盖可能存在结构性缺陷

### R004: 超时未复核
- **触发条件**: 异常记录超过24小时未复核
- **基础评分**: 15分
- **额外加分**: 每超时1小时加1分
- **说明**: 长时间未处理的异常可能导致风险升级

### 风险等级划分
| 等级 | 评分范围 | 颜色标识 |
|------|----------|----------|
| 极高风险 (Critical) | ≥ 90分 | 🔴 #DC2626 |
| 高风险 (High) | 70-89分 | 🟠 #EA580C |
| 中风险 (Medium) | 50-69分 | 🟡 #CA8A04 |
| 低风险 (Low) | < 50分 | 🟢 #16A34A |

## 注意事项

### 数据安全
- 所有数据保存在本地 `data/` 目录
- 审计日志记录所有操作
- 敏感数据请妥善保管

### 坐标系统
- 默认使用 WGS84 坐标系 (EPSG:4326)
- 经度范围: 118.0-120.0 (可在 config.py 修改)
- 纬度范围: 30.0-32.0 (可在 config.py 修改)

### 井盖编号格式
支持多种前缀自动归一化：
- `MH-`, `S-`, `SS-` (传感器前缀)
- `井盖-`, `井盖编号-`, `JH-`, `JG-` (人工巡检前缀)

归一化后只保留数字部分进行匹配。

## 常见问题

### Q1: 数据导入失败怎么办？
A: 检查以下几点：
- CSV 文件编码应为 UTF-8 或 GBK
- 确保包含所有必需列
- 坐标值在有效范围内
- 时间格式可被解析 (支持多种常见格式)

### Q2: 匹配率低是什么原因？
A: 可能原因：
- 井盖编号前缀不在支持列表中
- 坐标偏差超过10米阈值
- 时间戳差异过大

解决方法：
- 在 `config.py` 中添加自定义前缀
- 调整 `duplicate_distance_meters` 参数
- 检查数据坐标系统是否一致

### Q3: 规则没有触发？
A: 检查：
- 暴雨时间设置是否正确
- 异响次数是否达到阈值
- 时间戳格式是否正确解析

### Q4: 导出文件在哪里？
A: 默认保存在 `exports/` 目录下，文件名包含时间戳。
