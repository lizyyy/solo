# 多仓履约拆单系统

## 项目简介
多仓履约拆单API系统，用于替代临时脚本，实现订单录入后的智能拆单、仓库分配、运费计算和履约追踪。

## 技术栈
- **后端**: Python + FastAPI + SQLAlchemy + SQLite
- **前端**: Vue 3 + Element Plus + Axios + Vite
- **特性**: 状态幂等性、换仓留痕、运费规则修正、审计追溯

## 快速开始

### 后端启动
```bash
cd backend
pip install -r requirements.txt
python main.py
```
后端服务将在 http://localhost:8000 启动
API文档: http://localhost:8000/docs

### 前端启动
```bash
cd frontend
npm install
npm run dev
```
前端服务将在 http://localhost:3000 启动

## 使用流程

1. **初始化示例数据**
   - 进入"订单列表"页面
   - 点击"初始化示例数据"按钮
   - 系统将创建3个仓库（北京、上海、广州）及对应库存和运费规则

2. **创建订单**
   - 点击"新建订单"按钮
   - 填写订单信息（订单号自动生成）
   - 添加商品行（SKU可选: SKU001, SKU002, SKU003）
   - 提交订单

3. **执行拆单**
   - 在订单列表点击"拆单"按钮
   - 系统将根据库存自动分配仓库
   - 计算运费（匹配运费规则）
   - 生成履约记录

4. **查看和调整**
   - 点击"详情"查看完整履约信息
   - 可执行"换仓"操作（记录留痕）
   - 可"修正运费"（运费规则失败修正路径）
   - 最终"确认"后不可再修改

## 主要功能
1. **订单录入与管理** - 支持多商品行、保留原始输入
2. **智能拆单策略** - 基于可用库存自动分配仓库
3. **多仓库库存匹配** - 支持多仓库库存查询和预留
4. **运费规则计算** - 基于仓库、城市、重量计算运费
5. **换仓记录留痕** - 所有换仓操作记录审计日志
6. **状态幂等性保证** - 防止重复点击、刷新导致状态混乱
7. **运费规则失败修正路径** - 支持人工修正运费，记录原因
8. **履约结果追溯** - 详情页可追溯完整处理流程
