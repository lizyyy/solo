# 图书馆活动组活动签到数据清洗 CLI

专门用于图书馆活动签到数据清洗的命令行工具，解决分散在表格、截图和口头确认中的签到数据核对问题。

## 功能特性

- **同手机号多人检测**：识别同一手机号被多人使用的情况
- **扫码延迟检测**：检测超过阈值的延迟签到记录
- **可复跑追踪**：每条清洗后的记录都保留源文件和行号信息，支持追溯核对
- **多格式支持**：支持 CSV、Excel 等多种输入格式
- **预览模式**：先预览清洗结果，确认无误后再生成正式文件

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 预览清洗结果

先预览结果，检查数据问题是否被正确识别：

```bash
npm run preview
```

或使用完整命令：

```bash
node bin/cli.js --input ./input --rules ./rules.json --output ./output --preview
```

### 3. 正式执行清洗

确认预览无误后，执行正式清洗生成输出文件：

```bash
npm run clean
```

或使用完整命令：

```bash
node bin/cli.js --input ./input --rules ./rules.json --output ./output
```

### 4. 查看清洗报告

查看详细的数据问题报告：

```bash
npm run report
```

或直接查看文件：

```bash
cat output/report.md
```

## 输出文件说明

| 文件名 | 说明 |
|--------|------|
| `cleaned_signin.csv` | 清洗后的签到数据，包含源文件和行号追踪 |
| `source_tracking.csv` | 完整的源文件追踪对照表 |
| `report.md` | 详细的清洗报告，包含各类问题的具体分析 |

## 清洗规则配置

编辑 `rules.json` 自定义清洗规则：

```json
{
  "scanDelayThreshold": 30,        // 扫码延迟阈值（分钟）
  "requiredFields": ["姓名", "手机号", "活动名称", "签到时间"],  // 必填字段
  "phonePattern": "^1[3-9]\\d{9}$"  // 手机号正则
}
```

## 图书馆活动样例说明

本项目包含真实的图书馆活动场景样例数据：

| 数据源文件 | 活动名称 | 包含的数据问题 |
|-----------|----------|--------------|
| 扫码签到_世界读书日.csv | 世界读书日主题讲座 | 扫码延迟（45分钟、80分钟等） |
| 表格签到_绘本阅读.csv | 儿童绘本阅读分享会 | 同手机号多人（家长带孩子） |
| 口头补登_志愿者培训.csv | 图书馆志愿者培训 | 字段缺失（手机号、签到时间为空） |

这些样例数据模拟了图书馆活动组日常遇到的真实签到数据问题。

## 参数说明

| 参数 | 简写 | 说明 | 默认值 |
|------|------|------|--------|
| `--input` | `-i` | 输入目录路径 | `./input` |
| `--rules` | `-r` | 规则文件路径 | `./rules.json` |
| `--output` | `-o` | 输出目录路径 | `./output` |
| `--preview` | `-p` | 预览模式，不生成文件 | - |

## 使用场景

1. **月底签到核对**：将分散的多个签到表汇总清洗，一次性发现所有数据问题
2. **活动数据整理**：活动结束后快速整理签到数据，生成可用于上报的干净数据
3. **问题追溯**：发现数据异常时，通过源文件和行号快速定位原始记录位置
