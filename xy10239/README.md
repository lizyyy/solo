# 社区团购缺斤少两申诉台

## 安装运行

```bash
npm install
npm start
```

服务器运行在 http://localhost:3001

## 样例入口

1. 打开 http://localhost:3001
2. 点击「样例数据」标签页
3. 点击「导入样例数据」按钮

样例包含：
- 3个订单批次（大樱桃、西红柿、基围虾）
- 3条团长称重记录
- 3条用户申诉单

## 核心操作

**数据流程**：订单批次 → 称重记录 → 申诉处理

1. **新增批次**：「订单批次」→「新增批次」
2. **称重记录**：「称重记录」→「新增称重」，自动计算与订单的差异
3. **新增申诉**：「申诉管理」→「新增申诉」，关联对应批次
4. **修改申诉**：仅待处理状态可修改，点击「修改」按钮
5. **确认申诉**：点击「确认」，填写处理信息
6. **拒绝申诉**：点击「拒绝」，填写处理信息
7. **导出数据**：「申诉管理」→「导出数据」，生成Excel文件

## 如何检查结果

1. **数据概览**：首页显示批次统计、称重差异、申诉状态分布
2. **批次统计表格**：查看每个批次的订单重量、实际称重、重量差异、申诉数量
3. **称重记录**：对比团长称重与订单数据，红色表示缺斤少两
4. **申诉状态**：待处理/已确认/已拒绝三种状态区分显示
5. **重跑验证**：再次点击「导入样例数据」，数据不会重复，统计保持一致
6. **导出验证**：下载Excel文件，包含4个sheet：订单批次、称重记录、申诉单、统计数据
