🔄 批量审批回调协调器

📋 核心功能特性

  • 批次拆分 - 支持将大批量单据按配置分片处理
  • 幂等校验 - 通过幂等键防止重复提交产生脏数据
  • 部分失败定位 - 精确追踪每个单据的处理状态和错误信息
  • 范围重放 - 支持按单据ID、分片号或全量失败重放
  • 回执汇总 - 生成可导出的处理回执和问题排查报告
  • 时间线追踪 - 完整记录每个关键动作的操作轨迹

🚀 快速开始 - API 接口列表

  • POST /api/batches
    创建审批批次 - 支持批量单据提交，自动分片，幂等校验
  • POST /api/batches/{batchId}/start
    开始处理批次 - 推进批次状态至处理中
  • POST /api/batches/callback
    处理回调结果 - 接收业务系统的处理回执，更新单据状态
  • POST /api/batches/{batchId}/replay
    重放单据 - 支持按单据ID、分片号或全量失败重放
  • GET /api/batches/{batchId}
    查询批次详情 - 获取批次基本信息和处理统计
  • GET /api/batches
    批次列表查询 - 支持按时间范围、来源系统筛选
  • GET /api/batches/{batchId}/items
    查询批次下所有单据
  • GET /api/batches/{batchId}/items/failed
    查询失败单据列表
  • GET /api/batches/{batchId}/timeline
    查询批次时间线 - 完整追踪处理轨迹
  • POST /api/batches/{batchId}/receipts
    生成处理回执 - 生成结构化的处理汇总报告
  • GET /api/batches/{batchId}/debug-report
    导出问题排查报告 - 包含批次信息、失败明细、时间线和排查建议
  • GET /h2-console
    H2 数据库控制台 - 用于调试和查看数据

📊 核心数据模型

  • ApprovalBatch - 审批批次
    包含批次ID、业务类型、状态、统计信息、分片配置等
  • ApprovalItem - 审批单据
    包含单据ID、幂等键、状态、分片号、错误信息、重试次数等
  • TimelineEvent - 时间线事件
    记录每个关键动作的时间、类型、描述、操作人等
  • ProcessingReceipt - 处理回执
    结构化的处理汇总，包含明细数据，可导出用于审计

🔄 状态流转说明

  • 批次状态: CREATED → PROCESSING → PARTIAL_SUCCESS / COMPLETED → REPLAYING
  • 单据状态: PENDING → PROCESSING → SUCCESS / FAILED → REPLAYING → SUCCESS / FAILED
