# 期权波动率曲面 - 快速开始

## 先跑什么

```bash
# 1. 安装依赖 (已完成)
npm install

# 2. 启动开发服务器
npm run dev

# 3. 浏览器打开 http://localhost:3000
```

## 再看哪里

### 左侧面板
- **数据概览**: 合约统计、平均IV、总成交量
- **数据筛选**: 按状态/到期/行权价过滤，可重置
- **切片查看**: 按到期日或行权价做截面切片，滑块调节
- **数据操作**: 补录合约、批量导入(CSV/JSON)、重新校验、加载示例
- **校验状态**: 
  - ✅ 稀疏插值检查 - 插值点IV是否合理
  - ✅ 到期顺序检查 - 到期日序列是否正确排序
  - ⚠️ 异常遮挡检查 - 高成交量异常是否可见
  - ✅ 状态流转检查 - 导入→插值→校验→发布流程是否完整

### 顶部工具栏
- **运行诊断**: 系统级数据完整性、曲面构建、状态流转检查
- **📷 截图导出**: 3D曲面PNG截图，含异常点标注
- **导出JSON/CSV**: 完整波动率报告

### 中央3D视图
- **X轴**: 到期日 (红)
- **Y轴**: 行权价 (绿)  
- **Z轴**: 波动率 (蓝)
- **颜色条**: 蓝→绿→黄→红 对应IV从低到高
- **白点**: 实际报价点
- **紫点**: 插值生成点
- **红/黄球**: 异常/警告合约（脉动动画）
- **悬浮信息**: 鼠标悬停显示合约详情
- **视图控制**: 重置视角、线框/实体切换、自动旋转

### 底部面板
- **异常合约列表**: 前10条异常合约，可快速撤回
- **合约明细**: 点击列表查看完整信息、状态流转、编辑/撤回
- **操作历史**: 所有操作记录（补录、更新、撤回、导出等）

## 状态流转测试

1. **补录测试**: 左侧「补录合约」→ 填写信息 → 确定
   - 自动进入异常检测
   - 曲面自动更新
   - 操作历史记录

2. **撤回测试**: 底部异常列表 → 点击「撤回」
   - 合约状态变为 REVOKED
   - 从曲面中移除
   - 异常点标记消失

3. **编辑测试**: 合约明细 → 「编辑」→ 修改IV → 保存
   - 状态流转自动添加 "published"
   - 曲面重新渲染
   - 异常检测重新计算

4. **筛选联动**: 左侧修改筛选条件
   - 曲面实时更新
   - 异常列表联动

## 数据格式

### CSV导入格式
```
合约代码,标的,行权价,到期日,剩余天数,IV,成交量,持仓量
HO_4.0_2026-06-30,510300,4.0,2026-06-30,30,0.20,1000,2000
```

### JSON导入格式
```json
[
  {
    "contractCode": "HO_4.0_2026-06-30",
    "underlying": "510300",
    "strikePrice": 4.0,
    "expiryDate": "2026-06-30",
    "expiryDays": 30,
    "iv": 0.20,
    "volume": 1000,
    "openInterest": 2000,
    "isInterpolated": false
  }
]
```
