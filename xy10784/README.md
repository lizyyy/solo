# 推荐规则调试台

## 功能概述

这是一个全栈应用，用于监控和处理推荐系统中的排序分数异常、屏蔽规则误判等问题。

### 核心功能

1. **错误明细查看** - 展示推荐系统中的异常记录，包括：
   - 用户ID
   - 错误类型
   - 原始排序分数 vs 处理后分数
   - 屏蔽原因
   - 状态（待处理/已修正/已回滚/已补偿）

2. **回滚功能** - 单条记录快速回滚

3. **批量导入** - 支持Excel/CSV格式批量导入错误数据

4. **人工处理** - 在详情页提供多种处理选项：
   - 移除屏蔽，恢复原始分数
   - 调整屏蔽规则，放宽限制
   - 确认屏蔽有效，无需调整
   - 标记为正常数据，优化脏数据检测

5. **导出功能** - 导出格式对非研发人员友好，包含：
   - 错误明细
   - 用户画像
   - 候选物料
   - 推荐解释

6. **脏数据检测** - 特殊标记包含脏数据的记录，展示：
   - 检测到的问题
   - 自动处理措施
   - 人工处理建议

7. **用户画像关联** - 保留原始输入和处理后结果，方便追溯推荐解释

## 快速开始

### 方式一：使用启动脚本

```bash
chmod +x start.sh
./start.sh
```

### 方式二：手动启动

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 启动服务：
```bash
python app.py
```

3. 在浏览器中访问：http://localhost:5000

## 使用说明

1. **生成样本数据** - 点击页面上的"生成样本数据"按钮，自动生成包含脏数据的测试样本
2. **查看详情** - 点击任意记录的"详情"按钮，查看完整的错误信息、用户画像、候选物料和推荐解释
3. **人工处理** - 在详情页底部选择处理方式，应用到该条记录
4. **批量操作** - 勾选多条记录后，点击"批量补偿"进行批量处理
5. **导出数据** - 点击"导出Excel"，下载对产品/运营人员友好的报告

## API接口

- `GET /api/errors` - 获取错误列表（支持分页和状态过滤）
- `GET /api/errors/<id>` - 获取单条错误详情
- `POST /api/errors/<id>/rollback` - 回滚错误
- `POST /api/errors/<id>/fix` - 修正错误
- `POST /api/batch/import` - 批量导入
- `POST /api/batch/compensate` - 批量补偿
- `GET /api/export` - 导出Excel
- `GET /api/stats` - 获取统计数据
- `POST /api/generate-sample` - 生成样本数据
