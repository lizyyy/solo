# 冷饮机投放点补冰预测器

户外活动冷饮机投放点高温时段缺冰预测与补给路线智能建议。

## 安装运行

```bash
cd ice_predictor
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

访问 http://localhost:8765

## 样例入口

- 内置样例数据：`data/sample_sales.csv`（5个户外投放点，含高温时段销量与天气特征）
- 界面按钮：「数据导入」→「使用样例数据」→「加载样例数据」

## 核心操作

1. **导入数据**：上传 CSV/Excel，自动去重（按文件哈希）
2. **运行预测**：对导入批次执行缺冰预测
3. **查看结果**：按优先级/紧急度排序，每个预测附带可解释原因
4. **人工复核**：逐条审核，标记通过/拒绝/调整/待处理
5. **路线建议**：按紧急度生成补给顺序，显示总需冰量
6. **导出结果**：生成 Excel，含预测详情与复核状态

## 检查结果

- 同一文件重复上传：显示"该文件已导入过"，不产生重复记录
- 重跑预测：同一 import_id 下的预测记录会被更新而非新增
- 导出文件：存 `exports/` 目录，文件名带时间戳，互不覆盖
- 数据库：`ice_predictor.db`（SQLite），可直接查看各表状态
