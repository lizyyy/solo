## 1. 产品概述

展厅灯位校准工具，面向展厅项目经理，解决讲解路线、设备备注与CAD点位手工改动混杂后的状态追踪与导出一致性问题。核心目标：让项目经理一眼分辨"补材料"和"改结论"，手动改过的CAD点位前后变化留在历史中，巡检单和明细不各说各话。

- 目标用户：展厅项目经理（非评审、非概念图设计者）
- 核心价值：状态可回看、异常有解释、导出有复核，减少巡检单与明细的矛盾

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 展厅项目经理 | 直接使用 | 创建项目、录入灯位、修改点位、查看历史、导出巡检单 |

### 2.2 功能模块

1. **项目总览页**：项目列表、各项目校准状态统计、异常灯位快速跳转
2. **灯位校准详情页**：灯位表格（含状态标签）、变更历史时间线、异常解释面板
3. **巡检单导出页**：导出前复核清单、一致性校验结果、一键导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 项目总览页 | 项目卡片列表 | 展示项目名称、灯位总数、已校准/未校准/异常数量、最近修改时间 |
| 项目总览页 | 全局状态栏 | 汇总所有项目的待处理异常数、未补齐材料数 |
| 灯位校准详情页 | 灯位表格 | 每行一个灯位，显示编号、位置、状态标签（已校准/待补材料/已改结论/异常）、来源标记（讲解路线/设备备注/CAD手工改动） |
| 灯位校准详情页 | 变更历史时间线 | 按时间倒序展示每次变更，区分变更类型（补材料/改结论），展示前后值对比 |
| 灯位校准详情页 | 异常解释面板 | 点击异常灯位弹出，解释异常原因（如讲解路线早到但设备备注晚补、CAD点位手工改与原设计冲突等） |
| 灯位校准详情页 | 讲解路线样例 | 展示讲解路线中的灯位顺序，标记哪些是早到的（尚未有设备备注对应） |
| 灯位校准详情页 | 模型重复检测 | 列出同一位置被多次放置灯位的清单，供项目经理确认 |
| 巡检单导出页 | 复核清单 | 导出前逐项检查：是否有未补齐材料、是否有未确认的异常、CAD改动是否已同步到明细 |
| 巡检单导出页 | 一致性校验 | 自动比对巡检单数据与明细数据，标记不一致项 |
| 巡检单导出页 | 导出按钮 | 通过一致性校验后可导出，否则提示需先处理的不一致项 |

## 3. 核心流程

项目经理打开工具 → 选择项目 → 查看灯位校准详情 → 识别异常灯位（补材料 vs 改结论） → 手动修改CAD点位时系统自动记录前后变化 → 查看变更历史确认状态 → 导出巡检单前复核 → 通过一致性校验 → 导出

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰 #1a1a2e + 钢蓝 #16213e，强调色：琥珀 #f0a500（异常）、翠绿 #4ecca3（正常）
- 按钮风格：扁平圆角，状态色按钮（正常=绿、待补=琥珀、异常=红）
- 字体：JetBrains Mono（数据）+ Noto Sans SC（界面文字）
- 布局风格：左侧导航 + 右侧主内容区，表格为主，紧凑排列
- 图标风格：Lucide 线性图标，与数据密集场景匹配

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 项目总览页 | 项目卡片列表 | 卡片网格布局，每卡片含状态色条、项目名、3个状态计数器 |
| 项目总览页 | 全局状态栏 | 顶部固定栏，3个徽章：待处理异常/未补材料/今日改动 |
| 灯位校准详情页 | 灯位表格 | 紧凑表格，每行含状态标签、来源标记、最后修改时间，可展开行内详情 |
| 灯位校准详情页 | 变更历史时间线 | 右侧面板，时间线+diff视图，补材料用灰色标记，改结论用琥珀标记 |
| 灯位校准详情页 | 异常解释面板 | 底部滑出面板，异常灯位列表+原因说明+建议操作 |
| 灯位校准详情页 | 讲解路线样例 | 侧边折叠面板，展示路线灯位序列，早到标记黄色 |
| 灯位校准详情页 | 模型重复检测 | 顶部警告横幅+折叠列表，重复灯位高亮 |
| 巡检单导出页 | 复核清单 | 检查项列表，每项含勾选框和状态标记 |
| 巡检单导出页 | 一致性校验 | 校验结果表格，不一致项红色高亮 |
| 巡检单导出页 | 导出按钮 | 大号状态按钮，通过=绿色可点击，未通过=灰色禁用 |

### 4.3 响应式

桌面优先设计，最小支持 1280px 宽度。平板端折叠侧边栏，手机端暂不支持（展厅项目经理主要在办公电脑使用）。

### 4.4 3D场景

不适用，本工具为数据管理型应用。
