## 1. 产品概述

为琴房前台小温及团队打造的音频素材情绪标签复核工具，解决音频文件名与曲目表不匹配、人工标注易丢失、导出筛选结果不一致等实际工作痛点。支持曲目表、音频文件、合同截图、群聊批注等多源材料整合，完整覆盖从样例导入到结果导出的全流程。

- **核心问题**: 人工复核效率低、备注易丢失、异常情况不醒目
- **目标用户**: 琴房前台、音频编辑、项目负责人
- **产品价值**: 让复核工作"有迹可循、有据可依、有档可查"

## 2. 核心功能

### 2.1 用户角色
| 角色 | 核心权限 |
|------|----------|
| 复核人员 | 导入材料、标注情绪标签、填写备注、导出结果 |
| 查看人员 | 查看复核结果、筛选搜索 |

### 2.2 功能模块
1. **素材导入页**: 支持曲目表上传、音频文件匹配、合同截图关联、群聊批注录入
2. **复核工作台**: 素材列表、情绪标签标注、备注编辑、筛选搜索
3. **例外面板**: 授权过期、时码错位、重复曲目的醒目展示和处理
4. **报告生成**: 一键导出当前筛选结果、生成复核报告、数据持久化

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 复核工作台 | 顶部导航 | 导入、导出、报告生成快捷入口 |
| 复核工作台 | 筛选区域 | 按情绪标签、状态、来源、时间范围筛选 |
| 复核工作台 | 素材列表 | 展示文件名、曲目名称、情绪标签、备注、来源、处理时间 |
| 复核工作台 | 编辑面板 | 点击行内编辑情绪标签和备注，实时保存不丢失 |
| 复核工作台 | 例外悬浮面板 | 右侧常驻显示三类异常素材，可点击快速定位 |
| 素材导入 | 多源导入 | 支持曲目表（CSV/Excel）、音频文件清单、截图上传、文本批注 |
| 报告页 | 汇总统计 | 复核进度、异常统计、情绪标签分布 |
| 报告页 | 明细导出 | 按当前筛选条件导出Excel清单，报告与明细口径一致 |

## 3. 核心流程

```mermaid
flowchart LR
    A["开始复核"] --> B["导入多源材料"]
    B --> C["自动匹配音频与曲目"]
    C --> D["检测异常情况"]
    D --> E["例外面板高亮展示"]
    E --> F["人工标注情绪标签"]
    F --> G["填写处理备注"]
    G --> H["实时本地保存"]
    H --> I["筛选查看结果"]
    I --> J["导出当前清单"]
    J --> K["生成复核报告"]
    K --> L["完成/下次继续"]
    
    style D fill:#ff6b6b,stroke:#ff0000
    style E fill:#ffd93d,stroke:#ffa500
```

**流程说明**:
1. 琴房前台小温导入曲目表、音频文件清单、合同截图和群聊批注
2. 系统自动尝试匹配音频文件名与曲目表，不匹配的标黄提示
3. 自动检测授权过期（日期比对）、时码错位（时间格式校验）、重复曲目（名称查重）
4. 例外素材在右侧面板常驻展示，不会被淹没在正常素材中
5. 人工修改情绪标签或备注时，实时保存到本地存储，刷新页面不丢失
6. 每条记录保留原始来源和处理时间，可追溯
7. 导出功能严格按照当前筛选条件，确保"看到什么导出什么"
8. 复核报告与明细数据完全一致，不会出现两套说法

## 4. 用户界面设计

### 4.1 设计风格
- **设计基调**: 专业办公风，干净利落，重点突出
- **主色调**: 深蓝色系 (#1e3a5f) - 代表专业和信任
- **强调色**: 暖橙色 (#ff8c42) - 用于操作按钮和重点提示
- **异常色**: 
  - 红色 (#ff6b6b) - 授权过期（严重）
  - 橙色 (#ffd93d) - 时码错位（警告）
  - 紫色 (#a855f7) - 重复曲目（注意）
- **按钮风格**: 圆角矩形，轻微阴影，hover时上浮效果
- **字体**: 思源黑体 / PingFang SC，清晰易读
- **布局风格**: 左侧主内容 + 右侧例外面板的双栏布局
- **图标风格**: Linear 线性图标，简洁现代

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 设计要点 |
|-----------|-------------|-------------|
| 复核工作台 | 顶部导航栏 | 深蓝色背景，白色文字，左侧logo+标题，右侧操作按钮组 |
| 复核工作台 | 筛选栏 | 浅色背景卡片，标签式筛选，下拉选择，日期区间 |
| 复核工作台 | 素材列表 | 斑马纹表格，行悬停高亮，异常行背景色标注，内联编辑 |
| 复核工作台 | 例外面板 | 浅灰色背景，三类异常分组展示，数字徽章，点击跳转 |
| 复核工作台 | 编辑弹窗 | 居中模态框，情绪标签用色块选择，备注多行文本，来源信息只读展示 |
| 导入页 | 上传区域 | 拖拽上传区域，分步骤引导，实时进度反馈 |
| 报告页 | 统计卡片 | 彩色数据卡片，网格布局，进度条可视化 |

### 4.3 响应式
- 桌面端优先（1280px+）：双栏布局，例外面板常驻右侧
- 平板端（768px-1279px）：例外面板可折叠收起
- 移动端（<768px）：单栏布局，例外面板改为底部抽屉

### 4.4 交互细节
- 行内编辑：点击单元格直接进入编辑状态，失焦自动保存
- 实时提示：保存成功/失败显示Toast提示，不打断操作
- 异常提醒：新检测到的异常有轻微动画吸引注意
- 筛选联动：修改筛选条件后列表实时刷新，导出按钮同步显示数量
