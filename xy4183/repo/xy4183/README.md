# 雪道隐患巡检沙盘

❄️ 滑雪场巡检员专用的本地 3D 交互工具，用于雪道隐患巡检、风险评估和路线规划。

## 功能特性

### 🌐 三维场景渲染
- 基于 Three.js 的高性能 3D 地形渲染
- 支持鼠标旋转、缩放、平移操作
- 实时光照和阴影效果
- 地形高程网格可视化

### 📊 风险着色系统
**五种风险着色模式：**

| 模式 | 说明 |
|------|------|
| 坡度风险 | 按坡度角度着色（绿色安全→红色危险） |
| 结冰风险 | 综合汇流量、坡向、坡度计算 |
| 客流风险 | 基于人流密度和设施分布 |
| 海拔高度 | 按海拔高度分层着色 |
| 综合风险 | 加权综合上述所有因素 |

### 🎯 隐患标注功能
- 点击雪道任意位置添加隐患
- 支持五种隐患类型：结冰、坑洼、岩石、杂物、其他
- 四级严重程度：低风险、中风险、高风险、严重风险
- 可添加描述、处理建议和状态追踪

### 🛤️ 路线规划功能
- 交互式点击添加巡检点
- 路线可视化（虚线连接）
- 自动计算总距离和预估时间
- 路线优化算法（按距离排序）

### 💾 数据管理
- 本地存储项目数据（localStorage）
- 保存/加载多个项目
- 导出 Markdown 格式巡检报告
- 导出 JSON 格式标注数据包
- 导入外部 CSV/GeoJSON 数据

1. 运行 `npm install` 安装依赖

   - 严重风险：1

1. **旋转**：按住鼠标左键拖动场景
2. **平移**：按住鼠标中键或右键拖动
3. **缩放**：使用鼠标滚轮
4. 确认地形可自由操作

### 第四步：测试风险着色
1. 点击左侧 **"风险着色"** 区域的按钮
2. 依次测试所有模式：
   - 坡度风险 → 确认颜色变化
   - 结冰风险 → 确认颜色变化
   - 客流风险 → 确认颜色变化
   - 海拔高度 → 确认颜色变化
   - 综合风险 → 确认颜色变化
3. 确认图例区域同步更新

### 第五步：测试隐患标注
1. 点击左侧 **"标注隐患"** 模式按钮
2. 在 3D 雪道上点击任意位置
3. 确认弹出隐患标注窗口
4. 填写表单：
   - 类型：选择「结冰」
   - 严重程度：选择「高风险」
   - 影响范围：保持默认 5 米
   - 描述：输入「测试标注」
5. 点击 **"保存标注"**
6. 确认：
   - 雪道上出现红色/橙色标记
   - 右侧隐患列表新增一条记录
   - 左侧统计面板数字更新

### 第六步：测试路线规划
1. 点击左侧 **"规划路线"** 模式按钮
2. 在雪道上依次点击 3-4 个位置
3. 确认：
   - 每次点击都添加蓝色航点标记
   - 航点间用蓝色虚线连接
   - 右侧路线列表显示所有点位
   - 左侧统计面板显示：
     - 路线点：N
     - 预估距离：显示具体数值

1. 确保至少有 3 个路线点
2. 点击右侧路线面板底部的 **"优化路线"** 按钮
3. 确认提示消息显示「路线已优化」

### 第八步：测试数据导出
1. **导出巡检报告**：
   - 点击顶部 **"导出巡检报告"** 按钮
   - 确认下载 Markdown 文件
   - 打开文件检查内容是否完整

2. **导出 JSON 标注**：
   - 点击顶部 **"导出标注 JSON"** 按钮
   - 确认下载 JSON 文件
   - 检查文件格式是否正确

### 第九步：测试项目保存/加载
1. **保存项目**：
   - 点击顶部 **"保存项目"** 按钮
   - 在弹窗中输入项目名称
   - 确认提示消息显示保存成功

2. **加载项目**：
   - 点击顶部 **"加载项目"** 按钮
   - 在列表中选择刚才保存的项目

## 数据格式说明

### 高程网格 CSV
```csv
x,y,elevation,slope,aspect,flowAccumulation
0,0,1800,5,180,10
5,0,1802,6,175,15
...
```
- **x, y**: 平面坐标（米）
- **elevation**: 海拔高度（米）
- **slope**: 坡度（度）
- **aspect**: 坡向（度，0°=北向）
- **flowAccumulation**: 汇流量（用于结冰风险计算）

### 设施 GeoJSON
```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "properties": {
        "id": "cable_001",
        "name": "主缆车线",
        "type": "cableCar"
      },
      "geometry": {
        "type": "LineString",
        "coordinates": [[x, y, z], [x, y, z]]
      }
    }
  ]
}
```
**设施类型**：
- `cableCar`: 缆车线路
- `guardrail`: 护栏

### 隐患记录 JSON
```json
[
  {
    "id": "hazard_001",
    "type": "ice",
    "location": { "x": 10, "y": 20, "z": 1800 },
    "severity": "high",
    "description": "结冰区域",
    "radius": 8,
    "photos": ["photo_001"],
    "notes": "需要撒盐处理",
    "timestamp": "2024-01-15T08:30:00Z",
    "status": "pending"
  }
]
```
**隐患类型**：
- `ice`: 结冰
- `pit`: 坑洼
- `rock`: 岩石
- `debris`: 杂物
- `other`: 其他

**严重程度**：
- `low`: 低风险
- `medium`: 中风险
- `high`: 高风险
- `critical`: 严重风险

**状态**：
- `pending`: 待处理
- `in_progress`: 处理中
- `resolved`: 已解决

## 风险计算模型

### 坡度风险
```
阈值：
- 0-15°: 低风险（绿色）
- 15-25°: 中风险（黄色）
- 25-35°: 高风险（橙色）
- >35°: 严重风险（红色）
```

### 结冰风险
综合考虑三个因素：
1. **汇流量** (flowAccumulation): 高流量区域更容易积水结冰
2. **坡向** (aspect): 北向坡（0°）日照少，更容易结冰
3. **坡度** (slope): 陡坡结冰更危险

权重分配：
- 汇流量：40%
- 坡向：20%
- 坡度：20%

### 客流风险
- 基础密度：0.03（正常客流）
- 设施吸引区：缆车出口、起点等区域客流密度高
- 陡坡区域：高坡度+高客流 = 更高风险

### 综合风险
```
综合评分 = 坡度风险×0.5 + 结冰风险×0.3 + 客流风险×0.2
```

## 开发说明

### 模块架构
```
main.js (主程序)
    │
    ├── dataParser.js      → 数据解析（CSV, GeoJSON）
    ├── scene.js           → 3D 场景管理
    ├── riskCalculator.js  → 风险计算与着色
    ├── interactionState.js → 交互状态管理
    └── storageExporter.js → 存储与导出
```

### 添加新的风险着色模式
1. 在 `riskCalculator.js` 的 `colorMaps` 添加新配色
2. 在 `getColorForPoint()` 添加新的计算逻辑
3. 在 `getRiskLegend()` 添加新图例
4. 在 `index.html` 添加对应的按钮

### 扩展隐患类型
1. 在 `index.html` 的隐患类型下拉框添加选项
2. 在 `storageExporter.js` 的导出逻辑更新类型列表
3. 在 `riskCalculator.js` 可考虑添加针对该类型的风险评估
