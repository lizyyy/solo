# PII 扫描测试数据

本目录包含用于测试 PII 扫描器的各种样例数据。

## 目录结构

### 1. clean/ (干净文件)
不包含任何真实 PII 数据的文件，用于验证扫描器能正确识别安全文件。

### 2. real-pii/ (真实 PII)
包含各种类型的真实 PII 数据：
- 手机号
- 电子邮箱
- 身份证号
- 银行卡号
- 地址片段
- 真实姓名

### 3. redacted/ (脱敏数据)
包含已脱敏处理的数据，应该被标记为低风险且可接受：
- `138****5678` 形式的脱敏手机号
- `user@example.com` 测试邮箱
- `*` 符号脱敏的数据

### 4. false-positive/ (误报测试)
包含可能被误识别为 PII 的数据：
- 订单号、追踪号等长数字串
- 测试邮箱、示例数据
- 测试环境相关的文本

## 扫描结果预期

| 目录 | 结果 | 说明 |
|------|------|------|
| clean/ | ✅ 无问题 | 干净文件 |
| real-pii/ | ❌ 高风险 | 需要清理真实 PII |
| redacted/ | ✅ 可接受 | 已脱敏数据 |
| false-positive/ | ⚠️ 部分匹配 | 可能有少量误报，需使用 ignore 标记 |
