# 薄膜干涉颜色计算 - 快速上手指南

## 5分钟跑通

### 1. 安装依赖
```bash
pnpm install
```

### 2. 启动开发服务器
```bash
pnpm run dev
```

```bash
pnpm run build
```

```bash
pnpm run preview
```

## 参数物理意义

- **薄膜厚度 (d)**: 薄膜的物理厚度，单位nm
- **折射率 (n)**: 光在真空中速度与在介质中速度的比值
- **入射角 (θ)**: 入射光线与法线的夹角
- **光程差**: 两束反射光之间的光程差，决定干涉条件
- **干涉级次**: 光程差与波长的比值
- **主波长**: 反射光谱中占主导地位的波长

## 常见问题

**Q: 为什么有些参数会显示警告？**
A: 系统会检查参数的物理合理性。红色警告表示参数超出物理合理范围，会显著影响计算结果。

**Q: 为什么颜色看起来不对？**
A: 检查波长范围是否覆盖可见光(380-780nm)，以及是否发生全反射。

**Q: 如何复现之前的计算结果？**
A: 导出的JSON文件包含完整参数和引擎版本号，使用相同版本的引擎即可复现。
