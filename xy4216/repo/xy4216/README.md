# 3D叉车盲区复盘器

一款用于工厂安全员复盘差点碰撞事故的本地3D可视化工具。

## 功能特性

### 📊 数据导入与校验
- **叉车轨迹CSV导入** - 支持标准CSV格式的叉车定位数据
- **行人定位JSON导入** - 支持多种JSON格式的行人定位数据
- **仓库货架平面图导入** - 支持自定义仓库布局配置
- **数据校验** - 自动检测以下问题：
  - 时间错位（叉车与行人数据时间范围不重叠）
  - 坐标越界（坐标超出仓库边界）
  - 缺失帧（时间间隔超过阈值）
  - 重复设备号（同一数据集包含多个设备ID）

### 🎮 3D场景回放
- **叉车模型** - 带驾驶室、叉臂、车轮和头灯的详细3D模型
- **行人模型** - 穿戴安全背心和安全帽的人员模型
- **货架系统** - 支持多层货架、立柱和障碍物
- **轨迹可视化** - 叉车和行人的历史轨迹线
- **危险距离圈** - 实时显示风险区域（红色危险区/黄色预警区）

### ⏯️ 播放控制
- **播放/暂停** - 标准播放控制
- **倍速播放** - 支持0.25x、0.5x、1x、2x、4x倍速
- **时间轴拖动** - 快速跳转到任意时间点
- **帧步进** - 上一帧/下一帧精确控制
- **快速定位** - 跳转到开始/结束位置

### 📐 视角切换
- **俯视图** - 从正上方查看整个仓库
- **侧视图** - 从侧面查看场景
- **前视图** - 从前方查看场景
- **自由视角** - 支持鼠标拖拽旋转、滚轮缩放

### 🔍 风险分析
- **自动风险检测** - 基于距离阈值自动识别风险时段
- **风险等级** - 高危（<1.5m）、中危（1.5-3m）
- **风险点列表** - 按时间顺序展示所有风险点
- **点击跳转** - 点击风险点自动跳转到对应时间
- **详情面板** - 显示风险点的详细信息（时间、距离、位置等）

### 📤 导出功能
- **Markdown复盘报告** - 生成完整的事故复盘报告，包含：
  - 基本信息（日期、数据统计）
  - 数据校验结果
  - 风险点分析（按等级分类）
  - 安全建议
- **JSON风险清单** - 导出结构化的风险点数据，便于进一步分析

## 数据格式说明

### 1. 叉车轨迹数据 (CSV)

**必需字段：**
| 字段名 | 说明 | 示例 |
|--------|------|------|
| id | 记录ID | 0 |
| device_id | 设备ID | forklift_1 |
| timestamp | 时间戳（秒或ISO格式） | 0.00 或 2024-01-01T00:00:00Z |
| x | X坐标 | 5.0 |
| y | Y坐标（高度） | 0.0 |
| z | Z坐标 | 10.0 |
| heading | 朝向角（弧度） | 0.0 |
| speed | 速度（m/s） | 2.0 |

**示例：**
```csv
id,device_id,timestamp,x,y,z,heading,speed
0,forklift_1,0.00,5.0,0,10.0,0.0,2.0
1,forklift_1,0.10,5.3,0,10.0,0.0,2.0
2,forklift_1,0.20,5.6,0,10.0,0.0,2.0
```

### 2. 行人定位数据 (JSON)

支持多种格式：

**格式1 - 数组格式：**
```json
[
  {
    "id": 0,
    "device_id": "pedestrian_1",
    "timestamp": 0.00,
    "x": 18.0,
    "y": 0.0,
    "z": 5.0
  },
  {
    "id": 1,
    "device_id": "pedestrian_1",
    "timestamp": 0.10,
    "x": 18.0,
    "y": 0.0,
    "z": 5.25
  }
]
```

**格式2 - 包装格式：**
```json
{
  "data": [
    { "id": 0, "timestamp": 0.00, "x": 18.0, "y": 0, "z": 5.0 }
  ]
}
```

## 使用指南

### 1. 加载数据

有两种方式加载数据：

**方式1：使用示例数据**
- 点击顶部导航栏的"加载示例数据"按钮
- 系统将自动加载预设的差点碰撞场景数据

**方式2：导入自定义数据**
1. 在左侧面板依次导入三个数据文件：
   - 叉车轨迹CSV
   - 行人定位JSON
   - 仓库货架平面图（可选）
2. 点击"校验数据"按钮进行数据校验
3. 查看校验结果，确保数据无误

### 2. 查看回放

数据校验通过后：
- 点击播放按钮开始回放
- 使用时间轴快速跳转
- 调整倍速控制播放速度
- 使用视角按钮切换不同视角

### 3. 分析风险点

- 在左侧"风险点列表"中查看所有检测到的风险
- 点击某个风险点，场景将自动跳转到该时间点
- 在右侧面板查看风险点的详细信息

### 4. 导出报告

- 点击"导出Markdown复盘"生成完整的复盘报告
- 点击"导出JSON风险清单"导出结构化数据

## 配置选项

### 风险距离阈值

在 `src/modules/ruleChecker.js` 中可调整：

```javascript
const ruleChecker = new RuleChecker({
  maxTimeGap: 2.0,           // 最大允许时间间隙（秒）
  minOverlapSeconds: 1.0,     // 最小时间重叠要求（秒）
  riskDistanceThreshold: 3.0, // 风险距离阈值（米）
  dangerDistanceThreshold: 1.5 // 危险距离阈值（米）
});
```

## 常见问题

**Q: 数据校验不通过怎么办？**
- 检查时间戳格式是否正确
- 确认坐标范围在仓库尺寸内
- 查看校验结果中的详细错误信息

**Q: 3D场景显示异常？**
- 检查浏览器是否支持WebGL
- 尝试刷新页面
- 确认数据格式正确

**Q: 如何创建自定义示例数据？**
- 参考 `src/modules/sampleData.js` 中的数据生成逻辑
- 确保时间戳、坐标等字段格式正确
