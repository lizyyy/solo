## 1. 产品概述

衍生品确认书差异标注系统，用于基金会计在衍生品确认书与税费率备注之间进行差异比对、冲突裁决和复盘追踪。核心解决三个问题：同一业务号拆分为手续费/本金两行时的识别与复核、除权日截图与税费率备注冲突时的人工裁决、以及从税费率备注补录旧口径数据的完整留痕。

- 目标用户：基金会计（如林姐）、结算主管（复核拆行记录）
- 核心价值：不把材料"洗成一行干净数据"，保留差异证据链，提供可复盘的记录和可重新跑的命令

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 基金会计 | 默认登录 | 导入确认书、补看税费率备注、确认/驳回冲突、查看差异清单 |
| 结算主管 | 默认登录 | 复核拆行记录（手续费+本金）、审核冲突裁决结果 |

### 2.2 功能模块

1. **工作台页面**：三步流程导航（导入除权日截图 → 补看税费率备注 → 差异清单更新）、当前批次状态、操作历史
2. **差异清单页面**：按业务号聚合的差异列表、三种处理结果标注（正常/拆行待复核/旧口径补录）、冲突证据展示
3. **复盘记录页面**：操作时间线、可重新跑的命令生成、历史比对记录查询

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 工作台 | 三步流程导航 | 展示"导入除权日截图→补看税费率备注→差异清单更新"三步进度，高亮当前步骤 |
| 工作台 | 批次状态卡片 | 显示当前批次编号、导入时间、记录数、差异条数、待处理冲突数 |
| 工作台 | 快捷操作区 | 一键导入、一键比对、生成复盘命令按钮 |
| 差异清单 | 差异列表 | 按业务号聚合，标注处理结果：🟢正常 / 🟡拆行待复核 / 🔵旧口径补录 |
| 差异清单 | 冲突裁决面板 | 除权日截图与税费率备注矛盾时，列出双方证据，基金会计选择确认或驳回 |
| 差异清单 | 拆行详情展开 | 同一业务号拆成手续费+本金时，展示拆分明细，标记"待结算主管复核" |
| 复盘记录 | 操作时间线 | 按时间排列所有操作记录（导入、补录、裁决、复核） |
| 复盘记录 | 命令生成器 | 生成可重新执行的比对命令（含参数），支持复制和一键重跑 |
| 复盘记录 | 历史记录查询 | 按批次号、日期范围、业务号搜索历史比对结果 |

## 3. 核心流程

### 3.1 主流程

基金会计导入除权日截图数据 → 系统自动比对确认书与已有记录 → 基金会计补看税费率备注 → 系统检测冲突（除权日截图 vs 税费率备注） → 基金会计裁决冲突（确认/驳回） → 差异清单更新 → 拆行记录流转至结算主管复核 → 生成复盘记录与可重跑命令

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深青蓝(#0F4C5C)代表严谨金融，辅以暖琥珀(#E36414)标注差异与冲突
- 按钮风格：圆角8px，主操作实心填充，次要操作描边
- 字体：数字/金额用等宽字体 JetBrains Mono，正文用 Noto Sans SC
- 布局：左侧固定导航栏 + 右侧内容区，卡片式模块布局
- 图标：使用 lucide-react 图标库，金融场景适配

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 工作台 | 三步流程导航 | 水平步骤条，当前步骤高亮，已完成步骤打勾，动画过渡 |
| 工作台 | 批次状态卡片 | 4列统计卡片（记录数/差异数/冲突数/待复核数），带微动画数字 |
| 工作台 | 快捷操作区 | 3个主操作按钮横排，带图标和描述文字 |
| 差异清单 | 差异列表 | 表格布局，每行前有状态色标，可展开查看明细 |
| 差异清单 | 冲突裁决面板 | 侧滑抽屉，左右分栏展示冲突证据，底部确认/驳回按钮 |
| 差异清单 | 拆行详情 | 行内展开面板，展示手续费+本金拆分，复核状态徽章 |
| 复盘记录 | 操作时间线 | 垂直时间线，节点带图标和颜色编码，支持筛选 |
| 复盘记录 | 命令生成器 | 代码块样式展示命令，一键复制按钮，参数可编辑 |
| 复盘记录 | 历史查询 | 顶部搜索栏+筛选条件，下方结果表格 |

### 4.3 响应式

- 桌面优先设计，最小宽度1280px
- 表格在窄屏时支持横向滚动
- 冲突裁决面板在小屏幕时改为全屏弹窗

### 4.4 样例数据要求

系统内置至少三条样例数据，覆盖三种处理结果：

1. **顺利记录**：业务号 DRV-2024-001，确认书数据与税费率备注完全一致，标记为🟢正常
2. **拆行记录**：业务号 DRV-2024-002，同一业务号拆成手续费行和本金行，标记为🟡拆行待复核，流转至结算主管
3. **旧口径补录**：业务号 DRV-2024-003，税费率备注中包含旧口径数据，需从备注补录，标记为🔵旧口径补录

## 5. 非功能需求

- 所有操作必须留痕，支持审计追溯
- 冲突裁决不可自动执行，必须人工确认
- 拆行记录不可自动归为正常，必须经结算主管复核
- 命令生成器输出的命令必须可在终端直接执行
- 页面加载时间 < 2秒
