状态流转规则

草稿 → 已提交SUBMIT 动作 (前台/经理)
草稿 → 已取消CANCEL 动作 (前台/经理)
已提交 → 审核中START_REVIEW 动作 (主管/经理)
已提交 → 已取消CANCEL 动作 (前台/经理)
审核中 → 已通过APPROVE 动作 (主管/经理)
审核中 → 已驳回REJECT 动作 (主管/经理)
已驳回 → 草稿RESUBMIT 动作 (前台/经理)
已通过 → 已执行EXECUTE 动作 (收银/经理)
已通过 → 已取消CANCEL 动作 (经理)

冲突检测规则

续住/退房重叠同一订单不能同时有续住和退房扣项
押金金额不足扣款金额不能超过剩余押金
明细计算错误明细总金额必须与扣款金额一致
重复提交检测同一订单不能同时存在同类型的有效扣项
