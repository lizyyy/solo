# 急诊分诊夜班

急诊室夜班模拟游戏，玩家需要在有限时间内将患者正确分诊到不同优先级的队列。

## 本地预览

### 方法一：直接打开
双击 `index.html` 文件在浏览器中打开即可游玩。

### 方法二：本地服务器
```bash
# Python 3
python -m http.server 8000

# 然后访问 http://localhost:8000
```

### 方法三：Node.js 服务器
```bash
npx serve .
```

## 游戏玩法

### 操作方式
- **拖拽**：将患者卡片拖拽到对应颜色的分诊队列
- **键盘快捷键**：数字键 1-4 快速分诊当前患者
  - `1` = 红区 (1级立即处理)
  - `2` = 黄区 (2级紧急)
  - `3` = 绿区 (3级非紧急)
  - `4` = 留观 (4级需观察)
- **撤销**：`Ctrl/Cmd + Z` 或点击撤销按钮

### 分诊规则
游戏采用 ESI (Emergency Severity Index) 分诊标准：

| 队列 | 等级 | 说明 | 等待时间 |
|------|------|------|----------|
| 🔴 红区 | 1级 | 立即危及生命 | 0分钟 |
| 🟡 黄区 | 2级 | 紧急 | 10-30分钟 |
| 🟢 绿区 | 3级 | 非紧急 | 1-2小时 |
| ⚪ 留观 | 4级 | 需观察 | 30分钟 |

### 评分系统
- 正确分诊：+100~150 分（根据病情严重程度）
- 错误分诊：-50 分
- 连击奖励：连续正确可获得 1.0x ~ 3.0x 倍率加成

### 边界情况处理
- **信息缺失**：部分患者数据不完整，采取保守分诊策略（提升优先级）
- **症状矛盾**：检测到矛盾症状时，使用最坏情况假设

## 关卡说明

### 第一关：夜班开始
5位患者，3分钟，包含常见急症病例。

### 第二关：信息缺失
患者部分数据缺失，需要根据现有信息判断。

### 第三关：症状矛盾
患者存在相互矛盾的症状，需仔细分析。
