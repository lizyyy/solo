## 1. 产品概述

音准趋势小报是面向合唱音乐老师的排练分析工具，将每次排练的音高偏差按声部、学生和小节结构化呈现，保留人工标注痕迹，智能识别特殊排练场景，最终生成可导出的分析报告。

- 核心价值：解决合唱排练中"偏差被平均值掩盖"、"人工标注流失"、"问题溯源难"三大痛点
- 目标用户：音乐老师、声部长、排练负责人

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 音乐老师 | 本地登录 | 录入数据、手动标注、复核偏差、导出报告 |
| 排练负责人 | 本地登录 | 查看小报、分类筛选、导出报告 |

### 2.2 功能模块

1. **主页面 - 音准趋势小报**：按时间线展示各排练批次的偏差热力图、趋势曲线、分类统计
2. **偏差详情弹窗**：点击偏差点查看完整溯源信息（录音批次、备注来源、历史记录）
3. **录音批次管理**：录入/编辑录音批次信息，关联声部长备注、选曲表变更记录
4. **数据录入面板**：按声部/学生/小节录入音高偏差，支持手动标注和异常标记
5. **报告导出**：生成带分类标签（持续跑偏/偶发失误/未复核）的可打印小报

|----------|----------|----------|

## 3. 核心流程

### 3.1 主流程
老师录入排练录音数据 → 系统自动识别异常情况（转调/换声部/缺拍）→ 异常数据标记并隔离不参与平均值计算 → 老师手动标注重点问题 → 生成音准趋势小报 → 按分类标记偏差 → 导出给负责人

```mermaid
flowchart LR
    A["录入录音批次"] --> B["录入音高偏差数据"]
    B --> C{"识别特殊情况?"}
    C -->|是| D["标记为异常，隔离计算"]
    C -->|否| E["正常统计计算"]
    D & E --> F["生成趋势热力图"]
    F --> G["老师手动标注复核"]
    G --> H["自动分类（持续/偶发/未复核）"]
    H --> I["导出小报给负责人"]
```

### 3.2 偏差溯源流程
点击偏差点 → 加载偏差详情 → 显示关联录音批次 → 展示备注原文 → 对比历史数据 → 标记复核状态

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深墨绿 `#1a3a3a` + 金色点缀 `#d4a855` + 米白背景 `#f5f1e8`，营造音乐厅的高雅质感
- **辅助色**：偏差严重 `#c0392b`、轻微偏差 `#e67e22`、正常 `#27ae60`、未复核 `#7f8c8d`
- **字体**：标题用「Noto Serif SC」衬线体，正文用「Noto Sans SC」无衬线体，数字用等宽字体
- **排版**：编辑小报风格，留白充足，用细实线和点状分隔线营造纸张质感
- **特殊效果**：轻微的纸张纹理背景、乐谱符号装饰元素、卡片悬停时有书卷展开的微动效

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主页面 | 趋势概览区 | 深色图表区，金色线条，渐变填充，带乐谱装饰符 |
| 主页面 | 偏差热力图 | 格子矩阵，颜色渐变，鼠标悬停显示气泡，点击有缩放动效 |
| 主页面 | 分类卡片 | 三色卡片（红/橙/灰），数字大号加粗，底部有小字说明 |
| 主页面 | 时间线 | 垂直时间线，圆点标记排练日期，当前批次金色高亮 |
| 偏差详情弹窗 | 溯源区 | 仿便利贴样式展示备注，录音批次用磁带造型卡片 |
| 偏差详情弹窗 | 异常标记 | 三角形警示图标，带文字说明"此数据不参与平均值计算" |
| 批次管理 | 侧边栏 | 从右侧滑入，半透明毛玻璃效果，列表项有轻微阴影 |

### 4.3 响应式
- 桌面端（默认）：三栏布局（时间线+主视图+侧边栏）
- 平板端：两栏布局，侧边栏改为底部抽屉
- 移动端：单列布局，热力图简化为列表形式

### 4.4 动效设计
- 页面加载：元素按顺序淡入，热力图格子逐个点亮
- 卡片悬停：轻微上浮 + 阴影加深
- 弹窗出现：从点击位置缩放展开
- 分类标记切换：数字有滚动计数动效
