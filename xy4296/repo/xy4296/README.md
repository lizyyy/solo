# 人工增雨作业放行盘

一款用于县级气象站人工增雨作业前安全复核的本地桌面GUI应用。

## 功能概述

本应用整合了雷达回波、空域批复、作业点位、弹药库存和人员资质等分散数据，通过规则引擎自动检查风险，并提供地图和时间轴可视化展示，支持人工复核、状态管理和多格式导出。

### 核心功能

1. **数据导入**
   - 支持CSV、JSON、YAML三种格式的数据导入
   - 自动识别数据类型（雷达数据、空域批复、作业点位、弹药库存、人员资质）
   - 数据导入时自动进行完整性和有效性验证

2. **风险检查**
   - **禁飞时段检查**：确认作业时间是否在有效空域批复范围内
   - **风向影响区检查**：分析风暴移动方向，判断是否可能影响作业点位
   - **弹药库存检查**：检查弹药批号、库存数量和有效期
   - **人员资质检查**：检查作业人员资质是否有效
   - **雷达威胁检查**：根据回波强度评估气象风险

3. **可视化展示**
   - **地图视图**：直观展示作业点位、雷达回波位置和移动方向
   - **时间轴**：展示空域批复时段、雷达数据时间点，辅助判断作业窗口
   - **风险列表**：按严重程度分级展示所有风险点

4. **状态管理**
   - 作业会话管理（新建、加载、保存、删除）
   - 复核状态标记（待复核、已复核）
   - 审批状态管理（已放行、已驳回）

5. **数据导出**
   - **Markdown放行单**：导出包含作业信息、风险评估、复核意见的正式放行单
   - **CSV风险清单**：导出结构化的风险列表，便于后续分析
   - **JSON审计包**：导出完整的审计数据，包含会话信息、风险详情和数据摘要

## 安装说明

### 环境要求

- Python 3.7 或更高版本
- 操作系统：Windows、macOS、Linux

### 安装步骤

1. **克隆或下载项目**

   ```bash
   cd /path/to/xy4296
   ```

2. **安装依赖**

   ```bash
   pip install -r requirements.txt
   ```

   依赖说明：
   - `pyyaml`：用于解析YAML格式数据
   - `pandas`：数据处理（可选，用于未来扩展）
   - `matplotlib`：图形绘制（可选，用于未来扩展）

   注意：`tkinter` 是Python标准库，无需额外安装。

## 使用说明

### 启动应用

```bash
python main.py
```

### 基本操作流程

1. **新建作业会话**
   - 启动应用后会自动创建一个新的作业会话
   - 或通过菜单：`文件` → `新建作业`

2. **导入数据**
   - 点击按钮：`导入数据`
   - 或通过菜单：`文件` → `导入数据`
   - 选择数据文件（支持CSV、JSON、YAML格式）
   - 可以多次导入不同类型的数据，系统会自动合并

3. **执行风险检查**
   - 点击按钮：`执行风险检查`
   - 或通过菜单：`操作` → `执行风险检查`
   - 系统会自动运行所有规则检查
   - 检查结果会显示在风险列表和地图、时间轴中

4. **查看和分析风险**
   - 左侧面板显示风险摘要和风险列表
   - 点击风险列表中的项可以查看详细信息
   - 右侧地图视图显示作业点位和雷达回波位置
   - 时间轴展示空域批复时段和雷达数据时间点

5. **复核和审批**
   - 通过菜单：`操作` → `标记复核完成`（输入复核备注）
   - 通过菜单：`操作` → `放行作业`（输入放行意见）
   - 通过菜单：`操作` → `驳回作业`（输入驳回原因）

6. **导出数据**
   - 通过菜单：`文件` → `导出放行单`（导出Markdown格式）
   - 通过菜单：`文件` → `导出风险清单`（导出CSV格式）
   - 通过菜单：`文件` → `导出审计包`（导出JSON格式）

7. **保存和加载会话**
   - 关闭应用时会提示是否保存当前会话
   - 通过菜单：`文件` → `打开历史作业` 可以加载之前保存的会话

### 数据格式说明

#### CSV格式

每个CSV文件对应一种数据类型，系统会根据文件名自动识别：

- 包含 `radar` 或 `雷达`：雷达回波数据
- 包含 `airspace` 或 `空域` 或 `批复`：空域批复数据
- 包含 `point` 或 `点位` 或 `作业点`：作业点位数据
- 包含 `ammunition` 或 `弹药` 或 `库存`：弹药库存数据
- 包含 `personnel` 或 `人员` 或 `资质`：人员资质数据

各数据类型的字段说明，请参考 `examples/` 目录下的示例文件。

#### JSON/YAML格式

JSON和YAML文件可以包含多种数据类型，使用以下键名：

- `radar_data`：雷达回波数据数组
- `airspace_approvals`：空域批复数据数组
- `operation_points`：作业点位数据数组
- `ammunition_inventory`：弹药库存数据数组
- `personnel_qualifications`：人员资质数据数组

示例请参考 `examples/all_data.json` 和 `examples/all_data.yaml`。

## 风险等级说明

| 等级 | 颜色 | 说明 | 建议 |
|------|------|------|------|
| 严重 | 红色 | 存在重大安全隐患 | 必须立即处理，禁止作业 |
| 高 | 橙色 | 存在重要风险 | 建议处理后再作业 |
| 中 | 黄色 | 存在中等风险 | 请注意监控 |
| 警告 | 绿色 | 提示信息 | 建议关注 |
| 低 | 深绿 | 轻微或无风险 | 可以正常作业 |

## 规则说明

### 禁飞时段检查

- **通过条件**：作业时间在至少一个有效空域批复的时间范围内
- **警告条件**：空域批复即将过期（剩余时间 < 30分钟）
- **失败条件**：当前时间不在任何有效空域批复范围内

### 风向影响区检查

- **触发条件**：雷达回波强度 ≥ 30dBZ，且移动方向朝向作业点位（±45度范围）
- **风险等级**：
  - 预计到达时间 < 30分钟：严重
  - 预计到达时间 30-60分钟：高
  - 预计到达时间 60-120分钟：中

### 弹药库存检查

- **严重风险**：弹药已过期
- **高风险**：库存数量为0，或状态异常
- **警告**：弹药即将过期（30天内）

### 人员资质检查

- **严重风险**：人员资质已过期
- **警告**：人员资质即将过期（90天内）

### 雷达威胁检查

根据回波强度评估：
- ≥ 50dBZ：严重风险（强回波）
- 40-50dBZ：高风险（较强回波）
- 30-40dBZ：中等风险（中等强度回波）
- < 30dBZ：低风险或无风险

## 注意事项

1. **数据安全**：所有数据存储在本地，不会上传到任何服务器
2. **会话存储**：会话数据保存在用户主目录下的 `.rainfall_operation/states` 文件夹中
3. **示例数据**：`examples/` 目录下的数据仅用于测试，请勿用于实际作业
4. **时间同步**：建议保持系统时间准确，以便正确计算有效期和作业窗口

## 故障排除

### 应用无法启动

- 检查Python版本是否为3.7或更高
- 检查是否已安装所有依赖：`pip install -r requirements.txt`

### 数据导入失败

- 检查文件格式是否正确（CSV/JSON/YAML）
- 检查文件编码是否为UTF-8
- 查看控制台输出的错误信息

### 风险检查未发现预期风险

- 检查数据时间戳是否正确
- 检查弹药有效期和人员资质有效期的日期格式
- 确认雷达回波强度和移动方向数据是否完整
