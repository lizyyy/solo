# 依赖管理命令行工具

## 启动方式

### 1. 安装依赖
```bash
npm install
```

### 2. 安装为全局命令（可选）
```bash
npm link
```

### 3. 查看帮助
```bash
# 如果已全局安装
depmgr --help

# 或者直接运行
node src/index.js --help
```

### 4. 快速体验
```bash
# 计算依赖启动顺序
node src/index.js start-order

# 加载演示证书数据
node src/index.js cert-issue --demo

# 执行回滚（会先生成候选清单）
node src/index.js rollback

# 查看历史记录
node src/index.js history

# 查看规则版本
node src/index.js rule-list

# 加载班车预约演示数据
node src/index.js bus-import

# 按原始行号查询班车预约
node src/index.js bus-query --line 1
```

## 样例来源

### 1. 依赖启动顺序样例
- 包含10个典型微服务的依赖关系
- 服务包括：数据库、Redis、配置中心、认证服务、API网关、用户服务、订单服务、支付服务、通知服务、Web应用
- 设计了合理的依赖层级关系

### 2. 离线证书签发样例
- 包含4张演示证书，分属2个批次
- 特意包含1条"回滚测试证书-NOEVIDENCE"记录，用于回滚失败演示
- 该记录无审批证据，回滚时会失败并单独保存

### 3. 班车预约样例
- 包含5条演示预约记录
- 每条记录都有原始行号，支持按行号追溯
- 部分记录包含人工备注字段，已入库保存

### 4. 规则版本样例
- v1.0: 初始版本，基础审批机制
- v1.1: 增加高风险自动复核，收紧审批权限
- v2.0: 支持批量签发，引入风险评分机制

## 主流程

### 1. 依赖启动顺序计算流程
```
输入服务列表
    ↓
构建依赖关系图
    ↓
检测循环依赖
    ↓
有循环 → 输出具体链路 → 结束
    ↓ 无循环
拓扑排序计算启动顺序
    ↓
输出启动顺序表格
    ↓
结束
```

### 2. 离线证书签发流程
```
输入签发参数
    ↓
生成证书记录（含批次ID、规则版本）
    ↓
保存到数据文件
    ↓
记录操作历史
    ↓
输出签发结果
    ↓
结束
```

### 3. 回滚操作流程
```
输入过滤条件（批次/类型）
    ↓
生成回滚候选清单
    ↓
显示清单（含风险评估、无证据标记）
    ↓
用户确认（命令行自动执行）
    ↓
逐条执行回滚
    ↓
成功 → 标记为已回滚
    ↓
失败 → 记录到失败项文件
    ↓
输出统计结果和失败详情
    ↓
记录操作历史
    ↓
结束
```

### 4. 历史查询流程
```
输入过滤条件（批次/操作者/风险类型）
    ↓
过滤历史记录
    ↓
输出记录列表
    ↓
提示失败项数量
    ↓
结束
```

### 5. 规则口径解释流程
```
输入批次ID
    ↓
查找该批次使用的规则版本
    ↓
输出规则详情（签发标准、回滚策略）
    ↓
对比上一版本输出变更点
    ↓
结束
```

### 6. 班车预约导入流程
```
输入CSV文件路径
    ↓
解析文件内容
    ↓
为每条记录分配原始行号
    ↓
保存人工备注字段
    ↓
输出导入结果
    ↓
结束
```

## 失败路径

### 1. 循环依赖失败
**触发条件**: 服务之间存在循环依赖关系
```
检测到 A → B → C → A 的循环
    ↓
输出具体链路: A → B → C → A
    ↓
终止计算，提示用户修复依赖关系
```

### 2. 回滚无证据失败
**触发条件**: 回滚的证书缺少审批证据
```
生成候选清单时标记"无证据"
    ↓
执行回滚时检测到无证据
    ↓
抛出错误: "无审批证据，无法回滚"
    ↓
该条记录写入失败项文件 (failed-items.json)
    ↓
继续处理其他记录
    ↓
最终统计: 成功N条，失败M条
    ↓
输出失败项详情表格
```

### 3. 规则版本不存在失败
**触发条件**: 查找的规则版本不存在
```
输入批次ID
    ↓
查找对应规则版本
    ↓
未找到匹配版本
    ↓
输出错误信息
    ↓
结束
```

### 4. 班车预约行号不存在失败
**触发条件**: 查询的原始行号无对应记录
```
输入行号
    ↓
查找记录
    ↓
未找到
    ↓
输出提示信息
    ↓
结束
```

### 5. 文件导入失败
**触发条件**: CSV文件不存在或格式错误
```
尝试读取文件
    ↓
文件不存在或解析失败
    ↓
捕获异常
    ↓
输出错误详情
    ↓
结束
```

## 数据文件说明

| 文件 | 说明 |
|------|------|
| data/certificates.json | 离线证书签发记录 |
| data/failed-items.json | 失败项单独保存，便于接手 |
| data/history.json | 操作历史记录 |
| data/bus-reservations.json | 班车预约记录 |
| data/rules.json | 规则版本定义 |

## 命令清单

| 命令 | 说明 | 参数 |
|------|------|------|
| `start-order` | 计算依赖启动顺序 | `--services` 指定服务列表 |
| `cert-issue` | 签发离线证书 | `--demo` 加载演示数据 |
| `rollback` | 执行回滚操作 | `--batch` 指定批次 |
| `history` | 查询历史记录 | `--batch` `--operator` `--risk` |
| `bus-import` | 导入班车预约 | `--file` CSV文件路径 |
| `bus-query` | 查询班车预约 | `--line` 原始行号 |
| `rule-list` | 列出规则版本 | 无 |
| `rule-explain` | 解释批次规则 | `--batch` 批次ID |
