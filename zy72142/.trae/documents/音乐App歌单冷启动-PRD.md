## 1. 产品概述

音乐App歌单冷启动管理工具，解决厂牌运营团队在歌单筹备过程中的版本混乱、信息分散问题。通过结构化的歌单曲目管理，支持异常检测、版本追踪、备注持久化和筛选导出，让交接工作清晰可追溯。

- **核心问题解决**：替代文件夹+聊天记录的混乱管理方式，消除半中文半英文命名困扰
- **目标用户**：厂牌运营人员（如小孟）、歌单编辑、内容审核团队
- **核心价值**：歌单数据可追溯、异常项清晰标注、交接零疑问

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 运营人员 | 本地访问（无需注册） | 导入歌单、标注异常、添加备注、导出清单 |

### 2.2 功能模块

1. **歌单列表页**：曲目总览、筛选过滤、异常统计、版本信息
2. **曲目详情区**：单条曲目信息、异常标记、备注编辑、来源追溯
3. **异常管理区**：授权过期/时码错位/重复曲目分类展示
4. **导出功能**：按当前筛选条件导出，包含异常原因和处理记录

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 歌单管理主页面 | 顶部信息栏 | 显示歌单名称、版本号、最后更新时间、原始来源 |
| 歌单管理主页面 | 筛选工具栏 | 按状态（正常/异常）、异常类型、曲目名称搜索 |
| 歌单管理主页面 | 曲目列表 | 表格展示所有曲目，异常行高亮，支持行内编辑备注 |
| 歌单管理主页面 | 异常分类面板 | 分三类展示异常曲目，点击可跳转定位 |
| 歌单管理主页面 | 导出面板 | 选择导出范围（全部/筛选结果），预览导出内容 |

## 3. 核心流程

用户打开页面 → 自动加载本地存储的歌单数据 → 浏览曲目列表 → 筛选或搜索 → 点击异常项查看详情 → 编辑备注或标记状态 → 筛选目标曲目 → 导出CSV（含异常原因、处理时间、原始来源）→ 数据自动保存到本地

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深墨绿（#1E3A3A）- 专业、稳重
- **辅助色**：珊瑚红（#E07A5F）- 异常警示；浅金（#F2CC8F）- 标记高亮
- **背景色**：米白（#F4F1DE）- 舒适不刺眼
- **按钮风格**：方角微圆（4px），实心填充，悬停有轻微上浮效果
- **字体**：标题用思源黑体（粗体），正文用系统等宽字体（便于对齐曲目信息）
- **布局风格**：左窄右宽分栏，左侧异常分类，右侧主列表，顶部固定工具栏
- **图标风格**：简约线性图标，异常项用实心图标突出

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 主页面 | 顶部信息栏 | 歌单标题、版本标签、时间戳、来源链接样式按钮 |
| 主页面 | 筛选工具栏 | 下拉筛选框、搜索输入框、重置按钮 |
| 主页面 | 异常分类面板 | 三类异常卡片，各带计数徽章，点击高亮 |
| 主页面 | 曲目列表 | 斑马纹表格，异常行红边，备注可编辑，操作按钮列 |
| 主页面 | 底部导出栏 | 固定底部，统计选中数，导出按钮带预览图标 |

### 4.3 响应式
- **桌面优先**：1200px以上完美展示，左右分栏布局
- **平板适配**：900-1200px 异常面板收为顶部标签页
- **移动端**：900px以下 单列滚动，筛选收为折叠面板

### 4.4 动效设计
- 页面加载：列表项渐入+轻微上移，按行延迟
- 异常标记：红色边框脉冲动画2次
- 备注保存：输入框边框闪绿色1秒
- 导出进度：按钮内进度条填充
