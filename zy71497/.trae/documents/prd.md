## 1. 产品概述

"儿童练琴奖励账本"是一款面向钢琴老师的本地 Web 管理工具，用于记录学生练琴打卡、发放星星奖励、处理请假与补练、以及家长备注。所有操作实时落盘，刷新和重启后数据不丢失，确保账目清晰可追溯。

- 解决钢琴老师手工记账易出错、请假补练规则混乱、奖励统计不透明的问题
- 目标用户：独立钢琴老师或小型琴行，管理 5-50 名学生的练琴奖励

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 钢琴老师 | 直接访问本地页面 | 管理学生、录入打卡、审批请假、配置奖励规则、导出数据 |

### 2.2 功能模块

1. **学生名册页**：学生列表、新增/编辑/归档学生、查看个人详情
2. **打卡记录页**：按日期录入练琴时长、批量打卡、家长备注、异常标记
3. **请假与补练页**：请假登记、补练申请与审批、重复补练检测
4. **奖励星榜页**：星星汇总排行、奖励规则配置、奖励发放历史
5. **数据导出页**：按月/学期导出 CSV、核对重启前后数字一致性

## 3. 核心流程

### 3.1 打卡归集流程

老师选择日期 → 逐个录入学生练琴时长 → 系统自动计算应得星星 → 老师确认提交 → 后端写入数据库 → 星星流水记录生成

### 3.2 请假与补练流程

老师登记请假 → 系统扣除对应星星并记录流水 → 老师登记补练（关联请假记录）→ 系统检测是否重复补练 → 补练通过后返还星星 → 两条流水（扣+返）分别留存

### 3.3 异常处理流程

录入时长超过阈值 → 前端标黄警告（"该时长超出常规范围，确认提交？"）→ 老师确认后正常提交 → 后端记录中标记"时长异常" → 星星照常计算，但流水备注标注

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：暖金色 (#F6A623) + 深靛蓝 (#1A2744)，金色代表星星/奖励，靛蓝代表专业/信赖
- **辅助色**：珊瑚红 (#FF6B6B) 用于警告/扣分，薄荷绿 (#4ECDC4) 用于补练返还/正向反馈
- **按钮风格**：圆角 8px，填充按钮用主色调，次要按钮用描边风格
- **字体**：标题用 ZCOOL XiaoWei（站酷小薇体）营造亲切手写感，正文用 Noto Sans SC 保证可读性
- **布局风格**：左侧导航栏 + 右侧内容区，卡片式布局，每条记录为独立卡片
- **图标**：星星用 ⭐ 实心图标，请假用 🏖️，补练用 🔄，警告用 ⚠️
- **动效**：星星发放时掉落动画，卡片进入时轻微上滑渐入

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 学生名册页 | 学生列表 | 卡片网格布局，每张卡片显示姓名、星星数、状态标签，顶部搜索栏 |
| 学生名册页 | 新增学生 | 居中弹窗表单，金色确认按钮 |

| 打卡记录页 | 批量确认 | 底部固定操作栏，金色"确认提交"按钮 |

### 4.3 响应式设计

- 桌面优先（1280px+）：左侧导航 + 右侧内容双栏布局
- 平板（768px-1279px）：导航折叠为顶部标签栏，内容区单列
- 手机（<768px）：底部标签导航，卡片单列堆叠，输入区全宽

## 5. 业务规则说明（供业务同事参考）

| 规则名称 | 说明 | 可配置项 |
|----------|------|----------|
| 打卡归集 | 每日练琴时长 × 每分钟星数 = 当日获得星星；确认后不可被前端静默修改 | 每分钟星数 |
| 请假扣分 | 请假当日扣除固定星星数，无论是否补练，扣分记录独立保留 | 请假扣星数 |
| 补练返还 | 补练通过后，按补练时长计算返还星星；一条请假只能补练一次 | 补练返还倍率 |
| 重复补练 | 同一请假记录若已有通过的补练，再次提交时系统拒绝并提示"该请假已补练" | — |
| 时长夸大 | 练琴时长超过阈值时标黄警告，但不阻止提交；后端记录中标记"时长异常" | 时长阈值（分钟） |
| 规则修改 | 修改奖励规则只影响后续记录，已生成的流水不再回算 | — |
