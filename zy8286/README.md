# 产品试用问卷开放反馈归因复盘台

一个用于分析产品试用问卷开放反馈的本地工具，帮助产品经理进行自动分类、聚类分析和人工复核。

## 功能特性

- 📊 **数据导入** - 支持导入 survey_responses.csv、taxonomy.yaml 和 releases.json
- 🔍 **文本清洗** - 自动清洗和预处理用户反馈文本
- 🏷️ **自动分类** - 基于关键词匹配将反馈分到功能/价格/性能/协作/上手成本等标签
- 🔗 **智能聚类** - 使用 KMeans 算法将相似反馈聚成簇
- 👁️ **可视化展示** - 前端查看每条分类理由、关键词、相似样本和簇代表句
- ✏️ **人工复核** - 支持人工改类、合并/拆分簇并保存复核痕迹
- ⚠️ **智能提示** - 空文本、多标签冲突、小簇有可读提示
- 📤 **数据导出** - 导出 review.md、classified.csv、clusters.json

## 快速开始

### 环境要求

- Python 3.8+
- pip 包管理器

### 安装步骤

1. 安装依赖：

```bash
pip install -r requirements.txt
```

### 启动服务

```bash
python app.py
```

然后在浏览器中访问：`http://localhost:5000`

## 使用指南

### 1. 数据导入

在「数据导入」标签页，你有两种方式导入数据：

#### 方式一：加载 Sample 数据

点击「📦 加载 Sample 数据」按钮，系统会自动加载内置的示例数据。

#### 方式二：手动导入

依次导入以下三个文件：

1. **survey_responses.csv** - 问卷反馈数据
2. **taxonomy.yaml** - 分类体系配置
3. **releases.json** - 版本信息（可选）

### 2. 执行处理

导入数据后，依次点击：

1. **🔍 执行自动分类** - 系统会根据分类体系自动为每条反馈打标签
2. **🔗 执行聚类分析** - 系统会将相似反馈聚集成簇

### 3. 查看反馈列表

切换到「反馈列表」标签页：

- 查看所有反馈的分类结果
- 按分类、簇、特殊状态筛选
- 查看每条反馈的：
  - 分类理由
  - 匹配关键词
  - 置信度
  - 相似样本
  - 簇信息

### 4. 人工复核

#### 修改分类

1. 点击「✏️ 复核分类」按钮
2. 选择新的分类
3. 添加复核备注（可选）
4. 点击「确认复核」

#### 合并簇

1. 切换到「聚类分析」标签页
2. 点击某个簇的「🔗 合并」按钮
3. 选择目标簇（其他簇将合并到此簇）
4. 选择要合并的源簇
5. 点击「确认合并」

#### 拆分簇

1. 在「聚类分析」标签页点击某个簇的「✂️ 拆分」按钮（需要簇大小 > 1）
2. 选择要拆分出的反馈（至少选择 1 条）
3. 点击「确认拆分」

### 5. 查看特殊提示

系统会自动提示以下特殊情况：

- 🟠 **空文本** - 红色边框和标签提示
- 🟡 **多标签冲突** - 黄色边框和标签提示，显示匹配的多个分类
- 🟠 **小簇** - 聚类分析页面显示警告提示（≤2条反馈的簇）

### 6. 数据导出

切换到「数据导出」标签页，可以导出三种文件：

1. **📄 导出 CSV** - 下载 `classified.csv`，包含：
   - 所有反馈数据
   - 自动分类结果
   - 人工复核信息
   - 关键词和分类理由

2. **🔗 导出 JSON** - 下载 `clusters.json`，包含：
   - 所有簇信息
   - 簇代表句
   - 簇关键词
   - 簇内所有反馈

3. **📊 导出 Markdown 报告** - 下载 `review.md`，包含：
   - 统计概览
   - 分类分布
   - 簇分析
   - 复核操作痕迹

## 数据格式说明

### survey_responses.csv

| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | 整数 | 反馈唯一标识 |
| feedback_text | 字符串 | 用户反馈文本（核心字段） |
| user_type | 字符串 | 用户类型（个人/团队/企业等） |
| version | 字符串 | 使用的版本号 |

示例：
```csv
id,feedback_text,user_type,version
1,这个产品的功能很丰富，但是操作流程有点复杂,个人用户,1.0.0
2,价格有点贵了，相比同类产品性价比不高,团队用户,1.0.0
```

### taxonomy.yaml

定义分类体系和关键词：

```yaml
categories:
  - id: functionality
    name: 功能体验
    keywords:
      - 功能
      - 操作
      - 界面
      - 设计
  - id: price
    name: 价格策略
    keywords:
      - 价格
      - 贵
      - 性价比
```

### releases.json

版本信息（可选）：

```json
[
  {
    "version": "1.0.0",
    "release_date": "2024-01-15",
    "status": "current",
    "features": ["新增团队协作功能"],
    "bug_fixes": ["修复同步问题"]
  }
]
```

## 内置分类体系

默认包含以下6个分类维度：

| 分类ID | 分类名称 | 说明 |
|--------|----------|------|
| functionality | 功能体验 | 功能、操作、流程、界面、设计相关 |
| price | 价格策略 | 价格、付费、会员、性价比相关 |
| performance | 性能表现 | 速度、卡顿、崩溃、稳定性相关 |
| collaboration | 协作能力 | 团队、分享、权限、同步相关 |
| onboarding | 上手成本 | 学习、教程、文档、新手相关 |
| other | 其他 | 未匹配到关键词的反馈 |
| empty | 空文本 | 文本为空的反馈 |

## API 接口

### 数据导入

- `POST /api/upload/survey` - 上传问卷数据
- `POST /api/upload/taxonomy` - 上传分类体系
- `POST /api/upload/releases` - 上传版本信息
- `POST /api/load-samples` - 加载示例数据

### 数据处理

- `POST /api/process/classify` - 执行自动分类
- `POST /api/process/cluster` - 执行聚类分析

### 数据查询

- `GET /api/data/responses` - 获取反馈列表
- `GET /api/data/response/<id>` - 获取单条反馈详情
- `GET /api/data/clusters` - 获取簇列表
- `GET /api/data/categories` - 获取分类列表

### 复核操作

- `POST /api/review/response/<id>` - 复核单条反馈
- `POST /api/review/cluster/merge` - 合并簇
- `POST /api/review/cluster/split` - 拆分簇

### 数据导出

- `GET /api/export/classified_csv` - 导出分类数据 CSV
- `GET /api/export/clusters_json` - 导出簇数据 JSON
- `GET /api/export/review_md` - 导出复盘报告 Markdown

## 使用示例

### 完整流程演示

1. 启动服务：
   ```bash
   python app.py
   ```

2. 打开浏览器访问 `http://localhost:5000`

3. 在「数据导入」页面：
   - 点击「📦 加载 Sample 数据」

## 注意事项

1. **文本处理**：系统使用 jieba 进行中文分词，确保反馈文本为中文
2. **聚类数量**：聚类数量默认为自动计算（反馈数/5，最多10个），也可手动指定
3. **小簇处理**：≤2条反馈的簇会被标记为小簇，建议手动合并
4. **多标签冲突**：一条反馈匹配多个分类关键词时会被标记为冲突，需人工复核
5. **数据持久化**：当前版本数据存储在内存中，重启服务后会丢失，导出的文件会永久保存在 output/ 目录
