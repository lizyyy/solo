# 隐患闭环管理系统

一个用于项目安全员内部使用的隐患巡检闭环管理工具。

## 功能特性

- **CSV 批量导入**: 支持批量导入隐患数据，自动区分正常和异常记录
- **全流程管理**: 登记 → 派发 → 整改 → 复查 → 归档
- **业务规则**:
  - 逾期自动升级（逾期3天内升级为较大，超过3天升级为重大）
  - 缺照片不能通过复查
  - 同位置重复隐患自动合并
- **幂等性保证**: 重复提交不会产生重复记录
- **批量操作**: 失败时明确说明成功和失败项，重试不破坏已成功记录

## 快速开始

### 1. 安装依赖并启动服务

```bash
chmod +x start.sh test_flow.sh
./start.sh
```

服务将在 `http://localhost:8000` 启动

### 2. 运行完整测试流程

新开一个终端窗口：

```bash
./test_flow.sh
```

### 3. 查看 API 文档

浏览器访问: `http://localhost:8000/docs`

## API 接口

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/hazards/import` | 批量导入 CSV 隐患 |
| POST | `/api/hazards/assign` | 派发隐患给整改人 |
| POST | `/api/hazards/rectify` | 提交整改 |
| POST | `/api/hazards/review` | 复查隐患 |
| GET | `/api/hazards` | 获取隐患列表 |
| GET | `/api/hazards/{id}` | 获取隐患详情 |

## CSV 文件格式

```csv
location,description,level,found_time,found_by,photos,deadline
A区1号楼,消防通道堵塞,一般,2026-05-01T09:00:00,安全员A,photo1.jpg,2026-05-05T17:00:00
```

## 数据模型

- **Hazard (隐患)**: 位置、描述、等级、发现时间、状态、截止时间等
- **Assignment (派发)**: 整改人、派发时间、派发人
- **Rectification (整改)**: 整改人、整改描述、整改照片
- **Review (复查)**: 复查人、复查结果、意见
- **ImportRecord (导入记录)**: 批量导入的审计记录

## 关键业务逻辑

1. **逾期检测**: 每次操作时自动检查是否逾期，逾期则自动升级隐患等级
2. **照片校验**: 复查通过时必须有整改照片，否则被拦截
3. **重复隐患合并**: 同位置同描述的未闭环隐患会被合并
4. **幂等性**: 相同内容的重复提交会被识别并返回已有记录
