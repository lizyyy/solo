# 直播打赏分成结算

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173/

## 样例数据放置

样例数据在 `samples/` 目录下，共 4 个文件：

| 文件名 | 说明 |
|--------|------|
| `payment_flows.json` | 收款流水 |
| `refund_requests.json` | 退款申请 |
| `approval_emails.json` | 审批邮件（含乱备注原文，不清洗） |
| `handwritten_notes.json` | 手写备注 |

每个文件是 JSON 数组，每条记录必须包含 `anchorId` 字段用于关联。

## 重跑数据

方式一：页面右上角点「重跑数据」按钮

方式二：调用 API
```bash
curl -X POST http://localhost:3001/api/settlements/reload
```

重跑会清空数据库并从 `samples/` 目录重新加载所有样例数据。

## 差异报告去哪看

1. **导出 CSV**：页面右上角点「导出CSV」，下载文件包含「变更历史摘要」列，格式：`字段:旧值→新值(原因);...`
2. **本地归档**：每次导出同时在 `reports/` 目录生成带时间戳的 CSV 文件，例如：
   ```
   reports/settlement-export-2026-05-31T14-36-36-677Z.csv
   ```
3. **详情页变更时间线**：点击任意记录进入详情页，底部「变更历史」展示完整的改判/回退轨迹，包括操作人、时间、原因。

## 上次怎么判的

- 每条记录的「变更」列标记是否有过操作
- 详情页「变更历史」时间线按时间倒序展示所有改判/回退操作，包含：
  - 变更字段（打赏总额/退款金额/分成比例/结算金额/状态）
  - 旧值 → 新值
  - 原因（必填）
  - 操作人、时间
- 审批邮件原文原样保留，不乱备注。

## 样例记录说明

| 主播ID | 类型 | 说明 |
|--------|------|------|
| A001 小鱼儿 | 顺利记录 | 所有依据齐全，金额匹配 |
| A002 大明星 | 旧口径记录 | 从审批邮件补来，分成比例从 60% 改 50%，有变更历史 |
| A003 老王直播 | 需确认 | 退款金额 > 打赏金额，异常待核实 |
| A004 阿花 | 空值记录 | 所有金额字段为空 |
| A005 飞飞 | 边界 + 重复 | 全额退款（退款=打赏）+ 两条流水完全相同疑似重复 |

## 技术栈

- 前端：React 18 + TypeScript + Tailwind CSS + Zustand
- 后端：Express 4 + TypeScript
- 数据库：SQLite（better-sqlite3）
- 数据文件：`data/settlement.db`
