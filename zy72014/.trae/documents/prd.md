## 1. 产品概述

直播打赏分成结算小工具——让结算会计把审批邮件里的收款流水、退款申请、审批备注和手写备注对得上，不再手工对第二遍。
- 目标用户：结算会计（阿宁），单人使用，强调可交接
- 核心价值：把分散在邮件附件和手写备注里的结算依据归拢、匹配、留痕，晚到附件不盖掉原判断，差异留在明面上

## 2. 核心功能

### 2.1 用户角色
| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 结算会计 | 本地启动后浏览器访问 | 查看列表、查看详情、改判、回退、导出 |

### 2.2 功能模块
1. **结算列表页**：展示所有结算记录，支持按状态筛选，高亮需人工确认项，空值和重复项明确标记
2. **结算详情页**：查看单条记录的完整依据链（收款流水、退款申请、审批邮件备注、手写备注），展示变更历史
3. **改判 / 回退**：改判时必须填写原因，旧判断和新判断都保留；回退将状态回到上一节点，变更留痕
4. **导出**：导出当前结算结果为 CSV，含状态、金额、判断依据、变更历史摘要

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 结算列表页 | 状态筛选栏 | 按"已匹配/需确认/已改判/已回退"筛选 |
| 结算列表页 | 记录表格 | 展示主播ID、打赏总额、分成比例、结算金额、状态、是否有变更历史 |
| 结算列表页 | 空值/重复标记 | 空值字段显示"未填写"红标，重复项显示"疑似重复"黄标 |
| 结算详情页 | 依据链面板 | 分区展示收款流水、退款申请、审批邮件备注（含乱备注原文）、手写备注 |
| 结算详情页 | 变更历史时间线 | 每次改判/回退记录：操作人、时间、旧值→新值、原因 |
| 结算详情页 | 改判操作区 | 填写新判断值 + 必填原因，提交后追加变更历史 |
| 结算详情页 | 回退操作区 | 填写回退原因，状态回退到上一节点，追加变更历史 |
| 结算列表页 | 导出按钮 | 导出 CSV，包含所有列表字段 + 变更历史摘要列 |

## 3. 核心流程

1. 启动后加载样例数据（收款流水、退款申请、审批邮件、手写备注）
2. 系统自动匹配：收款流水 ↔ 退款申请 ↔ 审批邮件 ↔ 手写备注
3. 匹配结果分为：已匹配（顺利）、需确认（金额对不上/缺少依据）、疑似重复、有空值
4. 会计查看列表，点进详情查看依据链
5. 如需改判：填写新判断 + 原因 → 旧判断保留 → 变更历史追加
6. 如需回退：填写原因 → 状态回退 → 变更历史追加
7. 确认后导出 CSV

## 4. 界面设计

### 4.1 设计风格
- 主色调：中性灰底（#f5f5f4），强调色用深蓝（#1e3a5f）和警告橙（#c2410c）
- 按钮风格：小圆角矩形，无阴影，朴素实用
- 字体：等宽字体展示金额和ID，无衬线字体展示正文
- 布局：顶部导航栏 + 主内容区，表格式列表，详情用卡片分区
- 图标：用 lucide-react 简约图标

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 结算列表页 | 状态筛选栏 | 水平标签组，选中态深蓝底白字 |
| 结算列表页 | 记录表格 | 条纹行表格，状态列用色块标签，空值红标，重复黄标 |
| 结算详情页 | 依据链面板 | 四个折叠卡片：收款流水/退款/审批邮件/手写备注，审批邮件保留原文 |
| 结算详情页 | 变更历史 | 竖向时间线，每条显示旧值→新值箭头 |
| 结算详情页 | 改判/回退 | 底部固定操作栏，输入框 + 必填原因文本区 |

### 4.3 响应式
- 桌面优先，最小宽度 1024px
- 列表页表格横向可滚动
- 详情页卡片自适应宽度

## 5. 样例数据要求

| 样例类型 | 描述 |
|----------|------|
| 顺利记录 | 收款流水、退款、审批邮件、手写备注齐全，金额匹配，状态"已匹配" |
| 需人工确认记录 | 退款金额与收款流水不匹配，或缺少某项依据，状态"需确认" |
| 旧口径记录 | 从审批邮件补充的早期口径数据，判断标准与当前不同，变更历史可见前后差异 |
| 空值记录 | 部分字段为空，系统标记"未填写" |
| 重复记录 | 两条收款流水号不同但金额、时间、主播完全相同，标记"疑似重复" |
| 边界记录 | 退款金额等于打赏金额（全额退款），需特殊标记 |
