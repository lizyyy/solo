# 数据脱敏规则试验台

一个面向数据工程师的全栈练习项目，用于测试和预览数据脱敏策略。

## 功能特性

### 核心功能
- **样例数据管理**：支持手动录入或批量上传（Excel/CSV）字段样例
- **脱敏策略预览**：支持6种脱敏策略实时预览
- **例外审批流程**：敏感字段需要审批才能通过脱敏
- **合规记录追踪**：完整记录所有脱敏操作，支持导出Excel

### 脱敏策略
1. **掩码替换**：用指定字符掩盖部分内容（如手机号：138****5678）
2. **完全替换**：用固定字符串替换全部内容（如：[REDACTED]）
3. **哈希处理**：对内容进行不可逆哈希处理
4. **截断处理**：截断过长的内容
5. **加密处理**：对内容进行可逆加密
6. **不处理**：保留原始内容

### 字段类型支持
- 手机号、邮箱、身份证号、姓名、地址、银行卡号、通用类型

## 技术栈

### 后端
- **框架**：FastAPI
- **语言**：Python 3.8+
- **数据处理**：pandas, openpyxl

### 前端
- **框架**：React 18
- **UI组件**：Ant Design 5
- **路由**：React Router 6
- **HTTP客户端**：axios

## 快速开始

### 方式一：分别启动后端和前端

#### 启动后端服务

```bash
cd backend
pip install -r requirements.txt
python main.py
```

后端服务将在 `http://localhost:8000` 启动

API文档：`http://localhost:8000/docs`

#### 启动前端服务

```bash
cd frontend
npm install
npm start
```

前端服务将在 `http://localhost:3000` 启动

## 使用说明

### 1. 样例数据管理
- 点击"新增样例"按钮录入字段信息
- 或通过"上传文件"批量导入Excel/CSV文件
- 在列表中可查看所有样例及其处理状态

### 2. 脱敏预览
- 在左侧输入原始值并选择脱敏策略
- 点击"预览脱敏效果"查看处理结果
- 下方提供各策略的详细说明

### 3. 例外审批
- 身份证、银行卡等敏感字段需要审批
- 在详情页点击"进行审批"按钮
- 选择"通过"或"拒绝"并填写原因
- 审批后自动生成合规记录

### 4. 合规记录
- 查看所有脱敏操作的完整记录
- 支持按字段名称搜索
- 支持导出Excel文件（含水印标记）

## 预置演示数据

系统启动时会自动创建以下演示数据：
- 手机号（成功脱敏）
- 身份证号（格式错误，演示脏数据）
- 邮箱（待审批状态）
- 银行卡号（待处理）
- 姓名（已审批通过）

## 核心概念

### 脏数据检测
系统会自动检测字段格式是否正确：
- 手机号：11位数字，1开头
- 邮箱：符合邮箱格式规范
- 身份证号：18位，校验码验证通过
- 银行卡号：16-19位数字

### 审批触发条件
以下字段类型默认需要人工审批：
- 身份证号（id_card）
- 银行卡号（bank_card）

### 水印标记
通过审批的记录会标记为"包含水印"，在导出时会特殊处理。

## 开发说明

### 后端开发
- 所有API接口在 `backend/api/` 目录下
- 脱敏逻辑在 `masking_engine.py` 中扩展
- 数据模型定义在 `models.py`

### 前端开发
- 页面组件在 `frontend/src/pages/` 目录下
- API调用封装在 `services/api.js`
- 使用Ant Design组件库
