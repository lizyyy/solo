📁 样例在哪

点右上角「导入船上记录本」，选样例文件：样例_船上记录本.csv

样例里包含：正常记录、异常记录、云遮挡记录、边界样本各若干

⚠️ 异常在哪

1. 左侧「统计概览」点异常数字

2. 地图上红点 = 异常，黄点 = 云遮挡，紫点 = 边界

3. 下方记录本筛选栏选「异常」

点异常记录可回溯：船上原始记录 + 本次计算口径

📤 结果怎么导出

点右上角「导出结果」，导出 CSV 包含全部标注和复核状态

🔁 重复导入

同一批数据重复导入不会翻倍，人工备注也不会被覆盖

判断依据：记录ID + 经纬度 + 观测时间

📍 经纬度写法

船上记录本的度分秒（如 30°15'30"N）自动转十进制度

对照表在左侧，保留原始写法可追溯
