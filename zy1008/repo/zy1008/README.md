# 线下分享会报名签到系统

一个简单易用的全栈 Web 应用，用于管理线下分享会的报名、候补和现场签到。

## 功能特性

### 管理员功能
- 📝 创建活动：设置标题、时间、总名额、签到码、可选场次
- 📊 数据统计：按场次查看报名、候补、已签到、未到场人数
- ✅ 现场签到：输入签到码后标记用户已到场
- ❌ 取消报名：取消后候补用户自动递补
- 📥 导出数据：支持 CSV 格式导出报名数据

### 参与者功能
- 📋 查看活动列表
- ✍️ 填写姓名、手机号后四位报名
- 🎯 选择场次（可选）
- ⏳ 名额满自动进入候补队列
- 🔄 取消报名后自动释放名额

## 技术栈

- **后端**: Node.js + Express
- **数据库**: SQLite (better-sqlite3)
- **前端**: 原生 HTML + CSS + JavaScript
- **持久化**: SQLite 文件存储（data/events.db）

## 安装步骤

### 环境要求
- Node.js 16.0 或更高版本
- npm 或 yarn 包管理器

### 安装依赖

```bash
# 进入项目目录
cd zy1008

# 安装依赖
npm install
```

## 启动服务

```bash
npm start
```

服务启动后，访问以下地址：

| 页面 | 地址 | 说明 |
|------|------|------|
| 参与者报名 | http://localhost:3000 | 供参与者报名使用 |
| 管理员后台 | http://localhost:3000/admin | 供管理员管理活动和签到使用 |

## 核心流程测试

### 1. 管理员创建活动

1. 打开浏览器访问 http://localhost:3000/admin
2. 点击「+ 创建新活动」按钮
3. 填写活动信息：
   - 活动标题：例如「2024春季技术分享会」
   - 活动时间：选择具体日期和时间
   - 总名额：例如「5」（方便测试候补功能）
   - 签到码：例如「123456」（现场签到使用）
   - 可选场次：例如输入「上午场」和「下午场」（每行一个，留空则不分场次）
4. 点击「创建活动」

### 2. 参与者报名测试

1. 打开新浏览器窗口（或无痕模式）访问 http://localhost:3000
2. 点击刚创建的活动卡片
3. 填写报名信息：
   - 姓名：「张三」
   - 手机号后四位：「1234」
   - 选择场次（如果有设置场次）
4. 点击「提交报名」
5. 应该看到「报名成功」提示

### 3. 测试候补功能

1. 继续用不同的姓名和手机号后四位报名，直到名额满
2. 当名额满后，新的报名应该显示「候补成功」，并显示候补排位

### 4. 管理员签到测试

1. 回到管理员页面 http://localhost:3000/admin
2. 点击活动的「查看详情」
3. 可以看到统计数据和报名列表
4. 找到某个报名用户，点击「签到」按钮
5. 在弹出框中输入签到码（例如「123456」）
6. 点击「确认签到」
7. 用户状态变为「已签到」

### 5. 测试取消报名与候补递补

1. 在管理员页面，找到一个已报名（未签到）的用户
2. 点击「取消」按钮
3. 确认取消
4. 刷新页面，查看候补列表
5. 原候补第一位的用户应该自动变为「已报名」状态

### 6. 测试 CSV 导出

1. 在活动详情页面
2. 点击「导出 CSV」按钮
3. 下载 CSV 文件，用 Excel 或表格软件打开
4. 确认包含所有报名和候补数据

### 7. 测试数据持久化

1. 停止服务器（Ctrl+C）
2. 重新启动 `npm start`
3. 访问管理员页面，确认之前创建的活动和报名数据仍然存在

## API 接口说明

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | /api/events | 获取所有活动列表 |
| GET | /api/events/:id | 获取单个活动详情 |
| POST | /api/events | 创建新活动 |
| GET | /api/events/:id/stats | 获取活动统计数据 |
| POST | /api/events/:id/register | 用户报名活动 |
| POST | /api/registrations/:id/cancel | 取消报名 |
| POST | /api/registrations/:id/checkin | 用户签到 |
| GET | /api/events/:id/export | 导出 CSV |

## 注意事项

1. **签到码安全**：签到码应该保密，仅管理员知晓
2. **数据备份**：数据库文件在 `data/events.db`，定期备份此文件
3. **无用户认证**：当前版本管理员页面无登录认证，适合内部使用
4. **端口配置**：默认端口 3000，可通过环境变量 `PORT` 修改

## 常见问题

**Q: 如何修改端口？**
```bash
# macOS/Linux
PORT=8080 npm start

# Windows (PowerShell)
$env:PORT=8080; npm start
```

**Q: 数据库文件在哪里？**
```
项目目录/data/events.db
```

**Q: 如何重置所有数据？**
```bash
# 删除数据库文件，重启服务后会自动创建新的空数据库
rm -rf data/events.db
```

**Q: 如何添加更多功能？**

可以直接修改以下文件：
- `server.js` - 添加新的 API 接口
- `database.js` - 添加数据库操作
- `public/admin.html` - 修改管理员页面
- `public/index.html` - 修改参与者页面
