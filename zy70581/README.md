# 电子表头映射CLI

自动匹配Excel表头到标准字段，减少人工核对工作。

## ✨ 功能特性

- 🔍 **多种匹配方式**: 精确匹配、同义词匹配、模糊匹配
- 📊 **置信度评分**: 显示每个匹配的置信度
- ⚠️ **冲突检测**: 自动发现多个表头映射到同一标准字段的冲突
- 📋 **异常行检测**: 识别空行、大部分为空的行，并保留原始位置
- 📄 **多种输出格式**:
  - 彩色终端摘要
  - 机器可读的JSON结果
  - 适合发给同事的HTML报告

## 📖 快速开始

### 1. 初始化配置文件

```bash
header-mapper init
```

这会在当前目录创建两个示例配置文件：
- `standard_fields.yaml` - 标准字段列表
- `synonyms.yaml` - 同义词映射配置

### 2. 基本使用

```bash
header-mapper map 你的数据.xlsx -f standard_fields.yaml -s synonyms.yaml
```

### 3. 生成报告

```bash
# 生成HTML报告和JSON结果
header-mapper map 数据.xlsx \
  -f standard_fields.yaml \
  -s synonyms.yaml \
  -H report.html \
  -j result.json
```

## 📁 目录结构

```
.
├── standard_fields.yaml    # 标准字段配置

├── report.html             # 生成的HTML报告
└── result.json             # 生成的JSON结果
```

## ⚙️ 配置说明

### 标准字段配置 (standard_fields.yaml)

```yaml
fields:
  - 姓名
  - 手机号
  - 邮箱
  - 身份证号
  - 地址
  - 订单号
  - 订单金额
  - 下单时间
```

也支持简单的txt格式，每行一个字段：

```
姓名
手机号
邮箱
```

### 同义词配置 (synonyms.yaml)

```yaml
姓名:
  - 名字
  - 客户姓名
  - 用户名
  - 联系人
手机号:
  - 电话
  - 手机号码
  - 联系电话
  - 手机
邮箱:
  - 电子邮箱
  - email
  - 邮件地址
```

## 📝 命令参数

```
Usage: header-mapper map [OPTIONS] EXCEL_FILE

  对Excel文件进行表头映射分析

Options:
  -f, --fields PATH          标准字段配置文件 [required]
  -s, --synonyms PATH        同义词配置文件
  -S, --sheet TEXT           工作表名称 (默认: Sheet1)
  -r, --header-row INTEGER   表头所在行号 (从0开始, 默认: 0)
  -t, --threshold INTEGER    模糊匹配阈值 (0-100, 默认: 80)
  --case-sensitive           区分大小写
  -j, --json-output PATH     JSON结果输出路径
  -H, --html-output PATH     HTML报告输出路径
  -q, --quiet                不输出终端摘要
  --help                     Show this message and exit.
```

## 📊 匹配类型说明

| 类型 | 说明 | 置信度 |
|------|------|--------|
| exact | 精确匹配 | 100% |
| synonym | 同义词匹配 | 95% |
| fuzzy | 模糊匹配 | 80%-94% |
| unmatched | 无法匹配 | 0% |

## ❌ 退出码

- `0`: 所有表头成功匹配，无冲突，无异常
- `2`: 存在未匹配的表头或映射冲突
- `1`: 程序错误或异常

## 🎯 使用场景

1. **数据导入前检查**: 业务提供的Excel表头多变，提前检查能否映射到系统标准字段
2. **数据清洗准备**: 识别异常行，了解数据质量
3. **团队协作**: 生成HTML报告发给同事，说明哪些表头需要处理

## 🤝 常见问题

**Q: 模糊匹配不准确怎么办？**
A: 可以调整 `--threshold` 参数提高匹配门槛，或者在同义词配置中添加对应的同义词。

**Q: 如何处理多个表头指向同一标准字段的情况？**
A: 工具会自动检测并标记为冲突，你可以在终端输出或HTML报告中看到冲突提示，然后人工决定保留哪一列。

**Q: 支持哪些Excel格式？**
A: 支持 .xlsx 和 .xls 格式。
