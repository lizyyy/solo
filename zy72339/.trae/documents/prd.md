## 1. 产品概述

PageRank 站内推荐演示系统，用于教研负责人吴老师向新人讲解站内推荐评分的完整流程。系统内嵌小而真的演示数据，覆盖边界值说明导入、评分权重表补看、计算明细更新三步流程，并重点展示百分数与小数混出、旧口径补录等边界场景的正确处理方式。

- 目标用户：教研负责人（吴老师）、活动负责人、新入职教研人员
- 核心价值：让新人通过一次完整跑批看到三种不同处理结果，理解边界场景下"不急着归正常、留给活动负责人复核"的工作原则

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 教研负责人（吴老师） | 主导评分流程、补看权重表、执行人工修正 | 导入边界值说明、查看评分权重表、执行修正与重跑 |
| 活动负责人 | 复核边界场景处理结果 | 查看计算明细、确认或退回混合格式记录 |

### 2.2 功能模块

1. **流程总览页**：展示三步流程当前状态、每步的完成情况与待处理项
2. **边界值说明导入页**：第一次导入边界值说明数据，识别并标记异常格式
3. **评分权重表补看页**：教研负责人补看评分权重表，补充旧口径数据
4. **计算明细页**：展示三种记录类型的计算结果，支持人工修正和重跑

## 3. 核心流程

教研负责人吴老师的工作流程如下：

1. **第一步——边界值说明导入**：吴老师导入边界值说明文件。系统自动解析数据，遇到百分数与小数混出的字段时，不自动归为正常值，而是标记为"待复核"，留给活动负责人确认。
2. **第二步——评分权重表补看**：吴老师打开评分权重表，发现有旧口径数据缺失。她将旧口径数据补录到系统中，来源标记为"补录"。
3. **第三步——计算明细更新**：系统根据导入的边界值说明和补录的权重数据重新计算。吴老师查看三条记录的计算结果：顺利记录正常出分、混合格式记录需活动负责人确认后才出分、旧口径补录记录按补录口径计算。如发现异常可执行人工修正并重跑。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰（#1e293b）配暖橙色（#f97316）作为强调色，传达专业感与重点标注
- 辅助色：浅灰底（#f8fafc）配三色状态标签——绿色（顺利）、琥珀色（待复核）、蓝色（补录）
- 按钮风格：圆角矩形（rounded-lg），主操作用实心暖橙色，次操作用描边样式
- 字体：标题用 Noto Serif SC（衬线体，传达教研专业感），正文用 Noto Sans SC
- 布局：左侧固定步骤导航 + 右侧内容区，内容区采用卡片式布局
- 图标：使用 lucide-react 图标库，步骤图标用圆圈数字，操作图标用功能图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 流程总览页 | 步骤导航 | 左侧竖向三步进度条，当前步骤暖橙色高亮，已完成绿色打勾 |
| 流程总览页 | 记录摘要 | 三张统计卡片，分别显示三种记录数量，颜色对应状态标签 |
| 边界值说明导入页 | 数据导入区 | 顶部导入按钮 + 数据预览表格，混合格式单元格琥珀色背景 |
| 边界值说明导入页 | 异常标记列表 | 右侧滑出面板，逐条列出待复核字段及原因说明 |
| 评分权重表补看页 | 权重表展示 | 表格形式，旧口径差异行蓝色左侧边框 + "补录"标签 |
| 评分权重表补看页 | 旧口径补录 | 弹窗表单，输入旧口径值和来源说明 |
| 计算明细页 | 计算结果表格 | 分组折叠表格，三组用不同颜色标签区分，支持展开查看计算过程 |
| 计算明细页 | 人工修正操作 | 行内编辑按钮，点击弹出修正表单，修正后显示修正标记 |
| 计算明细页 | 重跑触发 | 顶部重跑按钮，点击后显示进度条和前后对比 |
| 计算明细页 | 历史记录 | 右侧时间线，每条记录显示操作类型、操作人、时间戳 |

### 4.3 响应式设计

- 桌面优先，最小宽度 1024px
- 步骤导航在窄屏下收缩为顶部横向步骤条
- 表格在窄屏下支持横向滚动

### 4.4 演示数据说明

系统预置以下三条演示数据：

1. **顺利记录**（课程"Python 入门"）：边界值说明中权重全部为标准小数格式，评分权重表完整，计算结果一次性通过
2. **混合格式记录**（课程"数据分析实战"）：边界值说明中部分权重用百分数（如"25%"）部分用小数（如"0.3"），系统标记为"待复核"，活动负责人确认后归入计算
3. **旧口径补录记录**（课程"机器学习基础"）：边界值说明导入时权重表缺少旧口径数据（旧口径"内容质量"权重为 0.35，新口径为 0.25），吴老师从权重表补录旧值，系统按补录口径计算
