# 可转债转股边界计算工具

同事写给同事看的可转债转股边界计算工具。专治各种参数表乱凑、单位混乱、算不出来悄悄消失的毛病。

## 核心特性

- **公式摆在明处**：每条记录的计算过程都能看到，不用再对着结果猜公式用对了没
- **单位自动转换**：元、万元、角、分混在一起也不怕，转换过程全记录
- **边界判断透明**：0%和2%的边界怎么来的、谁定的，备注都留着
- **异常不消失**：空值、重复、除零错误，算不出来就明说原因，不会悄悄从统计里抹掉
- **来源可追溯**：每条记录保留原始来源、处理时间、原始备注，后面补材料不用再问小岑
- **报告和明细一致**：汇总统计和明细数据用同一套结果，不会出现两套说法

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 生成样例数据

```bash
python -m src.cli sample
```

会在 `data/sample_bonds.csv` 生成包含各种异常情况的测试数据。

### 3. 运行计算

```bash
python -m src.cli calculate data/sample_bonds.csv
```

输出文件在 `output/` 目录下，包含：
- `sample_bonds_report_YYYYMMDD_HHMMSS.txt` - 人类可读的文本报告
- `sample_bonds_detail_YYYYMMDD_HHMMSS.csv` - 可用于后续分析的CSV明细
- `sample_bonds_report_YYYYMMDD_HHMMSS.json` - 机器可读的JSON格式

### 4. 查看参数说明

```bash
python -m src.cli show-params
```

## 输入格式

支持 CSV 和 JSON 两种格式。

### CSV 字段说明

| 字段名 | 说明 | 必填 |
|--------|------|------|
| bond_code | 转债代码 | 是 |
| bond_name | 转债名称 | 是 |
| bond_price | 转债价格 | 是 |
| bond_price_unit | 转债价格单位（元/万元/角/分） | 否，默认元 |
| conversion_price | 转股价格 | 是 |
| conversion_price_unit | 转股价格单位 | 否，默认元 |
| stock_price | 正股价格 | 是 |
| stock_price_unit | 正股价格单位 | 否，默认元 |
| face_value | 面值 | 否，默认100 |
| face_value_unit | 面值单位 | 否，默认元 |
| remark | 原始备注 | 否 |

也支持中文列名：转债代码、转债名称、转债价格、转债价格单位、转股价格、转股价格单位、正股价格、正股价格单位、面值、面值单位、备注。

### 计算公式

```
转股价值 = 面值 ÷ 转股价格 × 正股价格
转股溢价率 = (转债价格 - 转股价值) ÷ 转股价值 × 100%
```

### 边界判断规则

| 条件 | 结论 |
|------|------|
| 溢价率 < 0% | 边界内 - 建议转股 |
| 溢价率 = 0% | 临界点 - 正好触达下边界 |
| 0% < 溢价率 < 2% | 边界内 - 关注转股机会 |
| 溢价率 = 2% | 临界点 - 正好触达上边界 |
| 溢价率 > 2% | 边界外 - 不建议转股 |

边界值可通过 `--boundary-low` 和 `--boundary-high` 参数调整。

## 怎么看异常清单

运行命令后，控制台会先输出异常记录摘要：

```
--- 异常记录摘要 ---
❌ 行5: 110004 示例转债4 - 计算失败
   原因: 缺少必要字段: 转债价格，无法进行计算
⚠️  行8: 110001 示例转债1 - 计算成功
⏭️  行9: 110001 示例转债1-重复 - 已跳过
```

完整的异常清单在文本报告的「异常记录清单」章节，每条异常包含：
- 行号和转债标识
- 状态（计算失败/已跳过/有警告）
- 原始来源文件
- 处理时间
- 错误原因
- 警告信息
- 原始备注（方便追溯）

```
  INPUT_FILE                    输入文件路径（.csv 或 .json）

```

## 报告结构说明

### 文本报告结构
1. **状态统计**：成功/失败/跳过各多少条
2. **边界判断统计**：各种边界结论的分布
3. **转股溢价率统计**：平均/最小/最大值
4. **数据清洗情况**：重复、空值、单位混用各多少条
5. **计算参数备注**：保留小岑确认的那些备注
6. **异常记录清单**：所有有问题的记录汇总
7. **详细计算结果**：每条记录的完整计算过程

### CSV 明细字段
每条记录一行，包含计算结果、公式、单位、边界值、错误原因等，方便用 Excel 筛选分析。

## 处理的异常场景

- **空值**：转债价格、转股价格、正股价格任一为空，标记为计算失败并说明原因
- **重复记录**：同一转债代码出现多次，首条保留计算，其余标记为已跳过
- **单位混用**：自动转换为统一单位（元），并记录转换过程
- **空单位**：未指定单位时默认按元处理，给出警告
- **除零错误**：转股价格为0时标记失败
- **结果异常**：计算出异常值时保留公式，让你能看出哪里不对

## 常见问题

**Q: 为什么报告里有的记录状态是「已跳过」？**
A: 因为是重复记录。同一转债代码出现多次时，只计算第一条，其余跳过。跳过的记录会在异常清单里说明和哪一行重复。

**Q: 单位转换错了怎么办？**
A: 每条记录的「使用单位」部分会显示最终用的是什么单位，「计算公式」里能看到代入的数值。如果发现转换有问题，可以对照原始数据检查。

**Q: 想调整边界值怎么弄？**
A: 用 `--boundary-low` 和 `--boundary-high` 参数。比如想把上边界改成 3%：
```bash
python -m src.cli calculate data/sample_bonds.csv --boundary-high 3.0
```

**Q: 小岑之前确认的备注在哪里看？**
A: 文本报告里的「计算参数备注」章节，或者运行 `python -m src.cli show-params`。
