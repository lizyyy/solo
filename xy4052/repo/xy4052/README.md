# 急诊分诊夜班 - 急诊科新护士培训闯关游戏

一个用于急诊科新护士和院内培训老师的本地闯关游戏，模拟真实夜班分诊场景。

## 游戏玩法

### 基本规则
- 每局游戏时长：8-12分钟
- 玩家需要接收不断出现的患者
- 根据患者情况判断优先级（红/黄/绿/留观）
- 安排检查、治疗和呼叫医生
- 管理资源和时间压力

### 分诊级别
- **红色**：急危重症，需要立即处理
- **黄色**：急症，需要优先处理
- **绿色**：轻症，可以稍后处理
- **留观**：需要观察但不紧急

### 可执行动作
- 测量生命体征
- 心电图检查
- 抽血检验
- 补液治疗
- 呼叫医生
- 隔离措施
- 安抚家属

## 核心功能验证流程

### 1. 开始一局游戏
1. 打开浏览器访问 http://localhost:8080
2. 点击"开始游戏"按钮
3. 选择一个关卡
4. 游戏开始，计时器启动

### 2. 拖拽分诊
1. 新患者卡片出现在"待分诊"区域
2. 点击并拖动患者卡片
3. 拖拽到红/黄/绿/留观队列区域
4. 释放鼠标完成分诊

### 3. 安排检查
1. 点击已分诊的患者卡片
2. 在动作面板选择需要的动作
3. 系统检查资源是否可用
4. 动作执行，消耗时间和资源

### 4. 触发恶化
1. 患者等待时间过长
2. 关键检查未及时完成
3. 分诊级别判断错误
4. 系统自动触发病情恶化，影响评分

### 5. 完成结算
1. 游戏时间结束或所有患者处理完毕
2. 显示最终得分和评级
3. 查看错误归因和改进建议

### 6. 导入坏关卡被拦截
1. 点击"导入关卡"按钮
2. 选择一个有错误的JSON文件（如字段缺失、时间线倒序）
3. 系统显示校验错误信息
4. 当前关卡数据不被覆盖

### 7. 刷新恢复
1. 游戏进行中刷新浏览器页面
2. 重新打开游戏
3. 系统提示"检测到未完成的游戏"
4. 选择"继续游戏"恢复进度

### 8. 导出培训报告
1. 完成一局游戏
2. 在结算页面点击"导出报告"
3. 系统生成Markdown格式培训报告
4. 报告包含：事件回放、错误分析、改进建议

## 自定义关卡

### 关卡JSON格式
```json
{
  "id": "level1",
  "name": "普通夜班",
  "description": "一个典型的夜班分诊场景",
  "duration": 600,
  "patients": [
    {
      "id": "p1",
      "arrivalTime": 0,
      "chiefComplaint": "胸痛",
      "vitalSigns": {
        "heartRate": 110,
        "bloodPressure": "150/90",
        "temperature": 36.8,
        "spo2": 94
      },
      "riskFactors": ["高血压史", "糖尿病"],
      "correctTriage": "red",
      "requiredActions": ["ecg", "bloodTest", "callDoctor"],
      "deteriorationTime": 120
    }
  ]
}
```

### 校验规则
- 所有必填字段必须存在
- 时间线必须按顺序排列
- 患者ID不能重复
- 动作引用必须存在于动作库中
- 触发条件不能冲突

## 评分规则

### 加分项
- 高危患者正确识别 (+20分)
- 及时呼叫医生升级 (+15分)
- 合理释放资源 (+10分)
- 患者满意度高 (+5分)

### 扣分项
- 分诊级别错误 (-20分)
- 关键检查延误 (-15分)
- 隔离措施漏做 (-15分)
- 资源重复占用 (-10分)
- 患者等待超时 (-10分)
- 病情恶化 (-30分)
