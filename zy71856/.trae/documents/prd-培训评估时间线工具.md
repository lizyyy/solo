## 1. 产品概述

培训评估时间线工具，为水利闸门操作等实操培训提供统一的证据链管理平台。将步骤视频、学生误操作记录、评分表整合到同一条时间轴，支持自动判断与人工确认，确保教研负责人能清晰追溯每个操作的原因与下一步建议。

- **目标用户**：培训老师、教研负责人
- **核心价值**：证据链可追溯、异常标记明确、自动判断理由透明、教研视图友好

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 培训老师 | 本地账号 | 导入数据、查看时间线、人工确认、标记异常 |
| 教研负责人 | 本地账号 | 查看教研视图、审核自动判断、查看原因与下一步 |

### 2.2 功能模块

1. **时间线主页面**：统一展示步骤视频、误操作记录、评分表
2. **水利闸门操作模块**：自动判断、理由展示、教研视图
3. **数据导入模块**：处理真实材料包（正常/晚到/重复/人工更正）
4. **证据链管理**：视频+人工确认+课堂记录关联、持久化
5. **异常标记模块**：拖拽丢失、视角重置、步骤跳过 → 待确认

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 时间线主页 | 时间轴组件 | 按时间顺序展示所有事件，支持缩放、定位、筛选 |
| 时间线主页 | 视频播放器 | 同步播放步骤视频，支持打点标记 |
| 时间线主页 | 评分表面板 | 展示评分项与得分，关联对应时间点 |
| 水利闸门操作 | 自动判断卡片 | 展示判断结果、自动生成的判断理由 |
| 水利闸门操作 | 教研视图 | 清晰展示"原因"和"下一步"，无技术术语 |
| 数据导入 | 文件上传 | 支持拖拽上传数据包，自动识别处理各类记录 |
| 异常标记 | 待确认列表 | 集中展示所有异常事件，支持批量确认 |

## 3. 核心流程

### 3.1 数据导入与处理流程
培训老师上传数据包 → 系统识别记录类型（正常/晚到/重复/人工更正）→ 去重处理 → 时间轴排序 → 异常自动标记 → 生成待确认列表

### 3.2 自动判断流程
选择"水利闸门操作"场景 → 加载步骤标准 → 比对学生操作记录 → 生成判断结果与理由 → 关联视频证据 → 推送到教研视图

### 3.3 教研审核流程
教研负责人查看教研视图 → 阅读"原因"与"下一步" → 追溯视频证据 → 确认或调整判断 → 生成最终评估报告

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深蓝 #1e3a5f（专业、稳重），辅助色：橙 #e67e22（警告标记）、绿 #27ae60（正常）、红 #c0392b（异常）
- **按钮风格**：扁平设计，2px圆角，hover状态轻微上浮
- **字体**：标题用思源宋体（专业感），正文用思源黑体（可读性）
- **布局**：左侧时间轴 + 右侧详情面板，卡片式信息分组
- **图标**：线性图标，保持统一粗细

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 时间线主页 | 时间轴 | 垂直时间线，不同事件类型用不同颜色标记，hover显示预览 |
| 时间线主页 | 视频播放器 | 固定顶部，进度条同步时间线，支持打点 |
| 时间线主页 | 评分表面板 | 表格形式，支持点击跳转到对应时间点 |
| 水利闸门 | 自动判断卡片 | 结果高亮，理由分点展示，关联证据可展开 |
| 水利闸门 | 教研视图 | 大字体"原因"和"下一步"，避免技术术语，配色柔和 |
| 数据导入 | 上传区域 | 拖拽区域，上传后显示处理进度和统计 |
| 异常标记 | 待确认列表 | 醒目的橙色标记，每条带"确认"按钮 |

### 4.3 响应式
- 桌面端：左侧60%时间线 + 右侧40%详情
- 平板端：上下布局，时间线上方，详情下方
- 移动端：时间线卡片堆叠，详情弹窗展示

### 4.4 交互细节
- 时间线滚动时，视频进度自动同步
- 点击时间线事件，右侧详情自动定位
- 异常事件带有呼吸灯动画效果
- 教研视图切换时，有平滑过渡动画
