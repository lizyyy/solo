# 产品知识库

## 1. 用户注册流程

新用户注册后，需要经过人工审核，审核时间为1-2个工作日，审核通过后才能使用系统功能。

## 2. 会员等级

会员分为四个等级：
- 普通会员
- 银卡会员
- 金卡会员
- 钻石会员

## 3. 退款政策

退款申请提交后，需要经过客服审核和财务确认，整个流程需要5-7个工作日才能完成退款到账。

## 4. 账户安全

修改绑定手机号码需要经过以下步骤：
1. 验证原手机号码
2. 输入新手机号码
3. 验证新手机号码验证码
4. 完成修改
