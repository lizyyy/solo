## 1. 产品概述

河岸步道拥挤监测工具——为社区运营人员（阿宁）打造的轻量级监测看板，将 GIS 点位、居民反馈、巡检照片和街道手改备注统一归口到一张可交互地图上。核心目标是：让居民反馈表里的材料和导出结果一一对应、历史意见不被覆盖抹掉、数据冲突时把双方证据摆出来而不是替用户拍板，刷新后地图标注和人工备注不散掉。

- 目标用户：社区运营阿宁及后续接手人员
- 核心价值：消除"居民反馈表材料与监测结果对不上"的断层，让每条判定可追溯、冲突透明、接手无障碍

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 社区运营 | 直接访问 | 查看/编辑所有点位、备注、处理记录；导出报告 |
| 只读查看者 | 直接访问 | 查看地图点位、详情、历史记录；不可编辑 |

### 2.2 功能模块

1. **监测总览页**：交互地图 + 侧边栏列表 + 冲突提示 + 统计摘要
2. **点位详情页（侧滑面板）**：来源追溯、当前状态、处理记录时间线、历史意见、巡检照片、人工备注

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能说明 |
|----------|----------|----------|
| 监测总览页 | 交互地图 | Leaflet 地图上标注所有 GIS 点位；点位颜色/图标按状态区分（拥挤/正常/待确认）；点击点位弹出摘要卡片，再点进入详情面板 |
| 监测总览页 | 侧边栏-居民反馈列表 | 按时间倒序展示居民反馈条目，每条显示反馈人、时间、关联点位、冲突标记；点击可定位到地图对应点位 |
| 监测总览页 | 侧边栏-巡检照片 | 缩略图网格展示巡检照片，每张标注拍摄时间、关联点位；点击放大查看 |
| 监测总览页 | 侧边栏-人工备注 | 可编辑的备注区域，支持按街道分组；编辑后自动保存至 localStorage，刷新不丢失 |
| 监测总览页 | 冲突提示横幅 | 当居民反馈说法与导入数据冲突时，顶部显示冲突数量，展开可查看双方证据和建议动作 |
| 监测总览页 | 统计摘要栏 | 显示总点位数、各状态数量、冲突数量、最近更新时间 |
| 点位详情面板 | 来源追溯 | 显示该点位数据来源（GIS导入/居民反馈/巡检录入），附原始来源ID和导入时间 |
| 点位详情面板 | 状态与处理记录 | 当前状态 + 处理记录时间线（每次状态变更留痕：谁、什么时候、从什么改为什么、原因） |
| 点位详情面板 | 历史意见 | 旧方案被新方案覆盖时，历史意见完整保留并标注"已覆盖"，展示覆盖时间和覆盖原因，不可删除 |
| 点位详情面板 | 巡检照片 | 该点位关联的巡检照片缩略图 + 大图查看 |
| 点位详情面板 | 人工备注 | 该点位的单独备注，编辑后自动保存 |
| 点位详情面板 | 冲突详情 | 若存在冲突，展示"居民反馈说法"vs"导入数据"，两侧证据并列，建议动作按钮（以居民反馈为准/以导入数据为准/标记待核实） |

## 3. 核心流程

### 3.1 日常监测流程

社区运营阿宁打开工具 → 地图加载所有 GIS 点位（状态色标） → 浏览侧边栏居民反馈列表 → 点击反馈条目定位到地图点位 → 点击点位打开详情面板 → 查看来源、状态、处理记录、历史意见 → 如有冲突，查看双方证据并选择处理方式 → 编辑人工备注 → 导出报告

### 3.2 冲突处理流程

系统检测到居民反馈与导入数据冲突 → 顶部横幅提示冲突数量 → 点击展开冲突详情 → 展示双方证据并列 → 阿宁选择建议动作（以居民反馈为准/以导入数据为准/标记待核实） → 选择后自动生成处理记录（含选择原因） → 冲突标记更新

### 3.3 历史覆盖流程

某点位旧方案被新方案替换 → 旧方案状态变为"已覆盖" → 保留完整旧方案内容和覆盖时间 → 新方案标注覆盖原因 → 处理记录时间线自动追加一条覆盖记录

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深青蓝（#1a535c）+ 浅米色背景（#f7f3e9），体现河岸步道的水岸自然氛围
- **强调色**：琥珀橙（#ff6b35）用于冲突/需关注项，薄荷绿（#4ecdc4）用于正常状态
- **按钮风格**：圆角矩形，填充色为主色调，hover 时微抬阴影
- **字体**：标题用 Noto Serif SC（衬线体，庄重），正文用 Noto Sans SC（无衬线，清晰）
- **布局风格**：左侧地图（占60%宽），右侧侧边栏（占40%宽），详情面板从右侧滑入覆盖侧边栏
- **图标**：使用 lucide-react 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 监测总览页 | 交互地图 | 全高地图，点位圆形标记（拥挤=红、正常=绿、待确认=橙），点击弹出Leaflet Popup摘要卡片 |
| 监测总览页 | 侧边栏 | 固定右侧面板，顶部Tab切换（反馈/照片/备注），各Tab内列表滚动 |
| 监测总览页 | 冲突横幅 | 顶部固定条，琥珀橙背景，白色文字显示冲突数，点击展开下拉详情 |
| 监测总览页 | 统计摘要 | 侧边栏顶部卡片，数字大字+标签小字 |
| 点位详情面板 | 右侧滑入面板 | 宽400px，从右侧滑入，内部分区：来源区、状态区、时间线区、历史区、照片区、备注区、冲突区 |

### 4.3 响应式

- 桌面优先（1920×1080为基准）
- 小屏幕（<1024px）：侧边栏折叠为底部抽屉，详情面板全屏覆盖
- 触摸优化：地图点位点击区域加大，按钮间距加大

### 4.4 地图场景指引

- 地图底图：OpenStreetMap 免费瓦片
- 默认视角：河岸步道所在区域（示例：某城市河段）
- 点位聚合：点位置重叠时聚合显示数字
- 交互：点击点位 → Popup 摘要 → 点击"查看详情"按钮 → 右侧面板滑入
