## 项目简介

"吊点荷载沙盘"是一个专为舞台技术统筹设计的本地3D交互预演工具。在临时演出搭建灯架时，技术人员需要处理吊点表、桁架段、灯具重量和限高要求，最担心的问题包括：

- 🚨 某个电机超载
- ⚖️ 重心偏移导致失衡
- 💥 灯具与幕布/喷淋等障碍物打架

本工具提供直观的3D可视化界面，支持拖拽编辑、实时载荷计算、碰撞检测，并能导出专业的安全交底报告。

## 功能特性

### 🎯 核心功能

1. **3D场景编辑**
   - 拖拽添加吊点、桁架、灯具设备、障碍物
   - 支持对象选择、移动、删除、复制粘贴
   - 多视角切换（俯视图、正视图、侧视图、透视图）
   - 网格对齐功能

2. **实时载荷计算**
   - 基于力矩平衡原理计算吊点载荷分配
   - 支持单点、两点、多点吊装计算
   - 实时显示各吊点载荷百分比和状态
   - 超载警告（红色）、重载警告（黄色）

3. **重心与平衡分析**
   - 实时计算系统重心位置
   - 可视化显示重心指示器
   - 判断系统平衡状态
   - 提供配重建议

4. **碰撞与净空检测**
   - 设备间碰撞检测
   - 设备与障碍物碰撞检测
   - 净空距离检测（可配置警告阈值）
   - 限高冲突检测

5. **数据持久化**
   - 本地自动保存（每30秒）
   - 场景列表管理
   - JSON格式导入/导出
   - 场景备份功能

6. **专业报告导出**
   - Markdown格式安全交底报告
   - 包含载荷分布、碰撞检测、配重建议
   - 安全检查清单
   - JSON格式技术方案导出

## 使用指南

### 基本操作

#### 添加对象
1. 在左侧工具栏选择要添加的对象类型（吊点/桁架/设备/障碍物）
2. 在3D场景中点击要放置的位置
3. 新对象将出现在点击位置
4. 可以通过属性面板调整参数

#### 选择对象
1. 确保处于"选择"模式（左侧工具栏第一个按钮高亮）
2. 点击场景中的任意对象
3. 对象会高亮显示，同时右侧显示属性面板

#### 移动对象
1. 选中要移动的对象
2. 按住鼠标左键拖拽对象
3. 对象会按网格对齐移动
4. 释放鼠标完成移动

#### 删除对象
1. 选中要删除的对象
2. 按键盘 `Delete` 或 `Backspace` 键
3. 或在属性面板点击"删除对象"按钮

#### 复制粘贴
- 复制：选中对象后按 `Ctrl+C`
- 粘贴：按 `Ctrl+V`
- 快速复制：选中对象后按 `Ctrl+D`

### 数据结构说明

#### 吊点 (HangingPoint)
```javascript
{
  id: "hp_xxxx",
  name: "吊点1",
  position: { x: 0, y: 8, z: 0 },  // 位置（米）
  maxLoad: 500,                      // 最大载荷（kg）
  safetyFactor: 5,                   // 安全系数
  motorType: "1T电动葫芦"             // 电机类型
}
```

#### 桁架 (Truss)
```javascript
{
  id: "truss_xxxx",
  name: "主桁架",
  position: { x: 0, y: 6, z: 0 },
  length: 10,                         // 长度（米）
  weight: 80,                         // 自重（kg）
  rotation: 0,                        // 旋转角度
  hangingPointIds: ["hp_1", "hp_2"], // 关联的吊点ID
  attachedDeviceIds: ["dev_1"]       // 挂接的设备ID
}
```

#### 设备 (Device)
```javascript
{
  id: "dev_xxxx",
  name: "摇头灯1",
  position: { x: -2, y: 6, z: 0 },
  weight: 25,                         // 重量（kg）
  deviceType: "movingHead",           // 类型
  dimensions: { x: 0.5, y: 0.8, z: 0.5 } // 尺寸

```

#### 障碍物 (Obstacle)
```javascript
{

  obstacleType: "sprinkler",          // 类型
  dimensions: { x: 0.3, y: 4, z: 8 } // 尺寸
}
```

### 载荷计算原理

#### 两点吊装力矩平衡
对于桁架 AB，A 点坐标为 x₁，B 点坐标为 x₂，设备在位置 x 处，重量为 W：

```
  力矩平衡：W × (x - x₁) = F_B × (x₂ - x₁)
  垂直平衡：F_A + F_B = W

  F_B = W × (x - x₁) / (x₂ - x₁)
  F_A = W - F_B
```

#### 多点吊装
对于超过两个吊点的情况，采用均匀分配近似算法。

#### 重心计算
```
Cog_x = Σ(W_i × x_i) / ΣW_i
Cog_y = Σ(W_i × y_i) / ΣW_i
Cog_z = Σ(W_i × z_i) / ΣW_i
```

## 示例场景

项目包含4个预设示例场景：

### 1. 基础舞台场景
- 10米主桁架
- 6台摇头灯（每台25kg）
- 2个吊点（各500kg载荷能力）
- 总重量：230kg

### 2. 演唱会复杂场景
- 4个桁架（主桁架、左侧桁架、右侧桁架、后桁架）
- 24台设备（摇头灯、LED屏、追光灯）
- 8个吊点
- 总重量：1168kg

### 3. 超载警告场景
- 演示吊点超载情况
- 单个吊点承载超过额定载荷
- 显示红色超载警告

### 4. 碰撞测试场景
- 演示设备与障碍物碰撞
- 显示碰撞警告和净空警告

## 已知限制

1. **网络依赖**：Three.js 默认从 CDN 加载，首次加载需要网络连接
2. **浏览器支持**：需要支持 ES6 Modules 和 WebGL 的现代浏览器
3. **性能限制**：大量对象（>100个）时可能影响帧率
4. **计算精度**：多点吊装采用近似算法，复杂情况建议专业校核
