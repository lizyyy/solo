# 心理咨询室咨询预约数据脱敏工具

专门针对心理咨询室预约数据设计的批量脱敏命令行工具，保护来访者隐私的同时保留业务分析价值。

## ✨ 特性

- **真实业务字段支持** - 专门针对心理咨询预约场景设计，包括：来访者姓名、咨询师、学生学号、身份证号、联系电话、邮箱、咨询地点、主诉内容、咨询记录等
- **未成年人检测** - 自动识别未成年人信息并标记
- **自由文本脱敏** - 对主诉内容、咨询记录等自由文本中的敏感信息进行替换
- **可复跑输出** - 使用确定性哈希算法，相同输入产生相同输出
- **错误处理** - 单个文件损坏不影响整体处理，汇总报告清晰显示失败原因
- **重复行检测** - 自动检测并删除重复预约记录
- **智能字段识别** - 自动识别CSV文件中的业务字段，支持多种命名格式

## 🚀 快速开始

### 基本使用

```bash
# 处理单个CSV文件
counseling-desensitize samples/appointment_sample.csv

# 或使用npm脚本
npm start -- samples/appointment_sample.csv
```

### 输出目录指定

```bash
counseling-desensitize samples/appointment_sample.csv -o ./my_output
```

### 批量处理多个文件

```bash
counseling-desensitize samples/*.csv -o ./output
```

### 保留重复行

```bash
counseling-desensitize samples/appointment_sample.csv --keep-duplicates
```

### 检测CSV字段

```bash
counseling-desensitize detect samples/appointment_sample.csv
```

## 🔍 支持的脱敏字段

| 业务字段 | 脱敏方式 | 示例 |
|---------|---------|------|
| 来访者姓名 | 随机化化名 | 张三 → 来访1234同学 |
| 咨询师姓名 | 标准化称呼 | 李建国 → 李老师 |
| 联系电话 | 中间掩码 | 13800138001 → 138****8001 |
| 身份证号 | 中间掩码 | 110101200301011234 → 110101********1234 |
| 邮箱 | 用户名掩码 | zhangsan@example.com → 123***@example.com |
| 学号 | 重编码 | 20210101 → STU56789 |
| 咨询地点 | 标准化 | 咨询室101 → 咨询室A |
| 自由文本 | 敏感词替换 | "我叫张三" → "我是来访同学" |

## 🚦 退出码说明

| 退出码 | 含义 | 场景 |
|-------|------|------|
| 0 | 完全成功 | 所有文件处理成功，无特殊标记 |
| 1 | 部分成功 | 部分文件失败 / 包含未成年人信息 / 包含自由文本处理 / 有重复行被跳过 |
| 2 | 全部失败 | 所有文件处理失败 |

## 💡 验收要点

1. **真实业务字段** - 专门针对心理咨询预约数据设计，包含：来访者姓名、年龄、学号、咨询师、联系电话、咨询类型、预约时间、咨询地点、主诉内容、咨询记录等完整业务字段
2. **未成年人检测** - 自动识别并标记未成年人（<18岁），退出码返回1
3. **自由文本处理** - 对主诉内容、咨询记录等自由文本中的敏感信息进行脱敏
4. **可复跑输出** - 使用确定性哈希算法，相同输入产生相同输出
5. **错误处理** - 单个文件损坏时继续处理其他文件，汇总报告中明确显示失败原因
6. **重复行处理** - 自动检测并删除重复预约记录
7. **缺列处理** - 支持缺少部分字段的情况，仍能正常处理存在的字段
8. **业务样例** - 提供真实的心理咨询预约数据样例，非通用演示数据
