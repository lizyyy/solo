## 三、会失败的操作

### ❌ 失败操作：手动输入 w=0, x=0, y=0, z=0 的零四元数

#### 操作步骤
1. 点击右侧「参数设置」标签
2. 在「当前四元数」输入组中，将 **w、x、y、z** 四个分量全部改为 **0**
3. 观察系统反应

#### 为什么会失败
四元数数学上要求 ||q|| = 1。当所有分量为 0 时，模长为 0，无法归一化，属于非法输入。

#### 预期现象
- 四元数输入框边框变为**琥珀色**
- 左上角弹出红色「⚠ 待确认」提示：`四元数未归一 (||q|| = 0.000000)`
- 3D 姿态点落在默认位置（Y轴正向），卫星模型不旋转
- 系统不会崩溃，但会自动标记为「待确认」状态

#### 正确修复方式
点击输入组下方的「**归一化**」按钮，系统会将零四元数重置为单位四元数 (1,0,0,0)。

## 六、三种校验触发条件

### 1. 四元数未归一 ⚠
- **触发条件**：`||q|| - 1.0 > 0.001`
- **视觉提示**：输入框琥珀色边框 + 左上角黄色警告浮层 + 「归一化」按钮
- **建议操作**：点击「归一化」按钮自动修正

### 2. 万向节锁 ⚠
- **触发条件**：ZYX 顺序下 `|pitch - π/2| < 0.1` rad
- **视觉提示**：欧拉角输入组红色边框 + 红色脉冲动画 + 左上角警告浮层 + 球面红色脉冲环标记
- **建议操作**：改用四元数表示，或避免 pitch 接近 ±90°

### 3. 插值绕远 ⚠
- **触发条件**：起止四元数点积 < 0
- **视觉提示**：左上角警告浮层
- **建议操作**：将目标四元数四个分量全部取反（w→-w, x→-x, y→-y, z→-z）

> **设计原则**：宁可标「待确认」，绝不安静通过。所有异常均有明确视觉反馈。
