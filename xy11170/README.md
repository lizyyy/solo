# 舞蹈排练室计费核对 CLI

专门用于舞蹈排练室计费数据核对的命令行工具，帮助发现计费异常并提供修复建议。

## 功能特性

- ✅ **提前入场检测**：识别客户提前入场的情况，避免费用损失
- ✅ **延迟离场检测**：发现超时排练，确保计费完整
- ✅ **跨日排练检测**：识别跨越零点的排练，核实夜间费率
- ✅ **计费金额核对**：自动计算应缴费用与实际缴费的差异
- ✅ **正常/异常分离**：输出文件自动分离正常和异常记录
- ✅ **异常摘要报告**：统计各类异常并提供修复建议
- ✅ **可复跑输出**：支持重复运行，方便验证修正结果

## 安装依赖

```bash
npm install
```

## 使用方法

按照真实处理顺序执行以下三个步骤：

### 第一步：预览数据

在正式核对前，先预览输入数据，检查格式是否正确：

```bash
npm run preview
```

或手动指定输入文件：

```bash
node src/cli.js preview -i samples/input.csv
```

### 第二步：正式执行计费核对

执行完整的计费核对流程，生成所有输出文件：

```bash
npm run audit
```

或手动指定输入和输出路径：

```bash
node src/cli.js audit -i samples/input.csv -o output
```

### 第三步：查看异常报告

查看生成的异常摘要报告，了解异常详情和修复建议：

```bash
npm run report
```

或手动指定输出目录：

```bash
node src/cli.js report -o output
```

## 输出文件说明

核对完成后，`output` 目录会生成以下文件：

| 文件名 | 说明 |
|--------|------|
| `正常记录.csv` | 计费完全正常的预约记录 |
| `异常记录.csv` | 存在计费异常的预约记录（含异常类型和严重程度） |
| `异常详情.csv` | 每条异常的详细信息和具体修复建议 |
| `异常摘要报告.txt` | 异常类型统计、典型案例和可复跑说明 |

## 异常类型说明

| 异常类型 | 严重程度 | 说明 |
|----------|----------|------|
| 提前入场 | 警告 | 实际入场时间早于预约时间超过5分钟 |
| 延迟离场 | 警告 | 实际离场时间晚于预约时间超过5分钟 |
| 跨日排练 | 错误 | 排练跨越零点，涉及夜间费率 |
| 计费金额异常 | 错误 | 计费金额与实际应缴金额不符 |
| 排练室时间冲突 | 严重 | 同一排练室同一时段被多个预约占用 |

## 计费规则

本工具采用以下计费规则进行核对：

1. **计费单位**：按小时计费，不满1小时按1小时计算
2. **宽限期**：15分钟宽限期（超出预约时间15分钟内不计费）
3. **容差时间**：5分钟容差（入场/离场时间偏差5分钟内不计为异常）

## 核对流程建议

1. **首次运行**：发现所有异常记录
2. **人工核实**：对照异常详情，与前台或客户确认实际情况
3. **修正数据**：在原始输入文件中修正错误的计费记录
4. **重新运行**：再次执行audit命令，验证修正结果
5. **确认完成**：所有异常解决后，完成本次核对
