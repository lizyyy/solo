## 1. 产品概述

轨道站口共享单车疏导工具，面向交通工程师何工，用于将现场会议纪要中零散的共享单车疏导信息进行导入、归并、人工复核与导出公示清单。解决"材料对不上、来源查不到、脏数据没交代"的痛点，确保每条疏导记录可追溯到原始来源和处理时间，最终成果可供社区使用和工程师交接。

- 目标用户：交通工程师何工及其同事
- 核心价值：从杂乱材料到可公示清单的完整闭环，脏数据有明确交代

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 交通工程师 | 本地单机使用 | 导入、归并、复核、导出全部操作 |

### 2.2 功能模块

1. **导入页**：批量导入疏导记录（支持JSON/CSV），含脏数据识别与标注
2. **归并页**：自动归并同名路口、重复投诉，标记坐标偏移和跨时段统计，展示归并理由
3. **复核页**：人工逐条确认或修正疏导记录，可修改状态和备注
4. **导出页**：按"已处理/待核实/需要现场复看"分类导出公示清单，含疏导原因和来源追溯

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 导入页 | 数据源选择 | 选择文件上传或粘贴JSON/CSV数据 |
| 导入页 | 导入预览 | 预览解析结果，标注脏数据（同名路口、重复、坐标偏移、跨时段） |
| 导入页 | 导入确认 | 确认导入，生成带原始来源和时间戳的记录 |
| 归并页 | 自动归并 | 基于路口名称+坐标自动聚类，展示归并逻辑和冲突提示 |
| 归并页 | 冲突列表 | 列出容量超限、时段冲突、坐标偏移等异常，用人话解释 |
| 归并页 | 手动归并 | 允许人工合并或拆分记录 |
| 复核页 | 记录列表 | 按状态筛选（顺利/待确认/旧口径），逐条展示来源和处理时间 |
| 复核页 | 状态操作 | 将记录标记为已处理/待核实/需要现场复看，添加备注 |
| 导出页 | 分类预览 | 三类（已处理/待核实/需要现场复看）分别预览 |
| 导出页 | 导出操作 | 导出CSV/JSON，每条含疏导原因、原始来源、处理时间 |

## 3. 核心流程

用户打开工具 → 导入原始材料 → 系统自动归并并标记异常 → 人工逐条复核确认 → 按三类导出公示清单

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰（#1a1a2e）搭配琥珀色（#e8a838）强调色，体现市政交通的严肃与效率
- 辅助色：蓝灰（#4a5568）用于背景分区，绿色（#38a169）表示已处理，橙色（#dd6b20）表示待核实，红色（#e53e3e）表示需要现场复看
- 按钮风格：圆角矩形，轻微阴影，hover时微浮起
- 字体：标题用 Noto Serif SC，正文用 Noto Sans SC，数据用 JetBrains Mono
- 布局：左侧导航 + 右侧内容区，卡片式布局
- 图标：lucide-react 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 导入页 | 数据源选择 | 上传区域（虚线边框拖拽区），粘贴区域（代码编辑器风格） |
| 导入页 | 导入预览 | 表格展示，脏数据行标红底，tooltip显示具体问题 |
| 归并页 | 自动归并 | 聚类卡片，冲突项用橙色边框+警告图标 |
| 归并页 | 冲突列表 | 列表形式，每条含人话说明文字 |
| 复核页 | 记录列表 | 表格+状态标签，每行展开显示来源和操作时间 |
| 复核页 | 状态操作 | 下拉选择+确认按钮，右侧历史时间线 |
| 导出页 | 分类预览 | 三栏Tab切换预览，每条含完整溯源信息 |
| 导出页 | 导出操作 | 格式选择+下载按钮，导出含疏导原因说明 |

### 4.3 响应式

桌面优先设计，最小宽度1024px，适合办公室大屏操作。移动端仅做基本可用，不作为重点。

## 5. 样例数据设计

样例数据包含以下场景，覆盖"轨道站口共享单车疏导"从导入到导出的完整流程：

1. **顺利记录**：龙阳路站2号口，单车容量正常，来源为"2024年3月巡查记录"，自动归并无冲突，状态→已处理
2. **人工确认记录**：世纪大道站1号口，存在同名路口（世纪大道站1号口出现两次，坐标偏移约200米），需人工确认是否为同一疏导点
3. **旧口径记录**：静安寺站3号口，来源为"2023年12月现场会议纪要"，统计口径与当前不一致，标记为"旧口径补入"，状态→需要现场复看

脏数据场景：
- 同名路口：世纪大道站1号口出现两条，坐标不同
- 重复投诉：人民广场站2号口同一时段出现两次投诉
- 坐标偏移：南京西路站4号口记录坐标与实际位置偏移超过300米
- 跨时段统计：徐家汇站1号口早晚高峰数据被合并为一条
