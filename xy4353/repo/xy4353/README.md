# 老照片底片扫描管理工具

一个本地桌面应用，用于管理老照片底片扫描流程，解决漏扫、重名、分辨率不够、修复备注不同步等问题。

## 功能特性

### 📥 数据导入
- 支持 CSV 格式的扫描清单导入
- 支持中英文表头自动识别
- 导入前预览和风险预检
- 支持自定义最低分辨率要求

### 📋 记录管理
- 底片盒、张号、扫描文件、分辨率等信息管理
- 修复状态跟踪（未修复、修复中、已修复）
- 责任人登记
- 修复备注同步
- 交付图文件记录

### ⚠️ 风险检查引擎
自动检测以下风险：
- **缺文件** - 记录缺少扫描文件名，可能漏扫
- **重复编号** - 同一底片盒和张号重复
- **分辨率不足** - 低于设置的最低 DPI 要求
- **已修复未生成交付图** - 标记修复完成但无交付文件

### ✅ 逐条复核
- 步骤式复核界面
- 支持"通过"和"有问题"改判
- 复核备注记录
- 复核进度统计

### 📤 导出交付
- **Markdown 交接单** - 适合打印存档或邮件传递
- **JSON 审计包** - 完整数据备份和审计追踪
- 支持导出前预览
- 一键导出全部

### 💾 数据持久化
- 本地存储，数据不丢失
- 自动保存状态
- 支持随时关闭和继续

## 技术栈

- **框架**: Electron + React
- **UI**: Ant Design
- **数据**: localStorage 持久化
- **CSV 解析**: Papa Parse

## 安装和运行

### 环境要求
- Node.js 16.0 或更高版本
- npm 或 yarn 包管理器

### 安装依赖

```bash
npm install
```

### 开发运行

```bash
npm start
```

这会同时启动 React 开发服务器和 Electron 窗口。

### 构建打包

```bash
# 构建 React 应用
npm run build

# 打包成桌面应用
npm run electron:build
```

打包后的应用会生成在 `dist` 目录下。

## 使用指南

### 第一步：准备 CSV 文件

创建扫描清单 CSV 文件，格式如下：

```csv
盒号,张号,扫描文件,分辨率,责任人,修复状态,备注
A001,1,A001_001.tif,300,张三,已修复,
A001,2,A001_002.tif,300,张三,修复中,轻微划痕
A001,3,A001_003.tif,600,李四,未修复,
B001,1,B001_001.tif,300,王五,已修复,
```

**支持的表头名称（不区分大小写）**：
| 字段 | 支持的表头 |
|------|-----------|
| 底片盒号 | boxId, boxId, box_id, 盒号, 底片盒 |
| 张号 | frameNumber, frame_number, 张号, 编号 |
| 扫描文件 | scanFile, file, filename, 扫描文件, 文件 |
| 分辨率 | resolution, dpi, 分辨率 |
| 责任人 | responsible, 责任人, 负责人 |
| 修复状态 | repairStatus, 修复状态, 状态 |
| 备注 | remarks, 备注, 说明, 描述 |

### 第二步：导入数据

1. 打开应用，进入「数据导入」页面
2. 点击或拖拽 CSV 文件到上传区域
3. 点击「解析 CSV」查看预览
4. （可选）点击「风险预检」提前发现问题
5. 确认无误后点击「确认导入数据」

### 第三步：风险检查

1. 进入「风险检查」页面
2. 点击「执行风险检查」
3. 查看风险列表，按类型和状态筛选
4. 点击「处理」按钮处理风险
5. 可选择：已解决、确认问题、忽略此风险

### 第四步：逐条复核

1. 进入「复核处理」页面
2. 使用步骤导航或上/下条按钮浏览记录
3. 查看详细信息
4. 点击「通过」或「有问题」标记复核状态
5. 可点击「编辑详情」修改记录信息

### 第五步：导出交付

1. 进入「导出交付」页面
2. 查看当前统计数据
3. 可点击「预览」查看导出内容
4. 选择导出方式：
   - 「导出 Markdown」- 生成交接单
   - 「导出 JSON」- 生成审计包
   - 「一键导出全部」- 同时导出两种格式

## 界面功能说明

### 数据导入页面
- **CSV 格式要求**: 展示支持的字段说明
- **下载示例**: 下载 CSV 模板文件
- **最低分辨率**: 设置最低 DPI 要求（默认 300 DPI）

### 记录列表页面
- **统计卡片**: 总记录数、修复状态统计
- **搜索筛选**: 支持按盒号、张号、文件、责任人搜索
- **批量筛选**: 按底片盒、修复状态筛选
- **增删改**: 支持添加、编辑、删除记录

### 风险检查页面
- **风险统计**: 总风险数、待处理、已解决、已忽略
- **风险列表**: 详细的风险记录表格
- **风险类型说明**: 四种风险类型的具体含义
- **处理模态框**: 记录处理人、处理备注

### 复核处理页面
- **进度统计**: 复核进度百分比
- **步骤导航**: 可视化复核进度
- **详细信息**: 完整的记录详情展示
- **快速操作**: 通过/有问题一键标记

### 导出交付页面
- **实时统计**: 导出前的数据汇总
- **预览功能**: 查看导出内容格式
- **一键导出**: 同时生成两种格式
- **使用说明**: 导出文件的用途和查看方式

## 数据模型说明

### 记录 (Record)
```javascript
{
  id: "唯一标识符",
  boxId: "底片盒号",
  frameNumber: "张号",
  scanFile: "扫描文件名",
  scanResolution: 300,  // 分辨率 DPI
  repairStatus: "not_repaired",  // 未修复/修复中/已修复
  repairNotes: "修复备注",
  deliveryFile: "交付文件名",
  responsiblePerson: "责任人",
  remarks: "其他备注",
  reviewed: false,  // 是否已复核
  reviewStatus: null,  // pass/fail
  reviewNotes: "复核备注",
  reviewTime: "复核时间",
  createdTime: "创建时间",
  updatedTime: "更新时间"
}
```

### 风险 (Risk)
```javascript
{
  id: "唯一标识符",
  recordId: "关联的记录ID",
  riskType: "missing_file",  // 风险类型
  description: "风险描述",
  status: "pending",  // 待处理/已确认/已解决/已忽略
  handler: "处理人",
  handleNotes: "处理备注",
  createdTime: "发现时间",
  handledTime: "处理时间"
}
```

## 风险类型说明

| 风险类型 | 说明 | 可能原因 |
|---------|------|---------|
| 缺文件 | 记录缺少扫描文件名 | 漏扫、CSV 填写不完整 |
| 重复编号 | 同一底片盒+张号重复 | 重名、误录入 |
| 分辨率不足 | 低于设置的最低要求 | 扫描参数设置错误 |
| 已修复未生成交付图 | 标记修复完成但无交付文件 | 修复备注不同步、遗漏交付 |

## 注意事项

1. **数据备份**: 建议定期导出 JSON 审计包作为备份
2. **CSV 编码**: 请使用 UTF-8 编码保存 CSV 文件，避免中文乱码
3. **分辨率设置**: 根据实际需求调整最低分辨率要求（默认 300 DPI）
4. **关闭应用**: 数据会自动保存，下次打开时自动恢复
