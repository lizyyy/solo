# 麻醉病例复盘工具

一款为宠物医院麻醉师设计的本地桌面小工具，用于复盘当天犬猫手术麻醉监护记录。

## 功能特性

- **多格式数据导入**
  - 病例信息：CSV格式
  - 生命体征数据：JSONL格式（监护仪输出）
  - 药物剂量规则：YAML格式
  - 术后备注：文本格式

- **智能风险检测**
  - 低血压（收缩压<60mmHg或平均压<40mmHg）
  - 低体温（体温<35°C）
  - 药物剂量越界（超出推荐剂量范围）
  - 监护数据断采（间隔超过10分钟）

- **可视化展示**
  - 病例列表管理
  - 时间线视图（手术事件、给药、生命体征、风险事件）
  - 风险事件列表（支持标记确认）
  - 生命体征详细记录
  - 用药记录追踪
  - 术后备注编辑

- **数据导出**
  - 导出问题汇总：`issues.csv`
  - 导出麻醉复盘报告：`anesthesia_report.md`

## 边界情况处理

### 跨午夜手术
- 当手术时间跨越午夜时，自动识别并正确排序事件顺序
- 时间戳仅含时间部分（如"00:00:00"）时，相对于基准日期自动增加一天
- 支持完整日期时间格式和仅时间格式的混合解析

### 体重单位混用
- 自动识别并转换 `kg` 和 `lb`（磅）两种单位
- 药物剂量计算统一使用公斤（kg）作为基准
- 原始单位在界面中保留显示
- 支持带单位的体重值（如 "66 lb" 或 "25 kg"）

## 本地启动步骤

### 方式一：直接运行

```bash
python main.py
```

### 方式二：加载示例数据

1. 启动应用后，点击菜单 `数据` → `加载示例数据`
2. 系统会自动加载 `samples/` 目录下的4个示例病例
3. 在左侧病例列表选择病例进行查看

### 方式三：导入自己的数据

1. **导入病例CSV**：`文件` → `导入病例CSV`
2. **导入监护数据**：选择病例后，`文件` → `导入监护数据JSONL`
3. **导入药物规则**：`文件` → `导入药物规则YAML`
4. **分析风险**：点击 `分析风险` 按钮

## 数据格式说明

### 病例 CSV 格式

```csv
case_id,patient_name,species,weight,surgery_type,start_time,end_time,anesthesiologist,notes
CASE001,旺财,dog,25 kg,去势术,2026-05-03 09:00:00,2026-05-03 10:30:00,李医生,常规去势术
```

字段说明：
- `species`: `dog` 或 `cat`（支持中文"犬"/"猫"）
- `weight`: 支持 "25 kg" 或 "66 lb" 格式
- `start_time/end_time`: 支持多种日期时间格式

### 生命体征 JSONL 格式

每行一个JSON对象：

```json
{"timestamp": "09:00:00", "heart_rate": 90, "respiratory_rate": 20, "systolic_bp": 120, "diastolic_bp": 80, "mean_bp": 93, "temperature": 37.8, "spo2": 99, "etco2": 38, "source": "monitor"}
```

字段说明：
- `timestamp`: 支持 "HH:MM:SS" 或完整日期时间格式
- 所有数值字段支持空值（`null` 或省略）

### 药物规则 YAML 格式

```yaml
drugs:
  - name: Propofol
    species: [dog, cat]
    min_dose_per_kg: 3.0
    max_dose_per_kg: 8.0
    dose_unit: mg
    route: IV
    notes: 诱导麻醉剂
```

### 用药记录 YAML 格式

```yaml
administrations:
  - time: "09:00:00"
    name: Propofol
    dose: 100
    dose_unit: mg
    route: IV
    notes: 诱导麻醉
```

## 风险类型说明

| 风险类型 | 触发条件 | 严重程度评估 |
|---------|---------|-------------|
| 低血压 | SBP < 60mmHg 或 MAP < 40mmHg | 持续>10分钟或SBP<40为高危 |
| 低体温 | 体温 < 35°C | 持续>30分钟或<32°C为高危 |
| 剂量越界 | 超出药物推荐剂量范围 | 偏离50%以上为中/高危 |
| 监护断采 | 数据间隔>10分钟 | 间隔>30分钟为高危 |

## 数据存储

- 本地数据库存储于用户目录：`~/.anesthesia_review/data.db`
- 使用 SQLite 单文件数据库，便于备份和迁移
- 所有导入的数据都会持久化保存

## 导出功能

### 导出问题CSV

包含所有风险事件的详细信息：
- 病例信息
- 风险类型和严重程度
- 时间范围
- 描述
- 确认状态

### 导出麻醉报告MD

Markdown格式的完整复盘报告，包含：
- 基本信息表格
- 风险摘要统计
- 分等级风险事件详情
- 用药记录表
- 生命体征摘要（最值/平均值）
- 术后备注

## 使用流程

1. **导入数据**
   - 导入病例CSV
   - 对每个病例导入对应的监护数据JSONL
   - 导入药物剂量规则（一次导入，所有病例共用）

2. **分析风险**
   - 选择病例
   - 点击「分析风险」按钮
   - 系统自动检测并标记风险事件

3. **查看与确认**
   - 查看时间线了解事件顺序
   - 查看风险事件列表
   - 选中风险后点击「确认选中风险」

4. **导出报告**
   - 导出 `issues.csv` 用于问题追踪
   - 导出 `anesthesia_report.md` 用于存档和分享

## 常见问题

**Q: 跨午夜手术的时间如何处理？**
A: 系统会自动检测时间戳的递减情况，对于跨越午夜的事件自动增加一天。确保手术开始时间包含完整日期。

**Q: 体重单位不同会影响剂量计算吗？**
A: 不会。系统会自动将所有体重转换为公斤(kg)进行药物剂量计算，但在界面上会保留显示原始单位。

**Q: 监护仪数据有缺失怎么办？**
A: 系统会自动检测数据断采（间隔>10分钟）并标记为风险事件。建议在备注中记录断采原因。

**Q: 如何备份数据？**
A: 直接复制 `~/.anesthesia_review/data.db` 文件即可。也可以通过导出CSV/MD报告进行备份。

## 技术栈

- **GUI框架**: Python Tkinter (内置，无需额外安装)
- **数据解析**: 自定义解析器，支持多种日期时间格式
- **数据存储**: SQLite3 (单文件数据库)
- **依赖库**:
  - PyYAML: YAML文件解析
  - python-dateutil: 灵活的日期时间解析
