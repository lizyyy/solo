# 3D舞台吊杆防撞预演工具

一个用于舞美技术人员的舞台吊杆运动模拟和风险预演工具，使用Three.js进行3D可视化回放。

## 功能特性

- 🎭 **3D可视化回放** - 使用Three.js实时渲染舞台吊杆运动
- 📊 **风险检测** - 自动检测碰撞、超重、越界和安全距离不足等风险
- 🎬 **Cue回放控制** - 支持播放、暂停、步进、拖拽等回放控制
- 📁 **多格式支持** - 支持导入YAML舞台配置、CSV灯具数据、JSON Cue计划
- 📝 **报告导出** - 导出风险问题CSV和详细的Markdown回放报告
- 🛡️ **脏数据处理** - 智能处理缺失尺寸、时间倒序等异常数据

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动本地服务器

```bash
npm start
```

然后在浏览器中打开 `http://localhost:8080`

### 使用示例数据

1. 启动服务器后，点击页面顶部的 **"加载示例数据"** 按钮
2. 点击 **"分析风险"** 按钮进行风险检测
3. 在 **"风险"** 标签页查看检测到的问题
4. 在 **"控制"** 标签页控制回放动画

## 数据格式说明

### 1. stage.yaml - 舞台配置

定义舞台尺寸和吊杆轨道信息：

```yaml
stage:
  name: "主舞台"
  dimensions:
    width: 16.0    # 舞台宽度 (m)
    depth: 12.0     # 舞台深度 (m)
    height: 8.0     # 舞台高度 (m)
  unit: "meter"

battens:
  - id: "B1"              # 吊杆唯一标识
    name: "前檐景杆"      # 吊杆名称
    position:
      x: 0.0              # X轴位置
      y: 2.5              # Y轴位置（舞台深度方向）
    track:
      min_height: 0.5     # 最低允许高度
      max_height: 7.5     # 最高允许高度
    max_load: 500.0       # 最大载荷 (kg)
    speed: 0.3            # 移动速度 (m/s)

safety:
  minimum_gap: 0.3        # 吊杆间最小安全距离 (m)
  maximum_speed: 0.5      # 最大允许速度 (m/s)
```

### 2. fixtures.csv - 灯具/布景数据

定义挂载在吊杆上的灯具和布景：

| 字段 | 说明 | 示例 |
|------|------|------|
| id | 设备唯一标识 | F1 |
| name | 设备名称 | 主LED屏 |
| batten_id | 所属吊杆ID | B2 |
| type | 类型 | screen/set/light |
| width | 宽度 (m) | 8.0 |
| height | 高度 (m) | 4.0 |
| depth | 深度 (m) | 0.3 |
| weight | 重量 (kg) | 350.0 |
| x_offset | X轴偏移 | 0.0 |
| y_offset | Y轴偏移 | 0.0 |
| z_offset | Z轴偏移 | 0.0 |

示例CSV内容：
```csv
id,name,batten_id,type,width,height,depth,weight,x_offset,y_offset,z_offset
F1,主LED屏,B2,screen,8.0,4.0,0.3,350.0,0.0,0.0,0.0
F2,左侧屏,B3,screen,3.0,4.0,0.3,180.0,-3.0,0.0,0.0
```

### 3. cue_plan.json - Cue计划

定义每个Cue的吊杆高度和移动时间：

```json
{
  "show_name": "测试演出",
  "cues": [
    {
      "cue_id": "Q1",
      "cue_name": "开场",
      "start_time": 0.0,           # 开始时间 (s)
      "transition_time": 5.0,      # 过渡时间 (s)
      "batten_positions": {
        "B1": { "height": 7.0 },   # 吊杆目标高度
        "B2": { "height": 7.0 },
        "B3": { "height": 7.0 }
      }
    }
  ]
}
```

## 风险检测类型

### 1. 碰撞风险 (Critical)
检测吊杆在移动过程中，挂载的灯具/布景是否会发生物理碰撞。

### 2. 超重风险 (Warning)
检测吊杆的总载荷是否超过其最大承重限制。

### 3. 越界风险 (Warning)
检测吊杆高度是否超出轨道的最低/最高限制。

### 4. 安全距离不足 (Warning)
检测相邻吊杆在同一区域时，高度差是否小于安全距离。

## 脏数据处理

工具能够智能处理以下异常数据：

- **缺失尺寸** - 使用默认尺寸 (0.5m × 0.5m × 0.5m)
- **缺失重量** - 假设重量为0kg
- **无效吊杆ID** - 忽略无效引用
- **时间倒序** - 自动按时间重新排序
- **时间重叠** - 调整为连续移动
- **负数值** - 取绝对值或使用默认值

## 导出功能

### issues.csv
包含所有检测到的风险问题，格式：
```csv
"ID","类型","严重程度","描述","Cue","时间(s)","相关吊杆1","相关吊杆2"
"overweight_B3","overweight","warning","吊杆 \"侧屏吊杆\" (B3) 超重: 当前 1180.0kg / 最大 600kg","-","-","B3","-"
```

### replay_report.md
包含详细的回放报告，包括：
- 项目概览
- 风险统计和详情
- Cue列表

## 界面说明

### 左侧边栏

1. **文件标签**
   - 数据统计显示
   - 文件上传区域（支持拖拽）
   - 验证错误/警告显示

2. **风险标签**

   - 风险详情列表（按严重程度排序）

3. **控制标签**
   - 回放控制按钮（播放/暂停/重置/步进）
   - 时间轴滑块
   - Cue列表（点击跳转到对应Cue）

### 右侧视口

- 3D舞台视图
- 视角切换按钮（俯视图/正视图/侧视图/自由视角）
- 当前Cue和时间显示

## 技术栈

- **前端框架**: 原生JavaScript (ES6+)

- **开发服务器**: serve

## 注意事项

1. **浏览器兼容性**
   - 推荐使用最新版本的Chrome或Firefox
   - 需要支持WebGL和ES6 Module

2. **性能优化**
   - 大型舞台（超过20个吊杆）可能需要更强的GPU
   - 建议在台式机上运行以获得最佳体验

3. **数据验证**
   - 工具会自动验证数据并显示警告
   - 请确保关键数据（吊杆ID、Cue时间）正确
