# 风险来电复盘器

社区心理热线督导用的本地"风险来电复盘器"，用于协助督导人员识别、评估和跟踪高风险来电。

## 功能特性

### 核心功能
- **数据导入**：支持导入脱敏通话摘要 JSON、班表 CSV 和回访记录 CSV
- **自动风险识别**：
  - 自伤/自杀风险升级检测（基于文本关键词）
  - 重复来电识别（同一来电者7天内多次来电）
  - 漏回访检测（计划回访未按时完成）
  - 转介超时检测（转介后超过规定时间未处理）
- **轻量文本评分**：基于关键词和上下文的风险评分系统
- **风险队列管理**：按优先级排序的风险来电列表
- **督导功能**：
  - 补充督导意见
  - 手动改判风险等级
  - 查看评估历史
- **数据导出**：
  - Markdown 格式的复盘报告
  - CSV 格式的待办清单

### 风险等级
| 等级 | 颜色 | 评分范围 | 说明 |
|------|------|----------|------|
| 红 | 🔴 | 81-100 | 极高风险（有自杀企图或明确计划） |
| 橙 | 🟠 | 61-80 | 高风险（有自杀意念和具体计划） |
| 黄 | 🟡 | 31-60 | 中风险（有自杀意念但无具体计划） |
| 绿 | 🟢 | 0-30 | 低风险（一般情绪困扰） |

## 使用指南

### 1. 导入数据

通过菜单栏的 **文件** 选项导入以下数据：

#### 通话摘要（JSON）
导入接线员记录的脱敏通话摘要，系统将自动进行风险评估。

**JSON 格式要求：**
```json
[
    {
        "call_id": "CALL_001",
        "caller_id": "C_1001",
        "call_time": "2026-05-03 23:15:00",
        "duration_minutes": 45,
        "summary_text": "来电者表示最近压力很大...",
        "initial_risk_level": "orange",
        "operator_id": "OP_001",
        "operator_name": "张接线员",
        "has_referral": true,
        "referral_to": "市危机干预中心",
        "referral_time": "2026-05-03 23:50:00"
    }
]
```

**必填字段：** `call_id`, `caller_id`, `call_time`, `summary_text`

#### 班表（CSV）
导入接线员排班信息，用于管理值班安排。

**CSV 格式：**
```csv
date,operator_id,operator_name,shift_start,shift_end,role,notes
2026-05-03,OP_001,张接线员,08:00,16:00,接线员,正常班次
```

#### 回访记录（CSV）
导入后续回访记录，系统将自动检测漏回访。

**CSV 格式：**
```csv
follow_up_id,call_id,scheduled_time,actual_time,operator_id,operator_name,content,result,is_completed
FU_001,CALL_001,2026-05-04 10:00:00,,OP_001,张接线员,,,0
```

### 2. 查看风险队列

左侧面板显示按优先级排序的风险来电列表：
- 使用顶部的复选框筛选不同风险等级
- 点击列表项查看来电详情
- 不同风险等级以不同颜色背景区分

### 3. 来电详情

右侧面板包含多个标签页：

#### 来电详情
- 显示基本信息（来电ID、来电时间、接线员等）
- 通话摘要文本
- 回访记录列表

#### 风险评估
- 显示系统识别的风险标志
- 手动改判风险等级（需填写改判原因）
- 查看评估历史记录

#### 督导意见
- 添加新的督导意见
- 查看历史督导意见记录

#### 统计概览
- 总来电数
- 待回访数
- 风险等级分布
- 风险标志分布

### 4. 导出功能

#### 导出 Markdown 复盘报告
选择任意来电记录，通过 **文件 -> 导出当前来电复盘 (Markdown)** 生成详细的复盘报告。

报告包含：
- 基本信息表格
- 风险标志列表
- 通话摘要
- 评估原因
- 回访记录
- 督导意见
- 转介信息

#### 导出 CSV 待办清单
通过 **文件 -> 导出待办清单 (CSV)** 生成待办事项列表，包含：
- 漏回访跟进
- 转介超时
- 高风险回访提醒

## 风险规则说明

### 文本关键词检测

系统会自动检测以下关键词（中英文双语支持）：

| 风险类型 | 关键词示例 | 权重 |
|----------|------------|------|
| 自伤风险 | 割腕、割伤、自残、self-harm | 40 |
| 自杀意念 | 不想活、想死、自杀、want to die | 50 |
| 自杀计划 | 准备好了、计划好了、have a plan | 70 |
| 自杀企图 | 试过了、尝试过、attempted | 90 |

### 上下文加分

除关键词外，系统还会分析上下文：
- 紧急词（现在、马上、立刻）：+5分
- 确定性词（肯定、一定、决定）：+3分
- 方法词（刀片、绳子、农药、跳楼）：每个+8分（最多+30分）

### 其他规则

| 规则 | 触发条件 | 权重 |
|------|----------|------|
| 重复来电 | 同一来电者7天内来电≥2次 | 15/次（最多3次） |
| 风险升级 | 近期风险等级升高 | 25 |
| 漏回访 | 计划回访时间已过且未完成 | 30 |
| 转介超时 | 转介后超过72小时 | 20 |

### 强制升级规则

- 检测到"自杀企图"关键词 → 强制升级为红档（极高风险）
- 检测到"自杀计划"关键词且当前为黄档 → 升级为橙档（高风险）

## 数据安全与隐私

### 本地存储
- 所有数据存储在本地 SQLite 数据库
- 数据库文件位于 `data/db/risk_reviewer.db`
- 数据不会自动上传到任何服务器

### 数据脱敏建议
在导入数据前，建议对以下信息进行脱敏处理：
- 来电者真实姓名 → 使用编号（如 C_1001）
- 具体地址 → 仅保留区域信息
- 身份证号、电话号码 → 移除或脱敏

## 常见问题

### Q: 为什么有些来电没有显示在风险队列中？
A: 检查以下几点：
- 该来电的风险等级是否被筛选掉了（检查顶部筛选框）
- 来电是否有有效的风险评估记录
- 数据库是否正确连接

### Q: 如何重新评估所有来电的风险等级？
A: 使用菜单 **文件 -> 重新评估所有来电**，系统将使用最新的规则重新评估所有记录。

### Q: 导出的文件在哪里？
A: 默认导出到项目根目录下的 `exports/` 文件夹。

### Q: 如何备份数据？
A: 直接复制 `data/db/risk_reviewer.db` 文件即可。恢复时将文件放回原位置。
