## 1. 产品概述
校园食堂备餐游戏是一款面向食堂新人培训的轻3D浏览器模拟游戏，核心目标是通过模拟真实备餐流程，让受训人员掌握按年级分餐、过敏原规避、取餐时间窗口管理等关键技能。
- 解决食堂新人上岗前缺乏真实场景训练的痛点，降低备餐失误率（过敏餐错配、取餐窗口拥堵、备餐浪费）
- 产品价值：将抽象的食堂管理规则转化为可交互、可评分、可回放的训练工具

## 2. 核心功能

### 2.1 用户角色
| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 受训人员 | 食堂新人，通过游戏学习备餐规则 | 进行关卡训练、查看得分、回放历史对局 |
| 主管/管理员 | 查看训练报告、管理关卡配置 | 导出结算报告、配置难度参数 |

### 2.2 功能模块
1. **主菜单页**：关卡选择、训练模式、历史记录、设置
2. **游戏对局页**：3D备餐场景、2D订单队列、时间管理、评分系统
3. **结算报告页**：得分详情、失误分析、回放入口、报告导出
4. **历史回放页**：逐帧回放对局过程、关键事件标记

## 3. 核心流程

### 3.1 主流程
用户进入主菜单 → 选择关卡 → 进入游戏对局 → 处理订单（备餐+取餐）→ 回合结束 → 查看结算报告 → 可选择回放或返回主菜单

### 3.2 游戏对局流程
玩家点击"开始" → 订单队列开始生成 → 玩家拖拽餐品到对应年级备餐台 → 玩家点击取餐窗口分配等待中的学生 → 时间推进 → 回合结束 → 自动结算

### 3.3 失败条件
- 过敏餐错配：将含过敏原的餐品分配给对该过敏原过敏的学生 → 立即失败并记录
- 严重拥堵：取餐窗口等待人数超过阈值持续指定时间 → 扣分警告
- 大量浪费：备餐量远超实际取餐量 → 结算扣分

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：食堂暖黄色（#F5A623）+ 警示红色（#E74C3C）+ 清新绿（#27AE60）
- 辅助色：年级标识色（一年级蓝 #3498DB、二年级橙 #E67E22、三年级紫 #9B59B6）
- 按钮风格：圆角3D立体按钮，悬浮时微抬升，点击时有按压动效
- 字体：标题使用"站酷快乐体"或圆润无衬线字体，正文使用系统默认无衬线
- 布局风格：3D场景居中，2D面板环绕四周（左侧订单队列、右侧评分、顶部时间条、底部操作栏）
- 图标风格：扁平化线条图标，配合emoji增强亲切感（🍱🥗🍎⚠️⏰）

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主菜单页 | 关卡选择 | 卡片式布局，每卡展示关卡名、难度星级、最高分，悬浮缩放动效 |
| 主菜单页 | 训练模式 | 表单式参数配置（滑块、下拉选择），实时预览参数影响 |
| 游戏对局页 | 3D场景 | 透视视角食堂，备餐台按年级分区着色，取餐窗口排队可视化 |
| 游戏对局页 | 订单队列 | 左侧滑出面板，订单卡片按紧急程度着色（超时红色、临近黄色） |
| 游戏对局页 | 过敏原提示 | 餐品上方悬浮红色⚠️标签，备餐台禁区红色半透明遮罩 |
| 游戏对局页 | 操作反馈 | 拖拽时餐品跟随光标，放置时弹性动画，错误时红色抖动 |
| 结算报告页 | 得分详情 | 环形进度图展示各分项得分，失误列表带时间线 |
| 历史回放页 | 回放控制 | 底部控制栏，进度条带事件标记点，速度切换按钮 |

### 4.3 响应式设计
- 桌面端优先：1280x720及以上分辨率完美显示
- 平板适配：768px以上，面板自动调整位置
- 触屏优化：所有拖拽和点击操作支持触摸手势，按钮最小48x48px触控区域
- 不支持手机竖屏（游戏需要较宽阔操作空间）

### 4.4 3D场景指导
- 环境：室内食堂，暖色调点光源模拟顶灯，墙面简化处理
- 灯光：主光源模拟顶灯照射备餐台，辅助光突出取餐窗口
- 相机：固定俯视45度角，可鼠标拖拽平移，滚轮缩放
- 构图：备餐台居左，取餐窗口居右，中央区域为操作通道
- 交互：餐品模型可拖拽，学生角色在取餐窗口排队移动
- 动画：餐品放置弹性动效，学生走到窗口取餐动画，错误操作红色闪烁
- 后期：轻微泛光效果增强温暖感，边缘阴影增加立体感
- 性能预算：总面数控制在5万面以内，draw call不超过200

## 5. 游戏规则与计分系统

### 5.1 备餐规则
- 每个年级有对应的备餐台分区，餐品必须放到对应分区
- 含过敏原的餐品有明确标注，严禁分配给对该过敏原过敏的学生
- 备餐台有容量限制，超出则产生浪费

### 5.2 取餐规则
- 学生按取餐时间在对应窗口排队
- 窗口拥堵超过阈值扣分
- 取餐超时（超过指定时间窗口）扣分

### 5.3 计分系统
- 基础分：每个正确备餐+10分，正确取餐+15分
- 连击奖励：连续正确操作，每5连击额外+20分
- 扣分：过敏错配-100分（严重），取餐超时-30分，拥堵-20分，浪费-15分
- 关卡目标：达到指定分数通过，未达标则需重玩

|------|------|--------|------------|----------|----------|

| 进阶挑战 | ★★ | 40单 | 25% | 3个 | 5分钟 |
| 高峰时段 | ★★★ | 60单 | 35% | 4个 | 7分钟 |
| 过敏演练 | ★★★ | 30单 | 50% | 2个 | 4分钟 |
