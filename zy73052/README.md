# 塔吊维保备件排程

同一结果集驱动 **筛选 / 统计 / 明细 / 摘要**，异常单独拎出，线索可追溯，重跑不丢备注。

## 启动

```bash
npm install
npm run dev
```

## 三步操作

1. **设筛选**：选日期范围、塔吊、部件类别、状态；点「只看异常」可只保留异常记录。
2. **生成结果**：点「生成排程结果」。同一份结果同时驱动统计卡片、明细表格、结论面板、页面摘要。
3. **结论下钻**：在「结论与排程建议」或「异常单独拎出」面板里点关联记录 → 明细行会高亮并展开，查看 **异常证据** 和 **关联结论**（含「结论变化说明」）。

## 坏材料来了看哪里

| 现象 | 先看 | 再看 |
|---|---|---|
| 采样断档（`未采集`） | 「异常单独拎出」→ `采样断档` 组 | 展开明细行 → `异常证据` 看是哪天哪台谁巡检，结论面板里有「断档数量变化会直接影响统计均值」的变化说明 |
| 阈值超限（实测破阈值） | 「异常单独拎出」→ `阈值突破` 组 | 展开行 → 证据里有「超出多少单位」；看对应结论里的 `deltaNote`（结论变化说明） |
| 在阈值内但看着怪 | 「异常单独拎出」→ `被均值掩盖` 组 | 证据里给了 Z 分数和批次均值，解释为啥没被平均盖住 |
| 重跑后结论变了 | 顶部批次号 + 页面摘要「历史版本」| 结论的 `⚠ 结论变化说明` 字段说明本次结论为啥和上次不一样 |
| 想找上次备注 | 明细最后一列「备注」直接显示 | 页面摘要「运行快照」可点回老批次重算 |
