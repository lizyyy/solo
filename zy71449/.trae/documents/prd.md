## 1. 产品概述

保险灾害损失立方是一款面向保险精算师的 3D 可视化分析工具，将台风路径、地区保单分布和赔付金额融合在同一 3D 立方空间中，实现灾害损失的多维度穿透式分析。

- 解决保险精算中台风灾害数据分散、聚合后溯源困难、极端值遮蔽等问题，确保每条数据从源头可追溯
- 目标用户为保险精算师和再保分析师，产品价值在于提升灾害损失评估的透明度、可复核性和决策效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 精算分析师 | 直接访问 | 创建/编辑损失立方、调整参数、时间切片、地区钻取、导出 |
| 复核审计员 | 直接访问 | 查看历史立方、审查处理决策、比对导出数据 |

### 2.2 功能模块

1. **损失立方主页面**: 3D 立方可视化、侧边参数面板、数据统计面板、时间轴控制器
2. **历史记录页面**: 历史立方列表、参数快照对比、导出记录追溯

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 损失立方主页面 | 3D 损失立方 | 三轴分别为时间(X)、地区(Y)、赔付额(Z)；台风路径以曲线叠加在立方内；保单分布以柱体表示；极端赔付以红色高亮标记，不遮挡底层 |
| 损失立方主页面 | 侧边参数面板 | 实时调节台风事件、时间范围、地区筛选、赔付阈值等参数，参数变化后 3D 场景与侧边数据同步更新 |
| 损失立方主页面 | 时间切片控制器 | 沿时间轴拖动切片，展示特定时刻的保单分布与赔付快照，切片数据与 3D 场景联动 |
| 损失立方主页面 | 地区钻取面板 | 点击 3D 立方中的地区柱体，下钻到该地区的保单明细与赔付明细，保持数据溯源链完整 |
| 损失立方主页面 | 数据溯源面板 | 展示当前视图中每条数据的来源（台风路径/保单/赔付），标记时间错位与聚合异常，不允许被覆盖 |
| 损失立方主页面 | 导出面板 | 将 3D 视图、时间切片、地区钻取结果汇入同一导出报告，附带处理决策说明，支持 JSON/CSV 导出 |
| 损失立方主页面 | 异常标记引擎 | 自动检测路径时间错位、地区聚合冲突、极端赔付异常，在 3D 场景与面板中同时标记，历史留痕 |
| 历史记录页面 | 历史立方列表 | 展示所有已创建的损失立方，包含参数快照、处理决策、异常标记记录 |
| 历史记录页面 | 对比面板 | 选择两个历史立方进行参数与结果对比，差异高亮 |
| 历史记录页面 | 审计追溯面板 | 查看每个历史立方的处理决策原因（为什么这么聚合、为什么排除某些数据），确保复盘时可理解 |

## 3. 核心流程

用户打开应用 → 选择或创建台风事件 → 加载保单与赔付数据 → 在 3D 立方中浏览多维数据 → 调节参数实时联动 → 发现异常标记 → 时间切片/地区钻取深入分析 → 导出统一报告 → 保存到历史记录。

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**: 深海军蓝 (#0A1628) 为底色，搭配冰蓝 (#00D4FF) 强调色，传达专业冷静的精算氛围
- **辅助色**: 风暴橙 (#FF6B35) 标记异常，翠绿 (#00E676) 标记正常，琥珀黄 (#FFD600) 标记警告
- **按钮风格**: 半透明磨砂质感，圆角 6px，悬停时边框发光
- **字体**: 数据展示使用 JetBrains Mono 等宽字体，标题使用 Noto Sans SC，正文字号 14px
- **布局**: 左侧 3D 立方占据主体 (70%)，右侧参数与数据面板 (30%)，底部时间轴控制条
- **图标**: 线性描边风格，2px 粗细，与数据可视化语境匹配

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 损失立方主页面 | 3D 损失立方 | 深色背景 + 半透明立方体边框，台风路径为发光曲线，保单柱体为蓝绿色渐变，极端赔付为红色脉冲光柱，OrbitControls 旋转/缩放 |
| 损失立方主页面 | 侧边参数面板 | 磨砂玻璃面板，滑块/下拉/日期选择器，参数变更实时反射到 3D 场景，带数值标签 |
| 损失立方主页面 | 时间轴控制器 | 底部水平时间轴，可拖动切片指示器，时间范围高亮，锚点标记台风关键时间节点 |
| 损失立方主页面 | 地区钻取面板 | 点击柱体弹出抽屉式面板，展示该地区保单明细表与赔付曲线图，溯源链标签 |
| 损失立方主页面 | 数据溯源面板 | 折叠式面板，按数据源分组，时间错位以橙色警告图标标记，异常不可删除只能标记已确认 |
| 损失立方主页面 | 导出面板 | 右下角浮层，导出格式选择，包含当前参数快照与异常标记，一键导出 |
| 损失立方主页面 | 异常标记引擎 | 3D 场景中异常数据点悬浮警告标签，侧边面板同步高亮，点击跳转至数据溯源 |
| 历史记录页面 | 历史立方列表 | 卡片列表，每张卡片展示立方缩略图、参数摘要、创建时间、异常数量徽标 |
| 历史记录页面 | 对比面板 | 左右分栏展示两个立方参数，差异行高亮橙色背景 |
| 历史记录页面 | 审计追溯面板 | 时间线式展示，每个处理决策节点包含原因文本、操作人、时间戳 |

### 4.3 响应式设计

- 桌面优先设计，3D 立方要求最小 1024px 宽度
- 平板适配：侧边面板转为可收起抽屉，时间轴简化
- 移动端：仅展示 2D 数据面板摘要，3D 场景降级为静态截图

### 4.4 3D 场景指引

- **环境**: 深色空间环境，微弱网格地面，营造数据太空感
- **灯光**: 环境光 (0x1a2a4a, 强度 0.6) + 方向光 (0x00d4ff, 强度 0.8) + 点光源标记异常点
- **相机**: 透视相机，初始位置 (15, 12, 15)，目标点 (0, 0, 0)，45° 俯视角
- **交互**: OrbitControls 旋转缩放，鼠标悬停高亮数据点，点击触发钻取
- **动画**: 台风路径流动动画，异常点脉冲动画，参数切换时平滑过渡
- **后期处理**: 泛光效果 (Bloom) 用于台风路径发光，环境光遮蔽增加深度感
- **性能预算**: 初始加载 < 3s，交互响应 < 100ms，目标 60fps
