## 1. 产品概述

冷库门帘热损失核算工具，专为设备工程师何工设计，用于处理设备巡检表中的冷库门帘热损失数据，解决数据混乱、单位不统一、阈值判断不清晰的问题。

- 核心目标：将分散的巡检数据系统化，提供统一的核算流程、阈值提醒和报告输出
- 核心价值：确保计算可追溯、阈值版本可控、处理建议可执行，便于后续人员接手

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 设备工程师 | 本地浏览器访问 | 导入数据、参数配置、阈值调整、报告导出、历史对比 |

### 2.2 功能模块

1. **数据导入与清洗模块**：支持巡检数据导入、采样缺口处理、单位自动识别与换算
2. **热损失核算模块**：基于物理近似公式的热损失计算、参数可配置
3. **阈值管理模块**：阈值配置、版本追踪、超阈值预警
4. **备注补录模块**：单条记录补录备注、差异对比展示
5. **报告生成模块**：业务友好的处理建议、导出报告
6. **历史对比模块**：重跑数据时历史参数与新结果并排比较、审计追踪

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主计算面板 | 数据导入区 | 支持粘贴/上传巡检数据，预览原始数据 |
| 主计算面板 | 数据清洗区 | 显示采样缺口、单位混写情况，提供处理选项 |
| 主计算面板 | 核算参数区 | 配置物理参数、阈值，显示阈值版本历史 |
| 主计算面板 | 计算结果区 | 展示核算结果、超阈值高亮、风险等级 |
| 备注补录面板 | 补录区 | 选择记录添加备注，显示补录前后差异 |
| 历史对比面板 | 对比区 | 选择历史批次，并排展示参数和结果差异 |
| 报告导出面板 | 报告区 | 生成业务友好的处理建议报告，支持导出 |

## 3. 核心流程

### 3.1 主流程描述

设备工程师何工导入巡检数据 → 系统自动识别数据问题（采样缺口、单位混写）→ 配置核算参数和阈值 → 执行热损失计算 → 查看超阈值预警 → 补充备注信息 → 生成并导出报告 → 后续重跑时可对比历史版本

### 3.2 流程图

```mermaid
flowchart LR
    A["导入巡检数据"] --> B["数据质量检测"]
    B --> C{"存在数据问题?"}
    C -->|是| D["展示问题并提供处理方案"]
    C -->|否| E["配置核算参数"]
    D --> E
    E --> F["选择阈值版本"]
    F --> G["执行热损失计算"]
    G --> H["结果展示与预警"]
    H --> I["补录备注信息"]
    I --> J["生成处理建议报告"]
    J --> K["导出/保存结果"]
    K --> L["历史对比(可选)"]
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：工业蓝 (#165DFF) 作为主色，搭配深灰 (#1D2129) 背景，体现专业工程感
- **辅助色**：预警红 (#F53F3F)、提醒橙 (#FF7D00)、正常绿 (#00B42A) 用于状态标识
- **按钮风格**：直角矩形、轻微阴影，工业风设计
- **字体**：选用 JetBrains Mono 等宽字体展示数据，Inter 作为 UI 字体
- **布局风格**：卡片式分区布局，左侧导航，右侧内容区，信息密度适中
- **图标风格**：线性图标，简洁工业风

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|-----------|-------------|-------------|
| 主计算面板 | 数据导入区 | 拖放区域、文件选择按钮、数据预览表格 |
| 主计算面板 | 数据清洗区 | 问题统计卡片、问题列表、处理按钮组 |
| 主计算面板 | 核算参数区 | 参数输入表单、阈值版本选择器、版本历史 |
| 主计算面板 | 计算结果区 | 结果表格（带状态高亮）、汇总统计卡片 |
| 备注补录面板 | 补录区 | 记录选择器、备注输入框、差异对比视图 |
| 历史对比面板 | 对比区 | 批次选择器、双栏对比布局、差异高亮 |
| 报告导出面板 | 报告区 | 报告预览、处理建议列表、导出按钮 |

### 4.3 响应式设计

- 桌面端优先设计（针对工程师桌面工作场景）
- 支持平板适配，关键表格可横向滚动
- 触控元素最小尺寸 44px，便于平板操作

### 4.4 动效设计

- 页面加载：卡片渐入动画（staggered 延迟）
- 数据更新：数值变化平滑过渡
- 预警提示：轻微脉冲动画吸引注意
- 标签切换：内容区淡入淡出过渡
