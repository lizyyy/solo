📥 导入人工改判表

支持 Excel (.xlsx, .xls) 和 CSV 格式。
去重机制：同一批次ID重复导入时，会对比每行数据，只更新有变化的字段，不会重复计数。
保留证据：导入时自动记录原始行号，所有改动留痕可追溯。

📋 支持的列名（中英文兼容）：
  • 问题ID / question_id
  • 问题 / question
  • 原结论 / original_conclusion
  • 人工改判结论 / manual_conclusion
  • 备注 / manual_remark
  • 提示词版本号 / prompt_version
  • 引用链接 / reference_url
  • 链接状态 / reference_url_status（200/404/unknown）
