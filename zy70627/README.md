# 美容院疗程核销转店延期状态排查CLI

用于排查美容院疗程核销中的各类问题，包括转店验证、赠送扣减、延期申请、核销对账等。

## 项目结构

- `models.py` - 核心数据模型（顾客、疗程包、核销记录、延期申请等）
- `rules_engine.py` - 业务规则引擎（套餐拆分、转店确认、赠送扣减、延期状态机）
- `cli.py` - 命令行界面和报告导出

## 核心功能

### 1. 完整审计 (audit)
对指定套餐进行全面状态审计，包括：
- 顾客信息
- 套餐基本信息
- 过期状态
- 项目明细（购买/已用/赠送/剩余）
- 核销对账

### 2. 转店验证 (transfer)
验证套餐是否可以转店：
- 套餐状态检查
- 转店次数限制（最多3次）
- 目标门店一致性检查

### 3. 赠送扣减验证 (gift)
验证赠送次数是否合理：
- 剩余次数检查
- 赠送比例预警（>30%）

### 4. 延期申请验证 (extension)
验证延期申请是否合理：
- 新到期日必须晚于当前到期日
- 延期天数超过180天预警
- 避免重复申请

### 5. 过期状态检查 (expiry)
检查套餐是否过期：
- 考虑已审批的延期
- 7天内过期预警

### 6. 核销对账 (reconcile)
对比系统记录与实际核销记录：
- 发现差异（多记/少记）
- 按项目统计核销明细

## 使用方法

### 查看帮助
```bash
python3 cli.py --help
```

### 运行演示

**正常样例演示**（所有验证通过）：
```bash
python3 cli.py demo --type normal
```

**异常样例演示**（包含各类异常情况）：
```bash
python3 cli.py demo --type abnormal
```

### 单独命令示例

```bash
# 完整审计套餐
python3 cli.py audit P001

# 验证转店申请
python3 cli.py transfer P001 STORE_B

# 验证赠送扣减
python3 cli.py gift P001 ITEM001 2

# 验证延期申请
python3 cli.py extension P001 2027-06-30 "客户特殊申请"

# 检查过期状态
python3 cli.py expiry P001

# 核销对账
python3 cli.py reconcile P001

# 导出审计报告
python3 cli.py export P001 -o my_report --format both
```

## 样例数据类型

- `normal` - 正常数据，所有验证通过
- `dirty` - 脏数据，包含各种异常情况（转店超限、核销不一致、已过期等）
- `empty` - 空数据

## 报告格式

同时支持两种格式，确保数据一致性：

1. **人类可读格式** (.txt)
   - 清晰的分类
   - 图标标识状态
   - 表格形式展示明细

2. **机器可读格式** (.json)
   - 结构化数据
   - 可直接用于后续处理
   - 包含完整审计细节

## 验收标准

- ✅ 正常样例：所有验证通过，报告输出一致
- ✅ 异常样例：正确识别各类异常，错误提示准确
- ✅ 历史记录、报告内容、错误提示三者互相对应
