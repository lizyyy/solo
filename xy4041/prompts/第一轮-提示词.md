我想做一个给法务助理和售后仲裁小组用的本地命令行工具，叫“网页证据包整理员”。我们处理退款争议或合同履约纠纷时，经常会从浏览器导出一堆页面保存文件、截图、HAR 网络日志、聊天记录 txt 和附件，人工整理很容易漏掉关键时间点，也怕文件被改过说不清。请从 0 到 1 做一个可运行的 Python CLI 项目：init 命令能创建案件配置，维护证据类型、需要脱敏的字段、时区、时间可信度规则、附件大小限制和输出目录；import 命令能导入一个或多个目录里的 html/mhtml/har/png/jpg/pdf/txt 文件，保留原始文件，计算 SHA256，识别重复文件、同名不同内容和疑似被改过的截图元数据。extract 命令要从 HTML 标题、meta、HAR request/response、文本聊天记录和文件修改时间里抽取事件，统一成带来源、时间、可信度和摘要的 timeline.json；check 命令要校验证据编号缺失、时间倒序、跨时区冲突、附件哈希重复、HAR 里有 4xx/5xx 关键请求、聊天记录缺页、敏感信息未脱敏这些问题，坏项进入 quarantine.json 并说明原因。redact 命令要按配置把手机号、邮箱、身份证号、地址和自定义关键词脱敏，不能改动原始证据，只能生成 redacted 副本；report 命令能导出 Markdown 证据目录、CSV 时间线和 JSON 审计清单，verify 命令能重新校验哈希并报告哪些文件被移动、丢失或内容变化。希望代码拆成 CLI 入口、配置模型、导入与哈希、HTML/HAR/聊天记录解析、时间线合并、校验规则、脱敏器、隔离区、报告导出、示例证据和测试，不要写成一个大脚本。README 里写清楚安装方式、示例命令，以及如何用临时目录验证初始化、导入示例证据、抽取时间线、检查问题、脱敏、导出报告和二次校验这些核心流程。
