# 3D 仓库拣货路线规划工具

一个基于 WebGL 的 3D 仓库布局和拣货路线规划工具，帮助仓库管理人员在重新摆放货架前进行拣货路线预演。

## 功能特性

### 🏭 3D 仓库可视化
- 实时 3D 渲染仓库场景
- 支持多种视图切换（透视、俯视、正视、左视）
- 可旋转、平移、缩放查看场景

### 📦 对象管理
- 新增/编辑/删除货架、货区、出入口和禁放区
- 支持鼠标拖动和旋转对象
- 支持表单精确编辑坐标和尺寸
- 货架支持配置 SKU 位置

### ⚠️ 实时冲突检测
系统会实时检测以下布局问题：
- **对象重叠**：两个对象位置重叠
- **越界警告**：对象超出仓库边界
- **通道宽度不足**：货架之间通道小于最小宽度（默认 1.2m）
- **出入口被挡**：货架阻挡出入口
- **禁放区冲突**：对象位于禁放区内

### 🚚 拣货路线规划
- 支持导入 JSON 或 CSV 格式的拣货单
- 生成最优拣货路线（支持最近邻、2-opt、遗传算法）
- 3D 场景中可视化播放路线
- 显示预计距离和经过的货架点
- 支持手动调整路线顺序
- 对比推荐路线与手动路线的差异

### ✅ 数据验证
自动检测拣货单中的脏数据：
- SKU 找不到
- 货架位不存在
- 数量为负或无效
- 缺少订单号、货架位等必填字段

### 💾 数据持久化
- 本地自动保存工程草稿
- 支持导出/导入整个仓库方案 JSON
- 支持导出 Markdown 或 HTML 格式报告

### 📋 报告生成
报告包含以下内容：
- 布局问题清单（含具体涉及对象）
- 拣货路线摘要
- 总距离统计
- 异常 SKU 列表
- 改摆建议

## 快速开始

### 1. 环境要求
- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 无需安装任何额外软件

### 2. 启动方式
直接用浏览器打开 `index.html` 文件即可：

```bash
# 方式一：直接双击打开 index.html
# 方式二：使用本地 HTTP 服务器（推荐）
python -m http.server 8080
# 然后访问 http://localhost:8080
```

### 3. 首次使用
应用启动后会自动加载示例仓库数据，您可以：
1. 点击左侧对象列表查看和编辑对象
2. 选择对象后在右侧属性面板修改属性
3. 使用顶部工具栏切换工具模式（选择、平移、旋转、移动）
4. 点击「导入拣货单」导入示例数据
5. 点击「生成路线」查看推荐拣货路线

## 使用说明

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| V | 切换到选择工具 |
| H | 切换到平移工具 |
| R | 切换到旋转工具 |
| G | 切换到移动工具 |
| Delete / Backspace | 删除选中对象 |
| Escape | 取消选择 |

### 工具栏说明

- **选择**：点击选择对象，支持框选多个
- **平移**：按住左键拖动平移场景
- **旋转**：选中对象后拖动旋转
- **移动**：选中对象后拖动移动位置

### 导入拣货单

支持两种数据格式：

**JSON 格式：**
```json
[
  {
    "orderNo": "ORD001",
    "sku": "SKU001",
    "quantity": 10,
    "shelfSlot": "A-01-A1",
    "notes": "加急订单"
  }
]
```

**CSV 格式：**
```csv
orderNo,sku,quantity,shelfSlot,notes
ORD001,SKU001,10,A-01-A1,加急订单
ORD001,SKU003,5,A-01-B1,加急订单
```

### 配置货架 SKU

每个货架可以配置多个 SKU 位置，格式如下：
```json
[
  { "slot": "A-01-A1", "sku": "SKU001" },
  { "slot": "A-01-A2", "sku": "SKU002" }
]
```

### 路线优化算法

应用提供三种路线优化算法：

1. **最近邻算法**：快速简单，从起点开始每次选择最近的未访问点
2. **2-opt 算法**：通过交换路径中的两条边来优化路线
3. **遗传算法**：模拟生物进化过程，适合大规模问题

默认使用 2-opt 算法，兼顾效率和优化效果。

## 技术栈

- **Three.js**：WebGL 3D 渲染引擎
- **OrbitControls**：3D 视图交互控制
- **Tween.js**：动画过渡效果
- **纯原生 JavaScript**：无需任何前端框架
- **LocalStorage**：本地数据持久化

## 常见问题

### Q: 为什么需要用本地服务器运行？
A: 由于浏览器安全策略，直接双击打开 HTML 文件可能会遇到一些限制（如文件导入功能）。推荐使用本地 HTTP 服务器。

### Q: 数据保存在哪里？
A: 所有数据都保存在浏览器的 localStorage 中，刷新页面不会丢失。您也可以通过「导出方案」功能将数据保存为 JSON 文件。

### Q: 如何添加新的货架类型？
A: 在 `js/models/` 目录下创建新的模型类，继承自 `WarehouseObject`，然后在 `ObjectRenderer` 中添加对应的渲染逻辑。

### Q: 支持大规模仓库吗？
A: 应用使用 WebGL 渲染，可以支持数百个对象。对于超大规模仓库（超过 1000 个对象），可能需要调整渲染策略（如 LOD、视锥剔除等）。
