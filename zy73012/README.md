# 宠物寄养排程对账

体重曲线背后的用药提醒，不再靠口头交接——统一数据源驱动筛选、统计、明细、异常，全链路可追溯。

## 快速 3 步

1. **打开页面**：双击 `index.html`，或用 `python3 -m http.server 8080` 启动后访问 `http://localhost:8080`。
2. **看异常**：右侧「异常队列」按严重度排序，点每条的「为什么结论变了」读前后对比；点「指回原始记录」定位体重曲线具体哪条。
3. **导对账**：点右上角「导出CSV对账」，交复核人的文件里自带「体重原始字符串列表」「结论变化说明汇总」两列，无需额外解释。

> 试跑说明：数据特意留了 R001 奶盖作为正常记录（体重曲线全 kg 单位、用药全 done、零异常），其余 R002–R007 混入各种问题，模拟真实交接的"半干净半脏"状态。

## 异常类型对照

| 异常标签 | 说明 |
|---------|------|
| 单位混写（中危） | 同一只宠物同时出现 kg / g / lb，系统会自动换算后重算波动，修正初始误判 |
| 坏数据（高危） | 原始录入无法解析（如 `-- 没称上`），完整保留原始字符串与操作人 |
| 体重骤变（高危） | 两日波动 > 30%；如有单位混写会联动降级为「录入问题」 |
| 用药漏记（高危） | 用药提醒 status = missed，自动补全漏记原因字段 |

## 坏材料来了看哪里（重点）

遇到「数据不对劲但说不清楚哪条」时：

1. **先去详情弹窗的「原始线索」Tab**（明细行 → 详情 → 最右 Tab）。这里每条体重日志都有两个代码块：
   - `rawWeight`：原始录入的字符串（追溯关键，坏数据就看这个）
   - `rawSource`：设备/输入快照（秤编号、时间戳、真实输入值）
2. **再点「指回体重曲线」**：进入追溯视图，橙色高亮锚点标在 SVG 曲线上，上方标注对应原始字符串，下方标准化单位 + 操作人 + 关联寄养ID。
3. **复核人从导出CSV追**：CSV 的第 15/18/19 列分别是「体重原始字符串列表」「结论变化说明汇总」「异常解释汇总」，直接用 Excel 筛选对应列即可定位问题记录，无需回系统。

## 数据一致性保证

- 筛选条件、统计卡片、明细表、异常队列 **全部来自同一份 `useReconcileEngine()` 输出**；筛选仅过滤记录集、不重新计算异常，杜绝「统计数字和明细表对不上」。
- 体重单位标准化换算只做一次，结果写回 `weightKg` + `detectedUnit`，任何入口显示的 kg 值一致。
