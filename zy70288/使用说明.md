# 园区能耗分摊 API 系统

## 一、系统概述

本系统是一套园区公共能耗分摊管理 API，支持空调、电梯、照明三种公共能耗按**租户面积**和**使用时段**进行智能分摊。

### 核心功能
1. **租户档案管理** - 管理租户基本信息、承租面积、入住时间
2. **能耗读数管理** - 录入月度能耗数据（空调、电梯、照明）
3. **面积规则配置** - 各楼层公共区域比例、能耗分摊系数
4. **智能分摊计算** - 按面积占比 + 时段比例自动计算分摊费用
5. **账单管理** - 生成、审批、发送、支付账单
6. **争议处理** - 租户争议提交、处理、复核流程
7. **人工修正** - 特殊情况人工调整，需记录审批

### 1. 租户档案管理

#### 创建租户
```http
POST /api/tenants
Content-Type: application/json

{
    "tenant_id": "T001",
    "tenant_name": "科技先锋有限公司",

    "contact_person": "张三",
    "contact_phone": "13800138001"
}
```

**必填字段**：`tenant_id`, `tenant_name`, `floor`, `area`, `start_date`

#### 查询租户列表
```http
GET /api/tenants
```

#### 查询单个租户
```http
GET /api/tenants/{tenant_id}
```

#### 更新租户信息
```http
PUT /api/tenants/{tenant_id}
Content-Type: application/json

{
    "area": 600,
    "contact_phone": "13800138099"
}
```

### 2. 面积规则管理

#### 创建面积规则
```http
POST /api/area-rules
Content-Type: application/json

{
    "floor": 1,
    "public_area_ratio": 0.1,
    "air_conditioning_ratio": 0.6,
    "elevator_ratio": 0.5,
    "lighting_ratio": 0.6,
    "description": "1楼主要办公层"
}
```

**必填字段**：`floor`, `public_area_ratio`, `air_conditioning_ratio`, `elevator_ratio`, `lighting_ratio`

**字段说明**：
- `public_area_ratio`：公共区域占比（0-1）
- `air_conditioning_ratio`：空调能耗分摊比例
- `elevator_ratio`：电梯能耗分摊比例
- `lighting_ratio`：照明能耗分摊比例

#### 查询规则列表
```http
GET /api/area-rules
```

### 3. 能耗读数管理

#### 创建能耗读数
```http
POST /api/energy-readings
Content-Type: application/json

{
    "type": "air_conditioning",
    "period_start": "2024-01-01",
    "period_end": "2024-01-31",
    "total_consumption": 5000,
    "total_cost": 15000,
    "unit_price": 3.0,
    "source": "meter"
}
```

**必填字段**：`type`, `period_start`, `period_end`, `total_consumption`, `total_cost`

**type 可选值**：
- `air_conditioning`：空调
- `elevator`：电梯
- `lighting`：照明

#### 查询读数列表
```http
GET /api/energy-readings
```

### 4. 能耗分摊计算

#### 执行分摊
```http
POST /api/allocate
Content-Type: application/json

{
    "reading_id": "ER-20240101000000",
    "month": "2024-01"
}
```

**分摊算法说明**：
```
租户分摊费用 = 私有部分 + 公共部分

私有部分 = 总费用 × (1 - 公共区域比例) × 面积比例 × 时段比例
公共部分 = 总费用 × 公共区域比例 × 类型比例 × 时段比例

面积比例 = 租户面积 / 所有活跃租户总面积
时段比例 = 租户实际使用天数 / 统计周期总天数
```

### 5. 账单管理

#### 创建账单
```http
POST /api/bills
Content-Type: application/json

{
    "tenant_id": "T001",
    "month": "2024-01",
    "items": [
        {"type": "air_conditioning", "description": "空调能耗", "amount": 8100},
        {"type": "elevator", "description": "电梯能耗", "amount": 1800},
        {"type": "lighting", "description": "照明能耗", "amount": 1620}
    ]
}
```

**必填字段**：`tenant_id`, `month`, `items`

#### 查询账单
```http
GET /api/bills?tenant_id=T001&month=2024-01
```

#### 账单状态流转
```http
PUT /api/bills/{bill_id}/status
Content-Type: application/json

{
    "status": "approved",
    "reason": "财务审批通过"
}
```

**状态机**：
```
draft → pending_review → approved → sent → paid
  ↓          ↓            ↓         ↓
cancelled  rejected     disputed   disputed
              ↓
            draft
```

**合法流转**：
| 当前状态 | 允许流转到 |
|---------|-----------|
| draft | pending_review, cancelled |
| pending_review | approved, rejected, disputed |
| approved | sent, disputed |
| rejected | draft |
| sent | paid, disputed, overdue |
| disputed | resolved, pending_review |
| resolved | approved |
| paid | (无) |
| overdue | paid |
| cancelled | (无) |

### 6. 争议处理

#### 提交争议
```http
POST /api/disputes
Content-Type: application/json

{
    "bill_id": "BL-20240101000000",
    "tenant_id": "T001",
    "reason": "分摊面积计算错误",
    "description": "实际承租面积应为400平方米",
    "evidence": ["租赁合同", "测量报告"]
}
```

**必填字段**：`bill_id`, `tenant_id`, `reason`

#### 查询争议列表
```http
GET /api/disputes?status=open
```

#### 处理争议
```http
PUT /api/disputes/{dispute_id}
Content-Type: application/json

{
    "resolution": "partial_waive",
    "resolved_by": "园区管理处-李主任",
    "notes": "经核实，同意减免20%"
}
```

### 7. 人工修正

#### 人工修正账单
```http
POST /api/manual-correction
Content-Type: application/json

{
    "bill_id": "BL-20240101000000",
    "correction_type": "amount_adjustment",
    "correction_value": -100,
    "reason": "分摊计算有误，减免100元",
    "approved_by": "财务经理-王经理"
}
```

**必填字段**：`bill_id`, `correction_type`, `correction_value`, `reason`, `approved_by`

**注意**：人工修正后，账单状态自动变为 `pending_review`，需重新审批。

### 8. 数据导出

#### 导出账单
```http
GET /api/export/{bill_id}
```

### 9. 系统管理

#### 重置所有数据
```http
POST /api/reset
```

#### 查看审计日志
```http

```

## 五、关键差异点说明

### 1. 园区公共能耗

- **三种能耗类型独立管理**：
  - 空调（air_conditioning）
  - 电梯（elevator）
  - 照明（lighting）

- 每种能耗可设置不同的楼层分摊比例

### 2. 租户面积分摊

- **面积比例**：租户面积 / 楼层总面积

- **公共区域分摊**：
  - 公共能耗的 `public_area_ratio（10%-15%）
  - 按楼层的 `air_conditioning_ratio` 等比例分配

### 3. 使用时段分摊

- **时段比例**：租户实际使用天数 / 统计周期天数

- **示例**：
  - 租户 T003 于 2024-01-15 入住
  - 1月共31天，实际使用17天（15日-31日）
  - 时段比例 = 17/31 ≈ 55%

## 八、常见问题

### Q1: 如何重置测试数据？
```bash
curl -X POST http://localhost:5000/api/reset
```

### Q2: 如何查看所有审计日志？
```bash
curl http://localhost:5000/api/audit-logs
```

### Q3: 租户入住时间影响分摊吗？
是的，系统会根据租户的 `start_date` 和 `end_date` 自动计算时段比例。

### Q4: 如何处理跨月入住的租户？
- 15日入住的租户，时段比例为（实际使用天数/当月总天数。

### Q5: 人工修正需要审批吗？
是的，人工修正后账单状态变为 `pending_review`，需要重新走审批流程。
