# 岸电插拔复盘台

港口堆场冷藏箱岸电插拔数据分析与可视化工具，帮助调度员快速识别断电超时、插座冲突、移动未复插、报警未闭环等风险。

## 功能特性

### 数据解析与归一化
- 支持导入多源 CSV 数据：冷藏箱插电记录、堆位移动日志、闸口进出时间、报警事件
- 自动识别多种时间格式并统一时区（Asia/Shanghai）
- 标准化堆位标识格式（区块-行-贝-层）
- 构建统一事件时间轴

### 风险识别引擎
- **断电超时**：检测两次插电间隔超过阈值（默认30分钟）
- **插座冲突**：检测同一插座被多个集装箱同时占用
- **移动未复插**：检测集装箱移动后未在规定时间内复插
- **报警未闭环**：检测报警事件未及时处理

### 可视化分析
- **堆场热力图**：按区块展示通电状态和风险分布
- **箱号时间线**：单个集装箱完整事件追踪（插电/断电/移动/报警）
- **事件趋势**：按时间维度统计事件分布

### 会话管理
- 保存复盘会话，支持后续加载和继续分析
- 添加复盘备注
- 管理历史会话列表

### 报告导出
- **Markdown 报告**：完整的风险分析报告，含统计数据和风险详情
- **CSV 数据**：导出原始数据和风险清单
- **JSON 格式**：结构化数据，便于系统集成

### 2. 使用自定义数据

#### 数据格式要求

**冷藏箱插电记录 CSV** 必需列：
- `箱号` 或 `集装箱号` 或 `CONTAINER_NO`：集装箱编号
- `插电时间` 或 `plug_in_time`：插电时间
- 可选列：`断电时间`、`插座编号`、`堆位`、`区块`、`行`、`贝`、`层`、`操作员`

**堆位移动日志 CSV** 必需列：
- `箱号` 或 `集装箱号`：集装箱编号
- `移动时间` 或 `move_time`：移动时间
- 可选列：`操作类型`、`来源堆位`、`目标堆位`、`来源区块`、`来源行`、`来源贝`、`来源层`、`目标区块`、`目标行`、`目标贝`、`目标层`、`设备号`、`操作员`

**闸口进出记录 CSV** 必需列：
- `箱号` 或 `集装箱号`：集装箱编号
- 可选列：`进闸时间`、`出闸时间`、`运输方式`、`车牌号`、`提单号`

**报警事件 CSV** 必需列：
- `箱号` 或 `集装箱号`：集装箱编号
- `报警时间` 或 `alarm_time`：报警时间
- `报警类型` 或 `alarm_type`：报警类型
- 可选列：`报警级别`、`报警描述`、`堆位`、`处理状态`、`处理时间`、`处理人`

#### 时间格式支持
系统自动识别以下时间格式：
- `YYYY-MM-DD HH:MM:SS`
- `YYYY/MM/DD HH:MM:SS`
- `YYYY-MM-DD HH:MM`
- `YYYY/MM/DD HH:MM`
- `YYYY-MM-DD`
- `YYYY/MM/DD`
- `DD-MM-YYYY HH:MM:SS`
- `DD/MM/YYYY HH:MM:SS`

#### 堆位格式
支持两种方式指定堆位：
1. 直接使用 `堆位` 列，格式如 `A01-01-01-1`（区块-行-贝-层）
2. 使用分开的列：`区块`、`行`、`贝`、`层`，系统会自动组合

## 配置参数

可在 `config/settings.py` 中调整以下参数：

```python
class Settings:
    # 目录配置
    DATA_DIR = BASE_DIR / "data"           # 数据目录
    SESSIONS_DIR = BASE_DIR / "sessions"   # 会话目录
    EXPORTS_DIR = BASE_DIR / "exports"     # 导出目录
    
    # 风险阈值
    POWER_OUTAGE_THRESHOLD_MINUTES = 30   # 断电超时阈值（分钟）
    
    # 时区
    TIMEZONE = "Asia/Shanghai"
    
    # 堆场布局
    YARD_BLOCKS = ["A01", "A02", "A03", "B01", "B02", "B03", "C01", "C02", "C03"]
    YARD_ROWS = 10      # 行数
    YARD_BAYS = 6       # 贝数
    YARD_TIERS = 4      # 层数
```

## 风险严重程度分级

| 等级 | 条件 | 颜色 |
|------|------|------|
| 紧急 | 断电超过240分钟（4小时）<br>插座冲突<br>报警超过1440分钟（24小时）未处理 | 🔴 红色 |
| 重要 | 断电超过120分钟（2小时）<br>报警超过480分钟（8小时）未处理 | 🟠 橙色 |
| 一般 | 断电超过30分钟（阈值） | 🔵 蓝色 |
| 提示 | 一般报警（480分钟内未处理） | 🟢 绿色 |

## 常见问题

### Q: 上传文件后解析失败？
A: 请检查：
1. 文件编码是否为 UTF-8（可带 BOM）
2. 必需列是否存在且列名正确
3. 时间格式是否在支持的范围内

### Q: 为什么有些风险没有被检测到？
A: 风险检测依赖于完整的数据关联：
- 断电超时需要同一集装箱的多条插电记录
- 移动未复插需要同时有移动日志和插电记录
- 确保所有相关数据都已上传

### Q: 会话数据存储在哪里？
A: 会话数据默认存储在项目目录下的 `sessions/` 文件夹中：
- `.json` 文件：会话元数据和风险数据
- `_data.pkl` 文件：归一化后的原始数据（pickle 格式）

### Q: 如何修改断电超时阈值？
A: 编辑 `config/settings.py` 文件，修改 `POWER_OUTAGE_THRESHOLD_MINUTES` 参数，默认为 30 分钟。
