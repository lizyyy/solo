# 多轨素材交付台

一个为播客剪辑师设计的音频素材管理工具，帮助你高效管理多轨音频素材，避免漏交或版本混乱。

## 功能特性

- **项目管理**: 选择项目文件夹，自动管理最近打开的项目
- **智能扫描**: 后台扫描 wav/mp3/m4a 音频文件，解析元数据并生成素材清单
- **属性维护**: GUI 中维护集数、角色、收音质量、剪辑状态和交付版本
- **智能校验**: 自动检测采样率不一致、缺少角色轨、同名不同内容、静音过长等问题
- **任务队列**: 支持把待处理素材加入转码/归档队列，状态和历史保存到本地 SQLite
- **数据持久化**: 所有数据保存到本地 SQLite 数据库，重启后不丢失
- **导出功能**: 支持导出 Markdown 交付单和 CSV 问题清单

## 支持的音频格式

- WAV (.wav)
- MP3 (.mp3)
- M4A/MP4 (.m4a, .mp4)
- AAC (.aac)
- FLAC (.flac)

## 安装说明

### 环境要求

- Python 3.9 或更高版本
- 推荐安装 FFmpeg（用于完整功能）

### 安装步骤

1. **克隆或下载项目**

```bash
cd /path/to/project
```

2. **创建虚拟环境（可选但推荐）**

```bash
python -m venv venv

# macOS/Linux
source venv/bin/activate

# Windows
venv\Scripts\activate
```

3. **安装依赖**

```bash
pip install -r requirements.txt
```

4. **安装 FFmpeg（可选但推荐）**

FFmpeg 用于：
- 更准确的音频元数据解析
- 音频转码功能
- 静音检测

**macOS (使用 Homebrew)**:
```bash
brew install ffmpeg
```

**Windows**:
从 [FFmpeg 官网](https://ffmpeg.org/download.html) 下载并添加到 PATH。

**Linux (Debian/Ubuntu)**:
```bash
sudo apt install ffmpeg
```

## 快速开始

### 启动应用

```bash
python main.py
```

### 创建示例项目

如果你想快速体验，可以使用示例项目生成脚本：

```bash
python create_sample_project.py
```

这会在桌面创建一个包含各种测试场景的示例项目。

### 完整使用流程

#### 1. 打开项目

1. 启动应用后，点击 **"打开项目"** 按钮
2. 选择包含音频素材的文件夹
3. 项目信息会显示在左侧面板

#### 2. 扫描素材

1. 点击 **"扫描素材"** 按钮
2. 应用会自动扫描文件夹中的所有音频文件
3. 扫描过程中会显示进度
4. 扫描完成后，素材会显示在 **"素材清单"** 标签页

#### 3. 设置素材属性

1. 在素材清单中选择一个音频文件
2. 在下方的 **"素材详情"** 区域：
   - 设置 **角色**：主持人、嘉宾、片头、片尾、广告、远程录音等
   - 设置 **剪辑状态**：未剪辑、剪辑中、已完成、已交付

#### 4. 校验素材

1. 点击 **"校验素材"** 按钮
2. 应用会自动检测以下问题：
   - **采样率不一致**：不同文件采样率不同（如 44100 Hz vs 48000 Hz）
   - **声道数不一致**：单声道和立体声混合
   - **缺少角色轨**：可能缺少主持人或嘉宾轨
   - **未知角色**：未设置角色的素材
   - **同名不同内容**：文件名相同但内容不同（基于哈希值）
   - **静音过长**：音频中包含过长的静音段（需要 pydub）
   - **文件不存在**：数据库中记录但实际已删除的文件

3. 检测到的问题会显示在 **"问题清单"** 标签页

#### 5. 任务队列

1. 选择需要处理的素材
2. 点击 **"加入转码队列"** 或 **"加入归档队列"**
3. 在弹出的对话框中设置参数：
   - **转码**：目标格式、采样率、声道、输出文件夹
   - **归档**：输出文件夹、是否保留原始文件

4. 任务会显示在 **"任务队列"** 标签页
5. 任务执行历史会显示在 **"操作历史"** 标签页

#### 6. 导出交付单

1. 点击 **"导出交付单"** 按钮
2. 选择保存位置（默认在项目文件夹的 output 目录）
3. 会生成一个包含以下内容的 Markdown 文件：
   - 项目信息和统计概览
   - 素材清单（按角色分组）
   - 问题清单（未解决的问题）

#### 7. 导出问题清单

1. 点击 **"导出问题清单"** 按钮
2. 选择保存位置
3. 会生成一个 CSV 文件，方便进一步分析或分享

## 数据库存储

应用使用 SQLite 数据库存储所有数据，默认位置：

- **macOS**: `~/Library/Application Support/MultiTrackDelivery/data/multitrack.db`
- **Windows**: `%APPDATA%\MultiTrackDelivery\data\multitrack.db`
- **Linux**: `~/.local/share/multitrackdelivery/multitrack.db`

你也可以在设置中选择将数据库存储在项目文件夹内（与项目一起迁移）。

## 故障排查

### 问题 1：启动时报错 "No module named 'PyQt6'"

**解决**：确保已安装依赖
```bash
pip install -r requirements.txt
```

### 问题 2：扫描音频文件时元数据不完整

**可能原因**：mutagen 库对某些格式支持有限

**解决**：安装 FFmpeg，应用会优先使用 ffprobe 解析元数据

### 问题 3：无法进行转码

**原因**：需要 FFmpeg 进行转码

**解决**：安装 FFmpeg 并确保在 PATH 中

### 问题 4：静音检测不工作

**原因**：静音检测需要 pydub 库

**解决**：
```bash
pip install pydub
```
同时需要 FFmpeg。

### 问题 5：数据库损坏

**解决**：删除数据库文件，应用会重新创建

macOS:
```bash
rm ~/Library/Application\ Support/MultiTrackDelivery/data/multitrack.db
```

**注意**：删除数据库会丢失所有项目数据，但不会删除音频文件本身。
