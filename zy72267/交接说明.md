## 🔍 最容易出错的几个地方（系统帮你盯着）

### 1️⃣ 重复导入
- **以前的坑**：同一批点云日志导两遍，汇总数虚高，最后对不上
- **现在怎么防**：导入时自动算校验值，跟历史批次比对，重复了会标红提醒

### 2️⃣ 照片有点位但坐标表缺一行 ⚠️ **最要当心**
- **以前的坑**：照片上明明标了点，但坐标表漏了一行，汇总的时候直接被盖过去，安全员看不到
- **现在怎么防**：系统自动比对照片点位和坐标表，缺了就挂红牌，状态锁死在"照片有标记但坐标表缺行"，**不会自动归正常**，必须你安全员看过才算

### 3️⃣ 补录后重算
- **以前的坑**：补了坐标，但相关的安全半径、遮挡判定没跟着更新
- **现在怎么防**：补录坐标后自动触发重算，所有关联数据同步更新

### 4️⃣ 导出一致
- **以前的坑**：页面显示一个数，导出CSV又是另一个数，API接口再出来第三个数
- **现在怎么防**：**明细、页面、接口都读同一份数据**，导出前还能点"检查导出一致性"按钮三方对账

## 🚶 三步标准流程（一步都不能少）

### 第一步：导入点云抽稀日志
```
桌面上那堆点云抽稀日志 → 系统导入 → 自动去重
→ 导入照片点位标记 → 系统自动生成复核记录
```

### 第二步：补看安全半径表
```
摊开安全半径表 → 逐个核对测量距离和安全要求
→ 不满足的系统自动打标 → 全部录完状态更新为"安全半径已核对"
```

### 第三步：遮挡点清单更新
```
现场勘察或者看照片 → 标记哪些是天际线遮挡、建筑遮挡
→ 录入系统 → 状态更新为"遮挡点清单已更新"
```

## 📝 安全员追问时，怎么找证据？

**别再只报一个汇总数**，系统里每一条都留着底：

| 要查什么 | 去哪里找 | 能看到啥 |
|---------|---------|---------|
| 点云原始行号 | 点位详情 → 展开 | 原始行号、原始数据字符串、改动前后对比 |
| 谁什么时候改的 | 点位详情 → 审计日志 | 操作人、时间、改前改后的值、原因 |
| 当前处理状态 | 列表页面就有 | 待复核、缺坐标、已补录、待安全员复核、正常、异常 |
| 照片有标记但坐标缺行 | 自检结果红牌提醒 | 照片ID、照片中位置、点云坐标、原始行号 |

**关键**：点击每一行的"详情"展开，最下面有完整的操作审计日志，安全员问起来一条条念给他听，别自己扛。

## ⚠️ "照片有点位但坐标表缺一行"特殊处理

这个是红线，系统设计时就留了心眼：

1. **检测到后自动标红**，状态显示"照片有标记但坐标表缺行"
2. **小陶可以补录坐标**，补完状态变成"坐标已补录"，但还没完
3. **必须安全员复核**，复核弹窗里明明白白写着：
   > 照片有点位但坐标表缺一行的记录，不要急着归正常，请仔细核对。
4. 复核时选"通过（正常）"或者"不通过（异常）"，留复核意见
5. 这一条记录在明细、页面、接口里都会一直带着这个问题标签，不会消失

## 🖱️ 常用操作

### 小陶日常用的
- **导入点云**：调用接口 /api/import/point_cloud
- **导入坐标表**：调用接口 /api/import/coordinate（导完自动跑缺行检测）
- **补录坐标**：页面上点"补录"按钮，或者调 /api/review/supplement_coordinate
- **提交安全员复核**：/api/review/submit

### 安全员用的
- **复核**：页面上点"安全员复核"按钮，选通过/不通过，写意见
- **看审计日志**：批次详情页切到"操作审计日志"标签
- **检查导出一致**：点"检查导出一致性"按钮，会比对API、CSV、页面三个地方的数

## 📤 导出说明

导出的CSV包含这些列，每一列都有源数据支撑，不是凭空算的：
```
批次号, 点位ID, 原始行号, 状态, 问题列表,
点云X/Y/Z, 坐标X/Y/Z, 是否补录坐标,
安全半径, 实测距离, 是否满足安全半径,
遮挡类型, 遮挡描述,
照片ID, 照片中位置,
是否人工修改, 修改前X/Y/Z,
复核人, 复核时间, 安全员, 安全员复核时间, 备注
```

## 💡 几个专业术语，咱内部说不用绕

| 术语 | 大白话解释 |
|-----|-----------|
| 点云抽稀 | 就是把激光扫描出来的一大堆点，按规则简化，留有用的 |
| 退界 | 建筑物得往后退多少距离，给城市天际线留空间 |
| 安全半径 | 每个建筑周围得留多大安全距离 |
| 天际线遮挡 | 这栋楼会不会挡住城市天际线的观赏 |
| 抽稀日志原始行号 | 点云抽稀输出的CSV文件里的第几行，找原始数据用的 |

## ❓ 碰到异常怎么办

1. **重复导入警告**：先看看是不是真的导重了，是的话直接删掉这个批次
2. **坐标缺行红牌**：先去查原始坐标表，确实漏了就补录，补完叫安全员复核
3. **导出一致性检查不通过**：别慌，系统会告诉你哪边少了哪些点位，一个个核对
4. **人工改了点云坐标**：记得填原因，系统会留痕，安全员问起来有据可查
