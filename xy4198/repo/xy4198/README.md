# 浓烟疏散演练棋盘

一个用于商场安保培训的本地浏览器小游戏，模拟火灾烟雾扩散环境下的顾客疏散演练。

## 项目简介

本项目是一个基于 HTML5 Canvas 和 TypeScript 开发的疏散模拟游戏，旨在帮助商场安保人员学习如何合理规划疏散路线，避免顾客被烟雾堵住或走进封闭通道。

## 核心功能

### 关卡编辑
- **网格编辑**：支持 5x5 到 20x20 的网格大小调整
- **墙体绘制**：创建房间和走廊的墙体结构
- **出口设置**：放置安全出口位置
- **烟源设置**：设定火灾烟雾起源点
- **顾客放置**：安排需要疏散的顾客
- **指示牌放置**：设置疏散指引方向（点击可循环切换方向：上→右→下→左）
- **橡皮擦工具**：清除已放置的元素

### 模拟运行
- **烟雾扩散**：烟雾按时间步从烟源向四周扩散，浓度逐渐增加
- **自动寻路**：顾客根据指示牌和最近出口自动寻找路径
- **避障逻辑**：顾客会避开烟雾区域和其他顾客
- **暂停/继续**：支持模拟过程中的暂停和继续
- **实时显示**：显示当前时间步、已疏散人数、待疏散人数

### 评分系统
- **拥堵扣分**：多名顾客在同一位置拥堵时扣分
- **逆行扣分**：顾客改变移动方向（逆行）时扣分
- **死路扣分**：顾客被困在无路可走的位置时扣分
- **超时扣分**：超过最大时间步仍未疏散时扣分
- **实时原因**：详细列出每项扣分的具体原因和时间点

### 数据管理
- **保存关卡**：将当前关卡布局保存为 JSON 文件
- **载入关卡**：从 JSON 文件加载已保存的关卡
- **导出 Markdown 复盘**：生成详细的复盘报告，包含评分结果、事件详情、关卡布局
- **导出 JSON 回放**：导出完整的模拟过程数据，可用于后续分析

## 技术栈

- **TypeScript 5.1**：类型安全的 JavaScript 超集
- **Webpack 5**：模块打包器
- **HTML5 Canvas**：2D 游戏渲染
- **Jest**：单元测试框架
- **LocalStorage**：本地数据持久化

## 使用指南

### 编辑关卡

1. **选择工具**：点击左侧工具栏中的工具按钮
   - 🖱️ 选择：用于查看（无编辑功能）
   - 🧱 墙体：在网格上点击/拖拽绘制墙体
   - 🚪 出口：放置安全出口
   - 🔥 烟源：设置烟雾起源
   - 👤 顾客：放置需要疏散的人员
   - 🟢 指示牌：放置疏散指引（点击可切换方向）
   - 🗑️ 橡皮擦：清除元素

2. **调整网格大小**
   - 在"关卡"面板中修改宽度和高度
   - 点击"调整大小"按钮生效

3. **加载示例关卡**
   - 点击"示例关卡"下的按钮快速加载预设关卡

### 运行模拟

1. **准备模拟**
   - 确保关卡包含：至少 1 个顾客、至少 1 个出口、至少 1 个烟源（可选）

2. **开始模拟**
   - 点击"开始模拟"按钮
   - 观察烟雾扩散和顾客移动

3. **控制模拟**
   - 暂停：点击"暂停"按钮（变为"继续"）
   - 重置：点击"重置"按钮回到初始状态

### 查看结果

1. **评分面板**
   - 右侧面板显示实时评分
   - 总分、基础分、各项扣分一目了然

2. **扣分原因**
   - 详细列出每项扣分的具体信息
   - 包括时间步、位置、涉及顾客数等

3. **导出报告**
   - 点击"导出 Markdown 复盘"生成完整报告
   - 点击"导出 JSON 回放"导出原始数据

## 算法说明

### A* 寻路算法
- 使用曼哈顿距离作为启发函数
- 考虑墙体、烟雾、其他顾客作为障碍
- 支持指示牌引导（优先按指示牌方向规划路径）

### 烟雾扩散模型
- 每个时间步从烟源向四周扩散
- 烟雾浓度随时间递增
- 浓度超过 0.3 时顾客无法通过
- 浓度超过 0.5 时顾客被困

### 评分规则
- **基础分**：每个顾客 100 分
- **拥堵扣分**：每起拥堵事件 20 分 × 拥堵人数
- **逆行扣分**：每个逆行顾客 15 分
- **死路扣分**：每个被困顾客 50 分
- **超时扣分**：每个超时被困顾客 100 分
