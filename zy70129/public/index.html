操作指南

🏗️ 完整业务流程

  1. 创建订单 - 填写客户信息和押金金额
  2. 开始使用 - 客户入场后更新订单状态
  3. 开始验收 - 租借结束，进入验收流程
  4. 验收清单 - 检查设备数量和损坏情况
  5. 损坏扣费 - 根据损坏程度自动计算扣费
  6. 水电记录 - 录入水电表读数，自动计算费用
  7. 费用计算 - 汇总所有费用，计算应退押金
  8. 加入退款队列 - 确认退款金额和方式
  9. 处理退款 - 执行退款操作
  10. 订单完成 - 退款成功，订单关闭

❓ 常见问题排查


A: 可以在「费用计算」页面进行人工调整，并填写调整原因。所有调整都会被记录。

A: 系统会自动重试最多3次。超过次数后，订单状态变为「需人工审核」，需要手动确认处理。

A: 每个订单详情都包含完整的操作日志，可在订单详情页面查看。

A: 创建水电记录后，使用「分摊」功能按比例分摊到各订单。

A: 关键操作支持幂等性控制，使用 X-Idempotency-Key 头可防止重复请求。

💡 下一步操作提示

  • 如果订单在 PENDING：点击「开始使用」进入使用中
  • 如果订单在 IN_USE：使用结束后点击「开始验收」
  • 如果订单在 CHECKING：完成验收清单和水电记录
  • 如果订单在 FEE_CALCULATED：确认费用后加入退款队列
  • 如果订单在 REFUND_PENDING：在退款页面处理退款
  • 如果订单在 COMPLETED：订单已完成，可查看历史记录

🔧 API 接口

订单管理

  • POST /api/orders - 创建订单
  • GET /api/orders - 查询订单列表
  • GET /api/orders/:id - 查询订单详情
  • POST /api/orders/:id/start-using - 开始使用
  • POST /api/orders/:id/start-checking - 开始验收

验收清单

  • POST /api/checklists - 添加验收项目
  • GET /api/checklists/order/:orderId - 查询订单验收清单

损坏扣费

  • POST /api/damage/auto-generate/:orderId - 自动生成损坏扣费
  • POST /api/damage/:id/adjust - 人工调整扣费

费用计算

  • POST /api/fees/calculate/:orderId - 计算费用
  • POST /api/fees/order/:orderId/adjust-refund - 调整退款金额

退款处理

  • POST /api/refunds/enqueue/:orderId - 加入退款队列
  • POST /api/refunds/process/:id - 处理退款
  • POST /api/refunds/manual-process/:id - 人工确认退款

报表导出

  • GET /api/reports/daily/:date/export - 导出日报表
  • GET /api/reports/order/:orderId/export - 导出订单明细
