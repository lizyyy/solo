# 游学报名表清洗 CLI

一个用于清洗和标准化游学报名表数据的命令行工具，专门处理护照号、监护人电话和饮食禁忌字段的不一致问题。

## 功能特性

- **自动表头映射**: 智能识别不同老师提交的报名表字段名
- **字段标准化**:
  - 护照号：自动去除空格、横线，统一大写
  - 监护人电话：自动去除国家代码、分隔符，标准化为11位手机号
  - 饮食禁忌：自动识别并标准化常见过敏原表述
- **重复报名检测**: 基于护照号自动检测重复报名记录
- **异常行留存**: 保留所有原始数据，异常记录可追溯回原始行号
- **多种输出格式**: Excel清洗结果、异常数据文件、Markdown报告、JSON摘要
- **完善的错误提示**: 清楚的输入校验和错误信息

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 基本用法

```bash
python study_tour_cleaner.py -i 报名表.csv -o ./output
```

### 参数说明

| 参数 | 说明 | 必填 |
|------|------|------|
| `-i, --input` | 输入文件路径（支持 .xlsx, .xls, .csv） | 是 |
| `-o, --output` | 输出目录路径 | 是 |
| `-c, --config` | 可选配置文件路径（JSON格式） | 否 |
| `-v, --verbose` | 显示详细输出 | 否 |

### 示例

```bash
# 处理 CSV 文件
python study_tour_cleaner.py -i sample_registration.csv -o ./output

# 处理 Excel 文件
python study_tour_cleaner.py -i 游学报名表.xlsx -o ./output
```

## 输出文件

运行后会在输出目录生成以下文件（带时间戳）：

1. **`*_cleaned_*.xlsx`**: 清洗后的完整数据
2. **`*_errors_*.xlsx`**: 异常行数据（保留原始值和原始行号）
3. **`*_report_*.md`**: 给同事看的Markdown格式清洗报告
4. **`*_summary_*.json`**: 机器可读的JSON格式摘要

## 支持的字段映射

工具会自动识别以下字段名的变体：

| 标准字段 | 可识别的变体 |
|----------|-------------|
| student_name | 姓名、学生姓名、名字、学员姓名 |
| passport | 护照号、护照号码、证件号、护照 |
| guardian_phone | 监护人电话、家长电话、联系电话、手机 |
| dietary_restriction | 饮食禁忌、忌口、过敏食物、饮食注意 |
| 其他 | 年龄、性别、年级、学校、监护人姓名等 |

## 标准化规则

### 护照号
- 自动去除空格、横线、下划线
- 统一转为大写
- 格式：1位字母 + 8位数字为标准格式

### 监护人电话
- 自动去除 `+86`、`86` 前缀
- 去除空格、横线、括号等分隔符
- 格式：11位手机号码（1开头）

### 饮食禁忌
- 自动识别常见过敏原并标准化名称
- 支持多种分隔符（逗号、顿号、分号、换行）
- "无"、"没有"、空值统一显示为"无"

已支持的标准化过敏原：海鲜、花生、坚果、牛奶、鸡蛋、麸质、辛辣、猪肉、牛肉、羊肉、素食

## 注意事项

- 所有异常记录都会保留原始值和原始Excel行号，便于追溯
- Markdown报告与JSON摘要包含相同的问题记录，便于交叉验证
- 必填字段：学生姓名、护照号、监护人电话，缺失会在报告中警告
