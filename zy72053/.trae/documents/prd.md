## 1. 产品概述

水下管线腐蚀地图是一款面向运维工程师的管线腐蚀状态可视化与决策留存工具。核心目标是将分散在 GIS、巡检平板和临时 Excel 中的腐蚀数据统一呈现在 3D 空间地图上，让异常定位、来源追溯、冲突仲裁和判断留痕在一个工具内闭环完成，避免交接时因信息断层而反复人工对照巡检照片。

- 目标用户：运维工程师何工及其交接团队
- 核心价值：从数据导入到截图出图，每条腐蚀记录可追溯、可审计、可交接

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 运维工程师 | 直接访问 | 导入数据、查看地图、标记异常、导出截图、记录判断 |
| 评审方 | 只读链接 | 查看地图、查看判断记录、导出截图 |

### 2.2 功能模块

1. **腐蚀地图总览页**：3D 管线空间模型、异常高亮、筛选面板、统计摘要、截图导出
2. **数据管理与质控页**：多源数据导入、质量检测、冲突仲裁、来源追溯、判断日志
3. **记录详情页**：单条记录全链路信息、照片对照、判断历史时间线、证据并排

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 腐蚀地图总览 | 3D 管线场景 | 管线 3D 空间定位（非精细模型），支持旋转、缩放、点击选中点位；异常点位按严重度颜色编码（绿→黄→橙→红） |
| 腐蚀地图总览 | 筛选面板 | 按严重度等级、数据来源（GIS/巡检/Excel）、日期范围、管线段号筛选；筛选结果实时反映到 3D 场景和统计数字 |
| 腐蚀地图总览 | 统计摘要栏 | 显示当前筛选条件下的总点位数、异常数、例外数；例外不隐没于汇总，单独列出计数和明细入口 |
| 腐蚀地图总览 | 截图导出 | 截图自动叠加当前筛选条件水印（来源、日期范围、严重度筛选、导出时间戳），输出 PNG |
| 腐蚀地图总览 | 点位快览弹窗 | 点击 3D 点位弹出摘要卡片，含腐蚀等级、来源、最近巡检日期，提供"查看详情"入口 |
| 数据管理与质控 | 数据导入区 | 支持 Excel 文件上传（.xlsx）、GIS 数据模拟导入、巡检照片批量导入；导入时自动解析字段映射 |
| 数据管理与质控 | 质量检测面板 | 自动扫描空值、重复项、边界记录（超出管线范围的点位）；按类别统计，点击可定位到具体点位或照片 |
| 数据管理与质控 | 冲突仲裁面板 | 当巡检照片描述与导入数据矛盾时，并排展示双方证据（数据侧 vs 照片侧），列出建议动作，由用户选择采纳哪方 |
| 数据管理与质控 | 来源追溯链 | 每条记录展示完整来源链：原始数据源 → 导入时间 → 字段映射 → 质控结果 → 当前状态 |
| 数据管理与质控 | 判断日志 | 所有用户判断（冲突仲裁、异常确认、数据修正）记录时间戳、操作人、原始值、修改值、判断理由 |
| 记录详情 | 基本信息卡 | 点位 ID、坐标、管线段号、当前腐蚀等级、数据来源标签 |
| 记录详情 | 照片对照区 | 巡检照片展示，支持缩放和标注；与数据记录并排对比 |
| 记录详情 | 判断历史时间线 | 按时间排列该点位所有判断记录，含操作人、判断内容、理由、修改前后值 |
| 记录详情 | 证据并排视图 | 当存在冲突时，分栏展示数据侧证据和照片侧证据，高亮差异字段 |

## 3. 核心流程

### 3.1 数据导入到出图主流程

运维工程师将 GIS 导出文件、巡检平板照片和临时 Excel 表导入系统。系统自动进行质量检测，标记空值、重复和边界问题。发现巡检照片与导入数据冲突时，系统不自动裁决，而是并排展示双方证据和建议动作，由工程师判断。判断完成后，工程师在 3D 地图上查看管线腐蚀分布，按条件筛选，确认异常分布，导出带筛选条件水印的截图，用于评审会。

```mermaid
flowchart TD
    "数据导入" --> "质量检测"
    "质量检测" --> "空值/重复/边界标记"
    "质量检测" --> "冲突检测"
    "冲突检测" --> "冲突仲裁面板"
    "冲突仲裁面板" --> "用户判断"
    "用户判断" --> "判断日志记录"
    "空值/重复/边界标记" --> "数据修正"
    "数据修正" --> "判断日志记录"
    "判断日志记录" --> "3D 地图总览"
    "3D 地图总览" --> "筛选与定位"
    "筛选与定位" --> "截图导出（含筛选水印）"
```

### 3.2 交接回溯流程

新接手工程师打开系统，查看数据管理页的判断日志，了解前次判断过程；在记录详情页查看判断历史时间线，理解每个决策的依据。

```mermaid
flowchart TD
    "进入数据管理页" --> "查看判断日志"
    "判断日志" --> "定位到具体记录"
    "定位到具体记录" --> "打开记录详情"
    "打开记录详情" --> "查看判断历史时间线"
    "查看判断历史时间线" --> "理解前次判断依据"
```

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深海蓝 `#0A1628` 作为背景基底，搭配青绿 `#00C9A7` 作为主强调色
- **次色调**：腐蚀严重度渐变色谱——`#22C55E`（轻微）→ `#EAB308`（中等）→ `#F97316`（较重）→ `#EF4444`（严重）
- **按钮风格**：圆角 8px，深色填充 + 青绿色边框高亮，hover 时发光效果
- **字体**：数据区使用 `JetBrains Mono` 等宽字体，UI 文案使用 `Noto Sans SC`
- **布局风格**：左侧固定工具栏 + 中间主内容区 + 右侧面板抽屉，深色工业风仪表盘
- **图标风格**：线性图标（lucide-react），尺寸 18-20px

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 要素 |
|----------|----------|---------|
| 腐蚀地图总览 | 3D 管线场景 | 深色背景 + 管线白色线框 + 点位彩色球体；球体大小对应严重度；悬停显示 tooltip |
| 腐蚀地图总览 | 筛选面板 | 左侧抽屉式面板，含多选标签、日期滑块、来源复选框；顶部显示当前筛选条件摘要 |
| 腐蚀地图总览 | 统计摘要栏 | 顶部横条，4 个指标卡片（总点位、异常、例外、冲突），例外卡片用橙色边框突出 |
| 腐蚀地图总览 | 截图导出按钮 | 右下角悬浮按钮，点击后预览截图（含水印叠加），确认后下载 PNG |
| 腐蚀地图总览 | 点位快览弹窗 | 点击点位后右侧滑入半透明卡片，含关键信息和操作按钮 |
| 数据管理与质控 | 数据导入区 | 拖拽上传区域，支持多文件；导入进度条；导入后字段映射预览表格 |
| 数据管理与质控 | 质量检测面板 | 分类标签页（空值/重复/边界），每类下方列表含具体点位 ID 和问题描述 |
| 数据管理与质控 | 冲突仲裁面板 | 左右分栏布局：左侧"数据侧证据" + 右侧"照片侧证据"；底部建议动作按钮组 |
| 数据管理与质控 | 来源追溯链 | 纵向时间线，每个节点含来源图标、时间戳、操作描述 |
| 数据管理与质控 | 判断日志 | 表格布局，列含时间、操作人、记录 ID、判断类型、原值→新值、理由 |
| 记录详情 | 基本信息卡 | 顶部固定卡片，深色背景 + 青绿边框，字段标签用等宽字体 |
| 记录详情 | 照片对照区 | 网格布局展示巡检照片，点击放大；旁边数据对照表高亮差异字段 |
| 记录详情 | 判断历史时间线 | 纵向时间线，节点含时间戳和判断摘要，可展开查看详情 |
| 记录详情 | 证据并排视图 | 左右分栏，差异字段用红底高亮 |

### 4.3 响应式策略

- 桌面优先设计，最低支持 1280px 宽度
- 3D 场景区自适应容器尺寸
- 面板抽屉可折叠以适配较小屏幕

### 4.4 3D 场景指引

- **环境**：深色海底氛围，微弱环境光模拟水下效果，远距离雾化增加纵深感
- **灯光**：环境光 `#1a2a3a` 低强度 + 方向光 `#88ccff` 模拟水下光照
- **相机**：透视相机，初始俯视角 45°，支持轨道控制（OrbitControls）
- **构图**：管线沿 Z 轴延伸，异常点位悬浮于管线表面，严重异常点位带脉冲发光动画
- **交互**：鼠标悬停点位高亮放大，点击选中弹出详情；双击聚焦到该点位
- **后处理**：轻微 Bloom 效果让异常高亮更醒目
- **性能预算**：管线段 ≤ 50，点位 ≤ 200，保持 60fps

## 5. 数据完整性保障

- **例外不消失**：统计摘要栏中例外单独计数，筛选条件下例外仍可见，不混入正常汇总
- **筛选条件留存**：截图导出时叠加当前所有筛选条件（来源、日期、严重度、导出时间），确保评审可追溯版本
- **冲突不自动裁决**：检测到冲突时仅展示双方证据和建议，最终判断权留给用户
- **错误提示精确**：质量检测报错时指明具体点位 ID 或照片文件名及问题类别，便于后续处理人理解
- **判断过程可追溯**：所有判断操作记录时间、操作人、原始值、修改值和理由，形成完整审计链
