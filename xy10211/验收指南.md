## 业务场景验收
============

## 场景一：旺季缺套预警
当导入送洗记录后，执行：
```bash
node linen-tracker.js check-batch BATCH-2026-001
```

**核对要点：**
1. 每个房源的送洗数量 vs 配置数量
   - 101 配置 202 配置 3 套
   - 显示送洗与配置的差异
   - 如果送洗 < 配置 → 缺套预警 ⚠

2. 回收差异核对
   - 102 sheet 送洗 2，回收 1 → 缺 1 件
   - 显示缺失物品列表

## 场景二：重复数据检测
导入送洗异常文件时：
```bash
node linen-tracker.js import-wash samples/wash-batch-001-with-errors.csv
```

**核对要点：
- 第 3 行重复记录被跳过
- 显示 "重复记录"
- 不重复导入

## 场景三：人工改错
导入回收异常文件时：
```bash
node linen-tracker.js import-return samples/return-batch-001-with-errors.csv
```

**核对要点：**
- 第 2 行回收 3 件（送洗只有 2 件) → 超量回收
- 标记为 "待人工确认
- 在 list-review 中显示详细信息
