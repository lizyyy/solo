周一早会前流程

  1. 打开 材料导入 标签 → 点「📦 加载试跑样例」（现场材料就是这种格式，会自带一条撤回记录）
  2. 可选：再点一次「🔁 再导入一次」验证去重逻辑，确认记录不翻倍、人工备注不被覆盖
  3. 切到 预审结论 标签 → 顶部「撤回影响链路」就是早会讲稿骨架
  4. 如需人工复核结论：直接在表格里改"复核结论"或填"人工备注"，修改会自动进历史
  5. 切到 修改历史 标签 → 能看到每一步人工修改的字段级记录

关键设计

  • 撤回记录为何影响结论？：一条变更单撤回 → 依赖它的加固方案假设失效 → 碰撞检测空间关系重算 → 原本"已闭环"的碰撞需要"需重判"。影响链路在结论页最上方可视化展示。
  • 去重键：变更单号 + 构件编码 + 版本号，三要素相同视为重复。人工备注字段永不被导入覆盖。
  • 来源行锚定：每条碰撞记录都标注「送审表行号」，不再靠人眼扫变更单原文。
  • 影响范围：撤回记录直接列出「受影响碰撞编号清单」，不用人工翻模型。

数据位置

  • 所有数据在浏览器 localStorage 中，键名：clashPreReview_v1
  • 导入样例是结构化 JSON，实际对接时替换 getSampleSubmissionData() 即可
  • 修改历史单独存储，清空数据不会删除历史（防止误操作）
