# 🚌 通勤班车准点分析工具

一个本地的通勤班车数据分析与可视化工具，帮助公司行政或园区运营人员从 CSV 数据中发现晚点、超载等问题，并提供调班方案模拟和报告导出功能。

## ✨ 功能特性

### 📊 核心功能
- **内置示例数据**：无需上传即可体验完整功能
- **CSV 上传**：支持上传自己的班车运营数据
- **数据校验**：自动检测字段缺失、时间格式错误、超载等问题
- **多维度筛选**：按日期范围、线路、站点、时段、司机备注关键词筛选

### 🔍 分析功能
- **指标计算**：准点率、晚点分钟数、座位利用率、超载率等
- **异常归因**：自动识别6类异常问题：
  - 频繁晚点
  - 站点连续晚点
  - 高满载率
  - 频繁超载
  - 延误波动大
  - 高峰时段问题
- **智能建议**：每个异常附带原因分析和调整建议

### 🎯 调班模拟
- **调整发车时间**：提前/延后发车，模拟避堵效果
- **增加座位数**：模拟更换更大容量车型
- **增加班次**：模拟高峰时段增加发车频率
- **方案对比**：多方案并排对比，量化改善效果

### 📄 报告导出
- **Markdown 格式**：便于编辑和分享
- **HTML 格式**：带样式，可直接打印或在浏览器查看
- **完整内容**：包含关键指标、异常列表、方案对比结论

## 📋 CSV 数据格式

### 必填字段

| 字段名 | 说明 | 示例 |
|--------|------|------|
| 日期 | 运营日期 | 2026-04-20 |
| 线路 | 线路名称 | 园区专线1号线（东向） |
| 站点 | 站点名称 | 科技园西门 |
| 计划发车时间 | 计划发车时间 | 07:30 |
| 实际发车时间 | 实际发车时间 | 07:38 |
| 计划到站时间 | 计划到站时间 | 07:50 |
| 实际到站时间 | 实际到站时间 | 08:02 |
| 座位数 | 车辆座位数 | 50 |
| 签到人数 | 实际乘车人数 | 48 |
| 司机备注 | 司机填写的备注 | 早高峰堵车 |

### 时间格式支持
- `HH:MM` 如 `07:30`
- `HH:MM:SS` 如 `07:30:00`
- `YYYY-MM-DD HH:MM` 如 `2026-04-20 07:30`

### 示例数据
应用内置示例数据，点击「加载示例数据」按钮即可体验。示例数据包含：
- 7 条线路（园区专线、通勤快线、夜班车）
- 多个站点
- 早晚高峰模拟场景
- 14 天的运营记录

## 🎮 使用指南

### 1. 数据加载
- **使用示例数据**：点击「加载示例数据」快速体验
- **上传自己的数据**：选择 CSV 文件上传

### 2. 数据筛选（左侧边栏）
- 日期范围选择
- 线路多选
- 站点筛选
- 时段筛选（早高峰/晚高峰/午间/夜间/平峰）
- 仅工作日
- 司机备注关键词搜索

### 3. 数据概览页面
- **关键指标卡片**：准点率、平均延误、座位利用率等
- **趋势分析**：每日准点率、延误、座位利用率趋势图
- **线路对比**：各线路准点率、延误 vs 利用率散点图
- **时段分析**：不同时段的延误和满载对比
- **详细数据**：可筛选、下载的数据表格

### 4. 异常归因页面
- 按严重程度（严重/中等/轻微）分组展示
- 每个异常包含：
  - 问题描述
  - 关键指标
  - 原因分析
  - 调整建议
  - 受影响的记录

### 5. 调班模拟页面
1. 选择要调整的线路
2. 选择调整类型：
   - **调整发车时间**：提前/延后 + 分钟数 + 适用时段
   - **增加座位数**：滑动选择增加的座位数
   - **增加班次**：选择时段 + 增加的班次数
3. 点击「添加方案进行对比」
4. 查看调整前后的指标变化
5. 支持多方案并排对比

### 6. 报告导出页面
- 预览报告内容
- 下载 Markdown 格式
- 下载 HTML 格式（带样式）

## ⚙️ 配置说明

### 准点判定阈值
默认：延误 ≤ 3 分钟为准点

可在 `src/metrics.py` 中修改：
```python
ONTIME_THRESHOLD_MINUTES = 3  # 准点阈值（分钟）
SEVERE_DELAY_THRESHOLD = 10   # 严重延误阈值
OVERLOAD_THRESHOLD_RATIO = 0.95  # 高满载率阈值
```

## 📝 常见问题

### Q: 上传 CSV 时提示字段缺失？
A: 请确保 CSV 包含所有必填字段（日期、线路、站点、计划发车时间、实际发车时间、计划到站时间、实际到站时间、座位数、签到人数、司机备注）。

### Q: 时间格式不被识别？
A: 支持 `HH:MM`、`HH:MM:SS`、`YYYY-MM-DD HH:MM` 等格式。如 `07:30`、`2026-04-20 07:30:00`。

### Q: 如何判断一个问题是严重/中等/轻微？
A: 根据异常的发生频率、影响程度自动判定。可在 `src/anomaly_analyzer.py` 中调整阈值。

### Q: 调班模拟的结果准确吗？
A: 模拟基于历史数据的统计规律，仅供参考：
- 调整时间：假设延误与发车时间线性相关
- 增加座位：直接减少超载率
- 增加班次：假设乘客均匀分流
