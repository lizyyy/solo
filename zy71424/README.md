# 混音台救场夜 - Livehouse 调音师培训模拟器

一款面向Livehouse新人调音师的浏览器端培训游戏，通过模拟演出现场的调音问题，帮助新人在无风险环境下练习应急处理能力。

## 🎮 快速开始

### 1. 启动项目

```bash
npm install
npm run dev
```

打开浏览器访问 `http://localhost:5173/`

### 2. 先看样例（推荐新人第一步）

👉 **点击页面顶部「加载样例」按钮**

这会直接加载一局预设的演示数据，你可以：
- 查看完整的事件时间线
- 浏览证据链系统
- 体验交接助手功能
- 了解评分标准和复盘流程

### 3. 开始游戏

1. 点击「开始」进入新手引导
2. 或直接点击「直接开始」跳过引导
3. 演出时长：3分钟
4. 在演出过程中处理各种突发的调音问题

## 🎯 游戏玩法

### 四种问题类型

| 问题类型 | 图标 | 处理方式 | 扣分规则 |
|---------|------|---------|---------|
| **音量失衡** | 🎵 | 调整对应声道推子 | 持续5秒后开始扣分 |
| **返听请求** | 🎧 | 点击耳机图标调整返听状态 | 超时10秒后扣分 |
| **啸叫** | 🎤 | 快速拉低对应声道或主输出 | 每秒扣2分，非常危险！ |
| **主输出爆峰** | ⚠️ | 立即拉低主输出推子（>85%触发） | 每次爆峰扣30分 |

### 操作说明

1. **调整音量**：拖动推子上下移动
2. **静音/独奏**：点击声道下方的图标
3. **调整返听**：点击耳机图标选择状态
4. **处理事件**：在事件日志中点击「已处理」按钮
5. **查看状态**：顶部状态栏显示实时数据

## 📊 复盘系统

演出结束后点击「查看复盘」，包含三个标签页：

### 📈 摘要
- 最终评分和等级（S/A/B/C/D）
- 事件统计（总数/已处理/未处理）
- 平均响应时间
- 问题类型分布
- 导师建议

### ⏱️ 时间线
- **完整的操作记录**：推子调整、静音切换等
- **事件记录**：问题发生时间、处理状态
- **颜色区分**：红色=事件、蓝色=操作
- 点击任何节点可查看详情

### 🔗 证据链
- 自动关联相关事件和操作
- 左侧列表：所有证据链
- 右侧详情：选中证据的完整记录
- 包含：事件描述、操作记录、耗时统计

## 🤝 交接助手

点击「交接助手」查看自动归类的线索组：

- **自动关联**：基于时间窗口（±8秒）和声道关联
- **线索分组**：将相关的声道条、返听请求、啸叫点归为同一事件
- **交接说明**：每个线索组自动生成交接备注
- **方便同事接手**：问题上下文一目了然

## 💡 新人上手步骤

1. **先看样例**：点击「加载样例」→「查看复盘」，了解完整流程
2. **浏览时间线**：在复盘的时间线标签页，查看事件和操作的对应关系
3. **浏览证据链**：点击左侧证据链，看每个问题的完整处理过程
4. **新手引导**：点击「开始」进入引导，了解基本操作
5. **试玩一局**：开始游戏，不用太在意分数，先熟悉操作
6. **复盘总结**：结束后查看复盘，分析自己哪里反应慢了
7. **交接练习**：打开交接助手，看线索是如何自动归类的

## 🎯 评分标准

| 分数 | 等级 | 评价 |
|-----|------|------|
| 90+ | S | 完美救场！专业调音师水平 |
| 80-89 | A | 优秀！演出很顺利 |
| 70-79 | B | 良好，有些小问题但不影响 |
| 60-69 | C | 及格，需要多练习 |
| <60 | D | 需要加强训练 |

**加分规则**：
- 2秒内处理问题：+10分
- 5秒内处理问题：+5分
- 10秒内处理问题：+2分

**扣分规则**：
- 啸叫持续：-2分/秒
- 爆峰持续：-1.5分/秒
- 返听超时：-0.5分/秒（10秒后）
- 音量失衡：-0.3分/秒（5秒后）
