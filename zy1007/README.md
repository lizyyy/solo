# 维修工作室管理系统

一个为小型维修工作室设计的内部管理系统，解决微信群接单混乱、备件被多人同时占用、工单进度追踪困难等问题。

## 功能特性

### 工单管理
- 创建报修单：记录客户信息、设备信息、故障描述，可选择占用备件
- 状态筛选：按"待接单/维修中/等待备件/已完成/已取消"筛选工单
- 工单详情：查看完整工单信息，包括备件占用记录和沟通记录
- 状态推进：在详情页推进工单状态，可添加备注和占用新备件

### 备件管理
- 备件库存：维护备件的名称、型号、库存、安全库存、单价
- 库存预警：库存低于安全线时在看板显示警告
- 库存扣减/释放：创建工单时占用库存，取消工单时释放，完成时扣减

### 今日看板
- 待接单、维修中、等待备件、已完成的工单数量统计
- 今日新增和今日完成数量
- 库存低于安全线的备件列表

## 技术栈

- **后端**：Node.js + Express + SQLite
- **前端**：React + Vite + Ant Design
- **状态管理**：React Hooks
- **路由**：React Router

## 安装步骤

### 环境要求
- Node.js >= 14.0.0
- npm 或 yarn

### 1. 安装后端依赖

```bash
cd backend
npm install
```

### 2. 初始化数据库

```bash
npm run init-db
```

这会创建 `data/repair-shop.db` 数据库文件，并插入一些示例备件数据。

### 3. 安装前端依赖

```bash
cd ../frontend
npm install
```

## 启动项目

### 方式一：分开启动（开发时推荐）

**终端1 - 启动后端：**
```bash
cd backend
npm run dev
```
后端服务运行在 `http://localhost:3001`

**终端2 - 启动前端：**
```bash
cd frontend
npm run dev
```
前端服务运行在 `http://localhost:3000`

### 方式二：生产模式启动

**启动后端：**
```bash
cd backend
npm start
```

**启动前端：**
```bash
cd frontend
npm run build
npm run preview
```

## API 接口说明

### 工单相关

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/work-orders | 获取工单列表，支持 ?status=xxx 筛选 |
| GET | /api/work-orders/:id | 获取工单详情（含占用记录和沟通记录） |
| POST | /api/work-orders | 创建工单，支持同时占用备件 |
| PUT | /api/work-orders/:id/status | 更新工单状态，支持占用新备件 |
| POST | /api/work-orders/:id/communications | 添加沟通记录 |

### 备件相关

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/spare-parts | 获取备件列表，?low_stock=true 获取低库存 |
| GET | /api/spare-parts/:id | 获取单个备件 |
| POST | /api/spare-parts | 创建备件 |
| PUT | /api/spare-parts/:id | 更新备件 |
| DELETE | /api/spare-parts/:id | 删除备件（被使用的备件无法删除） |

### 看板相关

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/dashboard/stats | 获取看板统计数据 |

## 状态流转说明

```
待接单 (pending)
    ↓
维修中 (in_progress) ←→ 等待备件 (waiting_parts)
    ↓
已完成 (completed) 或 已取消 (cancelled)
```

### 库存处理规则

- **创建工单/占用备件**：库存 -= 占用数量，占用记录状态 = 'occupied'
- **取消工单**：库存 += 占用数量，占用记录状态 = 'released'
- **完成工单**：库存不变（已扣减），占用记录状态 = 'deducted'

## 常见问题

### 1. 前端提示"后端服务未连接"
- 检查后端服务是否启动
- 检查后端是否运行在 3001 端口
- 检查浏览器控制台是否有跨域错误

### 2. 数据库文件不存在
- 运行 `cd backend && npm run init-db` 初始化数据库
- 确保 `backend/data` 目录有写入权限

### 3. 如何重置数据
- 删除 `backend/data/repair-shop.db` 文件
- 重新运行 `npm run init-db`

### 4. 如何修改端口
- 后端：修改 `backend/server.js` 中的 PORT
- 前端：修改 `frontend/vite.config.js` 中的 server.port 和 proxy.target
