# 手机维修工单管理系统

为小型手机维修店设计的本地工单管理系统，替代微信群和纸本登记，让客户查进度不再困难。

## 功能特点

- 📋 **工单管理**：新建、编辑、查看、搜索维修工单
- 📊 **看板视图**：按状态分组显示工单，一目了然
- 🔄 **状态流转**：严格的状态流转控制，防止跳状态
- 📝 **操作记录**：完整记录所有状态变更和操作历史
- 📁 **CSV 导入导出**：支持导入历史数据，导出对账报表
- 💾 **持久化存储**：使用 SQLite 本地数据库，重启数据不丢失
- 🔍 **搜索筛选**：按客户姓名、电话、设备型号搜索，按状态筛选

## 技术栈

- **后端**: Node.js + Express + SQLite
- **前端**: 原生 HTML/CSS/JavaScript
- **存储**: SQLite 本地数据库
- **CSV**: csv-parser + json2csv

## 工单状态流转

系统采用严格的状态流转机制，防止随意跳状态：

```
待检测 (pending)
    ↓
报价中 (quoting)  ← 可取消 → 已取消 (cancelled)
    ↓
维修中 (repairing) ← 可取消 → 已取消 (cancelled)
    ↓
待取机 (ready) ← 可取消 → 已取消 (cancelled)
    ↓
已完成 (completed)
```

### 状态说明

| 状态 | 说明 | 可转换为 |
|------|------|----------|
| 待检测 | 新工单，等待检测 | 报价中、已取消 |
| 报价中 | 检测完成，等待客户确认报价 | 维修中、已取消 |
| 维修中 | 客户确认报价，正在维修 | 待取机、已取消 |
| 待取机 | 维修完成，等待客户取机 | 已完成、已取消 |
| 已完成 | 客户取机，工单结束 | 无 |
| 已取消 | 工单已取消 | 无 |

### 界面提示

当状态按钮不可用时，鼠标悬停会显示具体原因，例如：
- "当前状态「已完成」无法进行状态变更"
- "当前状态「待检测」只能变更为：报价中、已取消"

## 工单字段

每个工单包含以下字段：

| 字段 | 必填 | 说明 |
|------|------|------|
| 客户姓名 | 是 | 客户姓名 |
| 联系电话 | 是 | 手机号码（格式验证） |
| 设备型号 | 是 | 手机型号，如 iPhone 14 Pro |
| 故障描述 | 是 | 详细描述故障情况 |
| 报价金额 | 否 | 维修费用，如 500 |
| 维修配件 | 否 | 使用的配件，如 屏幕总成 |
| 预计取机时间 | 否 | 预计完成时间 |
| 备注 | 否 | 其他补充信息 |

## 使用指南

### 1. 新建工单

1. 点击右上角"新建工单"按钮
2. 填写必填字段（客户姓名、电话、设备型号、故障描述）
3. 可选填写报价、配件、预计取机时间等
4. 点击"保存"

### 2. 查看工单详情

1. 在看板上点击任意工单卡片
2. 查看完整工单信息
3. 查看操作记录历史

### 3. 状态流转

1. 打开工单详情
2. 点击对应状态按钮（只有可转换的状态按钮才可用）
3. 确认状态变更，操作记录会自动记录

### 4. 搜索工单

1. 在顶部搜索框输入关键词
2. 支持搜索客户姓名、电话、设备型号
3. 按回车或点击"搜索"按钮

### 5. CSV 导入

1. 点击"导入 CSV"按钮
2. 选择符合格式的 CSV 文件
3. 系统会自动验证并导入数据
4. 导入完成后显示成功/失败信息

#### 导入格式

CSV 文件需要包含以下字段（支持中英文表头）：

| 英文表头 | 中文表头 | 必填 | 说明 |
|----------|----------|------|------|
| customer_name | 客户姓名 | 是 | |
| phone | 联系电话 | 是 | 11 位手机号 |
| device_model | 设备型号 | 是 | |
| fault_description | 故障描述 | 是 | |
| quote_amount | 报价金额 | 否 | 数字 |
| repair_parts | 维修配件 | 否 | |
| expected_pickup_time | 预计取机时间 | 否 | |
| notes | 备注 | 否 | |

#### 示例 CSV

```csv
客户姓名,联系电话,设备型号,故障描述,报价金额,维修配件,备注
张三,13800138001,iPhone 14 Pro,屏幕碎裂,1200,原装屏幕总成,客户要求原装配件
李四,13900139002,华为 Mate 60,电池耗电快,350,原装电池,电池健康度 65%
```

### 6. CSV 导出

1. 点击"导出 CSV"按钮
2. 自动下载包含所有工单的 CSV 文件
3. 可用于月底对账或数据备份

## API 接口

### 工单管理

- `GET /api/orders` - 获取工单列表
  - 查询参数：`status`（状态筛选）、`search`（搜索关键词）

- `GET /api/orders/:id` - 获取单个工单详情（含操作记录）

- `POST /api/orders` - 创建新工单
  - Body: `{ customer_name, phone, device_model, fault_description, ... }`

- `PUT /api/orders/:id` - 更新工单信息

- `PUT /api/orders/:id/status` - 更新工单状态
  - Body: `{ status, note }`

### 状态信息

- `GET /api/status-info` - 获取状态流转配置

### CSV 操作

- `POST /api/csv/import` - 导入 CSV 数据
  - Content-Type: `multipart/form-data`
  - 参数：`file`（CSV 文件）

- `GET /api/csv/export` - 导出所有工单为 CSV

## 完整流程演示

1. **登记**：点击"新建工单"，填写客户信息和故障描述
2. **报价**：检测完成后，点击"转为报价中"，填写报价金额
3. **维修**：客户确认报价后，点击"转为维修中"

## 数据持久化

- 数据库文件存储在 `data/repair.db`
- 重启服务后数据不会丢失
- 所有状态变更都会记录操作日志

## 注意事项

- 这是一个本地运行的系统，适合单店使用
- 数据库文件建议定期备份
- 手机号码格式会自动验证（11 位，以 1 开头）
- 已完成和已取消的工单无法再修改状态
