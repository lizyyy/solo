# 海洋牧场时序回放 · FastAPI 服务启动说明

## 环境要求
- Python 3.9+
- 建议使用虚拟环境

## 安装与启动

### 1. 创建并激活虚拟环境（可选，推荐）
```bash
cd /Users/maca/pro/solo/workspaces/zy73152
python3 -m venv venv
source venv/bin/activate    # macOS / Linux
# Windows: venv\Scripts\activate
```

### 2. 安装依赖
```bash
pip install -r requirements.txt
```

### 3. 启动服务
**重要：必须在项目根目录启动**（即 `/Users/maca/pro/solo/workspaces/zy73152`），确保 `index.html`、`css/`、`js/` 能被正确定位。

```bash
# 项目根目录执行
uvicorn backend.main:app --reload --port 8000
```

### 4. 打开页面
浏览器访问：
```
http://localhost:8000/
```

> 顶部右上角有"后端已连接 / 未连接 / 异常"指示灯，可一眼判断服务状态。

## 验收流程（对应需求中的验收标准）

启动服务并打开页面后，按以下步骤端到端验证：

### 步骤 1 — 查看初始数据
- 默认选中第 3 次跑次（`v3-调云阈值0.30`），观察 6 张摘要卡：
  - 平均生物量、总生物量、样品数、剔除云景、云阈值、人工修正数
- 顶部差异横幅应显示相对 v2 的增减情况

### 步骤 2 — 触发坐标修正（验证人工修正真正进入计算）
1. 滚动到「坐标标准化」面板
2. 任意一行点「📍修正」按钮（如 lab-002）
3. 弹窗中把纬度改成 `37.5000`，经度改成 `122.3000`，写个备注如"人工确认偏移"，点确认
4. 重跑弹窗自动弹出，点「开始重算」
5. ✅ 验证：
   - 新跑次列表出现，自动跳转
   - 摘要卡「人工修正数」+1
   - 平均生物量应 **略降约 1%**（`manual_factor = 0.99`）
   - 顶部差异横幅显示对应变化
   - 坐标表被修正的行变金色高亮，下方小字显示"修正前：xxx"

### 步骤 3 — 触发云遮挡人工纳入（验证云遮挡真正影响结果）
1. 在新跑次上，滚动到「遥感云遮挡」面板
2. 找到一行「已剔除」状态的云（红色背景），点「✅ 人工纳入」
3. 重跑弹窗弹出，点「开始重算」
4. ✅ 验证：
   - 摘要卡「剔除云景」数字 -1
   - 平均生物量 **微增**（云纳入越多，`cloud_factor` 越接近 1）
   - 该行云记录变为绿色「已纳入」

### 步骤 4 — 下载报告并核对内容
1. 滚动到「📤 结果报告导出」面板
2. 点任意一张卡片下载（建议先下 HTML）
3. ✅ 验证：
   - 浏览器真实下载了文件，文件名含跑次 ID，非假按钮
   - 打开 HTML 报告，核对 8 个章节：
     1. 跑次基本信息（与页面顶部一致）
     2. 输入参数（云阈值、包含异常等）
     3. 坐标清洗前后对比（修正过的行有 `修正前/后`）
     4. 云遮挡记录（与面板状态一致）
     5. 晚到附件处理痕迹（含晚到样品）
     6. 生物量计算详情（6 个摘要卡数字）
     7. 相对上一版的重算差异
     8. 参数变化步骤链
   - CSV 用 Excel 打开不乱码（已带 BOM）
   - JSON 是完整结构化数据

### 步骤 5 — 材料区上传 & 新增晚到样品
1. 滚动到「📁 材料区」
2. 左侧表单选个本地文件点上传 → 应提示"上传成功"
3. 右侧"录入晚到样品"表单填：
   - 样品编号：`LATE-001`
   - 站点：`S5`
   - 纬度：`37°30'00"N`
   - 经度：`122°15'00"E`
   - 生物量：`180`
   - 采样日期：`2024-06-12`
   - 原因：`实验室补送`
4. 点「提交并重算」
5. ✅ 验证：
   - 新跑次中样品数 +1
   - 坐标表多一条高亮行，带「晚到」徽章
   - 晚到附件面板同步新增记录
   - 平均生物量按新样品重新计算

## 接口文档
启动后可直接用 Swagger UI 调试 API：
```
http://localhost:8000/docs
```

## 核心 API 一览
| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| GET  | `/api/health` | 健康检查 |
| GET  | `/api/runs` | 跑次列表 |
| GET  | `/api/runs/{id}` | 跑次详情 |
| GET  | `/api/runs/{id}/summary` | 计算摘要 + 差异 |
| POST | `/api/rerun` | 通用重算（含修正/参数） |
| POST | `/api/correct-coord` | 快速：坐标修正 |
| POST | `/api/correct-cloud` | 快速：云纳入/剔除 |
| POST | `/api/set-cloud-threshold` | 快速：调整云阈值 |
| POST | `/api/add-late-lab` | 快速：新增晚到样品 |
| GET  | `/api/runs/{id}/export?format=html\|csv\|json` | 报告下载 |
| GET  | `/api/samples` | 试跑样例说明 |
| POST | `/api/upload-material` | 材料上传 |
