# 热像异常复盘台

城市管廊巡检班专用的热像异常分析与复盘管理系统。

## 功能特性

- **数据导入**：支持导入热成像点位 CSV、设备运行日志和现场照片
- **智能风险识别**：
  - 温升突变检测（温度较历史上升超过15°C）
  - 连续高温检测（近3天多次超过阈值）
  - 日志告警未闭环检测
  - 重复点位检测
- **可视化展示**：
  - 平面点位分布图
  - 温度趋势图
  - 风险列表
- **人工复核**：支持人工改判、记录复核意见、闭环风险
- **数据导出**：
  - Markdown 格式复盘报告
  - CSV 风险清单
- **刷新不丢**：当前批次状态保存在本地存储

## 技术栈

- **后端**：Python Flask + SQLite
- **前端**：HTML + CSS + JavaScript (Bootstrap 5 + Chart.js)
- **数据库**：SQLite (Flask-SQLAlchemy)

## 快速开始

### 1. 环境准备

```bash
# 创建虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate  # macOS/Linux
# 或
venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

### 2. 启动应用

```bash
python app.py
```

应用将在 `http://localhost:8080` 启动。

### 3. 使用示例数据

按照以下步骤快速体验完整功能：

#### 步骤 1：新建巡检批次

1. 打开浏览器访问 `http://localhost:8080`
2. 点击顶部导航栏的 **"选择巡检批次"** 下拉菜单
3. 选择 **"+ 新建批次"**
4. 填写信息：
   - 批次名称：`2026-05-01 东区巡检`
   - 巡检日期：`2026-05-01`
   - 巡检人员：`张三`
   - 天气：`晴`
5. 点击 **"创建"** 按钮

#### 步骤 2：导入温度数据 CSV

1. 在左侧 **"数据导入"** 区域，点击 **"温度数据CSV"** 的文件选择框
2. 选择 `sample_data/thermal_points_20260501.csv`
3. 点击 **"导入CSV"** 按钮
4. 等待导入完成提示（成功导入 21 条温度记录）

**示例 CSV 字段说明**：
| 字段 | 说明 | 示例 |
|------|------|------|
| 点位代码 | 点位唯一标识 | DL-001 |
| 点位名称 | 点位中文名称 | 东区电缆接头A1 |
| 点位类型 | 电缆接头/阀井/风机 | 电缆接头 |
| 温度 | 热像温度(°C) | 78.5 |
| 环境温度 | 环境温度(°C) | 25.3 |
| X坐标 / Y坐标 | 点位坐标（用于分布图） | 10.5 |

#### 步骤 3：导入设备运行日志

1. 在 **"设备运行日志"** 区域，选择 `sample_data/device_logs_20260501.txt`
2. 点击 **"导入日志"** 按钮
3. 等待导入完成提示

**日志格式说明**（制表符分隔）：
```
时间	点位代码	日志级别	消息内容
```

日志级别映射：
- `ERROR` / `WARN` / `ALERT` / `CRITICAL` → 告警（需闭环）
- `INFO` → 普通日志

#### 步骤 4：运行风险分析

1. 在左侧 **"分析操作"** 区域，点击 **"运行风险分析"** 按钮
2. 系统将自动检测以下风险类型：
   - 高温异常（≥70°C）
   - 温度异常（≥55°C）
   - 连续高温（近3天多次）
   - 温度突变（较历史上升≥15°C）
   - 未闭环告警（设备日志告警）
   - 重复点位（同一批次重复导入）

#### 步骤 5：查看分析结果

**风险列表**：
- 表格展示所有检测到的风险
- 按风险等级（高/中/低）着色
- 支持筛选：风险等级、状态、搜索

**点位分布图**：
- 基于 X/Y 坐标渲染点位位置
- 颜色标识：绿色=正常、黄色=中风险、红色=高风险
- 点击标记可查看风险详情

**温度趋势**：
- 选择点位查看历史温度趋势
- 支持折线图/柱状图切换
- 显示当前温度与环境温度对比

#### 步骤 6：人工复核与闭环

1. 在风险列表中，点击某条风险的 **"详情"** 按钮
2. 查看：
   - 点位信息
   - 风险描述
   - 温度历史图表
   - 关联照片
3. **保存复核**：
   - 选择复核判定（确认风险/误报/低优先级/需持续关注）
   - 填写复核备注
   - 可选：跟进措施、建议复查日期
   - 点击 **"保存复核"**
4. **闭环风险**（仅未闭环状态）：
   - 点击 **"闭环风险"** 按钮
   - 确认后风险状态变为"已闭环"

#### 步骤 7：导出数据

**导出风险清单（CSV）**：
1. 点击左侧 **"导出风险清单"** 按钮
2. 下载包含所有风险的 CSV 文件

**导出复盘报告（Markdown）**：
1. 点击左侧 **"导出复盘报告"** 按钮
2. 下载 Markdown 格式报告，包含：
   - 巡检批次信息
   - 数据概览统计
   - 风险分析结果（高风险详情）
   - 复核记录

## 风险识别规则

| 风险类型 | 触发条件 | 风险等级 |
|----------|----------|----------|
| 高温异常 | 温度 ≥ 70°C | 高 |
| 温度突变 | 较历史平均上升 ≥ 15°C | 高 |
| 未闭环告警 | 设备日志告警且未闭环 | 高 |
| 连续高温 | 近3天 ≥2 次 ≥70°C | 高 |
| 连续较高温 | 近3天全部 ≥55°C | 中 |
| 温度异常 | 温度 ≥ 55°C | 中 |
| 重复点位 | 同批次同代码出现多次 | 中 |

## 常见问题

**Q: 刷新页面后数据丢失？**
A: 不会。当前选择的批次 ID 保存在浏览器 localStorage 中，刷新后会自动恢复。数据库中的数据永久保存。

**Q: 支持哪些照片格式？**
A: 支持 JPG、JPEG、PNG、GIF、BMP 格式。

**Q: 如何自定义温度阈值？**
A: 修改 `risk_analyzer.py` 中的常量：
```python
HIGH_TEMP_THRESHOLD = 70.0      # 高风险温度阈值
MEDIUM_TEMP_THRESHOLD = 55.0    # 中风险温度阈值
TEMP_RISE_THRESHOLD = 15.0       # 温升突变阈值
CONTINUOUS_HIGH_DAYS = 3          # 连续高温天数
```

**Q: 示例数据中的 DL-001 为什么有重复？**
A: 示例数据特意设计了一条重复记录（第14行），用于演示"重复点位"风险检测功能。

## 数据备份与恢复

数据库文件位于 `data/inspection.db`，可直接复制备份。照片位于 `data/photos/` 目录。

恢复时只需将备份文件放回原目录即可。
