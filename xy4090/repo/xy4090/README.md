# 术语闪卡时间轴

专为同传志愿者设计的本地桌面工具，帮助会前准备、现场标记、会后复盘。

## 功能特点

### 会前准备
- **导入术语表**: 支持 CSV 格式导入，自动校验格式，检测中英文列颠倒
- **导入议程**: 自动解析文本格式的议程，提取时间、标题、嘉宾、主题
- **导入嘉宾名单**: 支持纯文本格式，用于快速选择标记对象

### 现场模式
- **术语闪卡**: 会前浏览术语，支持搜索、洗牌、分类筛选
- **议程时间轴**: 实时显示当前议程，自动切换，进度条展示
- **快捷键标记**: 
  - `F1` - 标记卡词（忘记术语时）
  - `F2` - 标记误译（译错时，可记录正确译法）
  - `F3` - 标记已确认（关键译法确认）
- **快速标记**: 在输入框中输入术语后按回车快速卡词标记
- **嘉宾选择**: 下拉选择当前演讲嘉宾，自动关联到标记

### 复盘分析
- **多维度筛选**: 按嘉宾、主题、标记类型筛选
- **统计分析**: 卡词/误译/已确认次数统计，按嘉宾统计，高频问题术语分析
- **编辑标记**: 可补充备注、添加正确译法
- **多种导出格式**:
  - **Markdown 复盘报告**: 包含概览、问题汇总、高频分析、完整术语表、议程
  - **CSV 错词清单**: 便于后续整理和复习
  - **JSON 审计包**: 包含完整数据和统计信息，便于数据备份

### 本地存储
- 所有数据本地存储，保护隐私
- 自动保存机制，防止数据丢失
- 自动备份，支持数据恢复

### 模块说明

| 文件 | 功能 |
|------|------|
| `main.py` | Tkinter GUI 主程序，包含现场模式、复盘页面、所有交互逻辑 |

## 安装与运行

### 环境要求
- Python 3.8+

## 使用指南

### 首次使用

1. 运行 `python main.py` 启动程序
2. 点击「新建项目」，输入项目名称（如「2024科技峰会」）
3. 进入现场模式

### 导入数据

#### 导入术语表

1. 点击「导入术语表」按钮
2. 选择 CSV 格式的术语表文件

**术语表格式要求**：
```csv
chinese,english,category,notes,difficulty
人工智能,Artificial Intelligence,技术术语,缩写: AI,3
机器学习,Machine Learning,技术术语,缩写: ML,2
```

**必需列**：
- `chinese` - 中文术语
- `english` - 英文术语

**可选列**：
- `category` - 分类（如：技术术语、嘉宾、议程）
- `notes` - 备注信息
- `difficulty` - 难度（1-5，默认为1）

#### 导入议程

1. 点击「导入议程」按钮
2. 选择文本格式的议程文件

**议程格式要求**：
- 时间格式：`9:00 - 10:00` 或 `09:00:00 - 10:00:00`
- 自动识别：
  - `嘉宾:` 或 `speaker:` 开头的行
  - `主题:` 或 `topic:` 开头的行

**示例议程**：
```
9:00 - 10:00 开幕致辞
嘉宾: 张教授
主题: 会议开场

10:00 - 11:00 主题演讲
嘉宾: 李教授
主题: 人工智能发展趋势
```

#### 导入嘉宾名单

1. 点击菜单「编辑」→「导入嘉宾名单」
2. 选择文本格式的嘉宾名单

**格式**：每行一个嘉宾姓名，`#` 开头为注释

### 现场模式使用

#### 术语闪卡
- 点击「上一张」「下一张」或按 `←` `→` 键浏览术语
- 点击「随机洗牌」打乱顺序
- 搜索框输入关键词搜索术语

#### 现场标记

**快捷键**：
- `F1` - 卡词标记：忘记术语时按下，自动记录当前显示的术语或快速输入框中的内容
- `F2` - 误译标记：译错时按下，可弹出对话框输入正确译法
- `F3` - 已确认标记：关键译法确认时按下

**快速标记流程**：
1. 在「快速标记术语」输入框中输入卡词的术语
2. 选择当前演讲嘉宾（或让系统自动根据议程切换）
3. 按 `Enter` 或 `F1` 完成标记

#### 查看当前议程
- 右侧时间轴显示完整议程
- 高亮显示当前进行中的议程
- 进度条显示整体会议进度

### 复盘分析

1. 点击「复盘页面」按钮
2. 使用筛选条件过滤标记记录
3. 查看统计分析
4. 编辑或删除标记
5. 导出报告

#### 筛选功能
- **嘉宾筛选**: 选择特定嘉宾的所有标记
- **主题筛选**: 按议程主题筛选
- **类型筛选**: 只看卡词/误译/已确认

#### 编辑标记
- 双击或选择后点击「编辑选中」
- 可补充：术语文本、正确译法、备注

#### 导出功能

**导出 Markdown 复盘报告**：
- 包含完整的会议复盘信息
- 可直接用 Markdown 阅读器或浏览器打开
- 便于分享和后续整理

**导出 CSV 错词清单**：
- 包含所有卡词和误译记录
- 可导入 Excel 或其他工具进行复习整理

**导出 JSON 审计包**：
- 包含完整项目数据
- 便于数据备份和后续分析

## 数据存储位置

项目数据默认存储在以下位置：

- **Windows**: `%APPDATA%\flashcard_timeline\`
- **macOS/Linux**: `~/.local/share/flashcard_timeline/`

包含三个子目录：
- `projects/` - 项目数据文件（JSON 格式）
- `backups/` - 自动备份文件
- `temp/` - 临时文件

## 常见问题

**Q: 程序启动失败，提示缺少 tkinter？**

A: tkinter 是 Python 标准库的一部分，通常随 Python 一起安装。如果确实缺少：
- Windows: 重新安装 Python，确保勾选「tcl/tk and IDLE」
- macOS: 通常已预装，如缺失可使用 Homebrew 安装 `python-tk`
- Linux: `sudo apt install python3-tk` (Debian/Ubuntu)

**Q: 导入 CSV 时提示编码错误？**

A: 程序支持 UTF-8 和 GBK 编码自动检测。确保你的 CSV 文件使用这两种编码之一保存。

**Q: 数据保存在哪里？**

A: 点击菜单「帮助」→「关于」查看数据目录，或查看 README 中的「数据存储位置」章节。

**Q: 如何备份数据？**

A: 有三种方式：
1. 使用「文件」→「导出项目」功能导出单个项目
2. 直接复制整个数据目录
3. 程序会自动在 `backups/` 目录保留最近 10 个版本的备份
