# 小麦病斑样本分级器

用于农技员对小麦叶片病斑进行快速分级并保留人工复核的工具原型。

## 安装运行

```bash
pip install -r requirements.txt
python main.py
```

## 样例入口

运行 `python main.py` 将自动执行完整流程：
1. 生成 8 个样例样本数据
2. 导入并创建批次（相同数据复用同一批次）
3. 提取面积（病斑比例）和颜色（褐黄指数）特征
4. 基于规则分级并输出分级理由
5. 模拟人工复核（确认/修正/驳回）
6. 导出结果文件

## 核心操作

### 数据流程
```
样本导入 → 特征提取 → 规则分级 → 人工复核 → 结果导出
```

### 人工复核类型
- **确认 (Approve)**: 同意规则分级结果
- **修正 (Modify)**: 人工调整分级级别
- **驳回 (Reject)**: 标记需要重新采集

### 分级依据
- 面积权重 70%：病斑占叶片面积的比例
- 颜色权重 30%：褐色越深病情越重

### 批次管理
- 相同数据文件自动复用同一批次
- 重跑同一批数据不会产生重复批次
- 状态和结果会更新而非膨胀

## 检查结果

运行后查看 `exports/` 目录：

1. `results_<批次号>.csv` - 详细结果表
   - 样本编号、叶片面积、病斑面积、病斑颜色
   - 病斑比例、褐色指数、黄色指数
   - 规则分级、规则得分
   - 人工复核状态、最终分级、复核意见
   - 版本号

2. `summary_<批次号>.txt` - 汇总报告
   - 处理统计（待复核/已确认/已修正/已驳回）
   - 病情分布（轻度/中度/严重/极严重）
   - 每个样本的分级详情和理由

状态数据保存在 `states/` 目录，可随时查看：
```bash
python main.py status BATCH_<时间戳>
```
