# 夜市摊位油污巡查系统

可运行前端原型，用于夜市管理人员巡查摊位油污、明火和整改结果。

## 安装运行

```bash
npm install
npm run dev
```

访问 http://localhost:5173/

## 样例入口

系统启动后自动加载内置样例数据，包含 12 个摊位、6 个问题记录和 6 条整改记录。

如需重置为初始样例，点击页面右上角「重置为样例数据」按钮。

## 核心操作

### 1. 摊位网格巡查
- 左侧网格展示所有摊位，不同颜色标识状态
- 点击任意摊位查看详情
- 右侧面板显示摊位信息和问题列表
- 可标记新问题（油污/明火，选择严重程度）

### 2. 整改管理
- 切换到「整改管理」标签页
- 查看所有问题及其整改状态
- 点击「启动整改流程」创建整改任务
- 可编辑整改措施、截止日期和备注
- 状态流转：待整改 → 整改中 → 已完成 → 已验证

### 3. 整改公示
- 切换到「整改公示」标签页
- 查看统计概览（待整改/整改中/已完成/已验证）
- 查看详细的整改记录表格

### 4. 统计导出
- 切换到「统计导出」标签页
- 查看摊位分布、问题统计、整改情况
- 导出 CSV 文件：摊位数据、问题记录、整改记录

## 检查结果

1. **状态一致性**：
   - 摊位状态随问题和整改自动更新
   - 多次操作后统计数据准确

2. **数据持久化**：
   - 数据存储在浏览器本地存储
   - 刷新页面数据保留
   - 重跑样例使用「重置」按钮，不会重复导入

3. **导出文件**：
   - 导出的 CSV 文件编码正常（支持中文）
   - 数据与界面显示一致
