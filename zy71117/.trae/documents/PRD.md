# 装卸月台转弯模拟 - 产品需求文档

## 1. 产品概述
物流园月台规划前，车队需要模拟不同车长倒车入库场景，避免画线后才发现车辆无法转弯。本产品提供3D交互可视化模拟，支持在浏览器中操作和复盘。

- 核心价值：降低月台规划风险，节省改造成本，提升物流效率
- 目标用户：物流园区规划人员、车队调度员、场地设计师

## 2. 核心功能

### 2.1 功能模块
1. **3D模拟场景**：月台模型、货车、障碍物、装卸口可视化
2. **车辆配置**：车长、轴距、转弯半径、尺寸参数配置
3. **路径模拟**：倒车路径计算、扫掠碰撞检测
4. **样例系统**：导入预置样例、筛选场景
5. **时间轴控制**：播放/暂停/快进/重置、进度调节
6. **视角切换**：俯视、侧视、驾驶舱、自由视角
7. **碰撞检测**：实时显示碰撞区域、越界警告
8. **报告导出**：模拟结果报告、PDF/图片导出

### 2.2 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|-----------|-------------|---------------------|
| 主页面 | 3D视口 | Three.js渲染场景，显示月台、车辆、障碍物 |
| 主页面 | 左侧面板 | 车辆尺寸配置、转弯半径设置 |
| 主页面 | 顶部工具栏 | 样例选择、视角切换、报告导出 |
| 主页面 | 底部时间轴 | 播放控制、进度调节、状态显示 |
| 主页面 | 右侧信息 | 实时数据、碰撞检测结果、模拟状态 |

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：工业蓝 (#165DFF)、深灰 (#1D2129)
- 辅助色：成功绿 (#00B42A)、警告红 (#F53F3F)
- 字体：现代无衬线字体，清晰可读
- 布局：深色主题，科技感工业风格
- 3D场景：专业工程风格，网格地面，轮廓高亮

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|-----------|-------------|-------------|
| 主页面 | 3D视口 | 全屏渲染，鼠标交互，高亮碰撞区域红色闪烁 |
| 主页面 | 左侧面板 | 折叠式面板，滑块调节，单位切换 |
| 主页面 | 顶部工具栏 | 下拉选择器，图标按钮，状态指示灯 |
| 主页面 | 底部时间轴 | 进度条，播放按钮，时间显示 |
| 主页面 | 右侧信息 | 数据卡片，碰撞列表，状态标签 |

### 4.3 响应式
- 桌面端优先，支持大屏显示
- 侧边面板可折叠，适配不同屏幕尺寸
- 3D视口自适应

### 4.4 3D场景指导
- 环境：工业风格，网格地面，柔和环境光
- 光照：方向光 + 环境光，清晰阴影
- 相机：多视角切换，平滑过渡动画
- 交互：鼠标拖拽旋转，滚轮缩放，右键平移
- 动画：车辆移动平滑，碰撞时红色闪烁
- 性能：优先使用低多边形模型，保持60fps
