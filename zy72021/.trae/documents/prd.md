## 1. 产品概述

连锁药房医保垫付对账工具——为结算会计在交接周期中提供医保垫付流水与合同扫描件的自动比对、差异标注与改判回退能力，最终输出老板关心的差异清单。
- 解决手工对照合同扫描件、靠记忆逐条核对的低效与易错问题
- 目标用户：结算会计（如阿宁），使用场景为月度/季度交接前批量对账

## 2. 核心功能

### 2.1 用户角色
| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 结算会计 | 直接打开页面使用 | 导入数据、查看差异、改判、回退、导出报告 |

### 2.2 功能模块
1. **对账列表页**：显示所有对账记录，按状态筛选，高亮差异项
2. **对账详情页**：单条记录的完整信息（收款流水、退款申请、审批邮件、备注），差异对比视图
3. **改判与回退**：对自动判定的结果进行人工改判，支持回退到自动判定结果
4. **导入与增量处理**：上传数据文件，重复导入时明确跳过/更新/冲突策略
5. **导出差异报告**：一键导出差异清单 CSV

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 对账列表页 | 状态筛选栏 | 按对账状态（一致/差异/待确认/已改判）筛选记录 |
| 对账列表页 | 对账记录表格 | 显示药房名称、金额、医保金额、差异额、状态、操作按钮 |
| 对账列表页 | 批量操作栏 | 批量导出差异报告、批量改判 |
| 对账详情页 | 收款流水区 | 显示收款流水原始数据 |
| 对账详情页 | 合同扫描件区 | 显示合同约定的垫付口径与金额 |
| 对账详情页 | 差异对比区 | 并排对比流水与合同，标注差异字段 |

## 3. 核心流程

对账主流程：导入数据 → 自动比对 → 查看差异清单 → 人工确认/改判 → 导出差异报告

增量导入流程：再次导入 → 识别重复 → 按策略处理（跳过/更新/冲突）→ 继续对账

```mermaid
flowchart TD
    A["导入数据文件"] --> B["解析与校验"]
    B --> C{"是否存在重复记录?"}
    C -->|"否"| D["新增记录"]
    C -->|"是"| E{"重复策略"}
    E -->|"跳过"| F["保留原记录，计数+1"]
    E -->|"更新"| G["用新数据覆盖旧记录"]
    E -->|"冲突"| H["标记为冲突，待人工确认"]
    D --> I["自动比对"]
    F --> I
    G --> I
    H --> I
    I --> J{"比对结果"}
    J -->|"一致"| K["标记为一致"]
    J -->|"差异"| L["标记为差异"]
    J -->|"信息不全"| M["标记为待确认"]
    K --> N["差异清单"]
    L --> N
    M --> N
    N --> O{"人工处理"}
    O -->|"改判"| P["更新状态与理由"]
    O -->|"回退"| Q["恢复自动判定结果"]
    O -->|"导出"| R["生成差异报告 CSV"]
    P --> N
    Q --> N
```

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深灰 #1a1a2e 为底，白 #f0f0f5 为面板色，强调色用琥珀 #e8a838 标注差异，绿 #38a169 标注一致
- 按钮风格：圆角矩形，小号，无3D效果，朴素实用
- 字体：Noto Sans SC，正文 14px，表格 13px，标题 18px
- 布局：顶栏导航 + 左侧状态面板 + 右侧主内容区
- 图标：使用简洁线条图标，不使用 emoji

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 对账列表页 | 状态筛选栏 | 水平标签按钮组，选中态为琥珀色底 |
| 对账列表页 | 对账记录表格 | 条纹表格，差异行用琥珀左边框，一致行用绿左边框 |
| 对账列表页 | 批量操作栏 | 底部固定栏，导出按钮、统计数字 |
| 对账详情页 | 差异对比区 | 双列对比卡片，差异字段用琥珀背景高亮 |
| 对账详情页 | 改判面板 | 右侧抽屉，下拉选择+文本框+确认/取消 |
| 导入弹窗 | 文件上传 | 居中弹窗，虚线拖拽区域 |
| 导入弹窗 | 重复策略 | 三选一单选按钮组，附简要说明 |

### 4.3 响应式
- 桌面优先，最小宽度 1024px
- 表格在小屏下可横向滚动
- 详情页在窄屏下差异对比改为上下排列

### 4.4 3D 场景
- 不涉及
