# 连锁药房医保垫付 · 对账工具

为结算会计阿宁准备的交接前对账工具。

## 快速开始

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5175/

## 放样例数据

### 方法一：内置按钮加载
1. 点击右上角 **导入数据**
2. 选择 **加载主流程样例（3条）** 或 **加载边界测试（3条）**

### 方法二：拖拽 JSON 文件
样例文件在 `samples/` 目录下：
- `samples/医保垫付主流程样例.json` — 3 条主流程数据（顺利/待确认/旧口径差异）
- `samples/医保垫付边界测试.json` — 3 条边界数据（空值/重复/零金额）

**主流程样例包含**：
1. ✅ **康民大药房** — 顺利记录，流水=合同，状态一致
2. ⏳ **德善堂药房** — 待确认，合同金额为空
3. ⚠️ **益民药房** — 差异 -4,200 元，来自合同扫描件旧口径

**边界测试包含**：
1. 📭 空名称、空金额 — 待确认
2. 🔁 重复记录（康民大药房）— 用于测试重复策略
3. 0️⃣ 惠民药店零金额 — 边界一致

## 重复导入策略

导入重复数据时三选一：
- **跳过** — 保留原记录，跳过重复项
- **更新** — 用新数据覆盖旧记录
- **标记冲突** — 标记为红色冲突状态，人工确认

每次导入后会显示新增/跳过/更新/冲突的具体数量。

## 对账操作

1. **查看差异** — 点击记录进入详情页，并排对比流水与合同
2. **改判** — 详情页底部"改判"按钮，选择结果+填写理由
3. **回退** — 改判后可"回退到自动判定"
4. **加备注** — 详情页底部可添加手写备注
5. **筛选** — 列表顶部按状态筛选

## 差异报告去哪看

点击列表页右上角 **导出差异报告**，CSV 文件自动下载到浏览器下载目录：

```
~/Downloads/医保垫付差异报告_YYYY-MM-DD.csv
```

报告包含所有非"一致"的记录，字段：药房名称、流水号、流水金额、合同金额、医保金额、差异额、状态、自动判定、改判理由、来源、更新时间。

## 重跑

清空当前数据：右上角 **清空** 按钮，然后重新导入即可。

数据保存在浏览器 LocalStorage，刷新页面不丢失。

## 交接清单

给阿宁的结果 = 导出的 CSV 差异报告 + 列表页"已改判"备注。
