# 仓库巷道拣货热力图

基于 Three.js + React 的 3D 交互式仓库拣货路径热力分析工具。

## 功能特性

- **3D 仓库场景**: 真实比例的货架、巷道、地面网格渲染
- **路径回放系统**: 按时间轴播放拣货员/叉车移动轨迹
- **热力聚合图层**: 基于通行频率和停留时间的热力图叠加，窄巷自动加倍权重
- **时间筛选面板**: 按日期、时段、拣货单筛选数据
- **多视角切换**: 透视、俯视、正视、侧视四种视角
- **报告导出模块**: 生成包含热力图和统计数据的 PDF 分析报告
- **状态持久化**: 刷新页面保留筛选条件和关键状态

## 技术栈

- **前端框架**: React 18 + TypeScript
- **构建工具**: Vite 5
- **样式方案**: Tailwind CSS 3
- **3D 渲染**: Three.js 0.160
- **状态管理**: Zustand + persist middleware
- **图标库**: Lucide React
- **报告导出**: html2canvas + jsPDF

## 操作指南

### 基础操作

1. **3D 视角控制**
   - 🖱️ 左键拖拽: 旋转视角
   - 🖱️ 滚轮: 缩放场景
   - 🖱️ 右键拖拽: 平移视角

2. **工具栏**
   - ▶️ 播放按钮: 开始/暂停路径回放
   - 1x 下拉: 调整播放速度 (0.5x - 8x)
   - ↺ 重置: 恢复初始状态
   - 📊 图层切换: 热力图、路径、货架显示开关
   - 📷 视角: 切换透视/俯视/正视/侧视
   - 📥 导出: 导出 PDF 报告或 JSON 数据

3. **左侧筛选面板**
   - 点击拣货单可选中单个，Shift + 点击可多选
   - 查看巷道信息（普通/窄巷标记）

4. **右侧分析面板**
   - 热力图例说明
   - 热力强度调节滑块
   - 统计概览数据
   - 拥堵巷道排名

5. **底部时间轴**
   - 拖拽进度条查看不同时间点
   - 时间范围输入框筛选时段
   - 彩色条显示各拣货单时间分布

### 可复现操作流程

#### 场景 1: 查看全天热力分布

1. 打开应用，默认加载样例数据
2. 确认热力图开关（工具栏第一个按钮）已开启
3. 点击播放按钮开始回放
4. 观察窄巷 C、D 区域（紫色标记）的热力累积
5. 拖动时间轴滑块到不同时间点，观察热力变化

#### 场景 2: 筛选单个拣货单路径

1. 在左侧面板点击任意拣货单（如 order-001）
2. 观察 3D 场景中只显示该拣货单的路径
3. 点击播放，查看单个拣货员的完整行进路线
4. 点击「清除选择」恢复全部显示

#### 场景 3: 导出分析报告

1. 调整时间范围到 09:00 - 12:00
2. 切换到俯视图，调整到合适视角
3. 点击工具栏导出按钮 → 导出分析报告 (PDF)
4. 浏览器自动下载 PDF 文件

#### 场景 4: 验证状态持久化

1. 调整热力强度到 1.5x
2. 关闭左侧和右侧面板
3. 切换到俯视图视角
4. 刷新浏览器页面
5. 验证所有设置保持不变

## 热力图算法说明

### 热力值计算

```
热力值 = 基础权重 × (1 + 停留时间系数) × 巷道宽度系数
```

- **基础权重**: 10 × 热力强度设置
- **停留时间系数**: 速度 < 0.3 m/s 时，停留时间越长系数越高
- **巷道宽度系数**: 窄巷（宽度 < 2.5m）为 2.0，普通巷道为 1.0

### 颜色映射

| 热力等级 | 颜色   | 说明 |
|---------|--------|------|
| 0-25%   | 蓝色   | 低流量 |
| 25-50%  | 青色   | 中低流量 |
| 50-75%  | 黄色   | 中高流量 |
| 75-100% | 红色   | 高拥堵 |

## 注意事项

1. 应用内置样例数据，无需额外配置即可运行
2. 窄巷标记为紫色地面，拥堵计算权重加倍
3. 状态保存在浏览器 localStorage 中
4. 建议使用 Chrome/Edge 浏览器获得最佳性能
