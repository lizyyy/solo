## 二、正常业务流程验收

### 验收1：查看台账（入口）

**操作步骤：**
1. 打开前端页面 http://localhost:8080
2. 点击顶部导航栏的 **"📦 危化品台账"** 标签
3. 确认能看到 5 种预置化学品：硫酸、盐酸、乙醇、丙酮、氢氧化钠
4. 点击任一化学品右侧的 **"查看批号"** 按钮
5. 确认能看到该化学品的所有批号库存详情（批号、可用数量、位置等）

**验收点：**
- ✓ 危化品台账作为系统入口正常展示
- ✓ 每个化学品关联多个批号
- ✓ 批号信息包含：批号（证据标识）、生产商、有效期、可用数量、位置

---

### 验收2：新建领用单（审批作为关键校验）

**操作步骤：**
1. 点击 **"📝 领用单"** 标签
2. 点击右上角 **"+ 新建领用"** 按钮
3. 填写表单：
   - 领用人：选择"张同学"
   - 危化品：选择"硫酸"
   - 批号：选择"H2SO4-2024-001"（注意看可用数量：5000 mL）
   - 申请数量：输入 500
   - 用途：输入"有机合成实验"
   - 实验室位置：输入"化学楼A301"
   - 审批导师：选择"王教授"
4. 点击 **"创建领用单"** 按钮

**验收点：**
- ✓ 创建成功，领用单状态为"待导师审批"（如果选了导师）
- ✓ 系统自动关联了：化学品 → 具体批号 → 导师审批人

---

### 验收3：导师审批（关键校验点）

**操作步骤：**
1. 在领用单列表中找到刚创建的领用单
2. 点击右侧 **"详情"** 按钮
3. 在详情弹窗中，确认：
   - 顶部显示当前状态："待导师审批"
   - "下一步处理建议" 提示等待导师审批
   - "状态历史" 时间线显示创建记录
4. 点击 **"✅ 导师批准"** 按钮
5. 批准数量输入 500（必须 ≤ 申请数量）
6. 点击 **"确认批准"**

**验收点：**
- ✓ 状态变为"已批准"
- ✓ 批准数量被记录
- ✓ 状态历史增加了"已批准"记录
- ✓ 无法跳过审批直接出库（状态机校验）

---

### 验收4：办理出库（批号库存扣减）

**操作步骤：**
1. 继续在详情弹窗中
2. 点击 **"📦 办理出库"** 按钮
3. 打开 **"🏷️ 批号库存"** 标签页
4. 找到对应的批号 "H2SO4-2024-001"

**验收点：**
- ✓ 领用单状态变为"已出库"
- ✓ 批号库存可用数量从 5000 变为 4500（扣减了 500）
- ✓ 批号作为"库存证据"被精确跟踪

---

### 验收5：回收登记（闭环检查）

**操作步骤：**
1. 回到领用单详情
2. 点击 **"🔄 登记回收"** 按钮
3. 输入回收数量：300（假设实验用了 200，还剩 300）
4. 点击 **"确认回收"**

**验收点：**
- ✓ 状态变为"部分回收"（因为 300 < 500）
- ✓ 批号库存可用数量增加了 300（回收入库）
- ✓ 闭环率显示 60%
- ✓ 状态历史增加回收记录

**继续操作：**
5. 再次点击 **"🔄 登记回收"**
6. 输入回收数量：200（剩余的全部回收）

**验收点：**
- ✓ 状态变为"完全回收"
- ✓ 闭环率显示 100%
- ✓ 批号库存恢复到接近出库前水平

---

### 验收6：确认闭环（最终状态）

**操作步骤：**
1. 在完全回收状态下
2. 点击 **"🔒 确认闭环"** 按钮

**验收点：**
- ✓ 状态变为"已关闭"
- ✓ 整个领用流程完整闭环
- ✓ 状态历史完整记录全流程：创建 → 待审批 → 已批准 → 已出库 → 部分回收 → 完全回收 → 已关闭

## 六、状态机说明

系统严格遵循以下状态流转（无法跳步）：

```
草稿(DRAFT) 
    ↓
待导师审批(PENDING_APPROVAL) ←────┐
    ↓              ↓              │
  已批准         已拒绝(REJECTED)──┘
(APPROVED)
    ↓
  已出库(OUTBOUND)
    ↓
部分回收(PARTIAL_RETURN) ←──┐
    ↓                       │
完全回收(FULL_RETURN)       │
    ↓                       │
  已关闭(CLOSED)             │
```

**状态机特性：**
- 草稿 → 提交审批（必须选导师）
- 待审批 → 批准 或 拒绝（拒绝后可回退到草稿修改）
- 已批准 → 出库（扣减库存）
- 已出库 → 部分回收 或 完全回收（增加库存）
- 完全回收 → 关闭（必须 100% 回收）
