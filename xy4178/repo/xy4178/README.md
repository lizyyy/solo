# 分段吊装避碰沙盘

> 船厂吊装协调员 3D 预演工具

在开吊前，通过导入分段尺寸、吊车参数、码头障碍物 CSV 和潮位窗口数据，在 3D 环境中预演吊装过程，实时检查吊装半径、净空、重心偏移、潮位时间窗和障碍碰撞风险。

## 功能特性

### 🎯 核心功能

- **3D 场景可视化**: 可旋转缩放的 3D 船坞、吊车和分段模型
- **实时碰撞检测**: 吊装半径、净空高度、重心偏移、潮位窗口、障碍物碰撞
- **路径规划**: 拖动吊点和路径关键帧，规划最优吊装路线
- **数据导入**: 支持 CSV 格式的分段数据、吊车参数、障碍物、潮位窗口导入
- **方案导出**: Markdown 方案文档、CSV 风险清单、JSON 场景包
- **复核存储**: 本地持久化保存复核意见和场景状态

### 🔧 碰撞检测项

| 检测类型 | 说明 |
|---------|------|
| 吊装半径违规 | 分段位置超出吊车最大/最小半径范围 |
| 净空违规 | 分段高度低于安全净空要求 |
| 重心偏移 | 分段重心偏离中心或倾斜角度过大 |
| 潮位窗口 | 关键帧时间不在潮位窗口内 |
| 障碍物碰撞 | 分段与临时支架/现有结构距离过近 |
| 吊臂扫掠 | 吊臂路径可能与障碍物干涉 |
| 起重量违规 | 分段重量超出当前半径下起重量限制 |
| 转运路线阻挡 | 分段位于转运路线区域内 |

## 技术栈

- **前端框架**: React 18
- **3D 引擎**: Three.js + @react-three/fiber + @react-three/drei
- **构建工具**: Vite 5
- **类型系统**: TypeScript

- **图标库**: Lucide React
- **CSV 解析**: PapaParse
- **UUID 生成**: uuid

## 使用指南

### 1. 导入数据

左侧边栏提供了四种数据导入入口：

| 数据类型 | 说明 |
|---------|------|
| 分段数据 | 分段尺寸、重量、重心、吊点位置等 |
| 障碍物数据 | 临时支架、转运路线、现有结构等 |
| 潮位窗口 | 可吊装的时间窗口和潮位高度范围 |
| 吊车参数 | 吊车半径范围、起重量曲线、吊臂长度等 |

**快速开始**: 点击各数据类型的「示例」按钮下载示例 CSV，然后导入查看效果。

### 2. 查看 3D 场景

主界面是可交互的 3D 场景：

- **鼠标左键拖动**: 旋转视角
- **鼠标右键拖动**: 平移场景
- **鼠标滚轮**: 缩放场景
- **鼠标中键**: 重置视角（部分鼠标）

场景中显示的元素：

| 元素 | 颜色 | 说明 |
|------|------|------|
| 分段 | 绿色 | 待吊装的船体分段 |
| 吊车 | 橙色 | 码头起重吊车 |
| 临时支架 | 红色 | 需要注意避让的临时支撑 |
| 转运路线 | 蓝色 | 物料转运通道区域 |
| 现有结构 | 紫色 | 永久性建筑/设施 |
| 关键帧 | 青色 | 吊装路径控制点 |

### 3. 添加关键帧

1. 在左侧边栏展开「关键帧控制」
2. 点击「添加关键帧」按钮
3. 关键帧将自动添加到当前分段位置
4. 可在 3D 场景中看到关键帧标记

### 4. 运行碰撞检测

1. 展开左侧边栏「碰撞检测」
2. 点击「运行检测」按钮
3. 查看检测结果列表：
   - 🔴 红色: 严重风险，必须处理
   - 🟠 橙色: 警告风险，需要关注
   - 🔵 蓝色: 信息提示，常规信息

### 5. 导出方案

完成预演后，可导出三种格式的方案：

| 格式 | 说明 | 用途 |
|------|------|------|
| Markdown | 完整的吊装方案文档 | 提交审批、存档 |
| CSV | 风险清单表格 | 数据分析、汇报 |
| JSON | 完整场景数据包 | 后续编辑、共享 |

展开左侧边栏「导出方案」，点击对应按钮即可下载。

## 风险等级说明

| 等级 | 颜色 | 说明 | 处理建议 |
|------|------|------|----------|
| 严重 | 🔴 红色 | 可能导致安全事故 | 必须立即处理，调整吊装方案 |
| 警告 | 🟠 橙色 | 可能影响吊装作业 | 需要关注，考虑优化路径 |
| 信息 | 🔵 蓝色 | 常规提示信息 | 了解即可，不影响作业 |

## 注意事项

1. **数据准确性**: 请确保导入的 CSV 数据准确无误，特别是尺寸和重量参数
2. **潮位时间**: 潮位窗口的时间格式建议使用 ISO 格式 (YYYY-MM-DDTHH:mm:ss)
3. **坐标系**: 所有坐标均以船坞中心为原点，单位为米
4. **安全裕度**: 碰撞检测已包含 1 米的安全裕度，实际作业中请考虑额外裕度
5. **人工复核**: 本工具仅为预演辅助，最终吊装方案必须经过人工复核
