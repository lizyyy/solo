# 按压节奏训练器 - CPR 胸外按压训练

一款专为急救培训教练设计的本地浏览器小游戏，帮助学员掌握正确的 CPR 胸外按压节奏（100-120 次/分钟）。

## 功能特性

### 核心训练功能
- **实时节奏反馈**：根据按压时机给出「完美」「合格」「过快」「过慢」「漏拍」「连击误触」的即时反馈
- **多维度显示**：
  - 进度条：显示训练剩余时间
  - 节拍环：可视化当前节拍位置
  - 散点图：显示最近 10 次按压的偏差情况
- **多种时长选择**：支持 30 秒、60 秒、120 秒或自定义时长训练

### 评分系统
训练结束后自动生成本轮评分，包括：
- **综合评分**：0-100 分的整体评价
- **平均 BPM**：实际按压频率
- **准确率**：合格按压占比
- **稳定度**：节奏一致性评分
- **最长连续合格段**：最长的连续合格按压次数
- **详细统计**：过快、过慢、漏拍、连击误触、完美按压的具体次数
- **智能建议**：根据表现给出针对性的练习建议

### 教练模式
可配置高级训练参数：
- 目标 BPM 范围（默认 100-120）
- 误差容忍毫秒数（默认 100ms）
- 节拍提示音开关
- 鼠标点击输入开关
- 提示音音量调节
- 历史记录保存数量

### 数据管理
- **本地存储**：训练记录保存在浏览器 localStorage 中，刷新不丢失
- **历史记录**：可查看最近的训练记录和统计数据
- **数据导出**：支持导出单条或全部记录为 JSON 或 CSV 格式，方便课后汇总

### 边界情况处理
- 训练中途暂停/重开
- 窗口失焦自动暂停
- 按键长按连发防抖（150ms）
- 自定义时长非法值校验（10-600 秒）
- 没有任何按压时的特殊处理

## 安装和启动

### 方式一：直接打开 HTML 文件
由于使用了 ES Modules，直接双击打开可能会遇到 CORS 限制。建议使用本地服务器。

### 方式二：使用 Python 启动本地服务器

```bash
# Python 3
python3 -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```

然后在浏览器中访问：`http://localhost:8080`

### 方式三：使用 Node.js 的 http-server

```bash
# 安装（如果已安装可跳过）
npm install -g http-server

# 启动
http-server -p 8080
```

然后在浏览器中访问：`http://localhost:8080`

### 方式四：使用 VS Code Live Server 插件
1. 在 VS Code 中安装「Live Server」插件
2. 右键点击 `index.html`，选择「Open with Live Server」

## 手动验证核心流程

### 测试场景 1：完美节奏训练
**目标**：验证完美按压的反馈和评分

**操作步骤**：
1. 选择 30 秒训练时长
2. 点击「开始训练」，等待倒计时结束
3. 按 **约 0.5-0.6 秒** 的间隔连续按空格键（对应 100-120 BPM）
4. 持续按压直到训练结束

**预期结果**：
- 每次按压后显示「完美」或「合格」反馈
- 散点图上的点应该靠近中线
- 最终评分应该在 80 分以上
- 平均 BPM 应该在 100-120 之间

### 测试场景 2：过快/过慢节奏
**目标**：验证节奏偏差的反馈

**操作步骤**：
1. 选择 30 秒训练时长
2. 开始训练后，先快速按空格键（间隔 < 0.4 秒）
3. 然后放慢节奏（间隔 > 0.7 秒）
4. 观察反馈变化

**预期结果**：
- 快速按压时显示「过快」反馈，颜色为红色
- 慢速按压时显示「过慢」反馈，颜色为黄色
- 散点图上的点分别偏向上下两侧
- 最终统计中「过快次数」和「过慢次数」应该有数值

### 测试场景 3：连击误触测试
**目标**：验证防抖和连击误触检测

**操作步骤**：
1. 选择 30 秒训练时长
2. 开始训练后，快速连续按两次空格键（间隔 < 150ms）
3. 或者长按空格键不放

**预期结果**：
- 只有第一次按压被计数，第二次被忽略或显示「连击误触」
- 长按空格键不会产生多次按压
- 统计中可能出现「连击误触」计数

### 测试场景 4：漏拍测试
**目标**：验证漏拍检测

**操作步骤**：
1. 选择 30 秒训练时长
2. 开始训练后，正常按压几次
3. 然后停止按压 2 秒以上

**预期结果**：
- 停止按压约 1 秒后显示「漏拍」反馈
- 最终统计中「漏拍次数」应该有数值

### 测试场景 5：暂停/重开功能
**目标**：验证暂停和恢复

**操作步骤**：
1. 选择 60 秒训练时长
2. 开始训练并按压几次
3. 点击「暂停」按钮（或切换到其他标签页）
4. 等待几秒后点击「继续训练」
5. 继续按压直到结束

**预期结果**：
- 暂停期间计时器停止，按压输入无效
- 恢复后计时器继续，不计算暂停时间
- 最终的「最长连续合格段」可能会中断（暂停前的连击被重置）

### 测试场景 6：无按压训练
**目标**：验证零按压边界情况

**操作步骤**：
1. 选择 30 秒训练时长
2. 开始训练后不进行任何按压
3. 等待训练自然结束

**预期结果**：
- 训练结束后显示「本次训练没有进行任何按压」的提示
- 综合评分为 0 分
- 建议中提示尝试按压

### 测试场景 7：教练模式配置
**目标**：验证高级配置功能

**操作步骤**：
1. 从主界面点击「教练模式」
2. 尝试修改以下参数：
   - 目标 BPM 下限改为 90
   - 目标 BPM 上限改为 130
   - 误差容忍改为 150ms
   - 关闭「节拍提示音」
3. 点击「保存配置」
4. 返回主界面进行一次训练

**预期结果**：
- 配置保存成功无错误提示
- 训练时不再听到节拍音
- 节奏判断更加宽松（因为 BPM 范围更大、容忍度更高）

### 测试场景 8：配置错误验证
**目标**：验证非法配置的错误提示

**操作步骤**：
1. 进入教练模式
2. 将「目标 BPM 下限」设为 130，「目标 BPM 上限」设为 100（下限 > 上限）
3. 点击「保存配置」

**预期结果**：
- 显示错误提示：「目标 BPM 上限不能低于下限」
- 配置不会被保存

### 测试场景 9：历史记录和导出
**目标**：验证数据持久化和导出

**操作步骤**：
1. 完成一次训练
2. 从主界面点击「历史记录」
3. 查看刚才的训练记录
4. 点击单条记录的「导出 JSON」和「导出 CSV」
5. 点击「全部导出 JSON」和「全部导出 CSV」
6. 刷新页面，再次进入历史记录

**预期结果**：
- 历史记录列表显示刚才的训练
- 导出的文件被下载
- 刷新页面后历史记录仍然存在（localStorage 持久化）

## 技术说明

### 浏览器兼容性
- 使用 ES Modules（`import`/`export`）
- 使用 Web Audio API 生成音效
- 使用 localStorage 进行数据持久化
- 建议使用 Chrome、Firefox、Safari 最新版本

### 核心算法
- **BPM 计算**：基于最近两次有效按压的时间间隔计算
- **偏差判断**：
  - 完美：偏差 ±50ms 内
  - 合格：偏差在容忍范围内（默认 ±100ms）
  - 过快：间隔小于最小有效间隔
  - 过慢：间隔大于最大有效间隔
  - 连击：间隔小于最小有效间隔的 60%
- **评分公式**：
  ```
  综合评分 = 准确率 × 60 + 稳定度 × 30 + (最长连续/总按压) × 10
  ```
