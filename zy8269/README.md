# 🚇 地铁站早高峰限流调度小游戏

一个互动式地铁站客流管理模拟游戏，玩家扮演值班站长，通过控制闸机、扶梯和临时围栏来管理早高峰期间的人流。

## 🎮 游戏特性

- **客流状态机**：真实模拟乘客从进站到乘车的完整行为流程
- **容量计算系统**：实时监控各区域人流密度和容量利用率
- **风险预警机制**：根据人流情况提供多级风险提示
- **计分系统**：根据运营效率、安全性进行综合评分
- **复盘导出**：游戏结束后可导出完整的操作记录和统计数据
- **边界情况处理**：
  - 跨午夜末班车延误场景
  - 无障碍通道被误封的严重违规检测

## 📦 安装

### 环境要求
- Node.js 16+ 
- npm 或 yarn

1. 克隆或下载项目到本地
2. 在项目根目录执行：

## 🎯 游戏玩法

### 操作说明

| 操作对象 | 操作方式 | 效果 |
|---------|---------|------|
| 闸机 | 点击 | 打开/关闭 |
| 扶梯 | 点击 | 切换运行方向（上/下） |
| 临时围栏 | 点击 | 放置/移除 |

### 游戏目标

1. **安全第一**：确保所有乘客安全，避免踩踏等安全事件
2. **高效运营**：引导乘客快速通过闸机和扶梯，减少拥堵
3. **合规要求**：无障碍通道（标记为 ♿）必须保持开启！
4. **容量管理**：保持各区域人流密度在安全阈值以内（<85%）

### 风险等级

- 🟢 **正常** (风险 < 30%)：运营状况良好
- 🟡 **警戒** (风险 < 60%)：部分区域开始拥挤
- 🟠 **警告** (风险 < 80%)：人流密度较高，建议采取措施
- 🔴 **危险** (风险 >= 80%)：严重超载，立即限流！

### 计分规则

| 行为 | 分数变化 |
|------|---------|
| 乘客成功乘车 | +10分/人 |
| 安全运营连续60秒 | 连击加成 (+10%~+50%) |
| 无障碍通道被关闭 | -100分，安全事件+1 |
| 安全事件累计3次 | 游戏失败 |

## 📊 复盘导出

游戏结束后，点击"复盘导出"按钮可以下载完整的游戏记录JSON文件，包含：

- 游戏基本信息（关卡名称、起止时间）
- 最终统计数据（得分、疏散人数、最高风险、安全事件数）
- 完整操作历史（闸机开关、扶梯换向、围栏放置等）
- 重要事件记录（列车到站、客流波次、风险预警等）

导出文件可用于：
- 分析操作策略的有效性
- 教学演示最佳实践
- 游戏结果存档

## 🎨 自定义关卡

你可以通过修改 `src/levels/sample-level.js` 来创建自定义关卡，或添加新的关卡文件。

关卡配置包含以下主要部分：

```javascript
{
  name: '关卡名称',
  description: '关卡描述',
  areas: [/* 区域定义 */],
  objects: [/* 可交互对象（闸机、扶梯等） */],
  trainSchedule: [/* 列车时刻表 */],
  crowdWaves: [/* 客流波次 */],
  rules: { /* 游戏规则参数 */ }
}
```
