# 同步节拍工坊

一个给朋友聚会投屏玩的本地网页小游戏。画面里有一条会随音乐节拍滚动的生产线，玩家按方向键把落到判定区的零件打上颜色，连续命中会加连击，漏按或错按会让流水线卡顿。

## 功能特性

- 🎮 **四轨下落式音游**：四条轨道对应四个方向键
- ⏱️ **精准判定系统**：Perfect (±50ms)、Good (±150ms)、Miss
- 🔥 **连击系统**：连续命中增加连击，最高5倍分数加成
- 📊 **详细统计**：Perfect/Good/Miss计数、准确率、评级(S/A/B/C/D)
- ⏸️ **暂停功能**：随时暂停和继续游戏
- 🎵 **三首内置谱面**：新手入门、进阶挑战、大师级
- 🎨 **谱面编辑器**：创建和编辑自定义谱面
- 💾 **本地存储**：自动保存最高分记录
- 🎶 **定时节拍模拟**：无需真实音频，使用定时节拍

## 快速开始

### 启动方式

1. **使用本地服务器**（推荐）：

```bash
# 使用 Python
python3 -m http.server 8080

# 或者使用 Node.js (需要安装 http-server)
npx http-server -p 8080

# 或者使用 PHP
php -S localhost:8080
```

2. **直接打开**：
   - 双击 `index.html` 文件在浏览器中打开
   - 注意：某些浏览器可能限制本地文件的 localStorage 访问

3. **访问游戏**：
   - 打开浏览器访问 `http://localhost:8080`

### 玩法说明

#### 基本操作

| 按键 | 功能 |
|------|------|
| ← (左方向键) | 击打左轨道音符 |
| ↓ (下方向键) | 击打下轨道音符 |
| ↑ (上方向键) | 击打上轨道音符 |
| → (右方向键) | 击打右轨道音符 |
| ESC | 暂停/继续游戏 |

#### 游戏规则

1. **选择谱面**：在主菜单选择想要挑战的谱面
2. **击打音符**：当音符下落到判定线（屏幕底部发光线）时，按下对应的方向键
3. **判定时机**：
   - **Perfect**：误差在 ±50ms 以内，获得100分
   - **Good**：误差在 ±150ms 以内，获得50分
   - **Miss**：错过或按错，连击归零
4. **连击加成**：每连续命中一个音符，连击数+1，分数倍率最高可达5倍
5. **游戏结束**：所有音符结束后显示结算界面

#### 评级标准

| 评级 | 准确率要求 |
|------|-----------|
| S | ≥ 95% |
| A | ≥ 90% |
| B | ≥ 80% |
| C | ≥ 70% |
| D | < 70% |

## 内置谱面

游戏包含三首精心设计的示例谱面：

### 1. 新手入门
- **BPM**: 120
- **难度**: ⭐
- **特点**: 简单的循环节奏，适合新手熟悉操作
- **音符模式**: 按 ← ↓ ↑ → 顺序循环

### 2. 进阶挑战
- **BPM**: 140
- **难度**: ⭐⭐
- **特点**: 中等难度，包含多种节奏变化
- **音符模式**: 8种不同的四音符模式循环

### 3. 大师级
- **BPM**: 180
- **难度**: ⭐⭐⭐
- **特点**: 高难度谱面，考验反应速度
- **音符模式**: 随机与规律结合，快节奏

## 谱面编辑器

### 如何使用

1. 点击主菜单的「谱面编辑器」按钮
2. 设置谱面参数：
   - **谱面名称**：自定义谱面的名称
   - **BPM**：每分钟节拍数（影响节拍间隔）
   - **节拍间隔**：两个节拍之间的时间（秒）

3. 放置音符：
   - 点击画布上的轨道位置选择时间点
   - 点击下方的方向按钮（← ↓ ↑ →）放置音符
   - 音符会自动按时间排序

4. 编辑音符：
   - 点击画布上的音符可以选中
   - 点击「清除当前」按钮删除选中的音符

5. 预览和保存：
   - 点击「预览谱面」查看播放效果
   - 点击「保存谱面」保存到本地存储
   - 点击「加载谱面」加载已保存的谱面

### 注意事项

- 自定义谱面会保存在浏览器的 localStorage 中
- 清除浏览器数据会丢失自定义谱面
- 建议使用导出功能备份重要谱面

## 本地存储

游戏使用浏览器的 localStorage 存储以下数据：

### 存储内容

| 数据类型 | 说明 |
|---------|------|
| 最高分 | 每个谱面的历史最高分 |
| 自定义谱面 | 用户创建的谱面数据 |
| 游戏设置 | 音符速度等配置 |

### 数据导出/导入

在浏览器控制台执行：

```javascript
// 导出所有数据
const data = Storage.exportData();
console.log(data);

// 导入数据
Storage.importData(jsonString);
```

## 常见问题

### Q: 为什么双击 index.html 打开后无法保存谱面？
A: 某些浏览器出于安全考虑，限制了本地文件的 localStorage 访问。建议使用本地服务器启动。

### Q: 如何调整音符速度？
A: 目前音符速度固定为 400 像素/秒。可以修改 `renderer.js` 中的 `noteSpeed` 配置。

### Q: 可以添加自己的音乐吗？
A: 当前版本使用定时节拍模拟，不支持真实音频。后续版本可能添加音频支持。

### Q: 如何备份我的自定义谱面？
A: 在浏览器控制台执行 `Storage.exportData()` 获取 JSON 数据，保存到文件中。
