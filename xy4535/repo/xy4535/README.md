# 海盐晒场卤水结晶进度管理工具

一个本地可运行的小工具，帮助场长复盘每天的卤水结晶进度，支持数据导入、进度展示、人工改判和数据导出。

## 功能特点

- **数据导入**：支持导入盐池分区表、卤度计 CSV、天气站记录、闸门放卤日志和收盐批次记录
- **盐池总览**：按盐池展示浓缩进度、雨后稀释、错池放卤和可收盐风险
- **人工改判**：支持人工修改盐池状态判断，保存备注信息
- **数据持久化**：所有数据保存在浏览器本地存储，刷新页面不会丢失
- **数据导出**：支持导出 Markdown 交接单和 JSON 审计明细
- **示例数据**：内置示例数据，可快速体验工具功能

## 快速开始

### 方式一：直接打开

1. 下载或克隆本项目到本地
2. 双击打开 `index.html` 文件
3. 点击"加载示例数据"按钮即可体验完整功能

### 方式二：本地服务器（推荐）

如果你有 Python，可以使用简单的 HTTP 服务器：

```bash
# Python 3
python -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```

然后在浏览器中访问 `http://localhost:8080`

## 功能说明

### 1. 数据导入

在"数据导入"标签页，你可以导入以下类型的 CSV 文件：

#### 盐池分区表
```csv
盐池编号,分区名称,面积(亩),卤水深度(cm)
A-01,东区第一池,15.5,20
```

#### 卤度计 CSV
```csv
盐池编号,测量时间,卤度(°Be'),温度(°C)
A-01,2026-05-01 08:00,10.5,22
```

#### 天气站记录
```csv
日期,天气类型,气温(°C),湿度(%),风速(m/s),降水量(mm)
2026-05-01,晴,25,60,3.2,0
```

#### 闸门放卤日志
```csv
日期,操作时间,操作人,来源盐池,目标盐池,放卤量(m³),备注
2026-05-03,14:30,张三,A-01,A-02,500,补充稀释后的卤水
```

#### 收盐批次记录
```csv
批次号,盐池编号,收盐日期,收盐量(吨),盐质等级,操作人
H-2026-001,A-03,2026-05-06,0,待检测,待安排
```

示例数据存放在 `data/` 目录下，你可以直接使用这些文件进行测试。

### 2. 盐池总览

在"盐池总览"标签页，你可以：

- **查看所有盐池的状态**：包括正常浓缩、雨后稀释、可收盐风险、可收盐
- **使用筛选功能**：按盐池编号或状态进行筛选
- **查看详细信息**：点击任意盐池卡片，打开详情模态框

#### 盐池状态说明

- **正常浓缩（蓝色）**：卤度持续上升，无异常情况
- **雨后稀释（橙色）**：检测到降雨后卤度下降
- **可收盐风险（红色）**：卤度接近饱和（≥24°Be'），建议尽快收盐
- **可收盐（绿色）**：卤度已达到饱和（≥95%进度）

#### 盐池详情

点击盐池卡片后，可以查看：

- **基本信息**：盐池编号、名称、面积、深度、当前卤度、温度
- **浓缩进度**：可视化进度条和历史变化图表
- **雨后稀释**：是否检测到降雨后的卤度下降
- **错池放卤**：近期的放卤操作记录
- **可收盐风险**：当前风险等级和建议
- **人工改判**：可手动修改盐池状态判断
- **备注**：添加自定义备注信息

### 3. 数据导出

在"数据导出"标签页，你可以：

#### 导出 Markdown 交接单

适合打印或在线阅读的交接单，包含：
- 盐池总览表格
- 每个盐池的详细信息
- 近期天气记录
- 人工改判和备注

#### 导出 JSON 审计明细

完整的结构化数据，包含：
- 所有导入的原始数据
- 系统计算的盐池状态
- 人工改判记录
- 备注信息

## 技术实现

### 前端技术栈

- **HTML5**：页面结构
- **CSS3**：样式设计，响应式布局
- **原生 JavaScript**：业务逻辑实现
- **LocalStorage**：本地数据持久化

### 核心逻辑

1. **数据导入**：使用 FileReader API 读取 CSV 文件，解析为 JavaScript 对象
2. **状态计算**：
   - 浓缩进度 = (当前卤度 / 目标卤度) × 100%
   - 雨后稀释检测：比较降雨日期前后的卤度变化
   - 可收盐风险：卤度 ≥ 24°Be' 为高风险，≥ 22°Be' 为中等风险
3. **数据持久化**：所有数据通过 localStorage 存储，页面刷新后自动恢复
4. **数据导出**：
   - Markdown：手动生成格式化的文本内容
   - JSON：直接序列化完整数据对象

## 常见问题

### Q: 数据会丢失吗？
A: 数据保存在浏览器的 localStorage 中，只要不清除浏览器数据，数据就会一直保留。建议定期导出 JSON 审计明细作为备份。

### Q: 支持哪些浏览器？
A: 支持所有现代浏览器，包括 Chrome 60+、Firefox 55+、Safari 11+、Edge 79+。

### Q: 如何修改卤度饱和值？
A: 目前饱和卤度固定为 25°Be'，如果需要修改，可以在 `app.js` 文件中找到 `calculatePondStatus` 函数，修改 `targetSalinity` 变量的值。

### Q: 可以导入自己的数据吗？
A: 可以，请确保 CSV 文件的表头与示例数据一致。你可以参考 `data/` 目录下的示例文件格式。
