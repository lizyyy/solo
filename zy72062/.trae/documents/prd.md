## 1. 产品概述

金融集团股权星图是一个面向设计院工作人员的股权关系可视化与数据管理工具，核心解决股权数据在 GIS 空间中的呈现、参数联动、异常追踪和方案持久化问题。目标用户为设计院的小赵及其同事，需要处理包含坐标偏移、设备重名、缺照片和跨楼层异常等质量问题的原始材料，并保证每条数据的来源可追溯、异常不丢失、增补有差异记录。

- 解决股权材料保存后无法复原、参数面板与场景/明细/报告不同步的问题
- 保证异常数据不会被汇总数字吞没，坐标系不一致时显式标注而非强行合并

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 设计院分析师 | 无需注册，本地使用 | 导入材料、编辑参数、标注异常、导出报告 |

### 2.2 功能模块

1. **星图总览页**：股权关系星图可视化、GIS 底图叠加、异常标记、视角选择
2. **数据明细页**：股权实体列表、参数面板、增补备注、差异对比
3. **审计报告页**：汇总统计、异常清单、来源追溯、处理时间线

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 星图总览页 | 星图画布 | 力导向/径向股权关系图，节点可拖拽，支持缩放平移，坐标系不一致的节点用虚线边框+标签标注 |
| 星图总览页 | GIS 底图层 | 可叠加 GIS 底图，坐标系来源标注在图例中 |
| 星图总览页 | 异常浮层 | 点击异常节点弹出详情：坐标偏移量、重名匹配、缺照片、跨楼层标记，每条异常带来源和处理时间 |
| 星图总览页 | 视角选择器 | 保存/恢复视角（缩放级别+平移偏移），刷新后自动恢复上次视角 |
| 数据明细页 | 实体列表 | 所有股权实体的表格，支持筛选（按异常类型、坐标系、楼层），异常行高亮 |
| 数据明细页 | 参数面板 | 编辑实体参数（名称、持股比例、坐标、楼层等），修改后实时联动星图和报告 |
| 数据明细页 | 增补备注 | 对已有实体追加备注，记录增补时间、增补内容，差异对比展示（原文 vs 增补后） |
| 数据明细页 | 重名检测 | 自动识别同一设备/实体的不同写法，标记疑似重复，由用户确认合并或保留 |
| 审计报告页 | 汇总统计 | 持股比例汇总、实体数量统计，异常数量单独列出（不混入正常汇总） |
| 审计报告页 | 异常清单 | 所有异常的详细列表，每条带来源、处理时间、当前状态（待处理/已确认/已忽略） |
| 审计报告页 | 来源追溯 | 每条数据展示原始来源文件名、导入时间、处理时间戳 |
| 审计报告页 | 操作时间线 | 所有操作（导入、编辑、增补、标注）按时间排列，支持回溯 |

## 3. 核心流程

**主流程**：用户导入一小包材料 → 系统解析并检测异常（坐标偏移/重名/缺照片/跨楼层）→ 用户在星图中查看、在明细中编辑参数 → 参数变更联动更新星图和报告 → 用户增补备注 → 系统记录差异 → 保存方案（含视角、异常标注、处理状态）→ 刷新后恢复全部状态

**异常处理流程**：检测到异常 → 标注异常类型和来源 → 在星图中用虚线边框+标签显示 → 在明细表中高亮 → 在报告中单独列出（不混入正常汇总）→ 用户确认/忽略 → 状态变更记录时间戳

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深蓝灰（#1a1f2e）为底，金琥珀色（#d4a543）为强调色，代表金融的严肃与股权的价值感
- **辅助色**：异常用珊瑚红（#e8634f），坐标系标注用青色（#3ec9c2），正常数据用银灰（#8b95a5）
- **按钮风格**：扁平圆角，hover 时微弱发光边框
- **字体**：标题用 Noto Serif SC，正文用 Noto Sans SC，数据用 JetBrains Mono
- **布局风格**：左侧边栏导航，主区域为画布/表格，右侧面板为参数/详情
- **图标**：Lucide 图标集，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 星图总览页 | 星图画布 | Canvas/SVG 力导向图，深色背景，金琥珀色连线，节点按类型着色，异常节点虚线边框+角标，坐标系标签悬浮 |
| 星图总览页 | 视角选择器 | 右上角下拉，已保存视角列表，当前视角高亮 |
| 星图总览页 | 异常浮层 | 点击异常节点弹出卡片，含异常类型标签、来源、时间戳 |
| 数据明细页 | 实体列表 | 表格，表头固定，异常行左侧红条，列含来源标记 |
| 数据明细页 | 参数面板 | 右侧滑出面板，表单控件，实时预览变更 |
| 数据明细页 | 增补备注 | 弹出对话框，左原文右增补后，差异高亮 |
| 审计报告页 | 汇总统计 | 卡片式数字展示，正常统计和异常统计分栏 |
| 审计报告页 | 时间线 | 左侧竖线+圆点，每条操作含时间戳和操作人 |

### 4.3 响应式设计

- 桌面优先，最小宽度 1200px
- 侧边栏可折叠，主区域自适应
- 星图画布占满可用空间

### 4.4 数据持久化

- 所有状态（实体数据、异常标注、视角、增补记录、操作时间线）使用 localStorage 持久化
- 每次操作自动保存，刷新后完整恢复
- 导出为 JSON 文件可作为方案备份
