# 供应商票据池预警系统

风控复核员专用的票据复核工作台

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务
npm run dev
```

## 操作流程

### 林姐日常操作步骤

1. **导入材料包**
   - 点击"导入数据"按钮
   - 粘贴JSON格式数据
   - 系统自动分析：跳过/更新/冲突
   - 查看差异报告后确认导入

2. **浏览预警列表**
   - 搜索供应商名称或备注
   - 按状态筛选待处理记录

3. **详情审核**
   - 点击"查看详情"进入审核页
   - 查看原始备注（不可修改）
   - 查看相关材料分类展示
   - 阅读处理建议

4. **补充备注**
   - 点击"补充备注"添加说明
   - 原始备注始终保留不被覆盖
   - 修改前后差异自动记录

5. **改判状态**
   - 点击"改判状态"选择新状态
   - 填写改判说明
   - 操作历史全程留痕

6. **回退操作**
   - 在操作历史中找到改判记录
   - 点击"回退到此版本"恢复

7. **导出结果**
   - 导出CSV：Excel友好格式
   - 导出JSON：完整结构化数据

## 差异报告去哪看

- **导入时**：粘贴数据后点"分析数据"，系统展示差异对比
- **详情页**：操作历史中显示每次修改的前后对比
- **导出文件**：包含完整的历史记录和备注信息

## 脏数据处理

- 合同扫描件中的手写备注会标注"脏数据"但**不清洗**
- 格式异常材料会显示黄色警告提示
- 所有原始信息完整保留，供人工复核
