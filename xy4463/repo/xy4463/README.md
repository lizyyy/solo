# 野鸟救助站放飞前复核系统

一个用于野鸟救助站放飞前复核的本地全栈工具，帮助工作人员评估野鸟是否适合放飞。

## 功能特点

- **数据导入**：支持导入救助鸟档案、兽医用药记录、体重记录、飞行笼观察表、环志编号和放飞点天气数据
- **智能评估**：自动根据各项数据判断野鸟是否适合放飞
- **状态分类**：将野鸟分为"可放飞"、"需延后"、"需补检"和"待评估"四类
- **风险分析**：详细列出每只鸟的风险原因
- **人工改判**：支持人工修改评估状态并添加备注
- **数据持久化**：所有数据保存到本地，刷新页面不丢失
- **导出功能**：支持导出Markdown格式的放飞清单和JSON格式的审计包
- **示例数据**：内置示例数据，方便快速了解系统功能

## 系统要求

- Node.js 14.0 或更高版本
- npm 或 yarn 包管理器

## 安装步骤

1. 安装依赖：

```bash
npm install
```

2. 启动服务器：

```bash
npm start
```

3. 在浏览器中访问：

```
http://localhost:3000
```

## 使用说明

### 1. 数据导入

系统支持以下数据类型的导入：

- **救助鸟档案**：包含鸟的基本信息，如物种、救助日期、年龄、性别等
- **兽医用药记录**：记录兽医诊断和用药情况
- **体重记录**：跟踪鸟的体重变化
- **飞行笼观察表**：记录鸟在飞行笼中的行为表现
- **环志编号**：记录鸟的环志信息
- **放飞点天气**：记录放飞点的天气情况

**导入格式**：
系统支持JSON和NDJSON（换行分隔JSON）格式的数据文件。

示例JSON格式：
```json
[
  {
    "id": "B001",
    "species": "麻雀",
    "rescueDate": "2026-04-15",
    "rescueLocation": "城市公园",
    "condition": "轻微受伤",
    "age": "成鸟",
    "gender": "未知",
    "ringNumber": "R20260415001"
  }
]
```

### 2. 快速开始

点击页面顶部的"加载示例数据"按钮，系统会自动加载预设的示例数据，包括：
- 4只不同状态的野鸟
- 完整的兽医记录
- 体重变化记录
- 飞行笼观察记录
- 环志编号信息
- 放飞点天气数据

### 3. 运行评估

点击"运行放飞评估"按钮，系统会根据以下规则自动评估每只鸟：

**评估规则**：
1. **兽医记录检查**：
   - 无兽医记录 → 需补检
   - 仍在用药中 → 需延后

2. **体重检查**：
   - 体重记录不足2条 → 需补检
   - 体重下降超过5% → 需延后

3. **飞行能力检查**：
   - 无飞行笼观察记录 → 需补检
   - 飞行能力受限或差 → 需延后
   - 进食需要辅助 → 需延后

4. **年龄检查**：
   - 幼鸟 → 需延后

5. **救助时间检查**：
   - 救助时间不足7天 → 需延后

### 4. 查看详情和改判

点击任意鸟的卡片，可以查看：
- 基本信息
- 评估状态和风险原因
- 兽医记录
- 体重记录
- 飞行笼观察记录

在详情页面底部，可以进行人工改判：
1. 选择新的状态（可放飞、需延后、需补检）
2. 输入改判备注
3. 点击"保存改判"按钮

### 5. 导出数据

系统支持两种导出格式：

**Markdown放飞清单**：
- 包含统计信息
- 按状态分类列出所有鸟类
- 包含每只鸟的基本信息和风险原因
- 适合打印或分享

**JSON审计包**：
- 包含所有导入的数据
- 包含评估结果
- 包含人工改判记录
- 适合数据备份或进一步分析

## 数据存储

所有数据存储在项目目录的 `data` 文件夹中：

- `birds.json` - 救助鸟档案
- `vetRecords.json` - 兽医用药记录
- `weightRecords.json` - 体重记录
- `flightCageObservations.json` - 飞行笼观察表
- `ringNumbers.json` - 环志编号
- `weather.json` - 放飞点天气
- `assessments.json` - 评估结果
- `manualDecisions.json` - 人工改判记录

## API接口

### 数据接口

- `GET /api/data/:type` - 获取指定类型的数据
- `POST /api/data/:type` - 保存指定类型的数据

### 文件上传

- `POST /api/upload` - 上传数据文件

### 导出接口

- `GET /api/export/markdown` - 导出Markdown格式的放飞清单
- `GET /api/export/json` - 导出JSON格式的审计包

## 注意事项

1. 首次使用时，建议先加载示例数据了解系统功能
2. 导入数据时，请确保数据格式正确（JSON或NDJSON）
3. 人工改判会覆盖系统自动评估结果
4. 所有数据保存在本地，请定期备份 `data` 文件夹
5. 系统使用端口3000，如果端口被占用，请修改 `server.js` 中的端口配置

## 技术栈

- **后端**：Node.js + Express
- **前端**：原生HTML + CSS + JavaScript
- **数据存储**：本地JSON文件
- **文件上传**：Multer
