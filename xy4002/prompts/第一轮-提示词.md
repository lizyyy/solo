我想做一个本地运行的社区活动物资借还登记小系统，给居委会/志愿者用，不要做成纯静态页面。请从零搭一个可运行的全栈 Web 应用：前端要能登记物资、搜索库存、给居民办理借出/归还，并显示“在库、借出、逾期、已报废”这些状态；后端要有接口和 SQLite 持久化，所有状态变化都要写入操作流水，刷新页面后数据不能丢。

有几个真实场景麻烦一起处理：同一件物资不能重复借出；借出时要填居民姓名、联系方式、预计归还日期；超过预计归还日期后列表里自动标成逾期；归还时要记录实际归还时间和备注；报废的物资不能再被借出。希望能导入一份 CSV 初始化物资，也能导出当前库存和流水。页面不用很花，但要把常用流程做顺，最好 README 里写清楚怎么启动、怎么初始化数据库、接口大概有哪些。
