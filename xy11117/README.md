# 校车运营队校车站点稽核 CLI 工具

## 项目简介

本工具用于校车运营队对校车站点数据进行自动化稽核，自动识别定位漂移、临时站点和需要重新处理的数据，确保后续复核工作的准确性。

## 命令说明

### `audit` - 执行站点稽核

**功能：** 对输入的站点数据文件进行稽核，分类输出结果。

**参数：**

| 参数 | 缩写 | 必填 | 说明 |
|------|------|------|------|
| `--input` | `-i` | 是 | 输入文件或目录路径（支持 CSV、Excel） |
| `--output` | `-o` | 是 | 输出目录路径 |
| `--dry-run` | `-n` | 否 | 试运行模式，不写入文件，仅显示统计结果 |
| `--overwrite` | `-f` | 否 | 覆盖已存在的输出文件 |
| `--format` | `-t` | 否 | 输出文件格式：csv/excel/json（默认：excel） |

**使用示例：**

```bash
# 1. 基本使用 - 处理单个文件
school-bus-audit audit -i sample_data/2024年第一季度校车站点数据.csv -o output/

# 2. 处理整个目录
school-bus-audit audit -i sample_data/ -o output/ -f

# 3. 试运行（不生成文件，只看统计）
school-bus-audit audit -i sample_data/ -o output/ -n

# 4. 指定输出格式为 CSV
school-bus-audit audit -i sample_data/ -o output/ -t csv -f
```

### `version` - 查看版本

```bash
school-bus-audit version
```

## 稽核规则说明

工具会按以下优先级对每条站点数据进行分类：

### 1. 定位漂移（最高优先级）

满足以下任一条件即判定为定位漂移：
- 纬度不在 [30.0, 32.0] 范围内
- 经度不在 [120.0, 122.0] 范围内
- 距离参考点（上海市中心）超过 2 公里

### 2. 临时站点

满足以下任一条件即判定为临时站点：
- 站点类型包含"临时"字样
- 站点名称包含"临时"、"应急"、"备用"字样
- 运营状态为"暂停"、"测试"
- 生效日期与失效日期相同（单日站点）

### 3. 可复跑输出

满足以下任一条件即判定为需要重新处理：
- 缺少必填字段：站点ID、站点名称、纬度、经度、运营时间
- 经纬度为 0
- 经纬度格式错误
- 运营时间为"待定"

### 4. 正常站点

不满足以上任何条件的站点数据。

## 输出文件说明

稽核完成后，在输出目录会生成以下文件：

| 文件名 | 说明 |
|--------|------|
| `正常站点.xlsx` | 稽核通过的正常站点数据 |
| `定位漂移.xlsx` | 定位超出范围的站点数据 |
| `临时站点.xlsx` | 临时或应急站点数据 |
| `可复跑输出.xlsx` | 需要重新采集或修正的数据 |
| `稽核汇总报告.json` | 本次稽核的详细汇总报告 |

**重要：** 四类数据严格分离，不会混在同一个文件中，方便后续复核。

## 错误处理

### 文件损坏或格式错误

- 如果某个文件损坏无法读取，工具会**继续处理其他文件**，不会中断整个稽核流程
- 损坏文件的名称和错误原因会记录在最终汇总中
- 可以在 `稽核汇总报告.json` 的"未处理文件"和"失败详情"字段查看具体信息

### 输出文件已存在

- 默认情况下，如果输出文件已存在，工具会跳过该文件并显示警告
- 使用 `--overwrite` 或 `-f` 参数可以强制覆盖已存在的文件

## 完整操作流程示例

### 步骤1：准备数据

将需要稽核的 CSV 或 Excel 文件放入一个目录，例如：

```
/srv/bus_data/
├── 2024年1月站点.csv
├── 2024年2月站点.xlsx
└── 2024年3月站点.csv
```

### 步骤2：试运行确认

先进行试运行，查看统计结果是否符合预期：

```bash
school-bus-audit audit -i /srv/bus_data/ -o /srv/audit_output/ -n
```

观察控制台输出，确认：
- 文件数量是否正确
- 各类站点数量是否合理
- 有无文件处理失败

### 步骤3：正式执行稽核

确认无误后，正式执行：

```bash
school-bus-audit audit -i /srv/bus_data/ -o /srv/audit_output/ -f
```

### 步骤4：查看结果

检查输出目录：

```bash
ls -la /srv/audit_output/
```

查看汇总报告：

```bash
cat /srv/audit_output/稽核汇总报告.json
```

## 常见问题

### Q1: 提示"未找到任何支持的输入文件"

**A:** 请检查：
- 输入路径是否正确
- 文件扩展名是否为 .csv、.xlsx 或 .xls
- 文件是否有读取权限

### Q2: 某个文件处理失败了怎么办

**A:** 
1. 查看控制台输出的错误信息
2. 查看 `稽核汇总报告.json` 中的"失败详情"
3. 修复该文件后重新运行，工具会处理所有文件

### Q3: 如何只处理新增的文件

**A:** 
- 将新增文件放入单独的目录
- 或者不使用 `-f` 参数，已存在的输出文件会自动跳过

### Q4: 输出文件可以用 Excel 打开吗

**A:** 可以。默认输出格式就是 Excel（.xlsx），所有字段都保留原始格式。

### Q5: 如何自定义稽核规则

**A:** 修改 `school_bus_audit/audit_logic.py` 中的相关代码：
- 定位漂移范围：修改 `STANDARD_LATITUDE_RANGE`、`STANDARD_LONGITUDE_RANGE`
- 距离阈值：修改 `POSITION_DRIFT_THRESHOLD_KM`
- 参考点坐标：修改 `REFERENCE_POINT`
- 临时站点关键词：修改 `is_temporary_site` 方法中的判断逻辑
