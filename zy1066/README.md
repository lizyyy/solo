# 🧗 攀岩馆线路摆点预演器

一个本地运行的攀岩馆线路摆点和难度热区预演器，专为小攀岩馆或社团定线设计。

## 🎯 功能特性

### 核心功能
- **墙面编辑**: 创建和编辑抱石墙的宽度、高度、倾角和分区
- **岩点库**: 5种岩点类型（大岩点、小抠点、孔洞点、条型点、大斜面），支持3种尺寸
- **线路规划**: 创建多条线路，标记起点、终点和中间岩点
- **拖拽摆放**: 从岩点库拖拽岩点到墙面，自由调整位置
- **岩点编辑**: 修改岩点颜色、类型、尺寸，设置起点/终点标记

### 风险评估
- **距离检查**: 根据用户身高和臂展检测岩点间距是否合理
- **高度风险**: 评估高处落点风险
- **横向跨度**: 检测横向移动跨度是否过大
- **区域风险**: 基于墙面分区评估风险等级
- **难度匹配**: 检查线路难度与岩点类型是否匹配
- **密度检查**: 检测岩点是否过密，可能造成线路干扰
- **热区显示**: 在墙面上可视化显示风险热区

### 视图与导出
- **2D/3D 切换**: 2D 视图方便编辑，3D 视图可预览墙面倾角和岩点位置
- **本地存储**: 自动保存到浏览器 localStorage
- **JSON 导入导出**: 保存和加载完整项目数据
- **报告生成**: 导出 Markdown 或 HTML 格式的定线报告，包含：
  - 每条线路的难度估计
  - 风险点详情
  - 岩点清单
  - 调整建议

## 📖 使用指南

### 验证主要流程

#### 1. 查看示例数据
项目默认包含示例墙面和3条示例线路：
- **新手入门线** (绿色) - 初级难度，使用大岩点为主
- **进阶平衡线** (蓝色) - 中级难度，混合岩点类型
- **动态挑战线** (红色) - 高级难度，距离跨度较大

首次打开应用即可看到这些数据，已保存到本地存储。

#### 2. 创建新线路

1. 点击左侧面板的 **"+ 新建线路"** 按钮
2. 点击左侧列表中的新线路（会显示橙色高亮）
3. 从左侧岩点库拖拽岩点到墙面

#### 3. 编辑岩点

1. 点击墙面上的任意岩点
2. 在弹出的编辑器中可以：
   - 更改颜色
   - 调整尺寸（小/中/大）
   - 更改类型
   - 设置为起点或终点
   - 删除岩点

也可以直接**拖拽墙面上的岩点**来移动位置。

#### 4. 查看风险评估

1. 选择一条线路
2. 查看右侧 **风险评估** 面板：
   - 显示当前线路的风险等级和分数
   - 列出详细的风险点（距离太远、太高、跨度太大等）
   - 热区会在2D视图中叠加显示（红色半透明区域）

#### 5. 切换 2D/3D 视图

1. 点击画布右上角的 **"2D 编辑"** 或 **"3D 预览"** 按钮
2. 在 3D 视图中：
   - **鼠标左键拖动**: 旋转视角
   - **滚轮**: 缩放
   - **鼠标右键拖动**: 平移

#### 6. 编辑墙面配置

1. 点击顶部导航栏的 **"编辑墙面"** 按钮
2. 可以修改：
   - 墙面名称
   - 宽度和高度（单位：cm）
   - 倾角（角度：正值为仰角，负值为俯角）
   - 添加/删除风险分区

#### 7. 导出功能

1. 点击右上角 **"导出"** 按钮
2. 选择导出格式：
   - **JSON**: 完整项目数据，可后续导入
   - **Markdown**: 结构化报告，适合文档保存
   - **HTML**: 美观的网页格式报告

#### 8. 调整用户设置

点击右上角 **"⚙️ 设置"** 按钮，可以调整：
- 身高（影响风险评估中的距离计算）
- 臂展（影响风险评估中的距离计算）
- 技术等级

## 🧪 测试场景

### 场景 1: 创建一条"太远"的线路
1. 创建一条新线路
2. 放置2个岩点，相距超过 140cm（假设臂展 175cm）
3. 查看风险面板，应该显示 **"距离太远"** 的警告

### 场景 2: 创建一条"太高"的线路
1. 创建一条新线路
2. 在顶部区域放置岩点（y < 60，假设墙高 300cm）
3. 查看风险面板，应该显示 **"位置过高"** 的警告

### 场景 3: 验证 3D 视图
1. 点击 **"3D 预览"**
2. 拖动鼠标旋转视角，应该能看到墙面的倾角
3. 观察岩点的 3D 形状和位置

## 📝 说明

### 风险评估规则

风险评估基于以下简化规则（非专业攀岩定线规则，仅供参考）：

1. **距离风险**: 
   - 安全: < 80% 臂展
   - 警告: 80% - 96% 臂展
   - 危险: > 96% 臂展

2. **高度风险**:
   - 安全: < 1.5 倍身高
   - 警告: 1.5 - 1.8 倍身高
   - 危险: > 1.8 倍身高

3. **横向跨度**:
   - 安全: < 60% 臂展
   - 警告: 60% - 80% 臂展
   - 危险: > 80% 臂展

4. **岩点类型难度**:
   - 大岩点 (Jug): 最容易 (1/5)
   - 大斜面 (Sloper): 中等难度 (2/5)
   - 条型点 (Edge): 较难 (3/5)
   - 孔洞点 (Pocket): 很难 (4/5)
   - 小抠点 (Crimp): 最难 (5/5)

### 数据存储

所有数据自动保存到浏览器的 `localStorage`，键名为 `climbing-route-planner-data`。数据结构包括：

- `walls`: 墙面配置列表
- `routes`: 线路列表
- `activeWallId`: 当前选中的墙面
- `activeRouteId`: 当前选中的线路
- `userProfile`: 用户设置（身高、臂展、技术等级）
- `viewMode`: 当前视图模式（2D/3D）
