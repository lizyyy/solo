# 渔具归还押金扣减积分补偿排查CLI

用于钓场渔具租借后的押金扣减、积分补偿计算和异常排查的命令行工具。

## 功能特性

- ✅ **数据解析**: 支持CSV格式的会员、租借单、渔具清单、归还检查、押金记录解析
- ✅ **规则验证**: 清单核验、归还复核、押金状态一致性、物品丢失检测
- ✅ **来源追踪**: 坏行保留原文件位置，问题可追溯到具体行号
- ✅ **押金扣减**: 按鱼钩、鱼线、鱼护分类计算扣减金额
- ✅ **积分补偿**: 支持会员等级倍率的积分补偿计算
- ✅ **报告生成**: 生成多格式排查报告
- ✅ **结果稳定**: 排序处理确保重复运行结果一致

## 使用方法

### 基本用法

```bash
python3 main.py \
  --members data/members.csv \
  --rentals data/rentals.csv \
  --equipment data/equipment.csv \
  --returns data/returns.csv \
  --deposits data/deposits.csv
```

### 参数说明

| 参数 | 简写 | 必填 | 说明 |
|------|------|------|------|
| `--members` | `-m` | ✅ | 会员数据CSV文件路径 |
| `--rentals` | `-r` | ✅ | 租借单数据CSV文件路径 |
| `--equipment` | `-e` | ✅ | 渔具清单CSV文件路径 |
| `--returns` | `-rt` | ✅ | 归还检查记录CSV文件路径 |
| `--deposits` | `-d` | ✅ | 押金记录CSV文件路径 |
| `--output-dir` | `-o` | ❌ | 报告输出目录 (默认: reports) |
| `--quiet` | `-q` | ❌ | 静默模式，不输出控制台摘要 |

## 验证规则

### 1. 渔具清单匹配验证
- 检查租借单中的渔具是否全部在归还清单中
- 检查归还清单中是否有租借单以外的渔具

### 2. 归还完整性验证
- 检查渔具配套的鱼钩、鱼线、鱼护是否全部归还
- 对比渔具配置和归还状态

### 3. 押金状态一致性验证
- 检查租借单押金金额与押金记录原始押金是否一致
- 检查租借单是否有对应押金记录

### 4. 扣减金额一致性验证
- 根据归还检查计算应扣金额
- 对比实际扣减金额是否正确

## 积分补偿计算

- 基础积分倍率: 每扣1元补偿10积分
- 会员等级倍率:
  - 普通会员: 1.0倍
  - 银卡会员: 1.2倍
  - 金卡会员: 1.5倍
  - 钻石会员: 2.0倍

计算公式:
```
补偿积分 = 扣减金额 × 10 × 等级倍率
```

## 输出报告

工具会在输出目录生成以下报告：

1. **issues_report_[timestamp].csv** - 验证问题详情
2. **calculations_report_[timestamp].csv** - 押金扣减和积分计算详情
3. **summary_report_[timestamp].json** - 汇总统计数据
4. **invalid_rows_report_[timestamp].csv** - 坏行记录（如有）
5. **full_report_[timestamp].txt** - 完整排查报告

## 注意事项

1. 所有CSV文件需使用UTF-8编码（支持带BOM）
2. 布尔字段支持: 是/否、true/false、1/0、yes/no
3. 金额字段支持千分位格式（会自动去除逗号）
4. 多次运行同一批数据时，结果排序保持一致
