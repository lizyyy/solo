## 原始点子

我想做一个给海工检测队用的本地科学计算命令行工具，叫“ROV 放缆张力校核器”。我们用 ROV 检查海底管线时，甲板上会记录母船航迹、ROV 深度、推进器负载、海流剖面和脐带缆放出长度，现在靠 Excel 粗算很难判断哪一段缆线可能过张、弯曲半径不够或者和管线保护架擦碰。请从 0 到 1 做一个可运行的 Python CLI 项目：init 命令能创建项目配置，维护缆线规格、允许张力、最小弯曲半径、ROV 重量/浮力、海流层、采样时间步长和输出目录；import 命令能导入航迹 CSV、ROV 遥测 CSV、海流剖面 CSV，字段包括时间戳、经纬度或局部坐标、深度、放缆长度、艏向、推进器负载和海流速度方向，导入时要校验单位、时间倒序、重复时间戳、坐标缺失、深度为正负号混乱这些问题，坏行进入 quarantine.json 并说明原因。analyze 命令要按时间线对齐多源数据，估算每个采样点的水平偏移、缆线悬链近似形态、顶端张力、ROV 端张力、最小弯曲半径和安全裕度，识别张力超限、放缆不足、缆线角度突变、海流突变导致的风险、ROV 靠近管线保护架的擦碰风险。scenario 命令允许用户修改海流或放缆长度做一次假设推演，但不能覆盖原始记录；report 命令导出 Markdown 作业复盘、CSV 风险点清单和 JSON 计算审计包；history 命令能按作业日期或管线编号查询历史分析。请把 CLI 入口、配置模型、CSV 解析与单位换算、数据校验、时间线对齐、张力/悬链近似计算、风险规则、场景推演、存储层、报告导出、示例数据和测试拆成多个文件，不要写成一个大脚本。README 里写清楚安装方式、示例命令，以及如何用临时目录验证 init、导入三类数据、校验坏行、运行分析、做场景推演、导出报告和查询历史这些核心流程。
