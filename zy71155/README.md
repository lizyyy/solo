# 仓库装箱排序游戏

面向电商仓临时工培训的轻量级策略模拟游戏。通过2D拖拽装箱的形式，让玩家理解重物、易碎和时效件的装箱规则。

## 启动说明

### 环境要求
- Node.js >= 16.0.0
- npm >= 8.0.0

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

启动后访问 `http://localhost:5173` 进入游戏。

### 构建生产版本

```bash
npm run build
```

构建产物将输出到 `dist` 目录。

### 预览生产版本

```bash
npm run preview
```

## 游戏玩法

### 核心目标

在限定时间内，将所有商品正确装入箱子，遵守装箱规则，获得更高评分。

### 商品属性

每个商品都有以下属性，会影响装箱策略：

- **重量等级**：
  - 🟢 轻（0-5kg）
  - 🟡 中（5-15kg）
  - 🟠 重（15-30kg）
  - 🔴 超重（>30kg）

- **易碎等级**：
  - ✅ 不易碎
  - ⚠️ 易碎
  - 💔 极易碎

- **时效等级**：
  - ⚪ 普通
  - 🟢 当日达
  - 🟡 次日达
  - 🔴 隔日达

### 装箱规则

1. **重物不压易碎**：重/超重物品不能放在易碎物品上方
2. **易碎不压易碎**：易碎物品不能放在其他易碎物品上方
3. **时效优先**：时效等级高的商品优先放在上层（更易取出）
4. **不超重**：箱内总重量不能超过箱型最大承重
5. **空间利用**：尽量减少空间浪费，提高空间利用率

### 操作方式

- **选择商品**：点击右侧待装商品列表中的商品进行选中
- **放置商品**：选中商品后，拖拽到箱子内部的合适位置
- **网格吸附**：放置时自动吸附到网格，便于整齐排列
- **调整层级**：拖拽过程中滚动鼠标滚轮调整商品层级（z-index）
- **旋转商品**：拖拽过程中按 `R` 键旋转商品（宽高互换）
- **移除商品**：右键点击箱内商品可将其移出箱子
- **撤销/重做**：使用底部按钮或快捷键 `Ctrl+Z` / `Ctrl+Shift+Z`
- **暂停游戏**：点击顶部暂停按钮或按 `空格键`
- **重新开始**：点击顶部重新开始按钮或按 `R键`
- **提交装箱**：所有商品装箱完成后点击"提交装箱"按钮结算

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl + Z | 撤销上一步操作 |
| `Ctrl + Shift + Z` / `Ctrl + Y` | 重做 |
| `空格键` | 暂停/继续游戏 |
| `R`（拖拽中 | 旋转商品 |
| `鼠标滚轮`（拖拽中） | 调整商品层级 |
| `右键点击`（箱内商品） | 移除商品 |

## 关卡说明

游戏共有6个关卡，难度逐级递增：

### 关卡1：新手上路
- **难度**：⭐
- **描述**：基础规则练习，5件轻量商品
- **时间限制**：3分钟
- **特殊规则**：无
- **目标**：熟悉基础拖拽操作和重物不压易碎规则

### 关卡2：易碎品试炼
- **难度**：⭐⭐
- **描述**：包含3件易碎商品，注意易碎品摆放
- **时间限制**：3分钟
- **特殊规则**：易碎品必须放在最上层
- **目标**：掌握易碎品摆放规则

### 关卡3：时效件挑战
- **难度**：⭐⭐⭐
- **描述**：8件商品包含时效件，需要按优先级摆放
- **时间限制**：4分钟
- **特殊规则**：时效件必须放在上层，先装时效件再装普通件
- **目标**：理解时效件优先级概念

### 关卡4：重型货物
- **难度**：⭐⭐⭐
- **描述**：10件商品含重物，注意重量分布
- **时间限制**：4分钟
- **特殊规则**：重物必须放在底层
- **目标**：学习重物摆放原则

### 关卡5：空间大师
- **难度**：⭐⭐⭐⭐
- **描述**：12件商品，空间利用率要求80%以上
- **时间限制**：5分钟
- **特殊规则**：空间利用率低于70%扣分
- **目标**：提高空间利用率意识

### 关卡6：综合考验
- **难度**：⭐⭐⭐⭐⭐
- **描述**：15件商品混合场景，全面考核
- **时间限制**：6分钟
- **特殊规则**：综合所有规则
- **目标**：综合运用所有规则

## 评分系统

### 评分构成

| 项目 | 分数 | 说明 |
|------|------|------|
| 基础分 | 1000 | 完成基础目标获得 |
| 空间利用率 | 0-500 | 空间利用率×500 |
| 时间奖励 | 0-300 | 剩余时间×2 |
| 违规扣分 | - | 每次违规扣50-200分 |

### 违规类型及扣分

| 违规类型 | 扣分 | 是否致命 |
|----------|------|---------|
| 重物压易碎 | 150 | 是 |
| 易碎压易碎 | 100 | 否 |
| 时效件未优先 | 80 | 否 |
| 超重 | 200 | 是 |
| 空间利用率低 | 100 | 否 |
| 超时 | - | 是 |

### 等级评定

| 得分 | 等级 | 星级 |
|------|------|------|
| >= 1600 | S | ⭐⭐⭐⭐⭐ |
| 1400-1599 | A | ⭐⭐⭐⭐ |
| 1200-1399 | B | ⭐⭐⭐ |
| 1000-1199 | C | ⭐⭐ |
| < 1000 或 致命违规 | F | ❌ |

## 失败原因回看

游戏结算时会显示具体的失败原因，包括：

1. **致命违规（直接失败）：
   - 重物压易碎品
   - 箱子超重
   - 游戏超时

2. **非致命违规（扣分但可通过）：
   - 易碎品压易碎品
   - 时效件未优先
   - 空间利用率过低

在结算面板和历史记录中都可以查看详细的违规列表和失败原因。

## 历史记录和报告导出

### 历史记录
- 完成的每一局游戏都会自动保存到本地
- 可以在"历史记录"页面查看所有对局
- 每条记录包含：关卡名称、完成时间、用时、得分、等级、违规记录

### 报告导出
支持两种格式导出培训报告：

1. **JSON格式**：完整的结构化数据，便于后续分析
2. **文本格式**：可读性强的文本报告，便于打印存档

报告内容包括：
- 基本信息（关卡、时间、得分、等级
- 装箱明细（每个商品的位置和属性
- 违规记录（详细的违规类型和扣分
- 评分明细（各项得分和扣分）
- 改进建议（针对本局表现的优化建议）

## 边界案例

### 案例1：重物压易碎（致命错误）
- 场景：将15kg大米（重物）放在玻璃杯（易碎）上方
- 结果：直接判定失败，需重新摆放
- 正确做法：重物放在底层，易碎品放在上层，或者分箱

### 案例2：时效件放在底层（非致命错误）
- 场景：当日达包裹放在普通商品下方
- 结果：扣80分，但可通过
- 正确做法：时效等级高的商品放在上层，便于优先取出

### 案例3：空间利用率极低
- 场景：12件商品关卡，空间利用率仅60%
- 结果：扣100分，影响最终评级
- 正确做法：合理规划摆放位置，尽量紧凑排列

### 案例4：箱子超重
- 场景：小箱子（最大承重30kg，装入总重量35kg
- 结果：直接判定失败
- 正确做法：分箱或更换更大箱型

### 案例5：易碎品压易碎品
- 场景：鸡蛋放在玻璃杯上方
- 结果：扣100分
- 正确做法：易碎品之间留出空隙或分箱

### 案例6：游戏超时
- 场景：5分钟关卡，6分钟才完成
- 结果：直接判定失败
- 正确做法：提前规划，提高操作效率

## 技术栈

- **框架**：React 18 + TypeScript
- **构建工具**：Vite
- **状态管理**：Zustand
- **样式方案**：TailwindCSS 3
- **路由**：React Router DOM 6
- **图标**：lucide-react
- **渲染**：原生 Canvas 2D API
- **数据持久化**：localStorage
