# 农田灌溉轮灌可视化系统

## 安装运行

1. 安装依赖：
```bash
npm install
```

2. 启动服务：
```bash
npm start
```

3. 浏览器访问：
```
http://localhost:3000
```

## 样例入口

- 系统启动后自动生成样例数据
- 默认配置：8个地块、3条渠系、200m³可用水量

## 核心操作

1. **生成样例数据**：设置地块数量、渠系数量、总可用水量后点击"生成样例数据"
2. **运行轮灌算法**：点击"运行轮灌算法"执行灌溉分配
3. **查看详情**：点击地图上的地块查看详细信息
4. **查看轮灌计划**：点击"查看轮灌计划"查看完整灌溉顺序
5. **导出结果**：点击"导出结果"保存为JSON文件
6. **一致性检查**：先导出一次结果，再次运行算法后点击"检查一致性"验证结果一致性

## 检查结果

- 统计指标区显示：总需水量、可用水量、缺水量、灌溉效率等
- 渠系状态区显示各渠系利用率和流量情况
- 地图中地块颜色表示状态，数字表示轮灌顺序
- 一致性检查结果显示重跑同一批数据时结果是否一致
