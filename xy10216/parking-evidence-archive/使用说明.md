# 停车场逃费证据归档台 - 使用说明

## 项目概述

这是一个用于处理停车场逃费车辆证据管理的应用系统，覆盖车牌事件、证据附件、人工放行审核、补缴状态、案件时间线和导出包等功能。

## 快速开始

### 1. 启动项目

```bash
cd parking-evidence-archive
npm install
npm run dev
```

### 2. 访问应用

在浏览器中打开显示的本地地址（通常是 http://localhost:5173）

## 功能说明

### 主界面布局

- **左侧面板**：案件列表，显示所有案件的概览信息和统计数据
- **右侧面板**：案件详情，显示选中案件的完整信息

## 操作流程指南

### 流程一：顺利流程操作（样例一）

1. **查看案件**
   - 在左侧列表中选择「沪A·12345」案件
   - 右侧显示案件详情，状态为「待补缴」

2. **记录补缴**
   - 点击「补缴记录」区域的「+ 记录补缴」按钮
   - 输入补缴金额（45元）
   - 选择支付方式（如微信支付）
   - 点击「确认」完成
   - 状态自动变为「补缴完成」
   - 时间线自动更新

3. **导出案件**
   - 状态变为「补缴完成」后，底部出现导出区域
   - 输入操作员姓名
   - 点击「📦 导出案件包」按钮
   - ✅ 系统自动生成并下载完整的导出包（包含5个文件）
   - ✅ 状态变为「已导出」
   - ✅ 时间线记录导出操作

**导出包内容说明：**
- `case-summary.txt` - 案件摘要报告（基本信息、费用、证据情况）
- `evidence-index.txt` - 证据文件索引（列出所有证据及其状态）
- `timeline.txt` - 案件时间线（按时间顺序记录所有关键事件）
- `case-data.json` - 完整结构化数据（可用于程序导入和分析）
- `README.txt` - 归档包使用说明

### 流程二：待复核流程操作（样例二）

1. **查看案件**
   - 在左侧列表中选择「苏E·67890」案件
   - 右侧显示案件详情，状态为「待复核」
   - 注意：证据附件中有「出场记录」显示为「待补录」占位符

2. **补全证据链**
   - 点击「证据附件」区域的「+ 添加证据」按钮
   - 选择证据类型：「出场记录」
   - 输入文件名称：「出场记录_20240510_021500.pdf」
   - 可选：填写描述说明
   - 点击「添加」完成
   - 新证据添加到列表，时间线更新

3. **复核人工放行**
   - 在「人工放行记录」区域点击「复核放行记录」按钮
   - 选择复核结果：通过/拒绝
   - 输入复核人姓名
   - 输入复核意见（如：经核实，系统确实存在识别故障）
   - 点击「确认」完成
   - 放行记录状态变为「已复核」
   - 如果所有条件满足，案件状态自动变为「待补缴」

4. **后续流程**
   - 参考流程一，完成补缴和导出

### 其他操作

#### 新增案件

1. 点击左侧面板顶部的「+ 新增案件」按钮
2. 填写案件信息：
   - **车牌号码**（必填）
   - **入场时间**（必填）
   - **出场时间**（必填）
   - 停车时长（可自动计算或手动填写）
   - 应付/已付金额
   - 备注说明
3. 点击「创建案件」完成
4. 新案件出现在左侧列表

#### 编辑案件

1. 选择需要编辑的案件
2. 点击案件详情区域的「编辑案件」按钮
3. 修改需要更新的字段
4. 点击「保存修改」完成

#### 案件状态说明

| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| 待复核 | 案件需要审核确认 | 通过复核/拒绝案件/复核人工放行 |
| 已通过 | 审核通过，等待补缴 | 记录补缴/导出 |
| 已拒绝 | 审核不通过 | 查看详情 |
| 待补缴 | 等待车主缴费 | 记录补缴 |
| 补缴完成 | 已收到全部欠款 | 导出案件 |
| 已导出 | 已完成归档 | 查看详情 |

## 核心差异点说明

### 逃费证据链

1. **证据类型分类**：入场图片、出场记录、人工放行、补缴凭证、其他
2. **占位符机制**：缺失的证据显示为「待补录」橙色占位符，提醒操作员补全
3. **完整性检查**：只有证据链完整时，案件才能正常流转

### 人工放行复核

1. **自动拦截**：夜间（00:00-06:00）人工放行的案件会自动进入「待复核」状态
2. **多级审核**：放行记录需要单独复核，输入复核人和意见
3. **状态联动**：
   - 放行记录未复核 → 案件保持「待复核」
   - 证据有缺失 → 案件保持「待复核」
   - 全部条件满足 → 案件自动转为「待补缴」

### 数据流转

1. **状态管理**：使用 React Context 实现全局状态共享
2. **实时更新**：所有操作（添加证据、记录补缴、复核放行）都会立即更新 UI 和时间线
3. **时间线追踪**：每个关键操作都会在时间线中留下记录，便于追溯

### 注意事项

- 应用数据存储在内存中，刷新页面会重置
- ✅ **导出功能已实现**：点击导出按钮会自动生成并下载完整的导出包（5个文件）
- 样例数据中的图片、PDF 等文件为占位描述，实际项目需要接入文件上传系统
- 导出包中的 `evidences/` 目录在实际部署中包含真实证据文件
