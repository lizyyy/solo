# 社工走访风险分级物资核销排查CLI

一个功能完善的社区社工走访管理工具，支持风险分级、回访排程、物资核销、重复走访合并和报告导出。

## 功能特性

### 核心功能
1. **数据解析** - 支持Excel和CSV格式文件，坏行追踪和位置保留
2. **风险分级** - 基于年龄、居住情况、健康状况、子女情况、经济状况进行自动分级
3. **回访排程** - 根据风险等级自动安排回访计划，识别逾期回访
4. **物资核销** - 检查物资发放记录的完整性和合规性
5. **重复走访合并** - 自动识别并合并同一天同一社工对同一居民的重复走访
6. **报告导出** - 生成Excel格式完整报告，包含所有分析结果

### 数据追踪
- 每条数据保留来源文件和行号
- 支持坏行记录导出
- 稳定的排序算法，重复运行结果一致

## 使用说明

### 基本使用

```bash
# 处理单个文件
python cli.py process \
  -r sample_data/居民数据.csv \
  -v sample_data/走访记录.csv \
  -m sample_data/物资发放.csv

# 指定输出目录
python cli.py process \
  -r sample_data/居民数据.csv \
  -v sample_data/走访记录.csv \
  -m sample_data/物资发放.csv \
  -d ./output
```

### 批量处理

```bash
# 自动识别目录中的文件（文件名包含"居民"/"走访"/"物资"）
python cli.py batch ./sample_data
```

### 查看数据统计

```bash
python cli.py stats \
  -r sample_data/居民数据.csv \
  -v sample_data/走访记录.csv
```

### 命令参数说明

#### process 命令
- `-r, --residents`: 居民数据文件（可多次指定）
- `-v, --visits`: 走访记录文件（可多次指定）
- `-m, --materials`: 物资发放文件（可多次指定）
- `-s, --sheet`: Excel工作表名称（可选）
- `-o, --output`: 输出报告文件名（可选）
- `-d, --output-dir`: 输出目录（默认：./reports）

#### batch 命令
- `data_dir`: 数据目录位置
- `-d, --output-dir`: 输出目录（可选）

#### stats 命令
- `-r, --residents`: 居民数据文件（可多次指定）
- `-v, --visits`: 走访记录文件（可多次指定）
- `-m, --materials`: 物资发放文件（可多次指定）
- `-s, --sheet`: Excel工作表名称（可选）

## 数据格式要求

### 居民数据必填字段
- 身份证号
- 姓名
- 性别
- 年龄
- 住址
- 联系电话

### 走访记录必填字段
- 走访日期
- 社工姓名
- 走访内容
- 居民身份证号

### 物资发放必填字段
- 发放日期
- 物资名称
- 数量
- 领取人
- 居民身份证号

## 风险分级规则

### 高风险（满足任一条件）
- 独居且高龄（>=80岁）
- 有严重慢性病或近期住院
- 无子女或子女长期不在身边

### 中风险（满足至少两项条件）
- 独居（70-79岁）
- 有慢性病但稳定
- 子女在本地但探望频率低
- 经济困难
- 超过60天未走访
- 走访记录显示需要帮助

### 低风险
- 不满足高/中风险条件的居民

## 报告内容

生成的Excel报告包含以下工作表：

1. **总体概览** - 数据统计和风险分级汇总
2. **风险分级结果** - 每位居民的风险等级和风险因素
3. **回访计划安排** - 回访计划和逾期提醒
4. **物资核销结果** - 物资发放记录的检查结果
5. **重复走访记录** - 识别到的重复走访记录
6. **数据来源追踪** - 每条数据的来源文件和行号
7. **坏行记录** - 解析失败或校验失败的记录

## 注意事项

1. 请确保数据文件编码为UTF-8或GBK
2. 日期格式建议使用 "YYYY-MM-DD" 或 "YYYY/MM/DD"
3. 身份证号作为唯一标识符，必须准确填写
4. 坏行记录会保留原文件位置，方便排查问题
5. 重复运行同一批数据时，除时间戳外，结果排序和内容保持一致
