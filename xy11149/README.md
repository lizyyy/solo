# 园艺养护队园艺病害归档 CLI

园艺病害归档数据处理工具，自动识别脏记录，将正常结果和异常结果分开输出，方便人工复核。

## 功能特性

- ✅ 正常记录与异常记录分离输出
- ✅ 稳定识别重复拍摄记录（相同时间-位置-病害类型）
- ✅ 识别位置缺失记录
- ✅ 可复跑输出（重复执行结果一致）
- ✅ 异常分类标记，便于人工复核
- ✅ 典型园艺病害业务场景

## 安装

```bash
npm install
npm link
```

## 使用指南

### 第一步：预览数据处理结果

在正式处理前，先预览数据情况，了解有多少异常记录需要处理。

```bash
garden-archive preview
```

或指定输入输出目录：

```bash
garden-archive preview -i ./data/input -o ./data/output
```

预览将显示：
- 处理文件数量
- 总记录数、有效记录数、异常记录数
- 重复拍摄数量
- 位置缺失数量
- 异常记录摘要（前10条）

### 第二步：正式执行数据处理

确认预览结果无误后，执行正式处理：

```bash
garden-archive run
```

或指定输入输出目录：

```bash
garden-archive run -i ./data/input -o ./data/output
```

处理完成后将在输出目录生成以下文件：
- `valid-records.csv` - 有效记录，可直接归档
- `invalid-records.csv` - 异常记录，待人工复核
- `report.json` - 处理报告
- `.processed-hashes.json` - 已处理哈希记录（用于可复跑识别）

### 第三步：查看处理报告

查看详细的处理统计和异常分类说明：

```bash
garden-archive report
```

或指定输出目录：

```bash
garden-archive report -o ./data/output
```

报告将展示：
- 处理时间
- 统计数据（文件数、总记录数、有效/异常记录数等）
- 异常记录分类说明

## 异常记录类型说明

| 异常类型 | 说明 | 处理建议 |
|---------|------|---------|
| 重复拍摄 | 相同时间-位置-病害类型组合重复 | 确认是否重复拍摄，保留有效记录 |
| 位置缺失 | 病害发生位置未填写 | 补充具体位置信息 |
| 字段缺失 | 其他必填字段缺失 | 补充完整必填字段 |
| 数据异常 | 数据格式或范围不正确 | 核对修正数据 |
| 空目录 | 输入目录中没有CSV文件 | 检查数据目录 |
| 文件格式错误 | CSV文件缺少必需列 | 检查文件格式 |
| 文件读取错误 | 文件读取失败 | 检查文件是否损坏 |

## 数据格式要求

输入CSV文件需包含以下列：

| 列名 | 说明 | 必填 |
|-----|------|------|
| recordId | 记录ID | 是 |
| shootTime | 拍摄时间 | 是 |
| location | 位置 | 是 |
| diseaseType | 病害类型 | 是 |
| severity | 严重程度（1-5） | 是 |
| notes | 备注 | 否 |

## 注意事项

1. 重复执行 `garden-archive run` 会稳定识别相同的异常记录
2. 已处理的哈希记录保存在 `.processed-hashes.json` 中，确保跨次执行的一致性
3. 异常记录请人工复核后再决定是否归档
4. 建议每次处理前先执行 `preview` 预览结果
