# 船舱装载平衡模拟器

基于 Three.js 的 3D 交互可视化船舱装载平衡模拟工具，帮助货代在装船前规划重货、冷藏箱和危险品在舱位中的分布。

## 功能特性

### 🎯 核心功能
- **3D 船舱可视化** - 交互式船舱模型，支持旋转、缩放、平移
- **货物装载模拟** - 点击选择货物，点击舱位进行装载
- **实时重心计算** - 动态显示船舶重心位置，偏移超过阈值自动告警
- **规则校验引擎** - 自动检查危险品相邻、冷藏插座、重量限制
- **时间轴回放** - 记录装载步骤，支持回放和跳转到任意历史状态
- **报告导出** - 生成详细的装载报告，包含重心信息和告警清单

### 📦 货物类型
- **重货** (蓝色) - 普通重型货物
- **冷藏箱** (青色) - 需要电源插座的冷藏货物
- **危险品** (红色) - 有隔离要求的危险货物

### 🎮 操作方式
- **左键点击** - 选择货物 / 装载货物到舱位 / 选择已装载货物
- **双击** - 卸载已装载的货物
- **滚轮** - 缩放视角
- **右键拖拽** - 旋转视角
- **中键拖拽** - 平移视角

## 可复现操作步骤

以下是一组标准操作流程，用于验证系统的完整功能：

### 步骤 1: 导入样例数据
1. 启动应用后，点击顶部工具栏的 **"导入样例"** 按钮
2. 左侧货物清单会显示 12 个样例货物（重货、冷藏、危险品各若干）
3. 3D 视窗中显示 24 个舱位（3 行 × 2 层 × 4 列）

### 步骤 2: 装载重货
1. 在左侧货物清单中，点击 **"重型机械A"** (28吨，重货) 进行选择
2. 观察 3D 视窗中的空舱位会高亮显示（绿色边框表示可装载）
3. 点击中间位置的空舱位（如 bay-1-0-1）完成装载
4. 观察状态栏：重心偏移会更新，装载统计 +1

### 步骤 3: 装载冷藏箱（需供电）
1. 在左侧筛选栏点击 **"冷藏"**，只显示冷藏货物
2. 选择 **"冷藏海鲜"** (12吨，需供电)
3. 观察带电源的舱位（有青色标识的舱位）
4. 点击 bay-0-0-0 舱位（第一行第一层带有电源）
5. **验证：** 如果选择不带电源的舱位，会出现警告提示

### 步骤 4: 装载危险品（隔离规则）
1. 在左侧筛选栏点击 **"危险品"**
2. 选择 **"易燃液体"** (class3)
3. 装载到 bay-1-1-0 舱位
4. 再选择 **"氧化剂"** (class2)
5. **验证：** 尝试装载到相邻舱位时，会显示橙色警告边框，提示违规相邻
6. 装载到非相邻舱位（如 bay-0-1-3）

### 步骤 5: 观察重心偏移告警
1. 连续将多个重货装载到同一侧的舱位
2. 观察状态栏的 **"重心偏移"** 指标
3. **验证：** 当偏移超过 15% 时，指标变为红色并显示警告图标

### 步骤 6: 使用时间轴回放
1. 完成几次装载操作后，观察底部时间轴
2. 点击时间轴上的数字节点可以跳转到对应步骤
3. 点击 **播放** 按钮可以自动回放装载过程
4. 使用 **前进/后退** 按钮单步调试

### 步骤 7: 切换视角
1. 点击顶部工具栏的视角按钮：
   - **总览** - 45度俯视视角
   - **船首** - 从船头方向观察
   - **船尾** - 从船尾方向观察
   - **侧面** - 从船舶侧面观察
2. 也可以手动拖拽旋转到任意角度

### 步骤 8: 卸载和调整
1. 在 3D 视窗中双击已装载的货物
2. 货物会被卸载，回到待装清单
3. 观察重心和告警信息自动更新

### 步骤 9: 导出装载报告
1. 点击顶部工具栏的 **"导出报告"** 按钮
2. 系统会下载一个文本格式的装载报告
3. 报告包含：
   - 装载概览（舱位利用率、总重量）
   - 重心坐标和偏移程度
   - 已装载货物详细清单
   - 所有告警信息列表
   - 装载步骤历史记录

### 步骤 10: 重置和持久化验证
1. 刷新浏览器页面
2. **验证：** 之前的装载状态、筛选条件、视角设置都会被保留
3. 点击 **"重置状态"** 按钮可以清空所有装载，恢复初始状态

## 核心算法

### 重心计算
采用加权平均算法，根据每个货物的重量和舱位位置计算整体重心：
```
重心X = Σ(货物重量i × 舱位Xi) / 总重量
重心Z = Σ(货物重量i × 舱位Zi) / 总重量
```

### 危险品隔离规则
不同等级危险品有不同的隔离要求：
- Class1 (爆炸品): 与所有其他危险品隔离
- Class2 (气体): 与 Class1, Class3 隔离
- Class3 (易燃液体): 与 Class1, Class2, Class4 隔离
- Class4 (易燃固体): 与 Class1, Class3 隔离

## 数据持久化

系统使用 LocalStorage 自动保存以下状态：
- 舱位装载状态
- 装载历史记录
- 当前步骤
- 货物筛选类型
- 相机视角偏好

刷新页面后会自动恢复上次的工作状态。
