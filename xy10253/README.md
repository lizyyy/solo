# 合唱团声部分配器

一个用于合唱团排练前声部分配的工具，根据音域、出勤和站位经验智能分配声部。

## 功能特性

### 1. 成员管理
- 添加、编辑、删除成员
- 记录成员音域范围（最低音到最高音）
- 设置偏好声部
- 记录站位经验
- 标记核心成员

### 2. 声部配置
- 创建多个声部（男高、男低、女高、女中）
- 配置声部音域范围
- 设置声部容量（最小/最大人数）
- 配置声部优先级

### 3. 出勤管理
- 按排练日期管理出勤
- 快速标记出勤/缺勤
- 一键全部出勤/缺勤
- 实时统计出勤情况

### 4. 智能分配
- 根据音域匹配分配
- 考虑成员偏好声部
- 参考站位经验
- 平衡各声部人数
- 支持手动调整分配

### 5. 验证验收
- **音域验证**：检查成员音域设置是否有效，分配是否匹配
- **容量验证**：检查声部容量设置是否合理，分配是否超限
- **出勤验证**：检查出勤状态与分配结果是否一致
- **平衡验证**：检查各声部人数分配是否平衡
- **一致性验证**：检查数据内部一致性

### 6. 数据持久化
- 所有数据自动保存到本地存储
- 刷新页面后自动恢复工作区
- 支持导入示例数据快速体验

## 验证结果说明

### 通过标准
- **✓ 通过**：所有音域匹配有效，声部容量正常，出勤数据一致
- **⚠ 警告**：存在可接受的问题，建议但非必须人工处理

### 需要人工处理
- **✗ 失败**：存在必须修正的问题，分配结果不可用
- **⚡ 冲突**：需要人工决策的分配冲突

## 验收结果

### 正常处理 ✓
- 所有验证项均通过
- 音域匹配率 100%
- 声部容量满足要求
- 出勤数据一致

### 需要关注 ⚠
- 基本验证通过
- 存在警告项需要关注
- 可以继续使用，建议优化

### 需要人工决策 ⚡
- 存在冲突问题
- 需要人工判断调整
- 调整后重新运行验证

### 需要修正 ✗
- 存在失败项必须修复
- 按验证报告逐项修复
- 修正后重新运行验证

## 使用流程

1. **导入数据**：点击"导入示例数据"快速体验，或手动添加成员和声部
2. **设置出勤**：在出勤管理中标记本次排练的出勤情况
3. **运行分配**：在声部分配页面点击"开始分配"
4. **手动调整**：如有需要，在分配结果中通过下拉框手动调整
5. **验证验收**：在验证验收页面运行验证，检查结果
6. **修复问题**：如存在失败项，回到相应页面修正后重新验证

## 运行方式

直接在浏览器中打开 `index.html` 文件即可使用。

或者使用简单的 HTTP 服务器：

```bash
# Python 3
python3 -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js (需要安装 http-server)
npx http-server
```

然后在浏览器中访问 `http://localhost:8000`

## 核心算法

分配算法考虑以下因素（权重可配置）：
1. **音域匹配**（50%）：计算成员音域与声部音域的重叠度
2. **偏好声部**（30%）：优先分配到成员偏好的声部
3. **站位经验**（10%）：考虑成员的站位习惯
4. **核心成员**（10%）：核心成员优先分配
5. **声部平衡**：人数较多的声部会有轻微惩罚

## 业务语言说明

应用输出使用业务化语言：
- **当前状态**：说明当前分配的整体情况
- **处理建议**：给出具体的操作建议
- **最后汇总**：提供清晰的验收结论

## 边界条件

- **音域边界**：成员音域必须低于所有声部才能分配
- **容量边界**：不能超过声部最大容量，建议满足最小容量
- **平衡边界**：各声部人数差异过大时会给出警告

## 注意事项

1. 首次使用建议导入示例数据体验
2. 数据保存在浏览器本地，清除浏览器数据会丢失
3. 建议定期导出数据备份（浏览器开发者工具 localStorage）
4. 对于音域交叉的成员，可以考虑手动调整分配
