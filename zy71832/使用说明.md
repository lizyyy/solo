# 河谷水坝攻防 - 战报分析工具

给玩法策划使用的战报处理工具，重点解决重复导入、撤回修正、筛选导出口径一致性问题。

---

## 快速开始

### 1. 环境准备
```bash
pip install -r requirements.txt
```

### 2. 查看使用指南
```bash
python main.py guide
```

---

## 核心工作流程

### 第一步：放置战报文本
**位置**: `data/raw_reports/` 目录

**格式要求**:
- 纯文本文件 (.txt)
- 回合标记: `第X回合` 或 `X回合`
- 阵营标记: `进攻方` 或 `防守方`
- 行动记录: 玩家名 + 行动描述 + 结果

**样例参考**: `data/raw_reports/sample_battle_report.txt`

```
第1回合
进攻方:
玩家001 使用重型火炮对水坝A点造成1200点伤害 成功
玩家002 使用爆破装置对水坝B点造成800点伤害 成功
防守方:
玩家101 使用护盾装置防御 成功
玩家102 修复水坝A点恢复500点生命 成功
```

### 第二步：导入战报
```bash
python main.py import-report data/raw_reports/你的战报.txt
```

- 自动解析回合、阵营、玩家、行动、数值
- 自动归档源文件到 `data/archived_reports/`
- 生成导入会话ID，用于撤回
- 自动检测重复记录

### 第三步：查看状态和异常
```bash
# 查看数据摘要
python main.py status

# 查看异常记录
python main.py anomalies

# 检查回合顺序
python main.py check-order
```

**去哪看回合顺序算错**:
- 运行 `python main.py anomalies`
- 查找类型为「回合顺序错误」的记录
- 查看战报原文的行号（在备注字段）
- 确认每个回合内是否是 进攻方→防守方 顺序

### 第四步：（如有需要）人工修正
```bash
# 修改记录
python main.py modify <记录ID> <字段名> <新值> --reason "修改原因"

# 撤回导入
python main.py rollback <会话ID> --reason "导入错误"

# 查看历史快照
python main.py snapshots

# 回滚到快照
python main.py rollback-snapshot <快照ID>
```

### 第五步：导出前复核
```bash
python main.py quick-check
```

**复核清单**:
1. ✅ 待补记录是否已补充完整
2. ✅ 异常记录是否已处理确认
3. ✅ 人工修改是否已注明原因
4. ✅ 回合范围是否完整
5. ✅ 导出筛选条件是否正确

### 第六步：导出数据或生成报告
```bash
# 导出Excel（默认）
python main.py export

# 按回合范围导出
python main.py export --round-start 1 --round-end 10

# 导出CSV
python main.py export --format csv

# 生成完整复盘报告（给主策）
python main.py report
```

## 复盘报告说明

`python main.py report` 生成的 Excel 报告包含以下工作表:

| 工作表 | 说明 |
|--------|------|
| 全部记录 | 所有战斗记录，按回合→阵营→玩家排序 |
| 已确认 | 系统自动解析并通过校验的记录 |
| 待补 | 字段缺失或信息不完整，需人工补充 |
| 人工修改 | 经过人工编辑修正的记录，带修改原因 |
| 异常记录 | 检测到的所有异常，可标记已解决 |
| 导入历史 | 每次导入的会话记录，可追溯 |
| 处理口径说明 | **重要！** 数据处理标准和规则说明 |
| 数据统计 | 各项指标汇总统计 |

## 核心功能特性

### ✓ 状态回看
- 自动快照：每次数据变更自动保存快照
- 历史追溯：可查看最近20个快照
- 一键回滚：随时恢复到之前的状态

### ✓ 异常解释
| 异常类型 | 说明 | 严重程度 |
|----------|------|----------|
| 回合缺失 | 检测到中间回合断档 | 高 |
| 重复行动 | 同回合同玩家同行动重复 | 中 |
| 伤害异常 | 伤害值超过阈值 | 中 |
| 治疗异常 | 治疗值超过阈值 | 中 |
| 阵营错误 | 不在进攻方/防守方列表 | 低 |
| 字段缺失 | 玩家或行动信息缺失 | 低 |
| 回合顺序错误 | 可能顺序不对，建议查原文行号 | 低 |

### ✓ 导出一致性
- 统一排序规则：回合 → 阵营 → 玩家ID
- 统一字段顺序：15个标准字段
- 记录ID全局唯一，可追溯
- 导出前自动一致性检查

### ✓ 撤回修正
- 按导入会话撤回，影响范围明确
- 每次修改自动打标为「人工修改」
- 必须填写修改原因，可审计

## 常见问题

**Q: 导入后发现数据错了怎么办？**
A: 用 `python main.py rollback <会话ID> --reason "原因"` 撤回，修正战报后重新导入。

**Q: 回合顺序算错了怎么看？**
A: 运行 `python main.py check-order`，然后对照战报原文的行号检查。每个回合内应保持「进攻方行动在前，防守方行动在后」。

**Q: 导出前需要做什么？**
A: 先运行 `python main.py quick-check`，确保待补记录补完、异常已处理、修改都有原因。

**Q: 能只导出前10回合吗？**
A: 可以，用 `python main.py export --round-start 1 --round-end 10`。

**Q: 给主策的报告在哪？**
A: 运行 `python main.py report`，报告在 `output/` 目录，文件名带「复盘报告」。
