# 仓储拣货优化 - 结果验证管理系统

## 功能特性

### 1. 数据导入
- 支持 Excel (.xlsx, .xls) 和 CSV 格式
- 自动去重，确保重复导入口径一致
- 记录导入历史和统计信息

### 2. 自动验证 (核心功能)
- **结果漂移检测**: 对比基线数据，自动识别拣货数量变化超过阈值的记录
- **约束被覆盖检查**: 验证单订单最大拣货数、最小拣货数等业务约束
- **单位混用检测**: 识别同一SKU使用多种计量单位的情况
- **单位有效性验证**: 确保单位在允许的标准列表内

### 3. 人工复核
- 每条问题都包含：问题类型、描述、复核证据、处理建议
- 支持人工确认状态（正常/待确认/存疑/无效）
- 记录复核说明

### 4. 版本管理
- 完整的版本历史追踪
- 支持撤回修正（回滚到历史版本）
- 所有操作都有日志记录

### 5. 筛选导出
- 多条件筛选（状态、订单号、商品、运行ID）
- 导出包含问题详情、处理建议、复核证据
- 支持 Excel 和 CSV 格式

## 快速开始

### 安装依赖
```bash
pip install -r requirements.txt
```

### 启动程序
```bash
python cli.py
```

## 操作说明

### 1. 导入数据
- 选择菜单 `1. 导入拣货结果`
- 输入数据文件路径: `data/sample_data.csv`
- 输入运行ID和批次号（可直接回车使用默认值）

### 2. 自动验证
- 选择菜单 `2. 验证结果`
- 输入基线数据路径（用于漂移检测）: `data/baseline_data.csv`
- 系统自动检测问题并标记状态

### 3. 查看问题记录
- 选择菜单 `4. 查看待确认/存疑记录`
- 可以看到每条问题的详细信息和处理建议

### 4. 人工复核
- 选择菜单 `5. 人工复核确认`
- 输入记录ID，选择新状态，填写复核说明

### 5. 筛选导出
- 选择菜单 `8. 筛选导出`
- 设置筛选条件，输入文件名导出

## 验证规则说明

| 问题类型 | 触发条件 | 严重程度 | 处理建议 |
|---------|---------|---------|---------|
| 结果漂移 | 与基线数据差异超过5% | 高 | 人工复核，确认数据更新或模型漂移 |
| 单位混用 | 同一SKU有多个单位 | 高 | 统一计量单位 |
| 单位无效 | 单位不在标准列表 | 中 | 修正为标准单位 |
| 约束被覆盖 | 订单总数超上限 | 中 | 检查是否需要拆分订单 |
| 约束被覆盖 | 拣货数低于下限 | 低 | 确认数量是否正确 |

## 配置说明

在 [config.py](file:///Users/lzy/pro/solo/workspaces/zy71871/config.py) 中可调整：

- `DRIFT_THRESHOLD`: 漂移检测阈值（默认 0.05 = 5%）
- `ALLOWED_UNITS`: 允许的单位列表
- `STANDARD_CONSTRAINTS`: 业务约束参数
