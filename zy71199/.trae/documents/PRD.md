## 1. 产品概述

一款浏览器端「资料归档审计游戏」，玩家模拟档案管理员，根据真实归档规则对文件卡片进行分类、定级、入库、借阅登记等操作。通过关卡制和回合制呈现，重点训练保密级别判定、保管期限计算、借阅登记合规等核心技能。

- 目标用户：办公室档案管理人员、新入职员工培训、档案管理考核
- 核心价值：用游戏化方式让玩家熟练掌握档案归档规则，降低实际工作中的错误率

## 2. 核心功能

### 2.1 功能模块
1. **游戏主界面（3D 场景）**：档案柜、文件卡片、操作面板、规则提示
2. **关卡选择界面**：显示已解锁关卡、得分星级、可重开
3. **结算报告界面**：错误回放、历史记录、导出归档报告

## 3. 核心流程

玩家进入游戏后选择关卡，在每回合内处理一批文件卡片：查看文件信息 → 判定保密级别 → 选择保管期限 → 选择档案盒 → 入库。过程中穿插借阅请求需要处理。每关结束后根据正确率和用时结算得分，显示错误回放和结算报告。

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深墨绿 `#1a3a2e` 档案柜主色 + 米黄 `#f5e6c8` 纸张色 + 红色印章色 `#c0392b`
- **辅助色**：金色标签 `#d4a017`、蓝色保密标识 `#2980b9`、灰色边框 `#95a5a6`
- **按钮风格**：圆角矩形 6px，3D 微立体效果，hover 时轻微上浮
- **字体**：标题用「思源黑体 Heavy」或「站酷快乐体」体现档案感；正文用「思源宋体」模拟文件正文字体
- **布局**：中央 3D 场景 + 右侧 2D 操作面板，顶栏 HUD，底栏规则提示
- **图标**：Lucide 图标库 + 印章风格自定义图标（保密章、绝密章、机密章等）

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 游戏主界面 | 3D 档案柜 | 深墨绿档案柜、金色标签盒、红色保密印章、米色文件卡片 |
| 游戏主界面 | 2D 操作面板 | 文件信息卡、保密级别选择器（印章按钮）、保管期限选择器（下拉）、档案盒选择器 |
| 游戏主界面 | 规则提示面板 | 浅米黄背景、宋体文字、红色标注错误、绿色标注正确 |
| 游戏主界面 | HUD 状态栏 | 深色半透明背景、白色文字、金色分数 |
| 关卡选择界面 | 关卡卡片 | 档案盒样式卡片、金色标签、星级评分 |
| 结算报告界面 | 错误回放 | 时间轴样式、错误高亮红色、绿色正确标记 |

### 4.3 响应式
- 桌面优先设计，触控操作优化
- 移动端布局调整为：上方 3D 场景、下方 2D 操作面板堆叠
- 所有交互元素最小 44px 触控区
- 支持鼠标拖拽和触控拖拽

### 4.4 3D 场景指引
- **环境/HDRI**：办公室室内光线，柔和阴影，无 HDRI，纯色渐变背景（米黄→浅灰）
- **光照**：主光源上方定向光 + 环境光，模拟办公室荧光灯
- **相机**：固定俯视 45° 角，可拖拽旋转查看档案柜
- **构图**：中央档案柜为主体，周围散放文件卡片，右侧面板为 2D
- **交互**：卡片可拖拽放入档案盒槽位，有吸附动画
- **后处理**：Bloom 发光效果（印章、标签）、AO 环境遮蔽
- **资源**：程序化生成几何体（长方体+纹理），无外部 3D 模型
