四种业务路径说明

正常路径

问诊 → 处方创建 → 药师审核通过 → 支付完成 → 库存确认 → 配送完成

拦截路径

药师审核拒绝 → 流程终止 → 记录变更历史 → 医生重新开方

复核路径

审核中 → 药师复核 → 更新审核意见 → 记录修改前后值 → 继续流程

导出路径

按责任人 / 时间范围筛选 → 生成 CSV 报告 → 包含全流程数据
