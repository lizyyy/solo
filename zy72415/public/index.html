🔍 页面 / 接口 / 导出 三处同源验证

验证逻辑：页面、接口、导出都调用 ConflictRecordService 中同一份底层数据：

  • 页面展示 → getAllUnifiedRecords()
  • API 接口 → getRecordsForApi() → 内部还是 getAllUnifiedRecords()
  • 导出明细 → exportRecords() → 遍历同一份 store.records

追踪方式：每条记录有唯一 记录ID，在页面表格、API JSON、导出 CSV 第一列中都能对应上。
