# 🍰 BakeCalc - 烘焙店配方成本和过敏原替换工具

为小烘焙店设计的本地配方成本计算器和原料替换分析工具。帮助店主在换原料、改规格、调售价前看清影响。

## ✨ 核心功能

### 1. 原料库管理
- 维护原料基本信息：名称、单位、采购价、供应商
- 过敏原标签：乳制品、鸡蛋、坚果、花生、小麦、大豆、鱼类、甲壳类
- 饮食标签：纯素、素食、无乳制品、无坚果、无麸质
- 是否可替代标记 + 预设候选替换品
- 价格历史追踪（每次调价自动记录）

### 2. 配方/SKU管理
- 每个 SKU 可配置多个原料用量
- **损耗率支持**：实际成本 = 理论成本 × (1 + 损耗率)
- 自动计算：
  - 理论成本（不含损耗）
  - 实际成本（含损耗）
  - 理论毛利率 / 实际毛利率
  - 单位成本（按产量）
- 过敏原聚合分析
- 饮食标签交集计算（只有所有原料都符合才标记）

### 3. 替换演练 (核心价值)
选择配方 → 选择要替换的原料 → 选择候选替换品，系统显示：

| 分析维度 | 内容 |
|---------|------|
| 成本变化 | 替换前后成本差、变化百分比 |
| 毛利变化 | 替换前后毛利率差（百分点） |
| 过敏原变化 | 新增/移除了哪些过敏原 |
| 饮食标签变化 | 新增/失去了哪些标签 |
| 推荐决策 | 是否推荐此替换 |

**不推荐替换的典型情况**：
- 新增过敏原（会影响合规标签）
- 单位不一致（可能换算问题）
- 原料标记为"不可替代"且替换品不在预设列表
- 成本显著增加

### 4. 导入导出
- **导入**：CSV / JSON 格式，带字段校验（必填字段、价格非负、枚举值校验）
- **导出成本分析报告**：Markdown / HTML / CSV 三种格式
- **导出替换演练报告**：Markdown / HTML / CSV
- **导出过敏原清单**：所有配方的过敏原和标签汇总
- **完整备份/恢复**：JSON 格式完整数据

### 5. 本地持久化
- 数据默认存储在 `~/.bake-calc/data/`
- 刷新或重新启动后数据不丢失
- 支持指定自定义数据目录

## ❓ 常见问题

### Q1: 如何批量导入原料？

准备 CSV 文件，格式如下：

```csv
name,unit,current_price,supplier,allergens,dietary_labels,is_substitutable
无盐黄油,kg,85.00,新西兰乳制品公司,乳制品,,True
植物黄油,kg,45.00,国内食品厂,,纯素,True
```

然后在程序中选择 **[4] 导入导出** → **[1] 从 CSV 导入原料**

### Q2: 损耗率是什么？怎么设置？

损耗率是烘焙过程中不可避免的原料浪费比例，例如：
- 黄油软化时的少量残留
- 面粉过筛的损失
- 裱花时的浪费

设置范围：0.0 - 0.99（即 0% - 99%）

示例：损耗率 0.05 表示 5% 的损耗

```
实际用量 = 配方用量 × (1 + 损耗率)
实际成本 = 单价 × 实际用量
```

### Q3: 为什么某些替换被标记为"不推荐"？

系统会自动判断：

1. **新增过敏原** - 最严重。比如从"无坚果"配方变成"含坚果"，会影响产品合规标签
2. **单位不一致** - 可能需要换算，提醒确认
3. **原料标记为不可替代** - 且替换品不在预设列表
4. **成本显著增加** - 会显示警告但不直接阻止

### Q4: 数据备份存在哪里？如何恢复？

**备份**：选择 **[4] 导入导出** → **[6] 完整数据备份 (JSON)**

**恢复**：选择 **[4] 导入导出** → **[7] 从备份恢复**，输入备份文件路径

> ⚠️ 恢复会覆盖当前所有数据，请谨慎操作

### Q5: 毛利率是怎么计算的？

```
理论成本 = Σ(原料单价 × 配方用量)
实际成本 = Σ(原料单价 × 配方用量 × (1 + 损耗率))

理论毛利率 = 1 - (理论成本 / 目标售价)
实际毛利率 = 1 - (实际成本 / 目标售价)
```

例如：
- 目标售价 ¥168
- 实际成本 ¥58.45
- 实际毛利率 = 1 - (58.45 / 168) = 65.2%

## 🔍 调试和错误排查

### 常见错误

| 错误信息 | 原因 | 解决方法 |
|---------|------|---------|
| 原料不存在 | ID 错误或已删除 | 检查原料是否存在 |
| 价格不能为负数 | 输入了负价格 | 输入 >= 0 的价格 |
| 损耗率必须在 0-1 之间 | 输入了无效值 | 输入 0.00 - 0.99 |
| 原料正在被配方使用 | 删除前有依赖 | 先从配方中移除 |
| 文件不存在 | 路径错误 | 检查文件路径是否正确 |
