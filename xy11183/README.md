# 汽车试驾中心 - 试驾里程审计 CLI

## 项目简介

专为汽车试驾中心设计的试驾里程审计工具，重点解决以下审计问题：

1. **反复修改同一条记录**：同一试驾ID被多次修改，最后只剩一个结果
2. **试驾结束未签退**：缺少结束时间、结束里程或签退状态异常
3. **私自绕路**：行驶里程异常偏高，时速或路线不符合常规

## 目录结构

```
.
├── input/
│   ├── normal/      # 正常试驾记录文件
│   ├── bad/         # 包含问题的试驾记录文件
│   └── empty/       # 空文件或只有表头的文件
├── output/          # 审计报告输出目录
├── src/
│   └── drive_audit.py   # 审计CLI脚本
├── tests/           # 测试相关文件
└── README.md        # 本文件
```

## 环境要求

- Python 3.6+
- 无需额外依赖（仅使用Python标准库）

## 使用方法

### 1. 审计单个文件

```bash
python3 src/drive_audit.py -i input/bad/试驾记录_20240116_北京朝阳店_问题数据.csv
```

### 2. 审计整个目录

```bash
python3 src/drive_audit.py -i input/ -o output/
```

### 3. 参数说明

- `-i, --input`: 输入文件或目录路径（必需）
- `-o, --output`: 输出目录（默认: ./output）

## 样例输入文件

### 正常文件示例

`input/normal/试驾记录_20240115_上海浦东店.csv`

- 包含5条有效试驾记录
- 所有记录均已签退，里程正常，无重复ID

### 问题文件示例

`input/bad/试驾记录_20240116_北京朝阳店_问题数据.csv`

2. **结束未签退**：试驾ID TJ104、TJ106 未签退

## 期望输出

运行审计后，在 `output/` 目录生成两个文件：

### 1. 试驾里程审计报告_YYYYMMDD_HHMMSS.txt

包含：
- **反复修改同一条记录问题**：列出重复ID的来源文件和行号
- **试驾结束未签退问题**：列出未签退记录的详细信息
- **疑似私自绕路问题**：显示异常里程、时长、时速、路线
- **空文件或无效文件问题**：标记空文件或只有表头的文件
- **审计统计摘要**：各类问题的数量统计

### 2. 可复跑修复清单_YYYYMMDD_HHMMSS.csv

运营同事可直接使用此CSV文件进行数据修复，包含：
- 问题类型
- 来源文件和行号
- 试驾ID、试驾员、客户、车型等信息
- 问题描述
- 具体修复建议

## 问题修复指南

运营同事无需打开源码，根据输出报告即可修复数据：

1. **反复修改记录**：在来源文件指定行号处，保留最新一条记录，删除重复项
2. **结束未签退**：补充结束时间和结束里程，将签退状态改为"已签退"
3. **疑似私自绕路**：核实实际行驶路线和里程，确认是否存在绕路行为
4. **空文件问题**：补充试驾数据或删除无效文件

## 审计规则说明

- **正常时速基准**：60 km/h
- **最大时速阈值**：80 km/h
- **绕路判定**：时速超过80km/h 或 里程超过相同时长正常里程的1.5倍
