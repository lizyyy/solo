# 除冰调度模拟器

冬季机场机坪除冰作业调度模拟游戏。

## 游戏目标

玩家扮演机场除冰调度员，在倒计时内将待飞航班、除冰车和除冰液分配到多个除冰位，需要：

- 满足各机型的液量需求
- 遵循航班优先级和起飞窗口
- 处理临时返场、液量不足、车辆故障、车辆换班等突发事件
- 跨午夜航班的连续运营

## 本地预览步骤

### 方法一：使用 Python（推荐）

```bash
cd /path/to/deicing-dispatch

# 启动本地服务器
python3 -m http.server 8080

# 打开浏览器访问
# http://localhost:8080
```

### 方法二：使用 Node.js

```bash
cd /path/to/deicing-dispatch

# 安装 http-server（如果未安装）
npm install -g http-server

# 启动服务器
npx http-server -p 8080 -c-1

# 打开浏览器访问
# http://localhost:8080
```

### 方法三：直接打开文件

由于游戏完全运行在浏览器端，也可以直接双击 `index.html` 打开。
但部分浏览器可能限制 localStorage 等功能，建议使用服务器方式。

## 游戏操作

### 基本操作

- **拖拽航班**：将左侧航班列表中的航班卡片拖拽到除冰位
- **分配除冰车**：系统自动分配可用车辆到除冰位
- **时间控制**：使用速度按钮(1x/2x/4x/8x)控制游戏速度
- **暂停/继续**：暂停游戏进行规划

### 快捷键

- `Space`：暂停/继续
- `1-4`：切换速度

## 关卡说明

### level-01：基础教学

- 3架航班
- 2个除冰位，2辆除冰车
- 学习基本拖拽操作

### level-02：跨午夜挑战

- 4架航班（含2架跨午夜航班）
- 夜间运营，除冰效率降低20%
- 气温下降导致液量消耗增加

### level-03：车辆故障

- 6架航班
- 高峰期除冰车突发故障
- 考验应急调度能力

### level-04：综合挑战

- 10架航班（含返场航班、跨午夜航班）
- 除冰液库存紧张
- 车辆换班事件
- 全功能综合测试

## 结算报告

游戏结束后，点击"导出报告"可生成 `deicing_report.json` 文件，包含：

- 作业摘要（成功/延误/准点率）
- 除冰液使用统计
- 车辆利用率
- 问题记录
- 时间线事件

## 技术架构

```

├── styles.css          # 样式表
├── js/

│   ├── scheduler.js    # 调度状态机

│   ├── storage.js      # 本地存档与报告
│   └── game.js         # 主游戏逻辑
```
