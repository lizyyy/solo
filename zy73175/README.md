# 概率模拟批量验算 — 操作手册

> 面向排班同事 / 不看代码的老师。一条命令跑完所有样例，外推越界会自动挂起，请您人工确认。

---

## 一、一条命令跑完整包样例

在项目根目录执行：

```bash
python3 -m prob_check run
```

跑完后会出现一张汇总表，告诉你：

- 总共有几条记录
- 几条**验算通过**（单位和数值都对）
- 几条**挂起待确认**（外推越界 / 单位异常，需要人工判断）
- 几条**验算不通过**（数值偏差超容差）

如果有"挂起待确认"的记录，命令最后会告诉你**具体卡在哪**——比如：

```
退出提示：以下记录卡在外推越界或单位换算异常，已挂起等待排班同事人工确认：
  - 记录 CASE003（王小刚）：外推越界卡壳在【摄氏温度】，当前值 150.0，
    正常区间 [-50.0, 60.0]，方向：高于上限。请排班同事确认后再放行。
```

这时请继续看第二节。

## 二、人工确认挂起记录（别靠回忆，写下来就自动留痕）

命令格式：

```bash
python3 -m prob_check confirm <记录ID> <你的名字> "<改口径原因>"
# 如果要把数值也一起改掉，加 --override <新数值>
```

**示例**：王小刚那条算出来 150°C，超出设备量程 60°C，学生实际是单位写错了，应改为 65.6°C：

```bash
python3 -m prob_check confirm CASE003 李排班 \
  "学生单位写错，实际应为输入65.6摄氏度而非302华氏度，设备量程60°C以上需走特殊流程" \
  --override 65.6
```

执行完后，系统会自动记下来：

- 旧值是多少（150.0）
- 新判断的数值是多少（65.6）
- 为什么改（你写的那段话）
- 谁改的、什么时间改的

周一早会前翻记录，一眼就能看到，不用靠人回忆。

## 三、查看某条记录的完整历史（数字从哪来、改过几次、原因全在里面）

```bash
python3 -m prob_check show CASE003
```

你会看到：

- 学生姓名、公式描述、**数字来源线索**（比如"课本P35例2-3"、"实验报告第3组"）
- 输入值、单位、期望值、实际结果
- 当前状态（验算通过 / 挂起待确认 / 人工已确认）
- **附件 / 草稿备注**：学生写了什么、旧版本截图在哪、助教标注了什么（全部保留，不会只留最终值）
- **历史变更记录**：谁在什么时候改了什么、旧值新值、原因是什么

## 四、给记录补备注 / 截图引用（保留历史）

学生草稿里后来补的备注、旧版本截图路径，都可以补到记录里：

```bash
python3 -m prob_check attach CASE001 "草稿备注" "6月20日和小岑核对过，学生确实改了这步"
python3 -m prob_check attach CASE001 "截图引用" "学生手写草稿扫描件: img/case001_scan.pdf"
```

## 八、常见问题

**Q：如果我强制想改一条已经"验算通过"的记录口径怎么办？**
A：加 `--force` 参数，例如：
```bash
python3 -m prob_check confirm CASE001 王排班 "复核时发现期望值不对，改一下" --override 0.76 --force
```

**Q：单位库不包含我要用的单位怎么办？**
A：找助教小岑在 `prob_check/unit_converter.py` 的 `UNIT_FACTORS` 字典里加一行即可。

**Q：合理区间（比如摄氏温度 -50~60）想调整怎么办？**
A：找助教小岑在 `prob_check/boundary_checker.py` 的 `DEFAULT_BOUNDARIES` 里改。
