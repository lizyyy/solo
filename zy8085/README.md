# 社区团购团长核对工具

帮助社区团购团长核对自提日的缺货和错拿问题。

## 功能特性

- 导入订单数据、扫描记录、货架映射
- 按货架/订单展示待拣、已扫、异常件
- 支持扫码输入和手动改判
- 备注持久化存储
- 导出自提报告和退款列表

## 运行方式

```bash
python app.py
```

## 数据文件

工具会自动读取 `sample_data/` 目录下的以下文件：

### orders.csv

订单数据，包含字段：
- order_id: 订单号
- product_name: 商品名称
- sku: 商品SKU
- quantity: 数量
- shelf_code: 货架编码
- customer_name: 顾客姓名
- phone: 联系电话

### scan_events.jsonl

扫描事件记录，每行一条JSON，包含字段：
- scan_time: 扫描时间
- sku: 商品SKU
- shelf_code: 扫描时的货架编码
- scanner_id: 扫描设备ID

### shelf_map.yaml

货架映射配置，格式：
```yaml
货架名称:
  - 货架编码1
  - 货架编码2
```

## 使用说明

1. **视图切换**：可选择"按货架"或"按订单"查看
2. **扫码输入**：在底部输入框输入SKU后回车或点击扫码按钮
3. **手动改判**：选中订单后可标记异常或重置待拣
4. **编辑备注**：选中订单后可添加备注信息
5. **导出报告**：点击导出按钮生成 pickup_report.md 和 refund_list.csv

## 边界处理

- **同一商品多次扫码**：自动标记为重复扫描异常
- **订单临时换货架**：支持货架映射配置，可临时调整货架位置

## 输出文件

- pickup_report.md: 自提日核对报告，包含概览统计和各状态订单列表
- refund_list.csv: 异常订单退款列表，便于财务处理
