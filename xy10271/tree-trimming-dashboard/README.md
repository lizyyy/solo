# 小区树木修剪工单台

智能化树木修剪管理系统，按楼栋遮光、病虫害、居民投诉自动排序，支持处理结果公示。

## 安装运行

```bash
# 进入项目目录
cd tree-trimming-dashboard

# 安装依赖
npm install

# 启动开发服务器
npm run dev
```

启动后访问显示的本地地址（通常是 `http://localhost:5173`）。

## 样例入口

系统内置 8 棵树木、10 条投诉记录的完整样例数据，首次打开自动加载。

**核心样例场景：**

- **1号楼东侧悬铃木（T001）**：遮光 85%，3 条投诉（遮光×2、居民投诉×1）→ 高优先级工单
- **6号楼西侧银杏树（T006）**：遮光 90%，有天牛蛀洞，3 条投诉 → **紧急优先级**工单
- **2号楼南侧香樟树（T002）**：病虫害（褐斑病），2 条投诉 → 中高优先级

## 核心操作流程

### 1. 查看树木档案
- 左侧导航 → **树木档案**
- 可按楼栋、状态筛选，支持导出 CSV
- 点击「查看详情」查看树木信息和关联投诉

### 2. 投诉标记处理
- 左侧导航 → **投诉管理**
- 查看所有投诉（按类型：遮光/病虫害/居民投诉）
- 新增投诉：点击「➕ 新增投诉」，选择树木和类型
- 处理投诉：点击「处理」填写处理结果

### 3. 工单优先级排序（核心）
- 左侧导航 → **工单排序**
- 系统自动计算优先级（权重：遮光 40%、病虫害 35%、投诉 25%）
- 点击「详情」查看评分明细和关联投诉
- **开始处理**：填写负责人，状态变为「处理中」
- **完成处理**：填写处理结果 → 自动更新树木状态、标记投诉已解决
- **公示结果**：完成后点击「公示」，进入公示清单

### 4. 处理结果公示
- 左侧导航 → **结果公示**
- 查看所有已公示的处理结果
- 支持按楼栋筛选、导出公示清单

## 如何检查结果

### 数据一致性检查
1. **重置数据**：数据概览页面 → 点击「🔄 重置样例数据」
2. **重跑验证**：重置后查看各项统计应与初始状态一致
3. **工单不重复**：点击「刷新工单」不会生成重复工单

### 关键流程验证

**验证树木位置 → 遮光投诉 → 公示清单 跑通：**

1. 进入「工单排序」，找到 **6号楼西侧银杏树**（优先级最高）
2. 点击「开始」→ 输入负责人「绿化队张师傅」
3. 点击「完成」→ 输入处理结果：
   > 已修剪过密枝条，清除天牛蛀洞，喷洒农药防治，预计一周后复查
4. 点击「公示」确认公示
5. 进入「结果公示」→ 确认该工单已出现在公示清单中
6. 返回「树木档案」→ 查找该树木，状态应变为「已修剪」
7. 进入「投诉管理」→ 该树木关联的 3 条投诉应标记为「已解决」

### 导出功能检查
- 各模块均支持「📥 导出 CSV」
- 同一批数据导出的文件内容一致，不会重复或膨胀
- 导出文件包含完整字段信息

## 技术说明

- **前端框架**：React 19 + TypeScript + Vite
- **数据存储**：浏览器 localStorage（页面刷新数据不丢失）
- **无需后端**：完全前端实现，内置样例数据可直接验收
- **数据去重**：工单生成时检查已存在记录，避免重复
