# 自助打印店耗材补给系统 - 验收步骤

## 一、环境准备（终端执行）

### 1. 安装依赖
```bash
cd /Users/lzy/pro/solo/workspaces/zy70270
npm install
```

### 2. 初始化种子数据
```bash
npm run seed
```
预期输出：
```
种子数据初始化完成！
已创建: 3家门店, 5台设备, 14条耗材记录, 4个故障, 4个补给单
```

### 3. 启动服务
```bash
npm start
```
预期输出：
```
自助打印店补给系统运行在 http://localhost:3000
```

### 4. 打开应用
在浏览器中访问：**http://localhost:3000**

## 二、基础功能验收（界面点击操作）

### 验收1：查看总览数据
**操作步骤：**
1. 打开应用后默认在"总览"标签页
2. 观察四个统计卡片

**预期结果：**
- 门店数：3
- 设备数：5
- 耗材预警：≥5（查看具体预警列表）
- 待处理故障：3

### 验收2：以设备为入口查看详情
**操作步骤：**
1. 点击顶部"设备"标签
2. 观察设备卡片（每张卡片代表一台打印机）

**预期结果：**
- 每个卡片显示：设备编号、门店、型号、位置、状态
- 卡片左侧有颜色标识：
  - 蓝色 = 正常
  - 红色 = 有故障
  - 黄色 = 有耗材预警
- 卡片底部有三个按钮：编辑 / 报障 / 补给

### 验收3：查看耗材余量（关键校验）
**操作步骤：**
1. 点击顶部"耗材"标签
2. 观察"状态"列
3. 点击任意一条记录的"编辑"按钮

**预期结果：**
- 余量 ≤ 阈值的显示红色"预警" badge
- 余量 > 阈值的显示绿色"正常" badge
- 编辑弹窗可修改余量、阈值

### 验收4：新增门店
**操作步骤：**
1. 点击顶部"门店"标签
2. 点击右上角"+ 新增门店"按钮
3. 填写：
   - 门店名称：望京店
   - 地址：北京市朝阳区望京SOHO T3
   - 电话：010-99998888
4. 点击"保存"

**预期结果：**
- 列表新增一条记录
- 刷新页面后数据仍存在

### 验收5：新增设备
**操作步骤：**
1. 点击顶部"设备"标签
2. 点击右上角"+ 新增设备"按钮
3. 填写：
   - 所属门店：望京店
   - 设备编号：DEV-WJ-001
   - 型号：HP M428fdw
   - 位置：一层大堂
   - 状态：正常
4. 点击"保存"

**预期结果：**
- 设备列表新增一张卡片

### 验收6：登记故障
**操作步骤：**
1. 在"设备"页面找到 DEV-WJ-001 卡片
2. 点击卡片底部"报障"按钮
3. 填写：
   - 故障类型：卡纸
   - 描述：频繁卡纸，可能进纸器有问题
4. 点击"保存"
5. 切换到"故障"标签查看

**预期结果：**
- 故障列表新增一条记录
- 状态为"待处理"
- 故障记录有上报时间（证据）

### 验收7：处理故障
**操作步骤：**
1. 在"故障"标签页找到刚登记的卡纸故障
2. 点击"处理"按钮
3. 将状态改为"已解决"
4. 点击"保存"

**预期结果：**
- 状态badge变成绿色"已解决"
- 故障记录的解决时间被自动记录

### 验收8：新建补给单
**操作步骤：**
1. 在"设备"页面找到 DEV-ZGC-002（中关村店的Canon设备）
2. 点击卡片底部"补给"按钮
3. 填写：
   - 类型：耗材补给
   - 物品：黑色墨粉盒
   - 数量：1
4. 点击"保存"

**预期结果：**
- 切换到"补给单"标签可看到新记录

### 验收9：一键生成补给单（智能）
**操作步骤：**
1. 回到"总览"标签
2. 点击"耗材预警"卡片右上角"一键生成补给单"按钮
3. 确认弹窗
4. 切换到"补给单"标签

**预期结果：**
- 自动为所有低于阈值且无待处理订单的耗材创建补给单
- 补给单备注包含："自动生成：设备XXX的XX余量不足"
- 不会重复创建（已有待处理订单的跳过）

### 验收10：导出数据
**操作步骤：**
1. 点击右上角"📊 导出Excel"按钮
2. 打开下载的 Excel 文件

**预期结果：**
- Excel 包含6个工作表：
  - 门店
  - 设备
  - 耗材余量（含"是否预警"列）
  - 故障记录（含上报/解决时间）
  - 补给单
  - 预警汇总

## 三、异常样例验收

### 异常1：重复数据检测
**操作步骤：**
1. 点击顶部"⚠️ 异常测试"按钮（展开黄色面板）
2. 点击"❌ 测试重复数据"按钮

**预期结果：**
- 系统捕获重复数据错误
- 显示："重复数据错误：该记录已存在"

**界面验证方式：**
也可以手动在"门店"标签新增一个已存在的名称（如"中关村店"），保存时会报错。

### 异常2：缺失必填字段检测
**操作步骤：**
1. 在异常测试面板点击"❌ 测试缺字段"按钮

**预期结果：**
- 系统捕获字段校验错误
- 显示："缺少必填字段"

**界面验证方式：**
也可以手动在"设备"标签新增设备时不填"设备编号"直接保存，会报错。

### 异常3：人工改错演示
**操作步骤：**
1. 在异常测试面板点击"✏️ 人工改错演示"按钮
2. 阅读说明后，点击弹出的"演示：将XX改为5%"按钮
3. 确认模拟错误
4. 观察总览页的耗材预警数增加
5. 切换到"耗材"标签，找到那条被错误修改的记录（余量5%）
6. 点击"编辑"，把余量改回正常值（如60%）
7. 保存

**预期结果：**
- 模拟错误后，该耗材出现在预警列表
- 人工修改正确后，预警消失
- 验证：故障登记有时间戳，补给单也有创建时间，可交叉比对判断补给是否正确
