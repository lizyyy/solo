# 字幕质检工具

一个本地桌面工具，用于字幕质量检查，帮助译审同事快速发现字幕中的问题。

## 功能特性

### 核心检查规则

- **时间重叠检查** - 检测字幕时间是否与前一字幕重叠
- **每秒字数过高检查** - 检测字幕阅读速度是否过快
- **空字幕检查** - 检测文本为空或仅包含空格的字幕
- **说话人缺失检查** - 检测缺少说话人标签或说话人无效的字幕
- **敏感词命中检查** - 检测包含敏感词的字幕
- **时长过短检查** - 检测显示时间小于阈值的字幕

### 界面功能

- **时间线展示** - 可视化展示字幕、波形占位条、片段条
- **问题列表** - 表格形式展示所有问题，支持筛选
- **人工确认状态** - 支持标记问题为已确认、已忽略、已修复
- **会话管理** - 支持保存和加载质检会话
- **导出功能** - 导出 Markdown 报告和 CSV 问题列表

### 边界情况处理

- ✅ 跨小时时间格式（如 01:02:03,456）
- ✅ 毫秒格式不一致（逗号 , vs 点号 .）
- ✅ 连续空行处理
- ✅ 缺少序号的字幕块
- ✅ 无小时格式的时间（如 05:30,123）
- ✅ VTT 格式的头部和元数据


## 使用说明

### 基本工作流程

1. **导入文件**
   - 必需：字幕文件（.srt 或 .vtt）
   - 可选：片段清单（.json）- 用于说话人检查
   - 可选：配置文件（.yaml）- 用于说话人列表和敏感词

2. **运行质检**
   - 点击"运行质检"按钮或按 F5
   - 系统会自动执行所有检查规则

3. **查看问题**
   - 时间线：可视化展示字幕位置，红色表示有错误，黄色表示有警告
   - 问题列表：表格形式展示所有问题
   - 详情面板：查看选中问题的详细信息

4. **人工确认**
   - 选中问题后，点击"确认"、"忽略"或"已修复"按钮
   - 状态会自动保存

5. **导出结果**
   - 导出报告（Markdown）：生成可读的质检报告
   - 导出列表（CSV）：生成可编辑的问题列表

### 文件格式说明

#### 字幕文件（.srt / .vtt）

**SRT 格式：**
```
1
00:00:01,000 --> 00:00:03,500
[说话人] 字幕文本内容
```

**VTT 格式：**
```
WEBVTT

1
00:00:01.000 --> 00:00:03.500
[说话人] 字幕文本内容
```

**支持的说话人标签格式：**
- `[说话人] 文本`
- `【说话人】文本`
- `说话人: 文本`

#### 片段清单（.json）

```json
[
    {
        "id": "seg_001",
        "start": 1.0,
        "end": 3.5,
        "speaker": "张三",
        "content": "字幕文本内容"
    }
]
```

#### 配置文件（.yaml）

```yaml
# 有效说话人列表
speakers:
  - 张三
  - 李四
  - 王五

# 敏感词列表
sensitive_words:
  - 敏感词1
  - 敏感词2

# 质检参数
max_chars_per_second: 5.0    # 每秒最大字符数
min_subtitle_duration: 0.3    # 最小字幕时长（秒）
```

## 检查规则详解

### 1. 时间重叠检查

**问题描述**：当前字幕的开始时间早于前一字幕的结束时间。

**触发条件**：
- 当前字幕开始时间 < 前一字幕结束时间 - 10ms（微小重叠被忽略）

**严重程度**：错误 (Error)

**示例**：
```
字幕1: 00:00:01,000 --> 00:00:03,500
字幕2: 00:00:03,000 --> 00:00:05,000  <- 与字幕1重叠 0.5 秒
```

### 2. 每秒字数过高检查

**问题描述**：字幕阅读速度过快，观众可能无法及时阅读。

**触发条件**：
- （有效字符数 / 时长）> 阈值（默认 5 字符/秒）

**严重程度**：警告 (Warning)

**计算方式**：
- 有效字符数 = 去除空格、换行、HTML 标签后的字符数
- 时长 = 结束时间 - 开始时间

### 3. 空字幕检查

**问题描述**：字幕文本为空或仅包含空格/换行。

**触发条件**：
- 去除首尾空格后文本为空

**严重程度**：错误 (Error)

### 4. 说话人缺失检查

**问题描述**：字幕缺少说话人标签，或说话人不在有效列表中。

**两种情况**：

**情况 A**：字幕有说话人，但不在有效列表中
- 严重程度：警告 (Warning)

**情况 B**：字幕没有说话人，但片段清单中有对应说话人
- 严重程度：提示 (Info)

### 5. 敏感词命中检查

**问题描述**：字幕文本包含配置的敏感词。

**触发条件**：
- 字幕文本包含敏感词列表中的任意词

**严重程度**：错误 (Error)

**匹配方式**：
- 中文：直接包含匹配
- 不区分大小写

### 6. 时长过短检查

**问题描述**：字幕显示时间小于最小阈值。

**触发条件**：
- 时长 < 阈值（默认 0.3 秒）

**严重程度**：警告 (Warning)

## 导出格式说明

### Markdown 报告（review_report.md）

报告包含以下部分：

1. **统计概览**
   - 总字幕数、总问题数
   - 按严重程度分布
   - 按问题类型分布
   - 处理状态统计

2. **详细问题列表**
   - 按严重程度分组（错误 → 警告 → 提示）
   - 每个问题包含：字幕序号、时间范围、说话人、问题描述、字幕文本、详细信息

3. **附录**
   - 问题类型说明

### CSV 列表（issues.csv）

包含以下列：

| 列名 | 说明 |
|------|------|
| 序号 | 问题序号 |
| 问题类型 | 时间重叠/字数过高/空字幕/等 |
| 严重程度 | 错误/警告/提示 |
| 处理状态 | 待处理/已确认/已忽略/已修复 |
| 字幕序号 | 原字幕序号 |
| 开始时间 | HH:MM:SS.mmm 格式 |
| 结束时间 | HH:MM:SS.mmm 格式 |
| 时长(秒) | 字幕时长 |
| 说话人 | 说话人标签 |
| 问题描述 | 问题详细描述 |
| 字幕文本 | 原字幕文本 |
| 详细信息 | 额外的技术细节 |

## 常见问题

### Q1: 如何调整质检参数？

编辑配置文件（.yaml）中的以下字段：

```yaml
max_chars_per_second: 5.0    # 调整每秒最大字符数
min_subtitle_duration: 0.3    # 调整最小字幕时长
```

### Q2: 为什么某些时间格式无法解析？

程序支持以下时间格式：
- `HH:MM:SS,mmm`（标准 SRT）
- `HH:MM:SS.mmm`（VTT 格式）
- `MM:SS,mmm`（无小时）
- `MM:SS.mmm`（无小时）

如果遇到不支持的格式，请检查是否符合上述格式。

### Q3: 会话保存在哪里？

默认保存在当前目录下的 `.qa_state` 文件夹中，格式为 JSON。

### Q4: 支持批量处理多个字幕文件吗？

当前版本单次只能处理一个字幕文件。可以通过会话管理功能来处理多个文件，每次处理保存一个会话。

### 添加新的检查规则

1. 在 `rules_engine.py` 中的 `IssueType` 枚举添加新类型
2. 在 `RulesEngine` 类中添加新的检查方法
3. 在 `check_all` 方法中调用新方法
4. 在 `Exporter` 类中添加类型名称映射
