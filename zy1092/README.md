# CueDesk - 演出流程管理工具

CueDesk 是一个专为婚礼、年会、小剧场或社团演出设计的本地桌面应用，帮助音控师、主持助理等专业人员管理演出流程。

## 功能特性

### 📋 核心功能
- **项目管理**：创建和管理多个演出项目
- **流程段落管理**：每个流程可以包含音频素材、口播卡、负责人、麦克风、预估时长、彩排状态和现场备注
- **拖拽排序**：支持拖拽或按钮调整流程顺序
- **状态流转**：状态在"待确认 / 已彩排 / 现场变更 / 已完成"之间流转
- **本地存储**：所有数据存储在浏览器本地，刷新后不丢失

### 🚩 风险检查
- **音频文件路径缺失**：检查音频文件路径是否有效
- **时间重叠**：检测相邻段落时长是否重叠
- **麦克风冲突**：检查同一时间段是否有麦克风冲突
- **口播词缺失**：检测有人负责但口播词为空的情况
- **现场变更未确认**：提醒现场变更状态的流程需要重新确认

### 📥 导入导出
- **导入**：支持从 CSV 和 JSON 格式导入流程数据
- **导出**：
  - JSON 备份：完整数据备份
  - Markdown Cue Sheet：格式化的流程表
  - HTML Cue Sheet：带样式的 HTML 格式流程表
  - CSV 物料清单：简洁的 CSV 格式清单
  - 开场前 10 分钟急救清单：包含风险检查和确认项的急救清单

### 🎨 界面设计
- **三栏布局**：
  - 左侧：流程列表和筛选
  - 中间：编辑当前段落
  - 右侧：显示风险和导出入口
- **适合现场快速查看**：清晰的视觉层次和颜色编码

## 如何启动应用

CueDesk 是一个纯 Web 应用，不需要安装任何依赖，直接在浏览器中打开即可使用。

### 方法一：直接打开 HTML 文件
1. 找到项目目录中的 `index.html` 文件
2. 双击该文件，它将在默认浏览器中打开
3. 应用即可正常使用

### 方法二：使用本地服务器（推荐）
如果直接打开遇到 CORS 问题（如加载外部库），建议使用本地服务器：

#### 使用 Python
```bash
# Python 3
python3 -m http.server 8080

# Python 2
python -m SimpleHTTPServer 8080
```

然后在浏览器中访问 `http://localhost:8080`

#### 使用 Node.js（需要安装 http-server）
```bash
# 安装 http-server（如果没有安装）
npm install -g http-server

# 在项目目录中运行
http-server -p 8080
```

然后在浏览器中访问 `http://localhost:8080`

#### 使用 VS Code Live Server 插件
1. 在 VS Code 中安装 "Live Server" 插件
2. 右键点击 `index.html` 文件
3. 选择 "Open with Live Server"
4. 应用将在默认浏览器中打开

## 如何导入示例数据

项目提供了两个示例数据文件，位于 `examples/` 目录下：

1. `sample-wedding.json` - 婚礼流程示例（包含测试风险检查的数据）
2. `sample-annual-meeting.csv` - 年会流程示例

### 导入步骤：
1. 启动应用后，点击顶部的 "新建项目" 按钮创建一个新项目
2. 输入项目名称（如 "婚礼流程测试"），点击 "创建"
3. 点击顶部的 "导入" 按钮
4. 在弹出的导入模态框中，选择导入类型（JSON 或 CSV）
5. 点击 "选择文件" 或拖放文件到指定区域
6. 选择 `examples/sample-wedding.json` 或 `examples/sample-annual-meeting.csv`
7. 确认预览信息后，点击 "导入" 按钮
8. 示例数据将导入到当前项目中

### 示例数据说明：
- **婚礼流程示例 (JSON)**：包含 14 个流程，其中包含一些故意设置的风险项，用于测试风险检查功能：
  - 无效的音频路径（用于测试音频路径检查）
  - 时间重叠的流程（用于测试时间重叠检查）
  - 麦克风冲突的流程（用于测试麦克风冲突检查）
  - 有负责人但口播词为空的流程（用于测试口播词缺失检查）
  - 状态为"现场变更"的流程（用于测试现场变更未确认检查）

- **年会流程示例 (CSV)**：包含 10 个流程，展示了 CSV 格式的导入方式

## 功能使用说明

### 创建项目
1. 点击顶部的 "新建项目" 按钮
2. 输入项目名称和可选的项目描述
3. 点击 "创建" 按钮
4. 新项目将自动被选中

### 切换项目
1. 点击顶部的项目选择下拉框
2. 选择要切换的项目

### 添加流程
1. 确保已选中一个项目
2. 点击左侧流程列表上方的 "添加流程" 按钮
3. 新流程将被添加到列表底部
4. 在中间的编辑区域填写流程信息

### 编辑流程
1. 在左侧流程列表中点击要编辑的流程
2. 在中间的编辑区域修改流程信息
3. 点击 "保存" 按钮保存更改
4. 或点击 "取消" 按钮取消编辑

### 调整流程顺序
**方法一：拖拽排序**
1. 在左侧流程列表中，按住要移动的流程
2. 拖动到目标位置
3. 释放鼠标完成排序

**方法二：使用按钮**
1. 在左侧流程列表中选中要移动的流程
2. 在中间编辑区域的顶部，使用 "↑" 和 "↓" 按钮调整顺序

### 状态流转
1. 在中间编辑区域，找到 "状态" 下拉框
2. 选择新的状态：
   - 待确认
   - 已彩排
   - 现场变更
   - 已完成
3. 点击 "保存" 按钮保存更改

### 风险检查
1. 选择一个项目后，右侧风险检查区域会自动显示风险列表
2. 或点击 "重新检查" 按钮手动触发检查
3. 风险按严重程度排序：高风险（红色）、中风险（橙色）、低风险（黄色）
4. 点击风险项查看详细信息，然后在流程编辑中修复问题

### 导出功能
1. 选择一个项目后，右侧导出区域提供多种导出选项
2. 点击相应的导出按钮：
   - **JSON 备份**：导出完整项目数据，包含项目信息和所有流程
   - **Markdown Cue Sheet**：导出格式化的 Markdown 格式流程表
   - **HTML Cue Sheet**：导出带样式的 HTML 格式流程表
   - **CSV 物料清单**：导出简洁的 CSV 格式清单
   - **开场前 10 分钟急救清单**：导出包含风险检查和确认项的急救清单
3. 文件将自动下载到浏览器的默认下载位置

## 技术栈

- **HTML5**：页面结构
- **CSS3**：样式设计，支持响应式布局
- **原生 JavaScript**：应用逻辑，不依赖任何框架
- **Sortable.js**：实现拖拽排序功能（通过 CDN 加载）
- **LocalStorage**：本地数据存储

## 数据存储说明

所有数据都存储在浏览器的 LocalStorage 中：
- 项目数据：存储在 `cuedesk_projects` 键下
- 当前选中的项目：存储在 `cuedesk_current_project_id` 键下

**注意**：
1. 数据与浏览器绑定，如果清除浏览器数据，数据将丢失
2. 建议定期使用 "JSON 备份" 功能导出数据进行备份
3. 不同浏览器之间的数据不共享

## 浏览器兼容性

应用支持以下现代浏览器：
- Chrome 60+
- Firefox 55+

- Edge 79+

## 使用提示

1. **定期备份**：建议在每次重大修改后，使用 "JSON 备份" 功能导出数据
2. **风险检查**：在彩排前和开场前，务必点击 "重新检查" 按钮检查风险
3. **状态管理**：及时更新流程状态，特别是现场变更的流程
4. **导出急救清单**：开场前导出 "开场前 10 分钟急救清单"，逐一确认

## 常见问题

### Q: 为什么直接打开 index.html 后，Sortable.js 无法加载？
A: 某些浏览器对本地文件的 CORS 限制较严格。建议使用本地服务器方式启动应用（参见"如何启动应用"章节）。

### Q: 数据会丢失吗？
A: 数据存储在浏览器的 LocalStorage 中，正常情况下不会丢失。但如果清除浏览器数据或更换浏览器，数据将无法访问。建议定期导出 JSON 备份。

### Q: 如何在不同设备间同步数据？
A: 目前应用是纯本地应用，不支持云同步。可以通过导出 JSON 备份，然后在另一台设备上导入的方式手动同步。

### Q: 支持哪些音频格式？
A: 应用本身不播放音频，只是存储音频文件路径。支持的音频格式取决于您的播放设备。

### Q: 如何自定义导出格式？
A: 导出功能的代码位于 `import-export.js` 文件中，可以根据需要修改导出格式的实现。
