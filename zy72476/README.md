## 📋 十分钟看懂（开会前速看）

### 同一小区有新旧两个名字怎么处理？
**不用翻网格员巡查表**，系统在「小区复核」页面直接展示疑似同名的小区，点一下「设置别名」关联即可。关联后：
- ✅ 页面展示、导出明细、接口返回 **读同一份数据**
- ✅ 原始记录保留原来的小区名（不覆盖，便于追溯）
- ✅ 原始行号、人工改动标记、处理状态 **全部留痕**

### 最容易出错的四个点，系统帮你自检
1. **重复导入检测** - 同一份Excel别导入两次
2. **同一小区新旧名识别** - 自动列出疑似重名
3. **补录后重算检查** - 施工告示补录后有没有漏了重算
4. **导出一致性校验** - 导出、页面、接口三者数据是否一致

### 三步走完街道会准备
```
第一步：导入网格员巡查表 → 第二步：小付补看施工告示 → 第三步：导出摘要给街道会
```

## 🚀 新人快速上手（从样例到报告）

### 1. 启动后端
```bash
cd backend
pip3 install -r requirements.txt   # 首次运行安装依赖
python3 app.py
```
后端运行在 `http://localhost:5001`

### 2. 打开前端
直接用浏览器打开文件：
```
frontend/index.html
```
不需要构建、不需要npm。

### 3. 跑一遍完整流程（跟着点就行）

#### 第一步：导入网格员巡查表
1. 点击「📥 导入数据」
2. 选择样例文件：`samples/网格员巡查表样例.xlsx`
3. 点「开始导入」
4. ✅ 导入成功，12条记录

#### 第二步：复核小区新旧名（关键！）
1. 点击「🏘️ 小区复核」
2. 你会看到这些小区：
   - 阳光花园、阳光花园小区 → 是同一个
   - 翠湖家园、翠湖家园小区 → 是同一个
   - 和平里、和平里社区 → 是同一个
3. 点「阳光花园」那一行的「设置别名」
4. 下拉选择「阳光花园小区」，点「确认关联」
5. 同样处理另外两组

> 💡 **别急着归正常**：系统不会自动合并，留给市政巡检员手动复核确认。

#### 第三步：补看施工告示（小付操作）
1. 点击「🚧 施工告示」
2. 选择小区「阳光花园」
3. 标题填：XX路管线改造施工
4. 日期填：2024-06-03
5. 内容填：因市政管线改造，小区正门步道临时封闭3天
6. 影响出行次数：-5
7. 影响低碳得分：-1.2
8. 点「添加告示并标记重算」
9. ✅ 相关记录自动标记为「需重算」
10. 点「🔄 执行重算」应用影响

#### 第四步：自检（必做！）
1. 点击「✅ 自检中心」
2. 点「运行自检」
3. 看四个检查项有没有红的

#### 第五步：导出报告
1. 点右上角「📤 导出账本」
2. 下载的Excel包含4个Sheet：
   - 出行账本明细（含原始行号、处理状态、改动标记）
   - 小区名录（含新旧名关联）
   - 施工告示
   - 操作日志（证据链）

## 🔍 设计细节（给追问的人看）

### 证据链完整怎么保证？
- 每条巡查记录保留 `original_row`（Excel原始行号）
- 人工修改自动标记 `manual_edited = 1`，并记录 `operation_logs`
- 修改前后的值都存在日志里，谁改的、什么时候改的，可查
- 小区名关联不删除原始记录，只建立关联关系

### 为什么不自动合并新旧小区名？
- 网格员写的名可能有歧义（比如「滨河新村一期」和「滨河新村二期」不是同一个）
- 系统只做提示，最终判断交给人，避免误合并
- 复核过程本身就是一道质量关

### 导出、页面、接口怎么保证一致？
- 三者调用同一个 `get_export_data()` 函数
- 自检模块用MD5哈希校验三者数据一致
- 见 `backend/self_check.py` 的 `check_export_consistency()`

## 🛠️ API 一览

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | /api/import | 导入巡查表Excel |
| GET | /api/records | 查巡查明细 |
| PUT | /api/records/:id | 修改记录（自动留痕） |
| GET | /api/communities | 查小区列表 |
| POST | /api/communities/:id/alias | 设置小区别名关联 |
| POST | /api/construction-notices | 补录施工告示 |
| POST | /api/recalc | 执行重算 |
| GET | /api/self-check | 运行四项自检 |
| GET | /api/summary | 获取摘要看板数据 |
| GET | /api/export | 导出Excel账本 |
| GET | /api/operation-logs | 查操作日志 |
