## 1. 产品概述

"3D餐厅动线挑战"是一款面向餐饮培训的小型Web游戏，让员工在3D餐厅场景中规划服务员路线，体验出餐与收台动线冲突时的真实取舍。通过交互式操作而非简单点按钮，帮助员工理解动线设计的业务逻辑，培养在路径规划、任务优先级和时间压力下的决策能力。

- 目标用户：餐饮企业一线员工、店长、培训讲师
- 核心价值：将抽象的动线管理知识转化为可感知的操作体验，降低培训成本，提升实际运营效率

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 学员 | 培训参与者 | 进行游戏挑战、查看个人复盘报告 |
| 讲师 | 培训组织者 | 配置关卡参数、查看团队数据、审核记录 |

### 2.2 功能模块

1. **游戏主界面**：3D餐厅场景、服务员操控、路线绘制、实时状态面板
2. **风险看板**：分类展示路线交叉/出餐超时/清洁漏做三类风险，带决策解释
3. **记录管理**：已处理/待确认/退回补材料三种状态的记录列表
4. **复盘回放**：回放游戏过程，展示每一步决策的原因和后果

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 游戏主界面 | 3D餐厅场景 | 俯视角3D餐厅，含桌位、出餐口、收台区、通道；支持旋转/缩放 |
| 游戏主界面 | 服务员路线绘制 | 拖拽绘制服务员移动路径，出餐路线(橙色)与收台路线(蓝色)分色显示 |

## 3. 核心流程

玩家进入3D餐厅场景，观察桌位布局和出餐口位置。随着订单涌入，玩家需要：1）为服务员绘制出餐路线（从出餐口到桌位）；2）绘制收台路线（从桌位到收台区）；3）在多任务并发时决定优先执行顺序；4）在时间压力下做出取舍。游戏实时检测路线交叉、出餐超时、清洁漏做三类风险，并在风险看板中分类呈现。游戏结束后，玩家可进入复盘回放，理解每一步决策的得失。

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深炭灰(#1A1A2E)为底，搭配暖琥珀色(#F0A500)作为出餐路线强调色，冷钢蓝(#4A90D9)作为收台路线强调色
- 辅助色：风险红(#E74C3C)标记路线交叉，警告黄(#F39C12)标记出餐超时，遗漏紫(#9B59B6)标记清洁漏做
- 按钮风格：圆角矩形，微3D凸起效果（box-shadow），按下时内凹反馈
- 字体：思源黑体(Noto Sans SC)作为正文，站酷快乐体作为标题装饰
- 布局：左侧状态面板 + 中央3D场景 + 右侧任务面板，底部时间轴
- 图标风格：线性图标(Stroke)，2px线宽，与3D场景的实体感形成对比

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 游戏主界面 | 3D餐厅场景 | 俯视角等距3D渲染，地板木纹纹理，桌位为圆角方形实体，出餐口为发光门框，收台区为水槽模型 |
| 游戏主界面 | 路线绘制 | 鼠标拖拽形成路径点，出餐路径橙色虚线，收台路径蓝色虚线，交叉点脉冲闪烁 |
| 游戏主界面 | 状态面板 | 半透明深色卡片，桌位图标带状态色环(绿=空闲/橙=用餐/红=待收台) |
| 游戏主界面 | 时间压力条 | 顶部全宽进度条，渐变色+脉冲动画，剩余20%时闪烁警告 |
| 风险看板 | 三栏风险卡 | 红色卡片(路线交叉)、黄色卡片(出餐超时)、紫色卡片(清洁漏做)，各自独立计数徽章 |
| 风险看板 | 决策解释 | 灰底圆角气泡，内含一句中文解释，鼠标悬停展开详情 |
| 记录管理 | 三态列表 | 已处理=绿色勾标/待确认=黄色时钟标/退回=红色箭头标，Tab切换过滤 |
| 复盘回放 | 时间轴 | 底部深色轨道，圆形事件节点按时间排列，关键风险节点带对应颜色 |

### 4.3 响应式设计

- 桌面优先设计，最小支持1280px宽度
- 平板端(768-1024px)：左右面板折叠为可展开抽屉
- 不支持手机端（3D场景交互需要精确操作空间）

### 4.4 3D场景指引

- 环境/氛围：暖色调餐厅室内，顶部暖黄射灯，地板反射微光
- 灯光设置：顶部3盏点光源模拟餐厅吊灯，环境光偏暖(AmbientLight #FFF5E1 intensity 0.4)
- 相机设置：正交相机(OrthographicCamera)等距俯视角，角度约45度，支持鼠标拖拽旋转和滚轮缩放
- 构图与焦点：餐厅中央为活动区域，出餐口在左侧，收台区在右后侧，形成对角线动线
- 交互与动画：服务员沿路径平滑移动，到达桌位时执行服务动画(弯腰/端盘)，路线交叉点有粒子警告效果
- 后处理效果：轻微Bloom效果让灯光和路线发光，Vignette增加画面聚焦感
- 资源与性能：桌位/服务员用几何体组合(low-poly风格)，无外部模型加载，目标60fps
