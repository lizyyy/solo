## 1. 产品概述

离心机转速安全区管理系统——面向实验教师与设备工程师的参数复核与审计平台。从传感器编号与工况照片的临时拼接中提取转速安全区边界规则，确保人工改系数留痕、重复导入不翻倍、历史可溯源可复盘。

- 目标用户：实验教师（林老师等，负责数据导入与备注补写）、设备工程师（负责复核人工改动）
- 核心价值：将口头约定变为代码级规则与可审计记录，避免"改了系数没写原因"的安全隐患

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 实验教师 | 管理员分配账号 | 导入传感器编号、上传工况照片、补写备注、查看安全区 |
| 设备工程师 | 管理员分配账号 | 复核人工改动、确认或回滚系数变更、审阅历史记录 |
| 管理员 | 系统内置 | 用户管理、系统配置、安全区边界规则管理 |

### 2.2 功能模块

1. **总览仪表盘**：安全区状态概览、最近导入批次、待复核条目、异常标记
2. **传感器数据管理**：传感器编号批量导入（去重）、工况照片关联、备注编辑
3. **安全区参数复核**：参数列表与变更标记、人工改动检测、溯源跳转至传感器编号/工况照片
4. **历史变更追踪**：逐条变更的改前改后对比、变更原因记录、回滚操作、可重跑命令导出
5. **可视化分析**：3D 安全区展示与图表视图、点击穿透至原始数据源

## 3. 核心流程

### 3.1 传感器编号首次导入流程

实验教师上传传感器编号 CSV → 系统自动去重校验 → 生成安全区参数初值 → 参数回放页更新 → 标记为"待复核"

### 3.2 工况照片补看与备注流程

实验教师在传感器列表中点击"补看照片" → 上传/查看工况照片 → 编辑备注 → 保存触发变更记录 → 历史页新增一条变更

### 3.3 人工改系数复核流程

系统检测到系数被人工修改但未写原因 → 参数列表标红"未写原因" → 设备工程师收到待复核提醒 → 工程师查看溯源（跳转传感器编号/工况照片）→ 填写复核意见 → 标记"已复核"或"需回滚"

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深钢蓝 (#1B3A4B) + 安全橙 (#FF6B35) 作为警示色 + 冷灰底 (#F0F2F5)
- 按钮风格：圆角矩形，主操作深钢蓝实心，危险操作安全橙实心，次要操作灰色描边
- 字体：标题使用 Noto Sans SC Bold，正文使用 Noto Sans SC Regular，数据使用 JetBrains Mono
- 布局风格：左侧导航 + 顶部面包屑 + 右侧主内容区，卡片式内容组织
- 图标风格：线性图标，与 lucide-react 图标库一致

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 总览仪表盘 | 安全区状态卡片 | 3列网格卡片，数字加粗放大，图标辅助，底部趋势小折线 |
| 总览仪表盘 | 最近导入批次 | 紧凑表格，批次号可点击跳转，时间戳右对齐 |

### 4.3 响应式设计

- 桌面优先设计，最小宽度 1280px
- 平板适配：导航栏折叠为汉堡菜单，表格支持横向滚动
- 移动端：仅保留核心查看功能，导入与复核操作引导至桌面端

### 4.4 3D 场景指引

- 环境：工业风深色背景，微弱环境光 + 定向主光源
- 灯光：顶部偏冷白光，侧面暖色补光，待复核区域添加安全橙点光源
- 相机：默认等距投影，45度俯视角，鼠标控制旋转缩放
- 构图：安全区以半透明圆柱/锥体表示，转速轴为垂直方向
- 交互：悬浮高亮，点击弹出详情面板，双击跳转溯源
- 后处理：轮廓线描边（待复核区域），轻微辉光效果
- 性能预算：60fps，三角面数 < 50k
