# 小微贷款展期预警系统 - 使用说明

## 快速开始

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 启动服务

```bash
uvicorn app.main:app --reload
```

服务启动后访问: http://127.0.0.1:8000

### 3. 运行演示脚本（可选）

打开新终端执行：

```bash
python init_demo.py
```

## 核心功能

### ✅ 同一客户多账号合并检测
- **问题解决**: 通过身份证号自动识别同一客户拆分的多个客户编号
- **处理方式**: 自动关联到同一客户，生成高优先级预警
- **预警信息**: 列出所有关联账号、客户编号、合计剩余本金

### ✅ 退款跨清算日异常检测
- **问题解决**: 检测退款日期与清算日期不一致的情况
- **关联材料**: 指回具体的来源材料编号（如退款审批单、还款凭证）
- **预警信息**: 明确标注跨期天数、涉及金额、材料编号

### ✅ 智能数据清洗
无需手工清洗，系统自动处理：
- **空值处理**: 标记为空，生成待补全提示
- **重复项**: 自动检测并跳过重复账号
- **格式不统一**:
  - 日期: 支持 `2024-01-15`、`2024/01/15`、`20240115` 等格式
  - 金额: 自动去除千分位逗号、货币符号
  - 身份证: 15位自动升级为18位
  - 手机号: 自动去除空格、横杠、+86区号
  - 利率: 百分号自动转换为小数

### ✅ 复核记录导出
- 财务复核员可直接带走复核记录
- 异常说明字段可直接转发给相关人员
- 导出格式清晰，包含完整预警信息和复核意见
