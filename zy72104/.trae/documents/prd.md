## 1. 产品概述

水泵扬程管损估算工具——面向训练教练及业务同事的一站式计算看板，解决设备巡检表中单位混乱、手工换算易错、阈值判断靠经验、结果无法追溯的问题。目标：输入传感器记录和设备参数后，自动完成物理近似计算、单位换算校验、阈值提醒和处理建议生成，输出可归档、可复算、可并排比较的完整报告，训练教练老唐不用再手工对第二遍。

- 目标用户：训练教练、设备运维人员、业务同事
- 核心价值：消除单位换算错误、自动阈值判断、保留原始数据与处理轨迹、冲突时给出双面证据而非替用户拍板

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 训练教练 | 直接使用 | 输入数据、查看结果、导出报告、历史对比 |
| 业务同事 | 查看报告 | 查看处理建议、对照原始数据 |

### 2.2 功能模块

1. **数据输入页**：传感器记录录入、设备参数表、现场备注、人工修正
2. **估算看板页**：扬程/管损计算结果、单位换算状态、阈值提醒、处理建议
3. **历史对比页**：同批数据重跑并排比较、参数变更追踪
4. **报告页**：可归档的完整报告，报告与明细一致性保证

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据输入页 | 传感器记录区 | 导入或手动输入传感器数据（流量、压力、温度等），保留原始值和单位 |
| 数据输入页 | 设备参数区 | 泵型号、额定扬程、额定流量、管径、管长、粗糙度等，支持多种单位输入 |
| 数据输入页 | 现场备注区 | 自由文本，保留设备巡检表中的乱备注，不做清洗 |
| 数据输入页 | 人工修正区 | 标注修正值、修正原因，修正后仍保留原始值 |
| 估算看板页 | 扬程计算 | 基于伯努利方程的扬程估算，显示各项分量（静扬程、动扬程、管损） |
| 估算看板页 | 管损计算 | Darcy-Weisbach 公式计算沿程损失，Hazen-Williams 备选，局部损失系数表 |
| 估算看板页 | 单位换算状态 | 自动检测输入单位，换算为标准单位（SI），标注换算方向和系数 |
| 估算看板页 | 阈值提醒 | 扬程偏差、管损占比、效率下降等阈值超限高亮，分级提醒（注意/警告/危险） |
| 估算看板页 | 处理建议 | 业务同事能照着做的操作建议，如"请检查阀门开度""建议清洗滤网" |
| 估算看板页 | 来源追溯 | 每条结果标注原始数据来源、处理时间、修正记录 |
| 估算看板页 | 冲突提示 | 巡检表与导入数据冲突时，双面证据并列，建议动作分开列出 |
| 历史对比页 | 参数对比表 | 同批数据历史参数与新结果并排显示，变更项高亮 |
| 历史对比页 | 趋势图 | 扬程/管损随时间变化趋势 |
| 报告页 | 报告生成 | 包含完整计算过程、原始数据、修正记录、阈值判断、处理建议 |
| 报告页 | 明细一致性 | 报告摘要与明细数据同源，不允许两套说法 |

## 3. 核心流程

用户打开工具 → 输入/导入传感器记录和设备参数 → 系统自动检测单位并换算 → 用户确认或修正单位 → 执行扬程管损计算 → 系统校验阈值并生成分级提醒 → 展示计算结果、处理建议和来源追溯 → 如有冲突，双面证据并列 → 用户可选择导出报告或进行历史对比 → 报告与明细数据一致性校验通过后归档

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深灰底（#1a1a2e）+ 工程蓝（#0f3460）+ 警示橙（#e94560）+ 通过绿（#16c79a）
- 按钮风格：圆角微凸，主按钮工程蓝底白字，危险操作警示橙
- 字体：JetBrains Mono（数据展示）+ Noto Sans SC（中文界面）
- 布局：左侧导航 + 右侧内容区，卡片式模块，表格为主的数据展示
- 图标：lucide-react，工业风图标

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|----------|
| 数据输入页 | 传感器记录区 | 可编辑表格，单位下拉选择，行内校验提示，深色卡片 |
| 数据输入页 | 设备参数区 | 表单卡片，参数名+值+单位三列布局，单位自动检测标签 |
| 数据输入页 | 现场备注区 | 多行文本框，保留原始格式，浅色边框区隔 |
| 数据输入页 | 人工修正区 | 修正值+原始值双列，修正原因文本，删除线标注原始值 |
| 估算看板页 | 扬程计算 | 数值卡片组（静扬程/动扬程/管损/总扬程），进度条对比额定值 |
| 估算看板页 | 管损计算 | 管损分解表（沿程+局部），占比饼图 |
| 估算看板页 | 阈值提醒 | 分级色条（绿/黄/橙/红），闪烁动画标警告级 |
| 估算看板页 | 处理建议 | 建议卡片，图标+文案，可操作按钮 |
| 估算看板页 | 来源追溯 | 时间线组件，数据来源标签 |
| 估算看板页 | 冲突提示 | 双栏对比卡片，左侧巡检表/右侧导入数据 |
| 历史对比页 | 参数对比表 | 双列表格，变更项高亮背景 |
| 历史对比页 | 趋势图 | 折线图，悬停显示数值 |
| 报告页 | 报告生成 | 打印友好布局，段落结构清晰，表头表尾完整 |

### 4.3 响应式设计

- 桌面优先设计，1920px 主屏适配
- 平板端（768px+）保留完整功能，调整卡片布局为双列
- 移动端暂不优先，保证数据可读即可
