# 马拉松补给消耗预测器 (MSP) 使用说明

## 概述

马拉松补给消耗预测器（Marathon Supply Predictor, MSP）是一个专业工具，用于处理马拉松补给站按分段人数和天气备水备胶的日常问题。通过对分段人数、天气因素和补给规则的综合分析，预测各站点物资消耗、排查短缺风险、生成物资报告。

### 步骤 2：执行预测

```bash
python3 -m marathon_supply_predictor.cli process -i 你的数据文件.json -o 输出目录
```

### 步骤 3：查看中间结果

命令执行后，输出目录会生成以下文件（带时间戳）：

| 文件名 | 说明 |
|--------|------|
| `prediction_details_*.json` | 预测详细数据（可用于重跑比较） |
| `shortage_review_*.json` | 短缺复盘结果（根因分析 + 建议） |
| `processing_status_*.json` | 处理状态（各站状态、拦截原因） |
| `run_status_*.json` | 运行状态快照 |
| `final_report_*.txt` | 最终可读报告 |

### 步骤 4：复核与决策

如果输出 `需要人工复核`，请：

1. 打开 `shortage_review_*.json` 查看根因分析
2. 打开 `final_report_*.txt` 查看详细建议
3. 根据建议调整补给站备量
4. 重新运行预测进行对比

## 差异点详解

### 差异 1：补给站位置

补给站的公里数直接影响消耗预测：

| 里程段 | 水消耗系数 | 能量胶消耗系数 |
|--------|-----------|---------------|
| 0-10km | 0.6 | 0.5 |
| 10-20km | 0.9 | 0.8 |
| 20-30km | 1.1 | 1.2 |
| 30-35km | 1.3 | 1.5 |
| 35km+ | 1.5 | 1.5 |

**关键节点**：30km+ 站点消耗系数急剧上升，是短缺高发区。

### 差异 2：分段人数

不同分段的人数分布影响预测：
- 起始分段人数 = 总人数
- 后面分段人数逐渐减少（退赛因素）
- 分段难度系数（easy/medium/hard）影响消耗

### 差异 3：天气消耗

天气因素是最大变量：

#### 温度影响
| 温度 | 消耗系数 |
|------|---------|
| <5°C | 0.8 |
| 5-15°C | 0.9 |
| 15-25°C | 1.0 |
| 25-30°C | 1.3 |
| 30-35°C | 1.6 |
| ≥35°C | 2.0 |

#### 湿度影响
| 湿度 | 消耗系数 |
|------|---------|
| <40% | 1.1 |
| 40-60% | 1.0 |
| 60-80% | 1.15 |
| ≥80% | 1.35 |

**拦截样例的天气**：33°C（系数1.6）× 88%湿度（系数1.35）= 综合系数飙升。

## 拦截条件说明

满足以下任一条件将触发拦截：

1. **多站短缺**：≥2个补给站存在短缺风险
2. **关键段短缺**：30-40km 分段内站点短缺
3. **高温预警**：气温≥32°C
4. **高湿预警**：湿度≥85%

## 实际使用建议

1. **赛前 1 周**：使用预估人数和天气预报进行初测
2. **赛前 3 天**：更新最新天气预报，复测调整
3. **赛前 1 天**：确认最终人数，终测锁定备量
4. **保留各次报告**：便于赛后复盘对比

## 常见问题

**Q: 为什么分段人数总和大于总人数？**
A: 因为跑者会依次经过多个分段，分段人数是累计经过的人数，不是独立个体数。

**Q: 如何添加新的物资类型？**
A: 在 `supply_items` 数组中添加新条目，注意 `supply_type` 字段需唯一。

**Q: 如何调整消耗规则？**
A: 目前规则为内置（见 `prediction.py`），可通过调整 `prepared_supplies` 间接适配，或修改代码中的系数。
