## 1. 产品概述

"港口岸桥作业立方"是一款面向港口岸桥巡检方案的3D可视化管理工具。核心解决交接前方案经理需反复从巡检照片中人工比对异常、截图与筛选条件对不上的问题。通过3D空间定位 + 全链路溯源 + 冲突证据并排展示，确保每条异常判断可追溯、可续办、可交接，减少重复翻旧记录的负担。

- 目标用户：方案经理（如许姐）、巡检员、接手方案的同事
- 核心价值：从"照片堆里翻证据"变为"点击即溯源、续办有起点、交接无需再问"

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 方案经理 | 主操作人 | 导入数据、标注异常、保存方案、导出报告 |
| 巡检员 | 数据提供方 | 上传巡检照片、补充点位信息 |
| 接手同事 | 继任方案经理 | 查看溯源记录、继续处理异常 |

### 2.2 功能模块

1. **作业立方主界面**：3D岸桥模型 + 异常高亮 + 视角控制 + 侧边溯源面板
2. **数据管理面板**：点位表导入、照片关联、坐标修正、冲突检测
3. **方案工作台**：方案保存/加载、版本对比、截图导出（含筛选条件水印）
4. **报告视图**：报告与明细一致性校验、一键导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 作业立方主界面 | 3D岸桥场景 | 简化几何体岸桥模型，按点位表放置检测点标记；异常点位红色脉冲高亮；支持旋转/缩放/预设视角切换；视角选择持久保存 |
| 作业立方主界面 | 溯源侧边栏 | 点击3D异常标记后展示：来源行（点位表行号/照片ID）、处理备注、处理时间、处理人；支持直接编辑备注和追加材料 |
| 作业立方主界面 | 截图工具栏 | 一键截图当前3D视角，自动叠加筛选条件水印和时间戳，导出为PNG |
| 数据管理面板 | 点位表导入 | 支持CSV/Excel导入点位表，自动解析坐标与检测项；导入后每条记录生成唯一溯源ID |
| 数据管理面板 | 照片关联 | 上传巡检照片，手动或自动关联到点位表行；照片与数据冲突时弹窗并排展示两方证据 |
| 数据管理面板 | 冲突检测 | 巡检照片描述与导入数据不一致时，展示"照片说法 vs 数据说法 + 建议动作"，不替用户拍板 |
| 方案工作台 | 方案保存/加载 | 方案存为JSON（含视角、异常标注、备注、时间戳）；支持多版本列表，点击加载 |
| 方案工作台 | 截图导出 | 截图含筛选条件水印、时间戳、当前视角参数，确保截图与条件对得上 |
| 报告视图 | 报告生成 | 从方案数据生成报告，报告内容与明细表严格一致；校验报告与明细差异，有差异时标红提示 |
| 报告视图 | 导出 | 支持导出为PDF/打印 |

## 3. 核心流程

### 3.1 日常巡检方案处理流程

方案经理启动系统 → 加载上次方案（或新建）→ 导入最新点位表 → 系统自动比对已有数据 → 冲突项弹出证据并排面板 → 方案经理逐项确认/标注 → 点击3D模型异常点查看溯源 → 追加备注/材料 → 保存方案 → 导出截图和报告

### 3.2 交接流程

接手同事加载方案 → 浏览3D模型异常分布 → 点击异常查看溯源（来源行+处理备注+时间）→ 继续处理未完成项 → 保存为新版本

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深色工业风——以 #0F1923（深海蓝黑）为底色，#00E5A0（荧光绿）为正常状态色，#FF4757（警告红）为异常高亮色
- **辅助色**：#1B2B3A（面板底色）、#2A3F52（卡片底色）、#FFA502（冲突/待确认色）
- **字体**：标题使用 Rajdhani（工业几何风），正文使用 Noto Sans SC（中文可读性）
- **按钮风格**：微圆角（4px）、半透明边框、hover 时边框荧光绿亮起
- **布局风格**：左侧3D场景为主（占70%宽度），右侧溯源面板（30%），顶部工具栏
- **图标风格**：线性图标（Lucide），与工业风统一

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 作业立方主界面 | 3D岸桥场景 | 深色背景、线框+半透明面岸桥模型、绿色正常点/红色脉冲异常点、右下角视角预设按钮组 |
| 作业立方主界面 | 溯源侧边栏 | 半透明深色面板、来源行号高亮、时间戳灰色小字、备注可编辑文本框、追加材料按钮 |
| 作业立方主界面 | 截图工具栏 | 顶部工具栏、截图按钮带相机图标、导出后自动下载PNG |
| 数据管理面板 | 点位表导入 | 拖拽上传区域、导入进度条、数据预览表格（斑马纹） |
| 数据管理面板 | 冲突检测面板 | 左右分栏：左侧照片说法+缩略图、右侧数据说法+数值、底部建议动作按钮组 |
| 方案工作台 | 方案列表 | 卡片式列表、方案名/时间/异常数、hover显示摘要、点击加载 |
| 报告视图 | 报告预览 | A4纸张风格预览、异常汇总表+明细表、一致性校验状态指示灯 |

### 4.3 响应式策略

- 桌面优先（1920×1080为基准），3D场景不低于960px宽
- 小屏时溯源面板可折叠为底部抽屉
- 不做移动端适配（港口作业环境使用笔记本/台式机）

### 4.4 3D场景指引

- **环境**：暗色天空盒，微弱环境光，突出检测点高亮效果
- **光照**：一个主方向光（偏冷白）+ 环境光（低强度暖色），避免遮蔽检测点
- **相机**：默认斜45度俯视，支持OrbitControls旋转/缩放；3个预设视角（正面/侧面/俯视）
- **构图**：岸桥居中，检测点均匀分布，异常点用发光圈(bloom)突出
- **交互**：点击检测点弹出溯源面板，hover时显示点位名称tooltip
- **后处理**：异常点bloom效果，增强视觉区分
