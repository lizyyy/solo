## 原始点子

我想做一个给商场物业做消防演练复盘用的 3D 交互可视化小工具。每次演练后，保安只拿到一份楼层平面 CSV、几个出口位置和各楼层观察员记录的人员移动日志，很难判断哪里堵、谁走错出口、某段通道是不是临时封闭导致绕路。请从 0 到 1 做一个可本地运行的浏览器应用，主界面要用 Three.js 或同类 3D/Canvas 技术把多层楼面、楼梯/电梯井、出口、封闭通道和人员轨迹画出来，支持播放/暂停/拖动时间轴查看疏散过程；能导入示例 CSV/JSON 数据，包括楼层网格、连接边、出口、人员每分钟位置、观察员备注和临时封闭区间；要有一套路径分析规则，自动计算每个人实际用时、绕行距离、是否经过封闭通道、是否到达最近安全出口，并把拥堵边、异常停留和走错出口高亮出来；右侧面板能筛选楼层/人群/异常类型，点选一个人后显示他的轨迹摘要和备注；还能导出 Markdown 复盘报告和 JSON 分析结果。请把渲染层、数据解析、时间轴状态、路径/异常分析、导出报告和示例数据拆成清晰的多文件结构，不要只做静态截图。README 里写清楚安装、启动、示例数据格式，以及如何验证导入、播放、筛选、点选人员、异常高亮和报告导出的完整流程。
