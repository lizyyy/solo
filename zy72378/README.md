# 隧道风速压差核验

## 模块说明

| 文件 | 职责 |
|---|---|
| `models.py` | 数据模型：风速记录、安全阈值、异常工况、冲突证据 |
| `verification_engine.py` | 核心核验引擎：导入校验、阈值比对、冲突检测、导出一致性 |
| `workflow.py` | 三步工作流：手写备注导入 → 教练补看安全阈值表 → 异常工况表更新 |
| `error_messages.py` | 人话错误提示，不吐内部字段名 |
| `test_verification.py` | 正常材料 / 错口径材料 / 补录材料全场景测试 |

## 三步工作流

1. **第一步：手写巡检备注导入** — 导入现场师傅的手写巡检备注，系统自动检测方向标识异常（如负方向写成"向左"）、重复导入、数据合法性等问题。遇到方向不明或备注与阈值表冲突时，**不会自动归为正常**，而是标记为待复核。
2. **第二步：教练补看安全阈值表** — 训练教练老唐对照安全阈值表，对系统列出的冲突证据逐一确认或驳回。所有冲突处理完毕后才可进入第三步。
3. **第三步：异常工况表更新** — 系统根据已确认的数据重新核验阈值、匹配异常工况与历史记录、补录数据重算，最终更新异常工况表。

## 运行测试

```bash
python3 -m unittest test_verification -v
```

## 常见返工 — 老唐说

各位，我是训练教练老唐，干隧道风速压差核验好几年了，返工最多的就那几个坑，我把它们写出来，你们以后少踩。

### 一、负方向被现场师傅写成"向左"

这是返工第一大户。现场师傅手写巡检备注的时候，负方向不写"负向"，写"向左"。你说他错吧，他在现场看着确实是往左吹的；你说他对吧，系统只认"正向"和"负向"，"向左"是什么方向？系统没法自动判断。

**先查哪里：** 第一步导入的时候，系统会报"负方向被现场师傅写成了向左，已标记为待复核"这个错。你别急着把它改成负向或者正向，**先看手写巡检备注的原文**——师傅是只写了"向左"两个字，还是写了"负方向，风向向左"？如果是后者，那方向就是负向，"向左"只是补充描述，你确认采纳就行；如果只有"向左"两个字，那你自己判断不了，**留给实验老师复核**，别替业务同事拍板。

**再改哪里：** 在第二步教练补看安全阈值表的时候，系统会把冲突列出来——手写备注写的是"向左(手写)"，阈值表定义的是"负向(阈值表)"。你看清楚以后，确认就点"确认采纳"，觉得不对就点"驳回"，**系统不会替你自动选**。

### 二、重复导入

赶时间的时候最容易犯这个错——同一条记录提交了两遍。系统会报"这条记录之前已经导入过了，请检查是否重复提交"，还会告诉你记录编号。你看看是不是同一条，是的话直接跳过就行。

### 三、补录后忘重算

现场补录了新数据，导入之后忘了点重算，结果异常工况表里还是旧数据，导出来跟实际对不上。系统会提醒"补录数据后需要重新计算风速压差"，**补录完了第一件事就是重算**，别急着导出。

### 四、导出数据不一致

导出的时候发现跟核验结果对不上，多半是因为中间改了数据但没保存，或者补录后没重算就导出了。系统会报"导出数据与当前核验结果不一致"，你回去重算一遍再导出就好。

### 五、手写巡检备注和安全阈值表打架

备注里写的风速、方向跟安全阈值表的规定互相矛盾。这个**不要自动拍板**，系统会列出冲突证据——手写值是多少、阈值表值是多少、哪个字段不一致——你看完了选"确认采纳"或"驳回"。宁可多花两分钟确认，也别让系统自动帮你选了结果回头发现选错了。

---

> 老唐总结：遇到"向左"先查原文再定方向，补录完了一定要重算，导出前对一遍一致性，冲突别自动选。记住这四条，返工少一半。
