# 外呼任务记录重复呼叫拦截 CLI

自动检测外呼任务中的重复号码，避免重复呼叫。

## 功能特性

- ✅ **跨任务重复号码识别
- ✅ 号码归一化（自动去除 +86、空格、横杠等格式）
- ✅ 空号/无效号码拦截
- ✅ 黑名单号码拦截
- ✅ 输出文件结构稳定，便于 diff 比较规则变更影响
- ✅ 异常场景自动检测（缺列、文件损坏等）

## 业务规则

### 1. 号码归一化

自动处理以下号码格式：
- `+86 138 1234 5678` → `13812345678
- `86-139-3333-4444` → `13933334444
- `136 5555 6666` → `13655556666

### 2. 空号拦截

检测并拦截以下情况：
- 空字符串、空格
- `-`、`0`、`无`、`未填写`等标记
- 号码位数不足 7 位

### 3. 黑名单拦截

预设黑名单号码（可在代码中配置）：
- `13800000000
- `13900000000
- `17000000000

### 4. 跨任务去重

同一号码出现在多个任务文件中时，**仅保留首次出现的记录**，后续出现的全部拦截。

```bash
# 处理正常样本
node src/index.js ./samples/normal ./output

node src/index.js --help
```

## 输入格式

CSV 文件必需包含以下列：

| 列名 | 说明 | 示例 |
|------|------|------|
| 任务编号 | 任务唯一标识 | T001 |
| 任务名称 | 任务名称 | 新客回访 |
| 客户姓名 | 客户姓名 | 张三 |
| 手机号码 | 客户手机号 | 13812345678 |
| 外呼时间 | 计划外呼时间 | 2024-01-15 09:00:00 |

## 输出文件

处理完成后，输出目录会生成一个时间戳命名的子目录，包含以下文件：

| 文件名 | 说明 |
|--------|------|
| `可外呼-号码清单.csv | 通过所有检查，可正常外呼的号码 |
| `已拦截-跨任务重复号码.csv | 因跨任务重复被拦截的号码 |
| `已拦截-空号无效号码.csv | 因空号或格式无效被拦截的号码 |
| `已拦截-黑名单号码.csv | 因在黑名单中被拦截的号码 |
| `处理结果报告.txt | 详细的处理统计报告 |

### 拦截记录额外列

所有拦截文件都会包含以下额外列，便于追踪和 diff 比较：

| 列名 | 说明 |
|------|------|
| `_sourceFile` | 记录来源文件名 |
| `_拦截原因` | 拦截原因分类 |
| `_拦截详情` | 具体拦截说明 |

## 规则变更验证

当业务规则变更时（如：调整空号判断逻辑、增减黑名单号码、修改归一化规则），可以通过比较两次运行结果的 diff 来确认变更影响：

```bash
# 第一次运行（规则变更前）
node src/index.js ./samples/normal ./output/before

# 修改规则后第二次运行
node src/index.js ./samples/normal ./output/after

# 比较差异
diff -r ./output/before ./output/after
```

输出文件中的 `_拦截原因` 和 `_拦截详情` 列可以清晰展示规则变更的具体影响。

## 配置修改

如需修改配置，编辑 `src/index.js` 中的 `CONFIG` 对象：

```javascript
const CONFIG = {
  REQUIRED_COLUMNS: ['任务编号', '任务名称', '客户姓名', '手机号码', '外呼时间'],
  BLACKLIST_NUMBERS: new Set(['13800000000', '13900000000', '17000000000']),
  EMPTY_NUMBER_PATTERNS: ['', '-', '0', '无', '未填写', '暂无']
};
```
