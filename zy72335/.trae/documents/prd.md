## 1. 产品概述

模拟退火座位安排复核系统——面向竞赛教练唐老师和活动负责人的座位安排数据管理与复核平台。解决问卷原始行与边界值说明互相补台又互相打架的问题，确保数据导入去重、变更可追溯、报告可读、可视化可回溯。

- 目标用户：竞赛教练（唐老师）、活动负责人、复核人员
- 核心价值：先服务真实复核——谁改了什么、为什么改、改完影响哪些结果，都要说清楚

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 竞赛教练（唐老师） | 登录 | 导入问卷原始行、编辑边界值说明、修改备注、查看计算明细与报告 |
| 活动负责人 | 登录 | 复核百分数/小数混出项、确认或退回异常数据、查看报告 |
| 复核人员 | 登录 | 浏览全量数据、追溯变更历史、查看可视化与溯源 |

### 2.2 功能模块

1. **数据导入页**：问卷原始行导入（含去重）、边界值说明关联、导入日志
2. **数据复核页**：计算明细展示、百分数与小数混出标记、三步流程状态追踪
3. **变更历史页**：字段级 diff 展示、改前改后对比、变更影响范围
4. **可视化展示页**：3D 座位图与图表展示、点击溯源至原始行/边界值说明
5. **报告生成页**：人可读的座位安排报告、保留原因说明、缺料提示、下一步行动指引

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入页 | 问卷原始行导入 | 支持粘贴/上传原始行，自动按唯一键去重，重复导入不翻倍；显示去重统计 |

## 3. 核心流程

### 3.1 数据导入与去重流程

竞赛教练唐老师导入问卷原始行 → 系统按唯一键检测重复 → 已有条目跳过、新条目入库 → 关联已有边界值说明 → 缺失边界值的条目标红 → 唐老师补录边界值说明 → 触发计算明细更新

### 3.2 三步复核流程

第一步：问卷原始行第一次导入完成 → 第二步：唐老师补看边界值说明（补录/确认） → 第三步：计算明细更新 → 遇到百分数和小数混着出现时标记"待复核"，留给活动负责人复核

### 3.3 变更追踪流程

唐老师修改备注 → 系统记录字段级变更（改前值、改后值、时间、操作人、原因） → 自动计算影响范围 → 变更历史可查

```mermaid
flowchart TD
    "A[唐老师导入问卷原始行]" --> "B[系统按唯一键去重]"
    "B" --> "C{是否有重复？}"
    "C" -->|"是"| "D[跳过重复，记录日志]"
    "C" -->|"否"| "E[新条目入库]"
    "D" --> "F[关联边界值说明]"
    "E" --> "F"
    "F" --> "G{边界值说明是否完整？}"
    "G" -->|"否"| "H[标红缺失项，通知唐老师补录]"
    "G" -->|"是"| "I[计算明细更新]"
    "H" --> "J[唐老师补看/补录边界值说明]"
    "J" --> "I"
    "I" --> "K{百分数/小数混出？}"
    "K" -->|"是"| "L[标记待复核，留给活动负责人]"
    "K" -->|"否"| "M[数据正常，进入可视化/报告]"
    "L" --> "N[活动负责人复核确认/退回]"
    "N" --> "M"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深靛蓝 (#1e293b) 搭配琥珀色 (#f59e0b) 强调色，传达专业与紧迫感
- 辅助色：翡翠绿 (#10b981) 表示已完成、玫红 (#f43f5e) 表示异常/待复核
- 按钮风格：圆角微凸（rounded-lg + shadow-sm），主操作用实色填充，次操作用描边
- 字体：标题用 Noto Serif SC（衬线，权威感），正文用 Noto Sans SC（无衬线，易读）
- 布局风格：左侧导航 + 右侧内容区，顶部面包屑导航
- 图标风格：Lucide 图标库，线性风格

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 数据导入页 | 问卷原始行导入 | 卡片式布局，拖拽上传区，导入结果统计徽章，去重日志折叠面板 |
| 数据导入页 | 边界值说明关联 | 表格行内编辑，缺失项红色虚线边框，补录弹窗 |
| 数据复核页 | 三步流程状态 | 顶部步骤条（Steps），当前步骤高亮，已完成步骤打勾 |
| 数据复核页 | 百分数/小数混出标记 | 表格行黄色条纹背景 + 玫红标签"待复核"，悬停显示详情 |
| 数据复核页 | 计算明细 | 每条明细卡片：保留原因标签、缺料清单列表、行动按钮（找负责人/找唐老师） |
| 变更历史页 | 字段级 diff | 双栏对比视图，删除内容红底删除线，新增内容绿底 |
| 变更历史页 | 变更影响范围 | 右侧边栏展示受影响的计算结果和报告片段 |
| 可视化展示页 | 3D 座位图 | Three.js 3D 场景，座位可点击，右侧浮出溯源面板 |
| 可视化展示页 | 图表展示 | Recharts 交互图表，点击数据点弹出溯源弹窗 |
| 报告生成页 | 人可读报告 | 类文档排版，段落分明，保留原因用高亮引用块，缺料用警示框 |

### 4.3 响应式设计

- 桌面优先设计，确保复核对表格和 3D 场景的操作空间
- 平板适配：3D 场景可切换为简化图表，表格横向可滚动
- 移动端：仅支持基础浏览和审批操作

### 4.4 3D 场景指引

- 环境：浅灰地面 + 柔和天顶光，模拟考场氛围
- 灯光：主方向光（偏暖白）+ 环境光（冷白），座位 hover 时聚光灯效果
- 相机：斜 45° 俯视，支持旋转/缩放，点击座位时相机聚焦
- 交互：座位点击 → 高亮 → 右侧面板显示原始行和边界值说明
- 后处理：微弱辉光（Bloom），座位选中时边缘发光
