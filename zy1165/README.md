# 限流实验台 (Rate Limiter Lab)

一个用于比较令牌桶(Token Bucket)和漏桶(Leaky Bucket)限流算法的本地实验平台。

## 功能特性

### 核心功能
- **流量配置**: 支持配置突刺流量和稳定流量两段式流量模型
- **算法对比**: 同时运行令牌桶和漏桶两种限流算法
- **实时模拟**: 模拟每个请求的放行、排队、拒绝、超时状态
- **可视化展示**:
  - 时间轴视图: 追踪请求处理过程
  - 桶水位/令牌数变化图
  - 延迟分布直方图
  - 放行率对比图表

### 导出功能
- 导出 Markdown 格式报告
- 导出 JSON 格式数据

### 预设配置
- 推荐配置示例
- 坏配置示例（用于学习常见错误）

## 算法说明

### 令牌桶 (Token Bucket)

**工作原理**:
- 以恒定速率向桶中添加令牌
- 请求需要获取令牌才能被处理
- 桶有最大容量，满了之后不再添加新令牌
- 没有令牌时，请求被直接拒绝

**特点**:
- 允许一定程度的突发流量
- 长期来看流量被平滑
- 适用于需要允许突发的场景

**配置参数**:
- `tokenRate`: 令牌生成速率（个/秒）
- `tokenCapacity`: 桶容量

### 漏桶 (Leaky Bucket)

**工作原理**:
- 请求像水一样流入桶中
- 水以恒定速率从桶底漏出（被处理）
- 桶满时，新的请求要么排队要么被拒绝
- 队列满时，请求被拒绝
- 排队超时的请求被丢弃

**特点**:
- 输出速率严格恒定
- 可以进行流量整形
- 适用于需要严格控制输出的场景

**配置参数**:
- `leakRate`: 漏出速率（个/秒）
- `leakCapacity`: 桶容量
- `queueLength`: 队列长度
- `timeout`: 超时时间（毫秒）

## 使用指南

### 1. 配置实验参数

在页面上方的配置区域设置以下参数：

**流量配置**:
- **总请求数**: 实验中模拟的请求总数
- **突刺持续时间**: 高流量阶段的持续时间（秒）
- **突刺请求速率**: 高流量阶段的每秒请求数
- **平稳期持续时间**: 正常流量阶段的持续时间（秒）
- **平稳期请求速率**: 正常流量阶段的每秒请求数
- **随机种子**: 用于复现相同的流量模式（可选）

**令牌桶配置**:
- **令牌生成速率**: 每秒生成的令牌数
- **桶容量**: 令牌桶的最大容量

**漏桶配置**:
- **漏出速率**: 每秒处理的请求数
- **桶容量**: 漏桶的最大容量
- **队列长度**: 等待队列的最大长度
- **超时时间**: 请求在队列中等待的超时时间（毫秒）

### 2. 运行实验

点击"运行实验"按钮，系统将同时模拟令牌桶和漏桶两种算法处理相同的流量。

### 3. 分析结果

实验结果包含以下几个部分：

**放行率对比**: 直观比较两种算法的请求放行率

**时间轴视图**: 追踪请求在不同时间点的处理状态

**桶水位/令牌数变化**: 观察算法内部状态的变化

**延迟分布**: 分析请求处理延迟的分布情况

**详细统计表格**: 完整的统计数据对比

### 4. 导出报告

点击"导出 Markdown"或"导出 JSON"按钮保存实验结果。

## 坏配置示例

项目包含一些常见的错误配置示例，用于学习：

1. **令牌生成速率过低**: 令牌生成远低于请求速率，导致大量拒绝
2. **桶容量过小**: 无法缓冲突发流量
3. **队列过长导致超时**: 队列大但漏出慢，请求超时
4. **零队列长度**: 漏桶无法缓冲任何溢出
5. **超时时间过短**: 排队请求几乎立即超时

点击页面上的"加载坏配置示例"按钮可以体验这些配置。
