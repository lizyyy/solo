# 手机维修工单管理系统

一个专为小型手机维修店设计的本地工单管理系统，替代微信群和纸本登记，让工单管理更高效。

## 功能特性

- 📋 **看板视图**：按状态分组显示工单，一目了然
- 🔍 **搜索筛选**：支持按客户姓名、手机号、设备型号、工单号搜索
- 🔄 **状态流转**：严格的状态流程控制，防止随意跳状态
- 📊 **CSV 导入导出**：方便迁移旧数据和月底对账
- 💾 **持久化存储**：使用 SQLite 数据库，数据安全可靠
- 📝 **操作记录**：完整的状态变更历史追踪

### 状态流转规则

```
待检测 → 报价中 → 维修中 → 待取机 → 已完成
    ↘         ↘         ↘         ↘
              已取消（任何阶段都可取消）
```

- **待检测**：新创建的工单，等待检测
- **报价中**：检测完成，等待客户确认报价
- **维修中**：客户确认报价，开始维修
- **待取机**：维修完成，等待客户取机
- **已完成**：客户已取机，工单结束
- **已取消**：工单被取消，无法恢复

## 技术栈

- **后端**：Node.js + Express + SQLite (better-sqlite3)
- **前端**：原生 HTML + CSS + JavaScript
- **数据持久化**：SQLite 数据库文件存储在 `data/` 目录

## 快速开始

### 环境要求

- Node.js 16.0 或更高版本
- npm 或 yarn 包管理器

### 安装步骤

1. **安装依赖**

```bash
npm install
```

2. **启动服务**

```bash
npm start
```

或者使用开发模式（自动重启）：

```bash
npm run dev
```

3. **访问系统**

打开浏览器访问：http://localhost:3000

### 默认数据

首次启动时会自动创建示例数据，包含 5 个不同状态的工单，方便你体验完整流程。

## 完整流程演示

### 1. 新建工单

1. 点击右上角 **"+ 新建工单"** 按钮
2. 填写以下信息：
   - 客户姓名：必填
   - 手机号：必填（11位手机号格式）
   - 设备型号：必填
   - 故障描述：必填
   - 报价金额：可选（默认为 0）
   - 维修配件：可选
   - 预计取机时间：可选
   - 备注：可选
3. 点击 **"创建工单"**

新工单会出现在 **"待检测"** 列。

### 2. 状态流转

#### 待检测 → 报价中
1. 点击工单卡片打开详情
2. 在状态操作区域点击 **"开始报价"**
3. 系统自动记录状态变更原因

#### 报价中 → 维修中
1. 打开工单详情
2. 点击 **"确认报价，开始维修"**
3. 状态变更为 **"维修中"**

#### 维修中 → 待取机
1. 打开工单详情
2. 点击 **"维修完成，待取机"**
3. 状态变更为 **"待取机"**

#### 待取机 → 已完成
1. 打开工单详情
2. 点击 **"客户已取机，完成"**
3. 工单状态变为 **"已完成"**，流程结束

### 3. 取消工单

任何阶段都可以取消工单：
1. 打开工单详情
2. 点击 **"取消工单"** 按钮
3. 在弹出的对话框中输入取消原因
4. 点击确定

已取消的工单无法重新打开。

### 4. 编辑工单

1. 打开工单详情
2. 点击 **"✏️ 编辑工单"** 按钮
3. 修改需要更新的信息
4. 点击 **"保存修改"**

### 5. 搜索和筛选

- **搜索框**：输入客户姓名、手机号、设备型号或工单号进行搜索
- **状态筛选**：从下拉框选择特定状态查看
- **日期范围**：选择开始和结束日期筛选

### 6. CSV 导入导出

#### 导出数据
1. 点击右上角 **"📊 数据导入导出"**
2. 点击 **"导出所有工单"** 按钮
3. 系统会下载当前筛选条件下的所有工单

#### 导入数据
1. 点击 **"下载导入模板"** 获取 CSV 模板
2. 按照模板格式填写数据
3. 点击 **"选择 CSV 文件"** 上传文件
4. 系统会自动导入并显示成功/失败数量

## API 接口

### 工单接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/tickets | 获取工单列表 |
| GET | /api/tickets/:id | 获取工单详情 |
| POST | /api/tickets | 创建新工单 |
| PUT | /api/tickets/:id | 更新工单信息 |
| POST | /api/tickets/:id/status | 变更工单状态 |

### CSV 接口

| 方法 | 路径 | 描述 |
|------|------|------|
| GET | /api/csv/export | 导出工单数据 |
| POST | /api/csv/import | 导入工单数据 |
| GET | /api/csv/template | 下载导入模板 |

### 查询参数

GET /api/tickets 支持以下查询参数：

- `status`：按状态筛选
- `search`：搜索关键词（姓名、电话、设备、工单号）
- `start_date`：开始日期
- `end_date`：结束日期

## 常见问题

### 1. 服务启动失败

检查 Node.js 版本是否 >= 16.0：

```bash
node -v
```

### 2. 无法访问页面

确认端口 3000 未被其他程序占用，或者修改 `server/app.js` 中的 `PORT` 变量。

### 3. 状态按钮为什么是灰色？

系统有严格的状态流转规则，灰色按钮表示当前状态不允许执行该操作。将鼠标悬停在按钮上可以看到具体原因。

### 4. 数据存储在哪里？

所有数据都存储在项目目录下的 `data/tickets.db` SQLite 数据库文件中。

## 自定义配置

### 修改端口

编辑 `server/app.js`，修改第 10 行：

```javascript
const PORT = process.env.PORT || 3000;
```

或者在启动时设置环境变量：

```bash
PORT=8080 npm start
```

### 添加新状态

编辑 `server/database.js` 中的 `STATUS_FLOW` 对象，添加新的状态和允许的流转关系。
