# 🔧 问题修复记录

## 修复的问题

### 1. `server/routes/students.js` 语法错误
**问题**：第11行的 Promise 闭合语法错误，导致模块加载失败
**修复**：修正 `});` 为正确的 JavaScript 语法

### 2. 前端转班/退费弹窗无法加载报名记录
**问题**：`client/src/pages/Students.js` 直接使用列表页的学员数据，但列表接口只返回报名数量统计，不包含详细报名记录
**修复**：
- 点击转班/退费按钮时先调用学员详情接口 `/api/students/:id` 获取完整报名记录
- 弹窗选择框现在可以正确显示该学员的所有活跃报名记录
- 增加了加载状态提示

### 3. 操作历史事件查询优化
**问题**：`/api/events` 接口只能按 entity_id 查询，无法获取与学员相关的所有事件（包括报名、转班、退费等）
**修复**：
- 增加 `student_id` 查询参数
- 查询该学员本人及该学员所有报名记录相关的事件
- 学员时间线现在可以正确显示完整的操作历史（报名→转班→退费）
