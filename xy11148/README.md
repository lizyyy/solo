# 高校实验室实验试剂盘点 CLI

高校实验室实验试剂盘点统一口径工具，支持数据校验、异常分类统计、数据清洗功能。

## 功能特性

- ✅ **统一校验规则**：确保不同人员处理同一批数据获得一致结果
- 📊 **四类异常分类统计**：
  - 浓度单位异常（大小写不规范、单位未知）
  - 空瓶未报废（空瓶标记与剩余量不一致）
  - 可复跑输出（日期格式、数字格式错误，可自动修正）
  - 格式错误（缺列、重复行、编码异常等）
- 📝 **异常详情**：保留来源文件和行号，运营同事不用打开源码也能修数据
- 🔧 **数据清洗**：自动修正可复跑的格式错误

## 安装依赖

```bash
pip install -r requirements.txt
```

## 使用方法

### 1. 校验试剂盘点数据

```bash
python reagent_inventory.py validate sample_with_errors.csv
```

输出到文件：

```bash
python reagent_inventory.py validate sample_with_errors.csv -o report.txt
```

### 2. 清洗试剂盘点数据

```bash
python reagent_inventory.py clean sample_with_errors.csv cleaned_output.csv
```

## 运行测试

pytest test_reagent_inventory.py -v

### 测试覆盖场景

| 测试场景 | 说明 |
|---------|------|
| 缺列测试 | 验证缺少必要列时的错误检测 |
| 重复行测试 | 验证相同试剂编号+批号+存放位置的重复检测 |
| 编码异常测试 | 验证文件编码错误时的处理 |
| 浓度单位异常测试 | 验证大小写不规范、无效单位的检测 |
| 空瓶未报废测试 | 验证空瓶标记与剩余量不一致的检测 |
| 可复跑输出测试 | 验证日期格式、数字格式错误的检测 |
| 部分失败混合测试 | 验证同时存在多种错误时的正确统计 |
| 完美数据测试 | 验证正确数据时无错误报告 |
| 统计计数测试 | 验证各类异常的统计正确性 |
| 报告生成测试 | 验证报告格式和内容 |
| 文件行号测试 | 验证每个异常都包含来源文件和行号 |

## 常见问题

**Q: 如何快速定位错误？**
A: 异常报告中会明确显示文件路径和行号，直接打开CSV到对应行修改即可。

**Q: 什么是"可复跑输出"？**
A: 指日期格式（如2025/12/31应改为2025-12-31）、数字格式错误，这类错误可以通过`clean`命令自动修正。

**Q: 为什么浓度单位要区分大小写？**
A: 实验室规范要求单位符号必须使用正确的大小写（如mol/L而非mol/l），避免歧义。
