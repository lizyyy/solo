# 温室虫害诱捕分析器 - 验收步骤

## 📋 系统概述

本系统用于自动校验温室诱捕板虫害统计数据的质量，帮助业务人员快速发现数据问题。

**核心功能：**
- ✅ 样本导入作为入口
- ✅ 虫害计数作为关键校验
- ✅ 规则分级作为判断依据
- ✅ 带理由的分析结果

---

## 🔍 环境准备（只做一次）

### 步骤1：确认Python环境

请按以下方式操作：

**Windows用户：**
- 打开「开始菜单」→ 搜索「cmd」→ 点击「命令提示符」
- 复制下面的命令，右键粘贴到黑色窗口中，然后按回车键：

```cmd
python --version
```

**Mac用户：**
- 打开「启动台」→ 搜索「终端」→ 点击「终端」
- 复制下面的命令，按「Command + V」粘贴，然后按回车键：

```bash
python3 --version
```

**预期结果：** 应该看到类似 `Python 3.8.10` 或更高版本。
如果提示找不到命令，请先安装Python 3.8+版本。

### 步骤2：安装依赖

进入项目目录（替换为你的实际路径）：

```bash
cd greenhouse_pest_analyzer
```

安装所需的Python包：

```bash
pip install -r requirements.txt
```

或者Mac/Linux用户可能需要用：

```bash
pip3 install -r requirements.txt
```

**预期结果：** 显示 `Successfully installed PyYAML-x.x`

## 🚀 验收用例1：运行全部样例数据（推荐首次运行）

### 预期覆盖的场景
- ✅ 正常数据（3条）
- ✅ 重复记录异常（REC_0003与REC_0001重复）
- ✅ 缺少必填字段（REC_0004缺少诱捕板编号和板类型）
- ✅ 人工改幅度过大（REC_0005粉虱从10→63，差异530%）
- ✅ 多轮复核不一致（REC_0006第一轮60 vs 第二轮70）
- ✅ 日期无效（REC_0007日期为2030-01-01）
- ✅ 负数计数（REC_0008红蜘蛛AI计数为-5）
- ✅ 计数异常偏高（REC_0009蚜虫AI计数350>200阈值）
- ✅ 非预期虫害类型（REC_0010包含"未知甲虫"）
- ✅ 计数总和不一致（REC_0011分项和为45，记录为50）

### 执行命令

进入项目目录后，执行：

```bash
python run.py
```

或者Mac/Linux：

```bash
python3 run.py
```

### 检查输出结果

运行后，你会看到：

#### 1. 控制台输出（重要！请对照检查）

**批量统计概览部分应该显示：**
```
总记录数: 12
有效记录数: x   （有严重问题的会被标记为无效）
无效记录数: x

质量评级分布:
  - A级: x条  （正常记录）
  - B级: x条  （有小问题）
  - C级: x条  （有明显问题）
  - D级: x条  （不合格）
```

#### 2. 逐记录分析详情（关键验证点）

**REC_0001（正常数据）应该显示：**
- 评分约90-100分，A级
- 无严重问题
- 可能有轻微的计数差异提醒（蚜虫27 vs 28，差异约3.5%，<5%不扣分）

**REC_0003（重复记录）应该显示：**
- 🔴 严重错误：「重复记录」
- 扣分80分
- 详细说明：原始记录REC_0001，重复记录REC_0003

**REC_0004（缺少必填字段）应该显示：**
- 🔴 严重错误：「缺少必填字段」
- 扣分100分
- 具体指出缺少：诱捕板编号、板类型

**REC_0005（人工改幅过大）应该显示：**
- 🟠 高优先级问题：「人工改幅度过大」
- 粉虱：AI=10 → 最终=63，差异530% > 50%
- 扣分45分
- 蚜虫：AI=20 → 最终=22，差异10%，中优先级扣分20

**REC_0006（复核不一致）应该显示：**
- 🟡 中优先级问题：「多轮复核计数不一致」
- 第一轮=60，第二轮=70，差异16.7% > 10%
- 扣分30分

**REC_0007（无效日期）应该显示：**
- 🔴 严重错误：「日期无效」
- 原因：2030-01-01是未来日期
- 扣分90分

**REC_0008（负数计数）应该显示：**
- 🔴 严重错误：「负数计数」
- 红蜘蛛AI计数=-5
- 扣分100分

**REC_0009（计数偏高）应该显示：**
- 🟠 高优先级问题：「计数异常偏高」
- AI计数350 > 阈值200
- 扣分50分
- 同时可能有「人工改幅过大」（350→45，差异约87%）

**REC_0010（未知虫害）应该显示：**
- 🟡 中优先级问题：「非预期虫害类型」
- 检测到：未知甲虫
- 扣分25分

**REC_0011（总和不一致）应该显示：**
- 🟠 高优先级问题：「计数总和不一致」
- 分项和=45，记录=50
- 扣分60分

#### 3. 报告文件

运行结束后，在 `reports/` 目录下会生成两个文件：
- `analysis_report_xxx.txt`：文本报告，方便阅读
- `analysis_report_xxx.json`：JSON报告，方便程序处理

用以下命令查看报告目录：

```bash
ls reports/
```

## ❓ 常见问题

### Q1: 提示找不到模块 'src'？

**解决：** 确保你在 `greenhouse_pest_analyzer` 目录下运行命令。

```bash
cd /你的路径/greenhouse_pest_analyzer
python run.py
```

### Q2: 提示没有安装 PyYAML？

**解决：** 运行：

```bash
pip install PyYAML
```

### Q3: 报告在哪里？

**回答：** 报告自动保存在 `greenhouse_pest_analyzer/reports/` 目录下。
你可以用以下命令打开文件管理器查看：

Mac：
```bash
open reports/
```

Windows：
```cmd
explorer reports\
```

### Q4: 如何修改规则？

**回答：** 编辑 `config/rules.yaml` 文件，然后重新运行程序。
比如可以修改：
- `alert_thresholds`：虫害预警阈值
- `validation_rules`：各等级的扣分分数
- `pest_types`：添加新的虫害类型
