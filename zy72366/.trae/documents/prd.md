## 1. 产品概述

冰箱门封漏热检测管理系统——为维修师傅和实验老师提供温度校准记录的导入、审阅、异常处理全流程工具，确保导出明细、页面展示和接口返回读同一份结果数据，所有人工改动留有审计痕迹，边界规则写在代码和文档里，不靠口头约定。

- 目标用户：维修师傅（如老岑）、实验老师（复核角色）
- 核心价值：消除"一处显示异常、另一处消失"的数据不一致；让温度校准记录的原始行号、人工改动、处理状态可追溯；常见错口径（如负方向被写成向左）有明确判断、修改、回滚规则

## 2. 核心功能

### 2.1 用户角色

| 角色 | 说明 | 核心权限 |
|------|------|----------|
| 维修师傅 | 现场操作人员（如老岑） | 导入温度校准记录、补看传感器编号、标记异常状态 |
| 实验老师 | 复核人员 | 审阅异常工况、确认或驳回人工改动、回滚记录 |

### 2.2 功能模块

1. **温度校准记录导入页**：CSV/Excel 导入、原始行号保留、方向字段自动校验、错口径标记
2. **传感器编号审阅页**：维修师傅补看传感器编号、查看原始记录与改动历史、标记待复核
3. **异常工况表页**：异常条目汇总、状态流转（待复核→已确认→已回滚）、实验老师复核操作、全量导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 温度校准记录导入页 | 文件上传区 | 支持CSV/Excel导入，解析后展示预览表，保留原始行号 |
| 温度校准记录导入页 | 方向校验区 | 自动检测"向左""向右"等非标准方向值，标记为待复核，不自动归正常 |
| 温度校准记录导入页 | 导入确认区 | 确认导入后写入统一数据源，后续页面和接口均读此源 |
| 传感器编号审阅页 | 记录列表区 | 展示已导入记录，高亮方向异常条目，显示原始行号与当前状态 |
| 传感器编号审阅页 | 改动历史区 | 每条记录的改动时间线：谁改了什么、改前改后值、改动原因 |
| 传感器编号审阅页 | 状态操作区 | 维修师傅标记"待复核"，实验老师可"确认"或"驳回回滚" |
| 异常工况表页 | 异常汇总区 | 按异常类型分组展示，含方向异常、传感器编号缺失、温度超限等 |
| 异常工况表页 | 状态流转区 | 待复核→已确认/已回滚，每步记录操作人和时间 |
| 异常工况表页 | 导出区 | 导出明细与页面展示一致，读同一份数据源 |

## 3. 核心流程

维修师傅老岑导入温度校准记录 → 系统自动校验方向字段（如"向左"标记为异常但不自动修正）→ 老岑补看传感器编号，确认无误或标记待复核 → 异常工况表自动更新 → 实验老师复核异常条目，确认或驳回回滚 → 全程审计日志可追溯。

```mermaid
flowchart TD
    "A[维修师傅导入温度校准记录]" --> "B[系统自动校验方向字段]"
    "B" --> "C{方向字段是否标准?}"
    "C" --> "|标准|" D"正常入库"
    "C" --> "|非标准(如'向左')|" E"标记为'待复核'，不自动修正"
    "D" --> "F[维修师傅补看传感器编号]"
    "E" --> "F"
    "F" --> "G{传感器编号是否确认?}"
    "G" --> "|确认|" H"更新异常工况表"
    "G" --> "|有疑问|" I"标记'待复核'"
    "H" --> "J[实验老师复核]"
    "I" --> "J"
    "J" --> "K{复核结果}"
    "K" --> "|确认|" L"状态→已确认"
    "K" --> "|驳回|" M"回滚到原始值，状态→已回滚"
    "L" --> "N[审计日志记录]"
    "M" --> "N"
```

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深蓝灰 (#1B2A4A) 搭配警示橙 (#E8792B)，传递工业检测的严谨感
- 辅助色：状态绿 (#2D9B5A)、待复核黄 (#D4A72C)、回滚红 (#C4463A)
- 按钮风格：圆角微凸（2px border-radius），主操作深蓝灰底白字，警示操作橙底白字
- 字体：标题用 Noto Sans SC Bold，正文用 Noto Sans SC Regular，数据表格用 JetBrains Mono 等宽
- 布局：左侧固定导航栏 + 右侧内容区，表格为主的数据展示
- 图标：线性图标风格，配合状态色

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 温度校准记录导入页 | 文件上传区 | 拖拽上传框，支持区域高亮，蓝色虚线边框 |
| 温度校准记录导入页 | 方向校验区 | 表格行内黄底高亮异常字段，悬浮提示标准值参考 |
| 温度校准记录导入页 | 导入确认区 | 底部固定操作栏，显示检测统计（正常/异常/待复核数） |
| 传感器编号审阅页 | 记录列表区 | 条纹表格，异常行左侧橙色竖线标识，行号列灰色小字 |
| 传感器编号审阅页 | 改动历史区 | 右侧抽屉面板，时间线样式展示改动记录 |
| 传感器编号审阅页 | 状态操作区 | 行内下拉选择状态，实验老师操作区加确认弹窗 |
| 异常工况表页 | 异常汇总区 | 顶部统计卡片（待复核/已确认/已回滚数量），下方按类型分组的可折叠表格 |
| 异常工况表页 | 状态流转区 | 行内状态标签（彩色圆角胶囊），点击弹出流转详情 |
| 异常工况表页 | 导出区 | 右上角导出按钮，下拉选择导出范围（全部/仅异常） |

### 4.3 响应式

桌面优先设计，最小支持 1280px 宽度。表格区域在窄屏下横向滚动，导航栏折叠为汉堡菜单。
