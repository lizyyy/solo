我想做一个给小型设计工作室用的“样品借还和拍摄排期”全栈 Web 应用。我们现在靠群消息记录客户借走了哪些样品、什么时候归还、哪天要拍摄，经常漏还或者撞档。请你从零搭一个可运行的项目：

前端需要有样品库、借还登记、拍摄日历/列表、逾期提醒四个主要页面，可以新增样品，给样品设置编号、尺码/颜色、当前状态；登记借出时要选择客户、借出时间、预计归还时间和关联拍摄任务；归还后状态要自动恢复。拍摄排期里要能看到每个任务关联了哪些样品，如果样品已经借出或档期冲突，要在创建时拦截并提示原因。首页要有今天拍摄、即将到期、逾期未还的统计和列表。

后端请提供 API 和本地持久化，不要只写死前端假数据。借出、归还、创建拍摄任务这些操作要走统一的校验逻辑，避免同一个样品同时被两个客户或两个拍摄任务占用。需要支持导入一批样品 CSV，也能导出当前样品和借还记录。请写清楚启动方式，项目结构要清晰，能本地跑起来验证核心流程。
