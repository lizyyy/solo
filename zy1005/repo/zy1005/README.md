# 线下分享会报名系统

一个可以本地运行的全栈 Web 应用，用于管理线下分享会的报名、候补和签到。

## 功能特性

### 管理员功能
- ✅ 创建活动（设置标题、时间、总名额、签到码、可选场次）
- ✅ 按场次查看报名列表（已报名、候补、已签到、未签到）
- ✅ 现场签到（需输入签到码）
- ✅ 批量签到功能
- ✅ 取消报名（自动递补候补用户）
- ✅ 导出 CSV 报名名单
- ✅ 删除活动（含所有报名记录）

### 参与者功能
- ✅ 浏览活动列表（显示名额状态）
- ✅ 填写姓名、手机号后四位报名
- ✅ 选择场次报名（如果活动有场次）
- ✅ 名额满时自动进入候补队列
- ✅ 查看自己的报名记录
- ✅ 取消报名

### 技术特性
- ✅ 数据持久化（SQLite 文件存储）
- ✅ 刷新/重启服务数据不丢失
- ✅ 移动端友好的响应式布局
- ✅ 清晰的错误提示
- ✅ 空状态显示
- ✅ 候补自动递补机制

## 技术栈

- **后端**: Node.js + Express + better-sqlite3
- **前端**: 原生 HTML + CSS + JavaScript（无需构建工具）
- **数据库**: SQLite（文件存储，无需额外安装）

## 安装

### 前置要求
- Node.js >= 14.0.0
- npm 或 yarn

### 安装步骤

1. 进入项目目录：
```bash
cd zy1005
```

2. 安装依赖：
```bash
npm install
```

## 启动服务

### 生产模式
```bash
npm start
```

### 开发模式（自动重启）
```bash
npm run dev
```

服务启动后，访问以下地址：
- **用户端（报名）**: http://localhost:3000
- **管理端**: http://localhost:3000/admin

## API 接口说明

### 活动管理

#### 获取活动列表
```
GET /api/events
```

#### 获取活动详情
```
GET /api/events/:id
```

#### 创建活动
```
POST /api/events
Content-Type: application/json

{
  "title": "活动标题",
  "event_date": "2024-05-01 14:00",
  "total_slots": 50,
  "check_in_code": "123456",
  "sessions": ["上午场", "下午场"]  // 可选
}
```

#### 删除活动
```
DELETE /api/events/:id
```

### 报名管理

#### 获取报名列表
```
GET /api/events/:id/registrations?session=xxx&status=registered
```

#### 用户报名
```
POST /api/events/:id/register
Content-Type: application/json

{
  "name": "张三",
  "phone_last_four": "1234",
  "session": "上午场"  // 可选
}
```

#### 取消报名
```
POST /api/registrations/:id/cancel
```

### 签到管理

#### 单个用户签到
```
POST /api/registrations/:id/checkin
Content-Type: application/json

{
  "check_in_code": "123456"
}
```

#### 批量签到
```
POST /api/events/:id/checkin-batch
Content-Type: application/json

{
  "check_in_code": "123456",
  "registration_ids": [1, 2, 3]
}
```

### 导出功能

#### 导出 CSV
```
GET /api/events/:id/export?session=xxx
```

## 测试核心流程

### 1. 管理员创建活动

1. 打开管理端：http://localhost:3000/admin
2. 点击"创建新活动"
3. 填写表单：
   - 活动标题：测试分享会
   - 活动时间：选择未来的日期时间
   - 总名额：2
   - 签到码：123456
   - 场次（可选）：
     ```
     上午场 10:00
     下午场 14:00
     ```
4. 点击"创建活动"

### 2. 用户报名（名额充足时）

1. 打开用户端：http://localhost:3000
2. 点击"查看详情"进入活动
3. 点击"立即报名"
4. 填写：
   - 姓名：用户A
   - 手机号后四位：1111
   - 选择场次：上午场
5. 点击"确认报名"
6. 显示"报名成功"

### 3. 候补报名（名额已满时）

1. 继续报名第二个用户：
   - 姓名：用户B
   - 手机号后四位：2222
   - 选择场次：上午场
   - 显示"报名成功"

2. 报名第三个用户（此时名额已满）：
   - 姓名：用户C
   - 手机号后四位：3333
   - 选择场次：上午场
   - 显示"名额已满，您已进入候补队列，当前位置：第 1 位"

### 4. 取消报名 → 候补自动递补

1. 用户端点击"查看我的报名"
2. 找到用户A的报名记录
3. 点击"取消报名"
4. 确认后，显示"取消报名成功。候补用户 用户C 已自动递补"

### 5. 现场签到

1. 管理员打开管理端：http://localhost:3000/admin
2. 点击活动的"查看详情"
3. 选择"上午场"场次（如果有）
4. 在"已报名"标签页找到用户B
5. 点击"签到"按钮
6. 输入签到码：123456
7. 显示"签到成功"，用户B状态变为"已签到"

### 6. 批量签到

1. 在活动详情页，点击"批量签到"
2. 输入签到码：123456
3. 确认后，所有"已报名"状态的用户都会被标记为"已签到"

### 7. 导出 CSV

1. 在活动详情页，点击"导出当前场次"或在活动列表点击"导出CSV"
2. 浏览器会下载一个 CSV 文件
3. 用 Excel 或 Numbers 打开查看

## 数据持久化说明

数据存储在项目目录下的 `data/events.db` 文件中。

- SQLite 数据库文件会在首次启动时自动创建
- 刷新浏览器页面不会丢失数据
- 重启 Node 服务不会丢失数据
- 删除 `data/` 目录会清空所有数据

## 移动端使用

本系统完全支持移动端：

- **用户端**: 响应式设计，手机浏览器访问 http://你的IP:3000
- **管理端**: 同样支持移动端，现场签到时可用手机操作

### 局域网访问

如果需要让其他设备（如参与者的手机）访问：

1. 查看你的局域网 IP：
   - Mac: 在终端运行 `ifconfig | grep inet`
   - Windows: 在 cmd 运行 `ipconfig`

2. 找到类似 `192.168.1.100` 的 IP 地址

3. 让其他设备访问：`http://192.168.1.100:3000`

## 注意事项

1. **签到码安全**: 签到码用于管理员现场签到，请勿提前透露给参与者
2. **数据备份**: 定期备份 `data/events.db` 文件
3. **端口占用**: 如果 3000 端口被占用，可以设置环境变量 `PORT=8080 npm start`
4. **重复报名**: 同一活动中，姓名 + 手机号后四位唯一，防止重复报名

## 常见问题

### Q: 重启服务后数据会丢失吗？
A: 不会，数据存储在 `data/events.db` SQLite 文件中。

### Q: 可以有多个管理员同时操作吗？
A: 可以，但建议现场签到时只有一个管理员操作，避免并发冲突。

### Q: 如何修改已创建的活动？
A: 当前版本不支持修改活动信息，如需修改可删除后重新创建（会丢失报名数据）。

### Q: 导出的 CSV 中文乱码怎么办？
A: 导出时已添加 BOM 头，Excel 应该能正确识别。如果仍有问题，可尝试用 WPS 或 Numbers 打开，或在 Excel 中使用"数据 → 从文本/CSV 导入"功能。
