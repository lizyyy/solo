# 管弦乐谱缺页检查系统 产品需求文档

## 1. 产品概述
本系统为乐团管理员提供专业的乐谱发放检查工具，解决人工核对乐谱时容易出现的缺页、漏发修订页、声部混淆等问题。系统支持多源数据独立导入、智能校验、异常标记、变更对比和报告导出，确保乐谱发放流程可追溯、可审计。

### 1.1 产品目标
- 消除页码跳号、修订页未发、声部混淆等常见错误
- 建立完整的发放记录和签收留痕机制，便于追责
- 支持数据修改前后的对比，直观展示变更影响
- 生成可下载的检查报告，满足文档存档需求

### 1.2 目标用户
- 乐团管理员/谱务人员
- 声部首席/乐队长
- 乐团行政管理人员

## 2. 核心功能

### 2.1 用户角色
| 角色 | 描述 | 核心权限 |
|------|------|----------|
| 管理员 | 乐团谱务/行政人员 | 导入数据、执行检查、查看报告、导出结果 |
| 查看者 | 声部首席/乐队长 | 查看本声部检查结果、确认签收 |

### 2.2 功能模块
1. **数据导入中心**：声部谱、页码规则、乐手名单、修订页、发放记录独立导入
2. **检查执行面板**：页码校验、声部分发核对、修订页追踪、综合异常汇总
3. **签收管理**：乐手签收确认、未签收提醒、签收记录查询
4. **变更对比**：数据版本管理、前后结果差异对比
5. **报告导出**：多格式报告生成、自定义报告内容

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|---------|---------|----------|
| 工作台 | 仪表盘 | 检查概览、异常统计、快速操作入口 |
| 数据导入 | 导入管理 | 6类数据源独立上传、数据预览、版本保存 |
| 检查执行 | 页码校验 | 自动检测跳号、缺页、重复页码 |
| 检查执行 | 声部分发 | 核对每个乐手应得乐谱与实际发放 |
| 检查执行 | 修订追踪 | 检查修订页是否完整发放到相关声部 |
| 检查执行 | 异常汇总 | 所有异常分类展示、状态标记、批量处理 |
| 签收管理 | 签收台 | 乐手签收确认、批量签收、签收记录 |
| 变更对比 | 版本对比 | 选择两个版本、差异高亮展示、变更统计 |
| 报告导出 | 报告生成 | 自定义报告内容、PDF/Excel导出、打印预览 |

## 3. 核心流程

### 3.1 主操作流程
```mermaid
flowchart LR
    A["开始"] --> B["导入各类数据源"]
    B --> C["保存数据版本"]
    C --> D["执行综合检查"]
    D --> E{"有异常?"}
    E -->|是| F["查看异常详情"]
    F --> G["修正原始数据"]
    G --> C
    E -->|否| H["生成检查报告"]
    H --> I["乐手签收确认"]
    I --> J["归档完成"]
```

### 3.2 异常检查流程
1. **页码校验**：读取每页页码 → 检查连续性 → 标记跳号/缺页/重复
2. **声部分发检查**：按声部匹配乐手 → 核对发放数量 → 标记漏发/多发
3. **修订页追踪**：匹配修订页适用声部 → 检查发放状态 → 标记未发放
4. **综合判定**：汇总所有异常 → 分类统计 → 生成处理建议

## 4. 用户界面设计

### 4.1 设计风格
- **整体调性**：专业严谨、行政办公风格，体现工具的可信度
- **主色调**：深蓝色(#1e3a5f) - 代表专业、可靠
- **辅助色**：
  - 成功绿(#10b981) - 正常状态
  - 警告橙(#f59e0b) - 待确认
  - 错误红(#ef4444) - 异常状态
  - 信息蓝(#3b82f6) - 提示信息
- **字体**：标题使用 Noto Serif SC（衬线体，正式感），正文使用 Noto Sans SC（无衬线，易读性）
- **布局**：左侧导航 + 顶部工具栏 + 主内容区的经典管理后台布局
- **卡片风格**：圆角8px，浅阴影，清晰的分区感

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素描述 |
|---------|---------|-----------|
| 工作台 | 仪表盘 | 统计卡片网格、异常类型饼图、最近检查记录列表 |
| 数据导入 | 导入管理 | 6个独立导入卡片，每个包含上传区域、预览表格、版本信息 |
| 检查执行 | 检查面板 | 三栏布局：左侧声部树、中间检查结果列表、右侧异常详情 |
| 异常汇总 | 异常面板 | 状态标签筛选、异常分类Tab、批量操作工具栏 |
| 变更对比 | 对比视图 | 左右分屏对比，差异行高亮显示，变更统计摘要 |
| 报告导出 | 报告页面 | 报告配置表单项、实时预览区、导出按钮组 |

### 4.3 响应式设计
- **桌面优先**：针对1920×1080分辨率优化，支持1440px以上大屏
- **平板适配**：左侧导航可收起，内容区自适应宽度
- **操作优化**：重要按钮保持足够触控区域，表格支持横向滚动

### 4.4 交互与动画
- 数据导入时的进度条动画
- 异常项展开/收起的平滑过渡
- 版本切换时的淡入淡出效果
- 表格行悬停高亮、选中状态清晰
- 提交操作后的成功/失败toast提示

## 5. 非功能需求

### 5.1 性能要求
- 单页加载时间 ≤ 2秒
- 1000条数据的检查计算 ≤ 1秒
- 报告生成时间 ≤ 3秒

### 5.2 数据安全
- 所有数据本地存储，不上传服务器
- 支持数据导出备份
- 版本历史可追溯、不可篡改

### 5.3 易用性
- 提供样例数据一键导入功能
- 异常项有明确的状态说明和处理建议
- 关键操作有二次确认
- 支持键盘快捷键提高效率
