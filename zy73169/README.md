# 曲线拟合参数回放工具

教研编辑阿宁的好帮手，支持数据溯源、异常检测、变更对比、口径一致性校验。

---

## 三步操作指南

1. **创建会话** - 填写名称和操作人，点击「创建会话」
2. **录入数据** - 左侧「录入学生草稿」支持粘贴表格/JSON 或表单录入
3. **查看结果** - 选择拟合方法，点击「开始拟合」

---

## 坏材料来了该看哪里？

> 学生草稿拿到手多半不齐整，按以下顺序排查，负责人看图表前先扫一遍：

### 🔴 红色重复样本
- **看哪里**：顶部异常统计卡片的「重复样本」数字
- **怎么追**：点击数字或列表中的红色样本 → 右侧「原始来源」查看学生ID、草稿ID、文件名、行号
- **怎么办**：确认为重复后可「撤回样本」，或人工修正后「确认有效」

### 🟠 橙色离群值
- **看哪里**：图表上偏大/偏小的橙色点，或列表中的橙色异常标记
- **怎么追**：点击数据点 → 右侧「原始来源」核对是否录入错误
- **怎么办**：对照原始草稿「修正数值」，填写修正说明，或直接「撤回样本」

### 🔵 蓝色边界样本
- **看哪里**：样本量 < 5 个时全部标记为蓝色，或数据两端 10% 区域
- **怎么追**：查看「异常标记」描述，确认是否需要补充数据
- **怎么办**：补充更多样本，或人工确认边界点有效

### ⚪ 灰色已撤回
- **看哪里**：图表上的空心灰圈，或列表中的灰色样本
- **怎么追**：点击「撤回复算」对比撤回前后 R² 和系数变化
- **怎么办**：若撤回后拟合质量下降，可重新「确认有效」放回数据

## 评审会复盘怎么查？

> 负责人要看到人工确认前后到底改了什么：

1. **变更对比**：点击已确认的绿色样本 → 右侧「人工确认对比」面板
   - 原始值 → 修正值的变化
   - 状态变更（raw → dirty → confirmed）
   - 操作人、时间、备注一目了然

2. **口径校验**：点击「校验口径」→ 自动检查
   - ✅ 图表拟合值 vs 明细当前值
   - ⚠️ 原始值 vs 修正值（仅警告，不影响口径）
   - ❌ 样本排除状态不一致（需处理）

3. **完整链路**：每个样本从录入到确认的所有修改
   - 点击「变更历史」查看完整操作记录
   - 包括每次修改的原因、操作人、时间戳
