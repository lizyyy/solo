# 无人机救援航线挑战

航模社训练策略游戏 - 在有限电量里规划最优航线，绕开禁飞区、风区和山脊，把药包送到多个求救点。

## 项目简介

这是一个为学校航模社设计的本地策略小游戏，帮助社员训练航线规划能力。游戏强调：

- **电量管理**：有限电量，需要精准计算能耗
- **障碍规避**：禁飞区、山脊不可穿越
- **风向影响**：顺风省电，逆风耗电
- **返航安全**：最怕路线看着能飞其实返航电量不够

## 核心功能

### 1. 关卡系统
- **预置关卡**：初级、中级、高级三个训练关卡
- **地图编辑器**：可创建自定义关卡
- **元素类型**：
  - 🏠 起点/终点（必须返回）
  - 🆘 求救点（必须全部送达）
  - 🚫 禁飞区（不可穿越）
  - 💨 风区（影响能耗，有方向和风速）
  - ⛰️ 山脊（不可穿越）

### 2. 物理与能耗计算
- **基础能耗**：每单位距离消耗基础电量
- **风向影响**：
  - 顺风：减少能耗（最多节省100%）
  - 逆风：增加能耗（最多增加100%）
  - 侧风：能耗不变或轻微增加
- **实时估算**：规划路径时实时显示预估能耗

### 3. 路径校验
- **碰撞检测**：实时检查路径是否穿越禁飞区或山脊
- **越界判定**：检查路径点是否超出地图边界
- **电量安全**：计算总能耗是否超过可用电量
- **返航检查**：确保最后能安全返回起点
- **求救点覆盖**：检查是否所有求救点都被覆盖

### 4. 撤销重规划
- **撤销/重做**：支持最多50步的路径撤销和重做
- **路径历史**：自动保存每一步修改
- **快捷键**：Ctrl+Z 撤销，Ctrl+Shift+Z 重做

### 5. 评分与回放
- **评分系统**：
  - 完成任务：基础分 500
  - 求救点：每个 +100 分
  - 剩余电量：最多 +200 分
  - 路径效率：最优路径奖励
- **等级**：S(≥900) > A(≥750) > B(≥600) > C(≥400) > D(≥200) > F(<200)
- **回放功能**：成功完成后可回放整个飞行过程

### 6. 本地存储与导出
- **自动保存**：所有关卡和战绩保存在浏览器 LocalStorage
- **历史记录**：保存最近100次游戏记录
- **JSON导出**：
  - 回放数据导出为JSON
  - 包含完整路径、能耗、事件记录
  - 可用于事后分析和复盘

## 游戏规则详解

### 目标
在有限电量内，规划一条从起点出发，经过所有求救点，最后返回起点的最优航线。

### 胜负条件
**胜利条件**：
1. 路径从起点开始
2. 经过所有求救点
3. 最后返回起点
4. 总能耗 ≤ 初始电量
5. 不穿越任何禁飞区或山脊

**失败条件**：
- 验证时发现任何违规
- 执行过程中电量耗尽

### 能耗计算

#### 基础公式
```
能耗 = 距离 × 基础能耗系数
```

#### 风向影响计算
```
风向影响 = 风向角度差 × 风速系数

如果角度差 ≤ 90度（顺风）：
  影响 = -(1 - 角度差/90) × 风速
  
如果角度差 > 90度（逆风）：
  影响 = ((角度差 - 90)/90) × 风速

实际能耗 = 基础能耗 × (1 + 风向影响)
```

#### 示例
- 顺风飞行（角度差0度）：能耗 = 基础能耗 × (1 - 1×风速)
- 侧风飞行（角度差90度）：能耗 = 基础能耗 × 1
- 逆风飞行（角度差180度）：能耗 = 基础能耗 × (1 + 1×风速)

### 评分细则

```
总分 = 基础分 + 求救点奖励 + 电量奖励 + 效率奖励 - 惩罚
```

| 项目 | 分数 | 说明 |
|------|------|------|
| 任务完成 | +500 | 成功完成所有要求 |
| 求救点 | +100/个 | 每个送达的求救点 |
| 剩余电量 | 最多+200 | 剩余电量比例 × 200 |
| 路径效率 | 最多+200 | 基于最优路径比较 |
| 惩罚 | -20/次 | 擦边碰撞等警告 |

**等级划分**：
- S级：≥ 900 分
- A级：≥ 750 分
- B级：≥ 600 分
- C级：≥ 400 分
- D级：≥ 200 分
- F级：< 200 分（或任务失败）

## 技术栈

- **前端**：纯原生 JavaScript (ES6+)
- **渲染**：HTML5 Canvas
- **存储**：浏览器 LocalStorage
- **样式**：纯 CSS3，响应式设计
- **依赖**：无外部依赖库

## 浏览器兼容性

- ✅ Chrome 61+ (推荐)
- ✅ Firefox 60+
- ✅ Safari 11.1+
- ✅ Edge 79+

**注意**：需要支持 ES6 模块（`<script type="module">`）

## 已知限制

1. **本地文件限制**：某些浏览器（如Chrome）对从 file:// 协议加载的ES6模块有限制。建议使用HTTP服务器。

2. **单文件存储**：所有数据存储在浏览器LocalStorage中，清除浏览器数据会丢失。

3. **单用户设计**：当前版本为单用户设计，没有多用户或云同步功能。

4. **固定坐标系**：地图使用像素坐标系，没有缩放或平移功能。

## 故障排除

### 问题1：打开后是空白页面

**原因**：浏览器不支持从本地文件加载ES6模块。

**解决**：
1. 使用HTTP服务器方式运行（见"快速开始"）
2. 或者使用Firefox浏览器，它对本地文件的限制较少

### 问题2：关卡无法保存

**原因**：浏览器禁用了LocalStorage或处于隐私模式。

**解决**：
1. 检查浏览器是否允许网站存储数据
2. 退出隐私/无痕模式
3. 检查LocalStorage配额（通常为5MB）

### 问题3：游戏卡顿

**原因**：可能是Canvas渲染性能问题。

**解决**：
1. 使用性能更好的浏览器
2. 关闭其他占用GPU的应用
3. 简化关卡（减少多边形顶点数）

### 问题4：测试失败

**原因**：可能是代码修改引入的bug。

**解决**：
1. 检查控制台的具体错误信息
2. 确保使用原始代码重新测试
3. 联系开发者报告问题
