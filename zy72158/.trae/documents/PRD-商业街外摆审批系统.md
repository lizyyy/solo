## 1. 产品概述

商业街外摆审批管理系统，用于市政设计师处理商业街外摆点位的审批流程。解决人工核对GIS点位、审批记录分散、交接困难等问题，实现数据导入、智能归并、人工复核、导出公示的全流程管理。

- **核心目标**：将街道表格、现场照片、审批记录等多源数据统一管理，通过智能判断减少人工核对工作量
- **目标用户**：市政设计师（如老曹）、审批人员、交接人员
- **核心价值**：审批留痕、数据可追溯、交接顺畅、判断结果透明化

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 市政设计师 | 本地系统登录 | 数据导入、审批处理、人工复核、导出清单 |
| 交接人员 | 本地系统登录 | 查看审批记录、追溯来源、导出报告 |

### 2.2 功能模块
1. **数据导入页面**：多源数据导入（街道表格、现场照片、审批记录、GIS点位）
2. **审批工作台**：点位列表、智能归并结果、人工复核操作
3. **地图标注页**：GIS点位可视化、外摆位置标注、冲突展示
4. **报告导出页**：公示清单生成、审批报告导出、数据汇总

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入 | 文件上传区 | 支持Excel/CSV表格、图片批量上传 |
| 数据导入 | 数据预览 | 导入数据格式校验、脏数据提示 |
| 审批工作台 | 点位列表 | 待审批、已审批、需复核分类展示 |
| 审批工作台 | 智能判断 | 容量超限检测、时间段冲突检测、结果用人话说明 |
| 审批工作台 | 人工复核 | 添加备注、调整状态、保留处理时间 |
| 地图标注 | GIS点位图 | 外摆位置标注、冲突区域高亮 |
| 报告导出 | 公示清单 | 导出可打印的审批公示清单 |
| 报告导出 | 审批报告 | 包含来源追溯、处理时间、判断依据的完整报告 |

## 3. 核心流程

用户从数据导入开始，系统自动进行智能归并和冲突检测，设计师在工作台进行人工复核，可查看地图标注确认点位，最后导出公示清单和审批报告。所有操作保留原始来源和处理时间，便于后续交接。

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：政务蓝 `#1976d2`，代表专业、可信
- **辅助色**：警示橙 `#f57c00`（待复核）、成功绿 `#388e3c`（已通过）、错误红 `#d32f2f`（冲突）
- **中性色**：深灰 `#37474f`、中灰 `#78909c`、浅灰 `#eceff1`
- **按钮风格**：直角微圆角（4px）、政务风、扁平简洁
- **字体**：系统无衬线字体，清晰易读
- **布局**：顶部导航 + 左侧菜单 + 主内容区，典型后台管理系统布局
- **图标风格**：线性图标，简洁专业

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 审批工作台 | 统计卡片 | 四色统计卡片、数字醒目、hover动效 |
| 审批工作台 | 点位列表 | 表格列表、状态标签、操作按钮 |
| 地图标注 | 地图区域 | 可交互点位、冲突区域高亮 |
| 报告导出 | 预览区域 | 实时预览、导出选项 |

### 4.3 响应式
- 桌面端优先设计（1280px+）
- 平板自适应（768px-1280px）
- 移动端精简展示（<768px）

### 4.4 样例数据要求
- **顺利通过记录**：1条，容量合规、时间段无冲突
- **需人工确认记录**：1条，时间段边缘冲突，需人工判断
- **GIS补录旧口径**：1条，从历史GIS点位导入的旧数据
