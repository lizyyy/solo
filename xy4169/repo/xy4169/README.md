# 标本流转防错台

医院病理科冰冻切片值班员工具，用于管理手术标本的全流程追踪，防止多部位混淆、缺照片、超时未回报等问题。

## 功能特点

- **标本登记**：支持扫码/手工登记标本信息
- **时间线追踪**：完整记录标本从登记到放行的所有操作
- **异常检测**：自动检测多部位混淆、缺照片、超时等异常
- **状态管理**：规范化的标本流转状态机
- **复核放行**：支持复核签名和放行操作
- **延迟提醒**：支持标记延迟和调整截止时间
- **数据导出**：Markdown 交接单、CSV 异常表、JSON 审计包
- **本地存储**：使用 SQLite 本地数据库，无需联网

## 快速开始

### 1. 启动应用

```bash
python main.py
```

### 2. 导入示例数据

首次运行时，可以通过菜单导入示例数据体验功能：

1. 点击菜单 **数据** → **导入示例数据**
2. 确认后系统会生成 8 位患者、约 10 例标本（包含多部位、超时等异常场景）
3. 观察标本列表、异常清单和状态统计

### 3. 手工登记新标本

1. 在顶部扫码输入框输入标本号，或点击 **登记** 按钮
2. 填写患者姓名、部位等必填信息
3. 勾选已收到的材料（标本袋、申请单 CSV）
4. 点击确认登记

### 4. 标本流程操作

选择一个标本后，可通过工具栏按钮操作：

| 按钮 | 功能 | 适用状态 |
|------|------|----------|
| 拍照确认 | 记录照片数量，标记拍照完成 | 已登记/处理中 |
| 复核签名 | 输入复核人姓名，完成复核 | 待复核 |
| 放行 | 确认标本最终放行 | 已复核 |
| 标记延迟 | 输入延迟原因，调整截止时间 | 所有未完成状态 |
| 电话备注 | 记录术中电话沟通内容 | 所有状态 |

### 5. 查看异常

点击右侧 **异常清单** 标签页，查看系统自动检测到的异常：

- **缺照片**：标本已登记但照片数为 0
- **超时**：登记超过 30 分钟未放行
- **多部位混淆**：同一患者有多个不同部位标本
- **缺标本袋/CSV**：材料未确认收到
- **漏复核**：待复核但无签名

## 状态流转说明

标本状态流转遵循以下顺序：

```
已登记 → 处理中 → 待拍照 → 拍照完成 → 待复核 → 已复核 → 已放行
                                    ↘ 已延迟 ↗ （可从任意状态转入延迟）
```

各状态说明：

| 状态 | 说明 | 可执行操作 |
|------|------|------------|
| 已登记 | 标本刚录入系统 | 拍照、添加备注、标记延迟 |
| 处理中 | 正在进行标本处理 | 拍照确认、标记延迟 |
| 待拍照 | 等待拍照完成 | 拍照确认、标记延迟 |
| 拍照完成 | 照片已确认 | 提交复核、标记延迟 |
| 待复核 | 等待医师复核 | 复核签名、标记延迟 |
| 已复核 | 复核已完成 | 放行、标记延迟 |
| 已放行 | 标本已完成流程 | 无 |
| 已延迟 | 特殊标记状态 | 恢复流程 |

### 导出功能

#### 导出交接班 Markdown

菜单 **文件** → **导出交接班 Markdown...**

生成的文件包含：
- 交班时间
- 未完成标本数
- 每个标本的详细信息（患者、部位、状态、材料核对）
- 标本时间线事件
- 电话备注

#### 导出异常表 CSV

菜单 **文件** → **导出异常表 CSV...**

包含所有未解决的异常记录，可用于汇报或分析。

#### 导出审计包 JSON

菜单 **文件** → **导出审计包 JSON...**

包含完整的操作记录，用于审计目的：
- 所有标本信息
- 所有事件时间线
- 所有异常记录

## 常见问题

### Q: 扫码枪如何配置？

A: 本系统的扫码输入框支持标准键盘输入的扫码枪。扫码枪将条码内容模拟为键盘输入，最后加回车。系统捕获回车事件自动处理。

### Q: 超时时间如何设置？

A: 默认超时时间为 30 分钟（冰冻切片标准时限）。如需调整，可在标记延迟时手动设置新的截止时间。

### Q: 数据如何备份？

A: 直接复制 `.specimen_tracker/specimens.db` 文件即可。恢复时将备份文件放回原位置。

### Q: 如何修改示例数据的数量？

A: 编辑 `specimen_tracker/sample_data.py` 中的 `populate_database` 函数调用，修改 `patient_count` 参数。
