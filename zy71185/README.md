# ✈️ 航食装车检查游戏

一个用于培训航食公司装车员的Canvas策略小游戏，重点模拟真实的装车检查规则。

## 🚀 启动方式

1. **直接打开**：双击 `index.html` 文件，在浏览器中即可运行
2. **本地服务器**（推荐）：
   ```bash
   # Python 3
   python3 -m http.server 8080
   
   # Node.js
   npx serve .
   ```
   然后访问 `http://localhost:8080`

## 🎮 游戏玩法

### 核心目标
将左侧的餐车正确拖拽到Canvas中对应的航班和舱位，确保：
- ✅ 航班匹配正确
- ✅ 舱位匹配正确
- ✅ 装车口匹配正确
- ✅ 冷藏餐车在规定时间内完成装车

### 操作说明
1. 从左侧**待装车餐车**列表中，用鼠标拖拽餐车
2. 将餐车放到中间Canvas区域对应航班的正确舱位位置
3. 确保所有餐车在时间结束前装车完毕

### 游戏界面
- **左侧面板**：待装车的餐车列表，显示餐车类型、所属航班、舱位、装车口和温层
- **中间Canvas**：航班可视化区域，显示航班号、装车口、目的地和各舱位
- **右侧面板**：航班详细信息和实时错误记录
- **顶部状态栏**：关卡、得分、剩余时间、错误次数

## ❌ 常见错误类型

### 1. 航班错配 (-30分)
- **原因**：将餐车装入错误的航班
- **示例**：CA1234航班的餐车装入了MU5678航班

### 2. 舱位错配 (-25分)
- **原因**：餐车舱位与目标航班舱位不匹配
- **示例**：头等舱餐车装入了只有经济舱的航班

### 3. 装车口错误 (-20分)
- **原因**：餐车装车口与航班装车口不一致
- **示例**：A1口的餐车装入了B1口的航班

### 4. 冷藏超时 (-50分)
- **常温餐车**：无时间限制
- **冷藏餐车**：45秒内必须装车
- **冷冻餐车**：30秒内必须装车
- **快速奖励**：在一半时间内完成冷藏餐车装车 +25分

## 🎬 功能特性

### 暂停/重开
- 点击「暂停」按钮可以暂停游戏
- 点击「重开」按钮可以重新开始当前关卡
- 点击「菜单」返回关卡选择界面

### 历史回放
游戏结束后点击「错误回放」可以：
- 自动播放所有操作记录
- 手动上一个/下一个查看详细操作
- 查看每一步的操作时间、餐车信息、目标航班和结果

### 报告导出
点击「导出报告」可以下载详细的检查报告，包含：
- 基本信息（关卡、时间、得分）
- 统计数据（正确数、错误数、超时数、准确率）
- 完整错误记录
- 操作日志
- 改进建议

## ⚠️ 边界案例

### 案例1：同航班号不同装车口
> **场景**：两个航班都是CA1234，但装车口分别是A1和A2
> **错误**：容易忽略装车口，导致装车口错误
> **注意**：装车口是重要的判断依据，必须严格匹配

### 案例2：多舱位航班
> **场景**：航班有经济舱和商务舱，但餐车是头等舱
> **错误**：只看航班号，忽略舱位类型
> **注意**：先确认目标航班是否有该舱位

### 案例3：冷藏餐车优先级
> **场景**：同时有常温、冷藏、冷冻三种餐车
> **错误**：先装常温餐车，导致冷冻/冷藏超时
> **策略**：优先处理冷冻（30s），再处理冷藏（45s），最后处理常温

### 案例4：舱位区域判断
> **场景**：拖拽到两个舱位的边界线上
> **规则**：系统根据Y坐标自动判断所属舱位（三等分）
> **技巧**：尽量拖到舱位区域的中间位置

### 案例5：时间结束判定
> **场景**：最后一个餐车正在拖拽时时间到
> **规则**：必须在时间结束前完成装车（松开鼠标）
> **策略**：预留足够时间，不要卡点操作

## 🎯 得分规则

| 行为 | 得分 |
|------|------|
| 正确装车 | +100 |
| 冷藏快速完成（剩余>50%时间） | +25 |
| 航班错配 | -30 |
| 舱位错配 | -25 |
| 装车口错误 | -20 |
| 冷藏超时 | -50 |

## 💡 游戏技巧

1. **先看右侧航班信息**，了解每个航班的舱位和装车口
2. **优先处理冷冻/冷藏餐车**，避免超时扣分
3. **核对三项信息**：航班号 + 舱位 + 装车口
4. **不要着急拖拽**，先在脑子里确认目标位置
5. **注意剩余时间**，最后30秒时间会变红闪烁
