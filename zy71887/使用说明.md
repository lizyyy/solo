# 碰撞动量守恒实验数据处理工具 - 实验室助教使用说明

## 快速开始

### 1. 安装

```bash
npm install
npm run build
```

### 2. 查看命令帮助

```bash
npm run dev -- --help
```

---

## 核心操作流程

### 第一步：准备数据文件

**生成样例文件（推荐）**
```bash
npm run dev -- sample
```

这会生成 `实验数据样例.xlsx`，直接按此格式填写即可。

**必填字段**
| 字段 | 单位 | 说明 |
|------|------|------|
| studentId | - | 学号 |
| studentName | - | 姓名 |
| experimentDate | YYYY-MM-DD | 实验日期 |
| ballMass | **kg** | 钢球质量（注意: 不是克!） |
| ballDiameter | **m** | 钢球直径（注意: 不是厘米!） |
| initialHeight | cm | 初始高度 |
| horizontalDisplacement | cm | 水平位移 |
| collisionDisplacement | cm | 碰撞位移 |

---

### 第二步：导入数据

```bash
npm run dev -- import 你的数据文件.xlsx -o "张助教" -r "第1批数据"
```

**导入时自动检测：**
- 新增记录 vs 更新记录（自动识别）
- 单位换算问题提示
- 数据格式错误

**重复导入说明**：
- 同一学生同一天的数据会自动更新覆盖
- 每次导入生成批次ID，可整体撤回

---

### 第三步：检查单位换算错误

**去哪看单位换算错？**

```bash
npm run dev -- check-units
```

**常见单位错误：**
- 钢球质量写了 `67`（克），应为 `0.067`（千克）
- 钢球直径写了 `2.5`（厘米），应为 `0.025`（米）

系统会自动提示换算建议，修正后重新导入即可。

---

### 第四步：查看异常和状态

**查看所有记录**
```bash
npm run dev -- list
```

**只看有异常的记录**
```bash
npm run dev -- list --has-anomalies
```

**查看单条记录详情（含异常解释）**
```bash
npm run dev -- show 记录ID --history
```

每条异常都包含：
- **问题描述**：出了什么错
- **原因解释**：为什么会这样
- **处理建议**：该怎么修正

---

### 第五步：批改

```bash
npm run dev -- grade 记录ID 85 "实验操作规范，数据合理" -o "李助教"
```

**批改历史自动保留：**
- 改过分的记录会保存之前的分数和意见
- 用 `show 记录ID --history` 可查看所有修改

---

### 导出前复核步骤

**导出实验批改表前怎么复核？**

1. **检查待处理记录**
   ```bash
   npm run dev -- list -s pending
   ```
   确保没有遗漏的异常记录。

2. **检查单位错误**
   ```bash
   npm run dev -- check-units
   ```
   确认所有单位问题已修正。

3. **查看操作历史（可选）**
   ```bash
   npm run dev -- history
   ```
   确认所有批改和修改都记录在案。

4. **导出批改表**
   ```bash
   npm run dev -- export -f xlsx --with-history
   ```

**导出文件包含3个工作表：**
1. **实验批改表**：所有学生的成绩和异常信息
2. **操作历史**：所有修改记录（可追溯）
3. **统计摘要**：总记录数、已批改数、平均分等

---

## 撤回/修正操作

**撤回整个导入批次**
```bash
npm run dev -- rollback 批次ID "发现数据有误，重新整理"
```

**查看所有批次**
```bash
npm run dev -- batches
```

---

## 数据存储位置

所有数据保存在 `data/` 目录：
- `records.json`：实验记录
- `history.json`：操作历史（永远保留，可审计）
- `batches.json`：导入批次记录
- `calibration.json`：标定表配置

---

## 常用命令速查

| 命令 | 功能 |
|------|------|
| `sample` | 生成样例文件 |
| `import 文件` | 导入数据 |
| `list` | 列出记录 |
| `show ID --history` | 查看详情和历史 |
| `grade ID 分数 意见` | 批改 |
| `check-units` | 检查单位错误 |
| `export` | 导出批改表 |
| `batches` | 查看导入批次 |
| `rollback 批次ID 原因` | 撤回批次 |
| `history` | 查看所有操作历史 |
