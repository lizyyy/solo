🔗 API 端点

POST /api/token/exchange
交换令牌交换 - 将用户令牌交换为目标服务的短期令牌
POST /api/token/validate
验证令牌 - 校验令牌有效性并返回详细信息
POST /api/token/revoke
撤销令牌 - 立即使指定令牌失效
GET /api/token/timeline/{entityId}
查询时间线 - 获取指定实体的完整事件时间线
GET /api/token/usage/token/{tokenValue}
令牌使用记录 - 查询指定令牌的所有使用记录
GET /api/token/diagnostic/token/{tokenValue}
令牌诊断报告 - 生成令牌的完整排查报告
GET /api/token/diagnostic/user/{userId}
用户诊断报告 - 生成用户的完整活动报告
GET /api/token/diagnostic/summary
系统诊断汇总 - 生成系统整体运行状态汇总

ExchangeScenario

使用记录

完整的操作审计记录

TimelineEvent

时间线事件

关键动作时间线追踪

💡 使用示例

# 令牌交换请求示例

POST /api/token/exchange
Content-Type: application/json

{
  "userToken": "eyJhbGciOiJIUzI1NiIs...",
  "sourceServiceId": "service-user",
  "targetServiceId": "service-order",
  "scenarioCode": "USER_TO_ORDER",
  "requestedScopes": "read",
  "expireMinutes": 15,
  "maxUseCount": 5
}
# 令牌验证请求示例

POST /api/token/validate
Content-Type: application/json

{
  "token": "eyJhbGciOiJIUzI1NiIs...",
  "serviceId": "service-order",
  "requiredScope": "read"
}
