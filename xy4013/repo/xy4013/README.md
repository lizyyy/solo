# 自习室预约和请假补签管理系统

一个小型自习室连锁的预约和请假补签管理工具，包含前台页面和后台API，使用SQLite本地数据库持久化。

## 功能特点

- 学员管理：录入学员信息
- 座位管理：管理自习室座位
- 套餐管理：管理学员购买的小时数套餐
- 预约管理：预约座位，冲突校验
- 请假补签：请假释放座位，生成补签额度
- 数据展示：今日座位板、学员余额列表、请假补签流水
- 数据导出：支持CSV导出
- 按日期筛选：支持按日期查看数据

## 技术栈

- 后端：Node.js + Express
- 数据库：SQLite3
- 前端：原生HTML/CSS/JavaScript

## 安装和启动

### 1. 安装依赖

```bash
npm install
```

### 2. 启动服务

```bash
npm start
```

服务将在 http://localhost:3000 启动

### 3. 访问系统

打开浏览器访问 http://localhost:3000

## 测试样例

以下是一组可以验证冲突校验/补签扣减的测试样例：

### 测试前置条件
1. 系统已启动
2. 已创建至少一个学员（ID: 1）
3. 已创建至少两个座位（ID: 1, 2）
4. 学员已购买至少10小时套餐

### 测试样例1：正常预约
- 操作：预约学员1在2026-05-02 10:00-12:00使用座位1
- 预期：预约成功，学员余额减少2小时

### 测试样例2：座位冲突校验
- 前置：已成功执行测试样例1
- 操作：尝试预约学员2（新创建）在2026-05-02 11:00-13:00使用座位1
- 预期：预约失败，提示"座位已被占用"

### 测试样例3：时间冲突校验（同一学员）
- 前置：已成功执行测试样例1
- 操作：尝试预约学员1在2026-05-02 09:00-11:00使用座位2
- 预期：预约失败，提示"学员已有预约冲突"

### 测试样例4：余额不足校验
- 前置：学员1余额为1小时
- 操作：尝试预约学员1在2026-05-03 10:00-13:00（3小时）使用座位1
- 预期：预约失败，提示"余额不足"

### 测试样例5：闭馆时间校验
- 操作：尝试预约学员1在2026-05-03 23:00-次日01:00使用座位1（假设闭馆时间为22:00）
- 预期：预约失败，提示"超出营业时间"

### 测试样例6：请假功能
- 前置：已成功执行测试样例1（预约学员1在2026-05-02 10:00-12:00使用座位1）
- 操作：学员1请假该预约
- 预期：
  1. 原预约被取消
  2. 座位1被释放
  3. 学员1获得2小时补签额度
  4. 生成一条请假记录

### 测试样例7：补签扣减功能
- 前置：已成功执行测试样例6（学员1有2小时补签额度）
- 操作：学员1使用补签额度预约2026-05-03 14:00-16:00使用座位1
- 预期：
  1. 预约成功
  2. 学员1的补签额度减少2小时
  3. 正常余额不变
  4. 生成一条补签记录

### 测试样例8：CSV导出
- 操作：点击"导出CSV"按钮（在任意数据页面）
- 预期：下载CSV文件，包含当前页面的所有数据

## API接口

### 学员管理
- GET /api/students - 获取所有学员
- POST /api/students - 创建新学员
- PUT /api/students/:id - 更新学员信息
- DELETE /api/students/:id - 删除学员

### 座位管理
- GET /api/seats - 获取所有座位
- POST /api/seats - 创建新座位
- PUT /api/seats/:id - 更新座位信息
- DELETE /api/seats/:id - 删除座位

### 套餐管理
- GET /api/packages - 获取所有套餐
- POST /api/packages - 创建新套餐
- PUT /api/packages/:id - 更新套餐信息
- DELETE /api/packages/:id - 删除套餐

### 预约管理
- GET /api/reservations - 获取所有预约（支持日期筛选）
- POST /api/reservations - 创建新预约（含冲突校验）
- PUT /api/reservations/:id - 更新预约信息
- DELETE /api/reservations/:id - 取消预约

### 请假补签管理
- GET /api/leave-records - 获取所有请假补签记录（支持日期筛选）
- POST /api/leaves - 申请请假
- POST /api/makeups - 使用补签额度预约

## 数据导出

系统支持以下数据的CSV导出：
- 学员余额列表
- 预约记录
- 请假补签流水

## 注意事项

1. 系统使用本地SQLite数据库，数据存储在`study_room.db`文件中
2. 营业时间默认为08:00-22:00，可在代码中调整
3. 首次运行时会自动创建数据库表和初始数据
