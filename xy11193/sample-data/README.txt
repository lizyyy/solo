企业内训组内训成绩汇总 - 样例数据说明

本目录包含企业内训成绩汇总的样例数据，用于测试 CLI 工具功能。

文件列表:
1. 技术部_2024Q1_培训记录.csv - 技术部正常培训记录
2. 市场部_2024Q1_培训记录.csv - 市场部正常培训记录（包含同名员工"张伟"）
3. 人力资源部_2024Q1_培训记录.csv - 人力资源部记录（包含部门调整情况）
4. 异常数据_复跑记录.csv - 包含各种异常数据：复跑标记、重测标记、空值数据
5. README.txt - 本说明文件（非CSV，会被自动跳过）

包含的异常场景:
- 同名员工：张伟同时出现在技术部和市场部
- 部门调整：王芳出现在技术部和人事部
- 可复跑输出：培训课程名称包含"(复跑)"、"(重测)"，或是否通过标记为"复跑"
- 数据异常：关键业务列为空（员工编号、员工姓名、培训课程）

使用方法:
  npm run dev -- ./sample-data/*.csv
  或
  npm run dev -- ./sample-data/*.csv -v
