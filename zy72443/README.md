# 音乐人直播打赏分账系统

> 解决录音师小段最怕的"临时补材料"问题，尤其是票务导出表已经确认、音频文件备注又冒出授权地区少写了一个城市的尴尬场景。

## ✨ 系统特性

- **🔍 智能检测**: 自动对比票务导出表与音频文件备注，标出授权地区缺失的城市
- **📝 可追溯**: 点击异常记录可直接回到原始票务数据和音频备注，不止是漂亮图表
- **👥 流程化**: 店长复核 → 录音师小段补录 → 课时核销单自动更新
- **📊 可视化**: 支持 CLI 命令行 + Web 小看板（含图表和3D展示）
- **🧾 人性化报告**: 课时核销单说明为什么被留下、缺什么材料、下一步找谁

## 🚀 快速开始（新人照 README 跑通）

### 1. 安装依赖

```bash
npm install
```

### 2. 一键运行完整演示（推荐）

```bash
npm run demo
```

这会自动完成：
1. ✅ 导入5条样例票务导出表
2. ✅ 导入对应的音频文件备注
3. ✅ 系统自动校验授权地区（会检测到3条异常！）
4. ✅ 生成课时核销单
5. ✅ 输出完整的分账报告

### 3. 走完完整三步流程

演示运行后，你可以按以下步骤操作，体验完整流程：

#### 第一步：查看所有票单和异常
```bash
npm run start:cli -- list-tickets
npm run start:cli -- list-anomalies
```

#### 第二步：查看某张票单详情（可追溯原始数据）
```bash
# 比如查看李南风的票单（这条有异常）
npm run start:cli -- detail TK20250601002
```

你会看到：
- 📄 票务导出表原始数据（授权地区：北京、上海）
- 🎵 音频文件备注（实际授权地区：北京、上海、**杭州** ← 多了一个！）
- 📝 课时核销单（已标记为"预留"，说明原因、缺什么、下一步找店长）
- ⚠️ 异常记录（原始值 vs 期望值对比）

#### 第三步：店长复核，转交给录音师小段
```bash
npm run start:cli -- manager-review TK20250601002 --action escalate --notes "请小段核对杭州地区授权"
```

#### 第四步：录音师小段补录音频备注
```bash
npm run start:cli -- engineer-fix TK20250601002 --cities "北京,上海,杭州" --remark "已确认杭州地区授权有效"
```

补录完成后，课时核销单会自动更新！

#### 第五步：店长再次复核通过
```bash
npm run start:cli -- manager-review TK20250601002 --action approve --notes "数据无误，确认核销"
```

#### 第六步：生成最终报告
```bash
npm run start:cli -- report
```

- 🎲 3D 旋转立方体展示分账流程
- 📋 课时核销单列表，点击可查看详情并追溯原始数据
- ⚠️ 异常记录一览
- 🖱️ 页面内可直接完成店长复核和录音师补录

## 🎯 核心流程说明

```
票务导出表导入
      ↓
系统自动校验授权地区
      ↓
  ┌───┴───┐
  │       │
正常    异常（授权地区少写城市）
  │       ↓
  │    标记为"预留" → 留给店长复核
  │       ↓
  │    店长选择：通过 / 转交录音师小段
  │       ↓
  │    录音师小段补录音频文件备注
  │       ↓
  │    课时核销单自动更新
  │       ↓
  └───────┘
      ↓
最终分账报告生成
```

## 📋 课时核销单字段说明

每条课时核销单会清晰说明：
- **为什么被留下**: `预留原因` 字段说明具体问题
- **还缺什么材料**: `缺材料` 字段列出需要补充的内容
- **下一步该找谁**: `下一步找` 字段明确责任人（店长/录音师小段）

## 🔧 可用命令

| 命令 | 说明 |
|------|------|
| `npm run demo` | 一键运行完整演示 |
| `npm run start:cli -- demo` | 同上 |
| `npm run start:cli -- list-tickets` | 列出所有票单 |
| `npm run start:cli -- detail <票单号>` | 查看票单详情（含原始数据追溯） |
| `npm run start:cli -- list-anomalies` | 列出所有异常 |
| `npm run start:cli -- manager-review <票单号>` | 模拟店长复核 |
| `npm run start:cli -- engineer-fix <票单号>` | 模拟录音师小段补录 |
| `npm run start:cli -- report` | 生成分账报告 |
| `npm run start:web` | 启动 Web 小看板 |

## 💡 设计亮点

1. **不只有漂亮画面**: 图表里的每一条异常，点击都能追溯到原始票务导出表和音频文件备注
2. **报告不冷冰冰**: 课时核销单不是简单的状态标记，而是告诉你为什么、缺什么、找谁
3. **异常不急着归正常**: 检测到授权地区少写城市时，先标记"预留"，留给店长复核，不自动跳过
4. **新人友好**: `npm run demo` 一键跑通，附带每一步的操作提示
