🚀 快速开始

  1. 准备项目目录

    确保您的播客节目文件夹按照以下命名规则组织：

    • tech_talk_* - 科技访谈节目
    • daily_news_* - 每日新闻节目
    • music_hour_* - 音乐时刻节目
  2. 使用命令行扫描

    打开终端，运行以下命令扫描您的项目目录：

    python cli.py check /path/to/your/projects
  3. 在Web界面查看结果

    启动Web服务器，在浏览器中查看详细检查结果：

    python cli.py web
  4. 确认修复并导出报告

    修复问题后，在Web界面或命令行中确认修复，然后导出交付报告。
