## 🔁 重跑 / 清数据方式

### 日常重跑（同一批数据再跑一遍）
直接点「🔍 开始碰撞预审」。

**去重机制：** 系统按**稳定问题标识**识别同一个异常，不会产生重复副本：
- 碰撞：按「构件A-ID + 构件B-ID」排序后拼接，A碰B 和 B碰A 算同一个
- 偏移：按「构件ID」，每个构件的偏移是唯一的
- 已标记「已处理」的问题：再跑预审只更新「最后发现时间」，**状态和人工备注保住不变**
- 未处理的问题：坐标、建议等信息会刷新到最新

### 再来一次完全新的预审（清空全部重来）
停掉服务（终端 Ctrl+C），删数据库文件再启动：

```bash
rm -f roof_drainage.db
python3 app.py
```

然后回到「试跑样例」重新导入。

### 现场真实文件怎么导
把甲方/分包发来的 CSV 直接点：
- 材料送审表类 → 「📋 导入送审表」上传
- BIM/设计院导的坐标 CSV → 「📐 导入模型坐标」上传
- 上传完点「🔍 开始碰撞预审」即可

**CSV 字段名前后不一致也没事**，系统已内置别名识别（材料编号/物料编码/料号…都会认成同列）。只要保住这几个关键列就行：
- 送审表：`材料编号` + `规格` + `图纸版本/版次`（去重依据，缺了会翻倍）
- 坐标表：`构件编号` + `X/Y坐标`（碰撞/偏移计算依据）

**材料导入去重规则：**
- 同 `料号 + 同规格 + 同版次 → 同一条，重复导入**不新增**
- 已「确认」状态 → 永不回退为「待预审」
- 人工备注 → 永不覆盖
- 只会同步更新：数量、供应商、图号、送审日期、复核人、来源文件等来源字段

## ⚠️ 不会漏的三件事

1. **坐标偏移不会被吞**：构件备注里写了「偏移 / offset」字样，会单独出现在「坐标偏移」Tab，有自己的处理建议 3 条，不会跟碰撞合并掉。
2. **重复导入不翻倍 + 人工备注保住**：同料号 + 同规格 + 同图号 = 同一条，再导只更新其他字段，不新增记录；弹窗写的「人工备注」永远不被冲掉。
3. **预审重跑不产生重复副本**：已处理的碰撞/偏移保持状态，只更新最后发现时间，不会一边保留已处理一边又冒出未处理副本。
