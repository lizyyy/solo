## 📸 截图06 — 送审材料 Tab（来源追溯 + 人工备注不覆盖）

位置：右侧面板第三个 Tab

对照项：
- [ ] 「来源文件」列能看到是哪张 CSV 哪版（V2.1 张工 / V2.2 王工）
- [ ] 同一条料号（如 WS-003）不同版次算两条，同版次重复导入不翻倍
- [ ] 每行「备注」按钮：弹窗输入的内容，**再次重复导入同 CSV 不会被覆盖**
- [ ] 状态列点「确认」后变绿色，再重跑碰撞预审也不会被重置回「待预审」
- [ ] 字段名前后不一也能识别：V2.1 写的「材料编号 / 送审日期 / 复核人」和 V2.2 写的「物料编码 / 报审日期 / 审核人」都会进同一列

## 🧪 验证重复导入不翻倍的 3 个检查点

1. 先加载 `材料送审表_V2.1` → 看统计卡片「送审记录」数（应为 10）
2. 再加载一次同一文件 → 提示「重复 X 条」，总数仍然是 10（不翻倍）
3. 对 WS-005 点「备注」写「现场看过 OK」→ 再导一次同文件 → 备注内容还在
