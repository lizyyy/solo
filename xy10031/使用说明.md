# 仓库盘点管理系统

一个功能完整的桌面应用，专为仓库盘点员设计，支持离线操作、数据同步、状态流转、审计日志等核心功能。

## 功能特性

### 1. 状态流转
完整的任务状态流转机制：
- `待处理` → `进行中` → `待审批` → `已通过/已拒绝`
- 非法状态流转被禁止（如直接从待处理到已通过）
- 每次状态变更都记录历史

### 2. 失败重试（同步机制）
- 所有更新操作进入同步队列
- 支持重试次数配置（默认5次）
- 失败项可手动重置和重试
- 完整的同步状态追踪

### 3. 日志记录
- 所有关键操作自动记录审计日志
- 支持按用户、模块、级别、时间筛选
- 可导出为Excel

### 4. 历史版本
- 库存变更历史（每次变更记录旧值、新值、原因）
- 任务状态变更历史
- 可追溯任何数据变更

### 5. 导入导出
- Excel/CSV 导出库存清单
- Excel 导出盘点记录
- Excel 导入库存（新增或更新）
- Excel 导出审计日志

### 6. 批量操作
- 批量更新库存
- 批量添加盘点记录
- 批量导入商品

### 7. 异常恢复
- 同步失败可重试
- 离线数据本地持久化
- 启动时自动检查待同步项

### 8. 权限区分
- **管理员**：用户管理、审批任务、全部功能
- **盘点员**：执行盘点任务、查看库存

## 技术架构

- **前端**: Electron + React + TypeScript + Ant Design
- **后端**: Node.js
- **数据库**: SQLite + Prisma ORM
- **测试**: Jest

## 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 初始化数据库
```bash
npx prisma migrate dev --name init
```

### 3. 导入种子数据
```bash
npm run seed
```

### 4. 运行开发模式
```bash
npm run dev
```

### 5. 运行测试
```bash
npm run test
```

## 典型业务流程

### 创建并执行盘点任务
1. 管理员登录
2. 创建盘点任务，分配给盘点员
3. 盘点员登录，开始任务（状态：进行中）
4. 盘点员逐条添加盘点记录
5. 盘点员提交审核（状态：待审批）
6. 管理员审批（状态：已通过/已拒绝）
7. 导出盘点报告

### 库存管理
1. 查看所有商品及库存
2. 调整库存（记录变更历史）
3. 导出Excel进行外部处理
4. 导入Excel批量更新

### 数据同步
1. 操作自动进入同步队列
2. 系统自动或手动触发同步
3. 失败项可在同步中心查看
4. 支持重置重试
