# 旧公式截图说明

## 截图来源
- 日期: 2023-10-15
- 来源: 历史活动分流配置文档

## 旧公式内容

```
旧版本计分公式:
score = CTR * 0.8 + 0.1

其中:
- CTR = clicks / impressions
- 0.8 为历史权重系数
- 0.1 为保底分数偏移
```

## 新公式对比

汤普森采样公式:
```
score ~ Beta(alpha + clicks, beta + (impressions - clicks))
```

## 适用场景说明
- 旧公式: 2023年10月前的活动C系列
- 新公式: 2023年10月后所有新建活动
