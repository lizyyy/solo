# 音乐课作业讲评系统使用说明

## 快速开始

### 环境要求
- Python 3.7+
- 无需额外依赖（使用标准库）

### 基本命令格式
```bash
python cli.py <命令> [参数]
```

查看帮助：
```bash
python cli.py --help
python cli.py import --help
```

---

## 核心操作流程

### 1. 导入数据（声部长 / 节拍器）

**声部长备注导入：**
```bash
python cli.py import 声部长数据.csv --source voice --operator 王老师 --note "第3周声部长检查"
```

**节拍器记录导入：**
```bash
python cli.py import 节拍器数据.csv --source metronome --operator 李老师
```

**导入文件格式（CSV）：**
```csv
学生姓名,曲目,声部,备注
张三,茉莉花,女高,节奏稳定
李四,歌唱祖国,男高,需要加强
```

> 💡 **提示**：系统会自动检测重复记录（相同学生+相同曲目），并标记为"待处理"状态。

---

### 2. 查看待处理记录

```bash
python cli.py pending
```

输出示例：
```
待处理记录 (2 条):

ID: 5
  张三 - 茉莉花 (女高)
  来源: 节拍器
  原因: 重复导入：已存在来自 声部长 的记录
```

---

### 3. 处理待处理记录

**确认记录（保留）：**
```bash
python cli.py confirm 5 --operator 王老师 --note "确认节拍器记录有效"
```

**撤回记录（删除）：**
```bash
python cli.py withdraw 5 --operator 王老师 --reason "重复记录，以声部长数据为准"
```

---

### 4. 查看记录详情与历史

```bash
python cli.py detail 3
```

输出包含：
- 学生姓名、曲目、声部
- 当前状态、数据来源
- 待处理原因（如有）
- **完整修改历史**（谁改了什么，什么时候改的）

---

### 5. 修改选曲信息

```bash
python cli.py update 3 --song "茉莉花(新版)" --voice 女中 --operator 王老师 --reason "学生转声部"
```

> ✅ **重要**：所有修改都会被记录在历史中，排练小结可以追溯变更过程。

---

### 6. 查看重复记录统计

```bash
python cli.py duplicates
```

输出示例：
```
发现 2 组重复记录:

1. 张三 - 茉莉花
   重复 2 次，来源: 声部长, 节拍器
   记录ID: 1, 5
```

---

### 7. 导出数据

**导出所有有效记录：**
```bash
python cli.py export 导出明细.csv
```

**只导出已确认记录：**
```bash
python cli.py export 确认记录.csv --status confirmed
```

**导出排练小结统计：**
```bash
python cli.py summary 排练小结.csv
```

> 📋 **导出前复核流程**：
> 1. 先运行 `python cli.py pending` 确认没有未处理的记录
> 2. 运行 `python cli.py duplicates` 检查重复情况
> 3. 确认无误后再执行 `summary` 导出

---

## 状态说明

| 状态 | 说明 |
|------|------|
| 待处理 | 重复导入或需要人工确认 |
| 已确认 | 已审核确认的有效记录 |
| 已撤回 | 被标记为无效的记录 |

---

## 数据来源说明

| 来源 | 参数值 | 说明 |
|------|--------|------|
| 声部长 | `voice` | 各声部负责人手动录入的备注 |
| 节拍器 | `metronome` | 节拍器系统自动导出的数据 |
| 手动录入 | `manual` | 管理员手动添加的记录 |

---

## 声部长备注填写建议

**推荐格式（放在CSV备注列）：**
```
[音准]优秀/良好/需加强；[节奏]稳定/一般/需练习；[建议]具体建议
```

**示例：**
```
音准良好，节奏需要多跟伴奏练习，建议加强第2段
```

---

## 常用命令速查

```bash
# 导入
python cli.py import 文件.csv --source voice --operator 姓名

# 查看
python cli.py list                    # 全部
python cli.py list --status pending   # 待处理
python cli.py list --student 张三     # 按学生搜索
python cli.py detail 记录ID           # 详情+历史

# 处理
python cli.py confirm ID --operator 姓名    # 确认
python cli.py withdraw ID --operator 姓名 --reason 原因  # 撤回
python cli.py update ID --song 新曲 --voice 新声部 --operator 姓名  # 修改

# 统计
python cli.py duplicates   # 重复统计
python cli.py pending      # 待处理列表

# 导出
python cli.py export 明细.csv
python cli.py summary 小结.csv
```
