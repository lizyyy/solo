## 1. 产品概述

票据影像补录清单是对账运营人员日常使用的冲正/补录核验工具，核心解决"金额为 0 但备注写已冲正"被汇总数字掩盖、税费率备注与柜台流水尾号互相矛盾时无人裁决、补录后重算结果不可追溯三大痛点。目标用户为对账运营岗（如阿芬），次要用户为风控复核岗与业务负责人。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 对账运营 | 工号登录 | 导入材料、补录、确认/驳回冲突、导出清单 |
| 风控复核 | 工号登录 | 查看待复核项、标记复核结论 |
| 业务负责人 | 工号登录 | 查看摘要与历史记录、审批 |

### 2.2 功能模块

1. **清单主页**：票据列表、筛选器、自检状态徽标、导入/导出入口
2. **冲突裁决页**：税费率备注与柜台流水尾号矛盾时，列出冲突证据，供对账运营选择确认或驳回
3. **补录工作台**：三步流程（税费率备注导入 → 补看柜台流水尾号 → 摘要更新），金额为 0 且备注已冲正自动转风控复核
4. **历史记录页**：完整操作链路追溯，每条记录可下钻到原始证据

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 清单主页 | 票据列表 | 展示所有票据行，支持按状态（正常/错口径/补录/冲突/风控待复核）筛选，行内高亮金额为 0 且备注已冲正 |
| 清单主页 | 自检面板 | 一键触发自检，覆盖：重复导入、金额为 0 但备注已冲正、补录后重算偏差、导出一致性，结果以徽标+条目列表呈现 |
| 清单主页 | 导入/导出 | 导入 CSV/Excel 材料文件（正常/错口径/补录三种），导出带时间戳的清单，导出前自动校验一致性 |
| 冲突裁决页 | 冲突证据列表 | 当税费率备注与柜台流水尾号矛盾时，左右对照展示双方字段，高亮差异字段 |
| 冲突裁决页 | 裁决操作 | 对账运营选择「确认以税费率备注为准」「确认以柜台流水尾号为准」「驳回（需补材料）」，不可自动拍板 |
| 补录工作台 | 步骤一：税费率备注导入 | 上传或选择税费率备注数据，系统解析并展示预览 |
| 补录工作台 | 步骤二：补看柜台流水尾号 | 展示柜台流水尾号供运营补看，标记与步骤一的匹配/不匹配项 |
| 补录工作台 | 步骤三：摘要更新 | 根据补录结果自动重算摘要，运营确认后更新给负责人看的摘要 |
| 补录工作台 | 冲正转风控 | 金额为 0 且备注已冲正的条目自动标记为"风控待复核"，不归入正常，等待风控同事复核 |
| 历史记录页 | 操作时间线 | 每条票据的完整操作链，含操作人、时间、操作类型、变更前后对比 |
| 历史记录页 | 证据下钻 | 点击任意历史节点可查看原始数据快照与裁决依据 |

## 3. 核心流程

## 4. 用户界面设计

### 4.1 设计风格

- 主色：深靛蓝 `#1B2A4A`，辅色：琥珀警示 `#D97706`、翠绿通过 `#059669`、红绯驳回 `#DC2626`
- 按钮：圆角 6px，主操作实色填充，次操作描边，危险操作红色系
- 字体：思源黑体 / Noto Sans SC，数据区用等宽字体 JetBrains Mono
- 布局：左侧固定导航栏 + 右侧主内容区，表格为主，卡片为辅
- 图标：Phosphor Icons 线性风格，清晰克制

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 清单主页 | 票据列表 | 顶部筛选栏（状态下拉+搜索框），数据表格（斑马纹，冲突行琥珀底色，冲正行红色底色），分页器 |
| 清单主页 | 自检面板 | 右侧抽屉式面板，4 项自检结果用图标+数字徽标，通过项翠绿勾，未通过项琥珀叹号 |
| 清单主页 | 导入/导出 | 顶部操作栏按钮，导入弹出模态框（拖拽上传+类型选择），导出前弹出一致性校验摘要 |
| 冲突裁决页 | 冲突证据列表 | 左右双栏对照卡片，差异字段用高亮底色+箭头标注，底部操作按钮组 |
| 补录工作台 | 三步流程 | 顶部步骤条（1-2-3），当前步骤内容区，底部上一步/下一步按钮，步骤二内嵌匹配对照 |
| 历史记录页 | 操作时间线 | 左侧竖向时间线，节点带图标（导入/裁决/补录/复核），右侧展开详情卡片，含变更前后 diff |

### 4.3 响应式

桌面优先设计，最小支持 1280px 宽度。平板端（768-1280px）侧边栏可折叠，移动端暂不要求。

### 4.4 3D 场景指引

不适用。
