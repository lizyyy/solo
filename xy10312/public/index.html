📖 系统使用说明

🎂 1. 正常下单流程

  1. 点击首页或订单管理页的 "新增订单" 按钮
  2. 填写客户信息（姓名、电话必填）
  3. 选择蛋糕口味和尺寸，系统会自动计算价格和所需材料
  4. 选择周末取货日期和时间（只能选周六/周日）
  5. 填写定金金额（≥50元订单即确认，<50元处于待付定金状态）
  6. 系统会自动检查 产能 和 材料库存
  7. 检查通过后点击"确认下单"完成

⚠️ 2. 库存不足场景演示

  1. 点击"新增订单"
  2. 选择口味：芒果千层
  3. 选择尺寸：12寸（需要芒果700g）
  4. 选择本周末日期
  5. 系统会显示 "材料库存不足" 的提示
  6. 查看详细：当前库存600g，已占用700g，本单需700g，缺口800g
  7. 可前往"材料库存"页补充芒果库存后再下单

🔄 3. 截单后改期审核

  1. 查看订单 ORD2024005（已提交改期申请）
  2. 该订单原订周六，申请改到周日
  3. 由于原日期已过截单时间，需走审核流程
  4. 在订单操作中点击 "改期审核"
  5. 可选择：通过（调整产能和材料占用）或 驳回
  6. 审核记录会保留在订单历史中

❌ 4. 定金取消

  1. 查看订单 ORD2024004（状态：待付定金）
  2. 点击订单操作中的 "取消订单"
  3. 确认后：订单状态变为"已取消"，定金退还
  4. 该订单占用的 产能 和 材料 会自动释放
  5. 可在订单历史中查看取消记录

📊 5. 核心规则说明

  1. 产能计算：6寸=1单位，8寸=1.5，10寸=2，12寸=2.8
  2. 日产能上限：50单位/天
  3. 定金规则：未付定金订单最多占用70%产能（35单位），防止占用过多产能后取消
  4. 截单时间：取货日前1天 18:00
  5. 材料检查：按"库存 - 已占用 - 本单所需"计算，小于0则无法接单
  6. 改期规则：截单前可自由改期，截单后需审核

📄 6. 生产清单导出

  1. 进入"生产清单"页
  2. 选择要导出的日期（或全部待生产）
  3. 点击"导出生产清单"
  4. 导出文件包含：
    • 订单列表（按取货时间排序）
    • 口味/尺寸汇总
    • 材料需求清单（含库存对比）
    • 关键计算口径说明
