# 版本发布说明命令行工具使用说明

## 功能特性

1. **贴近灰度法务证据页** - 支持添加证据字段并追溯原始来源
2. **补偿动作漏执行识别** - 自动将补偿动作未执行标记为失败项
3. **原始输入可追溯** - 每个证据字段都有追踪ID和来源记录
4. **人工备注不覆盖** - 人工修正保留原始判断，只作备注
5. **失败项单独保存** - 所有失败项独立存储，方便接手人查看
6. **本地持久化** - 重启后所有数据仍然保留
7. **部分成功标记** - 既有成功又有失败时，整体状态标记为 partial
8. **模型评测人工确认** - 支持模型评测结果的人工确认流程
9. **按文件摘要搜索** - 可根据文件摘要过滤查询

## 安装依赖

```bash
pip3 install click python-dateutil
```

## 命令列表

### 1. 创建发布记录
```bash
python3 release_cli.py create -v "版本号" -d "描述" -m "材料摘要"
```

### 2. 向发布记录添加项目
```bash
python3 release_cli.py add-item <记录ID> \
    -s "文件摘要" \
    -p "文件路径" \
    -t <状态: pending/success/failed/partial/needs_review> \
    -c <补偿动作状态: not_executed/executed/skipped>
```

### 3. 添加可追溯的证据字段
```bash
python3 release_cli.py add-evidence <记录ID> <项目ID> \
    -k "字段键" \
    -v "字段值" \
    -s "原始来源"
```

### 4. 添加人工备注（不覆盖原始判断）
```bash
python3 release_cli.py add-note <记录ID> <项目ID> \
    -a "作者" \
    -c "备注内容" \
    -j '{"原始值": "JSON格式"}'
```

### 5. 添加模型评测结果
```bash
python3 release_cli.py add-model-review <记录ID> <项目ID> \
    -s "片段ID" \
    -c "片段内容" \
    -m "模型名称" \
    -r '{"模型结果": "JSON格式"}'
```

### 6. 人工确认模型评测
```bash
python3 release_cli.py confirm-model <记录ID> <项目ID> \
    -c "确认人" \
    -n "确认备注"
```

### 7. 列出所有发布记录
```bash
python3 release_cli.py list
```

### 8. 显示发布记录详情
```bash
python3 release_cli.py show <记录ID>
```

### 9. 列出所有失败项
```bash
python3 release_cli.py list-failures
```

### 10. 按文件摘要搜索
```bash
python3 release_cli.py search "关键词"
```

### 11. 导出为JSON
```bash
python3 release_cli.py export <记录ID> -o "输出文件路径"
```

## 使用示例

```bash
# 1. 创建发布记录
python3 release_cli.py create -v "1.0.0" -d "灰度发布第一版" -m "法务证据材料汇总"

# 2. 添加成功项目
python3 release_cli.py add-item <记录ID> -s "用户协议更新" -p "/legal/user_agreement_v2.md" -t success -c executed

# 3. 添加失败项目（会自动生成失败项）
python3 release_cli.py add-item <记录ID> -s "隐私政策合规检查" -p "/legal/privacy_policy_check.md" -t failed -c not_executed

# 4. 添加证据字段
python3 release_cli.py add-evidence <记录ID> <项目ID> -k "legal_check_result" -v "not_compliant" -s "法务系统API_20240515"

# 5. 添加人工备注
python3 release_cli.py add-note <记录ID> <项目ID> -a "法务专员张三" -c "经人工复核，该条款符合最新法规" -j '{"system_judgment": "failed", "human_judgment": "passed"}'

# 6. 添加模型评测并人工确认
python3 release_cli.py add-model-review <记录ID> <项目ID> -s "snippet_001" -c "隐私政策第三条" -m "GPT-4-legal" -r '{"compliance_score": 0.75}'
python3 release_cli.py confirm-model <记录ID> <项目ID> -c "资深法务李四" -n "模型识别准确"

# 7. 查看所有失败项
python3 release_cli.py list-failures

# 8. 按关键词搜索
python3 release_cli.py search "隐私政策"

# 9. 查看完整记录
python3 release_cli.py show <记录ID>
```

## 数据存储位置

所有数据存储在当前目录下的 `.release_notes/` 文件夹中：
- `records/` - 发布记录JSON文件
- `failures/` - 失败项JSON文件
- `index.json` - 索引文件，支持快速搜索和列表展示
