任务管理 API

  • POST /api/tasks 提交任务（支持重复策略：忽略/覆盖/追加）
  • GET /api/tasks/{id} 获取任务详情
  • GET /api/tasks/{id}/detail 获取任务完整详情（含明细、日志、审计）
  • POST /api/tasks/query 分页查询任务列表
  • POST /api/tasks/{id}/cancel 取消/撤回任务
  • POST /api/tasks/{id}/freeze 冻结任务（导出前冻结）
  • POST /api/tasks/{id}/unfreeze 解冻任务
  • POST /api/tasks/{id}/manual-takeover 人工接管
  • POST /api/tasks/{id}/compensate 补偿入账
  • POST /api/tasks/{id}/close 关闭任务
  • POST /api/tasks/{id}/judge 人工改判状态
  • POST /api/tasks/{id}/retry 手动触发重试
  • GET /api/tasks/{id}/logs 获取任务操作日志
  • GET /api/tasks/{id}/export 导出任务Excel
  • GET /api/tasks/{id}/validate 数据一致性校验

死信队列 API

  • GET /api/dead-letters 分页查询死信列表
  • POST /api/dead-letters/{id}/recover 从死信恢复（生成新批次号）
  • GET /api/dead-letters/stats/count-unrecovered 未恢复死信数量

边界情况覆盖

  • ✅ 重复提交（忽略/覆盖/追加三种策略）
  • ✅ 撤回后再提交（取消后重新生成批次）
  • ✅ 部分失败（明细级状态追踪）
  • ✅ 人工改判（仅人工处理中可改）
  • ✅ 导出前冻结（冻结后不可修改）
  • ✅ 异常不吞（全局异常处理+日志）
  • ✅ 数据一致性校验（导出前自动校验）

加盟商视角关注点

  • 📊 可重试分类（按状态筛选查询）
  • 📭 死信处理（独立死信队列+恢复机制）
  • 🔄 恢复后续跑（死信恢复后自动排队）
  • 📝 完整轨迹（操作日志+审计历史双记录）
  • ✅ 数据一致（列表、详情、历史、导出一致）
