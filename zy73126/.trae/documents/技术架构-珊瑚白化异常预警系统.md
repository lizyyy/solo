## 2. 技术说明
- **前端**：React@18 + TypeScript + tailwindcss@3 + Vite
- **初始化工具**：npm create vite@latest（React + TypeScript 模板）
- **后端**：无后端，纯前端 SPA，数据存储于 localStorage
- **数据**：内置 Mock 样例数据（含潮位单位混写脏数据 + 后补备注）
- **动画**：CSS 原生动画 + framer-motion（抽屉、时间线入场）

```mermaid
        string id PK

        float water_temp "水温(°C)"

        string created_by
        datetime created_at
        datetime updated_at
    }

    ANOMALY {
        string id PK
        string record_id FK
        string type "tide_unit_mix/time_mismatch/missing/outlier"
        string description
        boolean resolved
    }

    NOTE {
        string id PK
        string record_id FK
        string content "后补备注内容"
        string author "调查员如阿宁"
        datetime created_at
    }

    STATUS_LOG {
        string id PK
        string record_id FK
        string from_status
        string to_status
        string operator
        datetime created_at
    }

    TIMELINE_EVENT {
        string id PK
        string event_type "import/filter/note/status_change/export"
        string description
        datetime created_at
        string operator
    }

    FILTER_SNAPSHOT {
        string id PK
        string event_id FK
        json filters "{station, dateRange, anomalyType, status}"
    }
```

### 4.2 异常类型枚举
```typescript
type AnomalyType = 
  | 'tide_unit_mix'   // 潮位单位混写：如同时出现 m、厘米、ft
  | 'time_mismatch'   // 采样时间与实验结果时间错位
  | 'missing_value'   // 缺失值
  | 'outlier_value';  // 数值离群
```

### 4.3 记录状态枚举
```typescript
type RecordStatus = 
  | 'pending'        // 待处理
  | 'confirmed'      // 已确认
  | 'pending_info'   // 待补件
  | 'returned';      // 退回
```

## 6. 异常检测引擎核心逻辑
- **潮位单位混写**：扫描 `tide_level` 字段，正则匹配多种单位（m/米/厘米/cm/ft/英尺），若同批次数据出现 2 种以上单位或单条记录内单位不规范则标记异常
- **时间错位**：对比采样时间 `sampled_at` 与记录创建时间差，若超过阈值（如 24h）且无后补备注说明，则标记异常
- **缺失值**：关键字段（station、sampled_at、bleaching_rate）为空直接标记
- **数值离群**：水温 / 白化率超出 3σ 范围标记

## 7. 导出一致性保障
导出服务直接读取当前表格渲染的 state（含筛选后结果、排序、状态标签），不做二次查询，保证导出文件与屏幕数字完全一致。
