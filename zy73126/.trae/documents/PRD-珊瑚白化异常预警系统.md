## 1. 产品概述

珊瑚白化异常预警系统，用于生态调查员阿宁整理船上记录本中采样时间与实验结果不匹配的记录，实现异常数据检测、历史轨迹追溯与状态复核。

- 核心问题：船上记录本数据存在潮位单位混写、后补备注、采样时间与结果错位等脏数据，需单独拎出并跟踪处理
- 目标用户：海洋生态调查员（阿宁）
- 产品价值：将散落在记录本中的异常数据结构化，保留完整变更轨迹，支持月底快速复核分类

## 2. 核心功能

### 2.1 用户角色
| 角色 | 登录方式 | 核心权限 |
|------|---------|---------|
| 生态调查员 | 本地桌面应用 | 导入数据、标注异常、补充备注、查看历史、复核分类、导出结果 |

### 2.2 功能模块
1. **数据工作台**：船上记录本导入、实时异常扫描、数据表格展示、筛选与搜索
2. **异常详情面板**：脏数据单独拎出、异常类型标注（潮位单位混写/时间错位/缺失值等）、后补备注编辑、状态流转
3. **历史时间线**：筛选口径永久留存、变更记录可视化、操作轨迹回溯入口
4. **复核看板**：已确认/待补件/退回 三栏分类统计、批量状态操作、月底复核清单
5. **样例试跑区**：内置测试数据包（含潮位单位混写 + 后补备注）、一键重跑、流程说明

## 3. 核心流程

调查员阿宁的标准操作流程：导入船上记录本数据包 → 系统自动扫描并拎出异常（潮位单位混写等）→ 为异常记录补充后补备注 → 标记处理状态（已确认/待补件/退回）→ 通过历史时间线追溯每次操作与筛选口径 → 月底在复核看板按三类状态快速清点 → 导出与屏幕显示一致的结果文件

```mermaid
flowchart LR
    A["导入旧材料/船上记录本"] --> B["系统自动扫描异常"]
    B --> C["脏数据单独拎出展示"]
    C --> D["补充后补备注"]
    D --> E["标记状态:已确认/待补件/退回"]
    E --> F["历史时间线记录所有变更"]
    F --> G["月底复核看板分类清点"]
    G --> H["导出与屏幕一致的结果"]
```

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深海蓝 `#0A2540`，辅助色珊瑚橙 `#FF6B4A`，警示红 `#E63946`，成功绿 `#2EC4B6`
- **按钮风格**：圆角 6px，次要按钮描边，主按钮实色填充带轻微阴影
- **字体**：展示标题用「LXGW WenKai」或「思源宋体」，正文数据表格用「JetBrains Mono」等宽字体
- **布局**：左侧导航 + 右侧主工作区，卡片式容器，数据区表格密度适中
- **图标风格**：海洋生态主题 Emoji（🐚🪸🌊）配合线性 SVG 图标

### 4.2 页面设计概述
| 页面名称 | 模块名称 | UI 元素 |
|---------|---------|---------|
| 数据工作台 | 顶部横幅 | 深色渐变背景 + 珊瑚图标 + 系统标题，右侧功能入口胶囊按钮 |
| 数据工作台 | 导入卡 | 虚线边框拖拽区，橙色高亮，含示例数据下载入口 |
| 数据工作台 | 异常统计条 | 四个彩色数值卡片：总数/异常数/已处理/待处理 |
| 数据工作台 | 数据表格 | 斑马纹行，异常行左边框珊瑚橙竖条，状态标签彩色圆角 |
| 异常详情面板 | 右侧抽屉 | 从右滑入，半透明黑色遮罩，异常原因红底白字警示 |
| 历史时间线 | 垂直时间轴 | 左侧时间节点圆点，右侧卡片记录操作内容与筛选快照 |
| 复核看板 | 三栏并列 | 每栏独立背景色（绿/橙/红），顶部大数字 + 下方列表 |
| 样例试跑区 | 底部折叠面板 | 三步流程图 + 两个主要操作按钮 |

### 4.3 响应式
桌面端优先（1440px 基准），平板自适应两栏，移动端单列堆叠，表格横向滚动。

### 4.4 动效与氛围
- 页面加载：卡片从下往上错位淡入（stagger 50ms）
- 异常标记：珊瑚橙色脉冲动画（pulse 2s 循环）
- 抽屉面板：translateX 过渡 300ms ease-out
- 背景：极简深海蓝径向渐变 + 极淡噪点纹理
