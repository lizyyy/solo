# A/B实验配置台

一个用于管理A/B实验的全栈应用，包含实验分组、流量控制、互斥规则管理和效果报表功能。

## 技术栈

- **后端**: FastAPI (Python)
- **前端**: Vue 3 + Element Plus
- **数据**: 内存数据库（演示用）

## 功能特性

1. **仪表盘**: 查看实验概览和待处理问题
2. **实验管理**: 创建、查看、编辑实验
3. **分组管理**: 配置实验分组和流量比例
4. **互斥规则**: 管理实验间的互斥关系
5. **效果报表**: 查看实验指标报表
6. **人工修正**: 修正流量比例等问题，记录修正前后差异
7. **导出功能**: 支持JSON和Excel格式导出
8. **自动重计算**: 流量比例变化后自动重新计算报表

## 脏数据说明

系统预置了3条带有问题的实验数据，用于演示修正功能：

1. **登录流程优化实验 (exp-001)**:
   - 流量比例问题: 50% + 60% + 20% = 130% (应为100%)
   - 互斥规则问题: 2条无效规则

2. **首页推荐算法实验 (exp-002)**:
   - 状态: 已暂停
   - 数据正常，无问题

3. **支付页面改版实验 (exp-003)**:
   - 流量比例问题: 30% + 30% + 30% = 90% (应为100%)
   - 互斥规则问题: 1条无效规则

## 快速开始

### 后端启动

```bash
cd backend
pip install -r requirements.txt
python main.py
```

后端运行在 http://localhost:8000

API文档: http://localhost:8000/docs

### 前端启动

```bash
cd frontend
npm install
npm run dev
```

前端运行在 http://localhost:3000

## 使用流程

1. 访问仪表盘查看需要修正的实验
2. 进入实验详情页面
3. 查看"流量比例需要修正"的提示
4. 点击"立即修正"查看修正前后对比
5. 输入修正原因并应用修正
6. 验证流量比例已变为100%
7. 点击"重新计算"更新效果报表
