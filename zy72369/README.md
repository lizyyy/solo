# 光纤弯曲损耗记录系统

> 保留原始材料痕迹 · 杜绝自动拍板 · 全链路可审

面向设备工程师、现场施工师傅、实验老师的工业级光纤测试数据管理工具。
解决维修群截图备注比正式表格更关键却易丢失的痛点。

---

## 快速开始（新人照着这份跑通）

### 第 0 步：启动系统

```bash
# 安装依赖（首次使用）
npm install

# 启动开发服务器
npm run dev
```

浏览器打开 `http://localhost:5173/`

---

### 第 1 步：登录（选择角色）

**样例场景**：假设你是「设备工程师 — 何工」

1. 在登录页 **姓名** 框输入：`何工`
2. **角色** 选择：`设备工程师`
3. 点击 `进入系统`

> 💡 现场施工师傅选「现场施工师傅」，实验老师选「实验老师」，
> 不同角色在异常工况表中可操作的权限不同。

---

### 第 2 步：导入设备铭牌参数

进入系统后，先在 **数据录入页** 顶部的「设备铭牌参数导入」区域填入基准数据。

#### 填入以下真实样例（第一台设备）：

| 字段 | 填入值 | 说明 |
|------|--------|------|
| 设备编码 | `FBR-G652D-001` | 光缆盘号/唯一标识 |
| 光纤类型 | `G.652D` | 常用单模光纤 |
| 芯径(μm) | `9` | 标准单模芯径 |
| 包层直径(μm) | `125` | 标准外径 |
| 最小弯曲半径(mm) | `30` | 厂商规定的最小弯曲半径 |

点击 `导入铭牌` 按钮。

导入成功后，下方会出现已锁定的铭牌表格，显示：
- 设备编码 `FBR-G652D-001`
- 右上角出现「基准已锁定 (1)」标签

> 🔒 **为什么要锁定？** 铭牌参数是整个系统的基准值，
> 后续所有冲突检测都以此为依据，导入后不可修改，防止有人擅自改动。

#### （可选）第二台设备 — 用于测试"重复检测"

再导入一份铭牌：

| 字段 | 填入值 |
|------|--------|
| 设备编码 | `FBR-G657A1-002` |
| 光纤类型 | `G.657A1` |
| 芯径(μm) | `9` |
| 包层直径(μm) | `125` |
| 最小弯曲半径(mm) | `15` |

---

### 第 3 步：录入弯曲损耗数据（三种典型场景）

在「弯曲损耗数据录入」区域，逐条录入现场测得的数据。

---

#### 场景 A：正常数据（无异常）

| 字段 | 选择/填入 |
|------|-----------|
| 选择设备铭牌 | `FBR-G652D-001 - G.652D` |
| 弯曲半径(mm) | `30` |
| 方向 | `+ (正方向)` |
| 损耗值(dB) | `0.12` |

点击 `录入`。

录入后下方记录表格出现一行：
- 状态 = 「正常」（绿色标签）
- 方向 = `+`

---

#### 场景 B：负方向被写成「向左」（需要实验老师复核）

这是现场师傅最容易写错的情况。系统 **不会** 自动把「向左」归为「负方向 -」，
而是标记为「待复核」，留给实验老师确认。

| 字段 | 选择/填入 |
|------|-----------|
| 选择设备铭牌 | `FBR-G652D-001 - G.652D` |
| 弯曲半径(mm) | `25` |
| 方向 | `向左 (待复核)` |
| 损耗值(dB) | `0.35` |

⚠️ 注意：方向选「向左」后，录入框上方会出现橙色警告：
> 方向为"向左"将自动标记为"待复核"，不会自动归为正常，需实验老师复核确认

点击 `录入`。

录入后记录表格出现一行：
- 状态 = 「待复核」（橙色标签）
- 行左侧有一条橙色竖条（直观提示有模糊表述）
- 方向文字为橙色高亮

---

#### 场景 C：弯曲半径小于铭牌最小值（危险工况）

| 字段 | 选择/填入 |
|------|-----------|
| 选择设备铭牌 | `FBR-G652D-001 - G.652D` |
| 弯曲半径(mm) | `20` ← 小于铭牌的 30mm |
| 方向 | `- (负方向)` |
| 损耗值(dB) | `0.78` |

会出现 **红色警告**：
> 弯曲半径 20mm 小于铭牌最小弯曲半径 30mm

点击 `录入` 仍可录入（系统不会自动丢弃），但后续会在自检中标记。

---

### 第 4 步：补录数据（漏测后补）

如果现场漏测了一条，后续补上，系统需要标记「补录」并写入补录说明。

1. 勾选录入区下方的 `☑ 补录数据` 复选框
2. 出现黄色的「补录说明」输入框
3. 填入：

| 字段 | 填入值 |
|------|--------|
| 选择设备铭牌 | `FBR-G652D-001 - G.652D` |
| 弯曲半径(mm) | `40` |
| 方向 | `向右` |
| 损耗值(dB) | `0.08` |
| 补录说明 | `06月09日上午漏测，下午14:30补测，数据经现场确认无误` |

点击 `录入`。

录入后记录表格出现一行：
- 整行底色为淡黄色
- 「补录」列出现黄色「补」字标记
- 历史记录中会出现带「补录」标签的日志条目

---

### 第 5 步：上传维修群截图 + 备注（最关键！别清洗）

这是系统的核心价值之一：**维修群截图和备注永远保留，不会被自动清洗成一行"干净数据"。**

在「维修群截图上传」区域：

1. 从下拉框选择刚才录入的某条记录，例如 `FBR-G652D-001 | R=25 D=向左`
2. 点击「选择文件」按钮，上传一张手机拍的维修群截图（任意图片即可）
3. **备注框**（最关键）填入真实的维修群聊天内容，例如：
   > 现场师傅@张工反馈：25mm处向左弯折严重，群里发的视频显示光缆在拐角处被硬折了。铭牌写30mm，现场实测只有25mm。何工请看下是否超差。

4. 点击 `上传`

> 🔍 **为什么备注不能清洗？** 这些上下文文字（谁反馈的、在哪儿、什么情况）
> 往往比 0.35dB 这个数字本身更重要。系统会把备注原文带到报告里，
> 也会拿备注中的关键词（如「最小弯曲半径」「芯径」等）和铭牌参数自动比对，
> 发现矛盾就生成冲突条目。

---

### 第 6 步：查看「异常工况表」（冲突 + 待复核）

点击左侧导航栏的 `异常工况表`。

页面分为两部分：

#### ① 冲突检测区

如果截图备注里提到了某个参数（如最小弯曲半径 20mm）和铭牌基准值（30mm）不一致，
这里会出现红色冲突卡片，可展开查看：

```
┌─ 铭牌参数───────────────────────────────┐
│ 最小弯曲半径: 30mm                       │
│ 铭牌基准值 30mm (导入时间: 2026/6/9 ...) │
└──────────────────────────────────────────┘
                   vs
┌─ 截图备注───────────────────────────────┐
│ 最小弯曲半径: 20mm                       │
│ 截图备注"现场写的是20mm..." (上传时间...) │
└──────────────────────────────────────────┘
```

仅 **设备工程师** 可操作（何工登录后会看到三个按钮）：
- `确认铭牌` — 以铭牌为准，截图备注仅作参考
- `确认截图` — 以现场实际测量为准，铭牌需重新核验
- `驳回` — 退回现场，重新采集

裁决后，记录状态从「冲突」变为「正常」，并写入历史操作日志。

#### ② 待复核区

所有方向写了「向左」的记录都在这里。

仅 **实验老师** 登录可见「复核」按钮。点击后弹出对话框：
```
请填写复核结论，如：确认方向为负方向（-）
```

填写后，记录状态从「待复核」变为「已复核」（蓝色标签）。

---

### 第 7 步：查看「历史记录」

点击左侧导航栏的 `历史记录`。

#### ① 操作时间线

从最新到最旧，按时间排列所有操作：
- 🔵 蓝色圆点：导入、裁决
- 🟡 黄色圆点：补录
- 🟠 橙色圆点：冲突
- ⚪ 灰色圆点：其他

每条记录包含：
- 操作类型标签（导入/录入/补录/裁决/复核/自检）
- 操作人姓名
- 操作时间
- 详细文字说明（如"录入弯曲损耗数据: 半径25mm 方向向左 损耗0.35dB"）

#### ② 维修群截图画廊

所有上传的截图缩略图，点击可查看原图和完整备注。

---

### 第 8 步：运行自检 + 导出报告

点击左侧导航栏的 `自检与导出`。

点击 `一键自检` 按钮，系统运行 **6 项检查**：

| 检查项 | 通过标准 |
|--------|----------|
| 铭牌参数校验 | 无空值、数值范围合理、无重复设备编码 |
| 重复导入检测 | 无完全相同记录 / 或标注重复来源 |
| 负方向异常检测 | "向左"方向都处于「待复核」或「已复核」状态 |
| 补录后重算验证 | 所有补录数据都有说明，状态不为「正常」 |
| 导出一致性校验 | 无未裁决冲突、无未复核记录 |
| 截图备注完整性 | 所有有截图的记录都有备注 |

自检全部通过（所有卡片绿色对勾）后，「导出 JSON」和「导出 CSV」按钮解除禁用。

点击导出，文件名包含当前时间，例如：
- `光纤弯曲损耗记录_20260609_1530.json`
- `光纤弯曲损耗记录_20260609_1530.csv`

JSON 中包含完整的原始数据：铭牌参数、所有记录（含补录标记）、冲突及裁决、截图备注原文、操作日志、自检结果。
绝不会把维修群备注洗掉。

## 三种典型材料都能跑通

| 材料类型 | 模拟方法 | 预期结果 |
|----------|----------|----------|
| 正常材料 | 场景 A + 场景 C | 正常记录归入、超限记录标记 |
| 错口径材料 | 截图备注中写「芯径10μm」与铭牌9μm冲突 | 异常工况表出现冲突 → 何工裁决 |
| 补录材料 | 场景 D 勾选补录 | 补录标记 + 说明 + 自检重算通过 |

## 数据保存说明

- 所有数据保存在浏览器 LocalStorage（持久化，关闭浏览器不会丢）
- 截图二进制保存在 IndexedDB
- 如需清除所有数据：浏览器控制台执行 `localStorage.clear()` 后刷新页面

## 技术栈

- **前端**：React 18 + TypeScript + Tailwind CSS 3
- **构建**：Vite
- **状态管理**：Zustand（带持久化中间件）
- **图标**：Lucide Icons
- **字体**：Noto Sans SC（中文）+ JetBrains Mono（数据表格）

所有代码位于 `src/` 目录下，按职责分层：
- `src/types/` — 类型定义
- `src/utils/` — 纯函数工具（冲突检测、自检、导出）
- `src/store/` — Zustand 状态管理
- `src/components/` — 布局与登录组件
- `src/pages/` — 四大功能页面
