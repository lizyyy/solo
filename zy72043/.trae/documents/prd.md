## 1. 产品概述
电磁炮校准挑战是一款面向培训场景的考核小游戏，用于检验学员在电磁炮校准流程中的决策能力。培训讲师老冯在交接前最怕"错题本"里的挑战材料和导出结果脱节，本产品确保判断过程可追溯、暂停/继续后局面不乱、结算与导出像人话。

- 解决核心问题：培训交接时挑战记录与评分脱节、暂停后状态丢失、结算原因不可追溯
- 目标用户：培训讲师（出题/复盘）、学员（挑战/查看结果）

## 2. 核心功能

### 2.1 用户角色
| 角色 | 进入方式 | 核心权限 |
|------|----------|----------|
| 学员 | 直接进入挑战 | 进行校准选择、查看结算结果、查看回放 |
| 培训讲师 | 管理入口 | 配置关卡参数、查看评分备注、导出成绩与回放 |

### 2.2 功能模块
1. **挑战主页面**：校准参数展示、选择交互、计时器、暂停/继续/重开控制
2. **结算页面**：关键选择回顾、扣分明细、判断过程留痕、原始来源与处理时间
3. **复盘与导出页面**：成绩回放、人话导出（文本/打印）、审计追踪记录

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 挑战主页 | 校准参数面板 | 展示当前关卡的电磁炮参数（频率、功率、角度等），学员据此做选择 |
| 挑战主页 | 选择交互区 | 学员在多个校准选项中选择，每次选择立即记录选择内容、时间戳和回合号 |
| 挑战主页 | 控制栏 | 暂停、继续、重开按钮；显示当前回合数、已用时间、暂停状态 |
| 挑战主页 | 状态指示器 | 当前游戏状态（进行中/已暂停/已结束），回合进度条 |
| 结算页面 | 选择回顾 | 逐回合展示学员选择 vs 正确答案，标注关键选择 |
| 结算页面 | 扣分明细 | 每个扣分项的原因、对应回合、扣分值，汇总总分 |
| 结算页面 | 判断过程 | 保留评分引擎的判断逻辑输出，含原始来源和处理时间 |
| 复盘与导出 | 回放播放器 | 按回合逐步回放学员选择过程，含时间轴 |
| 复盘与导出 | 成绩导出 | 导出为可读文本（含人话描述），培训讲师可打印或存档 |
| 复盘与导出 | 审计追踪 | 每条记录含原始来源、处理时间、操作人，确保交接不脱节 |

## 3. 核心流程

学员进入挑战后，逐回合查看校准参数并做出选择。每回合记录选择内容、时间戳和回合号。暂停后状态冻结（回合数、已用时间、选择记录不变），继续后从中断处恢复。重开则清空当前挑战记录重新开始。挑战结束后进入结算页面，展示所有回合的选择、扣分原因和判断过程。培训讲师可在复盘页面查看回放并导出成绩。

## 4. 用户界面设计

### 4.1 设计风格
- **主色调**：深灰黑底（#0a0e17）+ 青蓝高亮（#00e5ff）+ 琥珀警示（#ffab00）
- **次色调**：钢蓝辅助（#546e7a）、暗红扣分（#ef5350）
- **字体**：标题用 JetBrains Mono（等宽工业感），正文用 Noto Sans SC（中文可读性）
- **布局**：仪表盘式——中央参数区、左侧回合进度、右侧控制栏、底部状态条
- **按钮风格**：圆角矩形、边框发光、按压时内凹效果
- **图标风格**：线性描边图标（lucide-react），配合发光效果

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 挑战主页 | 校准参数面板 | 深色卡片，参数值用大号等宽字体，变化值高亮动画 |
| 挑战主页 | 选择交互区 | 选项按钮排列，选中后边框青蓝发光，hover 时微弱脉冲 |
| 挑战主页 | 控制栏 | 圆形暂停/继续按钮，方形重开按钮，回合数用数字发光显示 |
| 挑战主页 | 状态指示器 | 顶部横条：进行中青蓝、暂停琥珀、结束暗红 |
| 结算页面 | 选择回顾 | 左右对比布局（学员选择 vs 正确答案），匹配项青蓝、偏差项暗红 |
| 结算页面 | 扣分明细 | 表格布局，每行含回合号、选择、扣分原因、分值，底部汇总 |
| 结算页面 | 判断过程 | 代码块风格展示判断逻辑，含时间戳和来源标签 |
| 复盘与导出 | 回放播放器 | 水平时间轴，可拖拽播放头，当前回合高亮 |
| 复盘与导出 | 成绩导出 | 预览区域 + 导出按钮，预览即所见即所得 |
| 复盘与导出 | 审计追踪 | 时间线样式，每条记录含来源标签、时间戳、操作人 |

### 4.3 响应式设计
- 桌面优先设计，最小宽度 1024px
- 平板（768-1024px）：参数面板压缩为可折叠，选择交互区垂直排列
- 触控优化：按钮最小触控区 44px，暂停/继续按钮加大

## 5. 数据完整性要求

### 5.1 暂停/继续/重开的稳定性
- 暂停时：冻结当前回合号、已用时间、所有选择记录
- 继续时：从冻结点精确恢复，回合数不跳变
- 重开时：生成新的挑战实例ID，旧记录保留归档

### 5.2 边界情况处理
- 空值：学员未做选择即进入下一回合，记录为"未选择"并标注扣分原因
- 重复项：连续相同选择不覆盖，每条记录独立保留
- 边界记录：超时未完成的回合，自动标注"超时"并记录已用时间

### 5.3 审计追踪
- 每条记录包含：原始来源（关卡配置/学员操作/系统自动）、处理时间（ISO 8601）、操作标识
- 导出结果与错题本数据一一对应，不脱节
