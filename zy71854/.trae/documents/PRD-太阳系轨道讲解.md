## 1. 产品概述

面向培训老师的"太阳系轨道讲解"教学辅助工具，解决演示脚本、零件清单、零散备注的整合管理问题。核心价值是让教学内容可追溯、处理口径一致、课堂记录可分类导出。

- 目标用户：培训老师（日常使用者）、教研负责人（审核课堂记录）
- 解决问题：多源数据整合难、修改追溯难、导出口径不一致、课堂记录分类混乱
- 核心价值：结论可追溯到原始材料、所有操作口径统一、课堂记录分类清晰

## 2. 核心功能

### 2.1 用户角色

| 角色 | 核心权限 |
|------|----------|
| 培训老师 | 导入数据、编辑修正、撤回操作、筛选查看、导出课堂记录 |
| 教研负责人 | 查看分类课堂记录、查看处理口径、复核导出内容 |

### 2.2 功能模块

1. **数据管理页**：演示脚本导入、零件清单导入、零散备注录入、数据追溯查看
2. **轨道讲解页**：知识点总览、结论追溯跳转、状态标记（已确认/待补/人工修改）
3. **课堂记录页**：分类视图（已确认/待补/人工修改）、处理口径展示、筛选导出
4. **操作指南页**：演示脚本样例放置说明、跳过步骤查看、导出前复核清单

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|---------|----------|----------|

| 数据管理页 | 操作历史 | 记录所有导入、修改、撤回操作，口径一致可追溯 |
| 轨道讲解页 | 知识点总表 | 展示所有讲解知识点，每行带状态标签和追溯链接 |

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：深空蓝 `#0B2545`（代表宇宙），辅色：星尘金 `#D4AF37`（代表恒星/重点）
- **中性色**：石墨灰 `#2D3748` 为主文字，浅灰 `#F7FAFC` 为背景
- **按钮风格**：圆角 4px，扁平化但带微妙阴影，hover 有轻微上浮效果
- **字体**：标题用思源宋体（学术感），正文用思源黑体（可读性）
- **布局风格**：左侧导航 + 主内容区，卡片式数据展示，表格为核心交互区
- **状态标签**：已确认（绿底白字）、待补（橙底白字）、人工修改（紫底白字）

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI 元素 |
|---------|----------|---------|
| 数据管理页 | 导入区域 | 拖拽框（虚线边框，hover 变星尘金）、上传按钮、格式提示 |
| 数据管理页 | 数据列表 | 斑马纹表格、类型图标（📜脚本/🔧零件/📝备注）、追溯徽章 |
| 轨道讲解页 | 知识点总表 | 可展开行、状态标签、追溯按钮（🔗）、行内编辑 |
| 轨道讲解页 | 追溯面板 | 右侧滑出面板、原文引用高亮、关联零件标记 |
| 课堂记录页 | 分类标签页 | 三个等宽标签、角标显示数量、筛选器固定在顶部 |
| 课堂记录页 | 处理口径 | 灰色小字、时间戳、操作人、口径说明徽章 |
| 操作指南页 | 说明卡片 | 三步卡片布局、序号图标、可折叠详情 |

### 4.3 响应式

- 桌面端优先（1280px+），左侧导航固定 240px
- 平板端（768-1279px）：导航可折叠，表格支持横向滚动
- 移动端（<768px）：底部导航，表格转卡片列表

### 4.4 动效设计

- 页面加载：内容区淡入（300ms），导航栏从左滑入
- 追溯面板：右侧滑入（250ms ease-out）
- 状态变更：标签颜色渐变 + 轻微缩放（200ms）
- 撤回操作：整行背景闪烁黄色 → 恢复（500ms）
- 导出进度：顶部进度条平滑增长
