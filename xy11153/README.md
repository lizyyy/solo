# 🏀 篮球场预约处球场天气补偿 CLI 工具

用于处理篮球场预约记录，自动识别天气补偿场景，将正常记录和异常记录分开，并识别局部降雨、半场使用等特殊场景。

## ✨ 功能特性

- 📋 **预览模式** - 先预览计划动作，确认后再执行
- 📝 **正式模式** - 写入结果文件，带时间戳避免覆盖
- 🌧️ **局部降雨识别** - 稳定识别局部降雨记录
- 🏀 **半场使用识别** - 识别半场使用场景
- 🔄 **可复跑输出** - 相同输入每次运行分类结果一致
- ⚙️ **规则可配置** - 默认口径清晰，便于接手修改
- 📦 **离线可用** - 所有样例内置，不依赖外网服务

## 🚀 快速开始

```bash

```

### 2. 预览模式（推荐先运行）

先预览处理结果，不写入文件：


### 3. 正式模式（写入文件）

## 📖 详细使用说明

### 命令格式

```bash
# 预览模式
ts-node src/index.ts preview [选项]

# 正式模式
ts-node src/index.ts run [选项]
```

### 命令选项

| 选项 | 缩写 | 说明 | 默认值 |
|------|------|------|--------|
| `--input <path>` | `-i` | 输入CSV文件路径 | `samples/sample-data.csv` |
| `--output <path>` | `-o` | 输出目录路径 | `output/` |
| `--rules <path>` | `-r` | 规则配置文件路径 | `config/rules.json` |

### 使用示例

```bash
# 使用自定义输入文件
npm run preview -- --input /path/to/your/data.csv

# 指定输出目录
npm run run -- --output /path/to/output

# 使用自定义规则配置
npm run preview -- --rules /path/to/custom-rules.json
```

## ⚙️ 规则配置说明

规则配置文件位于 `config/rules.json`，包含以下配置项：

### 1. 记录分类规则

#### 正常记录 (`normalRecords`)

默认判定条件（满足任一即可）：
- 天气状况不包含：雨、雷、暴、雪
- `是否降雨` 字段为 `否`
- `补偿状态` 字段为 `正常`

#### 异常记录 (`abnormalRecords`)

默认判定条件（满足任一即可）：
- `是否降雨` 字段为 `是`
- 天气状况包含：雨、雷、暴
- `补偿状态` 字段为 `待补偿` 或 `待复核`

### 2. 特殊场景识别

#### 局部降雨 (`partialRain`)

识别规则（满足任一即可）：
- 备注包含：局部、半场、南半场、北半场、时段、突然、后半场
- `降雨时段` 字段非空
- `球场使用情况` 为 `中断`

标签：`局部降雨`

#### 半场使用 (`halfCourtUsage`)

识别规则（满足任一即可）：
- `球场使用情况` 为 `半场使用`
- 备注包含：半场、北半场、南半场、训练、友谊赛

标签：`半场使用`

### 3. 补偿规则

| 补偿类型 | 触发条件 | 补偿比例 |
|----------|----------|----------|
| 全额补偿 | 球场使用情况为 `未使用` | 1.0 |
| 半场补偿 | 球场使用情况为 `中断` 或 `半场使用` | 0.5 |

### 4. 输出配置

- 编码：UTF-8
- 分隔符：逗号 (`,`)
- 包含表头：是
- 稳定输出：是（按 `预约编号` 排序）
- 时间戳格式：`YYYY-MM-DD_HH-mm-ss`

### 5. 数据验证

必需字段：
- 预约编号
- 球场编号
- 预约日期
- 天气状况
- 是否降雨

## 📊 输入数据格式

CSV 文件需包含以下字段：

| 字段名 | 说明 | 示例 |
|--------|------|------|
| 预约编号 | 预约唯一标识 | Y20240501001 |
| 球场编号 | 球场标识 | A01 |
| 预约日期 | YYYY-MM-DD | 2024-05-01 |
| 开始时间 | HH:mm | 09:00 |
| 结束时间 | HH:mm | 11:00 |
| 预约时长 | 分钟 | 120 |
| 预约人数 | 人数 | 10 |
| 天气状况 | 天气描述 | 晴/小雨/雷阵雨 |
| 是否降雨 | 是/否 | 是 |
| 降雨时段 | 具体时段 | 14:30-15:30 |
| 球场使用情况 | 使用状态 | 正常/中断/未使用 |
| 补偿状态 | 状态 | 正常/待补偿/待复核 |
| 备注 | 补充说明 | 局部降雨 |
| 数据来源 | 数据来源 | 系统导入/手动录入 |

## 📁 输出文件说明

正式模式会在输出目录生成以下文件（文件名带时间戳）：

| 文件名 | 说明 |
|--------|------|
| `正常记录_YYYY-MM-DD_HH-mm-ss.csv` | 无需补偿的正常预约记录 |
| `异常记录_YYYY-MM-DD_HH-mm-ss.csv` | 需要天气补偿的异常记录 |
| `局部降雨记录_YYYY-MM-DD_HH-mm-ss.csv` | 识别出的局部降雨场景 |
| `半场使用记录_YYYY-MM-DD_HH-mm-ss.csv` | 识别出的半场使用场景 |

## 🔧 自定义规则

如需修改业务规则，编辑 `config/rules.json` 文件：

### 修改分类条件示例

```json
"normalRecords": {
  "description": "正常记录 - 无需补偿",
  "conditions": [
    {
      "field": "天气状况",
      "operator": "notContains",
      "values": ["雨", "雷", "暴", "雪", "雾"]
    }
  ],
  "matchStrategy": "any",
  "outputFile": "正常记录.csv"
}
```

### 支持的操作符

| 操作符 | 说明 |
|--------|------|
| `equals` | 等于任一值 |
| `notEquals` | 不等于所有值 |
| `contains` | 包含任一值 |
| `notContains` | 不包含所有值 |
| `containsAny` | 包含任一值（同contains） |
| `startsWith` | 以任一值开头 |
| `endsWith` | 以任一值结尾 |
| `isEmpty` | 字段为空 |
| `notEmpty` | 字段非空 |
| `matchesPattern` | 匹配正则表达式 |
