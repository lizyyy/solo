## ⏱️ 时间控制（1分钟）

1. **播放/暂停**：点击底部中间的 ▶/⏸ 按钮
2. **速度调节**：0.5x / 1x / 2x / 5x 四档
3. **快速跳转**：拖动滑块，或点击 7:30/8:15/9:00 刻度
4. **前后跳5分钟**：点击 ⏮ / ⏭ 按钮

> 💡 早高峰时段 7:30-8:45 已用橙色高亮，8:15为峰值

---

## 🔍 瓶颈检测与联动（1分钟）

1. **查看异常**：右侧面板自动列出当前异常，按风险等级排序
2. **点击定位**：点击任意异常项 → 3D场景相机自动飞入对应区域
3. **视觉识别**：
   - 🔴 红色八面体 + 脉冲环 = 高风险
   - 🟡 黄色十二面体 = 中风险
   - 🟣 紫色X标记 = 数据冲突
4. **异常确认**：点击异常项自动标记为"已确认"

---

## ⚠️ 数据冲突处理（30秒）

1. 左下角面板显示待处理冲突
2. 查看三方数据源及置信度：
   - 站厅主信息（青）
   - 闸机补证据（黄）
   - 扶梯补证据（橙）
3. 置信度差>10%：点击"自动解决"（采信最高）
4. 置信度差≤10%：选择采信某一数据源（人工判断）

---

## 📄 报告导出（30秒）

1. 菜单栏 → 报告 → 生成当前报告
2. 预览报告内容：
   - 异常时间线 + 证据链
   - 数据冲突记录表
   - 运营建议
3. 选择格式：Markdown / JSON
4. 点击"导出报告"自动下载

> 💡 报告包含完整留痕，可用于事后复盘

## ❓ 常见问题

**Q: 3D场景卡顿怎么办？**
A: 降低浏览器窗口大小，或设置 dpr={1} 关闭高DPI渲染。

**Q: 如何查看历史异常？**
A: 拖动时间轴回溯，报告中会包含完整时间线。

**Q: 冲突解决后能撤销吗？**
A: 所有操作留痕，可在冲突面板查看历史记录，但不能撤销。

**Q: 数据从哪里来？**
A: 当前为Mock数据，实际接入时替换 `data/` 目录下的数据源即可。
