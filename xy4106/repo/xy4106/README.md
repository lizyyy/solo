# 盲文教材分页校对员

专为特教老师设计的本地命令行工具，用于制作和校对盲文教材。

## 功能特性

- **init**: 初始化课程目录结构
- **import**: 导入课文(Markdown)、注音(CSV)和图说明(JSON)
- **compose**: 生成盲文分页草稿（汉字→拼音→盲文点位映射+行宽控制）
- **check**: 智能校对（未注音词、超行、图文断链、页码跳号、同音词歧义）
- **export**: 导出多格式校对包（BRF/TXT/Markdown/JSON）

## 安装

```bash
pip install -e .
```

或使用别名：

```bash
# 安装后可以使用 braille-proofreader 或 br 命令
```

## 快速开始

### 1. 创建测试课程

```bash
# 在临时目录创建带样例数据的课程
mkdir -p /tmp/braille_test
cd /tmp/braille_test

# 初始化课程，使用样例数据
br init 语文第一课 --with-sample
```

### 2. 查看目录结构

```
语文第一课/
├── 课文/
│   └── 第一课_春天.md          # Markdown格式课文
├── 注音/
│   └── 第一课_注音.csv          # 词语注音表
├── 图说明/
│   └── 第一课_图说明.json       # 触摸图说明
├── 模板/
│   └── 页码模板.txt             # 页码排版模板
├── 输出/                         # 导出文件存放目录
├── 草稿/                         # 中间数据存放目录
└── 课程配置.json                 # 课程配置
```

### 3. 导入数据

```bash
br import --course 语文第一课
```

这会解析：
- Markdown课文 → 提取段落、图片引用
- CSV注音表 → 建立词语-拼音映射
- JSON图说明 → 提取图片编号和说明

### 4. 生成盲文分页

```bash
# 使用默认行宽32方，每页24行
br compose --course 语文第一课

# 或自定义参数
br compose --course 语文第一课 --line-width 28 --lines 20
```

### 5. 校对检查

```bash
br check --course 语文第一课

# 显示详细信息
br check --course 语文第一课 --verbose
```

校对会检测：
- **未注音词**: 课文中出现但注音表中没有的词语
- **超行**: 盲文行宽超过设置的限制
- **图文引用断链**: 课文引用的图片在图说明中不存在
- **页码跳号/重复**: 页码不连续或重复
- **同音词歧义**: 同一拼音对应多个词语且盲文相同

### 6. 导出校对包

```bash
# 导出所有格式
br export --course 语文第一课

# 指定格式导出
br export --course 语文第一课 --format brf --format md

# 包含校对报告
br export --course 语文第一课 --with-report
```

导出格式说明：

| 格式 | 扩展名 | 用途 |
|------|--------|------|
| BRF | .brf | 盲文标准格式，可直接用于盲文打印机/显示设备 |
| TXT | .txt | 纯文本格式，含Unicode盲文字符，便于阅读 |
| Markdown | .md | 可读性格式，含问题列表，便于校对修改 |
| JSON | .json | 完整结构化数据，便于程序处理 |

## 文件格式说明

### 课文 (Markdown)

```markdown
# 第一课 春天

春天来了，大地苏醒了。

小草从土里钻出来，嫩嫩的，绿绿的。

![春天的花朵](fig1)
```

- 标题: `# 标题` 或 `## 标题`
- 图片引用: `![替代文本](图片编号)`

### 注音表 (CSV)

```csv
词语,拼音,盲文点位,备注
春天,chun tian,1245 12356 1234 24,季节名称
大地,da di,145 135 145 24,
苏醒,su xing,234 136 1345 1456,
```

列说明：
- **词语**: 中文词语
- **拼音**: 对应拼音（空格分隔多字）
- **盲文点位**: 可选，自定义盲文点位
- **备注**: 可选，用于区分同音词

### 图说明 (JSON)

```json
{
    "图片": [
        {
            "编号": "fig1",
            "说明": "春天的花朵：桃花红、杏花粉...",
            "路径": "images/fig1.png",
            "替代文本": "三种颜色的花朵",
            "标签": ["花朵", "春天"],
            "位置": "第三段后"
        }
    ]
}
```

## 命令用例

### 用例1: 完整工作流

```bash
# 1. 初始化课程
br init 三年级语文 --with-sample

# 2. （可选）替换样例文件为真实内容
# cp 我的课文.md 三年级语文/课文/
# cp 我的注音.csv 三年级语文/注音/
# cp 我的图说明.json 三年级语文/图说明/

# 3. 导入数据
br import --course 三年级语文

# 4. 生成分页
br compose --course 三年级语文 --line-width 32

# 5. 校对检查
br check --course 三年级语文 --verbose

# 6. 根据校对结果修改源文件，重复步骤3-5

# 7. 导出最终版本
br export --course 三年级语文 --with-report
```

### 用例2: 只检查特定问题

```bash
# 先运行 compose 生成分页数据
br compose --course 我的课程

# 再运行 check
br check --course 我的课程
```

### 用例3: 批量处理多篇课文

```bash
# 将多篇课文放入课文目录
# 课文/
#   ├── 第一课_春天.md
#   ├── 第二课_夏天.md
#   └── 第三课_秋天.md

# import 会自动导入所有文件
br import --course 我的课程

# compose 按顺序处理
br compose --course 我的课程
```

## 注意事项

1. 本工具使用**现行盲文**映射规则，如需使用双拼盲文请自定义盲文点位列
2. 行宽默认32方（标准盲文纸宽度），可根据实际需求调整
3. 同音词问题强烈建议在备注列区分，或手动调整盲文点位
4. BRF格式导出使用标准ASCII盲文映射，兼容大多数盲文设备
