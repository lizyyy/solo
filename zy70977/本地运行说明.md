# 设备租赁客服系统 - 本地运行说明

## 项目概述
设备租赁客服系统，解决租赁订单、维修记录、押金扣减的跨订单追踪问题。支持CSV/JSON文件导入，自动按规则处理押金扣减，幂等导入防止重复提交，完整的押金流水追踪。

## 快速开始

### 1. 安装依赖
```bash
npm install
```

### 2. 启动服务
```bash
npm start
```
服务启动在 http://localhost:3000

### 3. 运行测试（新开一个终端）
```bash
npm test
```

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/import/rental` | 上传租赁订单CSV |

### 查询接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/batches` | 查询所有导入批次 |
| GET | `/api/batch/:batchId` | 查询批次详情 |
| GET | `/api/rental/orders` | 查询租赁订单（支持?customer=?device=?status=） |
| GET | `/api/repair/records` | 查询维修记录（支持?device=?order_no=） |

| GET | `/api/deposit/trace/:orderNo` | **押金流水追踪**（核心功能） |

## 支持的规则类型

### 1. 逾期租金规则 (overdue_rent)
- 逾期7天以内：按日租金1.5倍 × 逾期天数扣减
- 逾期8-30天：扣减押金10%
- 逾期30天以上：扣减全部押金

### 2. 维修责任规则 (repair_liability)
- 客户责任：全额扣减维修费用
- 公司责任：不扣减

## 幂等性说明
同一文件重复上传不会重复生效：
1. 系统计算文件MD5哈希
2. 通过哈希前缀匹配历史批次
3. 匹配成功直接返回上次结果，标记 `isDuplicate: true`

## 文件格式要求

### 租赁订单 CSV
```csv
order_no,device_id,customer_name,customer_phone,rental_start_date,rental_end_date,daily_rent,deposit_amount,status
ORD2024001,DEV001,张三,13800138001,2024-01-01,2024-01-15,50,2000,active
```

### 维修记录 JSON
```json
[
  {
    "repair_no": "REP2024001",
    "device_id": "DEV001",
    "rental_order_no": "ORD2024001",
    "repair_date": "2024-01-18",
    "repair_type": "屏幕损坏",
    "repair_cost": 500,
    "liability": "customer",
    "description": "客户使用不当",
    "status": "pending"
  }
]
```

### 押金规则 JSON
```json
[
  {
    "rule_code": "OVERDUE_001",
    "rule_name": "逾期7天以内扣减",
    "rule_type": "overdue_rent",
    "condition_expr": "overdueDays <= 7",
    "deduction_percent": 0,
    "deduction_amount": 0,
    "priority": 1,
    "is_active": true
  }
]
```

## 目录结构

## 复跑说明
如需完全重置测试：
```bash
# 删除数据库
rm -rf data/

# 重启服务
npm start

# 重新跑测试
npm test
```
