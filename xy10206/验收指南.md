### 验收场景 1：查看当前场景状态

**业务意义：** 了解剧场有哪些场景，当前激活的是哪个灯光版本

**操作步骤：**

打开一个新的终端窗口，复制以下命令（将 `3001` 替换为你记录的端口号）：

```bash
curl http://127.0.0.1:3001/api/scenes/scene-001
```

**快速方式**：先设置环境变量，后续命令会自动使用正确端口：
```bash
export API_PORT=3001  # 替换为你实际的端口号
curl http://127.0.0.1:$API_PORT/api/scenes/scene-001
```

**预期结果：**
- 看到场景名称：《天鹅湖》第二幕 - 月夜湖畔
- 看到当前激活版本：v1.0.0
- 看到场景状态：UNLOCKED（已解锁）

---

### 验收场景 2：创建新版本预设

**业务意义：** 灯光师根据导演意见调整灯光参数，保存为新版本

**操作步骤：**

复制以下命令到终端：

```bash
curl -X POST http://127.0.0.1:$API_PORT/api/presets \
  -H "Content-Type: application/json" \
  -d '{
    "sceneId": "scene-001",
    "version": "v3.0.0",
    "name": "浪漫紫调升级版",
    "description": "导演要求增加浪漫氛围",
    "lightPositions": {
      "主光-左": { "intensity": 75, "color": "#7C3AED", "pan": 0, "tilt": -15 },
      "主光-右": { "intensity": 75, "color": "#7C3AED", "pan": 0, "tilt": -15 },
      "面光-1": { "intensity": 45, "color": "#EDE9FE", "pan": 0, "tilt": 0 },
      "追光-1": { "intensity": 100, "color": "#FFFFFF", "pan": 0, "tilt": -30 }
    },
    "createdBy": "灯光师-小张"
  }'
```

**预期结果：**
- 返回 success: true
- 预设状态为：DRAFT（草稿）
- 有明确的成功消息

---

### 验收场景 3：提交审批

**业务意义：** 灯光师完成调整后，提交给导演审批

**操作步骤：**

先查看所有预设，找到刚创建的 v3.0.0 的 ID：
```bash
curl http://127.0.0.1:$API_PORT/api/presets?sceneId=scene-001
```

然后用返回的 presetId 替换下面命令中的 `你的presetId`：

```bash
curl -X POST http://127.0.0.1:$API_PORT/api/approvals/submit \
  -H "Content-Type: application/json" \
  -d '{
    "presetId": "你的presetId",
    "requestedBy": "灯光师-小张",
    "reason": "根据导演意见调整紫调氛围"
  }'
```

**预期结果：**
- 预设状态变为：PENDING（待审批）
- 创建了审批记录

---

### 验收场景 4：导演审批通过

**业务意义：** 导演审核通过后，版本才能用于演出

**操作步骤：**

用返回的 approvalId 替换下面命令中的 `你的approvalId`：

```bash
curl -X POST http://127.0.0.1:$API_PORT/api/approvals/decide \
  -H "Content-Type: application/json" \
  -d '{
    "approvalId": "你的approvalId",
    "approvedBy": "导演-王导",
    "decision": "APPROVE",
    "reason": "效果很好，可以冻结"
  }'
```

**预期结果：**
- 预设状态变为：APPROVED（已批准）
- 显示审批人：导演-王导

---

### 验收场景 5：冻结版本（演出前确认）

**业务意义：** 技术主管确认版本无误后冻结，防止误修改

**操作步骤：**

```bash
curl -X POST http://127.0.0.1:$API_PORT/api/presets/freeze \
  -H "Content-Type: application/json" \
  -d '{
    "presetId": "你的presetId",
    "operator": "技术主管-李工"
  }'
```

**预期结果：**
- 预设状态变为：FROZEN（已冻结）
- 显示冻结人和冻结时间

---

### 验收场景 6：回滚到确认版本

**业务意义：** 彩排发现问题，快速回到之前确认的版本

**操作步骤：**

```bash
curl -X POST http://127.0.0.1:$API_PORT/api/presets/rollback \
  -H "Content-Type: application/json" \
  -d '{
    "sceneId": "scene-001",
    "targetPresetId": "preset-001-v1",
    "rolledBackBy": "技术主管-李工",
    "reason": "紫调与演员服装冲突，回滚到确认版本"
  }'
```

**预期结果：**
- 当前激活版本回到 v1.0.0
- 原版本被冻结
- 生成回滚记录

---

### 验收场景 7：锁定场景（演出前防护）

**业务意义：** 演出前锁定场景，防止任何人误修改

**操作步骤：**

```bash
curl -X POST http://127.0.0.1:$API_PORT/api/scenes/lock \
  -H "Content-Type: application/json" \
  -d '{
    "sceneId": "scene-001",
    "lockedBy": "技术主管-李工",
    "reason": "演出前1小时，防止误操作"
  }'
```

**预期结果：**
- 场景状态变为：LOCKED（已锁定）
- 显示锁定人和锁定原因

## ❌ 异常场景验收

**操作：**
```bash
curl -X POST http://127.0.0.1:$API_PORT/api/presets \
  -H "Content-Type: application/json" \
  -d '{
    "sceneId": "scene-001",
    "version": "v1.0.0",
    "name": "重复版本测试",
    "lightPositions": {
      "主光-左": { "intensity": 50, "color": "#FFFFFF", "pan": 0, "tilt": 0 }
    },
    "createdBy": "测试员"
  }'
```

**预期：** 返回错误，提示版本已存在

---

### 异常 2：缺少必要字段

**操作：**
```bash
curl -X POST http://127.0.0.1:$API_PORT/api/presets \
  -H "Content-Type: application/json" \
  -d '{
    "sceneId": "scene-001",
    "version": "v9.9.9",
    "name": "缺少灯位参数"
  }'
```

**预期：** 返回错误，提示缺少 lightPositions 字段

---

### 异常 3：灯位参数错误（亮度超出范围）

**操作：**
```bash
curl -X POST http://127.0.0.1:$API_PORT/api/presets \
  -H "Content-Type: application/json" \
  -d '{
    "sceneId": "scene-001",
    "version": "v9.9.8",

      "主光-左": { "intensity": 150, "color": "#FFFFFF", "pan": 0, "tilt": 0 }

    "createdBy": "测试员"

```

**预期：** 返回错误，提示 intensity 必须在 0-100 之间

---

    "name": "锁定后创建",
    "lightPositions": {
      "主光-左": { "intensity": 50, "color": "#FFFFFF", "pan": 0, "tilt": 0 }
    },
    "createdBy": "测试员"

**预期：** 返回错误，提示场景已锁定

## 💡 业务流程说明

```
灯光师创建版本 (DRAFT)
      ↓
提交审批 (PENDING)
      ↓
导演审批 (APPROVED)  ← 审批证据
      ↓
技术主管冻结 (FROZEN)  ← 演出前确认
      ↓
激活为演出版本 (ACTIVE)
      ↓
┌─────────────────┐
│ 发现问题？       │
└────────┬────────┘
         ↓ 是
    回滚到确认版本 ← 关键功能
         ↓
    锁定场景防误改 ← 关键校验
```

## 🎬 剧场实际使用场景

### 场景：《天鹅湖》演出前 2 小时

1. **彩排时**：灯光师小张多次调整灯光效果，创建了 v1.0.0、v2.0.0、v3.0.0 三个版本
2. **导演确认**：王导审批通过 v1.0.0 为最终版本
3. **技术主管冻结**：李工冻结 v1.0.0，防止误修改
4. **激活版本**：v1.0.0 成为当前演出版本
5. **意外发生**：彩排时助理误操作激活了 v3.0.0
6. **快速回滚**：发现问题后，10 秒内回滚到 v1.0.0 确认版本
7. **锁定防护**：演出前 1 小时锁定场景，确保万无一失
