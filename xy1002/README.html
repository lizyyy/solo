项目简介

这是一个简单的示例项目，用于展示如何创建一个基本的HTML网页。

功能特性

  • 简洁的"Hello World"首页
  • 响应式设计，适配不同屏幕尺寸
  • 美观的页面样式

技术栈

  • HTML5
  • CSS3

如何运行

你可以使用任何HTTP服务器来运行这个项目。例如，使用Python内置的HTTP服务器：

python3 -m http.server 8000

然后在浏览器中访问 http://localhost:8000/

文件结构

  • index.html - 首页
  • README.html - 说明文档页面
