## 1. 产品概述

商业街外摆时段审批系统，用于城更项目经理阿宁与市政巡检员之间的协作审批。核心解决同一小区新旧名称混淆、无障碍坡道记录追溯、夜间采样点可信度判定等问题，确保导出明细、页面展示、接口返回三处数据完全一致。

- 目标用户：城更项目经理（阿宁）、市政巡检员、街道审批人员
- 核心价值：保留完整证据链，消除口头约定，明确边界规则，可回滚可追溯

## 2. 核心功能

### 2.1 用户角色

| 角色 | 登录方式 | 核心权限 |
|------|----------|----------|
| 城更项目经理（阿宁） | 账号登录 | 导入无障碍坡道记录、补看夜间采样点、更新摘要、标记待复核 |
| 市政巡检员 | 账号登录 | 复核新旧名称冲突、确认最终状态、追溯原始证据 |
| 街道审批人员 | 账号登录 | 查看审批摘要、导出明细 |

### 2.2 功能模块

1. **数据导入页**：无障碍坡道记录导入、原始行号保留、数据预览
2. **审批工作台**：三步流程处理（导入→补看→更新）、新旧名称冲突标记、状态流转
3. **记录详情页**：原始行号展示、人工改动历史、处理状态时间线、证据回溯
4. **摘要导出页**：街道会看摘要生成、数据一致性校验、导出明细
5. **边界规则页**：规则查阅、判定逻辑说明、回滚指引

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 数据导入页 | 文件上传区 | 支持 CSV/Excel 导入，实时预览，保留原始行号 |
| 数据导入页 | 冲突检测区 | 自动识别同一小区新旧名称，高亮标记待复核 |
| 审批工作台 | 流程进度条 | 三步流程可视化：导入→补看→更新 |
| 审批工作台 | 记录列表 | 每条记录显示：小区名（新旧）、无障碍坡道状态、夜间采样点可信度、当前处理人 |
| 审批工作台 | 操作区 | 阿宁补看、标记待巡检员复核、更新摘要 |
| 记录详情页 | 证据时间线 | 原始行号、导入时间、每次改动的操作人/时间/内容 |

| 边界规则页 | 规则列表 | 新旧名称判定规则、回滚操作说明、异常处理流程 |

## 3. 核心流程

### 三步审批主流程

```mermaid
flowchart LR
    A["第一步：无障碍坡道记录第一次导入"] --> B{新旧名称冲突?}
    B -->|是| C["标记为【待巡检员复核】，不急着归正常"]
    B -->|否| D["状态：待补看夜间采样点"]
    D --> E["第二步：城更项目经理阿宁补看夜间采样点"]
    C --> E
    E --> F{采样点与坡道记录一致?}
    F -->|一致| G["状态：待更新摘要"]
    F -->|不一致| H["标记差异，保留双方数据，待巡检员确认"]
    G --> I["第三步：给街道会看的摘要更新"]
    H --> I
    I --> J["巡检员最终复核 → 完成审批"]
```

### 数据一致性保证

所有页面展示、导出明细、接口返回均读取同一份处理结果数据。同一记录在任何位置展示的状态、小区名称、处理结论完全一致。

### 证据链保留规则

- 原始行号：导入时的 Excel/CSV 行号永久保留，永不删除
- 人工改动：每次修改记录操作人、时间、修改前后内容全部留存
- 处理状态：状态变更时间线完整可追溯，支持回滚到任意历史状态

## 4. 用户界面设计

### 4.1 设计风格

- **主色调**：政务蓝 (#1E40AF)，代表正式、可信
- **辅助色**：警示橙 (#F59E0B) 标记待复核，成功绿 (#10B981) 标记已完成，异常红 (#EF4444) 标记冲突
- **中性色**：深灰 (#1F2937) 正文，中灰 (#6B7280) 辅助文字，浅灰 (#F3F4F6) 背景
- **按钮风格**：圆角 6px，轻微投影，悬停有深度变化
- **字体**：标题用思源宋体（稳重正式），正文用思源黑体（清晰易读）
- **布局风格**：左右分栏，左侧导航 + 右侧内容区，卡片式模块，留白充足
- **视觉元素**：时间线组件展示处理流程，标签系统标记状态，对比表格展示数据差异

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|---------|
| 审批工作台 | 流程进度条 | 三步横向时间线，当前步骤高亮，已完成步骤打勾 |
| 审批工作台 | 记录卡片 | 小区名称卡片突出显示，新旧名称用不同标签区分，状态标签醒目 |
| 记录详情页 | 证据时间线 | 垂直时间线，每节点显示：操作人头像、时间、改动内容摘要 |
| 记录详情页 | 数据对比区 | 左右两栏对比布局，左侧坡道记录，右侧采样点数据，差异处高亮 |
| 边界规则页 | 规则卡片 | 折叠面板，标题为规则名称，展开显示详细判定逻辑和示例 |

### 4.3 响应式

- 桌面端优先设计（1280px+）
- 平板端（768-1279px）：左右分栏改为上下布局
- 移动端（<768px）：简化导航，卡片单列展示，保证核心操作可用

### 4.4 动效设计

- 页面加载：内容区淡入 + 轻微上移
- 状态变更：状态标签颜色渐变过渡
- 时间线：滚动时节点依次出现
- 冲突标记：脉冲动画吸引注意力
