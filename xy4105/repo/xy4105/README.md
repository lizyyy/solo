# 活字排版急救员

🏛️ 博物馆研学活动专用浏览器小游戏

## 游戏简介

"活字排版急救员"是一款专为博物馆研学活动设计的教育类浏览器小游戏。玩家将扮演古籍文献抢救人员，通过拖拽散乱的汉字活字，按照古籍版式还原经典短句，体验中国古代活字印刷术的魅力。

## 核心功能

### 🎮 游戏玩法
- **拖拽排版**：将字库中的汉字活字拖放到版框中
- **顺序验证**：必须按照古籍的阅读顺序（横排/竖排）放置活字
- **禁排格**：部分格子为装饰区域，不可放置活字
- **标点规范**：根据版式方向使用正确的标点符号

### 📚 关卡系统
- **5个内置关卡**：从《论语》、唐诗、三字经等经典中选取
- **难度递增**：关卡1为入门级别，关卡5为最高难度
- **自定义关卡**：支持导入/导出JSON格式的自定义关卡

### ⚙️ 操作功能
- **撤销/重做**：支持最多50步的历史记录回溯
- **暂停功能**：游戏过程中可随时暂停
- **重新开始**：随时可以重新挑战当前关卡

### 🏆 评分系统
- **计时**：记录完成关卡的时间
- **步数**：统计操作步数
- **得分**：根据时间和步数计算综合得分
- **评级**：S/A/B/C/D 五级评级
- **本地保存**：通关记录保存在浏览器本地存储中

## 模块说明

### 1. levelData.js - 关卡数据管理
- 加载内置关卡和自定义关卡
- 关卡数据验证
- JSON导入/导出功能
- 关卡模板生成

### 2. layoutRules.js - 排版规则引擎
- 活字放置验证（越界、禁排格、顺序）
- 标点符号方向验证（横排/竖排）
- 完成状态检测
- 阅读顺序计算

### 3. dragDrop.js - 拖拽交互
- 原生拖拽支持
- 移动端触摸拖拽
- 拖放区域管理
- 视觉反馈效果

### 4. stateStorage.js - 状态存储
- 撤销/重做历史栈

- 游戏状态序列化

### 5. scoring.js - 评分系统
- 计时器功能

- 评级判定（S/A/B/C/D）

### 6. uiManager.js - UI管理
- 界面切换（主菜单/关卡选择/游戏界面）
- 关卡列表渲染
- 游戏界面渲染
- 消息提示系统

### 7. game.js - 主游戏逻辑
- 模块整合与事件协调
- 游戏流程控制
- 各模块间通信

## 快速开始

### 运行游戏

由于游戏是纯前端项目，只需使用任何现代浏览器即可运行：

1. **直接打开方式
   - 双击 `index.html` 文件在浏览器中打开

2. **本地服务器方式（推荐）
   ```bash
   # 使用 Python
   python3 -m http.server 8080
   
   # 或使用 Node.js (需要安装 http-server)
   npx http-server
   
   # 然后在浏览器访问 http://localhost:8080
   ```

### 游戏操作说明

1. **开始游戏**
   - 点击"开始游戏"按钮
   - 在关卡列表中选择想要挑战的关卡

2. **游戏操作**
   - 从左侧字库中拖拽汉字活字
   - 放置到右侧版框中的正确位置
   - 点击已放置的活字可以移除
   - 已放置的活字也可以拖拽移动

3. **完成条件**
   - 按照古籍阅读顺序（横排从左到右，竖排从右到左、从上到下）
   - 将所有目标字按正确顺序放置
   - 避开禁排格

4. **通关后**
   - 查看得分、用时、步数和评级
   - 可以选择下一关或重新挑战

## 自定义关卡

### 关卡JSON格式

```json
{
    "id": "custom_level_001",
    "title": "自定义关卡标题",
    "description": "关卡描述",
    "hint": "提示信息",
    "difficulty": 2,
    "gridSize": {
        "rows": 3,
        "cols": 4
    },
    "targetSentence": "目标句子",
    "characterPool": ["目", "标", "句", "子", "干", "扰", "字"],
    "forbiddenCells": [
        {
            "row": 1,
            "col": 1,
            "reason": "此处为装饰格"
        }
    ],
    "punctuationDirection": "horizontal",
    "maxSteps": 20,
    "targetTime": 120
}
```

### 字段说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 否 | 关卡唯一标识（导入时自动生成） |
| title | string | 是 | 关卡显示名称 |
| description | string | 否 | 关卡描述 |
| hint | string | 否 | 提示文字，帮助玩家理解目标 |
| difficulty | number | 否 | 难度等级（1-5） |
| gridSize | object | 是 | 版心尺寸 |
| gridSize.rows | number | 是 | 行数 |
| gridSize.cols | number | 是 | 列数 |
| targetSentence | string | 是 | 目标句子，按正确顺序 |
| characterPool | array | 是 | 字库，包含目标字和干扰字 |
| forbiddenCells | array | 否 | 禁排格列表 |
| forbiddenCells[].row | number | 是 | 禁排格行号（从0开始） |
| forbiddenCells[].col | number | 是 | 禁排格列号（从0开始） |
| forbiddenCells[].reason | string | 否 | 禁排原因 |
| punctuationDirection | string | 否 | 标点方向: "horizontal"（横排）或 "vertical"（竖排） |
| maxSteps | number | 否 | 限步数（0表示不限） |
| targetTime | number | 否 | 目标时间（秒），影响时间奖励计算 |

### 导入/导出

1. **导出模板**
   - 在关卡选择界面点击"导出关卡模板"
   - 得到一个完整的JSON模板文件

2. **编辑关卡**
   - 使用文本编辑器编辑JSON文件
   - 修改各项参数

3. **导入关卡**
   - 在关卡选择界面点击"导入JSON关卡"
   - 选择编辑好的JSON文件
   - 导入成功后会出现在关卡列表中（带有"自定义"标识）

## 版式说明

### 阅读顺序

- **横排（horizontal）**：从左到右，从上到下
- **横排右起（horizontal-rl）**：从右到左，从上到下（古籍常见）
- **竖排（vertical）**：从右到左列，每列从上到下（传统竖排）

### 标点符号

横排和竖排使用不同的标点符号：

| 横排 | 竖排 | 说明 |
|------|------|------|
| ， | ︐ | 逗号 |
| 。 | ︒ | 句号 |
| 、 | ︑ | 顿号 |
| ： | ︓ | 冒号 |
| ； | ︔ | 分号 |
| ？ | ︖ | 问号 |
| ！ | ︕ | 感叹号 |
| 「 | ﹁ | 左引号 |
| 」 | ﹂ | 右引号 |
| （ | ︵ | 左括号 |
| ） | ︶ | 右括号 |
