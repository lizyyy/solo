# API文档互动示例台

一个面向技术练习的全栈项目，用于业务分析师上传/录入接口文档、查看示例参数变化、处理认证方式、执行记录异常处理，以及示例收藏功能。

## 功能特性

### 后端 (Python FastAPI)
- **文档管理**: 支持录入和上传API接口文档
- **脏数据检测**: 自动检测SQL注入、XSS攻击、非法字符等风险
- **认证处理**: 支持多种认证方式配置
- **执行记录**: 完整记录每次请求的状态和结果
- **错误解释**: 自动生成错误原因和修正说明
- **示例收藏**: 保存标准参数示例用例

### 前端 (React)
- **文档列表**: 查看、录入、上传API文档
- **参数执行**: 配置参数并执行请求
- **执行记录**: 展示脏数据拦截记录，提供"重试"和"回滚"按钮
- **差异对比**: 直观展示原始参数与修正后参数的差异
- **错误解释**: 展示系统的错误分析和修正说明
- **示例收藏**: 管理标准用例，可追溯到原始文档

## 脏数据示例

系统预置了以下类型的脏数据用于演示：

1. **SQL注入**: `admin' OR '1'='1`
2. **XSS攻击**: `<script>alert('xss')</script>`
3. **负数参数**: `id: -1`

## 快速开始

### 启动后端服务

```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

后端API文档: http://localhost:8000/docs

### 启动前端服务

```bash
cd frontend
npm install
npm start
```

前端访问: http://localhost:3000

## 使用说明

1. **查看文档列表**: 首页展示所有已录入的API文档，包含预置的示例数据
2. **执行测试**: 点击文档进入详情页，在"执行测试"标签页配置参数并执行
3. **查看拦截记录**: 在"执行记录"页面查看所有脏数据被拦截的记录，对比修正前后的差异
4. **收藏示例**: 将标准参数示例添加到收藏，作为标准用例
5. **查看原始内容**: 在文档详情页的"原始内容"标签页查看文档的原始输入和处理后结果

## 技术栈

- **后端**: Python 3.8+, FastAPI, SQLAlchemy, SQLite
- **前端**: React 18+, React Router, Axios
- **数据验证**: 正则表达式匹配，多维度安全检测
