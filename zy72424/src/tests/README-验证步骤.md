| S1-5 | 查看【已导入截图】卡片 | 图片卡片 | `contract-test-A.png` 左下角**没有** "重复导入" 标签 |

## 错误速查表

如任何一步不满足预期，对照下表定位：

| 症状 | 可能原因 | 检查位置 |
|------|----------|----------|
| 导入次数变成 "21" | Number() 转换丢失 | `fileHash.ts` 的 `handleDuplicateImport` 第 53 行 |
| 回滚后 importCount 是字符串 "2" | 回滚时没做类型转换 | `useStore.ts` 的 `rollbackHistory` 474-479 行 |
| 回滚备注后排练记录状态没变 | 联动逻辑未执行 | `useStore.ts` rollback 里 track_alias 分支 |
| 重复导入后 contracts 数量 +1 | 哈希检查不对 | `fileHash.ts` `checkDuplicate` |
| 备注换行丢失 | CSS 类名不对 | `index.css` `.remark-preserve` |
