## 1. 产品概述

版权采样授权台账——面向音乐制作人与版权复核团队的专业工具，用于管理采样音乐的授权期限、可用平台、分成比例全生命周期。解决核心问题：授权到期不自知、平台越界无感知、分成比例缺失导致结算争议。目标用户为版权复核会、制作人、法务团队。

## 2. 核心功能

### 2.1 用户角色

| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 版权复核员 | 系统主用户 | 录入/编辑采样、合同、平台、分成、发行计划；查看台账报告；导出报告 |
| 制作人 | 协作方 | 查看自身作品采样清单与授权状态；提交发行计划 |
| 法务 | 审核方 | 查看合同到期预警、平台越界提示；审阅台账报告 |

### 2.2 功能模块

1. **采样清单页**：采样条目管理（原始作品、采样片段、采样类型、来源信息），关联合同与分成规则
2. **授权合同页**：合同录入与管理（合同编号、授权方、被授权方、授权类型、起止日期、附件），状态自动判定
3. **平台范围页**：授权平台配置（平台名称、平台类型、授权区域、期限），平台越界检测
4. **分成规则页**：分成比例定义（权利方、比例、结算周期），分成试算计算器
5. **发行计划页**：发行排期（发行日期、目标平台、关联采样），与授权期限联动校验
6. **台账报告页**：全局台账视图，风险提示面板，授权状态总览，报告导出

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 采样清单 | 采样列表 | 展示所有采样条目，支持搜索、筛选、新增/编辑；缺失合同或分成时标红提示 |
| 采样清单 | 采样详情 | 展示单个采样的完整信息链：原始作品→合同→平台→分成→发行 |
| 授权合同 | 合同列表 | 展示所有合同，按状态分组（生效/即将到期/已过期/待签署），到期前30天预警 |
| 授权合同 | 合同详情 | 合同完整信息，含附件上传入口；过期合同时明确标注"卡在：授权到期，需续签" |
| 平台范围 | 平台列表 | 展示已授权平台，标注授权状态；检测发行计划中使用的平台是否在授权范围内 |
| 平台范围 | 越界检测 | 当发行计划选用未授权平台时，提示"平台越界：XX平台未在合同授权范围" |
| 分成规则 | 分成列表 | 展示所有分成规则，缺失分成比例时标注"分成缺失：无法计算结算金额" |
| 分成规则 | 分成试算 | 输入预估收益，按分成规则计算各方分配金额 |
| 发行计划 | 计划列表 | 展示所有发行计划，与授权期限和平台范围联动校验 |
| 发行计划 | 校验结果 | 发布前自动校验：授权是否有效、平台是否越界、分成是否完整 |
| 台账报告 | 总览面板 | 汇总统计：采样总数、有效/过期合同、平台覆盖、风险条目 |
| 台账报告 | 风险提示 | 聚合所有风险项（过期、越界、缺失），按严重程度排列，标注具体卡点步骤 |
| 台账报告 | 授权状态 | 以时间线/甘特图展示各合同授权周期 |
| 台账报告 | 报告导出 | 导出台账报告为CSV，含风险项与校验结果 |

## 3. 核心流程

用户录入采样→关联授权合同→配置授权平台与分成规则→创建发行计划→系统自动校验（授权有效期+平台范围+分成完整性）→生成台账报告→复核会审阅→导出最终报告

## 4. 用户界面设计

### 4.1 设计风格

- 主色调：深墨绿(#0F2419)搭配琥珀金(#D4A853)强调色，传达专业与严谨
- 辅助色：暖灰(#F5F3EF)作为背景，深灰(#1A1A1A)文字
- 风险色：红色(#DC2626)高危、橙色(#F59E0B)中危、蓝色(#3B82F6)提示
- 按钮风格：圆角6px，主操作用琥珀金填充，次要操作用描边
- 字体：标题用 Noto Serif SC 宋体感衬线体，正文用系统无衬线体
- 布局：左侧固定导航栏 + 右侧内容区，卡片式内容模块
- 图标：lucide-react 图标库

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 采样清单 | 采样列表 | 表格布局，行内状态标签，搜索栏，浮动新增按钮 |
| 授权合同 | 合同列表 | 卡片网格布局，顶部状态筛选标签页，到期倒计时标签 |
| 平台范围 | 平台列表 | 分组卡片（按平台类型），授权状态徽章，越界红色高亮 |
| 分成规则 | 分成列表 | 表格+可视化饼图，缺失行灰色虚线占位，试算弹窗 |
| 发行计划 | 计划列表 | 时间轴布局，校验结果内嵌，不通步骤红色标注 |
| 台账报告 | 总览面板 | 统计卡片组+风险列表+时间线图，导出按钮固定顶栏 |

### 4.3 响应式

桌面优先设计，1280px以上完整体验，768px以下折叠侧边栏为汉堡菜单，表格转卡片视图。
