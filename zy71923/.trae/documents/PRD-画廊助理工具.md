## 1. 产品概述

画廊助理布展协调工具，为策展人提供统一视图，整合灯光记录、策展备注和作品清单三类数据到同一条时间线，解决多来源数据异步、版本混乱的问题。

- 核心目标：帮助策展人理清布展过程中多源数据的先后关系和变更历史，明确每一项的处理状态和下一步动作
- 目标用户：画廊策展人、展览协调员
- 核心价值：减少信息差，避免因灯光记录早到、备注晚补、手工改动等异步操作导致的布展错误

## 2. 核心特性

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 策展人 | 无需注册，本地工具 | 查看时间线、艺术驻留排期、布展清单，确认/标记状态 |

### 2.2 功能模块

1. **时间线视图**：统一展示灯光记录、策展备注、作品清单三类数据，按时间轴排列，区分不同来源
2. **艺术驻留排期**：智能判断每条记录的变更类型（补材料/改结论），展示判断理由、原因说明和下一步动作
3. **布展清单**：按处理口径分类展示（已确认/待补/人工改过），带完整处理说明

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页面 | 顶部导航 | 工具标题、当前展览名称、视图切换标签（时间线/排期/清单） |
| 主页面 | 时间线视图 | 左侧时间轴，右侧按时间排列的记录卡片，卡片标注来源类型（灯光/备注/清单），颜色区分 |
| 主页面 | 艺术驻留排期 | 列表形式展示每条驻留记录，包含：作品信息、变更类型标签（补材料/改结论）、自动判断理由、问题说明（如尺寸单位错误来源）、下一步责任人、状态标记 |
| 主页面 | 布展清单 | 三栏布局（已确认/待补/人工改过），每栏下作品卡片带处理口径说明，可拖拽或点击切换状态 |

## 3. 核心流程

策展人打开工具 → 查看时间线了解三类数据的时间顺序和交叉情况 → 切换到艺术驻留排期查看每条记录的判断结果和待办 → 发现尺寸单位错误等问题时查看来源和责任人 → 切换到布展清单按分类确认布展状态 → 标记完成或待补充项。

```mermaid
    A["打开工具"] --> B["时间线视图<br/>查看三类数据时间线"]

    C --> D{"发现问题？"}
    D -->|是| E["查看问题来源<br/>灯光记录/策展备注"]
    D -->|否| F["布展清单<br/>按分类确认"]
    E --> G["明确下一步责任人"]
    G --> F
    F --> H["标记状态<br/>确认/待补/改过"]
```

## 4. 用户界面设计

### 4.1 设计风格

**整体调性**：极简编辑风格，接近档案管理系统的严谨感，强调信息层次而非视觉装饰，符合画廊专业调性。

- **主色**：深墨灰 `#1A1A1A`（文字、标题），象牙白 `#FAFAF7`（背景）
- **强调色**：
  - 灯光记录：赭石橙 `#C17817`
  - 策展备注：靛青蓝 `#2C5F8C`
  - 作品清单：森林绿 `#3D6B4F`
  - 待补状态：锈红 `#A84230`
  - 已确认：墨绿 `#2E5339`
  - 人工改过：暖棕 `#8B6914`
- **字体**：
  - 标题：Cormorant Garamond（衬线，艺术感）
  - 正文：Source Serif Pro（易读、专业）
  - 数据/编号：JetBrains Mono（等宽，清晰）
- **布局**：
  - 顶部固定导航栏 + 下方三标签页切换
  - 时间线采用左侧轴线 + 右侧卡片的经典档案式布局
  - 布展清单采用三列卡片墙布局
- **交互**：
  - 卡片悬停时轻微上浮，边框变色
  - 状态切换有平滑过渡动画
  - 时间线滚动时当前时间点高亮

### 4.2 页面设计概述

| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页面 | 顶部导航 | 左侧：「画廊助理 · 布展协调」标题（Cormorant Garamond 24px），右侧：三个标签按钮（时间线 / 驻留排期 / 布展清单），下划线指示当前激活 |
| 主页面 | 时间线视图 | 左侧垂直时间轴（细线 + 圆形时间标记），时间标记颜色对应数据来源；右侧卡片宽度自适应，卡片顶部有色条标识来源，卡片内包含：时间、来源标签、内容、关联作品 |
| 主页面 | 艺术驻留排期 | 表格化列表，每行行高足够容纳多行说明；列包含：作品编号、作品名称、变更类型标签、判断理由、问题说明、下一步、状态；自动判断行有淡灰色背景区分人工判断 |
| 主页面 | 布展清单 | 等宽三列，每列顶部有分类标题和计数；卡片内包含：作品缩略图占位、编号、名称、尺寸、处理口径说明；不同分类卡片边框颜色不同 |

### 4.3 响应式

桌面端优先设计，平板端自适应缩放，移动端将布展清单三列改为单列堆叠，时间线保持垂直布局。所有交互支持鼠标点击，无触屏特殊优化。

### 4.4 数据展示规则

**艺术驻留排期判断逻辑**：
- 仅时间戳晚于对应作品清单，但内容不涉及核心结论变更 → 标记「补材料」
- 内容涉及作品位置、尺寸、灯光方案等核心结论变更 → 标记「改结论」
- 尺寸单位错误：明确标注来源（「尺寸单位来自灯光记录，需与灯光师确认」或「尺寸单位来自策展备注，需与策展团队核实」）
- 自动判断必须展示判断理由字段，不可隐藏

**布展清单分类规则**：
- 已确认：所有数据一致，无冲突，自动判断通过
- 待补：缺少必要信息，或存在未解决的单位错误/来源冲突
- 人工改过：策展人手动修改过的记录，保留修改痕迹和处理口径
