## 1. 产品概述
美术配色距离度量工具——面向设计课教师，批量比较学生作品的配色方案，在色相、明度、饱和度三个维度上计算感知距离，暴露同色不同名、背景色混入、距离尺度错等脏数据问题，并输出可导出的分析报告。
- 解决问题：教师手动比对配色耗时且易漏判，色相差异和明度/饱和度过近的问题难以系统识别
- 目标用户：设计课教师、课程助教、需要自检配色的学生

## 2. 核心功能

### 2.1 用户角色
| 角色 | 使用方式 | 核心权限 |
|------|----------|----------|
| 教师 | 直接使用 | 录入/编辑作品数据、查看分析、导出报告 |
| 助教 | 直接使用 | 录入作品数据、查看分析 |
| 学生 | 只读 | 查看自己的作品分析 |

### 2.2 功能模块
1. **配色总览页**：配色矩阵热力图、聚类可视化、脏数据预警面板、待补资料标记
2. **作品明细页**：单件作品HSL分解、与其它作品的距离对比、图片联动、脏数据详情
3. **分析报告页**：聚类解释文字、全局统计、待办事项与最终结论关联、CSV/PNG导出

## 3. 核心流程
1. 教师录入学生作品数据（配色色值、主题标签、作品图片URL），系统自动转换至HSL/OKLCH色彩空间
2. 系统计算所有作品间的配色距离矩阵（CIEDE2000感知距离），同时分色相/明度/饱和度计算分量距离
3. 脏数据检测引擎扫描：同色不同名（HEX相同但名称不同）、背景色混入（与预设背景色距离过近）、距离尺度异常（欧氏距离与感知距离比值超阈值）
4. 基于距离矩阵进行层次聚类，生成聚类标签与解释
5. 教师在总览页快速定位问题，进入明细页查看细节，在报告页导出结论
6. 待补资料记录（如缺少图片或标签）贯穿全流程，在报告中汇总

## 4. 用户界面设计

### 4.1 设计风格
- 主色：深炭灰(#1A1A2E) + 暖橙(#E8A838) 强调色
- 辅助色：冷灰蓝(#4A5568)用于边框与次要信息，薄荷绿(#48BB78)用于"正常/通过"状态
- 字体：标题用 "Playfair Display"（衬线体，带艺术气质），正文用 "DM Sans"（清晰几何无衬线）
- 布局：桌面优先，左侧导航 + 右侧内容区，卡片式模块组合
- 图标：lucide-react 线性图标
- 整体气质：美术馆导览手册风格——深色背景、精致衬线标题、留白考究

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI要素 |
|----------|----------|--------|
| 配色总览页 | 热力图 | 网格矩阵，色深映射距离，悬浮tooltip显示HSL+数值 |
| 配色总览页 | 聚类可视化 | 色轮+分组弧段，节点可拖拽，树状图折叠展开 |
| 配色总览页 | 预警面板 | 红橙卡片列表，图标+问题类型+建议操作按钮 |
| 配色总览页 | 待补标记 | 黄色虚线边框卡片，"待补"徽章+缺失字段提示 |
| 作品明细页 | HSL面板 | 三行横条（色相弧/明度渐变/饱和度渐变），数值标注 |
| 作品明细页 | 对比表 | 表格行，色块缩略图+距离数值+分量条形图 |
| 作品明细页 | 图片区 | 大图+色块叠加层，点击色块高亮对应区域 |
| 作品明细页 | 脏数据详情 | 折叠面板，问题类型+原值→建议值+应用按钮 |
| 分析报告页 | 聚类解释 | 卡片式，聚类色环缩略图+自然语言描述+代表作品链接 |
| 分析报告页 | 统计图 | 直方图+箱线图，交互式hover |
| 分析报告页 | 待办结论 | 棋盘列表，待办复选框+结论文字，状态联动 |
| 分析报告页 | 导出 | 按钮组，格式选择+一键导出 |

### 4.3 响应式
- 桌面优先设计，最小宽度1024px
- 平板：侧边栏折叠为图标模式
- 手机：底部Tab导航，热力图改为列表模式
