# 倾听记录质检员

Listener Record Quality Inspector - 给公益热线督导用的本地 AI/ML 质检工具

## 项目简介

本工具旨在帮助公益热线督导人员对志愿者的通话记录进行质检，主要解决以下痛点：

- **高危求助漏标**：自动检测通话中的自杀/自伤等高风险关键词，避免志愿者漏标
- **模板话术检测**：识别志愿者是否过度使用标准化话术，影响服务质量
- **回访时间冲突**：自动检测同一志愿者的回访安排是否存在时间冲突

## 功能特性

### 核心功能

1. **多格式文件导入**
   - 通话转写 TXT 文件
   - 风险标签 CSV 文件
   - 回访安排表 CSV 文件

2. **智能风险评估**
   - 本地规则引擎：基于关键词匹配的高风险检测
   - 轻量文本分类器：基于 TF-IDF + Logistic Regression 的机器学习模型
   - 规则与模型融合：取最高风险等级作为最终判定

3. **问题检测**
   - **漏标高风险检测**：对比系统判定与志愿者原始标签，识别可能被漏标的高风险案例
   - **模板话术检测**：检测通话中是否过度使用标准化、缺乏同理心的话术
   - **回访时间冲突检测**：识别同一志愿者回访间隔小于30分钟的时间冲突

4. **人工复核**
   - 支持督导对系统判定进行人工改判
   - 记录改判原因和改判人信息
   - 完整的审计追踪

5. **多格式导出**
   - **Markdown 督导报告**：完整的质检报告，包含风险分布、问题案例、待回访清单
   - **CSV 问题清单**：可直接导入工单系统的问题列表
   - **JSON 审计包**：包含完整分析数据的结构化格式，便于存档和后续分析

## 安装说明

### 环境要求

- Python 3.8 或更高版本
- pip 包管理器

### 安装步骤

1. 克隆或下载项目到本地

2. 进入项目目录：
```bash
cd xy4137
```

3. 创建虚拟环境（推荐）：
```bash
python -m venv venv
source venv/bin/activate  # macOS/Linux

venv\Scripts\activate  # Windows
```

4. 安装依赖：
```bash
pip install -r requirements.txt
```

## 完整验证流程

### 步骤 1: 准备数据文件

确保你有以下三类文件：

#### 1. 通话转写 TXT 文件

格式示例：
```
通话ID: CALL_20240501_001
时间: 2024-05-01 19:30:00
来电人: 匿名用户
志愿者: 张志愿者
时长: 15分30秒

----------------------------------------

来电人: 我最近心情有点低落，想找人聊聊。

志愿者: 您好，请您理解，我是倾听热线的志愿者...
```

**支持的元数据字段**（可选）：
- 通话ID / Call ID / call_id
- 时间 / Time / Timestamp
- 来电人 / 来电人ID / Caller / caller_id
- 志愿者 / 志愿者ID / Volunteer / volunteer_id
- 时长 / Duration

#### 2. 风险标签 CSV 文件

支持两种列名格式：

**英文列名：**
```csv
call_id,risk_level,tags,confidence,notes,tagged_by,tagged_at
CALL_001,高风险,自杀倾向,0.9,高危案例,张志愿者,2024-05-01 10:00:00
```

**中文列名：**
```csv
通话ID,风险等级,标签,置信度,备注,标注人,标注时间
CALL_001,高风险,自杀倾向,0.9,高危案例,张志愿者,2024-05-01 10:00:00
```

#### 3. 回访安排表 CSV 文件

支持两种列名格式：

**英文列名：**
```csv
call_id,caller_name,callback_time,assigned_volunteer,priority,status,notes
CALL_001,张先生,2024-05-02 10:00:00,张志愿者,紧急,待回访,高危案例
```

**中文列名：**
```csv
通话ID,来电人姓名,回访时间,分配志愿者,优先级,状态,备注
CALL_001,张先生,2024-05-02 10:00:00,张志愿者,紧急,待回访,高危案例
```

### 步骤 2: 导入文件

启动程序后，使用 `import` 命令导入文件：

```bash

# 导入所有类型的文件
import --transcripts /path/to/calls/*.txt --risk-tags /path/to/risk_tags.csv --callback /path/to/callback.csv
```

## 风险等级说明

| 风险等级 | 判定标准 | 建议行动 |
|----------|----------|----------|
| **极高风险** | 存在明确的自杀/自伤计划、遗书、具体方法描述 | 立即启动危机干预流程，24小时内必须回访，考虑联系紧急联系人或专业机构 |
| **高风险** | 存在强烈的自杀意念、严重的绝望感、无助感 | 24小时内优先回访，密切关注情绪变化，评估自杀风险 |
| **中风险** | 存在情绪困扰、抑郁/焦虑症状、压力过大 | 48小时内回访，提供情绪支持，必要时转介专业资源 |
| **低风险** | 一般情绪倾诉，无明显危机迹象 | 按常规流程处理，记录归档 |

## 关键词配置

系统使用的关键词定义在 `config.py` 文件中，可根据实际需求调整：

```python
# 高风险关键词（自杀/自伤相关）
HIGH_RISK_KEYWORDS = [
    "自杀", "轻生", "不想活", "活着没意思", "结束生命",
    "割腕", "跳楼", "上吊", "服药", "烧炭",
    # ...
]

# 中风险关键词（心理问题相关）
MEDIUM_RISK_KEYWORDS = [
    "抑郁", "焦虑", "失眠", "压力大", "崩溃",
    # ...
]

# 模板话术（缺乏同理心的标准化表达）
TEMPLATE_PHRASES = [
    "请您理解", "请您配合", "按照规定", "根据制度",
    # ...
]
```

## 模块说明

### 核心模块

| 模块文件 | 功能说明 |
|----------|----------|
| `config.py` | 全局配置、风险等级定义、关键词库、目录配置 |
| `data_parser.py` | 数据解析：支持 TXT/CSV 文件解析，提取通话记录、风险标签、回访安排 |
| `feature_extractor.py` | 特征提取：关键词匹配、情绪评分、紧急程度评分、模板话术检测 |
| `text_classifier.py` | 文本分类器：基于 TF-IDF + Logistic Regression 的轻量模型 |
| `risk_fusion.py` | 规则融合：规则引擎与模型结果融合，时间冲突检测，待回访清单生成 |
| `storage.py` | 数据存储：会话管理、人工改判记录、数据持久化 |
| `exporter.py` | 报告导出：Markdown/CSV/JSON 三种格式导出 |
| `main.py` | 主程序入口：CLI 交互界面、命令处理 |

### 数据流程

```
输入文件
    ↓
[data_parser.py] 解析数据
    ↓
[feature_extractor.py] 提取特征
    ↓
    ├─→ [text_classifier.py] 模型预测
    └─→ 规则引擎（关键词匹配）
    ↓
[risk_fusion.py] 规则与模型融合
    ↓
检测：漏标高风险、模板话术、时间冲突
    ↓
[storage.py] 支持人工改判
    ↓
[exporter.py] 导出报告
```

## 注意事项

1. **本地运行**：本工具完全在本地运行，无需网络连接，保护用户隐私
2. **模型训练**：首次运行时会自动使用默认数据训练模型，模型文件保存在 `models/` 目录
3. **数据安全**：所有分析数据仅保存在本地，建议定期备份 `data/` 目录
4. **关键词扩展**：可根据实际需求在 `config.py` 中扩展关键词库
5. **阈值调整**：模板话术检测阈值（默认 10%）、时间冲突阈值（默认 30 分钟）可在对应模块中调整
