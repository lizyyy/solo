# 救援调度夜班

一款为桌游社活动热场设计的本地策略小游戏。玩家在一张小城市网格上派出救护车、维修车和志愿者队伍处理随机事件，考验你的调度能力！

## 游戏简介

在"救援调度夜班"中，你扮演城市应急调度中心的指挥官。夜晚的城市充满了各种突发事件：市民受伤需要救护车、区域断电需要维修车、道路堵塞需要疏通、物资短缺需要配送。你的任务是合理调度三种单位，在有限的回合内处理尽可能多的事件，保持城市的信誉值。

## 游戏特性

- **策略性调度**：三种不同类型的单位，各有专长
- **动态事件**：随机事件牌堆，每回合抽取新事件
- **路径规划**：A*寻路算法，自动计算最优路径
- **道路堵塞**：堵塞事件会影响通行，需要优先处理
- **存档/读档**：随时保存和加载游戏进度
- **回放功能**：游戏结束后可回放整局游戏
- **多个难度**：提供教程、简单、普通、困难四种关卡

## 游戏规则

### 单位类型

| 单位 | 图标 | 速度 | 处理时间 | 可处理事件 |
|------|------|------|----------|------------|
| 救护车 | 🚑 | 3格/回合 | 2回合 | 受伤事件 |
| 维修车 | 🔧 | 2格/回合 | 3回合 | 断电、堵塞事件 |
| 志愿者 | 🧑‍🤝‍🧑 | 4格/回合 | 1回合 | 短缺、堵塞事件 |

### 事件类型

| 事件 | 图标 | 时间限制 | 超时惩罚 | 处理单位 |
|------|------|----------|----------|----------|
| 受伤 | 🩸 | 5回合 | -20信誉 | 救护车 |
| 断电 | ⚡ | 6回合 | -15信誉 | 维修车 |
| 堵塞 | 🚧 | 4回合 | -10信誉 | 维修车/志愿者 |
| 短缺 | 📦 | 5回合 | -12信誉 | 志愿者 |

### 胜负条件

- **胜利条件**：达到30回合时信誉值 ≥ 50
- **失败条件**：
  - 信誉值 ≤ 0
  - 达到30回合时信誉值 < 50

### 游戏流程

1. **开始游戏**：选择关卡（默认为教程关卡）
2. **观察地图**：查看初始事件和单位位置
3. **选择单位**：点击地图上的单位或右侧单位列表
4. **派遣行动**：
   - 点击事件位置：自动派遣单位前往处理
   - 点击任意位置：移动单位到该位置
5. **推进回合**：点击"下一回合"按钮
   - 单位按速度移动
   - 工作中的单位增加进度
   - 事件时间减少
   - 自动抽取新事件
6. **处理事件**：
   - 单位到达事件位置后自动开始工作
   - 工作完成后事件解决，信誉 +5
7. **游戏结束**：显示胜负结果和统计数据

## 快速开始

### 环境要求

- 现代浏览器（Chrome、Firefox、Safari、Edge）
- 支持 ES6 模块
- 本地 HTTP 服务器（用于运行）

### 启动方式

#### 方法一：使用 Python 启动

```bash
# 进入项目目录
cd /path/to/xy4210

# 启动本地服务器
npm start
# 或
python3 -m http.server 8080
```

然后在浏览器中访问：`http://localhost:8080`

#### 方法二：使用其他 HTTP 服务器

你也可以使用任何静态文件服务器，例如：

- Node.js: `npx serve .`
- VS Code: 使用 Live Server 扩展

### 验证游戏流程

按照以下步骤验证一局完整的游戏流程：

1. **启动游戏**
   - 打开浏览器访问 `http://localhost:8080`
   - 确认游戏界面正常显示
   - 检查顶部信息：回合=1，信誉=100

2. **观察初始状态**
   - 地图上应该有：
     - 救护车 🚑 在 (0, 0)
     - 维修车 🔧 在 (9, 0)
     - 志愿者 🧑‍🤝‍🧑 在 (0, 9)
   - 右侧"当前事件"面板显示初始事件
   - 右侧"可用单位"面板显示三个单位

3. **执行第一个行动**
   - 点击救护车 🚑（在地图或单位列表中）
   - 点击一个受伤事件 🩸 的位置
   - 观察：
     - 救护车状态变为"移动中"
     - 游戏日志显示"派遣单位处理事件"
     - 事件显示"已分配单位"

4. **推进回合**
   - 点击"下一回合"按钮
   - 观察：
     - 回合数增加
     - 救护车根据速度移动
     - 事件剩余时间减少
     - 可能出现新事件
     - 游戏日志记录回合变化

5. **处理另一个事件**
   - 选择维修车或志愿者
   - 点击对应的事件（断电/堵塞/短缺）
   - 确认单位开始移动

6. **保存游戏**
   - 点击"保存游戏"按钮
   - 看到"游戏保存成功"提示
   - 游戏日志记录保存操作

7. **继续游戏**
   - 继续点击"下一回合"
   - 观察单位到达事件位置后自动开始工作
   - 工作完成后：
     - 事件状态变为"已解决"
     - 信誉值 +5
     - 游戏日志记录事件解决

8. **测试读档**
   - 点击"重新开始"并确认
   - 游戏重置到初始状态
   - 点击"加载存档"并确认
   - 游戏恢复到保存时的状态

9. **完成一局游戏**
   - 持续推进回合直到：
     - 信誉值降为0（失败）
     - 或达到30回合（根据信誉判断胜负）
   - 观察游戏结束模态框
   - 查看统计数据：最终回合、最终信誉、已解决事件、超时事件

10. **查看回放**
    - 游戏结束后（或游戏中）点击"查看回放"
    - 在回放模态框中：
      - 点击"开始回放"自动播放
      - 或点击"下一步"逐帧查看
      - 观察地图和日志随步骤变化
    - 点击"关闭回放"返回

## 操作说明

### 地图交互

- **选择单位**：点击地图上的单位图标或右侧单位列表
- **移动单位**：选中单位后，点击目标位置（道路区域）
- **派遣处理事件**：选中单位后，点击事件图标
- **取消选择**：再次点击已选中的单位

### 按钮功能

| 按钮 | 功能 |
|------|------|
| 抽取事件 | 手动从牌堆抽取一个事件（可选） |
| 下一回合 | 推进一个回合，执行所有行动 |
| 保存游戏 | 保存当前进度到浏览器本地存储 |
| 加载存档 | 加载之前保存的游戏进度 |
| 查看回放 | 打开回放模态框，查看游戏历史 |
| 重新开始 | 重置游戏到初始状态 |

### 界面说明

- **顶部信息栏**：显示当前回合、信誉值、活跃事件数
- **左侧地图**：10×10的城市网格，显示单位和事件位置
- **右侧面板**：
  - **可用单位**：显示所有单位的状态和位置
  - **当前事件**：显示活跃事件，按剩余时间排序
  - **事件牌堆**：显示剩余卡牌数，可手动抽取
  - **游戏操作**：各种功能按钮
  - **游戏日志**：记录游戏中的重要事件

## 技术实现

### 核心模块

1. **类型系统** (`src/types/index.js`)
   - 定义所有数据类型和枚举
   - 游戏默认配置
   - 单位与事件的映射关系

2. **游戏规则** (`src/rules/gameRules.js`)
   - 胜负条件判断
   - 路径和位置计算
   - 单位行动规则
   - 事件处理规则

3. **状态管理** (`src/state/gameState.js`)
   - 游戏状态的创建和更新
   - 事件牌堆管理
   - 关卡数据加载

4. **路径计算** (`src/pathfinding/pathfinder.js`)
   - A*寻路算法实现
   - 考虑道路堵塞的路径计算
   - 最短路径和回合数计算

5. **单位管理** (`src/units/unitManager.js`)
   - 单位移动逻辑
   - 事件派遣逻辑
   - 工作进度管理

6. **存储系统** (`src/storage/saveManager.js`)
   - localStorage 读写
   - 存档导入导出
   - 存档信息查询

7. **回放系统** (`src/replay/replayManager.js`)
   - 回放步骤记录
   - 回放控制器（播放/暂停/步进）
   - 步骤变化回调

8. **UI组件** (`src/ui/`)
   - 地图渲染和交互
   - 单位和事件列表渲染
   - 模态框管理
   - 日志显示

### 数据持久化

- 游戏存档使用浏览器的 `localStorage` 存储
- 存储键：`rescue_dispatch_save`
- 存储内容：
  - 游戏状态快照
  - 回放历史
  - 时间戳

### 事件随机性

- 事件牌堆包含12张卡牌：每种事件3张
- 每次抽取后洗牌，实现无限循环
- 每回合自动抽取配置数量的事件
- 事件位置随机生成在可用的道路上

## 扩展开发

### 添加新关卡

在 `src/data/levels/tutorial.js` 中添加新的关卡对象：

```javascript
export const MyLevel = {
  name: '我的自定义关卡',
  description: '关卡描述',
  config: {
    mapWidth: 10,
    mapHeight: 10,
    initialReputation: 100,
    maxTurns: 30,
    eventDrawsPerTurn: 1
  },
  units: [
    { type: UnitType.AMBULANCE, position: { x: 0, y: 0 } },
    // ... 更多单位
  ],
  initialEvents: [
    { type: EventType.INJURY, position: { x: 5, y: 5 } },
    // ... 更多初始事件
  ]
};
```

然后在 `src/main.js` 中修改 `startNewGame` 函数使用新关卡。

### 调整游戏平衡

在 `src/types/index.js` 中修改 `DefaultGameConfig` 对象：

- `unitSpeeds`：调整各单位的移动速度
- `unitWorkTimes`：调整各单位的工作时间
- `eventPenalties`：调整事件超时的信誉惩罚
- `eventTimeLimits`：调整事件的时间限制
