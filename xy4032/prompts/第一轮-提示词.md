我想做一个给生物实验室助理用的本地命令行工具，叫“96孔板稀释排版管家”。我们做 qPCR 或酶标实验前，经常要把一批样品按不同初始浓度稀释到目标浓度，再排到 96 孔板里；现在靠 Excel 手算，最容易出错的是单位混用、移液体积低于移液枪范围、重复孔和空白对照位置被挤掉。请从 0 到 1 做一个可直接运行的 Python CLI 项目：init 命令能创建项目配置，维护默认单位、最小/最大移液体积、死体积、板型布局和保留孔；import-samples 能导入样品 CSV，字段包括样品编号、批次、初始浓度、浓度单位、可用体积、目标浓度、重复孔数和备注；plan 命令要计算每个样品的稀释步骤和孔位排布，自动处理 ng/ul、pg/ul、nM、uM 这些单位换算，发现目标浓度高于原液、可用体积不足、移液体积越界、孔位不够、样品编号重复时要给出清楚错误，不要静默跳过。apply 命令确认方案后写入本地 ledger.json，扣减样品体积并记录板号、孔位、稀释倍数和操作时间；undo 命令能撤销最近一次 apply。还要有 export-plate 命令导出 96 孔板 CSV 和 Markdown 操作单，history 命令按批次或日期查询历史方案。请把 CLI 入口、单位换算、样品模型、稀释计算、孔位排布、账本存储、导出报告、示例数据和测试拆成多个文件，不要写成单文件脚本。README 里写清楚安装方式、示例命令，以及如何用临时目录验证 init、导入样品、生成方案、确认扣减、撤销和导出板图这些核心流程。
