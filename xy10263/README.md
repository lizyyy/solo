# 剧本杀房间线索复盘台

剧本杀主持人复盘工具，用于整理玩家、线索和时间线，检测冲突和遗漏，辅助还原真相。

## 安装运行

```bash
npm install
npm run dev
```

默认运行在 `http://localhost:5173`

## 样例入口

启动后点击顶部工具栏的 **「样例」** 按钮，即可加载预设的谋杀案复盘场景，体验完整流程。

样例包含：
- 4 名玩家角色（侦探、富商之女、管家、医生）
- 7 条线索（物证、证词、文档、特殊信息）
- 预设的冲突和遗漏检测用例

## 核心操作

### 1. 玩家管理
- 左侧「玩家角色」面板管理玩家
- 支持添加、编辑、删除玩家
- 每个玩家可设置头像颜色

### 2. 线索录入
- 中间「线索管理」面板录入线索
- 每条线索需设置：
  - 归属玩家
  - 时间点（用于时间轴排序）
  - 类型（物证/证词/文档/特殊）
  - 状态（发现/已分析/未解决/已解决）

### 3. 时间轴分析
- 右侧「时间轴」面板可视化线索分布
- 时间点按顺序排列，缺失时间点会高亮提示
- 可查看时间覆盖百分比

### 4. 冲突与遗漏
- 点击顶部 **「分析」** 按钮运行检测
- 「冲突」标签页显示检测到的矛盾点
- 「遗漏」标签页显示时间线缺口和未关联玩家
- 点击「标记解决」可记录解决方案

### 5. 数据持久化
- 所有操作自动保存到浏览器本地存储
- 刷新页面后自动恢复工作区
- 支持导出（JSON/Markdown）和导入

### 6. 导出报告
- 顶部 **「导出」** 按钮提供两种格式：
  - **JSON**: 完整数据备份，可用于导入
  - **Markdown**: 结构化复盘报告，包含统计、冲突、遗漏

## 如何检查结果

### 1. 统计概览
左侧面板实时显示：
- 总线索数、玩家数
- 时间线覆盖率
- 待处理问题数（冲突+遗漏）
- 各玩家线索分布条形图

### 2. 时间线验证
- 检查每个时间点是否都有线索覆盖
- 虚线框表示该时间点缺少信息
- 覆盖率达到 100% 表示时间线完整

### 3. 冲突验证
- 红色卡片表示未解决的冲突
- 绿色卡片表示已解决
- 解决时可填写备注记录推理过程

### 4. 导出校验
- 每次导出包含数据哈希和校验码
- 重跑相同数据时，统计结果一致
- 导入导出的 JSON 文件可验证数据完整性

### 5. 场景验证关键路径
样例场景验证步骤：
1. 点击「样例」加载数据
2. 观察时间轴：T0-T4 全覆盖
3. 点击「分析」运行检测
4. 查看冲突：管家证词与医生证词矛盾
5. 查看遗漏：部分线索仅标记为「发现」未分析
6. 导出报告，检查数据哈希
7. 刷新页面，验证工作区自动恢复

## 技术保障

- **数据一致性**: 使用哈希校验防止导出膨胀
- **刷新恢复**: localStorage 自动持久化
- **冲突检测**: 自动检测证词矛盾、时间冲突
- **缺失分析**: 识别时间线缺口、未关联玩家
