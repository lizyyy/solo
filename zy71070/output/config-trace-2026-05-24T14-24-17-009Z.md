## 合并配置类型说明

| 类型 | 说明 |
|------|------|
| NULL覆盖 | 显式设置为null，覆盖之前的值 |
| 值覆盖 | 新值覆盖旧值 |
| 数组替换 | 新数组完全替换旧数组 |
| 数组合并 | 新数组追加到旧数组后面 |
| 数组去重合并 | 合并数组并去重 |
| 对象合并 | 递归合并对象属性 |
| 新增值 | 该层级新增配置项 |
