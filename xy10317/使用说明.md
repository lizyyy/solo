# 园区访客车牌放行系统 - 使用说明

## 一、系统概览

这是一个专门给门岗保安用的访客车辆管理系统，就像你们平时用的门禁系统一样，只不过这个是用命令行操作的。

**系统能做什么：**
- 查预约：访客提前预约了才能进
- 扫车牌：车辆到门口，扫一下就知道能不能进
- 管换车：访客临时换车了，要走审批流程
- 记黑名单：有问题的车不能进
- 算超时：访客超过约好的时间走，系统会提醒
- 写交班：下班时一键生成交班记录
- 出报表：每天的访客情况自动汇总

---

## 二、谁来操作、什么时候操作

| 操作 | 操作人员 | 何时操作 |
|------|----------|----------|
| 录入访客预约 | 前台/行政 | 访客来之前提前录入 |
| 审批车牌变更 | 安保主管 | 访客申请换车时审批 |
| 扫描车牌入场 | 门岗保安 | 车辆到门口时 |
| 扫描车牌出场 | 门岗保安 | 车辆离开时 |
| 添加黑名单 | 安保主管 | 发现问题车辆时 |
| 生成交班日志 | 门岗保安 | 换班时（交班前） |
| 生成日报表 | 行政/安保主管 | 每天下班或第二天早上 |

## 四、日常操作指南

### 场景1：正常访客入场（最常用）

**什么时候做：** 访客开车到门口了

**怎么操作：**

```bash
# 先查一下这个车牌有没有预约
python3 -m park_visitor_system.cli check --plate 京A12345

# 没问题的话，执行入场扫描
python3 -m park_visitor_system.cli entry --plate 京A12345 --operator 张保安 --gate 南门
```

**看什么结果：**
- ✅ 显示"入场放行" → 开闸放行
- ❌ 显示"入场拦截" → 看下面的拦截原因，不要开闸

---

### 场景2：访客说换车了（临时换车审批）

**什么时候做：** 访客打电话说"我约的是京B67890，但今天开的是京B00001"

**怎么操作：**

**第一步：访客提交换车申请**
（访客自己或协助的前台操作）
```bash
python3 -m park_visitor_system.cli request-plate-change \
    --original-plate 京B67890 \
    --new-plate 京B00001 \
    --reason "原车辆故障，换车来访"
```

**第二步：主管审批**
（安保主管操作）
```bash
# 先看申请编号
# 然后审批
python3 -m park_visitor_system.cli approve-plate-change PC20240101120000
```

**第三步：新车牌入场**
```bash
python3 -m park_visitor_system.cli entry --plate 京B00001 --operator 李保安
```

---

### 场景3：访客离场

**什么时候做：** 访客开车要走了

**怎么操作：**

```bash
python3 -m park_visitor_system.cli exit --plate 京A12345 --operator 张保安
```

**看什么结果：**
- ✅ 显示"出场放行" → 正常放行
- ⚠️ 显示"超时离场" → 提醒访客超时了，记录下来
- ❌ 显示"出场异常" → 看提示，可能是没入场记录

---

### 场景4：遇到拦截该看哪里

**如果系统显示"入场拦截"，看一下拦截原因：**

| 拦截原因 | 怎么处理 | 找谁确认 |
|----------|----------|----------|
| 黑名单拦截 | 直接不让进 | 看黑名单记录，问主管 |
| 重复入场 | 这车已经在园里了 | 查"当前在园车辆"列表 |
| 预约未找到 | 这个车牌没预约 | 让访客联系预约人 |
| 预约未审批 | 预约还没通过 | 让访客催审批 |
| 预约已过期 | 预约时间过了 | 让访客重新预约 |
| 预约未到时间 | 来得太早了（提前30分钟以上） | 让访客等会儿 |

**怎么查这些信息：**

```bash
# 查预约列表
python3 -m park_visitor_system.cli list --type reservations

# 查黑名单
python3 -m park_visitor_system.cli list --type blacklist

# 查当前在园车辆
python3 -m park_visitor_system.cli list --type in-park

# 查今天发生了什么事
python3 -m park_visitor_system.cli list --type events
```

---

### 场景5：交班时生成日志

**什么时候做：** 换班的时候，比如白班换夜班

**怎么操作：**

```bash
# 生成今天8点到20点的交班日志
python3 -m park_visitor_system.cli shift-log \
    --start-time "2024-01-01 08:00" \
    --end-time "2024-01-01 20:00" \
    --operator "张保安" \
    --output "data/shift_log_20240101.json"
```

**日志里有什么：**
- 今天进了多少车
- 今天出了多少车
- 拦截了多少车
- 有没有违规（超时、黑名单等）
- 每一笔的详细记录

---

### 场景6：生成日报表

**什么时候做：** 每天下班时，或第二天早上

**怎么操作：**

```bash
# 生成1月1日的日报
python3 -m park_visitor_system.cli daily-report \
    --date "2024-01-01" \
    --output "data/daily_report_20240101.json"
```

**报表里有什么：**
- 当天预约总数
- 实际入场数
- 实际出场数
- 拦截数
- 过期预约数
- 超时离场数
- 平均停留时长

## 六、常见问题

### Q1：数据存在哪里？
**A：** 所有数据都在 `data/` 文件夹里，是 JSON 格式的文本文件，可以直接打开看。

### Q2：误操作了怎么办？
**A：** 目前版本不支持删除单条记录，如果误操作了，可以：
1. 找技术人员修改 `data/events.json` 文件
2. 或者用 `run_demo.sh` 里的"清空所有数据重新开始"（但会丢所有数据）

### Q3：能模拟历史时间吗？
**A：** 可以！大多数命令都支持 `--time` 参数，比如：
```bash
python3 -m park_visitor_system.cli entry --plate 京A12345 --time "2024-01-01 09:30"
```

### Q4：预约时间怎么算？
**A：** 系统允许提前30分钟入场，超过离场时间算超时。

### Q5：怎么知道当前哪些车在园里？
**A：** 运行这个命令：
```bash
python3 -m park_visitor_system.cli list --type in-park
```
