# 棋类培训升班评估器

基于对局记录、出勤记录和老师评价的智能升班评估系统，帮助棋类培训班科学判断学生是否升班。

## 核心业务闭环

```
对局导入 → 胜率趋势分析
                              ↘
出勤加权计算 → 升班评估 → 确认/拒绝 → 家长报告
                              ↗
老师评价标签
```

## 功能特性

- **学生管理**：新增、修改、删除学生信息
- **对局导入**：批量导入对局记录，支持对手级别区分
- **胜率趋势**：累积胜率趋势图，识别上升/下降/稳定趋势
- **出勤加权**：根据样本量动态调整出勤权重（10%-25%）
- **老师评价**：预设正/负评价标签，影响评估分数
- **升班评估**：综合胜率（45%-65%）+ 出勤 + 老师评价，含强手战胜加分
- **决策操作**：确认升班 / 拒绝升班
- **家长报告**：一键生成完整评估报告
- **样例演示**：一键运行3种典型学生场景

## 主流程演示

### 方式一：前端一键演示

1. 启动服务后访问 `http://localhost:3000`
2. 点击「样例演示」标签
3. 点击三个样例按钮之一，观察控制台输出：
   - **样例一（优秀生）**：高胜率 + 高出勤 + 正面评价 → **升班成功**
   - **样例二（边缘生）**：胜率一般 + 出勤一般 → **暂不推荐**

### 方式二：手动完整流程

1. **新增学生**：学生管理 → 新增学生 → 填写信息提交
2. **导入对局**：数据导入 → 选择学生 → 粘贴JSON → 导入
3. **导入出勤**：数据导入 → 选择学生 → 粘贴JSON → 导入
4. **执行评估**：升班评估 → 选择学生 → 勾选老师标签 → 执行评估
5. **查看结果**：查看综合评分、胜率趋势、评估理由
6. **决策操作**：建议升班时可「确认升班」或「拒绝升班」
7. **导出报告**：生成家长报告 → 查看完整评估信息

## 核心算法说明

### 胜率计算
```
胜率 = (胜场数 + 平局数 × 0.5) / 总场数
```

### 出勤权重（动态调整）
| 出勤记录数 | 权重 |
|-----------|------|
| ≥20条     | 25%  |
| 10-19条   | 20%  |
| 5-9条     | 15%  |
| <5条      | 10%  |

### 老师评价分数
```
评价分数 = (正面标签数 + 0.5 × 其他标签数) / 总标签数
评价权重 = 10% + min(标签数, 5) × 3%
```

### 综合评分
```
综合评分 = (胜率 × 胜率权重 + 出勤 × 出勤权重 + 评价 × 评价权重) × (1 + 额外加分)
胜率权重 = 1 - 出勤权重 - 评价权重 (最低45%)
```

### 额外加分项
- 战胜2+名高一级对手：+2%
- 战胜3+名高一级对手：+5%
- 战胜5+名高一级对手：+8%
- 胜率稳步上升：+2%
- 胜率明显上升：+5%

### 升班判定规则
1. 综合评分 ≥ 80分 → 推荐升班
2. 70-79分 + 胜率上升 → 推荐升班
3. 70-79分 + 出勤≥90% + 正面标签≥3个 → 推荐升班
4. 胜率 < 40% → 一票否决（暂不升班）
5. 出勤率 < 60% → 一票否决（暂不升班）

## 异常操作演示

| 操作场景 | 预期结果 |
|---------|---------|
| 对局少于5局评估 | 提示"对局数量不足"，分数偏低 |
| 胜率<40%但其他分高 | 评估结果显示"胜率过低"，不推荐升班 |
| 出勤率<60% | 评估结果显示"出勤率过低"，不推荐升班 |
| 对"暂不推荐"的记录确认升班 | 返回400错误："该评估未推荐升班" |
| 精英班继续升班 | 返回400错误："已在最高级别，无法继续升班" |
| 无评估记录生成报告 | 报告显示"暂无评估记录" |

## 关键判断依据

所有关键判断都体现在：
- **测试断言**：`tests/evaluation.test.js` 中明确的预期值

- **前端页面**：评估结果卡片、评分细项表、胜率趋势图
