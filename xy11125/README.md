# 水站配送队水桶流转追踪 CLI 工具

## 项目概述

本工具专为水站配送队设计，用于解决水桶流转追踪过程中数据质量校验、异常检测和可追溯性问题。不再依赖复制表格的方式处理，实现规则化、自动化的数据清洗。

## 核心特性

- ✅ **保留原始行号**：所有输出文件都保留原始数据的行号，方便定位问题
- ✅ **记录源文件名**：支持多文件处理时追踪数据来源
- ✅ **详细异常报告**：不只是统计总数，而是逐条记录异常原因和位置
- ✅ **桶号重复检测**：检测同一水站同一天的桶号重复问题
- ✅ **司机补录校验**：验证补录的司机ID、时限、原因是否合规
- ✅ **状态流转检查**：确保水桶状态按业务规则正常流转
- ✅ **可复跑设计**：修正数据后可重新运行验证，无需手动对照

## 快速开始

### 1. 安装依赖

```bash
npm install
```

### 2. 运行样例数据验证

```bash
npm test
```

或直接运行：

```bash
node src/cli.js validate -i sample-data/sample-2026-05.csv
```

### 3. 查看输出结果

运行完成后，在 `output` 目录下生成两个文件：

- **异常报告**：包含所有有问题的记录，每条都有：
  - 原始行号
  - 源文件名
  - 异常数量
  - 异常类型
  - 详细异常信息（列名、错误值、规则说明）

- **清洗结果**：包含所有验证通过的记录，保留：
  - 原始行号
  - 源文件名
  - 所有原始业务字段

### 4. 查看工具帮助

```bash
node src/cli.js --help
node src/cli.js info
```

## 验证规则说明

### 桶号规则
- 格式：`BT` 开头，后跟 6-10 位大写字母或数字
- 示例：`BT000001`、`BTABCD1234`
- 桶号为必填项

### 重复检测规则
- 同一水站同一天不允许桶号重复
- 已标记为「配送中」的桶不能重复标记为配送中

### 司机补录规则
- 必须填写司机ID
- 补录时间必须在配送日期后 48 小时内
- 补录原因必须是预设的合法原因：
  - 系统故障漏录
  - 现场临时加单
  - 交接时遗漏
  - 客户要求补送
  - 其他合理原因

### 状态流转规则
```
in_stock (在库)
  └→ out_for_delivery (待配送)
  └→ returned (已回收)

out_for_delivery (待配送)
  └→ in_transit (配送中)
  └→ delivered (已送达)
  └→ returned (已回收)
  └→ lost (丢失)

in_transit (配送中)
  └→ delivered (已送达)
  └→ returned (已回收)

delivered (已送达)
  └→ returned (已回收)
  └→ recycled (已循环)

returned (已回收)
  └→ in_stock (在库)
  └→ damaged (损坏)

lost (丢失)、damaged (损坏)、recycled (已循环) 为终态
```

## 自定义规则

编辑 `rules/default.json` 文件可调整以下参数：

- `bucketNumberRules.format.pattern`：桶号格式正则表达式
- `driverEntryRules.maxSupplementHours`：补录最大时限（小时）
- `driverEntryRules.validReasons`：合法补录原因列表
- `statusTransition.rules`：状态流转规则
- 其他业务字典值

## 给新接手人员的建议

1. **先跑样例**：按照「快速开始」步骤运行样例数据，确保工具正常工作
2. **理解规则**：阅读 `rules/default.json` 中的规则说明和业务口径
3. **查看异常**：对照异常报告和原始样例数据，理解各种异常的判断逻辑
4. **调整配置**：根据实际业务需求修改配置文件中的参数
5. **导入数据**：将真实数据按样例格式准备好，运行工具进行验证

## 命令行参数

```bash
node src/cli.js validate [选项]

选项：
  -i, --input     输入CSV文件路径（必填）
  -c, --config    规则配置文件路径（可选，默认 rules/default.json）
  -o, --output    输出目录路径（可选，默认 output 目录）
  --help          显示帮助
  --version       显示版本号
```
