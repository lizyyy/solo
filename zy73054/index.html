归因公式与单位 透明

异常归因权重得分 S：
S = W_sp × F_sp + W_te × F_te + W_hs × F_hs + W_bd × F_bd
范围: 0 ~ 100 分　|　≥60 判定为「异常」，≥80 为「严重异常」
① 备件滞后因子 F_sp：
F_sp = min( 100, (到货延迟天数 T_delay / 停机窗口 W_stop) × 100 )
W_sp = 0.40 (40%权重) [T_delay: 天, W_stop: 天]
② 班组执行因子 F_te：
F_te = min( 100, (实际用时 T_act − 标准工时 T_std) / T_std × 100 )
W_te = 0.25 (25%权重) [T_act, T_std: 小时]
③ 交接合规因子 F_hs：
F_hs = 100 × (1 − 交接完整率 R_hs)
W_hs = 0.20 (20%权重) [R_hs: 0~1]
④ 边界突破因子 F_bd：
F_bd = 100 × 突破项数 N_bd / 总检查项 N_total
W_bd = 0.15 (15%权重) [N_bd: 项]

边界值定义 边界

  • T_delay ≤ 0 天 → F_sp = 0（备件按时/提前）
  • T_delay = W_stop → F_sp = 100（延迟=窗口，满分）
  • T_act ≤ T_std → F_te = 0（不超工时）
  • R_hs ≥ 0.95 → F_hs = 0（交接≥95%视为完整）
  • S < 60 → 正常　|　60≤S<80 → 异常　|　S≥80 → 严重
  • 阈值临时偏移 > 15% → 标记为「脏数据」⚠
