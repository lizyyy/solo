原始想法：
我想做一个给小型水培种植社群用的本地营养液配方计算 CLI。我们每次按不同作物阶段配 A/B 液时，都要从一堆盐类库存表里手算氮、磷、钾、钙、镁这些元素含量，最怕单位换错、库存不够、某个元素超标。请从 0 开始做一个可运行的 Python 命令行项目：用户可以用 CSV 维护原料库存（名称、纯度、每克含有哪些元素、剩余克数、单价）和作物目标配方（目标体积、各元素 ppm 下限/上限、禁用原料、备注）；calc 命令要根据目标配方给出一份可执行称量方案，尽量贴近目标区间并提示无法满足的元素，不能让库存扣成负数。apply 命令确认使用方案后要写入本地 ledger.json，记录批次、原料扣减、成本和偏差；undo 命令能安全撤销最近一次扣减；check 命令能检查 CSV 字段缺失、单位非法、同一原料重复、元素名拼错和目标上下限冲突；report 命令能导出 Markdown 和 CSV 两种报告，包含每升成本、各元素实际 ppm、偏差原因和库存预警。请把 CSV 解析、单位/元素模型、配方求解、库存账本、报告生成和 CLI 入口拆成多个文件，补 README、示例数据和几条能跑的测试，让我能用临时目录完整验证 check、calc、apply、undo、report 这些流程。
